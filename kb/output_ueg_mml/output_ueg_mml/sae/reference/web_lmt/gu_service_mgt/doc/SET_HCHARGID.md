# 设置IMPI或PISI的计费地址ID(SET HCHARGID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPI或PISI的计费地址ID。 计费地址ID对应的具体地址信息可以在客户端上通过**MOD HCHGTPL**操作进行修改。

## 注意事项

参数IMPI和PISI必须存在且仅能存在一个。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI       | IMPI     | 用于指定一个用来配置计费地址ID的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                                                                                                                          |
| PISI       | PISI     | 用于指定一个用来配置计费地址ID的PISI，要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                                                                                                                          |
| CHARGTPLID | 计费地址模板ID | 用于指定一个计费地址模板，该参数必须通过ADD HCHGTPL命令定义后才能在此处索引。 取值范围：0～1024 默认值：无 说明： 当通过SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，该参数需要引用用户签约的“HLR序列号”下的计费地址模板。当用户只开户但不执行本命令签约该业务，执行LST HCHARGID命令查询时，参数“计费地址模板ID”默认为“0”。ADD HCHGTPL命令中“计费地址模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003243：计费地址模板ID不存在”错误提示。 |

## 使用实例

设置IMPI或PISI的计费地址ID。IMPI：impiinfo，计费地址模板ID：10。

```
SET HCHARGID: IMPI="impiinfo", CHARGTPLID=10;
```
