# 增加EPS QoS模板替代配置(ADD REPEPSQOSID)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游到指定的MME/S4SGSN/AAA时下发错误的QoS，因此执行本命令前，需要和运营商的EPS QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保添加的EPS QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中增加一条EPS QoS模板替代配置记录，将一个EPS QoS模板默认替换为另一个EPS QoS模板进行下发。增加了一条替代配置记录之后，如果用户漫游到指定的Diameter服务节点，并需要下发EPS QoS数据时，UDM将根据EPS QoS模板替代配置，使用替代模板代替用户签约的EPS QoS模板进行下发。

如果同一EPS QoS模板通过**SET DEFREPEPSQOSID**命令设置了缺省的替代配置，则缺省替代配置将不生效，UDM使用**ADD REPEPSQOSID**命令签约的替代配置进行下发。

## 注意事项

- 当设置了EPS QoS模板替代配置，系统会根据用户签约的EPS QoS模板找到替换的模板配置并下发数据，用户原来签约的EPS QoS模板将不会生效，会影响大量在网用户，因此现网执行该操作时需要慎重。执行该命令前需确定待添加的EPS QoS替代配置和运营商的EPS QoS模板替代配置表完全一致，并确保使用原EPS QoS模板的MME/S4-SGSN/3GPP AAA Server上支持替换后的EPS QoS模板对应的QoS数据。
- 该命令不允许进行批操作。
- 替换后和替换前的EPS QoS模板中，“QoS分类ID”（QCI）取值对应的Resource Type需要保持一致。GBR类型的QCI替换后必须仍为GBR类型，Non-GBR类型的QCI替换后必须仍为Non-GBR类型。QCI取值和Resource Type具体的对应关系，请参见协议3GPP TS 23.203中的相应内容。
- 系统中增加的EPS QoS模板替代配置的记录数不能超过3000条。

## 参数说明

| 参数标识           | 参数名称             | 参数说明                                                                                                                                                                                                                                                         |
|:---------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号           | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                 |
| USREPSQOSID    | 用户签约的EPS QoS模板ID | 用于标识一个待设置替换关系的EPS QoS模板ID。当用户签约了该ID对应的EPS QoS模板时，将使用“替代的EPS QoS模板ID”设置的模板下发QoS数据。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                     |
| PEERENTITYTYPE | 对端身份标识类型         | 用于标识待设置替代配置的Diameter服务节点的身份标识类型。 取值范围：Host Name：主机名，表示通过Diameter服务节点设备的主机名进行身份标识。Realm Name：域名，表示通过Diameter服务节点所在域的域名进行身份标识。 默认值：无。 说明：如果一个Diameter服务节点同时对应“对端身份标识类型”为“Host Name”和“Realm Name”的两条记录，则只会匹配其中“对端身份标识类型”为“Host Name”的一条记录。                      |
| PEERENTITY     | 对端身份标识           | 用于标识待设置替代配置的Diameter服务节点的身份标识，该标识唯一确定一个Diameter服务节点。当用户漫游到该Diameter服务节点时，将使用“替代的EPS QoS模板ID”设置的模板下发QoS数据。 取值范围：1～127个字符组成的相对域名格式字符串。 默认值：无。 说明：该字符串需满足以下条件：字符串开始和结束均不能是“.”。不能包含连续两个“.”。根据“.”拆分出每个字段，如果单个字段的长度大于63，则返回ERR1004“无效的参数值”错误码，且每个字段只能由数字、字母和“-”组成。 |
| REPEPSQOSID    | 替代的EPS QoS模板ID   | 用于标识一个替换后的Qos模板ID。使用该ID对应的模板代替“用户签约的EPS QoS模板ID”进行下发。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                 |

## 使用实例

增加一条EPS QoS模板替代配置记录，各参数分别设置为：

- “HLR序列号”为“1”
- “用户签约的EPS QoS模板ID”为“1”
- “对端身份标识类型”为“Host Name”
- “对端身份标识”为“test.huawei.com”
- “替代的EPS QoS模板ID”为“300”

```
ADD REPEPSQOSID: HLRSN=1, USREPSQOSID=1, PEERENTITYTYPE=Host Name, PEERENTITY="test.huawei.com", REPEPSQOSID=300;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                | 处理建议                                                                                                                                                  |
|:--------|:--------|:--------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                      |
| ERR3003 | 模板未定义   | 参数“用户签约的EPS QoS模板ID”或“替代的EPS QoS模板ID”没有在“HLR序列号”对应的虚拟HLR中预先定义。      | 根据实际情况，重新输入已定义的“用户签约的EPS QoS模板ID”和“替代的EPS QoS模板ID”，可通过LST EPSQOSTPL命令查询虚拟HLR中已定义的EPS QoS模板，确保输入的模板ID在“HLR序列号”对应的虚拟HLR中都已定义。                           |
| ERR3006 | 记录已存在   | 增加一条记录时，参数“HLR序列号”、“对端身份标识”和“用户签约的EPS QoS模板ID”三者的组合在数据库中已存在，不能重复添加。 | 根据实际情况，重新输入参数，确保输入的“HLR序列号”、“对端身份标识”和“用户签约的EPS QoS模板ID”的组合与系统中已存在的不重复。可执行LST REPEPSQOSID命令查询系统中已存在的EPS QoS模板替代配置记录。                                   |
| ERR3007 | 记录不存在   | 参数“HLR序列号”的取值未预先定义，对应序列号的虚拟HLR不能添加EPS QoS模板替代配置。                    | 使用LST HLRSN命令查询已定义的HLR序列号，根据查询结果中存在的HLR序列号，重新输入“HLR序列号”参数值。                                                                                           |
| ERR3047 | 超过最大限制  | 增加的EPS QoS模板替代配置记录数超过3000条。                                         | 根据实际情况，如需增加EPS QoS模板替代配置记录，处理步骤如下：执行LST REPEPSQOSID命令，查询已存在的EPS QoS模板替代配置记录。执行RMV REPEPSQOSID命令，删除不必要的QoS模板替代配置记录。执行该命令，增加EPS QoS模板替代配置，确保记录数在规定范围之内。 |
