# 增加PS的APN和EPS数据对应关系(ADD PSAPNEPS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条PS的APN和EPS数据的对应关系记录。

## 注意事项

系统中增加的PS的APN和EPS数据的对应关系记录数不能超过3000条。

## 参数说明

| 参数标识           | 参数名称                    | 参数说明                                                                                                                                                                                                                                                                                                       |
|:---------------|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号                  | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                               |
| APN            | 接入点名称                   | 用于标识待增加的APN名称。 取值范围：1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                                                                                                                                                              |
| APNTPLID       | APN模板ID                 | 用于标识EPS用户签约APN模板ID。该参数必须先由ADD APNTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。  说明： 该参数如果没有填写时，需要根据“接入点名称”去APN模板表获取对应的模板。如果找到，该处就填写对应模板ID。如果找不到，系统报错“输入的APN找不到对应的APNTPL模板，请填写APN模板ID”。                                                                                                                            |
| DEFAULTCFGFLAG | 是否是默认APN                | 用于标识是否将“APN模板ID”对应的APN模板设置为EPS APN的默认APN模板。 取值范围：TRUE：默认APN。FALSE：非默认APN。 默认值：FALSE                                                                                                                                                                                                                        |
| EPSQOSTPLID    | EPS QoS模板ID             | 用于标识EPS QoS模板ID。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                    |
| PDPTYPE        | PDP/PDN类型               | 对于每个会话，需要规定一种数据业务的类型， 称之为PDP/PDN类型。PDP/PDN类型分两大类，分别由ETSI和IETF两个组织制定，目前使用IETF制定的标准，该标准下有两种类型，分别为IPV4和IPV6。固定分配时，MS必须先签约，由网络分配相应的固定地址，同时写入该用户的USIM卡和用户数据库，PDP/PDN地址类型也必须在签约时说明，否则系统对不签约的PDP/PDN地址予以拒绝。 取值范围：IPV4IPV6IPV4IPV6IPV4_OR_IPV6 默认值：无。                                                              |
| VPLMN          | 是否允许用户从VPLMN访问PDP/PDN网络 | 用于标识是否允许用户从VPLMN访问PDP/PDN网络。 取值范围：TRUE：允许用户从VPLMN访问PDP/PDN网络。FALSE：不允许用户从VPLMN访问PDP/PDN网络，只允许从HPLMN访问PDP/PDN网络。 默认值：无。  说明： 建议设置为FALSE。                                                                                                                                                                    |
| CHARGE         | 计费特性                    | 用于标识每一类PDP/PDN级别计费特性。 取值范围：NONE：不签约计费特性。HOT：热计费，实时计费。FLAT：平计费。PREPAID：预付费用户。NORMAL：普通用户。3：热计费和平计费。5：热计费和预付费。6：平计费和预付费。7：热计费、平计费和预付费。9：热计费和普通计费。10：平计费和普通计费。11：热计费、平计费和普通计费。12：预付费和普通计费。13：热计费、预付费和普通计费。14：平计费、预付费和普通计费。15：热计费、平计费、预付费和普通计费。16～254：为自定义计费特性。 默认值：无。  说明： 建议设置为NORMAL。“计费特性”和“标准计费特性”不能同时存在。 |
| STDCHARGE      | 标准计费特性                  | 用于标识标准计费特性。针对每一类PDP/PDN类型。 取值范围：0000～FFFF，十六进制字符串。 默认值：无。  说明： “计费特性”和“标准计费特性”不能同时存在。                                                                                                                                                                                                                      |

## 使用实例

增加一条PS的APN和EPS数据的对应关系记录：“HLR序列号”为“1”，“接入点名称”为“huawei.com”，“APN模板ID”为“1”，“是否是默认APN”为“FALSE”，“EPS QoS模板ID”为“1”，“PDP/PDN类型”为“IPV4”，“是否允许用户从VPLMN访问PDP/PDN网络”为“FALSE”，“计费特性”为“NORMAL”：

```
ADD PSAPNEPS: HLRSN=1, APN="huawei.com", APNTPLID=1, DEFAULTCFGFLAG=FALSE, EPSQOSTPLID=1, PDPTYPE=IPV4, VPLMN=FALSE, CHARGE=NORMAL;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                           | 原因分析                                  | 处理建议                                                                                                                                                                                      |
|:--------|:--------------------------------|:--------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突                            | “计费特性”和“标准计费特性”两个参数都被输入。              | 根据实际情况，重新输入参数，确保满足“计费特性”和“标准计费特性”两个参数必须有且只能有一个参数出现。                                                                                                                                       |
| ERR3003 | 模板未定义                           | 输入的“APN模板ID”和“EPS QoS模板ID”参数未定义。      | 根据实际情况，重新输入“APN模板ID”和“EPS QoS模板ID”参数的取值，确保其存在。 已存在的“APN模板ID”可通过LST APNTPL命令查询。已存在的“EPS QoS模板ID”可通过LST EPSQOSTPL命令查询。                                                                      |
| ERR3006 | 记录已存在                           | 重复为同一个HLR序列号添加相同“接入点名称”。              | 根据实际情况，重新输入参数，确保输入的“接入点名称”与系统中已存在的不重复。可执行LST PSAPNEPS命令查询已存在的PS的APN和EPS数据的对应关系的记录。                                                                                                        |
| ERR3047 | 超过最大限制                          | 增加的PS的APN和EPS数据的对应关系的记录数超过3000条。      | 根据实际情况，如需增加PS的APN和EPS数据的对应关系的记录，处理步骤如下：执行LST PSAPNEPS命令，查询已存在的PS的APN和EPS数据的对应关系记录。执行RMV PSAPNEPS命令，删除不必要的PS的APN和EPS数据的对应关系记录。执行该命令增加PS的APN和EPS数据的对应关系记录，确保增加的PS的APN和EPS数据的对应关系记录数在规定范围之内。 |
| ERR4091 | 输入的APN找不到对应的APNTPL模板，请填写APN模板ID | “APN模板ID”没有填写时，系统根据APN参数匹配不到对应的APN模板。 | 根据实际情况，通过LST APNTPL命令查询已存在的“APN模板ID”，重新输入“APN模板ID”参数的取值。                                                                                                                                  |
