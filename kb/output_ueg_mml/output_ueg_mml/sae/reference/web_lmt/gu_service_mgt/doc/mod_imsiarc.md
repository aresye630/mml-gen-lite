# 修改IMSI与区号数据(MOD IMSIARC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条IMSI与区号数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条IMSI与区号数据记录：

- “HLR序列号”
- “IMSI前缀”

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                       |
|:-----------|:-------|:-------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号 | 标识一条IMSI与区号数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个HLR上的IMSI与区号数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。 |
| IMSIPREFIX | IMSI前缀 | 标识一条IMSI与区号数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条IMSI与区号数据记录的参数进行修改，操作员可以使用LST IMSIARC命令查询获得。    |
| AREACODE   | 区号     | 用于标识各地区电话号码的区号，与执行ADD DAREA命令增加的国内长途区号数据记录对应。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                 |

## 使用实例

修改“HLR序列号”为“1”、“IMSI前缀”为“460000009123456”的数据记录对应的“区号”，将原有数据修改为“91”：

```
MOD IMSIARC: HLRSN=1, IMSIPREFIX="460000009123456", AREACODE="91";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                         |
|:--------|:--------|:------------------------------------|:-------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“IMSI前缀”对应的IMSI与区号数据记录不存在。 | 使用LST IMSIARC命令查询后，重新确认要修改哪个“HLR序列号”和“IMSI前缀”对应的IMSI与区号数据记录。 |
