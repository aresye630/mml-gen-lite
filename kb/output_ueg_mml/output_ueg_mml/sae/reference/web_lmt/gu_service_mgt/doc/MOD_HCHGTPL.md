# 修改计费地址模板(MOD HCHGTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中修改一个计费地址模板的信息，系统通过计费地址模板ID参数来唯一标识一条计费地址模板数据记录。可以修改除模板ID以外的所有参数。

## 注意事项

- 本命令执行不当会导致用户计费出现错误，请慎重使用。
- “主在线计费地址”、“备在线计费地址”、“主离线计费地址”和“备离线计费地址”参数的取值必须是Diameter对端主机名。
- 在删除计费地址的时候，不能同时删除“主在线计费地址”和“主离线计费地址”，两者在计费模板中至少需要存在一个。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                     |
|:-----------|:----------|:-------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号    | 可选必选说明：可选参数 参数含义：用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                |
| TPLID      | 计费地址模板ID  | 可选必选说明：必选参数 参数含义：标识一条计费地址模板的关键字段，用于指定需要修改哪一条计费地址模板数据记录。可以通过LST HTPLINF查询获得。                                              |
| MODIFYTYPE | 操作类型      | 可选必选说明：可选参数 参数含义：用于标识执行该命令对计费地址模板数据实现的操作类型。 取值范围：MOD_ADDR：表示修改计费地址模板数据。DEL_ADDR：表示删除计费地址模板数据。 默认值：MOD_ADDR               |
| TPLNAME    | 计费地址模板名称  | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个计费地址模板名称。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无   |
| PECF       | 主在线计费地址   | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个主在线计费地址。 取值范围：长度不超过127的字符串 默认值： 无                            |
| SECF       | 备在线计费地址   | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个备在线计费地址。 取值范围：长度不超过127的字符串 默认值： 无                            |
| PCCF       | 主离线计费地址   | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个主离线计费地址。 取值范围：长度不超过127的字符串 默认值： 无                            |
| SCCF       | 备离线计费地址   | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个备离线计费地址。 取值范围：长度不超过127的字符串 默认值： 无                            |
| COMMENT    | 模板注释说明    | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“MOD_ADDR”时该参数有效，用于修改一个计费地址模板的注释。 取值范围：长度不超过512的字符串 默认值： 无                          |
| DELADDR    | 需要删除的计费地址 | 可选必选说明：条件可选参数 参数含义：仅当本命令中的“操作类型”参数取值为“DEL_ADDR”时该参数有效，用于标识删除一个或几个计费地址。如选择多个地址，两个地址之间用“&”隔开。 取值范围为：PECFSECFPCCFSCCF 默认值：无 |

## 使用实例

修改计费地址模板。计费地址模板ID：10，计费地址模板名称：Modify a Charging Address Template。

```
MOD HCHGTPL: TPLID=10, MODIFYTYPE=MOD_ADDR, TPLNAME="Modify a Charging Address Template";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                                                                                                                         | 处理建议                                                                                                                                                                            |
|----------:|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 900001008 | 参数不足    | 可能原因为如下之一： 参数“计费地址模板ID”没有输入。当“操作类型”取值为“MOD_ADDR”时，“计费地址模板名称”、“主在线计费地址”、“备在线计费地址”、“主离线计费地址”、“备离线计费地址”、“模板注释说明”参数都没有输入。当“操作类型”取值为“DEL_ADDR”时，“需要删除的计费地址”参数没有输入 | 根据实际情况，重新输入参数，确保满足以下几点： 参数“计费地址模板ID”必须输入。当“操作类型”取值为“MOD_ADDR”时，“计费地址模板名称”、“主在线计费地址”、“备在线计费地址”、“主离线计费地址”、“备离线计费地址”、“模板注释说明”参数必须至少设置其中一个。当“操作类型”取值为“DEL_ADDR”时，“需要删除的计费地址”参数必须设置。 |
