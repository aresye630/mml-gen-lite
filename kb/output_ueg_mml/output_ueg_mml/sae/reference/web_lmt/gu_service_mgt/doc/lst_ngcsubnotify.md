## 命令功能

该命令用于查询5G用户的订阅数据信息。

- 若需要查询单个用户的订阅数据信息，请输入参数“IMSI”，其他参数不输入。
- 若需要查询连续多个用户的订阅数据信息，请输入参数“IMSI”，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的订阅数据信息，请输入参数“IMSI文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“IMSI文件名”两个参数不能同时输入，否则会提示参数错误。
- “用户个数”不能与“IMSI文件名”不能同时输入，否则会提示参数错误。
- 通过SOAP接口之外营帐侧执行该命令时，由**SET UDMSERV**命令中“MML报文控制”参数控制该命令报文中参数“SUPPORTEDFEATURES”、“MCC”及“MNC”是否显示，默认不显示；通过SOAP接口营帐侧执行该命令时，报文中参数“SUPPORTEDFEATURES”、“MCC”及“MNC”不显示；通过PGW Web LMT执行该命令时，报文中参数“SUPPORTEDFEATURES”、“MCC”及“MNC”显示。

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                                                                                                                    |
|:---------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个IMSI来查询用户订阅数据信息。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                     |
| RECORDCOUNT    | 用户个数    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照设置的用户个数来查询对应用户的订阅数据。 取值范围：1～10000 默认值：无。 配置原则： 当需要为连续号码的多个用户查询用户的订阅数据信息时配置该参数，配置后，系统将会从已指定的IMSI号码开始，对连续号码的多个用户进行查询用户的订阅数据信息。该参数是对连续号码的多个用户查询用户的签约数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE       | IMSI文件名 | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询用户订阅数据信息的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstngcsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                |
| SUBSCRIPTIONID | 订阅ID    | 可选必选说明：可选参数 参数含义：用于标识AMF等网元订阅签约数据时的订阅ID，由UDM生成。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                   |

## 使用实例

1. 查询IMSI为“460990000060000”的用户的订阅信息：

   ```
   LST NGCSUBNOTIFY: IMSI="460990000060000";
   ```

   ```
   %%LST NGCSUBNOTIFY: IMSI="460990000060000";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                             IMSI = 460990000060000

                   SUBSCRIPTIONID = 611DB05872B4004D
                         RESOURCE = am-data
                      CALLBACKURI = http://10.189.171.60:8020/nudm_sdm/callback/v1/supi
                          SUBTIME = 2021-08-19 01:14:00
                     NFINSTANCEID = 11112222-1111-2222-3333-111122223333
              IMPLICITUNSUBSCRIBE = FALSE
                          EXPIRES = 2029-05-01 22:43:26
                           SNSSAI = 11-111222
                        SCPRTFLAG = FALSE
                SUPPORTEDFEATURES = 0000000000000001            
                              MCC = 460
                              MNC = 10

   Total count = 13

   There is together 1 report

   ---    END
   ```
2. 查询IMSI为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户的订阅信息：

   ```
   LST NGCSUBNOTIFY: IMSI="460000009123456", RECORDCOUNT=3;
   ```

   ```
   %%LST NGCSUBNOTIFY: IMSI="460000009123456", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:Operation is successful Batch ID: 16. CHK BATSTAT can be used to obtain the status of batch operation

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数含义请参见表1的参数说明。

| 输出项名称                    | 输出项说明                                                                                                                                                           |
|:-------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESOURCE                 | 用户签约数据资源标识，用于指示订阅哪种类型的数据。                                                                                                                                       |
| CALLBACKURI              | UDM向订阅的对端网元发送数据变更通知时使用的URI路径。                                                                                                                                   |
| AMFSERVICENAMEDATACHANGE | 用于订阅服务为AMF的场景下，AMF数据变更时AMF的服务名。                                                                                                                                 |
| SUBTIME                  | 订阅时间。                                                                                                                                                           |
| NFINSTANCEID             | 创建订阅的NF实例标识。                                                                                                                                                    |
| IMPLICITUNSUBSCRIBE      | 隐式去订阅：当IMPLICITUNSUBSCRIBE = TRUE时，用于指示该订阅ID下的订阅数据不失效，只有当AMF等网元向UDM去注册关于该用户的信息并且发送去订阅动作后订阅数据失效。当IMPLICITUNSUBSCRIBE = FALSE时，用于指示在订阅失效时间EXPIRES后，该订阅ID下的订阅数据失效。 |
| EXPIRES                  | 订阅失效时间点，格式为UTC秒。                                                                                                                                                |
| SNSSAI                   | 网络切片选择辅助信息。                                                                                                                                                     |
| DNN                      | 数据网络名称。                                                                                                                                                         |
| SCPRTFLAG                | SCP路由标识，用于指示系统标识用户订阅请求消息是否经过SCP路由，默认为未经过SCP路由。 当SCPRTFLAG = TRUE时，表示经过SCP路由。当SCPRTFLAG = FALSE时，表示未经过SCP路由。 说明：该参数不支持通过营帐系统查询。                                  |
| SUPPORTEDFEATURES        | 用于指示订阅者支持的特性能力标识。 取值范围：16位16进制数字组成的字符串。                                                                                                                         |
| MCC                      | 移动国家码，3位十进制数字组成的字符串，如中国为460。                                                                                                                                    |
| MNC                      | 移动网号，2位或3位的十进制数字组成的字符串，识别移动用户所归属的移动通信网。                                                                                                                         |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释   | 原因分析                                                               | 处理建议                                                                              |
|:--------|:--------|:-------------------------------------------------------------------|:----------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 原因为如下情形中的一种： 参数“IMSI”的取值中含有0～9以外的字符。参数“IMSI”的取值长度不符。参数“订阅ID”的取值无效。 | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                   |
| ERR3001 | 用户未开户   | 用户的IMSI号码输入错误，实际输入的参数“IMSI”对应的用户未开户。                               | 核实IMSI号码，确保其对应的用户为5G用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”对应的用户未开户，请参考ADD SUB页面给用户开户。 |
| ERR3007 | 记录不存在   | IMSI对应的用户未进行订阅，不存在该用户的订阅记录信息。                                      | 核实IMSI号码是否输入正确。                                                                   |
| ERR1010 | 参数冲突    | 可能的原因为如下之一： “IMSI”和“IMSI文件名”同时输入。“用户个数”和“IMSI文件名”同时输入。             | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”和“IMSI文件名”不能同时配置。“用户个数”和“IMSI文件名”不能同时配置。            |

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
