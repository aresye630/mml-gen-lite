# 删除游牧地址(RMV HNATPLADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户注册失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS的业务数据库中删除一条指定游牧地址模板中的游牧地址。

## 注意事项

- “NASS游牧模板ID”参数和“NASS游牧模板名称”参数必须存在且仅能存在一个。
- 如果操作员在指定游牧模板中删除一条游牧地址，则所有引用该模板的用户都将删除这条游牧地址，可能导致用户注册失败，请操作员在执行该操作之前仔细确认任务的可行性。
- 游牧模板中必须至少保留一条游牧地址信息，如果不需要模板中存在游牧地址，操作员可以使用**RMV HNATPL**命令将该模板删除。
- 对于有具体游牧地址的用户，如果要放开用户的游牧权限，使用本命令删除地址以放开用户的游牧范围。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                       |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NATPLID | NASS游牧模板ID | 标识一条游牧地址的关键字段之一，用于指定需要删除哪一个游牧模板中的游牧地址，操作员可以使用LST HTPLINF命令查询获得。 取值范围：0～67108863 默认值：无。 说明：可选参数。该参数为255表示无效值。                                                                                               |
| TPLNAME | NASS游牧模板名称 | 标识一条游牧地址的关键字段之一，用于指定需要删除哪一个游牧模板中的游牧地址，操作员可以使用LST HTPLINF命令查询获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                  |
| nan     | NASS游牧地址   | 标识一条游牧地址的关键字段之一，用于标识需要删除游牧模板中的哪一条游牧地址，操作员可以使用LST HNATPLADDR命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“FRONT”、“BACK”或“CONTAIN”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。           |
| BEGINIP | IP地址段起始地址  | 标识一条游牧地址的关键字段之一，用于标识需要删除游牧模板中地址IP段的起始地址，操作员可以使用LST HNATPLADDR命令查询获得。 取值范围：IPV4地址 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“IPSEGMENT”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。                            |
| ENDIP   | IP地址段结束地址  | 标识一条游牧地址的关键字段之一，用于标识需要删除游牧模板中地址IP段的结束地址，操作员可以使用LST HNATPLADDR命令查询获得。 取值范围：IPV4地址 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“IPSEGMENT”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。该参数IP必须大于或等于“IP地址段起始地址”的IP。 |

## 使用实例

1. 删除游牧地址，“NASS游牧模板ID”为“10”，“NASS游牧地址”为“china.huawei.com”：

   ```
   RMV HNATPLADDR: NATPLID=10, NA="china.huawei.com";
   ```
2. 删除游牧地址，“NASS游牧模板名称”为“07550011”，“IP地址段起始地址”为“10.2.2.10”，“IP地址段结束地址”为“10.2.2.50”：

   ```
   RMV HNATPLADDR: TPLNAME="07550011", BEGINIP="10.2.2.10", ENDIP="10.2.2.50";
   ```
