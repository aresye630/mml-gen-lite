# 修改用户类别(MOD USERCATEGORY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户是否为M2M用户。当用户需要签约M2M绑定业务及状态主动上报M2M业务时，若用户不是M2M用户，则需要通过执行该命令先将用户类型修改为M2M用户，才能签约并使用该业务。当用户修改为M2M用户后M2M平台也可以通过UDM主动获取用户的状态及位置信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- MSISDN-Less业务不能与MIMSI、多SIM、COMISDN、GROUPSIM、多号码用户群组、ALS、Follow Me、Home Zone业务同时签约。

## 参数说明

| 参数标识         | 参数名称      | 参数描述                                                                                                                                                                                                                                  |
|:-------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI      | 用于标识需要修改哪个IMSI号码的用户类别。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                  |
| ISDN         | MSISDN    | 用于标识需要修改哪个MSISDN号码的用户类别。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                |
| RECORDCOUNT  | 用户个数      | 用于标识需要修改用户类别的用户数目。 当需要为连续号码的多个用户签约或去签约用户类别业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户签约或去签约用户类别业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户签约或去签约用户类别业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE     | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要签约或去签约用户类别业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“usercategory.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                             |
| ISDNFILE     | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约或去签约用户类别业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“usercategory.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                       |
| USERCATEGORY | 是否是M2M用户  | 用于标识用户是否为M2M用户。 取值范围： NORMAL：普通用户。M2M：M2M用户。 默认值：无。 说明：当该参数取值为“M2M”时，若用户的IMSI号码和MSISDN相同，执行本命令后，该用户变更为MSISDN-Less用户。                                                                                                                  |

## 使用实例

将“IMSI”为“460000009123456”的用户修改为M2M用户（默认该用户为非M2M用户）:

```
MOD USERCATEGORY: IMSI="460000009123456",USERCATEGORY=M2M;
```
