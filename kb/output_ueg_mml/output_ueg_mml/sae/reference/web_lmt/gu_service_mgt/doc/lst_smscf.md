# 查询短消息前转签约数据(LST SMSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户的短消息前转签约数据。

- 若需要查询单个用户的短消息前转签约数据，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的短消息前转签约数据，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的短消息前转签约数据，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名 ”四个参数必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时存在，只能与“IMSI”或“MSISDN”一起出现，用于查询特定用户的短消息前转签约数据。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                        |
|:------------|:----------|:--------------------------------------------|
| IMSI        | IMSI      | 用于指示系统按照哪个IMSI来查询用户的短消息前转签约数据。              |
| ISDN        | ISDN      | 用于指示系统按照哪个MSISDN来查询用户的短消息前转签约数据。            |
| RECORDCOUNT | 用户个数      | 用于指示系统需要查询从IMSI或MSISDN开始的连续多少个用户的短消息前转签约数据。 |
| IMSIFILE    | IMSI文件名   | 用于指示系统按照哪个IMSI文件名来查询不连续的多个用户的短消息前转签约数据。     |
| ISDNFILE    | MSISDN文件名 | 用于指示系统按照哪个MSISDN文件名来查询不连续的多个用户的短消息前转签约数据。   |

## 使用实例

1. 当**SET MAPSERV**命令中参数“SMSCF\_MODE”设置为“MODE1”时，查询“IMSI”为“460021001008011”的用户的短消息前转签约数据。

   ```
   LST SMSCF: IMSI="460021001008011";
   ```

   ```
   %%LST SMSCF: IMSI="460021001008011";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460021001008011
                             ISDN = 8621001008011
                              FTN = 8613904011003
                           STATUS = PROV | REG | ACT

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 当**SET MAPSERV**命令中参数“SMSCF\_MODE”设置为“MODE2”时，查询“IMSI”为“460021001008011”的用户的短消息前转签约数据。

   ```
   LST SMSCF: IMSI="460021001008011";
   ```

   ```
   %%LST SMSCF: IMSI="460021001008011";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460021001008011
                             ISDN = 8621001008011
                           STATUS = PROV | ACT

   Total count = 3

   There is together 1 report

   ---    END
   ```
3. 查询第一个“IMSI”为“460021001008011”的3个连续用户的短消息前转签约数据。

   ```
   LST SMSCF: IMSI="460021001008011", RECORDCOUNT=3;
   ```

   ```
   %%LST SMSCF: IMSI="460021001008011", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
4. 查询“IMSI文件名”为“modsmscf.txt”的用户的短消息前转签约数据。

   ```
   LST SMSCF: IMSIFILE="modsmscf.txt";
   ```

   ```
   %%LST SMSCF: IMSIFILE="modsmscf.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：8. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD SMSCF**

命令的参数说明。表1列出的是未包含在

**MOD SMSCF**

命令参数含义中的输出项。

| 输出项名称   | 输出项解释                                                                                                                                                                           |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STATUS  | 用于返回用户的短消息前转状态。 取值范围：PROV：签约。REG：登记。ACT：激活。QUIESCENT：静止。                                                                                                                        |
| FTN     | 用于返回用户需要前转短消息的号码。 说明：当用户签约并激活短消息前转业务，且SET MAPSERV命令中参数“SMSCF_MODE”的值为“MODE1”时，该参数显示。 当用户签约但未激活短消息前转业务时，该参数不显示。 当用户签约并激活短消息前转业务，且SET MAPSERV命令中参数“SMSCF_MODE”的值为“MODE2”时，该参数不显示。 |
| 批操作ID   | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。                                                                                                                                      |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                              |

| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，确保满足“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                      |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                      |
| ERR3015 | 业务未提供      | “IMSI”或“MSISDN”对应的用户未签约短消息前转业务。                                                                    | 执行MOD SMSCF命令给用户签约短消息前转业务，然后使用本命令查询用户的短消息前转签约数据。                                                                  |
