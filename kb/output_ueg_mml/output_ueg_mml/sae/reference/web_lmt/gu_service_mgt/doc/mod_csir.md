# 修改CSI限制列表(MOD CSIR)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中设置CSI（CAMEL Subscription Information）限制列表，提供增加或删除VLR/SGSN号码前缀的功能。

HLR根据漫游用户所在的VLR/SGSN号码前缀或被叫取路由时的GMSC号码前缀，灵活控制CAMEL签约信息的下发。

## 注意事项

- CSI限制下发是系统级的功能，对HLR的所有用户都适用。
- 同一个“HLR序列号”中增加的CSI限制记录数不能超过1000条。

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                     |
|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                             |
| OPTYPE    | 操作类型       | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加一条记录。DELETE：删除一条已有记录。DELETEALL：删除所有记录。 默认值：无。                                                                                                              |
| VLRSGSNNP | VLR/SGSN前缀 | 仅当本命令中的“操作类型”参数为“ADD”或“DELETE”时该参数有效。用于标识VLR/SGSN号码前缀。 该参数支持最大匹配原则，输入的内容可以是完整的VLR/SGSN号码，也可以是VLR/SGSN的号码前缀。最大匹配原则是指在查询时对于一个具体的号码而言，系统将在所有的记录中查找与其号码最相近的一个。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

1. 用户在使用CAMEL功能时，通过以下配置限制该HLR中所有CAMEL用户的CSI数据只允许下发给配置的VLR/SGSN或被叫取路由时的GMSC。
   1. 执行**SET MAPCONF**命令设置系统支持CAMEL限制下发业务。

      ```
      SET MAPCONF: CSIRESTRICTION=TRUE;
      ```
   2. 执行**MOD CSIR**命令在“HLR序列号”为“1”的HLR上设置CSI限制列表。其中，“操作类型”为“ADD”，“VLR/SGSN前缀”为“12”：

      ```
      MOD CSIR: HLRSN=1, OPTYPE=ADD, VLRSGSNNP="12";
      ```
   3. 用户操作触发CAMEL业务，系统检查符合CSI数据下发的条件，则根据各个CSI定制下发配置情况决定是否要下发各个CSI数据。
2. 在“HLR序列号”为“1”的HLR上删除所有的CSI限制列表数据记录。其中，“操作类型”为“DELETEALL”：

   ```
   MOD CSIR: HLRSN=1, OPTYPE=DELETEALL;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                          | 处理建议                                                                                                                                                                     |
|:--------|:--------|:----------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”未定义。当“操作类型”为“DELETE”时，待删除的数据在系统中不存在。当“操作类型”为“DELETEALL”时，系统中不存在任何CSI限制列表数据。 | 根据实际情况，重新输入参数，确保满足以下要求：根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。当“操作类型”为“DELETE”时，可以执行LST CSIR命令查询数据库，确保待删除的数据在系统中已存在。当“操作类型”为“DELETEALL”时，可以执行LST CSIR命令查询数据库，确保数据库存在CSI限制列表数据。 |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                                                 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                         |
| ERR3006 | 记录已存在   | 当“操作类型”为“ADD”执行增加的操作时，输入的“VLR/SGSN前缀”在数据库中已存在。                                                | 根据实际情况，重新输入参数，确保输入的“VLR/SGSN前缀”与系统中已存在的不重复。可执行LST CSIR命令查询系统中已存在的CSI限制列表数据记录。                                                                                            |
| ERR1111 | 超过最大限制  | 增加的CSI限制记录数超过1000条。                                                                           | 根据实际情况，如需增加CSI限制记录，处理步骤如下：执行LST CSIR命令，查询已存在CSI限制记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的CSI限制记录。执行该命令，将参数“操作类型”设置为“ADD”增加的CSI限制记录，确保增加后CSI限制记录数在规定范围之内。                      |
