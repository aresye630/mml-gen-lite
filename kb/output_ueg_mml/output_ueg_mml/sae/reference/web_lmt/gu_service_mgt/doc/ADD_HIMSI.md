# 增加IMSI号码(ADD HIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中新增IMSI数据（IMSI号码和MSISDN号码以及关联的IMPI）。

## 注意事项

- 如果参数带IMPI，IMPI不能已经关联其它的IMSI，否则HSS返回失败。
- 如果参数带IMPI，则增加IMSI和IMPI之间的对应关系。
- 如果参数不带IMPI，则只增加IMSI。
- 如果参数IMPI所属SUBID下已经存在关联的IMSI，IMPI不能再关联IMSI，否则HSS返回失败。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示一个需要与IMSI建立关联关系的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无            |
| IMSI   | IMSI   | 用于定义一个IMSI，IMSI由长度[6，15]位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无   |
| ISDN   | MSISDN | 用于定义一个MSISDN，由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围： 长度不超过15的字符串 缺省值： 无 |

## 使用实例

增加IMSI号码。IMSI：460001234567890，MSISDN：8613988888888。

```
ADD HIMSI: IMSI="460001234567890", ISDN="8613988888888";
```
