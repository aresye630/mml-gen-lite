# 激活短消息前转业务(ACT SMSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户激活或去激活短消息前转业务。

当用户终端暂时无法接收短消息或希望通过其他终端接收短消息时，可以在用户已签约短消息前转业务的情况下，使用该命令激活短消息前转业务，满足用户紧急处理短消息的需求。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名 ”四个参数必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时存在，只能与“IMSI”或“MSISDN”一起出现，用于为用户激活或去激活短消息前转业务。
- 激活短消息前转业务的号码只能前转到归属于其HPLMN的号码或与其HPLMN签约了短消息路由协议的VPLMN号码。
- 当**SET MAPSERV**命令中，参数“SMSCF\_MODE”设置为“MODE1”时，检查短消息前转业务和ODB/CB业务冲突关系，存在冲突关系时，操作将被拒绝，系统提示补充业务冲突。参数“SMSCF\_MODE”设置为“MODE2”时，不检查短消息前转业务与ODB/CB业务中BOIC/BOICEXHC之间的冲突关系，其他冲突关系仍需检查，存在冲突关系时，操作将被拒绝，系统提示补充业务冲突。
- 当该命令中参数“是否激活SMSCF业务”设置为“TRUE”时，若**SET MAPSERV**命令中参数“SMSCF\_MODE”设置为“MODE1”，则“前转号码”和“前转号码属性”两个参数必须输入。若参数“SMSCF\_MODE”设置为“MODE2”，则“前转号码”和“前转号码属性”两个参数不能输入。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                      |
|:------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI        | 用于标识待激活或去激活短消息前转业务用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                |
| ISDN        | ISDN        | 用于标识待激活或去激活短消息前转业务用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                              |
| RECORDCOUNT | 用户个数        | 用于标识待激活或去激活短消息前转业务用户的数目。 当需要为连续号码的多个用户待激活或去激活短消息前转业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行激活或去激活短消息前转业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行激活或去激活短消息前转业务，当只有一个用户时，该参数不必配置。当一次激活或去激活短消息前转业务的用户个数很多时，对系统性能无影响，但激活或去激活短消息前转业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名     | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要激活或去激活短消息前转业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmscf.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                     |
| ISDNFILE    | MSISDN文件名   | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要激活或去激活短消息前转业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmscf.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                               |
| ACTIVE      | 是否激活SMSCF业务 | 用于标识执行该命令是为用户激活还是去激活短消息前转业务。 取值范围：TRUE：激活短消息前转业务。FALSE：去激活短消息前转业务。 默认值：无。                                                                                                                                                                                                 |
| FTN         | 前转号码        | 仅当本命令中“是否激活SMSCF业务”参数设置为“TRUE”时该参数有效，用于标识待激活短消息前转业务用户需要前转短消息的号码。前转号码格式要求参见前转号码格式说明。 取值范围：不超过16位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                       |
| PROPERTY    | 前转号码属性      | 仅当本命令中“是否激活SMSCF业务”参数设置为“TRUE”时该参数有效，用于标识前转号码是国际号码还是国内号码。 取值范围：INTERNATIONAL：国际号码。NATIONAL：国内号码 。 默认值：无。                                                                                                                                                                  |

## 使用实例

激活短消息前转业务时，需要配置如下数据：

1. 执行**MOD SMSCF**命令为用户签约短消息前转业务。

   MOD SMSCF: IMSI="460021001008011", PROV=TRUE;
2. 执行该命令为用户激活或去激活短消息前转业务。

   - 当**SET MAPSERV**命令中参数“SMSCF\_MODE”设置为“MODE1”时，为“IMSI”号码是“460021001008011”的用户激活短消息前转业务，“前转号码”为“8613904011003”，“前转号码属性 ”为“INTERNATIONAL”。

     ```
     ACT SMSCF: IMSI="460021001008011", ACTIVE=TRUE, FTN="8613904011003", PROPERTY=INTERNATIONAL;
     ```
   - 当**SET MAPSERV**命令中参数“SMSCF\_MODE”设置为“MODE2”时，为“IMSI”号码是“460021001008011”的用户激活短消息前转业务。

     ```
     ACT SMSCF: IMSI="460021001008011", ACTIVE=TRUE;
     ```
   - 为“IMSI”号码是“460021001008011”的用户去激活短消息前转业务。

     ```
     ACT SMSCF: IMSI="460021001008011", ACTIVE=FALSE;
     ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                       | 原因分析                                                                                               | 处理建议                                                                                                              |
|:--------|:----------------------------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值                      | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                          |
| ERR1009 | 参数丢失                        | “IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，确保满足“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                      |
| ERR1005 | 文件未找到                       | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1010 | 参数冲突                        | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户                       | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                |
| ERR1025 | 批操作文件中格式非法                  | 参数“IMSI文件名”或“MSISDN文件名”、对应的批操作文件格式不正确。                                                             | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                      |
| ERR3015 | 业务未提供                       | 输入的“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”参数对应的用户未签约短消息前转业务。                                         | 请先通过MOD SMSCF命令给用户签约短消息前转业务。                                                                                      |
| ERR4065 | 系统当前的短消息前转模式不能输入前转号码和前转号码属性 | 当SET MAPSERV命令中，参数“SMSCF_MODE”设置为“MODE2”时，输入了“前转号码”和“前转号码属性”两个参数。                                  | SET MAPSERV命令中参数“SMSCF_MODE”设置为“MODE2”且该命令中参数“是否激活SMSCF业务”设置为“TRUE”时，不能输入“前转号码”和“前转号码属性”两个参数。                     |
| ERR3018 | 补充业务冲突                      | 短消息前转业务与ODB/CB业务存在冲突关系。                                                                            | 短消息前转业务与ODB/CB业务不能同时签约，若要继续激活短消息前转业务，请先通过MOD ODB命令或MOD CB命令去签约ODB/CB业务，再通过该命令激活短消息前转业务。                           |
