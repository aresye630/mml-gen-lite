# 查询防欺诈业务(LST FRAUD)

- 注意事项

## 命令功能

此操作用来查询特定用户的防欺诈业务。

## 注意事项

“IMSI”和“ISDN”是条件可选参数，任何一个参数出现即可，但两个参数不能同时出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                      |
|:------------|:----------|:------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。                                               |
| ISDN        | MSISDN    | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。                                             |
| RECORDCOUNT | 用户个数      | 此参数用于设置用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | 此参数用于设置IMSI文件名称。IMSIFILE包含多个不连续的IMSI号码。 取值范围：1～16个字母或数字。                                  |
| ISDNFILE    | MSISDN文件名 | 此参数用于设置ISDN文件名称。ISDNFILE包含多个不连续的MSISDN号码。 取值范围：1～16个字母或数字。                                |

## 使用实例

查询IMSI号码为460000009123456用户的防欺诈业务。

```
LST FRAUD: IMSI="460000009123456";
```
