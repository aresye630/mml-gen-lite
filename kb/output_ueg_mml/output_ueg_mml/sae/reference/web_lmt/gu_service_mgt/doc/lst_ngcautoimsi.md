# 查询5G自动开户用户粒度黑白名单(LST NGCAUTOIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5G自动开户用户粒度黑白名单数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个IMSI来查询5G自动开户用户粒度黑白名单数据记录。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

查询一条5G自动开户用户粒度黑白名单数据记录，“IMSI”为“460061234567834”。

```
LST NGCAUTOIMSI: IMSI="460061234567834";
```

```

```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD NGCAUTOIMSI**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                          |
|:--------|:--------|:---------------------------------------|:------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。                   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                              |
| ERR3007 | 记录不存在   | 实际输入的参数“IMSI”对应的5G自动开户用户粒度黑白名单数据记录不存在。 | 核实输入的“IMSI”参数，重新输入参数，确保输入的IMSI已经通过执行MOD NGCAUTOIMSI命令携带“操作类型”参数为“ADD”添加了数据记录。 |
