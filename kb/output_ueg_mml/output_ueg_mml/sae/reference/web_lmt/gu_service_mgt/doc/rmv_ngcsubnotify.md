# 删除订阅信息(RMV NGCSUBNOTIFY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除5G用户的订阅数据信息。

## 注意事项

- “IMSI”和“IMSI文件名”不能同时输入，否则会提示参数冲突。
- “用户个数”参数和“IMSI文件名”不能同时输入，否则会提示参数冲突。
- 删除用户的订阅信息后，用户签约数据变更时UDM不会将数据变更知会到对端网元，请确认不再需要订阅时执行本命令。

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                                                                                                                   |
|:---------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI    | 可选必选说明：条件可选参数 参数含义：用于标识国际移动用户识别号。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                |
| RECORDCOUNT    | 用户个数    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照设置的用户个数来删除订阅信息。 取值范围：1～100000。 默认值：无。 配置原则： 当需要为连续号码的多个用户删除用户的订阅数据信息时配置该参数，配置后，系统将会从已指定的IMSI号码开始，对连续号码的多个用户进行删除用户的订阅数据信息。该参数是对连续号码的多个用户删除用户的订阅数据信息，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE       | IMSI文件名 | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1~16个字符组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待删除用户订阅数据信息的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvngcsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                  |
| SUBSCRIPTIONID | 订阅ID    | 可选必选说明：条件可选参数 参数含义：用于标识AMF等网元订阅签约数据时的订阅ID，由UDM生成。 取值范围：16位十六进制无符号数字。 默认值：无。 配置原则：无。                                                                                                                                                                    |

## 使用实例

1. 删除订阅信息，“IMSI”为“460000009123456”：

   ```
   RMV NGCSUBNOTIFY: IMSI="460000009123456";
   ```
2. 删除3个连续用户的订阅信息，“IMSI”为“460000009123456”、“460000009123457”和“460000009123458”：

   ```
   RMV NGCSUBNOTIFY: IMSI="460000009123456", RECORDCOUNT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                               | 处理建议                                                                   |
|:--------|:--------|:-------------------------------------------------------------------|:-----------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 原因为如下情形中的一种： 参数“IMSI”的取值中含有0～9以外的字符。参数“IMSI”的取值长度不符。参数“订阅ID”的取值无效。 | 根据实际情况，重新输入已定义的“IMSI”，确保其取值符合取值范围的要求。                                  |
| ERR3001 | 用户未开户   | 用户的“IMSI”输入错误，实际输入的参数“IMSI”对应的用户未开户。                               | 核实并输入正确的用户的“IMSI”。                                                     |
| ERR3007 | 记录不存在   | IMSI对应的用户未进行订阅，不存在该用户的订阅记录信息。                                      | 请运行LST NGCSUBNOTIFY命令，核实IMSI对应的用户是否存在订阅数据。                             |
| ERR1010 | 参数冲突    | 可能的原因为如下之一： “IMSI”和“IMSI文件名”同时输入。“用户个数”和“IMSI文件名”同时输入。             | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”和“IMSI文件名”不能同时配置。“用户个数”和“IMSI文件名”不能同时配置。 |
