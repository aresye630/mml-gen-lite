# 查询指定PUSI的AS地址(LST HAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定PUSI的AS地址，PUSI的AS地址可以通过SET HAS操作进行设置。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| PUSI   | PUSI   | 用于指定一个需要查询AS信息的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询指定PUSI的AS地址。PUSI：sip:pusiinfo@huawei.com。

```
LST HAS: PUSI="sip:pusiinfo@huawei.com";
```

## 输出结果说明

| 参数标识   | 参数说明    |
|:-------|:--------|
| AS     | 显示AS地址。 |
