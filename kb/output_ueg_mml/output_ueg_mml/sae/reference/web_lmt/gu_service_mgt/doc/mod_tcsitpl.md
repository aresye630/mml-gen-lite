## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条T-CSI（Terminating CAMEL Subscription Information）模板数据记录的某些参数进行修改或调整，同时还用于为一条T-CSI模板数据记录增加多条触发准则。在该命令中，系统通过以下关键参数的组合来唯一标识一条T-CSI模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 用户做被叫进行被叫取路由流程或其他涉及T-CSI模板的流程时，系统会根据用户签约的T-CSI模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 系统中同一个T-CSI模板增加的DP值记录数不能超过20条，且所有T-CSI模板增加的DP值总记录数不能超过5000条。

## 使用实例

1. 修改T-CSI模板数据记录，“HLR序列号”为“1”，“模板ID”为“2”，“CAMEL业务处理能力”为“PHASE2”，“是否提供DP值”为“TRUE”，“DP值”为“TAA”，“业务键”为“12”：

   ```
   MOD TCSITPL: HLRSN=1, TPLID=2, CAMEL=PHASE2, PROV=TRUE, DP=TAA, SK=12;
   ```
2. 修改T-CSI模板数据记录，增加一个DP值，“HLR序列号”为“1”，“模板ID”为“2”，“CAMEL业务处理能力”为“PHASE4”，“是否提供DP值”为“TRUE”，“DP值”为“TBUSY”，“SCP地址”为“8613911112”，“缺省呼叫处理”为“releaseCall”，GMSC的处理方式均采用参数表中第一项：

   ```
   MOD TCSITPL: HLRSN=1, TPLID=2, CAMEL=PHASE4, PROV=TRUE, DP=TBUSY, GSMSCFADD="8613911112", DEFCALL=releaseCall, WITHINTERAGRE_SUPCAMEL=ReturnT-CSI, WITHOUTINTERAGRE_SUPCAMEL=ReturnT-CSI, HPLMNINTER_SUPCAMEL=ReturnT-CSI, WITHINTERAGRE_SUPLPCAMEL=ReturnLPT-CSI, WITHOUTINTERAGRE_SUPLPCAMEL=ReturnLPT-CSI, HPLMNINTER_SUPLPCAMEL=ReturnLPT-CSI, WITHINTERAGRE_NOTSUPCAMEL=AllowMTCall, WITHOUTINTERAGRE_NOTSUPCAMEL=AllowMTCall, HPLMNINTER_NOTSUPCAMEL=AllowMTCall, AVAILABLE_PLMN=HPLMN;
   ```
