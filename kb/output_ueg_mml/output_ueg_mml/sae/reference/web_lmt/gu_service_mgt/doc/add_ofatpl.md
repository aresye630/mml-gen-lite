# 增加OFA模板(ADD OFATPL)

## 命令功能

该命令用于增加一个OFA（Origin for Forwarded-to number Analysis）模板。在用户开户或者修改前转业务时，OFA模板用于定义不同的号码前缀是否可以被前转到。每个用户可以根据自身需要签约OFA模板，每个前转业务（CFU、CFB、CFNRy、CFNRc）都可以单独签约一个OFA模板。

在增加OFA模板时，如果需要在一个模板中设置多条号码前缀，需要先使用**ADD OFATPL**命令增加模板，然后使用**MOD OFATPL**命令修改模板。在一个OFA模板中最多可设置5000条号码前缀。

## 注意事项

- 所有“HLR序列号”中增加的OFA模板总记录数不能超过5000条。
- 若本命令中“前转处理规则”参数取值为“CFU\_ANALYSIS”，则只支持当用户未签约ODBPB3闭锁业务（可通过**MOD ODBPB3**命令签约）时，对CFU或SMSCF登记前转进行号码变换和跳转。该功能只对默认OFA模板生效，业务级OFA模板不生效。
- 通过该命令签约的OFA模板有前转号码规整的功能（即当“前转处理规则”参数取值为“ANALYSIS”、“FULL\_MATCH”或“CFU\_ANALYSIS”时），该功能只对默认OFA模板生效，业务级OFA模板不生效。

**说明** 

- 默认OFA模板，即通过**MOD DEFAULTOFA**命令为用户签约的OFA模板。
- 业务级OFA模板，即在用户签约前转类业务时调用通过该命令配置的OFA模板。

  每个前转业务（CFU、CFB、CFNRy、CFNRc、SMSCF及SPN）都可以单独签约一个业务级OFA模板。如果用户没有签约业务级OFA模板但签约了默认OFA模板，那么登记前转号码时，将使用用户签约的默认OFA模板。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| TPLID       | 模板ID     | 用于标识待增加模板在系统中的序号。 取值范围：0～65534，其中255为无效值。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| TPLNAME     | 模板名      | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PREFIX      | 号码前缀     | 用于标识一个号码前缀，号码属性为国际号码格式。 取值范围：1～28位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| RULE        | 前转处理规则   | 该参数仅当本命令中的参数“号码前缀”设置时有效。 用于标识指定当前转号码和OFA模板中的号码前缀匹配时的处理规则。 取值范围：TRUE：允许。当前转号码和模板中号码前缀匹配时，允许前转。 FALSE：不允许。当前转号码和模板中号码前缀匹配时，不允许前转。 ANALYSIS：当前转号码和模板中号码前缀匹配时，先在系统中进行号码变换再确定是否进行前转。号码变换按照参数“删除位数指示”和“新增号码 ”的设置进行。号码变换后处理规则按照参数“分析跳转选项”的设置进行。 FULL_MATCH：当前转号码和模板中号码前缀完全匹配时，先在系统中进行号码变换再确定是否前转。号码变换后处理规则按照参数“分析跳转选项”的设置进行。 CFU_ANALYSIS：当前转号码和模板中号码前缀匹配。用户登记为CFU前转或SMSCF前转业务的号码时：若用户同时签约了ODBPB3闭锁业务（可通过MOD ODBPB3命令签约），则不允许前转。若用户未签约ODBPB3闭锁业务，则先在系统中进行号码变换再确定是否进行前转。号码变换按照参数“删除位数指示”和“新增号码 ”的设置进行。号码变换后处理规则按照参数“分析跳转选项”的设置进行。 用户登记为CCF（CFB、CFNRy、CFNRc）前转、CFD前转或SPN前转业务的号码时，则不允许前转。 说明： 对于CFD前转业务限制功能，需要将SET MAPCONF命令的“修改CFD是否进行前转号码规整”参数设置为“TRUE”时，系统才会进行OFA限制，该CFD前转号码不允许前转。 默认值：无。 |
| DEFAULTRULE | 缺省是否允许前转 | 用于标识当前转的号码与OFA模板中签约的前缀不匹配时，是否允许前转。 取值范围：TRUE：允许。 FALSE：不允许。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| REMOVIND    | 删除位数指示   | 该参数仅当本命令中的参数“前转处理规则”设置为“ANALYSIS”或者“FULL_MATCH”时有效。 用于标识系统在进行号码变换处理时可以删除的位数。 取值范围：0～8 默认值：无。 说明：参数“删除位数指示”具体删除号码的位数由运营商的号码处理规则确定。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ADDEDDIGIT  | 新增号码     | 该参数仅当本命令中的参数“前转处理规则”设置为“ANALYSIS”或者“FULL_MATCH”时有效。 用于标识系统在进行号码变换时，在原号码前面新增的号码段。 取值范围：1～8位十进制数字组成的字符串。 默认值：无。 说明：参数“新增号码”具体新增号码的位数由运营商的号码处理规整规则确定。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| TREEOPTION  | 分析跳转选项   | 该参数仅当本命令中的参数“前转处理规则”设置为“ANALYSIS”或者“FULL_MATCH”时有效。 用于标识系统在按照本模板进行号码分析处理完成后是否需要跳转到下一模板继续处理。 取值范围： FIRST DIGIT：跳转。下一模板的号码处理，从处理后的号码的第一位处理。例如：原始号码为“ABC”，删除一位“A”，增加号码“D”，按照此模板处理后的号码为“DBC”。若选择“FIRST DIGIT”，在下一个模板处理时，号码处理从“D”开始。NEXT DIGIT：跳转。下一模板的号码处理，从原始号码下一位开始。例如：原始号码为“ABC”，按照此模板处理后的号码为“DBC”。若选择“NEXT DIGIT”，在下一个模板处理时，号码处理从“B”开始。 默认值：无。                                                                                                                                                                                                                                                                                                                                     |
| NEXTINDEX   | 跳转模板号    | 该参数仅当本命令中的参数“分析跳转选项”设置为“FIRST DIGIT”或者“NEXT DIGIT”时有效。 用于标识系统在号码分析处理完成后跳转到哪一个模板继续处理。 取值范围：0～65534，255为无效值。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| PROCESSIND  | 前转号码处理指示 | 仅当本命令中的“前转处理规则”参数为“FULL_MATCH”时该参数有效，用于标识OFA模板中的前转号码处理指示功能。 取值范围： NO PROCESS：不做处理指示。ADD ISDN：添加用户ISDN到前转号码后进行前转操作。  说明： 由于“前转号码处理指示”参数取值为“ADD ISDN”时会与“REMOVIND”、“ADDEDDIGIT”、“TREEOPTION”和“NEXTINDEX”参数产生冲突，因此当该参数取值“ADD ISDN”时，系统将不对其它四个参数进行处理。 默认值：NO PROCESS                                                                                                                                                                                                                                                                                                                                                                                                                   |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条OFA模板数据记录，设置其前转处理规则和缺省是否允许前转等信息。其中，“模板ID”为“2”，“模板名”为“OFATPL”，“号码前缀”为“86755200”，“前转处理规则”为“ANALYSIS”，“缺省是否允许前转”为“TRUE”，“删除位数指示”为“1”，“新增号码 ”为“35”，“分析跳转选项”为“FIRST DIGIT”，“跳转模板号”为“10”。

`ADD OFATPL: HLRSN=1, TPLID=2, TPLNAME="OFATPL", PREFIX="86755200", RULE=ANALYSIS, DEFAULTRULE=TRUE, REMOVIND=1, ADDEDDIGIT="35", TREEOPTION=FIRST DIGIT, NEXTINDEX=10;`

该命令执行正常，会返回命令执行成功的提示信息。
