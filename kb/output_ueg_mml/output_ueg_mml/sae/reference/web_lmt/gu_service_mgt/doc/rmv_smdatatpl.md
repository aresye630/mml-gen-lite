# 删除5G SMDATA模板(RMV SMDATATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5G会话信息模板数据记录。

## 注意事项

当“模板ID”被**ADD NGSUSERTPL**命令引用，不允许删除该会话信息模板，如果要删除，必须先执行**RMV NGSUSERTPL**命令删除引用该“模板ID”的配置，或使用**MOD NGSUSERTPL**命令修改用户模板配置，使不引用该“模板ID”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识5G会话信息模板数据的关键字段之一，用于指定系统按照哪个HLR序列号来删除5G会话信息模板数据，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无 配置原则：无           |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识一条5G会话信息模板数据记录的关键字段之一，用于指定系统按照哪个模板ID来删除5G会话信息模板数据，操作员可使用LST SMDATATPL命令获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

删除5G会话信息模板，“HLR序列号”为“1”，“模板ID”为“1”，命令如下：

```
RMV SMDATATPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                 | 原因分析                            | 处理建议                                                                    |
|:--------|:----------------------|:--------------------------------|:------------------------------------------------------------------------|
| ERR1004 | 无效的参数值                | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。    | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                        |
| ERR3003 | 模板未定义                 | 输入的“HLR序列号”和“模板ID”标识的会话信息模板不存在。 | 使用LST SMDATATPL命令查询已定义的会话信息模板，然后执行本命令，根据实际情况删除会话信息模板。                   |
| ERR3097 | HLR序列号未定义             | 输入的“HLR序列号”未定义。                 | 使用LST HLRSN命令查询获得已存在的“HLR序列号”，然后使用LST SMDATATPL命令查询已定义的会话信息模板，根据实际情况删除。 |
| ERR4112 | 一个切片下必须存在且仅能存在一个默认DNN | 执行该命令时删除了默认DNN。                 | 使用LST SMDATATPL命令查询已定义的会话信息模板，确保一个切片下必须存在一个默认DNN。                       |
