# 删除锚定AS配置(RMV ANCHORMGCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来删除前缀锚定方式中前缀号码和MSISDN号段的关系，PRN锚定方式中锚定AS和MSISDN号段的关系。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                               |
|:--------------|:---------|:---------------------------------------------------|
| HLRSN         | HLR序列号   | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。           |
| MSISDN_PREFIX | MSISDN前缀 | 对应于此地区的国内移动号码前缀，1～15位的数字。此处的移动号码包括国家码，例：861380270。 |

## 使用实例

删除一条锚定AS，前缀号码和MSISDN号段的对应关系，HLR序列号为1，MSISDN前缀为861380270，命令如下：

RMV ANCHORMGCF: HLRSN=1, MSISDN\_PREFIX="861380270";
