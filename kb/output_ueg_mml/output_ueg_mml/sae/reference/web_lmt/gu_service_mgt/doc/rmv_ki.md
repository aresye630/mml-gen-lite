# 删除KI(RMV KI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本操作描述为一个和多个用户单独删除KI的过程。

对于连续的号码，预先不需要编辑批操作文件。

对于不连续的号码，预先要编辑批操作文件。

## 注意事项

已经开户的用户对应的KI无法删除。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                   |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                                                                         |
| RECORDCOUNT | 用户个数      | 需要删除的KI的总数，最大100000个。 该参数提供，表示以指定的IMSI为起始号码，号码连续的多个用户批删除KI。                                                                                                            |
| IMSIFILE    | 批删除KI的文件名 | 用于标识批删除KI的文件名。IMSI批操作文件包含多个不连续的需要删除KI的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvki.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。 |

## 使用实例

1. 删除IMSI号码为460000009123456的用户的KI。命令如下：

   RMV KI: IMSI="460000009123456";
2. 批删除rmvki.txt中的KI。命令如下:

   RMV KI: IMSIFILE="rmvki.txt";
3. 批删除以IMSI＝460000009123456为起始号码4个用户的KI。命令如下：

   RMV KI: IMSI="460000009123456",RECORDCOUNT=4;
