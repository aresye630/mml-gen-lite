# 模板方式修改共享数据(MOD SHRDATA)

## 命令功能

该命令用于签约、修改和删除用户模板方式签约的共享数据记录。

在该命令为用户提供模板方式签约共享数据之前，需要先用**ADD SHRDATATPL**命令定义5G共享数据模板，然后通过该命令引用对应的模板为用户提供业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。

- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| RECORDCOUNT  | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指示系统按照设置的用户个数来修改对应模板方式签约的共享数据。 取值范围：1~100000。 默认值：无。 配置原则： 当需要为连续号码的多个用户修改用户的签约数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改用户的签约数据。该参数是对连续号码的多个用户修改用户的签约数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |

## 使用实例

1. 修改“IMSI”为460000009123456的用户的核心网接入类型限制管理数据，其中“是否提供共享模板”为“FALSE”。

   ```
   MOD SHRDATA: IMSI="460000009123456", PROV=FALSE;
   ```
2. 修改“IMSI”为460000009123456、460000009123457、460000009123458的3个连续用户的核心网接入类型限制管理数据，其中“是否提供共享模板”为“FALSE”。

   ```
   MOD SHRDATA: IMSI="460000009123456", RECORDCOUNT=3, PROV=FALSE;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
