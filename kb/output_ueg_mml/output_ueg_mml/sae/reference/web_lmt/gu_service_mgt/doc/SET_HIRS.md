# 设置IRS(SET HIRS)

## 命令功能

该命令用于在HSS的业务数据库中设置多个IMPU或PUSI的隐式注册集属性：

- 完全新增一个隐式注册集。
- 向一个已经存在的隐式注册集中新增IMPU或PUSI。
- 从一个已经存在的隐式注册集中删除IMPU或PUSI，或完全删除此隐式注册集。

隐式注册集中的IMPU或PUSI在IMS网络中会同时注册或注销。新增隐式注册集的默认IMPU为“IMPU列表”中的首个IMPU，也可以使用**SET HDEFIMPU**命令重新设置已有隐式注册集的默认IMPU。

## 注意事项

- “IMPU列表”和“PUSI列表”必须存在且仅能存在一个。
- “IMPU列表”或“PUSI列表”中的多个IMPU或PUSI取值不允许相同。
- “IMPU列表”中所有IMPU关联的IMPI必须相同。
- “PUSI列表”中所有PUSI关联的PISI必须相同。
- “IMPU列表”中所有IMPU的漫游权限必须相同。
- “IMPU列表”中所有IMPU的注册权限必须相同。
- “IMPU列表”中所有IMPU的共享属性必须相同。
- 新增隐式注册集时，“IMPU列表”中IMPU的个数或“PUSI列表”中PUSI的个数不能小于2。
- 一个隐式注册集中最多64个IMPU。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                    |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IRSID    | 隐式注册集ID | 用于定义一个隐式注册集索引。 取值范围：0~255 默认值：无。 说明：必选参数。该参数取值为“0”时表示把指定的IMPU或PUSI从隐式注册集中删除。                                                                                                                                                                                            |
| IMPULIST | IMPU列表  | 用于指定要添加或者从隐式注册集中删除的成员。该参数的配置原则是：由1到10个IMPU以“&”连接组成（例如："sip:impuinfo1@huawei.com"&"sip:impuinfo2@huawei.com"，在字符"前需要添加转义字符\）。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。参数中的IMPU必须先由ADD HSUB、ADD HIMPI、ADD HIMPU或ADD HTPLIMPU命令定义，然后才能在此处索引。 取值范围：长度不超过1300的字符串 默认值：无。 说明：可选参数。 |
| PUSILIST | PUSI列表  | 用于指定要添加或者从隐式注册集中删除的成员。该参数的配置原则是：由1到10个PUSI以“&”连接组成（例如："sip:pusiinfo1@huawei.com"&"sip:pusiinfo2@huawei.com"，在字符"前需要添加转义字符\）。输入的PUSI值符合SIP URI或TEL URI格式，字母区分大小写。参数中的PUSI必须先由ADD HPSI或ADD HTPLPUSI命令定义，然后才能在此处索引。 取值范围：长度不超过1300的字符串 默认值：无。 说明：可选参数。                     |

## 使用实例

1. 新增IRS，新增“隐式注册集ID”为“1”，“IMPU列表”为**"sip:impuinfo\_1@huawei.com"&"sip:impuinfo\_2@huawei.com"&"sip:impuinfo\_3@huawei.com"**：

```
SET HIRS: IRSID=1, IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"&\"sip:impuinfo_3@huawei.com\"";
```

2. 将IMPU列表新增到已存在的IRS中，已有“隐式注册集ID”为“1”，需要添加的“IMPU列表”为**"sip:impuinfo\_4@huawei.com"**：

```
SET HIRS: IRSID=1, IMPULIST="\"sip:impuinfo_4@huawei.com\"";
```

3. 将IMPU列表从已存在IRS中删除，如果隐式注册集中剩余IMPU个数小于2，则此IRS自动删除。需要删除的“IMPU列表”为**"sip:impuinfo\_1@huawei.com"&"sip:impuinfo\_2@huawei.com"&"sip:impuinfo\_3@huawei.com"**：

```
SET HIRS: IRSID=0, IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"&\"sip:impuinfo_3@huawei.com\"";
```
