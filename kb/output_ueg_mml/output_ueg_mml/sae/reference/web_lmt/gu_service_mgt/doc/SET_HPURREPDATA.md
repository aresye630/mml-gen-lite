# 设置PUR更新的透明数据(SET HPURREPDATA)

## 命令功能

**须知** 

该命令属于高危命令，执行不当会造成用户签约的业务修改错误。请仔细评估恢复透明数据的依赖条件，确认待恢复的数据的正确性后方可执行。并且该命令不能和**LST LOG**、**LST HLOG**命令同时执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对指定IMS用户或PSI用户的透明数据进行更新操作。

该命令应用的场景为：HSS的透明数据错误时，为了与AS对端的数据保持一致，则根据Sh接口中PUR消息更新的透明数据的空口日志记录对当前HSS的透明数据进行更新操作。

如果设置时间段参数（“开始时间”、“结束时间”和“速率”）或输入参数为指定“IMPU”+时间段参数（“开始时间”、“结束时间”和“速率”）时，并且批操作完成后，以文本格式（文件名格式：SET\_HPURREPDATA\_yyyy-mm-dd-hh-mm-ss.txt）保存在PGW中，系统自动统计时间段方式设置PUR更新的透明数据操作成功的次数，操作结果可以通过PGW Web LMT上的“文件管理器”下载到本地。

## 注意事项

- 若只输入单用户参数（“IMPU”、“透明数据”、“透明数据的类型”和“AS主机名”），则“IMPU”和“透明数据”两个参数必须同时存在；若只输入时间段参数（“开始时间”、“结束时间”和“速率”），则“开始时间”参数必须存在。
- 参数“透明数据”、“透明数据的类型”和“AS主机名”与时间段参数（“开始时间”、“结束时间”和“速率”）互斥。
- 当“结束时间”参数存在时，“开始时间”参数必须存在，且“开始时间”的取值必须小于或等于“结束时间”的取值。
- 该命令只在主用局PGW上执行。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                  |
|:-------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU         | IMPU          | 用于标识待更新的透明数据的IMPU或PUSI。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                     |
| REPDATA      | 透明数据          | 用于标识指定的IMPU或PUSI的透明数据，此值可以为普通透明数据或者别名透明数据，如果存在字符=或者"，需要在该字符前添加转义字符\。操作员可以使用LST HPURREPDATA命令查询获得。 取值范围：长度不超过65000的字符串。 默认值：无。                                                                                                                                         |
| REPTYPE      | 透明数据的类型       | 用于标识待更新透明数据的类型。 取值范围：ALIASREPDATA(Aliasrepository data)：表示为别名透明数据。REPDATA(repository data)：表示为普通透明数据。 默认值：无。                                                                                                                                                          |
| AS           | AS主机名         | 用于标识根据该AS对端的用户数据更新HSS透明数据。操作员可以使用LST HPURREPDATA命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                     |
| STARTTIME    | 开始时间          | 用于标识待更新透明数据的开始时间。从该时间开始的空口日志中记录的透明数据更新到HSS中。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：当“结束时间”参数未输入，“开始时间”参数输入时，则表示从“开始时间”到当前时间的空口日志中记录的透明数据更新到HSS中。                                                                                                         |
| ENDTIME      | 结束时间          | 用于标识待更新透明数据的结束时间。截止该时间的空口日志中记录的透明数据更新到HSS中。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。                                                                                                                                                                           |
| SPEED        | 速率            | 用于标识更新透明数据的速率。 单位：条/秒 取值范围：1～400 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“50”。“0”表示不进行限制。                                                                                                                                                                                   |
| INCRSQN      | 透明数据序列号增加值    | 用于标识待更新透明数据的序列号增加值。更新透明数据过程中将空口日志的透明数据的SequenceNumber加上该参数的值记录到HSS透明数据的SequenceNumber中，若迭加后的值大于65535，则将迭加后的值减65535记录到HSS透明数据的SequenceNumber中。 取值范围：0～65535 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“1”，表示更新透明数据过程中默认将空口日志的透明数据SequenceNumber的值加1记录到HSS透明数据的SequenceNumber中。 |
| UPDATECSDATA | 是否更新该用户的CS域数据 | 用于标识该命令触发的内部PUR消息是否更新该用户的CS域数据信息。 取值范围：FALSE(FALSE)：即使支持业务一致性场景，也不更新CS数据。TRUE(TRUE)：业务一致性场景下，按照原有流程处理，支持更新CS数据。 默认值：无。                                                                                                                                                |

## 使用实例

1. 设置PUR消息更新的指定IMPU的透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“透明数据”为“<?xml version\=\"1.0\"?><Sh-Data><RepositoryData><ServiceIndication>3</ServiceIndication><SequenceNumber>0</SequenceNumber><ServiceData></ServiceData></RepositoryData></Sh-Data>”、“透明数据的类型”为“ALIASREPDATA”、“AS主机名”为“as1.huawei.com”：

   ```
   SET HPURREPDATA: IMPU="sip:impuinfo1@huawei.com", REPDATA="<?xml version\=\"1.0\"?><Sh-Data><RepositoryData><ServiceIndication>3</ServiceIndication><SequenceNumber>0</SequenceNumber><ServiceData></ServiceData></RepositoryData></Sh-Data>", REPTYPE=ALIASREPDATA, AS="as1.huawei.com";
   ```
2. 设置PUR消息更新的某时间段内的透明数据。“开始时间”为“2016&05&31&09&00&00”、“结束时间”为“2016&06&01&09&00&00”：

   ```
   SET HPURREPDATA: STARTTIME=2016&05&31&09&00&00, ENDTIME=2016&06&01&09&00&00;
   ```
3. 设置PUR消息更新的指定IMPU在某时间段内的透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“开始时间”为“2016&05&31&09&00&00”、“结束时间”为“2016&06&01&09&00&00”、“是否更新该用户的CS域数据”为“FALSE”：

   ```
   SET HPURREPDATA: IMPU="sip:impuinfo1@huawei.com", STARTTIME=2016&05&31&09&00&00, ENDTIME=2016&06&01&09&00&00, UPDATECSDATA=FALSE;
   ```
