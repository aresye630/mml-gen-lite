# 利用模板修改用户IMS数据(MOD TPLIMSSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中利用模板修改或调整用户IMS数据。在该命令中，系统通过以下关键参数的组合来唯一标识一条用户IMS数据：

- “HLR序列号”
- “IMSI”或“MSISDN”

## 注意事项

- “IMSI”和“MSISDN”是互斥参数，必须有且只能有一个参数出现。
- “闭锁的IMPU列表”、“VoLTE用户标志”和“IMS用户模板ID”参数至少输入一个。
- 本命令只能在SAE-HSS/IMS-HSS/HLR三个融合的场景下执行。
- 本命令只能修改通过**ADD TPLIMSSUB**命令添加的融合用户的IMS数据。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时需要注意：
  - 引用用户签约的“HLR序列号”下的IMS用户模板。
  - 本命令的“HLR序列号”与签约IMS用户模板对应的“HLR序列号”要一致。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                  |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号    | 用于标识一个IMS签约用户属于哪个虚拟HSS。 取值范围：0～255 默认值：无。                                                                                                                                                                                                                                             |
| IMSI        | IMSI      | 用于标识用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                          |
| ISDN        | MSISDN    | 用于标识用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                        |
| BARIMPULIST | 闭锁的IMPU列表 | 用于指定要闭锁的IMPU的值。该参数的配置原则是：由1到10个IMPU以“&”连接组成（例如：\"sip:impuinfo1@huawei.com\"&\"sip:impuinfo2@huawei.com\"，在字符"前需要添加转义字符\）。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：1～1300位由数字、字母或“.”、“&”、“：”等特殊字符组成的字符串。 默认值：无。 说明：输入的IMPU为非通配型，需包含在ADD TPLIMSSUB命令定义“IMPU列表”参数中。并且被闭锁的IMPU不能为默认IMPU。 |
| VOLTETAG    | VoLTE用户标志 | 用于指定用户是否是VoLTE用户。 取值范围：TRUE(TRUE)：表示该用户是VoLTE用户。FALSE(FALSE)：表示该用户不是VoLTE用户。 默认值：无。 说明：如果位置注册消息中携带该参数，则覆盖开户内容。如果不携带该参数，则保持开户信息。                                                                                                                                                       |
| IMSTPLID    | IMS用户模板ID | 用于修改指定用户对应的IMS用户模板号，该模板需要通过命令ADD IMSTPL定义，才能在此处索引。 取值范围：1～1024 默认值：无 说明：如果没有输入“IMS用户模板ID”参数值，则不为该用户修改该参数值。如果输入“IMS用户模板ID”参数值，每个用户对应所有IMPU的签约属性都一致，都采用同一个模板中的数据。                                                                                                                       |

## 使用实例

为“HLR序列号”为“1”，“IMSI”为“460001234567890”的用户修改IMS业务数据，参数取值如表1所示。

| 参数        | 值                            |
|:----------|:-----------------------------|
| 闭锁的IMPU列表 | \"sip:impuinf_2@huawei.com\" |
| VoLTE用户标志 | TRUE                         |
| IMS用户模板ID | 1                            |

```
MOD TPLIMSSUB: HLRSN=1, IMSI="460001234567890", BARIMPULIST="\"sip:impuinf_2@huawei.com\"", VOLTETAG=TRUE, IMSTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| ERR1010   | 参数冲突                       | “IMSI”和“MSISDN”两个参数都被输入。                                                                                                                                    | 根据实际情况，重新输入参数，确保满足“IMSI”和“MSISDN”两个参数必须有且只能有一个参数出现。                                                                                             |
| ERR3001   | 用户未开户                      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                                                                                      | 核实用户的IMSI号码或MSISDN号码，如果确定输入正确，说明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                                              |
| ERR3003   | 模板未定义                      | 可能原因为如下之一： 执行该命令时输入的“IMS用户模板ID”在“HLR序列号”下不存在。执行该命令时输入的“IMS用户模板ID”在“HLR序列号”下存在，但是SET HSYSTEMPARA命令中“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参取值不为“TRUE(TRUE)”。 | 根据实际情况，重新输入参数，确保满足以下两点： 执行ADD IMSTPL命令在“HLR序列号”下增加一条“IMS用户模板ID”记录。执行SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参取值为“TRUE(TRUE)”。 |
| ERR3092   | HLR序列号不匹配                  | 参数“HLR序列号”输入错误，实际输入的参数“HLR序列号”与“IMSI”或“MSISDN”不匹配。                                                                                                          | 根据实际情况，重新输入参数“HLR序列号”的取值，确保其取值已被定义，且与“IMSI”或“MSISDN”匹配。可通过LST SUB命令查询。                                                                          |

| ERR3810   | 用户不是EPS用户或未开户              | 参数“VOLTETAG”设置为“TRUE”或者使用STNSR(Session Transfer Number for SRVCC)号码时，但用户未签约EPS业务。                                                                           | 通过ADD SUB命令给用户签约EPS业务。                                                                                                                          |

| 900003051 | 请求消息中的SubId不存在             | 输入的参数“IMSI”对应的IMS用户未开户。                                                                                                                                     | 根据实际情况，重新输入参数，确保已通过ADD TPLIMSSUB命令增加了该用户的IMS数据。                                                                                                 |
