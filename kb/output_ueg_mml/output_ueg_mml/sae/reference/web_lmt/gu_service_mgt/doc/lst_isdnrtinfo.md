# 查询MSISDN全局路由数据(LST ISDNRTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用来查询MSISDN全局路由数据。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                    |
|:-----------|:---------|:--------------------------------------------------------|
| ISDNPREFIX | MSISDN前缀 | MSISDN号段，对应于此地区的MSISDN号段。 取值范围：1～15位的十进制数字组成的字符串。 可选参数。 |

## 使用实例

查询MSISDN全局路由数据：ISDNPREFIX为1234，命令如下：

LST ISDNRTINFO: ISDNPREFIX="1234";
