## 命令功能

该命令用于修改用户的VMCC（Voice Mail Call Completion）业务数据。

当用户签约了VMCC业务后，在位置更新、独立插入用户数据（登记/激活/去激活条件前转）、恢复用户数据流程中，若同时满足下面条件时，触发的ISD（Insert Subscriber Data）消息中不下发用户登记的前转号码，包括CFD（Call Forwarding Default）等的号码给VLR，否则正常下发前转号码到VLR。

- 用户处于国际漫游状态（当前漫游VLR为国际跨网或者国际本网）。
- 用户通过该命令签约了VMCC业务。
- 用户已登记了一个CCF（Conditional Call Forwarding）前转号码，且该规整后的前转号码最大匹配上**SET RESSPECFTN**配置的前转限制名单。

  **说明** 

  - 如果前转号码是CFB/CFNRy/CFNRc，当前转号码在限制名单中，用户还未签约VMCC，并在当前国际漫游的VLR上正常下发过签约的前转号码，后面再签约VMCC时，则下发ISD消息且携带的CCF状态为提供态。
  - 如果前转号码是CFD，用户在当前国际漫游的VLR上正常下发过签约的前转号码，再签约VMCC时：
    - 用户所签的“基本业务组”不相同，则下发的ISD消息中携带的CCF状态互不干扰。例如，用户签约的CFB在TS1X上是登记态（未被限制），CFD替代的CFB在TS6X上是激活态，则下发的ISD消息且携带的CCF状态在TS6X上是提供态 。
    - 用户所签的“基本业务组”相同，用户签约的CCF是登记态（未被限制），CFD替代的CCF是激活态，则下发用户签约的ISD消息中携带的CCF状态。例如，用户签约了CFB为登记态（未被限制），CFD替代CFB为激活态，则下发ISD消息且携带的CCF状态为登记态。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 当用户签约了VMCC业务后，在**SET MAPCONF**命令中的“补充业务MAP响应中是否携带相应信元”参数设置为“TRUE”时做如下处理：
  - 当登记、激活/去激活前转业务的消息中携带的“SS-Code”为“ALL CF”或“ALL CCF”时，响应消息中依然会携带其登记、激活/去激活状态。
  - 当登记、激活/去激活前转业务的消息中携带的“SS-Code”为“CFB”、“CFNRy”或“CFNRc”时，响应消息中仅会携带提供状态。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                         |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | 用于标识待修改VMCC业务的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。E.212格式的编码。 默认值：无。                                                                                                                                                                               |
| ISDN        | MSISDN     | 用于标识待修改VMCC业务的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。E.164格式的编码。 默认值：无。                                                                                                                                                                             |
| RECORDCOUNT | 用户个数       | 用于标识待修改VMCC业务的用户的数目。 当需要为连续号码的多个用户修改VMCC业务时配置该参数，配置后，系统将会从已指定的“IMSI”号码或“MSISDN”号码开始，对连续号码的多个用户修改VMCC业务。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户修改VMCC业务，当只有一个用户时，该参数不必配置。当一次修改VMCC业务的用户个数很多时，对系统性能无影响，但修改VMCC业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名    | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改VMCC业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvmcc.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                             |
| ISDNFILE    | MSISDN文件名  | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改VMCC业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvmcc.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                       |
| VMCC        | 是否提供VMCC业务 | 用于标识是否给用户提供VMCC业务。 取值范围： TRUE：提供。FALSE：撤销。 默认值：FALSE。                                                                                                                                                                                        |

## 使用实例

1. 为IMSI号码是“460000009123456”的用户提供VMCC业务。

   ```
   MOD VMCC: IMSI="460000009123456", VMCC=TRUE;
   ```
2. 为从IMSI号码是“460000009123456”的号码开始的3个连续号码的用户提供VMCC业务。

   ```
   MOD VMCC: IMSI="460000009123456", RECORDCOUNT=3, VMCC=TRUE;
   ```
3. 为3个非连续号码的用户提供VMCC业务。
   - 3个IMSI号码分别为：460000009123456、460000019123456、460000029123456。
   - 3个IMSI号码已保存在IMSI文件名为“modvmcc.txt”的文件中，并通过文件管理功能上传到指定目录。

   ```
   MOD VMCC: IMSIFILE="modvmcc.txt", VMCC=TRUE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
