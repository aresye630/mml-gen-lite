# 修改EPS用户模板（MOD EPSUSERTPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条EPS（Evolved Packet System）用户模板数据记录的某些参数进行修改或调整。在该命令中，系统通过“HLR序列号”和“模板 ID”关键参数的组合来唯一标识一条EPS用户模板数据记录。

## 注意事项

- 不允许删除最后一条PDN数据。
- 系统中所有EPS用户模板增加的PDN上下文总记录数不能超过10000条。

| TPLNAME            | 模板名称                 | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或数字组成的字符串。 默认值：无。                                                                                                                                                                               |

| AMBRMAXDL          | UE最大下行带宽             | 仅当参数“操作类型”为“MODEPSINFO”时该参数有效，用于标识EPS用户最大下行带宽，即接受消息的最大带宽。 取值范围：1～4294967295（单位：bit/s）。 默认值：无。                                                                                                                                 |

## 使用实例

修改“HLR序列号”为“1”，“模板 ID”为“1”的EPS用户模板数据，“模板名称”修改为“EPSUSERTPL01”，“操作类型”修改为“ADDPDNCNTX”，“PDN上下文索引值”修改为“1”，“EPSAPNQOS模板ID”修改为“1”:

`MOD EPSUSERTPL: HLRSN=1, TPLID=1, TPLNAME="EPSUSERTPL01", PROV=ADDPDNCNTX, CNTXID=1, EPSAPNQOSTPLID=1;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义    | “HLR序列号”和“模板 ID”参数对应的模板数据记录不存在。                                                                                                                                                                                           | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板 ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST EPSUSERTPL命令查询。                                                                                                                                                                 |
| ERR3047 | 超过最大限制   | 所有EPS用户模板增加的“PDN上下文索引值”总记录数超过10000条。                                                                                                                                                                                      | 根据实际情况，如需增加PDN上下文索引值，处理步骤如下：执行LST EPSUSERTPL命令，查询已存在的PDN上下文索引值。执行该命令删除不必要的PDN上下文索引值。执行该命令增加PDN上下文索引值，确保增加的PDN上下文索引值在规定范围之内。                                                                                                                      |
