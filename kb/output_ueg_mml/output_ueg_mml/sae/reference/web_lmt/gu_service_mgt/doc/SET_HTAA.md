# 设置指定IMPI的TAA鉴权模式(SET HTAA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPI的TAA鉴权模式。

## 注意事项

当指定的IMPI已开户且只支持TAA鉴权，如果取消该IMPI支持TAA鉴权，HSS返回失败。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                               |
|:--------|:--------|:-----------------------------------------------------------------------------------|
| IMPI    | IMPI    | 用于定义一个需要设置或者取消支持TAA鉴权模式的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无  |
| TAAFLAG | TAA鉴权标识 | 用于指定IMPI的TAA鉴权标识，其值域类型为布尔值，TRUE代表支持，FALSE代表不支持。 取值范围：FALSE(False)TRUE(True) 缺省值： 无 |

## 使用实例

设置指定IMPI的TAA鉴权模式。IMPI：impiinfo，TAA鉴权标识：TRUE。

```
SET HTAA: IMPI="impiinfo", TAAFLAG=TRUE;
```
