# 修改IMPI(MOD HIMPI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于对HSS的业务数据库中的一条IMPI记录进行修改，唯一标识数据记录的关键参数就是IMPI。

## 注意事项

- 对于VoLTE Multi-SIM用户，执行**MOD HIMPI**命令对用户主卡进行补卡时，修改主卡的IMPI后需要重新执行**MOD HMSIM**命令设置主卡标记。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| IMPI    | IMPI   | 标识一条IMPI和SUBID关联关系的关键参数，用于指定需要修改哪一条IMPI和SUBID之间的关联关系，操作员可以使用LST HSUB操作查询获得，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| NEWIMPI | 新的IMPI | 用于指定与签约用户关联的新的IMPI的值，该参数必须先由增加鉴权数据的相关操作定义，然后才能在此处索引，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                        |

## 使用实例

修改IMPI。IMPI：impiinfo，新的IMPI：new\_impiinfo。

```
MOD HIMPI: IMPI="impiinfo", NEWIMPI="new_impiinfo";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                    | 原因分析                                                                                                                                                               | 处理建议                                                                                                     |
|----------:|:-------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------|
| 900003512 | IMPI绑定的IMSI被共用，IMPI不能被删除 | 可能原因为当SET HSYSTEMPARA命令中的软参“EAA_IMPI_SHARE_IMSI_SUPPORT”取值为“TRUE”且出现如下场景之一：当“IMPI”的鉴权类型为EAA鉴权时，输入的“新的IMPI”的鉴权类型为非EAA鉴权。当“IMPI”的鉴权类型非EAA鉴权时，输入的“新的IMPI”的鉴权类型为EAA鉴权。 | 根据实际情况，重新输入参数，确保满足以下两点：当“IMPI”的鉴权类型是EAA鉴权时，“新的IMPI”的鉴权类型为EAA鉴权。当“IMPI”的鉴权类型非EAA鉴权时，“新的IMPI”的鉴权类型为非EAA鉴权。 |
