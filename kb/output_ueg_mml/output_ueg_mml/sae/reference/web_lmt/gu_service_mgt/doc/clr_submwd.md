# 清除短消息地址列表（CLR SUBMWD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该操作会清除用户的SMS业务相关的动态数据，是否继续？

此操作用于清除用户所有短消息相关的动态信息。

## 注意事项

- 此操作会导致用户短消息相关动态信息丢失，请谨慎操作。
- IMSI、MSISDN是可选参数，有且只能有一个参数出现。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------|
| IMSI    | IMSI   | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                      |
| ISDN    | MSISDN | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                    |
| CONTENT | 清除内容   | 清除短消息相关内容。 取值范围： ALL：清除所有与短消息相关的动态信息。FLAG：清除与短消息相关的标志位。MWDList：清除短消息等待队列列表。 缺省值：ALL |

## 使用实例

对IMSI号码是461107050672001的用户清除所有与短消息相关的动态信息。

CLR SUBMWD: IMSI="461107050672001", CONTENT=ALL;
