# 修改K2(MOD K2)

- 命令功能
- 注意事项

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS/HLR中修改K2密钥名称和K7序列号。在该命令中，系统通过以下关键参数的组合来唯一标识一条K2密钥信息：

- HLR序列号
- K2序列号

## 注意事项

- **LST K2**命令查询结果中的“ALGTYPE”不为空，且执行本命令签约了“HSM密钥索引”时，新开卡用户在UDM上加密。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                      |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号  | 标识K2数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的K2数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                          |
| K2SNO       | K2序列号   | 标识K2数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个K2序列号对应的K2名称进行修改或调整，操作员可以使用LST K2命令查询获得。                                                                                                                                                                               |
| KEYNAME     | K2名称    | 用于标识K2密钥名称。 取值范围：5位～60位的字符串。 默认值：无。                                                                                                                                                                                                                       |
| K7SNO       | K7序列号   | 用于标识需要修改的加密K2的K7序列号。此参数适用于如下场景：将无K7密钥加密的K2改为由HSM上K7密钥加密的K2，即新增K2的K7密钥。修改加密K2的HSM上的K7密钥。                                                                                                                                                                   |
| HSMKEYINDEX | HSM密钥索引 | 用于标识HSM上的密钥索引，在HSM上导入密钥后，把对应的HSM密钥索引添加到UDM。 取值范围：5位～60位的字符串。 默认值：无。 配置原则：该参数由组名称+参数名称+ID组成，中间使用“:”分开：组名称和参数名称为字符串形式，且不为空，分别对应导入密钥时的Object group和Object name参数；ID为十进制数字，取值范围是0～2147483647，对应导入密钥时的Object specifier参数。例如：mnts:myParam:1。该参数取值包含字母时，字母区分大小写。 |

## 使用实例

1. 在HSS/HLR中修改K2名称。“HLR序列号”为“1”，“K2序列号”为“1”，“K2名称”改为“K2namehlr1k2sno1”：

   ```
   MOD K2: HLRSN=1, K2SNO=1, KEYNAME="K2namehlr1k2sno1";
   ```
2. 在HSS/HLR中修改K7序列号。“HLR序列号”为“1”，“K2序列号”为“1”，“K7序列号”改为“2”：

   ```
   MOD K2: HLRSN=1, K2SNO=1, K7SNO=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:---------------|:-------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在          | 有两点原因：HLR序列号未定义。HLR序列号对应的K2序列号未添加。                                                                                       | 对于第一点原因，处理步骤如下：执行LST HLRSN命令查询出已定义的HLRSN。执行LST K2命令查询出该HLRSN对应的K2序列号。结合实际情况，根据HLRSN和K2序列号修改对应的K2数据。 对于第二点原因，只需执行上述处理步骤的2和3。                  |
| ERR3111 | 系统不支持该特性       | 可能原因为如下之一： SET MAPCONF命令中“是否支持K7密钥” 参数取值为“FALSE”时，本命令携带了“K7序列号”且对应的K7取值不为“0”。本命令携带了“K7序列号”且对应的K7取值和执行ADD K2命令添加的K7取值不一致。 | SET MAPCONF命令中“是否支持K7密钥” 参数取值为“FALSE”，确保不携带“K7序列号”或携带“K7序列号”时对应的K7取值为“0”，然后执行本命令。确保不携带“K7序列号”或携带的“K7序列号”对应的K7取值和执行ADD K2命令添加的K7取值一致，然后执行本命令。 |

| ERR4195 | 不支持处理保存在HSM的记录 | 待修改的“K2序列号”为HSM类型。                                                                                                       | 在用户签约的K2记录中查询“K2密钥输入方式”，然后重新执行本命令，确保待修改的“K2序列号”不为HSM类型。                                                                                      |
