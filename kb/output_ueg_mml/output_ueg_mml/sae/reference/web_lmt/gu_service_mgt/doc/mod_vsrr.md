# 修改VLR/SGSN漫游限制业务(MOD VSRR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM为用户提供或撤销VLR/SGSN漫游限制业务。VLR/SGSN漫游限制业务会根据运营商、网络或用户的要求，对用户移动性进行管理，设置用户允许漫游的VLR/SGSN范围。

在通过该命令为用户签约VLR/SGSN漫游限制业务之前，需要先用**ADD VSLIST**命令定义VLR/SGSN漫游限制模板，再通过该命令引用对应的模板为用户提供业务。

## 注意事项

- “IMSI”、“ISDN”、“IMSI文件名”和“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。
- 一个用户最多只能签约一个VLR漫游限制业务和一个SGSN漫游限制业务，如已签约了同一模板类型的业务，则当该命令的“是否提供VLR/SGSN漫游限制业务”参数取值为“TRUE”时，命令功能为修改，将会覆盖原来签约的漫游限制业务。
- 当**SET MAPCONF**命令中，参数“是否支持ARD增强处理”设置为“TRUE”，且VLR/SGSN支持对RAT类型的检查时，执行该命令修改VLR/SGSN漫游限制业务后，会检查用户当前的RAT接入类型，如果当前RAT接入受限，则HSS会向VLR/SGSN发送Cancel Location消息。

## 参数说明

| 参数标识        | 参数名称               | 参数说明                                                                                                                                                                                                                                |
|:------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI               | 用于标识需要进行模板开户的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                               |
| ISDN        | MSISDN             | 用于标识需要进行模板开户的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                             |
| RECORDCOUNT | 用户个数               | 用于标识需要修改漫游限制业务数据的用户数目。 当需要为连续号码的多个用户修改漫游限制业务数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改漫游限制业务数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改漫游限制业务数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名            | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改漫游限制业务数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvsrr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                               |
| ISDNFILE    | MSISDN文件名          | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改漫游限制业务数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvsrr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                         |
| PROV        | 是否提供VLR/SGSN漫游限制业务 | 用于标识执行该命令是提供/修改还是撤销漫游限制业务。 取值范围：TRUE：选择此值时命令功能是为用户提供或修改漫游限制业务，此时“VLR/SGSN漫游限制模板ID”和“模板类型”参数为必选。FALSE：选择此值时命令功能是为用户撤销漫游限制业务，此时“VLR/SGSN漫游限制模板ID”参数无效。 默认值：无。                                                                         |
| TPLTYPE     | 模板类型               | 当本命令中的“是否提供VLR/SGSN漫游限制业务”参数取值为“TRUE”时该参数必须输入，否则为可选参数。用于标识漫游限制模板的类型，区分是VLR模板还是SGSN模板。一个指定的模板只能存储一种类型的号码资源。 取值范围：VLR：VLR模板SGSN：SGSN模板 默认值：无。                                                                                         |
| TPLID       | VLR/SGSN漫游限制模板ID   | 仅当本命令中的“是否提供VLR/SGSN漫游限制业务”参数取值为“TRUE”时该参数有效。用于标识漫游限制模板号。该参数必须先由ADD VSLIST命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                       |

## 使用实例

1. 给IMSI号码为“460000009034567”的用户提供VLR/SGSN漫游限制业务，“是否提供VLR/SGSN漫游限制业务”为“TRUE”，“模板类型”为“VLR”，“VLR/SGSN漫游限制模板ID”为“1”：

   ```
   MOD VSRR: IMSI="460000009034567", PROV=TRUE, TPLTYPE=VLR, TPLID=5;
   ```
2. 给3个连续号码的用户提供漫游限制业务数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“用户个数”为“3”，“是否提供VLR/SGSN漫游限制业务”为“TRUE”，“模板类型”为“SGSN”，“VLR/SGSN漫游限制模板ID”为“1”：

   ```
   MOD VSRR: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, TPLTYPE=SGSN, TPLID=1;
   ```
3. 给3个非连续号码的用户撤销漫游限制业务数据，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modvsrr.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供VLR/SGSN漫游限制业务”为“FALSE”：

   ```
   MOD VSRR: ISDNFILE="modvsrr.txt", PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
