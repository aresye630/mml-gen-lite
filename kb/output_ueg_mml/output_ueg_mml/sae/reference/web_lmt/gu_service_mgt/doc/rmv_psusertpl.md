# 删除PS用户模板(RMV PSUSERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除PS用户模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识PS用户模板数据记录的关键字段之一，用于指定在哪个HLR上删除PS用户模板的数据记录，操作员可以使用LST HLRSN命令查询获得。  |
| TPLID  | 模板ID   | 标识PS用户模板数据记录的关键字段之一，用于指定需要删除哪条PS用户模板的数据记录，操作员可以使用LST PSUSERTPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“模板ID”为“10”的PS用户模板。命令如下：

`RMV PSUSERTPL: HLRSN=1, TPLID=10;`
