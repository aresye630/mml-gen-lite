# 校验IMPI的HA1信息(CHK HHA1)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验HTTP Digest鉴权信息与SIP Digest鉴权信息中的“IMPI”与“HA1值”是否匹配。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“HA1值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“HA1值”以明文显示。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| IMPI   | IMPI   | 标识一个用户的关键参数之一，用于指示系统验证哪一个IMPI。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。  |
| HA1    | HA1值   | 标识一个用户的关键参数之一，用于指示系统被验证的HA1值。 取值范围：长度等于32的16进制字符串 默认值：无。 说明：必选参数。 |

## 使用实例

校验IMPI的HA1信息，“IMPI”为“impiinfo”，“HA1值”为“11112222333344445555666677778888”。

```
CHK HHA1: IMPI="impiinfo", HA1="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                          | 处理建议        |
|----------:|:--------|:--------------------------------------------------------------|:------------|
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
