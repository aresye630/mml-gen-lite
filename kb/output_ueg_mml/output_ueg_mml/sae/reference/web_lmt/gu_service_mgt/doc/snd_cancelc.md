# 发送模拟Cancel Location消息(SND CANCELC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作是在用户数据管理台上人为的模拟HLR向VLR、Gn/Gp SGSN、S4 SGSN、MME等设备发送Cancel Location消息，以此来删除HLR中指定用户在相应的VLR/SGSN/MME等设备中的用户信息。系统默认场景下，发送Cancel消息若对端无响应时，UDM不会清除用户动态数据。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 该命令不允许进行批操作。
- 本命令适用于UDM和IWF场景。
- 执行该命令后会删除指定用户在HLR/HSS和相应的VLR/SGSN中的动态信息，会导致用户无法正常使用业务，因此执行该命令前，请评估是否确实需要清除用户的动态信息，如有疑问，请联系华为技术支持。

## 使用实例

1. 触发AMF 3GPP去注册流程，“IMSI”为“460030913121001”，“用户个数”为“2”，“发送目的地”为“AMF”，“AMF实例标识”为“10406029-ffff-ffff-ffff-6197a1d09d55”，“cancelType的取值”为“subscriptionWithdraw”：

   ```
   SND CANCELC: IMSI="460030913121001", RECORDCOUNT=2, DEST=AMF, CANCELTYPE=subscriptionWithdraw, AMFHOST="10406029-ffff-ffff-ffff-6197a1d09d55";
   ```
2. IMSI号码为460004600000009的用户向号码为7777的SGSN发送CANCEL LOCATION消息，发送前不检查是否本HSS的用户。命令如下：

   ```
   SND CANCELC: IMSI="460004600000009", DEST=SGSN, SGSNO="7777", CHECK=FALSE;
   ```
3. IMSI号码为460000009123456的用户同时向VLR、SGSN、MME、S4SGSN和AAA发送Cancel Location消息。命令如下：

   ```
   SND CANCELC: IMSI="460000009123456", DEST=ALL;
   ```
4. 代发场景下触发AMF 3GPP去注册流程，并清除5GS域动态数据，不等待对端返回通知消息，“IMSI”为“460030913121001”，发送目的地为“AMF”，“AMF实例标识”为“00000000-0000-0000-0000-000000000000”，“cancelType的取值”为“ CANCELTYPE=5GS\_TO\_EPS\_MOBILITY”，“AMF PLMNID”为“00000”，“AMF ID”为“000000”：

   ```
   SND CANCELC: IMSI="460030913121001", DEST=AMF, CANCELTYPE=5GS_TO_EPS_MOBILITY, AMFDEREGURI="http://172.16.2.2:8080/namf-uecm/v1/12345678/registrations/amf-3gpp-access", AMFHOST="00000000-0000-0000-0000-000000000000", AMFPLMN="00000", AMFID="000000", CLRNGSDYNDATA=CLR, WAITAMFRSP=FALSE;
   ```
5. 割接场景下，需要将被割接局点用户强制下线，“IMSI”为“460030913121001”，发送目的地为“MME”，“cancelType的取值”为“updateProcedure ”，“是否支持自动获取动态数据”为“TRUE”，“分区ID”为“10”：

   ```
   SND CANCELC: IMSI="460030913121001", DEST=MME, CANCELTYPE=updateProcedure, AUTOGETDYNDATA=TRUE, PID=10;
   ```
