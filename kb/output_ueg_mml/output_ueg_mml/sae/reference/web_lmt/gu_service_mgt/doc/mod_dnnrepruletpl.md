# 修改DNN替换规则模板(MOD DNNREPRULETPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户APN/DNN业务被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条DNN替换规则模板记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条DNN替换规则模板记录：

- “HLR序列号”
- “模板ID”

## 注意事项

DNN替换规则模板中必须保证至少存在5GS漫游模板、PLMN漫游模板或DIAMRR漫游模板三个其中之一的数据，如果本命令中的“是否签约5GS漫游模板ID”、“是否签约PLMN漫游模板ID”和“是否签约DIAMRR漫游模板ID”参数均为“FALSE”，则无法删除，系统会返回错误码“ERR3096：模板不能为空”。

## 使用实例

修改DNN替换规则模板的数据，“HLR序列号”为“1”，“模板ID”为“8”，“是否签约5GS漫游模板ID”为“TRUE”，“5GS漫游模板ID”为“3”。

```
MOD DNNREPRULETPL: HLRSN=1, TPLID=8, PROVNGCNODETPL_ID=TRUE, NGCNODETPL_ID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:----------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。                                            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                |
| ERR3003 | 模板未定义   | “5GS漫游模板ID”、“PLMN漫游模板ID”或“DIAMRR漫游模板ID”对应的模板未定义。                | 根据实际情况，重新输入参数，确保输入的“5GS漫游模板ID”、“PLMN漫游模板ID”或“DIAMRR漫游模板ID”对应的模板已定义，可通过执行LST NGCRRNODETPL、LST PLMNTPL或LST DIAMRRTPL命令查询已存在的模板信息。 |

| ERR3096 | 模板不能为空  | “是否签约5GS漫游模板ID”、“是否签约PLMN漫游模板ID”和“是否签约DIAMRR漫游模板ID”参数均为“FALSE”。 | 请确认是否需要删除DNN替换规则模板中的5GS漫游模板、PLMN漫游模板和DIAMRR漫游模板数据，若需要删除，请通过RMV DNNREPRULETPL命令删除相应模板。                                           |
