# 修改FM登记数据(MOD FMREG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于为本地管理的一个远端号码登记、去登记一个或最多5个的初始号码。

远端用户类型是GSM用户或虚拟用户。GSM远端用户是NAM为MSC和BOTH的用户。

## 注意事项

- 此命令只支持操作员管理本地的远端号码和初始用户，非本地用户不能进行管理。
- 初始用户号码不能是辅号。
- 登记的初始用户和远端号码不能相同。
- 去登记某一个远端号码时，会通知被解绑定的初始用户。
- 如果给远端号码登记初始号码， OPTION设置为REGISTER。如果全局配置开关FM\_MulCurInitNum\_SUP为FALSE，一个远端号码只能登记一个初始号码，否则允许一个远端号码最多登记5个初始号码。
- 如果给远端号码去登记初始号码，OPTION设置为ERASE，如果没有填入初始号码，则去登记远端号码的所有初始号码；如果填入初始号码， FM\_MulCurInitNum\_SUP为FALSE，则去登记远端号码的所有初始号码，FM\_MulCurInitNum\_SUP为TRUE，则去登记此初始号码。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识    | 参数名称          | 参数说明                                                                                                                                                                                                |
|:--------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号        | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                            |
| OPTION  | 操作选项          | 为某一远端用户登记或者删除初始用户。 取值范围： REGISTER: 登记初始用户ERASE: 删除初始用户 说明：必选参数。                                                                                                                                     |
| RMNUM   | 远端号码          | 远端号码，E.164格式的编码。 当SET MAPCONF命令中“是否支持远端号码里包含字母”标志位为缺省值“FALSE”时，远端号码为1～15位的十进制数字。 当SET MAPCONF命令中是否支持远端号码中包含字母标志位为“TRUE”时，远端号码为中国GSM-R网络用户号码： 不以2开头时，为1～15位的十进制数字。以2开头时，为可以包含字母和数字的4～10位字符。 说明：必选参数。 |
| INITNUM | 初始用户的MSISDN号码 | 仅当本命令中的"操作选项"参数为"Register"或"Erase"时该参数有效。初始用户的MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                                                      |

## 使用实例

为远端用户号码是8613900001234的用户登记初始用户，初始用户的MSISDN号码为8613865591111。

```
MOD FMREG: HLRSN=1, OPTION=Register, RMNUM="8613900001234", INITNUM="8613865591111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                | 处理建议                                             |
|:--------|:--------|:--------------------|:-------------------------------------------------|
| ERR3016 | 基本业务未提供 | 输入的“远端号码”参数未签约语音业务。 | 通过MOD TS命令设置“是否提供语音业务”参数为“TRUE”为用户签约语音业务后再执行该命令。 |
