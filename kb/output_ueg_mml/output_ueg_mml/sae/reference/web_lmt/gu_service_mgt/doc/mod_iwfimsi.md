# 修改IMSI号段属性(MOD IWFIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改某个IMSI号段的属性。在该命令中，系统通过“IMSI前缀”来唯一标识一个IMSI号段。

## 注意事项

- 当修改“工作模式”参数取值时，请确认修改后的“工作模式”涉及的条件必选参数均已设置。请参考**ADD IWFIMSI**命令输入该“工作模式”下所需的条件必选参数。
- 当修改“鉴权协议类型”参数取值时，请确认修改后的“鉴权协议类型”涉及的条件必选参数均已设置。请参考**ADD IWFIMSI**命令输入该“鉴权协议类型”下所需的条件必选参数。
- 当修改“工作模式”参数取值时，若“工作模式”参数为“SQNSYNC”，不支持将“SQNSYNC”修改为其它取值；若“工作模式”参数不为“SQNSYNC”，不支持将当前取值修改为“SQNSYNC”。

## 使用实例

1. 配置UTA业务时，如果需要调整IMSI号段的工作模式，例如修改“IMSI前缀”为“46000”，“工作模式”为“UDM”的一条IMSI号段属性记录，将“工作模式”修改为“IWF”，进行如下配置：

   ```
   MOD IWFIMSI: IMSIPRE="46000", MODE=IWF, NGSUSERTPLID=1, SERVLIST=1295, HLRSN=1;
   ```
2. 配置UTA业务时，如果需要调整IMSI号段某一工作模式下的其它参数，例如修改“IMSI前缀”为“46000”，“工作模式”为“UDM”，“鉴权协议类型”为“Diameter”的一条IMSI号段属性记录，将“鉴权协议类型”修改为“MAP”，进行如下配置：

   ```
   MOD IWFIMSI: IMSIPRE="46000", MODE=UDM, AUTHTYPE=MAP, SSN=149, NUMPLAN=IMSI, NODETYPE=16;
   ```
3. 配置UTA业务时，如果需要调整IMSI号段某一工作模式下的其它参数，例如修改“IMSI前缀”为“46000”，“工作模式”为“UDM”的一条IMSI号段属性记录，将“模拟MME注册消息中携带的默认PLMNID”修改为“11111”，进行如下配置：

   ```
   MOD IWFIMSI: IMSIPRE="46000", MODE=UDM, PLMNID="11111";
   ```
