# 查询号码前缀和国家码数据(LST NUMBERCCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询号码前缀和国家码数据的配置信息。

- 若需要查询系统中所有号码前缀和国家码数据的配置信息，请不要输入“号码前缀”参数。
- 若需要查询系统中某条号码前缀和国家码数据的详细配置信息，请输入“号码前缀”参数。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                 |
|:-------------|:-------|:-----------------------------------------------------|
| NUMBERPREFIX | 号码前缀   | 用于指示系统需要按照哪个号码前缀来查询号码前缀和国家码数据；若不输入，则表示所有的号码前缀和国家码数据。 |

## 使用实例

1. 查询系统中所有号码前缀和国家码数据记录：

   ```
   LST NUMBERCCODE:;
   ```

   ```
   %%LST NUMBERCCODE:;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "Number Prefix"    "Country Code"    "Description"
           1380270            86                <NULL>
           1380222            11                what

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询“号码前缀”为“1380270”的数据记录：

   ```
   LST NUMBERCCODE: NUMBERPREFIX="1380270";
   ```

   ```
   %%LST NUMBERCCODE: NUMBERPREFIX="1380270";%%
   RETCODE = 0 SUCCESS0001:操作成功

           "Number Prefix"    "Country Code"    "Description"
           1380270            86                <NULL>

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NUMBERCCODE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析               | 处理建议                                                                                         |
|:--------|:--------|:-------------------|:---------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“号码前缀”在数据库中不存在。 | 核实用户的“号码前缀”，如果确定输入无误，证明该用户不存在号码前缀和国家码的对应关系，不需要再执行该命令，否则重新输入正确的“号码前缀”，可通过LST NUMBERCCODE命令查询。 |
