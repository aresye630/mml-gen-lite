# 增加D-CSI模板(ADD DCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为HLR在配置数据库中增加一条D-CSI（Dialed Services CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约D-CSI模板ID签约D-CSI业务。

D-CSI是拨号业务CAMEL签约信息，D-CSI模板中包含D-CSI业务相关的数据。当用户位置更新时，D-CSI数据通过插入用户数据流程被插入用户当前所在的VLR。D-CSI包含用来调用CAMEL业务逻辑的触发信息，移动用户在VMSC中做主叫，或在VMSC/GMSC中做被叫发生呼叫前转时，D-CSI智能业务将被触发，按照用户签约的D-CSI模板中的信息进行业务逻辑处理。

## 注意事项

- 该命令只能给一个模板增加一条触发准则，如果需要增加多条触发准则，请执行**MOD DCSITPL**命令。
- 系统中增加的D-CSI模板记录数不能超过5000条。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:-----------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号                 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                        |
| TPLID     | 模板ID                   | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                               |
| TPLNAME   | 模板名                    | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                  |
| CAMEL     | CAMEL业务处理能力            | 用于标识gsmSCF（GSM Service Control Function）在处理该项具体CAMEL业务时所需要的CAMEL协议阶段的支持。CAMEL的发展经历了四个阶段，不同的阶段CAMEL特性的应用范围不同，可以按运营商的需要进行配置。该参数的配置应该与本命令中的“业务键”参数对应的具体CAMEL业务所要求支持的CAMEL支持能力一致。 取值范围：PHASE3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷。PHASE4：是PHASE3的增强，同时可应用于终结短消息业务（SMS MT）。 默认值：无。                                                                                                                                 |
| USHNDL    | VLR/GMSC不支持CAMEL时的处理方式 | 用于标识当VLR/GMSC不支持D-CSI所需要的CAMEL业务处理能力时的HLR替代下发的处理方式。 取值范围：CALLBAR：呼叫闭锁，与签约了ODB-BAOC（闭锁所有呼出业务）相同。RR：漫游限制。NONCAMEL：呼叫被当作非CAMEL呼叫继续处理。 默认值：无。                                                                                                                                                                                                                                                                                           |
| DIALLEDNO | 被叫号码准则                 | 用于标识D-CSI业务的触发准则，即被叫号码准则（DP3）。当用户拨打此号码为前缀的被叫号码，则会触发D-CSI智能业务。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                        |
| GSMSCFADD | SCP地址                  | 用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| SK        | 业务键                    | 用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                              |
| DEFCALL   | 缺省呼叫处理                 | 用于标识当gsmSSF与gsmSCF之间的对话出现差错或者呼叫受限于gsmSSF里的CallGap（CallGap是为了保证SCP系统不过负荷运行，需要在话务量过高时对相应的智能呼叫实施呼叫间隙控制的功能）时，缺省呼叫处理指示出对呼叫应给予释放还是继续。 取值范围：ReleaseCall：gsmSCF指示gsmSSF释放呼叫。ContinueCall：gsmSCF指示gsmSSF继续呼叫。 默认值：无。                                                                                                                                                                                                                         |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条D-CSI模板数据记录。其中，“模板ID”为“2”，“模板名”为“DCSITPL”，“CAMEL业务处理能力”为“PHASE3”，“VLR/GMSC不支持CAMEL时的处理方式”为“RR”，“被叫号码准则”为“8613758”，“SCP地址”为“8613911111”，“业务键”为11，“缺省呼叫处理”为“呼叫继续”：

```
ADD DCSITPL: HLRSN=1, TPLID=2, TPLNAME="DCSITPL", CAMEL=PHASE3, USHNDL=RR, DIALLEDNO="8613758", GSMSCFADD="8613911111", SK=11, DEFCALL=ContinueCall;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                                                                                                                         |
|:--------|:--------|:------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                            |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                             |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST DCSITPL命令查询系统中已存在的D-CSI模板。                                                       |
| ERR3047 | 超过最大限制  | 系统中增加的D-CSI模板记录数超过5000条。      | 根据实际情况，如需增加D-CSI模板，处理步骤如下：执行LST DCSITPL命令，查询已存在的D-CSI模板。执行RMV DCSITPL命令，删除不必要的D-CSI模板。执行该命令增加D-CSI模板，确保增加的D-CSI模板记录数在规定范围之内。 |
