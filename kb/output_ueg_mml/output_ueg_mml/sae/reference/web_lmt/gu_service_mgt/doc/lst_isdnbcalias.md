# 查询用户自定义承载能力(LST ISDNBCALIAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来查询指定用户的自定义承载能力。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，任何一个参数出现即可。
- RECORDCOUNT不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                     |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：可选参数 参数含义：用于标识要查询哪个“IMSI”号码对应用户的自定义承载能力。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                    |
| ISDN        | MSISDN    | 可选必选说明：可选参数 参数含义：用于标识要查询哪个“MSISDN”号码对应用户的自定义承载能力。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                  |
| RECORDCOUNT | 用户个数      | 可选必选说明：可选参数 参数含义：用于标识要查询自定义承载能力的用户数量，用于连续号段批操作。代表以指定的IMSI、MSISDN为起始号码，号码连续的“RECORDCOUNT”个用户。 取值范围：1～10000。如果只有一个用户，该参数不必提供。 默认值：无。 配置原则：无。                                                                               |
| IMSIFILE    | IMSI文件名   | 可选必选说明：可选参数 参数含义：用于标识要查询自定义承载能力用户IMSI文件名称，IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 取值范围：字符串类型，由1～16个字母或数字组成，不包含文件的绝对路径。 默认值：无。 配置原则：文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。       |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：可选参数 参数含义：用于标识要查询自定义承载能力用户MSISDN文件名称，ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：字符串类型，由1～16个字母或数字组成，不包含文件的绝对路径。 默认值：无。 配置原则：文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 |

## 使用实例

查询IMSI号码为460000009123456的用户自定义承载业务的情况。命令如下：

```
LST ISDNBCALIAS: IMSI="460000009123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                                                                                | 处理建议                                                                                                                     |
|:--------|:---------|:----------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突     | 可能原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户    | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数 “IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果输入有误，重新输入正确的IMSI号码或MSISDN号码。                                                                      |
| ERR3007 | 记录不存在    | 当前用户未设置自定义承载能力。                                                                                     | 前用户未设置自定义承载能力，请通过SET ISDNBCALIAS命令为用户设置自定义承载能力。                                                                          |
| ERR3111 | 系统不支持该特性 | 辅ISDN号码不支持配置自定义承载能力。                                                                                | 当前输入的“MSISDN”为辅ISDN，辅ISDN号码不支持配置自定义承载能力，请输入非辅ISDN的“MSISDN”。                                                              |
