# 清除APN动态数据(CLR APNDYNDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于清除用户APN动态数据，当需要清除数据库中存在的冗余APN动态数据时，可以执行此命令进行清除。

## 注意事项

- “IMSI”、“MSISDN”是可选参数，有且只能有一个参数出现。
- 执行本命令，将清除用户所有的APN动态数据。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                           |
|:-------|:-------|:-----------------------------------------------|
| IMSI   | IMSI   | 用于标识用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。   |
| ISDN   | MSISDN | 用于标识用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

1. 清除用户IMSI号码为“460011390290001”的所有的APN动态数据：

   ```
   CLR APNDYNDATA: IMSI="460011390290001";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                      |
|:--------|:--------|:-------------------------------------------------------|:--------------------------------------------------------------------------|
| ERR3001 | 用户未开户   | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。 | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明该用户已销户，不需要再执行命令，否则重新输入正确的IMSI号码或MSISDN号码。 |
