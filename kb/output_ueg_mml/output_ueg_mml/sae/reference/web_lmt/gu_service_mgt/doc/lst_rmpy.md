# 查询远端用户数据(LST RMPY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

操作员通过此命令可以查询远端用户的数据。查询内容包括：

- 功能描述
- 签约的COR角色（最多5个）
- FFNAddress
- 当前绑定的初始用户

## 注意事项

“远端号码”、“远端号码文件名”两个参数是条件可选参数，必须有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                       |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号  | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                   |
| RMNUM       | 远端号码    | 远端号码，E.164格式的编码。 当SET MAPCONF命令中“是否支持远端号码里包含字母”标志位为缺省值“FALSE”时，远端号码为1～15位的十进制数字。 当SET MAPCONF命令中是否支持远端号码中包含字母标志位为“TRUE”时，远端号码为中国GSM-R网络用户号码： 不以2开头时，为1～15位的十进制数字。以2开头时，为可以包含字母和数字的4～10位字符。 |
| RECORDCOUNT | 用户个数    | 用户的数目，最大10000个。 若只有一个远端号码，该参数不必提供。 若该参数提供，代表对以指定的远端号码为起始号码，号码连续的RECORDCOUNT个远端号码进行操作。 此参数必须与RMNUM同时出现。                                                                                     |
| FILE        | 远端号码文件名 | 远端号码文件名称，由1～16个字母或数字组成。FILE包含多个不连续的远端用户号码。                                                                                                                                                 |

## 使用实例

查询远端号码为8613900001234的远端用户数据。

```
LST RMPY: HLRSN=1, RMNUM="8613900001234";
```

```
%%LST RMPY: HLRSN=1, RMNUM="8613900001234";%%
RETCODE = 0 SUCCESS0001:操作成功

                         HLRSN = 1
                         RMNUM = 8613900001234
                      FUNCDESC = funcdesc
                       CORSET1 = COR_2
                       CORSET2 = COR_4
                       CORSET3 = COR_20
                       CORSET4 = COR_22
                    FFNADDRESS = 8613911111234

Total count = 8

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                   |
|:--------|:--------|:--------------------------|:-------------------------------------------------------|
| ERR1009 | 参数丢失    | “远端号码”、“远端号码文件名”两个参数同时缺失。 | 根据实际情况，重新输入参数，并满足“远端号码”、“远端号码文件名”两个参数必须有且只能有一个参数出现的条件。 |
