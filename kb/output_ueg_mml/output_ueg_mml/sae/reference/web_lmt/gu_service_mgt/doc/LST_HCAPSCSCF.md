# 查询S-CSCF名称(LST HCAPSCSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定Subscription或PSI用户能力集中的所有指派S-CSCF名称。

## 注意事项

SUBID参数和PISI参数必须存在且仅能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| SUBID  | SUBID  | 用于指示系统需要按照哪个Subscription ID查询所有指派S-CSCF名称。SUBID字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无   |
| PISI   | PISI   | 用于指示系统需要按照哪个PISI查询所有指派S-CSCF名称。要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询S-CSCF名称。SUBID：subinfo。

```
LST HCAPSCSCF: SUBID="subinfo";
```

## 输出结果说明

| 参数标识   | 参数说明        |
|:-------|:------------|
| SCSCF  | 显示S-CSCF名称。 |
