# 修改S4SGSN地址信息(MOD S4SGSNINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于维护用户的S4SGSN地址信息，当修改或清空了用户的S4SGSN地址信息后，在“CANCELWHENVLRORSGSNMOD”参数取值为“TRUE”时（请参见**设置MAP功能流程数据(SET MAPCONF)**），会向原S4SGSN设备下发Cancel Location消息，通知其需要同步删除原有的用户信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”及“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “RECORDCOUNT”参数不能与“IMSIFILE”或“ISDNFILE”同时存在。
- 执行该命令时，“S4SGSNHOST”、“S4SGSNREALM”、“SGSNNUM”参数为可选输入，如果都不输入则表示清空用户注册的S4SGSN地址信息。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识系统按照哪个“IMSI”号码修改或清空用户的S4SGSN地址信息。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                   |
| ISDN        | MSISDN    | 用于标识系统按照哪个“MSISDN”号码修改或清空用户的S4SGSN地址信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                  |
| RECORDCOUNT | 用户个数      | 用于标识系统需要修改或清空S4SGSN地址信息的用户个数。 当需要修改连续号码的S4SGSN地址信息时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，修改或清空连续号码的多个用户的S4SGSN地址信息。 取值范围：1～100000 默认值：无。                                                                                                                                                                                                |
| IMSIFILE    | IMSI文件名   | 用于标识系统按照哪个“IMSI文件名”修改或清空用户的S4SGSN地址信息。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“S4SGSNinfo.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                   |

| S4SGSNHOST  | S4SGSN主机名 | 用于标识对用户的S4SGSN地址信息修改后的新S4SGSN主机名称。 取值范围：1～127位由十进制数字、字母、特殊字符等组成的字符串。 默认值：无。 说明： 该参数必须满足以下配置原则：任意两个“.”不允许相邻。 任意两个“.”之间，第一个字符和最后一个字符必须为数字（0～9）或字母（a～z或A～Z）且长度小于等于63。 当SET MAPCONF命令中“是否进行主机名/域名合法性增强检查”参数取值为“TRUE”时，该参数除上述配置原则外还需满足以下配置原则：所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.” |
| S4SGSNREALM | S4SGSN域名  | 用于标识对用户的S4SGSN地址信息修改后的新S4SGSN域名名称。 取值范围：1～127位由十进制数字、字母、特殊字符等组成的字符串。 默认值：无。 说明： 该参数必须满足以下配置原则：任意两个“.”不允许相邻。 任意两个“.”之间，第一个字符和最后一个字符必须为数字（0～9）或字母（a～z或A～Z）且长度小于等于63。 当SET MAPCONF命令中“是否进行主机名/域名合法性增强检查”参数取值为“TRUE”时，该参数除上述配置原则外还需满足以下配置原则：所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.” |
| SGSNNUM     | SGSN号码    | 用于标识对用户的S4SGSN号码信息修改后的新S4SGSN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                         |

## 使用实例

1. 修改“IMSI”号码为“1500000”的用户S4SGSN地址信息，“新S4SGSN主机名”为“S4SGSN1.abc.com”：

   ```
   MOD S4SGSNINFO: IMSI="1500000", S4SGSNHOST="S4SGSN1.abc.com";
   ```
2. 清空“IMSI”号码为“1500000”的用户的S4SGSN地址信息：

   ```
   MOD S4SGSNINFO: IMSI="1500000";
   ```
