# 查询全局存储密钥(LST GK2**)**

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询全局存储密钥功能。

## 注意事项

无。

## 参数说明

无。

## 使用实例

执行命令系统中的全局存储密钥记录，系统已生成随机密钥，且密钥材料完整时返回：

```
LST GK2:;
```

```
+++    USCDB        2024-09-25 19:39:23
PGW    #009553
%%LST GK2:;%% 
RETCODE = 0 SUCCESS0001:Operation is successful 
  
GK2SNO      KEYID
1           3001
2           1
3           2 

Total count = 3 
  
There is together 1 report 
  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET GK2**命令的参数说明。
