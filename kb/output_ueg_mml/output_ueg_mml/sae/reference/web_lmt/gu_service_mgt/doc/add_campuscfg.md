# 增加园区配置(ADD CAMPUSCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在大网UDM中增加一条园区配置数据记录。

该命令的使用场景：

- 该命令与**ADD CAMPUSDATAFILTER**命令配合使用。当使用本命令增加园区配置时，会调用**ADD CAMPUSDATAFILTER**命令配置的过滤条件。
- 当大网UDM与园区UDM间由于传输网络故障和大网UDM失联时，为保证园区UDM上有对应的用户数据可供应急故障使用，使业务能够接续不中断，会根据过滤条件筛选用户数据，并把大网UDM的“K4序列号”和“OP序列号”替换成本命令配置的园区UDM的“K4序列号”和“OP序列号”之后，再导出用户数据。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 系统中增加的园区配置数据记录数不能超过350条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                 |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CAMPUSNAME  | 园区名称     | 可选必选说明：必选参数 参数含义：用于表示园区的名称。 取值范围：长度不超过16位的字符串，只允许输入数字、字母和下划线。 默认值：无。 配置原则：“园区名称”区分大小写字母。                                                                                                                                             |
| FILTERNAME  | 过滤条件名称   | 可选必选说明：必选参数 参数含义：用于标识一条园区配置数据记录的过滤条件名称。该参数必须由ADD CAMPUSDATAFILTER命令定义后才能在此处引用。 取值范围：长度不超过64位的字符串，只允许输入数字和字母。 默认值：无。 配置原则：无。                                                                                                          |
| K4SNO       | K4序列号    | 可选必选说明：必选参数 参数含义：用于标识园区的K4序列号。 取值范围：0～65535 默认值：无。 配置原则：无。                                                                                                                                                                           |
| OPSNO       | OP序列号    | 可选必选说明：可选参数 参数含义：用于标识园区的OP序列号。 取值范围：1～16777215 默认值：无。 配置原则：无。                                                                                                                                                                        |
| EXPDATATYPE | 园区导出数据类型 | 可选必选说明：可选参数 参数含义：用于标识园区导出的用户数据类型。 取值范围： 全部选中全部清空5G：导出5G签约数据4G：导出4G签约数据，包括NSA和NB-IoTIMS：导出IMS签约数据 默认值：5G。 配置原则：当该参数取值包含“4G”时，仅当SET MAPSERV命令“GPRS管理方式”参数取值为“SuppPsEpsSeparateTplManager”或“SuppGprsManageOptimizeon”时系统支持园区用户4G签约数据导出。 |
| FEATURETYPE | 特性数据类型   | 可选必选说明：条件可选参数 参数含义：用于标识园区导出的用户特性数据类型。 取值范围： 全部选中全部清空REDCAP：RedCap特性相关字段，仅当本命令中“园区导出数据类型”参数取值包含“5G”时，允许配置该枚举值，否则系统会报错。 默认值：无。 配置原则：无。                                                                                                 |

## 使用实例

当前大网UDM对接管理2个园区UDM的用户数据，需要增加2条园区配置数据记录。

- 园区1：“园区名称”为“campus1”，“过滤条件名称”为“filter1”，“K4序列号”为“1”，“OP序列号”为“1”：

  ```
  ADD CAMPUSCFG: CAMPUSNAME="campus1", FILTERNAME="filter1", K4SNO=1, OPSNO=1;
  ```
- 园区2：“园区名称”为“campus2”，“过滤条件名称”为“filter2”，“K4序列号”为“2”，“OP序列号”为“2”：

  ```
  ADD CAMPUSCFG: CAMPUSNAME="campus2", FILTERNAME="filter2", K4SNO=2, OPSNO=2;
  ```
