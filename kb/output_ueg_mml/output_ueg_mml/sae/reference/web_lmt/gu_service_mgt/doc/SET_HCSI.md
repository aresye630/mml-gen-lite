# 设置用户CAMEL签约数据(SET HCSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMSI的CAMEL(Customized Applications for Mobile network Enhanced Logic)签约数据。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                        |
|:---------|:--------------|:------------------------------------------------------------------------------------------------------------|
| IMSI     | IMSI          | 用于指定一个需要设置CAMEL签约数据的IMSI。由不超过15位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围：6–15 缺省值：无                 |
| ISDN     | MSISDN        | 用于指定一个需要设置CAMEL签约数据的IMSI关联的MSISDN。由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围：长度不超过15的字符串 缺省值：无 |
| CSITYPE  | CAMEL签约数据类型   | 用于CAMEL签约数据的类型，枚举值为O-CSI表示O-CSI类型，枚举值为T-CSI表示T-CSI类型。 取值范围： O-CSI(O-CSI)T-CSI(T-CSI) 缺省值：无                  |
| CSITPLID | CAMEL签约数据模板ID | 用于为IMSI关联一个CAMEL签约数据模板ID。0～254表示给用户提供对应的CSI模板数据； 255表示取消用户的模板数据。 取值范围：0～255 缺省值：无                           |

## 使用实例

设置用户CAMEL签约数据。IMSI：125353，MSISDN：86137565425，CAMEL签约数据类型：O-CSI，CAMEL签约数据模板ID：10。

```
SET HCSI: IMSI="125353", ISDN="86137565425", CSITYPE=O-CSI, CSITPLID=10;
```
