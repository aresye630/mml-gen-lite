# 以格式1查询用户GPRS优化选项(LST EGPRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于查询用户GPRS参数信息，以指定的格式返回查询结果。

使用场景限于运营商对返回报文有特殊适配需求。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                   |
|:-------|:-------|:-------------------------------------------------------|
| IMSI   | IMSI   | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。 说明：可选参数。   |
| ISDN   | MSISDN | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。 说明：可选参数。 |

## 使用实例

查询用户GPRS数据信息，以指定的数据格式返回。命令如下：

```
LST EGPRS: IMSI="460000009123456";
```
