# 增加5G业务下发模板(ADD NGCRSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加5G业务下发模板数据记录。

UDM向对端下发业务数据时，首先根据5G业务下发模板和5G业务限制模板管理对用户需要下发的DNN进行控制，实现按照不同预期下发不同的DNN。

## 注意事项

所有“HLR序列号”中增加的5G业务下发模板记录数不能超过3000条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TPLID       | 模板ID     | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| TPLNAME     | 模板名      | 可选必选说明：可选参数 参数含义：用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SERCODE     | 下发业务列表   | 可选必选说明：必选参数 参数含义：用于标识当用户漫游到特定的5G区域后，对哪些业务进行下发。 取值范围：SMDATA：SMF数据SXZW：DNN/APN替换业务 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SMDATATPLID | 会话信息模板ID | 可选必选说明：条件必选参数 参数含义：用于标识会话信息模板ID。该参数必须先由ADD SMDATATPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无。 配置原则：仅当本命令中的“下发业务列表”参数为“SMDATA”时该参数有效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| RESTSUBDNN  | 限制DNN子串  | 可选必选说明：可选参数 参数含义：用于标识业务下发时，当用户签约的DNN中存在该参数配置的DNN子串，则不下发用户签约的DNN。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无。 配置原则：仅当本命令中的“下发业务列表”参数为“SMDATA”时该参数有效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| OLDDNNLIST  | 旧DNN名称列表 | 可选必选说明：条件必选参数 参数含义：用于标识旧DNN名称列表。 取值范围：1～4000个字符组成的字符串。 默认值：无。 配置原则： 仅当本命令中的“下发业务列表”参数为“SXZW”时该参数有效。该参数由1个或多个DNN组成。每个DNN格式为1～64位的字符串，只允许输入字母、数字、“%”、“-”、“_”、“.”和“*”。单个DNN不允许仅配置“%”或“*”。如果只有一个DNN，参数不允许出现“"”或 “&”，例如：Mnet.com。如果存在多个DNN时，每个DNN需要使用“""”标识，DNN之间使用 “&”进行连接，在字符“"”前需要添加转义字符“\”，例如：\"Mnet.com\"&\"Cnet.com\"。如果存在多个DNN时，多个DNN不能重复。DNN数量必须与“新DNN名称列表”中的DNN数量保持一致。DNN不允许配置为通配DNN。该参数与“新DNN名称列表”参数中不能存在重复的DNN。如果DNN以“%”结尾，表示该DNN为模糊匹配DNN，即用户签约的DNN包含该DNN即替换，允许配置多个模糊匹配DNN。如果DNN配置为“default*”（字母区分大小写），表示该DNN为替换用户签约默认DNN，仅允许配置一个。匹配时“default*”、模糊匹配DNN、完整DNN的处理优先级如下：同一个DNN仅替换一次，不支持多条规则多次连续替换。“default*”优先级最高。如果完整DNN和模糊匹配都可以匹配同一个DNN，完整DNN优先级最高。如果多个模糊匹配都匹配同一个DNN，则按照旧DNN在当前参数中配置的先后顺序，在先的匹配成功后，在后的不再匹配。 |
| NEWDNNLIST  | 新DNN名称列表 | 可选必选说明：条件必选参数 参数含义：用于标识新DNN名称列表。 取值范围：1～4000个字符组成的字符串。 默认值：无。 配置原则： 仅当本命令中的“下发业务列表”参数为“SXZW”时该参数有效。该参数由1个或多个DNN组成。每个DNN格式为1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。如果只有一个DNN，参数不允许出现“"”或 “&”，例如：Mnet.com。如果存在多个DNN时，每个DNN需要使用“"”标识，DNN之间使用 “&”进行连接，在字符“"”前需要添加转义字符“\”，例如：\"Mnet.com\"&\"Cnet.com\"。如果存在多个DNN时，多个DNN可以重复。DNN数量必须与“旧DNN名称列表”中的DNN数量保持一致。DNN不允许配置为通配DNN。                                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

增加一个5G业务下发模板。“HLR序列号”为“1”，“模板ID”为“8”，“下发业务列表”为“SMDATA”，“会话信息模板ID”为“2”，“限制DNN子串”为“12543”。

```
ADD NGCRSITPL: HLRSN=1, TPLID=8, SERCODE=SMDATA, SMDATATPLID=2, RESTSUBDNN="12543";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                     | 处理建议                                                                                                                                     |
|:--------|:--------|:-------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。     | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                         |
| ERR3004 | 模板已存在   | “模板ID”在数据库中已存在。          | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST NGCRSITPL命令查询系统中已存在的5G业务下发模板。                                                                |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。             | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                           |
| ERR3047 | 超过最大限制  | 增加的5G业务下发数据模板记录数超过3000条。 | 根据实际情况，如需增加5G业务下发模板，处理步骤如下： 执行LST NGCRSITPL命令，查询已存在的5G业务下发模板。 执行RMV NGCRSITPL命令，删除不必要的5G业务下发模板。 执行该命令增加5G业务下发模板，确保增加的5G业务下发模板记录数在规定范围之内。 |
