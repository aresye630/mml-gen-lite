# 查询IMS用户割接策略配置(LST IMSMIGPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中查询IMS用户割接策略配置信息：

- 若需要查询单个IMS用户的割接策略配置信息，请输入参数“IMSI”、“MSISDN”、“IMPI”或“IMPU”。
- 若需要查询不连续的多个IMS用户的动态数据，请输入参数“IMSI文件名”、“MSISDN文件名”、“IMPI文件名”或“IMPU文件名”。

## 注意事项

“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“IMPI”、“IMPU”、“IMPI文件名”、“IMPU文件名”八个参数是可选参数，必须有且只能有一个参数出现。

## 使用实例

1. 查询“IMSI”号码为“460000009123456”的IMS用户的割接策略配置信息：

   ```
   LST MIGPOLICY: IMSI="460000009123456";
   ```

   ```
   %%LST MIGPOLICY: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 8613900001234
                     MIG_POLICYID = 0

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询第一个“MSISDN文件名”号码为“migpolicy.txt”的IMS用户的所有动态数据：

   ```
   LST MIGPOLICY: ISDNFILE="migpolicy.txt";
   ```

   ```
   %%LST MIGPOLICY: ISDNFILE="migpolicy.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID: 268435466. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
