# 修改T-CSI数据模板(MOD HTCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中修改一条T-CSI(Terminating CAMEL Subscription Information)模板数据记录。该数据记录用T-CSI数据模板ID来唯一标识，可以通过LST HTCSITPL操作查询获得一条数据记录的详细信息。可以修改除模板ID的所有参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                   |
|:-----------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID      | T-CSI模板ID | 可选必选说明：必选参数 参数含义：标识一条T-CSI数据模板的关键字段，用于指定需要修改哪一条T-CSI数据模板。可以通过LST HTCSITPL查询获得一条T-CSI数据模板的详细信息。 取值范围： 0～254 默认值： 无                                                                                      |
| TPLNAME    | T-CSI模板名称 | 可选必选说明：可选参数 参数含义：用于为一个T-CSI数据模板指定一个新的名称。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无                                                                                                             |
| GSMSCFADDR | gsmSCF地址  | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中定义一个新的gsmSCF地址。gsmSCF地址用于路由寻址，采用E.164格式。不同的gsmSCF地址可以与不同的TDPs（Trigger Detection Point）相关。 取值范围： 长度不超过15的字符串 默认值： 无                                                       |
| SK         | 业务键       | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中定义一个新的业务键。业务键即用户标识智能业务的编码。 取值范围： 0～2147483647 默认值： 无                                                                                                                     |
| DEFCALL    | 缺省呼叫处理    | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中定义缺省呼叫处理类型。当gsmSSF与gsmSCF之间的对话出现差错或者呼叫受限时，缺省呼叫处理指示出对呼叫应给予释放还是继续。 取值范围： CONTINUECALL(CONTINUECALL)：gsmSCF指示gsmSSF继续呼叫。RELEASECALL(RELEASECALL)：gsmSCF指示gsmSSF释放呼叫。 默认值： 无 |
| IMSSF      | IM-SSF地址  | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中定义一个新的IM-SSF地址。IM-SSF地址是为用户服务实现预付费的网元地址，用于对预付费网元进行路由寻址，IM-SSF地址采用E.164格式。 取值范围： 长度不超过15的字符串 默认值： 无                                                                       |
| COMMENT    | 模板注释说明    | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中重新设置对T-CSI模板的注释说明。 取值范围： 长度不超过512的字符串 默认值： 无                                                                                                                             |

## 使用实例

修改T-CSI数据模板。T-CSI模板ID：10，gsmSCF地址：8613922222。

```
MOD HTCSITPL: TPLID=10, GSMSCFADDR="8613922222";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                                                           | 处理建议                                                                                                             |
|----------:|:--------|:-----------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------|
| 900001008 | 参数不足    | 可能原因为如下之一： 参数“T-CSI模板ID”没有输入。“T-CSI模板名称”、“gsmSCF地址”、“业务键”、“缺省呼叫处理”、“IM-SSF地址”、“模板注释说明”参数都没有输入。 | 根据实际情况，重新输入参数，确保满足以下两点： 参数“T-CSI模板ID”必须输入。“T-CSI模板名称”、“gsmSCF地址”、“业务键”、“缺省呼叫处理”、“IM-SSF地址”、“模板注释说明”参数必须至少设置其中一个。 |
