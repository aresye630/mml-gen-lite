# 查询Early AKA鉴权模式(LST HEAA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于从HSS的业务数据库中查询指定IMPI对应的IMSI和Early AKA鉴权信息，需要输入唯一标识该数据记录的关键参数IMPI。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询Early AKA数据。该参数的配置原则是要求输入的IMPI值符合NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询Early AKA鉴权模式。IMPI：impiinfo。

```
LST HEAA: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识   | 参数说明                           |
|:-------|:-------------------------------|
| IMPI   | 显示用于查询Early AKA鉴权模式的IMPI。      |
| IMSI   | 显示支持Early AKA鉴权模式的IMPI对应的IMSI。 |
