# 查询QoS模板替代配置(LST REPQOSID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中查询一条或多条QoS模板替代配置记录：

- 若需要查询一条指定的QoS模板替代配置记录，请输入参数“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”。
- 若需要查询指定虚拟HLR下指定用户QoS模板ID对应的全部QoS模板替代配置记录，请输入参数“HLR序列号”和“用户签约的QoS模板ID”，参数“SGSN号码或号码前缀”不输入。
- 若需要查询指定虚拟HLR下的全部QoS模板替代配置记录，请只输入参数“HLR序列号”，参数“用户签约的QoS模板ID”和“SGSN号码或号码前缀”不输入。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                               |
|:-----------|:-------------|:-----------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于指示系统按照哪个HLR序列号来查询QoS模板替代配置。                                                      |
| USRQOSID   | 用户签约的QoS模板ID | 用于指示系统需要按照哪个用户签约的QoS模板ID来查询QoS模板替代配置；若不输入，则表示查询某个虚拟HLR下的全部QoS模板替代配置。               |
| SGSNPREFIX | SGSN号码或号码前缀  | 用于指示系统需要按照哪个SGSN号码或号码前缀来查询QoS模板替代配置；若不输入，则表示查询某个虚拟HLR下某个用户QoS模板ID对应的全部QoS模板替代配置记录。 |

## 使用实例

1. 查询“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”，“SGSN号码或号码前缀”为“860001”的一条QoS模板替换配置记录：

   ```
   LST REPQOSID: HLRSN=1, USRQOSID=1, SGSNPREFIX="860001";
   ```

   ```
   %%LST REPQOSID: HLRSN=1, USRQOSID=1, SGSNPREFIX="860001";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

           "QoS template ID"  "SGSN Number Prefix"  "Replaced QoS template ID"
           1                  860001                300

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”所对应的所有QoS模板替换配置记录：

   ```
   LST REPQOSID: HLRSN=1, USRQOSID=1;
   ```

   ```
   %%LST REPQOSID: HLRSN=1, USRQOSID=1;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

           "QoS template ID"  "SGSN Number Prefix"  "Replaced QoS template ID"
           1                  860001                300
           1                  860002                300

   Total count = 2

   There is together 1 report

   ---    END
   ```
3. 查询“HLR序列号”为“1”的虚拟HLR之下的所有QoS模板替换配置记录：

   ```
   LST REPQOSID: HLRSN=1;
   ```

   ```
   %%LST REPQOSID: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

           "QoS template ID"  "SGSN Number Prefix"  "Replaced QoS template ID"
           1                  860001                300
           1                  860002                300
           2                  860001                300

   Total count = 3

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                                          | 处理建议                                                                                                                                                                                                                                                                                                                                                  |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“SGSN号码或号码前缀”的取值不是1～15位十进制数字组成的字符串。                                                                                                                                         | 根据实际情况，重新输入参数“SGSN号码或号码前缀”的取值，确保其取值符合要求。                                                                                                                                                                                                                                                                                                              |
| ERR1009 | 参数丢失    | 输入了参数“SGSN号码或号码前缀”，但未输入参数“用户签约的QoS模板ID”。                                                                                                                                      | 根据实际情况，重新输入参数，确保“用户签约的QoS模板ID”和“SGSN号码或号码前缀”同时输入。                                                                                                                                                                                                                                                                                                     |
| ERR3007 | 记录不存在   | 可能原因为如下之一：输入的“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”的组合对应的QoS模板替换配置记录未预先定义。输入的“HLR序列号”和“用户签约的QoS模板ID”之下不存在任何QoS模板替换配置记录。输入的“HLR序列号”对应的虚拟HLR未预先定义。输入的“HLR序列号”之下不存在任何QoS模板替换配置记录。 | 根据实际情况，重新输入参数，确保对应的记录在数据库中存在：若输入了“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”，请只输入“HLR序列号”和“用户签约的QoS模板ID”，重新执行LST REPQOSID命令，确保待查询的记录在数据库中存在。若只输入了“HLR序列号”和“用户签约的QoS模板ID”，请只输入“HLR序列号”，重新执行LST REPQOSID命令，确保待查询的记录在数据库中存在。若只输入了“HLR序列号”，请使用LST HLRSN命令，判断对应的虚拟HLR是否已定义：是，说明虚拟HLR之下不存在任何QoS模板替换配置记录。否，虚拟HLR未定义，请输入正确的“HLR序列号”，或者使用ADD HLRSN命令，增加对应的虚拟HLR配置信息。 |
