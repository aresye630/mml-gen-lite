## 命令功能

**须知** 

该操作会修改开户模板数据，是否继续？

设置开户模板主要用于开户时使用模板定义的各种业务参数减少用户操作的复杂性。同时，设置开户模板可以将大量的工作放在开户前进行。

## 注意事项

- 如果签约MPTY业务，必须签约HOLD业务。
- 如果签约闭锁业务BAOC、BOIC、BOICEXHC、BAIC、BICROAM的任意一种，则必须设置CBCOU参数。
- 如果CFU=TRUE，参数CFUNCS、CFUCOU为必选参数，CFUOFAID为可选参数。
- 如果CFB=TRUE，参数CFBNCS、CFBNFS和CFBCOU为必选参数，CFBOFAID为可选参数。
- 如果CFNRY=TRUE，参数CFNRYNCS、CFNRYCOU和CFNRYTIME为必选参数，CFNRYOFAID为可选参数。
- 如果CFNRC=TRUE，参数CFNRCNCS和CFNRCCOU为必选参数，CFNRCOFAID为可选参数。
- 如果CFD=TRUE，参数CFDNFS、CFDNCS和CFDFTN为必选参数，CFDBSG和CFDNRTIME为可选参数，如果CFD=FALSE，参数CFDNFS、CFDNCS、CFDFTN、CFDBSG和CFDNRTIME不必出现。
- 如果CLIP=TRUE，参数CLIPOR为必选参数。
- 如果CLIR=TRUE，参数CLIRMODE为必选参数。
- 如果COLP=TRUE，参数COLPOR为必选参数。
- 如果CNAP=TRUE，参数CNAPOR为必选参数。
- 如果IST=TRUE，参数ISTTIMER和ISTRSP为必选参数。
- 如果PROVOPTGPRS=TRUE，参数OPTGPRSTPLID为必选参数，CHARGE\_GLOBAL为可选参数。
- 如果输入CHARGE\_GLOBAL或SCHARGE\_GLOBAL，则GPRSTPLID不允许输入。
- 如果通过“优化GPRS模板ID”给用户签约GPRS业务，则必须在命令**SET MAPSERV**中设置“GPRS管理方式”参数为“NotSupportGPRSManager”、“SupportGPRSManager”或“SuppGprsManageOptimizeon”。“GPRS管理方式”开局设定之后不能修改，如非开局场景，请勿修改此参数配置。
- 如果通过PSUSERTPLID/EPSUSERTPLID给用户签约PS/EPS业务，则必须在命令**SET MAPSERV**中设置“GPRS管理方式”为“SuppPsEpsSeparateTplManager”或在命令**SET MAPCONF**中设置“是否支持GPRS调整方式管理过渡”为“TRUE”。“GPRS管理方式”开局设定之后不能修改，如非开局场景，请勿修改此参数配置。
- 当NAEA\_PROV=TRUE时，需要提供NAEA\_CIC值；否则，表示不签约NAEA业务。
- 当未指定新值，则系统默认使用原来的值。
- 当PGW为简单模式时，不需要设置参数HLRSN，HLRSN仅在完整模式中设置。
- 如果对用户提供或修改ODB-POS，则ODBPOS和ODBPOSTYPE两个参数为必选参数。
- 如果签约ACR业务，必须签约CLIP业务。
- 如果NIRPROV=TRUE，参数NIRINDEX为必选参数。
- 如果PROVECATEGORY=TRUE，参数ECATEGORY和ECATOPTION至少出现一个，并且如果输入的ECATOPTION为有效值，则命令中或者原有模板中一定有ECATEGORY的有效值；如果PROVECATEGORY=FALSE，参数ECATEGORY和ECATOPTION不能出现。
- 如果NON3GPPSUPP=TRUE，模板必须包含EPS签约数据。
- 此模板被修改后，已经签约此模板的用户，数据不会被同步修改；后续再签约此模板的用户将使用修改后的模板数据。
- 如果“用户模板类型”为“CSPSTPL”时，那么“EPS业务标识”不出现，不可设置。
- 如果“是否提供EPSUSERTPL”和“是否提供PSUSERTPL”出现时， 那么“PS用户模板ID”和“EPS用户模板ID”为必选参数。
- 如果“用户模板类型”为“CSPSTPL”时，那么“网络接入模式”不能为“NONE”。
- 如果“用户模板类型”为“CSPSTPL”时，那么“EPSUSERTPL模板ID”不出现，不可设置。
- 如果输入“PSUSERTPL模板ID”，则“GPRS模板ID”和“优化GPRS模板ID”不允许输入。
- 如果输入“EPSUSERTPL模板ID”，则“GPRS模板ID”和“优化GPRS模板ID”不允许输入。
- 如果“EPSUSERTPL模板ID”出现，并且“EPS业务标识”不出现时，衍生出“EPS业务标识”为“TRUE”。
- 如果“EPS业务标识”参数为“TRUE”，是第一次签约EPS业务并且“EPSUSERTPL模板ID”参数没有出现时。

  - “UE最大上行带宽”和“NR上行速率”两个参数必须且只能配置一个。
  - “UE最大下行带宽”和“NR下行速率”两个参数必须且只能配置一个。
- 如果“EPS业务标识”为“TRUE”，并且“EPSUSERTPL模板ID”出现时，“UE最大下行带宽”和“UE最大上行带宽”、“NR上行速率”和“NR下行速率”不出现，不可设置。
- “周期RA/TA更新时间间隔”和“周期RAU/TAU更新时间间隔”两个参数不能同时签约，如果用户先签约了其中一个参数，再签约另一个参数时会强制修改第一个签约的参数值为“0”。
- 当“5GS用户数据模板”和“全局计费特性”同时存在，或者“5GS用户数据模板”和“标准全局计费特性”同时存在时，如果“5GS用户数据模板”中定义了“用户计费签约数据”参数，计费签约数据以“5GS用户数据模板”中的为准，否则，以“全局计费特性”或“标准全局计费特性”参数值为准。
- 当用户签约的“5GS用户数据模板”模板数据发生修改时，如果模板新增或修改了“用户计费签约数据”参数，计费签约数据以修改后的“5GS用户数据模板”中的为准。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。
- 执行本命令修改“CFD前转号码”时，系统默认在修改后的“CFD前转号码”前补充“91”前缀。例如：输入“123456”，执行**LST SUBTPL**命令时，查询结果中“CFD前转号码”显示为“91123456”。

## 使用实例

1. 修改“模板ID”为“2”的开户模板信息。其中“用户模板类型”为“NORMAL”，“卡类型”为“USIM卡”：

   ```
   MOD SUBTPL: HLRSN=1, TPLID=2, TPLTYPE=NORMAL, CARDTYPE=USIM;
   ```
2. 修改“模板ID”为“200”，“用户模板类型”为“NORMAL”的开户模板信息。其中“UE最大上行带宽”为“1500000 bit/s”，“UE最大下行带宽”为“3000000 bit/s”，“无线频率选择优先级”为“3级”，“PLMN漫游限制模板ID”为“101”：

   ```
   MOD SUBTPL: HLRSN=1, TPLID=200, TPLTYPE=NORMAL, CARDTYPE=USIM, NAM=BOTH, AMBRMAXUL=1500000, AMBRMAXDL=3000000, RATFREQSELPRIID=3, PLMNTPLID=101;
   ```
