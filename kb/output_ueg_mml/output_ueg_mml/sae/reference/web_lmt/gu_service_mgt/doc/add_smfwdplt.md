# 增加短消息转发平台地址(ADD SMFWDPLT)

- 参数说明

- 输出结果说明

## 命令功能

该命令用于增加SMS Forwarding业务的短消息转发平台地址信息。

当**SET MAPSERV**命令的“SMSCF\_MODE”参数设置为“MODE3”时，如果通过**ACT SMSCF**命令为终端用户激活了短消息前转业务，在以下情况，认为激活了SMS Forwarding业务：

- **ACT SMSCF**命令未携带前转号码时。此情况下采用默认短消息转发平台地址，即本命令“是否默认地址”参数为“TRUE”的“短消息转发平台地址”。
- **ACT SMSCF**命令携带的前转号码和本命令配置的某“短消息转发平台地址”完全匹配时。此时不需要检查短消息前转业务和ODB/CB业务冲突关系。

SMS Forwarding业务流程中，UDM处理SRI-for-SM消息时，直接通过响应消息返回本命令配置的短消息转发平台地址。

## 注意事项

- 系统中只能存在一个默认短消息转发平台地址，即“是否默认地址”为“TRUE”的短消息转发平台地址。
- 系统中增加的短消息转发平台地址记录数不能超过1000条。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                        |
|:------------|:----------|:--------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号    | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                |
| SMFWDPLAT   | 短消息转发平台地址 | 用于标识需要配置的短消息转发平台地址。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                           |
| ISDEFAULT   | 是否默认地址    | 用于标识“短消息转发平台地址”是否是默认地址，即ACT SMSCF命令未携带前转号码时采用的短消息转发平台地址。 取值范围：TRUE：是默认地址FALSE：不是默认地址 默认值：无。 |
| FWDPLATNAME | 短消息转发平台名称 | 为便于识别，为短消息转发平台指定的名称。 取值范围：长度不超过60的字符串。 说明：可选参数。                                             |

## 使用实例

增加一条短消息转发平台地址信息，设置“HLR序列号”为“1”，“短消息转发平台地址”为“1234567891”，“是否默认地址”为“TRUE”，“短消息转发平台名称”为“default”：

```
ADD SMFWDPLT: HLRSN=1, SMFWDPLAT="1234567891", ISDEFAULT=TRUE, FWDPLATNAME="default";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                                                                                                     |
|:--------|:--------|:--------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 增加的“短消息转发平台地址”记录数超过1000条。 | 根据实际情况，如需增加短消息转发平台地址，处理步骤如下：执行LST SMFWDPLT命令，查询已存在的短消息转发平台地址。执行RMV SMFWDPLT命令，删除不必要的短消息转发平台地址。执行该命令增加短消息转发平台地址，确保增加的短消息转发平台地址记录数在规定范围之内。 |
