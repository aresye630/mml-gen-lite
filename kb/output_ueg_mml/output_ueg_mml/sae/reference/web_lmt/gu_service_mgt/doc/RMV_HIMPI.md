# 删除IMPI(RMV HIMPI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一条指定的IMPI记录。

## 注意事项

执行命令前，需要确保对应的IMPI关联的IMSI没有被同一SUBID下的其他EAA用户关联。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 标识一条IMPI和SUBID关联关系记录的关键参数，用于指定需要删除哪一个IMPI和SUBID之间的关联关系，操作员可以使用LST HSUB操作查询获得，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

删除IMPI。IMPI：impiinfo。

```
RMV HIMPI: IMPI="impiinfo";
```
