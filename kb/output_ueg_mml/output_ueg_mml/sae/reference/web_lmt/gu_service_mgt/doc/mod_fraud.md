# 修改防欺诈业务(MOD FRAUD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来签约或去签约防欺诈业务。

## 注意事项

- “IMSI”和“ISDN”是条件可选参数，任何一个参数出现即可，但两个参数不能同时出现。
- “RECORDCOUNT”一定不能与“IMSIFILE”或“ISDNFILE”同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                         |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数。                                                                                   |
| ISDN        | MSISDN    | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数。                                                                                 |
| RECORDCOUNT | 用户个数      | 此参数用于设置用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                   |
| IMSIFILE    | IMSI文件名   | 此参数用于设置IMSI文件名称。IMSIFILE的内容是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 取值范围：1～16个字母或数字组成。                                            |
| ISDNFILE    | MSISDN文件名 | 此参数用于设置ISDN文件名称。ISDNFILE的内容是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：1～16个字母或数字组成。                                        |
| PROV        | 是否提供防欺诈业务 | 此参数用于设置是否提供防欺诈业务。 取值范围： TRUE：提供FALSE：不提供 说明：必选参数。                                                                            |
| TPLID       | 模板ID      | 仅当本命令中的"是否提供防欺诈业务"参数为"TRUE"时该参数有效，此参数用于设置防欺诈模板ID。 该参数必须由命令ADD FRAUDTPL定义，然后才能在此处引用。可使用命令LST FRAUDTPL查询防欺诈模板信息。 取值范围：0～65534。 |

## 使用实例

1. 为IMSI号码是460000009123456的用户提供防欺诈业务，采用模板ID为2的防欺诈模板。

   MOD FRAUD: IMSI="460000009123456", PROV=TRUE, TPLID=2;
2. 为IMSI号码是460000009123456的用户撤销防欺诈业务。

   MOD FRAUD: IMSI="460000009123456", PROV=FALSE;
