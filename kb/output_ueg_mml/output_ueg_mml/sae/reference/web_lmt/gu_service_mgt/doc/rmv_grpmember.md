# 删除智家随行家庭网关(RMV GRPMEMBER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条智家随行家庭网关数据记录。

## 注意事项

“智家随行家庭网关IMSI号码”和“智家随行家庭网关MSISDN号码”必须有且只能有一个参数出现。

## 参数说明

| 参数标识    | 参数名称             | 参数说明                                                                                                  |
|:--------|:-----------------|:------------------------------------------------------------------------------------------------------|
| IMSI    | 智家随行家庭网关IMSI号码   | 可选必选说明：条件可选参数 参数含义： 用于标识需要删除哪个IMSI号码的智家随行家庭网关数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                |
| ISDN    | 智家随行家庭网关MSISDN号码 | 可选必选说明：条件可选参数 参数含义：用于标识需要删除哪个MSISDN号码的智家随行家庭网关数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。               |
| GRPNAME | 智家随行家庭网关名称       | 可选必选说明：必选参数 参数含义：用于标识智家随行家庭网关名称。 取值范围：1～60位字符串，字符串由数字、字母、“.”、“-”或“_”组成。该参数输入的字母不区分大小写。 默认值：无。 配置原则：无。 |

## 使用实例

执行该命令删除“智家随行家庭网关IMSI号码”为“460030913121001”的用户的一条智家随行家庭网关数据记录，“智家随行家庭网关名称”为“home1”：

```
RMV GRPMEMBER: IMSI="460030913121001",GRPNAME="home1";
```
