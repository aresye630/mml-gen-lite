# 修改NGS对端类型（MOD NGSPETYPE）

- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响用户的漫游业务，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于修改UDM中的对端业务属性。在该命令中，系统通过以下关键参数的组合来唯一标识一条对端类型数据记录：

- “HLR序列号”
- “AMF身份类型”
- “PLMNID”
- “AMF Region ID”
- “AMF Set ID”

## 注意事项

无。

## 参数说明

| PETYPE     | AMF身份类型         | 可选必选说明：必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要对哪一个AMF、SMF或SMSF网元类型对应的NGS对端类型数据记录的参数进行修改，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围： PLMNAMFREGIONAMFSET 默认值：无 配置原则：无                                                                                                                                                                                                     |

| AMFREGION  | AMF Region ID   | 可选必选说明：条件必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要对哪一个AMF Region ID对应的NGS对端类型数据记录的参数进行修改，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围：0～255 默认值：无 配置原则：仅当本命令中的“AMF身份类型”参数为“AMFREGION”或“AMFSET”时该参数有效。                                                                                                                                                                        |

| PEERNAME   | 对端名称            | 可选必选说明：可选参数 参数含义：用于标识修改后的对端名称。 取值范围：长度不超过30的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                  |

## 使用实例

当对端AMF相对于UDM的业务属性发生变化或需要调整时，需要修改AMF业务属性。配置举例如下：

1. 在“HLR序列号”为“3”的UDM上，修改对端相对于本UDM的业务属性。其中“AMF身份类型”为“PLMN”，“PLMNID”为“111111”，“业务属性”为“LOCAL”：

   ```
   MOD NGSPETYPE: HLRSN=3, PETYPE=PLMN, PLMN="111111", TYPE=LOCAL;
   ```
2. 在“HLR序列号”为“1”的UDM上，修改对端相对于本UDM的业务属性。其中“AMF身份类型”为“AMFREGION”，“PLMNID”为“111111”，“业务属性”为“CROSSDOMESTIC”，“AMF Region ID”为“2”：

   ```
   MOD NGSPETYPE: HLRSN=1, PETYPE=AMFREGION, PLMN="11111", AMFREGION=2, TYPE=CROSSDOMESTIC;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数缺失    | 原因为如下之一： 必选参数缺失：“HLR序列号”、“AMF身份类型”、“PLMNID”、“业务属性”参数中的一个或多个缺失。可选参数缺失：“业务属性”和“对端名称”同时缺失。“AMF身份类型”参数取值为“AMFREGION”时，参数“AMF Region ID”缺失。“AMF身份类型”参数取值为“AMFSET”时，“AMF Region ID”、“AMF Set ID”参数其中一个缺失或者两个同时缺失。 | 重新输入缺失的参数： 执行本命令时，至少输入“业务属性”和“对端名称”参数其中的一个。当“AMF身份类型”参数取值为“AMFREGION”时，必须输入参数“AMF Region ID”。 当“AMF身份类型”参数取值为“AMFSET”时，必须同时输入“AMF Region ID”和“AMF Set ID”参数。 |
| ERR1010 | 参数冲突    | “AMF身份类型”参数取值和“AMF Region ID”、“AMF Set ID”参数冲突： “AMF身份类型”参数取值为“PLMN”时，输入了“AMF Region ID”、“AMF Set ID”参数中的一个或两个。“AMF身份类型”参数取值为“AMFREGION”时，输入了“AMF Set ID”参数。                                                | 根据“AMF身份类型”、“AMF Region ID”、“AMF Set ID”参数的配置原则重新输入参数值，然后执行本命令。                                                                                              |
