# 设置前转号段限制(SET BWFTN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用于设置前转号段限制表，设置它的缺省规则和有效业务。

所指定的前转号的属性为国际号码格式，BEGINFTN和ENDFTN的格式是：国家码＋区号＋本地号码。

## 注意事项

- 如果OPTYPE=ADD，参数BEGINFTN、ENDFTN和RULE或者参数FILE、RULE是必选。
- 如果OPTYPE=MODIFY，参数BEGINFTN、RULE是必选。
- 如果OPTYPE=DELETE，参数BEGINFTN是必选，其它的参数不能出现。
- 如果OPTYPE=DELETEALL，其它的参数不能出现。
- 如果OPTYPE=DEFRULE，参数RULE是必选，其它的参数不能出现。
- 如果OPTYPE=SERVICE，参数SERVICE是必选，其它的参数不能出现。
- 如果不增加SERVICE记录，执行**SET BWFTN**设置OPTYPE为DEFRULE，ADD增加一条前转号段限制记录后对所有前转业务有效。
- 系统中增加的前转号段限制总记录数不能超过2000条。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                    |
|:---------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号       | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                |
| OPTYPE   | 操作类型         | 操作类型。取值如下： ADD：增加一条记录或批增加多条记录。 MODIFY：修改一条已有记录的前转规则。 DELETE：删除一条已有记录。 DELETEALL：删除所有记录。 DEFRULE：设置缺省的前转规则，即当前转号码与表中的前转号码不匹配时，是否允许前转。 SERVICE：设置［前转号段限制表］作用的呼叫前转业务。                      |
| BEGINFTN | 起始前转号码       | 仅当本命令中的“操作类型”参数为“ADD”、“DELETE”或“MODIFY”时该参数有效。用于标识前转号段的起始号码。 取值范围：1～16位十进制数字组成的字符串。 默认值：无。 说明：该参数的长度必须与“结束前转号码”的长度相同。当前转号码的长度被限制时，即SET MAPCONF命令中“是否限制前转号码长度”参数为“TRUE”，前转号码的长度最多只能为15位。 |
| ENDFTN   | 结束前转号码       | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识前转号段的终止号码。 取值范围：1～16位十进制数字组成的字符串。 默认值：无。 说明：该参数的长度必须与“起始前转号码”的长度相同。当前转号码的长度被限制时，即SET MAPCONF命令中“是否限制前转号码长度”参数为“TRUE”，前转号码的长度最多只能为15位。                   |
| FILE     | 起始/结束前转号码文件名 | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识文件名称。 取值范围：1～16位数字或字符组成的字符串，不可包含路径名称。 文件内容由多个前转号段组成，每一行为一个号段，格式为：起始FTN 终止FTN。 例如： 21000000 30499999 30520000 30520299 30520900 30522999 默认值：无。          |
| RULE     | 前转规则         | 仅当本命令中的“操作类型”参数为“ADD”、“MODIFY”或“DEFRULE”时该参数有效。用于标识前转规则，即某个前转号段是否允许前转。 取值范围： FORBIDDEN：不允许前转。 ALLOWABLE：允许前转。 默认值：无。                                                                    |
| SERVICE  | 呼叫前转业务       | 仅当本命令中的“操作类型”参数为“SERVICE”时该参数有效。用于标识前转号段限制表作用的呼叫前转业务。 取值范围： CFUCFBCFNRYCFNRCCFD 默认值：无。 说明：可以选择多个选项，并用“&”连接，例如CFU&CFB&CFNRY。                                                             |
| MAXMATCH | 是否最大匹配       | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”时该参数有效。用于标识是否执行最大匹配。 取值范围：FALSE：全匹配TRUE：最大匹配 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值FALSE。                                                                      |

## 使用实例

设置前转号段限制表，命令如下:

SET BWFTN: HLRSN=1, OPTYPE=ADD, BEGINFTN="86139755001", ENDFTN="86139755999",RULE=ALLOWABLE;

SET BWFTN: HLRSN=1, OPTYPE=ADD, FILE="WhiteList.txt", RULE=ALLOWABLE;

SET BWFTN: HLRSN=1, OPTYPE=MODIFY, BEGINFTN="86139755001",RULE=FORBIDDEN;

SET BWFTN: HLRSN=1, OPTYPE=DELETE, BEGINFTN="86139755001";

SET BWFTN: HLRSN=1, OPTYPE=DELETEALL;

SET BWFTN: HLRSN=1, OPTYPE=DEFRULE,RULE=FORBIDDEN;

SET BWFTN: HLRSN=1, OPTYPE=SERVICE, SERVICE=CFU&CFB;

SET BWFTN: HLRSN=1, OPTYPE=SERVICE,SERVICE=CFB;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                 | 处理建议                                                                                                                                                      |
|:--------|:--------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 增加的前转号段限制记录数超过2000条。 | 根据实际情况，如需增加前转号段限制记录，处理步骤如下：执行LST BWFTN命令，查询已存在前转号段限制记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的前转号段限制记录。执行该命令，将参数“操作类型”设置为“ADD”增加的前转号段限制记录，确保增加后前转号段限制记录数在规定范围之内。 |
