# 设置系统参数的值(SET HSYSTEMPARA)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户无法使用业务，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在开局阶段设置系统参数的值以实现对IMS网络中HSS网元功能数据的处理。

## 注意事项

- 该命令中所描述的系统初始设置值，是指操作员通过**LST HSYSTEMPARA**命令查询得出的系统在初始化时的预置参数值。
- 以下三种系统参数值的设置会对业务数据的处理产生一定的影响，请操作员谨慎操作：
  - AKA鉴权参数会影响AKA鉴权算法，而AKA鉴权算法结果会影响用户接入IMS网络时的合法性，若设置不当，有可能造成用户接入IMS网络失败，无法使用IMS网络资源的情况出现。
  - 对于“通配用户标识保存方式”参数，在开局阶段若运营商有配置需求，则根据配置需求配置，若无配置要求，则默认保存于DRU中。不允许随意切换，以免切换过程产生垃圾数据，影响系统运行。
  - 对于“是否启用IMS-HSS的分权分域功能”参数，在开局阶段若运营商有配置需求，则根据配置需求配置，若无配置要求，则默认不开启IMS-HSS的分权分域功能。不允许随意修改，以免导致用户已有的数据不可用。
- 该命令不允许进行批操作。

## 使用实例

设置系统AKA鉴权参数的值。“AKA鉴权参数R1”取值为“20”，“AKA鉴权参数R2”取值为“13”，“AKA鉴权参数R3”取值为“2F”，“AKA鉴权参数R4”取值为“49”，“AKA鉴权参数R5”取值为“5B”：

```
SET HSYSTEMPARA: R1="20", R2="13", R3="2F", R4="49", R5="5B";
```
