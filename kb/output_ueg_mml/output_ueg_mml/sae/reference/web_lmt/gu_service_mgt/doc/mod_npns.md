# 修改PNP业务(MOD NPNS)

## 命令功能

此操作用来修改用户的PNP（Private Numbering Plan）业务签约情况。为未签约PNP业务的用户提供该业务，或者为已签约PNP业务的用户撤销该业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时出现。
- 如果PROV=TRUE，表示提供PNP业务，参数PNPINDEX必须出现；如果PROV=FALSE，表示撤销PNP业务，参数PNPINDEX不出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                |
|:------------|:----------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                      |
| ISDN        | MSISDN    | ISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                     |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1～16个字母或数字组成的字符串。IMSIFILE包含多个不连续的IMSI号码。                                   |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，1～16个字母或数字组成的字符串。ISDNFILE包含多个不连续的MSISDN号码。                               |
| PROV        | 是否提供PNP业务 | 提供还是撤销PNP业务。 TRUE：提供FALSE：撤销                                                        |
| PNPINDEX    | PNP索引     | 仅当本命令中的"是否提供PNP业务"参数为"TRUE"时该参数有效。PNP业务的索引值，用于标识用户已经签约PNP业务。值域为1～99999。             |

## 使用实例

1. 运营商为“IMSI”号码是“460000001234567”的用户提供PNP业务，并指定“PNP索引”值为“600”。

   ```
   MOD NPNS: IMSI="460000001234567", PROV=TRUE, PNPINDEX=600;
   ```
2. 运营商为“IMSI”号码是“460000009123455”、“460000009123466”和“460000009123477”的用户提供PNP业务，并指定“PNP索引”值为“600”。
   1. 编写“IMSIFILE”，文件名称为“IMSIBAT”，内容如下：

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD NPNS命令提供PNP业务，并指定“PNP索引”值为“600”。

      ```
      MOD NPNS: IMSIFILE="IMSIBAT", PROV=TRUE, PNPINDEX=600;
      ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“PNP索引”的取值中含有1～99999以外的字符。                                                                       | 根据实际情况，重新输入“PNP索引”。                                                                                                     |
| ERR1009 | 参数丢失    | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户   | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
