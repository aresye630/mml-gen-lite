# 查询业务能力(LST CAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户所关联的业务能力，执行命令一次只能查询一个用户的业务能力。

## 注意事项

“IMSI”和“MSISDN”是可选参数，必须有且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                        |
|:-------|:-------|:----------------------------|
| IMSI   | IMSI   | 用于指示系统按照哪个IMSI号码来查询用户的能力。   |
| ISDN   | MSISDN | 用于指示系统按照哪个MSISDN号码来查询用户的能力。 |

## 使用实例

查询用户的能力，“IMSI”为“123456789”：

```
LST CAP: IMSI="123456789";
```

```
%%LST CAP: IMSI="123456789";%%
RETCODE = 0 SUCCESS0001:操作成功

                          MCAP = 1&2
                          OCAP = 3&4
                         SCSCF = sip:scscf2.huawei.com
                         SCSCF = sip:scscf1.huawei.com

Total count = 4

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见**MOD CAP**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                               |
|:--------|:--------|:-------------------------------------------------------|:-----------------------------------------------------------------------------------|
| ERR1010 | 参数冲突    | “IMSI”和“MSISDN”两个参数同时输入。                               | 根据实际情况，重新输入参数，确保满足“IMSI”和“MSISDN”两个参数必须有且只能有一个参数出现。                                |
| ERR3001 | 用户未开户   | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。 | 核实用户的IMSI号码或MSISDN号码，如果确定输入正确，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。 |
| ERR3045 | 条件参数丢失  | “IMSI”和“MSISDN”两个参数都没有输入。                              | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”两个参数必须有且只能有一个参数出现的条件。                              |
| ERR1118 | 参数重复    | 输入命令中的同一参数重复出现。                                        | 根据实际情况，删除重复的参数，确保命令中每一个参数只出现一次。                                                    |
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                   |
| ERR1003 | 无效的参数名  | 输入的参数标识不正确。                                            | 根据实际情况，重新输入提示错误的参数标识，确保参数标识正确。                                                     |
