## 命令功能

该命令用于从HSS的业务数据库中删除参数“SUBID”指定的IMS签约用户，以及IMS签约用户中的“IMPI”，“IMPU”。执行本命令不会删除IMS用户绑定的IMSI信息。

## 注意事项

- 如果操作员在删除了指定IMS签约用户，则可能会影响该IMS签约用户对应用户业务，请操作员在执行该操作之前仔细确认任务的可行性。
- 如果需要删除IMS用户绑定的IMSI信息， 需要先删除鉴权信息，再执行**RMV HIMSI**命令删除关联IMSI。可以通过执行**LST HAUTHINF**命令查询IMPI的鉴权模式。HTTP Digest鉴权数据、SIP Digest鉴权数据、NASS Bundled鉴权数据分别使用对应的**RMV HHDAINF**、**RMV HSDAINF**、**RMV HNBAINF**命令进行删除；Early IMS鉴权数据、Early AKA鉴权数据、Trusted Access鉴权数据、CAVE AKA鉴权数据通过设置对应命令里的鉴权标识参数为“FALSE”进行删除。
- 操作前请务必确认指定的用户为本HSS中已不再商用或测试的用户。否则执行不当将正常的用户销户，会导致正常用户无法使用业务，且销户后用户无法恢复。

**说明** 

如果需要删除“SUBID”或“IMSI”关联的用户所有信息，可以执行**RMV HHSSSUB**命令一键式销户删除关联信息，包括IMPI的鉴权信息、IMSI信息。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                  |
|:-------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID  | SUBID         | 标识一个签约用户数据记录的关键参数，用于指定需要删除哪一个签约用户数据记录，操作员可以使用LST HSUB操作查询获得，SUBID字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                                           |
| SUPCAN | 是否抑制下发消息给对端网元 | 用于标识IMS-HSS是否抑制下发销户时触发的网络侧消息给对端设备。 取值范围： SUPPRESSION：抑制，不下发销户时触发的网络侧消息给对端设备。UNSUPPRESSION：不抑制，下发销户时触发的网络侧消息给对端设备。 默认值：UNSUPPRESSION。 说明：该参数设置为“SUPPRESSION”时，会导致IMS-HSS与对端设备存储的数据不一致。 |

## 使用实例

销户，“SUBID”为“+862970119992@domain50.huawei.com”：

```
RMV HSUB: SUBID="+862970119992@domain50.huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900001008 | 参数不足           | 参数“SUBID”没有输入。   | 根据实际情况，重新输入参数“SUBID”，确保参数“SUBID”正确输入。                     |
| 900003051 | 请求消息中的SubId不存在 | 输入的参数“SUBID”未定义。 | 检查用户的“SUBID”，如果确定输入无误，证明该用户已销户，不需要再执行命令，否则重新输入正确的“SUBID”。 |
| 900001004 | 无效的参数名         | 输入的参数标识不正确。      | 根据实际情况，重新输入提示错误的参数标识，确保参数标识正确。                            |
| 900001007 | 无效的参数值         | 输入的参数取值不在其取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                          |
| 900001010 | 参数重复           | 输入命令中的同一参数重复出现。  | 根据实际情况，删除重复的参数，确保命令中每一个参数只出现一次。                           |
|      1001 | 无效的命令          | 输入的命令名称不正确。      | 重新输入正确的命令。                                                |
