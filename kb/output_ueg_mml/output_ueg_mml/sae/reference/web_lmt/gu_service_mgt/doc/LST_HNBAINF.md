# 查询IMPI的NASS Bundled鉴权信息(LST HNBAINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPI的NASS Bundled鉴权信息，需要输入唯一标识该数据记录的关键参数IMPI。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询NASS Bundled鉴权信息。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPI的NASS Bundled鉴权信息。IMPI：impiinfo。

```
LST HNBAINF: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识      | 参数说明         |
|:----------|:-------------|
| LINEIDIDX | 显示Line ID索引。 |
| LINEID    | 显示Line ID。   |
