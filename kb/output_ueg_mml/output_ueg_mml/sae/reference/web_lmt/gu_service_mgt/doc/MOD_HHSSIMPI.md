# 一键式修改IMPI(MOD HHSSIMPI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于对HSS的业务数据库中的一条IMPI记录进行修改，且对新的IMPI增加鉴权信息，系统通过“IMPI”参数来唯一标识一条IMPI数据记录。

操作员可以通过使用该命令，一键式修改IMPI与增加鉴权信息。

## 注意事项

- 执行该命令前，必须先使用**ADD HSUB**命令开户，否则会返回“指定IMPI对应的用户未开户”错误。
- 当参数“新的IMPI的鉴权类型”为“HDA”或者“SDA”时，存在“HA1值”和“用户名称”、“密码”两种加密方式。对于一个“IMPI”，“HA1值”和“用户名称”、“密码”只能存在一种，即只存在“HA1值”或只存在“用户名称”和“密码”的组合。推荐使用HA1值。
- 如果在“命令输入区”输入命令后再输入各参数，“KI密钥”、“OPC值”、“密码”和“HA1值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“KI密钥”、“OPC值”、“密码”和“HA1值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，本命令中的“新的IMPI的鉴权类型”参数为“HDA(HTTP Digest)”或“SDA(SIP Digest)”，执行该命令时如果未使用K4对KI/OPC/HA1/PWD进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
- 对于VoLTE Multi-SIM用户，执行**MOD HHSSIMPI**命令对用户主卡进行补卡时，修改主卡的IMPI后需要重新执行**MOD HMSIM**命令设置主卡标记。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 对于2G/3G/4G和IMS融合用户，改卡时必须在2G/3G/4G（执行**MOD IMSI**命令改卡）和IMS域（执行本命令改卡）同时修改。

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI            | IMPI        | 标识一条IMPI和SUBID关联关系的关键参数，用于指定需要修改哪一条IMPI和SUBID之间的关联关系，操作员可以使用LST HSUB操作查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。输入的IMPI值符合NAI格式，字母区分大小写。                                                                                                                                                                                                                                                          |
| NEWIMPI         | 新的IMPI      | 用于指定与签约用户关联的新的IMPI的值。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。输入的IMPI值符合NAI格式，字母区分大小写。输入的IMPI未增加过鉴权信息，为新增的IMPI记录。当参数“新的IMPI的鉴权类型”为CAA时，该IMPI的@符号前面的内容要与关联的IMSI相同，该参数的配置原则：要求输入的IMPI值符合username@realm形式的NAI格式。                                                                                                                                                                                         |
| NEWIMPIAUTHTYPE | 新的IMPI的鉴权类型 | 用于指定与签约用户关联的新的IMPI的鉴权类型。 取值范围：AKA(IMS AKA)：表示鉴权类型为IMS AKA鉴权。HDA(HTTP Digest)：表示鉴权类型为HTTP Digest鉴权。EIA(Early IMS)：表示鉴权类型为Early IMS鉴权。NBA(NASS Bundled)：表示鉴权类型为NASS Bundled鉴权。EAA(Early AKA)：表示鉴权类型为Early AKA鉴权。TAA(Trusted Access)：表示鉴权类型为Trusted Access鉴权。SDA(SIP Digest)：表示鉴权类型为SIP Digest鉴权。CAA(CAVE AKA)：表示鉴权类型为CAVE AKA鉴权。 默认值：无。 说明：必选参数。                                                 |
| K               | KI密钥        | 用于定义鉴权数据KI的值，要求输入16进制字符，字母不区分大小写。 取值范围：长度等于32的16进制字符串 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为AKA时，该参数为必选参数。                                                                                                                                                                                                                                                                                                |
| K4SNO           | K4索引号       | 用于指定AKA鉴权使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。 取值范围：0～128 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“AKA”时，该参数为必选参数。如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。                                                                                                                                                                                                                                                      |
| OPSNO           | OP索引号       | 用于指定AKA鉴权使用的OP的值，该参数必须先由ADD HOP操作定义，然后才能在此处索引。 取值范围：0～128 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“AKA”时，该参数为必选参数。如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不能存在。                                                                                                                                                                                                                                         |
| AMFSNO          | AMF索引号      | 用于指定AKA鉴权使用的AMF的值，该参数必须先由ADD HAMF操作定义，然后才能在此处索引。 取值范围：1～128 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“AKA”时，该参数为必选参数。                                                                                                                                                                                                                                                                                        |
| OPC             | OPC值        | 用于在HSS的业务数据库中定义鉴权数据OPC的值，要求输入16进制字符，字母不区分大小写。 取值范围：长度等于32的16进制字符串 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“AKA”时，该参数为可选参数。当OPC取值全零时为无效值，禁止输入。                                                                                                                                                                                                                                                               |
| OPCK4SNO        | OPC K4索引号   | 用于指定AKA鉴权中对OPC进行解密时使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。 取值范围：0～128 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“AKA”时，该参数为可选参数。如果OPCK4SNO取值为0，表明OPC未被加密；否则，表明OPC是经OPCK4加密过的；OPC和OPCK4SNO条件可选，如果设置了其中一个，另一个必须设置。                                                                                                                                                                                                |
| HUSERNAME       | 用户名称        | 用于定义一个用户名，该参数的配置原则是：用户名必须唯一。 取值范围：长度不超过127的字符串 默认值：无。 说明：当参数“新的IMPI的鉴权类型”为“SDA”或“HDA”时，该参数为可选参数。                                                                                                                                                                                                                                                                                               |

## 使用实例

1. 一键式修改IMPI，“IMPI”为“impiinfo”，“新的IMPI”为“new\_impiinfo”，“新的IMPI的鉴权类型”为“SDA”，“用户名称”为“hss\_user”，“密码”为“Sysabcde@2009”，“域名”为“huawei.com”：

   ```
   MOD HHSSIMPI: IMPI="impiinfo", NEWIMPI="new_impiinfo", NEWIMPIAUTHTYPE=SDA, HUSERNAME="hss_user", PWD="*****", REALM="huawei.com";
   ```
2. 一键式修改IMPI，“IMPI”为“impiinfo”，“新的IMPI”为“new\_impiinfo”，“新的IMPI的鉴权类型”为“SDA”，“域名”为“huawei.com”，“HA1值”为“11112222333344445555666677778888”：

   ```
   MOD HHSSIMPI: IMPI="impiinfo", NEWIMPI="new_impiinfo", NEWIMPIAUTHTYPE=SDA, REALM="huawei.com", HA1="*****";
   ```
3. 一键式修改IMPI，“IMPI”为“impiinfo”，“新的IMPI”为“new\_impiinfo”，“新的IMPI的鉴权类型”为“TAA”：

   ```
   MOD HHSSIMPI: IMPI="impiinfo", NEWIMPI="new_impiinfo", NEWIMPIAUTHTYPE=TAA;
   ```
