# 查询记录空口日志的透明数据黑名单(LST HBLKLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在空口日志的透明数据黑名单中查询已有记录。

- 若需要查询全部的透明数据黑名单记录，请不要输入任何参数。
- 若需要查询指定“服务标识”对应的透明数据的黑名单记录，请输入参数“服务标识”。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------|
| SERVICEID | 服务标识   | 用于标识需要查询的记录空口日志的透明数据黑名单的IMPU或PUSI的服务标识。 取值范围：长度不超过127的字符串。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 查询全部的透明数据黑名单记录：

   ```
   LST HBLKLIST:;
   ```

   ```
   %%LST HBLKLIST:;%%
   RETCODE = 0 SUCCESS0001:操作成功

   SERVICEID                     
   TAS-UPDATE-DATA 
   TEST

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询“服务标识”为“TAS-UPDATE-DATA”对应的透明数据的黑名单记录：

   ```
   LST HBLKLIST:SERVICEID="TAS-UPDATE-DATA";
   ```

   ```
   %%LST HBLKLIST:SERVICEID="TAS-UPDATE-DATA";%%
   RETCODE = 0 SUCCESS0001:操作成功

   SERVICEID                     
   TAS-UPDATE-DATA 

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码       | 错误码解释   | 原因分析               | 处理建议                                                               |
|:----------|:--------|:-------------------|:-------------------------------------------------------------------|
| 900001007 | 无效的参数值  | 输入的参数取值不符合要求。      | 根据实际情况，重新输入参数，并确保各参数取值都符合要求。                                       |
| ERR3007   | 记录不存在   | 输入的“服务标识”对应的记录不存在。 | 根据实际情况，重新输入参数，确保输入的“服务标识”对应的记录是存在的，可通过LST HBLKLIST命令查询已存在的透明数据黑名单。 |
