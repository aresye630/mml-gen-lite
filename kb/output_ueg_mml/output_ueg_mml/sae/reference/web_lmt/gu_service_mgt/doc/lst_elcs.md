## 命令功能

此操作用于查询用户ELCS业务的参数设置。

## 注意事项

IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                      |
|:------------|:----------|:------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数。                                                |
| ISDN        | MSISDN    | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数。                                              |
| RECORDCOUNT | 用户个数      | 此参数用于设置用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | 此参数用于设置IMSI文件名称。IMSIFILE包含多个不连续的IMSI号码。 取值范围：1～16个字母或数字组成。                                |
| ISDNFILE    | MSISDN文件名 | 此参数用于设置ISDN文件名称。ISDNFILE包含多个不连续的MSISDN号码。 取值范围：1～16个字母或数字组成。                              |

## 使用实例

查询IMSI号码为460000009123456用户的ELCS业务，命令如下：

LST ELCS: IMSI="460000009123456";

如果操作成功，返回的结果可能如下：

```
%%LST ELCS: IMSI="460013071001001";%%
RETCODE = 0 SUCCESS0001:操作成功

                          IMSI = 460013071001001
                          ISDN = 8613071001001
                          ELCS = PROV

Total count = 3

There is together 1 report

---    END
```
