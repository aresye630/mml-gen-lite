# 删除IMPU基本信息模板(RMV HIMPUTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中删除一个IMPU基本信息模板。

## 注意事项

当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                      |
|:-------|:---------|:------------------------------------------------------------------------------------------|
| TPLID  | IMPU模板ID | 可选必选说明：必选参数 参数含义：标识一个IMPU基本信息模板记录的关键字段，用于指定需要删除哪一个IMPU基本信息模板记录，操作员可以使用LST HIMPUTPL操作查询获得。 |

## 使用实例

删除IMPU基本信息模板。IMPU模板ID：10。

```
RMV HIMPUTPL: TPLID=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释         | 原因分析                                                                       | 处理建议   |
|----------:|:--------------|:---------------------------------------------------------------------------|:-------|
| 900003524 | 分权分域模式下不支持此命令 | SET HSYSTEMPARA命令的“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参设置为“TRUE(TRUE)”。 | 无需处理。  |
