# 查询RR模板(LST RRTPL)

## 命令功能

该命令用于查询区域漫游RR（Regional Roaming）模板的配置信息：

- 若需要查询全部区域漫游模板信息，请输入“HLR序列号”，其他参数不输入。
- 若需要查询某个区域漫游模板数据的详细信息，请输入“HLR序列号”和“模板ID”。

## 注意事项

仅输入“HLR序列号”查询所有的模板数据时，会导致PGW模块的CPU占用率升高，因此推荐输入“HLR序列号”和“模板ID”精确查询模板数据。当必须查询所有的模板数据时，请在低话务量时执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统需要按照哪个HLR序列号来查询区域漫游模板信息，该参数必须选择。                                                                                                                                                                                                                                                                                        |
| TPLID  | 模板ID   | 用于指示系统需要按照哪个模板ID来查询区域漫游模板信息；若不输入，则表示查询所有区域漫游模板信息。                                                                                                                                                                                                                                                                             |
| SAVEAS | 保存文件名  | 用于标识保存查询结果的文件名称。 当查询结果的记录数超过5000条时必须输入该参数，将查询结果保存在文件中，否则会报错“ERR4102：查询结果已经超过5000条，需要指定保存文件名进行查询”。 取值范围：长度不超过20的字符串。 默认值：无 说明： “保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。“SYSHLRSN”默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。 “保存文件名”指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。 |

## 使用实例

1. 查询“HLR序列号”为“1”的HLR上的区域漫游模板数据记录：

   ```
   LST RRTPL: HLRSN=1;
   ```

   ```
   %%LST RRTPL: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                  TPLID        TPLNAME
                  3            TEST1
                  4            TEST2

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”的HLR上的区域漫游模板数据记录。其中，“模板ID”为“3”：

   ```
   LST RRTPL: HLRSN=1, TPLID=3;
   ```

   ```
   %%LST RRTPL: HLRSN=1, TPLID=3;%%
   RETCODE = 0 SUCCESS0001:操作成功

                            TPLID = 3
                          TPLNAME = TEST1
                               CC = 86
                              NDC = 0755
                              ZC1 = 0001
                              ZC2 = 0002
                              ZC3 = 0003
                              ZC4 = 0004

   Total count = 8

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD RRTPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                        | 原因分析                       | 处理建议                                                                                   |
|:--------|:-----------------------------|:---------------------------|:---------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义                        | “HLR序列号”未定义或者“模板ID”未定义。    | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST RRTPL命令查询已定义的“模板ID”。 |
| ERR4102 | 查询结果已经超过5000条，需要指定保存文件名进行查询。 | 查询结果超过5000条，但未输入参数“保存文件名”。 | 输入参数“保存文件名”，将查询结果保存在文件中。                                                               |
