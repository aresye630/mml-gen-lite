# 修改用户签约私有短信业务(MOD NSMSIN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来给用户签约、去签约以及修改私有短信业务。

该指令支持批操作。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 根据NCC模板配置获知VLR支持能力，如果没有配置，则按照默认NCC的模板配置，如果均没有配置，则按不支持处理，此时不下发插入用户数据。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                  |
|:------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI          | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                                       |
| ISDN        | MSISDN        | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                     |
| RECORDCOUNT | 用户个数          | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                   |
| IMSIFILE    | IMSI文件名       | IMSI文件名称，1～16个字母或数字组成。IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。                                                                     |
| ISDNFILE    | MSISDN文件名     | ISDN文件名称，1～16个字母或数字组成。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。                                                                 |
| SMSINPROV   | 是否提供NSMSIN业务  | 是否提供NSMSIN业务。 取值范围： TRUE：提供 FALSE：不提供 说明：必选参数。                                                                                        |
| SCPADD      | SCP地址         | SCP地址。 取值范围：为1～15位的十进制数字。 说明：当SMSINPROV为TRUE，且为用户签约该业务时，该参数为必选参数；当SMSINPROV为TRUE，且为用户修改该业务时，该参数为可选参数。                                 |
| SKEY        | NSMSIN业务键     | NSMSIN业务键。 取值范围：0～2147483647。 说明：当SMSINPROV为TRUE，且为用户签约该业务时，该参数为必选参数；当SMSINPROV为TRUE，且为用户修改该业务时，该参数为可选参数。                             |
| DP          | DP值           | 指示在哪个检测点触发。 取值范围： MO：移动台发起时。 MT：移动台终止时。 SR: 状态表被发送时。 说明：当SMSINPROV为TRUE，且为用户签约该业务时，该参数为必选参数；当SMSINPROV为TRUE，且为用户修改该业务时，该参数为可选参数。支持多选。 |
| TAMM        | 是否所有的短消息都触发智能 | 仅当本命令中的“是否提供NSMSIN业务”参数为“TRUE”时该参数有效。是否所有的短消息都触发智能。 取值范围： TRUE：触发。 FALSE：不触发。 缺省值：FALSE。                                              |
| ACT         | 是否激活NSMSIN业务  | 仅当本命令中的“是否提供NSMSIN业务”参数为“TRUE”时该参数有效。是否激活NSMSIN业务。 取值范围： TRUE：激活。 FALSE：不激活。 缺省值：TRUE。                                                |

## 使用实例

为IMSI号码为460000009123456的用户签约私有短信业务，是否提供NSMSIN业务为TRUE，SCP地址为8613911111，NSMSIN业务键为1，DP值为MO，是否所有的短消息都触发智能为TRUE。

MOD NSMSIN: IMSI="460000009123456", SMSINPROV=TRUE, SCPADD="8613911111", SKEY=1, DP=MO, TAMM=TRUE;
