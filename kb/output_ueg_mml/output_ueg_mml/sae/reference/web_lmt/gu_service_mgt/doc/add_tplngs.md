## 命令功能

该命令用于给一个或多个4G用户通过模板方式添加5G数据。

该命令的使用场景：为已开户用户签约5G数据，使其能够使用5G业务。

在混合组网场景，执行该命令会触发用户迁移到新的分区。用户数据仅支持迁移，不支持5G相关业务。

- 对于增强GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“TRUE”），执行该命令时可以将组内所有成员一同迁移到新的分区。对于普通的GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“FALSE”），执行该命令时无法将组内所有成员一同迁移到新的分区，会造成普通GROUPSIM的主卡、辅卡不在同一个归属分区的场景。各业务流程已实现成员跨分区业务无影响。
- 迁移过程中License统计结果不更新，依赖License周期性校验校正。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 对一个或者多个4G用 户，使用已定义的“5GS漫游限制模板”与“5GS用户数据模板”，为4G用户签约5G业务。
   1. 给“IMSI”为“46100000912345”的4G用户使用模板方式添加5G数据，“5GS漫游限制模板”的ID为“3”，“5GS用户数据模板”的ID为“6”，命令如下:

      ```
      ADD TPLNGS: IMSI="46100000912345", NGCNODETPL_ID=3, NGSUSERTPLID=6;
      ```
   2. 批量为“IMSI”首号码为“461000009012346”的连续3个4G用户使用模板方式添加5G数据，“5GS漫游限制模板”的ID为“3”，“5GS用户数据模板”的ID为“6”，命令如下：

      ```
      ADD TPLNGS: IMSI="461000009012346", RECORDCOUNT=3, NGCNODETPL_ID=3, NGSUSERTPLID=6;
      ```
2. 给“IMSI”为“460031200100003”的4G用户使用模板方式添加5G数据，“5GS用户数据模板”的ID为“10”，将“旧DNN名称列表”为"Cnet.com"^"Dnet.com"、“旧的切片列表”为"123-A123D4"^"123-B456E7"替换为“新DNN名称列表”为"Enet.com"^"Fnet.com"、“新的切片列表”为"123-B123C4"^"123-D456E7"，命令如下：

   ```
   ADD TPLNGS: IMSI="460031200100003", NGSUSERTPLID=10, OLDDNNLIST="\"Cnet.com\"&\"Dnet.com\"", NEWDNNLIST="\"Enet.com\"&\"Fnet.com\"", OLDNSSAILIST="\"123-A123D4\"^\"123-B456E7\"", NEWNSSAILIST="\"123-B123C4\"^\"123-D456E7\"";
   ```
3. 给“IMSI”为“460000009123456”的用户签约CAG数据，“5GS用户数据模板”的ID为“1”，“PLMNID”为“111111”，“是否只允许UE通过CAG小区接入5GS”为“TRUE”，“CAGID”为“11111111”，命令如下：

   ```
   ADD TPLNGS: IMSI="460000009123456", NGSUSERTPLID=1, PLMNID="111111", CAGONLY=TRUE, CAGID="11111111";
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
