# 修改增强用户类别(MOD ECATEGORY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的增强用户类别业务签约情况。为未签约增强用户类别业务的用户提供该业务，或者为已签约增强用户类别业务的用户修改或撤销该业务。

执行此命令后，如果是给用户签约或修改该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或SDNFILE同时存在。
- 如果PROV=TRUE，表示提供增强用户类别业务，参数ECATEGORY和ECATOPTION至少出现一个，并且如果输入的ECATOPTION为有效值，则命令中或者HLR数据库中一定有用户的ECATEGORY签约信息；如果PROV=FALSE，表示撤销增强用户类别业务，参数ECATEGORY和ECATOPTION都不能出现。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                       |
|:------------|:-----------|:-------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                            |
| ISDN        | MSISDN     | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                          |
| RECORDCOUNT | 用户个数       | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。        |
| IMSIFILE    | IMSI文件名    | IMSI文件名称，1～16个由字母、数字、下划线和点号组成的字符串。IMSIFILE包含多个不连续的IMSI号码。                                  |
| ISDNFILE    | MSISDN文件名  | ISDN文件名称，1～16个由字母、数字、下划线和点号组成的字符串。ISDNFILE包含多个不连续的MSISDN号码。                                |
| PROV        | 是否提供增强用户类别 | 是否提供增强用户类别业务。 TRUE：提供 FALSE：不提供                                                            |
| ECATEGORY   | 增强用户类别     | 仅当本命令中的“是否提供增强用户类别”参数为“TRUE”时该参数有效。增强用户类别，值域为1～254。                                        |
| ECATOPTION  | 增强类别扩展     | 仅当本命令中的“是否提供增强用户类别”参数为“TRUE”时该参数有效。该参数为增强用户类别的扩展。 取值范围：0～127，有效值为1～127，0代表不签约（不提供）。 缺省值：0。 |

## 使用实例

1. 运营商为IMSI号码是460000009123456的用户提供增强用户类别业务，并指定增强用户类别为32。

   MOD ECATEGORY: IMSI="460000009123456", PROV=TRUE, ECATEGORY=32;
2. 运营商为IMSI号码是460000009123455、460000009123466和460000009123477的用户提供增强用户类别业务，并指定增强用户类别为32。

   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD ECATEGORY命令提供增强用户类别业务。

      MOD ECATEGORY: IMSIFILE="IMSIBAT", PROV=TRUE, ECATEGORY=32;
