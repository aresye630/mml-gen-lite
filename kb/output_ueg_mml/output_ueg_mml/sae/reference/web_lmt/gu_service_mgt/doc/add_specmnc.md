## 命令功能

用于增加一条特殊MNC配置。

## 注意事项

- 总记录数最大为256条。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 用于标识移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460，英国为234等。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。 |
| MNC    | 移动网络码  | 用于标识移动网络码。移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配。 取值范围：3位的十进制数字组成的字符串。 默认值：无。 配置原则：首位必须为0。                                                                 |
| DESC   | 配置描述   | 可选必选说明：必选参数 参数含义：用于标识MCC与MNC配置的描述。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                      |

## 使用实例

执行该命令增加一条特殊MNC配置。

```
ADD SPECMNC: MCC="722", MNC="070", DESC="huaweitest1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

| 错误码     | 错误码解释   | 原因分析                 | 处理建议                                                                        |
|:--------|:--------|:---------------------|:----------------------------------------------------------------------------|
| ERR1111 | 超过最大限制  | 新增的特殊MNC配置数超过最大限制。   | 请按照以下步骤操作： 执行LST SPECMNC命令查询特殊MNC配置。根据查询结果删除不必要的特殊MNC配置，确保设置的数据记录总数在256条以内。 |
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                            |
| ERR3006 | 记录已存在   | 新增的特殊MNC配置已存在。       | 请按照以下步骤操作： 执行LST SPECMNC命令查询特殊MNC配置。根据查询结果确认新增的特殊MNC配置是否与已有记录重复。            |
