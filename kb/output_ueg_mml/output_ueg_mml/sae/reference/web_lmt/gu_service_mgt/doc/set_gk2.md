# 设置全局存储密钥(SET GK2)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败，造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加全局存储密钥GK2记录。

新建局点：在全新部署流程中，首次通过**ADD HLRSN**命令添加HLRSN记录时，系统会默认生成一条KEYID为3001的缺省随机密钥记录，同时会自动生成一条“GK2SNO”为“1”全局的随机默认GK2记录，并使用KEYID为3001的随机秘钥加密该GK2数据。

**说明** 

无论**SET MAPCONF**命令中的“是否启用随机密钥”参数如何设置，系统都会自动生成“KEYID”为“3001”的缺省随机密钥。

- 当执行本命令指定“密钥ID”时，需要使用该KEYID对应的随机密钥加密GK2数据。
- 当执行本命令未指定“密钥ID”时，需要使用系统自动生成的KEYID为3001的缺省随机密钥加密GK2数据。

## 注意事项

- 执行该命令只能增加GK2数据记录，不能修改或删除，系统中最多可增加254条GK2数据记录。
- 混合组网场景下，执行本命令会报错“ERR3111：系统不支持该特性”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GK2SNO | GK2序列号 | 可选必选说明：必选参数 参数含义：用于标识GK2序列号。 取值范围：1～254。 配置原则：无。 默认值：无。                                                                                                      |
| KEYID  | 密钥ID   | 可选必选说明：可选参数 参数含义：用于标识密钥ID。该参数必须先由SET RANDOMKEY命令定义，然后才能在此处引用。 取值范围：1～3000 配置原则：当携带时，全局存储密钥会使用该密钥ID对应的随机密钥加密。当不携带时，全局存储密钥会使用3001的随机密钥加密。3001记录系统自动生成，不需要人工配置。 |

## 使用实例

增加一条全局存储密钥记录。

```
SET GK2: GK2SNO=1, KEYID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                    | 原因分析                                      | 处理建议                                                                     |
|:--------|:-------------------------|:------------------------------------------|:-------------------------------------------------------------------------|
| ERR3111 | 系统不支持该特性。                | 混合组网场景不支持该命令配置。                           | 混合组网场景不支持该特性，请勿在混合组网场景下使用该命令。                                            |
| ERR4222 | 已生成全局存储密钥，不需要重复生成全局存储密钥。 | 执行该命令时输入的“GK2序列号”参数对应的全局存储密钥数据记录在数据库中已存在。 | 根据实际情况，重新输入参数，确保输入的“GK2序列号”和系统中已存在的不重复。可执行LST GK2命令查询系统中已存在的全局存储密钥数据记录。  |
| ERR4223 | HLRSN未配置。                | 系统未配置HLRSN记录。                             | 系统未配置HLRSN记录，不允许执行该命令配置全局存储密钥。                                           |
| ERR4130 | 没有指定的随机密钥记录。             | 输入的“密钥ID”在系统中没有对应的随机密钥记录。                 | 根据实际情况，重新输入参数，处理步骤如下：执行LST RANDOMKEY查询已存在的随机密钥记录。执行该命令确保输入的“密钥ID”已存在。    |
| ERR4133 | 密钥丢失。                    | 输入的“密钥ID”在对应的随机密钥不完整。                     | 根据实际情况，重新输入参数，处理步骤如下：执行LST RANDOMKEY查询已存在的随机密钥记录。执行该命令确保输入的“密钥ID”已存在且完整。 |
