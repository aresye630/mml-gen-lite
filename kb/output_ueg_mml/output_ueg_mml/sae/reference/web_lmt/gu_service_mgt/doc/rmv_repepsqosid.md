# 删除EPS QoS模板替代配置(RMV REPEPSQOSID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游到指定的MME/S4SGSN/AAA时下发错误的QoS，因此执行该命令前，需要和运营商的EPS QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保删除的EPS QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中删除一条或多条EPS QoS模板替代配置记录：

- 若需要删除一条指定的QoS模板替代配置记录，请输入参数“HLR序列号”、“用户签约的EPS QoS模板ID”和“对端身份标识”。
- 若需要删除指定虚拟HLR下指定用户的EPS QoS模板ID对应的全部替代配置记录，请输入参数“HLR序列号”和“用户签约的EPS QoS模板ID”，参数“对端身份标识”不输入。

## 注意事项

- 当删除了EPS QoS模板替代配置，系统会不再统一下发替换后的EPS QoS模板数据，而是仍采用用户签约的EPS QoS模板下发数据，会影响大量在网用户，如对应的MME/S4-SGSN/3GPP AAA Server不支持相关业务，则会导致大量用户签约的EPS QoS业务无法生效，因此现网执行该操作时需要慎重。
- 如不输入参数“对端身份标识”，表示删除指定EPS QoS模板ID对应的全部替代配置。删除前请先执行**LST REPEPSQOSID**命令，并确定该EPS QoS模板ID对应的所有记录都是可以删除的。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                          |
|:------------|:-----------------|:----------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号           | 用于标识EPS QoS模板替代配置记录的关键字段之一，用于指定需要删除哪个HLR中的EPS QoS模板替代配置记录，操作员可以使用LST HLRSN命令查询获得。             |
| USREPSQOSID | 用户签约的EPS QoS模板ID | 用于标识EPS QoS模板替代配置记录的关键字段之一，用于指定需要删除哪个用户签约的QoS模板ID对应的QoS模板替代配置记录，操作员可以使用LST REPEPSQOSID命令查询获得。 |
| PEERENTITY  | 对端身份标识           | 用于标识EPS QoS模板替代配置记录的关键字段之一，用于指定需要删除哪个对端身份标识对应的EPS QoS模板替代配置记录，操作员可以使用LST REPEPSQOSID命令查询获得。   |

## 使用实例

1. 删除“HLR序列号”为“1”，“用户签约的EPS QoS模板ID”为“1”，“对端身份标识”为“test.huawei.com”的一条EPS QoS模板替换配置记录：

   ```
   RMV REPEPSQOSID: HLRSN=1, USREPSQOSID=1, PEERENTITY="test.huawei.com";
   ```
2. 删除“HLR序列号”为“1”，“用户签约的EPS QoS模板ID”为“1”所对应的所有EPS QoS模板替换配置记录：

   ```
   RMV REPEPSQOSID: HLRSN=1, USREPSQOSID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                | 处理建议                                                                              |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                                                                                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                  |
| ERR3007 | 记录不存在   | 可能原因为如下之一：输入的“HLR序列号”、“用户签约的EPS QoS模板ID”、和“对端身份标识”的组合对应的EPS QoS模板替代配置记录未预先定义。 输入的“HLR序列号”和“用户签约的EPS QoS模板ID”之下不存在任何EPS QoS模板替代配置记录。 | 使用LST REPEPSQOSID命令查询系统中已存在的EPS QoS模板替代配置记录，根据查询结果中存在的EPS QoS模板替换配置记录，重新输入相应的参数值。 |
