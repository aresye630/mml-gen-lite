# 修改ALS ODB业务(MOD ALSODB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户ALS（Alternative Line Service） ODB业务签约情况。

如果UDM支持签约管理优化（执行**SET MAPCONF**命令将“用户被锁后是否允许操作相关补充业务”设置为“TRUE”），即使用户停机，包括运营商锁（LCK）和用户锁（SABLCK），闭锁入呼叫和出呼叫，仍可以执行该命令修改“ALS ODB业务选择类别”参数的“ODB-BOC”和“ODB-BIC”业务。

执行此命令后，当用户在网，且处于可用状态，则会下发插入用户数据消息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                  |
|:-------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI          | 用于标识需要修改ALS ODB业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                            |
| ISDN         | MSISDN        | 用于标识需要修改ALS ODB业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                          |
| RECORDCOUNT  | 用户个数          | 用于标识需要修改ALS ODB业务的用户数目。 当需要为连续号码的多个用户修改ALS ODB业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改ALS ODB业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改ALS ODB业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                               |
| IMSIFILE     | IMSI文件名       | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改ALS ODB业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“IMSIBAT”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                                       |
| ISDNFILE     | MSISDN文件名     | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改ALS ODB业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“MSISDNBAT”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                               |
| ALS_ODB_TYPE | ALS ODB业务选择类别 | 用于标识ALS ODB业务选择类别，每次只支持选择一个ODB业务，如果要给ALS号码签约多个ODB业务，那么需要使用MOD ALSODB命令签约多次。 取值范围：ODB-ENTE：闭锁高额费率娱乐业务出呼叫。ODB-INFO：闭锁高额费率声讯业务出呼叫。ODB-PB1：PLMN特定闭锁类型1。ODB-PB2：PLMN特定闭锁类型2。ODB-PB3：PLMN特定闭锁类型3。ODB-PB4：PLMN特定闭锁类型4。ODB-SS：闭锁补充业务接入。ODB-BOC：锁所有出呼叫或移动始发短消息。ODB-BIC：闭锁所有入呼叫或移动终结短消息。 默认值：无。 |
| PROV         | 是否提供补充业务      | 仅当本命令中的“ALS ODB业务选择类别”参数为“ODB-ENTE”、“ODB-INFO”、“ODB-PB1”、“ODB-PB2”、“ODB-PB3”、“ODB-PB4”或“ODB-SS”时该参数有效。用于标识提供还是撤销ALS ODB业务。 取值范围： TRUE：提供。FALSE：撤销。 默认值：无。                                                                                                                             |
| ODBOC        | ODB-闭锁出呼叫     | ODB-闭锁出呼叫：仅当本命令中的“ALS ODB业务选择类别”参数为“ODB-BOC”时该参数有效。用于标识闭锁出呼叫的种类。 取值范围：NOBOC：不闭锁出呼叫。BAOC：闭锁所有呼出业务。BOIC：闭锁国际呼出业务。BOICEXHC：闭锁除到归属国以外的国际呼出业务。BOCROAM：漫游出归属PLMN国家以外时，闭锁呼出业务。 默认值：无。                                                                                                        |
| ODBIC        | ODB-闭锁入呼叫     | ODB-闭锁入呼叫：仅当本命令中的“ALS ODB业务选择类别”参数为“ODB-BIC”时该参数有效。用于标识闭锁入呼叫的种类。 取值范围：NOBIC：不闭锁入呼叫。BAIC：闭锁所有入呼叫。BICROAM：当漫游出HPLMN (Home PLMN)国家时， 闭锁入呼叫。 默认值：无。                                                                                                                                       |

## 使用实例

1. 为IMSI号码为“123111111111111”的用户提供ODB业务，并指定“ALS ODB业务选择类别”为“ODB-PB4”：

   ```
   MOD ALSODB: IMSI="123111111111111", ALS_ODB_TYPE=ODB-PB4, PROV=TRUE;
   ```
2. 修改3个连续号码的用户的“ALS ODB业务选择类别”，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，对应的“ALS ODB业务选择类别”为“ODB-PB4”：

   ```
   MOD ALSODB: ISDN="13310911001", RECORDCOUNT=3, ALS_ODB_TYPE=ODB-PB4, PROV=TRUE;
   ```
3. 为两个非连续号码的用户提供ODB业务，这2个IMSI号码分别为“460000000000000”和“123111111111111”，已保存在“IMSI文件名”为“IMSIBAT”的文件中，并通过文件管理功能上传到指定目录，并指定“ALS ODB业务选择类别”为“ODB-PB4”：

   ```
   MOD ALSODB: IMSIFILE="IMSIBAT", ALS_ODB_TYPE=ODB-PB4, PROV=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失    | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到   | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户   | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
