# 增加锚定AS配置(ADD ANCHORMGCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来添加前缀锚定方式中前缀号码和MSISDN号段的关系，PRN锚定方式中锚定AS和MSISDN号段的关系。

## 注意事项

- 添加“锚定前缀”参数时，请合理配置其长度，确保添加后通过此锚定前缀号码生成的IMRN号码（国家码+锚定前缀号码+ISDN号码）长度不超过16位。
- 同一个“HLR序列号”中增加的锚定AS地址和IMRN前缀配置的记录数不能超过1000条。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                     |
|:--------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                             |
| MSISDN_PREFIX | MSISDN前缀   | 用于标识国内移动号码前缀。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明：MSISDN前缀包含国家码。                                                                                                                           |
| ANCHOR_PREFIX | 锚定前缀       | 用于标识增加前缀方式锚定时的锚定前缀。 取值范围：1～15位的十六进制数字（0～E）组成的字符串。 默认值：无。 说明：锚定前缀不包含国家码。输入的十六进制数“A”、“B”、“C”、“D”、“E”，分别代表电信业务BCD字符“*”、“#”、“A”、“B”、“C”。通过该参数生成IMRN号码（国家码+锚定前缀号码+ISDN号码）时，确保IMRN号码总长度不超过16位。 |
| MGCF_ADDR1    | 锚定AS GT 地址 | 用于标识发送PRN方式锚定时的锚定AS地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                    |

## 使用实例

增加一条锚定AS，锚定前缀和MSISDN号段关系，MSISDN前缀为861380270，锚定前缀为1234，锚定AS GT地址为460000000000000，命令如下：

ADD ANCHORMGCF: HLRSN=1, MSISDN\_PREFIX="861380270", ANCHOR\_PREFIX="1234", MGCF\_ADDR1="460000000000000";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                                                                                                                                                                |
|:--------|:--------|:-------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1111 | 超过最大限制  | 增加的锚定AS地址和IMRN前缀配置的记录数超过1000条。 | 根据实际情况，如需增加锚定AS地址和IMRN前缀配置记录，处理步骤如下：执行LST ANCHORMGCF命令，查询已存在锚定AS地址和IMRN前缀配置记录。执行RMV ANCHORMGCF命令，删除不必要的锚定AS地址和IMRN前缀配置记录。执行该命令，增加的锚定AS地址和IMRN前缀配置记录，确保增加后锚定AS地址和IMRN前缀配置记录数在规定范围之内。 |
