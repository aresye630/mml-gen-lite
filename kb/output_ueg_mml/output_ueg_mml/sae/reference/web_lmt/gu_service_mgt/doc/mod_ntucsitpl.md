# 修改NT-U-CSI模板(MOD NTUCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条NT-U-CSI模板数据记录中的U-CSI模板进行增加或删除。在该命令中，系统通过关键参数“HLR序列号”和“NT-U-CSI模板ID”的组合来唯一标识一条NT-U-CSI模板数据记录。

执行该命令可以为NT-U-CSI模板配置多个U-CSI模板。

## 注意事项

- NT-U-CSI模板中必须保证至少有一条U-CSI模板数据记录，如果该命令的“操作类型”设置为“DELETE”，要删除NT-U-CSI模板中唯一一条U-CSI模板数据记录，则无法删除。
- 如果给NT-U-CSI模板配置多个U-CSI模板，执行该命令多次，每个NT-U-CSI模板最多允许配置20个模板。如果模板数超过20条，会返回提示信息“ERR3047：超过最大限制”，必须先执行该命令删除不必要的U-CSI模板，使添加的总U-CSI模板数在20之内。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                                                               |
|:-----------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识一条NT-U-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条NT-U-CSI模板数据记录的参数进行增加或删除，可以使用LST HLRSN命令查询获得。 默认值：无。                                                                               |
| TPLID      | NT-U-CSI模板ID | 用于标识一条NT-U-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条NT-U-CSI模板数据记录的参数进行增加或删除，可以使用LST NTUCSITPL命令查询获得。 默认值：无。                                                                           |
| TPLNAME    | 模板名称         | 用于标识待修改NT-U-CSI模板在系统中的名称。 取值范围：长度不超过60的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                         |
| PROV       | 操作类型         | 用于标识该命令是为NT-U-CSI模板增加还是删除一个U-CSI模板。 取值范围：ADD：为NT-U-CSI模板增加一个U-CSI模板。 DELETE：为NT-U-CSI模板删除一个U-CSI模板。 默认值：无。                                                                         |
| UCSI_TPLID | U-CSI模板ID    | 仅当该命令中的“操作类型”参数取值为“ADD”或“DELETE”时该参数有效。用于标识NT-U-CSI模板修改的U-CSI模板ID。该参数可以设置多个，即可增加或删除多个U-CSI模板。增加U-CSI模板：该参数必须先通过ADD UCSITPL命令配置才能在此处引用。删除U-CSI模板：该参数可以通过LST NTUCSITPL命令查询获得。 默认值：无。 |

## 使用实例

1. 增加“HLR序列号”为“1”的HLR上的NT-U-CSI模板数据记录。其中，“NT-U-CSI模板ID”为“1”，“模板名”为“NTUCSI1”，“是否提供NT-U-CSI模板”为“ADD”，“U-CSI模板ID”为“2”：

   ```
   MOD NTUCSITPL: HLRSN=1, TPLID=1, TPLNAME="NTUCSI1", PROV=ADD, UCSI_TPLID=2;
   ```
2. 删除“HLR序列号”为“1”的HLR上的NT-U-CSI模板数据记录。其中，“NT-U-CSI模板ID”为“1”，“模板名”为“NTUCSI1”，“是否提供NT-U-CSI模板”为“DELETE”，“U-CSI模板ID”为“1”：

   ```
   MOD NTUCSITPL: HLRSN=1, TPLID=1, TPLNAME="NTUCSI1", PROV=DELETE, UCSI_TPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                                                                                                         | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                                |
| ERR1009 | 参数丢失    | 该命令中的所有可选参数全部没有输入。                                                                                                       | 根据实际情况，重新输入参数，并满足参数的输入条件。                                                                                                                                                                       |
| ERR3003 | 模板未定义   | 当该命令中的“操作类型”参数取值为“ADD”时，输入的参数“U-CSI模板ID”对应的U-CSI模板数据记录不存在。                                                               | 根据实际情况，重新输入参数“U-CSI模板ID”，确保“U-CSI模板ID”对应的NT-U-CSI模板数据记录存在，可使用LST UCSITPL命令进行查询。                                                                                                                 |
| ERR3006 | 记录已存在   | 当该命令中的“操作类型”参数取值为“ADD”时，输入的参数“U-CSI模板ID”已被该NT-U-CSI模板配置。                                                                 | 根据实际情况，重新输入参数“U-CSI模板ID”，确保“U-CSI模板ID”在该NT-U-CSI模板中未被配置。执行LST NTUCSITPL命令，输入参数“HLR序列号”或“NT-U-CSI模板ID”，可查询NT-U-CSI模板中已配置的“U-CSI模板ID”。                                                            |
| ERR3007 | 记录不存在   | 可能原因为如下之一：输入的参数“HLR序列号”和“NT-U-CSI模板ID”对应的NT-U-CSI模板数据记录不存在。当该命令中的“操作类型”参数取值为“DELETE”时，输入的参数“U-CSI模板ID”对应的U-CSI模板数据记录不存在。 | 根据实际情况进行处理，确保满足以下两点： 重新输入参数“HLR序列号”或“NT-U-CSI模板ID”，确保“HLR序列号”和“NT-U-CSI模板ID”对应的NT-U-CSI模板数据记录存在，可使用LST NTUCSITPL命令进行查询。重新输入参数“U-CSI模板ID”，确保“U-CSI模板ID”对应的NT-U-CSI模板数据记录存在。可使用LST UCSITPL命令进行查询。 |
| ERR3047 | 超过最大限制  | 为NT-U-CSI模板配置的U-CSI模板数超过最大限制。                                                                                            | 处理步骤：使用LST NTUCSITPL命令查询NT-U-CSI模板已配置的U-CSI模板。使用该命令删除不必要的U-CSI模板，使添加的总U-CSI模板数在20之内。                                                                                                            |
| ERR3096 | 模板不能为空  | 参数“操作类型”设置为“DELETE”时，参数“U-CSI模板ID”的取值是NT-U-CSI模板中唯一的一条U-CSI模板数据记录。                                                       | 不允许删除NT-U-CSI模板中唯一的一条U-CSI模板数据记录。                                                                                                                                                               |
