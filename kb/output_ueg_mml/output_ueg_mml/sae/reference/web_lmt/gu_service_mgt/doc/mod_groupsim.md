## 命令功能

此操作用来新增、修改或删除GROUPSIM用户组。GROUPSIM用户组允许一个组MSISDN号码对应多个成员号码，华为UDM支持一个GROUPSIM用户组最多有8个成员号码。

在混合组网场景，执行该命令会触发用户迁移到新的分区。用户数据仅支持迁移，不支持5G相关业务。

- 对于增强GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“TRUE”），执行该命令时可以将组内所有成员一同迁移到新的分区。对于普通的GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“FALSE”），执行该命令时无法将组内所有成员一同迁移到新的分区，会造成普通GROUPSIM的主卡、辅卡不在同一个归属分区的场景。各业务流程已实现成员跨分区业务无影响。
- 迁移过程中License统计结果不更新，依赖License周期性校验校正。

## 注意事项

- GROUPSIM业务还与其他许多业务存在冲突，不能同时签约。这些业务包括：多SIM、多SIM增强、一卡多号多Profile、M2M COMISDN和M2M ISDN-Less。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 用户同时签约**MOD COMISDN**业务和**MOD GROUPSIM**业务时，需要满足以下条件：
  - **MOD GROUPSIM**命令的“组IMSI号码”/“组MSISDN号码”和**MOD COMISDN**的主号是同一个用户。
  - **MOD COMISDN**命令的主辅号不相同。
  - **MOD GROUPSIM**成员号码不能是未开卡开户号码。

## 使用实例

1. 增加GIMSI为“460000009123456”，GISDN为"460000009012389"的GROUPSIM用户组，操作类型为ADD，HLRSN为1，GROUPSIM类型为Sequential，MEMBERISDN1为"460000009012388"。

   ```
   MOD GROUPSIM: GIMSI="460000009123456", GISDN="460000009012389", PROV=ADD, HLRSN=1, MSIMTYPE=Sequential, MEMBERISDN1="460000009012388";
   ```
2. 修改GIMSI为“460000009123456”的GROUPSIM用户组，操作类型为MOD，用户类型为254，铃音类型为Intelligent\_Tone。

   ```
   MOD GROUPSIM: GIMSI="460000009123456", PROV=MOD, USERTYPE=254, TONETYPE=Intelligent_Tone;
   ```
3. 删除GIMSI为“460000009123456”的GROUPSIM用户组，操作类型为RMV。

   ```
   MOD GROUPSIM: GIMSI="460000009123456", PROV=RMV;
   ```
