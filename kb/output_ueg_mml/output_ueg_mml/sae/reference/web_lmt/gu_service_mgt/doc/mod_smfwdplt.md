# 修改短消息转发平台地址(MOD SMFWDPLT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对一条短消息转发平台地址的某些参数进行修改或调整。在该命令中，系统通过“短消息转发平台地址”参数来唯一标识一条短消息转发平台地址。

## 注意事项

系统中只能配置存在一个默认短消息转发平台地址，即“是否默认地址”为“TRUE”的短消息转发平台地址。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                 |
|:------------|:----------|:-------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号    | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                         |
| SMFWDPLAT   | 短消息转发平台地址 | 用于标识需要配置的短消息转发平台地址。 取值范围：1～15位十进制数字组成的字符串。                                           |
| ISDEFAULT   | 是否默认地址    | 用于标识“短消息转发平台地址”是否是默认地址，即ACT SMSCF命令未携带前转号码时采用的短消息转发平台地址。 取值范围：TRUE：是默认地址FALSE：不是默认地址 |
| FWDPLATNAME | 短消息转发平台名称 | 为便于识别，为短消息转发平台指定的名称。 取值范围：长度不超过60的字符串。                                               |

## 使用实例

修改一条短消息转发平台地址信息，设置“HLR序列号”为“1”，“短消息转发平台地址”为“1234567891”，“是否默认地址”为“TRUE”，“短消息转发平台名称”为“default2”：

```
MOD SMFWDPLT: HLRSN=1, SMFWDPLAT="1234567891", ISDEFAULT=TRUE, FWDPLATNAME="default2";
```
