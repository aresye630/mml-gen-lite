# 修改AAA动态信息（MOD AAAINFO）

## 命令功能

该命令用于在用户的AAA（Authentication，Authorization and Accounting）动态数据未正常注销而引起用户注册失败的情况下，修改或清除已注册的AAA动态数据，以保证用户可以注册成功。

当用户向网络发起注册流程时，用户向AAA发送认证、授权和计费请求消息，AAA收到该消息后向UDM发起注册请求流程，消息中携带AAA主机名信息，UDM记录并回复响应消息，完成用户注册。如果用户未正常注销，UDM所记录的AAA主机名信息不会改变，此后用户再次注册时，UDM根据协议会比较消息中的AAA主机名和此前注册的主机名是否一致。

- 如果一致，用户正常注册。
- 如果不一致，则UDM在向AAA返回的响应消息中携带UDM所记录的AAA主机名信息与本次请求消息中的主机名信息不一致的错误提示“DIAMETER\_ERROR\_IDENTITY\_ALREADY\_REGISTERED”，需要执行本命令修改或清除已注册的AAA动态数据，以保证用户可以注册成功。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “操作类型”参数为“MOD”时，必须至少输入“AAA主机名”、“AAA域名”、“拜访网络识别码”、“注册状态”参数中的一个。
- “操作类型”参数为“CLR”时，“AAA主机名”、“AAA域名”、“拜访网络识别码”、“注册状态”参数均不显示，将其全部置为默认值，表示清除AAA动态信息。
- 执行该命令修改AAA动态数据错误，将导致对应用户无法注册，请谨慎操作。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                     |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改AAA动态数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                 |
| ISDN        | MSISDN    | 用于标识需要修改AAA动态数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                               |
| RECORDCOUNT | 用户个数      | 用于标识需要修改AAA动态数据的用户数量。 当需要修改连续号码用户的AAA动态数据时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，修改连续多个号码用户的AAA动态数据。 取值范围：1～100000 默认值：无。                                                                                  |
| IMSIFILE    | IMSI文件名   | 用于标识需要修改AAA动态数据的IMSI文件名称。 IMSI批操作文件包含多个不连续的需要修改AAA动态数据用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modaaainfo.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。       |
| ISDNFILE    | MSISDN文件名 | 用于标识需要修改AAA动态数据的MSISDN文件名称。 MSISDN批操作文件包含多个不连续的需要修改AAA动态数据用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modaaainfo.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。 |
| OPERTYPE    | 操作类型      | 用于标识在执行该命令时对AAA动态数据执行哪种操作。 取值范围： MOD：修改动态信息CLR：清除动态信息 默认值：无。                                                                                                                                             |
| AAAHOST     | AAA主机名    | 仅当本命令中的“操作类型”参数选择为“MOD”时该参数有效，用于标识用户向HSS发起注册请求流程中的AAA动态数据携带的完成认证、授权和计费信息的AAA的主机名称。 取值范围：1～127位字符串。 默认值：无。                                                                                                |
| AAAREALM    | AAA域名     | 仅当本命令中的“操作类型”参数选择为“MOD”时该参数有效，用于标识用户向HSS发起注册请求流程中的AAA动态数据携带的完成认证、授权和计费信息的AAA的域名。 取值范围：1～127位字符串。 默认值：无。                                                                                                  |
| VNI         | 拜访网络识别码   | 仅当本命令中的“操作类型”参数选择为“MOD”时该参数有效，用于标识AAA动态数据中的用户所要拜访的网络的域名。 取值范围：1～127位字符串。 默认值：无。                                                                                                                          |
| REGSTATUS   | 注册状态      | 仅当本命令中的“操作类型”参数选择为“MOD”时该参数有效，用于标识AAA动态数据中用户是否完成注册。 取值范围： REGISTERED：已注册NOT_REGISTERED：未注册 默认值：无。                                                                                                        |

## 使用实例

1. 当用户未正常注销时，修改UDM所记录的AAA动态数据信息，使修改后的信息与请求消息中的AAA数据信息一致。

   修改“IMSI”为“460000009123456”的用户的AAA动态数据，“AAA主机名”为“aaa1.abc.com”，“AAA域名”为“abc.com”，“注册状态”为“REGISTERED”，命令如下：

   ```
   MOD AAAINFO: IMSI="460000009123456", OPERTYPE=MOD, AAAHOST="aaa1.abc.com", AAAREALM="abc.com", REGSTATUS=REGISTERED;
   ```
2. 当用户未正常注销时，删除UDM所记录的AAA动态数据信息，使用户可以重新注册。

   删除“IMSI”为“460000009123456”的用户的AAA动态数据，命令如下：

   ```
   MOD AAAINFO: IMSI="460000009123456", OPERTYPE=CLR;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
