# 查询5G自动开户黑白名单（LST NGCAUTOIMSIPRE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询控制5G自动开户的用户IMSI号码前缀信息。

- 若要查询控制5G自动开户的全部IMSI号码前缀信息，请不要输入任何参数。
- 若要查询控制5G自动开户的某个IMSI号码前缀信息，请输入“IMSI前缀”。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IMSI号码前缀来查询控制5G自动开户的IMSI号码前缀信息；若不输入则表示所有的IMSI号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无 配置原则：无 |

## 使用实例

1. 查询控制5G自动开户的全部IMSI号码前缀信息：

   ```
   LST NGCAUTOIMSIPRE:;
   ```

   ```
   %%LST NGCAUTOIMSIPRE:;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                  IMSIPREFIX      NGCAUTOPROV
                  46000           4G-5G

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询IMSI号码前缀为“46000”的用户进行5G自动开户的控制规则，需要执行如下操作：

   ```
   LST NGCAUTOIMSIPRE: IMSIPREFIX="46000";
   ```

   ```
   %%LST NGCAUTOIMSIPRE: IMSIPREFIX="46000";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                       IMSIPREFIX = 46000
                      NGCAUTOPROV = 4G-5G

   Total count = 2

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD NGCAUTOIMSIPRE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                            | 处理建议                                                    |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI前缀”的取值不是1～15位十进制数字组成的字符串。                                                                                | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                        |
| ERR3007 | 记录不存在   | 可能原因为如下之一：若执行该命令时未输入参数，则系统未使用MOD NGCAUTOIMSIPRE添加过控制5G自动开户的用户IMSI号码前缀信息。若执行该命令时输入了“IMSI前缀”，则输入的“IMSI前缀”数据记录不存在。 | 根据实际情况，选择是否使用MOD NGCAUTOIMSIPRE添加控制5G自动开户的用户IMSI号码前缀信息。 |
