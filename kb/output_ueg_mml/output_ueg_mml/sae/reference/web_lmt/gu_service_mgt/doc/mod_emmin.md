# 修改EMMIN业务(MOD EMMIN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户签约MMINT(Mobility Management IN Triggering)业务或对用户已签约的MMINT业务信息进行修改和调整。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识待签约或待修改用户的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ISDN        | MSISDN    | 用于标识待签约或待修改用户的MSISDN号码。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| RECORDCOUNT | 用户个数      | 用于标识待签约或待修改用户的数目。当需要为连续号码的多个用户签约或修改MMINT业务信息时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行操作。 取值范围：1～100000 默认值：无。                                                                                                                                                                                                                                                                                                                                                                    |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 取值范围：1～16位由数字、字母或特殊字符等组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 取值范围：1～16位由数字、字母或特殊字符等组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PROV        | 操作类型      | 用于标识签约或修改MMINT业务信息时的操作类型。 取值范围： ADD：增加用户记录。MOD：修改用户记录。DEL：删除当前DP对应的一条记录。DEL_ALL：删除用户的所有记录。ACTIVE_ALL：激活或去激活用户签约的所有业务。 默认值：无。                                                                                                                                                                                                                                                                                                                                                              |
| DP          | DP点       | 仅当“操作类型”参数取值为“ADD”、“MOD”和“DEL”时该参数有效。用于标识触发MMINT业务的检出点的值，当在检出点满足相应的DP触发准则时，就会触发相应的MMINT业务。 取值范围：0～255 默认值：无。                                                                                                                                                                                                                                                                                                                                                                              |
| SCPADDR     | SCP地址     | 仅当“操作类型”参数取值为“ADD”和“MOD”时该参数有效。用于标识接入gsmSCF（GSM Service Switching Function）功能实体的地址。 取值范围：1～15位采用E.164编码方式的字符串。编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”，各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| SK          | 业务键       | 仅当“操作类型”参数取值为“ADD”和“MOD”时该参数有效。用于标识用户在gsmSCF中签约MMINT业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                                                      |
| ACTIVE      | 激活态       | 仅当“操作类型”参数取值为“ADD”、“MOD”和“ACTIVE_ALL”时该参数有效。用于标识是否激活MMINT业务。 取值范围： TRUE：激活。FALSE：不激活。 缺省值：TRUE。                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

1. 为网络中的单个用户签约MMINT业务，“IMSI”为“1234567”，“操作类型”为“ADD”，“DP点”为“12”，“SCP地址”为“1111”，“业务键”值为“12”：

```
MOD EMMIN: IMSI="1234567", PROV=ADD, DP=12, SCPADDR="1111", SK=12;
```

2. 为网络中3个连续号码的用户签约MMINT业务，“IMSI”分别为“1234567”、“1234568”和“1234569”，“操作类型”为“ADD”，“DP点”为“12”，“SCP地址”为“1111”，“业务键”值为“12”：

```
MOD EMMIN: IMSI="1234567", RECORDCOUNT=3, PROV=ADD, DP=12, SCPADDR="1111", SK=12;
```

3、为网络中3个非连续号码的用户签约MMINT业务，“IMSI”分别为“1234567”、“1234569”和“1234571”，“操作类型”为“ADD”，“DP点”为“12”，“SCP地址”为“1111”，“业务键”值为“12”，用户信息已保存在“MSISDN文件名”为“modemmin.txt”的文件中，并通过文件管理功能上传到指定目录：

```
MOD EMMIN: ISDNFILE="modemmin.txt", PROV=ADD, DP=12, SCPADDR="1111", SK=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                     | 处理建议                                                                              |
|:--------|:-----------|:-------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
| ERR1010 | 参数冲突       | 用户输入参数时同时输入“IMSI”或“MSISDN”或“IMSI文件名”或“MSISDN文件名”参数中的两个或多个。               | 重新输入“IMSI”或“MSISDN”或“IMSI文件名”或“MSISDN文件名”参数，保证其只存在一个。                             |
| ERR1004 | 参数值无效      | 用户输入的“IMSI”或“MSISDN”或“用户个数”或“IMSI文件名”或“MSISDN文件名”或“DP点”或“业务键”的参数值超出取值范围。 | 重新输入“IMSI”或“MSISDN”或“用户个数”或“IMSI文件名”或“MSISDN文件名”或“DP点”或“业务键”取值范围内的参数值。            |
| ERR3001 | 用户未开户      | 输入的“IMSI”或“MSISDN”或“IMSI文件名”或“MSISDN文件名”参数对应的用户未在网络中存在。                  | 重新输入网络中已存在的用户信息，可以使用LST EMMIN命令查询。                                                |
| ERR1009 | 参数丢失       | 用户没有输入“IMSI”或“MSISDN”或“IMSI文件名”或“MSISDN文件名”参数。                           | 重新输入“IMSI”或“MSISDN”或“IMSI文件名”或“MSISDN文件名”参数，保证其唯一性和存在性。                           |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                         | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                    | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                      |
