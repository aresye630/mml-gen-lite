# 修改用户全局计费特性(MOD CCGLOBAL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改用户全局计费特性。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                          |
|:---------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI      | 用于标识待修改用户全局计费特性的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                      |
| ISDN           | MSISDN    | 用于标识待修改用户全局计费特性的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                    |
| RECORDCOUNT    | 用户个数      | 用于标识待修改用户全局计费特性的用户数目。 当需要为连续号码的多个用户修改用户全局计费特性时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改用户全局计费特性。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行修改用户全局计费特性，当只有一个用户时，该参数不必配置。当一次修改用户全局计费特性的用户个数很多时，对系统性能无影响，但修改用户全局计费特性的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                                                        |
| IMSIFILE       | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待修改用户全局计费特性的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modccglobal.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                                                                                                                         |
| ISDNFILE       | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待修改用户全局计费特性的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modccglobal.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                                                                                                                   |
| CHARGE_GLOBAL  | 全局计费特性    | 用于标识计费特性，实现计费控制的两种方式之一，需要在网络规划的时候决定的。针对所有PDP/PDN类型。 取值范围： NONE：不签约计费特性。HOT：热计费，实时计费。FLAT：平计费。PREPAID：预付费用户。NORMAL：普通用户。3：热计费和平计费。5：热计费和预付费。6：平计费和预付费。7：热计费、平计费和预付费。9：热计费和普通计费。10：平计费和普通计费。11：热计费、平计费和普通计费。12：预付费和普通计费。13：热计费、预付费和普通计费。14：平计费、预付费和普通计费。15：热计费、平计费、预付费和普通计费。16～254：为自定义全局计费特性。 默认值：无。 说明：建议设置为NORMAL。“全局计费特性”和“标准全局计费特性”只能存在一个。 |
| SCHARGE_GLOBAL | 标准全局计费特性  | 用于标识标准全局计费特性，实现计费控制的两种方式之一，需要在网络规划的时候决定的。针对所有PDP/PDN类型。 取值范围：0000～FFFF 默认值：无。 说明：“全局计费特性”和“标准全局计费特性”只能存在一个。                                                                                                                                                                                                                                   |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户修改全局计费特性。

   ```
   MOD CCGLOBAL: IMSI="460000009123456", CHARGE_GLOBAL=NORMAL;
   ```
2. 修改第一个IMSI号码为“460000009123456”的连续5个用户的全局计费特性。

   ```
   MOD CCGLOBAL: IMSI="460000009123456", RECORDCOUNT=5, CHARGE_GLOBAL=NORMAL;
   ```
3. 修改“IMSIFILE”为“mod\_ccglobal.txt”的用户的全局计费特性。

   ```
   MOD CCGLOBAL: IMSIFILE="mod_ccglobal.txt", CHARGE_GLOBAL=NORMAL;
   ```
