# 查询IMS签约信息(LST HSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询用户签约数据信息，一次只能查询一个“SUBID”下的数据。

## 注意事项

- “SUBID”、“IMPI”、“IMPU”三个参数必须存在且只能存在一个。
- 系统将根据输入的“SUBID”、“IMPI”、“IMPU”三个条件中的任意一个查询其所对应IMS签约用户下的所有数据信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| SUBID  | SUBID  | 用于指示系统需要按照哪个SUBID来查询一个签约用户数据。一次只能查询一个签约用户数据记录，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                              |
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询一个签约用户数据。一次只能查询一个签约用户数据记录，要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。              |
| IMPU   | IMPU   | 用于指示系统需要按照哪个IMPU来查询一个签约用户数据。一次只能查询一个签约用户数据记录，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。 |

## 使用实例

查询IMS签约信息，“SUBID”为“1”：

```
LST HSUB: SUBID="1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，以下列出的是未包含在本命令输入参数中的输出项，其他输出项的详细说明请参见参数说明。

| 输出项名称    | 输出项解释                                                                                   |
|:---------|:----------------------------------------------------------------------------------------|
| SHARED   | 用于显示用户的共享属性。 “0”：指该IMPU不是共享IMPU。“1”：指该IMPU是共享IMPU。                                      |
| IRSID    | 用于显示用户的隐式注册集ID，“0”表示该IMPU不属于任何隐式注册集。                                                    |
| ALIASID  | 用于显示别名组ID，“0”表示该IMPU不属于任何别名组。                                                           |
| DEFIMPU  | 用于显示该IMPU是否为默认IMPU。 “0”：指该IMPU不是默认IMPU。“1”：指该IMPU是默认IMPU。 当IMPU不属于任何隐式注册集时，该参数的值固定为“0”。 |
| IMPUTYPE | 用于显示该IMPU的类型。 “1”：指该IMPU是精确IMPU。“2”：指该IMPU是通配IMPU。                                      |
| SYSNO    | 用于标识一个IMS签约用户属于哪个虚拟HSS。                                                                 |
