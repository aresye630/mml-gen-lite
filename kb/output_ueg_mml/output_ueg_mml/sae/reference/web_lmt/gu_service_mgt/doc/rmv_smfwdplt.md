# 删除短消息转发平台地址(RMV SMFWDPLT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除SMS Forwarding业务的短消息转发平台地址信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                         |
|:----------|:----------|:---------------------------------------------|
| HLRSN     | HLR序列号    | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 |
| SMFWDPLAT | 短消息转发平台地址 | 用于指示系统需要删除哪个短消息转发平台地址。 说明：此参数为必选。            |

## 使用实例

要删除一条短消息转发平台地址列表，“HLR序列号”为“1”，“短消息转发平台地址”为“1234567891”：

```
RMV SMFWDPLT: HLRSN=1, SMFWDPLAT="1234567891";
```
