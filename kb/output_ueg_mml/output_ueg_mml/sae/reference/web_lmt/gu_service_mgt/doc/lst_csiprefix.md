# 查询CSI前缀号码匹配(LST CSIPREFIX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用来查询ISDN或IMSI号码前缀和UCSI模板的对应关系。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                         |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号 | HLR序列号。 取值范围：1～255。 说明：必选参数，在PGW支持容灾功能或虚拟HLR功能时设置。                                                           |
| PREFIXNUM | 号码前缀   | ISDN或IMSI号码前缀。 取值范围：1～15位十进制数字组成的字符串。 说明：可选参数。如果未带号码前缀，则查询该HLR下的所有号码前缀和UCSI模板的对应关系。否则，只查询指定号码前缀和UCSI模板的对应关系。 |

## 使用实例

查询号码前缀为"234"的UCSI模板对应关系。例如：

LST CSIPREFIX: HLRSN=1, PREFIXNUM="234";
