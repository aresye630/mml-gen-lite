# 增加K2(ADD K2)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于在HSS/HLR中增加K2密钥。

当需要对**ADD KI**中的“KI值”进行K2加密时，需要提前通过该命令增加K2密钥。

## 注意事项

- K2密钥添加成功后，请使用**CHK K2**命令校验“K2值”。
- “K2密钥输入方式”三种取值方式的说明如下：
  - “K2密钥输入方式”为“ClearKey”或“Ciphertxt”时，参数“K2值”为必选参数。
  - “K2密钥输入方式”为“6EyesRule”时, K2密钥输入使用六眼法则。即K2由三部分组成，三部分长度合计32位或64位。每部分由不同的操作人员输入，并且每部分输入两遍。如果两次输入不等，会弹出提示框提示“K2密钥的第1/2/3部分输入不一致，请重新输入”，请用户重新输入密钥。
  - “K2密钥输入方式”为“6EyesRule”时，参数“K2第一部分取值”、“K2第一部分取值确认”、“K2第二部分取值”、“K2第二部分取值确认”、“K2第三部分取值”和“K2第三部分取值确认”为必选参数。
  - “K2密钥输入方式”为“GenOnHSM”时，“HSM密钥索引”参数为必选参数，表示由HSM生成K2密钥。
  - “K2密钥输入方式”为“Ciphertxt”时，不携带参数“K7序列号”。
- “算法类型”为“AES128”，K2值必须为32位；“算法类型”为“AES256”，K2值必须为64位。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“ERR4086 随机密钥默认ID未设置”。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                            |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号     | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                       |
| K2SNO       | K2序列号      | 用于标识K2序列号。 取值范围：1～254。 默认值：无。                                                                                                                                                                                                                                                                                                                                                   |
| KEYNAME     | K2名称       | 用于标识K2密钥名称。 取值范围：1位～60位的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                             |
| KEYTYPE     | K2密钥输入方式   | 用于标识K2密钥输入方式。 ClearKey：明文。6EyesRule：六眼法则。K2密钥值由三部分组成，三部分长度合计32位或64位，每部分为十六进制数字组成的字符串。每部分由不同的操作人员输入，并且每部分输入两遍。如果两次输入不等，会弹出提示框提示“K2密钥的第1/2/3部分输入不一致，请重新输入”，请用户重新输入密钥。GenOnHSM：由HSM生成K2密钥。Ciphertxt：密文。GenRAND：内部随机生成。 默认值：ClearKey。 配置原则：该参数取值为“GenRAND”时，SET MAPCONF命令的“是否启用随机密钥”参数取值必须为“TRUE”并且SET MAPSERV命令的“SAE-HSS AES加密模式”参数取值必须为“CBC”，否则本命执行失败，并返回“ERR3111 系统不支持该特性”的错误提示。 |
| HSMKEYINDEX | HSM密钥索引    | 用于标识HSM上的密钥索引，在HSM上导入密钥后，把对应的HSM密钥索引添加到UDM。 取值范围：5位～60位的字符串。 默认值：无。 配置原则：当本命令中的“K2密钥输入方式”参数为“GenOnHSM”时该参数必选。该参数由组名称+参数名称+ID组成，中间使用“:”分开：组名称和参数名称为字符串形式，且不为空，分别对应导入密钥时的Object group和Object name参数；ID为十进制数字，取值范围是0～2147483647，对应导入密钥时的Object specifier参数。例如：mnts:myParam:1。该参数取值包含字母时，字母区分大小写。                                                                                   |
| K2VALUE     | K2值        | 用于标识K2密钥值。 取值范围：32位或64位的十六进制数字组成的字符串。 默认值：无。 配置原则：“K2密钥输入方式”参数取值为“ClearKey”或“Ciphertxt”时，该参数必选。“K2密钥输入方式”参数取“Ciphertxt”时，本参数取值为32位十六进制数字组成的字符串；“K2密钥输入方式”参数取其他值时，本参数取值为32位或64位的十六进制数字组成的字符串。                                                                                                                                                                                    |
| K7SNO       | K7序列号      | 仅当本命令中的“K2密钥输入方式”参数为“ClearKey”或“6EyesRule”时该参数有效。用于标识对K2进行AES加密的K7序列号。该参数必须先由ADD K7命令定义，然后才能在此处引用。 取值范围：1～10。 默认值：无。                                                                                                                                                                                                                                                            |
| KEYPART1    | K2第一部分取值   | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第一部分取值。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                          |
| KEYPART1CNF | K2第一部分取值确认 | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第一部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                        |
| KEYPART2    | K2第二部分取值   | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第二部分取值。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                          |
| KEYPART2CNF | K2第二部分取值确认 | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第二部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                        |
| KEYPART3    | K2第三部分取值   | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第三部分取值。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                          |
| KEYPART3CNF | K2第三部分取值确认 | 仅当本命令中的“K2密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K2密钥第三部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                        |
| ALGTYPE     | 算法类型       | 仅当本命令中的“K2密钥输入方式”参数为“ClearKey”、“6EyesRule”或“GenRAND”时该参数有效。用于标识K2值的加密算法类型。 AES128：K2值为32位的十六进制数字组成的字符串。AES256：K2值为64位的十六进制数字组成的字符串。 默认值：AES128。                                                                                                                                                                                                                                 |

## 使用实例

1. 在HSS/HLR中添加K2。“HLR序列号”为“1”，“K2序列号”为“1”，“K2值”为“1234567890abcde1234567890abcde12”：

   ```
   ADD K2: HLRSN=1, K2SNO=1, KEYTYPE=ClearKey, K2VALUE="*****";
   ```
2. 在HSS/HLR中添加K2。“HLR序列号”为“1”，“K2序列号”为“1”，“K2值”为“1234567890abcde1234567890abcde12”,“K7序列号”为“2”：

   ```
   ADD K2: HLRSN=1, K2SNO=1, KEYTYPE=ClearKey, K2VALUE="*****", K7SNO=2;
   ```
3. 在HSS/HLR中添加K2。“HLR序列号”为“1”，“K2序列号”为“1”，“K2密钥输入方式”为“6EyesRule”，“K7序列号”为“2”，“K2第一部分取值”为“1234567890a”,“K2第一部分取值确认”为“1234567890a”,“K2第二部分取值”为“bcde1234567”，“K2第二部分取值确认”为“bcde1234567”，“K2第三部分取值”为“890abcde12”，“K2第三部分取值确认”为“890abcde12”：

   ```
   ADD K2: HLRSN=1, K2SNO=1, KEYTYPE=6EyesRule, K7SNO=2, KEYPART1="*****", KEYPART1CNF="*****", KEYPART2="*****", KEYPART2CNF="*****", KEYPART3="*****", KEYPART3CNF="*****";
   ```
4. 在HSS/HLR中添加K2。“HLR序列号”为“1”，“K2序列号”为“1”，“K2密钥输入方式”为“GenOnHSM”，“K7序列号”为“2”：

   ```
   ADD K2: HLRSN=1, K2SNO=1, KEYTYPE=GenOnHSM, K7SNO=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR3372 | 密钥的总长度不正确   | 可能原因如下： 选择的“算法类型”是“AES128”，K2值是64位。选择的“算法类型”是“AES256”，K2值是32位。                                                                            | 参数输入必须遵循以下规则：选择的“算法类型”是“AES128”，“K2第一部分取值”、“K2第二部分取值”和“K2第三部分取值”合起来的取值为32位。选择的“算法类型”是“AES256”，“K2第一部分取值”、“K2第二部分取值”和“K2第三部分取值”合起来的取值为64位。 |
| ERR1004 | 无效的参数值      | “K2密钥输入方式”是“ClearKey”且“算法类型”是“AES128”，输入的“K2值”不是32位。“K2密钥输入方式”是“ClearKey”且“算法类型”是“AES256”，输入的“K2值”不是64位。输入的“HSM密钥索引”参数值不在取值范围内或不符合参数配置原则。 | “算法类型”是“AES128”，重新输入32位的K2值。“算法类型”是“AES256”，重新输入64位的K2值。重新输入“HSM密钥索引”参数，确保其值在参数取值范围内，且符合配置原则。                                             |
