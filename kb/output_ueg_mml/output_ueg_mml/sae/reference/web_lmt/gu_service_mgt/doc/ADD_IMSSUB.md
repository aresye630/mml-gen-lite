# 增加IMS用户(ADD IMSSUB)

- 命令功能

## 命令功能

该命令用于为GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户签约IMS业务数据。

GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户可直接通过本命令签约IMS业务，不需要换卡。用户执行该命令后，系统会更新用户在数据库中的数据。当用户进行位置更新时，IMS-HSS将用户的IMS业务数据下发给MME。

## 注意事项

- “IMSI”和“MSISDN”是可选参数，必须有且只能有一个参数出现。
- 执行该命令前确保用户已开户，可以通过**LST SUB**命令查询。
- 在混合组网环境执行该命令，若IMPI已存在，系统提示IMPI已与其它用户关联。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时需要注意：
  - 引用用户签约的“HLR序列号”下的计费模板、拜访网络地址模板及共享iFC模板。
  - 本命令的“HLR序列号”与签约IMS用户模板对应的“HLR序列号”要一致。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                    |
|:------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号      | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                                                                                                                                                                                                                                 |
| IMSI        | IMSI        | 用于标识待增加IMS用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                      |
| ISDN        | MSISDN      | 用于标识待增加IMS用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                    |
| IMPI        | IMPI        | 用于标识待增加IMS用户的IMPI值。 取值范围：1～127位字符串。 默认值：无。 说明：输入的IMPI值应符合NAI（Network Access Identifier）格式，字母区分大小写。有效格式为：用户名＋“@”＋域名。如username@huawei.com。输入的IMPI未增加过鉴权信息，为新增的IMPI记录。IMPI是否增加过鉴权信息可通过LST HAUTHINF命令查询。                                                                                                                                                                                    |
| IMPULIST    | IMPU列表      | 用于标识要添加的IMPU的值。 取值范围：1～1300位字符串。 默认值：无。 配置原则：由1到10个IMPU以“&”连接组成，在字符“"”前需要添加转义字符“\”。例如：\"sip:impuinfo1@huawei.com\"&\"sip:impuinfo2@huawei.com\"。输入的IMPU值应符合SIP URI或TEL URI格式，字母区分大小写。 说明：输入的IMPU为非通配型。通配IMPU和非通配IMPU内容请参见《特性文档 > 特性（IMS网络） > IMS-HSS业务 >通配IMPU功能 > 特性描述》 。一个用户可以签约多个IMPU，系统将这些IMPU设置到同一个隐式注册集，“隐式注册集ID”默认为“1”，将所有的IMPU都设置到同一个别名组下，“IMPU别名组ID”默认为“1”。该参数中的首个IMPU为默认IMPU。 |
| BARIMPULIST | 闭锁的IMPU列表   | 用于标识要闭锁的IMPU的值。 取值范围：1～1300位字符串。 默认值：无。 配置原则：由1到10个IMPU以“&”连接组成，在字符“"”前需要添加转义字符“\”。例如：\"sip:impuinfo1@huawei.com\"&\"sip:impuinfo2@huawei.com\"。输入的IMPU值应符合SIP URI或TEL URI格式，字母区分大小写。 说明：输入的IMPU为非通配型，包含在“IMPU列表”中，并且被闭锁的IMPU不能为默认IMPU。                                                                                                                                                 |
| VOLTETAG    | VoLTE用户标志   | 用于标识待增加IMS用户是否是VoLTE用户。 取值范围：TRUE：VoLTE用户。FALSE：非VoLTE用户。 默认值：无。                                                                                                                                                                                                                                                                                                                        |
| CHARGTPLID  | 计费模板ID      | 用于标识新增IMPI的计费地址模板，该模板必须先由ADD HCHGTPL命令定义，然后才能在此处引用。 取值范围：0~1024 默认值：无。 配置原则：ADD HCHGTPL命令中“计费地址模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003243：计费地址模板ID不存在”错误提示。                                                                                                                                                                                                                |
| MCAP        | 必选能力集       | 用于标识待增加IMS用户的必选能力集。 取值范围：1～352位由十进制数字和“&”组成的字符串。该参数是1到32个用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。例如1&2，取值代表能力，是由运营商统一规划的。 默认值：无。                                                                                                                                                                                                                                             |
| OCAP        | 可选能力集       | 用于标识待增加IMS用户的可选能力集。 取值范围：1～352位由十进制数字和“&”组成的字符串。该参数是1到32个用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。例如1&2，取值代表能力，是由运营商统一规划的。 默认值：无。                                                                                                                                                                                                                                             |
| SCSCFLIST   | S-CSCF名称列表  | 用于标识用户能力集的S-CSCF的名称集合，可以由1到5个S-CSCF名称组成，每个S-CSCF名称不超过127个字符，不同的S-CSCF的名称以“&”符连接，在字符“"”前需要添加转义字符“\”。例如：\"sip:scscf1.huawei.com\"&\"sip:scscf2.huawei.com\"。 取值范围：1～649位字符串。 默认值：无。                                                                                                                                                                                                       |
| MEDIAID     | 签约媒体ID      | 用于标识签约媒体ID值。 取值范围：0～4294967295。当该参数取值为“4294967295”时，表示去掉此IMPU关联的Service Profile的签约媒体ID信息。 默认值：无。                                                                                                                                                                                                                                                                                        |
| VNTPLID     | 拜访网络地址模板ID  | 用于标识一个漫游地址ID。该参数必须先由ADD HVNTPL命令定义，然后才能在此处引用。 取值范围：0~1024 默认值：无。 配置原则：ADD HVNTPL命令中“拜访网络模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003245：拜访网络模板ID不存在”错误提示。                                                                                                                                                                                                                       |
| SIFCLIST    | 共享iFC模板ID列表 | 用于标识共享iFC模板ID列表。 取值范围：1～192位由十进制数字和“&”组成的字符串。该参数是共享iFC模板ID用“&”连接起来的集合，集合中的共享iFC模板ID不允许重复并且至少要存在一个，最多不超过32个。共享iFC模板ID可以通过ADD HSIFCTPL命令增加。                                                                                                                                                                                                                                               |
| STNSR       | SRVCC会话传输号码 | 用于标识一个STNSR（Session Transfer Number for SRVCC）号码。 取值范围：3～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                        |

## 使用实例

为已经开户的用户签约IMS业务数据，参数取值如表1所示。

| 参数     | 值                                                                |
|:-------|:-----------------------------------------------------------------|
| HLR序列号 | 1                                                                |
| IMSI   | 460030913121001                                                  |
| IMPI   | +86460030913121001@huawei.com                                    |
| IMPU列表 | \"sip:+86460030913121001@huawei.com\"&\"tel:+86460030913121001\" |

```
ADD IMSSUB: HLRSN=1, IMSI="460030913121001", IMPI="+86460030913121001@huawei.com", IMPULIST="\"sip:+86460030913121001@huawei.com\"&\"tel:+86460030913121001\"";
```
