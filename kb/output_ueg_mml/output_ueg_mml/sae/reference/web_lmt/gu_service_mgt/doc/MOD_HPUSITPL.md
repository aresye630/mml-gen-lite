# 修改PUSI基本信息模板(MOD HPUSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该操作用于在HSS的业务数据库中修改一个PUSI基本信息模板，在该操作中系统通过PUSI模板ID来唯一标识一条PUSI基本信息模板记录，可以修改除模板ID外的所有参数。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                            |
|:---------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID    | PUSI模板ID  | 可选必选说明：必选参数 参数含义：标识一个PUSI基本信息模板记录的关键字段，用于指定需要修改的PUSI基本信息模板的序号，操作员可以使用LST HTPLINF操作查询获得。 取值范围：0-254 缺省值：无                                                                        |
| TPLNAME  | PUSI模板名称  | 可选必选说明：可选参数 参数含义：该参数用于具体描述一个PUSI基本信息模板，以便于识别。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 缺省值：无                                                                                   |
| AS       | PUSI的AS地址 | 可选必选说明：可选参数 参数含义：HSS与对端网元（AS）对接的参数之一，用于指定PUSI需要用到的对端网元的地址，地址格式必须为SIP格式。需要和对端网元配置的地址协商一致，若不一致，HSS将无法于完成发往对端网元的业务处理。 取值范围：长度不超过127的字符串 缺省值：无                                      |
| BAR      | 闭锁标志      | 可选必选说明：可选参数 参数含义：指定PUSI的闭锁状态（闭锁状态用于指定是否允许该用户进行呼叫）。 取值范围： FALSE(False)：解除闭锁TRUE(TRUE)：闭锁 缺省值：无                                                                                   |
| ACTSTATE | 激活状态      | 可选必选说明：可选参数 参数含义：指定PUSI的激活状态（激活状态用于指定用户开户后是否已经激活）。 取值范围： FALSE(False)：未激活 TRUE(TRUE)：激活 缺省值：无                                                                                   |
| SERPRVID | 服务提供商标识   | 可选必选说明：可选参数 参数含义：指定的Service Provider ID(服务提供商标识) 取值范围：长度不超过39的字符串 缺省值：无                                                                                                         |
| LRI      | 松路由指示信息   | 可选必选说明：可选参数 参数含义：指定PUSI是否签约松路由指示。不指定该参数表示去签约松路由指示。 取值范围： LOOSE_ROUTE_NOT_REQUIRED(LOOSE_ROUTE_NOT_REQUIRED)：去签约松路由指示。LOOSE_ROUTE_REQUIRED(LOOSE_ROUTE_REQUIRED)：签约松路由指示。 缺省值： 无 |
| COMMENT  | 模板注释说明    | 可选必选说明：可选参数 参数含义：该参数用于具体描述一个PUSI基本信息模板的注释信息，以便于理解和使用。 取值范围： 长度不超过512的字符串 缺省值：无                                                                                                  |

## 使用实例

修改PUSI基本信息模板。PUSI模板ID：10，PUSI模板名称：Modify a PUSI Template。

```
MOD HPUSITPL: TPLID=10, TPLNAME="Modify a PUSI Template";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                                                                  | 处理建议                                                                                                                  |
|----------:|:--------|:------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------|
| 900001008 | 参数不足    | 可能原因为如下之一： 参数“PUSI模板ID”没有输入。参数“PUSI模板名称”、“PUSI的AS地址”、“闭锁标志”、“激活状态”、“服务提供商标识”、“松路由指示信息”、“模板注释说明”都没有输入。 | 根据实际情况，重新输入参数，确保满足以下两点： 必须输入“PUSI模板ID”参数。参数“PUSI模板名称”、“PUSI的AS地址”、“闭锁标志”、“激活状态”、“服务提供商标识”、“松路由指示信息”、“模板注释说明”必须至少输入一个。 |
