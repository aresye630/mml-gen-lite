# 删除SOAP报文格式(RMV SOAPFORMAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致SOAP通知消息发送失败，因此执行该命令前需要确认此配置是否正在被使用。

该命令用于删除UDM发送给业务发放系统的通知消息里SOAP报文格式的配置信息。

## 注意事项

该命令执行不当会导致SOAP通知消息发送失败，因此执行该命令前需要确认对应配置是否正在被使用。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                      |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 可选必选说明：必选参数 参数含义：标识一条SOAP报文格式配置信息的关键字段之一，用于指定在哪个HLR上删除SOAP报文格式的配置信息。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无。 配置原则：无。                                                                                                                                                                                             |
| MSGTYPE | 消息类型   | 可选必选说明：必选参数 参数含义：标识一条SOAP报文格式配置信息的关键字段之一，用于指定删除哪种消息类型的SOAP报文格式的配置信息。 取值范围：AUTOPRV：自动开户的通知消息。 OUTROAM：用户漫游出国的通知消息，表示用户从国内（包含国内本网和国内跨网）漫游到国际（包含国际跨网和国际本网）时下发的SOAP订阅通知消息格式。 INROAM：用户漫游回国的通知消息，表示用户从国际（包含国际跨网和国际本网）漫游回国内（包含国内本网和国内跨网）时下发的SOAP订阅通知消息格式。 5GAUTOPROV：5G自动开户的通知消息。VOLTEAUTOPROVCUS：定制的Volte自开通消息。 默认值：无。 配置原则：无。 |
| ISFORCE | 是否强制删除 | 可选必选说明：可选参数 参数含义：标识是否强制删除SOAP报文格式的配置信息。 NO：不强制删除SOAPFORMAT配置，系统会判断对应的配置信息是否正在被使用，当配置信息可能正在被使用时，执行该命令会删除失败。 YES：强制删除SOAPFORMAT配置，无论对应的配置信息是否正在被使用，系统都会强制删除。 默认值：NO 配置原则：当该参数配置为“YES”时，执行该命令可能会导致SOAP通知消息发送失败。请操作员在执行该操作之前仔细确认此配置是否正在被使用。                                                                                   |

## 使用实例

删除“HLR序列号”为“1”、“消息类型”为“AUTOPRV”的所有SOAP报文格式配置信息：

```
RMV SOAPFORMAT: HLRSN=1, MSGTYPE=AUTOPRV;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                                                                                                                                                                                                                                                                                                                        | 处理建议                                                                                               |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在     | 可能原因为如下之一：“HLR序列号”未定义。 “HLR序列号”和“消息类型”对应的SOAP报文格式配置信息不存在。                                                                                                                                                                                                                                                                                                                   | 根据实际情况，重新输入已定义的“HLR序列号”或“消息类型”，可通过LST HLRSN命令查询已定义的“HLR序列号”、通过LST SOAPFORMAT命令查询已经定义的SOAP报文格式配置信息。 |
| ERR4181 | 配置可能正在使用。 | 原因为如下之一： 当“消息类型”取值为“OUTROAM”或“INROAM”时，SET MAPCONF命令中软参“是否支持CS域漫游状态发生变化时触发订阅通知”取值为“TRUE”，说明此配置可能正在使用。当“消息类型”取值为“VOLTEAUTOPROVCUS”或“AUTOPRV”时，SET MAPSERV命令中软参“LTE/VoLTE自动开户后通知BOSS系统的SOAP消息报文格式”取值为“MODE5”，说明此配置可能正在使用。当“消息类型”取值为“5GAUTOPROV”时，SET UDMSERV命令中软参满足以下条件说明此配置可能正在使用：“是否启用5G自动开户特性”取值为“TRUE”。“5G自动开户通知BOSS系统的SOAP消息报文格式”取值为“MODE1”。“5G自动开户方式”取值为“NOTIFY”或“ALL”。 | 根据原因分析中原因确认此配置是否可能正在使用。                                                                            |
