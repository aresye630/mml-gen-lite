# 删除AMF(RMV AMF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中删除一条指定AMF序列号的AMF鉴权信息。

在该命令中，系统通过以下关键参数的组合来唯一标识一条AMF鉴权管理域信息：

- “HLR序列号”
- “AMF序列号”

## 注意事项

当AMF鉴权信息已经通过**ADD KI**命令给用户绑定时，无法通过该命令删除相应AMF鉴权信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识待删除的AMF鉴权数据所在的HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                           |
| AMFSNO | AMF序列号 | 用于标识待删除的AMF鉴权数据在系统中的序号。 取值范围：3～65535 默认值：无。 说明：“AMF序列号”取1和2的两条记录为系统初始设置，对应的AMF值为0x724C，这两条记录不允许删除。 |

## 使用实例

删除一条“HLR序列号”为“1”，“AMF序列号”为“3”的AMF鉴权管理域信息：

```
RMV AMF: HLRSN=1, AMFSNO=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                      | 处理建议                                                                                                         |
|:--------|:----------|:------------------------------------------|:-------------------------------------------------------------------------------------------------------------|
| ERR4000 | AMF被使用    | 对应“AMF序列号”的AMF鉴权数据已通过ADD KI等命令为用户绑定，无法删除。 | 不允许删除已被使用的AMF鉴权信息。                                                                                           |
| ERR4001 | AMF序列号未定义 | 参数“AMF序列号”的取值没有预先通过ADD AMF定义。             | 执行LST AMF命令查询数据库中已存在的AMF鉴权数据，检查需要删除的AMF鉴权信息是否存在，如不存在则无需处理，如存在，但“AMF序列号”和输入不一致，则根据查询结果，重新设置“AMF序列号”删除AMF鉴权数据。 |
