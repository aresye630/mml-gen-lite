## 命令功能

**须知** 

本命令属于高危命令，执行不当会使PUSSD消息处理失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加USSD（Unstructured Supplementary Service Data）控制数据。主要包括：

- 定义非结构化补充业务数据的业务码，用来标识用户不同的操作请求。
- 定义非结构化补充业务数据的类型，用来标识不同的控制数据。

当需要为用户开通USSD业务时，必须先在HLR上执行该命令配置USSD控制数据。

## 注意事项

- 如果将本命令中的参数“USSD类型”的值设为“VLRWSM”或“SGSNWSM”时，则参数“业务码”的取值必须是6位字符。当参数“USSD类型”的值设为“VLRWSM”时建议参数“业务码”的值设为“010400”，当参数“USSD类型”的值设为“SGSNWSM”时建议参数“业务码”的值设为“010401”。
- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的USSD控制数据记录数不能超过1000条。

## 使用实例

在“HLR序列号”为“1”的HLR上，添加USSD控制数据类型为“WAP方式前转到USSD中心”，明确其中的业务码为特殊码，并使得其中的业务码按照最大匹配的原则进行匹配。其中，“业务码”为“168”，“前转设备号码”为“86123999”，“是否是特殊码”为“TRUE”，“业务码匹配原则”为“MAX\_MATCH”：

```
ADD USSDDAT: HLRSN=1, SRCODE="168", FUNCTION=WAPMODE, FWDADD="86123999", SPECIFIC=TRUE, MATCH_RULE=MAX_MATCH;
```
