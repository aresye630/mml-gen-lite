# 增加5G SMDATA模板(ADD SMDATATPL)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于在数据库中增加5G会话信息模板数据记录。

该命令的使用场景：在配置5GS用户模板前，需要先配置会话信息模板。

该命令的参数关系索引图如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 系统最大支持添加20000个5G会话信息模板。
- 5G会话信息模板包含S-NSSAI和DNN数据，其中S-NSSAI数据最多添加16个，DNN数据最多添加50个。

## 参数说明

| 参数标识                 | 参数名称           | 参数说明                                                                                                                                                                                                                      |
|:---------------------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN                | HLR序列号         | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无 配置原则：无                                                                                                                                     |
| TPLID                | 模板ID           | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。该参数在系统中唯一，不能重复。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                          |
| TPLNAME              | 模板名            | 可选必选说明：可选参数 参数含义：用于标识5G会话信息模板在系统中的名称。 取值范围：1～60位字符串。 默认值：无 配置原则：无                                                                                                                                                         |
| SNSSAI               | 切片标识           | 可选必选说明：必选参数 参数含义：用于标识5G系统中的网络切片，由SST(Slice/Service Type)与SD(Slice Differentiator)组成。 取值范围：1～10位字符串。 SST为取值范围是0～255的数字；SD是固定长度为3字节的十六进制字符串。SST与SD间使用“-”连接。 例如：当SST为1，SD为D143A5，则填写为1-D143A5；当SST为1，无SD，则填写为1。 默认值：无 配置原则：无 |
| DEFSNSSAI            | 是否默认S-NSSAI    | 可选必选说明：必选参数 参数含义：用于标识签约的S-NSSAI数据是否为默认S-NSSAI数据。 取值范围： TRUE：签约的S-NSSAI数据为默认S-NSSAI数据。FALSE：签约的S-NSSAI数据为非默认S-NSSAI数据。 默认值：无 配置原则：当该命令增加第一条S-NSSAI签约数据时，必须是默认S-NSSAI。该参数必须设置为“TRUE”。最大允许定义8个默认S-NSSAI。                     |
| DNN                  | 数据网名称          | 可选必选说明：必选参数 参数含义：用于标识数据网名称。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无 配置原则： 同一个S-NSSAI下增加的第一个DNN必须是默认DNN，且只允许定义一个默认DNN。单个S-NSSAI中最大允许包含50个DNN数据。所有S-NSSAI下包含的DNN数据总数也不超过50个。不允许将通配DNN配置为默认DNN，通配DNN即该参数取值为“*”的DNN。 |
| DNNQOSTPLID          | 5GS DNNQOS模板ID | 可选必选说明：必选参数 参数含义：用于标识引用的5GS DNNQOS模板的ID。该参数必须由ADD DNNQOSTPL命令定义后才能在此处引用。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                   |
| SUGGESTEDPACKETNUMDL | 建议的下行数据缓存包大小   | 可选必选说明：可选参数 参数含义：用于标识建议的下行数据缓存包大小。当网络设备向终端用户发送数据，发现终端用户不可达， 数据需要被缓存起来时，SMF可以使用该参数配置SMF/UPF或NEF中的缓存数据包大小。 取值范围：1～2147483647 默认值：无。 配置原则：无。                                                                                 |

## 使用实例

配置5GS用户模板前，需要先配置会话信息模板，用户再通过签约5GS用户模板给用户签约5G业务数据。

1. 增加一个5G会话信息模板。“HLR序列号”为“1”，“模板ID”为“1”，“切片标识”为“1-D143A5”，“是否默认S-NSSAI”为“TRUE”，“数据网名称”为“12543”，“5GS DNNQOS模板ID”为“2”：

   ```
   ADD SMDATATPL: HLRSN=1, TPLID=1, SNSSAI="1-D143A5", DEFSNSSAI=TRUE, DNN="12543", DNNQOSTPLID=2;
   ```
2. 增加一个5G会话信息模板。“HLR序列号”为“1”，“模板ID”为“3”，“切片标识”为“1-D143A5”，“是否默认S-NSSAI”为“TRUE”，“数据网名称”为“12543”，“5GS DNNQOS模板ID”为“1”：

   ```
   ADD SMDATATPL: HLRSN=1, TPLID=3, SNSSAI="1-D143A5", DEFSNSSAI=TRUE, DNN="12543", DNNQOSTPLID=1;
   ```
