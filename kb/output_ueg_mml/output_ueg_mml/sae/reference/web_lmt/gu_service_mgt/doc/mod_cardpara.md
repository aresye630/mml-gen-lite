# 修改卡参数(MOD CARDPARA)

## 命令功能

本操作用来修改用户的USIM/SIM卡参数。

如果指定的用户正在使用且正在漫游，HLR将发送一个cancel location的消息给该用户所在的VLR/SGSN，并删除VLR/SGSN中该用户的所有数据。

## 注意事项

- “IMSI”、“IMSI文件名”是条件可选参数，任何一个参数出现即可。“K4序列号”、“鉴权算法类型”、“卡类型”至少必须有一个出现，可以同时出现。
- “OP序列号”是可选参数，当“鉴权算法类型”为“MILENAGE”、“MILENAGE\_2”、“CUSTOM\_1”或“CUSTOM\_6”时，它才出现。
- “OP序列号”取值为“0”时，系统会把对应用户已存在的“OP序列号”清除，但如果系统中存在用户通过**ADD KI**签约的“OPC值”，则保留对应的“OPC值”。
- “OP序列号”取值不为“0”时，系统会清除对应用户通过**ADD KI**签约的“OPC值”。
- 如果用户的KI是通过GK2加密，系统不支持通过本命令修改用户的K4，否则执行本命令会报错“ERR4209:不支持的数据形态”。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI     | IMSI    | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| IMSIFILE | IMSI文件名 | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| K4SNO    | K4序列号   | K4序列号，值域为0～65535。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| CARDTYPE | 卡类型     | 卡类型。 SIM：采用GSM鉴权。USIM：采用UMTS鉴权。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ALG      | 鉴权算法类型  | 仅当本命令中的“卡类型”参数为“SIM”或“USIM”时该参数有效。用于标识鉴权算法类型。 取值范围： COMP128_1COMP128_2COMP128_3CUSTOM_1XORMILENAGEMILENAGE_2CAVE38CUSTOM_2CUSTOM_3CUSTOM_4CUSTOM_5CUSTOM_6CUSTOM_7CUSTOM_8CUSTOM_9 默认值： 当“卡类型”设置为“SIM”时，无默认值；当“卡类型”设置为“USIM”时，默认值为“MILENAGE”。 说明：当“卡类型”设置为“SIM”时，支持的算法类型包括：“COMP128_1”、“COMP128_2”、“COMP128_3”、“XOR”、“MILENAGE”、“MILENAGE_2”、“CAVE38”、“CUSTOM_2”、“CUSTOM_3”、“CUSTOM_4”、“CUSTOM_5”、“CUSTOM_7”、“CUSTOM_8”和“CUSTOM_9”； 当“卡类型”设置为“USIM”时，支持的算法类型包括:“CUSTOM_1”、“CUSTOM_6”、“CUSTOM_9”、“MILENAGE”和“MILENAGE_2”； “MILENAGE_2”与“MILENAGE”的区别在于将鉴权五元组的XRES转换为鉴权三元组的SRES时使用的算法不同。 COMP128_1、COMP128_2鉴权算法为不安全算法，建议使用更安全的鉴权算法。 |
| OPSNO    | OP序列号   | 仅当本命令参数中的“鉴权算法类型”为“MILENAGE”、“MILENAGE_2”、“CUSTOM_1”或“CUSTOM_6”时该参数有效。用于标识OP序列号。 取值范围：0～16777215。 默认值：无。 说明：该参数取值为“0”表示无OP数据被使用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| AMFSNO   | AMF序列号  | 仅当本命令参数中的“鉴权算法类型”为“MILENAGE”、“MILENAGE_2”、“CUSTOM_1”或“CUSTOM_6”时该参数有效。用于标识AMF序列号。 取值范围：1～65535。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## 使用实例

修改IMSI号码为946000000012345的用户的卡类型。命令如下：

MOD CARDPARA: IMSI="946000000012345", K4SNO=2, CARDTYPE =USIM, ALG=MILENAGE,OPSNO=1;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                  | 原因分析                                                                                   | 处理建议                                                                                         |
|:--------|:-----------------------|:---------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------|
| ERR1068 | 参数冲突检测失败               | 待修改用户开卡通过ADD KI只签约了“OP序列号”，而未签约“OPC值”时，输入的“OP序列号”取值为“0”。                               | 为避免“OP序列号”去签约导致用户鉴权失败，开卡时只签约了“OP序列号”而未签约“OPC值”的用户，无法通过本命令去签约“OP序列号”。                         |
| ERR4202 | 不支持修改HSM用户的卡类型、鉴权算法和K4 | 待修改的用户为HSM用户。                                                                          | 不支持修改HSM用户的卡参数。执行LST KI命令查询用户的“K2序列号”，然后执行LST K2命令查询“HSM密钥索引”，若“HSM密钥索引”不为空，则为HSM用户。         |
| ERR4203 | 不支持修改UDM用户的K4为HSM类型    | 待修改的用户类型为UDM，修改K4为HSM。                                                                 | 在用户签约的K4记录中查询“K4密钥输入方式”，确保用户类型为UDM时，K4不为HSM类型。                                               |
| ERR4199 | 默认的HSM鉴权参数ID不存在        | 待修改卡参数的用户为HSM用户且携带了“AMF序列号”参数时，SET UDMSERV命令“HSM鉴权时携带的鉴权参数ID”参数和ADD AMF命令配置的“参数ID”均无效。 | 待修改卡参数的用户为HSM用户且携带了“AMF序列号”参数时，输入SET UDMSERV命令“HSM鉴权时携带的鉴权参数ID”参数或执行MOD AMF修改“参数ID”后重新执行本命令。 |
| ERR4209 | 不支持的数据形态               | 如果用户的KI是通过GK2加密，系统不支持通过本命令修改用户的K4。                                                     | 软件不支持此能力。                                                                                    |
