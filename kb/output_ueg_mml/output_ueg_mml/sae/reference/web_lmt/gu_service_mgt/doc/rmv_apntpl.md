# 删除APN模板(RMV APNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于删除APN模板。

## 注意事项

如果该模板已经通过其他命令关联，例如**ADD EPSAPNQOSTPL**/**MOD EPSAPNQOSTPL**、**ADD PSAPNQOSTPL**/**MOD PSAPNQOSTPL**、**ADD OPTGPRSTPL**/**MOD OPTGPRSTPL**或**MOD OPTGPRS**命令，当执行该命令删除APN模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该APN模板不能被删除。如果要删除该APN模板，必须先执行关联命令的修改命令，例如**MOD EPSAPNQOSTPL**、**MOD PSAPNQOSTPL**、**MOD OPTGPRSTPL**或**MOD OPTGPRS**，去掉对应模板（例如EPS模板、PS模板）与APN模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| TPLID  | 模板ID   | 模板号，必选参数，0～65534。                        |

## 使用实例

删除2号APN模板数据。命令如下：

RMV APNTPL: HLRSN=1, TPLID=2;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                    | 处理建议                                                                                                                                                          |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”未定义或者“模板ID”未定义。                                                                                                                 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST APNTPL命令查询已定义的“模板ID”。                                                                       |
| ERR3005 | 模板已经被使用 | 待删除的APN模板已经通过执行其他命令被使用，例如ADD EPSAPNQOSTPL/MOD EPSAPNQOSTPL、ADD PSAPNQOSTPL/MOD PSAPNQOSTPL、ADD OPTGPRSTPL/MOD OPTGPRSTPL或MOD OPTGPRS命令。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，需要执行以下步骤： 执行关联命令的修改命令，例如MOD EPSAPNQOSTPL、MOD PSAPNQOSTPL、MOD OPTGPRSTPL或MOD OPTGPRS，去掉对应模板（例如EPS模板、PS模板）与APN模板的关联关系。执行该命令删除该APN模板。 |
