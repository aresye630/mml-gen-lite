# 删除VLR/SGSN漫游限制模板(RMV VSLIST)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，如果携带了参数漫游区域配置方式，执行不当会使签约该模板的用户数据被同步修改，影响在网用户业务体验。因此执行该命令前，请仔细检查配置的正确性，确认该配置方式的数据没有被使用后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于删除一条VLR/SGSN漫游限制模板数据。

## 注意事项

- 当执行该命令删除用户已签约的VLR/SGSN漫游限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该VLR/SGSN漫游限制模板不能被删除。如果要删除该VLR/SGSN漫游限制模板，必须先执行**MOD VSRR**命令给用户去签约相关的VLR/SGSN漫游限制模板。
- 当模板中存在VLR/SGSN号码前缀配置方式的数据，同时存在VLR/SGSN漫游区域模板配置方式的数据时，如果只删除其中一个的数据，则不能影响另一种配置方式的数据。如果模板中只存在一种配置方式的数据，并且是本次需要删除该配置方式的数据，则删除整个模板的记录；如果是删除另一种记录不存在的配置方式的数据，系统会提示“ERR3007 记录不存在”的错误信息。
- 当执行该命令时不携带参数“漫游区域配置方式”，则表示删除包括两种存储方式的整个模板数据。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                             |
|:-----------|:---------|:---------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 标识VLR/SGSN漫游限制数据记录的关键字段之一，用于指定在哪个HLR上删除VLR/SGSN漫游限制数据记录，操作员可以使用LST HLRSN命令查询获得。  |
| TPLID      | 模板ID     | 标识VLR/SGSN漫游限制数据记录的关键字段之一，用于指定需要删除哪个模板的VLR/SGSN漫游限制数据记录，操作员可以使用LST VSLIST命令查询获得。 |
| TPLTYPE    | 模板类型     | 标识VLR/SGSN漫游限制数据记录的关键字段之一，用于指定需要删除哪种模板类型的VLR/SGSN漫游限制数据记录。                       |
| VSAREATYPE | 漫游区域配置方式 | 标识VLR/SGSN漫游限制数据记录的关键字段之一，用于指定需要删除哪种配置方式的VLR/SGSN漫游限制数据记录。                       |

## 使用实例

删除“HLR序列号”为“1”的HLR上的VLR/SGSN漫游限制模板数据记录。其中，“模板号”为“1”，“模板类型”为“VLR”：

```
RMV VSLIST: HLRSN=1, TPLID=1, TPLTYPE=VLR;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                          | 处理建议                                                                                                     |
|:--------|:--------|:------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”和“模板ID”对应的区域漫游模板数据记录不存在。 “模板ID”和“模板类型”的匹配关系和数据库中实际存在的模板不一致。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST VSLIST命令查询已定义的“模板ID”和“模板类型”在数据库中的匹配关系。 |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                                                                     | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD VSRR命令给用户去签约该模板，然后才能执行RMV VSLIST命令删除。                                  |
| ERR3007 | 记录不存在   | 输入的“漫游区域配置方式”对应的记录不存在。                                                        | 根据实际情况，重新输入参数，确保输入的配置方式的数据是存在的，可通过LST VSLIST命令查询已存在的VLR/SGSN漫游限制数据。                                      |
