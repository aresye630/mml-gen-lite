# 删除OP(RMV OP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用来删除OP。

## 注意事项

如果CMCC鉴权增强开关打开，该命令不允许执行。可通过**LST MAPCONF**查看CMCC鉴权增强开关是否打开。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| OPSNO  | OP序列号  | OP序列号，值域为1～16777215。必选参数。                |

## 使用实例

删除OP，HLR序列号为1，OP序列号为1。命令如下：

RMV OP: HLRSN=1,OPSNO=1;
