# 查询计费地址模板(LST HCHGTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询计费地址模板的配置信息，该操作用计费地址模板ID来唯一标识一个计费地址模板的数据，一次不能查询多条记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                           |
|:-------|:---------|:-------------------------------------------------------------------------------|
| HLRSN  | HLR序列号   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个HLR序列号来查询计费地址数据。如果不输入，则表示查询“HLR序列号”为“0”的所有计费地址数据。 |
| TPLID  | 计费地址模板ID | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个计费地址模板ID来查询计费地址数据。已有模板ID可以使用LST HTPLINF命令查询获得。    |

## 使用实例

查询计费地址模板。计费地址模板ID：10。

```
LST HCHGTPL: TPLID=10;
```

## 输出结果说明

| 参数标识    | 参数说明              |
|:--------|:------------------|
| TPLNAME | 查询计费地址模板名称。       |
| PECF    | 查询计费地址模板的主在线计费地址。 |
| SECF    | 查询计费地址模板的备在线计费地址。 |
| PCCF    | 查询计费地址模板的主离线计费地址。 |
| SCCF    | 查询计费地址模板的备离线计费地址。 |
| COMMENT | 查询计费地址模板的模板注释说明。  |
