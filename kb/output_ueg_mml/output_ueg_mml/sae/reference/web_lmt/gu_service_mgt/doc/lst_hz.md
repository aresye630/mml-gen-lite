# 查询Home Zone业务(LST HZ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中查询用户的Home Zone业务信息。

## 注意事项

“IMSI”和“MSISDN”两个参数是可选参数，必须有且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                   |
|:-------|:-------|:---------------------------------------|
| IMSI   | IMSI   | 用于指示系统需要按哪个IMSI号码查询用户的Home Zone业务信息。   |
| ISDN   | MSISDN | 用于指示系统需要按哪个MSISDN号码查询用户的Home Zone业务信息。 |

## 使用实例

1. 在HLR上查询“IMSI”为“460000009123456”的Home Zone业务信息：

   ```
   LST HZ: IMSI="460000009123456";
   ```

   ```
   %%LST HZ: IMSI="460000009123456";%%
   ```

2. 在HLR上查询“MSISDN”为“86131075003001”的Home Zone业务信息：

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                    |
|:--------|:--------|:--------------------------|:----------------------------------------|
| ERR1010 | 参数冲突    | “IMSI”、“MSISDN”两个参数同时被输入。 | “IMSI”、“MSISDN”两个参数是可选参数，必须有且只能有一个参数出现。 |
