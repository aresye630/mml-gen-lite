# 删除外置AUC错误码映射(RMV AUCERRORCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除已配置的外置AUC错误码映射信息。

仅输入参数“域”，表示删除当前域的所有错误码映射信息；同时输入“域”和“原始错误码”时，表示仅删除当前域下指定的原始错误码对应的错误码映射信息。

## 注意事项

删除错误码映射后，对于错误场景UDM默认给对端返回“5012 DIAMETER\_UNABLE\_TO\_COMPLY”错误码。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                              |
|:----------|:-------|:----------------------------------------------------------------------------------|
| DOMAIN    | 域      | 可选必选说明：必选参数 参数含义：标识外置AUC错误码映射信息的关键字段，用于指定删除哪个域的错误码映射关系。 取值范围：4GIMS 默认值：无。 配置原则：无。 |
| ERRORCODE | 原始错误码  | 可选必选说明：可选参数 参数含义：用于指定删除外置AUC返回的哪个原始错误码对应的映射关系。 取值范围：0～65535 默认值：无。 配置原则：无。        |

## 使用实例

删除4G域下，“原始错误码”为“403”的错误码映射关系：

```
RMV AUCERRORCODE: DOMAIN=4G, ERRORCODE=403;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                          | 处理建议                                                       |
|:--------|:--------|:----------------------------------------------|:-----------------------------------------------------------|
| ERR1009 | 参数丢失    | 执行本命令时，没有输入参数“域”。                             | 输入参数“域”后重新执行本命令重试。                                         |
| ERR3007 | 记录不存在   | 输入的“域”下不存在错误码映射记录或者输入的“域”和“原始错误码”下不存在错误码映射记录。 | 执行LST AUCERROCODE命令查看已存在的错误码映射，输入正确的“域”和“原始错误码”后重新执行本命令重试。 |
