# 修改NT-U-CSI业务(MOD NTUCSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于通过U-CSI模板灵活为用户签约或去签约U-CSI业务。

执行该命令可以签约一个或多个U-CSI模板。设置U-CSI模板，请参见“U-CSI模板管理 ”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。
- 仅当**SET MAPSERV**命令中“UCSI签约管理方式”参数值设置为“NON-Template”时，该命令生效。
- 如果需要签约多个U-CSI模板，执行该命令多次，最多允许签约20个模板。如果模板数超过20条，会返回提示信息“ERR3047：超过最大限制”，必须通过先执行**MOD NTUCSI**命令删除不必要的模板，使添加的总模板数在20之内。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                             |
|:------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI         | 用于标识待修改U-CSI业务用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                           |
| ISDN        | MSISDN       | 用于标识待修改U-CSI业务用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                         |
| RECORDCOUNT | 用户个数         | 用于标识待修改U-CSI业务用户的数目。 当需要为连续号码的多个用户修改U-CSI业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改U-CSI业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行修改U-CSI业务，当只有一个用户时，该参数不必配置。当一次修改U-CSI业务的用户个数很多时，对系统性能无影响，但修改U-CSI业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名      | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待修改U-CSI业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modntucsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                |
| ISDNFILE    | MSISDN文件名    | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待修改U-CSI业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modntucsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                          |
| PROV        | U-CSI业务的操作类型 | 用于标识为用户签约还是去签约U-CSI模板信息。 取值范围：ADD：为用户签约一个U-CSI模板。DELETE：为用户去签约一个U-CSI模板。DELETEALL：为用户去签约所有U-CSI模板。 默认值：无。                                                                                                                                        |
| UCSIID      | U-CSI模板ID    | 仅当该命令中的“U-CSI业务的操作类型”参数取值为“ADD”或“DELETE”时该参数有效，用于标识为用户签约或去签约的U-CSI模板ID。该参数必须先通过ADD UCSITPL命令配置才能在此处引用。 取值范围：0～65534之间的十进制数字。                                                                                                                     |

## 使用实例

1. 为“IMSI”为“460000009012345”的用户签约一个U-CSI模板。命令如下：

   ```
   MOD NTUCSI: IMSI="460000009012345", PROV=ADD, UCSIID=1;
   ```
2. 为“IMSI”为“460000009012345”的用户去签约一个U-CSI模板。命令如下：

   ```
   MOD NTUCSI: IMSI="460000009012345", PROV=DELETE, UCSIID=1;
   ```
3. 为“IMSI”为“460000009012346”的用户签约2个U-CSI模板。命令如下：

   ```
   MOD NTUCSI: IMSI="460000009012346", PROV=ADD, UCSIID=1;
   MOD NTUCSI: IMSI="460000009012346", PROV=ADD, UCSIID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                                               | 处理建议                                                                                                                                                                            |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。参数“U-CSI模板ID”的取值不是0～65534之间的十进制数字。         | 根据实际情况，重新输入“IMSI” 、“MSISDN”或“U-CSI模板ID”的取值，确保其取值符合要求。                                                                                                                           |
| ERR1009 | 参数丢失       | 该命令中的所有可选参数全部没有输入。                                                                                                 | 根据实际情况，重新输入参数，并满足参数的输入条件。                                                                                                                                                       |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。                 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。                                                               |
| ERR3003 | 模板未定义      | 当“U-CSI业务的操作类型”参数为“ADD”时，输入的“U-CSI模板ID”在数据库中未定义。                                                                   | 使用LST UCSITPL命令查询后，重新确认要签约哪个“U-CSI模板ID”。                                                                                                                                        |
| ERR3006 | 记录已存在      | 当“U-CSI业务的操作类型”参数为“ADD”时，输入的“U-CSI模板ID”已被该用户签约。                                                                    | 使用LST NTUCSI命令查询系统中用户已签约的U-CSI模板记录，根据实际情况，重新输入参数，确保输入的“U-CSI模板ID”和用户已签约的U-CSI模板ID不重复。                                                                                           |
| ERR3007 | 记录不存在      | 可能原因为如下之一：用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。当“U-CSI业务的操作类型”参数为“DELETE”时，输入的“U-CSI模板ID”未被该用户签约。 | 根据实际情况，重新输入参数，确保满足以下两点：核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。使用LST NTUCSI命令查询系统用户中已签约的U-CSI模板记录，重新确认要删除哪个“U-CSI模板ID”对应的U-CSI模板数据记录。 |
| ERR3047 | 超过最大限制     | 用户已签约的U-CSI模板数超过最大限制。                                                                                              | 使用LST NTUCSI命令查询系统中用户已签约的U-CSI模板记录，并使用MOD NTUCSI命令删除不必要的数据记录，使添加的总模板数在20之内。                                                                                                     |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                                              | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                                                                                    |
