# 删除切片管理数据（RMV SNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除5GS用户的一条或多条S-NSSAI签约数据。

## 注意事项

- 必须确保执行该命令后，用户剩下的S-NSSAI签约数据中至少包含一条默认S-NSSAI数据，或者删除用户所有的S-NSSAI签约数据。
- 当某个S-NSSAI被删除后，UDM将此S-NSSAI对应的会话管理签约数据也一并自动删除。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “切片标识”和“切片列表”互斥，不能同时携带。
  - 如果携带“切片标识”，则表示删除此S-NSSAI及其下属的所有DNN信息。
  - 如果携带“切片列表”，则表示删除指定的多个SNSSAI及其下属的所有DNN信息。
  - 如果两个都不携带，则表示删除此用户的所有S-NSSAI及其下属的所有DNN信息。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                           |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要删除S-NSSAI数据的5GS用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                       |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除S-NSSAI数据的5GS用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                     |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识需要删除S-NSSAI数据的用户数目。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户删除S-NSSAI数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除S-NSSAI数据。该参数是对连续号码的多个用户删除S-NSSAI数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待删除S-NSSAI数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待删除S-NSSAI数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsnssail.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                         |
| SNSSAI      | 切片标识      | 可选必选说明：可选参数 参数含义：用于标识5G系统中的网络切片，由SST（Slice/Service Type）与SD（Slice Differentiator）组成。可执行LST SNSSAI命令获得。 取值范围：1～10位字符串。 默认值：无。 配置原则：不携带SNSSAI参数表示删除此用户的所有S-NSSAI及其下属的所有DNN信息。同时携带SST和SD，删除具体的一条S-NSSAI及其下属的所有DNN信息。                                              |
| NSSAILIST   | 切片列表      | 可选必选说明：可选参数 参数含义：用于指定需要删除S-NSSAI数据的5GS用户的切片列表。 取值范围：1~64位字符串。 默认值：无。 配置原则： 该参数由1到5个SNSSAI组成。如果只有一个SNSSAI时，参数不带字符“"”、“"” 和“ &”(例如：123-A123D4)。如果存在多个SNSSAI时，每个SNSSAI需要使用“"”、“"”标识，用“&”进行连接(例如："123-A123D4"&"123-B456E7")。                                       |

## 使用实例

1. 删除“IMSI”为“460030913121001”的用户的切片管理数据：

   ```
   RMV SNSSAI: IMSI="460030913121001";
   ```
2. 删除“MSISDN文件名”为“rmvsnssail.txt”的用户的切片管理数据：

   ```
   RMV SNSSAI: ISDNFILE="rmvsnssail.txt";
   ```
3. 删除“IMSI”为“460031200100003”的用户切片管理数据中“切片标识”为"123-B123C4"的切片：

   ```
   RMV SNSSAI: IMSI="460031200100003", SNSSAI="123-B123C4";
   ```
4. 删除“IMSI”为“460031200100003”的用户切片管理数据中“切片列表”为"123-A123D4"和"123-B456E7"的切片：

   ```
   RMV SNSSAI: IMSI="460031200100003", NSSAILIST=""123-A123D4"&"123-B456E7"";
   ```
