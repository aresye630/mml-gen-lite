# EPS用户提供/撤销EGR业务(MOD EGR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于EPS用户签约或者去签约EGR业务。

- 如果对单个用户签约或者去签约EGR业务，使用参数“IMSI”或者“MSISDN”
- 如果对多个用户统一签约或者去签约EGR业务，使用参数“用户个数”或者“IMSI文件名”或者“MSISDN文件名”

## 注意事项

- “IMSI”、“ISDN”、“IMSIFILE”、“ISDNFILE”是互斥参数，有且只能有一个参数出现。
- “RECORDCOUNT”存在时，“IMSIFILE”和“ISDNFILE”不能存在；“IMSI”或“ISDN”必须存在一个。
- 如果用户不是EPS类型用户时，执行此命令，会返回错误码3810，不允许签约。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                    |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。 默认值：无。 说明：可选参数。                                                                                                    |
| ISDN        | MSISDN    | MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数。 默认值：无。 说明：可选参数。                                                                                                   |
| RECORDCOUNT | 用户个数      | 用户数量，用于连续号段批操作。代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 取值范围：整数类型，1～100000。如果只有一个用户，该参数不必提供。 默认值：无。 说明：可选参数。                                         |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 取值范围：字符串类型，由1～16个字母或数字组成，不包含文件的绝对路径。 默认值：无。 说明：可选参数。文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置。         |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：字符串类型，由1～16个字母或数字组成，不包含文件的绝对路径。 默认值：无。 说明：可选参数。文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置。   |
| PROV        | 是否提供EGR业务 | 是提供还是撤销EGR业务 TRUE：提供FALSE：撤销                                                                                                                            |
| EGRHLRSN    | HLR序列号    | 仅当本命令中的“是否提供EGR业务”参数为“TRUE”时该参数有效。EGR业务对应的HLR序列号。此参数与系统配置的序列号相关，如果填写错误，会导致EGR业务不可用 取值范围：0～255 说明：提供EGR业务时，如果没有输入HLR序列号，则该参数的默认值为0。撤销EGR业务时，不需要输入HLR序列号。 |

## 使用实例

给IMSI号码为460000009123456的EPS用户提供EGR业务，HLR序列号为1。命令如下：

`MOD EGR: IMSI="460000009123456", PROV=TRUE, EGRHLRSN=1;`

给ISDN号码为86137724089000的EPS用户提供EGR业务，HLR序列号为1。命令如下：

`MOD EGR: ISDN="86137724089000", PROV=TRUE, EGRHLRSN=1;`
