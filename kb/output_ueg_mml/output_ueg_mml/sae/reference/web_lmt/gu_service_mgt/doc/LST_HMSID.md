# 查询IMPI关联的IMSI数据(LST HMSID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中通过IMPI、IMSI或MSISDN查询IMPI关联的IMSI数据。

## 注意事项

输入的参数IMPI、参数IMSI和参数ISDN必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指定一个IMPI，用来查询该IMPI及其关联的IMSI数据。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| IMSI   | IMSI   | 用于指定一个IMSI，用来查询IMPI及其关联的IMSI数据。 取值范围： 6–15 缺省值： 无                                    |
| ISDN   | MSISDN | 用于指定一个MSISDN，用来查询IMPI及其关联的IMSI数据。 取值范围： 长度不超过15的字符串 缺省值： 无                           |

## 使用实例

查询IMPI关联的IMSI数据。IMSI：8613988888888。

```
LST HMSID: IMSI="8613988888888";
```

## 输出结果说明

| 参数标识   | 参数说明              |
|:-------|:------------------|
| IMPI   | 显示与IMSI关联的IMPI。   |
| IMSI   | 显示与IMPI关联的IMSI。   |
| ISDN   | 显示与IMSI关联的MSISDN。 |
