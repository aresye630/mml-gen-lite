# 增加5G NCC模板(ADD NGSNCCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中添加5G NCC模板记录，设置使用模板配置UDM支持备份AMF的方式，配置跨PLMN漫游场景下UDM作为Consumer发送给对端的请求消息URI或UDM发送给对端的callback或location消息URI中是否携带端口号。

## 注意事项

- 同一个“HLR序列号”中增加的5G NCC模板记录数不允许超过3000条。
- 所有“HLR序列号”增加的记录数总和不允许超过5000条。
- 需要指出的是，本命令中所描述的系统初始设置值，是指操作员执行该命令未输入数值时系统设置的参数值，可以通过**LST NGSNCCTPL**命令查询。

## 使用实例

给UDM中增加一条5G NCC模板数据记录，其中“HLR序列号”为“1”、“模板ID”为“1”、“模板名”为“test01”、不支持备份AMF，且异网漫游请求消息URI和异网漫游回调消息URI均携带端口号。

```
ADD NGSNCCTPL: HLRSN=1, TPLID=1, TPLNAME="test01", BKAMFMODE=NONE, ROAM_REQ_WITH_PORT=0, ROAM_CBK_WITH_PORT=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:----------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的提示参数不在相应的参数取值范围内。                                    | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                    |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。                                    | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST NGSNCCTPL命令查询系统中已存在的NCC模板。                                                              |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                              | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                   |
