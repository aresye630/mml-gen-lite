# 修改IMS用户模板(MOD IMSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中修改一个IMS用户模板。在该命令中，系统通过关键参数“IMS用户模板ID”唯一标识一条IMS用户模板信息。

## 注意事项

修改IMS用户模板记录时，输入的“计费模板ID”、“能力集模板ID”、“ServiceProfile模板ID”和“拜访网络地址模板ID”必须对应同一个“HLR序列号”。

## 参数说明

| 参数标识       | 参数名称               | 参数说明                                                                                                                                          |
|:-----------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号             | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                      |
| TPLID      | IMS用户模板ID          | 用于标识一个IMS用户基本信息模板记录的关键字段（其取值不能被修改），用于指定需要对哪一个IMS用户基本信息模板记录的参数进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。                                                |
| TPLNAME    | IMS用户模板名称          | 用于标识待修改的IMS用户基本信息模板的名称。 取值范围： 1～60位字符串 默认值：无                                                                                                  |
| CHARGTPLID | 计费模板ID             | 用于给IMS用户模板指定一个计费地址模板，该模板需要通过命令ADD HCHGTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无 说明：如果没有输入该参数，默认“计费地址模板ID”为“0”。                                         |
| CAPTPLID   | 能力集模板ID            | 用于给IMS用户模板指定一个能力集模板，该模板需要通过命令ADD HCAPTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无                                                                         |
| SPTPLID    | ServiceProfile模板ID | 用于给IMS用户模板指定一个Service Profile模板，该模板需要通过命令ADD HSPTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无                                                              |
| VNTPLID    | 拜访网络地址模板ID         | 用于指定一个漫游地址ID。该参数必须先在ADD HVNTPL中定义，然后才能在此处引用。 取值范围：0~1024 缺省值：无                                                                                |
| PROVSTNSR  | 提供或撤销STN-SR        | 是否提供STN-SR（Session Transfer Number for SRVCC）。 取值范围：TRUE：可以使用参数“SRVCC会话传输号码”。FALSE：清除STN-SR信息。 默认值：无 说明：不输入时，表示不修改STN-SR信息。                   |
| STNSR      | SRVCC会话传输号码        | 仅当本命令中的“提供或撤销STN-SR”参数为“TRUE”时该参数有效。用于标识SRVCC会话传输号码。MME(Mobility Management Entity)使用它获取从PS域到CS域的网址路径会话传递。 取值范围：E.164格式的编码，3～15位的十进制数字。 默认值：无 |

## 使用实例

修改IMS用户模板，参数取值如表1所示。

| 参数                 | 值                 |
|:-------------------|:------------------|
| IMS用户模板ID          | 1                 |
| IMS用户模板名称          | IMS User Template |
| 计费模板ID             | 1                 |
| 能力集模板ID            | 1                 |
| ServiceProfile模板ID | 1                 |
| 拜访网络地址模板ID         | 1                 |
| 提供或撤销STN-SR        | TRUE              |
| SRVCC会话传输号码        | 8613484929766     |

```
MOD IMSTPL: TPLID=1, TPLNAME="IMS User Template", CHARGTPLID=1, CAPTPLID=1, SPTPLID=1, VNTPLID=1, PROVSTNSR=TRUE, STNSR="8613484929766";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
