# 增加DNN替换规则模板(ADD DNNREPRULETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条DNN替换规则模板数据记录。

在4G网络中，PLMN粒度使用PLMN匹配区域，Diameter粒度使用主机名或域名匹配区域，客户可根据具体应用选择配置不同粒度的规则。

- 同时配置“PLMN漫游模板ID”和“DIAMRR漫游模板ID”参数时主机名域名优先级高于PLMN。
- 仅配置“DIAMRR漫游模板ID”参数时主机名优先级高于域名。

## 注意事项

- 所有“HLR序列号”中增加的DNN替换规则模板记录数不能超过10000条。
- 同一个“HLR序列号”下，不同“模板ID”的DNN替换规则模板不允许配置相同的“业务码”。
- “5GS漫游模板ID”、“PLMN漫游模板ID”和“DIAMRR漫游模板ID”三个参数至少输入一个。

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                |
|:---------------|:-------------|:--------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号       | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                             |
| TPLID          | 模板ID         | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。 取值范围：1～65535 默认值：无。 配置原则：无。                                                      |
| TPLNAME        | 模板名          | 可选必选说明：可选参数 参数含义：用于标识待增加模板在系统中的名称。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                                                   |
| CTRLSCHE       | 业务码          | 可选必选说明：必选参数 参数含义：用于标识DNN/APN替换规则业务类型。 取值范围：1～30位的字符串，只允许输入字母、数字、“-”、“_”、“.”或“*”。 默认值：无。 配置原则：无。                     |
| NGCNODETPL_ID  | 5GS漫游模板ID    | 可选必选说明：条件可选参数 参数含义：用于标识DNN替换规则配置的NGC漫游限制模板ID。该参数必须先由ADD NGCRRNODETPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无 配置原则：无。 |
| PLMNTPLID      | PLMN漫游模板ID   | 可选必选说明：条件可选参数 参数含义：用于标识APN替换规则配置的PLMN区域漫游模板ID。该参数必须先由ADD PLMNTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 配置原则：无。         |
| DIAMNODETPL_ID | DIAMRR漫游模板ID | 可选必选说明：条件可选参数 参数含义：用于标识APN替换规则配置的Diameter漫游限制模板ID。该参数必须先由ADD DIAMRRTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 配置原则：无。   |

## 使用实例

增加一个DNN替换规则模板。“HLR序列号”为“1”，“模板ID”为“8”，“业务码”为“WZA01”，“5GS漫游模板ID”为“2”。

```
ADD DNNREPRULETPL: HLRSN=1, TPLID=8, CTRLSCHE="WZA01", NGCNODETPL_ID=2;
```
