# 查询动态用户数(LST DYNSUBDATA)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成DSU模块过载，引发DSU模块流控导致业务受损，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，并评估本局点所有DSU模块CPU最大不能超过85%。操作前必须由华为工程师提交RFC至华为机关审核操作实施方案、测试方案和回退方案后才可以实施。如有疑问请联系华为公司处理。

该命令用于运营商日常运营维护时，查询当前数据库中动态用户数信息。

## 注意事项

- 执行该命令最长会耗时70秒，在此期间无法在PGW Web LMT MML命令界面执行其他命令。
- 升级之后，执行该命令首次查询NPHLR的携入用户数时，需先执行**UPG NPHLRSN**更新携入用户的HLRSN。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                                                         |
|:-----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESULT     | 查询对象    | 此参数用于设置查询对象的类型。 取值范围： ALL：查询所有类型的动态用户数。CS：查询CS类型的动态用户数。PS：查询PS类型的动态用户数。VLR：查询VLR类型的动态用户数。SGSN：查询SGSN类型的动态用户数。EPS：查询EPS类型的动态用户数。MME：查询MME类型的动态用户数。S4SGSN：查询S4SGSN类型的动态用户数。AAA：查询AAA类型的动态用户数。NPHLR：查询NPHLR的携入用户数。查询NPHLR用户数据时不考虑用户的位置信息。SA：查询SA类型动态用户数。 默认值：无。 |
| ADDR       | 地址号码    | 仅当本命令中的“查询对象”参数取值为“VLR”或“SGSN”时该参数有效。用于标识查询的VLR对象或SGSN对象的地址信息。 取值范围：E.164格式的地址，1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                      |
| HOST       | 主机名称    | 仅当本命令中的“查询对象”参数取值为“MME”、“S4SGSN”或“AAA”时该参数有效。用于标识查询对象的主机名称。 取值范围：1～127位的字符串。 默认值：无。                                                                                                                                                                          |
| REALM      | 主机域名    | 仅当本命令中的“查询对象”参数取值为“MME”、“S4SGSN”或“AAA”时该参数有效。用于标识查询对象的主机域名。 取值范围：1～127位的字符串。 默认值：无。                                                                                                                                                                          |
| PURGE_FLAG | PURGE标识 | 仅当本命令中的“查询对象”参数取值为“ALL”、“CS”、“PS”、“VLR”、“SGSN”、“EPS”、“MME”、“S4SGSN”或“SA”时该参数有效。用于标识查询对象是否包括PURGE用户。取值范围： TRUE：查询结果包括PURGE用户FALSE：查询结果不包含PURGE用户 默认值：TRUE。                                                                                                    |
| HLRSN      | HLR序列号  | 用于标识查询对象的HLR序列号。 取值范围：1～255。 默认值：无。                                                                                                                                                                                                                          |
| BEGQRYTM   | 起始时间    | 仅当本命令中“查询对象”取值为非“NPHLR”时该参数有效。用于标识系统查询哪个时间点之后做过位置更新的动态用户数。 取值范围：符合“YYYY&MM&DD&HH&MM&SS”格式的数字字符串。 默认值：无。                                                                                                                                                      |
| RN         | 路由码     | 用于标识系统通过哪个路由码查询NPHLR中携入用户数。 取值范围：1～10位的十进制数字或者A～E字符 默认值：无。 说明：“路由码”不能和本网路由码相同。                                                                                                                                                                               |
| LOCAL_FLAG | 本地标识    | 仅在混合组网场景下VRSP所在的业务发放系统执行本命令时，该参数有效。用于标识是否仅查询本VRSP的动态用户数。 取值范围： TRUE：查询结果仅包括本VRSP的动态用户数。FALSE：查询结果包括所有分区（SP、RSP和VRSP）的动态用户数。 默认值：无。                                                                                                                           |
| MCC        | 移动国家码   | 仅当本命令中的“查询对象”参数取值为“ALL”或“SA”时该参数有效。用于标识移动国家码。 移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460。 取值范围：3位十进制数字组成的字符串。 默认值：无。                                                                                     |
| MNC        | 移动网络码   | 仅当本命令中的“查询对象”参数取值为“ALL”或“SA”时该参数有效。用于标识移动网络码。 移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配，如中国移动为00，中国联通为01等。 取值范围：2位或3位的十进制数字组成的字符串。 默认值：无。                                                                                                                 |
| AMFID      | AMF标识   | 仅当本命令中的“查询对象”参数取值为“ALL”或“SA”时该参数有效。用于标识AMF区域ID。与“移动国家码”、“移动网络码”组成AMF全球唯一标识。当指定该参数时，仅统计指定AMF下的SA动态用户数量。 取值范围：6位十六进制的字符串。 默认值：无。                                                                                                                               |

## 使用实例

1. 查询所有动态用户数信息。命令如下：

   ```
   LST DYNSUBDATA: RESULT=ALL;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=ALL;%%
   RETCODE = 0 SUCCESS0001:操作成功

                     CsDynSubData = 1
                     PsDynSubData = 0
                    MmeDynSubData = 0
                 S4SgsnDynSubData = 0
                Non3GppDynSubData = 0
                     SADynSubData = 7

   Total count = 6

   There is together 1 report

   ---    END
   ```
2. 查询所有“HLR序列号”为“1”的动态用户数信息：

   ```
   LST DYNSUBDATA: RESULT=ALL, HLRSN=1;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=ALL, HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                     CsDynSubData = 2
                     PsDynSubData = 0
                    MmeDynSubData = 0
                 S4SgsnDynSubData = 0
                Non3GppDynSubData = 0
                     SADynSubData = 7

   Total count = 6

   There is together 1 report

   ---    END
   ```
3. 查询“EPS”类型的动态用户数信息：

   ```
   LST DYNSUBDATA: RESULT=EPS;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=EPS;%%
   RETCODE = 0 SUCCESS0001:操作成功

                    MmeDynSubData = 0
                 S4SgsnDynSubData = 0
                Non3GppDynSubData = 0

   Total count = 3

   There is together 1 report

   ---    END
   ```
4. 查询“MME”类型的动态用户数信息，“主机名称”为“e.huawei.com”，“PURGE标识”为“TRUE”，“HLR序列号”为“1”：

   ```
   LST DYNSUBDATA: RESULT=MME, HOST="e.huawei.com", PURGE_FLAG=TRUE, HLRSN=1;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=MME, HOST="e.huawei.com", PURGE_FLAG=TRUE, HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                    MmeDynSubData = 0

   Total count = 1

   There is together 1 report

   ---    END
   ```
5. 查询所有HLRSN下，“路由码”取值为“1234”的携入用户个数。

   ```
   LST DYNSUBDATA: RESULT=NPHLR, RN="1234";
   ```

   ```
   %% LST DYNSUBDATA: RESULT= NPHLR, RN="1234";%%
   RETCODE = 0 SUCCESS0001:操作成功

                    PortInSubData = 10

   Total count = 1

   There is together 1 report

   ---    END
   ```

6. 查询“查询对象”取值为“ALL”，“本地标识”取值为“TRUE”的动态用户数信息：

   ```
   LST DYNSUBDATA: RESULT=ALL, LOCAL_FLAG=TRUE;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=ALL, LOCAL_FLAG=TRUE;%%
   RETCODE = 0 SUCCESS0001:操作成功
    
                     CsDynSubData = 2
                     PsDynSubData = 0
                    MmeDynSubData = 0
                 S4SgsnDynSubData = 0
                Non3GppDynSubData = 0
                     SADynSubData = 7
    
   Total count = 6
    
   There is together 1 report
    
   ---    END
   ```
7. 查询“查询对象”取值为“SA”的动态用户数信息：

   ```
   LST DYNSUBDATA: RESULT=SA;
   ```

   ```
   %%LST DYNSUBDATA: RESULT=SA;%% 
   RETCODE = 0 SUCCESS0001:操作成功
                       SADynSubData = 7  

   Total count = 1  

   There is together 1 report  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
