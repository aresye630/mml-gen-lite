# 修改5G自动开户用户粒度黑白名单(MOD NGCAUTOIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响用户自动开户业务，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加或删除需要进行自动开户控制的黑白名单数据记录，业务处理时根据黑白名单数据判断是否允许对用户进行自动开户操作。

该命令的使用场景：当为用户设置是否需要启动自动开户特性时执行该命令。

## 注意事项

- 为了避免影响系统容量，系统中增加的5G自动开户用户粒度黑白名单记录数不能超过系统2G/3G静态用户数和4G静态用户数的最大值的5%。其中2G/3G静态用户数和4G静态用户数可登录“USCDB MML命令”界面，执行**DSP LICRATE**命令分别查看“静态合同用户数”和“LTE BE基本软件”获得。
- UDM每5分钟比较一次全局表记录的5G自动开通黑白名单的数量与根据**SET UDMSERV**命令设置的“自动开通黑白名单比例”参数来确定的5G自动开通黑白名单数量的最大值。最大值=“LTE BE基本软件”license最大值\*“自动开通黑白名单比例”。
  - 自动开户的黑白名单数量超过最大值的90%时，系统会上报**ALM-18002 5G自动开户黑白名单用户数即将达到容量限制**告警。
  - 自动开户的黑白名单数量超过最大值时，系统将不允许增加自动开户控制的黑白名单数量，如果增加则返回失败并上报错误码ERR4173：“5G自动开通黑白名单达到上限”。
- 混合组网场景下，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                             |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTYPE      | 操作类型         | 可选必选说明：必选参数 参数含义：用于标识执行该命令所实现的操作类型。 取值范围： ADD：增加IMSI数据记录。DELETE：删除IMSI数据记录。 默认值：无。 配置原则：无。                                                                                                                                                                       |
| IMSI        | IMSI         | 可选必选说明：必选参数 参数含义：用于标识需要进行自动开户控制的用户IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                  |
| NGCAUTOPROV | 是否启用5G自动开户特性 | 可选必选说明：条件必选参数 参数含义：用于标识是否启用5G自动开户特性。 取值范围：FALSE：不支持5G自动开户。4G-5G：仅支持4G到5G的自动开户。4G_VoLTE-5G：仅支持4G_VoLTE到5G的自动开户。 默认值：无。 配置原则： 仅当本命令的参数“操作类型”为“ADD”时该参数有效。执行LST EPS命令查询“EPS”输出项为“PROV”可判断用户为4G用户。执行LST EPS命令查询“EPS”输出项为“PROV”且“VOLTETAG”输出项为“TRUE”可判断用户为4G_VoLTE用户。 |

## 使用实例

配置5G自动开户业务时，当某些用户需要进行自动开户，某些用户不需要进行自动开户时，可以进行配置。

1. 配置5G自动开户业务时，当某些用户需要进行自动开户，则增加一条数据记录到自动开户白名单。例如IMSI号码为“460061234567834”的4G用户需要进行自动开户，则配置“操作类型”为“ADD”，“IMSI”为“460061234567834”，“是否启用5G自动开户特性”为“4G-5G”。

   ```
   MOD NGCAUTOIMSI: OPTYPE=ADD, IMSI="460061234567834", NGCAUTOPROV=4G-5G;
   ```
2. 配置5G自动开户业务时，当禁止某些用户进行自动开户时，则增加一条数据记录到自动开户黑名单。例如IMSI号码为“460061234567835”的用户禁止进行自动开户，则配置“操作类型”为“ADD”，“IMSI”为“460061234567835”，“是否启用5G自动开户特性”为“FALSE”。

   ```
   MOD NGCAUTOIMSI: OPTYPE=ADD, IMSI="460061234567835", NGCAUTOPROV=FALSE;
   ```
3. 当某些用户的5G自动开户业务需要调整，例如原黑/白名单用户不再禁止或进行自动开户，则删除对应IMSI数据记录，例如取消对IMSI号码为“460061234567835”的用户进行的5G自动开户控制，则设置“操作类型”为“DELETE”，“IMSI”为“460061234567835”。

   ```
   MOD NGCAUTOIMSI: OPTYPE=DELETE, IMSI="460061234567835";
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:---------------|:-----------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值         | 界面输入的参数不在相应的参数取值范围内。                                 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                 |
| ERR3006 | 记录已存在          | “操作类型”参数为“ADD”时，“IMSI”参数对应的5G自动开户用户粒度黑白名单数据记录已存在。    | 根据实际情况，重新输入参数，当“操作类型”参数为“ADD”时，确保输入的“IMSI”参数和系统中已存在的不重复。可执行LST NGCAUTOIMSI命令查询待增加的IMSI对应的5G自动开户用户粒度黑白名单数据记录是否存在。 |
| ERR3007 | 记录不存在          | “操作类型”参数为“DELETE”时，“IMSI”参数对应的5G自动开户用户粒度黑白名单数据记录不存在。 | 根据实际情况，重新输入已配置的“IMSI”参数，可执行LST NGCAUTOIMSI命令查询待删除的IMSI对应的5G自动开户用户粒度黑白名单数据记录是否存在。                                 |
| ERR3111 | 系统不支持该特性       | 在非路由分区下执行该命令。                                        | 该命令仅支持在路由分区下执行。                                                                                                  |
| ERR4173 | 5G自动开通黑白名单达到上限 | 自动开户的黑白名单数量超过“自动开通黑白名单比例”参数控制的最大值。                   | 增加的5G自动开通黑白名单数量达到上限，不允许再增加。如果需要增加，则首先执行SET UDMSERV命令提高“自动开通黑白名单比例”参数的取值后，再执行该命令增加。                               |
