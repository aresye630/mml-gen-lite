# 删除K4(RMV HK4)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一个鉴权数据K4的数据记录。

## 注意事项

只有没有被使用的K4数据才可以删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------|
| K4SNO  | K4索引号  | 标识一条K4数据记录的关键参数，用于指定需要删除哪一条K4数据记录，操作员可以使用LST HK4操作查询获得。 取值范围：1～128 缺省值： 无 |

## 使用实例

删除K4。K4索引号：10。

```
RMV HK4: K4SNO=10;
```
