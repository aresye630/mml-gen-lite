# 查询NT-U-CSI业务(LST NTUCSI)

- 命令功能

- 参数说明

- 输出结果说明

## 命令功能

该命令用于查询通过**MOD NTUCSI**命令签约的U-CSI业务。

- 若需要查询单个用户签约的U-CSI模板，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户签约的U-CSI模板，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户签约的U-CSI模板，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                |
|:------------|:----------|:------------------------------------|
| IMSI        | IMSI      | 用于指示系统按照哪个IMSI号码来查询用户签约的U-CSI模板。    |
| ISDN        | MSISDN    | 用于指示系统按照哪个MSISDN号码来查询用户签约的U-CSI模板。  |
| RECORDCOUNT | 用户个数      | 用于指示系统按照查询多少个用户签约的U-CSI模板。          |
| IMSIFILE    | IMSI文件名   | 用于指示系统按照哪个IMSI文件名来查询用户签约的U-CSI模板。   |
| ISDNFILE    | MSISDN文件名 | 用于指示系统按照哪个MSISDN文件名来查询用户签约的U-CSI模板。 |

## 使用实例

1. 查询“IMSI”为“460000009012345”的用户签约的U-CSI模板。

   ```
   LST NTUCSI: IMSI="460000009012345";
   ```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，各参数含义请参见**MOD NTUCSI**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失       | 该命令中的所有参数全部没有输入。                                                                                   | 根据实际情况，重新输入参数，并满足参数的必选条件。                                                                                               |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
