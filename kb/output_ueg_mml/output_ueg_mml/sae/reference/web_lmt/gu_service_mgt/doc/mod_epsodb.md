# 修改EPS用户的ODBPOS业务(MOD EPSODB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改EPS用户的ODBPOS业务签约信息。

- 当用户在网时，执行该命令修改EPS用户的签约信息并根据**SET MAPSERV**命令中的“EPS域下发的ODBPOS的控制方式”参数值向对端下发用户更新后的签约信息。
- 当用户不在网，执行该命令仅更新用户在数据库中的数据。当用户再次进行位置更新时，UDM会根据**SET MAPSERV**命令中的“EPS域下发的ODBPOS的控制方式”参数值向对端下发用户更新后的签约信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                                                                                                                                                                                |
|:------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI             | 用于标识需要签约或去签约ODBPOS业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                       |
| ISDN        | MSISDN           | 用于标识需要签约或去签约ODBPOS业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                     |
| RECORDCOUNT | 用户个数             | 用于标识需要签约或去签约ODBPOS业务的用户数目。 当需要为连续号码的多个用户签约或去签约ODBPOS业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户签约或去签约ODBPOS业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户签约或去签约ODBPOS业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名          | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要签约或去签约ODBPOS业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modepsodb.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                         |
| ISDNFILE    | MSISDN文件名        | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约或去签约ODBPOS业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modepsodb.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                   |
| EPSODBPOS   | EPS用户的ODB-闭锁分组业务 | 用于标识EPS用户的ODBPOS业务。 取值范围： NOBPOS：不闭锁分组业务。BAPOS：闭锁所有的分组业务。BHPLMNAPROAM：当接入点在HPLMN并且用户在VPLMN漫游时闭锁分组业务。BALLAPROAM：当接入点在VPLMN并且用户在VPLMN漫游时闭锁分组业务。 默认值：无。                                                                                                |

## 使用实例

为EPS网络用户修改ODBPOS业务，数据配置可参考如下实例。

1. 为IMSI号码为“460000009123456”的用户修改ODBPOS业务，“EPS用户的ODB-闭锁分组业务”为“NOBPOS”：

   ```
   MOD EPSODB: IMSI="460000009123456", EPSODBPOS=NOBPOS;
   ```
2. 修改3个连续号码的用户的ODBPOS业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“EPS用户的ODB-闭锁分组业务”为“NOBPOS”：

   ```
   MOD EPSODB: ISDN="13310911001", RECORDCOUNT=3, EPSODBPOS=NOBPOS;
   ```
3. 修改3个非连续号码的用户的ODBPOS业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modepsodb.txt”的文件中，并通过文件管理功能上传到指定目录，对应的“EPS用户的ODB-闭锁分组业务”为“NOBPOS”：

   ```
   MOD EPSODB: ISDNFILE="modepsodb.txt", EPSODBPOS=NOBPOS;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                                                                                              | 处理建议                                                                                                                                                                                   |
|:--------|:--------------|:--------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                          | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                                                                               |
| ERR1009 | 参数丢失          | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                 | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                                                                                            |
| ERR1005 | 文件未找到         | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                  | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                                                                                     |
| ERR1010 | 参数冲突          | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。                                                                |
| ERR1025 | 批操作文件中格式非法    | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                             | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                                                                                           |
| ERR3810 | 用户不是EPS用户或未开户 | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户或者不是EPS用户。                                   | 核实IMSI号码或MSISDN号码，确保其对应的用户为EPS用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户或不是EPS用户：若用户未开户，请参考ADD SUB或ADD SUBTPL命令给用户开户为EPS用户。若用户已开户但不是EPS用户，则请参考MOD SUBTPL或MOD EPS命令使用户成为EPS用户。 |
