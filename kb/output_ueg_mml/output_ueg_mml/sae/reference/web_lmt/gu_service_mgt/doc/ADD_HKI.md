# 增加KI(ADD HKI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中增加一个鉴权数据KI的数据记录，此操作增加的鉴权信息用于IMS AKA鉴权。

## 注意事项

- KI/OPC是重要鉴权参数，建议对KI/OPC进行加密。如果已经对KI/OPC加密，可以通过**ADD HKI**命令输入加密参数。
- 如果在“命令输入区”输入命令后再输入各参数，“KI密钥”和“OPC值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“KI密钥”和“OPC值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时如果未使用K4对KI/OPC进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                               |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI     | IMPI      | 用于定义AKA鉴权数据索引IMPI的值，要求输入IMPI值符合NAI格式，字母区分大小写，一个IMPI对应一个物理终端，在网络侧对应一个安全上下文，其属性类似于GSM网络中的IMSI号码。 取值范围： 长度不超过127的字符串 缺省值： 无                                           |
| K        | KI密钥      | 用于定义鉴权数据KI的值，要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                                                                                      |
| K4SNO    | K4索引号     | 用于指定AKA鉴权使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明：如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。 取值范围： 0～128 缺省值： 无                                                           |
| OPSNO    | OP索引号     | 用于指定AKA鉴权使用的OP的值，该参数必须先由ADD HOP操作定义，然后才能在此处索引。说明：如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不能存在。 取值范围： 0～128 缺省值： 无                                              |
| AMFSNO   | AMF索引号    | 用于指定AKA鉴权使用的AMF的值，该参数必须先由ADD HAMF操作定义，然后才能在此处索引。 取值范围： 1～128 缺省值： 无                                                                                                |
| OPC      | OPC值      | 用于在HSS的业务数据库中定义鉴权数据OPC的值，要求输入16进制字符，字母不区分大小写。说明：当OPC取值全零时为无效值，禁止输入。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                                                    |
| OPCK4SNO | OPC K4索引号 | 用于指定AKA鉴权中对OPC进行解密时使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明： 如果OPCK4SNO取值为0， 表明OPC未被加密；否则， 表明OPC是经OPCK4加密过的； OPC和OPCK4SNO条件可选，如果设置了其中一个，另一个必须设置。 取值范围： 0～128 缺省值： 无 |

## 使用实例

增加KI。IMPI：impiinfo，KI密钥：1234567890abcdef1234567890ABCDEF，K4索引号：1，OP索引号：1，AMF索引号：1。

```
ADD HKI: IMPI="impiinfo", K="*****", K4SNO=1, OPSNO=1, AMFSNO=1;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900003522 | 默认K2不存在                      | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时未使用K4对KI/OPC进行加密，同时未执行SET DEFAULTK2SNO命令设置默认HK2。 | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时需要使用K4对KI/OPC进行加密，或已执行SET DEFAULTK2SNO命令设置默认HK2。 |
