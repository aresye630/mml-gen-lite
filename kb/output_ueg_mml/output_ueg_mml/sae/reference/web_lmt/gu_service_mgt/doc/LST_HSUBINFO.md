# 查询IMS用户描述(LST HSUBINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询指定“SUBID”的“用户描述”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| SUBID  | SUBID  | 用于指示系统需要按照哪个SUBID来查询用户描述。一次只能查询一个用户，SUBID字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

查询指定SUBID的用户描述，“SUBID”为“6290000001”：

```
LST HSUBINFO: SUBID="6290000001";
```

```
%%LST HSUBINFO: SUBID="6290000001";%%
RETCODE = 0 操作成功

SUBID                                                                                                                           SUBINFO
6290000001                                                                                                                      +866290000001@huawei.com

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 参数标识    | 参数说明                 |
|:--------|:---------------------|
| SUBINFO | 用户描述信息。长度不超过127的字符串。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|       错误码 | 错误码解释          | 原因分析             | 处理建议                                                  |
|----------:|:---------------|:-----------------|:------------------------------------------------------|
| 900001008 | 参数不足           | 参数“SUBID”没有输入。   | 根据实际情况，重新输入参数，确保参数“SUBID”必须输入。                        |
| 900003051 | 请求消息中的SubId不存在 | 输入的参数“SUBID”未定义。 | 根据实际情况，重新输入参数，确保“SUBID”已经定义。可通过LST HSUB命令查询已定义的SUBID。 |
|      1001 | 无效的命令          | 输入的命令名称不正确。      | 重新输入正确的命令。                                            |
| 900001007 | 无效的参数值         | 输入的参数取值不在其取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                      |
| 900001010 | 参数重复           | 输入命令中的同一参数重复出现。  | 根据实际情况，删除重复的参数，确保命令中每一个参数只出现一次。                       |
