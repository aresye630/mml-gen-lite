# 修改相邻TAI关系(MOD TAILIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS中修改TAI(Tracking Area Identity)与相邻TAI关系。

## 注意事项

无。

## 参数说明

| 参数标识                  | 参数名称       | 参数说明                                                                                                                                                                                                                                                                          |
|:----------------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN                 | HLR序列号     | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                     |
| TAI                   | 跟踪区标识      | 用于标识跟踪区，标识相邻TAI关系数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪些相邻TAI关系数据记录的参数进行修改或调整，操作员可以使用LST TAILIST命令查询获得。 默认值：无。 说明：TAI由MCC(Mobile Country Code)，MNC(Mobile Network Code)及TAC(Tracking Area Code)组成，总长度为9或10位。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，有效范围0000-FFFE。 |
| ADJOINTAI1～ADJOINTAI9 | 相邻跟踪区标识1～9 | 用于标识相邻跟踪区，在PGW初始化相邻TAI列表时作为相邻TAI使用。 默认值：无。 说明：相邻TAI由MCC(Mobile Country Code)，MNC(Mobile Network Code)及TAC(Tracking Area Code)组成，总长度为9或10位。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，有效范围0000-FFFE。当相邻TAI值为全F组成时，该命令相当于删除主TAI与该相邻TAI的关系。                      |

## 使用实例

1. 在“HLR序列号”为“1”的HSS上修改TAI为“460212345”相邻TAI关系。其中，“ADJOINTAI1”为“460212355”：

   ```
   MOD TAILIST: HLRSN=1, TAI="460212345", ADJOINTAI1="460212355";
   ```
2. 在“HLR序列号”为“1”的HSS/HLR上删除TAI为“460212345”，“ADJOINTAI1”为“460212355”的相邻TAI关系：

   ```
   MOD TAILIST: HLRSN=1, TAI="460212345", ADJOINTAI1="FFFFFFFFFF";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                                                                                                                         |
|:--------|:--------|:---------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 根据实际情况选择：HLR序列号未定义。TAI未定义。 | 根据实际情况选择：如果需要为已定义的HLRSN修改TAI与相邻TAI映射关系，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN修改TAI与相邻TAI映射关系。如果需要为已定义的TAI修改对应的相邻TAI映射关系，则执行LST TAILIST命令先查询已定义的TAI，再为已定义的TAI修改TAI与相邻TAI映射关系。 |
