## 命令功能

开户是给用户开通多种业务。

PGW提供强大的开户功能，不仅可以为单个用户开户，而且可以同时为多个用户批量开户。为了简化操作，还提供了模板开户功能。

常见的开户方法有两种：

第一种：执行**ADD SUB**命令开户，适用于为单个用户开户或大量用户批量开户的情况。

第二种：事先设置各种开户模板，执行**ADD TPLSUB**命令进行模板开户。同时，为了简化操作，增加/修改各种业务也可以通过事先设置业务模板，然后采用模板进行增加/修改。

## 注意事项

- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- RECORDCOUNT参数只能与IMSI/ISDN一起出现，用于增加多个连续号码的用户时使用。此种情况下，开户操作为批操作。
- FILE中包含不连续的IMSI号码和对应的MSISDN号码，在批开户模式下使用。
- 通过开户批操作文件为不连续号码的M2M用户开户成为MSISDN-Less用户时，由于开户批操作文件必须同时输入IMSI和MSISDN，需在批操作文件中将用户的MSISDN与IMSI保持一致。
- 如果CFU=TRUE，参数CFUNCS、CFUCOU为必选参数，CFUOFAID为可选参数。
- 如果CFB=TRUE，参数CFBNCS、CFBNFS和CFBCOU为必选参数，CFBOFAID为可选参数。
- 如果CFNRY=TRUE，参数CFNRYNFS、CFNRYNCS和CFNRYCOU为必选参数，CFNRYOFAID为可选参数。
- 如果CFNRC=TRUE，参数CFNRCNCS和CFNRCCOU为必选参数，CFNRCOFAID为可选参数。
- 如果CFD=TRUE，参数CFDNFS、CFDNCS和CFDFTN为必选参数，CFDBSG和CFDNRTIME为可选参数；如果CFD=FALSE，参数CFDNFS、CFDNCS、CFDFTN、CFDBSG和CFDNRTIME不必出现。
- 如果CLIP=TRUE，参数CLIPOR为必选参数。
- 如果CLIR=TRUE，参数CLIRMODE为必选参数。
- 如果COLP=TRUE，参数COLPOR为必选参数。
- 如果CNAP=TRUE，参数CNAPOR为必选参数。
- 如果IST=TRUE，参数ISTTIMER和ISTRSP为必选参数。
- 如果签约MPTY业务，必须签约HOLD业务。
- 如果输入CHARGE\_GLOBAL或SCHARGE\_GLOBAL，则GPRSTPLID不允许输入。
- 如果通过“优化GPRS模板ID”给用户签约GPRS业务，则必须在命令**SET MAPSERV**中设置“GPRS管理方式”参数为“NotSupportGPRSManager”、“SupportGPRSManager”或“SuppGprsManageOptimizeon”。“GPRS管理方式”参数开局设定之后不能修改，如非开局场景，请勿修改此参数配置。
- 如果签约闭锁业务BAOC、BOIC、BOICEXHC、BAIC、BICROAM的任意一种，则必须设置CBCOU参数。
- 开户前，请使用**ADD KI**命令加载KI。
- 当PGW为简单模式时，不需要设置参数HLRSN，HLRSN仅在完整模式中设置。
- 由于HLR数据库性能和大小跟签约的业务多少有关，对于运营商没有开通的业务建议不要签约。
- 如果用户签约ODB-POS，ODBPOS和ODBPOSTYPE两个参数为必选参数。
- 如果签约ACR业务，必须签约CLIP业务。
- 如果NIRPROV=TRUE，参数NIRINDEX为必选参数。
- 如果输入的ECATOPTION为有效值，则必须输入ECATEGORY。
- 如果“是否支持Non-3GPP接入”参数为“TRUE”。
  - “UE最大上行带宽”和“NR上行速率”两个参数必须且只能配置一个。
  - “UE最大下行带宽”和“NR下行速率”两个参数必须且只能配置一个。
- 参数“ODBROAM”取值为“BROHPLMN”、“BROHPLMNC”或“BROHPLMNCGPRS”时，从HSS业务配置中获取ODBROAM是否控制EPS域（通过**LST MAPCONF**命令查询，**SET MAPCONF**命令设置），再根据主机名或域名检查网络类型，判断是否需要增加对该用户EPS域的漫游闭锁。
- 只有当GPRS管理模式为独立管理，或者兼容开关打开的时候，新增参数“PSUSERTPL模板ID”和“EPSUSERTPL模板ID”才允许出现。
- 如果“EPS业务标识”参数为“TRUE”时，并且“UE最大上行带宽”、“UE最大下行带宽”、“NR上行速率”和“NR下行速率”参数都不出现，那么“EPS用户模板ID”必须出现。
- “UE级别的运营商标识”、“UE最大上行带宽”、“UE最大下行带宽”、“无线频率选择优先级”、“Active定时器”、“EUTRAN eDRX周期”、“NB-IOT eDRX周期”、“WB模式PTW”、“NB模式PTW”，这几个参数的优先级高于EPS模板中参数的优先级。当这些参数和“EPS用户模板ID”同时携带时，使用本命令中的参数给用户签约。
- “周期RA/TA更新时间间隔”和“周期RAU/TAU更新时间间隔”两个参数不能同时签约，如果用户先签约了其中一个参数，再签约另一个参数时会强制修改第一个签约的参数值为“0”。
- 如果用户号段的工作模式已配置为“IWF”或“UDM”模式（通过**ADD IWFIMSI**命令配置），此时执行UDM开卡、开户，则需要先执行**RMV IWFSUB**命令删除用户UTA缓存数据，然后再执行**ADD KI**、**ADD SUB**命令为用户开卡、开户。
- 当“5GS用户数据模板”和“全局计费特性”同时存在，或者“5GS用户数据模板”和“标准全局计费特性”同时存在时，如果“5GS用户数据模板”中定义了“用户计费签约数据”参数，计费签约数据以“5GS用户数据模板”中的为准，否则，以“全局计费特性”或“标准全局计费特性”参数值为准。
- 当“5GS用户数据模板”和“GPRS模板ID”同时存在时，如果“5GS用户数据模板”中定义了“用户计费签约数据”参数，计费签约数据以“5GS用户数据模板”中的为准，否则，以“GPRS模板ID”中定义的计费参数为准。
- 当“5GS用户数据模板”和“优化GPRS模板ID”同时存在时，如果“5GS用户数据模板”中定义了“用户计费签约数据”参数，计费签约数据以“5GS用户数据模板”中的为准，否则，以“优化GPRS模板ID”中定义的计费参数为准。
- 当用户签约的“5GS用户数据模板”模板数据发生修改时，如果模板新增或修改了“用户计费签约数据”参数，计费签约数据以修改后的“5GS用户数据模板”中的为准。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 增加用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“卡类型”为“SIM”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“电信业务”为“TS11”，“承载业务”为“BS20”，“是否提供CLIP业务”为“提供”，“CLIP超越属性”为“有效”，“呼叫等待”为“提供”，命令如下：

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=SIM, NAM=BOTH, DEFAULTCALL=TS11, TS=TS11, BS=BS20, CLIP=TRUE, CLIPOR=TRUE, CW=TRUE;
   ```
2. 增加EPS用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“网络接入模式”为“BOTH”，“EPS业务标识”为“TRUE”，“缺省呼叫类型”为“TS11”，“卡类型”为“USIM”，“UE最大上行带宽”为“102400”，“UE最大下行带宽”为“204800”，命令如下:

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=USIM, NAM=BOTH, EPS=TRUE, DEFAULTCALL=TS11,UTRANNOTALLOWED=TRUE, GERANNOTALLOWED=TRUE, AMBRMAXUL=102400, AMBRMAXDL=204800;
   ```
3. 增加普通M2M用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“卡类型”为“USIM”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，命令如下:

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=USIM, NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M;
   ```
4. 增加MSISDN-Less用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“卡类型”为“USIM”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，命令如下:

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", CARDTYPE=USIM, NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M;
   ```
5. 增加M2M Common MSISDN用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“卡类型”为“USIM”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，“M2MCISDN号码”为“8613900001235”，命令如下:

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=USIM, NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M, M2MCISDN="8613900001235";
   ```
6. 增加NPN用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“卡类型”为“USIM”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“5GS用户数据模板”为“1”，“PLMNID”为“111111”，“是否只允许UE通过CAG小区接入5GS”为“TRUE”，“CAGID”为“11111111”，命令如下：

   ```
   ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=USIM, NAM=BOTH, DEFAULTCALL=TS11, NGSUSERTPLID=1, PLMNID="111111", CAGONLY=TRUE, CAGID="11111111";
   ```
