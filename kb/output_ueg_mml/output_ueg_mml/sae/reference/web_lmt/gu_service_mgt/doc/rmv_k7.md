# 删除K7(RMV K7)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条K7数据记录。

## 注意事项

只有没有被使用的K7密钥才可以删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识K7数据记录的关键字段之一，用于指定在哪个HLR上删除K7的数据记录，操作员可以使用LST HLRSN命令查询获得。     |
| K7SNO  | K7序列号  | 标识一条K7数据记录的关键字段之一，用于标识需要删除哪一个K7序列号对应的K7数据记录，操作员可以使用LST K7命令查询获得。 |

## 使用实例

在HSS/HLR中删除“HLR序列号”为“1”，“K7序列号”为“2”的K7密钥：

```
RMV K7: HLRSN=1,K7SNO=2;
```
