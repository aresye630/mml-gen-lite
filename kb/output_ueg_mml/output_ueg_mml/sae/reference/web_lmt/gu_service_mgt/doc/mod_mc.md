# 修改MC业务(MOD MC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来为用户提供或撤销MC业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 如果提供MC业务，PROV=TRUE；如果撤销MC业务，PROV=FALSE。
- 第一次执行此命令，PROV=TRUE时，若不选择参数NBRSB，则NBRSB将取默认值7；若不选择参数NBRUSER，则NBRUSER将取默认值1。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                |
|:------------|:-------------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI         | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                      |
| ISDN        | MSISDN       | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                    |
| RECORDCOUNT | 用户个数         | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名      | IMSIFILE文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                   |
| ISDNFILE    | MSISDN文件名    | ISDNFILE文件名称，1～16个字母或数字组成。 ISDNFILE包含多个不连续的MSISDN号码。                                |
| PROV        | 是否提供MC业务     | 是否提供MC业务。 TRUE：提供 FALSE：不提供                                                         |
| NBRSB       | HLR支持多呼最多呼叫数 | 仅当本命令中的“是否提供MC业务”参数为“TRUE”时该参数有效。HLR支持的多呼最多呼叫数，值域2～7。                               |
| NBRUSER     | 用户决定多呼最多呼叫数  | 仅当本命令中的“是否提供MC业务”参数为“TRUE”时该参数有效。用户决定的多呼最多呼叫数，值域1～7。                                |

## 使用实例

1. 为IMSI号码是460000009012345的用户提供MC业务。

   MOD MC: IMSI="460000009012345", PROV=TRUE;
2. 为IMSI号码是460000009012345的用户撤销MC业务。

   MOD MC: IMSI="460000009012345", PROV=FALSE;
