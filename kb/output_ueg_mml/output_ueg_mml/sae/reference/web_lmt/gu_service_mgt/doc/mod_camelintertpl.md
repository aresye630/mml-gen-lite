# 修改CAMEL查询模板(MOD CAMELINTERTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用此模板的OCSI模板或TCSI模板数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条CAMEL（Customized Applications for Mobile network Enhanced Logic）查询协议模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个CAMEL查询协议模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

- 因为当用户进行位置更新或触发其他涉及CAMEL查询协议模板的流程时，系统会根据用户签约的CAMEL查询协议模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 执行该命令修改CAMEL查询协议模板数据，如果此模板已经被用户使用，请根据实际情况考虑是否需要针对这些用户执行**SND RESET**命令发送Reset消息。模拟Reset消息通常在HLR割接时进行，使原来的用户找到新割接的HLR，在新HLR中存储用户的位置信息（VLR号码/SGSN号码/GMSC号码等），以保证用户能够正常呼叫。
- 该命令不允许进行批操作。
- 系统中同一个CAMEL查询模板增加的GMSC号码前缀记录数不能超过1000条，且所有CAMEL查询模板增加的GMSC号码前缀总记录数不能超过5000条。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                            |
|:--------|:-----------|:------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号     | 标识CAMEL查询协议模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的CAMEL查询协议模板信息数据进行修改，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID   | 模板ID       | 标识CAMEL查询协议模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个CAMEL查询协议模板信息数据进行修改，操作员可以使用LST CAMELINTERTPL命令查询获得。 |
| TPLNAME | 模板名        | 用于标识待修改模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                              |
| PROV    | 是否提供GMSC数据 | 用于标识执行该命令是增加/修改还是删除GMSC号码前缀。 取值范围：TRUE：表示增加/修改GMSC号码前缀。FALSE：表示删除GMSC号码前缀。 默认值：无。               |
| GMSCNP  | GMSC号码前缀   | 用于标识支持CAMEL查询协议的GMSC号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                         |

## 使用实例

修改CAMEL查询协议模板，在一个已存在的模板中增加一个新的GMSC号码前缀。“HLR序列号”为“1”，“模板ID”为“3”，“是否提供GMSC数据”为“TRUE”，“GMSC号码前缀”为“12345678912”：

```
MOD CAMELINTERTPL: HLRSN=1, TPLID=3, PROV=TRUE, GMSCNP="12345678912";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                              | 处理建议                                                                                                                      |
|:--------|:--------|:----------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的CAMEL查询协议模板数据记录不存在。                                             | 使用LST CAMELINTERTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的CAMEL查询协议模板数据记录。                                                      |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”和“模板ID”参数不在相应的参数取值范围内。                                              | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                          |
| ERR1009 | 参数丢失    | 当“是否提供GMSC数据”参数为“TRUE”或“FALSE”时“GMSC号码前缀”参数没有输入。                                  | 当“是否提供GMSC数据”参数为“TRUE”或“FALSE”时，必须同时输入“GMSC号码前缀”参数。                                                                       |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个“模板ID”增加的“GMSC号码前缀”数据记录数超过1000条。所有CAMEL查询模板增加的“GMSC号码前缀”总记录数超过5000条。 | 根据实际情况，如需增加GMSC号码前缀，处理步骤如下：执行LST CAMELINTERTPL命令，查询已存在的GMSC号码前缀。执行该命令删除不必要的GMSC号码前缀。执行该命令增加GMSC号码前缀，确保增加的GMSC号码前缀在规定范围之内。 |
| ERR3096 | 模板不能为空  | 当“是否提供GMSC数据”参数为“FALSE”时删掉的是模板中的最后一条GMSC号码前缀数据。                                   | 当“是否提供GMSC数据”参数为“FALSE”时，使用LST CAMELINTERTPL命令查询，不能删掉模板中的最后一条GMSC号码前缀数据。                                                  |
