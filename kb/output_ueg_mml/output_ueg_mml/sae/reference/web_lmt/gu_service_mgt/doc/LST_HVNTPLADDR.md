# 查询拜访网络地址(LST HVNTPLADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中查询指定拜访网络模板ID关联的所有拜访网络地址。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                      |
|:--------|:---------|:--------------------------------------------------------------------------|
| HLRSN   | HLR序列号   | 用于指示系统需要按照哪个HLR序列号来查询拜访网络地址数据。如果不输入，则表示查询“HLR序列号”为“0”的所有拜访网络地址数据。 说明：可选参数 |
| VNTPLID | 拜访网络模板ID | 用于指示系统需要按照哪个模板ID来查询拜访网络地址数据，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。            |

## 使用实例

查询拜访网络地址，“拜访网络模板ID”为“10”：

```
LST HVNTPLADDR: VNTPLID=10;
```

```
%%LST HVNTPLADDR: VNTPLID=10;%%
RETCODE = 0 操作成功

VN                                                                                                                              VNTYPE
ens.huawei.com                                                                                                                  1
hss.huawei.com                                                                                                                  1
china.huawei.com                                                                                                                0

Total count = 3

There is together 1 report

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                       |
|:--------|:------------------------------------------------------------|
| VN      | 用于显示拜访网络模板中的拜访网络地址。                                         |
| VNTYPE  | 用于显示拜访网络模板的拜访网络地址类型。 “0”：表示IMS系统将允许用户注册。“1”：表示IMS系统将限制用户注册。 |
