# 查询IMS用户的动态数据(LST HDYNDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMS用户相关动态数据，可以查询一组或者一个数据。

## 注意事项

“IMPI”和“IMPU”参数必须至少存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指定一个要查询动态数据IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无。              |
| IMPU   | IMPU   | 用于指定一个要查询动态数据的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无。 |

## 使用实例

查询“IMPI”为“impiinfo”，“IMPU”为“sip:impuinfo@huawei.com”的IMS用户的动态数据。

```
LST HDYNDATA: IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com";
```

```
%%LST HDYNDATA: IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com";%%

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 参数标识               | 参数说明                                                                                                                                                               |
|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI               | 显示用于查询动态数据的IMPI。                                                                                                                                                   |
| IMPU               | 显示用于查询动态数据的IMPU。                                                                                                                                                   |
| IMSUSERST          | 显示IMS用户注册状态。 “0”：NOTREGISTERED，用户未注册状态，且没有指定的S-CSCF。“1”：REGISTERED，用户注册状态，且服务器由指定的S-CSCF来完成。“2”：UNREGISTERED，用户未注册状态，但是签约了未注册业务且触发过此业务，当该状态用户执行呼叫请求时存在指定服务的S-CSCF。 |
| PENDINGFLG         | 显示鉴权未决标志，表示IMS用户在注册流程中鉴权通过，但还未注册完成的中间状态。 NOTPENDING：用户不在鉴权通过，但还未注册完成的中间状态。PENDING：用户在鉴权通过，但还未注册完成的中间状态。                                                            |
| SERVER             | 显示S-CSCF名称。                                                                                                                                                        |
| ISEXISTRESTOREDATA | 显示S-CSCF容灾数据标志。 “0”：指不存在S-CSCF容灾数据。“1”：指存在3GPP标准S-CSCF容灾数据。“2”：指存在华为私有S-CSCF容灾数据。“3”：指存在3GPP标准S-CSCF容灾数据和华为私有S-CSCF容灾数据。                                           |
