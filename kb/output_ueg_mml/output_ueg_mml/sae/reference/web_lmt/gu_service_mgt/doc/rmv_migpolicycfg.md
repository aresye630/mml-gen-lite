# 删除割接策略模板(RMV MIGPOLICYCFG)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该策略ID的用户的消息被转发到错误的HSS或HLR，导致业务呼损，因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系，制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于删除一条割接策略模板数据记录。

## 注意事项

如果已经通过**MOD MIGPOLICY**命令关联该模板，当执行该命令删除割接策略模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该割接策略模板不能被删除。如果需要删除该割接策略模板，必须先执行**MOD MIGPOLICY**命令修改用户签约的割接策略ID，解除用户签约的割接策略数据与系统配置割接策略模板的关联关系，在执行该命令删除模板。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                   |
|:-------------|:-------|:-----------------------------------------------------------------------|
| HLRSN        | HLR序列号 | 标识割接策略模板数据记录的关键字段之一，用于指定需要删除哪个HLR上的割接策略模板数据记录，操作员可以使用LST HLRSN命令查询获得。  |
| MIG_POLICYID | 割接策略ID | 标识割接策略模板记录的关键字段之一，用于指定需要删除哪一条割接策略模板数据记录，操作员可以使用LST MIGPOLICYCFG命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“割接策略ID”为“0”割接策略模板。命令如下：

```
RMV MIGPOLICYCFG: HLRSN=1, MIG_POLICYID=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                                 |
|:--------|:--------|:-------------------------------------|:-----------------------------------------------------------------------------------------------------|
| ERR3007 | 模板未定义   | “HLR序列号”或“策略ID”未定义。                  | 根据实际情况，重新输入已定义的“HLR序列号”或“策略ID”。可通过LST HLRSN命令查询已定义的“HLR序列号”，或通过LST MIGPOLICYCFG命令查询已定义的“策略ID”。       |
| ERR3005 | 模板已经被使用 | 待删除的割接策略模板已经通过MOD MIGPOLICY等命令为用户签约。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD MIGPOLICY命令修改用户签约的割接策略ID，解除用户签约的割接策略数据与系统配置割接策略模板的关联关系，然后才能执行该令删除。 |
