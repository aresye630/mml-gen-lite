# 设置Early AKA鉴权模式(SET HEAA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中设置或取消指定IMPI的Early AKA鉴权模式。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                      |
|:--------|:--------|:------------------------------------------------------------------------------------------|
| IMPI    | IMPI    | 用于定义一个IMPI，此IMPI必须已经和IMSI建立了关联关系，该参数的配置原则是要求输入的IMPI值符合NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无    |
| EAAFLAG | EAA鉴权标识 | 用于定义一个EAAFLAG标识，其值域类型为布尔值。TRUE:支持EAA鉴权。FALSE:不支持EAA鉴权。 取值范围：FALSE(False)TRUE(True) 缺省值： 无 |

## 使用实例

设置Early AKA鉴权模式。IMPI：impiinfo，EAA鉴权标识：TRUE。

```
SET HEAA: IMPI="impiinfo", EAAFLAG=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释               | 原因分析                    | 处理建议                                                                       |
|----------:|:--------------------|:------------------------|:---------------------------------------------------------------------------|
| 900003117 | IMPI与IMSI间的关联关系不存在。 | 输入的IMPI对应的IMSI在数据库中不存在。 | 执行LST IMSSUB命令查询IMPI对应的IMSI信息，若IMPI对应的IMSI不存在，则执行ADD IMSSUB命令重新为用户签约IMS业务。 |
