# 增加TAI与ZC映射关系(ADD TAIZCLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS中增加TAI(Tracking Area Identity)与ZC（Zone Code）映射关系。

## 注意事项

系统中增加的TAI与ZC映射关系记录数不能超过20000条。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                          |
| TAI    | 跟踪区标识  | 用于标识跟踪区，标识TAI与ZC映射关系数据记录的关键字段之一，用于指定需要增加哪些TAI与ZC映射关系数据记录，操作员可以使用LST TAIZCLIST命令查询获得。 默认值：无。 说明：TAI由MCC(Mobile Country Code)，MNC(Mobile Network Code)及TAC(Tracking Area Code)组成，总长度为9或10位。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，有效范围0000-FFFE。 |
| ZC     | 区域码    | 用于标识地区码。 取值范围：4位十六进制字符串。 默认值：无。 说明: 必选参数。FFFF表示无效。                                                                                                                                                                                                                 |

## 使用实例

1. 在“HLR序列号”为“1”的HSS上添加TAI为“460212345”，ZC为“0001”的映射关系：

   ```
   ADD TAIZCLIST: HLRSN=1, TAI="460212345", ZC="0001";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                                                                                                         |
|:--------|:--------|:-----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号添加相同的TAI与ZC映射关系。       | 该TAI与ZC映射关系已添加，根据实际情况确认是否需要添加其他的TAI与ZC映射关系。                                                                                                                  |
| ERR3007 | 记录不存在   | HLR序列号未定义。                         | 根据实际情况选择：如果需要为该HLRSN添加TAI与ZC映射关系，则执行ADD HLRSN命令先定义该HLRSN，再为该HLRSN添加TAI与ZC映射关系。如果需要为已定义的HLRSN添加TAI与ZC映射关系，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN添加TAI与ZC映射关系。 |
| ERR3047 | 超过最大限制  | 增加的“跟踪区标识”与“区域码”映射关系数据记录数超过20000条。 | 根据实际情况，如需增加TAI与ZC映射关系，处理步骤如下：执行LST TAIZCLIST命令，查询已存在的TAI与ZC映射关系。执行RMV TAIZCLIST命令，删除不必要的TAI与ZC映射关系。执行该命令增加TAI与ZC映射关系，确保增加的TAI与ZC映射关系记录数在规定范围之内。              |
