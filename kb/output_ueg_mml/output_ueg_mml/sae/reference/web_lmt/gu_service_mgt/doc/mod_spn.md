## 命令功能

该命令用于为用户签约、修改和去签约SPN（Single Personal Number）业务。该命令支持单用户处理，同时也支持连续以及不连续的用户批处理。

该业务使用的主要场景为车载电话，当签约了SPN业务的用户开车时，如果20s不接电话就会前转到SPN登记的前转号码，从而保证对用户的每一次呼叫都能接通。

- 当使用该命令签约或修改SPN业务参数时，会触发ISD（Insert Subscriber Data）消息给VLR，并将用户的SPN业务数据通过ISD消息下发给VLR。
- 当使用该命令去签约SPN业务时，会触发DSD（Delete Subscriber Data）消息给VLR，在DSD私有信元中携带SPN的业务码。

**说明** 

仅当**ADD NCCTPL**命令中的“SPN业务下发受限标志”参数设置为“SR”时，才会在ISD或DSD消息中携带SPN业务私有信元，否则不会下发该业务的相关数据。

如果UDM支持签约管理优化（执行**SET MAPCONF**命令将“用户被锁后是否允许操作相关补充业务”设置为“TRUE”），即使用户停机，包括运营商锁（LCK）和用户锁（SABLCK），闭锁入呼叫和出呼叫，用户的业务签约变更仍可继续进行。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- SPN业务仅对语音业务生效，并仅在用户不可及或者无应答时前转。
- 登记SPN的前转号码时，需要根据CF的规则进行号码规整和冲突检测处理。
- SPN业务仅支持MAP3版本，且不支持USSD操作。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                  |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识待修改SPN业务的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                    |
| ISDN        | MSISDN    | 用于标识待修改SPN业务的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                  |
| RECORDCOUNT | 用户个数      | 用于标识待修改SPN业务用户的数目。 当需要为连续号码的多个用户修改SPN业务时配置该参数，配置后，系统将会从已指定的“IMSI”号码或“MSISDN”号码开始，对连续号码的多个用户修改SPN业务。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户修改SPN业务，当只有一个用户时，该参数不必配置。当一次修改SPN业务的用户个数很多时，对系统性能无影响，但修改SPN业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI文件名称。 IMSI文件包含多个不连续的待修改SPN业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modspn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                              |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN文件名称。 MSISDN文件包含多个不连续的待修改SPN业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modspn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                        |
| PROV        | 是否提供SPN业务 | 用于标识是否提供SPN业务。 取值范围： TRUE：提供。FALSE：撤销。 默认值：无。                                                                                                                                                                                         |
| FTN         | 前转号码      | 仅当参数“是否提供SPN业务”取值为“TRUE”时该参数有效，用于标识SPN登记前转号码，为有效的国际格式号码。 取值范围：1～16位十进制数字组成的字符串。 默认值：无。                                                                                                                                                |
| PROPERTY    | 前转号码属性    | 仅当参数“是否提供SPN业务”取值为“TRUE”时该参数有效，用于标识登记的前转号码的属性。 取值范围： INTERNATIONAL：国际号码。NATIONAL：国内号码。 默认值：NATIONAL。                                                                                                                                  |
| OFAID       | OFA模板ID   | 仅当参数“是否提供SPN业务”取值为“TRUE”时该参数有效，用于标识通过SPN业务对应的OFA模板ID对用户进行筛选。该参数必须通过ADD OFATPL命令定义后才能在此使用。 取值范围：0～65535 默认值：无。 说明：255和65535表示去签约OFA模板ID。                                                                                               |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供SPN业务数据，“是否提供SPN业务”为“TRUE”，“前转号码”为“460000009”，“前转号码属性”为“INTERNATIONAL”：

   ```
   MOD SPN: IMSI="460000009123456", PROV=TRUE, FTN="460000009", PROPERTY=INTERNATIONAL;
   ```
2. 给3个连续号码的用户提供SPN业务数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“是否提供SPN业务”为“TRUE”，“前转号码”为“460000009”，“前转号码属性”为“INTERNATIONAL”：

   ```
   MOD SPN: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, FTN="460000009", PROPERTY=INTERNATIONAL;
   ```
3. 给3个非连续号码的用户撤销SPN业务数据，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modspn.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供SPN业务”为“FALSE”：

   ```
   MOD SPN: ISDNFILE="modspn.txt", PROV=FALSE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。
