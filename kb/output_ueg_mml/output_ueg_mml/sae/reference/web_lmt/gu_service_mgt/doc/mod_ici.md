# 修改ICI业务(MOD ICI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中给用户签约或去签约ICI（Immediate Call Itemization subscription）业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                     |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要签约或去签约ICI业务信息的用户IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                             |
| ISDN        | MSISDN    | 用于标识需要签约或去签约ICI业务信息的用户MSISDN号码。 取值范围:1～15位的十进制数字组成的字符串。 默认值:无。                                                                                                                           |
| RECORDCOUNT | 用户个数      | 用于标识需要修改ICI业务信息的用户数目。 当需要为连续号码的多个用户修改ICI业务信息时配置该参数，配置后系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改ICI业务信息。 取值范围：1～100000 默认值：无。                                                               |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改类型的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modici.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母，数字或字母和数字组成的字符串。 默认值：无。       |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改类型的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modici.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母，数字或字母和数字组成的字符串。 默认值：无。 |
| PROV        | 是否提供ICI业务 | 用于标识是否给用户提供ICI业务。 取值范围： TRUE：提供ICI业务。FALSE：不提供ICI业务。 默认值：FALSE。                                                                                                                          |

## 使用实例

1. 在HLR上修改“IMSI”号码为“460000009123456”的用户ICI信息：

   ```
   MOD ICI: IMSI="460000009123456", PROV=TRUE;
   ```
2. 在HLR上修改“IMSIFILE”名为“modici.txt”批操作文件中的用户ICI信息：

   ```
   MOD ICI: IMSIFILE="modici.txt", PROV=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                 | 处理建议                                                                                                                      |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突    | 可能原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。 “用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。 “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1004 | 无效的参数值  | 输入的“IMSI”或“MSISDN”参数值不在取值范围内。                                                                        | 请重新输入正确的“IMSI”或“MSISDN”参数值。                                                                                               |
