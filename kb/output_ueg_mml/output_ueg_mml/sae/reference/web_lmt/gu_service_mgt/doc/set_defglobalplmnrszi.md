# 设置全局PLMN区域缺省漫游限制(SET DEFGLOBALPLMNRSZI)

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响该HLRSN中用户的缺省漫游能力，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于设置全局PLMN区域缺省漫游限制业务数据。当某一HLRSN中用户漫游到未通过**MOD GLOBALPLMNRSZI**命令设置全局PLMN区域漫游限制状态的区域时，可以通过本命令设置是否允许该HLRSN中用户漫游。

## 注意事项

- 该命令不允许进行批操作。
- “缺省漫游限制状态”和“漫游限制时的错误码”参数至少输入一个。
- 当执行**ADD HLRSN**命令添加一个HLRSN后，系统会为该HLRSN自动生成一条“缺省漫游限制状态”为“PERMISSION”、“漫游限制时的错误码”为“ROAMNTALD”的全局PLMN区域缺省漫游限制记录。
- 通过该命令设置的数据只对S6a/S6d接口生效。

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号    | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| DEFAULTRULE    | 缺省漫游限制状态  | 用于标识全局PLMN区域缺省漫游的限制能力，即用户漫游到未通过MOD GLOBALPLMNRSZI命令设置全局PLMN区域漫游限制的区域时，是否允许漫游。 取值范围：PERMISSION：漫游允许RESTRICT：漫游限制 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| DEFAULTERRCODE | 漫游限制时的错误码 | 用于标识UDM处理全局PLMN区域缺省漫游限制时返回给网络侧的错误码。通过返回的错误码或其携带的诊断信息可以排查出该HLRSN中用户漫游失败的原因。 取值范围： ROAMNTALD：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，不携带诊断信息。ROAMNTALDODBH：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_HPLMN_APN，表示闭锁了归属PLMN的APN。ROAMNTALDODBV：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_VPLMN_APN，表示闭锁了拜访PLMN的APN。ROAMNTALDODBA：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_ALL_APN，表示闭锁了所有的APN。RATNTALD：返回DIAMETER_ERROR_RAT_NOT_ALLOWED (5421)，不携带诊断信息。UNEPSSUB：返回DIAMETER_ERROR_UNKNOWN_EPS_SUBSCRIPTION (5420)，不携带诊断信息。UNEPSSUBNOGD：返回DIAMETER_ERROR_UNKNOWN_EPS_SUBSCRIPTION (5420)，携带诊断信息为NO_GPRS_DATA_SUBSCRIBED，表示无GPRS签约数据。USERUNKNOWN：返回DIAMETER_ERROR_USER_UNKNOWN (5001)，不携带诊断信息。 默认值：无。 |

## 使用实例

为“HLR序列号”为“1”中的用户设置全局PLMN区域缺省漫游限制数据。“缺省漫游限制状态”为“RESTRICT”，“漫游限制时的错误码”为“ROAMNTALD”：

```
SET DEFGLOBALPLMNRSZI: HLRSN=1, DEFAULTRULE=RESTRICT, DEFAULTERRCODE=ROAMNTALD;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                                                      |
|:--------|:--------|:-------------------------------|:--------------------------------------------------------------------------|
| ERR1009 | 参数丢失    | “缺省漫游限制状态”和“漫游限制时的错误码”参数都没有输入。 | 根据实际情况，重新输入“缺省漫游限制状态”和“漫游限制时的错误码”参数的值，确保满足“缺省漫游限制状态”和“漫游限制时的错误码”参数至少输入一个。 |
