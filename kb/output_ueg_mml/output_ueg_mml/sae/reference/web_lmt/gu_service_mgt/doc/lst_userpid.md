# 查询用户的归属分区(LST USERPID)

## 命令功能

该命令用于查询用户的PID（Service Partition标识）信息：

- 若需要查询单个用户的PID信息，请输入“IMSI”、“MSISDN”、“PI”或“PU”。
- 若需要查询多个连续用户的PID信息，请输入“IMSI”、“MSISDN”、“PI”或“PU”与“用户个数”的组合。
- 若需要查询多个不连续用户的PID信息，请输入“IMSI文件名”、“MSISDN文件名”、“PI文件名”或“PU文件名”。

## 注意事项

- 该命令只允许在vRSP上执行。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“PI”、“PU”、“PI文件名”及“PU文件名”八个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”、“MSISDN文件名”，“PI文件名”或“PU文件名”同时配置。
- 该命令报文仅显示输入的“IMPI”或“IMPU”的PID信息，如果是VoLTE 用户，建议使用“IMSI”或“ISDN”查询PID信息。

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                       |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识系统按照哪个“IMSI”号码查询用户的PID信息。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                               |
| ISDN        | MSISDN    | 用于标识系统按照哪个“MSISDN”号码查询用户的PID信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                              |
| PI          | PI        | 用于标识系统按照哪个“IMPI”或“PISI”号码查询用户的PID信息。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                                              |
| PU          | PU        | 用于标识系统按照哪个“IMPU”或“PUSI”号码查询用户的PID信息。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                                              |
| RECORDCOUNT | 用户个数      | 用于指定系统查询多少个连续用户的PID信息。 当需要查询连续号码的PID信息时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，查询连续号码的多个用户的PID信息。 取值范围：1～10000 默认值：无。                                                                                                         |
| IMSIFILE    | IMSI文件名   | 用于标识系统按照哪个“IMSI文件名”查询用户的PID信息。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“PIDinfo.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。                                  |
| ISDNFILE    | MSISDN文件名 | 用于标识系统按照哪个“MSISDN文件名”查询用户的PID信息。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“PIDinfo.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。                            |
| PIFILE      | PI文件名     | 用于标识系统按照哪个“IMPI”或“PISI”查询用户的PID信息。 IMPI/PISI批操作文件包含多个不连续的需要修改割接策略数据的IMS用户的IMPI/PISI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimsmigpolicy.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见PIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。 |
| PUFILE      | PU文件名     | 用于标识系统按照哪个“IMPU”或“PUSI”查询用户的PID信息。IMPU/PUSI批操作文件包含多个不连续的需要修改割接策略数据的IMS用户的IMPU/PUSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimsmigpolicy.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见PUFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。  |

## 使用实例

查询“IMSI”号码为“811111111111171”用户的PID信息：

```
LST USERPID: IMSI="811111111111171";
```

```
%%LST USERPID: IMSI="811111111111171";%%

                          IMSI = 811111111111171
                          ISDN = 811111111111111
                           PID = 81

Total count = 3

There is together 1 report

---    END
```
