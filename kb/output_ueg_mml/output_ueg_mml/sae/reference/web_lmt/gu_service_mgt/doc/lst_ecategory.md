# 查询增强用户类别(LST ECATEGORY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用来查询用户的增强用户类别业务属性。

## 注意事项

IMSI和ISDN是可选参数，任何一个参数出现即可，但两个参数不能同时出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                               |
|:------------|:----------|:-----------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                    |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                  |
| RECORDCOUNT | 用户个数      | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1～16个由字母、数字、下划线和点号组成的字符串。IMSIFILE包含多个不连续的IMSI号码。                          |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个由字母、数字、下划线和点号组成的字符串。ISDNFILE包含多个不连续的MSISDN号码。                        |

## 使用实例

查询IMSI号码为460000009123456的用户的增强用户类别业务属性。

```
LST ECATEGORY: IMSI="460000009123456";
```
