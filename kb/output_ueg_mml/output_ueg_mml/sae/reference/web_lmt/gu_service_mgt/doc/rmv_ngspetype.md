# 删除NGS对端类型（RMV NGSPETYPE）

- 命令功能
- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响用户的漫游业务，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于删除对端类型数据记录。

## 注意事项

- 如果输入的“AMF身份类型”参数取值为“PLMN”，则必须输入“PLMNID”参数。
- 如果输入的“AMF身份类型”参数取值为“AMFREGION”，则必须输入“PLMNID”和“AMF Region ID”参数。
- 如果输入的“AMF身份类型”参数取值为“AMFSET”， 则必须输入“PLMNID”、“AMFREGION”和“AMFSET”参数。

## 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                              |
|:----------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号        | 可选必选说明：必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定删除哪个HLR序列号上的NGS对端类型数据记录，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无 配置原则：无                                                               |
| PETYPE    | AMF身份类型       | 可选必选说明：必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要删除哪一个AMF、SMF或SMSF网元类型对应的NGS对端类型数据记录，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围： PLMNAMFREGIONAMFSET 默认值：无 配置原则：无                              |
| PLMN      | PLMNID        | 可选必选说明：必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要删除哪一个PLMNID对应的NGS对端类型数据记录，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围：5～6位的十进制数字组成的字符串。 默认值：无 配置原则：无                                           |
| AMFREGION | AMF Region ID | 可选必选说明：条件必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要删除哪一个AMF Region ID对应的NGS对端类型数据记录，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围：0～255 默认值：无 配置原则：仅当本命令中的“AMF身份类型”参数为“AMFREGION”或“AMFSET”时该参数有效。 |
| AMFSET    | AMF Set ID    | 可选必选说明：条件必选参数 参数含义：标识一条NGS对端类型数据记录的关键字段之一，用于指定需要删除哪一个AMF Set ID对应的NGS对端类型数据记录，操作员可以使用LST NGSPETYPE命令查询获得。 取值范围：0～1023 默认值：无 配置原则：仅当本命令中的“AMF身份类型”为“AMFSET”时该参数有效。                 |

## 使用实例

当调整5G漫游闭锁业务，不再使用某些对端AMF业务属性时，需要将其删除，配置举例如下：

1. 删除“HLR序列号”为“3”的UDM上的对端类型数据，其中“AMF身份类型”为“PLMN”，“PLMNID”为“11111”：

   ```
   RMV NGSPETYPE: HLRSN=3, PETYPE=PLMN, PLMN="11111";
   ```
2. 删除“HLR序列号”为“1”的UDM上的对端类型数据，其中“AMF身份类型”为“AMFREGION”，“PLMNID”为“11111”，“AMF Region ID”为“2”：

   ```
   RMV NGSPETYPE: HLRSN=1, PETYPE=AMFREGION, PLMN="11111", AMFREGION=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                                               | 处理建议                                                                                                                         |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数缺失    | 原因为如下之一： 必选参数缺失：“HLR序列号”、“AMF身份类型”、“PLMNID”参数中的一个或多个缺失。可选参数缺失：“AMF身份类型”参数取值为“AMFREGION”时，参数“AMF Region ID”缺失。“AMF身份类型”参数取值为“AMFSET”时，“AMF Region ID”、“AMF Set ID”参数其中一个缺失或者两个同时缺失。 | 重新输入缺失的参数： 当“AMF身份类型”参数取值为“AMFREGION”时，必须输入参数“AMF Region ID”。 当“AMF身份类型”参数取值为“AMFSET”时，必须同时输入“AMF Region ID”和“AMF Set ID”参数。 |
| ERR1010 | 参数冲突    | “AMF身份类型”参数取值和“AMF Region ID”、“AMF Set ID”参数冲突： “AMF身份类型”参数取值为“PLMN”时，输入了“AMF Region ID”、“AMF Set ID”参数中的一个或两个。“AMF身份类型”参数取值为“AMFREGION”时，输入了“AMF Set ID”参数。                       | 根据“AMF身份类型”、“AMF Region ID”、“AMF Set ID”参数的配置原则重新输入参数值，然后执行本命令。                                                              |
| ERR3007 | 记录未定义   | 可能原因为如下之一： 输入的“HLR序列号”未定义。输入的“PLMNID”、“AMF Region ID”或“AMF Set ID”参数中的一个或多个的参数值不正确。                                                                                                | 执行LST HLRSN命令查询“HLR序列号”，输入正确参数值后重新执行本命令删除。执行LST NGSPETYPE命令查询对端类型数据，输入正确的参数值后重新执行该命令进行删除。                                    |
