# 增加5G业务区域信息模板(ADD SERAREATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置5G业务区域信息模板，为用户签约做准备。

操作员通过执行**MOD AMDATA**命令可以给5G用户签约该模板，系统将在指定区域限制用户的业务。运营商可以灵活高效的对用户进行移动性管理。

## 注意事项

系统中增加的5G业务区域信息模板记录数不能超过20000条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 可选必选说明：必选参数 参数含义：用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| TPLID       | 模板ID     | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| TPLNAME     | 模板名      | 可选必选说明：可选参数 参数含义：用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| SERAREAINFO | 业务区域限制信息 | 可选必选说明：必选参数 参数含义：用于标识业务区域限制信息。 取值范围：不超过4000位的字符串。业务区域限制信息符合Json格式，具体格式请参考3GPP 29.503协议。名称和类型如下： restrictionType：业务区域限制类型。字符串枚举类型，取值可以是：ALLOWED_AREAS：允许服务区域注册的区域。NOT_ALLOWED_AREAS：不允许服务区域注册的区域。 areas：区域信息。包含以下字段：tacs：跟踪区域代码。areaCode/areaCodes：区域代码，每个区域代码代表跟踪区域的集合。29.571-f30及之前版本协议支持信元名称为areaCodes，29.571-f40及之后版本协议支持信元名称为areaCode。 maxNumOfTAs：允许跟踪区域的最大数量。最小值为0的整数类型。 格式如下： {\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}]}{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}]}{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}]\,\"maxNumOfTAs\":2} 默认值：无 配置原则： 该参数的配置需要满足Json格式，如果输入中包含“"”和“,”特殊字符，则在这些特殊字符前添加转义字符“\”。areas数组中，每一个对象中的tacs、areaCode和areaCodes同时仅允许配置1个。当restrictionType=NOT_ALLOWED_AREAS时，不需要配置参数maxNumOfTAs。业务区域限制类型不能同时配置两种枚举类型。 |

## 使用实例

若运营商需要对指定5G业务区域进行限制管理，则需要先增加5G业务区域信息模板，后续签约给用户以对用户进行移动性管理。

1. 增加1个5G业务区域信息模板，该模板ID指定的区域允许服务注册，下面示例为areas数组中的tacs和areaCodes取值配置样例的几种场景。

   ```
   ADD SERAREATPL: HLRSN=1, TPLID=100, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"430A5B\"]}]}";
   ADD SERAREATPL: HLRSN=1, TPLID=101, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}]}";
   ADD SERAREATPL: HLRSN=1, TPLID=102, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}]}";
   ADD SERAREATPL: HLRSN=1, TPLID=103, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}\,{\"tacs\":[\"430A6B\"]}]}";
   ADD SERAREATPL: HLRSN=1, TPLID=106, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}\,{\"areaCode\":\"4306\"}]}";
   ADD SERAREATPL: HLRSN=1, TPLID=107, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}\,{\"areaCodes\":\"4306\"}]}";
   ```
2. 增加1个5G业务区域信息模板，该区域允许服务注册，并指定tac数量不能大于2。

   ```
   ADD SERAREATPL: HLRSN=1, TPLID=108, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}]\,\"maxNumOfTAs\":2}";
   ```
3. 增加1个5G业务区域信息模板，该模板ID指定的区域不允许服务注册。

   ```
   ADD SERAREATPL: HLRSN=1, TPLID=111, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"NOT_ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4306\"}]}";
   ```
