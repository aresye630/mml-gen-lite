# 查询前转号码变换(LST FTNTRANS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询前转号码变换表信息：

- 若需要查询全部的前转号码变换表信息，请输入“HLR序列号”即可。
- 若需要查询某个旧前转号码前缀相关的前转号码变换表信息，请输入“HLR序列号”和“旧前转号码前缀”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                  |
|:-------|:--------|:------------------------------------------------------|
| HLRSN  | HLR序列号  | 用于指示系统按照哪个HLR序列号来查询前转号码变换表信息，该参数必须选择。                 |
| OLDFTN | 旧前转号码前缀 | 用于指示系统按照哪个旧前转号码前缀来查询前转号码变换表信息；若不输入，则表示查询所有的前转号码变换表信息。 |

## 使用实例

1. 为了了解前转号码变换表某条记录的信息，通过此命令查询。其中“HLR序列号”为“1”，“旧前转号码前缀”为“01”：

   ```
   LST FTNTRANS: HLRSN=1, OLDFTN="01";
   ```

   ```
   %%LST FTNTRANS: HLRSN=1, OLDFTN="01";%%
   RETCODE = 0 SUCCESS0001:操作成功

           OLD FTN PREFIX                NEW FTN PREFIX
           01                            1

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”的HLR上的前转号码变换表信息的所有记录：

   ```
   LST FTNTRANS: HLRSN=1;
   ```

   ```
   %%LST FTNTRANS: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

           OLD FTN PREFIX                NEW FTN PREFIX
           003                           3
           01                            1
           02                            

   Total count = 3

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET FTNTRANS**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                                     |
|:--------|:--------|:---------------------------------------|:-----------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“旧前转号码前缀”的取值中含有0～9以外的字符。             | 重新输入“前转号码”，确保只含有0～9以内的字符。                                                                |
| ERR3007 | 记录不存在   | 有两点原因：HLR序列号未定义。HLR序列号对应的“旧前转号码前缀”未添加。 | 对于第一点原因，执行LST HLRSN命令查询出已定义的HLRSN，然后在执行命令时输入即可。 对于第二点原因，在执行LST FTNTRANS命令时只输入“HLR序列号”即可。 |
