# 删除短消息Short-Code类型(RMV SCTYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条短消息Short-Code类型数据记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                            |
|:-----------|:-------------|:------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 标识短消息Short-Code类型数据记录的关键字段之一，用于指定在哪个HLR上删除短消息Short-Code类型的数据记录，操作员可以使用LST HLRSN命令查询获得。          |
| CODEPREFIX | Short-Code前缀 | 标识一条短消息Short-Code类型数据记录的关键字段之一，用于标识需要对哪一条短消息Short-Code类型数据记录的参数进行修改或调整，操作员可以使用LST SCTYPE命令查询获得。 |

## 使用实例

删除短消息Short-Code类型数据，“HLR序列号”为“1”，“Short-Code前缀”为“800”：

```
RMV SCTYPE: HLRSN=1, CODEPREFIX="800";
```
