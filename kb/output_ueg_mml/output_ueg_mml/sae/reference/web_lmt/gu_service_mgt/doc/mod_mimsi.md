## 命令功能

该命令用于为用户修改一号多卡业务的数据，包括增加辅IMSI/删除辅IMSI/修改呼叫序号/修改短消息接收卡/修改VOBB卡/去签约等6种操作。

UDM的一号多卡业务有如下特性：

- 支持一个MSISDN号码最多可以签约9张不同的（U）SIM卡。
- 每张卡都拥有独立的鉴权数据和动态数据，所有的卡具有同样的业务签约数据。
- 所有的卡都可以做主叫和被叫。
- 只有一张（U）SIM卡可以接收短消息。

对于在网用户执行该命令后，如果是给用户签约该业务，则UDM会向MSC/VLR/MME/S4SGSN下发插入用户数据消息；如果是给用户去签约该业务，则UDM会向MSC/VLR/MME/S4SGSN下发删除用户数据消息。对于不在网用户执行该命令后，则仅会更新用户在数据库中的数据，当用户进行位置更新时UDM将用户的一号多卡业务数据下发给MSC/VLR/MME/S4SGSN。

## 注意事项

- “IMSI”、“MSISDN”两个参数是可选参数，必须有且只能有一个参数出现。
- 执行该命令前需要先设置**SET MAPCONF**命令的“是否支持多IMSI”参数为“TRUE”。
- MIMSI业务还与其他许多业务存在冲突，不能同时签约。这些业务包括：COMISDN、多SIM、多SIM增强、Home Zone、一卡多号、一卡多号多Profile、FM、ALS、LINKED SIM、M2M COMISDN和M2M ISDN-Less。
- 使用MIMSI业务时，辅卡不能存在IMS用户数据。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 在5G网络中，UDM目前仅支持平等卡类型的一号多卡业务。

## 参数说明

| 参数标识                    | 参数名称                  | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:------------------------|:----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI                    | IMSI                  | 用于标识待修改一号多卡业务数据的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ISDN                    | ISDN                  | 用于标识待修改一号多卡业务数据的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| PROV                    | 是否提供多IMSI业务           | 用于标识执行该命令是给用户提供还是撤销一号多卡业务。 取值范围：TRUE：提供FALSE：撤销 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| CALL_INDEX1             | IMSI的呼叫序号             | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识一号多卡业务用户做被叫时，签约该业务的（U）SIM卡的呼叫序号。 取值范围：1～9 默认值：无。 说明：对于主辅卡和顺振类型，呼叫序号表示各（U）SIM卡振铃的顺序。对于同振和平等卡类型，呼叫序号只用来区分不同的（U）SIM卡，不代表优先级。                                                                                                                                                                                                                                                                                                                                                                                               |
| OPTIONTYPE              | 操作类型                  | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识执行该命令是增加还是修改辅IMSI号码。 取值范围：ADD：增加MOD：修改 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| MIMSITYPE               | 多IMSI类型               | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识签约一号多卡业务的用户作为被叫时（U）SIM卡的呼叫类型。 取值范围：MultiIMSI：主辅卡，当某主叫用户呼叫被叫MSISDN号码的时候，系统仅对呼叫序号最高且在网的IMSI进行呼叫。不需要华为MSC/VLR/MME/S4SGSN网元的支持。OrderlyRing：顺振，当某主叫用户呼叫被叫MSISDN号码的时候，系统会根据用户IMSI号码的呼叫序号顺序振铃，直到IMSI号码的呼叫序号较高用户通话成功。存在9个在网的IMSI对应的用户都不接听电话的情况，这时UDM支持把本次入呼叫转移到指定的语音邮箱中。当前UDM只支持2个语音邮箱号码，可以执行MOD MIMSIVM命令进行设置。需要华为MSC/VLR/MME/S4SGSN网元的支持。SimultaneousRing：同振，可以实现多张（U）SIM卡同时振铃，当有一张卡接通或所有的卡都呼叫失败时终止呼叫。需要华为MSC/VLR/MME/S4SGSN网元的支持。OneLive：平等卡，当某主叫用户呼叫被叫MSISDN号码时候，系统将振铃当前UDM中登记有位置信息的用户。不需要华为MSC/VLR/MME/S4SGSN网元的支持。 默认值：无。 |
| IMSI2-IMSI9             | IMSI2～IMSI9           | 用于标识待签约一号多卡业务用户的8个辅号。 取值范围：IMSI号码，E.212格式的编码，为6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| CALL_INDEX2-CALL_INDEX9 | IMSI2的呼叫序号～IMSI9的呼叫序号 | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识一号多卡业务用户做被叫时，各个（U）SIM卡的呼叫序号。呼号序号的作用请参考“多IMSI类型”参数的取值范围内容。 取值范围：1～9 默认值：无。 说明：可以执行ADD USSDDAT命令设置USSD（Unstructured Supplementary Service Data）业务码，通过USSD方式设置和查询用户做被叫时辅号的呼叫序号。                                                                                                                                                                                                                                                                                                                                            |
| MIMSI_SMS               | 短消息接收卡                | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识设置哪个（U）SIM卡为短消息接收卡，只有该卡可以接收短消息。 取值范围：1～9 默认值：无。 说明：可以执行ADD USSDDAT命令设置USSD业务码，通过USSD方式设置短消息接收卡。当用户签约平等卡类型（指同一时刻只允许9个IMSI号码中的一个IMSI号码在UDM有位置信息），不允许修改短消息接收卡号。                                                                                                                                                                                                                                                                                                                                                            |
| MIMSI_VOBB              | VOBB卡                 | 仅当本命令中的“是否提供多IMSI业务”参数为“TRUE”时该参数有效。用于标识设置哪张卡为VOBB卡。VOBB用户短消息灵活路由指可以把固定电话号码当作MSISDN处理。当VOBB卡对应的IMSI无法接收短消息时，要用呼叫序号最高的那个IMSI来接收短消息。 取值范围：0～9，0表示没有设置VOBB卡。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值0。                                                                                                                                                                                                                                                                                                                                                                   |

## 使用实例

为“IMSI”为“123456789012345”的用户提供一号多卡业务，该卡的“IMSI的呼叫序号”为“1”，1号辅卡IMSI为：234567891234567，该卡呼叫序号为2，2号辅卡IMSI为：345678912345678，该卡呼叫序号为3。其中“多IMSI类型”为“MultiIMSI”，签约序号为1的卡为短消息接收卡。命令如下：

```
MOD MIMSI: IMSI="123456789012345", CALL_INDEX1=1, PROV=TRUE, OPTIONTYPE=ADD, MIMSITYPE=MultiIMSI, IMSI2="234567891234567", CALL_INDEX2=2, IMSI3="345678912345678", CALL_INDEX3=3, MIMSI_SMS=1;
```

**说明** 

2G/3G/4G一号多卡特性的详细配置内容请参见“WHFD-218035 一号多卡”特性手册。
