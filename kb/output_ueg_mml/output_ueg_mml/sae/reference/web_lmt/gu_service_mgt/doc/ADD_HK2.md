# 增加K2(ADD HK2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条鉴权数据K2的数据记录。K2是鉴权计算的一个输入参数，用于作为加密密钥对KI数据进行加密，加密算法为AES256算法。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“K2值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“K2值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                    |
|:--------|:-------|:------------------------------------------------------------------------|
| K2SNO   | K2序列号  | 用于标识鉴权数据K2的序列号，以方便对鉴权数据K2进行查询和引用，配置原则是不能与已有的K2序列号重复。 取值范围：1～254。 默认值：无。 |
| KEYNAME | K2名称   | 用于标识K2密钥名称。 取值范围：1～60位的字符串。 默认值：无。                                      |
| K2VALUE | K2值    | 用于标识K2密钥值。 取值范围：64位的十六进制数字组成的字符串。 默认值：无。                                |

## 使用实例

增加K2数据记录，“K2序列号”为“1”，“K2值”为“8765432187654321876543218765432187654321876543218765432187654321”：

```
ADD HK2: K2SNO=1, K2VALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                                | 原因分析                                                          | 处理建议                                                                      |
|----------:|:-------------------------------------|:--------------------------------------------------------------|:--------------------------------------------------------------------------|
| 900003515 | 已启用随机密钥功能，请先执行SET RANDOMKEY命令生成随机密钥。 | 已启用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，执行SET RANDOMKEY命令生成随机密钥，并设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。 |
| 900003519 | 请求消息中的K2Index已经存在                    | “K2序列号”在数据库中已存在。                                              | 根据实际情况，重新输入参数，确保输入的“K2序列号”参数和系统中已存在的不重复。可执行LST HK2命令查询系统中已存在的K2数据记录。      |
| 900003523 | 密钥丢失                                 | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                               |
