# 增加APN运营商标识符模板(ADD APNOITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一个APNOI模板。

APNOI模板标识了GPRS业务中的APNOI数据，通过执行**MOD GPRS**或**MOD PSAPNOI**命令为用户签约APN级别或PS域UE级别的APNOI数据时，只需要签约APNOI模板即可。UDM在位置更新或用户签约APNOI数据时会把用户签约的数据下发到用户所在的SGSN，SGSN根据用户位置更新的情况决定是否更新用户的APNOI数据信息。

- 当用户在网但未进行位置更新时，SGSN保持原有的APNOI数据信息不变。
- 当用户不在网时，保持原有的APNOI数据信息不变，重新在网后SGSN会从UDM获取用户最新的位置信息并更新APNOI数据。

## 注意事项

系统中增加的APN运营商标识符模板记录数不能超过5000条。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                          |
|:--------|:----------|:------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号    | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                     |
| TPLID   | 模板ID      | 用于标识待增加模板在系统中的序号。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。                                                                         |
| TPLNAME | 模板名       | 用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                            |
| APNOI   | APN运营商标识符 | 用于标识待增加模板的APN运营商标识符。 取值范围：1～63个字母或十进制数字组成的相对域名格式字符串。 默认值：无。 说明：后面带有“.”的就是绝对域名，其他都是相对域名，例如：huawei.com.就是绝对域名，huawei.com就是相对域名。 |

## 使用实例

为PS域UE级别的用户添加一个APNOI模板，操作员需要进行以下数据配置。

1. 增加一个APNOI模板，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“test”，“APN运营商标识符”为“abc.com”：

   ```
   ADD APNOITPL: HLRSN=1, TPLID=2, TPLNAME="test", APNOI="abc.com";
   ```
2. 为“IMSI”号码为“2222222”的用户签约APN数据，“是否提供PS域UE级别的APN运营商标识符”为“TRUE”，“PS域UE级别的APN运营商标识符模板ID”号码为“2”：

   ```
   MOD PSAPNOI: IMSI="2222222", PROV=TRUE, PSAPNOITPLID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                                                                                                               |
|:--------|:--------|:--------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3004 | 模板已存在   | 用户输入的“模板ID”参数在该HLR中已添加。   | 先执行LST APNOITPL命令查询已添加的模板，然后重新输入未添加的“模板ID”及其他信息。                                                                                                   |
| ERR3007 | 记录不存在   | 用户输入的“HLR序列号”在系统中未添加。     | 先执行LST HLRSN命令查询已添加的“HLR序列号”，然后根据查询结果重新输入“HLR序列号”及其他信息或使用ADD HLRSN命令先添加虚拟HLR后再执行此命令。                                                               |
| ERR3047 | 超过最大限制  | 增加的APN运营商标识符模板记录数超过5000条。 | 根据实际情况，如需增加APN运营商标识符模板，处理步骤如下：执行LST APNOITPL命令，查询已存在的APN运营商标识符模板。执行RMV APNOITPL命令，删除不必要的APN运营商标识符模板。执行该命令增加APN运营商标识符模板，确保增加的APN运营商标识符模板记录数在规定范围之内。 |
