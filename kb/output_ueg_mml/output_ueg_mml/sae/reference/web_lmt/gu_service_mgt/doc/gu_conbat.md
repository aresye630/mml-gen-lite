# 业务条件批操作（CONBAT）

- 命令功能

- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成链路拥塞、CPU负荷过载等现象，因此执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用于按照业务条件批量执行MML命令。

此操作可以通过用户号段、指定的业务条件对用户进行过滤，并对过滤后用户进行业务签约、修改或去签约。

## 注意事项

- “起始IMSI”和“结束IMSI”参数必须同时指定或同时不指定，且长度必须相等；这两个参数同时指定时，“结束IMSI”的取值必须大于“起始IMSI”的取值。
- “起始MSISDN”和“结束MSISDN”必须同时指定或同时不指定，且长度必须相等；这两个参数同时指定时，“结束MSISDN”的取值必须大于“起始MSISDN”的取值。
- “IMSI文件名”、“MSISDN文件名”、“起始IMSI”/“结束IMSI”和“起始MSISDN”/“结束MSISDN”是四组可选参数，但最多只能出现一组。
- “业务条件”是可选参数，“新业务”是必选参数，“业务条件”和“新业务”都最多可以选择8项业务，并且可以和“起始IMSI”/“结束IMSI”或“起始MSISDN”/“结束MSISDN”参数同时出现。
- 当“(新)多方会话补充业务”取值为“TRUE”时，用户必须已签约HOLD业务，否则需要同时设置“(新)呼叫保持补充业务”参数为“TRUE”。
- 当“(新)显式呼叫转移补充业务”取值为“TRUE”时，用户必须已签约HOLD业务，否则需要同时设置“(新)呼叫保持补充业务”参数为“TRUE”。
- 当“(新)是否提供ACR业务”取值为“TRUE”时，用户必须已签约CLIP业务，否则需要同时设置“(新)CLIP补充业务”参数为“TRUE”。
- AOCC和AOCI是互斥业务，不能同时签约。
- 当“业务条件”参数取值为“AOC”时，参数AOCC和AOCI至少提供一个，但不能同时为TRUE；当“新业务”取值为“AOC”时，参数“(新)是否提供AOCC业务”和“(新)是否提供AOCI业务”至少提供一个，但不能同时为“TRUE”。
- 当“业务条件”参数取值为“CB”时，参数“CB类型”和“CB控制属性”至少提供一个；当“新业务”参数取值为“CB”时，参数“(新)CB类型”和“(新)CB控制属性”至少提供一个。
- 当“业务条件”参数取值为“ODBECT”时，参数“ODB-闭锁显式呼叫转移业务”、“ODBECT-呼入/呼出业务均由被服务用户付费”和“ODBECT-被服务用户在同一MSC/VLR中存在已被转移呼叫”至少提供一个；当“新业务”参数取值为“ODBECT”时，参数“(新)ODB-闭锁显式呼叫转移业务”、“(新)ODBECT-呼入/呼出业务均由被服务用户付费”和“(新)ODBECT-被服务用户在同一MSC/VLR中存在已被转移呼叫”至少提供一个。
- 当“业务条件”参数取值为“ODBPOS”时，参数“ODB-闭锁分组业务”和“ODB-闭锁PDP上下文激活有效的标识类型”至少提供一个；当“新业务”参数取值为“ODBPOS”时，参数“(新)ODB-闭锁分组业务”和“(新)ODB-闭锁PDP上下文激活有效的标识类型”至少提供一个。
- 当“业务条件”参数取值为“EIN”时，参数“是否提供EOCSI业务”、“是否提供ETCSI业务”、“是否提供BEOCSI业务”和“是否提供EOICK业务”至少提供一个；当“新业务”参数取值为“EIN”时，参数“(新)是否提供EOCSI业务”、“(新)是否提供ETCSI业务”、“(新)是否提供BEOCSI业务”和“(新)是否提供EOICK业务”至少提供一个。
- 当“(新)是否提供CFD业务”取值为“FALSE”时，参数“(新)CFD缺省的前转业务”和“(新)CFD基本业务组”至少提供一个，但是不能同时存在。
- 当“(新)是否提供增强用户类别”取值为“TRUE”时，参数“(新)增强用户类别”和“(新)增强类别扩展”至少出现一个，并且如果输入的“(新)增强类别扩展”为有效值，则命令中或者数据库中一定有用户的ECATEGORY签约信息；当“(新)是否提供增强用户类别”取值为“FALSE”时，参数“(新)增强用户类别”和“(新)增强类别扩展”不能出现。
- 当“新业务”参数取值为“EPS”且不输入“业务条件”参数时，表示为指定号段的用户签约或修改AMBR数据。
- 当“是否提供EPSAMBR业务”参数取值为“TRUE”时，如果“UE最大上行带宽”和“UE最大下行带宽”参数同时都不输入，表示按照当前已有的UE最大上下行带宽只过滤EPS用户。
- 当“(新)是否提供EPSAMBR业务”参数取值为“TRUE”时，“(新)UE最大上行带宽”和“(新)UE最大下行带宽”参数二者必须至少输入一个。如果是CS/PS用户首次签约AMBR业务，则“(新)UE最大上行带宽”和“(新)UE最大下行带宽”参数必须同时输入。
- 该命令需要在低话务量下执行。
- 当“业务条件”参数取值为“CHARGE\_GLOBAL”时，参数“全局计费特性业务”和“标准全局计费特性业务”只能提供一个；当“新业务”参数取值为“CHARGE\_GLOBAL”时，参数“(新)全局计费特性业务”和“(新)标准全局计费特性业务”只能提供一个。
- 当“业务条件”参数取值为“EPS”时，参数“是否提供EPS业务”和“是否提供EPSAMBR业务”至少提供一个；当“新业务”参数取值为“EPS”时，参数“(新)是否提供EPS业务”和“(新)是否提供EPSAMBR业务”至少提供一个。
- “新业务”参数中“CHARGE\_GLOBAL”和“OPTGPRS\_WITHOUTTP”冲突，不能同时存在。

## 使用实例

1、对IMSI号段460030912号段内的所有用户签约COLP业务。命令如下：

CONBAT: BEGINIMSI="460030912000000", ENDIMSI="460030912999999", NEWSERVICE=COLP, NEWCOLP=TRUE, NEWCOLPOR=TRUE;

2、对ISDN号段861390916号段的用户，去签约CW业务。命令如下：

CONBAT: BEGINISDN="8613909160000", ENDISDN="8613909169999", NEWSERVICE=CW, NEWCW=FALSE;

3、对全局计费为预付费的用户，签约模板号为13的优化GPRS业务。命令如下：

CONBAT: SERVICE=CHARGE\_GLOBAL, CHARGE\_GLOBAL=PREPAID, NEWSERVICE=OPTGPRS, NEWOPTGPRSPROV=TRUE, NEWOPTGPRSTPL=13;

4、对ISDN号段861390917号段内签约HOLD业务的用户，签约MPTY业务。命令如下：

CONBAT: BEGINISDN="8613909170000", ENDISDN="8613909179999", SERVICE=HOLD, HOLD=TRUE, NEWSERVICE=MPTY, NEWMPTY=TRUE;

5、对所有用户签约模板号为5的OFA模板，命令如下：

CONBAT: NEWSERVICE=DEFOFATPL, NEWDEFOFATPL=5;

6、对闭锁所有入呼叫的用户，签约为当漫游出HPLMN（Home PLMN）国家时，闭锁入呼叫。

CONBAT: SERVICE=ODBIC, ODBIC=BAIC, NEWSERVICE=ODBIC, NEWODBIC=BICROAM;
