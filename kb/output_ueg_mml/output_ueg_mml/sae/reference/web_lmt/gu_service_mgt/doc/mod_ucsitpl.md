# 修改U-CSI模板(MOD UCSITPL)

- 命令功能

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条U-CSI（USSD CAMEL Subscription Information）模板数据记录的某些参数进行修改或调整，同时还用于为一条U-CSI模板数据记录增加多条触发准则。在该命令中，系统通过以下关键参数的组合来唯一标识一条U-CSI模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 用户进行USSD智能业务操作或其他涉及U-CSI模板的流程时，系统会根据用户签约的U-CSI模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 系统中同一个U-CSI模板增加的业务码记录数不能超过1000条，且所有U-CSI模板增加的业务码总记录数不能超过45000条。

## 参数说明

| 参数标识              | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:------------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN             | HLR序列号      | 标识一条U-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条U-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| TPLID             | 模板ID        | 标识一条U-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条U-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST UCSITPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| TPLNAME           | 模板名         | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| PROV              | 是否保留数据      | 用于标识执行该命令是增加/修改还是删除数据。如果待修改模板中只设置了一个业务码，该参数不能设置为FALSE。 取值范围：TRUE：增加/修改如果指定的业务码在模板中不存在，则与该业务码对应的数据将被增加到模板中。 FALSE：删除如果指定的业务码已经存在，与指定的业务码相关的数据将被删除。如果指定的业务码在模板中不存在，系统将会提示错误。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SCODE             | 业务码         | 用于标识用户在通过移动终端发起USSD操作时所需输入的、gsmSCF（GSM Service Control Function）中指定应用的业务码。 取值范围：1～16个十进制数字组成的字符串。仅当操作员通过SET MAPCONF命令将“是否支持特殊的USSD业务码”参数设为“TRUE”时，业务码可以包含“*”、“#”符号。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| GSMSCFADD         | SCP地址       | 仅当本命令中的“是否保留数据”参数为“TRUE”时该参数有效。用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。                                                                                                                                                                                                                                  |
| PUSSDOPTION       | PUSSD号码携带选项 | 仅当本命令中的“是否保留数据”参数为“TRUE”时该参数有效。用于标识HLR在透明传输PUSSD请求消息时的号码携带选项，设置该参数时需与运营商确认使用何种号码携带方式。 取值范围：NONE：PUSSD请求在TCAP层不携带MSISDN和VLR Number，携带目的参考，在MAP层携带MSISDN。ONLY_MSISDN：PUSSD请求在TCAP层携带MSISDN和目的参考，MAP层不携带MSISDN。ONLY_VLRNUM：PUSSD请求在TCAP层携带VLR Number和目的参考，MAP层携带MSISDN。BOTH_MSISDN_VLRNUM：PUSSD请求在TCAP层携带MSISDN、VLR Number和目的参考，MAP层不携带MSISDN。NO_DESTREF：PUSSD请求在TCAP层携带MSISDN，不携带目的参考，MAP层不携带MSISDN。BSAMSISDN：PUSSDv1请求在BSA消息中携带MSISDN号码。DESTREF_MSISDN：PUSSD请求在TCAP层携带目的参考，目的参考携带MSISDN，MAP层不携带MSISDN。DESTREF_MAP_MSISDN：PUSSD请求在TCAP层携带目的参考，目的参考携带MSISDN，MAP层携带MSISDN。 默认值：无。 说明：当HLR收到用户发送的PUSSD请求消息时，处理的优先级是：先检查用户级U-CSI模板的号码携带选项。再检查通过执行ADD USSDDAT命令增加的号码携带选项。最后检查通过执行SET MAPSERV命令配置的全局号码携带选项。 |
| FUNCTION          | USSD类型      | 仅当本命令中的“是否保留数据”参数为“TRUE”时该参数有效。用于标识USSD数据的转发模式。 取值范围：GSMMODE：GSM方式前转到USSD中心，当USSD中心支持通过IMSI标识用户时，选择此项。对应的“SSN”为“MSC(0x08)”。WAPMODE：WAP方式前转到USSD中心，当USSD中心支持通过MSISDN标识用户时，选择此项。对应的“SSN”为“MSC(0x08)”。GSMSCF：当USSD中心支持U-CSI时，用户的USSD请求被前转到gsmSCF。对应的SCCP子系统号“SSN”为“GSMSCF(0x93)”。MAP：当USSD中心支持通过IMSI标识用户时，用户的USSD请求以MAP方式被前转到USSD中心。对应的SCCP子系统号“SSN”为“MAP(0x05)”。GSMSPECIALMODE：GSMSPECIALMODE方式前转到USSD中心，当USSD中心支持通过IMSI标识用户时，选择此项。对应的“SSN”为“SSN15(0x0F)”。 默认值：无。 说明：需要在OM Portal的“UDM MML命令”界面执行ADD SCCPSSN命令配置SCCP子系统号才能转发成功。                                                                                                                                                                       |
| MATCH_RULE        | 业务码匹配原则     | 仅当本命令中的“是否保留数据”参数为“TRUE”时该参数有效。用于标识业务码的匹配原则。 取值范围： MAX_MATCH：最大匹配ALL_MATCH：完全匹配 默认值：MAX_MATCH 说明：最大匹配即匹配到与业务码最大相似的地方，如：数据库中有三条记录139、1385、13852，则当需要和数据库中记录匹配的数据为1385213时，就会匹配到13852；如果需要和数据库匹配的数据为13851，那么匹配到的就是1385。                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PUSSDORIGINREFCFG | PUSSD源参考配置  | 仅当本命令中的“是否保留数据”参数为“TRUE”时该参数有效。用于标识HLR转发PUSSD消息时，TCAP层携带源参考地址的方式。 取值范围：GLOBAL_CFG: PUSSD消息携带的源参考地址通过命令SET MAPCONF中的参数“USSDSENDVLRGT”进行配置。HLR_GT：PUSSD消息携带HLR_GT作为源参考地址。VLR_GT：PUSSD消息携带VLR_GT作为源参考地址。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| TPLTYPE           | 模板类型        | 用于标识U-CSI模板的模板类型。 取值范围：SUB：用户规则模板，允许被替换。REPLACE：替代规则模板，不允许被替换。 默认值：SUB 说明：SUB类型U-CSI模板可以引用CSI替代模板，并且一个SUB类型U-CSI模板只能引用一个CSI替代模板；CSI替代模板只能引用REPLACE类型的U-CSI模板。当“模板类型”从“SUB”改为“REPLACE”时，如果之前签约了替代模板ID，则替代模板ID会被删除。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| PROVREPTPL        | 是否提供替代模板    | 仅当本命令中的“模板类型”参数为“SUB”时该参数有效。用于标识增加/修改或删除替代模板ID。 取值范围：TRUE：增加/修改替代模板ID。FALSE：删除替代模板ID。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| REPTPLID          | 替代模板ID      | 仅当本命令中的“是否提供替代模板”参数为“TRUE”时该参数有效。用于标识CSI替代模板ID号，该参数必须先由SET CSIREPTPL命令定义，然后才能在此处引用。 取值范围： 0～65534 默认值：无 说明：当用户所在网络（VLR前缀/漫游区域）与模板定义的使用范围一致时，采用CSI替代模板里的参数控制U-CSI业务。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的U-CSI模板数据记录，修改SCP地址。其中，“模板ID”为“2”，“是否保留数据”为“TRUE”，“业务码”为“10”，“SCP地址”为“8613907551113”：

   ```
   MOD UCSITPL: HLRSN=1, TPLID=2, PROV=TRUE, SCODE="10", GSMSCFADD="8613907551113";
   ```
2. 修改“HLR序列号”为“1”的HLR上的U-CSI模板数据记录，增加一个USSD业务码。其中，“HLR序列号”为“1”，“模板ID”为“2”，“是否保留数据”为“TRUE”，“业务码”为“11”，“SCP地址”为“8613907551112”：

   ```
   MOD UCSITPL: HLRSN=1, TPLID=2, PROV=TRUE, SCODE="11", GSMSCFADD="8613907551112";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                   | 处理建议                                                                                       |
|:--------|:--------|:-----------------------------------------------------------------------|:-------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的U-CSI模板数据记录不存在。                                      | 使用LST UCSITPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的U-CSI模板数据记录。                                 |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个“模板ID”增加的“业务码”数据记录数超过1000条。所有U-CSI模板增加的“业务码”总记录数超过45000条。 | 根据实际情况，如需增加业务码，处理步骤如下：执行LST UCSITPL命令，查询已存在的业务码。执行该命令删除不必要的业务码。执行该命令增加业务码，确保增加的业务码在规定范围之内。 |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”和“模板ID”参数不在相应的参数取值范围内。                                   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                           |
