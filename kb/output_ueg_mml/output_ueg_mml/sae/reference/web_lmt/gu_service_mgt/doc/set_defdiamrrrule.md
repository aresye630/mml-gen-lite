# 设置Diameter漫游限制模板的缺省漫游限制状态(SET DEFDIAMRRRULE)

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，可能导致漫游受限，影响在网用户漫游，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置Diameter漫游限制模板的缺省漫游限制状态。在该命令中，系统通过以下关键参数的组合来唯一标识一个Diameter漫游限制模板的缺省漫游限制状态：

- “HLR序列号”
- “模板ID”

## 注意事项

“缺省漫游限制状态”参数作用范围为该命令中模板ID的取值范围，只能通过该命令设置，无法删除。如果设置不当将导致签约该模板的用户，在未设置漫游限制模板时不能正常漫游。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                 |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                                                                       |
| TPLID       | 模板ID     | 用于标识Diameter漫游限制模板在系统中的序号。该参数必须先由ADD DIAMRRTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                    |
| DEFAULTRULE | 缺省漫游限制状态 | 用于标识在缺省状态下Diameter漫游限制能力。当用户漫游区域的Diameter服务节点的身份标识与模板中的Diameter身份标识不匹配时，根据该参数的取值判断是否允许用户漫游。 取值范围：PERMISSION：漫游允许RESTRICT：漫游限制 默认值：无。 |

## 使用实例

允许用户在该命令中模板ID的取值范围内漫游。其中，“HLR序列号”为“1”，“模板ID”为“0”，“缺省漫游限制状态”为“PERMISSION”：

```
SET DEFDIAMRRRULE: HLRSN=1, TPLID=0, DEFAULTRULE=PERMISSION;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                    |
|:--------|:--------|:-------------|:----------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。 | 根据实际情况，重新输入参数“HLR序列号”，确保输入的“HLR序列号”已定义。 |
