# 删除APN运营商标识符模板(RMV APNOITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条APNOI模板信息记录。

## 注意事项

如果已经通过**MOD PSAPNOI**、**ADD GPRSTPL**、**ADD SUB**、**MOD GPRS**或**ADD CSPSSUB**等命令关联该模板，当执行该命令删除APNOI模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该APNOI模板不能被删除。如果要删除该APNOI模板，必须先执行相关的修改命令去掉APNOI模板或GPRS模板与APNOI模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识APN运营商标识符模板信息数据的关键字段之一，用于指定需要删除哪个HLR上的APN运营商标识符模板信息数据记录，操作员可以使用LST HLRSN命令查询获得。      |
| TPLID  | 模板ID   | 标识APN运营商标识符模板信息数据的关键字段之一，用于指定需要删除哪个模板ID对应的APN运营商标识符模板信息数据记录，操作员可以使用LST APNOITPL命令查询获得。 |

## 使用实例

删除一条APN运营商标识符模板信息，“HLR序列号”为“1”，“模板ID”为“1”：

```
RMV APNOITPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                      |
|:--------|:--------|:-----------------------------------|:--------------------------------------------------------------------------|
| ERR3005 | 模板已经被使用 | 用户输入的“HLR序列号”和“模板ID”对应的模板已经在系统中使用。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD PSAPNOI或MOD GPRSTPL命令去签约该模板，然后再执行该删除命令。 |
| ERR3003 | 模板未定义   | 用户输入的“HLR序列号”和“模板ID”对应的模板信息不存在。    | 执行LST APNOITPL命令查询已添加的模板信息，根据查询结果重新输入参数。                                  |
