# 修改业务限制模板(MOD SERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改业务限制模板信息，并且为一个业务限制模板新增、修改或删除一个限制业务。在该命令中，系统通过以下关键参数的组合来唯一标识一个业务限制模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- 通过业务限制模板设置的“ETCSI”、“BAOC”、“BOIC”、“BOICEXHC”和“CLIR”限制业务的优先级高于通过业务下发模板（通过**ADD RSITPL**命令配置）设置的“ETCSI”、“BAOC”、“BOIC”、“BOICEXHC”和“CLIR”业务的优先级。即当用户同时签约用户限制模板和业务下发模板，并且其中都包含“ETCSI”、“BAOC”、“BOIC”、“BOICEXHC”和“CLIR”时，优先根据业务限制模板处理限制以上业务的下发。
- 通过业务限制模板设置的“BAOC”限制业务的优先级低于用户申请锁SABLCK（Subscriber Application Barring LCK）场景下以BAOC替代下发的优先级。即SABLCK替代下发的BAOC的状态不受业务限制模板的限制。
- 当该命令签约的“业务限制列表”中包含“OPTGPRS”，并被**ADD PLMNTPL**或**ADD VSLIST**命令引用时，可以实现UDM对优化GPRS模板中的APN限制下发的功能，即不将优化GPRS模板中的APN信息的变化通知MME/SGSN/AAA，但SGSN必须为S4-SGSN，否则APN限制下发的功能会失效。
- PS域暂时不支持以下业务限制下发：**ODB-BOIC**、**ODB-BAOC**、**ODB-BOICEXHC**、**ODB-BOCROAM**、**ODB-INFO**、**ODB-ENTE**、**ODB-PB1**、**ODB-PB2**、**ODB-PB3**、**ODB-PB4**。
- 当“业务限制列表”取值为“TS11”、“TS21”或“TS22”中的任何一个时，参数“基本业务组”、“优化GPRS模板ID”、“APN限制模板ID”或“智能限制业务键模板ID”不能出现，否则执行失败，上报“ERR1010 参数冲突”错误。
- “业务限制列表”设置为“OPTGPRS”时，**MOD SERRESTTPL**设置的优化GPRS业务限制只对4G业务生效，优化GPRS业务限制设置的默认APN不生效。
- 参数“业务限制列表”设置为“BAIC”时，漫游用户的BAIC业务会生效，但在用户做被叫的流程中不下发BAIC业务。

## 使用实例

1. 修改“HLR序列号”为“1”、“模板ID”为“3”的业务限制模板的“模板名”为“temp”。命令如下：

   ```
   MOD SERRESTTPL: HLRSN=1, TPLID=3, TPLNAME="temp";
   ```
2. 修改“HLR序列号”为“1”，“模板ID”为“3”的业务限制模板，当用户漫游到特定的VLR/SGSN区域后对无条件前转业务也进行限制。“HLR序列号”为“1”，“模板ID”为“3”，“是否提供限制业务”为“TRUE”，“业务限制列表”为“CFU”。命令如下：

   ```
   MOD SERRESTTPL: HLRSN=1, TPLID=3, PROV=TRUE, SERCODE=CFU;
   ```
3. 修改“HLR序列号”为“1”，“模板ID”为“3”的业务限制模板，当用户漫游到特定的VLR/SGSN区域后对“优化GPRS模板ID”为“2”中的优化GPRS业务进行限制。命令如下：

   ```
   MOD SERRESTTPL: HLRSN=1, TPLID=3, PROV=TRUE, SERCODE=OPTGPRS, OPTGPRSTPLID=2;
   ```
4. 修改“HLR序列号”为“1”，“模板ID”为“3”的业务限制模板，当用户漫游到特定的VLR/SGSN区域后对呼叫等待业务不进行限制。“是否提供限制业务”为“FALSE”，“业务限制列表”为“CW”。命令如下：

   ```
   MOD SERRESTTPL: HLRSN=1, TPLID=3, PROV=FALSE, SERCODE=CW;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                          | 处理建议                                                                                                           |
|:--------|:--------|:----------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失    | “模板名”和“是否提供限制业务”参数一个都没有输入。                                                                    | 根据实际情况，输入“模板名”和“是否提供限制业务”，确保至少输入一个。                                                                            |
| ERR1010 | 参数冲突    | 当参数取值为“TS11”、“TS21”或“TS22”中的任何一个时，同时输入“基本业务组”、“优化GPRS模板ID”、“APN限制模板ID”或“智能限制业务键模板ID”中一个或多个参数。 | 根据实际情况，重新输入参数，确保当的“业务限制列表”取值为“TS11”、“TS21”或“TS22”中的任何一个时，参数“基本业务组”、“优化GPRS模板ID”、“APN限制模板ID”或“智能限制业务键模板ID”不能出现。 |
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。                                                                | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST SERRESTTPL命令查询。                                |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                                                                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                              |
