# 设置容灾探测配置数据(SET DETECTCFG)

## 命令功能

该命令用于在主用局FE设置探测容灾局业务信息的配置数据。

操作员可通过在主用局配置容灾探测数据，从而获取容灾局业务状态信息。在FE主备容灾场景中，由于主用局对容灾局的可用性无法判断，故障无法感知，为了提前发现并避免主用局重复故障，需要从主用局获取容灾局的可用性，提高系统的容灾能力、可靠性。系统容灾探测基本流程说明请参考图1。

## 注意事项

- 该功能仅适用于**2\*（FE+BE）无缝地理容灾主备方案**。
- 该功能只限于主用局配置使用，不能在容灾局使用，容灾接管后也不能使用该功能。
- 要使用该功能，操作员需要登录OM Portal在“UDM MML命令”界面执行**MOD INSP**命令进行软件参数设置，其中“软件参数类型”为“HSS9860(HSS9860)”，“是否启用容灾FE探测功能”设置为“1”，即开启容灾FE探测功能，该设置才会在系统中被使用。
- 该功能需要将容灾局软件参数“是否启用容灾FE探测功能”设置为“0”，即关闭容灾探测。
- 该命令中所描述的系统初始设置值，是指操作员通过**LST DETECTCFG**命令查询得出的系统在初始化时的预置参数值。

## 参数说明

| REDUNDANCY_DETECT_TYPE      | 容灾探测业务类型         | 用于标识容灾探测的业务类型。目前系统支持探测容灾局2/3G、EPS、IMS融合网络业务状态。 取值范围：23G：是否探测容灾局2/3G业务状态（默认值：TRUE）EPS：是否探测容灾局EPS业务状态（默认值：FALSE）IMS：是否探测容灾局IMS业务状态（默认值：FALSE） 说明：操作员可以同时探测容灾局2/3G、EPS和IMS业务状态，并用“&”连接，例如23G-1&EPS-1&IMS-1。参数复选框中的灰化表示不修改系统原有值。 |

| REDUNDANCY_DETECT_MMEREALM  | 容灾探测对接的MME域名     | 用于标识探测容灾局EPS业务的对接MME域名。操作员可登录容灾局登录OM Portal在“UDM MML命令”界面执行命令LST DMPE查询Diameter对端网元的域名。 取值范围：1～127位的字符串。 默认值：无。 说明：若命令参数取值不正确，会导致误报ALM-15066 容灾FE业务异常告警。                                                                     |

## 使用实例

操作员需要了解容灾局业务状态，首先需要在主用局完成探测业务数据配置，并通过一个测试用户信息，来了解容灾局业务状态。

1. 添加一个测试用户信息，该用户必须为GSM/UMTS/EPS/IMS融合用户。融合用户开户具体可参考**ADD TPLUSCSUB**命令。执行命令如下：

   ```
   ADD TPLUSCSUB: HLRSN=1, IMSI="460000009123456", ISDN="8613484929766", TPLID=2, SUBID="subinfo", IMPI="impiinfo", IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"", IRSID=1, ALIASID=1;
   ```
2. 配置探测容灾局2/3G业务状态信息。“容灾探测业务类型”为“23G”，“容灾探测周期”为“5”，“容灾探测用户的IMSI”为“460000009123456”，“容灾探测对接的VLR号码”为“123456”。执行命令如下：

   ```
   SET DETECTCFG: REDUNDANCY_DETECT_TYPE=23G-1, REDUNDANCY_DETECT_PERIOD=5, REDUNDANCY_DETECT_IMSI="460000009123456", REDUNDANCY_DETECT_VLRNO="123456";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析          | 处理建议                         |
|:--------|:--------|:--------------|:-----------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不符合要求。 | 根据实际情况，重新输入参数，并确保各参数取值都符合要求。 |
| ERR1009 | 参数丢失    | 必须参数未输入。      | 根据实际情况，重新输入参数，并满足所有必须参数都有输入。 |
