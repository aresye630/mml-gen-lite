# 修改5G NCC模板(MOD NGSNCCTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用此NCC模板的5G业务数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改已配置的5G NCC（Network Capability Configuration）模板数据记录。在该命令中，系统通过“HLR序列号”和“模板ID”参数的组合来唯一标识一条5G NCC模板数据信息。

## 注意事项

无。

## 使用实例

1. 修改“HLR序列号”为“1”、“模板ID”为“1”的5G NCC模板数据记录中“UDM支持备份AMF的方式”为“AMFSET”：

   ```
   MOD NGSNCCTPL: HLRSN=1, TPLID=1, BKAMFMODE=AMFSET;
   ```
2. 修改“HLR序列号”为“2”、“模板ID”为“2”的异网漫游请求消息URI和异网漫游回调消息URI均不携带端口号：

   ```
   MOD NGSNCCTPL: HLRSN=2, TPLID=2, ROAM_REQ_WITH_PORT=2, ROAM_CBK_WITH_PORT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                               |
|:--------|:--------|:-----------------------------------|:---------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面提示的参数不在相应的参数取值范围内。               | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                   |
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的5G NCC模板数据记录不存在。 | 使用LST NGSNCCTPL命令查询已存在的模板记录，然后输入已存在的记录重新执行本命令进行修改。 |
