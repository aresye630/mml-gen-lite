# 一键式销户(RMV HHSSSUB)

## 命令功能

该命令用于从HSS的业务数据库中删除参数“SUBID”或“IMSI”关联的用户所有信息，包括IMPI的鉴权信息、IMSI信息。

## 注意事项

- “SUBID”和“IMSI”必须输入且每次只能输入一个。
- 如果操作员在删除了指定签约用户，则会影响该签约用户对应用户业务，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                  |
|:-------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID  | SUBID         | 标识签约用户数据信息的关键字段之一，用于指定需要删除哪一个签约用户的所有信息，操作员可以使用LST HSUB操作查询获得，SUBID字母区分大小写。 取值范围：长度不超过127的由字母、数字或“.”、“_”、“—”等特殊字符组成的字符串。 默认值：无。                                                        |
| IMSI   | IMSI          | 标识签约用户数据信息的关键字段之一，用于指定删除哪个IMSI对应的用户的签约信息，采用E.212格式。例如：460001234567890。操作员可以使用LST IMSI操作查询获得。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                            |
| SUPCAN | 是否抑制下发消息给对端网元 | 用于标识IMS-HSS是否抑制下发销户时触发的网络侧消息给对端设备。 取值范围： SUPPRESSION：抑制，不下发销户时触发的网络侧消息给对端设备。UNSUPPRESSION：不抑制，下发销户时触发的网络侧消息给对端设备。 默认值：UNSUPPRESSION。 说明：该参数设置为“SUPPRESSION”时，会导致IMS-HSS与对端设备存储的数据不一致。 |

## 使用实例

1. 一键式销户，“SUBID”为“+862970119992@domain50.huawei.com”：

   ```
   RMV HHSSSUB: SUBID="+862970119992@domain50.huawei.com";
   ```
2. 一键式销户，“IMSI”为“460001234567890”：

   ```
   RMV HHSSSUB: IMSI="460001234567890";
   ```
