# 修改用户的归属分区(MOD USERPID)

- 命令功能

- 参数说明

## 命令功能

该命令用于修改用户的PID（Service Partition标识）信息，即用户的归属分区。

在混合组网下，修改用户的PID信息会触发用户迁移到新的分区。如果是多卡用户，会将多卡组内的所有用户都迁移到新的分区。

## 注意事项

- 该命令只允许在vRSP上执行。
- 执行该命令时，“新分区ID”、“目标分区参考号码类型”、“目标分区参考号码”参数为可选输入，其中
  - “目标分区参考号码类型”、“目标分区参考号码”必须同时存在。
  - “新分区ID”与“目标分区参考号码类型”、“目标分区参考号码”不能同时存在。
  - 如果都不输入则将用户迁移到vRSP。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“PI”、“PU”、“PI文件名”及“PU文件名”八个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”参数不能与“IMSI文件名”、“MSISDN文件名”、“PI文件名”或“PU文件名”同时存在。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 执行该命令携带“PI”或“PU”进行用户迁移的时候，支持迁移非多卡用户，针对多卡用户，只支持迁移签约了VoLTE Multi-SIM或VoLTE Multi-IMSI业务的用户。

## 使用实例

修改“IMSI”号码为“811111111111171”的用户PID信息，“新分区ID”为“82”：

```
MOD USERPID: IMSI="811111111111171", NEWPID=82;
```
