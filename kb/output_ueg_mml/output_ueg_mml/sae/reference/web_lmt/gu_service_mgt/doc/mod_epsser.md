## 命令功能

该命令用于修改用户的EPS数据及对PDN上下文索引值对应数据的操作。当GSM/UMTS用户需要改造为GSM/UMTS/EPS融合用户、GSM/UMTS用户需要改造为VoLTE用户时，可以执行该命令为用户提供EPS业务数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- 最后一条或默认“PDN上下文索引值”不能删除。
- 执行本命令删除用户通过APN模板签约的APN数据时，用户通过**SET APNLIST**命令签约的具有相同PDN上下文索引的APN数据会被同时删除。
- 执行本命令为用户签约EPSAPNQOS模板数据时，需要执行**SET MAPSERV**命令将“GPRS管理方式”设置为“SuppPsEpsSeparateTplManager”，或执行**SET MAPCONF**命令将“是否支持GPRS调整方式管理过渡”设置为“TRUE”。

## 使用实例

1. 修改“IMSI”为“460000009123456”的EPS数据业务。其中，“操作类型”修改为“ADDPDNCNTX”，“PDN上下文索引值”修改为“2”，“EPSAPNQOS模板ID”修改为“2”：

   ```
   MOD EPSSER: IMSI="460000009123456", PROV=ADDPDNCNTX, CNTXID=2, EPSAPNQOSTPLID=2;
   ```
2. 批量修改用户的EPS数据业务，具体操作如下：
   1. 编写IMSI批操作文件。
      - 文件名：IMSI.txt
      - 文件格式：
        - 460000009012345
        - 460000009012346
        - 460000009012347
        - 460000009012348
   2. 将IMSI批操作文件传到指定位置。

      通过Web UI上的文件选项将本地文件上传到指定位置。
   3. 批量修改“操作类型”为“ADDPDNCNTX”的用户的“EPSAPNQOS模板ID”为“3”：

      `MOD EPSSER: IMSIFILE="IMSI.txt", PROV=ADDPDNCNTX, EPSAPNQOSTPLID=3;`
