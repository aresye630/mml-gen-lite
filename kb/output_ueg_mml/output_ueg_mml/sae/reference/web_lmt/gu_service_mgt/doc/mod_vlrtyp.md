# 修改VLR类型数据(MOD VLRTYP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到该VLR区域后出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改VLR类型信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条VLR类型信息：

- “HLR序列号”
- “VLR号码前缀”

## 注意事项

- 修改VLR类型数据属于高危操作，随意修改可能导致用户无法正常进行位置更新，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识             | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-----------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN            | HLR序列号             | 标识VLR类型数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的VLR类型数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                              |
| VLRPREFIX        | VLR号码前缀            | 标识VLR类型数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪些VLR的网络类型数据记录的参数进行修改或调整，操作员可以使用LST VLRTYP命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                               |
| VLRNAME          | VLR名称              | 用于标识不同的VLR。当“VLR号码前缀”配置的是一组VLR时，“VLR名称”标识的就是这组VLR。 取值范围：长度不超过30位的字母或数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                |
| TYPE             | VLR号相对于本HLR所属的网络类型 | 用于标识VLR相对于本地HLR所属的网络类型。该参数的配置与运营商的网络规划和运营策略有关，配置前需要与运营商确认。 取值范围： LOCAL（本地）：表示VLR和本地HLR在同一个地区。LOCALDOMESTIC（国内本网）：表示VLR和本地HLR在同一个国家，且在同一个PLMN（Public Land Mobile Network）内。CROSSDOMESTIC（国内跨网）：表示VLR和本地HLR在同一个国家，但在不同的PLMN内。LOCALINTERNATIONAL（国际本网）：表示VLR和本地HLR不在同一个国家，但在相同的PLMN内。CROSSINTERNATIONAL（国际跨网）：表示VLR和本地HLR不在同一个国家，也不在同一个PLMN内。LOCALAREA（省内本网）：表示VLR和本地HLR在同一个省和PLMN内。CROSSAREA（省内跨网）：表示VLR和本地HLR在同一个省内，但在不同的PLMN内。 默认值：无。 配置“VLR相对于本地HLR所属的网络类型”时，可参考VLR和本地HLR的位置关系示意图。 |
| NCCPROV          | 是否提供NCC模板          | 用于标识VLR是否提供NCC（Network Capability Configuration）模板支持能力。 取值范围： TRUE：提供，即VLR支持按照NCC模板设置的能力进行业务处理。此时参数“NCC模板ID”为必选。FALSE：不提供，即VLR不支持按照NCC模板设置的能力进行业务处理。 默认值：无。                                                                                                                                                                                                                                                                                                                         |
| NCCTPL           | NCC模板ID            | 仅当本命令中的“是否提供NCC模板”参数为“TRUE”时该参数有效。用于标识VLR支持的网络能力，使HLR能根据NCC模板设置的VLR的网络能力进行业务和MAP流程的处理，提高HLR和VLR的兼容性。 NCC模板ID对应的网络能力可以通过LST NCCTPL命令进行查询。 取值范围：0～99998。 默认值：无。 配置原则：必须先由ADD NCCTPL命令定义，然后才能在此引用。                                                                                                                                                                                                                                                                                     |
| SERVICETY        | 是否允许签约OKSC业务       | 可选参数。 用于设置HLR是否对指定的VLR进行签约业务区域限制。 可以通过MOD OKSC命令签约或去签约业务区域限制。 各参数选项的含义是：PERMISSION：业务允许。 RESTRICT：业务限制。 当该参数设置为“RESTRICT”后，HLR在向指定的VLR下发用户的签约数据时，HLR通过检测该参数得知该VLR已经被设置了业务区域限制，从而在下发用户数据到该VLR时就不会下发不允许的业务。 默认值：PERMISSION。                                                                                                                                                                                                                                                           |
| PROVCAPTPL       | 是否提供CAMEL能力模板      | 用于标识VLR是否提供CAMEL（Customized Applications for Mobile network Enhanced Logic）模板支持能力。 取值范围： TRUE：提供，即VLR支持按照CAMEL模板设置的能力进行业务处理，此时参数“CAMEL能力模板ID”为必选。FALSE：不提供，即VLR不支持按照CAMEL模板设置的能力进行业务处理。 默认值：无。                                                                                                                                                                                                                                                                                      |
| CAMELCAPTPL      | CAMEL能力模板ID        | 仅当本命令中的“是否提供CAMEL能力模板”参数为“TRUE”时该参数有效。用于标识VLR支持的CAMEL能力，使指定的VLR能够根据CAMEL能力模板设置的能力对CAMEL业务进行处理。 CAMEL模板ID对应的CAMEL能力可以通过命令LST CAMELCAPTPL命令进行查询。 取值范围：0～65534。 默认值：无。 配置原则：必须先由ADD CAMELCAPTPL命令定义，然后才能在此引用。                                                                                                                                                                                                                                                                          |
| PROVETCSIRESTTPL | 是否提供ETCSI限制模板      | 用于标识UDM是否提供ETCSI限制模板。 取值范围：TRUE：提供FALSE：不提供 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ETCSIRESTTPLID   | ETCSI限制模板ID        | 仅当本命令中“是否提供ETCSI限制模板”参数为“TRUE”时该参数有效，用于标识ETCSI限制模板的模板ID。该参数必须先由ADD ETCSIRESTTPL命令定义，然后才能在此引用。 取值范围：0～65534。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

1. 在“HLR序列号”为“1”的HLR上，修改VLR号相对于本HLR所属的网络类型。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“VLR号相对于本HLR所属的网络类型”为“CROSSDOMESTIC”：

   ```
   MOD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", TYPE=CROSSDOMESTIC;
   ```
2. 在“HLR序列号”为“1”的HLR上，修改VLR类型数据，实现对使指定的VLR进行业务限制。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“是否允许签约OKSC业务”为“PERMISSION”：

   ```
   MOD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", SERVICETY=PERMISSION;
   ```
3. 在“HLR序列号”为“1”的HLR上，修改VLR类型数据，使VLR提供指定NCC模板的支持能力。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“是否提供NCC”为“TRUE”，“NCC模板ID”为“2222”：

   ```
   MOD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", NCCPROV=TRUE, NCCTPL=2222;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                      | 处理建议                                                                                                                                   |
|:--------|:--------|:------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“VLR号码前缀”的取值中含有0～9以外的字符。                | 根据实际情况，重新输入“VLR号码前缀”，确保其取值为长度不超过14位的数字组成的字符串。                                                                                          |
| ERR3003 | 模板未定义   | “NCC模板ID”、“CAMEL能力模板ID”或“ETCSI限制模板ID”未定义。 | 分别执行LST NCCTPL命令、LST CAMELCAPTPL命令或LST ETCSIRESTTPL命令查询已定义的NCC模板、CAMEL能力模板或ETCSI限制模板，根据实际情况输入已定义的模板ID。                                 |
| ERR3007 | 记录不存在   | 有两点原因：HLR序列号未定义。HLR序列号对应的VLR号码前缀未添加。      | 对于第一点原因，处理步骤如下：执行LST HLRSN命令查询出已定义的HLRSN。执行LST VLRTYP命令查询出该HLRSN对应的VLR号码前缀。结合实际情况，根据HLRSN和VLR号码前缀修改对应的VLR类型数据。 对于第二点原因，只需执行上述处理步骤的2和3。 |
