# 增加NGC漫游限制模板操作(ADD NGCRRNODETPL)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该操作用于在数据库中添加一个NGC漫游限制模板。在AMF/SMF/SMSF注册流程，或者鉴权流程中，AMF/SMF/SMSF向UDM发起注册请求消息或者鉴权请求后，UDM检测用户是否签约了NGC漫游限制模板，如果签约，则根据签约规则匹配PLMN等，以实现NGC漫游限制。

## 注意事项

- 全局增加的NGC漫游限制模板记录数不能超过10000条。
- NGC漫游限制模板关联的漫游限制区域模板数不能超过20000个。
- 如果执行该命令时误将如下四类参数设置为“RESTRICT”，用户漫游出配置的限制区域，将限制漫游接入5G网络。请在华为技术支持指导下执行该操作。
  - AMF注册缺省漫游限制状态
  - SMF注册缺省漫游限制状态
  - 鉴权缺省漫游限制状态
  - SMSF注册缺省漫游限制状态

## 使用实例

1. 增加一个NGC漫游限制模板，用户通过签约该模板在AMF注册流程中实现NGC漫游限制。
   1. 执行**ADD NGCRRAREATPL**命令，增加一个NGC漫游限制区域模板。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“test”，“AMF限制类型”为“AMFPOINTER”,“PLMNID”为“12345”，“AMF Region ID”为“1”，“AMF Set ID”为“1”，“AMF Pointer ID”为“1”。

      ```
      ADD NGCRRAREATPL: HLRSN=1, TPLID=1, TPLNAME="test", AREATYPE=AMFPOINTER, PLMN="12345", AMFREGION=1, AMFSET=1, AMFPOINTER=1;
      ```
   2. 执行本命令签约该模板，用于在AMF注册流程中根据模板配置实现NGC漫游限制。“HLR序列号”为“1”，“模板ID”为“1”，“AMF注册缺省漫游限制状态”为“PERMISSION”，“漫游限制区域模板ID”为“88”,“漫游限制状态”为“PERMISSION”。

      ```
      ADD NGCRRNODETPL: HLRSN=1, TPLID=1, DEFAULTRULE=PERMISSION, RRAREATPLID=88,RULE=PERMISSION;
      ```
2. 增加一个NGC漫游限制模板，用户通过签约该模板在鉴权流程中实现NGC漫游限制。
   1. 执行**ADD NGCRRAREATPL**命令，增加一个NGC漫游限制区域模板。“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“test”，“AMF限制类型”为“AMFPOINTER”,“PLMNID”为“11111”，“AMF Region ID”为“2”。

      ```
      ADD NGCRRAREATPL: HLRSN=1, TPLID=3, TPLNAME="test", AREATYPE=AMFREGION, PLMN="11111", AMFREGION=2;
      ```
   2. 执行本命令签约该模板，用于在鉴权流程中根据模板配置实现NGC漫游限制。“HLR序列号”为“1”，“模板ID”为“3”，“AMF注册缺省漫游限制状态”为“PERMISSION”，“鉴权缺省漫游限制状态”为“PERMISSION”，“漫游限制区域模板ID”为“3”,“漫游限制状态”为“PERMISSION”。

      ```
      ADD NGCRRNODETPL: HLRSN=1, TPLID=3, DEFAULTRULE=PERMISSION, AUTHDEFAULTRULE=PERMISSION, RRAREATPLID=3, RULE=PERMISSION;
      ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                           | 处理建议                                                                                                             |
|:--------|:----------|:---------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义     | 输入的“漫游限制区域模板ID”对应的记录不存在。                                       | 根据实际情况，重新输入已定义的“漫游限制区域模板ID”，确保参数对应的漫游限制区域模板数据记录已存在。可通过LST NGCRRAREATPL命令查询已定义的“漫游限制区域模板ID”。                      |
| ERR3004 | 模板已存在     | 输入的“模板ID”在数据库中已存在。                                             | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST NGCRRNODETPL命令查询系统中已存在的NGC漫游限制模板。                                    |
| ERR3007 | HLR序列号未定义 | “HLR序列号”未定义。                                                   | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                            |
| ERR3047 | 超过最大限制    | 可能原因如下： 增加的NGC漫游限制模板记录数超过10000条。NGC漫游限制模板关联的漫游限制区域模板数超过20000个。 | 根据实际情况，如需增加NGC漫游限制模板，处理步骤如下：执行LST NGCRRNODETPL命令，查询已存在的NGC漫游限制模板。执行RMV NGCRRNODETPL命令，删除不必要的NGC漫游限制模板。再次使用本命令添加。 |
