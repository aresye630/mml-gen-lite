# 查询SMSF数据（LST SMSFINFO）

- 命令功能
- 注意事项

## 命令功能

该命令用于查询用户的SMSF的签约数据。

- 若需要查询单个用户的签约数据信息，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的签约数据信息，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的签约数据信息，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”参数同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”参数中的一个同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                         |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要查询哪个IMSI号码对应的SMSF签约数据。 取值范围：6～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                                                         |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要查询哪个MSISDN号码对应的SMSF签约数据。 取值范围：1～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                                                       |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指定需要查询从IMSI或者MSISDN对应的用户开始的SMSF签约数据的个数。 取值范围：1～10000 默认值：无。 配置原则： 当需要为连续号码的多个用户查询SMSF业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行查询SMSF业务。当只有一个用户时，该参数不必配置。 当一次查询SMSF业务的用户个数很多时，对系统性能无影响，但查询SMSF业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于指定需要查询的SMSF签约数据的IMSI批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要查询的SMSF业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                           |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于指定需要查询的SMSF签约数据的MSISDN批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要查询的SMSF业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                     |

## 使用实例

1. 查询IMSI号码为“460000009123456”的用户的SMSF的签约数据：

   ```
   LST SMSFINFO: IMSI="460000009123456";
   ```

   ```
   %%LST SMSFINFO: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                             IMSI = 460000009123456
                   SMSFINSTANCEID = 3a80e8fa-80a4-4d21-8cde-9567a8
                SUPPORTEDFEATURES = 00000000000FFDDE
                           PLMNID = 123456
                       SMSFNUMBER = 123453
                          REGTIME = 2020-06-10 11:45:33
                         MNRFSMSF = FALSE
                         MNRRSMSF = no reason

   Total count = 8

   There is together 1 report

   ---    END
   ```
2. 查询第一个IMSI号码为“460000009123456”的连续3个用户的SMSF签约数据记录：

   ```
   LST SMSFINFO: IMSI="460000009123456", RECORDCOUNT=3;
   ```

   ```
   %%LST SMSFINFO: IMSI="460000009123456", RECORDCOUNT=3;%% 
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：4. 使用CHK BATSTAT指令可查看此批操作的执行情况  

   There is together 1 report  

   ---    END
   ```
3. 查询“IMSI文件名”为“lstsmsfinfo.txt”的SMSF签约数据记录：

   ```
   LST SMSFINFO: IMSIFILE="lstsmsfinfo.txt";
   ```

   ```
   %%LST SMSFINFO: IMSIFILE="lstsmsfinfo.txt";%%   
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：19. 使用CHK BATSTAT指令可查看此批操作的执行情况    

   There is together 1 report   
    ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。各参数含义请见

**MOD SMSFINFO**

命令的参数说明，表1列出的是未包含在

**MOD SMSFINFO**

命令参数说明中的输出项。

| 输出项名称    | 输出项解释                                                                                                     |
|:---------|:----------------------------------------------------------------------------------------------------------|
| REGTIME  | 用于返回SMSF的签约时间。                                                                                            |
| MNRFSMSF | 用于返回SMSF的MNRF（Mobile Not Reachable Flag）标记。 TRUE：可达FALSE：不可达 默认值：FALSE                                    |
| MNRRSMSF | 用于返回SMSF的MNRR（Mobile Not Reachable Reason）。 no paging response via AMFAMF detachedno reason 默认值：no reason |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|

| ERR1009 | 参数丢失。   | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3007 | 记录不存在。  | 输入的“IMSI”或“MSISDN”无对应的SMSF签约数据。                                                                    | 请确认输入正确的“IMSI”或“MSISDN”后重新执行本命令查询。                                                                                      |
