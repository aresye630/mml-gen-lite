# 增加ADSU鉴权算法配置(ADD ALGTAG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加ADSU鉴权算法配置。

## 注意事项

参数ADSUALG和ALG必选。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                        |
|:--------|:----------|:------------------------------------------------------------------------------------------------------------|
| ADSUALG | ADSU鉴权算法值 | 用于标识ADSU鉴权算法值。 取值范围：1～127 默认值：无。                                                                            |
| ALG     | 鉴权算法类型    | 用于标识鉴权算法类型。 取值范围： COMP128_1COMP128_2COMP128_3MILENAGE 默认值：无。 说明：COMP128_1、COMP128_2鉴权算法为不安全算法，建议使用更安全的鉴权算法。 |

## 使用实例

在［ADSU鉴权算法配置表］中增加一条记录，设置ADSU鉴权算法值为1，鉴权算法类型为COMP128\_1。命令如下：

ADD ALGTAG: ADSUALG=1, ALG=COMP128\_1;
