# 删除短消息中心地址(RMV HSMSCADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS中删除用户签约的短消息中心地址信息。

## 注意事项

当删除用户已签约的短消息中心地址信息时，系统将在数据库中删除该数据记录且不会在UDA消息中携带该短消息中心地址信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| ISDN   | MSISDN | 标识一条短消息中心地址数据记录的关键参数（其取值不能被修改），用于标识待删除短消息中心地址的MSISDN号码。操作员可以使用LST IMSSUB命令查询用户信息获得。 |

## 使用实例

为已开户用户去签约短消息中心地址，“MSISDN”号码为“4600000091234”，执行命令如下：

```
RMV HSMSCADDR: ISDN="4600000091234";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析            | 处理建议                           |
|----------:|:--------|:----------------|:-------------------------------|
| 900001007 | 无效的参数值  | 输入的参数取值不符合要求。   | 根据实际情况，重新输入“MSISDN”，确保其取值符合要求。 |
| 900001008 | 参数不足    | 参数“MSISDN”没有输入。 | 重新输入参数“MSISDN”，确保有输入且符合要求。     |
