# 增加VLR类型数据(ADD VLRTYP)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到该VLR区域后出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中增加VLR类型数据，主要包括：

- 定义VLR相对于本地HLR所属的网络类型，用来标识不同VLR相对于本地HLR的位置信息。

  当一个VLR区域的移动用户向网络发起位置更新请求时，移动用户的归属HLR要根据此VLR所属的网络类型和用户签约的漫游权限来判断该用户在此VLR区域内是否能正常进行位置更新。例如，当用户漫游的VLR所属的网络类型为国际漫游类型，同时该用户有国际漫游权限时，则位置更新成功，否则位置更新失败。
- 定义VLR支持的业务范围，标识是否对指定的VLR进行业务限制。
- 定义VLR的业务支持能力，即VLR是否根据NCC（Network Capability Configuration）模板和CAMEL（Customized Applications for Mobile network Enhanced Logic）模板设置的能力分别对MAP业务和CAMEL业务进行处理。

## 注意事项

- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的VLR类型数据记录数不能超过1500条。

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号             | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| VLRPREFIX      | VLR号码前缀            | 用于标识具有相同号码前缀的VLR。 VLR号码前缀支持最大匹配和精确匹配，即可以输入具有相同前缀的一组VLR号码的前缀，也可以精确到输入一个VLR号码。 例如，A地区的3个VLR，VLR号码分别861375501、861375502、861375503，它们有相同的前缀8613755，配置时可以输入前缀“8613755”配置1次，也可以分别输入“861375501”、“861375502”、“861375503”配置3次。 取值范围：长度不超过14位的数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                      |
| VLRNAME        | VLR名称              | 用于标识不同的VLR。当“VLR号码前缀”配置的是一组VLR时，“VLR名称”标识的就是这组VLR。 取值范围：长度不超过30位的字母或数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TYPE           | VLR号相对于本HLR所属的网络类型 | 用于标识VLR相对于本地HLR所属的网络类型。该参数的配置与运营商的网络规划和运营策略有关，配置前需要与运营商确认。 取值范围： LOCAL（本地）：表示VLR和本地HLR在同一个地区。LOCALDOMESTIC（国内本网）：表示VLR和本地HLR在同一个国家，且在同一个PLMN（Public Land Mobile Network）内。CROSSDOMESTIC（国内跨网）：表示VLR和本地HLR在同一个国家，但在不同的PLMN内。LOCALINTERNATIONAL（国际本网）：表示VLR和本地HLR不在同一个国家，但在相同的PLMN内。CROSSINTERNATIONAL（国际跨网）：表示VLR和本地HLR不在同一个国家，也不在同一个PLMN内。LOCALAREA（省内本网）：表示VLR和本地HLR在同一个省和PLMN内。CROSSAREA（省内跨网）：表示VLR和本地HLR在同一个省内，但在不同的PLMN内。 默认值：无。 如果在本地HLR上不为某VLR配置网络类型，则此VLR相对于本地HLR所属的网络类型默认为“国际跨网”，当归属于此HLR的移动用户漫游到该VLR区域，除非该移动用户有国际漫游权限，否则位置更新将被拒绝。 配置“VLR相对于本地HLR所属的网络类型”时，可参考VLR和本地HLR的位置关系示意图。 |
| NCCTPL         | NCC模板ID            | 用于标识VLR支持的网络能力，使HLR能根据NCC模板设置的VLR的网络能力进行业务和MAP流程的处理，提高HLR和VLR的兼容性。 NCC模板ID对应的网络能力可以通过LST NCCTPL命令进行查询。 配置时若不选择该参数，则HLR默认采用MAP Phase3版本来标识VLR支持的网络能力，所有与VLR相关的业务数据都向VLR下发。 取值范围：0～99998。 默认值：无。 配置原则：必须先由ADD NCCTPL命令定义，然后才能在此引用。                                                                                                                                                                                                                                                                                                                                                          |
| SERVICETY      | 是否允许签约OKSC业务       | 可选参数。 用于设置HLR是否对指定的VLR进行签约业务区域限制。 可以通过MOD OKSC命令签约或去签约业务区域限制。 各参数选项的含义是：PERMISSION：业务允许。 RESTRICT：业务限制。 当该参数设置为“RESTRICT”后，HLR在向指定的VLR下发用户的签约数据时，HLR通过检测该参数得知该VLR已经被设置了业务区域限制，从而在下发用户数据到该VLR时就不会下发不允许的业务。 默认值：PERMISSION。                                                                                                                                                                                                                                                                                                                                                                 |
| CAMELCAPTPL    | CAMEL能力模板ID        | 用于标识VLR支持的CAMEL能力，使指定的VLR根据CAMEL能力模板设置的能力对CAMEL业务进行处理。 CAMEL模板ID对应的CAMEL能力可以通过LST CAMELCAPTPL命令进行查询。 配置时若不选择该参数，则HLR默认采用CAMEL Phase4版本来标识VLR支持的CAMEL能力。 取值范围：0～65534。 默认值：无。 配置原则：必须先由ADD CAMELCAPTPL命令定义，然后才能在此引用。                                                                                                                                                                                                                                                                                                                                                                       |
| ETCSIRESTTPLID | ETCSI限制模板ID        | 用于标识ETCSI限制模板的模板ID。该参数必须先由ADD ETCSIRESTTPL命令定义，然后才能在此引用。 取值范围：0～65534。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## 使用实例

1. 在“HLR序列号”为“1”的HLR上添加VLR网络类型为“国内本网”。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“VLR号相对于本HLR所属的网络类型”为“LOCALDOMESTIC”：

   ```
   ADD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", TYPE=LOCALDOMESTIC;
   ```
2. 在“HLR序列号”为“1”的HLR上添加VLR网络类型，并使该VLR支持业务限制功能。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“VLR号相对于本HLR所属的网络类型”为“LOCALDOMESTIC”，“是否允许签约OKSC业务”为“RESTRICT”：

   ```
   ADD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", TYPE=LOCALDOMESTIC, SERVICETY=RESTRICT;
   ```
3. 在“HLR序列号”为“1”的HLR上添加VLR网络类型，并使该VLR根据CAMEL模板设置的能力对CAMEL业务进行处理。其中，“VLR号码前缀”为“8613800”，“VLR名称”为“VLR1”，“VLR号相对于本HLR所属的网络类型”为“LOCALDOMESTIC”，“CAMEL能力模板ID”为“1”：

   ```
   ADD VLRTYP: HLRSN=1, VLRPREFIX="8613800", VLRNAME="VLR1", TYPE=LOCALDOMESTIC, CAMELCAPTPL=1	;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                      | 处理建议                                                                                                                                                                                         |
|:--------|:--------|:------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“VLR号码前缀”的取值中含有0～9以外的字符。                | 根据实际情况，重新输入“VLR号码前缀”，确保其取值为长度不超过14位的数字组成的字符串。                                                                                                                                                |
| ERR3003 | 模板未定义   | “NCC模板ID”、“CAMEL能力模板ID”或“ETCSI限制模板ID”未定义。 | 根据实际情况选择：如果需要使用已定义的模板，则分别执行LST NCCTPL命令、LST CAMELCAPTPL命令或LST ETCSIRESTTPL命令查询已定义的NCC模板、CAMEL能力模板或ETCSI限制模板的ID，然后输入。如果需要重新定义新的模板，则分别执行ADD NCCTPL命令、ADD CAMELCAPTPL命令或ADD ETCSIRESTTPL命令添加模板。 |
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号添加相同的VLR号码前缀。                 | 该VLR号码前缀已添加，根据实际情况确认是否需要添加其他的VLR号码前缀。                                                                                                                                                        |
| ERR3007 | 记录不存在   | HLR序列号未定义。                                | 根据实际情况选择：如果需要为该HLRSN添加VLR类型数据，则执行ADD HLRSN命令先定义该HLRSN，再为该HLRSN添加VLR类型数据。如果需要为已定义的HLRSN添加VLR类型数据，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN添加VLR类型数据。                                             |
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的VLR类型数据记录数超过1500条。         | 根据实际情况，如需增加VLR类型数据，处理步骤如下：执行LST VLRTYP命令，查询已存在的VLR类型数据。执行RMV VLRTYP命令，删除不必要的VLR类型数据。执行该命令增加VLR类型数据，确保增加的VLR类型数据记录数在规定范围之内。                                                                   |
