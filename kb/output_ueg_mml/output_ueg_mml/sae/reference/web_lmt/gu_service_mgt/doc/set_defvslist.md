# 设置VLR/SGSN漫游限制模板的缺省漫游限制状态(SET DEFVSLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，可能导致漫游受限，影响在网用户漫游，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置VLR/SGSN漫游限制模板的缺省漫游限制状态。在该命令中，系统通过以下关键参数的组合来唯一标识一个VLR/SGSN漫游限制模板的缺省漫游限制状态：

- “HLR序列号”
- “模板ID”
- “模板类型”

## 注意事项

“缺省漫游限制状态”参数作用范围为该命令中模板ID的取值范围，只能通过该命令设置，无法删除。如果设置不当将导致该VLR/SGSN区域下的用户，在未设置漫游限制模板时不能正常漫游。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                               |
|:----------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN           | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                                                                                                                                                                     |
| TPLID           | 模板ID       | 用于标识VLR/SGSN漫游限制模板在系统中的序号。该参数必须先由ADD VSLIST命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                     |
| TPLTYPE         | 模板类型       | 用于标识模板类型，通过该参数区分是VLR模板还是SGSN模板。 取值范围：VLR：表示通过拜访位置寄存器限制用户漫游区域，若限制CS域选择VLR。SGSN：表示通过服务GPRS支持节点限制用户漫游区域，若限制PS域选择SGSN。 默认值：无。                                                                                                          |
| ROAMDEFAULTRULE | 缺省漫游限制状态   | 用于标识用户漫游到的VLR/SGSN的号码与模板中的VLR/SGSN号码不匹配时，是否允许漫游。 取值范围：PERMISSION：漫游允许，表示允许用户在该VLR/SGSN区域漫游。 RESTRICT：漫游限制，表示不允许用户在该VLR/SGSN区域漫游。 BAOCTS11：闭锁语音出呼，表示用户在该VLR/SGSN区域漫游，只限制语音呼出业务，不限制语音呼入及数据业务。 CUSTOMIZED：定制业务，表示可根据客户的要求定制业务。 默认值：无。 |
| DEFSERRESTTPLID | 缺省业务限制模板ID | 仅当本命令中的“缺省漫游限制状态”参数为“CUSTOMIZED”时该参数有效。用于标识缺省业务限制模板ID，即用户漫游到的VLR/SGSN的号码与模板中的VLR/SGSN号码不匹配时，通过签约业务限制模板HLR向VLR/SGSN下发缺省状态下运营商限制的业务。该参数必须先由ADD SERRESTTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                         |
| DEFRSITPLID     | 缺省业务下发模板ID | 仅当本命令中的“缺省漫游限制状态”参数为“CUSTOMIZED”时该参数有效。用于标识缺省业务下发模板ID，即用户漫游到的VLR/SGSN的号码与模板中的VLR/SGSN号码不匹配时，通过签约业务下发模板HLR向VLR/SGSN下发缺省状态下运营商定制的业务。该参数必须先由ADD RSITPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                             |

## 使用实例

允许用户在该命令中模板ID的取值范围内漫游。其中，“HLR序列号”为“1”，“模板ID”为“0”，“模板类型”为“VLR”，“缺省漫游限制状态”为“PERMISSION”：

```
SET DEFVSLIST: HLRSN=1, TPLID=0, TPLTYPE=VLR, ROAMDEFAULTRULE=PERMISSION;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                    | 处理建议                                                                                                                                        |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：待修改的VLR/SGSN漫游限制模板未定义：“HLR序列号”或者“模板ID”未定义。需要修改的模板的“模板ID”和“模板类型”不匹配。 当界面输入“缺省漫游限制状态”参数为“CUSTOMIZED”时，“缺省业务限制模板ID”或“缺省业务下发模板ID”参数指示的模板在数据库中未定义。 | 根据实际情况，重新输入参数，确保满足以下两点：使用LST VSLIST命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的VLR/SGSN漫游限制模板数据记录。在使用“缺省业务限制模板ID”或“缺省业务下发模板ID”参数指示的模板前，确保这些模板在数据库中已存在。 |
| ERR1010 | 参数冲突    | 当“缺省漫游限制状态”参数不为“CUSTOMIZED”时，输入了“缺省业务限制模板ID”或“缺省业务下发模板ID”参数。                                                                                            | 根据实际情况，重新输入参数，确保“缺省漫游限制状态”参数不为“CUSTOMIZED”时，不能输入“缺省业务限制模板ID”或“缺省业务下发模板ID”参数。                                                                |
| ERR1009 | 参数缺失    | 当“缺省漫游限制状态”参数为“CUSTOMIZED”时，未输入“缺省业务限制模板ID”或“缺省业务下发模板ID”参数。                                                                                             | 根据实际情况，重新输入参数，确保“缺省漫游限制状态”参数为“CUSTOMIZED”时，输入“缺省业务限制模板ID”或“缺省业务下发模板ID”参数。                                                                   |
