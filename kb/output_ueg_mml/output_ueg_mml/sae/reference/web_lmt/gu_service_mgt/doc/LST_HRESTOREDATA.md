# 查询IMS用户的3GPP标准S-CSCF容灾数据(LST HRESTOREDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMS用户的3GPP标准S-CSCF容灾数据。

## 注意事项

“IMPI”和“IMPU”参数必须至少存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指定一个要查询容灾数据的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无             |
| IMPU   | IMPU   | 用于指定一个要查询容灾数据的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无 |

## 使用实例

查询“IMPI”为“+862986010343@huawei.com”，“IMPU”为“tel:+862986010344”的IMS用户的容灾数据。

```
LST HRESTOREDATA: IMPI="+862986010343@huawei.com", IMPU="tel:+862986010344";
```
