# 查询NEF漫游状态事件通知PLMN黑白名单(LST NEFROAMNTFPLMNWBLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统配置的NEF漫游状态事件通知PLMN黑白名单数据记录。

- 当不输入“PLMNID”参数时，系统显示指定“HLR序列号”下所有NEF漫游状态事件通知PLMN黑白名单数据记录。
- 当输入“PLMNID”参数时，系统显示一条具体NEF漫游状态事件通知PLMN黑白名单数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：用于指定根据哪个HLR序列号来查询系统配置的NEF漫游状态事件通知PLMN黑白名单记录。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                     |
| PLMN   | PLMNID | 可选必选说明：可选参数 参数含义：用于指定根据哪个PLMN序列号来查询系统配置的NEF漫游状态事件通知PLMN黑白名单记录。 取值范围：5～6位的十进制数字组成的字符串。 默认值：无。 配置原则：“PLMNID”的取值是由MCC（前三位）和MNC（后两至三位）组成，当输入的MNC不足三位时前面会自动补0。如：输入“12345”，系统识别为 PLMNID=“123045”。 |

## 使用实例

- 查询指定“HLR序列号”下所有NEF漫游状态事件通知PLMN黑白名单数据记录。

  ```
  LST NEFROAMNTFPLMNWBLIST: HLRSN=1;
  ```

  ```
  %%LST NEFROAMNTFPLMNWBLIST: HLRSN=1;%%
  RETCODE = 0 SUCCESS0001:Operation is successful
  PLMN     TYPE
  111011   WHITELIST
  333333   BLACKLIST
  Total count = 2
  There is together 1 report
  ---    END
  ```
- 查询一条具体NEF漫游状态事件通知PLMN黑白名单数据记录。

  ```
  LST NEFROAMNTFPLMNWBLIST: HLRSN=1, PLMN="111011";
  ```

  ```
  %%LST NEFROAMNTFPLMNWBLIST: HLRSN=1, PLMN="111011";%%
  RETCODE = 0 SUCCESS0001:Operation is successful
                            PLMN = 111011
                            TYPE = WHITELIST
  Total count = 2
  There is together 1 report
  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NEFROAMNTFPLMNWBLIST**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1009 | 参数缺失      | 必选参数缺失：“HLR序列号”、“PLMNID”参数中的一个或多个缺失。                       | 重新输入缺失的参数。                                                                                                                                                                                     |
