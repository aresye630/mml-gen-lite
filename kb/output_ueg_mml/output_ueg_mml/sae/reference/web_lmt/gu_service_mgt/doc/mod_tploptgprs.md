# 模板修改优化GPRS/EPS业务(MOD TPLOPTGPRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作采用优化GPRS/EPS模板来为用户提供、修改或删除GPRS/EPS业务。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 参数PROV设置为TRUE，参数TPLID为必选参数，否则为可选参数。
- 当命令**SET MAPSERV**中参数“GPRS管理方式”的值设置为“SuppGprsManageOptimizeonTplBind”时，本命令和**MOD OPTGPRS**命令可同时为用户签约APN，且本命令是通过用户模板绑定方式为用户签约。签约的APN在进行下发时，如果出现通过**MOD OPTGPRS**命令签约的APN和通过本命令用模板绑定方式签约的APN存在冲突时，则下发通过**MOD OPTGPRS**命令签约的APN和通过本命令用模板绑定方式签约的不冲突的APN，即下发APN数据时通过**MOD OPTGPRS**命令签约的APN优先级高于通过本命令用模板绑定方式签约的APN。
- 当删除用户所有4G的APN时，触发的CancelLocation消息中信元cancelType的取值由**SET MAPSERV**命令中参数“cancelType的取值”控制。

## 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI           | 用于标识IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。 默认值：无。                                                                                                                                                                                                                                                                                                                                                             |
| ISDN           | MSISDN         | 用于标识MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。 默认值：无。                                                                                                                                                                                                                                                                                                                                                           |
| RECORDCOUNT    | 用户个数           | 用于标识用户的数目，代表以指定的IMSI、MSISDN为起始号码，号码连续的用户个数；如果只有一个用户，该参数不必提供。 取值范围：1～100000 默认值：无。                                                                                                                                                                                                                                                                                                                           |
| IMSIFILE       | IMSI文件名        | 用于标识IMSI文件名称。 取值范围：1～16位的字母或数字，包含多个不连续的IMSI号码。 默认值：无。                                                                                                                                                                                                                                                                                                                                                       |
| ISDNFILE       | MSISDN文件名      | 用于标识MSISDN文件名称。 取值范围：1～16个字母或数字，包含多个不连续的MSISDN号码。 默认值：无。                                                                                                                                                                                                                                                                                                                                                    |
| PROV           | 是否提供优化GPRS业务   | 用于标识是否提供优化GPRS/EPS业务。 取值范围：TRUE：提供/修改FALSE：删除 默认值：无。                                                                                                                                                                                                                                                                                                                                                        |
| TPLID          | 优化GPRS模板ID     | 仅当本命令中的“是否提供优化GPRS业务”参数为“TRUE”或“FALSE”时该参数有效。用于标识优化GPRS模板ID。该参数必须先由ADD OPTGPRSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 说明：当本命令中的“是否提供优化GPRS业务”参数为“TRUE”时，该参数为必选参数。当SET MAPSERV命令“GPRS管理方式”参数为“NotSupportGPRSManager”或“SupportGPRSManager”，执行LST SUB命令查询得到用户的“NAM”为非“NONE”的值，执行该命令给用户签约包含“APN类型”为“PS_APN”或“BOTH”的PDP/PDN上下文的优化GPRS/EPS模板，此时虽然用户可以成功签约该优化GPRS/EPS模板，但是当用户GPRS位置更新成功时UDM不会下发PS域APN，GPRS业务无法正常使用。 |
| DELOLD         | 是否删除已有的APN     | 仅当本命令中的“是否提供优化GPRS业务”参数为“TRUE”时该参数有效。用于标识是否删除已有的APN。 取值范围：FALSE：不删除TRUE：删除 默认值：FALSE 说明：当SET MAPSERV命令中参数“GPRS管理方式”的值设置为“SuppGprsManageOptimizeonTplBind”时，该参数的设置不起作用，系统默认按照删除已有的APN方式处理。                                                                                                                                                                                                                   |
| ONLYFORDISPLAY | 是否存储优化GPRS模板ID | 仅当本命令中的“是否提供优化GPRS业务”参数为“TRUE”时该参数有效。用于标识是否存储用户签约的“优化GPRS模板ID”。 取值范围：FALSE：否TRUE：是 默认值：无 说明：当该参数取值为“TRUE”，执行该命令时，不用于修改优化GPRS/EPS业务。若需要修改优化GPRS/EPS业务，该参数取值为“FALSE”或不设置该参数。当且仅当该参数取值为“TRUE”且SET MAPCONF命令中参数“是否在LST OPTGPRS命令返回报文中显示用户签约的优化GPRS模板ID”取值为“TRUE”时，会在LST OPTGPRS命令返回报文中显示用户签约的“优化GPRS模板ID”。                                                                                                      |

## 使用实例

1. 模板修改优化GPRS业务：IMSI为460000009123456，提供优化GPRS业务，优化GPRS模板的ID为2。执行命令如下：

   ```
   MOD TPLOPTGPRS: IMSI="460000009123456", PROV=TRUE, TPLID=2, DELOLD=FALSE;
   ```
2. 模板修改优化GPRS业务：IMSI为460000009123456，不提供优化GPRS业务，优化GPRS模板的ID为2。执行命令如下：

   ```
   MOD TPLOPTGPRS: IMSI="460000009123456", PROV=FALSE, TPLID=2;
   ```
3. 模板修改优化GPRS业务：IMSI为460000009123456，不提供优化GPRS业务。执行命令如下：

   ```
   MOD TPLOPTGPRS: IMSI="460000009123456", PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                        | 处理建议                                                                                                                                                                                                                                                                                 |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3196 | 参数冲突    | 当参数“是否删除已有的APN”取值为“FALSE”时，用户已签约的模板与输入的“优化GPRS模板ID”中“APN模板ID”相同的“PDP/PDN上下文索引值”对应的“是否是Non-IP PDN类型的APN”不一致。 | 执行该命令前先通过LST OPTGPRSTPL命令查询已定义的优化GPRS/EPS模板相关信息，如果存在用户已签约的模板与输入的“优化GPRS模板ID”中“APN模板ID”相同的“PDP/PDN上下文索引值”对应的“是否是Non-IP PDN类型的APN”不一致的情况，请先通过MOD OPTGPRS修改一致后再执行该命令。确保满足：当参数“是否删除已有的APN”取值为“FALSE”时，输入的“优化GPRS模板ID”与用户已签约的模板中“APN模板ID”相同的“PDP/PDN上下文索引值”对应的“是否是Non-IP PDN类型的APN”一致的条件。 |
