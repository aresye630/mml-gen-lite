# 新增测试用户（ADD TESTUSERLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于新增测试用户。

## 注意事项

每种“用户类型”最多可配置500个测试用户。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                 |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------|
| USERTYPE | 用户类型   | 可选必选说明：必选参数 参数含义：用于标识待添加的测试用户类型。 取值范围： IMSIIMPI 默认值：无。 配置原则：无。                                       |
| IMSI     | IMSI号码 | 可选必选说明：条件必选参数 参数含义：用于标识待添加的测试用户的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。 配置原则：该参数仅在“用户类型”取值为“IMSI”时有效。 |
| IMPI     | IMPI号码 | 可选必选说明：条件必选参数 参数含义：用于标识待添加的测试用户的IMPI号码。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数仅在“用户类型”取值为“IMPI”时有效。      |

## 使用实例

新增“IMSI号码”为“460000009123456”的新增测试用户。

```
ADD TESTUSERLIST: USERTYPE=IMSI, IMSI="460000009123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1 错误码列表所示。

| 错误码     | 错误码解释   | 原因分析                                        | 处理建议                                                      |
|:--------|:--------|:--------------------------------------------|:----------------------------------------------------------|
| ERR1009 | 参数丢失    | 必选参数和条件必选参数未填。                              | 请重新输入，确保必选参数和条件必选参数均有输入。                                  |
| ERR1010 | 参数冲突    | 可能原因为如下之一： IMSI和IMPI不能同时输入。用户类型和输入的号码类型不匹配。 | 根据实际情况，重新输入参数，确保满足以下两点： IMSI和IMPI只能输入1个。用户类型和输入的号码类型需要匹配。 |
| ERR1037 | 记录已经存在  | 当前输入的测试用户已存在。                               | 执行LST TESTUSERLIST命令查询已经添加的测试用户，根据查询结果，重新输入一个未添加的测试用户。    |
