# 修改服务号码(MOD OSNNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于修改服务号码信息，即服务号码的“服务号码名称”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                       |
|:--------|:-------|:-----------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。               |
| OSNNUM  | 服务号码   | 用于标识SRI消息中需要进行特殊处理的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |
| OSNNAME | 服务号码名称 | 为便于识别，为服务号码指定的名称。 取值范围：1～60个字母或数字组成的字符串。 默认值：无。            |

## 使用实例

修改一个服务号码的服务号码名称，设置“HLR序列号”为“1”，“服务号码”为“1234567890”，“服务号码名称”为“service2”：

`MOD OSNNUM: HLRSN=1, OSNNUM="1234567890", OSNNAME="service2";`
