# 修改本网携出用户(MOD NPDONORSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于修改携出用户数据。

此操作支持批处理。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，任何一个参数出现即可。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                          |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                                                |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                             |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                |
| IMSIFILE    | IMSI文件名   | 文件名称，1～16位的数字或字符组成的字符串，不可包括路径名称。 IMSIFILE的内容由不连续的IMSI号码组成。 说明：可选参数。                                                                           |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。 说明：可选参数。                                                                                      |
| RN          | 路由码       | 路由码，1～10位的十进制数字或者A~E字符。 说明：可选参数。                                                                                                              |
| AUDIT       | AUDIT     | 仅在SOAP接口中使用，用于标识待修改的用户不存在时的处理方式。 取值范围： 非1整数：待修改的用户不存在，上报“ERR3044 无效的参数取值”。1：待修改的用户不存在，则按照新增记录处理。 说明：执行该命令不输入该参数时，待修改的用户不存在，上报“ERR3007 记录未定义”。 |
| MSCNUM      | MSC号码     | MSC号码，E.164格式的编码，1～15位的十进制数字。 说明：可选参数。                                                                                                        |

## 使用实例

修改单个携出用户。

修改IMSI号码为460000009012345的携出用户的路由码为1113，命令如下：

```
MOD NPDONORSUB: IMSI="460000009012345", RN="1113";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                | 处理建议                       |
|:--------|:--------|:--------------------|:---------------------------|
| ERR3007 | 记录不存在   | 输入的“AUDIT”对应的用户不存在。 | 根据实际情况，重新输入参数，确保输入的用户是存在的。 |
| ERR3044 | 无效的参数取值 | 输入的“AUDIT”为非1的取值。   | 重新输入“AUDIT”，取值为“1”，执行该命令。  |
