# 删除SMF数据(RMV SMDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除已经存在的5GS会话管理签约数据。

- 只输入IMSI或者MSISDN参数时表示删除用户所有的会话管理数据信息。

- 输入IMSI或者MSISDN参数同时输入“切片标识”参数时，删除用户此“切片标识”下的所有会话管理数据信息。

- 输入IMSI或者MSISDN参数同时输入“切片标识”和“数据网名称”参数时，删除用户此“切片标识”下的指定会话管理数据信息。

- 其它组合不允许。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 每用户每SNSSAI下必须存在一个且只允许存在一个默认DNN。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                      |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要删除哪个IMSI号码的会话管理数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                         |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除哪个MSISDN号码的会话管理数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                       |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识待删除会话管理数据的用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 需要为连续号码的多个用户删除会话管理数据时配置该参数。当只有一个用户时，该参数无需配置。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除会话管理数据。当一次删除会话管理数据的用户个数很多时，对系统性能无影响，但删除会话管理数据的用户个数越多，消耗的时间越长。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除的会话管理数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsmdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。               |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要删除会话管理数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsmdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。          |
| SNSSAI      | 切片标识      | 可选必选说明：可选参数 参数含义：用于标识网络切片ID。该参数必须由ADD SNSSAI命令签约后才能在此处引用。 取值范围：1～10位字符串。 默认值：无。 配置原则：无。                                                                                                                                   |
| DNN         | 数据网名称     | 可选必选说明：可选参数 参数含义：用于标识数据网名称。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无。 配置原则：无。                                                                                                                                     |

## 使用实例

删除会话管理数据信息，“IMSI”为“460000009123456”，“切片标识”为“1-123456”，“数据网名称”为“dnn”：

```
RMV SMDATA: IMSI="460000009123456", SNSSAI="1-123456", DNN="dnn";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:----------|:-----------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 参数取值范围不符。                                                                                            | 根据系统提示及实际情况，重新输入参数值，确保其取值符合取值范围的要求。                                                                               |
| ERR1005 | 文件不存在     | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                     | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1009 | 参数丢失      | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数同时缺失。                                                     | 根据实际情况，“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。                                                    |
| ERR1010 | 参数冲突      | 可能的原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户     | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                               | 核实并输入正确的用户的“IMSI”或“MSISDN”。                                                                                       |
| ERR4112 | 默认DNN不能删除 | 该SNSSAI下存在非默认DNN，待删除的DNN数据为默认DNN。                                                                    | 根据实际情况，通过LST SMDATA命令查询DNN数据，删除非默认DNN数据或者删除全部DNN数据。                                                               |
