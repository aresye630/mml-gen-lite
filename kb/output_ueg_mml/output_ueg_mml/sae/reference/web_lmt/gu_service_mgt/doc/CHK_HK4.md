# 校验K4(CHK HK4)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于校验K4的值。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“K4值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“K4值”以明文显示。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                           |
|:--------|:-------|:-------------------------------------------------------------------------------|
| K4SNO   | K4索引号  | 标识一条K4值的关键参数之一，用于指示系统验证哪一条K4索引对应的K4值。 取值范围： 1～128 缺省值： 无                       |
| K4VALUE | K4值    | 标识一条K4值的关键参数之一，用于指示系统验证哪一个K4值。要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于16的16进制字符串 缺省值： 无 |

## 使用实例

校验K4。K4索引号：1，K4值：1234567890abcDEF。

```
CHK HK4: K4SNO=1, K4VALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                          | 处理建议        |
|----------:|:--------|:--------------------------------------------------------------|:------------|
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
