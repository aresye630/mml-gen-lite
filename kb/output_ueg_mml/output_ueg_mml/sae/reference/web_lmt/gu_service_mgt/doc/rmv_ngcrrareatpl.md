# 删除NGC漫游限制区域模板(RMV NGCRRAREATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在数据库中删除一个NGC漫游限制区域模板。

## 注意事项

删除模板时需要执行**LST NGCRRNODETPL**检查模板数据引用情况，如果被引用，则不允许删除。如果要删除模板，则要先执行**MOD NGCRRNODETPL**删除被NGC漫游限制模板引用的模板信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识NGC漫游限制区域模板数据记录的关键字段之一，用于指定在哪个HLR上删除NGC漫游限制区域模板的数据记录，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无 配置原则：无            |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识NGC漫游限制区域模板数据记录的关键字段之一，用于指定需要删除哪条NGC漫游限制区域模板的数据记录，操作员可以使用LST NGCRRAREATPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

删除NGC漫游限制区域模板,“HLR序列号”为“1”，“模板ID”为“1”,命令如下：

```
RMV NGCRRAREATPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                        | 处理建议                                                                |
|:--------|:--------|:----------------------------|:--------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应模板数据记录不存在。 | 使用LST NGCRRAREATPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的NGC漫游限制区域模板数据记录。 |
| ERR3005 | 模板已经被使用 | “模板ID”被引用，该NGC漫游限制区域模板无法删除。 | 如果要删除该NGC漫游限制区域模板，必须先执行MOD NGCRRNODETPL命令删除相关被引用的模板信息。              |
