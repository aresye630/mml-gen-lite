# 增加5G共享数据模板(ADD SHRDATATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在系统中增加5GS共享数据模板数据记录，该模板定义了5GC网络和EPC网络共有的数据，目前主要是ARD和CN Restriction。

该命令的使用场景：为用户提供模板方式签约共享数据，执行本命令增加5G共享数据模板后，通过**MOD SHRDATA**命令引用该模板为用户提供相应业务。

## 注意事项

所有“HLR序列号”中增加的5GS共享数据模板记录数不能超过5000条。

## 使用实例

通过该命令增加模板，当需要给用户签约核心网接入类型限制管理数据时通过**MOD SHRDATA**命令引用该模板，为用户提供相应业务。

1. 增加一个5G共享数据模板。“HLR序列号”为“1”，“模板ID”为“8”，“模板名”为“shrdatatpl”，“不允许接入EPC”为“FALSE”，“不允许接入5GC”为“FALSE”，“不允许接入E-UTRAN”为“FALSE”。

   ```
   ADD SHRDATATPL: HLRSN=1, TPLID=8, TPLNAME="shrdatatpl", EPCNOTALLOWED=FALSE, NGCNOTALLOWED=FALSE, EUTRANNOTALLOWED=FALSE;
   ```
2. 增加一个5G共享数据模板。“HLR序列号”为“1”，“模板ID”为“9”，“模板名”为“shrdatatpl\_01”，“不允许接入EPC”为“FALSE”，“不允许接入5GC”为“FALSE”，“不允许接入E-UTRAN”为“FALSE”，“不允许接入NB-IoT”为“TRUE”，“不允许NR作为第二RAT”为“TRUE”，“不允许接入NR”为“TRUE”。

   ```
   ADD SHRDATATPL: HLRSN=1, TPLID=9, TPLNAME="shrdatatpl_01", EPCNOTALLOWED=FALSE, NGCNOTALLOWED=FALSE, EUTRANNOTALLOWED=FALSE, NBIOTNOTALLOWED=TRUE, NRNOTALLOWED=TRUE, NR5GSNOTALLOWED=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                   | 处理建议                                                                                                                                       |
|:--------|:--------|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                           |
| ERR3004 | 模板已存在   | “模板ID”在数据库中已存在。        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST SHRDATATPL命令查询系统中已存在的共享数据模板。                                                                   |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。           | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                             |
| ERR3047 | 超过最大限制  | 增加的5G共享数据模板记录数超过5000条。 | 根据实际情况，如需增加5G共享数据模板，处理步骤如下： 执行LST SHRDATATPL命令，查询已存在的5G共享数据模板。 执行RMV SHRDATATPL命令，删除不必要的5G共享数据模板。 执行该命令增加5G共享数据模板，确保增加的5G共享数据模板记录数在规定范围之内。 |
