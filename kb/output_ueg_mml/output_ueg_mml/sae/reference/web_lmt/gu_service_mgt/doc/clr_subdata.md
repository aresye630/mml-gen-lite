# 清除垃圾数据(CLR SUBDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户数据丢失和系统过载，因此执行该命令前，请仔细评估当前系统能力，确认对系统没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

当发现数据库中存在垃圾数据（例如，执行查询命令时提示某用户不存在，但是开户时失败，提示用户已经开户），且无法通过正常命令予以恢复时，通过本命令强制清除指定用户相关的数据。

- 如果输入的是IMSI，删除所有含有IMSI字段的表数据。
- 如果输入的是ISDN，删除所有含有ISDN字段的表数据。

## 注意事项

- 当用户数据不完整的时候，需要执行这条命令删除用户残留的垃圾数据，由于用户数据不完整，所以无法根据路由信息找到用户数据所在的DSU节点，只能通过广播方式在所有的DSU节点删除一遍，如果在话务高峰或连续多次执行会引起系统过载。
- 执行该命令前需确定该用户的数据不再使用、可以清除；执行该命令时必须避开话务高峰期，不要连续、大批量执行。
- 若本命令需要执行多条，需间隔一段时间后执行，不可连续执行，具体间隔时间请与华为技术支持联系后根据实施方案执行。
- 在混合组网下，在vRSP或vSP执行该命令时，仅删除本分区的用户数据，不跨分区删除其他分区的数据。
- 当输入的参数对应的用户不存在时，该命令返回执行成功。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                           |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------|
| IMSI          | IMSI     | 用于标识待清除垃圾数据的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                              |
| ISDN          | MSISDN   | 用于标识待清除垃圾数据的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                            |
| SID           | SID      | 用于标识用户的SID。 取值范围：16位十六进制数字组成的字符串。 默认值：无。                                                                                       |
| QUERY_ALL_DSU | 是否发起广播查询 | 用于标识是否需要发起广播查询。 取值范围：TRUE：广播查询，当用户路由数据丢失时，广播查询所有DSU，然后删除指定用户号码关联的表。FALSE：不广播查询，当用户路由数据存在时，以指定用户号码获取用户SID后，基于SID删除所有关联表。 默认值：无。 |

## 使用实例

清除IMSI号码为"460000009123456"的用户数据。命令如下：

```
CLR SUBDATA: IMSI="460000009123456";
```
