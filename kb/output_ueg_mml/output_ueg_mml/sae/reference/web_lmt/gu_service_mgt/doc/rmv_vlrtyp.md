# 删除VLR类型数据(RMV VLRTYP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到该VLR区域后出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条或多条VLR类型数据记录。

## 注意事项

- 删除对应的VLR类型后，该VLR类型默认为“国际跨网（CROSSINTERNATIONAL）”。当用户漫游到此VLR区域后可能出现位置更新失败，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                               |
|:----------|:--------|:-------------------------------------------------------------------|
| HLRSN     | HLR序列号  | 标识VLR类型数据记录的关键字段之一，用于指定在哪个HLR上删除VLR类型的数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| VLRPREFIX | VLR号码前缀 | 标识VLR类型数据记录的关键字段之一，用于指定需要删除哪些VLR类型的数据记录，操作员可以使用LST VLRTYP命令查询获得。   |

## 使用实例

删除“HLR序列号”为“1”的HLR上的VLR类型数据。其中，“VLR号码前缀”为“8613800”：

```
RMV VLRTYP: HLRSN=1, VLRPREFIX="8613800";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                   |
|:--------|:--------|:------------------------------------|:-------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“VLR号码前缀”的取值中含有0～9以外的字符。          | 根据实际情况，重新输入“VLR号码前缀”，确保其取值为长度不超过14位的数字组成的字符串。          |
| ERR3007 | 记录不存在   | HLR序列号和VLR号码前缀对应的VLR类型数据记录不存在或已被删除。 | 使用LST VLRTYP命令查询后，重新确认要删除哪个HLR序列号和VLR号码前缀对应的VLR类型数据记录。 |
