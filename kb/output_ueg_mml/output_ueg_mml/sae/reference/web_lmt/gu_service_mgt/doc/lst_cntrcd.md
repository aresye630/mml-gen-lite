# 查询国家/地区码(LST CNTRCD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询国家/地区码的配置信息。

- 若需要查询系统中所有国家/地区码的配置信息，请不要输入“国家/地区码”参数。
- 若需要查询系统中某条国家/地区码的详细配置信息，请输入“国家/地区码”参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                             |
|:---------|:-------|:-------------------------------------------------|
| CNTRCODE | 国家/地区码 | 用于指示系统需要按照哪个国家/地区码来查询国家/地区码数据；若不输入，则表示所有的国家/地区码。 |

## 使用实例

1. 查询系统中所有国家/地区码数据记录，不输入参数：

   ```
   LST CNTRCD:;
   ```
2. 查询“国家/地区码”为“86”的国家/地区码数据记录：

   ```
   LST CNTRCD: CNTRCODE="86";
   ```

   ```
   %%LST CNTRCD: CNTRCODE="86";%%
   RETCODE = 0 SUCCESS0001:操作成功

           "COUNTRY AREA CODE"    "COUNTRY AREA NAME"
           86                     CHINA

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD CNTRCD**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                                   |
|:--------|:--------|:-------------|:-------------------------------------------------------|
| ERR3007 | 记录不存在   | “国家/地区码”未定义。 | 根据实际情况，重新输入已定义的“国家/地区码”，可通过LST CNTRCD命令查询已定义的“国家/地区码”。 |
