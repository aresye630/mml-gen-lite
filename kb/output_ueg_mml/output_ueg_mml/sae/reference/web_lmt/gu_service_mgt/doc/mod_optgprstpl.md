# 修改优化GPRS/EPS模板(MOD OPTGPRSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于修改优化GPRS/EPS模板。

## 注意事项

- 如果给模板增加PDP/PDN上下文，“操作类型”参数设置为“ADDPDPCNTX”时，同时需要设置以下参数：
  - 当“APN类型”参数取值为“PS\_APN”时，需要输入“QoS模板ID”、“计费特性”或“标准计费特性”参数。
  - 当“APN类型”参数取值为“EPS\_APN”时，需要输入“EPS QoS模板ID”、“计费特性”或“标准计费特性”参数。
  - 当“APN类型”参数取值为“BOTH”时，需要输入“QoS模板ID”、“EPS QoS模板ID”、“计费特性”或“标准计费特性”参数。
- 如果修改模板的PDP/PDN上下文，则需要先通过**LST OPTGPRSTPL**查询出对应的“PDP/PDN上下文索引值”或“APN模板ID”，然后设置“操作类型”为“MODPDPCNTX”，根据“PDP/PDN上下文索引值”修改其他参数，或根据“APN模板号”修改其他参数。
- 如果是删除模板的PDP/PDN上下文，“操作类型”设置为“RMVPDPCNTX”，同时需要设置“PDP/PDN上下文索引值”或“APN模板ID”的值。
- 当给模板增加PDP/PDN上下文时，如果系统支持ContextID自动排序生成，则“PDP/PDN上下文索引值”可以不设置；反之，这个参数则一定要设置。
- 一个优化GPRS/EPS模板中最多可定义50个PDP/PDN上下文。
- 同一优化GPRS/EPS模板中的不同PDP/PDN上下文中PDP/PDN类型、PDP/PDN地址、APN模板ID不能够全部相同。
- 此模板被修改后，已经签约此模板的用户，数据不会被同步修改；后续再签约此模板的用户将使用修改后的模板数据。
- 系统中所有优化GPRS/EPS模板增加的PDP/PDN上下文总记录数不能超过40000条。

## 使用实例

修改模板ID为3的优化GPRS/EPS模板，该模板已经存在，待修改PDP/PDN上下文索引为2，APN模板ID为2，QoS模板ID为2，PDP/PDN类型为IPV4。命令如下：

MOD OPTGPRSTPL: HLRSN=1, TPLID=3, PROV=MODPDPCNTX, CNTXID=2, APNTPLID=2, QOSTPLID=2, PDPTYPE=IPV4;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制   | 所有优化GPRS/EPS模板增加的“PDP/PDN上下文索引值”总记录数超过40000条。                                                                              | 根据实际情况，如需增加PDP/PDN上下文索引值，处理步骤如下：执行LST OPTGPRSTPL命令，查询已存在的PDP/PDN上下文索引值。执行该命令删除不必要的PDP/PDN上下文索引值。执行该命令增加PDP/PDN上下文索引值，确保增加的PDP/PDN上下文索引值在规定范围之内。                           |
| ERR3111 | 系统不支持该特性 | 当SET MAPSERV命令“GPRS管理方式”参数为“NotSupportGPRSManager”或“SupportGPRSManager”时，不能通过执行该命令给模板增加“APN类型”为“PS_APN”或“BOTH”的PDP/PDN上下文。 | 根据实际情况，如需给模板增加“APN类型”为“PS_APN”或“BOTH”的PDP/PDN上下文，需要执行SET MAPSERV命令设置“GPRS管理方式”参数为非“NotSupportGPRSManager”或“SupportGPRSManager”的值。“GPRS管理方式”参数开局设定之后不能修改，如非开局场景，请勿修改此参数配置。 |
