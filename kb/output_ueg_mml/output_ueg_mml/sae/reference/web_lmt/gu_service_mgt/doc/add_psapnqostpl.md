# 增加PSAPNQOS模板(ADD PSAPNQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中增加一条PS模板数据记录。

PS模板通过“APN模板ID”和“QOS模板ID”参数关联APN模板和QOS模板，定义了PS用户的APN数据信息、QoS数据信息和PDP数据信息，通过执行**MOD PSSER**命令为用户签约PS业务，只需签约对应的PS模板。

## 注意事项

- “PDP级别计费特性”和“标准计费特性”参数必须有且只能有一个参数出现。
- 同一个“HLR序列号”中增加的PS模板记录数不能超过20000条，且系统中增加的所有PS模板记录数不能超过30000条。

## 使用实例

为用户签约PS业务数据：

1. 增加PS模板，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“PSAPN-QoS”，“APN模板ID”为“2”，“QOS模板ID”为“2”，“PDP地址类型”为“IPV4”，“是否允许用户从VPLMN访问PDP网络”为“TRUE”，采用热付费计费方式，命令如下：

   ```
   ADD PSAPNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="PSAPN-QoS", APNTPLID=2, QOSTPLID=2, PDPTYPE=IPV4, VPLMN=TRUE, PDPCHARGE=HOT;
   ```
2. 执行**MOD PSSER**给用户签约PS业务，命令如下：

   ```
   MOD PSSER: IMSI="460000009012345", PROV=ADDPDPCNTX, CNTXID=2, PSAPNQOSTPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                            | 处理建议                                                                                                                  |
|:--------|:--------|:--------------------------------|:----------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                      |
| ERR3003 | 模板未定义   | 输入的“APN模板ID”或“QOS模板ID”参数未定义。    | 根据实际情况，重新输入“APN模板ID”或“QOS模板ID”参数的取值，确保其存在。已存在的“APN模板ID”参数可以通过LST APNTPL命令查询。已存在的“QOS模板ID”参数可以通过LST QOSTPL命令查询。        |
| ERR3004 | 模板已存在   | 输入的“模板ID”在数据库中已存在。              | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST PSAPNQOSTPL命令查询系统中已存在的PS模板。                                               |
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的PS模板记录数超过20000条。 | 根据实际情况，如需增加PS模板，处理步骤如下：执行LST PSAPNQOSTPL命令，查询已存在的PS模板。执行RMV PSAPNQOSTPL命令，删除不必要的PS模板。执行该命令增加PS模板，确保增加的PS模板记录数在规定范围之内。 |
| ERR3045 | 条件参数丢失  | “PDP级别计费特性”和“标准计费特性”参数都没有输入。    | 根据实际情况，重新输入参数，确保“PDP级别计费特性”和“标准计费特性”参数有且只能有一个参数出现。                                                                    |
| ERR1010 | 参数冲突    | “PDP级别计费特性”和“标准计费特性”参数都输入。      | 根据实际情况，重新输入参数，确保“PDP级别计费特性”和“标准计费特性”参数有且只能有一个参数出现。                                                                    |
