# 查询Early IMS鉴权模式(LST HEIA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于从HSS的业务数据库中查询支持Early IMS鉴权模式的IMPI的鉴权信息，包括与IMPI关联的IMSI及IP地址信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询Early IMS鉴权数据。该参数的配置原则是要求输入IMPI值符合NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询Early IMS鉴权模式。IMPI：impiinfo。

```
LST HEIA: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识     | 参数说明                      |
|:---------|:--------------------------|
| IMPI     | 显示用于查询Early IMS鉴权模式的IMPI。 |
| IMSI     | 显示用于查询Early IMS鉴权模式的IMSI。 |
| IPV4ADDR | 显示IPV4地址。                 |
| IPV6ADDR | 显示IPV6地址。                 |
