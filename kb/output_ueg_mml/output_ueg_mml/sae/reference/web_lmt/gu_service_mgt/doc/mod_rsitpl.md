## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一个业务下发模板中的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个业务下发模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- “模板名”、“增强用户类别”和“是否提供下发业务”为条件可选参数，至少有一个参数出现。
- 如果参数“下发业务列表”为“OPTGPRS”时，参数“优化GPRS模板ID”是必选参数。
- 如果参数“下发业务列表”为“BAOC”、“BAIC”、“BOICEXHC”或“BOIC”时，参数“基本业务组”是必选参数。
- 如果参数“是否提供下发业务”为“TRUE”、“下发业务列表”为“CLIR”时，由于无法区分本次操作是添加还是修改操作，要求参数“基本业务组”和“CLIR限制模式”是必选参数。
- 如果参数“是否提供下发业务”为“TRUE”、“下发业务列表”取值为“ODBECT”时，参数“ODB-闭锁显式呼叫转移业务”是必选参数。
- 如果参数“是否提供下发业务”为“FALSE”，参数“优化GPRS模板ID”和“基本业务组”均不能出现。
- 如果参数“是否提供下发业务”为“FALSE”，不允许携带参数“基本业务组”、“CLIR限制模式”、“ODB-闭锁显式呼叫转移业务”，即通过参数“下发业务列表”去签约CLIR和ODBECT业务。
- 用户进行位置更新或触发其他涉及业务下发模板的流程时，系统会根据用户签约的业务下发模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 系统中所有业务下发模板增加的下发业务列表总记录数不能超过3000条。
- 参数“下发业务列表”为“BAIC”时，漫游用户的BAIC业务会生效，但在用户做被叫的流程中不下发BAIC业务。

## 使用实例

修改业务下发模板，“HLR序列号”为“1”，“模板ID”为“1”，“是否提供下发业务”为“TRUE”，“下发业务列表”为“OPTGPRS”，“优化GPRS模板ID”为“2”，命令如下：

```
MOD RSITPL: HLRSN=1, TPLID=1, PROV=TRUE, SERCODE=OPTGPRS, OPTGPRSTPLID=2;
```
