# 修改5G共享数据模板(MOD SHRDATATPL)

## 命令功能

**须知** 

该命令属于高危命令，修改5G共享数据模板会使引用此模板的用户5G共享数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对一条5G共享数据模板记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条5G共享数据模板记录：

- “HLR序列号”
- “模板ID”

## 注意事项

无。

## 使用实例

修改5G共享数据模板的数据，将“不允许接入EPC”参数修改为“TRUE”，其中“HLR序列号”为“111”，“模板ID”为“22”：

```
MOD SHRDATATPL: HLRSN=111, TPLID=22, EPCNOTALLOWED=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                  | 处理建议                                                                |
|:--------|:----------|:--------------------------------------|:--------------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 界面输入的参数不在相应的参数取值范围内。                  | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                    |
| ERR3003 | 模板未定义     | 输入的“HLR序列号”和“模板ID”对应的5G共享数据模板数据记录不存在。 | 根据实际情况，使用LST SHRDATATPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的5G共享数据模板记录。 |
| ERR3007 | HLR序列号未定义 | “HLR序列号”未定义。                          | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。               |
