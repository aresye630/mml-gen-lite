# 修改SM2公钥（MOD SM2PUBKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改已配置的SM2公钥记录。

## 注意事项

- 本命令为局点定制命令，非定制局点使用前请务必先联系华为技术支持。
- 执行本命令修改SM2公钥时，相同“HLR序列号”下的“公钥名”参数取值不能重复。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识待修改的HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无。 配置原则：无。                                                                                              |
| KEYSNO  | 密钥序列号  | 可选必选说明：必选参数 参数含义：用于标识待修改的国密SM2公钥序列号。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                                       |
| KEYNAME | 公钥名    | 可选必选说明：可选参数 参数含义：用于标识修改后的国密SM2公钥名称。 取值范围：1～60位由字母、数字或“.”、“-”等字符组成的字符串。该参数输入字母时字母转换为小写在数据库中存储。 默认值：无。 配置原则： 该参数取值一般和证书CN取值相同。同一个“HLR序列号”下该参数唯一。                                         |
| PUBKEY  | 公钥值    | 可选必选说明：可选参数 参数含义：用于标识修改后的国密SM2公钥值。 取值范围：130位的十六进制字符串。 默认值：无。 配置原则：SM2公钥长度为65个字节，第一个字节为压缩标识，固定为“04”，表示公钥未被压缩。当密钥中间存在空格或":"时，系统自动去除空格和":"，去除空格和":"后公钥有效长度为130位；包含空格和":"时，最大允许的输入长度为194位。 |

## 使用实例

修改“HLR序列号”为“1”，“密钥序列号”为“2”的国密SM2公钥记录，修改后“公钥名”为“keyname001”：

```
MOD SM2PUBKEY: HLRSN=1, KEYSNO=2, KEYNAME="keyname001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                         | 处理建议                                                                                                               |
|:--------|:--------|:-----------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
| ERR3006 | 记录已存在   | 该“HLR序列号”下已存在相同的“公钥名”。该“HLR序列号”下输入的“公钥名”包含大写字母且转换为全小写后和数据库中此条记录的“公钥名”取值完全相同。 | 执行LST SM2PUBKEY命令，查询已存在的SM2公钥： 重新输入“HLR序列号”或“公钥名”，确保同一个“HLR序列号”下的“公钥名”不重复。重新输入“公钥名”参数，确保转换为全小写后和数据中此条记录的“公钥名”取值不同。 |
| ERR3007 | 记录不存在   | 待修改的国密SM2公钥记录不在。                                                             | 执行LST SM2PUBKEY命令查询已生成的国密SM2公钥记录，根据实际情况，输入已存在的记录后重新执行本命令删除。                                                        |
