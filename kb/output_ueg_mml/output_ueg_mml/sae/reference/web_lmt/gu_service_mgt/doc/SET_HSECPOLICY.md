# 设置密码强度检查策略(SET HSECPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置SIP Digest/HTTP Digest鉴权用户开户时的密码强度检查策略。IMS-HSS在IMS用户开户时会根据该策略对操作人员输入的密码进行强度检查，对于输入的密码不符合密码强度的密码进行错误提示，提升用户数据安全性。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                    |
|:----------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SECURITY        | 密码安全策略     | 用于标识IMS-HSS在开户时是否启用密码强度检查策略对操作员输入的密码进行符合度检查。 取值范围： TRUE：启用FALSE：不启用 系统初始设置值：TRUE                                                                                                                                                                                                        |
| MINLEN          | 密码最小长度     | 仅当“密码安全策略”参数取值为“TRUE”时该参数有效。用于标识操作人员在开户时允许输入的密码最小长度。 取值范围：6～32 系统初始设置值：8                                                                                                                                                                                                                |
| COMPLEX         | 密码复杂度      | 仅当“密码安全策略”参数取值为“TRUE”时该参数有效。用于标识操作人员在开户时允许输入的密码复杂度。 取值范围： CHARTYPE: 密码包含字符集。NOID: 密码不允许包含用户名称。NOORD: 密码不允许顺序字符串。 系统初始设置值：CHARTYPE+NOID+NOORD 说明：操作人员可以设置多个密码复杂度，并用“&”连接，例如CHARTYPE-1&NOID-1&NOORD-1。参数复选框中的灰化表示不修改系统初始设置值。                                                              |
| CHARTYPE        | 密码字符集      | 仅当“密码安全策略”参数取值为“TRUE”时该参数有效。用于标识操作人员在开户时输入的密码中允许包含的字符集类型。 取值范围： UPPER：大写字母。LOWER：小写字母。NUMBER：数字。SPECIAL：特殊字符，输入的特殊字符中包含“;”、“,”时，则需要在特殊字符前添加转义字符“\”。例如参数输入“\;”，输出为“;”。 系统初始设置值：UPPER+LOWER+NUMBER 说明：操作人员可以设置多个密码复杂度，并用“&”连接，例如UPPER-1&LOWER-1&NUMBER-1&SPECIAL-1。参数复选框中的灰化表示不修改系统初始设置值。 |
| CONTSAMECHARNUM | 相同字符连续个数限制 | 仅当“密码安全策略”参数取值为“TRUE”时该参数有效。用于标识操作人员在开户时输入的密码中相同字符连续个数需要小于的数目。 取值范围：2～32 系统初始设置值：3                                                                                                                                                                                                      |

## 使用实例

设置SIP Digest/HTTP Digest鉴权用户开户时的密码强度检查策略，“密码安全策略”为“TRUE”，“密码最小长度”为“8”，“相同字符连续个数限制”为“3”，命令如下：

```
SET HSECPOLICY: SECURITY=TRUE, MINLEN=8, CONTSAMECHARNUM=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
