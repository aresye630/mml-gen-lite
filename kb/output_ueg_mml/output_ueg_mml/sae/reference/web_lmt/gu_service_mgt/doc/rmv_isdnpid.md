# 删除MSISDN与云分区数据(RMV ISDNPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除某一MSISDN号段与云分区的映射关系。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                       |
|:---------|:---------|:-------------------------------------------------------------------------------------------|
| ISDNPRFX | MSISDN号段 | 标识一条MSISDN号段与云分区映射关系数据记录的关键字段之一，用于指定需要删除哪一条MSISDN号段与云分区的映射关系数据记录，操作员可以使用LST ISDNPID命令查询获得。 |

## 使用实例

删除“MSISDN号段”为“86139”的相关数据，命令如下：

```
RMV ISDNPID: ISDNPRFX="86139";
```
