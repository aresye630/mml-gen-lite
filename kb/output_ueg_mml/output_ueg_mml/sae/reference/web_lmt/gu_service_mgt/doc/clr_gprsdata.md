# 清除GPRS数据(CLR GPRSDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该操作会清除用户GPRS数据，是否继续？

该命令用于在GPRS管理方式的调整过程中清理用户GPRS业务数据。

## 注意事项

“CLRGPRS”、“CLROPTGPRS”、“CLRPS”、“CLREPS”、“CLRINDEXEDPS”、“CLRINDEXEDEPS”六个参数至少出现一个，参数出现只能取值为“TRUE”。

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                |
|:--------------|:----------------|:--------------------------------------------------------------------|
| IMSI          | IMSI            | 用于标识用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                        |
| CLRGPRS       | 是否清除GPRS业务数据    | 用于标识是否清除此用户的GPRS业务数据。 取值：TRUE，表示清除GPRS业务数据。若不取值，表示不清除。 默认值：无。       |
| CLROPTGPRS    | 是否清除OPTGPRS业务数据 | 用于标识是否清除此用户的OPTGPRS业务数据。 取值：TRUE，表示清除OPTGPRS业务数据。若不取值，表示不清除。 默认值：无。 |
| CLRPS         | 是否清除PS业务数据      | 用于标识是否清除此用户的PS业务数据。 取值：TRUE，表示清除PS业务数据。若不取值，表示不清除。 默认值：无。           |
| CLREPS        | 是否清除EPS业务数据     | 用于标识是否清除此用户的EPS业务数据。 取值：TRUE，表示清除EPS业务数据。若不取值，表示不清除。 默认值：无。         |
| CLRINDEXEDPS  | 是否清除索引化存储的PS数据  | 用于标识是否清除已索引化存储的PS域用户业务数据。 取值范围：TRUE，表示清除；若不取值，表示不清除。 默认值：无。         |
| CLRINDEXEDEPS | 是否清除索引化存储的EPS数据 | 用于标识是否清除已索引化存储的EPS域用户业务数据。 取值：TRUE，表示清除；若不取值，表示不清除。 默认值：无。          |

## 使用实例

1. 清除用户IMSI号码为“460011390290001”的GPRS业务数据：

   ```
   CLR GPRSDATA: IMSI="460011390290001", CLRGPRS=TRUE;
   ```
2. 清除用户IMSI号码为“460011390290001”的GPRS业务数据、OPTGPRS业务数据、PS业务数据、EPS业务数据：

   ```
   CLR GPRSDATA: IMSI="460011390290001", CLRGPRS=TRUE, CLROPTGPRS=TRUE, CLRPS=TRUE, CLREPS=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                              | 处理建议                            |
|:--------|:--------|:----------------------------------------------------------------------------------|:--------------------------------|
| ERR3001 | 用户未开户   | “IMSI”用户不存在。                                                                      | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。 |
| ERR1009 | 参数丢失    | “CLRGPRS”、“CLROPTGPRS”、“CLRPS”、“CLREPS”、“CLRINDEXEDPS”、“CLRINDEXEDEPS”六个参数至少出现一个。 | 根据实际情况，增加输入参数，确保命令参数符合要求。       |
