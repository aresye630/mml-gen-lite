# 增加或删除（Vo）LTE自动开户IMEI前缀限制(MOD LTEAUTOFORBIDIMEIPRE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响用户自动开户业务，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加或删除需要进行自动开户控制的用户IMEI号码前缀信息。

当系统需要对自动开户的用户按IMEI号码前缀进行控制时配置。

- 使用本命令增加了IMEI号码前缀后，会按照对应参数的取值规则进行控制。增加该控制的优先级高于全局参数（通过**SET MAPCONF**命令的参数“是否启用LTE/VoLTE自动开户特性”和**SET MAPSERV**命令的参数“SWx接口是否支持LTE用户自动开通VoWiFi功能”设置）的设置。
- 使用本命令删除了IMEI号码前缀后，需要查询与该IMEI号码用户的IMSI号码前缀是否匹配到IMSI限制自动开户：
  - 是，按照**MOD LTEAUTOFORBIDIMSIPRE**命令中“是否启用LTE/VoLTE自动开户特性”取值规则进行控制。
  - 否，按照全局参数的设置（通过**SET MAPCONF**命令的参数“是否启用LTE/VoLTE自动开户特性”和**SET MAPSERV**命令的参数“SWx接口是否支持LTE用户自动开通VoWiFi功能”设置）进行自动开户。

## 注意事项

- 系统中增加的IMEI号码前缀记录数不能超过10000条。
- 当IMSI号码前缀或者IMEI号码前缀中有一个匹配到限制自动开户（即**MOD LTEAUTOFORBIDIMSIPRE**命令中“是否启用LTE/VoLTE自动开户特性”取值为“FALSE”或**MOD LTEAUTOFORBIDIMEIPRE**命令中“是否启用限制LTE/VoLTE自动开户特性”取值为“FORBID”）时，则限制自动开户功能。

## 参数说明

| 参数标识                   | 参数名称                | 参数说明                                                                                                                         |
|:-----------------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| OPTYPE                 | 操作类型                | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加前缀。DELETE：删除前缀。 默认值：无。                                                                         |
| IMEIPREFIX             | IMEI前缀              | 用于标识需要进行自动开户控制的用户IMEI号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                     |
| FORBID_LTEAUTOPROV     | 是否限制LTE/VoLTE自动开户特性 | 仅当本命令的参数“操作类型”为“ADD”时该参数有效，用于标识UDM是否限制LTE自动开户和VoLTE自动开户特性。 取值范围：NOT_CTRL：不控制LTE/VoLTE自动开户功能。FORBID：限制LTE/VoLTE自动开户功能。 默认值：无。 |
| FORBID_VOWIFI_AUTOPROV | 是否限制自动开通VoWiFi      | 仅当本命令的参数“操作类型”为“ADD”时该参数有效，用于标识UDM是否限制自动开通VoWiFi自动开户业务。 取值范围：NOT_CTRL：不控制VoWiFi自动开户功能。FORBID：限制VoWiFi自动开户功能。 默认值：无。          |

## 使用实例

1. 对于IMEI号码前缀为“47000”的用户，限制LTE/VoLTE自动开户功能，且限制用户自动开通VoWiFi自动开户业务。

   ```
   MOD LTEAUTOFORBIDIMEIPRE: OPTYPE=ADD, IMEIPREFIX="47000", FORBID_LTEAUTOPROV=FORBID, FORBID_VOWIFI_AUTOPROV=FORBID;
   ```
2. 取消对IMEI号码前缀为“47001”的用户进行的自动开户控制，命令如下：

   ```
   MOD LTEAUTOFORBIDIMEIPRE: OPTYPE=DELETE, IMEIPREFIX="47001";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:-----------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“操作类型”的取值不是“ADD”或“DELETE”。参数“IMEI前缀”的取值不是1～15位十进制数字组成的字符串。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                              |
| ERR1111 | 超过最大限制  | 参数“操作类型”取值为“ADD”时，所增加的“IMEI前缀”数据记录超过了10000条。                           | 根据实际情况，如需增加IMEI号码前缀信息，处理步骤如下：执行LST LTEAUTOFORBIDIMEIPRE命令，查询已配置的IMEI号码前缀信息。执行该命令删除不必要的IMEI号码前缀信息。执行该命令增加IMEI号码前缀信息，确保增加的IMEI号码前缀信息记录数在规定范围之内。 |
| ERR3006 | 记录已存在   | 参数“操作类型”取值为“ADD”时，所输入的“IMEI前缀”数据记录已存在。                                 | 请按照以下步骤操作：执行LST LTEAUTOFORBIDIMEIPRE命令，查询已配置的IMEI号码前缀信息。根据查询结果重新输入“IMEI前缀”，确保输入的“IMEI前缀”不在查询结果中。                                              |
| ERR3007 | 记录不存在   | 参数“操作类型”取值为“DELETE”时，所输入的“IMEI前缀”数据记录不存在。                              | 请按照以下步骤操作：执行LST LTEAUTOFORBIDIMEIPRE命令，查询已配置的IMEI号码前缀信息。根据查询结果重新输入“IMEI前缀”，确保输入的“IMEI前缀”包含在查询结果中。                                             |
