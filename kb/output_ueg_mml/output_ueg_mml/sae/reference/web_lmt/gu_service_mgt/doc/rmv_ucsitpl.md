# 删除U-CSI模板(RMV UCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条U-CSI（USSD CAMEL Subscription Information）模板数据记录。

## 注意事项

当执行**RMV UCSITPL**命令删除U-CSI模板时，如果为以下几种情况，系统会提示“ERR3005:模板已经被使用”的错误信息，该U-CSI模板不能被删除。

- 用户已签约该模板。
- 用户已执行**MOD CSIPREFIX**命令将MSISDN前缀与U-CSI模板相关联。
- 用户已执行**SET CSIREPTPL**命令使CSI替代模板引用了该U-CSI模板。

如果确实需要删除U-CSI模板，请参见错误码ERR3005:模板已经被使用的处理建议。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一条U-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条U-CSI模板数据记录，操作员可以使用LST HLRSN命令查询获得。   |
| TPLID  | 模板ID   | 标识一条U-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条U-CSI模板数据记录，操作员可以使用LST UCSITPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”的HLR上的U-CSI模板数据记录。其中，“模板ID”为“3”：

```
RMV UCSITPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                 | 处理建议                                                                                                                                                                                                                                   |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的U-CSI模板数据记录不存在。                                                                    | 使用LST UCSITPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的U-CSI模板数据记录。                                                                                                                                                                             |
| ERR3005 | 模板已经被使用 | 可能原因为以下几种：用户已签约该模板。用户已执行MOD CSIPREFIX命令将MSISDN前缀与U-CSI模板相关联。用户已执行SET CSIREPTPL命令使CSI替代模板引用了该U-CSI模板。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，必须先执行以下操作，然后才能执行RMV UCSITPL命令删除。执行MOD CAMEL、MOD UCSI或MOD NTUCSI命令给用户去签约相关的U-CSI模板。执行MOD CAMEL、MOD UCSI或MOD NTUCSI命令给用户去签约相关的U-CSI模板，同时执行MOD CSIPREFIX命令删除MSISDN前缀与U-CSI模板的关联关系。执行SET CSIREPTPL命令，删除CSI替代模板。 |
