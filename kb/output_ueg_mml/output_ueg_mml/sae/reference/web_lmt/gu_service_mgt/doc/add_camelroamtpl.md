## 命令功能

该命令用于增加CAMEL漫游模板，通过该命令，可以把一个VLRN号码前缀及其对应的名称添加到CAMEL漫游模板里，使该VLR与UDM具有CAMEL漫游协议。

在HLR中CAMEL漫游协议用于用户在非归属网络漫游，当用户发起位置更新时控制O-CSI，在用户做被叫的SRI流程中控制T-CSI的下发。

- 控制O-CSI下发

  通过该命令将**VLR号码前缀**添加到CAMEL漫游协议模板中，就认为该VLR与HLR有漫游协议。然后通过**ADD OCSITPL**命令设置CAMEL业务的支持能力，包括与某VLR是否有CAMEL漫游协议。当用户漫游出归属网络并向网络发起位置更新请求，用户的归属HLR要根据此VLR号码前缀来判断是否限制对O-CSI数据的下发。
- 控制T-CSI下发

  通过该命令将**VLR号码**添加到CAMEL漫游协议模板中，就认为该VLR与HLR有漫游协议。然后通过**ADD TCSITPL**命令设置CAMEL业务的支持能力，包括与某VLR是否有CAMEL漫游协议。当用户在非归属网络漫游做被叫时用户的归属HLR要根据此VLR号码判断是否限制对T-CSI数据的下发。

  - 当用户在网时不下发T-CSI数据。
  - 当用户不在网时，当**SET MAPCONF**命令设置的“不在网时是否抑制TCSI功能”参数为“TRUE”（抑制），则不下发T-CSI数据；当**SET MAPCONF**命令设置的“不在网时是否抑制TCSI功能”参数为“FALSE”（不抑制），则下发T-CSI数据。

## 注意事项

所有“HLR序列号”中增加的CAMEL漫游模板总记录数不能超过2000条。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                   |
|:------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号      | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                           |
| TPLID       | 模板ID        | 用于标识一个CAMEL漫游模板在系统中的序号。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。                                                                                                            |
| TPLNAME     | 模板名         | 用于标识CAMEL漫游模板在系统中的名称。不同模板ID的模板名称允许相同。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                 |
| VLRSGSNNP   | VLR号码前缀     | 用于标识需要签约CAMEL漫游协议的VLR的号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：当CAMEL漫游模板用作T-CSI限制功能，且SET MAPSERV中的参数“TCSITPL里CAMELROAMTPL的使用场景”被设置为“TCSI_SUPPRESS”时，需输入整个VLR号码，而不是号码前缀。 |
| CAMEL       | CAMEL业务处理能力 | 用于指示gsmSCF所要求的CAMEL业务阶段。CAMEL的4个阶段请参见CAMEL业务。 取值范围：PHASE1PHASE2PHASE3PHASE4 默认值：无。                                                                                     |
| VLRSGSNNAME | VLR名称       | 用于标识需要签约CAMEL漫游协议的VLR在系统中的名称。不同模板ID的VLR名称允许相同。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                                                        |

## 使用实例

为指定VLR增加CAMEL漫游模板，设置参数“HLR序列号”为“1”，“模板ID”为“3”，“模板名称”为“CAMELROAMTPL”，“VLR号码前缀”为“12345678912”，“VLR名称”为“VLR1”，“CAMEL业务处理能力”为“PHASE1”：

```
ADD CAMELROAMTPL: HLRSN=1, TPLID=3, TPLNAME="CAMELROAMTPL", VLRSGSNNP="12345678912", VLRSGSNNAME="VLR1", CAMEL=PHASE1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                       | 处理建议                                                                                                                                             |
|:--------|:--------|:-------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“VLR号码前缀”的取值不是1～15位十进制数字组成的字符串。          | 根据实际情况，重新输入参数“VLR号码前缀”的取值，确保其取值符合要求。                                                                                                             |
| ERR3004 | 模板已存在   | 参数“模板ID”在数据库中已存在。                          | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST CAMELROAMTPL命令查询系统中已存在的CAMEL漫游模板。                                                                    |
| ERR3007 | 记录不存在   | 参数“HLR序列号”的取值未预先定义，对应序列号的HLR不能添加CAMEL漫游模板。 | 使用LST HLRSN命令查询已定义的HLR序列号，根据查询结果中存在的HLR序列号，重新输入“HLR序列号”参数值。                                                                                      |
| ERR3047 | 超过最大限制  | 所有“HLR序列号”中增加的CAMEL漫游模板总记录数超过2000条。        | 根据实际情况，如需增加CAMEL漫游模板，处理步骤如下：执行LST CAMELROAMTPL命令，查询已存在的CAMEL漫游模板。执行RMV CAMELROAMTPL命令，删除不必要的CAMEL漫游模板。执行该命令增加CAMEL漫游模板，确保增加的CAMEL漫游模板记录数在规定范围之内。 |
