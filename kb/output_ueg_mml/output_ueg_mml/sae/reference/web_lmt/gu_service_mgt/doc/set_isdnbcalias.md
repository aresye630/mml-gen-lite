## 命令功能

该命令用于实现：

- 通过本命令设置用户自定义承载能力，当用户签约了SENDROUTINGINFO消息中携带承载对应的基础业务且在SENDROUTINGINFO消息中携带的承载业务和本命令中设置的承载业务一致时，UDM可以根据本命令设置的自定义承载能力替换SENDROUTINGINFO请求中携带的承载能力。
- 针对移动用户呼叫PSTN用户的场景，SENDROUTINGINFO请求中携带TS11，但被叫用户未签约TS11，且被叫用户签约的“缺省呼叫类型”为非TS11的场景，当被叫用户签约“缺省呼叫类型”的业务码与本命令中的为用户签约的业务码一致时，系统根据本命令签约的用户业务码和承载能力替换SENDROUTINGINFO请求中携带的用户业务码和承载能力。

## 注意事项

- “IMSI”、“ISDN”、“IMSI文件名”和“MSISDN文件名”是条件可选参数，任何一个参数出现即可。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。
- 使用该命令为用户设置自定义承载能力时，会导致内存增大。
- 对于通过**SET MULTISDN**命令开户的多MSISDN用户，该命令仅支持主号码签约，不支持辅号码签约自定义承载能力。
- 未签约承载能力的用户可以通过本命令签约自定义承载能力。

## 使用实例

1. 运营商为IMSI号码是“460000009012345”的用户添加“数据业务码”为“BS20”，“承载能力别名”为“BC20”的自定义承载能力：

   ```
   SET ISDNBCALIAS: IMSI="460000009012345", PROV=TRUE, DSCODE=BS20, BCALIAS="BC20";
   ```
2. 运营商为IMSI号码是“460000009123455”、“460000009123466”和“460000009123477”的用户添加“数据业务码”为“BS43”，“承载能力别名”为“BC43”的自定义承载能力。

   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      ```
      460000009123455
      460000009123466
      460000009123477
      ```
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行本命令提供BS43业务。

      ```
      SET ISDNBCALIAS: IMSIFILE="IMSIBAT", PROV=TRUE, DSCODE=BS43, BCALIAS="BC43";
      ```

## 参考信息

基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
