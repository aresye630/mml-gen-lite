## 命令功能

该命令用于在HSS的业务数据库中增加一个游牧地址模板。

游牧模板由一个或多个游牧地址组成，操作员可以在使用**ADD HNATPL**增加游牧模板后，执行**SET HNATPLID**命令，设置此用户与游牧模板的对应关系，以对用户的游牧范围进行控制：

- 当IMS固网用户进入游牧地址允许的区域时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配成功，游牧地址信息中的NASS游牧地址类型是允许游牧，IMS系统将允许用户注册。
- 当IMS固网用户进入游牧地址限制的区域时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配成功，游牧地址信息中的NASS游牧地址类型是限制游牧，IMS系统将限制用户注册。
- 当IMS固网用户进入的区域在游牧地址信息中不存在时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配失败，根据游牧模板中的缺省游牧限制策略决定是否允许用户游牧，PERMISSION表示IMS系统将允许用户注册，RESTRICTION表示IMS系统将限制用户注册。

## 注意事项

- “NASS游牧模板ID”参数、“NASS游牧模板名称”参数和“NASS游牧扩展模板ID”参数至少存在一个。
- 每个游牧模板可以包含1–3000个游牧地址，且系统允许的游牧地址数量最大为40000个，请操作员在执行该命令前妥善规划，仔细确认任务的可行性。
- 本命令中“缺省漫游限制策略”参数设为“RESTRICTION(Restriction)”时表示限制游牧。如果要放开用户的游牧权限，使用**MOD HNATPL**命令将“缺省漫游限制策略”参数修改为“PERMISSION(Permission)”。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID       | NASS游牧模板ID   | 用于定义一个新的游牧模板索引，系统可以通过该索引找到新增的游牧模板。该参数的配置原则是：新增的游牧模板ID必须与现存的不同，现有游牧模板ID可以使用LST HTPLINF命令获得。 取值范围：0～65535 说明： 当用户不输入模板ID时，系统自动生成的模板ID范围为：65535～67108863。 默认值：无。 说明：可选参数。该参数为255表示无效值。“NASS游牧模板ID”和“NASS游牧扩展模板ID”，只允许输入其中一个参数。                                                                                                                                                                                                                                                              |
| TPLNAME     | NASS游牧模板名称   | 用于定义新增游牧模板的名称，系统可以通过模板名称找到新增的游牧模板。该参数的配置原则是：新增的游牧模板名称必须与现存的不同，现有游牧模板名称可以使用LST HTPLINF命令获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                     |
| DEFAULTRULE | 缺省游牧限制策略     | 用于定义新增游牧模板的缺省限制策略，当用户携带的接入位置信息与签约的游牧地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：RESTRICTION。 说明：可选参数。                                                                                                                                                                                                                                                                                                            |
| MATCHTYPE   | 匹配类型         | 用于定义新增游牧模板的匹配类型。 取值范围： FRONT(Front)：表示前向匹配。前向匹配原则表示游牧地址只要前缀相同的都匹配。如果签约的游牧地址模板信息为HSS，则前缀为HSS的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.com”。BACK(Back)：表示后向匹配。后向匹配原则表示游牧地址后缀相同的都匹配。如果签约的游牧地址模板信息为huawei.com，则后缀为huawei.com的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.huawei.com”。IPSEGMENT(IPsegment)：表示IP地址段匹配。IP地址段匹配原则表示在该游牧模板内匹配所有位于“IP地址段起始地址”至“IP地址段结束地址”范围内的游牧地址IP。CONTAIN(Contain)：表示包含匹配。即游牧地址只要包含该地址的都匹配。如果签约的游牧地址模板信息为HSS，则包含HSS的游牧地址都能匹配成功，例如携带的游牧地址为“huawei.HSS.com”、“HSS.com”、“huawei.HSS”。 默认值：无。 说明：必选参数。 |
| nan         | NASS游牧地址     | 用于定义在游牧模板中增加的游牧地址。一个游牧模板中至少应存在一条游牧地址，因此在添加游牧模板时必须在其中同时添加一条游牧地址。 取值范围：长度不超过127的字符串 默认值：无。 说明：当“匹配类型”为“FRONT”、“BACK”或“CONTAIN”时，该参数为必选参数。                                                                                                                                                                                                                                                                                                                                                  |
| BEGINIP     | IP地址段起始地址    | 用于定义在游牧模板中增加的IP地址段的起始地址。 取值范围：IPV4地址 默认值：无。 说明：当“匹配类型”为“IPSEGMENT”时，该参数为必选参数。                                                                                                                                                                                                                                                                                                                                                                                                            |
| ENDIP       | IP地址段结束地址    | 用于定义在游牧模板中增加的IP地址段的结束地址。 取值范围：IPV4地址 默认值：无。 说明：当“匹配类型”为“IPSEGMENT”时，该参数为必选参数。该参数IP必须大于或等于“IP地址段起始地址”的IP。                                                                                                                                                                                                                                                                                                                                                                                 |
| NATYPE      | NASS游牧地址类型   | 用于指定新增游牧地址的类型。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                      |
| COMMENT     | 模板注释说明       | 用于指定新增游牧模板的注释。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| EXTTPLID    | NASS游牧扩展模板ID | 用于定义一个新的游牧模板索引，该参数用于输入系统自动生成的模板ID。 取值范围：65536～67108863 默认值：无 说明：可选参数。“NASS游牧模板ID”和“NASS游牧扩展模板ID”，只允许输入其中一个参数。                                                                                                                                                                                                                                                                                                                                                                            |

## 使用实例

1. 增加游牧模板，“NASS游牧模板ID”为“10”，“NASS游牧模板名称”为“NASS Nomadism Template”，“匹配类型”为“FRONT”，“缺省游牧限制策略”为“PERMISSION”，“NASS游牧地址”为“china.huawei.com”，“NASS游牧地址类型”为“PERMISSION”，“模板注释说明”为“NASS Nomadism Template For ADD HIMPUTPL”：

   ```
   ADD HNATPL: TPLID=10, TPLNAME="NASS Nomadism Template", MATCHTYPE=FRONT, DEFAULTRULE=PERMISSION, NA="china.huawei.com", NATYPE=PERMISSION, COMMENT="NASS Nomadism Template For ADD HIMPUTPL";
   ```
2. 增加游牧模板，“NASS游牧模板ID”为“11”，“NASS游牧模板名称”为“NASS TPL”，“匹配类型”为“BACK”，“缺省游牧限制策略”为“RESTRICTION”，“NASS游牧地址”为“hss.huawei.com”，“NASS游牧地址类型”为“PERMISSION”，“模板注释说明”为“NASS TPL FOR SET HNATPLID”：

   ```
   ADD HNATPL: TPLID=11, TPLNAME="NASS TPL", MATCHTYPE=BACK, DEFAULTRULE=RESTRICTION, NA="hss.huawei.com", NATYPE=PERMISSION, COMMENT="NASS TPL FOR SET HNATPLID";
   ```
3. 增加游牧模板，“NASS游牧模板名称”为“07550011”，“匹配类型”为“IPSEGMENT”，“缺省游牧限制策略”为“RESTRICTION”，“IP地址段起始地址”为“10.2.2.10”，“IP地址段结束地址”为“10.2.2.50”，“NASS游牧地址类型”为“PERMISSION”，“模板注释说明”为“IPSEGMENT NASS TPL”：

   ```
   ADD HNATPL: TPLNAME="07550011", MATCHTYPE=IPSEGMENT, DEFAULTRULE=RESTRICTION, BEGINIP="10.2.2.10", ENDIP="10.2.2.50", NATYPE=PERMISSION, COMMENT="IPSEGMENT NASS TPL";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                              | 处理建议                                  |
|----------:|:--------|:----------------------------------|:--------------------------------------|
| 900001009 | 参数冲突    | 同时输入了“NASS游牧模板ID”和“NASS游牧扩展模板ID”。 | 只输入“NASS游牧模板ID”或“NASS游牧扩展模板ID”，执行该命令。 |
