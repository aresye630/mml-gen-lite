# 查询ISDNPRE/GT号码模板(LST ISDNPREGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询ISDNPRE/GT号码模板。

- 若需要查询某个HLR序列号下全部ISDNPRE/GT号码模板的概要配置信息，请只输入“HLR序列号”。
- 若需要查询某个HLR序列号下某个ISDNPRE/GT号码模板的详细配置信息，请输入“HLR序列号”和“模板ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                 |
|:-------|:-------|:-----------------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询ISDNPRE/GT号码模板数据。                 |
| TPLID  | 模板ID   | 用于标识系统需要按照哪个模板ID来查询ISDNPRE/GT号码模板数据；若不输入，则表示所有的模板ID。 |

## 使用实例

1. 查询“HLR序列号”为“1”的所有ISDNPRE/GT号码模板信息：

   ```
   LST ISDNPREGT: HLRSN=1;
   ```
2. 查询“HLR序列号”为“1”的HLR上的ISDNPRE/GT号码模板数据记录。其中，“模板ID”为“65534”：

   ```
   LST ISDNPREGT: HLRSN=1, TPLID=65534;
   ```
