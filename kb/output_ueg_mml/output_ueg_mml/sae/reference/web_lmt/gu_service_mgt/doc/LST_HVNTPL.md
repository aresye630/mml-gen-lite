# 查询拜访网络模板(LST HVNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询一条由拜访网络模板ID指定的拜访网络模板的配置信息。

## 注意事项

**ADD HVNTPL**命令里的拜访网络地址信息由**LST HVNTPLADDR**命令查询。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                      |
|:-------|:---------|:--------------------------------------------------------------------------|
| HLRSN  | HLR序列号   | 用于指示系统需要按照哪个HLR序列号来查询拜访网络模板数据。如果不输入，则表示查询“HLR序列号”为“0”的所有拜访网络模板数据。 说明：可选参数 |
| TPLID  | 拜访网络模板ID | 用于指示系统需要按照哪个模板ID来查询拜访网络模板数据，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。            |

## 使用实例

查询拜访网络模板，“拜访网络模板ID”为“10”：

```
LST HVNTPL: TPLID=10;
```


## 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                                                                                                                                           |
|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLNAME     | 用于显示拜访网络模板的名称。                                                                                                                                                                                                                                  |
| MATCHTYPE   | 用于显示拜访网络模板的匹配类型。 取值范围：“0”：表示前向匹配。前向匹配原则表示拜访网络地址只要前缀相同的都匹配。如果签约的拜访网络地址模板信息为HSS，则前缀为HSS的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.com”。“1”：表示后向匹配。后向匹配原则表示拜访网络地址后缀相同的都匹配。如果签约的拜访网络地址模板信息为huawei.com，则后缀为huawei.com的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.huawei.com”。 |
| DEFAULTRULE | 用于显示拜访网络模板的缺省限制策略，当用户携带的接入位置信息与签约的拜访网络地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： “0”：表示IMS系统将限制用户注册。“1”：表示IMS系统将允许用户注册。                                                                                                                                   |
| COMMENT     | 用于显示拜访网络模板的注释。                                                                                                                                                                                                                                  |
