# 增加能力集信息模板(ADD HCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在业务数据库中增加一个能力集模板。

## 注意事项

- MCAP参数、OCAP参数、SCSCFLIST参数必须至少存在一个，可同时存在。
- MCAP和OCAP的合法取值分为以下两种情况：

  - 只有一个无效ID值，0为无效ID值。
  - 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。

  当MCAP参数和OCAP参数都存在，且取值都为第二种情况时，两个参数的集合之间不允许有相同的整数。
- 系统中增加的共享能力集信息模板记录数不能超过5000条。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                        |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号  | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                                                    |
| TPLID     | 能力集模板ID | 用于新增一个能力集模板ID。 取值范围： 0~1024 默认值： 无 说明： 同一个“HLR序列号”，能力集模板ID唯一，已有模板ID可以使用LST HTPLINF命令查询获得。参数取值为“255”时为无效值。该参数取值大于“254”时只支持“IMS用户模板管理”（IMSTPL）命令组引用该模板。                       |
| TPLNAME   | 能力集模板名称 | 用于新增一个能力集模板名称。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无                                                                                                            |
| MCAP      | 必选能力集   | 用于新增一个能力集模板中必选能力集，配置原则是能力之间不能重复，不同的能力以“&”符连接。只有一个无效ID值，0为无效ID值。 取值范围： 长度不超过352的字符串 默认值： 无                                                                                   |
| OCAP      | 可选能力集   | 用于新增一个能力集模板的可选能力集，配置原则是能力之间不能重复，不同的能力以“&”符连接。只有一个无效ID值，0为无效ID值。 取值范围： 长度不超过352的字符串 默认值： 无                                                                                   |
| SCSCFLIST | SCSCF列表 | 用于新增一个能力集模板的SCSCF的名称集合，可以由1到5个SCSCF名称组成，每个SCSCF名称不超过127个字符，不同的SCSCF的名称以“&”符连接（例如："sip:scscf1.huawei.com"&"sip:scscf2.huawei.com"，在字符"前需要添加转义字符\）。 取值范围： 长度不超过649的字符串 默认值： 无 |
| COMMENT   | 模板注释说明  | 用于新增一个能力集模板的注释。 取值范围： 长度不超过512的字符串 默认值： 无                                                                                                                                   |

## 使用实例

增加能力集信息模板。能力集模板ID：10，能力集模板名称：Capability template，必选能力集：2，可选能力集：7&32，SCSCF列表：**"sip:scscf1.huawei.com"&"sip:scscf2.huawei.com"**，模板注释说明：Capability Template For ADD HTPLSUB。

```
ADD HCAPTPL: TPLID=10, TPLNAME="Capability template", MCAP="2", OCAP="7&32", SCSCFLIST="\"sip:scscf1.huawei.com\"&\"sip:scscf2.huawei.com\"", COMMENT="Capability Template For ADD HTPLSUB";
```
