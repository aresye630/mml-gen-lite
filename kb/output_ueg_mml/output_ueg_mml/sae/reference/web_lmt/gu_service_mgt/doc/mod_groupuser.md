# 修改GROUPSIM用户组成员(MOD GROUPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来增加、删除GROUPSIM用户组成员，或修改GROUPSIM用户组成员的数据。通过参数“组IMSI号码”或“组MSISDN号码”来唯一标识一个GROUPSIM用户组。

在混合组网场景，执行该命令会触发用户迁移到新的分区。用户数据仅支持迁移，不支持5G相关业务。

- 对于增强GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“TRUE”），执行该命令时可以将组内所有成员一同迁移到新的分区。对于普通的GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“FALSE”），执行该命令时无法将组内所有成员一同迁移到新的分区，会造成普通GROUPSIM的主卡、辅卡不在同一个归属分区的场景。各业务流程已实现成员跨分区业务无影响。
- 迁移过程中License统计结果不更新，依赖License周期性校验校正。

## 注意事项

在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。

- 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
- 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                                                                                                                   |
|:-----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GIMSI      | 组IMSI号码      | GROUPSIM用户组的IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。                                                                                                                                                                                       |
| GISDN      | 组MSISDN号码    | GROUPSIM用户组的MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。                                                                                                                                                                                     |
| PROV       | 操作类型         | 对GROUPSIM用户组的成员号码的操作类型。 取值范围： ADD：增加组成员RMV：删除组成员MOD：修改组成员 说明：必选参数。取值为“MOD”时，若参数“成员顺序”对应的号码已存在，则不允许修改。如成员顺序为8的号码“460000009012388"，要改变成员顺序为1，但是已存在成员顺序为1的号码”460000009012381"，则不允许修改。                                                     |
| MEMBERISDN | 成员号码         | GROUPSIM用户组的成员号码。 取值范围：E.164格式的编码，1～15位的十进制数字。 说明：必选参数                                                                                                                                                                                 |
| ORDER      | 成员顺序         | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。GROUPSIM用户组成员号码的顺序。 取值范围：0～8 默认值：无。 说明：0代表该成员号码在GROUPSIM用户组中为非激活用户，1～8代表激活用户的顺序。                                                                                                                     |
| MBRSYNC    | 成员是否允许同步     | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识成员用户是否允许补充业务同步。 取值范围： Allowed：允许同步。Denied：拒绝同步。 默认值：无。 说明：可通过LST SUB命令查询。                                                                                                                        |
| DENYUSSD   | 成员用户USSD操作权限 | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识成员用户USSD操作权限。 取值范围： Denied：成员用户允许通过USSD请求操作自己的GROUPSIM业务。Not_Denied： 成员用户允许通过USSD请求操作该用户所在群组的所有成员用户的GROUPSIM业务。Not_Support：成员用户不允许通过USSD请求操作该用户所在群组的所有成员用户的GROUPSIM业务。 默认值：无。 说明：可通过LST SUB命令查询。 |
| MBRDC      | 成员用户直接呼叫权限   | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识直接拨打GROUPSIM组的成员号码时，HSS/HLR是否禁止此呼叫。 取值范围： Denied：禁止。该成员用户无法收到主叫用户的呼叫。Not_Denied：不禁止。该成员用户能正常收到主叫用户的呼叫。 默认值：无。 说明：当“操作类型”参数为“ADD”时，执行该命令并且不输入该参数时，系统会设置初始值Not_Denied。                             |
| MBRSMS     | 成员用户SMS接收权限  | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识直接给GROUPSIM组的成员号码发送短消息时，HSS/HLR是否禁止此短消息的发送。 取值范围： Denied：禁止。该成员用户无法收到用户发送的短消息。Not_Denied：不禁止。该成员用户能正常收到用户发送的短消息。 默认值：无。 说明：当“操作类型”参数为“ADD”时，执行该命令并且不输入该参数时，系统会设置初始值Not_Denied。                   |

## 使用实例

1. 为GIMSI是“460000009123456”的GROUPSIM用户组增加成员号码，操作类型为ADD，MEMBERISDN为"460000009012388"。

   ```
   MOD GROUPUSER: GIMSI="460000009123456", PROV=ADD, MEMBERISDN="460000009012388";
   ```
2. 为GIMSI是“460000009123456”的GROUPSIM用户组修改成员号码"460000009012388"的顺序，操作类型为MOD，ORDER为1。

   ```
   MOD GROUPUSER: GIMSI="460000009123456", PROV=MOD, MEMBERISDN="460000009012388", ORDER=1;
   ```
3. 为GIMSI是“460000009123456”的GROUPSIM用户组删除成员号码"460000009012388"，操作类型为RMV。

   ```
   MOD GROUPUSER: GIMSI="460000009123456", PROV=RMV, MEMBERISDN="460000009012388";
   ```
