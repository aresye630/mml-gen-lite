# 删除CAMEL漫游模板(RMV CAMELROAMTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用来删除一个CAMEL漫游模板。在该命令中，系统通过以下关键参数的组合来唯一标识一个CAMEL漫游模板：

- “HLR序列号”
- “模板ID”

## 注意事项

如果已经通过**ADD OCSITPL**或**ADD TCSITPL**命令关联该模板，当执行该命令删除CAMEL漫游协议模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该CAMEL漫游协议模板不能被删除。如果要删除该CAMEL漫游协议模板，必须先执行**MOC OCSITPL**或**MOD TCSITPL**命令去掉O-CSI模板或T-CSI模板与CAMEL漫游协议模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识待删除的CAMEL模板所在的HLR序列号。                     |
| TPLID  | 模板ID   | 用于标识待删除的CAMEL漫游模板在系统中的序号。 取值范围：0～65534 默认值：无。 |

## 使用实例

删除一个“HLR序列号”为“1”，“模板ID”为“1”的CAMEL漫游模板。

```
RMV CAMELROAMTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                          | 处理建议                                                                                                                  |
|:--------|:--------|:--------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。                                | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST CAMELROAMTPL命令查询。                                     |
| ERR3005 | 模板已经被使用 | 参数“模板ID”对应的模板已通过CAMEL漫游模板已经通过ADD OCSITPL或ADD TCSITPL等命令给用户签约。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOC OCSITPL或MOD TCSITPL命令去掉O-CSI模板或T-CSI模板与CAMEL漫游协议模板的关联关系，然后才能执行RMV CAMELROAMTPL命令删除。 |
