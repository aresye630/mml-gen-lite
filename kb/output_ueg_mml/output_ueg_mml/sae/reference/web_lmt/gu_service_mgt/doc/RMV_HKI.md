# 删除KI(RMV HKI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一个鉴权数据KI的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 标识一条KI数据记录的关键参数，用于指定需要删除哪一条KI数据记录，操作员可以使用LST HKI操作查询获得，要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

删除KI。IMPI：impiinfo。

```
RMV HKI: IMPI="impiinfo";
```
