# 修改NIR业务(MOD NIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来签约或去签约NIR业务。

## 注意事项

- IMSI和ISDN是条件可选参数，任何一个参数出现即可，但两个参数不能同时出现。
- 当PROV为TRUE时，NIR参数才会出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                |
|:------------|:----------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                     |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                   |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | IMSIFILE文件名称，由16个以内的数字或字母组成。IMSIFILE的内容是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。          |
| ISDNFILE    | MSISDN文件名 | ISDNFILE文件名称，由16个以内的数字或字母组成。ISDNFILE的内容是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。      |
| PROV        | 是否提供NIR业务 | 用于表示是否提供NIR业务。 TRUE：提供FALSE：不提供                                                     |
| NIR         | NIR索引     | 仅当本命令中的“是否提供NIR业务”参数为“TRUE”时该参数有效。NIR索引。 值域0～999。                                   |

## 使用实例

1. 为IMSI号码是460000009123456的用户提供NIR业务，NIR索引为22。

   MOD NIR: IMSI="460000009123456", PROV=TRUE, NIR=22;
2. 为IMSI号码是460000009123456的用户撤销NIR业务。

   MOD NIR: IMSI="460000009123456", PROV=FALSE;
