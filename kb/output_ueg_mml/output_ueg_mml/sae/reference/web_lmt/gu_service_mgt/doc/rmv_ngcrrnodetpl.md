# 删除NGC漫游限制模板操作(RMV NGCRRNODETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在数据库中删除一个NGC漫游限制模板。

## 注意事项

当执行该命令删除用户已签约或已被关联的NGC漫游限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该NGC漫游限制模板不能被删除。如果要删除该NGC漫游限制模板，必须先执行以下操作：

- 执行**MOD NGSRRS**命令给用户去签约相关的NGC漫游限制模板。
- 执行**MOD DNNREPRULETPL**命令去掉DNN替换规则模板与NGC漫游限制模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识NGC漫游限制模板数据记录的关键字段之一，用于指定在哪个HLR上删除NGC漫游限制模板的数据记录，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无 配置原则：无            |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识NGC漫游限制模板数据记录的关键字段之一，用于指定需要删除哪条NGC漫游限制模板的数据记录，操作员可以使用LST NGCRRNODETPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

删除NGC漫游限制模板,“HLR序列号”为“1”，“模板ID”为“1”,命令如下：

```
RMV NGCRRNODETPL: HLRSN=1,TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                      | 处理建议                                                                                                                                                 |
|:--------|:--------|:------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应模板数据记录不存在。               | 使用LST NGCRRNODETPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的NGC漫游限制模板数据记录。                                                                                    |
| ERR3005 | 模板已经被使用 | 可能原因为如下之一： 用户已签约该NGC漫游限制模板。NGC漫游限制模板已被关联。 | 根据实际情况，确定是否要删除该NGC漫游限制模板。如果确实需要删除，需要执行以下步骤：执行MOD NGSRRS命令给用户去签约该模板。执行MOD DNNREPRULETPL命令去掉DNN替换规则模板与NGC漫游限制模板的关联关系。执行RMV NGCRRNODETPL命令删除该NGC漫游限制模板。 |
