# 查询ICI业务(LST ICI)

- 注意事项

- 输出结果说明

## 命令功能

该命令用于在HLR中查询ICI业务信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                   |
|:------------|:----------|:---------------------------------------|
| IMSI        | IMSI      | 用于指示系统需要按照哪个IMSI号码查询用户的ICI业务信息。        |
| ISDN        | MSISDN    | 用于指示系统需要按照哪个MSISDN号码查询用户的ICI业务信息。      |
| RECORDCOUNT | 用户个数      | 用于指示系统需要查询连续多少个用户的ICI业务信息。             |
| IMSIFILE    | IMSI文件名   | 用于指示系统需要查询哪个IMSI批操作文件中包含的用户的ICI业务信息。   |
| ISDNFILE    | MSISDN文件名 | 用于指示系统需要查询哪个MSISDN批操作文件中包含的用户的ICI业务信息。 |

## 使用实例

1. 在HLR上查询“IMSI”为“460000009123456”的用户的ICI信息：

   ```
   LST ICI: IMSI="460000009123456";
   ```

   ```
   %%LST ICI: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 86131075003001
                             PROV = TRUE

   Total count = 3

   There is together 1 report
   ```
2. 在HLR上查询“MSISDN”为“86131075003001”的用户的ICI信息：

   ```
   LST ICI: ISDN="86131075003001";
   ```

   ```
   %%LST ICI: ISDN="86131075003001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 86131075003001
                             PROV = TRUE

   Total count = 3

   There is together 1 report
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                 | 处理建议                                                                                                                      |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突    | 可能原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。 “用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。 “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1004 | 无效的参数值  | 输入的“IMSI”或“MSISDN”参数值不在取值范围内。                                                                        | 请重新输入正确的“IMSI”或“MSISDN”参数值。                                                                                               |
