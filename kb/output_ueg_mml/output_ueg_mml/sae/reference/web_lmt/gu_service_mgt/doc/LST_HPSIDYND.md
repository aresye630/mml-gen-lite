# 查询PSI用户的动态数据(LST HPSIDYND)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定PSI用户相关动态数据，需要输入PISI、PUSI中的一个，或者同时输入。

## 注意事项

- 如果参数中只有PISI存在，查询PISI关联的所有PISI-PUSI的动态数据。
- 如果参数中只有PUSI存在，查询指定PUSI关联的PISI-PUSI的动态数据。
- 如果参数中PISI和PUSI都存在，查询指定PISI-PUSI的动态数据。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| PISI   | PISI   | 用于指示系统需要按照哪个PISI来查询动态数据。要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无。             |
| PUSI   | PUSI   | 用于指示系统需要按照哪个PUSI来查询动态数据，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无。 |

## 使用实例

查询PSI用户的动态数据。PUSI：sip:pusiinfo@huawei.com。

```
LST HPSIDYND: PUSI="sip:pusiinfo@huawei.com";
```
