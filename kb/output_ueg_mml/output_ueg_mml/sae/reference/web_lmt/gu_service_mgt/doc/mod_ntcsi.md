# 修改非模板CSI业务(MOD NTCSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于以非模板方式为用户签约、修改或去签约CAMEL业务，CAMEL业务包括：O-CSI（Originating CAMEL Subscription Information）、T-CSI（Terminating CAMEL Subscription Information）。

执行此命令后，如果是给用户签约、修改O-CSI业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 使用实例

1. 为IMSI起始号码为460000009123456的用户提供O-CSI业务命令如下：

   **MOD NTCSI**: IMSI="460000009123456", CAMELTYPE=OCSI, PROV=ADD, CAMEL=PHASE3, OCSIDP=COLLECTINFO, SK=1, GSMSCFADD="13500000", DEFCALL=releaseCall, VLR\_NOTSUPPHASE1=AllowLocationUpdateWithMOCall, VLR\_NOTSUPPHASE2=ReturnLPO-CSI, VLR\_NOTSUPPHASE3=ReturnLPO-CSI, VLR\_NOTSUPPHASE4=ReturnLPO-CSI, GMSC\_NOTSUPPHASE1=AllowMTCall, GMSC\_NOTSUPPHASE2=ReturnLP-CSI, GMSC\_NOTSUPPHASE3=ReturnLP-CSI, GMSC\_NOTSUPPHASE4=ReturnLP-CSI;
2. 为IMSI起始号码为460000009123456的用户修改O-CSI业务参数GSMSCFADD，命令如下：

   **MOD NTCSI**: IMSI="460000009123456", CAMELTYPE=OCSI, PROV=MOD, OCSIDP=COLLECTINFO, GSMSCFADD="13600000";
3. 为IMSI起始号码为460000009123456的用户撤销O-CSI业务，命令如下：

   **MOD NTCSI**: IMSI="460000009123456", CAMELTYPE=OCSI, PROV=DELETE, OCSIDP=COLLECTINFO;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                        | 处理建议                                                                                  |
|:--------|:---------|:--------------------------------------------|:--------------------------------------------------------------------------------------|
| ERR3111 | 系统不支持该特性 | SET MAPSERV命令的“CAMEL签约管理方式”参数取值为“Template”。 | 根据实际情况，修改SET MAPSERV命令的“CAMEL签约管理方式”参数取值为“INTERIM”或“NON-Template”，可通过LST MAPSERV命令查询。 |
