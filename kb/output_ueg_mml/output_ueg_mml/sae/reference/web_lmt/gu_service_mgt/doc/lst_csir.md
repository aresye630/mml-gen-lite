# 查询CSI限制列表(LST CSIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询CSI（CAMEL Subscription Information）限制列表的配置信息。

输入“HLR序列号”参数可以查询某个虚拟HLR中所有CSI限制列表的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                            |
|:-------|:-------|:--------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统需要按照哪个HLR序列号来查询CSI限制列表数据。 |

## 使用实例

查询禁止前转号码数据记录，“HLR序列号”为“1”：

```
LST CSIR: HLRSN=1;
```

```
%%LST CSIR: HLRSN=1;%%
RETCODE = 0 SUCCESS0001:操作成功

                    VLRSGSNNP1 = 11
                    VLRSGSNNP2 = 12

Total count = 2

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD CSIR**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                                  |
|:--------|:--------|:-------------|:------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。 | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。 |
