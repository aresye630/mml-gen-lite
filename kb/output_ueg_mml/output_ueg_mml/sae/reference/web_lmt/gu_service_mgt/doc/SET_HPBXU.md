# 设置IMS PBX标识(SET HPBXU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中设置指定“SUBID”的“PBX标识”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                    |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID       | SUBID   | 标识一条IMS签约用户数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条IMS签约用户数据记录的参数进行修改或调整，操作员可以使用LST HSUB命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                 |
| PBXUSERFLAG | PBX用户标识 | 用于标识一个IMS签约用户是否PBX用户。PBX指Private Branch eXchange，PBX用户通常指总分机用户，应用时公布总机号码，分机不分配公网号码，以通配的方式接入IMS网络。 取值范围：TRUE(TRUE)：表示该用户为PBX用户。FALSE(FALSE)：表示用户为非PBX用户。 默认值：无。 说明：必选参数。 |

## 使用实例

设置PBX用户标识，“SUBID”为“+862970119992@domain50.huawei.com”，“PBX用户标识”为“TRUE(TRUE)”：

```
SET HPBXU: SUBID="+862970119992@domain50.huawei.com", PBXUSERFLAG=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|----------:|:---------------|:-------------------------|:---------------------------------------------------------|
| 900001008 | 参数不足           | 参数“SUBID”或“PBX用户标识”没有输入。 | 根据实际情况，重新输入参数，确保参数“SUBID”和“PBX用户标识”必须存在。                 |
| 900003051 | 请求消息中的SubId不存在 | 输入的参数“SUBID”未定义。         | 根据实际情况，重新输入参数，确保参数“SUBID”已经定义。可通过LST HSUB命令查询已定义过的SUBID。 |
|      1001 | 无效的命令          | 输入的命令名称不正确。              | 重新输入正确的命令。                                               |
| 900001007 | 无效的参数值         | 输入的参数取值不在其取值范围内。         | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                         |
| 900001010 | 参数重复           | 输入命令中的同一参数重复出现。          | 根据实际情况，删除重复的参数，确保命令中每一个参数只出现一次。                          |
