## 命令功能

**须知** 

该命令属于高危命令，执行不当会造成用户的业务异常。请仔细评估待通知的数据为用户的正确业务数据，确认待通知的数据的正确性后方可执行。并且该命令不能和**LST LOG**、**LST HLOG**命令同时执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于将IMS-HSS中IMS用户或PSI用户的数据通过PNR消息发送给AS对端。

该命令应用的场景为：IMS-HSS的数据正确，AS对端的数据错误时，为了AS对端的数据与IMS-HSS的保持一致，则将空口日志中透明数据变更的用户所对应的IMS-HSS中最新数据通过Sh接口的PNR消息发送给AS对端。

如果设置时间段参数（“开始时间”、“结束时间”和“速率”）或输入参数为指定“IMPU”+时间段参数（“开始时间”、“结束时间”和“速率”）时，并且批操作完成后，以文本格式（文件名格式：SND\_HPNR\_yyyy-mm-dd-hh-mm-ss.txt）保存在PGW中，系统自动统计时间段方式发送模拟PNR消息操作成功的次数，操作结果可以通过PGW Web LMT上的“文件管理器”下载到本地。

## 注意事项

- 参数“服务标识”与时间段参数（“开始时间”、“结束时间”和“速率”）互斥。
- 当“结束时间”参数存在时，“开始时间”参数必须存在，且“开始时间”的取值必须小于或等于“结束时间”的取值。
- 该命令只在主用局PGW上执行。

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                                                                                                                                           |
|:-----------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU       | IMPU        | 用于标识待通知PNR消息中数据的IMPU或PUSI，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                     |
| STARTTIME  | 开始时间        | 用于标识待通知PNR消息的开始时间。从该时间开始的空口日志中透明数据变更的用户所对应的IMS-HSS中最新数据通过PNR消息下发给AS对端。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：当“结束时间”参数未输入，“开始时间”参数输入时，则表示从“开始时间”到当前时间的空口日志中透明数据变更的用户所对应的IMS-HSS中最新数据通过PNR消息下发给AS对端。                                                               |
| ENDTIME    | 结束时间        | 用于标识待通知PNR消息的开始时间。截止该时间的空口日志中透明数据变更的用户所对应的IMS-HSS中最新数据通过PNR消息下发给AS对端。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。                                                                                                                                                          |
| SPEED      | 速率          | 用于标识给AS对端下发PNR消息的速率。 单位：条/秒 取值范围：1～400 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“50”。“0”表示不进行限制。                                                                                                                                                                                      |
| AS         | AS主机名       | 用于标识给指定的AS对端下发PNR消息。操作员可以登录OM Portal在“UDM MML命令”界面执行LST DMPE命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数未输入，表示给所有订阅该数据的AS对端下发PNR消息。                                                                                                                                                |
| WAITRSP    | 是否需要等待响应    | 用于标识IMS-HSS向AS对端发送PNR消息后是否需要等待AS对端PNA响应消息。 取值范围：FALSE(FALSE)：不等待响应，即执行完该命令后直接返回操作成功。TRUE(TRUE)：等待响应，即执行完该命令后等待AS对端的返回PNA响应消息并携带操作成功或失败的结果。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“FALSE(FALSE)”。                                                                                   |
| DATAREF    | 通知的数据类型     | 用于标识待下发PNR消息中数据的类型。 取值范围：RepositoryData，表示为普通透明数据和别名透明数据。 默认值：无。                                                                                                                                                                                                               |
| CHECKEXIST | 检查指定的数据是否存在 | 用于标识IMS-HSS向AS对端发送PNR消息前检查数据是否存在。 取值范围：FALSE(FALSE)：不需要检查数据是否存在，直接向AS对端发送PNR消息。如果数据不存在，则向AS对端发送PNR消息中携带的透明数据内容为空。TRUE(TRUE)：检查数据是否存在，IMS-HSS对检查结果进行处理：存在：检查存在后向AS对端发送PNR消息。不存在：返回错误码“900003197 指定ServiceIndication的透明数据不存在”。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“FALSE(FALSE)”。 |
| SERVICEID  | 服务标识        | 仅当本命令中的“通知的数据类型”参数为“RepositoryData”时该参数有效。用于标识待下发PNR消息中一条透明数据记录。 取值范围：长度不超过127的字符串 默认值：无。 说明：该参数未输入，表示PNR消息下发所有透明数据到AS对端。                                                                                                                                                      |

## 使用实例

1. 按指定的IMPU通知AS对端恢复透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“AS主机名”为“as1.huawei.com”、“通知的数据类型”为“RepositoryData”：

   ```
   SND HPNR: IMPU="sip:impuinfo1@huawei.com", AS="as1.huawei.com", DATAREF=RepositoryData;
   ```
2. 按时间段方式通知AS对端恢复透明数据。“开始时间”为“2016&05&31&09&00&00”、“结束时间”为“2016&06&01&09&00&00”、“AS主机名”为“as1.huawei.com”、“通知的数据类型”为“RepositoryData”：

   ```
   SND HPNR: STARTTIME=2016&05&31&09&00&00, ENDTIME=2016&06&01&09&00&00, AS="as1.huawei.com", DATAREF=RepositoryData;
   ```
3. 通知AS对端删除废弃的透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“AS主机名”为“as1.huawei.com”、“通知的数据类型”为“RepositoryData”、“检查指定的数据是否存在”为“FALSE(FALSE)”、“服务标识”为“10”：

   ```
   SND HPNR: IMPU="sip:impuinfo1@huawei.com", AS="as1.huawei.com", DATAREF=RepositoryData, CHECKEXIST=FALSE, SERVICEID="10";
   ```
4. 按指定的IMPU和时间段方式通知AS对端恢复透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“开始时间”为“2016&05&31&09&00&00”、“结束时间”为“2016&06&01&09&00&00”、“AS主机名”为“as1.huawei.com”、“通知的数据类型”为“RepositoryData”：

   ```
   SND HPNR: IMPU="sip:impuinfo1@huawei.com", STARTTIME=2016&05&31&09&00&00, ENDTIME=2016&06&01&09&00&00, AS="as1.huawei.com", DATAREF=RepositoryData;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900001008 | 参数不足                        | “IMPU”或“开始时间”两个参数都未输入。                             | 根据实际情况，重新输入参数，确保“IMPU”或“开始时间”两个参数必须存在且只能存在一个。                                    |
