# 增加IMS用户模板(ADD IMSTPL)

## 命令功能

该命令用于在HSS的业务数据库中增加一个IMS用户模板。

操作员可以使用**ADD IMSTPL**增加IMS用户模板，在**ADD TPLIMSSUB**命令引用参数“IMS用户模板ID”，可以设置GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户签约IMS业务数据模板，签约成功后，GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户可正常使用IMS业务。

该命令的参数索引关系如图1所示。

**图1** 命令的参数索引关系图

## 注意事项

- 系统中增加的IMS用户模板记录数不能超过5000条。
- 新增IMS用户模板记录时，输入的“计费模板ID”、“能力集模板ID”、“ServiceProfile模板ID”和“拜访网络地址模板ID”必须对应同一个“HLR序列号”。

## 参数说明

| 参数标识       | 参数名称               | 参数说明                                                                                                                 |
|:-----------|:-------------------|:---------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号             | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                             |
| TPLID      | IMS用户模板ID          | 用于定义IMS用户基本信息模板的序号，以方便对IMS用户基本信息模板进行查询和引用。 取值范围：1～1024 默认值：无 说明：同一个“HLR序列号”，IMS用户模板ID唯一，已有模板ID可以使用LST HTPLINF命令查询获得。 |
| TPLNAME    | IMS用户模板名称          | 该参数用于具体描述一个IMS用户基本信息模板，以便于识别。 取值范围： 1～60位字符串 默认值：无                                                                   |
| CHARGTPLID | 计费模板ID             | 用于给IMS用户模板指定一个计费地址模板，该模板需要通过命令ADD HCHGTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无 说明：如果没有输入该参数，默认“计费地址模板ID”为“0”。                |
| CAPTPLID   | 能力集模板ID            | 用于给IMS用户模板指定一个能力集模板，该模板需要通过命令ADD HCAPTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无                                                |
| SPTPLID    | ServiceProfile模板ID | 用于给IMS用户模板指定一个Service Profile模板，该模板需要通过命令ADD HSPTPL定义，才能在此处索引。 取值范围：0~1024 缺省值：无                                     |
| VNTPLID    | 拜访网络地址模板ID         | 用于指定一个漫游地址ID。该参数必须先在ADD HVNTPL中定义，然后才能在此处引用。 取值范围：0~1024 缺省值：无                                                       |
| STNSR      | SRVCC会话传输号码        | SRVCC会话传输号码。MME(Mobility Management Entity)使用它获取从PS域到CS域的网址路径会话传递。 取值范围：E.164格式的编码，3～15位的十进制数字。 默认值：无                |

## 使用实例

增加一个IMS用户模板，参数取值如表1所示。

| 参数                 | 值                 |
|:-------------------|:------------------|
| IMS用户模板ID          | 1                 |
| IMS用户模板名称          | IMS User Template |
| 计费模板ID             | 1                 |
| 能力集模板ID            | 1                 |
| ServiceProfile模板ID | 1                 |
| 拜访网络地址模板ID         | 1                 |
| SRVCC会话传输号码        | 8613484929766     |

```
ADD IMSTPL: TPLID=1, TPLNAME="IMS User Template", CHARGTPLID=1, CAPTPLID=1, SPTPLID=1, VNTPLID=1, STNSR="8613484929766";
```
