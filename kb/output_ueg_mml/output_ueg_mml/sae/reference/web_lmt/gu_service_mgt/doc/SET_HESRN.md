# 设置紧急服务路由号码(SET HESRN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU的紧急服务路由号码。如果该IMPU属于某隐式注册集，则该隐式注册集内其它IMPU也被自动设置为相同的紧急服务路由号码。

## 注意事项

当参数ESRN不存在时，表示将IMPU的ESRN数据删除。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                     |
|:-------|:---------|:-----------------------------------------------------------------------------------------|
| IMPU   | IMPU     | 用于指定一个需要设置紧急服务路由号码的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| ESRN   | 紧急服务路由号码 | 指定该IMPU的紧急服务路由号码，可以为任意字符串。 取值范围： 长度不超过127的字符串 缺省值： 无                                     |

## 使用实例

设置IMPU的紧急服务路由号码。IMPU：sip:impuinfo@huawei.com，紧急服务路由号码为：shenzhenbantian。

```
SET HESRN: IMPU="sip:impuinfo@huawei.com", ESRN="shenzhenbantian";
```
