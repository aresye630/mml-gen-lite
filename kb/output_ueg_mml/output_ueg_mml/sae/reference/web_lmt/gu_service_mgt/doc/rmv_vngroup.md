# 删除5G虚拟网络组 (RMV VNGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，删除时会广播查询所有用户是否签约该群组，会增加USCDB性能消耗，可能导致流控，影响业务成功率。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条5G虚拟网络组配置信息。

## 注意事项

- 当组成员已通过执行**ADD GROUPID**或**ADD GRPMEMBER**命令加入5G虚拟网络组，则不允许删除该5G虚拟网络组，否则系统会报错。
- 混合组网场景下，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                       |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INGROUPID  | 内部组ID  | 可选必选说明：条件必选参数 参数含义：标识5G虚拟网络组数据记录的关键字段，用于指定需要删除哪一条5G虚拟网络组数据记录，操作员可以使用LST VNGROUP命令查询获得。 取值范围：10～38个十进制数字、十六进制数字或“-”组成的字符串。 默认值：无。 配置原则： 该参数与“外部组ID”两个参数必须输入且只能输入其中一个。该参数输入的字母不区分大小写。        |
| EXTGROUPID | 外部组ID  | 可选必选说明：条件必选参数 参数含义：标识5G虚拟网络组数据记录的关键字段，用于指定需要删除哪一条5G虚拟网络组数据记录，操作员可以使用LST VNGROUP命令查询获得。 取值范围：3～128个字母、十进制数字、“@”、“.”、“-”或“_”组成的字符串。 默认值：无。 配置原则：该参数与“内部组ID”两个参数必须输入且只能输入其中一个。该参数输入的字母不区分大小写。 |

## 使用实例

删除“内部组ID”为“1-46001-2D”的5G虚拟网络组数据。

```
RMV VNGROUP: INGROUPID="1-46001-2D";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

| 错误码     | 错误码解释                     | 原因分析                                | 处理建议                                                   |
|:--------|:--------------------------|:------------------------------------|:-------------------------------------------------------|
| ERR1009 | 参数丢失                      | 执行命令时未输入“内部组ID”或“外部组ID”两个参数任何一个。    | “内部组ID”和“外部组ID”两个参数必须且只能输入一个。                          |
| ERR1010 | 参数冲突                      | 执行命令时同时输入“内部组ID”和“外部组ID”参数。         | “内部组ID”与“外部组ID”两个参数必须输入且只能输入其中一个。                      |
| ERR3007 | 记录不存在                     | “内部组ID”或“外部组ID”参数对应的5G虚拟网络组数据记录不存在。 | 可以先通过LST VNGROUP命令查询“内部组ID”或“外部组ID”对应的5G虚拟网络组数据记录是否存在。 |
| ERR3111 | 系统不支持该特性                  | 混合组网场景下，在非路由分区下执行该命令。               | 混合组网场景下，该命令仅支持在路由分区下执行。                                |
| ERR4165 | 5G VM Group下还有组成员，请先删除组成员 | 执行该命令时5G虚拟网络组下还有组成员。                | 根据实际情况，可以先通过RMV GROUPID或RMV GRPMEMBER命令删除5G虚拟网络组的成员。   |
