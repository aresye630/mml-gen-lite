# 删除PS的APN和EPS数据对应关系(RMV PSAPNEPS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条PS的APN和EPS数据的对应关系记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识PS的APN和EPS数据的对应关系记录的关键字段之一，用于指定在哪个HLR上删除计费特性和EPS数据对应关系记录，操作员可以使用LST HLRSN命令查询获得。    |
| APN    | 接入点名称  | 标识PS的APN和EPS数据的对应关系记录的关键字段之一，用于指定需要删除哪个PS的APN和EPS数据的对应关系记录，操作员可以使用LST PSAPNEPS命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“接入点名称”为“huawei.com”的PS的APN和EPS数据的对应关系记录：

```
RMV PSAPNEPS: HLRSN=1, APN="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                               | 处理建议                                                                                                      |
|:--------|:--------|:-------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”未定义。 “HLR序列号”和“接入点名称”的对应的PS的APN和EPS数据的对应关系记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”或“接入点名称”。 已定义的“HLR序列号”可通过LST HLRSN命令查询。已存在的PS的APN和EPS数据的对应关系记录可通过LST PSAPNEPS命令查询。 |
