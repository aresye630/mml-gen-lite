# 删除PSI用户(RMV HPSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中删除一条指定的PSI用户记录或者从一个已经存在的PSI用户下删除一个PUSI记录，在PSI用户销户或者删除一条PUSI记录时使用该操作。

## 注意事项

参数PISI和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| PISI   | PISI   | 标识一条PISI数据记录的关键参数，用于指定需要删除哪一条PISI数据记录下对应的PISI和PUSI之间的对应关系，操作员可以使用LST HPSI操作查询获得，要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值： 无             |
| PUSI   | PUSI   | 标识一条PUSI数据记录的关键参数，用于指定需要删除哪一条PUSI数据记录下对应的PISI和PUSI之间的对应关系，操作员可以使用LST HPSI操作查询获得，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值： 无 |

## 使用实例

删除一个PSI用户。PISI：pisiinfo。

```
RMV HPSI: PISI="pisiinfo";
```
