# 修改UE级别NSA用户AMBR数据(MOD NSAAMBR)

- 命令功能

- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改NSA（Non-Standalone）用户AMBR（Aggregate Maximum Bit Rate）数据。

该命令仅适用于混合组网场景，其他场景下请勿使用该命令。

- 混合组网场景下，执行该命令给NSA用户签约AMBR数据，会将用户从ATCA分区迁移到NFV分区。如果运营商规划给NSA用户签约AMBR数据时不做迁移，则可以使用**MOD EPS**/**MOD EPSAMBR**命令给用户签约。
- 如果需要给NSA用户去签约AMBR参数，需要执行**MOD EPS**/**MOD EPSAMBR**命令给用户签约EPS AMBR参数。混合组网场景下，若用户已经从ATCA迁移到了NFV，则去签约操作不会把用户从NFV迁回ATCA。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 在混合组网场景下，该命令必须在vRSP执行，否则系统会返回错误。
- 在Global-Local组网场景下，不支持使用本命令修改NSA用户AMBR数据，否则系统会返回错误。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                  |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改AMBR数据的NSA用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| ISDN        | MSISDN    | 用于标识需要修改AMBR数据的NSA用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                          |
| RECORDCOUNT | 用户个数      | 用于标识需要修改AMBR数据的NSA用户数目。 当需要为连续号段的多个NSA用户修改AMBR数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个NSA用户修改AMBR数据。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个NSA用户修改AMBR数据，当只有一个用户时，该参数不必配置。 当一次修改AMBR数据的用户个数很多时，对系统性能无影响，但修改AMBR数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改AMBR数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modnsaambr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                   |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改AMBR数据的NSA用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modnsaambr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                          |
| AMBRNRUL    | NR上行速率    | 用于标识5G网络NSA用户的最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位为kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“NR下行速率”参数必须配置一个。                                                                                                                                 |
| AMBRNRDL    | NR下行速率    | 用于标识5G网络NSA用户的最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位为kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“NR上行速率”参数必须配置一个。                                                                                                                                 |

## 使用实例

1. 修改IMSI号码为“460030913121001”的“NR上行速率”，修改为“10000”：

   ```
   MOD NSAAMBR: IMSI="460030913121001", AMBRNRUL=10000;
   ```
2. 修改3个连续号码的用户的“NR上行速率”，第一个用户的IMSI号码为“460030913121001”，对应的“NR上行速率”修改为“20000”：

   ```
   MOD NSAAMBR: IMSI="460030913121001", RECORDCOUNT=3, AMBRNRUL=20000;
   ```
3. 修改3个非连续号码的用户的“NR下行速率”，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modnsaambr.txt”的文件中，并通过文件管理功能上传到指定目录，对应的“NR下行速率”修改为“20000”：

   ```
   MOD NSAAMBR: ISDNFILE="modnsaambr.txt", AMBRNRDL=20000;
   ```
