# 根据模板信息新增IMS用户数据(ADD HTPLSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中，利用IMS签约用户相关的能力集模板、计费地址模板、ServiceProfile模板、IMPU基本信息模板，增加一个IMS用户。

该命令的参数索引关系如图1所示。

**图1** 命令的参数索引关系图

## 注意事项

- 参数SPTPLID、IMPUTPLID存在时，IMPU参数必须存在。
- 参数CHARGTPLID、CAPTPLID和IMPU存在时，IMPI参数必须存在。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。

## 使用实例

1. 根据模板信息新增IMS用户数据。“SUBID”为“subinfo”，“IMPI”为“impiinfo”，“IMPU”为“sip:impuinfo@huawei.com”，“能力集模板ID”为“1”，“计费地址模板ID”为“1”，“ServiceProfile模板ID”为“1”，“IMPU基本信息模板ID”为“1”，“PBX用户标识”为“TRUE（TRUE）”：

```
ADD HTPLSUB: SUBID="subinfo", IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com", CAPTPLID=1, CHARGTPLID=1, SPTPLID=1, IMPUTPLID=1, PBXUSERFLAG=TRUE;
```

2. 根据模板信息新增IMS用户数据。“SUBID”为“subinfo”，“IMPI”为“impiinfo”，“IMPU”为“tel:+33145297![247].\*!”，“IMPUTYPE”为“WIMPU（WIMPU）”，“能力集模板ID”为“1”，“计费地址模板ID”为“1”，“ServiceProfile模板ID”为“1”，“IMPU基本信息模板ID”为“1”，“PBX用户标识”为“TRUE（TRUE）”，“系统序列号”为“10”：

```
ADD HTPLSUB: SUBID="subinfo", IMPI="impiinfo", IMPU="tel:+33145297![247].*!", IMPUTYPE=WIMPU, CAPTPLID=1, CHARGTPLID=1, SPTPLID=1, IMPUTPLID=1, PBXUSERFLAG=TRUE, SYSNO=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                    | 原因分析                                                                       | 处理建议                                                                                                                      |
|----------:|:-------------------------|:---------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| 900003100 | IMPU已存在，或与IMPU同名的PUSI已存在 | 可能原因如下之一：实际输入的参数“IMPU”已经签约过IMS业务数据。实际输入的参数“IMPU”与IMS网络中已存在的PUSI同名。         | 根据实际情况，重新输入参数，确保满足以下两点：输入的“IMPU”没有签约IMS业务数据。可通过LST HSUB命令查询IMPU是否已签约。输入的“IMPU”与IMS网络已存在的PUSI不同名。可通过LST HPSI命令查询PUSI是否已存在。 |
| 900003524 | 分权分域模式下不支持此命令            | SET HSYSTEMPARA命令的“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参设置为“TRUE(TRUE)”。 | 无需处理。                                                                                                                     |
| 900003239 | 能力集模板ID不存在               | “能力集模板ID”输入错误，实际输入的参数“能力集模板ID”未定义。                                         | 如果输入的“能力集模板ID”确定正确，说明实际输入的参数“能力集模板ID”未定义，请先通过ADD HCAPTPL命令定义“能力集模板ID”。                                                    |
| 900003240 | SP模板ID不存在                | 输入的Service Profile模板ID在系统中未定义。                                             | 根据实际情况，重新输入Service Profile模板ID，确保输入的Service Profile模板ID已定义。                                                               |
| 900003243 | 计费地址模板ID不存在              | “计费模板ID”参数输入错误，实际输入的“计费模板ID”参数未定义。                                         | 根据实际情况，重新输入参数，确保“计费模板ID”参数已存在。“计费模板ID”参数可以通过ADD HCHGTPL命令增加。                                                              |
