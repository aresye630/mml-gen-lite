# 修改国内长途区号(MOD DAREA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条国内长途区号数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条国内长途区号数据记录：

- “HLR序列号”
- “国内长途区号”

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                  |
|:---------|:-------|:--------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号 | 标识一条国内长途区号数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个HLR上的国内长途区号数据记录进行修改，操作员可以使用LST HLRSN命令查询获得。 |
| AREACODE | 国内长途区号 | 标识一条国内长途区号数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条国内长途区号数据记录的参数进行修改，操作员可以使用LST DAREA命令查询获得。   |
| CNAME    | 国内地区名称 | 用于标识国内地区名称。 取值范围：由不超过30位字符组成的字符串。 默认值：无。                                              |

## 使用实例

修改“HLR序列号”为“1”、“国内长途区号”为“755”的数据记录对应的“国家和地区名称”，将原有数据修改为“Shenzhen2”：

```
MOD DAREA: HLRSN=1, AREACODE="755", CNAME="Shenzhen2";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                      |
|:--------|:--------|:-----------------------------------|:----------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“国内长途区号”对应的国内长途区号数据记录不存在。 | 使用LST DAREA命令查询后，重新确认要修改哪个“HLR序列号”和“国内长途区号”对应的国内长途区号数据记录。 |
