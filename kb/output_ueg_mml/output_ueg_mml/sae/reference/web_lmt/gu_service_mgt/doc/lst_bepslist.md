# 查询EPS黑名单用户列表(LST BEPSLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询EPS黑名单号码列表。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                      |
|:-------|:-------|:------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统需要按照哪个HLR序列号来查询地址限制表中的EPS黑名单用户号码信息。 |

## 使用实例

1. 查询HLR序列号为“1”的EPS黑名单用户号码信息：

   ```
   LST BEPSLIST: HLRSN=1;
   ```

   ```
   %%LST BEPSLIST: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

   "BEPS_ISDN"
   460000009123456

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET BEPSLIST**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                                            |
|:--------|:--------|:-------------|:----------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。 | 如果“HLR序列号”未定义，则执行ADD HLRSN命令先定义该“HLR序列号”，再为该“HLR序列号”设置EPS黑名单列表。 |
