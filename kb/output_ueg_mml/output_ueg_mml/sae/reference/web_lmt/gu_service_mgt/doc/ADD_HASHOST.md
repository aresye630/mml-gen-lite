# 增加AS主机名(ADD HASHOST)

## 命令功能

该命令用于增加AS对端实体和数据库中的ASID间的对应关系。

当通过**ADD DMPE**命令增加完AS类型的Diameter对端实体后，需要执行此命令。

通过**ADD DMPE**命令增加对端实体时，IMS-HSS会按照顺序自动为对端实体分配ID。IMS-HSS和AS间的PNR/PNA和SNR/SNA消息基于ASID进行处理，为了避免容灾倒换后因主用局和容灾局增加AS对端实体的顺序不一致导致的业务异常，在**SET HSYSTEMPARA**命令的参数“ASID管理方式”取值为“STORE\_IN\_USCDB”时，只需在主用局通过该命令增加AS对端实体和数据库中的ASID间的对应关系，实现同一个AS的ASID在主用局和容灾局一致。

## 注意事项

- 本命令的配置必须在**SET HSYSTEMPARA**命令的软参“ASID管理方式”取值为“STORE\_IN\_USCDB”时才能生效。
- 系统中通过执行该命令增加的最大记录数为1000条。

| SERVICELIST  | 业务列表            | 仅当该命令中的“基于局向的透明数据下发格式开关”参数设置为“CTRL”时该参数有效且必须选择。用于标识基于AS局向设定下发的补充业务一致性透明数据格式。 取值范围： 全部选中：选中除“全部清空”外的所有取值。全部清空：在客户端界面清空除“全部清空”外的所有取值。CFD：基于局向支持在MMTEL-Service里不携带CFD，同时支持PUR消息中不携带CFD。NO_MEDIA：基于局向在CB下发时，在MMTEL-Service里当video、audio同时激活或同时去激活时支持不携带media，同时支持PUR消息中不携带media；当video、audio只激活一个或只去激活一个时携带media。 默认值：全部清空                                              |

## 使用实例

增加一条AS对端实体和数据库中的ASID间的对应关系。“ASID”为“1”，“主机名”为“as1.huawei.com”，“域名”为“huawei.com”：

```
ADD HASHOST: ASID=1, HOSTNAME="as1.huawei.com", REALMNAME="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释        | 原因分析                      | 处理建议                                                                              |
|----------:|:-------------|:--------------------------|:----------------------------------------------------------------------------------|
| 900003493 | ASID已经存在     | 该命令输入的“ASID”已经添加过，命令执行重复。 | 请按照以下步骤操作： 执行LST HASHOST命令查询数据记录。根据查询结果重新输入“ASID”，确保其不重复。                         |
| 900003494 | 主机名已经存在      | 该命令输入的“主机名”已经添加过，命令执行重复。  | 请按照以下步骤操作： 执行LST HASHOST命令查询数据记录。根据查询结果重新输入“主机名”，确保其不重复。                          |
| 900003496 | AS信息已经达到最大数量 | 超出1000条                   | 请按照以下步骤操作： 执行LST HASHOST命令查询数据记录。根据查询结果执行RMV HASHOST命令删除不必要的数据记录，使添加的总记录数在1000之内。 |
