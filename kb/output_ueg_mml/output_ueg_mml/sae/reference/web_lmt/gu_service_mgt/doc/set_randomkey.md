# 设置随机密钥功能(SET RANDOMKEY)

- 输出结果说明

## 命令功能

该命令用于设置随机密钥功能。

- 新建局点时，**SET MAPCONF**命令中的“是否启用随机密钥”参数系统初始设置值为“FALSE”。在全新部署流程中，配置本局数据时，请先执行该命令生成随机密钥，并执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥。当**SET MAPCONF**命令中的“是否启用随机密钥”参数设置为“TRUE”后，如果未执行该命令生成密钥材料，则执行鉴权相关命令时会返回错误：“已启用随机密钥功能，请先执行SET RANDOMKEY命令生成随机密钥。”
- 主用局、容灾局都升级完成后，通过执行该命令生成密钥材料，执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，并设置**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”启用随机密钥功能。

## 注意事项

- 执行该命令只能增加随机密钥数据记录，不能删除，系统中最多可增加3000条随机密钥数据记录。
- 新建局点首次通过**ADD HLRSN**命令添加第一条HLRSN记录时，无论**SET MAPCONF**命令中的“是否启用随机密钥”参数如何设置，系统都会自动生成“KEYID”为“3001”的缺省随机密钥。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                  |
|:-------|:-------|:------------------------------------------------------|
| KEYID  | 密钥ID   | 可选必选说明：必选参数 参数含义：用于标识密钥ID。 取值范围：1～3000 默认值：无。 配置原则：无。 |

## 使用实例

执行该命令生成密钥材料，“密钥ID”为“1”：

```
SET RANDOMKEY:KEYID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释          | 原因分析                                  | 处理建议                                                                      |
|:--------|:---------------|:--------------------------------------|:--------------------------------------------------------------------------|
| ERR4088 | 已生成随机密钥，不需重复生成 | 执行该命令时输入的“密钥ID”参数对应的随机密钥数据记录在数据库中已存在。 | 根据实际情况，重新输入参数，确保输入的“密钥ID”和系统中已存在的不重复。可执行LST RANDOMKEY命令查询系统中已存在的随机密钥数据记录。 |
