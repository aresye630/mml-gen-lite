# 模板开户(ADD TPLSUB)

- 命令功能

## 命令功能

该命令用于对一个或多个用户采用开户模板进行开户。为具有同样业务类型的用户业务发放时使用。

本命令中“模板类型”参数取值不同，定义开户模板的命令不同。

- 当本命令中的“模板类型”为“NORMAL”时，使用**ADD SUBTPL**定义开户模板，其中定义了用户需要使用的CS、PS、EPS或5G业务。
- 当本命令中的“模板类型”为“EPS\_SEPARATE”时，
  - 使用**ADD SUBTPL**定义CSPS用户开户模板，其中定义了用户需要使用的CS、PS业务。
  - 使用**ADD EPSUSERTPL**定义EPS用户模板，其中定义了用户需要使用的EPS业务。
  - 使用**ADD NGSUSERTPL**定义5G用户模板，其中定义了用户需要使用的5G业务。

## 注意事项

- 开户前，请使用**ADD KI**命令加载KI。
- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- 通过开户批操作文件为不连续号码的M2M用户开户成为MSISDN-Less用户时，由于开户批操作文件必须同时输入IMSI和MSISDN，需在批操作文件中将用户的MSISDN与IMSI保持一致。
- “用户个数”和“IMSI/MSISDN文件名”有且只能有一个参数出现。
- “用户个数”或“IMSI/MSISDN文件名”参数不能与“SRVCC会话传输号码”参数同时配置。
- “5G用户模板ID”和“CSPS用户模板ID”同时存在时，如果“5G用户模板ID”中定义了“用户计费签约数据”参数，计费签约数据以“5G用户模板ID”中的为准，否则，以“CSPS用户模板ID”中定义的计费参数为准。
- 当用户签约的“5G用户模板ID”模板数据发生修改时，如果模板新增或修改了“用户计费签约数据”参数，计费签约数据以修改后的“5G用户模板ID”中的为准。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 为“IMSI”为“460000009123456”、“MSISDN”为“8613900001234”的用户使用“NORMAL”类型进行模板开户，“模板ID”为“2”，命令如下:

   ```
   ADD TPLSUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", TPLTYPE=NORMAL, TPLID=2;
   ```
2. 为“IMSI”为“460000009123466”、“MSISDN”为“8613900001244”的用户使用“EPS\_SEPARATE”类型进行模板开户，“EPS用户模板ID”为“2”，“5G用户模板ID”为“1”，命令如下:

   ```
   ADD TPLSUB: HLRSN=1, IMSI="460000009123466", ISDN="8613900001244", TPLTYPE=EPS_SEPARATE, EPSUSERTPLID=2, NGSUSERTPLID=1;
   ```
3. 为“IMSI”为“460000009123476”、“MSISDN”为“8613900001254”的用户使用“EPS\_SEPARATE”类型进行NPN开户，“5G用户模板ID”为“1”，“PLMNID”为“111111”，“是否只允许UE通过CAG小区接入5GS”为“TRUE”，“CAGID”为“11111111”，命令如下：

   ```
   ADD TPLSUB: HLRSN=1, IMSI="460000009123476", ISDN="8613900001254", TPLTYPE=EPS_SEPARATE, NGSUSERTPLID=1, PLMNID="111111", CAGONLY=TRUE, CAGID="11111111";
   ```
4. 批量为“IMSI”号码分别为“460000009012346”、“460000009012347”、“460000009012348”，“MSISDN”号码分别为“8613900001234”、“8613900001235”、“8613900001236”的连续3个用户使用模板开户，“模板ID”为“2”，命令如下：

   ```
   ADD TPLSUB: HLRSN=1, IMSI="460000009012346", ISDN="8613900001234", RECORDCOUNT=3, TPLID=2;
   ```
