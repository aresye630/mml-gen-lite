# 修改PLMN区域漫游业务(MOD PLMNRSZI)

## 命令功能

该命令用于给EPS用户以模板方式提供或撤销PLMN（Public Land Mobile Network）区域漫游业务。

对于在网用户执行该命令后，UDM把用户签约的ZC（Zone Code）列表下发到用户所在的MME（Mobility Management Entity），MME收到ZC列表后，根据用户所在漫游区域的ZC和漫游限制策略（黑名单或白名单），限制用户的漫游状态。如果用户不在网时签约区域漫游限制业务，仅更新用户在数据库中的数据，当用户进行位置更新流程时UDM将用户签约的ZC列表下发给MME。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”中的一个同时存在。
- 当PLMN区域漫游限制模板中同时签约了业务限制模板（通过**ADD SERRESTTPL**命令定义的模板）和业务下发模板（通过**ADD RSITPL**命令定义的模板），按照业务下发模板优先的原则处理。比如，业务下发模板和业务限制模板都定义了同一个APN（APN名称和类型相同），那么这个APN将会被下发到对端，不需要被限制。
- 当通过**LST MAPSERV**命令查询出来的“PLMN漫游限制的控制策略 ”的值为“S6a\_S6d\_SWx”时，不能将本命令中的参数“漫游控制类型”设置为“SWx”，否则漫游控制模板设置无效。如果需要通过SWx接口控制，则需要通过**SET MAPSERV**命令修改“PLMN漫游限制的控制策略 ”的值为“S6a\_S6d”。

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                            |
|:------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI            | 用于标识需要修改PLMN区域漫游业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                     |
| ISDN        | MSISDN          | 用于标识需要修改PLMN区域漫游业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                   |
| RECORDCOUNT | 用户个数            | 用于标识需要修改PLMN区域漫游业务的用户数目。 当需要为连续号码的多个用户修改PLMN区域漫游业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改PLMN区域漫游业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改PLMN区域漫游业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                     |
| IMSIFILE    | IMSI文件名         | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改PLMN区域漫游业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modplmnrszi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                                     |
| ISDNFILE    | MSISDN文件名       | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改PLMN区域漫游业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modplmnrszi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                               |
| PROV        | 提供或撤销PLMN区域漫游业务 | 用于标识执行该命令是给用户提供/修改还是撤销PLMN区域漫游业务。 取值范围：TRUE：提供/修改FALSE：撤销 默认值：无。                                                                                                                                                                                                |
| PLMNTPLID   | PLMN漫游限制模板ID    | 仅当本命令中的“提供或撤销PLMN区域漫游业务”参数为“TRUE”时该参数有效。用于标识待给用户提供/修改的PLMN漫游限制模板ID。该参数必须先由ADD PLMNTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                        |
| TYPE        | 漫游控制类型          | 用于标识SAE-HSS按照哪个接口签约PLMN漫游模板来控制用户签约的漫游限制业务。 取值范围： S6a_SWx：表示同时为S6a/SWx接口签约PLMN漫游模板来控制用户签约的漫游限制业务。S6a：表示为S6a接口签约PLMN漫游模板来控制用户签约的漫游限制业务。SWx：表示为SWx接口签约PLMN漫游模板来控制用户签约的漫游限制业务。 默认值：S6a。 说明：VoWiFi场景下，接口为“S6a_SWx”或“SWx”时，如果MAR消息未携带VNI，则不支持通过“PLMN漫游限制模板ID”限制下发APN。 |

## 使用实例

1. 修改IMSI号码为“460000009123456”的用户的PLMN区域漫游业务，“提供或撤销PLMN区域漫游业务”为“TRUE”，“PLMN模板ID”为“2”：

   ```
   MOD PLMNRSZI: IMSI="460000009123456", PROV=TRUE, PLMNTPLID=2;
   ```
2. 修改3个连续号码的用户的PLMN区域漫游业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“提供或撤销PLMN区域漫游业务”为“TRUE”，“PLMN模板ID”为“2”：

   ```
   MOD PLMNRSZI: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, PLMNTPLID=2;
   ```
3. 修改3个非连续号码的用户的PLMN区域漫游业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modplmnrszi.txt”的文件中，并通过文件管理功能上传到指定目录，“提供或撤销PLMN区域漫游业务”为“FALSE”：

   ```
   MOD PLMNRSZI: ISDNFILE="modplmnrszi.txt", PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
