# 查询AUC状态(LST AUCSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来查询相应用户的鉴权状态。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                        |
|:------------|:--------|:----------------------------------------------------------------------------|
| IMSI        | IMSI    | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数    | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名 | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。              |

## 使用实例

查询IMSI号码为460000009012345的用户对应的鉴权状态。例如：

LST AUCSTATUS: IMSI="460000009012345";
