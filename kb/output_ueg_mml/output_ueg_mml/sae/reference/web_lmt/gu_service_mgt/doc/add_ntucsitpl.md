# 增加NT-U-CSI模板(ADD NTUCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于NT-U-CSI模板的初始化定义，为HLR在配置数据库中增加一条NT-U-CSI模板数据记录，即为NT-U-CSI模板初始配置一个U-CSI模板。

## 注意事项

执行该命令只能为NT-U-CSI模板定义一个U-CSI模板。如果需要添加多个U-CSI模板，请参见**MOD NTUCSITPL**命令。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                              |
|:-----------|:-------------|:----------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 默认值：无。                               |
| TPLID      | NT-U-CSI模板ID | 用于标识待增加NT-U-CSI模板在系统中的序号。 取值范围：0～65534 默认值：无。                                     |
| TPLNAME    | 模板名称         | 用于标识待增加NT-U-CSI模板在系统中的名称。 取值范围：长度不超过60的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。        |
| UCSI_TPLID | U-CSI模板ID    | 用于标识在NT-U-CSI模板中待增加的U-CSI模板ID。该参数必须先通过ADD UCSITPL命令配置才能在此处引用。 取值范围：0～65534 默认值：无。 |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条NT-U-CSI模板数据记录。其中，“NT-U-CSI模板ID”为“1”，“模板名”为“NTUCSI1”，“U-CSI模板ID”为“1”：

```
ADD NTUCSITPL: HLRSN=1, TPLID=1, TPLNAME="NTUCSI1", UCSI_TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                             |
|:--------|:--------|:-----------------------------------|:---------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                 |
| ERR3003 | 模板未定义   | 输入的参数“U-CSI模板ID”对应的U-CSI模板数据记录不存在。 | 根据实际情况，重新输入参数“U-CSI模板ID”，确保“U-CSI模板ID”对应的U-CSI模板数据记录存在，可使用LST UCSITPL命令进行查询。     |
| ERR3004 | 模板已存在   | 输入的参数“NT-U-CSI模板ID”在数据库中已存在。       | 根据实际情况，重新输入参数，确保输入的“NT-U-CSI模板ID”和系统中已存在的不重复。可执行LST NTUCSITPL命令查询系统中已存在的U-CSI模板。 |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                       | 根据实际情况，重新输入“HLR序列号”的取值，确保已通过ADD HLRSN命令定义。                                       |
