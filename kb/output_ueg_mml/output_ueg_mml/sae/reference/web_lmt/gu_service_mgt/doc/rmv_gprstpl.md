# 删除GPRS模板(RMV GPRSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来删除指定GPRS模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| TPLID  | 模板ID   | 模板号码，必选参数，0～65534。                       |

## 使用实例

删除2号GPRS模板中的数据。

RMV GPRSTPL: HLRSN=1, TPLID=2;
