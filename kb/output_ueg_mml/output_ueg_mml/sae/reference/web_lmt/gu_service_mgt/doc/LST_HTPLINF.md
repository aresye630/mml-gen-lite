# 查询模板信息(LST HTPLINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询模板的模板ID和模板名称。该操作输入模板类型查询某一种类型的模板数据，根据数据库中的模板记录显示多条或者单条记录。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLTYPE | 模板类型   | 用于指示系统需要按照哪种模板类型来查询模板数据。 取值范围： IMPUTPL(IMPU template)：表示查询IMPU模板的基本信息。PUSITPL(PUSI template)：表示查询PUSI模板的基本信息。CAPTPL(capability template)：表示查询能力集模板的基本信息。SPTPL(SP template)：表示查询Service Profile模板的基本信息。IFCTPL(iFC template)：表示查询IFC模板的基本信息。AKATPL(AKA template)：表示查询AKA模板的基本信息。CHARGTPL(charge template)：表示查询计费模板的基本信息。NATPL(NASS template)：表示查询游牧模板的基本信息，最多显示1000条记录，超过1000条的记录，可以通过指定ID执行LST HNATPL命令进行查询。VNTPL(VN template)：表示查询拜访网络模板的基本信息。OCSITPL(O-CSI template)：表示查询O-CSI模板的基本信息。TCSITPL(T-CSI template)：表示查询T-CSI模板的基本信息。SIFCTPL(Shared iFC template)：表示查询共享IFC模板的基本信息。IMSTPL(IMS subscription template)：表示查询IMS用户模板的基本信息。 缺省值： 无 |

## 使用实例

查询模板信息:“模板类型”为“IMSTPL”：

```
LST HTPLINF: TPLTYPE=IMSTPL;
```

```
%%LST HTPLINF: TPLTYPE=IMSTPL;%%
RETCODE = 0 SUCCESS0001:操作成功

HLRSN   TPLID            TPLNAME
1       1                IMS User Template

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

| 参数标识    | 参数说明               |
|:--------|:-------------------|
| HLRSN   | 用于返回查询模板对应的HLR序列号。 |
| TPLID   | 用于返回查询模板ID。        |
| TPLNAME | 用于返回查询模板名称。        |
