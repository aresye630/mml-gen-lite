# 修改CAPL业务(MOD CAPL)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于修改用户CAPL（Channel Allocation Priority Level）业务的签约信息。为未签约CAPL业务的用户提供该业务，或者为已签约CAPL业务的用户去签约该业务。

当用户在网，且处于可用状态时，如果为用户签约CAPL业务，执行该命令则HLR会向MSC/VLR下发插入用户数据的消息；如果为用户去签约CAPL业务，执行该命令则HLR会向MSC/VLR下发删除用户数据的消息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 撤销CAPL业务，参数“CAPLPROV”必须设置为“FALSE”。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                               |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | 用于标识需要修改CAPL业务数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                          |
| ISDN        | MSISDN     | 用于标识需要修改CAPL业务数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                        |
| RECORDCOUNT | 用户个数       | 用于标识需要修改CAPL业务数据的用户数目。 当需要为连续号码的多个用户修改CAPL业务数据时配置该参数，配置后系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改CAPL业务数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改CAPL业务数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名    | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改CAPL业务数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modcaplimsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。                                          |
| ISDNFILE    | MSISDN文件名  | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改CAPL业务数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modcaplisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。                                    |
| CAPLPROV    | 是否提供CAPL业务 | 用于标识提供还是撤销CAPL业务。 取值范围：TRUE：提供FALSE：撤销 默认值：无。                                                                                                                                                                                      |
| CAPL        | CAPL业务级别   | 仅当本命令中的“是否提供CAPL业务”参数为“TRUE”时该参数有效。用于标识所要修改的CAPL业务数据的CAPL业务级别。HLR/HSS在某用户签约CAPL业务后，通过下发用户数据消息将业务级别下发给MSC/VLR，MSC/VLR通知BSS基于业务级别给用户分配信道。 取值范围：1～15，数字越小优先级越高。 默认值：无。                                                                |

## 使用实例

1. 为“IMSI”为“460000009123456”的用户提供CAPL业务，指定“CAPL业务级别”为“2”：

   ```
   MOD CAPL: IMSI="460000009123456", CAPLPROV=TRUE, CAPL=2;
   ```
2. 为3个连续MSISDN号码用户提供CAPL业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，指定“CAPL业务级别”为“5”：

   ```
   MOD CAPL: ISDN="13310911001", RECORDCOUNT=3, CAPLPROV=TRUE, CAPL=5;
   ```
3. 为3个非连续MSISDN号码用户提供CAPL业务，这3个MSISDN号码分别为“13310900001”、“13310900010”、“13310900100”，已保存在“MSISDN文件名”为“modcapl01.txt”的文件中，并通过文件管理功能上传到了指定目录，指定“CAPL业务级别”为“4”：

   ```
   MOD CAPL: ISDNFILE="modcapl01.txt", CAPLPROV=TRUE, CAPL=4;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                             | 处理建议                                                                                                              |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                          |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                       |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                 | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1010 | 参数冲突       | 原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI号码”或“MSISDN号码”对应的用户未开户。                                       | 检查用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                            | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                      |
