# 设置补充业务限制号段(SET ODBSSRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于添加和删除补充业务限制号段。

## 注意事项

- 如果OPTYPE=ADD，参数BEGINRANGE和ENDRANGE是必选。
- 如果OPTYPE=DELETE，参数BEGINRANGE是必选，且必须与ADD时的某一个BEGINRANGE完全相同。
- 如果OPTYPE=DELETEALL，其它的参数不能出现。
- 系统中增加的补充业务限制号段记录数不能超过1000条。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                     |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------|
| OPTYPE     | 操作类型   | 操作类型。取值如下： ADD：增加一条补充业务限制号段。 DELETE：删除一条已有补充业务限制号段。 DELETEALL：删除所有补充业务限制号段。                              |
| BEGINRANGE | 限制起始号码 | 仅当本命令中的“操作类型”参数为“ADD”或“DELETE”时该参数有效。用于标识补充业务限制起始号码。 取值范围：15位以内的十进制数字。 默认值：无。 说明：该参数的长度必须与“限制结束号码”的长度相同。 |
| ENDRANGE   | 限制结束号码 | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识补充业务限制结束号码。 取值范围：15位以内的十进制数字。 默认值：无。 说明：该参数的长度必须与“限制起始号码”的长度相同。          |

## 使用实例

设置前转号段限制表，命令如下:

SET ODBSSRANGE: OPTYPE=ADD, BEGINRANGE="460000000000001", ENDRANGE="460000000000009";

SET ODBSSRANGE: OPTYPE=DELETE, BEGINRANGE="460000000000001";

SET ODBSSRANGE: OPTYPE=DELETEALL;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                   | 处理建议                                                                                                                                                               |
|:--------|:--------|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 增加的补充业务限制号段记录数超过1000条。 | 根据实际情况，如需增加补充业务限制号段，处理步骤如下：执行LST ODBSSRANGE命令，查询已存在的补充业务限制号段记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的补充业务限制号段记录。执行该命令，将“操作类型”设置为“ADD”增加补充业务限制号段，确保增加的补充业务限制号段记录数在规定范围之内。 |
