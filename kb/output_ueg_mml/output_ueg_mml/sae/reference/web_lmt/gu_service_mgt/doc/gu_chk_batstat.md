# 查询批操作状态(CHK BATSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询批操作任务的状态。

- 若需要查询所有批操作任务，请不要输入任何参数。
- 若需要查询某个批操作任务的状态，请输入“批操作任务ID”或其他参数或这些参数的组合。

## 注意事项

“起始时间”和“结束时间”参数必须同时指定或同时不指定。当这两个参数同时指定时，“结束时间”的取值必须大于“起始时间”的取值。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASKID    | 批操作任务ID  | 用于标识批操作任务号。 取值范围：1～4294967295 默认值：无。 说明：如果该命令的“是否提供详细信息”参数为“TRUE”，此参数必须输入。                                                                                                                                                                                                                                                                                          |
| OPNAME    | 操作员名称    | 用于标识操作员的名称。 取值范围：1～32位字母或十进制数字组成的字符串，并且首字符必须为字母。 默认值：无。                                                                                                                                                                                                                                                                                                             |
| BEGINTIME | 起始时间     | 用于标识批操作任务执行的起始时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 配置原则：该参数与“批操作任务ID”参数不能同时存在。                                                                                                                                                                                                                                                                             |
| ENDTIME   | 结束时间     | 用于标识批操作任务执行的结束时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 配置原则：该参数与“批操作任务ID”参数不能同时存在。                                                                                                                                                                                                                                                                             |
| STATE     | 执行状态     | 用于标识需要查询哪种状态的批操作任务。 取值范围：READY：准备RUNNING：运行COMPLETED：完成ABORTED：中止PENDING：等待 UPLDFAIL：上传文件失败，导入批操作结果文件从负载PGW上传到主备PGW失败。DWLDING：下载文件中，导入文件正在从主备PGW下载到负载PGW中。DWLDFAIL：下载文件失败，导入文件从主备PGW下载到负载PGW失败。CFGFAIL：执行导入批操作BAT IMP命令时，参数“配置文件名”对应文件内容不合法。 默认值：无。 配置原则：该参数与“批操作任务ID”参数不能同时存在。                                                                                     |
| DETAIL    | 是否提供详细信息 | 用于标识执行该命令是否返回批操作的详细信息。 取值范围：TRUE：提供详细信息FALSE：不提供详细信息 默认值：无。 说明：该参数取值为“TRUE”时，“批操作任务ID”参数必须同时指定。                                                                                                                                                                                                                                                                     |
| SAVEAS    | 保存文件名    | 用于标识保存查询结果的文件名。 取值范围：1～20位字符串，可由字母、数字或字符组成，字符不能包含“>”、“/”、“?”、“\”、“:”、“*”、“"”、“<”、“|”、“,”、“;”、“=”和“'”。 默认值：无。 说明： 如果输入“保存文件名”参数，命令执行结果保存在文件内，不在WebUI显示命令执行结果。操作员可以通过WebUI的文件下载功能获取该文件。 如果不输入“保存文件名”参数，并且显示的记录超过250条，则在WebUI显示前250条记录信息。 如果不输入“保存文件名”参数，并且显示的记录不超过250条，则在WebUI显示所有记录信息。 当“是否提供详细信息”参数为“FALSE”时该参数不能存在。如果输入“保存文件名”和“批操作任务ID”参数，需同时输入“是否提供详细信息”为“TRUE”。 |
| TASKTYPE  | 查询任务类型   | 用于指定查询进度的任务类型。 取值范围： IMP：导入批操作任务 BAT：普通批操作任务 默认值：无。                                                                                                                                                                                                                                                                                                                 |

## 使用实例

1. 查询所有批操作任务，不输入任何参数：

   ```
   CHK BATSTAT:;
   ```

   ```
   %%CHK BATSTAT:;%%
   RETCODE = 0 操作成功

   TASK ID = 536871010
   TASK ID = 536871011
   TASK ID = 536871012
   TASK ID = 536871106

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询“批操作任务ID”为“536871106”的批操作任务状态，不保存查询结果：

   ```
   CHK BATSTAT: TASKID=536871106, DETAIL=FALSE;
   ```

   ```
   %%CHK BATSTAT: TASKID=536871106, DETAIL=FALSE;%%
   RETCODE = 0 操作成功

   <TASK ID>   <HLR INDEX>   <OPERATOR NAME>                   <START TIME>         <END TIME>           <STATUS>   <TOTAL>  <SUCCESS>  <DB SUCCEED BUT NETWORK FAIL>  <MML CMD>
   536871106   1             admin                             2013-07-31 09:57:57  2013-07-31 09:57:58  COMPLETED  3        3          0                              /*HWHandle=139*/BAT: FILE="file.txt";

   Total count = 1

   There is together 1 report

   ---    END
   ```
3. 查询“批操作任务ID”为“536871106”的批操作任务的详细状态，保存查询结果：
   1. 执行**CHK BATSTAT**命令。

      ```
      CHK BATSTAT: TASKID=536871106, DETAIL=TRUE, SAVEAS="file1.txt";
      ```
   2. 通过MML操作界面的“文件管理器”下载包含批操作执行结果的文件。文件内容如下：

      ```
      -------------------------------------------------Glossary Information---------------------------------------------------------
      <TASKID>    <OPERATOR NAME>   <START TIME>          <END TIME>            <STATUS  TOTAL>            <SUCCEESS>            <DB SUCCEED BUT NETWORK FAIL> <MML CMD>                                                   

      536871106   admin             2013-07-31 09:57:57   2013-07-31 09:57:58   COMPLETED 3                3                     0                             /*HWHandle=139*/BAT: FILE="file.txt";                      

      ------------------------------------------------Success/Error/Status Report --------------------------------------------------
      <TIME:2013-07-31 09:57:57> <MML_CMD:LST HLRSN:; > <RESULT:  Retcode = 0 SUCCESS0001:Operation is successful >
      <TIME:2013-07-31 09:57:57> <MML_CMD:LST CNTRCD:; > <RESULT:  Retcode = 0 SUCCESS0001:Operation is successful >
      <TIME:2013-07-31 09:57:58> <MML_CMD:LST MAPSERV:; > <RESULT:  Retcode = 0 SUCCESS0001:Operation is successful >
      <TIME:2013-07-31 09:57:58BATCH_COMPLETED>END
      ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**CHK BATSTAT**

命令的参数说明。表1列出的是未包含在

**CHK BATSTAT**

命令参数说明中的输出项。

| 输出项名称                       | 输出项解释                                   |
|:----------------------------|:----------------------------------------|
| HLR INDEX                   | 表示操作员当前登录的系统HLRSN。                      |
| DB SUCCEED BUT NETWORK FAIL | 表示该批操作任务中存在的命令执行结果是数据库执行成功但网络更新失败的命令个数。 |
| MML CMD                     | 表示该批操作任务是执行哪个批操作命令产生的。                  |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。
