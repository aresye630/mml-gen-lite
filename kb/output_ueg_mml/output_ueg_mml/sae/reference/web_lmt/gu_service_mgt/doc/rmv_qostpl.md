# 删除QoS模板(RMV QOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条QoS模板数据记录。

## 注意事项

若待删除的QoS模板已经通过**ADD SUB**、**MOD OPTGPRS**、**MOD PSSER**或**MOD EPSSER**等命令为用户签约，则不能删除该模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识QoS模板数据记录的关键字段之一，用于指定在哪个HLR上删除QoS模板数据记录，操作员可以使用LST HLRSN命令查询获得。  |
| TPLID  | 模板ID   | 标识QoS模板数据记录的关键字段之一，用于指定需要删除哪个模板的QoS模板数据记录，操作员可以使用LST QOSTPL命令查询获得。 |

## 使用实例

删除3号QoS模板。命令如下：

```
RMV QOSTPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                            | 处理建议                                                                                                                             |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”未定义或者“模板ID”未定义。                                                                                                         | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST QOSTPL命令查询已定义的“模板ID”。                                          |
| ERR3005 | 模板已经被使用 | 可能原因为如下之一：待删除的QoS模板已经通过ADD SUB、MOD OPTGPRS、MOD PSSER或MOD EPSSER等命令为用户签约。待删除的QoS模板已经通过ADD REPQOSID命令的“替换的QoS模板ID”参数设置了QoS模板替换配置。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD OPTGPRS、MOD PSSER或MOD EPSSER命令给用户去签约该模板，并使用RMV REPQOSID命令删除该QoS模板相关的替换配置，然后才能执行RMV QOSTPL命令删除。 |
