# 修改闭锁短消息业务(MOD PREMSMS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改用户的短消息闭锁业务。当用户签约了闭锁某种类型的短消息，该类型的短消息将不会再发送给该用户。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                            |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改短消息闭锁业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                        |
| ISDN        | ISDN      | 用于标识需要修改短消息闭锁业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                      |
| RECORDCOUNT | 用户个数      | 用于标识需要修改短消息闭锁业务的用户数目。 当需要为连续号码的多个用户修改短消息闭锁业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改短消息闭锁业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改短消息闭锁业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改短消息闭锁业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpremsms.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                            |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改M短消息闭锁业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpremsms.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                     |
| ODBPREMSMS  | 是否闭锁付费短消息 | 是否闭锁付费短消息。 取值范围： TRUE：提供。FALSE：不提供。 默认值：FALSE。                                                                                                                                                                                  |
| ODBADULTSMS | 是否闭锁成人短消息 | 是否闭锁成人短消息。 取值范围： TRUE：提供。FALSE：不提供。 默认值：FALSE。                                                                                                                                                                                  |

## 使用实例

1. 为MSISDN号码为“13310911001”的用户签约PREMSMS和ADULTSMS闭锁：

   ```
   MOD PREMSMS: IMSI="13310911001", ODBPREMSMS=TRUE, ODBADULTSMS=TRUE;
   ```
2. 为3个连续号码的用户签约PREMSMS和ADULTSMS闭锁，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”：

   ```
   MOD PREMSMS: IMSI="13310911001", RECORDCOUNT=3, ODBPREMSMS=TRUE, ODBADULTSMS=TRUE;
   ```
3. 为3个非连续号码的用户签约PREMSMS和ADULTSMS闭锁，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modpremsms.txt”的文件中，并通过文件管理功能上传到指定目录：

   ```
   MOD PREMSMS: ISDNFILE="modpremsms.txt", ODBPREMSMS=TRUE, ODBADULTSMS=TRUE;
   ```
