# 增加IMSI号段属性(ADD IWFIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加某个IMSI号段的工作模式和其他属性。

该命令的使用场景：为了避免5G部署初期对已有的4G网络稳定性造成影响，通过本命令可以为不同的IMSI号段分别配置IWF、UDM或者UDM和HSS融合模式的工作模式属性，减少对用户使用现有业务的影响，灵活的配置工作模式方便客户选择，使得用户5G业务可以按需部署，提升用户体验。

**说明** 

1. 局向流控和局向话统是基于对端主机名称（通过本命令中“分区ID”参数可以配置IMSI号段和对端HSS的对应关系）进行控制和统计。
2. 实际号段配置：如果本命令配置的IMSI号段是实际号段，则参数“分区ID”（该参数由**ADD SPRTINFO**命令定义）标识的对端主机名配置为实际对端HSS主机名，局向流控和局向话统按照实际的对端主机名进行控制和统计。
3. 大号段配置：如果本命令配置的IMSI号段是大号段，则参数“分区ID”（该参数由**ADD SPRTINFO**命令定义）标识的对端主机名配置为虚拟的HSS主机名，局向流控和局向话统按照虚拟的HSS主机名进行控制和统计，实际控制大号段范围内的所有HSS局点。
4. 建议使用实际号段配置。

## 注意事项

最多增加50000条IWFIMSI号段属性数据。

## 使用实例

1. 配置UTA业务时，如果根据组网方案配置某IMSI号段为UDM模式时，则添加该IMSI号段属性进行配置。例如“IMSI前缀”为“46000”，“工作模式”为“UDM”，“分区ID”为“2”，“鉴权协议类型”为“MAP”，“主叫子系统”为“149”，“被叫GT编号计划”为“IMSI”，“请求节点类型”为“16”，“模拟MME注册消息中携带的默认PLMNID”为“12345”，“是否支持5GS 类型的RAT-Type”为“TRUE”，“OMU HLR序列号”为“1”，“模拟Cx口LIR消息是否携带目的主机名”为“TRUE”，“模拟MME的首次注册消息是否携带目的主机名”为“TRUE”，“模拟MME主动向HSS发起的消息是否使用注册响应记录的主机名和域名”为“TRUE”：

   ```
   ADD IWFIMSI: IMSIPRE="46000", MODE=UDM, PID=2, AUTHTYPE=MAP, SSN=149, NUMPLAN=IMSI, NODETYPE=16, PLMNID="12345", NGSRATSUPP=TRUE, OMUHLRSN=1, LIRHOSTFLAG=TRUE, ULRHOSTFLAG=TRUE, USERECOREDHOST=TRUE;
   ```
2. 配置UTA业务时，如果根据组网方案配置某IMSI号段为IWF模式时，则添加该IMSI号段属性进行配置。例如“IMSI前缀”为“46001”，“工作模式”为“IWF”，“分区ID”为“2”，“鉴权协议类型”为“MAP”，“主叫子系统”为“149”，“被叫GT编号计划”为“IMSI”，“请求节点类型”为“16”，“模拟MME注册消息中携带的默认PLMNID”为“12345”，“5G用户模板”为“1”，“业务列表”为“ODBPOS&APN”，“虚拟HLR序列号”为“1”，“是否支持5GS 类型的RAT-Type”为“TRUE”，“OMU HLR序列号”为“1”，“模拟Cx口LIR消息是否携带目的主机名”为“TRUE”，“模拟MME的首次注册消息是否携带目的主机名”为“TRUE”，“模拟MME主动向HSS发起的消息是否使用注册响应记录的主机名和域名”为“TRUE”：

   ```
   ADD IWFIMSI: IMSIPRE="46001", MODE=IWF, PID=2, AUTHTYPE=MAP, SSN=149, NUMPLAN=IMSI, NODETYPE=16, PLMNID="12345", NGSUSERTPLID=1, SERVLIST=5, HLRSN=1, NGSRATSUPP=TRUE, OMUHLRSN=1, LIRHOSTFLAG=TRUE, ULRHOSTFLAG=TRUE, USERECOREDHOST=TRUE;
   ```
3. 配置UTA业务时，如果根据组网方案配置某IMSI号段为BlackList模式时，则添加该IMSI号段属性进行配置。例如“IMSI前缀”为“46002”，“工作模式”为“BlackList”：

   ```
   ADD IWFIMSI: IMSIPRE="46002", MODE=BlackList;
   ```
4. 配置UTA业务时，如果根据组网方案配置某IMSI号段为AuthOnly模式时，则添加该IMSI号段属性进行配置。例如“IMSI前缀”为“46003”，“工作模式”为“AuthOnly”，“分区ID”为“2”，“鉴权协议类型”为“MAP”，“请求节点类型”为“16”，“主叫子系统”为“149”，“被叫GT编号计划”为“IMSI”，“OMU HLR序列号”为“1”：

   ```
   ADD IWFIMSI: IMSIPRE="46003", MODE=AuthOnly, PID=2, AUTHTYPE=MAP, SSN=149, NUMPLAN=IMSI, NODETYPE=16, OMUHLRSN=1;
   ```
5. 配置UTA业务时，如果根据组网方案配置某IMSI号段为SQNSYNC模式时，则添加该IMSI号段属性进行配置。例如“IMSI前缀”为“46004”，“工作模式”为“SQNSYNC”，“分区ID”为“2”，“鉴权协议类型”为“MAP”，“主叫子系统”为“149”，“被叫GT编号计划”为“IMSI”，“请求节点类型”为“16”，“OMU HLR序列号”为“1”：

   ```
   ADD IWFIMSI: IMSIPRE="46004", MODE=SQNSYNC, PID=2, AUTHTYPE=MAP, SSN=149, NUMPLAN=IMSI, NODETYPE=16, OMUHLRSN=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
