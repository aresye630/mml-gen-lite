# 增加OP(ADD HOP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中增加一个鉴权数据OP的数据记录，OP（Operator Variant Algorithm Configuration Field）是鉴权计算的一个输入参数。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“OP值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“OP值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| OPSNO   | OP索引号  | 用于定义鉴权数据OP的序号，以方便对OP进行查询和引用，配置原则是不能与已有的OP索引号重复。 取值范围： 1～128 缺省值： 无                                                                       |
| OPVALUE | OP值    | 用于定义鉴权数据OP的值，OP（Operator Variant Algorithm Configuration Field）即运营商可变算法配置域，是鉴权计算的一个输入参数。要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无 |

## 使用实例

增加OP。OP索引号：1，OP值：1234567890abcdefABCDEF1234567890。

```
ADD HOP: OPSNO=1, OPVALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                                | 原因分析                                                          | 处理建议                                                                      |
|----------:|:-------------------------------------|:--------------------------------------------------------------|:--------------------------------------------------------------------------|
| 900003515 | 已启用随机密钥功能，请先执行SET RANDOMKEY命令生成随机密钥。 | 已启用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，执行SET RANDOMKEY命令生成随机密钥，并设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。 |
| 900003523 | 密钥丢失                                 | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                               |
