# 删除SCP地址模板(RMV SCPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一个SCP（Service Control Point）地址模板。

## 注意事项

当执行**RMV SCPTPL**命令删除用户已签约的SCP模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该SCP板不能被删除。如果要删除该SCP模板，必须先执行**MOD OCSITPL**或者**MOD TCSITPL**命令给用户去签约相关的O-CSI和T-CSI模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一个SCP地址模板的关键字段之一，用于指定需要在哪个HLR中删除SCP地址模板，操作员可以使用LST HLRSN命令查询获得。 |
| TPLID  | 模板ID   | 标识一个SCP地址模板的关键字段之一，用于指定需要删除哪一个SCP地址模板，操作员可以使用LST SCPTPL命令查询获得。    |

## 使用实例

删除SCP地址模板，“HLR序列号”为“1”，“模板ID”为“1”。命令如下：

```
RMV SCPTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                           | 处理建议                                                                        |
|:--------|:----------|:-------------------------------|:----------------------------------------------------------------------------|
| ERR3003 | 模板未定义     | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。 | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST SCPTPL命令查询。 |
| ERR3097 | HLR序列号未定义 | “HLR序列号”未定义。                   | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                           |
