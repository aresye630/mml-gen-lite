# 查询IMSI(LST IMSI)

## 命令功能

该命令用于查询用户的IMSI号码：

- 如果需要查询单个用户的IMSI号码信息，请输入“MSISDN”或“备选IMSI”参数。
- 如果需要查询多个连续用户的IMSI号码信息，请输入“MSISDN”（或“备选IMSI”）和“用户个数”参数。
- 如果需要查询多个不连续用户的IMSI号码信息，请输入“MSISDN文件名”或“备选IMSI文件名”参数。

## 注意事项

- “MSISDN”、“备选IMSI”、“MSISDN文件名”和“备选IMSI文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“MSISDN文件名”或“备选IMSI文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ISDN        | MSISDN    | 用于指示系统按照哪个“MSISDN号码”来查询用户正在使用的IMSI号码。 取值范围：1～15位十进制数字组成的字符串。                                                                                                                                                    |
| IMSI        | 备选IMSI    | 用于指示系统按照哪个“备选IMSI号码”来查询用户正在使用的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 用于指示系统需要查询IMSI的用户个数。 当需要查询连续号码的IMSI时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，查询出连续号码的多个用户的IMSI信息。 取值范围：1～10000 说明： 该参数用于查询连续号码的多个用户的IMSI数据，当只有一个用户时，该参数不必配置。当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| ISDNFILE    | MSISDN文件名 | 用于指示系统按照哪个“MSISDN批操作文件”来查询用户正在使用的IMSI号码。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstimsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。                    |
| IMSIFILE    | 备选IMSI文件名 | 用于指示系统按照哪个“IMSIFILE批操作文件”来查询用户正在使用的IMSI号码。 备选IMSI批操作文件包含多个不连续的用户的备选IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstimsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。                  |

## 使用实例

1. 查询“MSISDN”为“13310911001”的用户的IMSI号码信息：

   ```
   LST IMSI: ISDN="13310911001";
   ```

   ```
   %%LST IMSI: ISDN="13310911001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 46000876543210
                             ISDN = 2013521
                            IMSI2 = 45000001
                            IMSI3 = 45000002

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询第一个“MSISDN”为“13310911001”的连续3个用户的IMSI号码信息：

   ```
   LST IMSI: ISDN="13310911001", RECORDCOUNT=3;
   ```

   ```
   %%LST IMSI: ISDN="13310911001", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：25. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“MSISDN文件名”为“lstimsi.txt”的用户的IMSI号码信息：

   ```
   LST IMSI: IMSIFILE="lstimsi.txt";
   ```

   ```
   %%LST IMSI: IMSIFILE="lstimsi.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435482. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。表1列出的是未包含在本命令参数含义中的输出项。

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| 批操作ID   | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| ERR1005 | 文件未找到      | “MSISDN文件名”或“备选IMSI文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                       | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                            |

| ERR1025 | 批操作文件中格式非法 | 参数“MSISDN文件名”或“备选IMSI文件名”对应的批操作文件格式不正确。                                                                  | 请根据ISDNFILE文件格式和IMSIFILE文件格式，重新确定对应的批操作文件格式。                                                                                  |
