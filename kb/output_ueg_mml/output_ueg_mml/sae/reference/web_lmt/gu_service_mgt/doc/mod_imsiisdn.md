# 修改IMSI和ISDN绑定关系(MOD IMSIISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于给多卡多号用户签约或去签约辅IMSI和辅ISDN的绑定关系。

## 注意事项

- 该用户在签约辅IMSI和辅ISDN的绑定关系时必须确保已开户。
- 一个辅IMSI只能绑定一个辅ISDN，一个辅ISDN可以绑定多个辅IMSI。
- 参数“IMSI”和“MSISDN”必须同时存在，且不能与参数“IMSI/MSISDN文件名”同时配置。
- 多卡多号业务不能与特殊一卡多号业务同时签约。

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                                                                                                                                 |
|:-------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI           | 用于标识待签约或待修改用户的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                 |
| ISDN   | MSISDN         | 用于标识待签约或待修改用户的MSISDN号码。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                               |
| FILE   | IMSI/MSISDN文件名 | 用于标识待签约或待修改用户的IMSI/MSISDN批操作文件。 IMSI/MSISDN批操作文件包含多个不连续的待签约或待修改用户的IMSI号码和MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimsiisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见多卡多号批操作文件格式。 取值范围：1～16位的字母或十进制数字组成的字符串。 默认值：无。 |
| PROV   | 是否签约绑定关系       | 用于标识是否给用户提供签约辅IMSI和辅ISDN的绑定关系。 取值范围： TRUE：提供。FALSE：不提供。 默认值：无。                                                                                                                                                       |

## 使用实例

1. 为用户签约辅“IMSI”号码为“2014521”与辅“MSISDN”为“2014521”的绑定关系。

   ```
   MOD IMSIISDN: IMSI="2013521", ISDN="2014521", PROV=TRUE;
   ```
2. 为用户签约“IMSI/MSISDN文件名”为“modimsiisdn.xml”的绑定关系。

   ```
   MOD IMSIISDN: FILE="modimsiisdn.xml", PROV=TRUE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR3247 | 用户类型不匹配            | 输入的辅“IMSI”号码不是平等卡用户类型。                               | 请重新输入平等卡用户类型的“IMSI”号码，确保其是平等卡用户类型。                                                                                              |
| ERR3251 | 不支持处理主MSISDN       | 输入的“MSISDN”号码是用户的主“MSISDN”号码。                        | 请重新输入“MSISDN”号码，确保其不是用户的主“MSISDN”号码。                                                                                            |
| ERR3249 | MSISDN号码没有提供       | 输入的辅“MSISDN”号码没有定义。                                  | 请重新输入“MSISDN”号码，确保其已被定义。                                                                                                        |

| ERR1010 | 参数冲突               | 同时输入了参数“IMSI/MSISDN文件名”和参数“IMSI”、“MSISDN”其中之一或两者的组合。 | 请重新输入参数“IMSI/MSISDN文件名”或参数“IMSI”、“MSISDN”，确保参数“IMSI/MSISDN文件名”不能与“IMSI”或“MSISDN”同时配置。                                           |
| ERR4063 | 业务冲突，IMSI和MSISDN相同 | 输入的辅“IMSI”号码和辅“MSISDN”号码相同，且二者至少有一个为M2M用户。           | 请使用LST SUB命令查看辅IMSI和辅MSISDN的主号码对应的所有辅IMSI和辅MSISDN，重新输入参数，确保输入的M2M用户的辅“IMSI”号码和辅“MSISDN”不相同。 可以使用LST USERCATEGORY命令查看用户是否为M2M用户。 |
