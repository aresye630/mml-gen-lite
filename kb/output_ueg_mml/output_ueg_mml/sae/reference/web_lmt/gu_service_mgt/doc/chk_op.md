# 校验OP(CHK OP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来校验OP值。

## 注意事项

如果CMCC鉴权增强开关打开，该命令不允许执行。可通过**LST MAPCONF**查看CMCC鉴权增强开关是否打开。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                           |
|:--------|:-------|:-----------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。   |
| OPSNO   | OP序列号  | 用于标识一个鉴权数据OP的序号。 取值范围：1～16777215 默认值：无。        |
| OPVALUE | OP值    | 用于标识一个32位鉴权数据OP的值。 取值范围：32位十六进制数字组成的字符串 默认值：无。 |

## 使用实例

校验OP，序列号为1，OP数据为12345678901234561234567890123456。命令如下：

```
CHK OP: HLRSN=1, OPSNO=1, OPVALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                          | 处理建议        |
|:--------|:--------|:--------------------------------------------------------------|:------------|
| ERR4133 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
