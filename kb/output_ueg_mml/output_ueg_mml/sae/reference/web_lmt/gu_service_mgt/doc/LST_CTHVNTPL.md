# 以格式2查询IMS漫游模板(LST CTHVNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询IMS漫游模板数据。

使用场景限于运营商对返回报文有特殊适配需求。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------|
| TPLID  | 拜访网络模板ID | 可选必选说明：必选参数。 参数含义：用于指示系统按照哪个模板ID来查询IMS漫游模板信息。 配置原则：该参数必须先由SET HVNTPLID命令定义，然后才能在此处引用。 |

## 使用实例

查询“拜访网络模板ID”为“1”的IMS漫游模板信息，以特定的数据格式返回：

```
LST CTHVNTPL: TPLID=1;
```

```
%%LST CTHVNTPL: TPLID=1;%%
RETCODE = 0 SUCCESS0001:Operation is successful

                         TPLID = 1
                       TPLNAME = VN TPL
                   DEFAULTRULE = 0
VNLIST
                            VN = hss.huawei.com
                     MATCHTYPE = 1
                        VNTYPE = 0

Total count = 5

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HVNTPLID**命令参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释       | 原因分析                                 | 处理建议                                                                       |
|----------:|:------------|:-------------------------------------|:---------------------------------------------------------------------------|
| 900003245 | 拜访网络模板ID不存在 | “拜访网络模板ID”输入错误，实际输入的参数“拜访网络模板ID”未定义。 | 如果输入的“拜访网络模板ID”确定正确，说明实际输入的参数“拜访网络模板ID”未定义，请先通过ADD HVNTPL命令定义“拜访网络地址模板ID”。 |
