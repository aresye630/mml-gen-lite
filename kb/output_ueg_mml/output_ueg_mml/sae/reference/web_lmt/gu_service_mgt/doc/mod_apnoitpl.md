# 修改APN运营商标识符模板(MOD APNOITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该操作会修改APN运营商标识符模板数据，是否继续？

该命令用于修改用户签约的APN运营商标识符模板信息，通过修改此模板信息修改用户签约的APNOI数据，修改后的信息将在用户下一次进行位置更新后生效。在该命令中，系统通过以下关键参数的组合来唯一标识一条APN运营商标识符模板信息记录：

- “HLR序列号”
- “模板ID”

## 注意事项

“模板名”和“APN运营商标识符”两个参数至少存在一个。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                        |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号    | 标识APN运营商标识符模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的APN运营商标识符模板信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                           |
| TPLID   | 模板ID      | 标识APN运营商标识符模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个模板ID的APN运营商标识符模板信息数据记录的参数进行修改，该参数必须先由LST APNOITPL命令进行查询。                        |
| TPLNAME | 模板名       | 用于标识待修改的模板名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                              |
| APNOI   | APN运营商标识符 | 用于标识待修改的APN运营商标识符。 取值范围：1～63个字母或十进制数字组成的相对域名格式字符串。 默认值：无。 说明：后面带有“.”的就是绝对域名，其他都是相对域名，例如：huawei.com.就是绝对域名，huawei.com就是相对域名。 |

## 使用实例

修改已签约的APN运营商标识符模板信息，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“test”，“APN运营商标识符”为“bcd.com”：

```
MOD APNOITPL: HLRSN=1, TPLID=1, TPLNAME="test", APNOI="bcd.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                       |
|:--------|:--------|:---------------------------------|:-------------------------------------------|
| ERR1009 | 参数丢失    | 用户没有输入“模板名”和“APN运营商标识符”参数中的任何一个。 | 重新输入参数，输入完成后确保“模板名”和“APN运营商标识符”两个参数至少存在一个。 |
| ERR3003 | 模板未定义   | 用户输入的“HLR序列号”和“模板ID”对应的模板信息未添加。  | 执行LST APNOITPL命令查询已添加的模板信息，根据查询结果重新输入参数。   |
