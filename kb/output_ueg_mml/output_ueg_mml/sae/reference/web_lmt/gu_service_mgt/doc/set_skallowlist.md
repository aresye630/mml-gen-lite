# 配置强制允许SK列表(SET SKALLOWLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR上增加或删除TCSI或ETCSI的SK（Service Key）列表。

业务处理中需要根据SK列表来决定是否下发TCSI或ETCSI，如果用户签约的SK在SK列表中，HLR应该忽略VLR的状态，下发TCSI或者ETCSI。

## 注意事项

系统中增加的SK数据记录数不能超过1000条。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                      |
|:---------|:-----------|:--------------------------------------------------------------------------|
| HLRSN    | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                              |
| PROV     | 是否提供强制允许SK | 用于控制给强制允许SK列表模板增加还是删除SK数据。 取值范围： TRUE：增加FALSE：删除 默认值：无。                   |
| SKTYPE   | 业务键类型      | 用于标识配置的业务键类型。 取值范围： TCSIETCSI 默认值：无。                                      |
| TCSI_SK  | TCSI的业务键   | 仅当本命令中的“业务键类型”参数为“TCSI”时该参数有效，用于标识强制允许的TCSI的业务键。 取值范围：0～2147483647 默认值：无。 |
| ETCSI_SK | ETCSI的业务键  | 仅当本命令中的“业务键类型”参数为“ETCSI”时该参数有效，用于标识强制允许的ETCSI的业务键。 取值范围：1～999 默认值：无。      |

## 使用实例

1. 设置强制允许SK列表，其中“HLR序列号”为“1”，“是否提供强制允许SK”为“TRUE”，“业务键类型”为“TCSI”，“TCSI的业务键”为“1”，脚本如下：

   `SET SKALLOWLIST: HLRSN=1, PROV=TRUE, SKTYPE=TCSI, TCSI_SK=1;`
2. 删除强制允许SK列表，其中“HLR序列号”为“1”，“是否提供强制允许SK”为“FALSE”，“业务键类型”为“TCSI”，“TCSI的业务键”为“1”，脚本如下：

   `SET SKALLOWLIST: HLRSN=1, PROV=FALSE, SKTYPE=TCSI, TCSI_SK=1;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                    | 处理建议                                                                                                   |
|:--------|:--------|:------------------------|:-------------------------------------------------------------------------------------------------------|
| ERR3004 | 模板已存在   | 重复为同一个“HLR序列号”添加相同数据记录。 | 根据实际情况，重新输入参数，确保输入的“HLR序列号”和系统中已存在的不重复。可执行LST SKALLOWLIST命令查询系统中已存在的数据记录。                              |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。            | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                      |
| ERR3047 | 超过最大限制  | 增加的SK数据记录数超过1000条。      | 根据实际情况，如需增加SK数据，处理步骤如下：执行LST SKALLOWLIST命令，查询已存在的SK数据。执行该命令删除不必要的SK数据。执行该命令增加SK数据，确保增加的SK数据记录数在规定范围之内。 |
