# 销户(RMV SUB)

## 命令功能

该命令用于为单个用户或多个用户进行销户。

销户后，MSISDN号和IMSI号码的对应关系解除，系统会自动向VLR、Gn/Gp SGSN、MME或S4 SGSN下发Cancel Location消息来清除该用户的相关数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 软参“NPSWITCH（NP 开关）”取值为“0”或“2”时，执行**RMV SUB**命令，若用户不存在，则返回错误码ERR3001；软参“NPSWITCH（NP 开关）”取值为“1”时，执行**RMV SUB**命令，若用户不存在，则返回错误码ERR3007。
- 当由**SET MAPCONF**的“RMV SUB时检查用户是否签约VoLTE”取值为“TRUE”时，执行该命令会检查当前销户的用户是否为VoLTE用户。销户的用户是VoLTE用户时，需要先执行**RMV HHSSSUB**命令删除该用户的IMS签约数据，再执行**RMV SUB**和**RMV KI**命令销户。否则系统将返回错误码ERR4156。
- 执行该命令前请务必确认指定的用户为本HLR/HSS中已不再商用或测试的用户。否则执行不当将正常的用户销户，会导致正常用户无法使用业务，且销户后用户无法恢复。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                   |
|:------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI          | 用于标识待销户用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                        |
| ISDN        | MSISDN        | 用于标识待销户用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                      |
| RECORDCOUNT | 用户个数          | 用于标识待销户用户的数目。 当需要为连续号码的多个用户销户时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行销户。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行销户，当只有一个用户时，该参数不必配置。当一次销户的用户个数很多时，对系统性能无影响，但销户的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名       | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待销户用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                                |
| ISDNFILE    | MSISDN文件名     | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待销户用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                          |
| RMVKI       | 是否删除KI        | 用于标识在销户的同时，是否删除此用户的KI（Individual Subscriber Authentication Key）。 取值范围： TRUE：删除KI。FALSE：不删除KI。 默认值：FALSE。 说明：销户时可以通过该参数删除KI，也可以使用RMV KI命令删除KI。                                                          |
| SUPCAN      | 是否抑制下发消息给对端网元 | 用于标识UDM是否抑制下发销户时触发的网络侧消息给对端设备。 取值范围： SUPPRESSION：抑制，不下发销户时触发的网络侧消息给对端设备。UNSUPPRESSION：不抑制，下发销户时触发的网络侧消息给对端设备。 默认值：UNSUPPRESSION。 说明：该参数设置为“SUPPRESSION”时，会导致HSS与对端设备存储的数据不一致。                          |

## 使用实例

1. 为MSISDN号码为“13310911001”的单个用户销户：

   ```
   RMV SUB: ISDN="13310911001";
   ```
2. 为3个连续号码的用户销户，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”：

   ```
   RMV SUB: ISDN="13310911001", RECORDCOUNT=3;
   ```
3. 为3个非连续号码的用户销户，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“rmvsub.txt”的文件中，并通过文件管理功能上传到指定目录：

   ```
   RMV SUB: ISDNFILE="rmvsub.txt";
   ```
