# 删除被叫号码分析数据(RMV CALLEDNA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户的CB、ODB等业务失效，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条被叫号码分析数据记录。

## 注意事项

- 删除一条被叫号码分析数据记录，会导致用户登记涉及该被叫号码分析数据的前转号码时失败，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                   |
|:-----------|:-------|:-----------------------------------------------------------------------|
| HLRSN      | HLR序列号 | 标识一条被叫号码分析数据记录的关键字段之一，用于标识需要删除哪一条被叫号码分析数据记录，操作员可以使用LST HLRSN命令查询获得。    |
| CALLPREFIX | 呼叫字冠   | 标识一条被叫号码分析数据记录的关键字段之一，用于标识需要删除哪一条被叫号码分析数据记录，操作员可以使用LST CALLEDNA命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“呼叫字冠”为“09093767622”的数据记录：

```
RMV CALLEDNA: HLRSN=1, CALLPREFIX="09093767622";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                                       |
|:--------|:--------|:---------------------------------|:-----------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“呼叫字冠”对应的被叫号码分析数据记录不存在。 | 使用LST CALLEDNA命令查询后，重新确认要删除哪个“HLR序列号”和“呼叫字冠”对应的被叫号码分析数据记录。 |
