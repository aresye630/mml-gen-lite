# 设置全局软参(SET FUNCCONF)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成某些基本功能不可用，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置全局软参数据。在配置FNR业务或配置NPHLR、NPMSC、鉴权AUC的本局数据时，可以使用该命令配置本局功能属性。

## 注意事项

- “本局功能属性”参数必须输入。
- 当“本局功能属性”参数为“NPHLR”时，“虚拟IMSI”参数必须输入。
- 当“本局功能属性”参数为“HLR”且“是否支持携出用户查询”参数为“TRUE”时，“虚拟IMSI”参数必须输入。
- 该命令中所描述的系统初始设置值，是指操作员通过**LST FUNCCONF**命令查询得出的系统在初始化时的预置参数值。
- 该命令不允许进行批操作。
- NPHLR为中国区规范定义，“本局功能属性”取值为“NPHLR”时的命令配置场景只适用于中国区。

## 参数说明

| 参数标识          | 参数名称                 | 参数说明                                                                                                                                                                                                                                          |
|:--------------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCFUNC       | 本局功能属性               | 用于标识本局功能属性。 取值范围： HLR：归属位置寄存器 NPMSC：号码携带移动业务交换中心 NPHLR：号码携带归属位置寄存器 AUC：鉴权中心 系统初始设置值：HLR                                                                                                                                                       |
| PORTOUTCHK    | 是否支持携出用户查询           | 仅当本命令中的“本局功能属性”参数为“HLR”时该参数有效。用于标识是否支持携出用户查询。携出用户可以通过LST NPDONORSUB命令查询。 取值范围： TRUE：支持 FALSE：不支持 系统初始设置值：FALSE                                                                                                                                |
| SRI4SM_ROUTE  | 短信取路由查询方式            | 仅当本命令中的“本局功能属性”参数为“NPHLR”时该参数有效。用于标识短信取路由的查询方式。 取值范围： IndirectQuery：间接路由 DirectQuery：直接路由 系统初始设置值：IndirectQuery                                                                                                                               |
| SUPP_ROUTLOOP | 支持防循环路由              | 仅当本命令中的“本局功能属性”参数为“NPHLR”时该参数有效。用于标识是否支持防循环路由。 取值范围： TRUE：支持 FALSE：不支持 系统初始设置值：FALSE                                                                                                                                                          |
| PRNMNPERR     | PRN消息返回的错误码          | 仅当本命令中的“本局功能属性”参数为“NPMSC”时该参数有效。用于标识NPMSC在收到PRN（Provide Roaming Number）消息后如果没有查找到用户的携出数据，则在PRN响应消息中返回的错误码。 取值范围： UnexpectedDataValue AbsentSubscriber 系统初始设置值：UnexpectedDataValue                                                             |
| ROAMNATION    | 漫游号码返回属性             | 仅当本命令中的“本局功能属性”参数取值满足以下条件之一时，则该参数有效：“本局功能属性”参数取值为“NPMSC”或“NPHLR”。“本局功能属性”参数取值为“HLR”且“是否支持携出用户查询”参数取值为“TRUE”。 用于标识NPMSC在收到PRN消息后，在PRN响应消息中返回的伪漫游号码的属性。 取值范围： RoamingNation_Normal：国内格式 RoamingNation_Unknown：未知格式 系统初始设置值：RoamingNation_Normal |
| FAKE_IMSI     | 虚拟IMSI               | 仅当本命令中的“本局功能属性”参数取值满足以下条件之一时，则该参数有效：“本局功能属性”参数取值为“NPHLR”。“本局功能属性”参数取值为“HLR”且“是否支持携出用户查询”参数为“TRUE”。 用于标识虚拟IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                |
| MOVE_CONTROL  | 是否允许用户数据跨Partition迁移 | 仅当本命令中的“本局功能属性”参数为“HLR”时该参数有效。用于标识在异地KI操作或补卡业务流程中，如果新卡和旧卡数据不在同一个Partition，是否允许将新卡和旧卡数据迁移到同一个Partition。 取值范围：ALLOW：允许。NOT_ALLOW：不允许。 系统初始设置值：ALLOW                                                                                             |

## 使用实例

配置与NPHLR业务相关的全局数据，“本局功能属性”为“NPHLR”，“漫游号码返回属性”为“RoamingNation\_Normal”，“虚拟IMSI”为“460030913121002”：

```
SET FUNCCONF: LOCFUNC=NPHLR, ROAMNATION=RoamingNation_Normal, FAKE_IMSI="460030913121002";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                         | 处理建议                                                                                                                                        |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的“虚拟IMSI”参数不是6～15位十进制数字组成的字符串。                                                                                             | 根据实际情况，重新输入参数，并满足输入的“虚拟IMSI”参数是6～15位十进制数字组成的字符串。                                                                                            |
| ERR1009 | 参数丢失    | 可能原因如下：“本局功能属性”参数没有输入。当本命令中的“本局功能属性”参数为“NPHLR”时，“虚拟IMSI”参数没有输入。当本命令中的“本局功能属性”参数为“HLR”且“是否支持携出用户查询”参数为“TRUE”时，“虚拟IMSI”参数没有输入。 | 根据实际情况，重新输入参数，并满足如下条件：“本局功能属性”参数必须输入。当本命令中的“本局功能属性”参数为“NPHLR”时，“虚拟IMSI”参数必须输入。当本命令中的“本局功能属性”参数为“HLR”且“是否支持携出用户查询”参数为“TRUE”时，“虚拟IMSI”参数必须输入。 |
