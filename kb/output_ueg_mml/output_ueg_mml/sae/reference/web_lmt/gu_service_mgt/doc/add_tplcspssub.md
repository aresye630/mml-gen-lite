# CSPS模板开户(ADD TPLCSPSSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一个或多个用户采用CSPS模板进行开户，为具有同样CS、PS业务类型的用户业务发放时使用。

CSPS模板使用**ADD SUBTPL**定义，其中定义了用户需要使用的多种CS、PS业务。

## 注意事项

- 开户前，请使用**ADD KI**命令加载KI。
- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- 通过开户批操作文件为不连续号码的M2M用户开户成为MSISDN-Less用户时，由于开户批操作文件必须同时输入IMSI和MSISDN，需在批操作文件中将用户的MSISDN与IMSI保持一致。
- “用户个数”和“IMSI/MSISDN文件名”有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                              |
|:------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号         | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                      |
| IMSI        | IMSI           | 用于标识需要进行模板开户的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                             |
| ISDN        | MSISDN         | 用于标识需要进行模板开户的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：当ADD SUBTPL命令中的参数“是否是M2M用户”取值为“M2M”时。若不输入该参数或输入的值与“IMSI”相同，系统将自动选取参数“IMSI”的值作为用户的MSISDN号码，开户后用户为MSISDN-Less用户。若输入的MSISDN与IMSI不相同，开户后用户为非MSISDN-Less用户。 |
| RECORDCOUNT | 用户个数           | 用于标识需要模板开户的用户数目。 当需要为连续号码的多个用户开户时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户开户。 取值范围：1～100000 默认值：无。 说明：该参数为可选参数，是对连续号码的多个用户开户，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。       |
| FILE        | IMSI/MSISDN文件名 | 用于标识待开户用户的IMSI/MSISDN批操作文件。 IMSI/MSISDN批操作文件包含多个不连续的待开户用户的IMSI号码和MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“addtplcspssub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见开户批操作文件格式。 取值范围：1～35位的字母或十进制数字组成的字符串。 默认值：无。      |
| CSPSTPLID   | CSPS用户模板ID     | 用于标识用于开户的CSPS模板的ID。该参数必须先由ADD SUBTPL命令定义，然后才能在此处引用，且ADD SUBTPL命令参数“用户模板类型”必须为“CSPSTPL”。 取值范围：0～65534 默认值：无。                                                                                                       |
| M2MCISDN    | M2MCISDN号码     | 用于标识M2M Common MSISDN用户的Common MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：只有M2M用户才能设置该参数。                                                                                                                         |
| PSUSERTPLID | PS用户模板ID       | 用于标识PS用户模板ID。该参数必须先由ADD PSUSERTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                              |

## 使用实例

1. 为IMSI为“460000009012345”、“MSISDN”为“8613900001234”的用户使用CSPS模板开户，“CSPS用户模板ID”为“124”，命令如下：

   ```
   ADD TPLCSPSSUB: HLRSN=123, IMSI="460000009012345", ISDN="8613900001234", CSPSTPLID=124;
   ```
2. 批量为“IMSI”号码分别为“460000009012346”、“460000009012347”、“460000009012348”，“MSISDN”号码分别为“8613900001234”、“8613900001235”、“8613900001236”的连续3个用户使用CSPS模板开户，“CSPS用户模板ID”为“124”，命令如下：

   ```
   ADD TPLCSPSSUB: HLRSN=1, IMSI="460000009012346", ISDN="8613900001234", RECORDCOUNT=3, CSPSTPLID=124;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
