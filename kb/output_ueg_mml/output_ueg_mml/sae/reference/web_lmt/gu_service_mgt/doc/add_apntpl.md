# 增加APN模板(ADD APNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于增加APN模板。

## 注意事项

- 在相同HLRSN下，TPLID和APN必须唯一。
- 系统中增加的所有APN模板记录数不能超过45000条。
- 当本命令中的“Non-IP传输模式”参数设置为“SCEF\_BASED\_DATA\_DELIVERY”时，“SCEF主机名”和“SCEF域名”两个参数必须同时输入。
- 由于系统对“接入点名称”的大小写不敏感，当执行本命令输入的“接入点名称”参数与系统已存在的记录中“接入点名称”有相同的字符串组合时，系统会上报错误码“ERR3197：关键参数已使用”。

## 参数说明

| 参数标识             | 参数名称          | 参数说明                                                                                                                                                                                                                                                      |
|:-----------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN            | HLR序列号        | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                                                                                  |
| TPLID            | 模板ID          | 模板号，必选参数，0～65534。                                                                                                                                                                                                                                         |
| TPLNAME          | 模板名           | 模板名称，1～60位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。                                                                                                                                                                                                                   |
| APN              | 接入点名称         | 接入点名称，必选参数，1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 说明：当该参数设置为“*”且用于EPS网络时，表示该APN模板为通配APN模板，即用户入网时，MME根据一定的通配原则为用户分配一个APN，该APN可以是用户未签约已授权的APN。                                                                                                                  |
| PDNGWALLOCTYPE   | PDN GW地址分配类型  | PDN GW地址分配类型。 枚举类型（单选）：STATIC：静态。DYNAMIC：动态。 默认值：DYNAMIC 说明：可选参数。当该参数为“DYNAMIC”时，“MIPHAHOST”、“MIPHAREALM”、“MIPHAADDRIPV4”和“MIPHAADDRIPV6”参数不可见。当该参数为“STATIC”时，“MIPHAHOST”、“MIPHAREALM”、“MIPHAADDRIPV4”和“MIPHAADDRIPV6”参数可见。当“APN”为“*”时，该参数必须设置为“DYNAMIC”。 |
| MIPHAHOST        | PDN GW 主机名称   | 仅当本命令中的“PDN GW地址分配类型”参数为“STATIC”时该参数有效。用于标识PDN GW（Packet Data Networks GateWay）主机地址。 取值范围：1～127位字符串。 默认值：无。 说明：“MIPHAHOST”和“MIPHAREALM”必须同时存在。                                                                                                            |
| MIPHAREALM       | PDN GW 域名名称   | 仅当本命令中的“PDNGWALLOCTYPE”参数为“STATIC”时该参数有效。用于标识PDN GW域名地址。 取值范围：1～127位字符串。 默认值：无。 说明：“MIPHAHOST”和“MIPHAREALM”必须同时存在。                                                                                                                                        |
| MIPHAADDRIPV4    | PDN GW IPV4地址 | 仅当本命令中的“PDN GW地址分配类型”参数为“STATIC”时该参数有效。用于标识PDN GW IPV4地址。 取值范围：IPV4地址格式。 默认值：无。 说明：可选参数。                                                                                                                                                                  |
| MIPHAADDRIPV6    | PDN GW IPV6地址 | 仅当本命令中的“PDN GW地址分配类型”参数为“STATIC”时该参数有效。用于标识PDN GW IPV6地址。 取值范围：IPV6地址格式。 默认值：无。 说明：可选参数。                                                                                                                                                                  |
| APNOI            | APN运营商标识符     | APN运营商标识符。 取值范围：1～63个字符组成的相对域名格式字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                      |
| NONIPDATADELMECH | Non-IP传输模式    | 用于标识Non-IP PDN类型的APN数据传输给MME时的传输模式。 取值范围：SGi_BASED_DATA_DELIVERY：通过SGi接口点对点传输。SCEF_BASED_DATA_DELIVERY：通过SCEF传输。 默认值：SGi_BASED_DATA_DELIVERY                                                                                                              |
| SCEFID           | SCEF主机名       | 仅当本命令中的“Non-IP传输模式”参数设置为“SCEF_BASED_DATA_DELIVERY”时该参数有效。用于标识SCEF的主机名称。 取值范围：1～127位字符串。 默认值：无。                                                                                                                                                            |
| SCEFREALM        | SCEF域名        | 仅当本命令中的“Non-IP传输模式”参数设置为“SCEF_BASED_DATA_DELIVERY”时该参数有效。用于标识SCEF的域名名称。 取值范围：1～127位字符串。 默认值：无。                                                                                                                                                            |

## 使用实例

增加APN模板，模板ID为2，模板名称为APN2，接入点名称为APN。命令如下：

```
ADD APNTPL: HLRSN=1, TPLID=2, TPLNAME="APN2", APN="APN";
```

为EPS用户增加APN模板，模板ID为65534，模板名称为APN-EPS，接入点名称为abc.com，PDN GW地址分配类型为STATIC，PDN GW 主机名称为PDN-GW，PDN GW 域名为abc.com，PDN GW IPV4地址为10.144.98.135。命令如下:

```
ADD APNTPL: HLRSN=1, TPLID=65534, TPLNAME="APN-EPS", APN="abc.com", PDNGWALLOCTYPE=STATIC, MIPHAHOST="PDN-GW", MIPHAREALM="abc.com", MIPHAADDRIPV4="10.144.98.135";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                                | 处理建议                                                                                                                                                                             |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 系统中增加的所有APN模板记录数超过45000条。                                                                                                                                           | 根据实际情况，如需增加APN模板，处理步骤如下：执行LST APNTPL命令，查询已存在的APN模板。执行RMV APNTPL命令，删除不必要的APN模板。执行该命令增加APN模板，确保增加的APN模板记录数在规定范围之内。                                                                 |
| ERR1009 | 参数丢失    | 可能原因为如下之一：当本命令中的“PDN GW地址分配类型”参数设置为“STATIC”时，“PDN GW 主机名称”和“PDN GW 域名名称”两个参数没有同时输入。当本命令中的“Non-IP传输模式”参数设置为“SCEF_BASED_DATA_DELIVERY”时，“SCEF主机名”和“SCEF域名”两个参数没有同时输入。 | 根据实际情况，重新输入参数，确保满足以下条件：当本命令中的“PDN GW地址分配类型”参数设置为“STATIC”时，“PDN GW 主机名称”和“PDN GW 域名名称”两个参数必须同时输入。当本命令中的“Non-IP传输模式”参数设置为“SCEF_BASED_DATA_DELIVERY”时，“SCEF主机名”和“SCEF域名”两个参数必须同时输入。 |
| ERR3197 | 关键参数已使用 | 输入的“接入点名称”参数与系统已存在的记录中“接入点名称”有相同的字符串组合。                                                                                                                             | 根据实际情况，重新输入参数，处理步骤如下： 执行LST APNTPL命令，查询已存在的APN模板。执行该命令增加APN模板，重新输入“接入点名称”，确保重新输入的参数未在记录中。                                                                                        |
