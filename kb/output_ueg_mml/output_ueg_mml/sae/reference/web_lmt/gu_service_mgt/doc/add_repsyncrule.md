# 增加透明数据同步规则(ADD REPSYNCRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加透明数据同步的规则。

割接过程中为了保证UDM上的透明数据和被割接局点HSS在一段时间内的透明数据的一致性，需要在用户割接到UDM后的一段时间，透明数据发生变动时依然能将最新的透明数据推送至被割接局点的HSS上，UDM支持模拟AS通过PUR推送最新透明数据给被割接的HSS，从而保证透明数据的一致性。

## 注意事项

- 一个“透明数据同步规则ID”下可以配置多个“服务标识”取值的同步规则，但是这些“服务标识”对应的“是否同步透明数据”取值必须均为“TRUE”，或均为“FALSE”。
- “规则类型”为“Global”时，“透明数据同步规则ID”取值对应的同步规则只能存在一个，“规则类型”为“SubBasis”时，“透明数据同步规则ID”取值对应的同步规则可以存在多个。
- “规则类型”为“Global”的“透明数据同步规则ID”和“规则类型”为“SubBasis”的“透明数据同步规则ID”的取值不能相同。
- 透明数据同步规则最多存在128个。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                            |
|:-------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------|
| INDEX  | 记录索引       | 可选必选说明：必选参数 参数含义：用于标识一个透明数据同步规则数据记录的索引。 取值范围：1～65534 默认值：无。 配置原则：该参数在UDM中唯一，不能重复。                                               |
| RULEID | 透明数据同步规则ID | 可选必选说明：必选参数 参数含义：用于标识透明数据同步规则的ID。 取值范围：1～65534 默认值：无。 配置原则：无。                                                                   |
| TYPE   | 规则类型       | 可选必选说明：必选参数 参数含义：用于标识透明数据同步规则类型。 取值范围： Global：全局规则SubBasis：用户级同步规则 默认值：无。 配置原则：无。                                               |
| SRVIND | 服务标识       | 可选必选说明：必选参数 参数含义：用于标识透明数据对应的Service Indication。如果存在字符“=”、“;”、“\”、“,”、“"”和“'”，需要在该字符前添加转义字符“\”。 取值范围：长度不超过127的字符串 默认值：无。 配置原则：无。 |
| PROV   | 是否同步透明数据   | 可选必选说明：必选参数 参数含义：用于标识是否在透明数据变更时进行透明数据同步。 取值范围： TRUE：同步FALSE：不同步 默认值：无。 配置原则：在同一“透明数据同步规则ID”下，该参数必须均为“TRUE”，或均为“FALSE”。          |

## 使用实例

增加“透明数据同步规则ID”为“1”、“记录索引” 为“1”、“规则类型”为“SubBasis”、“服务标识”为“abc”、“是否同步透明数据”为“FALSE”的透明数据同步规则。

```
ADD REPSYNCRULE:RULEID=1, INDEX=1, TYPE=SubBasis, SRVIND="abc", PROV=FALSE ;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:----------|:-------------------------------------------|:-----------------------------------------------------|:---------------------------------------------------------------------------|

| ERR4183   | 全局规则类型的RULEID只能存在一个                        | “规则类型”为“Global”的“透明数据同步规则ID”只能添加一个。                  | 已存在“规则类型”为“Global”的“透明数据同步规则ID”，如需添加，请使用RMV REPSYNCRULE删除已有的规则后再执行本命令添加。   |
| ERR4184   | SRVIND已经存在，请使用LST REPSYNCRULE命令查询对应结果确认。   | 输入的“服务标识”已存在。                                        | 请使用LST REPSYNCRULE命令查询对应结果，重新输入与已有透明数据同步规则对应的“服务标识”不同的取值。                  |
| ERR4185   | 参数冲突，同一个RULEID下只能有PROV为TRUE或者PROV为FALSE的规则 | “透明数据同步规则ID”取值相同时，“是否同步透明数据”取值必须均为“TRUE”，或均为“FALSE”。 | 请使用LST REPSYNCRULE命令查询对应结果，确认“透明数据同步规则ID”取值相同的透明数据同步规则的“是否同步透明数据”的取值，重新输入。 |
| 900003426 | 记录数超过限制。                                   | 透明数据同步规则最多存在128个。                                    | 请使用LST REPSYNCRULE命令查询对应结果，将不再使用的透明数据同步规则删除后再执行本命令。                        |
