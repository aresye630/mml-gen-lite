# 查询SGSN类型数据(LST SGSNTYP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于查询SGSN类型信息。

## 注意事项

如果SGSNPREFIX没有出现，SGSN类型的全部相关信息要出现。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                            |
|:-----------|:---------|:------------------------------------------------|
| HLRSN      | HLR序列号   | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。        |
| SGSNPREFIX | SGSN号码前缀 | SGSN号码前缀，SGSN号码的前一段，用于标识有相同前缀的SGSN号属性，14位以内的数字。 |

## 使用实例

查询SGSN类型数据，HLR序列号为1，SGSN前缀为91。命令如下：

LST SGSNTYP: HLRSN=1, SGSNPREFIX="91";
