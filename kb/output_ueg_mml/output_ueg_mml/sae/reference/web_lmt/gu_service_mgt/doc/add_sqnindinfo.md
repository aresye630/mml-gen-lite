# 增加SQN的IND分域配置(ADD SQNINDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于为每个SQN IND签约对应的域。

## 注意事项

- 同一个“HLR序列号”中增加的SQN的IND分域配置记录数不能超过1000条。

- 添加SQN的IND分域配置记录时，必须确保“IND”参数枚举中所有的域都配置了IND。

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                      |
|:-----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号     | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                   |
| INDSNO     | IND分域序列号   | 可选必选说明：必选参数 参数含义：用于标识SQN的IND分域序列号。 取值范围：0～65534 默认值：无。 配置原则：无。                                                                                                            |
| IND0~IND31 | IND0~IND31 | 可选必选说明：可选参数 参数含义：用于标识IND0~IND31签约的域。 取值范围：CS：表示签约CS域PS：表示签约PS域LTE：表示签约EPS域IMS：表示签约IMS域BSF：表示签约BSF域AAA：表示签约NON-3GPP域NGC：表示签约5GC域 默认值：无。 配置原则：设置IND参数值时，必须确保枚举中所有的域都配置了IND。 |

## 使用实例

增加一条SQN的IND分域配置记录，其中“HLR序列号”为“1”，“IND分域序列号”为“1”，“IND0”为“CS”，“IND1”为“PS”，“IND2”为“LTE”，“IND3”为“IMS”，“IND4”为“BSF”，“IND5”为“AAA”，“IND6”为“NGC”：

```
ADD SQNINDINFO: HLRSN=1, INDSNO=1, IND0=CS, IND1=PS, IND2=LTE, IND3=IMS, IND4=BSF, IND5=AAA, IND6=NGC;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                            | 处理建议                                                                                                                       |
|:--------|:------------|:--------------------------------|:---------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值      | 界面报错的参数不在取值范围内。                 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                           |
| ERR1037 | 记录已存在       | 输入的“HLR序列号”已存在配置信息。             | 执行LST SQNINDINFO命令查询已存在的记录，输入没有配置信息的“HLR序列号”后执行本命令重试。                                                                      |
| ERR3007 | 记录不存在       | 参数“HLR序列号”的取值未预先定义，对应序号的HLR不存在。 | 根据实际情况选择：如果需要使用输入的“HLR序列号”配置，则执行ADD HLRSN命令，添加所需的“HLR序列号”，然后再引用。如果需要使用已定义的“HLR序列号”配置，则执行LST HLRSN查询已定义的“HLR序列号”，然后执行本命令重试。 |
| ERR3047 | 超过最大限制      | 同一个“HLR序列号”中增加的IND分域记录数超过1000条。 | 执行LST SQNINDINFO命令查询已存在的记录，根据实际情况，执行RMV SQNINDINFO命令删除不必要记录后，重新执行本命令增加。                                                    |
| ERR4210 | 存在未配置IND值的域 | 设置“IND”参数值时，枚举中的一个或多个域未使用。      | 查看报错的配置记录，和“IND”的枚举进行对比，重新配置“IND”参数后执行本命令，确保每个域都被使用。                                                                       |
