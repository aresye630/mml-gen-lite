# 查询IMPI和IMSI的关联关系(LST HASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询IMPI与IMSI的关联，需要输入唯一标识该数据记录的关键参数IMPI或IMSI。

## 注意事项

参数IMPI和参数IMSI必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询IMSI数据；若不输入，则表示按照IMSI查询。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                        |
| IMSI   | IMSI   | 用于指示系统需要按照哪个IMSI来查询IMPI数据；若不输入，则表示按照IMPI查询。IMSI由长度[6，15]位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无 |

## 使用实例

查询IMPI和IMSI的关联关系。IMPI：impiinfo。

```
LST HASSOC: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识   | 参数说明            |
|:-------|:----------------|
| IMPI   | 显示与IMSI关联的IMPI。 |
| IMSI   | 显示与IMPI关联的IMSI。 |
