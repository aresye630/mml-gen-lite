# 查询虚拟网络组成员所属组 (LST GROUPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5G虚拟网络组成员所属组。

- 若需要查询单个用户的5G虚拟网络所属组，请输入“IMSI”或“MSISDN”。
- 若需要查询多个连续用户的5G虚拟网络所属组，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要查询多个不连续用户的5G虚拟网络所属组，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                        |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：可选参数 参数含义：用于标识要查询哪个IMSI号码对应的5G虚拟网络所属组。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                         |
| ISDN        | MSISDN    | 可选必选说明：可选参数 参数含义：用于标识要查询哪个MSISDN号码对应的5G虚拟网络所属组。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                       |
| RECORDCOUNT | 用户个数      | 可选必选说明：可选参数 参数含义：用于标识查询5G虚拟网络所属组的用户数目。 取值范围：1～10000。 默认值：无。 配置原则： 当需要查询连续号码的多个用户的所属组数据时配置。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，查询连续号码的多个用户的所属组数据。该参数是对连续号码的多个用户进行所属组数据查询，当只有一个用户时，该参数不必配置。当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询所属组数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstgroupid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                  |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待查询签约数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstgroupid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                             |

## 使用实例

1. 查询IMSI号码为“460030913121001”的用户的5G虚拟网络所属组：

   ```
   LST GROUPID: IMSI="460030913121001";
   ```

   ```
   %%LST GROUPID: IMSI="460030913121001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460030913121001
                             ISDN = 86111111113

                        INGROUPID = 1-46001-2D
                         SHAREDID = 46001-shared1

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询第一个MSISDN号码为“13310911001”的连续3个用户的5G虚拟网络所属组：

   ```
   LST GROUPID: ISDN="13310911001", RECORDCOUNT=3;
   ```

   ```
   %%LST GROUPID: ISDN="13310911001", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：29. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“MSISDN文件名”为“lstgroupid.txt”的用户的5G虚拟网络所属组：

   ```
   LST GROUPID: ISDNFILE="lstgroupid.txt";
   ```

   ```
   %%LST GROUPID: ISDNFILE="lstgroupid.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435486. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD GROUPID**

命令的参数说明，表1列出的是未包含在

**ADD GROUPID**

命令参数说明中的输出项。

| 输出项名称    | 输出项解释                                      |
|:---------|:-------------------------------------------|
| 批操作ID    | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。 |
| SHAREDID | 用于返回为内部组创建的共享数据的ID。                        |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3001 | 用户未开户      | 输入的“IMSI”或“MSISDN”参数对应的用户未开户。                                                                      | 输入的“IMSI”或“MSISDN”参数对应的用户未开户，请先通过ADD SUB命令给用户开户。                                                                        |
| ERR3007 | 记录不存在      | 用户没有签约任何5G虚拟网络组。                                                                                   | 可根据实际情况执行ADD GROUPID命令签约5G虚拟网络组。                                                                                        |
