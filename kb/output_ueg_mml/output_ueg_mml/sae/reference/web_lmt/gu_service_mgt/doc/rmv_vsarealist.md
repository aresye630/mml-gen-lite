# 删除VLR/SGSN漫游区域模板(RMV VSAREALIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条VLR/SGSN漫游区域模板数据。

## 注意事项

当执行该命令删除用户已签约的VLR/SGSN漫游区域模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该VLR/SGSN漫游区域模板不能被删除。如果要删除该VLR/SGSN漫游区域模板，必须先执行以下步骤：

1. 执行**MOD VSRR**命令给用户去签约相关的VLR/SGSN漫游限制模板。
2. 执行**MOD VSLIST**命令删除该VLR/SGSN漫游限制模板。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 标识VLR/SGSN漫游区域数据记录的关键字段之一，用于指定在哪个HLR上删除VLR/SGSN漫游区域数据记录，操作员可以使用LST HLRSN命令查询获得。        |
| TPLID   | 模板ID   | 标识VLR/SGSN漫游区域数据记录的关键字段之一，用于指定需要删除哪个模板的VLR/SGSN漫游区域数据记录，操作员可以使用LST VSAREALIST命令查询获得。   |
| TPLTYPE | 模板类型   | 标识VLR/SGSN漫游区域数据记录的关键字段之一，用于指定需要删除哪种模板类型的VLR/SGSN漫游区域数据记录，操作员可以使用LST VSAREALIST命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”的HLR上的VLR/SGSN漫游区域模板数据记录。其中，“模板号”为“1”，“模板类型”为“VLR”：

```
RMV VSAREALIST: HLRSN=1, TPLID=1, TPLTYPE=VLR;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                  | 处理建议                                                                                                                                                     |
|:--------|:--------|:----------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”或“模板ID”未定义。“HLR序列号”和“模板ID”对应的VLR/SGSN漫游区域模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST VSAREALIST命令查询已定义的“模板ID”和“模板类型”在数据库中的匹配关系。                                             |
| ERR3005 | 模板已经被使用 | 用户已签约该VLR/SGSN漫游区域模板。                                                 | 根据实际情况，确定是否要删除该VLR/SGSN漫游区域模板。如果确实需要删除，需要执行以下步骤：执行MOD VSRR命令给用户去签约相关的VLR/SGSN漫游限制模板。执行MOD VSLIST命令删除该VLR/SGSN漫游限制模板。执行RMV VSAREALIST命令删除该VLR/SGSN漫游区域模板。 |
