# 设置IMSI与ADD业务数据(SET IMSIADD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置IMSI与ADD业务相关的数据。例如，配置某一IMSI号段是否触发ADD消息及是否记录IMEI轨迹文件。

## 注意事项

系统中增加的IMSI与ADD业务相关的数据记录数不能超过1000条。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                                  |
|:-----------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                          |
| OPTYPE     | 操作类型         | 用于标识执行该命令实现的操作类型。 取值范围：ADD：增加记录。MOD：修改记录。RMV：删除记录。 默认值：无。                                                                                             |
| IMSIPRE    | IMSI前缀       | 用于标识待配置是否触发ADD消息的IMSI号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                |
| SENDADD    | 是否下发ADD消息    | 仅当该命令中的“操作类型”参数设置为“ADD”或“MOD”时该参数有效，用于标识在触发ADD业务后，UDM是否下发SOAP消息给ADD Server。 取值范围：NONE：不下发。SOAP：下发。 默认值：NONE                                           |
| RECORDIMEI | 是否记录IMEI轨迹文件 | 仅当该命令中的“操作类型”参数设置为“ADD”或“MOD”时该参数有效，用于标识在UDM检测到用户的IMEI、IMSI和MSISDN任何一个发生变化时，是否将用户的IMEI、IMSI和MSISDN信息记录在IMEI变化轨迹文件中。 取值范围：TRUE：记录。FALSE：不记录。 默认值：FALSE |

## 使用实例

1. 增加一条“IMSI前缀”下发ADD消息的记录，其中“HLR序列号”为“1”，“操作类型”为“ADD”，“IMSI前缀”为“12345”，“是否下发ADD消息”为“SOAP”，“是否记录IMEI轨迹文件”为“FALSE”：

   ```
   SET IMSIADD: HLRSN=1, OPTYPE=ADD, IMSIPRE="12345", SENDADD=SOAP, RECORDIMEI=FALSE;
   ```
2. 删除一条“IMSI前缀”下发ADD消息的记录，其中“HLR序列号”为“1”，“操作类型”为“RMV”，“IMSI前缀”为“12345”：

   ```
   SET IMSIADD: HLRSN=1, OPTYPE=RMV, IMSIPRE="12345";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                    | 处理建议                                                                                                                                                              |
|:--------|:--------|:------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI前缀”的取值不是1～15位十进制数字组成的字符串。                                        | 根据实际情况，重新输入“IMSI前缀”的取值，确保其取值符合要求。                                                                                                                                 |
| ERR1009 | 参数丢失    | 当参数“操作类型”设置为“MOD”时，“是否下发ADD消息”和“是否记录IMEI轨迹文件”都没有输入。                     | 根据实际情况，重新输入参数。                                                                                                                                                    |
| ERR1010 | 参数冲突    | 当参数“操作类型”设置为“RMV”时，携带了“是否记录IMEI轨迹文件”或同时输入了参数“是否下发ADD消息”和“是否记录IMEI轨迹文件”。 | 根据实际情况，当参数“操作类型”设置为“RMV”时，不允许输入“是否下发ADD消息”和“是否记录IMEI轨迹文件”中的任何一个。                                                                                                  |
| ERR1118 | 参数重复    | 重复输入了该命令中的任意参数。                                                         | 核实输入的命令，若命令中任意参数输入了两次以上，则删除多余的重复参数后，重新执行该命令。                                                                                                                      |
| ERR3006 | 记录已存在   | 当参数“操作类型”设置为“ADD”时，新增加的“IMSI前缀”记录已经存在。                                  | 当参数“操作类型”设置为“ADD”时，可以执行LST IMSIADD命令查询数据库，确保待添加的数据在系统中不存在。                                                                                                        |
| ERR3007 | 记录不存在   | 当参数“操作类型”设置为“MOD”或“RMV”时，输入的“IMSI前缀”不存在。                                | 根据实际情况，重新输入“IMSI前缀”参数的取值，确保其存在。                                                                                                                                   |
| ERR3047 | 超过最大限制  | 增加的IMSI与ADD业务相关的数据记录数超过1000条。                                           | 根据实际情况，如需增加IMSI与ADD业务相关的数据记录，处理步骤如下：执行LST IMSIADD命令，查询已存在IMSI与ADD业务相关的数据记录。执行该命令删除不必要的IMSI与ADD业务相关的数据记录。执行该命令增加的IMSI与ADD业务相关的数据记录，确保增加后IMSI与ADD业务相关的数据记录数在规定范围之内。 |
