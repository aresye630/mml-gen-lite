# 增加APN限制模板(ADD APNRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于增加APN限制模板。

通过此命令增加的限制模板会在**ADD SERRESTTPL**命令中被引用。

通过本命令只能给一个模板配置一个APN，如果要为一个模板配置多个APN需要通过**MOD APNRESTTPL**完成。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                             |
|:-------------|:-------|:-----------------------------------------------------------------|
| HLRSN        | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                     |
| APNRESTTPLID | 模板ID   | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                            |
| TPLNAME      | 模板名    | 用于标识待增加模板在系统中的名称。 取值范围：1～60位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |
| APN          | 接入点名称  | 用于标识待增加的APN名称。 取值范围：1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。    |

## 使用实例

增加一个APN限制模板，设置“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“apn1”，“接入点名称”为“abc.com”：

`ADD APNRESTTPL: HLRSN=1, APNRESTTPLID=2, TPLNAME="apn1", APN="abc.com";`
