# 增加开户模板(ADD SUBTPL)

## 命令功能

设置开户模板主要用于开户时使用模板定义的各种业务参数减少用户操作的复杂性。同时，设置开户模板可以将大量的工作放在开户前进行。

## 注意事项

- 如果“用户模板类型”为“CSPSTPL”时，那么“EPS业务标识”不出现，不可设置。
- 如果“EPS业务标识”为“TRUE”时，那么“EPSUSERTPL模板ID”参数出现。
- 如果“EPS业务标识”参数为“TRUE”，并且“EPSUSERTPL模板ID”没有出现时。

  - “UE最大上行带宽”和“NR上行速率”两个参数必须且只能配置一个。
  - “UE最大下行带宽”和“NR下行速率”两个参数必须且只能配置一个。
- 如果“EPS业务标识”为“TRUE”，并且“EPSUSERTPL模板ID”出现时，“UE最大下行带宽”、“UE最大上行带宽”、“NR上行速率”和“NR下行速率”不出现，不可设置。
- 如果“用户模板类型”为“CSPSTPL”时，那么“网络接入模式”不能为“NONE”。
- 如果“用户模板类型”为“CSPSTPL”时，那么“EPSUSERTPL模板ID”不出现，不可设置。
- 如果输入“PSUSERTPL模板ID”，则“GPRS模板ID”和“优化GPRS模板ID”不允许输入。
- 如果“PSUSERTPL模板ID”出现，并且“全局计费特性”不出现时，衍生出“全局计费特性”的属性为NONE。
- 如果输入“EPSUSERTPL模板ID”，则“GPRS模板ID”和“优化GPRS模板ID”不允许输入。
- 如果“EPSUSERTPL模板ID”出现，并且“EPS业务标识”不出现时，衍生出“EPS业务标识”为“TRUE”。
- 如果“EPSUSERTPL模板ID”出现，并且“全局计费特性”不出现时，衍生出“全局计费特性”的属性为NONE。
- 如果“EPS业务标识”为“FALSE”时，那么“EPSUSERTPL模板ID”不出现，不可设置。
- 只有当GPRS管理模式为独立管理，或者兼容开关打开的时候，新增参数“PSUSERTPL模板ID”和“EPSUSERTPL模板ID”才允许出现。
- 如果输入“全局计费特性”、“标准全局计费特性”或“优化GPRS模板ID”，则“GPRS模板ID”不允许输入。
- 如果输入“GPRS模板ID”参数，则“全局计费特性”、“标准全局计费特性”或“优化GPRS模板ID”不允许输入。
- 请参见“**ADD SUB**”中的注意事项。
- 同一个“HLR序列号”中增加的开户模板记录数不能超过15000条，且系统中所有开户模板的总记录数不能超过15000条。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。
- 执行本命令签约“CFD前转号码”时，系统默认在签约的“CFD前转号码”前补充“91”前缀。例如：输入“123456”，执行**LST SUBTPL**命令时，查询结果中“CFD前转号码”显示为“91123456”。

## 使用实例

1. 为3G用户设置开户模板，用户模板类型为NORMAL、模板中提供语音业务（TS11）、短消息接收业务（TS21）、短消息始发业务（TS22）、BS20承载业务。命令如下：

   ```
   ADD SUBTPL: HLRSN=1, TPLID=2,TPLNAME="subtsbs", TPLTYPE=NORMAL, CARDTYPE=USIM, NAM=BOTH, CATEGORY=COMMON, TS=TS11&TS21&TS22, BS=BS20;
   ```
2. 为EPS用户设置开户模板，模板ID是200、模板名称为subtpl-200、用户模板类型为NORMAL、USIM卡、网络接入类型为BOTH、普通用户类型、模板中提供语音业务（TS11）、UE最大上行带宽（1000000 bit/s）、UE最大下行带宽（2000000 bit/s）、无线频率选择优先级为2级、PLMN漫游限制模板ID为100。命令如下：

   ```
   ADD SUBTPL: HLRSN=1, TPLID=200, TPLNAME="subtpl-200",TPLTYPE=NORMAL, CARDTYPE=USIM, NAM=BOTH, CATEGORY=COMMON, DEFAULTCALL=TS11, AMBRMAXUL=1000000, AMBRMAXDL=2000000, RATFREQSELPRIID=2, PLMNTPLID=100;
   ```
