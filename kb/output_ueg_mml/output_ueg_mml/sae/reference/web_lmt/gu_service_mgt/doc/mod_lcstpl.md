## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条LCS（Location Services）模板数据记录的某些参数进行修改或调整，同时还用于为一条LCS模板数据记录增加多条PE（Privacy Exception） List数据和MO-LR（Mobile Originating Location Request） list数据。在该命令中，系统通过以下关键参数的组合来唯一标识一条LCS模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 当用户进行位置更新或触发其他涉及LCS模板的流程时，系统会根据用户签约的LCS模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 同一个LCS模板中增加的“GMLC地址”记录数不能超过20条。

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的LCS模板数据记录，增加一条业务码为Universal的PE list数据并修改MO-LR数据。其中，“模板ID”为“2”，“是否提供PECODE、MOLR或GMLC的指示”为“TRUE”，“本地优先标志”为“SGSN”，“privacy class的补充业务码”为“Universal”，“Molr补充业务码”为“BasicSelfLocation”：

   ```
   MOD LCSTPL: HLRSN=1, TPLID=2, PROV=TRUE, PLF=SGSN, PECODE=Universal, MOLR=BasicSelfLocation;
   ```
2. 修改“HLR序列号”为“1”的HLR上的LCS模板数据记录。其中，“模板ID”为“2”，“本地优先标志”为“SGSN”，“是否提供归属GMLC地址”为“FALSE”，“是否提供PPR地址”为“FALSE”：

   ```
   MOD LCSTPL: HLRSN=1, TPLID=5, PLF=SGSN, PROVHGMLC=FALSE, PROVPPR=FALSE;
   ```

| ERR3003 | 模板未定义         | “HLR序列号”和“模板ID”对应的LCS模板数据记录不存在。                                                                                                                                                                                                                                            | 使用LST LCSTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的LCS模板数据记录。                                                                                                                                                                                                                                         |
| ERR1009 | 参数丢失          | 可能原因为如下之一：参数“是否提供PECODE、MOLR或GMLC的指示”被输入时，“GMLC地址”、“privacy class的补充业务码”和“Molr补充业务码”没有任何一个被输入。参数“归属GMLC地址类型”被输入时，参数“IPV4格式的归属GMLC地址”或“IPV6格式的归属GMLC地址”没有一个被输入。参数“PPR地址类型”被输入时，参数“IPV4格式的PPR地址”或“IPV6格式的PPR地址”没有一个被输入。参数“是否提供R-GMLC访问限制模板”取值为“TRUE”时，参数“R-GMLC访问限制模板ID”未输入。 | 根据实际情况，重新输入参数，确保满足以下条件：参数“是否提供PECODE、MOLR或GMLC的指示”被输入时，必须至少输入“GMLC地址”、“privacy class的补充业务码”或“Molr补充业务码”三个参数其中之一。参数“归属GMLC地址类型”被输入时，参数“IPV4格式的归属GMLC地址”和“IPV6格式的归属GMLC地址”至少输入其中一个。参数“PPR地址类型”被输入时，参数“IPV4格式的PPR地址”和“IPV6格式的PPR地址”至少输入其中一个。参数“是否提供R-GMLC访问限制模板”取值为“TRUE”时，参数“R-GMLC访问限制模板ID”必须输入。 |
| ERR3352 | RGMLCTPLID不存在 | Diameter漫游限制模板未定义。                                                                                                                                                                                                                                                         | 使用已定义的Diameter漫游限制模板的ID作为参数“R-GMLC访问限制模板ID”的取值（可以使用LST DIAMRRTPL命令查询已定义的Diameter漫游限制模板）或根据实际情况，使用ADD DIAMRRTPL命令重新定义新的Diameter漫游限制模板，并作为参数“R-GMLC访问限制模板ID”的取值。                                                                                                                                  |
| ERR3047 | 超过最大限制        | 在同一个LCS模板增加的“GMLC地址”数据记录数超过20条。                                                                                                                                                                                                                                            | 根据实际情况，如需增加GMLC地址，处理步骤如下： 执行LST LCSTPL命令，查询已存在的GMLC地址。执行该命令删除不必要的GMLC地址。执行该命令增加GMLC地址，确保增加的GMLC地址在20条之内。                                                                                                                                                                                        |
