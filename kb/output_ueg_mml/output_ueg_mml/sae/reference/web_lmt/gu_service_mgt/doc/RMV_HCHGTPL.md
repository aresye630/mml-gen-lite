# 删除计费地址模板(RMV HCHGTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一个计费地址模板。

## 注意事项

- “计费地址模板ID”为“0”的模板不允许删除。
- 当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                        |
|:-------|:---------|:----------------------------------------------------------------------------|
| HLRSN  | HLR序列号   | 可选必选说明：可选参数 参数含义：用于指定需要删除哪一条HLR序列号对应的计费地址模板数据记录。可以通过LST HTPLINF查询获得。        |
| TPLID  | 计费地址模板ID | 可选必选说明：必选参数 参数含义：标识一条计费地址模板的关键字段，用于指定需要删除哪一条计费地址模板数据记录。可以通过LST HTPLINF查询获得。 |

## 使用实例

删除计费地址模板。计费地址模板ID：10。

```
RMV HCHGTPL: TPLID=10;
```
