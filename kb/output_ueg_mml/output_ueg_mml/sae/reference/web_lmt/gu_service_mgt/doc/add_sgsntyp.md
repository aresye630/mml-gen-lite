# 增加SGSN类型数据(ADD SGSNTYP)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到该SGSN区域后出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

SGSN类型用于判定GPRS(General Packet Radio Service)用户的漫游类型，表明该SGSN号码相对与本HLR来说是本地、还是国内漫游或国际漫游。

设置SGSN类型表，会影响用户的位置更新。例如：当用户漫游的SGSN为国际漫游类型，但用户又没有国际漫游权限时，位置更新将被拒绝。

## 注意事项

- 在配置SGSN类型的时候，需根据局方提供的SGSN GT及SGSN所在位置所属类型进行配置。本地SGSN若GT比较规范，则直接配置一个前缀即可。若不规范，则需一一配置。 如果非本地的SGSN，可以不配置，表示为国际漫游。 具体配置需要根据局方的SGSN分布来配置。如：深圳地区的SGSN，其GT都规范的以8613755开始，如：861375501、861375502等，则只需配置一条数据： ADD SGSNTYP: HLRSN=1, SGSNPREFIX="8613755", NAME="shenzhen", TYPE=LOCAL; 如：8613是某运营商独立的前缀，则如下命令配置其国内本网SGSN前缀： ADD SGSNTYP: HLRSN=1, SGSNPREFIX="8613", NAME="CM", TYPE=LOCALDOMESTIC;
- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的SGSN类型数据记录数不能超过1000条。

## 参数说明

| 参数标识        | 参数名称                | 参数说明                                                                                                                                                       |
|:------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号              | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                   |
| SGSNPREFIX  | SGSN号码前缀            | SGSN号码前缀，SGSN号码的前一段，用于标识有相同前缀的SGSN号属性，14位以内的数字。                                                                                                            |
| NAME        | SGSN名称              | SGSN名称，30个以内的字母或数字组成的字符串，用于标识不同的SGSN。                                                                                                                      |
| TYPE        | SGSN号相对于本HLR所属的网络类型 | 标明此SGSN号相对于本HLR所属的网络类型，取值如下： LOCAL：本地。LOCALDOMESTIC：国内本网。CROSSDOMESTIC：国内跨网。LOCALINTERNATIONAL：国际本网。CROSSINTERNATIONAL：国际跨网。LOCALAREA：省内本网。CROSSAREA：省内跨网。 |
| NCCTPL      | NCC模板ID             | SGSN签约的NCC模板号，值域0～99998。                                                                                                                                   |
| SERVICETY   | 是否允许签约OKSC业务        | 是否允许签约业务区域限制。 取值范围：PERMISSION：业务允许 RESTRICT：业务限制 缺省值：PERMISSION。                                                                                           |
| CAMELCAPTPL | CAMEL能力模板ID         | CAMELCAP模板ID。 取值范围：0～65534。                                                                                                                                |

## 使用实例

增加前缀为1111的SGSN1，SGSN漫游类型为国内本网，命令如下：

ADD SGSNTYP: HLRSN=1, SGSNPREFIX="1111", NAME="SGSN1", TYPE=LOCALDOMESTIC;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                                                                                |
|:--------|:--------|:-----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的SGSN类型数据记录数超过1000条。 | 根据实际情况，如需增加SGSN类型数据，处理步骤如下：执行LST SGSNTYP命令，查询已存在的SGSN类型数据。执行RMV SGSNTYP命令，删除不必要的SGSN类型数据记录。执行该命令增加SGSN类型数据，确保增加的SGSN类型数据记录数在规定范围之内。 |
