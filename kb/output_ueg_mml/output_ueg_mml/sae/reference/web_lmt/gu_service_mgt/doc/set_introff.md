## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置本局信息数据记录。

系统初始化时会在数据库中添加一条无效本局数据记录，在开局配置本局数据时需要根据运营商的要求进行修改。系统中只存在一条本局数据记录，执行该命令后会覆盖原有数据。

## 注意事项

- 本局数据在配置数据库中是重要的基础数据，请勿随意修改本局数据的参数配置。如需修改，修改时请务必确保所有参数都填写完整，执行该命令后会覆盖原有数据，未填写的参数将会被清除。
- 该命令不允许进行批操作。
- 本局数据在容灾局无需配置，参考容灾系统管理手册检查数据是否同步到容灾局即可。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                              |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LHLRNO | 本局HLR号码    | 用于标识本局HLR号码，在No.7信令网中使用的代表本局HLR的号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：该参数的取值需要与OM Portal的"UDM MML命令"界面上SET OFI命令中的“LOCGT”参数定义的GT码相同。                                                                             |
| FUNCID | 本局HLR的功能ID | 用于标识本局HLR的功能ID，该ID相当于HLR的一个名字标识。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                 |
| CCODE  | 国家码        | 用于标识本局所在国家的国家代码。当用户登记前转号码、系统进行号码规整时，如果需要国家码但待登记的前转号码中未携带并且系统无法获取用户所在虚拟HLR的国家码时，使用该数据记录中的国家码作为规整后前转号码的国家码。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。 配置原则：该参数的取值需要与OM Portal的"UDM MML命令"界面上SET OFI命令中的“LOCGT”参数定义的GT码中包含的国家码相同。 |
| RN     | 本网RN       | 用于标识路由码。当本局HLR实现的是NPHLR（Number Portability Home Location Register）的功能时设置该参数，本局HLR功能属性是通过执行SET FUNCCONF命令设置“本局功能属性”参数实现的。 取值范围：1～10位十进制数字或大写字母A～E组成的字符串。 默认值：无。                                                    |

## 使用实例

在开局阶段配置本局数据时，根据运营商的要求设置本局信息，“本局HLR号码”为“8613901000”，“国家码”为“86”：

```
SET INTROFF: LHLRNO="8613901000", CCODE="86";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                 | 处理建议                             |
|:--------|:--------|:---------------------|:---------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。 |
