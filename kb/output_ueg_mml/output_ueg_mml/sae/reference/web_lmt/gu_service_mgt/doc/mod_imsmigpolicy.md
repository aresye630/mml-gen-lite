# 修改IMS用户割接策略配置(MOD IMSMIGPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于撤销或修改IMS用户的割接策略信息。IMS用户通过该命令配置的“割接策略ID”与**割接策略模板**关联，UDM根据IMS用户消息中携带的IMS用户标识及IMS用户签约的割接策略判断是否对IMS用户的Diameter消息转发到待割接设备进行处理。

- 当系统对现网IMS用户进行割接操作时，IMS用户签约的割接策略中“是否转发IMS DIAMETER消息”为“TRUE”时，UDM转发IMS用户的Diameter消息到对应的待割接设备处理。
- 当系统对现网IMS用户进行割接操作时，IMS用户签约的割接策略中“是否转发IMS DIAMETER消息”为“FALSE”时，IMS用户的Diameter消息在UDM本地处理。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“IMPI”、“IMPU”、“IMPI文件名”、“IMPU文件名”八个参数是可选参数，必须有且只能有一个参数出现。
- 执行此命令前需设置“IMS用户在Diameter FNR功能中使用的HLRSN”软参取值。
- 不支持为PSI用户签约此割接策略。

## 使用实例

当UDM割接现网IMS用户时，配置UDM的割接策略，需要进行如下配置。以IMS用户标识为IMSI为例。

1. 执行**ADD MIGPOLICYCFG**命令增加割接策略模板，该模板“割接策略ID”为“0”。其中“HLR序列号”为“1”、“路由类型”为“IMSI\_TYPE”、“是否转发MAP消息”为 “TRUE”、“HLR号码”为“1”。

   ```
   ADD MIGPOLICYCFG: HLRSN=1, MIG_POLICYID=0, ROUTETYPE=IMSI_TYPE, WHETHER_FORWARD_MAP=TRUE, HLRNO="1";
   ```
2. 执行本命令，增加一条割接策略记录。“IMSI”为“460000009123456”。

   ```
   MOD IMSMIGPOLICY: IMSI="460000009123456", PROV=TRUE, MIG_POLICYID=0;
   ```
