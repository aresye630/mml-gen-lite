# 查询支持一卡多号的VLR信息(LST OCMNVLR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询虚拟HLR上已添加的VLR号码前缀和MSISDN号码前缀的对应关系信息记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                        |
|:-------|:-------|:----------------------------|
| HLRSN  | HLR序列号 | 用于指示系统需要查询哪个虚拟HLR上已添加的信息记录。 |

## 使用实例

查询“HLR序列号”为“1”的虚拟HLR上的信息记录，命令如下：

```
LST OCMNVLR: HLRSN=1;
```

```
%%LST OCMNVLR:HLRSN=1;%%
RETCODE = 0 SUCCESS0001:操作成功

                 HLRSN                  VLRPREFIX              ISDNPREFIX
                 1                      7888                   154

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD OCMNVLR**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                                       |
|:--------|:--------|:------------------------------------|:---------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“HLR序列号”错误或对应的虚拟HLR上未添加任何数据记录信息。 | 请确认输入的“HLR序列号”的正确性，若确定输入无误，则先使用ADD OCMNVLR命令添加对应虚拟HLR的数据记录信息，然后再使用本命令进行查询。 |
