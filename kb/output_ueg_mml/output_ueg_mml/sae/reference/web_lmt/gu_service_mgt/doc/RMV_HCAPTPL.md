# 删除能力集信息模板(RMV HCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在业务数据库中删除一个能力集模板。

## 注意事项

当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                     |
|:-------|:--------|:---------------------------------------------------------|
| HLRSN  | HLR序列号  | 用于指定需要删除哪一个HLR序列号的能力集模板数据记录。可以通过LST HTPLINF查询获得。         |
| TPLID  | 能力集模板ID | 标识一条能力集模板的关键字段，用于指定需要删除哪一条能力集模板数据记录。可以通过LST HTPLINF查询获得。 |

## 使用实例

删除能力集信息模板。能力集模板ID：10。

```
RMV HCAPTPL: TPLID=10;
```
