# 发送模拟USSD Notify操作（SND FMNOTIFY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

此操作是在网络和手机的FM(FollowMe)数据不一致时，操作员发送模拟的USSD Notify操作通知手机，以便手机修改FM数据，和网络的FM数据保持一致。

## 注意事项

- 初始用户号码不能是辅号。
- 初始用户是HLR在网用户。

## 参数说明

| 参数标识    | 参数名称          | 参数说明                                       |
|:--------|:--------------|:-------------------------------------------|
| RMNUM   | 远端号码          | 远端号码，E.164格式的编码，1～15位的十进制数字。必选参数。          |
| INITNUM | 初始用户的MSISDN号码 | 初始用户的MSISDN号码，E.164格式的编码，1～15位的十进制数字。必选参数。 |

## 使用实例

向初始用户号码为8613865591111的用户发送模拟的USSD Notify操作，删除取值为8613900001234的远端号码。

SND FMNOTIFY: RMNUM="8613900001234", INITNUM="8613865591111";
