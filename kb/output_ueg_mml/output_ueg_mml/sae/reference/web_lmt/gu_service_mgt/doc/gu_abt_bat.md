# 终止批操作(ABT BAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于终止定时执行的或正在执行的某个批操作任务。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                          |
|:-------|:--------|:--------------------------------------------------------------|
| TASKID | 批操作任务ID | 用于标识批操作任务号。可通过CHK BATSTAT命令查询批操作任务号。 取值范围：1～4294967295 默认值：无。 |

## 使用实例

终止“批操作任务ID”为“56”的批操作任务：

```
ABT BAT: TASKID=56;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                             |
|:--------|:--------|:------------------------------|:---------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的“批操作任务ID”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。 |
