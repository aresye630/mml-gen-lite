# 增加PSI用户(ADD HPSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中新增一个PSI用户记录或者在一个已存在的PSI用户下新增一个PUSI记录，在PSI用户开户或者增加PUSI用户时使用该操作。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                      |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PISI     | PISI   | 用于定义PISI的值，要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值： 无                                                                                                                                            |
| PUSI     | PUSI   | 用于增加一个PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值： 无                                                                                                                                |
| PUSITYPE | PUSI类型 | 用于标识新增PUSI的类型，当取值为DPUSI，表示新增的PUSI为非通配型；当取值为WPUSI，表示新增的PUSI为通配型。当PUSI为通配型时，PUSI的格式必须符合@符之前是“!.*!”，例如sip:chatlist_!.*!@huawei.com。 取值范围： DPUSI(DPUSI)WPUSI(WPUSI) 缺省值： 无 说明：系统允许的通配IMPU和通配PUSI数量最大为120000个。 |
| SYSNO    | 系统序列号  | 用于标识一个PSI用户属于哪个虚拟HSS。通过ADD HLRSN定义，然后才能在此处索引。 取值范围：0～255 缺省值：0 说明：可选参数。                                                                                                                                   |

## 使用实例

增加PSI用户。PISI：pisiinfo，PUSI：sip:pusiinfo@huawei.com，PUSI类型：DPUSI。

```
ADD HPSI: PISI="pisiinfo", PUSI="sip:pusiinfo@huawei.com", PUSITYPE=DPUSI;
```
