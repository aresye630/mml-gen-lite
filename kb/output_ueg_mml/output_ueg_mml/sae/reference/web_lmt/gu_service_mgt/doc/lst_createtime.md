# 查询用户开户时间(LST CREATETIME)

## 命令功能

该命令用于从内存库查询2G/3G/4G用户、VoLTE用户、VoBB用户及PSI用户的开户时间。

对于2G/3G/4G用户：

- 若需要查询单个用户的开户时间，请输入参数“IMSI”或“MSISDN”。
- 若需要查询连续多个用户的开户时间，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”。
- 若需要查询不连续的多个用户的开户时间，请输入参数“IMSI文件名”或“MSISDN文件名”。

对于VoLTE用户：

- 当需要查询2G/3G/4G网络侧的用户开户时间：
  - 若需要查询单个用户的开户时间，请输入参数“IMSI”或“MSISDN”。
  - 若需要查询连续多个用户的开户时间，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”。
  - 若需要查询不连续的多个用户的开户时间，请输入参数“IMSI文件名”或“MSISDN文件名”。
- 当需要查询IMS网络侧的用户开户时间，请输入参数“SUBID”、或“IMPI”，或“IMPU”。

对于VoBB用户：若需要查询单个用户的开户时间，请输入参数“SUBID”、或“IMPI”、或“IMPU”。

对于PSI用户：若需要查询单个用户的开户时间，请输入参数“PISI”或“PUSI”。

**说明** 

- 查询结果包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并严格控制查询结果文件的访问权限。
- 在从运营商网络获取数据前，必须要获得运营商的授权。
- 若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在http://support.huawei.com/网站获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“SUBID”、“IMPI”、“IMPU”、“PISI”、“PUSI”九个参数必须有且只能有一个参数出现。
- “用户个数”需要与“IMSI”或“MSISDN”组合配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                               |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识系统需要按照哪个IMSI号码查询对应用户的开户时间。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                       |
| ISDN        | MSISDN    | 用于标识系统需要按照哪个MSISDN号码查询对应用户的开户时间。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                     |
| RECORDCOUNT | 用户个数      | 用于标识系统查询用户开户时间的用户数目。当需要查询连续号码的多个用户的开户时间时配置。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，查询连续号码的多个用户的开户时间。 取值范围：1～10000 默认值：无。 说明：该参数是对连续号码的多个用户进行开户时间查询，当只有一个用户时，该参数不必配置。当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识系统查询用户开户时间的IMSI批操作文件。 IMSI批操作文件包含多个不连续的待查询开户时间的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstcreatetime.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                     |
| ISDNFILE    | MSISDN文件名 | 用于标识系统查询用户开户时间的MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待查询开户时间的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstcreatetime.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。               |
| SUBID       | SUBID     | 用于标识系统需要按照哪个SUBID号码查询对应用户的开户时间。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                          |
| IMPI        | IMPI      | 用于标识系统需要按照哪个IMPI来查询对应用户的开户时间。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                            |
| IMPU        | IMPU      | 用于标识系统需要按照哪个IMPU来查询对应用户的开户时间。 取值范围： 长度不超过127的字符串 默认值： 无                                                                                                                                                            |
| PISI        | PISI      | 用于标识系统需要按照哪个PISI来查询对应用户的开户时间。要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                   |
| PUSI        | PUSI      | 用于标识系统需要按照哪个PUSI来查询对应用户的开户时间。要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                       |

## 使用实例

1. 查询“IMSI”号码为“460111111111113”的用户的开户时间：

   ```
   LST CREATETIME: IMSI="460111111111113";
   ```

   ```
   %%LST CREATETIME: IMSI="460111111111113";%%
   RETCODE = 0 SUCCESS0001:操作成功 

                       IMSI = 460111111111113
               CreationTime = 2015-10-31 17:12:24

   Total count = 2  

   There is together 1 report  

   ---    END
   ```
