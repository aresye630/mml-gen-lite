## 命令功能

该命令用于更新敏感数据信息的加密方式。UDM中保存了系统或用户重要的敏感数据，该类数据泄漏后会给运营商带来很大的损失。为了更加安全，可以通过本命令将一条敏感数据信息的加密方式升级为更安全的加密算法，或由固定密钥更新成指定密钥，或由明文更新成固定密钥，或更新随机密钥，或升级原有兼容模式的CB密钥信息为AES-GCM模式。

## 注意事项

- 执行该命令时参数“类型”取值不为“IMSI”、“IMPI”和“OP”时，只有将**SET MAPCONF**命令中的“是否启用随机密钥”参数设置为“TRUE”时，才允许执行本命令；若该参数不为“TRUE”，执行本命令返回：“系统不支持随机密钥”。
- 执行该命令时参数“类型”取值不为“IMSI”和“IMPI”且未携带“密钥ID”参数的场景下，当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数设为“TRUE”， 执行该命令“类型”为“IMSI”或“IMPI”时，必须同时输入“K2索引号”。
- 执行该命令时参数“类型”为“OP”时，支持更新OP加密方式的场景如下：
  - 执行该命令时未携带“密钥ID”参数，当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“FALSE”，且**SET MAPSERV**命令中的“OP加密存储模式”参数为“ENHANCED”时，OP加密方式支持从异或加密更新为AES固定密钥加密。
  - 执行该命令时无论是否携带“密钥ID”参数，当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，且**SET MAPSERV**命令中的“OP加密存储模式”参数为“ENHANCED”时，OP加密方式支持从异或加密更新为AES随机密钥加密，支持从AES固定密钥加密更新为AES随机密钥加密，OP加密方式已经使用AES随机密钥的支持更新加密密钥（此时如果执行该命令时修改前后有变化，则更新密钥；如果修改前后无变化，则返回“ERR4131 密钥ID未变化”）。
- 当**SET MAPSERV**命令中的“CBPWD加密模式”参数设置为“GCM”，对于以前使用兼容模式存储的CB密码，可以使用该命令升级为AES-GCM模式存储。当系统中不存在默认K2数据记录时，则执行该命令时会返回错误：“默认K2不存在”。
- 启用支持K2加密OPC功能时必须满足以下条件：
  - **SET MAPCONF**命令的“是否支持K2加密OPC”和“是否启用随机密钥”参数必须配置为“TRUE”。
  - **SET MAPSERV**命令的“SAE-HSS AES加密模式”参数必须配置为“CBC”。
- 非混合组网场景下，如果存在有效的全局存储密钥GK2，并且存在加密GK2的随机密钥，则使用加密GK2的随机密钥（系统默认使用“密钥ID”为“3001”的缺省随机密钥，或者**SET GK2**命令中已经设置了随机密钥的“密钥ID”对应的随机密钥）加密全局数据。

## 使用实例

更新一条敏感数据信息的加密方式，“类型”参数为“K2”，“HLR序列号”参数为“1”，“索引号”参数为“1”：

```
UPG KEY: TYPE=K2, HLRSN=1, SNO=1;
```
