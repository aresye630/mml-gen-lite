# 删除5G禁止区域模板管理（RMV FORBIDAREATPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5G禁止区域模板数据记录。

## 注意事项

删除模板时需要检查用户签约数据引用情况（通过**MOD AMDATA**签约或者通过**ADD NGSUSERTPL**引用），如果被签约或者引用，则不允许删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识5G禁止区域模板数据记录的关键字段之一，用于指定在哪个HLR上删除5G禁止区域模板的数据记录，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无 配置原则：无             |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识5G禁止区域模板数据记录的关键字段之一，用于指定需要删除哪个5G禁止区域模板的数据记录，操作员可以使用LST FORBIDAREATPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

假如运营商需要删除某一个5G禁止区域模板，其模板ID为1。

```
RMV FORBIDAREATPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                                                                                                                                                  |
|:--------|:--------|:-------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，确保参数对应的模板数据记录已存在。可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST FORBIDAREATPL命令查询已定义的“模板ID”。                                                       |
| ERR3005 | 模板已被使用  | 用户已签约该5G禁止区域模板。                | 根据实际情况，确定是否要删除该LST FORBIDAREATPL模板。如果确实需要删除，需要执行以下步骤：若通过MOD AMDATA给用户签约，则执行MOD AMDATA命令给用户去签约该模板。若通过ADD NGSUSERTPL命令签约，则执行MOD NGSUSERTPL命令去掉对该模板的引用。执行该命令删除该5G禁止区域模板。 |
