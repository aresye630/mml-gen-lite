# 修改被叫号码分析数据(MOD CALLEDNA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户的CB、ODB等业务失效，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条被叫号码分析数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条被叫号码分析数据记录：

- “HLR序列号”
- “呼叫字冠”

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                      |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 标识一条被叫号码分析数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条被叫号码分析数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                    |
| CALLPREFIX | 呼叫字冠     | 标识一条被叫号码分析数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条被叫号码分析数据记录的参数进行修改或调整，操作员可以使用LST CALLEDNA命令查询获得。                                                                                                                 |
| SERPROP    | 业务属性     | 用于标识被叫号码的属性。 业务属性的配置主要用于判断前转号码的属性，并通过前转号码的属性对照SET MAPSERV命令中的“前转地区限制”参数，来决定前转号码登记能否成功。 取值范围：LOCAL：本地NATIONAL：国内长途PLMN：移动号码。INTERNATIONAL：国际长途OTHER：其它 默认值：无。                                              |
| INFOFLAG   | 是否信息台号码  | 用于标识是否信息台号码。 执行MOD ODBINFO命令可以设置是否被闭锁信息台业务，根据该业务的闭锁情况，决定信息台号码作为前转号码登记能否成功。 取值范围：TRUE：是信息台号码FALSE：不是信息台号码 默认值：FALSE。                                                                                       |
| ENTERFLAG  | 是否娱乐台号码  | 用于标识是否娱乐台号码，值域为TRUE和FALSE。 执行MOD ODBENTE命令可以设置是否被闭锁娱乐台业务，根据该业务的闭锁情况，决定娱乐台号码作为前转号码登记能否成功。 取值范围：TRUE：是信息台号码FALSE：不是信息台号码 默认值：FALSE。                                                                         |
| VMSFLAG    | 是否语音信箱号码 | 用于标识是否语音信箱号码。 用户签约闭锁出呼叫的类型为闭锁所有呼出业务ODB-BAOC（Operator-Determined Barring–Barring of All Outgoing Calls），且呼叫前转业务激活时： 如果用户的前转号码是语音信箱号码，则登记前转号码成功。如果前转号码是其他号码，则登记前转号码失败。 取值范围：TRUE：是信息台号码FALSE：不是信息台号码 默认值：无。 |
| PROV       | 是否提供号码长度 | 用于标识是否启用号码长度限制功能。例如，前转号码与“呼叫字冠”最大匹配结果是“PLMN”，但是此时的前转号码长度不在“最小号码长度”以及“最大号码长度”区间内，那么该号码的属性就不是“PLMN”，继续寻求其次的匹配结果进行处理。 取值范围： TRUE：提供FALSE：不提供 默认值：无。                                                          |
| MINLEN     | 最小号码长度   | 仅当本命令中的“是否提供号码长度”参数为“TRUE”时该参数有效。用于标识前转号码的最小长度。 取值范围：1～32 默认值：无。 配置原则：该参数的取值不能大于“最大号码长度”参数的取值。该参数的取值不能小于“呼叫字冠”参数的长度。                                                                                      |
| MAXLEN     | 最大号码长度   | 仅当本命令中的“是否提供号码长度”参数为“TRUE”时该参数有效。用于标识前转号码的最大长度。 取值范围：1～32 默认值：无。                                                                                                                                          |

## 使用实例

1. 修改被叫号码分析数据记录，修改“呼叫字冠”为“09093767622”的记录，对应的“业务属性”修改为“LOCAL”：

   ```
   MOD CALLEDNA: HLRSN=1, CALLPREFIX="09093767622", SERPROP=LOCAL;
   ```
2. 修改被叫号码分析数据记录，修改“呼叫字冠”为“168”的记录，对应的“是否信息台号码”修改为“TRUE”：

   ```
   MOD CALLEDNA: HLRSN=1, CALLPREFIX="168", INFOFLAG=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                            | 处理建议                                                         |
|:--------|:--------|:------------------------------------------------|:-------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“呼叫字冠”对应的被叫号码分析数据记录不存在。                | 使用LST CALLEDNA命令查询后，重新确认要修改哪个“HLR序列号”和“呼叫字冠”对应的被叫号码分析数据记录。   |
| ERR1009 | 参数丢失    | 当“是否提供号码长度”参数为“TRUE”时，未同时输入“最小号码长度”或“最大号码长度”参数。 | 根据实际情况，当“是否提供号码长度”参数为“TRUE”时，必须至少输入“最小号码长度”或“最大号码长度”这两个参数之一。 |
