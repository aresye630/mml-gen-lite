# 使用PSUSERTPL模板签约PS业务(MOD TPLPSSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于实现模板签约用户的PS业务数据，当“GPRS管理方式”为“SuppPsEpsSeparateTplManager”时使用，GPRS管理方式通过**LST MAPSERV**查询。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                           |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI          | 用于标识需要签约PS数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                          |
| ISDN         | MSISDN        | 用于标识需要签约PS数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                        |
| RECORDCOUNT  | 用户个数          | 用于标识需要签约PS业务的用户数目。 当需要为连续号码的多个用户签约PS业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户签约PS业务。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户签约PS业务，当只有一个用户时，该参数不必配置。 当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                                          |
| IMSIFILE     | IMSI文件名       | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要签约的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modtplpsser.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                                                                                 |
| ISDNFILE     | MSISDN文件名     | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modtplpsser.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                                                                           |
| TPLID        | PSUSERTPL模板ID | 用于标识PSUSERTPL模板ID，该参数需要先在ADD PSUSERTPL处定义才能在此处引用。 默认值：无。                                                                                                                                                                                                                                       |
| PSCNTXIDLIST | PS域上下文索引值列表   | 用于标识PS域PDP上下文索引值列表。 配置原则：由最多5个上下文索引值以&连接组成且每个索引值需要用""标识，在字符"前需要添加转义字符\（例如：\"1\"&\"2\"），当只有一个上下文索引值时，参数不携带字符""和&。 每个PDP上下文索引值的取值范围为1～50。 PDP上下文索引值的取值不能重复。 PDP上下文索引值必须是系统中PS用户模板签约的PDP上下文索引值。 该参数必须和“PS域接入点名称列表”同时输入，且每个PDP上下文索引值与接入点名称一一对应。 取值范围：1～24位字符的字符串。 默认值：无。 说明：最多给用户签约5个PS域PDP上下文索引值。 |
| PSAPNLIST    | PS域接入点名称列表    | 用于标识PS域接入点名称列表。 配置原则：由最多5个接入点名称以&连接组成且每个接入点名称需要用""标识，在字符"前需要添加转义字符\（例如：\"huawei1.com\"&\"huawei2.com\"），当只有一个接入点名称时，参数不携带字符""和&。 每个接入点名称的取值范围为1～63位字符的字符串。 该参数必须和“PS域上下文索引值列表”同时输入，且每个接入点名称与PDP上下文索引值一一对应。 取值范围：1～339位字符的字符串。 默认值：无。                                                           |

## 使用实例

1. 给IMSI号为“460000009123456”的用户签约PS业务，采用预先设置的“PSUSERTPL模板ID”为“2”的模板。执行命令如下：

   ```
   MOD TPLPSSER: IMSI="460000009123456", TPLID=2;
   ```
2. 给IMSI起始号码为“460000009123455”的连续4个用户签约PS业务，采用预先设置的“PSUSERTPL模板ID”为“2”的模板。执行命令如下：

   ```
   MOD TPLPSSER: IMSI="460000009123455", RECORDCOUNT=4, TPLID=2;
   ```
