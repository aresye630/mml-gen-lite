# 修改VoLTE多SIM业务（MOD HMSIM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS网络中设置VoLTE用户的Multi-SIM业务。

该命令的使用场景：当在IMS中需要支持、删除Multi-SIM业务或变更Multi-SIM业务中的主卡时，操作员可以通过本命令设置。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                               |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------|
| IMSI       | IMSI   | 用于标识VoLTE用户Multi-SIM业务的IMSI号码。IMSI号码采用E.212格式的编码，例如：460001234567890。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 |
| MASTERFLAG | 主卡标记   | 用于设置VoLTE用户Multi-SIM业务的主卡标记。 取值范围：FALSE：取消主卡标记TRUE：设置主卡标记 默认值：无。                                   |

## 使用实例

修改VoLTE用户的Multi-SIM业务信息，“IMSI”为“1234567891”，“主卡标记”为“TRUE”：

```
MOD HMSIM: IMSI="1234567891", MASTERFLAG=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释      | 原因分析                           | 处理建议                              |
|----------:|:-----------|:-------------------------------|:----------------------------------|
| 900001007 | 无效的参数值     | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。 | 根据实际情况，重新输入参数“IMSI”的取值，确保其取值符合要求。 |
| 900003113 | 指定的IMSI不存在 | 输入的参数“IMSI”不存在。                | 根据实际情况，重新输入参数，确保参数“IMSI”已经存在。     |
