# 添加5G虚拟网络组成员 (ADD GROUPID)

## 命令功能

该命令用于增加5G虚拟网络组成员。UDM支持对用户签约的5G虚拟网络组数据的下发。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 每个用户可以签约加入多个5G虚拟网络组，最多可以加入10个组。
- 根据**SET UDMSERV**命令的“5GLAN支持签约相同的DNN和切片”参数取值确定用户是否可以签约多个“数据网名称”和“切片标识”相同的5G虚拟网络组。
  - 如果参数取值为“TRUE”，用户可以签约多个“数据网名称”和“切片标识”相同的5G虚拟网络组。
  - 如果参数取值为“FALSE”，对于“数据网名称”和“切片标识”相同的5G虚拟网络组，用户只能签约一个。

## 使用实例

1. 执行命令使IMSI号码为“460030913121001”的用户加入“内部组ID”为“1-46001-2D”的5G虚拟网络组：

   ```
   ADD GROUPID: IMSI="460030913121001",INGROUPID="1-46001-2D";
   ```
2. 执行命令使3个连续号码的用户加入“内部组ID”为“1-46001-2D”的5G虚拟网络组，第一个用户的IMSI号码为“460030913121001”：

   ```
   ADD GROUPID: IMSI="460030913121001",RECORDCOUNT=3,INGROUPID="1-46001-2D";
   ```
3. 执行命令使3个非连续号码的用户加入“外部组ID”为“group1@huawei.com”的5G虚拟网络组，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“addgroupid.txt”的文件中，并通过文件管理功能上传到指定目录：

   ```
   ADD GROUPID: ISDNFILE="addgroupid.txt",EXTGROUPID="group1@huawei.com";
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
