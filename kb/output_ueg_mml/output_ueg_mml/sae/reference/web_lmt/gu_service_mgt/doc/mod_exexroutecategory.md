# 修改扩展增强路由(MOD EXEXROUTECATEGORY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改扩展增强路由业务，包括签约、去签约以及修改扩展增强路由类别。

执行此命令后，给用户签约或去签约该业务，均会下发插入用户数据消息。

## 注意事项

- 当使用连续批操作时需定义RECORDCOUNT与IMSI/ISDN参数，当使用非连续批操作时需定义IMSIFILE/ISDNFILE参数。
- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识              | 参数名称       | 参数说明                                                                                                      |
|:------------------|:-----------|:----------------------------------------------------------------------------------------------------------|
| IMSI              | IMSI       | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                            |
| ISDN              | MSISDN     | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                          |
| RECORDCOUNT       | 用户个数       | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                       |
| IMSIFILE          | IMSI文件名    | IMSIFILE文件名称，由16个以内的数字或字母组成。IMSIFILE的内容是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。                                |
| ISDNFILE          | MSISDN文件名  | ISDNFILE文件名称，由16个以内的数字或字母组成。ISDNFILE的内容是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。                            |
| PROV              | 是否提供扩展增强路由 | 是否提供扩展增强路由业务。 取值范围： TRUE：提供 FALSE：不提供                                                                     |
| EXEXROUTECATEGORY | 扩展增强路由类别   | 仅当本命令中的“是否提供扩展增强路由”设置为“TRUE”时该参数有效。用于标识增强扩展路由业务标识。 取值范围：1～2147483647 说明：当“是否提供扩展增强路由”设置为“TRUE”时，该参数为必选参数。 |

## 使用实例

为IMSI号码是460000009123456的用户提供增强路由业务。

MOD EXEXROUTECATEGORY: IMSI="460000009123456", PROV=TRUE, EXEXROUTECATEGORY=4;
