# 设置IMPU的拜访网络模板ID(SET HVNTPLID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU的拜访网络模板ID。如果该IMPU属于某隐式注册集，则该隐式注册集内其它IMPU也被自动设置为相同的拜访网络模板ID。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                             |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU    | IMPU       | 用于指定一个需要设置拜访网络模板的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                                                                                           |
| VNTPLID | 拜访网络地址模板ID | 用于在HSS的业务数据库中指定一个拜访网络地址模板，该参数必须通过ADD HVNTPL命令定义后才能在此处引用。 取值范围：0～1024 默认值：无 说明： 参数取值为255时，表示该IMPU的原漫游权限无效。当通过SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，该参数需要引用用户签约的“HLR序列号”下的拜访网络地址模板。ADD HVNTPL命令中“拜访网络模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003245：拜访网络模板ID不存在”错误提示。 |

## 使用实例

设置IMPU的拜访网络模板ID。IMPU：sip:impuinfo@huawei.com，拜访网络地址模板ID：10。

```
SET HVNTPLID: IMPU="sip:impuinfo@huawei.com", VNTPLID=10;
```
