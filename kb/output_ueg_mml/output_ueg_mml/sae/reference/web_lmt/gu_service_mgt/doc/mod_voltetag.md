# 修改VoLTE用户标志(MOD VOLTETAG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令在需要用到VoLTE用户标志的场景下使用，用于修改用户的VoLTE标志以标识用户是否为VoLTE用户。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”及“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “RECORDCOUNT”参数不能与“IMSIFILE”或“ISDNFILE”同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                              |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识系统按照哪个“IMSI”号码修改用户的VoLTE标志。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                    |
| ISDN        | MSISDN    | 用于标识系统按照哪个“MSISDN”号码修改用户的VoLTE标志。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 用于标识系统需要修改VoLTE标志的用户个数。 当需要修改连续号码的MSISDN时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，修改连续号码的多个用户的VoLTE标志。 取值范围：1～100000 说明：该参数用于修改连续号码的多个用户的VoLTE标志，当只有一个用户时，该参数不必配置。 默认值：无。                             |
| IMSIFILE    | IMSI文件名   | 用于标识系统按照哪个“IMSI文件名”修改用户的VoLTE标志。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。       |
| ISDNFILE    | MSISDN文件名 | 用于标识系统按照哪个“MSISDN文件名”修改用户的VoLTE标志。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。 |
| VOLTETAG    | VoLTE用户标志 | 用于标识用户是否为VoLTE用户。 取值范围： TRUE：VoLTE用户FALSE：非VoLTE用户 默认值：无。                                                                                                                                         |

## 使用实例

修改“IMSI”号码为“46000000012345”的用户为非VOLTE用户：

```
MOD VOLTETAG: IMSI="46000000012345", VOLTETAG=FALSE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失          | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到         | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突          | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3810 | 用户不是EPS用户或未开户 | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户或者不是EPS用户。                                    | 核实IMSI号码或MSISDN号码，确保其对应的用户为EPS用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请参考ADD SUB页面给用户开户。                    |
| ERR1025 | 批操作文件中格式非法    | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
