# 删除Diameter漫游限制模板(RMV DIAMRRTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条Diameter漫游限制模板的数据记录。

## 注意事项

当执行该命令删除用户已签约或已被关联的Diameter漫游限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该Diameter漫游限制模板不能被删除。如果要删除该Diameter漫游限制模板，必须先执行以下操作：

- 执行**MOD DIAMRRS**命令给用户去签约相关的Diameter漫游限制模板。
- 执行**MOD CCEPS**命令去掉计费特性和EPS数据对应关系与Diameter漫游限制模板的关联关系。
- 执行**MOD DNNREPRULETPL**命令去掉DNN替换规则模板与Diameter漫游限制模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识Diameter漫游限制模板的关键字段之一，用于指定在哪个HLR上删除Diameter漫游限制模板的数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| TPLID  | 模板ID   | 标识Diameter漫游限制模板的关键字段之一，用于指定删除哪个Diameter漫游限制模板的数据记录，操作员可以使用LST DIAMRRTPL命令查询获得。  |

## 使用实例

删除Diameter漫游限制模板。“HLR序列号”为“1”，“模板ID”为“100”：

```
RMV DIAMRRTPL: HLRSN=1, TPLID=100;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                | 处理建议                                                                                                                                                                                                                |
|:--------|:--------|:----------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”未定义或者“模板ID”未定义。                             | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST DIAMRRTPL命令查询已定义的“模板ID”。                                                                                                                          |
| ERR3005 | 模板已经被使用 | 可能原因为如下之一： 用户已签约该Diameter漫游限制模板。Diameter漫游限制模板已被关联。 | 根据实际情况，确定是否要删除该Diameter漫游限制模板。如果确实需要删除，需要执行以下步骤：执行MOD DIAMRRS命令给用户去签约该模板。执行MOD CCEPS命令去掉计费特性和EPS数据对应关系与Diameter漫游限制模板的关联关系。执行MOD DNNREPRULETPL命令去掉DNN替换规则模板与Diameter漫游限制模板的关联关系。执行RMV DIAMRRTPL命令删除该Diameter漫游限制模板。 |
