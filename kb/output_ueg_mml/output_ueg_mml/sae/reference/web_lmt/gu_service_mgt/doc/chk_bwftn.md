# 校验前转号段限制(CHK BWFTN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于校验前转号码是否允许前转。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                      |
| FTN    | 前转号码   | 用于标识待校验的前转号码。采用国际格式。 取值范围：1～28位十进制数字组成的字符串。 默认值：无。 说明：如果在SET MAPCONF命令中设置“是否支持Long FTN”参数为“TRUE”，则前转号码长度最多为28位。如果在SET MAPCONF命令中设置“是否支持Long FTN”参数为“FALSE”，则根据在SET MAPCONF命令中设置“是否限制前转号码长度”参数决定前转号码长度最多为15位还是16位。 |

## 使用实例

校验前转号码为1000011的前转限制，命令如下：

```
CHK BWFTN: HLRSN=1, FTN="1000011";
```
