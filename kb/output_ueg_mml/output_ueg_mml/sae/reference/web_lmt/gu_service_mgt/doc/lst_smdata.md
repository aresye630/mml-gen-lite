## 命令功能

该命令用于查询会话管理数据信息。

- 若需要查询单个用户的会话管理数据信息，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的会话管理数据信息，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的会话管理数据信息，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                   |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个“IMSI”来查询会话管理数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                    |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个“MSISDN”来查询会话管理数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无 配置原则：无。                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指示系统需要查询连续多少个用户的会话管理数据。 取值范围：1～10000 默认值：无。 配置原则： 当需要为连续号码的多个用户查询会话管理数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行查询会话管理数据。该参数是对连续号码的多个用户查询会话管理数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个“IMSI文件名”来查询不连续的多个用户的会话管理数据。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询S-NSSAI数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsmdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个“MSISDN文件名”来查询不连续的多个用户的会话管理数据。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待查询S-NSSAI数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsmdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。          |
| DETAIL      | 是否显示详细信息  | 可选必选说明：可选参数 参数含义：用于指示系统是否显示用户的会话管理数据的详细信息。 取值范围： TRUE：显示DNN QoS模板的详细数据信息。FALSE：只显示DNN QoS模板ID数据。 默认值：FALSE 配置原则：无。                                                                                                                                     |

## 使用实例

1. 查询会话管理数据信息，“IMSI”为“460000009123456”：

   ```
   LST SMDATA: IMSI="460000009123456";
   ```

   ```
   %%LST SMDATA: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 460000009123456

                           SNSSAI = 1-123456
                              DNN = dnn
                          DEFAULT = TRUE
                      DNNQOSTPLID = 11
             SUGGESTEDPACKETNUMDL = 1

                           SNSSAI = 1-123456
                              DNN = 1111
                          DEFAULT = FALSE
                      DNNQOSTPLID = 12  

   Total count = 11

   There is together 1 report

   ---    END
   ```
2. 查询第一个“IMSI”为“460000009123456”的3个连续用户的会话管理信息。

   ```
   LST SMDATA: IMSI="460000009123456", RECORDCOUNT=3;
   ```

   ```
   %%LST SMDATA: IMSI="460000009123456", RECORDCOUNT=3;%% 
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况  

   There is together 1 report 

    ---    END
   ```
3. 查询“IMSI文件名”为“lstsmdata.txt”的用户的会话管理信息。

   ```
   LST SMDATA: IMSIFILE="lstsmdata.txt";
   ```

   ```
   %%LST SMDATA: IMSIFILE="lstsmdata.txt";%% 
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：8. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report 

    ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SMDATA**和**ADD DNNQOSTPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                                 | 处理建议                                                                                                              |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 参数取值范围不符。                                                                                            | 根据系统提示及实际情况，重新输入参数值，确保其取值符合取值范围的要求。                                                                               |
| ERR1005 | 文件不存在      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                     | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1009 | 参数丢失       | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数同时缺失。                                                     | 根据实际情况，“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中必须适当地输入其中一个。                                                     |
| ERR1010 | 参数冲突       | 可能的原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”和“MSISDN文件名”对应的批操作文件格式不正确。                                                                | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                      |
| ERR3001 | 用户未开户      | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                               | 核实并输入正确的用户的“IMSI”或“MSISDN”。                                                                                       |
