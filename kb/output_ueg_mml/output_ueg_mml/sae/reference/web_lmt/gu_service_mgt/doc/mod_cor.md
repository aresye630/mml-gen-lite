# 修改COR数据(MOD COR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

本操作用来对FM功能号码寻址业务的安全性进行管理。操作员可以增加/删除/修改HLR的全局COR(Class of Registration)记录。

## 注意事项

- 如果PROV=TRUE，则该命令用于提供/修改制定的COR角色，HLR会进行COR验证；如果PROV=FALSE，则该命令用于删除指定的COR角色，HLR不会进行COR验证。
- 如果有初始用户、管理者或远端用户签约了某一个COR，则不允许删除此COR，但可修改它的名称。
- 此命令不支持批处理。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                       |
|:--------|:--------|:-----------------------------------------------------------|
| HLRSN   | HLR序列号  | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                   |
| PROV    | 是否提供COR | 提供/修改还是删除指定的COR角色。 TRUE:提供/修改指定的COR角色FALSE:删除指定的COR角色      |
| COR     | COR     | COR的索引值，有效值域为COR_1～COR_254。                                |
| CORNAME | COR名称   | 仅当本命令中的“是否提供COR”参数为“TRUE”时该参数有效。COR的名称，由1～60个字母或数字组成。可选参数。 |

## 使用实例

增加COR角色，COR名称为CORNAME，COR索引值为COR\_228。

MOD COR: HLRSN=1, PROV=TRUE, COR=COR\_228, CORNAME="CORNAME";
