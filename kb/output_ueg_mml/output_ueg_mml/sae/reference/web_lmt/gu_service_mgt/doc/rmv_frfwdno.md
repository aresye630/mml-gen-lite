# 删除禁止前转号码(RMV FRFWDNO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条禁止前转号码数据记录。

## 注意事项

删除一条禁止前转号码数据记录，会使用户登记该禁止前转号码（如紧急呼叫号码）时可以成功，导致不良后果，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一条禁止前转号码数据记录的关键字段之一，用于指定需要删除哪一个HLR上的禁止前转号码数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| FWDNO  | 禁止前转号码 | 标识一条禁止前转号码数据记录的关键字段之一，用于指定需要删除哪一条禁止前转号码数据记录，操作员可以使用LST FRFWDNO命令查询获得。    |

## 使用实例

删除“HLR序列号”为“1”，“禁止前转号码”为“122222222321675”的数据记录：

```
RMV FRFWDNO: HLRSN=1, FWDNO="122222222321675";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                  |
|:--------|:--------|:---------------------------|:------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“禁止前转号码”对应的记录不存在。 | 使用LST FRFWDNO命令查询后，重新确认要删除哪个“HLR序列号”和“禁止前转号码”对应的数据记录。 |
