# 查询DIC业务(LST DIC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询用户的DIC业务属性。

## 注意事项

IMSI、ISDN是条件可选参数，二者不能同时定义。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                               |
|:------------|:----------|:-----------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                     |
| ISDN        | MSISDN    | ISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                    |
| RECORDCOUNT | 用户个数      | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                      |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                  |

## 使用实例

查询IMSI号码为460020008001502的用户的DIC业务签约属性。

```
LST DIC: IMSI="460020008001502";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                              | 处理建议                                                                                 |
|:--------|:-----------|:----------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------|
| ERR3210 | 系统不支持ACC业务 | 执行该命令时，SET MAPCONF命令中的“是否支持DIC业务”取值为“FALSE”或SET MAPSERV命令中的“设置DIC业务SSCODE”参数取值为空。 | 执行该命令前，确保SET MAPCONF命令中的“是否支持DIC业务”取值为“TRUE”且SET MAPSERV命令中的“设置DIC业务SSCODE”参数取值为不为空。 |
