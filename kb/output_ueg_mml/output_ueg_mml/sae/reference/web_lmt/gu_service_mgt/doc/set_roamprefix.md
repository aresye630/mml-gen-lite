# 配置运营商的VLR/SGSN号码前缀(SET ROAMPREFIX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置运营商的VLR/SGSN号码前缀，用以匹配一个VLR/SGSN号码前缀对应的运营商。设置不同运营商对应的VLR/SGSN号码前缀时，该命令支持运营商网络VLR/SGSN号码前缀的增加，修改和删除。

## 注意事项

- 该命令只可以配置非本国网络。
- **SET ROAMPREFIX**设置运营商的VLR/SGSN号码前缀最多可以设置10000个；运营商最多可以设置500个，每个运营商最多可以设置20个VLR/SGSN号码前缀。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                    |
|:--------|:-------------|:----------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号       | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                             |
| OPRID   | 运营商ID        | 用于标识一个运营商数据记录。 取值范围：1～65535 默认值：无。                                                      |
| OPTYPE  | 操作类型         | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加前缀DEL：删除前缀MOD：修改运营商名称DELALL：删除运营商配置信息 默认值：无。              |
| OPRNAME | 运营商名称        | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识一个运营商数据记录。 取值范围：1～60位由字母、数字或特殊字符组成的字符串。 默认值：无。    |
| PREFIX  | VLR/SGSN号码前缀 | 仅当本命令中的“操作类型”参数为“ADD”或“DEL”时该参数有效。用于标识运营商网络VLR/SGSN号码前缀。 取值范围：16位以内的十进制数字组成的字符串。 默认值：无。 |

## 使用实例

配置运营商的VLR/SGSN号码前缀，“HLR序列号”为“1”，“运营商ID”为“1”，“操作类型”为“ADD”，“运营商名称”为“Peking1”，“号码前缀”为“12345678”：

```
SET ROAMPREFIX: HLRSN=1, OPRID=1, OPTYPE=ADD, OPRNAME="Peking1", PREFIX="12345678";
```
