# 修改HLR序列号(MOD HLRSN)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改虚拟HLR的配置信息。在该命令中，系统通过“HLR序列号”参数唯一标识一个虚拟HLR的配置信息记录。

## 注意事项

- 执行该命令时，必须输入“HLR序列号”和其余参数中的至少一个参数。
- 该命令不允许进行批操作。
- 当**SET MAPCONF**命令中“主备容灾部署时容灾FE是否使用主用局主机名”参数取值为“TRUE”并且**SET MAPSERV**中参数“本局信息选取方式”取值为“DEFAULT”时，该命令配置的“主用局主机名”和“主用局域名”、或者“IMS主用局主机名”和“IMS主用局域名”参数必须也在“UDM MML命令”界面执行**ADD DMLE**/**MOD DMLE**命令进行配置，否则会上报“ALM-16014 本端信令配置数据不一致”告警。
- 混合组网下，执行该命令修改“HLR最大用户数”、“HLR最大EPS用户数”、“IMS最大用户数”参数值，只能在vRSP上生效，不支持同步到SP。

## 使用实例

1. 激活“HLR序列号”为“1”的主用HLR：

   ```
   MOD HLRSN: HLRSN=1, STATUS=ACTIVE;
   ```
2. 将“HLR序列号”为“1”的HLRSN所允许的最大IMS用户数量修改为“10000”：

   ```
   MOD HLRSN: HLRSN=1, MAXIMSUSERNUM=10000;
   ```
