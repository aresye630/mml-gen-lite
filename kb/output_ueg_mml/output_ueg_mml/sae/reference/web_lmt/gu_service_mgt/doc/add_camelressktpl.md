# 增加CAMEL限制业务键模板(ADD CAMELRESSKTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中增加一条CAMEL限制业务键模板数据记录。使用该命令，只能在模板中增加一个CAMEL业务键，如果一个模板需要配置多个CAMEL业务键，则首先使用该命令定义一个CAMEL限制业务键模板，然后使用**MOD CAMELRESSKTPL**命令增加多个CAMEL业务键。

当位置更新流程或Restore流程触发ISD（Insert Subscriber Data）消息时，UDM需要根据该命令配置的CAMEL限制模板数据判断是否在ISD中下发相关的CAMEL业务数据。

## 注意事项

系统中增加的CAMEL限制业务键模板记录数不能超过3000条，且所有CAMEL限制业务键模板增加的CAMEL业务键总记录数不能超过3000条。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                         |
|:--------|:-----------|:-------------------------------------------------------------|
| HLRSN   | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                 |
| TPLID   | 模板ID       | 用于标识CAMEL限制业务键模板在系统中的序号。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。 |
| TPLNAME | 模板名        | 用于标识CAMEL限制业务键模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。    |
| SKTYPE  | CAMEL业务键类型 | 用于标识待添加的CAMEL业务键类型。 取值范围：OCSI，即主叫用户CAMEL签约数据。 默认值：无。         |
| SK      | CAMEL业务键   | 用于标识待添加的限制下发的CAMEL业务键。 取值范围：0～2147483647 默认值：无。              |

## 使用实例

在UDM中增加一条CAMEL限制业务键模板数据记录，在该模板中添加多个CAMEL业务键并将该CAMEL限制业务键模板增加到业务限制模板，具体步骤如下：

1. 执行本命令添加一条CAMEL限制业务键模板数据记录。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“CAMELRESSKTPL”，“CAMEL业务键类型”为“OCSI”,“CAMEL业务键”为“1”，命令如下：

   ```
   ADD CAMELRESSKTPL: HLRSN=1, TPLID=1, TPLNAME="CAMELRESSKTPL", SKTYPE=OCSI, SK=1;
   ```
2. 执行**MOD CAMELRESSKTPL**命令在已定义的模板中增加一个CAMEL业务键，其中“CAMEL业务键”为“2”，命令如下：

   ```
   MOD CAMELRESSKTPL: HLRSN=1, TPLID=1, OPTYPE=ADD, SKTYPE=OCSI, SK=2;
   ```
3. 执行**ADD SERRESTTPL**命令将以上已定义的CAMEL限制业务键模板添加到业务限制模板，命令如下：

   ```
   ADD SERRESTTPL: HLRSN=1, TPLID=1, SERCODE=CAMELRES, CAMELRESSK_TPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                      | 处理建议                                                                                                                                                                                                 |
|:--------|:--------|:--------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“HLR序列号”未定义。                                                           | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                                                                                       |
| ERR1004 | 无效的参数值  | 输入的非“HLR序列号”参数不在相应的参数取值范围内。                                               | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                                     |
| ERR3004 | 模板已存在   | 输入的“模板ID”在数据库中已存在。                                                        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST CAMELRESSKTPL命令查询系统中已存在的CAMEL限制业务键模板。                                                                                                                    |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的CAMEL限制业务键模板记录数超过3000条。所有CAMEL限制业务键模板增加的CAMEL业务键总记录数超过3000条。 | 根据实际情况，如需增加CAMEL限制业务键模板，处理步骤如下：执行LST CAMELRESSKTPL命令，查询已存在的CAMEL限制业务键模板。执行RMV CAMELRESSKTPL命令，删除不必要的CAMEL限制业务键模板记录。或执行MOD CAMELRESSKTPL删除CAMEL业务键记录。执行该命令增加CAMEL限制业务键模板，确保增加的CAMEL限制业务键模板记录数在规定范围之内。 |
