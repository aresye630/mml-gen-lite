## 命令功能

**须知** 

本命令属于高危命令，执行不当会增加数据库的负荷，引起系统过载，因此建议在夜间话务量低时执行该命令。

该命令用于按照查询条件来批量查询数据库中满足指定条件的用户统计数据，查询结果以文本格式保存在PGW如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。例如，当前系统HLRSN为“001”，操作员名称为“admin”，则存储查询结果的目录为：“/opt/pgw/pgwtmpfile/001admin”。查询结果的文件名格式为“查询对象-时间-序列号.txt”，例如：CountOfSub-2011-07-08-17-12-35-355.txt。

查询结果可以通过PGW Web LMT上的“文件管理器”下载到本地。

**说明** 

- **SET MAPSERV**命令中的“LST命令导出文件压缩控制”取值不为“0”且**LST CONSUBDATA**查询结果大于或者等于“LST命令导出文件压缩控制”设置的取值时，查询结果的文件格式为“查询对象-时间-序列号.tar.gz”。**LST CONSUBDATA**命令报文中查询结果的文件格式固定显示为“查询对象-时间-序列号.txt”。
- 查询结果包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并严格控制查询结果文件的访问权限。
- 在从运营商网络获取数据前，必须要获得运营商的授权。
- 若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在http://support.huawei.com/网站获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 注意事项

- 执行该命令会消耗较多系统资源，影响系统性能，请在话务量较低的时候执行。
- 执行该命令可通过IMSI号段、“查询条件”来查询用户数据。
  - 当查询对象为“CountOfSub”时，此时“查询条件”参数可取“NAM”、“QOSID”、“ROUCAT”、“BAOC”、“CALLREDIRECT”、“LOCK”、“RROPTION”和“NRBT”中的一个。
  - 当查询对象为“DataOfSub”时，此时“查询条件”参数仅支持取“ROUCAT”、“CALLREDIRECT”、“LOCK”、“RROPTION”和“NRBT”中的一个，不支持取值“NAM”、“QOSID”和“BAOC”，否则会报错“ERR1010：参数冲突”。
- 当数据量过大时，执行本命令前可以通过配置软参“EXPORTSPEED（导出速度(记录数/秒)）”的值来提高用户数据查询效率，“EXPORTSPEED（导出速度(记录数/秒)）”值建议修改为“1000”，用户可以根据实际情况配置，导出完成后恢复原配置。当前导出速度可以通过**LST INSP**命令查询。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESULT       | 查询对象     | 用于标识查询的用户数据类型。 取值范围： CountOfSub：业务用户数目。DataOfSub：业务用户IMSI。 默认值：无。                                                                                                                                                                                                                               |
| RANGE        | 查询范围     | 用于标识查询的用户数据范围。 取值范围： AllSub：查询所有开户用户的数据。RangeByIMSI：根据IMSI号段查询用户的数据。 默认值：无。                                                                                                                                                                                                                     |
| RANGEPARA1   | 起始IMSI   | 仅当本命令中的“查询范围”参数为“RangeByIMSI”时该参数有效。用于标识查询范围中的起始IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                           |
| RANGEPARA2   | 结束IMSI   | 仅当本命令中的“查询范围”参数为“RangeByIMSI”时该参数有效。用于标识查询范围中的结束IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                           |
| CONDITION    | 查询条件     | 用于标识查询用户数据的条件。 取值范围： NAM：网络接入模式。QOSID：QOS模板。ROUCAT：路由用户类别。BAOC：闭锁所有出呼。CALLREDIRECT：呼叫重定向类别。LOCK：LCK锁。RROPTION：区域漫游限制选项。NRBT：NRBT索引。 默认值：无。                                                                                                                                                      |
| NAM          | 网络接入模式   | 仅当本命令中的“查询条件”参数为“NAM”时该参数有效。用于标识系统按照网络接入模式来查询用户数据。 取值范围： BOTH：允许接入电路域、分组域、EPS网络和5GS网络。MSC：允许接入电路域和EPS网络。SGSN：允许接入分组域、EPS网络和5GS网络。 默认值：无。 说明：参数取值为“MSC”时，仅当SET MAPCONF命令中“用户NAM取值为MSC时，在EPC域鉴权、注册是否按照3GPP协议处理”参数取值为“FALSE”时，允许接入电路域和EPS网络；取值为“TRUE”时，只允许接入电路域，不允许接入EPS网络。参数取值可通过LST MAPCONF命令查询。 |
| QOSID        | QOS模板ID  | 仅当本命令中的“查询条件”参数为“QOSID”时该参数有效。用于标识系统按照QoS模板的ID来查询用户数据。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                      |
| ROUCAT       | 增强路由类别   | 仅当本命令中的“查询条件”参数为“ROUCAT”时该参数有效。用于标识系统按照增强路由业务标识来查询用户数据。 取值范围：0～255 默认值：无。 说明： 该参数取值为“0”代表未签约增强路由业务。当“查询对象”取值为“DataOfSub”时，该参数不能为“0”。                                                                                                                                                            |
| BAOC         | 闭锁所有出呼   | 仅当本命令中的“查询条件”参数为“BAOC”时该参数有效。用于标识系统按照闭锁所有出呼叫业务的签约情况来查询用户数据。 取值范围： NOTPROV：未签约。PROV：签约。 默认值：无。                                                                                                                                                                                                   |
| CALLREDIRECT | 呼叫重定向类别  | 仅当本命令中的“查询条件”参数为“CALLREDIRECT”时该参数有效。用于标识系统按照呼叫重定向业务标识来查询用户数据。 取值范围：0～255 默认值：无。                                                                                                                                                                                                                |
| LOCK         | LCK锁     | 仅当本命令中的“查询条件”参数为“LOCK”时该参数有效。用于标识系统按照LCK锁的签约情况来查询用户数据。 取值范围： NOTPROV：同时未签约锁呼入业务（IC）、锁呼出业务（OC）、GPRS锁业务（GPRSLOCK）、闭锁CS位置更新业务（CSUPLLCK）和闭锁GPRS位置更新业务（PSUPLLCK）。PROV：同时签约IC、OC、GPRSLOCK、CSUPLLCK和PSUPLLCK。 默认值：无。                                                                                   |
| RROPTION     | 区域漫游限制选项 | 仅当本命令中的“查询条件”参数为“RROPTION”时该参数有效。用于标识系统按照区域漫游限制情况来查询用户数据。 取值范围： ALL_PLMNS：允许在所有的移动网络中漫游。ONE_NPLMN_ALL_FPLMNS：允许在归属移动网络和其它所有国际移动网络中漫游。ONLY_HPLMN：只允许在归属移动网络中漫游。RR_TEMPLATE：根据区域漫游模板来限制用户漫游。 默认值：无。                                                                                               |
| NRBT         | NRBT索引   | 仅当本命令中的“查询条件”参数为“NRBT”时该参数有效。用于标识系统按照NRBT业务的索引来查询用户数据。 取值范围：1～65535 默认值：无。                                                                                                                                                                                                                      |

## 使用实例

1. 批量查询所有开户用户的数目：

   ```
   LST CONSUBDATA: RESULT=CountOfSub, RANGE=AllSub;
   ```

   ```
   %%LST CONSUBDATA: RESULT=CountOfSub, RANGE=AllSub;%%
   RETCODE = 0 SUCCESS0001:操作成功

   CountOfSub-2012-04-24-09-36-32-192.txt

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 批量查询“111111111111111”～“666666666666666”号段内所有开户用户的IMSI号码：

   ```
   LST CONSUBDATA: RESULT=DataOfSub, RANGE=RangeByIMSI, RANGEPARA1="111111111111111", RANGEPARA2="666666666666666";
   ```

   ```
   %%LST CONSUBDATA: RESULT=DataOfSub, RANGE=RangeByIMSI, RANGEPARA1="111111111111111", RANGEPARA2="666666666666666";%%
   RETCODE = 0 SUCCESS0001:操作成功

   DataOfSub-2012-04-24-09-50-26-026.txt

   Total count = 1

   There is together 1 report

   ---    END
   ```
3. 按照“网络接入模式”条件查询时，批量查询满足条件的用户数目：

   ```
   LST CONSUBDATA: RESULT=CountOfSub, RANGE=AllSub, CONDITION=NAM, NAM=BOTH;
   ```

   ```
   %%LST CONSUBDATA: RESULT=CountOfSub, RANGE=AllSub, CONDITION=NAM, NAM=BOTH;%%
   RETCODE = 0 SUCCESS0001:操作成功

   CountOfSub-2012-10-24-15-06-12-172.txt

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释          | 原因分析                                      | 处理建议                                       |
|:--------|:---------------|:------------------------------------------|:-------------------------------------------|
| ERR1004 | 无效的参数值         | 参数“起始IMSI”或“结束IMSI”的取值不是6～15位十进制数字组成的字符串。 | 根据实际情况，重新输入“起始IMSI”或“结束IMSI”的取值，确保其取值符合要求。 |
| ERR1026 | 结束参数应大于/晚于起始参数 | “起始IMSI”的取值大于“结束IMSI”的取值。                 | 根据实际情况，重新输入参数，并确保“起始IMSI”的取值小于“结束IMSI”的取值。 |
