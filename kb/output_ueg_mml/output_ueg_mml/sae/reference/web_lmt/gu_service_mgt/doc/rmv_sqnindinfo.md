# 删除SQN的IND分域配置(RMV SQNINDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本令用于删除一条SQN IND分域配置记录。

## 注意事项

配置的“IND分域序列号”在**ADD AMF**命令中被索引时，不支持删除。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                               |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号   | 可选必选说明：必选参数 参数含义：标识IND分域记录的关键字段之一，用于指定需要对哪个HLR上的IND分域记录进行删除，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。      |
| INDSNO | IND分域序列号 | 可选必选说明：必选参数 参数含义：标识IND分域记录的关键字段之一，用于指定需要对哪个IND分域记录的参数进行删除，操作员可以使用LST SQNINDINFO命令查询获得。 取值范围：0～65534 默认值：无。 配置原则：无。 |

## 使用实例

删除“HLR序列号”为“1”，“IND分域序列号”为“1”的配置记录：

```
RMV SQNINDINFO: HLRSN=1, INDSNO=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                  | 处理建议                                                                                                                                                                                     |
|:--------|:--------|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面报错的参数不在取值范围内。                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                         |
| ERR3005 | 模板已经被使用 | 待删除的SQNINDINFO记录在ADD AMF命令中被索引，不支持删除。 | 根据实际情况，建议如下处理：如果配置记录达到上限，需要删除记录后重新添加，则执行LST SQNINDINFO命令查看已配置的记录，并执行LST AMF命令查看被引用的“IND分域序列号”，选择不需要继续使用且没有被引用的记录，重新执行本命令删除。如需删除当前输入的SQNINDINFO记录，请执行RMV AMF命令删除被引用的“IND分域序列号”，然后执行本命令删除。 |
| ERR3007 | 记录不存在   | 待删除的“HLR序列号”对应的配置记录不存在。               | 执行LST SQNINDINFO命令查询已配置的记录，根据实际情况，选择已配置的“HLR序列号”然后执行本命令删除。                                                                                                                               |
