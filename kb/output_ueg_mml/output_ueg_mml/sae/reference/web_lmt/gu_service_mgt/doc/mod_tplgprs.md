# 模板修改GPRS业务(MOD TPLGPRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作采用GPRS模板来为用户提供、修改或删除GPRS业务。

开局场景下，如果需要签约多个GPRS模板，在**SET MAPSERV**命令中设置“GPRSMANAGER”参数值为“SupportGPRSManager”。“GPRSMANAGER”参数开局设定之后不能修改，如非开局场景，请勿修改此参数配置。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 参数PROV设置为TRUE，参数TPLID为必选参数，否则为可选参数。
- 去签约GPRS业务时，如果不携带参数TPLID，则表示去签约用户所有的GPRS业务。
- 当用户签约多个GPRS业务时，如果通过模板去签约GPRS业务，则将会去签约所有与模板中APN相同的GPRS业务。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                |
|:------------|:-----------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI       | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                     |
| ISDN        | MSISDN     | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                   |
| RECORDCOUNT | 用户个数       | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名    | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                       |
| ISDNFILE    | MSISDN文件名  | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                     |
| PROV        | 是否提供GPRS业务 | 是否向用户提供GPRS业务。 TRUE：提供/修改 FALSE：撤销                                                  |
| TPLID       | GPRS模板ID   | 仅当本命令中的“是否提供GPRS业务”参数不为空时该参数有效。用于标识GPRS模板ID。 取值范围：0～65534 默认值：无。                    |

## 使用实例

1. 给IMSI号为123456789012345的用户增加GPRS业务，GPRS模板ID为123。执行命令如下：

   ```
   MOD TPLGPRS: IMSI="460000009123456",PROV=TRUE,TPLID=123;
   ```
2. 给IMSI号为123456789012345的用户撤销GPRS业务。执行命令如下：

   ```
   MOD TPLGPRS: IMSI="460000009123456",PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                                                                                                 | 处理建议                                                                     |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------|
| ERR3111 | 系统不支持该特性 | 该命令不支持GPRS优化管理或者PS/EPS独立模板管理，即仅当SET MAPSERV命令中“GPRS管理方式”取值为“NotSupportGPRSManager” 或“SupportGPRSManager”时，该命令才能执行成功。 | 联系华为技术支持，确认当前局点软参“GPRS管理方式”是否设置正确、当前局点使用的GPRS管理方式是否正确。详情见“GPRS管理方式”软参描述。 |
