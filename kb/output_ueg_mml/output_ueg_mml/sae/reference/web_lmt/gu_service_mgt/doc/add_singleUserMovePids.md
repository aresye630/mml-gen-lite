# 增加4升5迁移指令PID规则(ADD SINGLEUSERMOVEPIDS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条4升5迁移指令PID规则。

在**SET MAPSERV**命令的“单用户迁移增强”参数取值“NSA\_ADDSUB\_MOVE\_SRCPIDS2DESTPIDS” 或“SA\_ADDSUB\_MOVE\_SRCPIDS2DESTPIDS”的场景下，将CloudDB版本或ATCA版本HSS上的5G SA或者NSA用户数据迁移至UDM。

## 注意事项

系统最大支持添加100个4升5迁移指令PID规则。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------|
| SRCPID  | 用户源PID | 可选必选说明：必选参数 参数含义：用于标识用户的源PID信息，源PID只能增加一条且必须是CloudDB版本或ATCA版本的HSS。 取值范围：1～250 默认值：无。 配置原则：无。 |
| DESTPID | 用户新PID | 可选必选说明：必选参数 参数含义：用于标识用户的目标PID信息，目的PID只能是UDM。 取值范围：1～250 默认值：无。 配置原则：无。                       |

## 使用实例

添加“用户源PID”为“21”，“用户新PID”为“81”的4升5迁移指令PID规则。

```
ADD SINGLEUSERMOVEPIDS: SRCPID=21, DESTPID=81;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释           | 原因分析                                                   | 处理建议                                                                                                                                                                                             |
|:--------|:----------------|:-------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3006 | 记录已存在           | “用户源PID”和“用户新PID”已配置4升5迁移指令PID规则记录。                    | 执行LST SINGLEUSERMOVEPIDS查询已配置的4升5迁移指令PID规则，如需重新配置请执行RMV SINGLEUSERMOVEPIDS删除4升5迁移指令PID规则，再执行该命令重新配置。                                                                                             |
| ERR3047 | 超过最大限制          | 系统增加的4升5迁移指令PID规则数量超过100条。                             | 根据实际情况，如需增加4升5迁移指令PID规则，处理步骤如下： 执行命令，LST SINGLEUSERMOVEPIDS查询已存在的4升5迁移指令PID规则。执行RMV SINGLEUSERMOVEPIDS命令，删除不必要的4升5迁移指令PID规则。执行ADD SINGLEUSERMOVEPIDS命令增加4升5迁移指令PID规则，确保增加的4升5迁移指令PID规则数量在规定范围之内。 |
| ERR3380 | Partition ID不匹配 | 可能原因为如下之一： “用户源PID”不是CloudDB或ATCA版本的HSS。“用户新PID”不是UDM。 | 执行该命令时确保“用户源PID”是CloudDB或ATCA版本的HSS，“用户新PID”是UDM。                                                                                                                                                |
