## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用来修改系统中已存在的OP数据。

## 注意事项

- 如果修改指定的OP值已被使用，此操作是非常危险的。
- 如果CMCC鉴权增强开关打开，该命令不允许执行。可通过**LST MAPCONF**查看CMCC鉴权增强开关是否打开。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                           |
|:--------|:-------|:-----------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。   |
| OPSNO   | OP序列号  | 用于标识一个鉴权数据OP的序号。 取值范围：1～16777215 默认值：无。        |
| OPVALUE | OP值    | 用于标识一个32位鉴权数据OP的值。 取值范围：32位十六进制数字组成的字符串 默认值：无。 |

## 使用实例

修改OP序列号为1的记录，OP值修改为12345678901234561234567890123456。

```
MOD OP: HLRSN=1, OPSNO=1, OPVALUE="12345678901234561234567890123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                                                          | 处理建议                                             |
|:--------|:------------|:--------------------------------------------------------------|:-------------------------------------------------|
| ERR4086 | 随机密钥默认ID未设置 | 要使用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。 |
| ERR4133 | 密钥丢失        | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                      |
