# 增加支持一卡多号的VLR信息(ADD OCMNVLR)

## 命令功能

该命令用于增加虚拟HLR上的VLR号码前缀和MSISDN号码前缀的对应关系，该对应关系用于特殊一卡多号业务用户在漫游地进行CS域位置更新流程中，在下发用户数据时，UDM会先根据位置更新流程中携带的当前VLR号码与该命令配置的VLR前缀号码相比较，根据匹配结果再对本命令已配置的MSISDN号码前缀和用户签约的MSISDN（通过

**SET MULTISDN**

命令签约）进行匹配，根据最终匹配结果决定下发哪个MSISDN号码的数据到当前的MSC/VLR，匹配场景如表1所示：

| 多号码业务用户类型   | 消息携带的VLR号码与该命令配置的VLR前缀是否匹配   | 用户签约的号码与该命令配置的MSISDN前缀是否匹配   | 下发号码           |
|:------------|:-----------------------------|:-----------------------------|:---------------|
| OCMN类型      | 不匹配                          | -                            | 下发主号           |
| OCMN类型      | 匹配                           | 匹配                           | 下发和ISDN前缀匹配的号码 |
| OCMN类型      | 匹配                           | 不匹配                          | 下发主号           |

**说明** 

- 若用户为普通多MSISDN业务用户，则根据MSISDN号码处于的激活状态进行下发，若主MSISDN号码处于激活状态则下发主号，辅MSISDN号码处于激活状态则下发辅号。（用户的业务类型可通过**SET MULTISDN**命令中的“多MSISDN业务类型”参数设置，可通过**LST SUB**命令查询。MSISDN号码的激活状态可通过**MOD MNUG**设置，通过**LST MNUG**查询。）
- PS/EPS位置更新时，所有场景都下发主号。

## 注意事项

系统中增加的VLR号码前缀和MSISDN号码前缀的对应关系记录数不能超过3000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                          |
|:-----------|:---------|:----------------------------------------------|
| HLRSN      | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。  |
| VLRPREFIX  | VLR号码前缀  | 用于标识一个VLR号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。  |
| ISDNPREFIX | ISDN号码前缀 | 用于标识一个ISDN号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

增加“HLR序列号”为“1”的虚拟HLR上的漫游地和ISDN的对应关系，“VLR号码前缀”为“8866”，“ISDN号码前缀”为“180”，命令如下：

```
ADD OCMNVLR: HLRSN=1, VLRPREFIX="8866", ISDNPREFIX="180";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|:--------|:--------|:---------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3006 | 记录已存在   | 输入的“HLR序列号”、“VLR号码前缀”及“ISDN号码前缀”三个参数值对应的数据记录已经添加过。 | 请先使用LST OCMNVLR命令查询已添加过的数据记录，根据查询结果重新输入“HLR序列号”、“VLR号码前缀”及“ISDN号码前缀”三个参数值，确保这三个参数中至少有一个参数值未在查询结果中存在。                                                                                     |
| ERR3007 | 记录不存在   | 输入的“HLR序列号”未在系统中添加。                                | 请确认输入的“HLR序列号”是否正确，若输入错误，请重新输入；若输入无误，则必须先通过ADD HLRSN命令添加要输入的“HLR序列号”，然后再执行该命令添加新的记录信息。                                                                                                   |
| ERR3047 | 超过最大限制  | 增加的“VLR号码前缀”与“ISDN号码前缀”对记录数超过3000条。                | 根据实际情况，如需增加VLR号码前缀和MSISDN号码前缀对，处理步骤如下：执行LST OCMNVLR命令，查询已存在的VLR号码前缀和MSISDN号码前缀对。执行RMV OCMNVLR命令，删除不必要的VLR号码前缀和MSISDN号码前缀对。执行该命令增加VLR号码前缀和MSISDN号码前缀对，确保增加的VLR号码前缀和MSISDN号码前缀对记录数在规定范围之内。 |
| ERR1040 | 记录超过上限  | 添加的数据记录数量超过3000个。                                  | 若要继续添加新的数据记录，请先使用RMV OCMNVLR命令删除旧的不需要的数据记录，确保删除后的总数据记录数量不超过3000，然后再使用本命令添加新的数据记录。                                                                                                        |
| ERR1004 | 无效的参数值  | 输入的“VLR号码前缀”或“ISDN号码前缀”参数不在取值范围内。                  | 请参考参数的取值范围进行输入。                                                                                                                                                                          |
