# 设置用户缺省漫游限制(SET DEFHLRRR)

- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响该HLRSN中用户的漫游能力（如：在本命令设置了“缺省漫游限制状态”参数为“漫游限制”，导致正常用户被漫游限制引起业务受损），因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，需要与华为技术支持联系制定修改的实施方案、测试方案和回退方案后才可以实施。

该命令用于设置HLRSN中的用户在未设置“VLR/SGSN号码前缀”对应的端局下是否允许漫游的能力。

## 注意事项

- “缺省漫游限制状态”参数作用范围为整个HLRSN，只能通过该命令设置，无法删除。如果设置不当将导致该HLRSN下的用户，在未设置的“VLR/SGSN号码前缀”下不能正常漫游。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                              |
|:----------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN           | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                      |
| ROAMDEFAULTRULE | 缺省漫游限制状态 | 用于标识HLR中所有用户的缺省漫游限制状态，即用户漫游到未设置漫游限制状态的VLR/SGSN中时，是否允许漫游。 取值范围：PERMISSION：漫游允许。 RESTRICT：漫游限制。 系统初始设置值：PERMISSION 说明：系统初始设置值，是指操作员通过LST HLRRR命令查询得出的系统在初始化时的预置参数值。 |

## 使用实例

允许HLR中所有用户在全网范围内漫游。命令如下：

```
SET DEFHLRRR: HLRSN=1, ROAMDEFAULTRULE=PERMISSION;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                    |
|:--------|:--------|:-------------|:----------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。 | 根据实际情况，重新输入参数“HLR序列号”，确保输入的“HLR序列号”已定义。 |
