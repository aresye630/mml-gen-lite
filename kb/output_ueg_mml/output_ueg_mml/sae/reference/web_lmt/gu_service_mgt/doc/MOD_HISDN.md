# 修改MSISDN号码(MOD HISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中修改一个已经存在的MSISDN，唯一标识该数据记录的关键参数是MSISDN。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                           |
|:--------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| ISDN    | MSISDN   | 标识一条MSISDN数据记录的关键参数（其取值不能被修改），用于指定需要对哪一条MSISDN数据记录的参数进行修改或调整。MSISDN由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围： 长度不超过15的字符串 缺省值： 无 |
| NEWISDN | 新的MSISDN | 用于指定标识一条新MSISDN数据记录。MSISDN由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围： 长度不超过15的字符串 缺省值： 无                                          |

## 使用实例

修改ISDN号码。MSISDN：8613988888888，新的MSISDN：8613977777777。

```
MOD HISDN: ISDN="8613988888888", NEWISDN="8613977777777";
```
