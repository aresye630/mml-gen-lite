# 删除SMF注册信息数据(RMV SMFREGINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除用户的SMF注册信息数据。

- 若需要删除单个用户的SMF注册信息数据，请输入参数“IMSI”，其他参数不输入。
- 若需要删除连续多个用户的SMF注册信息数据，请输入参数“IMSI”，再输入参数“用户个数”，其他参数不输入。
- 若需要删除不连续的多个用户的SMF注册信息数据，请输入参数“IMSI文件名”，其他参数不输入。
- 若“PDU会话ID”未填写，则删除该用户所有的SMF注册信息数据。

## 注意事项

- “IMSI”、“IMSI文件名”两个参数不能同时输入，否则会提示参数错误。
- “用户个数”不能与“IMSI文件名”不能同时输入，否则会提示参数错误。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                     |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除SMF注册信息数据的用户的“IMSI号码”。 取值范围：6~15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                 |
| SESSIONID   | PDU会话ID | 可选必选说明：可选参数 参数含义：用于标识不同PDU Session，区分不同的UE与提PDU connectivity service的数据网络之间的关联。 取值范围：0~ 4294967295的无符号数字。 默认值：无。 配置原则：无。                                                                                                                                                 |
| RECORDCOUNT | 用户个数    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照设置的用户个数来删除对应用户的SMF注册信息数据。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户删除用户的SMF注册信息记录时配置该参数，配置后，系统将会从已指定的IMSI号码开始，对连续号码的多个用户进行删除用户的SMF注册信息记录。该参数是对连续号码的多个用户删除用户的SMF注册信息记录，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名 | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1~16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除SMF注册信息数据的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsmfreginfo.txt”，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                                        |

## 使用实例

1. 删除“IMSI号码”为“460000009123456”的用户SMF注册信息数据。

   ```
   RMV SMFREGINFO: IMSI="460000009123456";
   ```
2. 删除“IMSI号码”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户的SMF注册信息数据。

   ```
   RMV SMFREGINFO: IMSI="460000009123456", RECORDCOUNT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                              |
|:--------|:--------|:-------------------------------------------------------|:----------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。                         | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                   |
| ERR3001 | 用户未开户   | 用户的IMSI号码输入错误，实际输入的参数“IMSI”对应的用户未开户。                   | 核实IMSI号码，确保其对应的用户为5G用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”对应的用户未开户，请参考ADD SUB页面给用户开户。 |
| ERR1010 | 参数冲突    | 可能的原因为如下之一： “IMSI”和“IMSI文件名”同时输入。“用户个数”和“IMSI文件名”同时输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”和“IMSI文件名”不能同时配置。“用户个数”和“IMSI文件名”不能同时配置。            |
