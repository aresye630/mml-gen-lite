# 增加5GS DNN QoS模板(ADD DNNQOSTPL)

## 命令功能

该命令用于在系统中增加5GS DNN QoS（Quality of Service）模板数据记录。

5GS DNN是指5G网络的数据网络名称，QoS是指网络通信过程中，允许用户业务在丢包率、延迟、抖动和带宽等方面获得可预期的服务水平，通过执行**ADD SMDATA**命令为用户签约5GS DNN QoS业务，只需签约对应的5GS DNN QoS模板。

## 注意事项

所有“HLR序列号”中增加的5GS DNN QoS模板记录数不能超过20000条。

## 使用实例

5G用户开户前，运营商需要提前在系统中增加5GS DNN QoS模板，以便后续签约给用户使用。

1. 增加一个5GS DNN QoS模板。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“test”，“默认PDU类型”为“IPV4”，“其他允许的PDU型”为“IPV6”，“默认SSC模式”为“SSC\_MODE\_1”，“其他允许的SSC模式”为“SSC\_MODE\_2”，“是否签约EPS互操作”为“FALSE”，“是否为LADN”为“FALSE”，“是否允许Local Break Out”为“FALSE”，“5GC QoS模板ID”为“80”，“DNN级别上行速率”为“100”,“DNN级别上行速率单位”为“Mbps”，“DNN级别下行速率”为“1”, “DNN级别下行速率单位”为“Mbps”，“计费特性”为“1111”,“用户面完整性保护策略”为“NOT\_NEEDED”，“用户面机密性保护策略”为“NOT\_NEEDED”：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV6, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, IWKEPSIND=FALSE, LADN=FALSE, LBO=FALSE, NGCQOSTPLID=80, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```
2. 增加一个5GS DNN QoS模板。“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“test”，“默认PDU类型”为“IPV6”，“其他允许的PDU型”为“IPV4”，“默认SSC模式”为“SSC\_MODE\_2”，“其他允许的SSC模式”为“SSC\_MODE\_3”，“是否签约EPS互操作”为“TRUE”，“是否为LADN”为“TRUE”，“是否允许Local Break Out”为“FALSE”，“5GC QoS模板ID”为“3”，“DNN级别上行速率”为“100”,“DNN级别上行速率单位”为“Mbps”，“DNN级别下行速率”为“1”, “DNN级别下行速率单位”为“Mbps”，“计费特性”为“1111”,“用户面完整性保护策略”为“NOT\_NEEDED”，“用户面机密性保护策略”为“NOT\_NEEDED”, “是否需要二次认证授权”为“TRUE”，“PDU会话建立是否需要SMF向DN-AAA请求UE的IP地址”为“TRUE”，“用于二次认证授权的DN-AAA服务器Ipv4地址”为“192.168.100.0”，“到相同DNN和S-NSSAI的多个PDU会话是否需要相同的SMF”为“TRUE”，“使用静态IP地址/前缀时的相关SMF列表”为“00000000-0000-0000-0000-000000000000”：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=3, TPLNAME="test", PDUTYPE=IPV6, ALLOWEDPDUTYPE=IPV4, SSCMODE=SSC_MODE_2, ALLOWEDSCCMODE=SSC_MODE_3, IWKEPSIND=TRUE, LADN=TRUE, LBO=FALSE, NGCQOSTPLID=3, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED, SECONDARYAUTH=TRUE, AAAIPALLOCATION=TRUE, AAAIPV4ADDR="192.168.100.0", SAMESMFIND=TRUE, SMFLIST="00000000-0000-0000-0000-000000000000";
   ```
