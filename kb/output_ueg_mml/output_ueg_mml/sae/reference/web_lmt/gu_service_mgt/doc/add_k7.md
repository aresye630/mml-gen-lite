# 增加K7(ADD K7)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于增加K7密钥。KI值是为用户鉴权而设。建议给KI值进行加密。给KI值加密时可以使用K2密钥，而K2密钥还可以使用K7密钥进行加密，而K7密钥还可以使用私有密钥进行加密，从而实现对KI值的多次加密。

## 注意事项

- 添加K7密钥成功后，请使用**CHK K7**命令校验“K7值”。

  **说明** 

  当K7的密钥输入方式选择“HSM\_MBK”时，**CHK K7**命令不适用检查已添加的K7密钥是否正确。系统会每10s检测PGW输入的K7的HASH值和HSM上的MBK的HASH值是否一致，如果不一致，则系统上报告警。
- 当**LST K7**命令查询K7密钥时返回的“STATE”为“LOSE”时，可以通过**ADD K7**命令再次添加K7密钥，此时添加的K7密钥必须和先前添加的K7密钥相同，否则可能引起业务异常。
- “K7密钥输入方式”三种取值方式的说明如下：
  - “K7密钥输入方式”为“ClearKey”时，参数“K7值”为必选参数。
  - “K7密钥输入方式”为“6EyesRule”时， K7密钥输入使用六眼法则。即K7由三部分组成，三部分长度合计32位或64位。每部分由不同的操作人员输入，并且每部分输入两遍。如果两次输入不等，会弹出提示框提示“K7密钥的第1/2/3部分输入不一致，请重新输入”，请用户重新输入密钥。
  - “K7密钥输入方式”为“6EyesRule”时，参数“K7第一部分取值”、“K7第一部分取值确认”、“K7第二部分取值”、“K7第二部分取值确认”、“K7第三部分取值”和“K7第三部分取值确认”为必选参数。
  - “K7密钥输入方式”为“HSM\_MBK”时，“K7哈希值”和“MBK槽位号”为必选参数。
- “算法类型”为“AES128”，K7值必须为32位；“算法类型”为“AES256”，K7值必须为64位。
- “算法类型”为“AES128”和“AES256”的K7记录最多可以增加10个。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“ERR4086 随机密钥默认ID未设置”。

| PKEYSNO     | 私有密钥序列号    | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识对K7进行AES加密的私有密钥序列号。该参数必须先由ADD PRVTKEY命令定义，然后才能在此处引用。 取值范围：1～10。 默认值：无。                                                                                                                                                                  |

| KEYPART1CNF | K7第一部分取值确认 | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K7密钥第一部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                          |
| KEYPART2    | K7第二部分取值   | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K7密钥第二部分取值。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| KEYPART2CNF | K7第二部分取值确认 | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K7密钥第二部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                          |
| KEYPART3    | K7第三部分取值   | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K7密钥第三部分取值。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| KEYPART3CNF | K7第三部分取值确认 | 仅当本命令中的“K7密钥输入方式”参数为“6EyesRule”时该参数有效。用于标识K7密钥第三部分取值确认。 取值范围：8位～32位的十六进制数字组成的字符串。 默认值：无。                                                                                                                                                                                          |
| K7HASH      | K7哈希值      | 仅当本命令中的“K7密钥输入方式”参数为“HSM_MBK”时该参数有效。用于标识K7密钥的哈希值，即HSM上MBK的哈希值。可通过DSP HSMMBK命令查询获得。 取值范围：32位十六进制数字组成的字符串。 默认值：无。 说明：SET MAPCONF命令的“是否支持K7密钥”参数取值为“TRUE”时，UDM支持执行该命令添加K7密钥；取值为“FALSE”时，系统提示“ERR3111: 系统不支持该特性”。该参数取值“FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF”表示无效值，系统提示“ERR3044: 无效的参数取值”。 |

| ALGTYPE     | 算法类型       | 仅当本命令中的“K7密钥输入方式”参数为“ClearKey”或“6EyesRule”时该参数有效。用于标识K7值的加密算法类型。 AES128：K7值为32位的十六进制数字组成的字符串。AES256：K7值为64位的十六进制数字组成的字符串。 默认值：AES128。                                                                                                                                             |

## 使用实例

1. 在HSS/HLR中添加K7。“HLR序列号”为“1”，“K7序列号”为“1”，“K7值”为“1234567890abcde1234567890abcde12”：

   ```
   ADD K7: HLRSN=1, K7SNO=1, KEYTYPE=ClearKey, K7VALUE="*****";
   ```
2. 在HSS/HLR中添加K7。“HLR序列号”为“1”，“K7序列号”为“1”，“K7密钥输入方式”为“6EyesRule”，“私有密钥序列号”为“2”，“K7第一部分取值”为“1234567890a”，“K7第一部分取值确认”为“1234567890a”，“K7第二部分取值”为“bcde1234567”，“K7第二部分取值确认”为“bcde1234567”，“K7第三部分取值”为“890abcde12”，“K7第三部分取值确认”为“890abcde12”：

   ```
   ADD K7: HLRSN=1, K7SNO=1, KEYTYPE=6EyesRule, PKEYSNO=2, KEYPART1="*****", KEYPART1CNF="*****", KEYPART2="*****", KEYPART2CNF="*****", KEYPART3="*****", KEYPART3CNF="*****";
   ```
3. 在HSS/HLR中添加K7。“HLR序列号”为“1”，“K7序列号”为“1”，“K7密钥输入方式”为“HSM\_MBK”，“K7哈希值”为“DDCC0FA199DE65F1F8EEA129BB9664F9”，“MBK槽位号”为“3”：

   ```
   ADD K7: HLRSN=1, K7SNO=1, KEYTYPE=HSM_MBK, K7HASH="DDCC0FA199DE65F1F8EEA129BB9664F9", MBKSLOTNO=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR3044 | 无效的参数取值     | 输入的“K7哈希值”为无效值。                                                                                          | 参考参数的取值说明，重新输入“K7哈希值”执行该命令。                                                                                                               |

| ERR4133 | 密钥丢失        | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                                            | 联系华为技术支持处理。                                                                                                                               |
