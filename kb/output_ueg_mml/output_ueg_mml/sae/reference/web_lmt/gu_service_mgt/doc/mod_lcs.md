# 修改LCS业务(MOD LCS)

- 命令功能

- 参数说明

## 命令功能

该命令用于以模板方式为用户提供、撤销或修改LCS（Location Services）业务。

对于在网用户执行该命令后，如果是给用户签约该业务，则UDM会向MSC/VLR、SGSN或MME下发插入用户数据消息（Insert Subscriber Data）；如果是给用户去签约该业务，则UDM会向MSC/VLR、SGSN或MME下发删除用户数据消息（Delete Subscriber Data）。对于不在网用户执行该命令只更新数据库，当用户进行位置更新时UDM将用户的LCS业务数据下发给对端设备。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                    |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改LCS业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| ISDN        | MSISDN    | 用于标识需要修改LCS业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                |
| RECORDCOUNT | 用户个数      | 用于标识需要修改LCS业务的用户数目。 当需要为连续号码的多个用户修改LCS业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改LCS业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改LCS业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改LCS业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modlcs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                       |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改LCS业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modlcs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                 |
| PROV        | 是否提供LCS业务 | 用于标识执行该命令是提供/修改还是撤销LCS业务。 取值范围：TRUE：提供/修改，需要提供LCS业务的用户已经开户成功。FALSE：撤销，需要修改LCS业务的用户必须已经开户，并且已提供LCS业务。 默认值：无。                                                                                                             |
| TPLID       | 模板ID      | 仅当本命令中的“是否提供LCS业务”参数为“TRUE”时该参数有效。用于标识需要提供、修改或撤销的LCS业务模板ID。该参数必须先由ADD LCSTPL命令定义，然后才能在此处引用。执行MOD LCSTPL命令修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户。 取值范围：0～65534 默认值：无。                                                           |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供LCS业务，“是否提供LCS业务”为“TRUE”，“模板ID”为“2”：

   ```
   MOD LCS: IMSI="460000009123456", PROV=TRUE, TPLID=2;
   ```
2. 给3个连续号码的用户提供LCS业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“是否提供LCS业务”为“TRUE”，“模板ID”为“2”：

   ```
   MOD LCS: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, TPLID=2;
   ```
3. 给3个非连续号码的用户撤销LCS业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modlcs.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供LCS业务”为“FALSE”：

   ```
   MOD LCS: ISDNFILE="modlcs.txt", PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3003 | 模板未定义      | 当“是否提供LCS业务”参数为“TRUE”时，输入的“模板ID”参数对应的LCS模板在数据库中不存在。                                                | 当“是否提供LCS业务”参数为“TRUE”时，确保数据库中存在输入的“模板ID”对应的LCS模板。可以执行LST LCSTPL命令进行查询。                                                  |
