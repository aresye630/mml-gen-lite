# 设置业务签约信息共享(SET HSPSHARE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中指定一个“IMPU”与特定的“基本IMPU”共享Service Profile。

Service Profile即业务签约信息，是业务和用户相关数据的一个集合。当同一用户的多个号码签约同样业务时，操作员可以使用**SET HSPSHARE**命令设置Service Profile共享。

## 注意事项

- “IMPU”与“基本IMPU”必须已开户且同属一个IMS用户。
- 如果指定的“IMPU”所关联的Service Profile没有被其他IMPU共享时，执行该命令后，此Service Profile会被删除。例如，指定的“IMPU”当前关联的Service Profile为SP1，“基本IMPU”当前关联的Service Profile为BaseSP，通过设置Service Profile共享可以将指定的“IMPU”关联的Service Profile由SP1改变为BaseSP，当SP1无其他IMPU共享时，会被自动删除。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| BASEIMPU | 基本IMPU | 用于指定一个“基本IMPU”，其关联的Service Profile被共享，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。     |
| IMPU     | IMPU   | 用于指定一个需要共享“基本IMPU”的Service Profile的“IMPU”，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

设置业务签约信息共享，“基本IMPU”为“sip:impuinfo\_base@huawei.com”，“IMPU”为“sip:impuinfo@huawei.com”：

```
SET HSPSHARE: BASEIMPU="sip:impuinfo_base@huawei.com", IMPU="sip:impuinfo@huawei.com";
```
