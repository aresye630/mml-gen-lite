# 修改共享iFC模板信息(MOD HSIFCINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该操作用于在HSS的业务数据库中修改指定共享iFC模板中的已经存在的共享iFC信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条共享iFC模板记录：

- “共享iFC模板ID”
- “优先级”

## 注意事项

- 修改了共享iFC模板信息的参数可能会影响用户业务，请操作员在执行该操作之前仔细确认任务的可行性。
- 待修改的可选参数必须至少设置其中一个，否则HSS返回失败。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识          | 参数名称                              | 参数说明                                                                                                                                                                                                                                                                       |
|:--------------|:----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号                            | 用于标识一个HLR序列号。 可选必选说明：可选参数 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                                                                                                                                       |
| SIFCTPLID     | 共享iFC模板ID                         | 用于标识一个共享iFC模板ID索引，系统可以通过该索引找到需要修改共享iFC模板信息的共享iFC模板。操作员可以使用LST HTPLINF命令查询获得。 可选必选说明：必选参数                                                                                                                                                                                   |
| IFCNAME       | iFC名称                             | 用于标识所要修改共享IFC模板的IFC信息名称。 可选必选说明：可选参数 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                                                                                                               |
| PRIORITY      | 优先级                               | 用于指定一个新共享iFC的优先级。需要指出的是，该参数数字越小，优先级越高，0代表最高优先级。 可选必选说明：必选参数 取值范围：0～65535 默认值：无。                                                                                                                                                                                            |
| PARTIND       | 业务相关性                             | 用于指定共享iFC是与注册业务相关还是与非注册业务相关。 可选必选说明：可选参数 取值范围： REGISTERED(Registered)：与注册业务相关，即当用户当前注册状态为注册时，触发该共享iFC。UNREGISTERED(Unregistered)：与未注册业务相关，即当用户当前注册状态为未注册时，触发该共享iFC。PARTIND_DEFAULT(Default)：以上两种状态都会触发的业务。 默认值：无。                                                          |
| SERVER        | 共享iFC的AS地址                        | 用于指定共享iFC所要触发的AS地址。该参数的配置规则是：地址格式必须为SIP格式。需要和对端网元（AS）配置的地址一致，若不一致，HSS将无法完成发往对端网元的业务处理。 可选必选说明：可选参数 取值范围：由字母、十进制数字、“.”、“:”、“;”、“=”、“?”、“@”、“&”等特殊字符或转义字符“\”组成的长度不超过127的字符串。 默认值：无。 配置约束：该参数的配置需要满足SIP标准协议，如果输入中包含“;”和“=”，则在这些特殊字符前添加转义字符“\”。                                |
| DEFHND        | 默认处理方式                            | 用于指定一个触发指定AS失败后的处理方式。 可选必选说明：可选参数 取值范围： SESSION_CONTINUED(Session continued)：会话继续。SESSION_TERMINATED(Session terminated)：会话中止。DEFHANDLING_DEFAULT(Default handling)：由AS决定如何处理该会话。 默认值：无。                                                                                   |
| SERVINFO      | 业务信息                              | 用于指定该共享iFC的描述。 可选必选说明：可选参数 取值范围： 长度不超过127的字符串 默认值： 无。                                                                                                                                                                                                                      |
| INCLUDEREGREQ | 携带第一方注册请求                         | 用于指定S-CSCF发起第三方注册时，是否携带第一方注册的请求消息内容。 可选必选说明：可选参数 取值范围： NO(No)：不携带。YES(Yes)：携带。 默认值： 无。                                                                                                                                                                                     |
| TRIGPT        | 触发点                               | 用于指定该共享iFC的触发点。触发点用来决定是否去触发应用服务器。它的运算规则有两种：结合范式CNF（Conjunctive Normal Form）和非结合范式DNF（Disjunctive Normal Form），这两种运算规则总称正规表达式。若是没有触发点实例，则表明是无条件触发到申请服务器上。 可选必选说明：可选参数 取值范围：长度不超过3072的字符串 默认值：无。 配置原则：该参数的配置需要满足结合范式CNF和非结合范式DNF运算规则，如果输入中包含特殊字符（\";,'=），则在这些特殊字符前添加转义字符“\”。 |
| INCLUDEREGRSP | iFC是否携带IncludeRegisterResponse标志位 | 用于指定S-CSCF发起第三方注册时，iFC是否携带IncludeRegisterResponse标志位。该参数取值需要与网络中S-CSCF对接的AS设备协商确定。 可选必选说明：可选参数 取值范围：NO(No)：不携带。YES(Yes)：携带。 默认值：无。                                                                                                                                         |

## 使用实例

1. 修改共享iFC模板中的iFC信息，“共享iFC模板ID”为“10”，“优先级”为“10”，“共享iFC的AS地址”为“sip:as.huawei.com”：

   ```
   MOD HSIFCINF: SIFCTPLID=10, PRIORITY=10, SERVER="sip:as.huawei.com";
   ```
2. 修改共享iFC模板中的iFC信息，“共享iFC模板ID”为“10”，“iFC名称”为“as host”，“优先级”为“5”，“业务相关性”为“REGISTERED(Registered)”，“共享iFC的AS地址”为“sip:AS@huawei.com”，“默认处理方式”为“SESSION\_TERMINATED(Session terminated)”，“业务信息”为“Mode AS”：

   ```
   MOD HSIFCINF: SIFCTPLID=10, IFCNAME="as host", PRIORITY=5, PARTIND=REGISTERED, SERVER="sip:AS@huawei.com", DEFHND=SESSION_TERMINATED, SERVINFO="Mode AS";
   ```
