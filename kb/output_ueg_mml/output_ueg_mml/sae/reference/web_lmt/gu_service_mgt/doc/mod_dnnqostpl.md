## 命令功能

**须知** 

该命令属于高危命令，修改5GS DNN QoS模板会使引用此模板的用户5GS DNN QoS数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对一条5GS DNN QoS模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个5GS DNN QoS模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 使用实例

1. 修改5GS DNN QoS模板。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“dnnqostpl”，“默认PDU类型”为“IPV6”，“其他允许的PDU型”为“IPV4”，“默认SSC模式”为“SSC\_MODE\_1”，“其他允许的SSC模式”为“SSC\_MODE\_2”，“是否签约EPS互操作”为“TRUE”，“是否为LADN”为“TRUE”，“是否允许Local Break Out”为“FALSE”，“5GC QoS模板ID”为“80”，“DNN级别上行速率”为“3000”，“DNN级别上行速率单位”为“Mbps”，“DNN级别下行速率”为“1”，“DNN级别下行速率单位”为“Mbps”，“计费特性”为“1111”,“用户面完整性保护策略”为“NOT\_NEEDED”，“用户面机密性保护策略”为“NOT\_NEEDED”：

   ```
   MOD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="dnnqostpl", PDUTYPE=IPV6, ALLOWEDPDUTYPE=IPV4, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, IWKEPSIND=TRUE, LADN=TRUE, LBO=FALSE, NGCQOSTPLID=80, AMBRUP=3000, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```
2. 修改5GS DNN QoS模板。“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“tests”，“默认PDU类型”为“IPV4V6”，“其他允许的PDU型”为“IPV4”，“默认SSC模式”为“SSC\_MODE\_1”，“其他允许的SSC模式”为“SSC\_MODE\_2”，“是否签约EPS互操作”为“FALSE”，“是否为LADN”为“FALSE”，“是否允许Local Break Out”为“FALSE”：

   ```
   MOD DNNQOSTPL: HLRSN=1, TPLID=3, TPLNAME="tests", PDUTYPE=IPV4V6, ALLOWEDPDUTYPE=IPV4, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, IWKEPSIND=FALSE, LADN=FALSE, LBO=FALSE;
   ```
