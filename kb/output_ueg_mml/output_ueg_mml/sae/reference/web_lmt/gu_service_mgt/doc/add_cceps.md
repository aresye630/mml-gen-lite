# 增加计费特性和EPS数据对应关系(ADD CCEPS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条计费特性和EPS数据对应关系记录。

## 注意事项

系统中增加的计费特性和EPS数据对应关系记录数不能超过3000条。

## 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:--------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号           | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| STDCHARGE     | 标准计费特性           | 用于标识标准计费特性，实现计费特性和标准计费特性两种计费控制方式，具体的计费方式需要在网络规划的时候决定并与设备商约定在业务流程中可以识别。针对所有PDP/PDN类型都生效。 取值范围：0000～FFFF（4位十六进制数字组成的字符串） 默认值：无。 说明：如果该参数为计费特性，则取值如下：0000：不签约计费特性。0100：热计费，实时计费。0200：平计费。0400：预付费用户。0800：普通用户。0300：热计费和平计费。0500：热计费和预付费。0600：平计费和预付费。0700：热计费、平计费和预付费。0900：热计费和普通计费。0A00：平计费和普通计费。0B00：热计费、平计费和普通计费。0C00：预付费和普通计费。0D00：热计费、预付费和普通计费。0E00：平计费、预付费和普通计费。0F00：热计费、平计费、预付费和普通计费。F100～FE00：为自定义计费特性。                                                                                               |
| OPTGPRSTPLID  | 优化GPRS模板ID       | 用于标识优化GPRS模板ID。该参数必须先由ADD OPTGPRSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 说明：在自动开户给用户签约EPS数据时，配置的“优化GPRS模板ID”对应的优化GPRS模板中的所有APN的“APN类型”建议配置为“EPS_APN”。原因如下：若“优化GPRS模板ID”对应的优化GPRS模板中的所有APN的“APN类型”均为“PS_APN”，则签约失败，HSS通过ULA消息给MME返回“DIAMETER_ERROR_UNKNOWN_EPS_SUBSCRIPTION”错误码。若“优化GPRS模板ID”对应的优化GPRS模板中存在“EPS_APN”或“BOTH”的APN，则签约成功。但在签约“BOTH”类型的APN时，可能会存在以下冲突，从而导致GPRS数据签约失败：该APN数据和用户PS域APN的PDP/PDN类型、PDP/PDN地址、APN模板ID全部相同。该APN数据和用户PS域的PDP/PDN上下文索引值相同（此时SET MAPCONF中参数“是否对ContextId自动排序”设置为“FALSE”）。 |
| AMBRMAXUL     | UE最大上行带宽         | 用于标识UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位为bit/s 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| AMBRMAXDL     | UE最大下行带宽         | 用于标识UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位为bit/s 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| DIAMNODETPLID | Diameter漫游限制模板ID | 用于标识Diameter漫游限制模板ID。该参数必须先由ADD DIAMRRTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PLMNTPLID     | PLMN漫游限制模板ID     | 用于标识PLMN区域漫游限制模板号。该参数必须先由ADD PLMNTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

增加一条计费特性和EPS数据对应关系记录：“HLR序列号”为“1”，“标准计费特性”为“0800”，“优化GPRS模板ID”为“2”，“UE最大上行带宽”为“500000”，“UE最大下行带宽”为“100000”：

```
ADD CCEPS: HLRSN=1, STDCHARGE="0800", OPTGPRSTPLID=2, AMBRMAXUL=500000, AMBRMAXDL=100000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:--------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                                        | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                             |
| ERR3003 | 模板未定义   | 输入的“优化GPRS模板ID”、“Diameter漫游限制模板ID”或“PLMN漫游限制模板ID”参数未定义。 | 根据实际情况，重新输入“优化GPRS模板ID”、“Diameter漫游限制模板ID”或“PLMN漫游限制模板ID”参数的取值，确保其存在。 已存在的“优化GPRS模板ID”可通过LST OPTGPRSTPL命令查询。已存在的“Diameter漫游限制模板ID”可通过LST DIAMRRTPL命令查询。已存在的“PLMN漫游限制模板ID”可通过LST PLMNTPL命令查询。 |
| ERR3006 | 记录已存在   | 输入的“HLR序列号”和“标准计费特性”对应的数据记录在数据库中已存在。                    | 根据实际情况，重新输入参数，确保输入的“HLR序列号”和“标准计费特性”与系统中已存在的不重复。可执行LST CCEPS命令查询已存在的计费特性和EPS数据对应关系记录。                                                                                                        |
| ERR3007 | 记录不存在   | 输入的“HLR序列号”未定义。                                         | 根据实际情况，重新输入参数“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                                                                                          |
| ERR3047 | 超过最大限制  | 增加的计费特性和EPS数据对应关系的记录数超过3000条。                           | 根据实际情况，如需增加计费特性和EPS数据对应关系的记录，处理步骤如下：执行LST CCEPS命令，查询已存在的计费特性和EPS数据对应关系记录。执行RMV CCEPS命令，删除不必要的计费特性和EPS数据对应关系记录。执行该命令增加计费特性和EPS数据对应关系记录，确保增加的计费特性和EPS数据对应关系记录数在规定范围之内。                         |
