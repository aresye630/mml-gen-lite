# 修改K2(MOD HK2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于对一条鉴权数据K2的数据记录中的K2名称进行修改或调整，在该命令中，系统通过“K2序列号”参数的来唯一标识一条鉴权数据K2的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------|
| K2SNO   | K2序列号  | 标识K2数据记录的关键字段（其取值不能被修改），用于指定需要对哪个K2序列号的K2数据记录的参数进行修改，操作员可以使用LST HK2命令查询获得。 |
| KEYNAME | K2名称   | 用于标识K2密钥名称。 取值范围：1位～60位的字符串。 默认值：无。                                        |

## 使用实例

修改一条K2数据记录，“K2序列号”为“3”，“K2名称”为“K2\_new”。

```
MOD HK2: K2SNO=10, KEYNAME="K2_new";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释            | 原因分析        | 处理建议                                               |
|----------:|:-----------------|:------------|:---------------------------------------------------|
| 900003520 | 请求消息中的K2Index不存在 | “K2序列号”未定义。 | 根据实际情况，重新输入已定义的“K2序列号”参数，可通过LST HK2命令查询已定义的K2数据记录。 |
