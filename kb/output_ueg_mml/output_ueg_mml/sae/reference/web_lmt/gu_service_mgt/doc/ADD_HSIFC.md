# 增加共享iFC(ADD HSIFC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中为指定“IMPU”或者“PUSI”相关的Service Profile添加一个新的共享iFC（Shared Initial Filter Criteria）。

当多个Service Profile有相同的iFC时，使用**ADD HSIFCTPL**命令增加共享iFC模板之后，执行该命令，设置此共享iFC模板与用户“IMPU”或“PUSI”的对应关系，以对用户的业务触发原则进行管理。

## 注意事项

- 每个“IMPU”或“PUSI”下最多可以添加32个共享iFC模板。
- “IMPU”和“PUSI”必须存在且只能存在一个。
- 如果为“IMPU”或“PUSI”签约超过8个共享iFC模板，增加的S-CSCF对端设备一定要启用“共享iFC”特性。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                                            |
|:-------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU      | 用于指定一个需要增加共享iFC的“IMPU”，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                 |
| PUSI   | PUSI      | 用于指定一个需要增加共享iFC的“PUSI”，要求输入的PUSI值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                 |
| SIFCID | 共享iFC模板ID | 用于指定一个共享iFC信息模板的序号，以方便对共享iFC信息模板进行查询和引用，配置原则是不能与该“IMPU”或者“PUSI”已经签约的共享iFC信息模板的模板ID重复。该参数必须先由ADD HSIFCTPL命令定义，然后才能在此处引用。 取值范围：0～65535 默认值：无 说明： 必选参数。当通过SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，该参数需要引用用户签约的“HLR序列号”下的共享iFC模板。 |

## 使用实例

增加共享iFC，“IMPU”为“sip:impuinfo@huawei.com”，“共享iFC模板ID”为“10”：

```
ADD HSIFC: IMPU="sip:impuinfo@huawei.com", SIFCID=10;
```
