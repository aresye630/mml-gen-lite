# 修改APN限制模板(MOD APNRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于修改APN限制模板，包括调整模板名称和增删APN。

## 注意事项

- APN限制模板中的最后一个APN不能通过本命令删除，即一个模板中至少要定义一个APN。
- 系统中同一个APN限制模板增加的接入点名称记录数不能超过200条，且所有APN限制模板增加的接入点名称总记录数不能超过3000条。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                            |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------|
| HLRSN        | HLR序列号  | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                    |
| APNRESTTPLID | 模板ID    | 用于标识待修改模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                           |
| TPLNAME      | 模板名     | 用于标识待修改模板在系统中的名称。 取值范围：1～60位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                |
| PROV         | 是否提供APN | 用于标识是增加还是删除指定的APN。 取值范围： TRUE：增加APN，此时参数“接入点名称”指定的APN必须在此模板中未定义。FALSE：删除APN，此时参数“接入点名称”指定的APN必须在此模板中已定义。 默认值：无。 |
| APN          | 接入点名称   | 仅当本命令中的“是否提供APN”参数为“TRUE”或“FALSE”时该参数有效。用于标识当前命令进行操作的APN名称。 取值范围：1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。      |

## 使用实例

1. 为一个APN限制模板新增一个APN，设置“HLR序列号”为“1”，“模板ID”为“2”，“是否提供APN”为“TRUE”“接入点名称”为“def.com”：

   `MOD APNRESTTPL: HLRSN=1, APNRESTTPLID=2, PROV=TRUE, APN="def.com";`
2. 从一个APN限制模板中删除一个APN，设置“HLR序列号”为“1”，“模板ID”为“2”，“是否提供APN”为“FALSE”“接入点名称”为“def.com”：

   `MOD APNRESTTPL: HLRSN=1, APNRESTTPLID=2, PROV=FALSE, APN="def.com";`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                     | 处理建议                                                                                                    |
|:--------|:--------|:-------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个“模板ID”增加的“接入点名称”数据记录数超过200条。所有APN限制模板增加的“接入点名称”总记录数超过3000条。 | 根据实际情况，如需增加接入点名称，处理步骤如下：执行LST APNRESTTPL命令，查询已存在的接入点名称。执行该命令删除不必要的接入点名称。执行该命令增加接入点名称，确保增加的接入点名称在规定范围之内。 |
