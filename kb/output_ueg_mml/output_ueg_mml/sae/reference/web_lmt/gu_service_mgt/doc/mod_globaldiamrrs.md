# 设置全局Diameter漫游限制(MOD GLOBALDIAMRRS)

- 命令功能

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响该HLRSN中用户的漫游能力，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于设置全局Diameter漫游限制业务数据。通过本命令可以为指定HLRSN中的所有用户签约或去签约全局Diameter漫游限制业务，签约后运营商不需要添加任何附加网络设备，可以限定该HLRSN中所有用户允许或禁止访问的MME/S4-SGSN服务范围，从而灵活高效的对用户进行移动性管理。

## 注意事项

- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的用户漫游限制的记录数不能超过3000条。
- 当“操作类型”参数为“ADD\_DIAM”时，“Diameter身份标识”、“Diameter身份标识类型”和“漫游限制状态”参数必须输入。
- 当“操作类型”参数为“MOD\_DIAM”时，“Diameter身份标识”参数必须输入，“Diameter身份标识类型”、“漫游限制状态”和“漫游限制时的错误码”参数至少输入一个。
- 当“操作类型”参数为“RMV\_DIAM”时，“Diameter身份标识”参数必须输入，不能输入“Diameter身份标识类型”、“漫游限制状态”和“漫游限制时的错误码”参数。
- 当未通过本命令设置或通过本命令删除某个HLRSN中Diameter身份标识对应的全局Diameter漫游限制相关数据时，该HLRSN中用户的全局Diameter缺省漫游限制数据生效。
- 通过该命令设置的数据只对S6a/S6d接口生效。

## 参数说明

| 参数标识             | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-----------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN            | HLR序列号         | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| OPTYPE           | 操作类型           | 用于标识执行该命令对全局Diameter漫游限制数据实现的操作类型。 取值范围：ADD_DIAM：表示增加全局Diameter漫游限制相关数据。MOD_DIAM：表示修改全局Diameter漫游限制相关数据。RMV_DIAM：表示删除全局Diameter漫游限制相关数据。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| DIAMIDENTITYTYPE | Diameter身份标识类型 | 仅当本命令中“操作类型”参数为“ADD_DIAM”或“MOD_DIAM”时该参数有效。用于标识Diameter身份标识类型。 取值范围： HOSTNAME：表示通过Diameter服务节点设备的主机名进行身份标识的认证和授权。REALMNAME：表示通过Diameter服务节点所在域的域名进行身份标识的认证和授权。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| DIAMIDENTITY     | Diameter身份标识   | 用于标识Diameter身份标识，该标识唯一确定一个Diameter服务节点。 取值范围：1～127个字符组成的相对域名格式字符串。 默认值：无。 说明：该字符串需满足以下条件：字符串开始和结束均不能是“.”。不能包含连续两个“.”。根据“.”拆分出每个字段，如果单个字段的长度大于63，则返回ERR1004“无效的参数值”错误码，且每个字段只能由数字、字母和“-”组成。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RULE             | 漫游限制状态         | 仅当本命令中“操作类型”参数为“ADD_DIAM”或“MOD_DIAM”时该参数有效。用于标识全局Diameter漫游的限制能力。当HLRSN中用户所在漫游区域的Diameter服务节点的身份标识与本命令设置的“Diameter身份标识”匹配时，根据该参数的取值判断是否允许用户漫游。 取值范围：PERMISSION：漫游允许RESTRICT：漫游限制 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## 使用实例

1. 为“HLR序列号”为“1”中的用户增加Diameter身份标识数据。“操作类型”为“ADD\_DIAM”，“Diameter身份标识类型”为“HOSTNAME”，“Diameter身份标识”为“test1.huawei.com”，“漫游限制状态”为“RESTRICT”：

   ```
   MOD GLOBALDIAMRRS: HLRSN=1, OPTYPE=ADD_DIAM, DIAMIDENTITYTYPE=HOSTNAME, DIAMIDENTITY="test1.huawei.com", RULE=RESTRICT;
   ```
2. 为“HLR序列号”为“2”中的用户修改Diameter身份标识数据。“操作类型”为“MOD\_DIAM”，“Diameter身份标识类型”为“REALMNAME”，“Diameter身份标识”为“test2.huawei.com”，“漫游限制状态”为“PERMISSION”：

   ```
   MOD GLOBALDIAMRRS: HLRSN=2, OPTYPE=MOD_DIAM, DIAMIDENTITYTYPE=REALMNAME, DIAMIDENTITY="test2.huawei.com", RULE=PERMISSION;
   ```
3. 删除“HLR序列号”为“3”的“Diameter身份标识”。“操作类型”为“RMV\_DIAM”，“Diameter身份标识”为“test3.huawei.com”：

   ```
   MOD GLOBALDIAMRRS: HLRSN=3, OPTYPE=RMV_DIAM, DIAMIDENTITY="test3.huawei.com";
   ```
