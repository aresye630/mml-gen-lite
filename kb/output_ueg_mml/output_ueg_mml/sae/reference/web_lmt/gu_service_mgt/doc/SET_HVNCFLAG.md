# 设置指定IMPU的IMS漫游权限检查标志(SET HVNCFLAG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU的IMS漫游权限检查标志，用于标识是否对用户的漫游权限进行检查。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                     |
|:--------|:---------|:-----------------------------------------------------------------------------------------|
| IMPU    | IMPU     | 用于指定一个需要设置漫游权限检查标识的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| VNCFLAG | 漫游权限检查标志 | 当枚举值为TRUE，表示需要检查漫游权限；枚举值为FALSE，表示不需要检查漫游权限。 取值范围：FALSE(False)TRUE(TRUE) 缺省值： 无           |

## 使用实例

设置指定IMPU的IMS漫游权限检查标志。IMPU：sip:impuinfo@huawei.com，漫游权限检查标志：TRUE。

```
SET HVNCFLAG: IMPU="sip:impuinfo@huawei.com", VNCFLAG=TRUE;
```
