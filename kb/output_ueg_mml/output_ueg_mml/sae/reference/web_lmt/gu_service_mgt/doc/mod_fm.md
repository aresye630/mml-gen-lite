# 修改FM业务数据(MOD FM)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

操作员通过此操作为某一个本地GSM用户提供/修改/删除FM业务的初始用户或者管理者，并可提供/修改/删除其COR签约。此命令也支持对多个用户进行FM业务数据的设置。但不支持辅号签约。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，任何一个参数出现即可，但不能同时出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 同一个GSM用户可以既签约初始用户，又签约管理者。签约的前提条件是该用户的NAM不能为SGSN用户。但在删除签约时，没有NAM的限制。
- 去签约FM业务的初始用户时，初始用户与远端号码的绑定关系将被解除，但不通知初始用户。
- 操作员修改初始用户的COR时，不影响本HLR或非本HLR建立的与远端号码的绑定关系。
- FM业务还与其他许多业务存在冲突，不能同时签约。这些业务包括：COMISDN、MIMSI、多SIM、多SIM增强、一卡多号多Profile、Home Zone、M2M COMISDN和M2M ISDN-Less。

## 参数说明

| 参数标识        | 参数名称                  | 参数说明                                                                                                                                                                                                                                                                                                                                                                                         |
|:------------|:----------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI                  | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                                                                                                                                                                                                                                                                                               |
| ISDN        | MSISDN                | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                                                                                                                                                                                                                                                                                             |
| RECORDCOUNT | 用户个数                  | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                                                                                                                                                                                                                                                          |
| IMSIFILE    | IMSI文件名               | IMSI文件名称，1~16个由字母、数字、下划线和点号组成的字符。IMSIFILE包含多个不连续的IMSI号码。                                                                                                                                                                                                                                                                                                                                     |
| ISDNFILE    | MSISDN文件名             | ISDN文件名称，1~16个由字母、数字、下划线和点号组成的字符。ISDNFILE包含多个不连续的MSISDN号码。                                                                                                                                                                                                                                                                                                                                   |
| PROV        | 是否提供FM业务的初始用户或管理者签约数据 | 提供/修改还是撤销用户FM业务的初始用户或管理者签约。 TRUE:提供或修改FALSE:撤销                                                                                                                                                                                                                                                                                                                                               |
| TYPE        | 签约类型                  | 对用户提供/修改/撤销FM业务的类型，是对初始用户签约还是对管理者签约进行操作。 Initiating subscriber: 初始用户Supervisor: 管理者                                                                                                                                                                                                                                                                                                          |
| CORSET      | COR集合                 | 仅当本命令中的“是否提供FM业务的初始用户或管理者签约数据”参数为“TRUE”时该参数有效，提供/修改或者删除用户的COR的集合。 值域： COR_1、COR_2、COR_3...COR_254、Delete_COR。 说明：最多可以选择5个COR（不包括Delete COR），也可以不签约任何COR。签约的COR必须是HLR已定义的。签约多个COR时，各COR之间用“&”连接。 不选择Delete COR，表示提供或修改用户的COR(若修改，则以修改后的COR为准)。 选择Delete COR和其他具体的COR，表示要删除所选择的COR。比如：选择Delete COR和COR_1，表示要删除用户角色中的COR_1。 如果只选择Delete COR，表示要删除用户的所有COR。 如果用户没有对COR进行设置，表示不修改COR，而不是删除全部的COR。 |

## 使用实例

为IMSI为460000009123456的用户提供FM业务的初始用户签约，且签约的角色集合为COR\_3&COR\_5&COR\_62&COR\_164。

```
MOD FM: IMSI="460000009123456", PROV=TRUE, TYPE=Initiating subscriber, CORSET=COR_3&COR_5&COR_62&COR_164;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                  | 处理建议                                                       |
|:--------|:--------|:----------------------|:-----------------------------------------------------------|
| ERR3114 | COR未定义  | 输入的“COR集合”参数中的COR未定义。 | 根据实际情况，重新输入“COR集合”参数，确保参数中的COR已定义，可通过LST COR命令查询已定义的COR数据。 |
