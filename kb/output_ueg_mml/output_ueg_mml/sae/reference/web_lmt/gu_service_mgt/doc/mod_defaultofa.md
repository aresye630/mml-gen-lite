# 修改默认OFA业务(MOD DEFAULTOFA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作为用户提供用户默认的OFA模板。登记前转号码时，将会根据默认OFA模板中配置的规则进行号码变换。当用户签约单个前转业务（CFU、CFB、CFNRY、CFNRC）时，如果没有提供业务级的OFA模板，那么登记前转号码时，此操作设置的OFA模板就会生效，来进行前转号码是否允许登记的处理。

当模板号为255时表示撤销用户默认的OFA模板。

## 注意事项

- 参数“IMSI”、“ISDN”、“IMSIFILE”、“ISDNFILE”是条件可选参数，有且只能有一个参数出现。参数“DEFAULTOFA\_ID”为必选参数。
- 执行**LST OFATPL**命令，查询“DEFAULTOFA\_ID”参数是否存在。如果不存在，请执行**ADD OFATPL**命令增加。

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                |
|:--------------|:----------|:------------------------------------------------------------------------------------|
| IMSI          | IMSI      | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                     |
| ISDN          | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                   |
| RECORDCOUNT   | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE      | IMSI文件名   | IMSI文件名称，1～16个字母或数字组成。IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。                   |
| ISDNFILE      | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。               |
| DEFAULTOFA_ID | OFA模板号    | OFA模板号。 参数范围：0～65534。 说明：255表示撤销用户默认的OFA模板。                                         |

## 使用实例

1. 为IMSI号码为460035589300001的用户提供默认的OFA模板。

   MOD DEFAULTOFA: IMSI="460035589300001", DEFAULTOFA\_ID=8;
2. 为IMSI号码为460035589300001的用户撤销默认的OFA模板。

   MOD DEFAULTOFA: IMSI="460035589300001", DEFAULTOFA\_ID=255;
