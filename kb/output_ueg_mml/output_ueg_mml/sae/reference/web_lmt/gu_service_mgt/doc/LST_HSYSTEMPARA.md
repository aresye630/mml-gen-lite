# 查询系统参数的值(LST HSYSTEMPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中查询系统参数的值。

## 注意事项

无。

## 参数说明

无。

## 使用实例

LST HSYSTEMPARA:;
