# 查询核心网接入类型限制(LST CNRESTRICT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询指定用户允许或限制接入指定的核心网。

- 若需要查询单个用户的核心网接入类型限制管理数据信息，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的核心网接入类型限制管理数据信息，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的核心网接入类型限制管理数据信息，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                   |
|:------------|:----------|:---------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于指示系统按照哪个“IMSI”来查询核心网接入类型限制管理数据。“IMSI”和“MSISDN”参数二选一。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。   |
| ISDN        | MSISDN    | 用于指示系统按照哪个“MSISDN”来查询核心网接入类型限制管理数据。“IMSI”和“MSISDN”参数二选一。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |
| RECORDCOUNT | 用户个数      | 用于指示系统需要查询多少个用户的核心网接入类型限制管理数据。                                                         |
| IMSIFILE    | IMSI文件名   | 用于指示系统按照哪个IMSI文件名来查询不连续的多个用户的核心网接入类型限制管理数据。                                            |
| ISDNFILE    | MSISDN文件名 | 用于指示系统按照哪个MSISDN文件名来查询不连续的多个用户的核心网接入类型限制管理数据。                                          |

## 使用实例

查询“IMSI”为“461120093456123”的用户的核心网接入类型限制管理数据信息：

```
LST CNRESTRICT: IMSI="461120093456123";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数含义请参见MOD CNRESTRICT命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                   | 处理建议                                                                                                               |
|:--------|:-----------|:-------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 参数取值范围不符。                                              | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                           |
| ERR1005 | 文件不存在      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。       | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                 |
| ERR1009 | 参数丢失       | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数同时缺失。       | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                        |
| ERR1010 | 参数冲突       | “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”和“MSISDN文件名”对应的批操作文件格式不正确。                  | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                       |
| ERR3001 | 用户未开户      | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。 | 核实用户的IMSI号码或MSISDN号码，如果输入有误，重新输入正确的IMSI号码或MSISDN号码。                                                                |
| ERR3007 | 记录不存在      | 用户未签约接入和移动管理数据。                                        | 请执行LST AMDATA命令查询IMSI对应的用户是否未签约，若未签约请参考MOD AMDATA为用户签约正确的接入和移动管理数据后重新执行本条命令。                                       |
