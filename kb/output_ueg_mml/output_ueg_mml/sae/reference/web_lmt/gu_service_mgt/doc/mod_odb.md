# 修改呼叫ODB业务(MOD ODB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

ODB（Operator Determined Barring）即运营商决定的闭锁，是指用户接入网络的业务能力，是由PLMN网络运营商来决定的。

- 当用户接入WCDMA/TD-SCDMA、GSM或LTE网络时，此操作用来同时签约或同时去签约运营商决定的闭锁业务（ODBSS、ODBIC、ODBOC、ODBPB1、ODBPB2、ODBPB3、ODBPB4、ODBENTE、ODBINFO、ODBROAM、ODBRCF、ODBECT、ODBDECT、ODBMECT、ODBPOS、ODBPOSTYPE、ODBENTEROAM和ODBINFOROAM）。

  如果UDM支持签约管理优化（执行**SET MAPCONF**命令将“用户被锁后是否允许操作相关补充业务”设置为“TRUE”）。
  - 即使已执行**MOD LCK**命令禁止用户呼入，仍可以执行该命令修改用户的“ODB-闭锁入呼叫”业务。
  - 即使已执行**MOD LCK**命令禁止用户呼出，仍可以执行该命令修改用户的“ODB-闭锁出呼叫”业务。

  执行此命令后，系统将向VLR/SGSN/MME/S4-SGSN下发插入用户数据消息。
- 当用户接入5GC网络时，此操作用来同时签约或同时去签约运营商决定的闭锁业务（ODBROAM、ODBPOS）。

  可以通过**SET UDMSERV**命令中的“NGS闭锁漫游生效方式”和“NGS下ODBPOS控制方式”参数来控制5GC网络下闭锁漫游和闭锁分组业务的生效方式。

## 注意事项

- 条件参数IMSI、ISDN必须且只能有一个存在。
- 所有ODB数据都是条件参数，至少指定一个。
- 当参数“ODBROAM”取值为“BROHPLMN”、“BROHPLMNC”或“BROHPLMNCGPRS”时，从HSS业务配置中获取ODBROAM是否控制EPS域（通过**LST MAPCONF**命令查询，**SET MAPCONF**命令设置），再根据主机名或域名检查网络类型，判断是否需要增加对该用户EPS域的漫游闭锁。

## 使用实例

1. 为IMSI号码为460000009123456的用户签约补充业务接入业务 、不闭锁入呼叫业务、闭锁所有呼出业务、不闭锁显式呼叫转移、签约ODBECT-呼入呼出业务均由被服务用户付费业务、不闭锁分组业务、对MS和网络发起的PDP上下文激活都有效业务。

   ```
   MOD ODB: IMSI="460000009123456", ODBSS=TRUE, ODBIC=NOBIC, ODBOC=BAOC, ODBECT=NOBECT, ODBDECT=TRUE, ODBPOS=NOBPOS, ODBPOSTYPE=BOTH;
   ```
2. 为IMSI号码为460000009123456的用户去签约补充业务接入业务 、不闭锁显式呼叫转移、不签约ODBECT-呼入呼出业务均由被服务用户付费业务、不闭锁呼叫转移业务、不闭锁分组业务、对MS和网络发起的PDP上下文激活都有效业务。

   ```
   MOD ODB: ISDN="460000009123456", ODBSS=FALSE, ODBECT=NOBECT, ODBDECT=FALSE, ODBMECT=FALSE, ODBPOS=NOBPOS, ODBPOSTYPE=BOTH;
   ```
