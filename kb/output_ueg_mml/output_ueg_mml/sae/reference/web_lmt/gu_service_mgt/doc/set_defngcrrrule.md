# 设置NGC漫游限制模板的缺省漫游限制状态(SET DEFNGCRRRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，可能导致漫游受限，影响在网用户漫游，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置NGC漫游限制模板的缺省漫游限制状态。在该命令中，系统通过以下关键参数的组合来唯一标识一个NGC漫游限制模板：

- HLR序列号
- 模板ID

## 注意事项

“AMF注册缺省漫游限制状态”、“SMF注册缺省漫游限制状态”、“鉴权缺省漫游限制状态”、“SMSF注册缺省漫游限制状态”参数作用范围为该命令中模板ID的取值范围，只能通过该命令设置，无法删除。如果设置不当将导致签约该模板的用户，在未设置漫游限制模板时不能正常漫游。

## 参数说明

| 参数标识            | 参数名称           | 参数说明                                                                                                        |
|:----------------|:---------------|:------------------------------------------------------------------------------------------------------------|
| HLRSN           | HLR序列号         | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无 配置原则：无                       |
| TPLID           | 模板ID           | 可选必选说明：必选参数 参数含义：用于标识NGC漫游限制模板在系统中的序号。该参数必须先由ADD NGCRRNODETPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无 配置原则：无 |
| DEFAULTRULE     | AMF注册缺省漫游限制状态  | 可选必选说明：可选参数 参数含义：用于标识AMF注册流程中缺省漫游限制状态。 取值范围： PERMISSION：漫游允许。 RESTRICT：漫游限制。 默认值：无 配置原则：无                   |
| SMFDEFAULTRULE  | SMF注册缺省漫游限制状态  | 可选必选说明：可选参数 参数含义：用于标识SMF注册流程中缺省漫游限制状态。 取值范围： PERMISSION：漫游允许。 RESTRICT：漫游限制。 默认值：无 配置原则：无                   |
| AUTHDEFAULTRULE | 鉴权缺省漫游限制状态     | 可选必选说明：可选参数 参数含义：用于标识鉴权流程中缺省漫游限制状态。 取值范围： PERMISSION：漫游允许。 RESTRICT：漫游限制。 默认值：无 配置原则：无                      |
| SMSFDEFAULTRULE | SMSF注册缺省漫游限制状态 | 可选必选说明：可选参数 参数含义：用于标识SMSF注册流程中缺省漫游限制状态。 取值范围： PERMISSION：漫游允许。 RESTRICT：漫游限制。 默认值：无 配置原则：无                  |

## 使用实例

设置“HLR序列号”为“1”、“模板ID”为“1”的NGC漫游限制模板的缺省漫游限制状态，“AMF注册缺省漫游限制状态”为“PERMISSION”，“SMF注册缺省漫游限制状态”为“PERMISSION”，“鉴权缺省漫游限制状态”为“PERMISSION”，“SMSF注册缺省漫游限制状态”为“PERMISSION”。

```
SET DEFNGCRRRULE: HLRSN=1, TPLID=1, DEFAULTRULE=PERMISSION, SMFDEFAULTRULE=PERMISSION, AUTHDEFAULTRULE=PERMISSION, SMSFDEFAULTRULE=PERMISSION;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                                                                                                           |
|:--------|:--------|:------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”和“模板ID”对应的NGC漫游限制模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”的组合，可通过LST HLRSN命令查询已定义的“HLR序列号”，使用LST NGCRRNODETPL命令输入已定义“HLR序列号”参数，其他参数不输入，查询已定义“HLR序列号”和“模板ID”的NGC漫游限制模板数据记录。 |
