# 查询APN模板(LST APNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，如果查询数据量大（超过5000条）的场景下会导致PGW模块和全局DRU模块CPU有明显上升，建议在营帐话务低时执行该命令。

此操作用于查询APN模板。

## 注意事项

- 输入“模板ID”或“接入点名称”都可进行APN模板数据查询，但是两个参数只能输入一个，不能同时输入。

  **说明** 

  执行本命令查询系统已添加的APN模板记录，当输入“接入点名称”参数时，系统对“接入点名称”的大小写不敏感，会自动匹配查询相同字符串组合的APN对应的记录信息。
- 如果没有指定“模板ID”和“接入点名称”，显示所有的APN模板ID和相关数据。
- 仅输入“HLR序列号”查询所有的模板数据时，会导致PGW模块的CPU占用率升高，因此推荐输入“HLR序列号”和“模板ID”的组合或者“HLR序列号”和“接入点名称”的组合精确查询模板数据。当必须查询所有的模板数据时，请在低话务量时执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                                                                                                                                                   |
| TPLID  | 模板ID   | 模板号，0～65534。                                                                                                                                                                                                                                                                                                               |
| APN    | 接入点名称  | 接入点名称，1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 说明：当该参数设置为“*”且用于EPS网络时，表示该APN模板为通配APN模板，即用户入网时，MME根据一定的通配原则为用户分配一个APN，该APN可以是用户未签约已授权的APN。                                                                                                                                                                                        |
| SAVEAS | 保存文件名  | 用于标识保存查询结果的文件名称。 当查询结果的记录数超过5000条时必须输入该参数，将查询结果保存在文件中，否则会报错“ERR4102：查询结果已经超过5000条，需要指定保存文件名进行查询”。 取值范围：长度不超过20的字符串。 默认值：无 说明：“保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。SYSHLRSN默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。 保存文件名参数指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。 |

## 使用实例

查询模板ID为65534的EPS APN模板数据。命令如下：

```
LST APNTPL: HLRSN=1, TPLID=65534;
```

如果操作成功，返回的结果可能如下：


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                        | 原因分析                       | 处理建议                     |
|:--------|:-----------------------------|:---------------------------|:-------------------------|
| ERR4102 | 查询结果已经超过5000条，需要指定保存文件名进行查询。 | 查询结果超过5000条，但未输入参数“保存文件名”。 | 输入参数“保存文件名”，将查询结果保存在文件中。 |
