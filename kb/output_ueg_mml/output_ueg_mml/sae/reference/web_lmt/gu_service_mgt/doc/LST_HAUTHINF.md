# 查询IMPI支持的鉴权模式(LST HAUTHINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定用户对各种鉴权模式的支持情况，需要输入唯一标识该数据记录的关键参数IMPI。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询IMPI的鉴权模式。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPI支持的鉴权模式。IMPI：impiinfo。

```
LST HAUTHINF: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识        | 参数说明       |
|:------------|:-----------|
| AKAFLAG     | 显示AKA鉴权标识。 |
| EAAFLAG     | 显示EAA鉴权标识。 |
| SDAFLAG     | 显示SDA鉴权标识。 |
| TAAFLAG     | 显示TAA鉴权标识。 |
| EIAFLAG     | 显示EIA鉴权标识。 |
| HDAFLAG     | 显示HDA鉴权标识。 |
| NBAFLAG     | 显示NBA鉴权标识。 |
| CAVEAKAFLAG | 显示CAA鉴权标识。 |
