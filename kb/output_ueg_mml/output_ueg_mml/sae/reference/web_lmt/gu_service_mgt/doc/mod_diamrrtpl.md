# 修改Diameter漫游限制模板(MOD DIAMRRTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条Diameter漫游限制模板数据记录的某些参数进行修改或调整，同时还用于为一条Diameter漫游限制模板数据记录增加多个“Diameter身份标识”。在该命令中，系统通过以下关键参数的组合来唯一标识一个Diameter漫游限制模板信息数据：

- “HLR序列号”
- “模板ID”

## 注意事项

- 因为当用户进行位置更新或触发其他涉及Diameter漫游限制模板的流程时，系统会根据用户签约的Diameter漫游限制模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 该命令不允许进行批操作。
- 系统中增加的Diameter漫游限制模板个数不能超过3000个，同一个Diameter漫游限制模板增加的Diameter身份标识记录数不能超过4000条，且所有Diameter漫游限制模板增加的Diameter身份标识总记录数不能超过40000条。
- 同一个Diameter漫游限制模板只能配置一个“缺省业务下发模板ID”和“缺省业务限制模板ID”。

## 使用实例

1. 修改Diameter漫游限制模板数据，增加一个“Diameter身份标识”。“HLR序列号”为“1”，“模板ID”为“100”，“操作类型”为“ADD\_DIAM”，“Diameter身份标识类型”为“HOSTNAME”，“Diameter身份标识”为“test.huawei.com”，“是否提供缺省业务下发模板”为“TRUE”，“缺省业务下发模板ID”为“11”，“主机域名”为“huawei.com”，“漫游限制状态”为“RESTRICT”，“是否提供业务下发模板”为“TRUE”，“业务下发模板ID”为“22”：

   ```
   MOD DIAMRRTPL: HLRSN=1, TPLID=100, MODIFYTYPE=ADD_DIAM, PROVDEFRSITPL=TRUE, DEFRSITPLID=11, DIAMIDENTITY="test.huawei.com", DIAMIDENTITYTYPE=HOSTNAME, REALMNAME="huawei.com", RULE=RESTRICT, PROVRSITPL=TRUE, RSITPLID=22;
   ```
2. 修改Diameter漫游限制模板数据，修改模板中原有的“Diameter身份标识”。“HLR序列号”为“1”，“模板ID”为“100”，“操作类型”为“MOD\_DIAM”，“Diameter身份标识类型”为“REALMNAME”，“Diameter身份标识”为“test.huawei.com”：

   ```
   MOD DIAMRRTPL: HLRSN=1, TPLID=100, MODIFYTYPE=MOD_DIAM, DIAMIDENTITYTYPE=REALMNAME, DIAMIDENTITY="test.huawei.com";
   ```
3. 修改Diameter漫游限制模板数据，删除模板中原有的“Diameter身份标识”。“HLR序列号”为“1”，“模板ID”为“100”，“操作类型”为“RMV\_DIAM”，“Diameter身份标识”为“test.huawei.com”：

   ```
   MOD DIAMRRTPL: HLRSN=1, TPLID=100, MODIFYTYPE=RMV_DIAM, DIAMIDENTITY="test.huawei.com";
   ```
