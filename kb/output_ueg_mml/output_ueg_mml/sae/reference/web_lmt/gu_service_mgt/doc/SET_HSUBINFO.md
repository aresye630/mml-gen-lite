# 设置IMS用户描述(SET HSUBINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中设置指定“SUBID”的“用户描述”。

## 注意事项

如果不设置用户描述的值，表示删除用户描述。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                    |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| SUBID   | SUBID  | 标识一条IMS签约用户数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条IMS签约用户数据记录的参数进行修改或调整，操作员可以使用LST HSUB命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |
| SUBINFO | 用户描述   | 标识一个IMS签约用户的用户描述。用户描述是对IMS签约用户的描述信息。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                  |

## 使用实例

设置IMS用户描述，“SUBID”为“6290000001”，“用户描述”为“+866290000001@huawei.com”：

```
SET HSUBINFO: SUBID="6290000001", SUBINFO="+866290000001@huawei.com";
```
