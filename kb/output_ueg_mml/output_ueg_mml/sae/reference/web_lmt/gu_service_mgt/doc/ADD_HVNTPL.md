# 增加拜访网络模板(ADD HVNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中增加一个拜访网络模板。

拜访网络模板也称漫游模板，其由一个或多个拜访网络地址组成，操作员可以在使用**ADD HVNTPL**增加拜访网络模板后，执行**SET HVNTPLID**命令，设置此用户与拜访网络模板的对应关系，以对用户的漫游范围进行控制：

- 当IMS移动用户进入拜访网络地址允许的区域时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配成功，拜访网络地址信息中的拜访网络地址类型是允许漫游，IMS系统将允许用户注册。
- 当IMS移动用户进入拜访网络地址限制的区域时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配成功，拜访网络地址信息中的拜访网络地址类型是限制漫游，IMS系统将限制用户注册。
- 当IMS移动用户进入的区域在拜访网络地址信息中不存在时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配失败，根据拜访网络模板中的缺省漫游限制策略决定是否允许用户注册，PERMISSION表示IMS系统将允许用户注册，RESTRICTION表示IMS系统将限制用户注册。

## 注意事项

- 系统允许的拜访网络模板数量最大为5000个，请操作员在执行该命令前妥善规划，仔细确认任务的可行性。
- 本命令中“缺省漫游限制策略”参数设为“RESTRICTION(Restriction)”时表示限制漫游。如果要放开用户的漫游权限，使用**MOD HVNTPL**命令将“缺省漫游限制策略”参数修改为“PERMISSION(Permission)”。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                              |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明： 可选参数当该参数不输入时，系统默认初始设置值为0。                                                                                                                                                                                                                     |
| TPLID       | 拜访网络模板ID | 用于定义一个新的拜访网络模板索引，系统可以通过该索引找到新增的拜访网络模板。 取值范围：0～1024 默认值：无。 说明： 必选参数。同一个“HLR序列号”，拜访网络模板ID唯一，拜访网络模板ID可以使用LST HTPLINF命令查询获得。该参数取值为“255”时为无效值。该参数取值大于“254”时只支持“IMS用户模板管理”（IMSTPL）命令组引用该模板。                                                                                             |
| TPLNAME     | 拜访网络模板名称 | 用于定义新增拜访网络模板的名称。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                                                                                                                                        |
| MATCHTYPE   | 匹配类型     | 用于定义新增拜访网络模板的匹配类型。 取值范围：FRONT(Front)：表示前向匹配。前向匹配原则表示拜访网络地址只要前缀相同的都匹配。如果签约的拜访网络地址模板信息为HSS，则前缀为HSS的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.com”。BACK(Back)：表示后向匹配。后向匹配原则表示拜访网络地址后缀相同的都匹配。如果签约的拜访网络地址模板信息为huawei.com，则后缀为huawei.com的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.huawei.com”。 默认值：无。 说明：必选参数。 |
| DEFAULTRULE | 缺省漫游限制策略 | 用于定义新增拜访网络模板的缺省限制策略。当用户携带的接入位置信息与签约的拜访网络地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：RESTRICTION。 说明：可选参数。                                                                                                 |
| VN          | 拜访网络地址   | 用于指定在拜访网络模板中增加的拜访网络地址。一个拜访网络模板中至少应存在一条拜访网络地址，因此在添加拜访网络模板时必须在其中同时添加一条拜访网络地址。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                     |
| VNTYPE      | 拜访网络地址类型 | 用于指定新增拜访网络地址的类型。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：必选参数。                                                                                                                                                             |
| COMMENT     | 模板注释说明   | 用于指定新增拜访网络模板的注释。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                |

## 使用实例

1. 增加拜访网络模板，“拜访网络模板ID”为“10”，“拜访网络模板名称”为“Visited Network Template”，“匹配类型”为“FRONT(Front)”，“缺省漫游限制策略”为“PERMISSION(Permission)”，“拜访网络地址”为“china.huawei.com”，“拜访网络地址类型”为“PERMISSION(Permission)”，“模板注释说明”为“Visited Network Template For ADD HTPLIMPU”：

   ```
   ADD HVNTPL: TPLID=10, TPLNAME="Visited Network Template", MATCHTYPE=FRONT, DEFAULTRULE=PERMISSION, VN="china.huawei.com", VNTYPE=PERMISSION, COMMENT="Visited Network Template For ADD HTPLIMPU";
   ```
2. 增加拜访网络模板，“拜访网络模板ID”为“11”，“拜访网络模板名称”为“VN TPL”，“匹配类型”为“BACK(Back)”，“缺省漫游限制策略”为“RESTRICTION(Restriction)”，“拜访网络地址”为“hss.huawei.com”，“拜访网络地址类型”为“PERMISSION(Permission)”，“模板注释说明”为“VNTPL For SET HVNTPLID”：

   ```
   ADD HVNTPL: TPLID=11, TPLNAME="VN TPL", MATCHTYPE=BACK, DEFAULTRULE=RESTRICTION, VN="hss.huawei.com", VNTYPE=PERMISSION, COMMENT="VNTPL For SET HVNTPLID";
   ```
