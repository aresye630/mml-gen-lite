# 设置IMPU或PUSI的闭锁状态(SET HBAR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU或PUSI的闭锁标志状态(当用户被设置闭锁时，不能享受IMS的任何服务)。PUSI的闭锁状态对PUSI的流程处理暂无任何影响。

## 注意事项

参数IMPU和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指定一个需要设置为闭锁的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无                                                                             |
| PUSI   | PUSI   | 用于指定一个需要设置为闭锁的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无                                                                             |
| BAR    | 闭锁标志   | 指定该IMPU的闭锁状态。TRUE：闭锁；FALSE：解除闭锁。PUSI的闭锁状态对PUSI的流程处理暂无任何影响。 取值范围：FALSE(False)TRUE(True) 缺省值：无 说明：当用户只开户但不执行本命令签约该业务，执行LST HBAR命令查询时，参数“闭锁标志”默认为“FALSE(False)”。 |

## 使用实例

设置IMPU或PUSI的闭锁状态。IMPU：sip:impuinfo@huawei.com，闭锁标志：闭锁。

```
SET HBAR: IMPU="sip:impuinfo@huawei.com", BAR=TRUE;
```
