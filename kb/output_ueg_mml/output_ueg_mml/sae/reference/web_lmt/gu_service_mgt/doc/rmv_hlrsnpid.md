# 删除HLRSN与云分区数据(RMV HLRSNPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中删除一条HLRSN与云分区映射关系的数据记录，仅在开局或升级改造云部署之前使用，用于删除错误的HLRSN与云分区的对应关系。

## 注意事项

在现网业务正常运转的情况下，使用该命令会造成业务中断或其他致命性影响，请谨慎使用。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识HLRSN与云分区映射关系数据记录的关键字段，用于指定删除哪个HLRSN与云分区映射关系的数据记录，操作员可以使用LST HLRSNPID命令查询获得。 |

## 使用实例

在数据库中删除一条“HLRSN”为“5”的HLRSN与云分区映射关系的数据记录：

```
RMV HLRSNPID: HLRSN=5;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                  |
|:--------|:--------|:---------------------------------------|:----------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的HLR序列号未在ADD HLRSNPID命令中添加与云分区的对应关系。 | 请检查确保输入的HLRSN已由ADD HLRSNPID命令添加，然后重新输入。可使用LST HLRSNPID命令查询已定义的HLR序列号。 |
