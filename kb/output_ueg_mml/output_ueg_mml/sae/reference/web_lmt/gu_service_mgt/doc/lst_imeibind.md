# 查询M2M绑定业务(LST IMEIBIND)

- 命令功能

- 输出结果说明

## 命令功能

该命令用于查询已签约M2M绑定业务的用户的M2M绑定业务数据。

- 若需要查询单个用户的M2M绑定信息，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的M2M绑定信息，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的M2M绑定信息，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数”参数一定不能与“IMSI文件名”或“MSISDN文件名”同时配置，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现，用于查询多个用户的M2M绑定业务时使用。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                    |
|:------------|:--------|:----------------------------------------|
| IMSI        | IMSI    | 用于指示系统按照哪个IMSI来查询用户的M2M绑定信息。            |
| ISDN        | MSISDN  | 用于指示系统按照哪个MSISDN来查询用户的M2M绑定信息。          |
| RECORDCOUNT | 用户个数    | 用于指示系统需要查询多少个用户的M2M绑定信息。                |
| IMSIFILE    | IMSI文件名 | 用于指示系统按照哪个IMSI文件名来查询不连续的多个用户的M2M绑定信息。   |
| ISDNFILE    | ISDN文件名 | 用于指示系统按照哪个MSISDN文件名来查询不连续的多个用户的M2M绑定信息。 |

## 使用实例

1. 查询“IMSI”为“123456789012345”的用户的M2M绑定信息。

   ```
   LST IMEIBIND: IMSI="123456789012345";
   ```

   ```
   %%LST IMEIBIND: IMSI="123456789012345";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 123456789012345
                     IMSIIMEIBIND = 12345678901234

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询第一个“IMSI”为“123456789012345”的3个连续用户的M2M绑定信息。

   ```
   LST IMEIBIND: IMSI="123456789012345", RECORDCOUNT=3;
   ```

   ```
   %%LST IMEIBIND: IMSI="123456789012345", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“IMSI文件名”为“modimeibind.txt”的用户的M2M绑定信息。

   ```
   LST IMEIBIND: IMSIFILE="modimeibind.txt";
   ```

   ```
   %%LST IMEIBIND: IMSIFILE="modimeibind.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：8. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD IMEIBIND**

命令的参数说明。表1列出的是未包含在

**MOD IMEIBIND**

命令参数含义中的输出项。

| 输出项名称        | 输出项解释                                      |
|:-------------|:-------------------------------------------|
| IMSIIMEIBIND | 用于返回与IMSI绑定的IMEI号码。                        |
| 批操作ID        | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。 |
