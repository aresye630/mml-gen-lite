# 根据模板新增iFC信息(ADD HTPLIFC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中，使用一个iFC模板，为一个IMPU或PUSI增加一个iFC业务。

## 注意事项

参数IMPU和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                           |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU     | IMPU    | 用于指定一个需要根据模板新增iFC信息的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                      |
| PUSI     | PUSI    | 用于指定一个需要根据模板新增iFC信息的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                      |
| IFCTPLID | iFC模板ID | 用于唯一标识一个IFC模板，该参数必须通过ADD HIFCTPL定义，然后才能在此处索引。 取值范围：０～1024 默认值：无 说明：当通过SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，该参数需要引用用户签约的“HLR序列号”下的共享iFC模板。 |

## 使用实例

根据模板新增iFC信息。IMPU：sip:impuinfo@huawei.com，iFC模板ID：1。

```
ADD HTPLIFC:IMPU="sip:impuinfo@huawei.com", IFCTPLID=1;
```
