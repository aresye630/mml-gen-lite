# 设置特殊前转号码限制（SET RESSPECFTN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在特殊前转号码限制表中增加前转号码，该前转号码在位置更新、独立插入用户数据（登记/激活/去激活条件前转）、恢复用户数据流程中的ISD（Insert Subscriber Data）消息中不下发。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                            |
| OPTYPE | 操作类型   | 用于标识特殊前转号码限制表中的前转号码的操作类型。 取值范围： ADD：增加一条记录或批量增加多条记录。 DELETE：删除一条已有记录。 DELETEALL：删除所有记录。 默认值：无。          |
| RESFTN | 前转限制号码 | 仅当本命令中的“操作类型”参数取值为“ADD”或“DELETE”时该参数有效。用于标识特殊前转号码限制表中的前转号码。 取值范围：1～15位以内数字组成的字符串。 默认值：无。 说明：该号码必须携带国家码。 |

## 使用实例

1. 增加一条特殊前转号码限制表记录，其中“前转限制号码”为“861380755001”：

   ```
   SET RESSPECFTN: HLRSN=1, OPTYPE=ADD, RESFTN="861380755001";
   ```
2. 删除一条特殊前转号码限制表记录，其中“前转限制号码”为“861380755001”：

   ```
   SET RESSPECFTN: HLRSN=1, OPTYPE=DELETE, RESFTN="861380755001";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                          | 处理建议                                                                                   |
|:--------|:----------|:------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失      | 可能原因为如下之一：参数“HLR序列号”、“操作类型”未输入。当参数“操作类型”选择“ADD”或“DELETE”后，“前转限制号码”未输入。        | 根据实际情况，重新输入所有参数，并确保其取值符合要求。                                                            |
| ERR1010 | 参数冲突      | 当参数“操作类型”选择“DELETEALL”后，输入了“前转限制号码”。                                          | 根据实际情况，重新输入参数，确保“操作类型”参数选择“DELETEALL”后，不能输入“前转限制号码”参数。                                 |
| ERR1111 | 超过最大限制    | 当参数“操作类型”选择“ADD”后，设置的前转限制号码数超过3000条。                                          | 请按照以下步骤操作：执行LST RESSPECFTN命令查询特殊前转号码限制表中全部前转号码数据。根据查询结果删除不必要的数据记录，确保设置的数据记录总数在3000条以内。 |
| ERR3007 | 记录不存在     | 可能原因为如下之一：当参数“操作类型”选择“DELETE”后，输入的“前转限制号码”未定义。当参数“操作类型”选择“DELETEALL”后，无可删除记录。 | 根据实际情况，重新输入“前转限制号码”参数，已定义记录可通过LST RESSPECFTN命令查询。                                      |
| ERR3097 | HLR序列号未定义 | “HLR序列号”参数输入错误，实际输入的“HLR序列号”参数未定义。                                            | 根据实际情况，重新输入参数“HLR序列号”的取值，确保其取值已被定义。已定义的“HLR序列号”可通过LST HLRSN命令查询。                       |
