# 修改AMF 3GPP注册信息数据（MOD AMF3GPPREGINFO）

## 命令功能

该命令用于提供AMF 3GPP注册信息数据修改业务，灵活管理用户的接入注册信息。

## 注意事项

- “IMSI”和“IMSI文件名”是互斥参数，不能同时输入，否则会提示参数冲突。
- “用户个数”参数和“IMSI文件名”是互斥参数，不能同时输入，否则会提示参数冲突。
- 执行该命令修改“移动国家码”、“移动网络码”或“AMF标识”参数，且“是否发送去注册消息”参数取值为“TRUE”时，则向老的AMF发送去注册消息。
- 执行该命令修改“VPNID”参数需要触发去注册消息时，可以执行该命令结束后再执行**SND CANCELC**命令。
- 执行该命令修改“VPNID”参数时只能修改“VPNID”一个参数，不能同时修改其它参数，如果包含了其它参数，系统会提示参数冲突。

## 参数说明

| 参数标识                | 参数名称        | 参数说明                                                                                                                                                                                                                    |
|:--------------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI                | IMSI        | 可选必选说明：条件可选参数 参数含义：用于标识需要修改AMF 3GPP注册信息业务的用户的“IMSI号码”。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                           |
| RECORDCOUNT         | 用户个数        | 可选必选说明：条件可选参数 参数含义：用于标识需要修改AMF 3GPP业务的用户数目。 取值范围：1～100000。 默认值：无。 配置原则： 该参数提供，代表以指定的IMSI为起始号码，号码连续的RECORDCOUNT个用户。该参数是对连续号码的多个用户修改AMF 3GPP注册业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE            | IMSI文件名     | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要修改AMF 3GPP的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modamf3gpp.txt”，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                        |
| AMFINSTANCEID       | AMF主机名      | 可选必选说明：可选参数 参数含义：用于标识AMF在NRF中进行注册的主机名，该参数唯一。通过该参数NRF确保AMF能被其他NF发现，同时将该注册服务与已存在NF实例进行关联。 取值范围：0～36个字符。 默认值：无。 配置原则：无。                                                                                                    |
| DEREGCALLBACKURI    | 去注册时URI     | 可选必选说明：可选参数 参数含义：用于标识去注册时的URI，当用户在新的AMF上注册后，UDM使用此URI，去老的AMF上删除用户签约数据。 取值范围：0～512个字符。 默认值：无。 配置原则：无。                                                                                                                    |
| AMFSERVICENAMEDEREG | 去注册的AMF服务名称 | 可选必选说明：可选参数 参数含义：用于标识发起去注册流程的AMF服务名称。 取值范围：0～32个字符。 默认值：无。 配置原则：无。                                                                                                                                                      |
| MCC                 | 移动国家码       | 可选必选说明：可选参数 参数含义：用于标识移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460，英国为234等。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                   |
| MNC                 | 移动网络码       | 可选必选说明：可选参数 参数含义：用于标识移动网络码，移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配，如中国移动为00，中国联通为01等。 取值范围：2位或3位的十进制数字组成的字符串。 默认值：无。 配置原则：每个移动国家码最多可以包含200个移动网络码。                                                                  |
| AMFID               | AMF标识       | 可选必选说明：可选参数 参数含义：用于标识同一PLMN下的AMF的名称，具有唯一性。 取值范围：0～6个十六进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                        |
| RATTYPE             | 无线接入类型      | 可选必选说明：可选参数 参数含义：用于标识用户终端接入网络的无线接入技术类型。 取值范围： NR：5G无线网。Eutra：进化的UMTS陆地无线接入网。Wlan：无线局域网。Virtual：虚拟专用网。NR_REDCAP：轻量化5G 默认值：无。 配置原则：无。                                                                                     |
| SENDDEREG           | 是否发送去注册消息   | 可选必选说明：可选参数 参数含义：用于标识UDM是否向老的AMF发送去注册消息。如果用户修改了MCC/MNC/AMFID，则向老的AMF发送去注册消息，如果用户未修改则不发送。 取值范围： TRUE：发送去注册消息FALSE：不发送去注册消息 默认值：无。 配置原则：无。                                                                                |
| VPNID               | VPNID       | 可选必选说明：可选参数 参数含义：用于标识AMF注册时使用的VPNID。 取值范围：0～255，65535。 默认值：无。 配置原则：当该参数取值为“65535”时，表示使用移动网络。错误的VPNID会导致通知消息选择错误的VPN而无法到达对端。                                                                                             |

## 使用实例

1. 修改“IMSI号码”为“460000009123456”的用户注册信息数据。

   ```
   MOD AMF3GPPREGINFO: IMSI="460000009123456", AMFID="111122";
   ```
2. 修改“IMSI号码”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户的注册信息数据。

   ```
   MOD AMF3GPPREGINFO: IMSI="460000009123456", RECORDCOUNT=3, AMFINSTANCEID="111122", RATTYPE=NR;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1 错误码列表所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                                                   |
|:--------|:--------|:-------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入参数不符合参数取值范围。如：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。         | 根据实际情况，重新输入，确保其取值符合要求。如：重新输入“IMSI”的取值。                                                                 |
| ERR1009 | 参数丢失    | AMF 3GPP注册信息需要的参数没有输入完全。                               | 除“IMSI”和“IMSI文件名”不能同时输入， “AMF标识”，“AMF主机名”，“去注册时URI”，“去注册的AMF服务名称”，“移动国家码”，“移动网络码”，“是否发送去注册消息”必须选择一个输入。 |
| ERR1010 | 参数冲突    | 可能原因为如下之一： “IMSI”和“IMSI文件名”同时输入。修改“VPNID”参数时，同时修改其它参数。 | 根据实际情况，重新输入参数，确保满足以下条件：“IMSI”和“IMSI文件名”不能同时输入。修改“VPNID”参数时，不能同时修改其它参数。                                 |
| ERR3001 | 用户未开户   | 用户的IMSI号码输入错误，实际输入的参数“IMSI”对应的用户未开户。                   | 核实IMSI号码，确保其对应的用户为5G用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI” 对应的用户未开户，请先通过ADD SUB命令给用户开户。                    |
| ERR4104 | 非5G用户   | 输入的参数“IMSI”对应的用户没有签约5G业务。                              | 使用ADD TPLNGS命令添加5G数据。                                                                                  |

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
