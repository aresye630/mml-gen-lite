# 设置私有业务的业务码（SET ESERCODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置私有业务的业务码取值。呼叫流程中，MSC会携带不同的业务码至HLR以指示不同的私有业务，这些业务码的取值是可以配置的。例如，249表示支持彩铃业务，如果要正常实现彩铃业务，就需要将HLR指示的彩铃业务的业务码改为249。

## 注意事项

- 该命令全部参数都是可选的，但是必须保证至少有一个参数出现。
- MSCCPPFLAG和CLOPPCPPFLAG两个参数可以同时设置为NONE，MSCCPPFLAG和MAP2RESERVE2、 CLOPPCPPFLAG和MAP2DT参数取值可以相同，其他所有MAP2版本参数取值必须互不相同。
- 参数MAP3EMA的取值不能与其他已存在的MAP3业务码取值相同，已存在的MAP3业务码取值包括6、7、8、9、10、13。
- “ICI主业务码”参数与“ICI从业务码”参数的取值不能相同。

## 使用实例

设置MAP2版本OSK业务的业务码为243。命令如下：

SET ESERCODE: MAP2OSK=243;
