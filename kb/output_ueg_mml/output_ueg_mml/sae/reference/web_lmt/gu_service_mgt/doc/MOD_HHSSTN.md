# 一键式改号(MOD HHSSTN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中修改已存在用户的“MSISDN”、“IMPU”和“IMPU2”。

当用户希望换号不换卡时，可以使用该命令进行一键式改号。改号后，系统将向VLR/SGSN下发新的MSISDN号码。

## 注意事项

- 参数“MSISDN”、“IMPU”和“IMPU2”中包含的信息必须属于同一个用户。
- “IMPU”和“IMPU2”不能相同，“NEWIMPU”和“NEWIMPU2”不能相同。
- “IMPU”和“NEWIMPU”必须同时输入或同时不输入，“IMPU2”和“NEWIMPU2”必须同时输入或同时不输入。
- 对于2G/3G/4G和IMS融合用户，改号时必须在2G/3G/4G和IMS域同时修改。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                           |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ISDN     | MSISDN   | 用于标识待改号用户的旧MSISDN号码。 取值范围：长度不超过15位的十进制数字组成的字符串。 默认值：无。                                                                                                                         |
| NEWISDN  | 新的MSISDN | 用于标识待改号用户的新MSISDN号码。 取值范围：长度不超过15位的十进制数字组成的字符串。 默认值：无。                                                                                                                         |
| IMPU     | IMPU     | 用于标识待改号用户的旧IMPU。该参数的配置原则是：输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。IMPU类型必须是非通配的。 取值范围：长度不超过127的由字母、数字或“.”、“_”、“—”、空格等特殊字符组成的字符串。 默认值：无。 说明：一个通配IMPU可以代表一组IMPU，一个非通配IMPU只能代表一个IMPU。 |
| NEWIMPU  | 新的IMPU   | 用于标识待改号用户的新IMPU。该参数的配置原则是：输入的新的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。新的IMPU类型必须是非通配的。 取值范围：长度不超过127的由字母、数字或“.”、“_”、“—”、空格等特殊字符组成的字符串。 默认值：无。                                        |
| IMPU2    | IMPU2    | 用于标识待改号用户的旧IMPU2。该参数的配置原则是：输入的IMPU2值符合SIP URI或TEL URI格式，字母区分大小写。IMPU2类型必须是非通配的。 取值范围：长度不超过127的由字母、数字或“.”、“_”、“—”、空格等特殊字符组成的字符串。 默认值：无。                                         |
| NEWIMPU2 | 新的IMPU2  | 用于标识待改号用户的新IMPU2。该参数的配置原则是：输入的新的IMPU2值符合SIP URI或TEL URI格式，字母区分大小写。新的IMPU2类型必须是非通配的。 取值范围：长度不超过127的由字母、数字或“.”、“_”、“—”、空格等特殊字符组成的字符串。 默认值：无。                                     |

## 使用实例

一键式改号，“MSISDN”为“8613988888888”，“新的MSISDN”为“8613977777777”，“IMPU”为“sip:impuinfo@huawei.com”，“新的IMPU”为“sip:new\_impuinfo@huawei.com”，“IMPU2”为“sip:impu2info@huawei.com”，“新的IMPU2”为“sip:new\_impu2info@huawei.com”：

```
MOD HHSSTN: ISDN="8613988888888", NEWISDN="8613977777777", IMPU="sip:impuinfo@huawei.com", NEWIMPU="sip:new_impuinfo@huawei.com", IMPU2="sip:impu2info@huawei.com", NEWIMPU2="sip:new_impu2info@huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900001009 | 参数冲突               | 原因为下列情况中的一种：“IMPU”和“NEWIMPU”只输入了其中一个参数。“IMPU2”和“NEWIMPU2”只输入了其中一个参数。           | 根据实际情况，重新输入参数，确保满足以下两点：“IMPU”和“NEWIMPU”必须同时输入或同时不输入。“IMPU2”和“NEWIMPU2”必须同时输入或同时不输入。 |
| 900003460 | IMPU和IMPU2相同       | “IMPU”和“IMPU2”取值相同。                                                            | 根据实际情况，重新输入参数，确保“IMPU”和“IMPU2”取值不相同。                                                |
