# 修改5G业务下发模板(MOD NGCRSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条5G业务下发模板记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条5G业务下发模板记录：

- “HLR序列号”
- “模板ID”

## 注意事项

如果本命令中的“是否提供下发业务”参数为“FALSE”，要删除5G业务下发模板中唯一的一条SMF数据记录或DNN/APN替换业务数据，则无法删除，系统会返回错误码“ERR3096：模板不能为空”。

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号      | 可选必选说明：必选参数 参数含义：标识5G业务下发模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的5G业务下发模板数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| TPLID          | 模板ID        | 可选必选说明：必选参数 参数含义：标识5G业务下发模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个5G业务下发模板数据记录的参数进行修改，操作员可以使用LST NGCRSITPL命令查询获得。 取值范围：0～65534 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| TPLNAME        | 模板名         | 可选必选说明：可选参数 参数含义：用于标识待修改模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PROV           | 是否提供下发业务    | 可选必选说明：可选参数 参数含义：用于标识是否提供下发业务。 取值范围：FALSE：不提供TRUE：提供 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SERCODE        | 下发业务列表      | 可选必选说明：条件必选参数 参数含义：用于标识当用户漫游到特定的5G区域后，对哪些业务进行下发。 取值范围： SMDATA：SMF数据SXZW：DNN/APN替换业务 默认值：无。 配置原则： 仅当本命令中的“是否提供下发业务”参数取值不为空时该参数有效。当“是否提供下发业务”为“TRUE”时为下发，当“是否提供下发业务”为“FALSE”时为不下发。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SMDATATPLID    | 会话信息模板ID    | 可选必选说明：条件必选参数 参数含义：用于标识会话信息模板ID。该参数必须先由ADD SMDATATPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无。 配置原则：仅当本命令中的“下发业务列表”参数为“SMDATA”时该参数有效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PROVRESTSUBDNN | 是否提供限制DNN子串 | 可选必选说明：可选参数 参数含义：用于标识需要对已添加的限制DNN子串进行哪种操作。 取值范围： FALSE：表示需要删除已添加的限制DNN子串。TRUE：表示需要修改已添加的限制DNN子串。 默认值：无。 配置原则：仅当本命令中的“下发业务列表”参数取值为“SMDATA”时该参数有效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| RESTSUBDNN     | 限制DNN子串     | 可选必选说明：条件必选参数 参数含义：用于标识业务下发时，当用户签约DNN中存在该参数配置的DNN子串，则不下发用户签约的DNN。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无。 配置原则：仅当本命令中的“是否提供限制DNN子串”参数为“TRUE”时该参数必须输入。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| OLDDNNLIST     | 旧DNN名称列表    | 可选必选说明：条件必选参数 参数含义：用于标识旧DNN名称列表。 取值范围：1～4000个字符组成的字符串。 默认值：无。 配置原则： 仅当本命令中的“下发业务列表”参数为“SXZW”时该参数有效。该参数由1个或多个DNN组成。每个DNN格式为1～64位的字符串，只允许输入字母、数字、“%”、“-”、“_”、“.”和“*”。单个DNN不允许仅配置“%”或“*”。如果只有一个DNN，参数不需要带：“""”和 “&”，例如：Mnet.com。如果存在多个DNN时，每个DNN需要使用“"”标识，DNN之间使用 “&”进行连接，在字符“"”前需要添加转义字符“\”，例如：\"Mnet.com\"&\"Cnet.com\"。如果存在多个DNN时，多个DNN不能重复。DNN数量必须与“新DNN名称列表”中的DNN数量保持一致。DNN不允许配置为通配DNN。该参数与“新DNN名称列表”参数中不能存在重复的DNN。如果DNN以“%”结尾，表示该DNN为模糊匹配DNN，即用户签约的DNN包含该DNN即替换，允许配置多个模糊匹配DNN。如果DNN配置为“default*”（字母区分大小写），表示该DNN为替换用户签约默认DNN，仅允许配置一个。匹配时“default*”、模糊匹配DNN、完整DNN的处理优先级如下：同一个DNN仅替换一次，不支持多条规则多次连续替换。“default*”优先级最高。如果完整DNN和模糊匹配都可以匹配同一个DNN，完整DNN优先级最高。如果多个模糊匹配都匹配同一个DNN，则按照旧DNN在当前参数中配置的先后顺序，在先的匹配成功后，在后的不再匹配。 |
| NEWDNNLIST     | 新DNN名称列表    | 可选必选说明：条件必选参数 参数含义：用于标识新DNN名称列表。 取值范围：1～4000个字符组成的字符串。 默认值：无。 配置原则： 仅当本命令中的“下发业务列表”参数为“SXZW”时该参数有效。该参数由1个或多个DNN组成。每个DNN格式为1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。如果只有一个DNN，参数不需要带：“""”和 “&”，例如：Mnet.com。如果存在多个DNN时，每个DNN需要使用“"”标识，DNN之间使用 “&”进行连接，在字符“"”前需要添加转义字符“\”，例如：\"Mnet.com\"&\"Cnet.com\"。如果存在多个DNN时，多个DNN可以重复。DNN数量必须与“旧DNN名称列表”中的DNN数量保持一致。DNN不允许配置为通配DNN。                                                                                                                                                                                                                                                                                                                                                |

## 使用实例

修改5G业务下发模板的数据，“HLR序列号”为“1”，“模板ID”为“8”，“是否提供下发业务”为“TRUE”，“下发业务列表”为“SMDATA”，“会话信息模板ID”为“3”。

```
MOD NGCRSITPL: HLRSN=1, TPLID=8, PROV=TRUE, SERCODE=SMDATA, SMDATATPLID=3;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1009 | 参数丢失      | “模板名”和“是否提供下发业务”两个参数任意一个都没有输入。                                           | 根据实际情况，确保输入“模板名”和“是否提供下发业务”两个参数任意一个。                                       |
