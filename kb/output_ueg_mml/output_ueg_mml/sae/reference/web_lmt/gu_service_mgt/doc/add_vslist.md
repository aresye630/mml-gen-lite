# 增加VLR/SGSN漫游限制模板(ADD VSLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中增加VLR/SGSN限制模板数据记录，主要包括：

- 定义VLR/SGSN号码前缀，用于标识有相同前缀的VLR/SGSN号码的区域范围。

  当一个VLR/SGSN区域的移动用户向网络发起位置更新请求时，根据位置更新请求消息中携带的VLR/SGSN号码是否能匹配（最大前缀匹配）用户已签约VLR/SGSN漫游限制模板中的某个VLR/SGSN：
  - 如果能匹配，则根据该VLR/SGSN对应的漫游限制标志来判断允许该用户漫游还是禁止该用户漫游。
  - 如果不能匹配，则根据该模板中的缺省漫游限制标志来判断允许该用户漫游还是禁止该用户漫游。
- 定义用户在指定VLR/SGSN中的定制业务和超级接入限制数据。

## 注意事项

- 执行该命令只能对一个模板定义一个VLR/SGSN号码前缀，如果需要在一个模板中定义多个VLR/SGSN号码前缀，则需要执行**MOD VSLIST**命令进行添加。
- 系统中增加的VLR/SGSN漫游限制模板记录数分别不能超过3000条。
- 当参数“漫游区域配置方式”取值为“VSAREA\_TPL\_TYPE”时，参数“VLR/SGSN漫游区域模板ID”为必选参数，参数“VLR/SGSN号码前缀”不能携带。
- 当参数“漫游区域配置方式”取值为“VSAREA\_NUMBER\_TYPE”时，参数“VLR/SGSN号码前缀”为必选参数，参数“VLR/SGSN漫游区域模板ID”不能携带。
- 当参数“漫游区域配置方式”不携带时，参数“VLR/SGSN漫游区域模板ID”不能携带，参数“VLR/SGSN号码前缀”可以携带。

## 使用实例

为用户签约VLR/SGSN区域漫游限制业务操作员需要配置以下数据。

1. 增加“模板号”为“123”，“模板名称”为“SZLG”的VLR/SGSN漫游限制模板，模板中的VLR号码前缀为“8613900001”，允许用户在该VLR中漫游，用户的“缺省漫游限制状态”为“漫游限制”：

   ```
   ADD VSLIST: HLRSN=1, TPLID=123, TPLNAME="SZLG", TPLTYPE=VLR, VLRSGSNNO="8613900001", ROAMRULE=PERMISSION, ROAMDEFAULTRULE=RESTRICT;
   ```
2. 执行**MOD VSRR**命令给用户签约VLR/SGSN区域漫游限制业务。

   ```
   MOD VSRR: IMSI="460000009034567", PROV=TRUE, TPLTYPE=VLR, TPLID=123;
   ```
