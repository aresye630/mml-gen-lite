# 修改IMPI全局路由数据(MOD IMPIRTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条IMPI全局路由数据记录的某些参数进行修改或调整。在该命令中，系统通过“IMPI前缀”参数来唯一标识一条IMPI全局路由数据记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                             |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------|
| IMPIPREFIX | IMPI前缀 | 标识一条IMPI全局路由数据记录的关键字段（其取值不能被修改），用于指定需要对哪一个IMPI前缀对应的IMPI全局路由数据记录进行修改，操作员可以使用LST IMPIRTINFO命令查询获得。 |
| PID        | 分区ID   | 用于标识分区编号。该参数必须先由ADD SPRTINFO命令定义，然后才能在此处引用。 取值范围：1～250 默认值：无。                                    |

## 使用实例

修改IMPI全局路由数据，“IMPI前缀”为“1234”, “分区ID”为“12”，命令如下：

```
MOD IMPIRTINFO: IMPIPREFIX="1234", PID=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                     | 处理建议                                                                            |
|:--------|:--------|:-------------------------|:--------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“IMPI前缀”参数对应的数据记录不存在。 | 根据实际情况，重新输入参数，确保输入的“IMPI前缀”参数对应的数据记录是存在的，可通过LST IMPIRTINFO命令查询已存在的IMPI全局路由数据记录。 |
| ERR4142 | PID不存在  | PID未定义。                  | 执行LST SPRTINFO命令查询已配置云分区路由数据，重新执行该命令。                                           |
