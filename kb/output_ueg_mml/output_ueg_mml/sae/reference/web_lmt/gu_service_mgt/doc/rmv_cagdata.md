# 删除CAG管理数据(RMV CAGDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除5GS用户的一条或多条CAG数据。

## 注意事项

- 当5GS用户的“PLMNID”下携带“CAGID”时，一次只能删除一条“CAGID”数据。当删除最后一条“CAGID”数据会同时删除“PLMNID”数据。
- 当5GS用户的“PLMNID”下不携带“CAGID”时，则删除该条“PLMNID”数据。
- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                             |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：可选参数 参数含义：标识一条CAG数据记录的关键字段之一，用于指定需要删除哪一条CAG数据记录，操作员可以使用LST CAGDATA命令查询获得。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                           |
| ISDN        | MSISDN    | 可选必选说明：可选参数 参数含义：标识一条CAG数据记录的关键字段之一，用于指定需要删除哪一条CAG数据记录，操作员可以使用LST CAGDATA命令查询获得。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                           |
| RECORDCOUNT | 用户个数      | 可选必选说明：可选参数 参数含义：用于标识删除CAG数据的5GS用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户删除CAG数据时配置该参数。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除。当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                              |
| IMSIFILE    | IMSI文件名   | 可选必选说明：可选参数 参数含义：标识CAG数据记录的关键字段之一，用于指定需要删除哪几条CAG数据记录，操作员可以使用LST CAGDATA命令查询获得。 取值范围：1～35个字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待删除CAG数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvcagdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。     |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：可选参数 参数含义：标识CAG数据记录的关键字段之一，用于指定需要删除哪几条CAG数据记录，操作员可以使用LST CAGDATA命令查询获得。 取值范围：1～35个字母或十进制数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待删除CAG数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvcagdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 |
| PLMNID      | PLMNID    | 可选必选说明：必选参数 参数含义：用于标识需要删除CAG数据的5GS用户的PLMNID。 取值范围：5～6位十进制数字组成的字符串。 默认值：无。 配置原则：“PLMNID”的取值是由MCC（前三位）和MNC（后两至三位）组成，当输入的MNC（后两至三位）前缀为“0”时，不识别“0”。如：输入“123045”，系统识别为 PLMNID=“12345”。                                                                                |
| CAGID       | CAGID     | 可选必选说明：可选参数 参数含义：用于标识需要删除CAG数据的5GS用户的CAGID。 取值范围：8位十六进制数字组成的字符串。 默认值：无。 配置原则：参数取值中的字母不区分大小写。                                                                                                                                                                     |

## 使用实例

删除“IMSI”为“460031200100001”的用户CAG管理数据，其中“PLMNID”为"11111"，“CAGID”为“11111111”：

```
RMV CAGDATA: IMSI="460031200100001", PLMNID="11111", CAGID="11111111";
```
