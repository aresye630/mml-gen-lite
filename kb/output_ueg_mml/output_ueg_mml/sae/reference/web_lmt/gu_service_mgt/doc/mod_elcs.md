# 修改ELCS业务(MOD ELCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于提供、撤销或修改ELCS业务。

执行此命令后，如果是给用户提供该业务，则会下发插入用户数据消息；如果是给用户撤销该业务，则会下发删除用户数据消息。

需要提供ELCS业务的用户必须已经开户成功，且没有签约ELCS业务。

需要修改ELCS业务的用户必须已经开户成功，并且提供ELCS业务。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 撤销ELCS业务，参数PROV必须设置为FALSE。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                       |
|:------------|:-----------|:-------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数。                                                 |
| ISDN        | MSISDN     | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数。                                               |
| RECORDCOUNT | 用户个数       | 此参数用于设置用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名    | 此参数用于设置IMSI文件名称。IMSIFILE包含多个不连续的IMSI号码。 取值范围：1～16个字母或数字组成。                                 |
| ISDNFILE    | MSISDN文件名  | 此参数用于设置ISDN文件名称。ISDNFILE包含多个不连续的MSISDN号码。 取值范围：1～16个字母或数字组成。                               |
| PROV        | 是否提供ELCS业务 | 此参数用于设置是否提供增强位置业务（ELCS）。 取值范围： TRUE：提供FALSE：撤销 说明：必选参数。                                    |

## 使用实例

1. 为IMSI号码为460000009123456的用户提供ELCS业务，命令如下：

   MOD ELCS: IMSI="460000009123456", PROV=TRUE;
2. 为IMSI号码为460000009123456的用户撤销ELCS业务，命令如下：

   MOD ELCS: IMSI="460000009123456", PROV=FALSE;
