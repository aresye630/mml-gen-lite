# 查询IMPU基本信息模板(LST HIMPUTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询一个IMPU基本信息模板记录，一次只能查询一个IMPU基本信息模板记录，需要输入唯一标识该数据记录的关键参数IMPU模板ID。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                        |
|:-------|:---------|:----------------------------------------------------------------------------|
| TPLID  | IMPU模板ID | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个IMPU模板ID来查询IMPU基本信息模板数据，一次只能查询一个IMPU基本信息模板的数据。 |

## 使用实例

查询IMPU基本信息模板。IMPU模板ID：10。

```
LST HIMPUTPL: TPLID=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD HIMPUTPL**

命令的参数说明。表1是执行本命令输出参数取值

“0”

和

“1”

与

**ADD HIMPUTPL**

命令参数枚举含义的对应关系。

| 输出项名称   | 输出项解释                                                                                   |
|:--------|:----------------------------------------------------------------------------------------|
| BAR     | 用于返回指定IMPU的闭锁状态。0：FALSE，解除闭锁。1：TRUE，闭锁。                                                 |
| REGAUTH | 用于返回指定IMPU的注册权限。0：FALSE，不允许注册。1：TRUE，允许注册。                                              |
| VNCFLAG | 用于返回指定IMPU的漫游权限检查标志。0：FALSE，取消漫游权限检查。1：TRUE，进行漫游权限检查。                                   |
| LRI     | 用于返回指定IMPU是否签约松路由指示。0：LOOSE_ROUTE_NOT_REQUIRED，去签约松路由指示。1：LOOSE_ROUTE_REQUIRED，签约松路由指示。 |
