# 修改USSD控制数据(MOD USSDDAT)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使PUSSD消息处理失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改USSD控制数据信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条USSD控制数据类型信息：

- “HLR序列号”
- “业务码”

## 注意事项

- 如果将本命令中的参数“USSD类型”的值设为“VLRWSM”或“SGSNWSM”时，则参数“业务码”的取值必须是6位字符。当参数“USSD类型”的值设为“VLRWSM”时建议参数“业务码”的值设为“010400”，当参数“USSD类型”的值设为“SGSNWSM”时建议参数“业务码”的值设为“010401”。
- 该命令不允许进行批操作。

## 使用实例

在“HLR序列号”为“1”的HLR上，修改USSD控制数据类型为“WAP方式前转到USSD中心”，明确其中的业务码为特殊码，并使得其中的业务码按照完全匹配的原则进行匹配。其中，“业务码”为“\*168#”，“前转设备号码”为“86123999”，“业务码匹配原则”为“ALL\_MATCH”：

```
MOD USSDDAT: HLRSN=1, SRCODE="*168#", FUNCTION=WAPMODE, FWDADD="86123999", SPECIFIC=TRUE, MATCH_RULE=ALL_MATCH;
```

该命令执行正常，会返回命令执行成功的提示信息。
