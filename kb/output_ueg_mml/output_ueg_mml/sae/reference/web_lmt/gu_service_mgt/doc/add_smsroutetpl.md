# 增加SMS-Route模板(ADD SMSROUTETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来增加SMS-Route模板。

## 注意事项

系统中增加的SMS-Route模板记录数不能超过1000条。

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                              |
|:-----------|:------------|:--------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号      | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                      |
| TPLID      | 模板ID        | 用于标识待增加的SMS-Route模板ID。 取值范围：0～65534 默认值：无。                                                        |
| TPLNAME    | 模板名         | 用于标识待增加的SMS-Route模板名称。 取值范围：1～60位字母或数字组成的字符串。 默认值：无。                                              |
| ROUTEADDR  | SMS-Route地址 | 用于标识待增加的SMS-Route模板中的SMS-Route地址。此地址用于短消息重定向时作为目的GT地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。             |
| IP_SM_ADDR | IP-SM-GW地址  | 用于标识待增加的SMS-Route模板中的IP-SM-GW地址。此地址用于VoLTE用户在IMS域发送IP短消息时作为目的GT地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 |

## 使用实例

增加SMS-Route模板，“模板ID”为“3”，“模板名”为“SMSRoute”，“SMS-Route地址”为1，“IP-SM-GW地址”为“2”。命令如下：

ADD SMSROUTETPL: HLRSN=1, TPLID=3, TPLNAME="SMSRoute", ROUTEADDR="1", IP\_SM\_ADDR="2";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                                                                                                                     |
|:--------|:--------|:--------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 增加的SMS-Route模板记录数超过1000条。 | 根据实际情况，如需增加SMS-Route模板，处理步骤如下：执行LST SMSROUTETPL命令，查询已存在的SMS-Route模板。执行RMV SMSROUTETPL命令，删除不必要的SMS-Route模板。执行该命令增加SMS-Route模板，确保增加的SMS-Route模板记录数在规定范围之内。 |
