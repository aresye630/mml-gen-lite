# 删除HLR序列号(RMV HLRSN)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除虚拟HLR的配置信息。

## 注意事项

- 删除某个虚拟HLR配置信息时请核实该HLR是否已被使用，若被使用则不能删除。
- 只有当待删除的HLRSN状态取值为“INACTIVE”时才可以被删除。
- 混合组网下，执行该命令删除一条虚拟HLR配置信息时删除的“HLR最大用户数”、“HLR最大EPS用户数”、“IMS最大用户数”，只能在vRSP上生效，不支持同步SP。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                     |
|:-------|:--------|:-----------------------------------------|
| HLRSN  | 虚拟HLRSN | 标识虚拟HLR配置信息记录的关键字段，用于指定需要删除哪个虚拟HLR的配置信息。 |

## 使用实例

删除“HLR序列号”为“1”的虚拟HLR的配置信息，命令如下：

```
RMV HLRSN: HLRSN=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                        |
|:--------|:--------|:---------------------------|:----------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 用户输入的“HLR序列号”参数对应的数据记录不存在。 | 请按照以下步骤操作： 执行LST HLRSN命令查询需要查询的“HLR序列号”对应的数据记录信息。根据查询结果重新输入HLR序列号参数值进行删除操作。 |
| ERR3087 | 资源在使用   | 用户需要删除的虚拟HLR正在被使用或处于激活状态。  | 请先核实是否需要删除此虚拟HLR的信息记录，如需删除则需先使用MOD HLRSN命令进行去激活，然后再执行此命令。                   |
