# 修改ODB-RCF业务(MOD ODBRCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改运营商决定的闭锁－闭锁用户登记前转业务。

## 注意事项

- IMSI、MSISDN、IMSI文件名和MSISDN文件名是条件可选参数，任何一个参数出现即可。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI         | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ISDN        | MSISDN       | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                                                                                                                                                                                                                                                                                                                                    |
| RECORDCOUNT | 用户个数         | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                                                                                                                                                                                                                                                                                                                  |
| IMSIFILE    | IMSI文件名      | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                                                                                                                                                                                                                                                                                                                                                                                        |
| ISDNFILE    | MSISDN文件名    | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                                                                                                                                                                                                                                                                                                                                                                                      |
| ODBRCF      | ODB-闭锁用户登记前转 | 运营商决定的闭锁－闭锁用户登记前转。 NOBRCF：不闭锁。 BRACF：闭锁用户所有的前转业务登记。 BRICFEXHC：闭锁用户登记除了归属国以外的国际号码前转。 BRICF：闭锁用户登记国际号码前转。 配置原则：本参数取值为“BRICFEXHC”时，由SET MAPSERV命令“ODB-闭锁用户登记前转规则控制”参数的取值确定控制规则。DEFAULT_RULE：默认控制规则，规则如下所示：对于CFU业务，闭锁用户登记除了本网归属国家的前转号码。对于CFB、CFNRC、CFNRY业务，闭锁用户登记除了本网归属国家和漫游国家的前转号码。 BRICFEXHC_RULE：CFU和CCF按照相同规则控制，闭锁用户登记除了本网归属国家的前转号码。 本参数取值为“BRICF”时， 用户在HPLMN时，闭锁用户登记所有的国际号码前转；用户漫游出HPLMN时，对CFU业务，闭锁登记非HPLMN的前转号码；对CFB、CFNRC、CFNRY业务，闭锁登记HPLMN的前转号码。 |

## 使用实例

运营商为IMSI号码是460000009012345的用户应用ODB-RCF业务，闭锁的类型为闭锁用户登记国际号码前转。命令如下：

```
MOD ODBRCF: IMSI="460000009123456", ODBRCF=BRICF;
```
