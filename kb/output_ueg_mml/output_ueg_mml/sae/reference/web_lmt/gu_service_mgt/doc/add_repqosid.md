# 增加QoS模板替代配置(ADD REPQOSID)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游到指定的SGSN时下发错误的QoS，因此执行该命令前，需要和运营商的QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保添加的QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中增加一条QoS模板替代配置记录。增加了该QoS模板之后，当用户漫游在指定的SGSN下时，如果需要下发QoS数据，UDM将根据QoS模板替代关系，使用替代模板代替用户签约的QoS模板进行下发。

## 注意事项

- 当设置了QoS模板替代配置，系统会根据用户签约的QoS模板找到替换的模板配置并下发数据，用户原来签约的QoS模板将不会生效，会影响大量在网用户，因此现网执行该操作时需要慎重。执行该命令前需确定待添加的QoS替代配置和运营商的QoS模板替代配置表完全一致，并确保指定的SGSN上支持替换后的QoS模板对应的QoS数据。
- 参数“用户签约的QoS模板ID”和“替换的QoS模板ID”的取值不能相同。
- 该命令不允许进行批操作。
- 系统中增加的QoS模板替代配置的记录数不能超过3000条。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                   |
|:-----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                           |
| USRQOSID   | 用户签约的QoS模板ID | 用于标识一个待设置替换关系的QoS模板ID。当用户签约了该ID对应的QoS模板，并且漫游到指定的SGSN下时，将使用“替换的QoS模板ID”设置的替换模板进行下发。该参数必须先由ADD QOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 |
| SGSNPREFIX | SGSN号码或号码前缀  | 用于标识一个待设置替换关系的SGSN号码或号码前缀，采用最大匹配的原则进行匹配。在一个SGSN上，对同一“用户签约的QoS模板ID”，只有前缀匹配部分最长的一条记录能够生效。 取值范围：1～15位的十进制数字。 默认值：无。                       |
| REPQOSID   | 替换的QoS模板ID   | 用于标识一个替换后的Qos模板ID。在匹配的SGSN上，使用该ID对应的模板代替“用户签约的QoS模板ID”进行下发。该参数必须先由ADD QOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                        |

## 使用实例

为指定SGSN增加一条QoS模板替代配置记录，设置参数“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”，“SGSN号码或号码前缀”为“860001”，“替换的QoS模板ID”为“300”：

```
ADD REPQOSID: HLRSN=1, USRQOSID=1, SGSNPREFIX="860001", REPQOSID=300;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                    | 原因分析                                                       | 处理建议                                                                                                                                             |
|:--------|:-------------------------|:-----------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值                   | 参数“SGSN号码或号码前缀”的取值不是1～15位十进制数字组成的字符串。                      | 根据实际情况，重新输入参数“SGSN号码或号码前缀”的取值，确保其取值符合要求。                                                                                                         |
| ERR3003 | 模板未定义                    | 参数“用户签约的QoS模板ID”或“替换的QoS模板ID”没有在“HLR序列号”对应的虚拟HLR中预先定义。     | 根据实际情况，重新输入已定义的“用户签约的QoS模板ID”和“替换的QoS模板ID”，可通过LST QOSTPL命令查询虚拟HLR中已定义的QoS模板，确保输入的模板ID在“HLR序列号”对应的虚拟HLR中都已定义。                                     |
| ERR3006 | 记录已存在                    | 参数“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”的组合在数据库中已存在，不能重复添加。 | 根据实际情况，重新输入参数，确保输入的“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”的组合与系统中已存在的不重复。可执行LST REPQOSID命令查询系统中已存在的QoS模板替代配置记录。                                    |
| ERR3007 | 记录不存在                    | 参数“HLR序列号”的取值未预先定义，对应序列号的虚拟HLR不能添加QoS模板替代配置。               | 使用LST HLRSN命令查询已定义的HLR序列号，根据查询结果中存在的HLR序列号，重新输入“HLR序列号”参数值。                                                                                      |
| ERR3047 | 超过最大限制                   | 添加的QoS模板替代配置记录超过了3000条。                                    | 根据实际情况，如需增加QoS模板替代配置记录，处理步骤如下：执行LST REPQOSID命令，查询已存在的QoS模板替代配置记录。执行RMV REPQOSID命令，删除不必要的QoS模板替代配置记录。执行该命令增加QoS模板替代配置记录，确保增加的QoS模板替代配置记录数在规定范围之内。 |
| ERR4075 | 业务冲突，USRQOSID和REPQOSID相同 | 参数“用户签约的QoS模板ID”和“替换的QoS模板ID”的取值相同。                        | 根据实际情况，重新输入参数“用户签约的QoS模板ID”和“替换的QoS模板ID”，确保二者取值不同。                                                                                               |
