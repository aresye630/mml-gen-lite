# 显示升级操作执行结果（DSP UPDACTIONRESULT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示升级操作执行结果。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示升级操作结果：

```
DSP UPDACTIONRESULT:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
           升级命令 =  加载软件包（LOD PACKAGE）
       命令开始时间 =  2016-01-28 15:09:13
       命令结束时间 =  2016-01-28 15:09:14
       命令执行状态 =  该升级操作已经执行完成。
  命令执行进度（%） =  100
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                                                  |
|:----------|:-----------------------------------------------------------------------|
| 升级命令      | 表示当前正在进行或者已经执行结束的升级命令，包括LOD PACKAGE、ACT PACKAGE、RBK PACKAGE和RMV PATCH。 |
| 命令开始时间    | 表示升级操作开始时间点。                                                           |
| 命令结束时间    | 表示升级操作结束时间点。                                                           |
| 命令执行状态    | 表示升级操作的执行结果。                                                           |
| 命令执行进度（%） | 表示升级操作的执行进度。                                                           |
