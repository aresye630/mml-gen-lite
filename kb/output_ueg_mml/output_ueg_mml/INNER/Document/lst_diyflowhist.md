# 查询原子对象记录（LST DIYFLOWHIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询原子对象记录。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                            |
|:---------|:---------|:--------------------------------------------------------------------------------|
| ATOM_OBJ | 原子对象记录标识 | 可选必选说明：可选参数  参数含义：原子对象记录标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

查询所有开关记录。

```
%%LST DIYFLOWHIST:;%%
RETCODE = 0  操作成功

结果如下
--------
原子对象记录值  原子对象         

enable          GLOBALFABRICOAM    
On              NODEREPSWITCH    
TRUE            PAEEXAMINATION   
ENABLE          PODHEALCTRL      
VNFM            SCALINGSWITCH    
(结果个数 = 5)

---    END
```

|:---------|:----------|

| 原子对象记录标识 | 原子对象记录标识。 |
