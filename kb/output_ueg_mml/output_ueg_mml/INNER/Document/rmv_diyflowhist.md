# 删除原子对象记录（RMV DIYFLOWHIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除原子对象记录。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                            |
|:---------|:---------|:--------------------------------------------------------------------------------|
| ATOM_OBJ | 原子对象记录标识 | 可选必选说明：必选参数  参数含义：原子对象记录标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

删除Pod自愈开关记录。

```
RMV DIYFLOWHIST: ATOM_OBJ="PODHEALCTRL";
```
