# 设置外部策略广播核查开关（SET EXTPLCYCHKOPT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置外部策略广播核查开关。将开关设置为关闭状态，SDRC停止用于对所有APP核查外部策略的定时广播。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                           |
|:-------|:---------------|:---------------------------------------------------------------------------------------------------------------|
| SWITCH | 设置外部策略广播核查开关状态 | 可选必选说明：必选参数  参数含义：是否开启外部策略广播核查，ON表示开启， OFF表示关闭。  数据来源：本端规划 取值范围： ON（开启外部策略广播核查）OFF（关闭外部策略广播核查）  默认值：无。  配置原则：无 |

## 使用实例

使用如下命令关闭外部策略广播核查。

```
%%SET EXTPLCYCHKOPT: SWITCH=OFF;%%
RETCODE = 0  Operation succeeded
```
