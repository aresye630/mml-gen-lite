# 设置灰度升级状态（SET SAUPGSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务异常变更，请谨慎使用并联系华为技术支持协助处理，非必要请勿手动触发。

该命令用于灰度升级过程中自动设置灰度升级状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                        |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SAUPGSTATUSFLAG | 灰度升级状态 | 可选必选说明：必选参数。 参数含义：该参数用于设置灰度升级状态。 数据来源：本端规划 取值范围： 0：非灰度升级状态。1：整系统灰度升级开始状态。2：主控板复位升级结束。3：业务板滚动升级结束。4：整系统灰度升级结束。5：拨测阶段开始。6：拨测阶段结束。7：整系统无损回退开始。8：主控板复位回退结束。9：业务板复位回退结束。10：整系统无损回退结束。11~15：预留字段。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数。 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划。 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无。 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                             |

#### 使用实例

如果升级过程中，主控板复位升级结束，升级流程会执行该命令将灰度升级状态设为复位升级结束状态：

```
SET SAUPGSTATUS: SAUPGSTATUSFLAG=2, SERVICEINSTANCE="CSLB_VNFC_999";
```
