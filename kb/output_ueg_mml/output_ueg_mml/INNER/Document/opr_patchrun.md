# 一键式运行补丁（OPR PATCHRUN）

#### 命令功能

**须知** 

本命令属于高危命令，会激活或者删除系统补丁，涉及冷补丁时，会重启系统，请谨慎使用并联系华为支持协助操作。

该命令用于一键式运行补丁。当只需要给当前版本打补丁，不需要升级基础版本时，可以不执行加载，激活命令，直接使用该命令打补丁。

#### 注意事项

- 该命令执行后立即生效。
- 如果PKGVERSIONID参数指定基础版本号则会删除补丁。
- 该命令执行后，涉及重启的，需要在重启后参数RBKTIMER所设置的时间内立即登录，并通过DSP PATCHDETAILINFO或者DSP PATCHINFO查询该操作是否成功。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                           |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| PKGVERSIONID    | 版本号    | 可选必选说明：必选参数 参数含义：该参数用于指定基础软件版本号或补丁版本号，如果指定基础版本号则会删除补丁，如果指定补丁版本号，则一键式运行对应的补丁版本，但这个补丁版本必须与当前补丁版本存在增减量关系。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| RBTMODE         | 重启模式   | 可选必选说明：可选参数 参数含义：该参数用于指定允许的重启模式。 数据来源：本端规划 取值范围：枚举类型。 NO：不重启。SOFT：软重启，不需要重启资源。 默认值：NO                                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                   |

#### 使用实例

一键运行补丁包：

```
OPR PATCHRUN:PKGVERSIONID="V100R005SPH001",RBTMODE=SOFT,SERVICEINSTANCE="vnfc";
```
