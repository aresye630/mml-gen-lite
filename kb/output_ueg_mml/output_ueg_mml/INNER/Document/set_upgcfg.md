# 设置升级状态（SET UPGCFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置灰度升级状态。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                             |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| UPGTYPE | 升级指令   | 可选必选说明：必选参数 参数含义：灰度升级状态表的升级阶段信息。 数据来源：本端规划 取值范围：枚举类型。 NORMAL：非升级态。UPGRADE：升级开始。MIGRATE：迁移开始。ROLLBACK：升级回退。 默认值：无 |
| PLANE   | 升级平面   | 可选必选说明：必选参数 参数含义：灰度升级状态表的平面信息。 数据来源：本端规划 取值范围：枚举类型。 NORMAL：非升级态平面。OLD：旧平面。NEW：新平面。 默认值：无                         |

#### 使用实例

设置灰度升级状态表信息：

```
SET UPGCFG: UPGTYPE=MIGRATE, PLANE=OLD;
```
