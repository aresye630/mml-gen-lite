# 删除VNFC内的资源配置信息（RMV VNFCRES）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除VNFC内的资源配置信息。当删除某资源单元对应的容器时，需要同时执行该命令删除此资源单元的配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只支持在容器场景下执行。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                         |
|:----------------|:-------|:---------------------------------------------------------------------------------------------|
| VNFCNAME        | VNFC名称 | 可选必选说明：必选参数 参数含义：该参数用于表示资源所在的VNFC名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无     |
| RESINSTANCETYPE | 资源实例类型 | 可选必选说明：必选参数 参数含义：用于表示资源实例类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无             |
| PARRESNAME      | 父资源名称  | 可选必选说明：必选参数 参数含义：用于表示父资源名称，即资源所在Pod的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。不支持空格，区分大小写。 默认值：无 |

#### 使用实例

删除VNFC名称为VNFP、资源实例类型为IPU\_A、父资源名称为ipu-node-app-5fe4b77c-1的资源配置信息：

```
RMV VNFCRES:VNFCNAME="VNFP",RESINSTANCETYPE="IPU_A",PARRESNAME="ipu-node-app-5fe4b77c-1";
```
