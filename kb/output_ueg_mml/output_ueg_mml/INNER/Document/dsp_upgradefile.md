# 显示升级数据文件列表信息（DSP UPGRADEFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看升级数据文件列表信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| OPERTYPE        | 操作类型   | 可选必选说明：必选参数 参数含义：操作类型。 数据来源：本端规划 取值范围：枚举类型。 backup：逃生回退场景下网元数据文件的相关操作。upgrade：灰度升级场景下升级数据文件的相关操作。 默认值：无      |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示升级数据文件列表信息：

```
DSP UPGRADEFILE:OPERTYPE=upgrade,SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
---------
    文件索引  = 1   
文件创建时间  = Feb 23 2016 10:02:26                   
 文件大小（B）= 225
    文件名称  = version.txt
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 文件索引    | 网元升级文件序号，从1开始编号。 |
| 文件创建时间  | 网元升级文件最后一次更改时间。  |
| 文件大小（B） | 网元升级文件大小。        |
| 文件名称    | 网元升级文件名。         |
