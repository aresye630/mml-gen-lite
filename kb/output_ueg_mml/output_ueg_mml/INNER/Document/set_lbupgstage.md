# 设置LB灰度升级阶段（SET LBUPGSTAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置CSLB灰度升级阶段。

#### 注意事项

- 该命令执行后立即生效。

该命令存在系统初始记录，参数的初始设置值如下表：

| STAGE        |
|:-------------|
| STEADY_STAGE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                             |
|:-------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STAGE  | CSLB灰度升级阶段 | 可选必选说明：必选参数 参数含义：该参数用于设置CSLB灰度升级阶段。 数据来源：本端规划 取值范围：枚举类型STEADY_STAGE：稳态阶段； CSLB_GRAY_UPGRADE_BEGIN：CSLB灰度升级开始；CSLB_GRAY_UPGRADE_END：CSLB灰度升级结束；CSLB_ROLLBACK_BEGIN：CSLB灰度回退开始；CSLB_ROLLBACK_END：CSLB灰度回退结束； 默认值：无 |

#### 使用实例

设置CSLB灰度升级阶段为CSLB灰度升级开始，执行以下命令：

```
SET LBUPGSTAGE: STAGE=STEADY_STAGE;
```
