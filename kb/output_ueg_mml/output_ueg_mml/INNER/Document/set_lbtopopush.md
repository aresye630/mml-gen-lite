# 设置LB拓扑推送状态（SET LBTOPOPUSH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于无损升级中，控制Topo推送状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| VALUE  | 参数值    | 可选必选说明：必选参数 参数含义：该参数用于选择TOPO推送状态。 数据来源：全网规划 取值范围：枚举类型DEFAULT：默认状态（不阻止推送） KEEP：保持状态DOWN：阻止推送状态 默认值：DEFAULT |

#### 使用实例

设置灰度升级模式，执行以下命令：

SET LBTOPOPUSH: VALUE=DEFAULT;
