# 查询NP工作模式（DSP NPMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询NP网络模式和加速模式。

该命令仅适用于灰度升级场景。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询NP工作模式：

```
%%DSP NPMODE:;%%
RETCODE = 0  操作成功

结果如下
--------
网络模式  =  2
加速模式  =  2
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                            |
|:--------|:-----------------------------------------------------------------|
| 网络模式    | 表示NP卡网络模式。返回值为： 0：非NP卡或NP卡非加速模式。1：NP卡ECMP组网模式。2：NP卡省交换组网模式。      |
| 加速模式    | 表示NP卡加速模式。返回值为： 0：非NP卡或NP卡非加速模式。1：NP卡加速VNRS卸载模式。2：NP卡加速CSLB卸载模式。 |
