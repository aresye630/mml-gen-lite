# 查询升级状态表（LST UPGCFG）

- 命令功能

#### 命令功能

该命令用于查询灰度升级状态表。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询灰度升级状态表信息：

```
LST UPGCFG;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
升级状态  =  非升级态
升级平面  =  新平面
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET UPGCFG**的参数说明。
