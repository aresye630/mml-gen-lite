# 查询升级模式（DSP UPDMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询灰度升级模式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

查询升级模式：

```
DSP UPDMODE:;
```

```
RETCODE = 0  操作成功

结果如下
------------------------
  升级模式  =  单倍资源升级模式
      结果  =  成功
    结果码  =  0
   升级步数 =  6
   扩展模式 =  1
   特性版本 =  1.0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释      |
|:--------|:-----------|
| 升级模式    | 用于表示升级模式。  |
| 结果      | 用于表示查询结果。  |
| 结果码     | 用于表示查询结果码。 |
| 升级步数    | 用于表示升级步数。  |
| 扩展模式    | 用于表示扩展模式。  |
| 特性版本    | 用于表示特性版本。  |
