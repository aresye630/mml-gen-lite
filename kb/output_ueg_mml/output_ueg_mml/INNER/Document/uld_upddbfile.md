# 上传DB文件（ULD UPDDBFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于上传升级DB文件。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| UPDDBFILE       | 升级DB文件 | 可选必选说明：必选参数 参数含义：该参数用于指定升级DB文件。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                     |
| UPDMKFILE       | 升级密钥文件 | 可选必选说明：可选参数 参数含义：该参数用于指定升级密钥文件。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                     |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

上传升级DB文件：

```
ULD UPDDBFILE:UPDDBFILE="vrpcfg.dat",UPDMKFILE="mkcfg.dat",SERVICEINSTANCE="vnfc";
```
