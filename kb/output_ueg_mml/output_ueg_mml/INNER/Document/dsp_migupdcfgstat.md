# 查询升级状态（DSP MIGUPDCFGSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询升级时业务状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                         |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGFILEPATH | 配置文件路径   | 可选必选说明：必选参数 参数含义：该参数用来指定配置文件路径信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无                                                                                                                                                                   |
| UPGFILENAME | 升级操作文件名称 | 可选必选说明：必选参数 参数含义：该参数用来显示升级操作文件名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                                  |
| UPGRADEMODE | 升级模式     | 可选必选说明：必选参数 参数含义：该参数用来指定升级模式信息。 数据来源：本端规划 取值范围：枚举类型。 SINGLE：单倍资源升级模式。DOUBLE：双倍资源升级模式。HALFRU：一半RU切换升级模式。DUAL_PLANE：双平面升级模式。 默认值：无                                                                                                             |
| ROLE        | 升级角色     | 可选必选说明：必选参数 参数含义：该参数用来指定升级角色信息。 数据来源：本端规划 取值范围：枚举类型。 OLD：旧版本的VNFC。NEW：新版本的VNFC。 默认值：无                                                                                                                                                        |
| STEP        | 步骤       | 可选必选说明：条件必选参数 前提条件：该参数在“UPGRADEMODE”配置为“DOUBLE” 或 “DUAL_PLANE”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“UPGRADEMODE”配置为“HALFRU”时为可选参数。 参数含义：该参数用于表示步骤。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。DOUBLE模式STEP取值范围由升级server向VNFC查询得到，HALFRU模式STEP取值范围为1~3。 默认值：无 |
| RUID        | RU号      | 可选必选说明：条件必选参数 前提条件：该参数在“UPGRADEMODE”配置为“SINGLE”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“UPGRADEMODE”配置为“HALFRU”时为可选参数。 参数含义：该参数用于表示RU ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                |

#### 使用实例

查询升级状态：

```
DSP MIGUPDCFGSTAT:CFGFILEPATH="/",UPGFILENAME="UpgradeExt",UPGRADEMODE=HALFRU,ROLE=OLD,STEP=1;
```

```
RETCODE = 0  操作成功

结果如下
------------------------
      升级结果  =  成功
        返回码  =  0
(结果个数 = 1)
---    END
```
