# 执行灰度升级规划、配置迁移、配置回退及配置资源清理（MOD UPDCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

注意：该命令用于IPNLS灰度升级，包括配置规划，升级配置迁移，升级配置回退以及资源清理。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令可能会修改设备配置。
- 该命令仅供灰度升级使用。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                        |
|:-------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTIONMODE   | 操作类型      | 可选必选说明：必选参数 参数含义：该参数用来指定操作类型。 数据来源：本端规划 取值范围：枚举类型。 MODIFYCFG：修改升级配置。MIGRATE：迁移升级配置。ROLLBACK：回退升级配置。CLEARRES：清理资源。 默认值：无                                                                                                                                                                     |
| ISENCRYPTED  | 文件是否加密    | 可选必选说明：条件必选参数 前提条件：该参数在“OPTIONMODE”配置为“MODIFYCFG”时为必选参数。 参数含义：该参数用来指文件是否加密。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不需要密码。TRUE：需要密码。 默认值：无                                                                                                                                                               |
| PASSWORD     | 解密密码      | 可选必选说明：条件必选参数 前提条件：该参数在“ISENCRYPTED”配置为“TRUE”时为必选参数。 参数含义：该参数用来指定配置文件解密的密码信息。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～31。 默认值：无                                                                                                                                                                        |
| ROLLBACKMODE | 回退模式      | 可选必选说明：条件必选参数 前提条件：该参数在“OPTIONMODE”配置为“ROLLBACK”时为必选参数。 参数含义：该参数用来指定回退模式信息。 数据来源：本端规划 取值范围：枚举类型。 LOSSLESS：无损模式。LOSSY：有损模式。 默认值：无                                                                                                                                                            |
| UPGRADEMODE  | 升级模式      | 可选必选说明：条件必选参数 前提条件：该参数在“OPTIONMODE”配置为“MODIFYCFG”、“MIGRATE”、“ROLLBACK” 或 “CLEARRES”时为必选参数。 参数含义：该参数用来指定升级模式信息。 数据来源：本端规划 取值范围：枚举类型。 SINGLE：单倍资源升级模式。DOUBLE：双倍资源升级模式。HALFRU：一半RU切换升级模式。DUAL_PLANE：双平面升级模式。 默认值：无                                                                             |
| CFGFILEPATH  | 配置文件路径    | 可选必选说明：必选参数 参数含义：该参数用来指定配置文件路径信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无                                                                                                                                                                                                                  |
| CFGFILENAME  | 配置文件名称    | 可选必选说明：条件必选参数 前提条件：该参数在“OPTIONMODE”配置为“MODIFYCFG” 或 “CLEARRES”时为必选参数。 参数含义：该参数用来指定配置文件名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                         |
| NEWFILENAME  | 修改后配置文件名称 | 可选必选说明：条件必选参数 前提条件：该参数在“OPTIONMODE”配置为“MODIFYCFG” 或 “CLEARRES”时为必选参数。 参数含义：该参数用来显示修改后配置文件名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                      |
| MODLOGNAME   | 日志文件名称    | 可选必选说明：必选参数 参数含义：该参数用来显示修改日志文件名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                                                                                 |
| UPGFILENAME  | 升级操作文件名称  | 可选必选说明：必选参数 参数含义：该参数用来显示升级操作文件名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                                                                                 |
| ROLE         | 升级角色      | 可选必选说明：必选参数 参数含义：该参数用来指定升级角色信息。 数据来源：本端规划 取值范围：枚举类型。 OLD：旧版本的VNFC。NEW：新版本的VNFC。 默认值：无                                                                                                                                                                                                       |
| STEP         | 步骤        | 可选必选说明：条件必选参数 前提条件：该参数在“UPGRADEMODE”配置为“DUAL_PLANE”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“OPTIONMODE”配置为“MIGRATE”时为可选参数。 可选必选说明：条件可选参数 前提条件：该参数在“ROLLBACKMODE”配置为“LOSSLESS”时为可选参数。 参数含义：该参数用于表示步骤。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。DOUBLE模式STEP取值范围由升级server向VNFC查询得到，HALFRU模式STEP取值范围为1~3。 默认值：无 |
| RUID         | RU ID     | 可选必选说明：条件可选参数 前提条件：该参数在“UPGRADEMODE”配置为“SINGLE”时为可选参数。 参数含义：该参数用于表示RU ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                                                                                                                      |
| CONFIRM      | 确认状态      | 可选必选说明：条件可选参数 前提条件：该参数在“UPGRADEMODE”配置为“SINGLE” 或 “DUAL_PLANE”时为可选参数。 参数含义：该参数用来指定确认状态。 数据来源：本端规划 取值范围：枚举类型。 BEGIN：开始。END：结束。 默认值：无                                                                                                                                                         |

#### 使用实例

灰度升级：

```
MOD UPDCFG:UPGRADEMODE=HALFRU,CFGFILENAME ="MML",CFGFILEPATH ="/",NEWFILENAME="MML_CFG",MODLOGNAME="UpgradeModifyRecord",UPGFILENAME="UpgradeExt",OPTIONMODE=MODIFYCFG,ISENCRYPTED=FALSE,ROLE=OLD;
```
