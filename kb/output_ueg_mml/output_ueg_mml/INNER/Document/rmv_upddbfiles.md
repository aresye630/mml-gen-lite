# 删除DB文件（RMV UPDDBFILES）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除所有升级DB文件。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，会删除所有保存的升级DB文件。
- 该命令为异步操作，操作过程中网元会上报进度信息，进度上报显示操作成功或者失败，表示该操作结束。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

删除所有保存的升级DB文件：

```
RMV UPDDBFILES:SERVICEINSTANCE="vnfc";
```
