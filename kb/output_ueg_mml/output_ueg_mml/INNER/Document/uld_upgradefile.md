# 上传升级数据文件（ULD UPGRADEFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于上传升级数据文件或网元数据文件。

#### 注意事项

- 该命令执行后立即生效。
- 上传升级数据文件依赖通过**BKP UPGRADEFILE**命令对升级数据文件进行备份。
- 该命令为异步操作，操作过程中网元会上报进度信息，进度上报显示操作成功或者失败，表示该操作结束。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称      | 参数说明                                                                                                         |
|:------------------|:----------|:-------------------------------------------------------------------------------------------------------------|
| OPERTYPE          | 操作类型      | 可选必选说明：必选参数 参数含义：操作类型。 数据来源：本端规划 取值范围：枚举类型。 backup：逃生回退场景下网元数据文件的相关操作。upgrade：灰度升级场景下升级数据文件的相关操作。 默认值：无      |
| TRANSFERPROTOCOL  | 传输协议      | 可选必选说明：必选参数 参数含义：传输协议。 数据来源：对端协商 取值范围：枚举类型。 SFTP：传输协议为SFTP。 默认值：无 配置原则：当前只支持SFTP传输协议。                        |
| IPVERSION         | 服务器IP地址类型 | 可选必选说明：可选参数 参数含义：服务器IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4类型。IPV6：IPv6类型。 默认值：IPV4                           |
| SERVERIPV4ADDRESS | 服务器IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：服务器IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无            |
| SERVERIPV6ADDRESS | 服务器IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：服务器IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无            |
| SERVERPORT        | 服务器端口号    | 可选必选说明：必选参数 参数含义：服务器端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65535。 默认值：无                                             |
| USERNAME          | 用户名       | 可选必选说明：必选参数 参数含义：用户名。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～64。不支持空格，区分大小写。 默认值：无                                    |
| PASSWORD          | 密码        | 可选必选说明：可选参数 参数含义：密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～64。不支持空格，区分大小写。 默认值：无                                      |
| DIR               | 服务器目录     | 可选必选说明：必选参数 参数含义：服务器目录。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～255。不支持空格，区分大小写。 默认值：无                                 |
| SERVICEINSTANCE   | 服务实例      | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

上传升级数据文件：

```
ULD UPGRADEFILE:OPERTYPE=upgrade,TRANSFERPROTOCOL=SFTP,SERVERPORT=22,IPVERSION=IPV4,SERVERIPV4ADDRESS="10.1.1.1",USERNAME="omuser",PASSWORD="******",DIR="upgrade/data/",SERVICEINSTANCE="vnfc";
```
