# 查询灰度升级状态（LST SAUPGSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示灰度升级状态。

灰度升级过程前后，可以使用该命令查询灰度升级状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

如果用户希望显示当前灰度升级状态时，可以执行如下操作：

```
LST SAUPGSTATUS: SERVICEINSTANCE="CSLB_VNFC_999";
RETCODE = 0  操作成功。
结果如下
--------
灰度升级状态 = 0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                 |
|:--------|:--------------------------------------------------------------------------------------|
| 灰度升级状态  | 表示灰度升级状态。返回值为： 0：非灰度升级状态。1：整系统灰度升级开始状态。2：主控板复位升级结束。3：业务板滚动升级结束。4：整系统灰度升级结束。5~9: 预留字段。 |
