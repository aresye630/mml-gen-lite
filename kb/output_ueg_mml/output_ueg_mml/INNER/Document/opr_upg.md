# 处理升级请求（OPR UPG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于下发GSC灰度升级指令。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------|
| UPGTYPE | 升级指令   | 可选必选说明：必选参数 参数含义：灰度升级的操作指令。 数据来源：本端规划 取值范围：枚举类型。 NORMAL：非升级态。UPGRADE：升级开始。CERT：拷贝证书。MIGRATE：迁移开始。ROLLBACK：升级回退。MODIFYCFG：修改升级配置。 默认值：无 |
| PLANE   | 升级平面   | 可选必选说明：必选参数 参数含义：灰度升级的平面。 数据来源：本端规划 取值范围：枚举类型。 NORMAL：非升级态平面。OLD：旧平面。NEW：新平面。 默认值：无                                                    |

#### 使用实例

下发灰度升级操作指令：

```
OPR UPG: UPGTYPE=CERT, PLANE=NEW;
```
