# 查询用户跟踪策略（LST USRTRCPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示用户跟踪策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询用户跟踪策略：

```
LST USRTRCPLY:;
```

```
RETCODE = 0 操作成功。

用户跟踪策略
-----------------
最大保留天数  =  7
匿名化开关  =  使能
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET USRTRCPLY的参数说明。
