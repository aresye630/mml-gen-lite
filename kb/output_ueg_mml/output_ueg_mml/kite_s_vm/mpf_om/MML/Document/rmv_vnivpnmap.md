# 删除VNI到VPN的映射（RMV VNIVPNMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，此操作会中断Vxlan隧道，可能导致相关业务中断。

该命令用于删除VNI与VPN的映射关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| VNI    | VNI    | 可选必选说明：必选参数 参数含义：该参数用于配置VxLan隧道标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777215。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商想要将VNI为1的映射关系删除：

```
RMV VNIVPNMAP: VNI=1;
```
