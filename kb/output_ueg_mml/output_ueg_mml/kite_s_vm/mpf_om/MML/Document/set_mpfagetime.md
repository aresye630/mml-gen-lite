# 设置MEC会话老化时长（SET MPFAGETIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于配置MPF上的普通用户和UAC用户上下文老化时间，当达到老化时间后，释放用户上下文。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   CTXAGETIME |   UACCTXAGETIME |
|:-------|-------------:|----------------:|
| 初始值    |           60 |               2 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                   |
|:--------------|:--------------|:-------------------------------------------------------------------------------------------------------|
| CTXAGETIME    | 上下文老化时长（分）    | 可选必选说明：可选参数 参数含义：该参数用于设置上下文老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为5~1440，单位是分钟，0为不老化。 默认值：无 配置原则：该参数设置后立即生效。   |
| UACCTXAGETIME | UAC上下文老化时长(分) | 可选必选说明：可选参数 参数含义：该参数用于设置UAC上下文老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~120，单位是分钟，0为不老化。 默认值：无 配置原则：该参数设置后立即生效。 |

#### 使用实例

执行命令设置MPF上的普通用户老化时长为60分钟，UAC用户老化时长为2分钟：

```
SET MPFAGETIME: CTXAGETIME=60, UACCTXAGETIME=2;
```
