# 增加黑名单规则（ADD BLACKLISTRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

此命令用于在配置业务策略的时候增加指定策略类型的黑名单规则，用于实现相应策略类型的黑名单规则。通过的报文经过流过滤器或流过滤器组的匹配基于优先级选择相应策略类型中优先级最高的规则，命中黑名单规则的业务流无需执行相应策略类型的策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- RULE命令与BLACKLISTRULE命令同属于Rule对象，共享配置记录空间、MOD RULE命令、RMV RULE命令和LST RULE命令。
- 对于同属于Rule对象的RULE命令和BLACKLISTRULE命令来说，规则名称和策略类型共同构成一条配置的唯一标识，由于共享配置记录空间，ADD RULE命令和ADD BLACKLISTRULE命令不能配置相同的规则名称和策略类型。
- BlackListRule的匹配原则与Rule是一致的，命中BlackListRule的业务流无需执行相应策略类型的策略。
- 如果BlackListRule没有配置生效时间，则默认一直生效。
- 不支持配置策略类型为MTP的黑名单规则。
- 如果流过滤器绑定了除DNS外的其他七层协议，则不能使用Web代理策略。
- 该命令设定后的数据，需要通过LST RULE命令进行查看。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                                        |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME       | 规则名称         | 可选必选说明：必选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                   |
| POLICYTYPE     | 策略类型         | 可选必选说明：必选参数 参数含义：该参数用于设置策略类型。 数据来源：本端规划 取值范围：枚举类型。 BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。 默认值：无 配置原则：黑名单规则不配置和执行任何策略。                                                       |
| FILTERINGMODE  | 流过滤器或流过滤器组选择 | 可选必选说明：必选参数 参数含义：该参数用于设置流过滤器或流过滤器组选择。 数据来源：本端规划 取值范围：枚举类型。 FLOWFILTER：指定流过滤器作为过滤条件。FLOWFILTERGRP：指定流过滤器组作为过滤条件。 默认值：无 配置原则： 如果运营商希望基于流过滤器设置过滤条件，设置该参数为FLOWFILTER。如果运营商希望基于流过滤器组设置过滤条件，设置该参数为FLOWFILTERGRP。                                                  |
| FLOWFILTERNAME | 流过滤器名称       | 可选必选说明：条件必选参数 前提条件：该参数在“FILTERINGMODE”配置为“FLOWFILTER”时为必选参数。 参数含义：该参数用于设置流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD FLOWFILTER命令配置生成。设置的FLOWFILTERNAME必须是系统已经存在的流过滤器名称。                                                    |
| FLWFLTRGRPNAME | 流过滤器组名称      | 可选必选说明：条件必选参数 前提条件：该参数在“FILTERINGMODE”配置为“FLOWFILTERGRP”时为必选参数。 参数含义：该参数用于设置流过滤器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：该参数使用ADD FLOWFILTERGRP命令配置生成。                                                                                      |
| TIMERANGENAME  | 时间段名称        | 可选必选说明：可选参数 参数含义：该参数用于设置TimeRange名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD TIMERANGE命令配置生成。如果运营商希望控制BlackListRule生效的时间段信息，则可以配置TimeRange对象名称，只有TimeRange定义的时间段内，BlackListRule才可以生效并参与匹配和策略处理。设置的TIMERANGENAME必须是系统已经存在的时间段名称。 |
| PRIORITY       | 全局优先级        | 可选必选说明：可选参数 参数含义：该参数用于设置全局优先级，仅对PCC用户生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。值越小优先级越高。 默认值：65535 配置原则：设置的PRIORITY仅对PCC用户生效。为了避免后续规划的规则与已配置规则的优先级冲突，建议规划优先级时按照10的倍数来定义，以便于后续插入任意优先级的新规则。                                                                        |

#### 使用实例

假如运营商需要定义一个带宽控制的黑名单规则，要求命中FlowFilter为TESTFLOWFILTER的业务不需要进行带宽控制操作，优先级为50：

```
ADD BLACKLISTRULE:RULENAME="TESTBLACKLISTRULE",POLICYTYPE=BWM,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="TESTFLOWFILTER",PRIORITY=50;
```
