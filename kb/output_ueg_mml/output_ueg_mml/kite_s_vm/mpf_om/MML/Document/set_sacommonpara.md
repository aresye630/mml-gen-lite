# 设置SA业务公共参数（SET SACOMMONPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用来配置SA业务相关控制参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   NORSTPKTNUM | CDNENHANCEDSW   |
|:-------|--------------:|:----------------|
| 初始值    |             0 | DISABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                    |
|:--------------|:-------------|:--------------------------------------------------------------------------------------------------------|
| NORSTPKTNUM   | 没有确定业务的报文的个数 | 可选必选说明：可选参数 参数含义：控制连续多少个报文没有确定业务，则确定业务。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：无                    |
| CDNENHANCEDSW | CDN增强识别功能    | 可选必选说明：可选参数 参数含义：该参数用于指定是否开启CDN识别增强功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无 |

#### 使用实例

控制连续多少个报文没有确定业务，则确定业务：

```
SET SACOMMONPARA:  NORSTPKTNUM=0;
```
