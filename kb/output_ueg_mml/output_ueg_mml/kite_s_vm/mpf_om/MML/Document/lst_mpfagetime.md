# 查询MEC会话老化时长（LST MPFAGETIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询MPF上的普通用户和UAC用户上下文老化时间。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前MPF上的普通用户和UAC用户上下文老化时长：

```
LST MPFAGETIME:;
```

```
RETCODE = 0 操作成功

MPF老化时长信息
---------------
上下文老化时长（分） = 60
UAC上下文老化时长(分) = 2
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET MPFAGETIME的参数说明。
