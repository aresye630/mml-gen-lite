# 增加过滤器组（ADD FILTERGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加过滤器组，添加过滤器到过滤器组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 单个FilterGroup可以配置5000个Filter。
- 最多支持100000条Filter和FilterGroup的绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                        |
|:--------------|:-------|:--------------------------------------------------------------------------------------------|
| FILTERGRPNAME | 过滤器组名称 | 可选必选说明：必选参数 参数含义：该参数用于设置过滤器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| FILTERNAME    | 过滤器名称  | 可选必选说明：可选参数 参数含义：该参数用于设置过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无  |

#### 使用实例

- 如果要添加一个名称为group1的过滤器组，执行如下命令：

  ```
  ADD FILTERGROUP: FILTERGRPNAME="group1";
  ```
- 如果要添加名称为filter1的过滤器，到过滤器组group1中，执行如下命令：

  ```
  ADD FILTERGROUP: FILTERGRPNAME="group1", FILTERNAME="filter1";
  ```
