# 增加本地用户组（ADD LOCALUSERPROF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加本地用户模板。该命令全局生效，通过绑定到已有的USERPROFILE，对所有用户进行对应的规则控制。

#### 注意事项

- 该命令执行后60s生效。
- 该命令最大记录数为1。
- 该命令需绑定到已有USERPROFILE上。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户组名称  | 可选必选说明：必选参数 参数含义：该参数用于指定用户组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及“,”、“;”、“"”等特殊字符，不区分大小写。 默认值：无 配置原则：该USERPROFILENAME与ADD USERPROFILE命令的“USERPROFILENAME”必须配置为相同值。即将已有User Profile指定为全局User Profile，实现所有用户全局匹配对应的业务规则。 |

#### 使用实例

假如运营商需要增加本地用户模板，本地用户模板名称为“testuserprofilename”：

```
ADD LOCALUSERPROF: USERPROFILENAME="testuserprofilename";
```
