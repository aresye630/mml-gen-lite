# 添加DNS规则（ADD DNSRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

当系统为处于边缘节点的应用提供DNSLite业务时，该命令用于新增一条DNS规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。
- APPLICATIONID与DNSRULENAME唯一标识一条记录。
- 当SET DNSLITEPARA中DNSLPOLICYSW使能后该规则才生效。
- 每个APPLICATIONID和DOMAIN下配置的IPADDRESS不可以重复。
- 每个APPLICATIONID下的DOMAIN配置的IPV4ADDRESS最大不超过16个。
- 每个APPLICATIONID下的DOMAIN配置的IPV6ADDRESS最大不超过16个。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                    |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------|
| APPLICATIONID | 应用标识    | 可选必选说明：必选参数 参数含义：该参数用于配置DNS列表所属的应用标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无                             |
| DNSRULENAME   | DNS规则名称 | 可选必选说明：必选参数 参数含义：该参数用于配置DNS规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无                                  |
| DOMAIN        | 域名      | 可选必选说明：必选参数 参数含义：该参数用于设置DNS规则的服务器域名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无                              |
| IPVERSION     | IP地址类型  | 可选必选说明：必选参数 参数含义：该参数用于指定DNS域名的IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：该DOMAIN对应的地址类型。      |
| IPV4ADDRESS   | IPv4地址  | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定域名对应的IPv4类型的服务器地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| IPV6ADDRESS   | IPv6地址  | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定域名对应的IPv6类型的服务器地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| DNSTTL        | DNS TTL | 可选必选说明：可选参数 参数含义：该参数用于设置域名解析信息在DNS中的存在时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：86400 配置原则：无                       |

#### 使用实例

在需要配置轻量DNS规则时，执行该命令设置新增规则：

```
ADD DNSRULE: APPLICATIONID="app1", DNSRULENAME="rule1", DOMAIN="www.huawei1.com", IPVERSION=IPV4, IPV4ADDRESS="10.0.0.1", DNSTTL=1;
```
