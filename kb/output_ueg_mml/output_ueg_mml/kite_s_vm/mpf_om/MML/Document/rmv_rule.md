# 删除规则（RMV RULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，会删除规则下所有绑定关系，并且会导致正在使用此规则的用户出现规则匹配错误、计费错误等现象。

该命令用于删除规则。如果不输入RULENAME，表示删除系统中所有的规则，如果不输入POLICYTYPE，表示删除该RULENAME对应的所有策略类型的规则。

#### 注意事项

- 该命令执行后立即生效。
- 如果Rule被用户模板（UserProfile）绑定，删除Rule会自动解除与用户模板的绑定关系。
- 如果Rule正在被业务使用，则不允许删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME   | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：设置该参数时表示删除指定名称的规则，未设置该参数时表示删除系统中所有的规则。                                                                                                                      |
| POLICYTYPE | 策略类型   | 可选必选说明：可选参数 参数含义：该参数用于设置策略类型。 数据来源：本端规划 取值范围：枚举类型。 MTP：Mec流策略控制，代表该规则可以配置MTP策略，用于实现Mec业务流控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。 默认值：无 配置原则：根据部署的业务策略选择相应的策略类型。 |

#### 使用实例

- 删除名称为testrule的所有规则：

  ```
  RMV RULE: RULENAME="testrule";
  ```
- 删除类型为MTP，名称为testrule的规则：

  ```
  RMV RULE: RULENAME="testrule", POLICYTYPE=MTP;
  ```
