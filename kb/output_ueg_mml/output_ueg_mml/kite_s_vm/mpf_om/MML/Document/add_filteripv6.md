# 增加IPv6过滤器（ADD FILTERIPV6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加过滤器，其中包含三、四层的协议、源端口号、目的端口号、源IPv6地址和目的IPv6地址等。数据报文通过时，系统会根据过滤器选择到对应的规则，然后执行选中规则对应的动作策略。

#### 注意事项

- 该命令执行后需要等待执行SET REFRESHSRV命令（REFRESHTYPE参数设置为USERPROFILE或ALL）刷新后生效。
- Filter和FilterIPv6的总记录数最大为50000。
- 当过滤器指定了HOSTNAME配置时，需要另外使用ADD HOST命令配置针对DNS协议的七层解析规则，通过解析DNS响应报文，得到Host名称和服务器IP地址的对应关系。
- 当过滤器指定了手机IP列表名称配置时，系统会自动生成多个过滤器，生成的过滤器会占用系统的过滤器总规格。生成过滤器数目的计算公式为：生成过滤器数目 = 手机IP列表名称的IP数目 \* 服务器IP列表名称的IP数目。
- 配置的过滤器用于上行方向报文的规则匹配时，其中的MSIP、MSIPV6MASK、MSSTARTPORT、MSENDPORT、SRVIPV6、SRVIPV6MASK、SRVSTARTPORT、SRVENDPORT分别对应待匹配报文的源地址、源地址掩码、源端口号范围、目的地址、目的地址掩码、目的端口号范围。
- 配置的过滤器用于下行方向报文的规则匹配时，其中的MSIP、MSIPV6MASK、MSSTARTPORT、MSENDPORT、SRVIPV6、SRVIPV6MASK、SRVSTARTPORT、SRVENDPORT分别对应待匹配报文的目的地址、目的地址掩码、目的端口号范围和源地址、源地址掩码、源端口号范围。
- 当L34PROTOCOL选择为ICMP或GRE时，不允许配置端口。
- 服务类型仅适用于防火墙的相关功能，不适用于动作策略的相关功能。
- 该命令设定后的数据，需要通过LST FILTER命令进行查看。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

运营商需要增加一个过滤器，要求过滤三四层协议输入类型为字符串类型，三四层协议类型为ANY，手机IP为“2001:db8::1428:0”的报文：

```
ADD FILTERIPV6:FILTERNAME="filter1",L34PROTTYPEV6=STRING,L34PROTOCOL=ANY,MSIPMODE=IP,MSIPV6="2001:db8::1428:0",MSIPV6MASKTYPE=LENGTHTYPE,MSIPV6MASKLEN=128;
```
