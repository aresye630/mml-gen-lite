# 查询MTP策略组（LST MTPPOLICYGRP）

#### 命令功能

**适用NF：MPF**

此命令用于查询MTP策略组。

支持批量查询，不输入查询条件，表示查询已经配置的所有MTP策略组。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                     |
|:---------------|:---------|:-----------------------------------------------------------------------------------------|
| MTPPOLICYGRPNM | MTP策略组名称 | 可选必选说明：可选参数 参数含义：设置MTP策略组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 查询名称为test\_mtpgrp\_1的MTP策略组：

  ```
  LST MTPPOLICYGRP: MTPPOLICYGRPNM="test_mtpgrp_1";
  ```

  ```
  RETCODE = 0  操作成功。

  MTP策略组信息
  -------------
         MTP策略组名称  =  test_mtpgrp_1
       MTP动作属性名称  =  NULL
  (结果个数 = 1)
  ---    END
  ```
- 查询所有的MTP策略组：

  ```
  LST MTPPOLICYGRP:;
  ```

  ```
  RETCODE = 0  操作成功。

  MTP策略组信息
  -------------
  MTP策略组名称    MTP动作属性名称

  test_mtpgrp_1    NULL           
  test_mtpgrp_2    NULL            
  (结果个数 = 2)
  ---    END
  ```
