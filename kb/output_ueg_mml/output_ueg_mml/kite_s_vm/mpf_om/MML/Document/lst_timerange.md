# 查询时间段（LST TIMERANGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示配置的时间段信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                              |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------|
| TIMERANGENAME | 时间段名称  | 可选必选说明：可选参数 参数含义：该参数用于设置时间段的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写，以字母开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询一条时间段记录：

  ```
  LST TIMERANGE:TIMERANGENAME="t1";
  ```

  ```
  RETCODE = 0  操作成功。

  时间段信息
  ----------
  时间段名称  =  t1
    生效状态  =  不生效
  (结果个数 = 1)
  ---    END
  ```
- 查询所有时间段记录：

  ```
  LST TIMERANGE:;
  ```

  ```
  RETCODE = 0  操作成功。

  时间段信息
  ----------
  时间段名称 生效状态
  t1         不生效     
  t2         不生效
  t3         不生效
  (结果个数 = 3)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 生效状态    | 用于显示时间段的生效状态。 |

其余输出项请参见ADD TIMERANGE的参数说明。
