# 设置统一接入控制功能（SET UACFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置统一接入控制功能开关是否开启。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SINGLENETSW   |
|:-------|:--------------|
| 初始值    | DISABLE       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                           |
|:------------|:--------|:-----------------------------------------------------------------------------------------------|
| SINGLENETSW | 单网通功能开关 | 可选必选说明：必选参数 参数含义：该参数用于设置单网通功能开关。 数据来源：本端规划 取值范围： DISABLE：不使能单网通功能。ENABLE：使能单网通功能。 默认值：无 配置原则：无 |

#### 使用实例

开启统一接入控制功能开关：

```
SET UACFUNC: SINGLENETSW=ENABLE;
```
