# 修改逻辑接口（MOD LOGICINF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，此操作会更改逻辑接口，可能导致相关业务中断。

该命令用于修改指定的逻辑接口。逻辑接口是指能够实现数据交换功能但物理上不存在，需要通过配置建立的接口。

#### 注意事项

- 该命令执行后立即生效。
- 修改逻辑接口前，需要确保被修改的逻辑接口已经被创建。如果需要输入该命令的可选参数VPN实例名称（即逻辑接口与VPN绑定），则需要提前配置ADD VPNINST命令。
- 如果MOD命令中输入了VPNINSTANCE这个参数，则该逻辑口下的所有IP地址都会被删除掉，需要再下发一遍MOD命令来重新配置逻辑接口IP地址，且再下发MOD命令时不需要带VPNINSTANCE这个参数。
- 如果修改前后VPN不变，则MOD命令不要输入VPN参数，否则记录不会被修改。
- 若逻辑接口被IPFarm等对象绑定时，不允许修改逻辑口的配置信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                  |
|:---------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME           | 逻辑接口名称          | 可选必选说明：必选参数 参数含义：该参数用于配置逻辑接口名称，确保逻辑接口的唯一性。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 逻辑接口名称格式固定为：逻辑接口类型（如nxuaif）ISU组号/实例类型/逻辑接口号，如nxuaif1/1/0；第二个数字为实例类型；第三个数字为逻辑接口号，各逻辑接口类型有各自的配置范围。逻辑接口类型：phif，nxcaif，nxuaif。（其中nxcaif为预置接口，配置后只允许执行ping操作。）。ISU组号：1。ISU实例类型：0或1。0表示组级类型，1表示Instance级类型。逻辑接口号：phif：0~1599，nxcaif：0，nxuaif：0~31。 |
| IPVERSION      | 逻辑接口的IP版本       | 可选必选说明：可选参数 参数含义：该参数用于用户指定IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：添加逻辑接口IP的版本为IPv4。IPV6：添加逻辑接口IP的版本为IPv6。IPVER_ALL：添加逻辑接口IP的版本为IPv4和IPv6。 默认值：无 配置原则：无                                                                                                                                                                                        |
| IPV4ADDRESS1   | 逻辑接口的IPv4地址1    | 可选必选说明：可选参数 参数含义：该参数用于指示逻辑接口配置主IP。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：根据环境的网络规划进行配置，点分十进制格式。除A、B、C类地址合法外，其余都为非法地址。                                                                                                                                                                                                |
| IPV4MASK1      | 逻辑接口的IPv4掩码1    | 可选必选说明：可选参数 参数含义：该参数用于指示逻辑接口配置主IP掩码。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：逻辑口IP地址的掩码为32位。                                                                                                                                                                                                                           |
| IPV4MTU        | IPv4逻辑接口MTU（字节） | 可选必选说明：可选参数 参数含义：该参数用于指定逻辑接口IPv4报文的最大传输单元。 数据来源：全网规划 取值范围：整数类型，取值范围为328～9600。 默认值：无 配置原则：根据数据包大小进行配置。                                                                                                                                                                                                                                 |
| IPV6ADDRESS1   | 逻辑接口的IPv6地址1    | 可选必选说明：可选参数 参数含义：该参数用于指示逻辑接口配置主IPV6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：根据环境的网络规划进行配置，冒号分十六进制格式。除单播、任播、组播地址合法外，其余都为非法地址。                                                                                                                                                                                |
| IPV6MTU        | IPv6逻辑接口MTU（字节） | 可选必选说明：可选参数 参数含义：该参数用于指定逻辑接口IPv6报文的最大传输单元。 数据来源：全网规划 取值范围：整数类型，取值范围为1280～9600。 默认值：无 配置原则：根据数据包大小进行配置。                                                                                                                                                                                                                                |
| VPNINSTANCE    | VPN实例名称         | 可选必选说明：可选参数 参数含义：该参数用于将逻辑接口与VPN绑定。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。绑定VPN时需要确保该VPN已经配置（ADD VPNINST）。                                                                                                                                                                                        |
| IPV6PREFIXLEN1 | IPv6前缀长度1       | 可选必选说明：可选参数 参数含义：该参数用于指示逻辑接口配置的主IPv6前缀长度。 数据来源：全网规划 取值范围：整数类型，取值范围为1～128。 默认值：无 配置原则：逻辑口IPv6前缀长度为128。                                                                                                                                                                                                                                 |

#### 使用实例

修改逻辑接口，逻辑接口名称为nxuaif1/1/0，逻辑接口的IPv4地址1为192.168.100.1，逻辑接口的IPv4掩码1为255.255.255.255，IPv4逻辑接口MTU为900：

```
MOD LOGICINF: NAME="nxuaif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="192.168.100.1", IPV4MASK1="255.255.255.255", IPV4MTU=900;
```
