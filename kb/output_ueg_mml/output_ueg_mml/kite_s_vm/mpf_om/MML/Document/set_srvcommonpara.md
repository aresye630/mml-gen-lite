# 设置业务公共参数（SET SRVCOMMONPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，可能会影响业务。

该命令用来配置业务相关控制参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   FDMAXNUM |   DOMAINIPAGETIME | USERFLOWADJSW   | DNSOLENDOMAIN   | IPV4EMBV6SW   |   IPV4EMBV6PFX |
|:-------|-----------:|------------------:|:----------------|:----------------|:--------------|---------------:|
| 初始值    |        600 |                 0 | ENABLE          | PREFIX_DOMAIN   | DISABLE       |            nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称                              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------------|:----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FDMAXNUM        | 用户session的五元组节点最大数量               | 可选必选说明：可选参数 参数含义：该参数用于指定用户session的五元组节点最大数量。 数据来源：本端规划 取值范围：整数类型，取值范围为1～2550。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                 |
| DOMAINIPAGETIME | DNS的serverip和domain对应关系老化时间配置（小时） | 可选必选说明：可选参数 参数含义：该参数用于指定DNS的serverip和domain对应关系老化时间配置。 数据来源：本端规划 取值范围：整数类型，取值范围为0～24，单位是小时。 默认值：无 配置原则：当该参数为0时，表示每天4点老化，老化阈值为24小时；当该参数为非0整数时，表示每20分钟老化，老化阈值为该参数。                                                                                                                                                                                                                                                                           |
| USERFLOWADJSW   | 单用户最大流表数动态调整开关                    | 可选必选说明：可选参数 参数含义：该参数用于指定单用户最大流表数动态调整开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                   |
| DNSOLENDOMAIN   | DNS超长域名                           | 可选必选说明：可选参数 参数含义：DNS报文进行SA处理时，如果报文中的域名长度超过了127字节，该如何做截断处理。 数据来源：本端规划 取值范围：枚举类型。 PREFIX_DOMAIN：保留超长域名的前段内容。POSTFIX_DOMAIN：保留超长域名的后段内容。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                         |
| IPV4EMBV6SW     | 内嵌IPv4的IPv6前缀功能开关                 | 可选必选说明：可选参数 参数含义：该参数用于设置系统是否支持内嵌IPv4的IPv6前缀的开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：关闭IPv4内嵌IPv6前缀功能。ENABLE：开启IPv4内嵌IPv6前缀功能。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                        |
| IPV4EMBV6PFX    | 内嵌IPv4的IPv6前缀                     | 可选必选说明：条件必选参数 前提条件：该参数在“IPV4EMBV6SW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定内嵌IPv4的IPv6业务的前缀。 数据来源：全网规划 取值范围：枚举类型。 Prefix1：指定IPv4内嵌Ipv6的前缀为2001:db8::/32。Prefix2：指定IPv4内嵌Ipv6的前缀为2001:db8:100::/40。Prefix3：指定IPv4内嵌Ipv6的前缀为2001:db8:122::/48。Prefix4：指定IPv4内嵌Ipv6的前缀为2001:db8:122:300::/56。Prefix5：指定IPv4内嵌Ipv6的前缀为2001:db8:122:344::/64。Prefix6：指定IPv4内嵌Ipv6的前缀为2001:db8:122:344::/96。Prefix7：指定IPv4内嵌Ipv6的前缀为64:ff9b::/96。NULL：NULL。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要更改业务公共参数，单用户最大流表数动态调整开关为ENABLE：

```
SET SRVCOMMONPARA:USERFLOWADJSW=ENABLE;
```
