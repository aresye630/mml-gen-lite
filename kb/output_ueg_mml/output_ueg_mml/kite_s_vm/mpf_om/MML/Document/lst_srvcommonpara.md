# 查询业务公共参数（LST SRVCOMMONPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用来显示业务相关控制参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示业务公共参数：

```
LST SRVCOMMONPARA:;
```

```
RETCODE = 0  操作成功。

业务公共参数信息
----------------
                  用户session的五元组节点最大数量  =  600
DNS的serverip和domain对应关系老化时间配置（小时）  =  0
                     单用户最大流表数动态调整开关  =  使能
                                      DNS超长域名  =  前缀域名
                       内嵌IPv4的IPv6前缀功能开关  =  不使能
                               内嵌IPv4的IPv6前缀  =  NULL

(结果个数 = 1)
---    END
```
