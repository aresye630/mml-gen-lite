# 增加MPF路由（ADD MPFROUTE）

- 操作用户权限

#### 命令功能

**适用NF：MPF**

该命令用于发布用户路由。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。
- 每个IPv4地址段最多配置1048576个地址，每个IPv6地址段可以配置1048576个地址。
- 同一个VPN下，各个地址段里的地址不能相互重叠。注意，当两个地址段均未配置VPN，代表其VPN相同。
- IPv6前缀长度固定为64。
- 路由配置中的IPv6地址只支持冒分十六进制表示法，不支持0位压缩表示法和内嵌IPv4地址表示法。组播地址、链路本地地址、环回地址或未指定的地址为非法地址。
- MPF的地址段必须包含所有通过MPF访问APP服务器的UE地址，否则用户下行数据包无法正确发送到MPF。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

- 假设运营商配置一个路由标识为“1”、IPv4类型的地址段：

  ```
  ADD MPFROUTE: MPFROUTEID="1", IPVERSION=IPV4, V4STARTIP="10.10.10.0", V4ENDIP="10.11.11.1";
  ```
- 假设运营商配置一个路由标识为“2”、IPv6类型的地址段：

  ```
  ADD MPFROUTE: MPFROUTEID="2", IPVERSION=IPV6, V6PREFIXSTART="2001:0db8:86a3:08d2:0:0:0:0", V6PREFIXEND="2001:0db8:86a3:08f2:0:0:0:0";
  ```
