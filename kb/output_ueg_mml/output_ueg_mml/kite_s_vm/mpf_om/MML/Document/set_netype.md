# 设置 ne 类型（SET NETYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

本命令用于改变网元形态。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 网元形态初始值由系统生成,该命令参数初始值为NULL。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   NETYPEENUM |
|:-------|-------------:|
| 初始值    |          nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                    |
|:-----------|:-------|:----------------------------------------------------------------------------------------|
| NETYPEENUM | 网元形态   | 可选必选说明：可选参数 参数含义：网元形态枚举。 数据来源：本端规划 取值范围：位域类型。 SGWUPGWUUPFGGSNUProxySGWUMEP 默认值：无 配置原则：无 |

#### 使用实例

将网元形态设置为upf：

```
SET NETYPE:NETYPEENUM=GGSNU-0&PGWU-0&ProxySGWU-0&SGWU-0&UPF-1;
```
