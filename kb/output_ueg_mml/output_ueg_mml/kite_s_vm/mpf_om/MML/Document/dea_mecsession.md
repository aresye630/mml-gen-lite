# 去活MEC会话（DEA MECSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于去激活用户，假设运营商需要去激活用户，可选择NF等方式去活用户。即当需要手动在系统上去激活用户时，使用该命令。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------|
| DEATYPE | 去活的方式  | 可选必选说明：必选参数 参数含义：该参数用于指定去活的方式。 数据来源：本端规划 取值范围： NF：去活所有用户。 默认值：无 配置原则：无 |

#### 使用实例

执行命令去活用户：

```
DEA MECSESSION: DEATYPE=NF;
```
