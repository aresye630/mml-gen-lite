# 查询MPF的锁定信息（LST MDP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询MPF的锁定状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MPF的锁定状态：

```
LST MDP:;
```

```
RETCODE = 0 操作成功

MPF锁定信息
--------------
MPF锁定开关 = 不使能
(结果个数 = 1)

--- 结束
```

#### 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| MPF锁定开关 | 用于配置是否开启MPF锁定开关。 |
