# 查询业务匹配统计结果（DSP SRVMATCHSQRY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询匹配到对应业务的计数。

#### 注意事项

使用该命令可以监控规则的业务匹配次数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                         |
|:-------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVMATCHQRYT | 业务匹配统计查询类型 | 可选必选说明：必选参数 参数含义：该参数用于设置业务匹配统计查询类型。 数据来源：本端规划 取值范围：枚举类型。 RULE：监控规则匹配。 默认值：无 配置原则：RULE：需要监控规则匹配次数时，配置该参数。                                                                     |
| RULENAME     | 规则名称       | 可选必选说明：条件可选参数 前提条件：该参数在“SRVMATCHQRYT”配置为“RULE”时为可选参数。 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD RULE 或 ADD BLACKLISTRULE 命令配置生成。 |

#### 使用实例

查询Rule的匹配次数：

```
DSP SRVMATCHSQRY:SRVMATCHQRYT=RULE;
```
