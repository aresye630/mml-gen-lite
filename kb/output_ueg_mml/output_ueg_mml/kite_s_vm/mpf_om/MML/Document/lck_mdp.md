# 设置MPF锁定开关（LCK MDP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，MPF锁定后会导致UPF与MPF之间的通信链路断开，请及时解锁。

该命令用于锁定MPF，锁定后UPF和MPF之间链路会断开。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                          |
|:-----------|:--------|:----------------------------------------------------------------------------------------------|
| LOCKSWITCH | MPF锁定开关 | 可选必选说明：必选参数 参数含义：该参数用于配置是否开启MPF锁定开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

配置MPF为锁定状态：

```
LCK MDP: LOCKSWITCH=ENABLE;
```
