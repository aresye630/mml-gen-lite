#### 命令功能

**适用NF：MPF**

该命令用于显示对应IP farm的信息，包括IP farm的名称，Virtual IP，VPN属性和绑定的心跳检测接口名称，server类型。如果参数为空，则显示所有IP farm的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                           |
|:-----------|:----------|:-----------------------------------------------------------------------------------------------|
| IPFARMNAME | IP-Farm名称 | 可选必选说明：可选参数 参数含义：该参数用于设置IP farm名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 查询一条IP farm记录：

  ```
  LST IPFARM:;
  ```

  ```
  RETCODE = 0  操作成功。

  IPFarm信息
  ----------
            IP-Farm名称  =  test
             服务器类型  =  重定向
                VPN实例  =  NULL
           健康检查标记  =  使能
             IP协议版本  =  IPV4
             虚拟IP地址  =  10.0.0.0
           虚拟IPv6地址  =  ::
       心跳检测接口名称  =  NULL
  (结果个数 = 1)
  ---    END
  ```
- 查询所有IP farm记录：

  ```
  LST IPFARM:;
  ```

  ```
  RETCODE = 0  操作成功。

  IPFarm信息
  ----------
  IP-Farm名称    服务器类型    VPN实例    健康检查标记    IP协议版本    虚拟IP地址    虚拟IPv6地址    心跳检测接口名称
  f1              重定向        NULL       使能            IPV4          10.0.0.0       ::              NULL           
  f2              重定向        NULL       使能            IPV4          10.0.0.1       ::              NULL                    
  (结果个数 = 2)
  ---    END
  ```
