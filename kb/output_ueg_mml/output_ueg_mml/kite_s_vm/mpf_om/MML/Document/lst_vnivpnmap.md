# 显示VNI到VPN的映射（LST VNIVPNMAP）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询VNI与VPN的映射关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商想要查询所有绑定关系：

```
LST VNIVPNMAP:;
```

```
RETCODE = 0 操作成功

MPF VNI映射
-----------
VNI VPN实例名 VPN用途

1 vpn_2 通用业务
2 vpn_2 通用业务
3 vpn_3 UAC业务
(结果个数 = 3)

--- END
```
