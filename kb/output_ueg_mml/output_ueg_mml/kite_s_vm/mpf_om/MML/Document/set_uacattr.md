# 设置UAC属性（SET UACATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置UAC属性。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   SNMSGTIMER |   SNRATELIMIT |
|:-------|-------------:|--------------:|
| 初始值    |            5 |            10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                           |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------|
| SNMSGTIMER  | 单网通消息定时器时长 | 可选必选说明：可选参数 参数含义：该参数用于配置单网通消息定时器的超时时长。 数据来源：本端规划 取值范围：整型数字类型，取值范围为3~7。 默认值：无 配置原则：无            |
| SNRATELIMIT | 单网通速率控制    | 可选必选说明：可选参数 参数含义：该参数用于设置单个用户IP的单网通消息最大速率。 数据来源：本端规划 取值范围：整型数字类型，取值范围为0~100，0为不限速。 默认值：无 配置原则：无 |

#### 使用实例

设置UAC属性：

```
SET UACATTR: SNMSGTIMER=5, SNRATELIMIT=5;
```
