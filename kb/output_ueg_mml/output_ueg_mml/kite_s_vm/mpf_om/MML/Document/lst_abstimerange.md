# 查询绝对时间段（LST ABSTIMERANGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示配置的绝对时间段信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                              |
|:----------------|:--------|:------------------------------------------------------------------------------------------------------------------|
| TIMERANGENAME   | 时间段名称   | 可选必选说明：可选参数 参数含义：该参数用于设置时间段的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写，以字母开头。 默认值：无 配置原则：无                 |
| ABSTIMERANGESEQ | 绝对时间段序号 | 可选必选说明：可选参数 参数含义：该参数用于设置绝对时间段的序号值。在一个时间段内，绝对时间段序号不能重复，每一个序号代表一个绝对时间段。 数据来源：本端规划 取值范围：整数类型，取值范围为1～12。 默认值：无 配置原则：无 |

#### 使用实例

- 查询一条绝对时间段记录：

  ```
  LST ABSTIMERANGE:TIMERANGENAME="t1",ABSTIMERANGESEQ=1;
  ```

  ```
  RETCODE = 0  操作成功。

  绝对时间段信息
  --------------
                时间段名称  =  t1
            绝对时间段序号  =  1
       起始时间，格式HH:MM  =  21:33
  起始日期，格式MM/DD/YYYY  =  2017-02-28
       结束时间，格式HH:MM  =  21:30
  结束日期，格式MM/DD/YYYY  =  2017-03-03
  (结果个数 = 1)
  ---    END
  ```
- 查询所有绝对时间段记录：

  ```
  LST ABSTIMERANGE:;
  ```

  ```
  RETCODE = 0  操作成功。

  绝对时间段信息
  --------------
  时间段名称    绝对时间段序号    起始时间，格式HH:MM    起始日期，格式MM/DD/YYYY    结束时间，格式HH:MM    结束日期，格式MM/DD/YYYY

  t1            1                 21:33                  2017-02-28                  21:30                  2017-03-03              
  t2            1                 06:54                  2017-03-05                  10:55                  2017-03-08              
  (结果个数 = 2)
  ---    END
  ```
- 查询一个时间段下的所有绝对时间段记录：

  ```
  LST ABSTIMERANGE: TIMERANGENAME="t1";
  ```

  ```
  RETCODE = 0  操作成功。

  绝对时间段信息
  --------------
                时间段名称  =  t1
            绝对时间段序号  =  1
       起始时间，格式HH:MM  =  21:33
  起始日期，格式MM/DD/YYYY  =  2017-02-28
       结束时间，格式HH:MM  =  21:30
  结束日期，格式MM/DD/YYYY  =  2017-03-03
  (结果个数 = 1)
  ---    END
  ```
