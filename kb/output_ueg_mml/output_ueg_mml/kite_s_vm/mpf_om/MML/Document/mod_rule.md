# 修改规则（MOD RULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于修改规则，其中包含策略类型、流过滤器、流过滤器组、策略信息、生效时间段以及优先级等。只有已经添加成功的规则才能够修改。

#### 注意事项

- 该命令执行后立即生效。
- 修改Rule时，如果有业务正在使用该Rule，则可能会导致业务中断，或业务处理是非预期的。
- 软参Bit596为0时，如果通过MOD RULE修改webproxy的IPFARM，已匹配过此规则的在线用户无法切换IPFARM，除非用户正在使用的server状态异常，才会切换到修改后的IPFARM。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME       | 规则名称         | 可选必选说明：必选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                 |
| POLICYTYPE     | 策略类型         | 可选必选说明：必选参数 参数含义：该参数用于设置策略类型。 数据来源：本端规划 取值范围：枚举类型。 MTP：Mec流策略控制，代表该规则可以配置MTP策略，用于实现Mec业务流控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。 默认值：无 配置原则： 根据部署的业务策略选择相应的策略类型。当PolicyType为WEBPROXY时，不允许配置绑定了七层协议和协议组的FlowFilter。                                    |
| FILTERINGMODE  | 流过滤器或流过滤器组选择 | 可选必选说明：可选参数 参数含义：该参数用于设置流过滤器或流过滤器组选择。 数据来源：本端规划 取值范围：枚举类型。 FLOWFILTER：指定流过滤器作为过滤条件。FLOWFILTERGRP：指定流过滤器组作为过滤条件。 默认值：无 配置原则： 如果运营商希望基于流过滤器设置过滤条件，修改该参数为FLOWFILTER。如果运营商希望基于流过滤器组设置过滤条件，修改该参数为FLWFLTRGRPNAME。                                                                                                                               |
| FLOWFILTERNAME | 流过滤器名称       | 可选必选说明：条件必选参数 前提条件：该参数在“FILTERINGMODE”配置为“FLOWFILTER”时为必选参数。 参数含义：该参数用于设置流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD FLOWFILTER命令配置生成。设置的FLOWFILTERNAME必须是系统已经存在的流过滤器名称。                                                                                                                                  |
| FLWFLTRGRPNAME | 流过滤器组名称      | 可选必选说明：条件必选参数 前提条件：该参数在“FILTERINGMODE”配置为“FLOWFILTERGRP”时为必选参数。 参数含义：该参数用于设置流过滤器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：该参数使用ADD FLOWFILTERGRP命令配置生成。                                                                                                                                                                    |
| TIMERANGENAME  | 时间段名称        | 可选必选说明：可选参数 参数含义：该参数用于设置TimeRange名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD TIMERANGE命令配置生成。如果运营商希望控制Rule生效的时间段信息，则可以配置TimeRange对象名称，只有TimeRange定义的时间段内，Rule才可以生效并参与匹配和策略处理。设置的TIMERANGENAME必须是系统已经存在的时间段名称。                                                                                                 |
| PRIORITY       | 全局优先级        | 可选必选说明：可选参数 参数含义：该参数用于设置全局优先级，仅对PCC用户生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。值越小优先级越高。 默认值：无 配置原则：设置的PRIORITY仅对PCC用户生效。为了避免后续规划的规则与已配置规则的优先级冲突，建议规划优先级时按照10的倍数来定义，以便于后续插入任意优先级的新规则。                                                                                                                                                          |
| POLICYNAME     | 策略名称         | 可选必选说明：条件可选参数 前提条件：该参数在“POLICYTYPE”配置为“MTP”、“BWM” 或 “WEBPROXY”时为可选参数。 参数含义：该参数用于设置策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 设置的POLICYNAME必须是本策略类型所属的系统已经存在的策略名称。根据策略类型的取值不同，所对应的策略定义对象不同，其代表的对象名也做相应的调整。 MTP：策略控制，代表该策略名称为MTP策略组的名称。BWM：带宽管理，代表该策略名称为BWM分类属性的名称。WEBPROXY：Web Proxy，代表该策略名称为WebProxy业务对应的IPFarm的名称。 |

#### 使用实例

修改一条名为TESTRULE的规则，绑定一条名为TESTFLOWFILTER的流过滤器，策略类型是MTP，对应策略组名称为TESTMTPPOLICYGRPNM，该规则的优先级设置为50：

```
MOD RULE:RULENAME="TESTRULE",POLICYTYPE=MTP,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="TESTFLOWFILTER",PRIORITY=50,POLICYNAME="TESTMTPPOLICYGRPNM";
```
