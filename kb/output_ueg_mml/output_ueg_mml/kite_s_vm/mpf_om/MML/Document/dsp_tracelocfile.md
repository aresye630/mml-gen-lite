# 查询用户跟踪本地文件（DSP TRACELOCFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询指定pod下用户跟踪本地存盘文件。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                               |
|:-----------|:-------|:-----------------------------------------------------------------------------------|
| PODNAMEQRY | POD名称  | 可选必选说明：必选参数 参数含义：POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询mpfisu-pod-0下的用户跟踪本地存盘文件：

```
DSP TRACELOCFILE: PODNAMEQRY="mpfisu-pod-0";
```
