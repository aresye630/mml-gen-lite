# 删除带宽管理用户组（RMV BWMUSERGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，会删除带宽管理用户组下所有绑定关系。

该命令用于删除带宽管理用户组。当运营商希望删除已配置的默认用户组或具体用户组时，则执行该命令。

#### 注意事项

- 删除一个带宽管理用户组，对已在线用户的用户级TOS业务生效，其他业务不生效。
- 删除一个带宽管理用户组会同时删除该用户组下所有的带宽管理规则和与APN、UserProfile的绑定关系。
- 全局用户组为系统默认配置，不能删除。
- 如果不指定用户组名称，则删除所有用户组（全局用户组除外）。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| USERGROUPTYPE | 用户组类型  | 可选必选说明：可选参数 参数含义：该参数用于配置带宽管理用户组的类型。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT_GROUP：默认用户组。SPECIFIC_GROUP：特定用户组。 默认值：无 配置原则：无                                     |
| USERGROUPNAME | 用户组名称  | 可选必选说明：条件必选参数 前提条件：该参数在“USERGROUPTYPE”配置为“SPECIFIC_GROUP”时为必选参数。 参数含义：该参数用于配置带宽管理用户组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要删除名为“testbwmusergroup”的具体带宽管理业务：

```
RMV BWMUSERGROUP: USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="testbwmusergroup";
```
