# 增加用户模板和规则的绑定关系（ADD RULEBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加用户模板与规则绑定关系，当用户数据报文可以匹配到多个规则时，需要将多个规则绑定到用户模板下。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为100000。
- 单个用户模板最多可以绑定8000个规则。
- 对已经在线的用户，依次扫描生效，生效时间最长为1小时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                   |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称 | 可选必选说明：必选参数 参数含义：该参数用于设置用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD USERPROFILE命令配置生成。                                                                                                                                                                                                                                  |
| RULENAME        | 规则名称   | 可选必选说明：必选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD RULE 或 ADD BLACKLISTRULE 命令配置生成。                                                                                                                                                                                                                     |
| POLICYTYPE      | 策略类型   | 可选必选说明：可选参数 参数含义：该参数用于显示策略类型。 数据来源：本端规划 取值范围：枚举类型。 MTP：Mec流策略控制，代表该规则可以配置MTP策略，用于实现Mec业务流控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。 默认值：无 配置原则： 如果本处不指定策略类型，则将相同规则名称、不同策略类型的规则都绑定到用户模板下。可以通过指定策略类型来区分相同规则名称的不同规则。如果指定策略类型，则该策略类型需要与ADD RULE命令配置生成的相同规则名称的规则对应的策略类型一致。 |

#### 使用实例

如果使用全局用户模板，则在系统上需要将配置的规则绑定到对应的用户模板上：

```
ADD RULEBINDING: USERPROFILENAME="userprofile",RULENAME="rule";
```
