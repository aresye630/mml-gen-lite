# 删除流过滤器协议绑定关系（RMV PROTBINDFLOWF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，可能会影响业务。

该命令用于删除协议与流过滤器绑定关系。

#### 注意事项

- 该命令执行后60s生效。
- 如果不输入ProtocolName，则代表删除该FlowFilterName对应的流过滤器下所有的协议与流过滤器绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                        |
|:---------------|:-------|:--------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：必选参数 参数含义：该参数用于指定流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| PROTOCOLNAME   | 协议名称   | 可选必选说明：可选参数 参数含义：该参数用于设置协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无   |

#### 使用实例

删除协议与流过滤器绑定关系：“FLOWFILTERNAME”为“testflowfiltername”, “PROTOCOLNAME”为“http”：

```
RMV PROTBINDFLOWF:FLOWFILTERNAME="testflowfiltername",PROTOCOLNAME="http";
```
