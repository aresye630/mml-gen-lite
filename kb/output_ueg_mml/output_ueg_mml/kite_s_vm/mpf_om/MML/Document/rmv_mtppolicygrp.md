# 删除MTP策略组（RMV MTPPOLICYGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，会删除Mtp策略组下所有的业务属性绑定关系

此命令用于删除Mtp策略组。

支持批量删除：不输入条件，表示删除所有未被引用的Mtp策略组。

#### 注意事项

- 该命令执行后立即生效。
- 输入的MtpPolicyGrpNm通过LST RULE查询Rule记录，如果引用了该MtpPolicyGrp的Rule的记录存在，则不允许删除MtpPolicyGrp记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                     |
|:---------------|:---------|:-----------------------------------------------------------------------------------------|
| MTPPOLICYGRPNM | MTP策略组名称 | 可选必选说明：可选参数 参数含义：设置MTP策略组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为TestMtpPolicyGrpName的MTP策略组：

```
RMV MTPPOLICYGRP:MTPPOLICYGRPNM ="TestMtpPolicyGrpName";
```
