# 显示 NeInfo（DSP NEINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

显示网元形态列表以及NF列表。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

列出当前网元形态列表：

```
DSP NEINFO;
```

```
RETCODE = 0 操作成功。

结果如下
--------
网元基本信息 =
NE type list = MEP
NF list = FrameWork, MDP, MPF 
(Number of results = 1)

---    END
```
