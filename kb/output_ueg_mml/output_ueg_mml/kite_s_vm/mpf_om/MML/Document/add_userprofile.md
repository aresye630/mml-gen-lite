# 增加用户模板（ADD USERPROFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加用户模板。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5000。
- 单个用户模板可以配置绑定1个扩展属性名称。
- 当前版本不支持此命令的“实时位置上报开关”参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称 | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及“,”、“;”、“"”等特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要增加用户模板，用户模板名称为“testuserprofilename”：

```
ADD USERPROFILE:USERPROFILENAME="testuserprofilename";
```
