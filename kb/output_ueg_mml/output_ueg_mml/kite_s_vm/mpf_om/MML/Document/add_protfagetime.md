# 增加协议五元组老化时间（ADD PROTFAGETIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于配置不同的协议组、协议相关的五元组老化时间。目的是在不影响系统正常业务的前提下，充分利用系统的五元组资源。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 如果协议组、协议对应的五元组老化时间未配置，则继承FlowAgetime中配置的any协议五元组老化时间。
- 如果五元组老化时间配置过大，会造成整机五元组使用数量太多的情况。
- 协议组里any的五元组老化时间在FlowAgetime中配置，该命令不对any进行配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                    |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLLEVEL | 协议等级    | 可选必选说明：必选参数 参数含义：该参数用于显示配置的协议组、协议级别。 数据来源：本端规划 取值范围：枚举类型。 PROTOCOLGROUP：协议组级别。PROTOCOL：协议级别。 默认值：无 配置原则：无                                                                                                               |
| PROTGROUPNAME | 协议组名称   | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOLGROUP”时为必选参数。 参数含义：该参数用于设置协议组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的默认协议组，可以通过工程命令smctrldsp protocol-list查询。                        |
| PROTOCOLNAME  | 协议名称    | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOL”时为必选参数。 参数含义：该参数用于设置协议名称。数据源为系统支持识别的所有类型的协议、子协议。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的所有类型的协议、子协议，可以通过工程命令smctrldsp protocol-list查询。 |
| AGETIME       | 老化时间（秒） | 可选必选说明：必选参数 参数含义：该参数用于设置五元组节点的老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为20～7200，单位是秒。 默认值：无 配置原则：无                                                                                                                                 |

#### 使用实例

假如运营商需要设置p2p协议组的五元组老化时间为60秒，配置命令如下：

```
ADD PROTFAGETIME:PROTOCOLLEVEL=PROTOCOLGROUP,PROTGROUPNAME="p2p",AGETIME=60;
```
