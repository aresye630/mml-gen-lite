# 查询逻辑口报文统计信息（DSP INTERFACEPERF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用来查看接口当前运行状态和接口统计信息。在监控接口的状态或检查接口的故障原因时，可执行该命令获取接口的状态信息和统计信息。用户可以根据这些信息进行流量统计和接口的故障诊断等。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                              |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACENAME | 逻辑接口名称 | 可选必选说明：可选参数 参数含义：该参数用于指定要查询的逻辑接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由逻辑口类型和逻辑口编号组成，逻辑口类型和编号之间可以有空格也可以没有空格。支持的逻辑口类型为：nxua、phif。逻辑口编号形式为x/y/z，其中x为ISU组号（1），y为ISU实例ID（0~1），z为逻辑口的接口编号。 默认值：无 配置原则：无 |

#### 使用实例

以nxua接口为例，查看nxuaif1/1/0接口的状态信息和统计信息：

```
DSP INTERFACEPERF: INTERFACENAME="nxuaif1/1/0";
```
