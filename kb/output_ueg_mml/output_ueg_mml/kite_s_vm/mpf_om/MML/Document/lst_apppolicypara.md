# 显示应用策略参数（LST APPPOLICYPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示app策略参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询app策略参数：

```
LST APPPOLICYPARA:;
```

```
RETCODE = 0 操作成功。

应用策略开关
------------------------
黑白名单策略开关 = ENABLE
应用带宽策略开关 = ENABLE
   DNS重定向开关 = DISABLE
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET APPPOLICYPARA的参数说明。
