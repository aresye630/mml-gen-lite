# 设置主机域参数（SET HOSTDOMAINPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置主机域相关参数，通过该命令可以控制host是否全量学习。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | MULTIHOSTSTUDY   |
|:-------|:-----------------|
| 初始值    | DISABLE          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                        |
|:---------------|:----------|:------------------------------------------------------------------------------------------------------------|
| MULTIHOSTSTUDY | 多Host学习开关 | 可选必选说明：必选参数 参数含义：该参数用于设置是否支持一个报文学习到多个Host。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无 |

#### 使用实例

打开host全量学习开关：

```
%%SET HOSTDOMAINPARA: MULTIHOSTSTUDY=ENABLE;%%
RETCODE = 0  操作成功

---    END
```
