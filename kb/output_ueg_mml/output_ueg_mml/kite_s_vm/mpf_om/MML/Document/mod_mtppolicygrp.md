# 修改MTP策略组（MOD MTPPOLICYGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

此命令用于修改MtpPolicyGrp配置，只有已经添加成功的MtpPolicyGrp才能够修改。可以通过命令，修改MTP策略组，包括MTP动作属性。

#### 注意事项

- 该命令执行后立即生效。
- 被绑定的MtpPolicyGrp不允许删除，必须先解除绑定关系。但是可以动态添加、修改、删除组合。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                    |
|:---------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MTPPOLICYGRPNM | MTP策略组名称  | 可选必选说明：必选参数 参数含义：设置MTP策略组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                |
| MTPACTPROPNAME | MTP动作属性名称 | 可选必选说明：可选参数 参数含义：设置MTP动作属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD MTPACTIONPROP命令配置生成。如果运营商需要定义该MTP策略组的MTP动作策略时，建议配置用于控制处理的MTP动作属性对象名称。 |

#### 使用实例

假如运营商需要修改一个MTP策略组，要求在该MTP策略组中包含MTP动作策略。
增加MTP策略组，设置MTP动作属性；“MTPPOLICYGRPNM”为“TestMtpPolicyGrpNm”，“MTPACTPROPNAME”为“TestMtpActPropName”：

```
MOD MTPPOLICYGRP:MTPPOLICYGRPNM="TestMtpPolicyGrpNm",MTPACTPROPNAME="TestMtpActPropName";
```
