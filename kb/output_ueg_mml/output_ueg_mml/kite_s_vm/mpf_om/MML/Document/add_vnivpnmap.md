# 增加VNI到VPN的映射（ADD VNIVPNMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于增加VNI到VPN的映射。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1000。
- “\_public\_”是公网缺省的VPN的实例名，不需要在VPNInst中配置VPN即可添加映射关系。配置的VPN相同时，VPN用途也相同。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                            |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| VNI         | VNI    | 可选必选说明：必选参数 参数含义：该参数用于配置VxLan隧道标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777215。 默认值：无 配置原则：无                            |
| VPNINSTANCE | VPN实例名 | 可选必选说明：必选参数 参数含义：该参数用于配置VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写，不支持空格。 默认值：无 配置原则：该参数使用ADD VPNINST命令配置生成。 |
| USAGE       | VPN用途  | 可选必选说明：可选参数 参数含义：该参数用于指定VPN业务用途。 数据来源：本端规划 取值范围： GENERAL：VPN用于通用业务。UAC：VPN用于UAC业务。 默认值：GENERAL 配置原则：无           |

#### 使用实例

假如运营商想要增加VNI为1与VPN为vpn\_1的映射关系：

```
ADD VNIVPNMAP: VNI=1, VPNINSTANCE="vpn_1";
```
