# 删除MPF路由（RMV MPFROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，该操作会影响用户业务。

该命令用于删除用户路由。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                      |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------|
| MPFROUTEID | MPF路由标识 | 可选必选说明：必选参数 参数含义：该参数用于指定MPF路由标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31，单位是字节。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商不再使用路由标识为1的地址段，则可删除该地址段：

```
RMV MPFROUTE: MPFROUTEID="1";
```
