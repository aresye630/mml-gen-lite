# 删除用户做car的参数（RMV QOSCARBURST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于清除用户流量管理时的突发尺寸（即令牌桶的深度）做CAR时的突发尺寸。

#### 注意事项

- 该命令执行后立即生效。
- RMV QoSCARBURST命令只能用于清除已配置的Rate对应的突发尺寸。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                               |
|:-------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RATE   | Qos-Car速率（千比特/秒） | 可选必选说明：必选参数 参数含义：该参数用于指定速率，该参数一般由运营商规划给出。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295，单位是千比特每秒。 默认值：无 配置原则：当指定速率rate为0时，配置的突发尺寸是系统的缺省值。若配置的缺省值为0，或未配置缺省值，则缺省的突发尺寸和速率rate有关：若rate为0，则突发尺寸的值为0。若rate（kbit/s）<=53kbit/s，则突发尺寸的值为10000 Byte。若rate（kbit/s）>53kbit/s，突发尺寸的值等于rate（kbit/s）*1000/8*1.5s，单位是Byte。 |

#### 使用实例

删除128kbps速率的突发尺寸的配置：

```
RMV QOSCARBURST:RATE=128;
```
