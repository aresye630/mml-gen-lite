# 修改带宽管理用户组（MOD BWMUSERGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于修改一个带宽管理用户组。带宽管理用户组分三种，分别是全局用户组、默认用户组和具体用户组。当运营商希望修改某具体组的优先级，或修改某具体或默认用户组的带宽控制的业务类型时，则执行该命令。

#### 注意事项

- 修改一个带宽管理用户组对已经在线的用户不生效。
- 全局用户组为系统默认配置，不能修改，并且不能绑定APN和UserProfile进行策略选择，无优先级，全局用户组下配置的规则默认生效。
- 全局用户组下只支持配置TOS类型的带宽业务规则。
- 全局用户组下只能绑定全局的带宽管业务理规则。
- 默认用户组不配置优先级，其优先级别最低，当没有其它可用的用户组或其它用户组里没有配规则时才使用默认用户组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                                                    |
|:----------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERGROUPTYPE   | 用户组类型    | 可选必选说明：必选参数 参数含义：该参数用于配置带宽管理用户组的类型。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT_GROUP：默认用户组。SPECIFIC_GROUP：特定用户组。 默认值：无 配置原则： DEFAULT_GROUP：如果运营商希望在用户没有具体用户组或具体用户组没有配置带宽管理规则时，对此类用户业务带宽进行控制，则配置该参数。SPECIFIC_GROUP：如果运营商希望对某一类用户访问的业务进行带宽控制，则配置该参数，并绑定APN或UserProfile。 |
| USERGROUPNAME   | 用户组名称    | 可选必选说明：条件必选参数 前提条件：该参数在“USERGROUPTYPE”配置为“SPECIFIC_GROUP”时为必选参数。 参数含义：该参数用于配置带宽管理用户组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                     |
| USERGROUPPRI    | 用户组优先级   | 可选必选说明：条件可选参数 前提条件：该参数在“USERGROUPTYPE”配置为“SPECIFIC_GROUP”时为可选参数。 参数含义：该参数用于配置带宽管理用户组的优先级，当用户同时属于两个具体用户组，则根据用户组优先级最终确定用户的归属。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32768。 默认值：无 配置原则： 每个优先级下只能有一个带宽管理用户组。默认用户组和全局用户组无优先级。                                           |
| USERLEVSRVTYPE  | 用户级业务类型  | 可选必选说明：可选参数 参数含义：该参数用于配置用户级别的带宽管理业务类型。 数据来源：本端规划 取值范围：枚举类型。 TOS：TOS类型。NONTOS：非TOS类型。 默认值：无 配置原则： TOS：如果运营商希望对用户业务做基于TOS类型的带宽控制，则配置该参数。NONTOS：如果运营商希望对用户业务做基于非TOS类型的带宽控制，非TOS类型有分类属性、7层协议和协议组。                                                           |
| USERGLEVSRVTYPE | 用户组级业务类型 | 可选必选说明：可选参数 参数含义：该参数用于配置用户组级别的带宽管理业务类型。 数据来源：本端规划 取值范围：枚举类型。 TOS：TOS类型。NONTOS：非TOS类型。 默认值：无 配置原则： TOS：如果运营商希望对用户组级的业务做基于TOS类型的带宽控制，则配置该参数。NONTOS：如果运营商希望对用户组级业务做基于非TOS类型的带宽控制，非TOS类型有分类属性、7层协议和协议组。                                                     |

#### 使用实例

假如运营商需要修改具体用户组“testbwmusergroup”的优先级及业务类型：

```
MOD BWMUSERGROUP: USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="testbwmusergroup",USERGROUPPRI=3,USERLEVSRVTYPE=TOS,USERGLEVSRVTYPE=NONTOS;
```
