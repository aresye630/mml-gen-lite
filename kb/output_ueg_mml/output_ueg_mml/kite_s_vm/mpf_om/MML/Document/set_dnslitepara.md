# 设置轻量DNS参数（SET DNSLITEPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置轻量DNS参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | DNSLMATCHSW   | DNSLPOLICYSW   | DNSRULESTATSW   |
|:-------|:--------------|:---------------|:----------------|
| 初始值    | DISABLE       | DISABLE        | DISABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                              |
|:--------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| DNSLMATCHSW   | 轻量DNS规则匹配开关 | 可选必选说明：可选参数 参数含义：当SMF下发PDR规则时，用于控制是否开启将PDR中的APPID匹配DNS规则。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                        |
| DNSLPOLICYSW  | 轻量DNS策略执行开关 | 可选必选说明：可选参数 参数含义：用于控制命中DNS规则后，是否响应UE的DNS查询请求。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：该参数使用SET DNSLITEPARA命令配置生成。          |
| DNSRULESTATSW | DNS规则状态控制开关 | 可选必选说明：可选参数 参数含义：用于控制是否可以修改静态DNS规则的状态。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：当DNS规则状态控制开关配置为“DISABLE”时，每条静态DNS规则默认为激活状态。 |

#### 使用实例

在需要配置轻量级DNS规则匹配使能、执行轻量DNS策略并且允许修改静态DNS规则的状态，执行如下命令：

```
SET DNSLITEPARA: DNSLMATCHSW=ENABLE, DNSLPOLICYSW=ENABLE, DNSRULESTATSW=ENABLE;
```
