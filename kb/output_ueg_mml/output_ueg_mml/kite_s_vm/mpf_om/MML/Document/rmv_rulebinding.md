# 删除用户模板和规则的绑定关系（RMV RULEBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于删除用户模板与规则的绑定关系。当运营商规划不再使用用户模板下的指定规则进行业务匹配，则配置该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果既不输入策略类型，也不输入规则名称，表示删除该用户模板名称对应的用户模板下所有的规则与用户模板绑定关系。
- 如果输入规则名称，不输入策略类型，表示删除该用户模板名称对应的用户模板下所有该规则名称对应的规则。
- 如果不输入规则名称，输入策略类型，表示删除该用户模板名称对应的用户模板下所有该策略类型的规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                              |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称 | 可选必选说明：必选参数 参数含义：该参数用于设置用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                       |
| RULENAME        | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                         |
| POLICYTYPE      | 策略类型   | 可选必选说明：可选参数 参数含义：该参数用于显示策略类型。 数据来源：本端规划 取值范围：枚举类型。 MTP：Mec流策略控制，代表该规则可以配置MTP策略，用于实现Mec业务流控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要删除指定用户模板下与所有规则的绑定关系：

```
RMV RULEBINDING: USERPROFILENAME="userprofile";
```
