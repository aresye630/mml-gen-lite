# 显示MEC会话信息（DSP MECSESSINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询MPF用户上下文。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                      |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE   | 查询方式   | 可选必选说明：必选参数 参数含义：该参数用于指定查询方式。 数据来源：本端规划 取值范围： IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无                                                           |
| IPV4ADDR    | IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“IPV4”时为必选参数。 参数含义：该字段用于指定IPv4地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无                                    |
| IPV6ADDR    | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定IPv6地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无                                    |
| VPNINSTANCE | VPN实例  | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“IPV4” 或 “IPV6”时为必选参数。 参数含义：该参数用于指定VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写，不支持空格。 默认值：无 配置原则：无 |

#### 使用实例

查询当前MEP用户上下文：

```
DSP MECSESSINFO: QUERYTYPE=IPV6, IPV6ADDR="fe80:0db8:145:3000:0:0:0:0", VPNINSTANCE="vpnauto";
```

#### 输出结果说明

| 输出项名称       | 输出项解释                   |
|:------------|:------------------------|
| UE IPv4地址   | UE IPv4地址。              |
| UE IPv6地址   | UE IPv6地址。              |
| UE VPN      | 用户VPN实例。                |
| Nxuc IPv4地址 | 与MPF对接的对端VXLAN隧道IPv4地址。 |
| Nxuc IPv6地址 | 与MPF对接的对端VXLAN隧道IPv6地址。 |

| Nxua IPv6地址 | MPF本端的VXLAN隧道IPv6地址。    |
| VNI         | VxLan隧道标识。              |
