# 设置前缀URL匹配时的控制参数（SET PREFIXURLPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置前缀URL匹配时的控制开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称           | 参数说明                                                                                                                                                                                 |
|:----------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称         | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD USERPROFILE命令配置生成。                                                                |
| CHECKDESTURL    | 匹配Server IP的开关 | 可选必选说明：必选参数 参数含义：指定是否需要将前缀URL与报文的Server IP进行匹配。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：当需要控制PrefixUrl匹配流程中，是否需要检查IP地址格式，并且匹配Server IP时，设置此参数为Enable。         |
| CHECKSCHEME     | 检查Scheme开关     | 可选必选说明：必选参数 参数含义：指定是否需要在匹配prefix url之前先检查path是否以Scheme开头。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：当需要控制PrefixUrl匹配流程中，需要判断PATH以http://或者https://开头时，配置此参数为使能。 |

#### 使用实例

为用户模板配置前缀URL参数，使能检查目的IP：

```
SET PREFIXURLPARA: USERPROFILENAME="testprofile1", CHECKDESTURL=ENABLE, CHECKSCHEME=DISABLE;
```
