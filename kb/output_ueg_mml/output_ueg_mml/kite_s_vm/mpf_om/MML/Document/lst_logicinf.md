# 查询逻辑接口（LST LOGICINF）

#### 命令功能

**适用NF：MPF**

该命令用于显示逻辑接口的相关信息。

#### 注意事项

默认为输出所有逻辑接口配置信息；若想查看指定逻辑接口配置信息，可指定逻辑接口名称，如果输入的逻辑接口名称在系统中不存在，则查询失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME   | 逻辑接口名称 | 可选必选说明：可选参数 参数含义：该参数用于配置逻辑接口名称，确保逻辑接口的唯一性。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 逻辑接口名称格式固定为：逻辑接口类型（如nxuaif）ISU组号/实例类型/逻辑接口号，如nxuaif1/1/0；第二个数字为实例类型；第三个数字为逻辑接口号，各逻辑接口类型有各自的配置范围。逻辑接口类型：phif，nxcaif，nxuaif。（其中nxcaif为预置接口，配置后只允许执行ping操作。）。ISU组号：1。ISU实例类型：0或1。0表示组级类型，1表示Instance级类型。逻辑接口号：phif：0~1599，nxcaif：0，nxuaif：0~31。 |

#### 使用实例

- 显示nxuaif1/1/0逻辑接口信息：

  ```
  LST LOGICINF: NAME="nxuaif1/1/0";
  ```

  ```
  RETCODE = 0  操作成功。

  逻辑接口信息
  ------------
             逻辑接口名称  =  nxuaif1/1/0
      逻辑接口的IPv4地址1  =  192.168.123.166
      逻辑接口的IPv4掩码1  =  255.255.255.255
  IPv4逻辑接口MTU（字节）  =  1500
              VPN实例名称  =  _public_
         逻辑接口的IP版本  =  IPv4
      逻辑接口的IPv6地址1  =  ::
  IPv6逻辑接口MTU（字节）  =  1800
              IP Suit名称  =  NULL
            IPv6前缀长度1  =  0
  (结果个数 = 1)
  ---    END
  ```
- 显示所有的逻辑接口信息：

  ```
  LST LOGICINF:;
  ```

  ```
  RETCODE = 0  操作成功。

  逻辑接口信息
  ------------
  ```
