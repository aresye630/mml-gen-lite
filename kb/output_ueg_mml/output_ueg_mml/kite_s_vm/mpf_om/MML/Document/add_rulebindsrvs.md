# 增加业务统计规则绑定配置（ADD RULEBINDSRVS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于将Rule绑定到ServiceStat实例下，添加基于业务的性能统计组合中的Rule对象，添加Rule过滤规则。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为1600。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| SRVSTATNAME | 业务统计名称 | 可选必选说明：必选参数 参数含义：该参数用于指定业务统计配置的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写，不支持空格。 默认值：无 配置原则：无                      |
| RULENAME    | 规则名称   | 可选必选说明：必选参数 参数含义：该参数用于指定被绑定的Rule的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写，不支持空格。 默认值：无 配置原则：该参数使用ADD RULE命令配置生成。 |

#### 使用实例

假如运营商希望配置基于业务的性能统计组合，统计规则“rule1”下的业务的数据包的请求次数、响应次数和响应时延：

```
ADD RULEBINDSRVS:SRVSTATNAME="stat1",RULENAME="rule1";
```
