# 清除逻辑口报文统计信息（CLR INTERFACEPERF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用来清除接口输入输出报文的统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                               |
|:--------------|:-------|:-----------------------------------------------------------------------------------|
| INTERFACENAME | 逻辑接口名称 | 可选必选说明：可选参数 参数含义：该参数用于指定要查询的逻辑接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

当运营商需要统计一定时间内某接口的流量信息时，这时必须在统计开始前清除该接口原有的统计信息，使接口重新进行统计：

```
CLR INTERFACEPERF:INTERFACENAME="nxuaif1/1/0";
```
