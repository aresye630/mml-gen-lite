# 增加流过滤器的过滤器绑定关系（ADD FLTBINDFLOWF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于新增过滤器与流过滤器绑定关系，使用该过滤条件的业务可以成功匹配该流过滤器的L34层过滤条件。

#### 注意事项

- 该命令执行后需要等待执行SET REFRESHSRV命令刷新后对新数据流生效。
- 该命令最大记录数为100000。
- 单个FlowFilter可以配置Filter和FilterIPv6总数为5000个。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                            |
|:---------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：必选参数 参数含义：该参数用于设置流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD FLOWFILTER命令配置生成。            |
| FILTERNAME     | 过滤器名称  | 可选必选说明：必选参数 参数含义：该参数用于设置过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD FILTER或者ADD FILTERIPV6命令配置生成。 |

#### 使用实例

增加过滤器到流过滤器，FLOWFILTERNAME为“testflowfiltername”，FILTERNAME为“testfiltername”：

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="testflowfiltername",FILTERNAME="testfiltername";
```
