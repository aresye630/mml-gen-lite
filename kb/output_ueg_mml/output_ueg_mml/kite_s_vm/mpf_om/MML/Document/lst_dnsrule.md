# 显示DNS规则（LST DNSRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于回显DNS规则。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                        |
|:--------------|:--------|:--------------------------------------------------------------------------------------------|
| APPLICATIONID | 应用标识    | 可选必选说明：可选参数 参数含义：该参数用于配置DNS列表所属的应用标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无 |
| DNSRULENAME   | DNS规则名称 | 可选必选说明：可选参数 参数含义：该参数用于配置DNS规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无      |
| DOMAIN        | 域名      | 可选必选说明：可选参数 参数含义：该参数用于设置DNS规则的服务器域名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无  |

#### 使用实例

在需要查看轻量DNS规则时，执行该命令查看现有规则：

```
LST DNSRULE: APPLICATIONID="app1", DNSRULENAME="rule1";
```
