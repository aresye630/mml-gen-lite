# 修改业务统计配置（MOD SERVICESTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于修改基于业务的性能统计对象组合，配置是否统计HTTP协议和DNS协议的请求次数、成功/错误响应次数和响应时延等。

#### 注意事项

该命令执行后对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                            |
|:---------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVSTATNAME    | 业务统计名称      | 可选必选说明：必选参数 参数含义：该参数用于指定业务统计配置的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写，不支持空格及特殊字符“#”、“:”和“&”。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                  |
| PRIORITY       | 优先级         | 可选必选说明：可选参数 参数含义：该参数用于设置组合间的优先级顺序。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则： 除缺省值65535外的优先级不允许重复。数值越小优先级越高。                                                                                                                                                                                                                                                                 |
| HTTPSTATSWITCH | HTTP统计开关    | 可选必选说明：可选参数 参数含义：该参数用于设置是否支持对HTTP协议进行统计。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：取值可以为ENABLE，DISABLE。如果没有配置，缺省为DISABLE。各取值的说明如下：ENABLE：对HTTP协议的请求次数、成功响应次数、错误响应次数和响应时延进行统计。DISABLE：不对HTTP协议的请求次数、成功响应次数、错误响应次数和响应时延进行统计。                                                                                                                                 |
| DNSSTATSWITCH  | DNS统计开关     | 可选必选说明：可选参数 参数含义：该参数用于设置是否支持对DNS协议进行统计。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：取值可以为ENABLE，DISABLE。如果没有配置，缺省为DISABLE。各取值的说明如下：ENABLE：对DNS协议的请求次数、成功响应次数、错误响应次数和响应时延进行统计；DISABLE：不对DNS协议的请求次数、成功响应次数、错误响应次数和响应时延进行统计。                                                                                                                                    |
| ENODEBIP       | eNodeB IP地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPV6SWITCH”配置为“DISABLE”时为可选参数。 参数含义：设置指定eNodeB的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。不支持配置为255.255.255.255。 默认值：无 配置原则：配置为0.0.0.0表示不对eNodeB的IP进行匹配。                                                                                                                                                                                                             |
| USERTYPE       | 用户类型        | 可选必选说明：可选参数 参数含义：设置用户类型，未配置用户类型时，表示支持匹配所有用户。 数据来源：本端规划 取值范围：枚举类型。 IMSI：IMSI。MSISDN：MSISDN。NONE：不配置。 默认值：无 配置原则：设置用户类型，未配置用户类型时，表示支持匹配所有用户。                                                                                                                                                                                                                                      |
| IMSI           | IMSI        | 可选必选说明：条件必选参数 前提条件：该参数在“USERTYPE”配置为“IMSI”时为必选参数。 参数含义：表示用户的IMSI号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。必须全部为整数。 IMSI由三部分组成： 1、Mobile Country Code (MCC)包含3个数字。MCC唯一标识移动用户的居住国家。 2、Mobile Network Code (MNC)包含2个或3个数字用于GSM/UMTS应用。MNC标识移动用户的归属PLMN。MNC的长度取决于MCC的值。不推荐单个MCC区内两个和三个数字混合编码的MNC，此种情况已经在本书之外。 3、Mobile Subscriber Identification Number (MSIN)标识PLMN内的移动用户。 默认值：无 配置原则：无 |
| MSISDN         | MSISDN      | 可选必选说明：条件必选参数 前提条件：该参数在“USERTYPE”配置为“MSISDN”时为必选参数。 参数含义：表示用户的MSISDN号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。必须全部为整数，且不能为“19”。 MSISDN号的组成： 1、用户注册的国家的Country Code (CC) 2、国家移动号，组成如下：National Destination Code (NDC)；Subscriber Number (SN)。 默认值：无 配置原则：无                                                                                                                             |
| TCPSTATSWITCH  | TCP统计开关     | 可选必选说明：可选参数 参数含义：TCP协议统计的功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                 |
| RATTYPE        | RAT类型       | 可选必选说明：可选参数 参数含义：无线接入技术类型。 数据来源：本端规划 取值范围：枚举类型。 UTRAN：UTRAN类型。EUTRAN：EUTRAN类型。OTHER：其它类型。NONE：不配置。 默认值：无 配置原则：未配置该参数表示支持匹配所有接入类型。                                                                                                                                                                                                                                               |
| STARTFILESIZE  | 起始文件大小      | 可选必选说明：可选参数 参数含义：文件大小区间起始值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000000，单位是千字节。 默认值：无 配置原则：需要与EndFileSize参数同时配置。FileSize指整条TCP流的下行总流量。                                                                                                                                                                                                                                                   |
| ENDFILESIZE    | 结束文件大小      | 可选必选说明：可选参数 参数含义：文件大小区间终止值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000000，单位是千字节。 默认值：无 配置原则：需要与StartFileSize参数同时配置。FileSize指整条TCP流的下行总流量。                                                                                                                                                                                                                                                 |
| STARTRTTRATIO  | 起始RTT比例     | 可选必选说明：可选参数 参数含义：无线侧RTT与有线侧RTT的比例区间或有线侧RTT与无线侧RTT的比例区间起始值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～50。 默认值：无 配置原则：需要与EndRttRatio参数同时配置。                                                                                                                                                                                                                                                      |
| ENDRTTRATIO    | 结束RTT比例     | 可选必选说明：可选参数 参数含义：无线侧RTT与有线侧RTT的比例区间或有线侧RTT与无线侧RTT的比例区间终止值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～50。 默认值：无 配置原则：需要与StartRttRatio参数同时配置。                                                                                                                                                                                                                                                    |
| IPV6SWITCH     | IPV6 地址开关   | 可选必选说明：可选参数 参数含义：该参数用来设置是否配置IPV6地址。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                            |
| ENODEBIPV6     | eNodeB IP地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPV6SWITCH”配置为“ENABLE”时为可选参数。 参数含义：设置指定eNodeN的IP地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                                                                                                                                                                                                                               |

#### 使用实例

假如运营商希望修改基于业务的性能统计配置“stat1”，把优先级修改为10，并打开HTTP统计开关，统计HTTP协议的请求次数、响应次数和响应时延：

```
MOD SERVICESTAT:SRVSTATNAME="stat1",PRIORITY=10,HTTPSTATSWITCH=ENABLE;
```
