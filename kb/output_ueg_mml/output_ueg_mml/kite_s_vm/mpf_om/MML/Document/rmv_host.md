# 删除Host（RMV HOST）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：MPF**

RMV HOST此命令用来删除指定Host主机名或所有Host主机名。

#### 注意事项

- 该命令执行后立即生效。
- 在删除Host信息执行RMV HOST命令前，需要确定HostName是否被Filter对象引用，如已绑定需先解除绑定后执行RMV HOST命令。
- 输入HostName删除指定记录，不输入HostName删除全部记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                          |
|:---------|:---------|:----------------------------------------------------------------------------------------------|
| HOSTNAME | Host配置名称 | 可选必选说明：可选参数 参数含义：该参数用于指定HOST配置名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除Host主机名称，主机名为“huawei”：

```
RMV HOST:HOSTNAME="huawei";
```
