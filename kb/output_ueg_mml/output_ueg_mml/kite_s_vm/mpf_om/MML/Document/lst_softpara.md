# 查询软参记录（LST SOFTPARA）

- 命令功能

#### 命令功能

**适用NF：MPF**

该命令用于查询软件参数信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                   |
|:--------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT      | 软参记录数据类型 | 可选必选说明：可选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 BIT：比特。BYTE：字节。DWORD：双字。STRING：字符串。 默认值：无 配置原则： 配置BIT表示需要查询比特类型软件参数。配置BYTE表示需要查询字节类型软件参数。配置DWORD表示需要查询双字类型软件参数。配置STRING表示需要查询字符串类型软件参数。                               |
| DATANUM | 软参记录索引   | 可选必选说明：可选参数 参数含义：待查询软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1920。 默认值：无 配置原则： 当DT取值为BIT时，“DATANUM”的取值范围是“1~1920”。当DT取值为BYTE时，“DATANUM”的取值范围是“1~960”。当DT取值为DWORD时，“DATANUM”的取值范围是“1~120”。当DT取值为STRING时，“DATANUM”的取值是“1~30”。 |

#### 使用实例

查询当前参数索引为1的单字节类型软参的设置情况：

```
LST SOFTPARA: DT=BYTE, DATANUM=1;
```

```

    软参记录索引  =  1

---    END
```
