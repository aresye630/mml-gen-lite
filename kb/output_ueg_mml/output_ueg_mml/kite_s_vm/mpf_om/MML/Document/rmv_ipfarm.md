# 删除IPFarm（RMV IPFARM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于删除一个IP farm，同时批量删除该IP farm下的所有IP farm服务器。

#### 注意事项

- 该命令执行后立即生效。
- 如果规则中配置的Web Proxy重定向引用了该IP farm，可能会导致该IP farm对应用户当前的重定向业务中断，则不允许删除该IP farm。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                           |
|:-----------|:----------|:-----------------------------------------------------------------------------------------------|
| IPFARMNAME | IP-Farm名称 | 可选必选说明：可选参数 参数含义：该参数用于设置IP farm名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商需要删除一个名称为“test”的IP Farm，则使用如下命令：

```
RMV IPFARM:IPFARMNAME="test";
```
