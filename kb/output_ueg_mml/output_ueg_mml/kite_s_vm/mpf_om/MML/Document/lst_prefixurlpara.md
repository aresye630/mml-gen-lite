# 查询前缀URL参数（LST PREFIXURLPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询用户模板的前缀URL配置参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                  |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD USERPROFILE命令配置生成。 |

#### 使用实例

查询用户模板的前缀URL配置参数：

```
LST PrefixUrlPara: USERPROFILENAME="testprofile1";
```
