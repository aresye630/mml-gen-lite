# 清除NETCONF会话统计信息（RTR NCARSTSSNSTATS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除NETCONF会话统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                  |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| SESSIONID       | 会话ID   | 可选必选说明：必选参数 参数含义：该参数用于指定NETCONF会话ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无                                                          |
| STCTYPE         | 清除类型   | 可选必选说明：必选参数 参数含义：该参数用于指定NETCONF清除类型。 数据来源：本端规划 取值范围：枚举类型。 NTFFAIL：Notification失败统计信息。NTFSTC：Notification统计信息。SESSIONSTC：会话统计信息。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                          |

#### 使用实例

清除NETCONF会话统计信息：

```
RTR NCARSTSSNSTATS:SESSIONID=456,STCTYPE=SESSIONSTC,SERVICEINSTANCE="vnfc";
```
