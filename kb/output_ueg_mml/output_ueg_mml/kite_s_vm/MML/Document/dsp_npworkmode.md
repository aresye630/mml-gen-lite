# 显示NP工作模式（DSP NPWORKMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示NP所在槽号、框号和工作模式。

## 注意事项

该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示NP槽号、框号和工作模式：

```
%%DSP NPWORKMODE:;%%
RETCODE = 0  操作成功

结果如下
--------
槽号  框号  NP号  工作模式  

1     0     0     1  
2     0     0     1  
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                               |
|:--------|:----------------------------------------------------------------------------------------------------|
| 槽号      | NP所在的槽号。                                                                                            |
| 框号      | NP所在的框号。                                                                                            |
| NP号     | NP的编号。                                                                                              |
| 工作模式    | NP工作模式。工作模式的详细信息可以通过OPR DBGDATA: DBGTYPE=CELLTYPE, CELLTYPE=135, DEBUGNAME="femf workmode info";获取。 |
