# 查询自动配置开关（LST AUTOCONFIG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询自动配置开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询自动配置开关：

```
LST AUTOCONFIG:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
自动配置开关  =  FALSE
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET AUTOCONFIG的参数说明。
