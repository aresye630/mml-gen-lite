# 显示PAE端口统计信息（DSP PAEPORT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAE端口统计信息。

通过统计PAE外联端口、Fabric端口、Loop端口、Control端口收发报文的数目以及收发速率，可了解PAE模块与其他模块通信是否正常，并进行故障诊断。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |
| PORTTYPE     | 端口类型   | 可选必选说明：可选参数 参数含义：该参数用于指定PAE端口类型。 数据来源：本端规划 取值范围：枚举类型。 extern：外联口。fabric：内联口。loop：Loop口。base：base口。acc：加速端口。control：控制端口。 默认值：无                                          |

#### 使用实例

显示所有微服务类型为aa的微服务实例aa的PAE外联口统计信息：

```
DSP PAEPORT:CELLTYPE="aa", CELLINSTANCE="aa";
```
