# 查询匹配规则（DSP MSSRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询匹配规则。

用户设置规则后通过该命令进行查询当前的规则信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |

#### 使用实例

查询匹配规则：

```
DSP MSSRULE:RUNAME = "VNODE_VNRS_VNFC_IPU_0066";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
规则ID   偏移类型              引用计数   偏移  规则   掩码
1        UFP包控制块           0          0     ffff   ffff
2        UFP包控制块           0          0     ffff   ffff
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 引用计数    | 用于表示引用计数。 |

其余输出项请参见SET MSSRULE的参数说明。
