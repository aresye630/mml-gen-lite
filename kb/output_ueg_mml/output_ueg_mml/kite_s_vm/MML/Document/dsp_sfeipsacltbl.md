# 查询软转发SFE IPSEC-ACL表项信息（DSP SFEIPSACLTBL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令查询软转发SFE IPSEC-ACL表项信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                  |
|:-----------|:-------------|:----------------------------------------------------------------------------------------------------------------------|
| RUNAME     | 资源单元名称       | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称，可使用命令DSP RU查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用DSP RU查看RU名称。          |
| TABLETYPE  | IPSEC ACL表类型 | 可选必选说明：必选参数 参数含义：该参数表示需要查询的IPSEC ACL表类型。 数据来源：本端规划 取值范围：枚举类型。 flex：灵活引流ACL。split：传输模式分流ACL。 默认值：无                     |
| INDEX      | IPSEC ACL索引  | 可选必选说明：必选参数 参数含义：该参数表示需要查询的IPSEC ACL表项索引。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                |
| SOURCEIP   | 源IPv4地址      | 可选必选说明：必选参数 参数含义：该参数用于表示需要查询的报文源IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                  |
| DESTIP     | 目的IPv4地址     | 可选必选说明：必选参数 参数含义：该参数用于表示需要查询的报文目的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                 |
| SOURCEPORT | 源端口号         | 可选必选说明：条件必选参数 前提条件：该参数在“TABLETYPE”配置为“split”时为必选参数。 参数含义：该参数用于表示需要查询的报文源端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无  |
| DESTPORT   | 目的端口号        | 可选必选说明：条件必选参数 前提条件：该参数在“TABLETYPE”配置为“split”时为必选参数。 参数含义：该参数用于表示需要查询的报文目的端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 |
| PROTOCOL   | IP协议类型       | 可选必选说明：条件必选参数 前提条件：该参数在“TABLETYPE”配置为“split”时为必选参数。 参数含义：该参数用于表示需要查询的报文IP协议类型。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无  |
| VPNID      | VPN编号        | 可选必选说明：必选参数 参数含义：该参数用于表示需要查询的报文VPN编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                         |

#### 使用实例

- 查询灵活引流ACL表类型信息：

  ```
  DSP SFEIPSACLTBL:RUNAME=" VNODE_VNRS_VNFC_IPU_0066",TABLETYPE= flex, INDEX=1,DESTIP="192.168.1.1", SOURCEIP="192.168.1.2",VPNID=3;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
  动作索引号  =  0                                                                                       
  RE索引  =  17                                                                                      
  IPSEC出接口索引  =  12                                                                                      
  IPSEC Tunnel口绑定的Vpn  =  3

  (结果个数 = 1)
  ---    END
  ```
- 查询传输模式分流ACL表类型信息：

  ```
  DSP SFEIPSACLTBL:RUNAME=" VNODE_VNRS_VNFC_IPU_0066",TABLETYPE= split, PROTOCOL=17,DESTPORT=0,SOURCEPORT=0,INDEX=1,DESTIP="192.168.1.1", SOURCEIP="192.168.1.2",VPNID=3;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
  动作索引号  =  0
  匹配动作 =  0
  目的RU号 = 65
  引擎口索引 = 10                                                                                                                                                                          
  IPSEC出接口索引  =  12                                                                                      
  IPSEC Tunnel口绑定的Vpn  =  3
  与对端建立的隧道编号 = 4001

  (结果个数 = 1)
  ---    END
  ```
