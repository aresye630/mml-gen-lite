# 查询QoS接口信任（LST QOSIFTRUST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询绑定在以太主接口上的简单流分类策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                        |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名称    | 可选必选说明：可选参数 参数含义：该参数用于指定一个接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。                         |
| DSNAME    | DS域名    | 可选必选说明：可选参数 参数含义：该参数用于指定DS域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                     |
| FLAG8021P | 8021p标志 | 可选必选说明：可选参数 参数含义：该参数用于指定映射的优先级。 数据来源：本端规划 取值范围：枚举类型。 false：不支持以太子接口上根据802.1p的值进行简单流分类。true：支持以太子接口上根据802.1p的值进行简单流分类。 默认值：无 |

#### 使用实例

查询当前所有的简单流分类策略：

```
LST QOSIFTRUST:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
    DS域名 = 1
  接口名称 = Ethernet66/0/3
8021p标志 = 否
  (结果个数 = 1)
----END
```

#### 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| DS域名    | 该参数表示DS域名称。      |
| 接口名称    | 该参数表示接口名称。       |
| 8021p标志 | 该参数表示是否支持802.1p。 |
