#### 命令功能

该命令用于查询基于IPv6信息的设置路由下一跳的配置结果。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                     |
|:-------------|:--------|:-------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字  | 可选必选说明：可选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |
| NODESEQUENCE | 路由策略节点号 | 可选必选说明：可选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 |

#### 使用实例

查询设置路由下一跳配置信息：

```
LST APPLYIPV6NEXTHOP:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
      路由策略名字  =  a
    路由策略节点号  =  10
是否是对等体IP地址  =  否
        下一跳类型  =  IP地址
          接口名字  =  NULL
        下一跳地址  =  2001:DB8::
(结果个数 = 1)
---    END
```

#### 参考信息

为实现路由策略，首先定义将要实施路由策略的路由特征，即定义一组匹配规则和设置规则，然后将它们应用于路由的发布、接收和引入等过程的路由策略中。
