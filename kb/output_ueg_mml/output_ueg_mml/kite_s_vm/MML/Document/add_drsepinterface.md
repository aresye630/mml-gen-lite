# 增加接口故障隔离（ADD DRSEPINTERFACE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在免交换组网下组成热备容灾关系的网元间DCI通道变化时，添加需要关闭/开启的逻辑接口。

## 注意事项

- 该命令执行后立即生效。

- 该命令只用于在UEG-M/UEG网元采用主备（热备）容灾模式下执行。
- 该命令执行时，请确保配置接口名称正确。如果配置错误，请先执行**RMV DRSEPINTERFACE**命令，再执行此命令添加正确的接口。

- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                          |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：必选参数  参数含义：该参数用于配置容灾组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无                                |
| IFNAME    | 接口名    | 可选必选说明：必选参数  参数含义：该参数用于配置接口名称。可通过LST DRSEPINTERFACE命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无 |

## 使用实例

新增故障隔离接口。

```
ADD DRSEPINTERFACE: DRGROUPID=1, IFNAME="itf1";
```
