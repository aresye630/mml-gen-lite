# 显示MFIB4表项（DSP SFEMFIB4）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示MFIB4表项。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------|
| SRCIP   | 源IP    | 可选必选说明：必选参数 参数含义：该参数表示源IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                   |
| GROUPIP | 组播组IP  | 可选必选说明：必选参数 参数含义：该参数表示组播组IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                 |
| VPN     | VPN编号  | 可选必选说明：必选参数 参数含义：该参数表示VPN编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                          |
| RUNAME  | RU名称   | 可选必选说明：必选参数 参数含义：该参数表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

显示指定资源单元、组播源IP、组播目的IP、VPN的组播MFIB4表项：

```
DSP SFEMFIB4:SRCIP="10.1.1.100",GROUPIP="239.0.0.1",VPN=0,RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```
