# 显示流控统计（DSP FCSTATIS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询进程运行中的调试信息。当管理员需要查询流控功能当前的统计信息时，可以使用本命令查询。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                      |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPRCOND     | 调试类型   | 可选必选说明：必选参数  参数含义：该参数用于表示查询消息发送对象类型。  数据来源：本端规划 取值范围： “CELLID（进程标识）”：进程标识“CELLTYPE（进程类型标识）”：进程类型标识  默认值：无  配置原则：无                                                         |
| CELLID      | 进程标识   | 可选必选说明：该参数在"OPRCOND"配置为"CELLID"时为条件必选参数。  参数含义：该参数用于表示流控查询消息发给某一个进程，进程标识可以通过使用命令DSP MSPROCESS获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无                      |
| CELLTYPE    | 进程类型   | 可选必选说明：该参数在"OPRCOND"配置为"CELLTYPE"时为条件必选参数。  参数含义：该参数用于表示流控查询消息发给某一类进程，进程标识可以通过使用命令DSP MSPROCTYPE获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                    |
| QUERYCOND   | 查询类型   | 可选必选说明：必选参数  参数含义：该参数用于表示查询对象类型。  数据来源：本端规划 取值范围： “QUERYALL（查询全部套餐）”：查询全部套餐“QUERYONE（查询指定套餐）”：查询指定套餐  默认值：无  配置原则：无                                                       |
| SERVICENAME | 服务名称   | 可选必选说明：该参数在"QUERYCOND"配置为"QUERYONE"时为条件必选参数。该参数在"QUERYCOND"配置为"QUERYALL"时为条件可选参数。  参数含义：该参数用于表示服务名称，根据服务名称来查询对应的套餐信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |
| SERVICETYPE | 服务类型   | 可选必选说明：该参数在"QUERYCOND"配置为"QUERYONE"时为条件必选参数。  参数含义：该参数用于表示服务类型，根据服务类型来查询对应的套餐信息。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                       |
| GROUPID     | 服务组标识  | 可选必选说明：该参数在"QUERYCOND"配置为"QUERYONE"时为条件必选参数。  参数含义：该参数用于表示服务组标识，根据服务组标识来查询对应的套餐信息。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                     |
| CASEID      | 套餐标识   | 可选必选说明：该参数在"QUERYCOND"配置为"QUERYONE"时为条件必选参数。  参数含义：该参数用于表示套餐标识，根据套餐标识来查询对应的套餐信息。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                       |
