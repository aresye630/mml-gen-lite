# 显示SDRS中的APPTYPE信息（DSP SDRSAPPTYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRS中APP的类型。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                   |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| CELLID | Cell ID | 可选必选说明：必选参数  参数含义：该参数用于指定SDR调试消息发送的CELLID，可以通过使用命令DSP MSPROCESS获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRS中缓存的APP类型信息：

```
%%DSP SDRSAPPTYPE:  CELLID="vup-pod-010-104-1-24__103__0";%%
RETCODE = 0  操作成功
结果如下
--------
Cell ID  = vup-pod-010-104-1-24__103__0
app类型  = 114 126 127
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                            |
|:--------|:-------------------------------------------------|
| Cell ID | 该参数用于指定SDR调试消息发送的CELLID，可以通过使用命令DSP MSPROCESS获取。 |
| app类型   | 该参数用于标识SDRS拥有其路由策略的服务类型。                         |
