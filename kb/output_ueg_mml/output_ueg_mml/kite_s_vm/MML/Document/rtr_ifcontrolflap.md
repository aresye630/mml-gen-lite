# 清除接口震荡抑制信息（RTR IFCONTROLFLAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除接口震荡抑制信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名    | 可选必选说明：必选参数 参数含义：该参数用于指定震荡抑制的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| FLAPCOUNT | 震荡次数   | 可选必选说明：必选参数 参数含义：该参数用于指定是否清除震荡次数。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                         |
| PENALTY   | 震荡惩罚值  | 可选必选说明：必选参数 参数含义：该参数用于指定是否清除震荡惩罚值。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                        |

#### 使用实例

清除接口震荡抑制信息：

```
RTR IFCONTROLFLAP:IFNAME="ethernet64/0/3",FLAPCOUNT=TRUE,PENALTY=TRUE;
```
