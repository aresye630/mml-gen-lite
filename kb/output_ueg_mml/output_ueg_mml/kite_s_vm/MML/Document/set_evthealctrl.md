# 设置事件全局开关（SET EVTHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置事件全局开关。去使能时，所有事件自愈功能失效。使能时，以**SET EVTSW**命令配置的单个事件的开关状态为准。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| EVENTSWITCH   |
|:--------------|
| ENABLE        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                    |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------|
| EVENTSWITCH | 事件全局开关 | 可选必选说明：必选参数  参数含义：该参数用于表示事件全局开关。  数据来源：本端规划 取值范围： “ENABLE（打开）”：自愈使能“DISABLE（不使能）”：自愈不使能  默认值：无。  配置原则：无 |

## 使用实例

关闭事件全局开关

```
%%SET EVTHEALCTRL: EVENTSWITCH=ENABLE;%% 
RETCODE = 0  操作成功
```
