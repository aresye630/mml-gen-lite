# 显示微服务进程可用状态统计信息（DSP CELLSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询进程可用状态统计信息，支持基于POD类型查询和整系统查询。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECT  | 对象类型   | 可选必选说明：必选参数  参数含义：该参数用于表示查询的对象类型，根据Pod类型查询或查询整系统。  数据来源：本端规划 取值范围： “PODTYPE（POD类型）”：升级，实例化场景下检查POD是否就绪。“VNF（网元）”：查询整个网元  默认值：无  配置原则：  “PODTYPE”用于Pod升级、实例化场景下，检查Pod是否就绪。“VNF”用于查询整个网元内的进程是否处于就绪状态。 |
| PODTYPE | POD类型  | 可选必选说明：该参数在"OBJECT"配置为"PODTYPE"时为条件可选参数。  参数含义：该参数用于查询该类型POD内的进程信息。当不输入该参数时，按POD名称返回整个网元的进程统计信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：  使用DSP PODINFO命令获取POD类型作为该参数的输入。                 |

## 使用实例

查询整网元进程统计信息

```
%%DSP CELLSTAT: OBJECT=VNF;%%
RETCODE = 0  操作成功

结果如下
--------
    对象名称  =  VNF
  就绪进程数  =  176
未就绪进程数  =  25
  故障进程数  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| 对象名称    | 该参数用于显示进程所在POD的名称。 |
| 就绪进程数   | 该参数表示就绪进程的数量。      |
| 未就绪进程数  | 该参数表示未就绪进程的数量。     |
| 故障进程数   | 该参数表示故障进程的数量。      |
