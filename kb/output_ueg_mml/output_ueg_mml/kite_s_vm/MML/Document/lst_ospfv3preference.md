# 查询OSPFv3路由优先级配置（LST OSPFV3PREFERENCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3路由优先级配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                        |
|:----------|:----------|:--------------------------------------------------------------------------------------------|
| PROCID    | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                    |
| ROUTETYPE | 路由类型      | 可选必选说明：可选参数 参数含义：路由类型。 数据来源：本端规划 取值范围：枚举类型。 non-ase：非AS-External路由。ase：AS-External路由。 默认值：无 |

#### 使用实例

查询OSPFv3进程1下ASE路由优先级配置：

```
LST OSPFV3PREFERENCE:PROCID=1,ROUTETYPE=ase;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
OSPFv3进程号  =  1
    拓扑标识  =  0
    路由类型  =  AS-External路由
      优先级  =  150
路由策略名称  = NULL
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                  |
|:----------|:---------------------------------------|
| OSPFv3进程号 | 该参数指定用户创建的OSPFv3进程号。                   |
| 拓扑标识      | 该参数指定用户创建的OSPFv3拓扑标识。                  |
| 路由类型      | 该参数指定OSPFv3路由类型。                       |
| 优先级       | 该参数指定OSPFv3路由优先级，路由优先级的值越小，其实际的优先程度越高。 |
| 路由策略名称    | 该参数指定路由策略名称，使用路由策略为特定的路由设定优先级。         |
