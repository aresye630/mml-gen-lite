# 增加L3VPN实例地址族（ADD VPNINSTAFIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置指定VPN实例下的地址族。

## 注意事项

- 该命令执行后立即生效。

- 需要确保指定的VPN实例在设备上已经通过**ADD L3VPNINSTIPSEC**增加。
- 不能给VPN实例\_\_mpp\_vpn\_inner\_\_添加地址族。

- 最多可输入1001条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定用户增加地址族的L3VPN实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  不支持空格。使用LST L3VPNINSTIPSEC命令查看可用VPN。 |
| AFTYPE  | 地址族类型   | 可选必选说明：必选参数  参数含义：该参数用于设置指定VPN实例下的地址族。  数据来源：本端规划 取值范围： “Ipv4uni（IPv4地址族）”：IPv4地址族“Ipv6uni（IPv6地址族）”：IPv6地址族  默认值：无  配置原则：无         |

## 使用实例

增加名称为“vrf1”的VPN实例下的IPv4单播地址族：

```
ADD VPNINSTAFIPSEC:VRFNAME="vrf1", AFTYPE=Ipv4uni;
```
