# 修改隧道选择器节点（MOD TUNNELSELECTORNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改隧道选择器节点。

#### 注意事项

- 该命令执行后立即生效。
- 配置该命令前，必须已经配置了该节点指定隧道选择器的名字，必须配置了要修改的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                              |
|:----------------|:--------|:----------------------------------------------------------------------------------|
| NODESEQUENCE    | 隧道选择器节点 | 可选必选说明：必选参数 参数含义：该参数用来指定隧道选择器节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无         |
| TNLSELECTORNAME | 隧道选择器名字 | 可选必选说明：必选参数 参数含义：该参数用于指定隧道选择器名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～40。 默认值：无          |
| MATCHMODE       | 匹配模式    | 可选必选说明：必选参数 参数含义：该参数用来指定隧道选择器的匹配模式。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无 |

#### 使用实例

修改隧道选择器a的一个节点属性，节点号为10：

```
MOD TUNNELSELECTORNODE:TNLSELECTORNAME="a",NODESEQUENCE=10,MATCHMODE=deny;
```
