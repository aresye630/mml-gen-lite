# 查询文件存留期设置（LST CHRFILESAVETIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查看文件最大保留时间以及存留期设置是否生效。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

用户需要查看当前的chr存留期的设置时，直接调用该命令，无需参数，系统会返回文件存留期限以及存留是否开启。

```
%%LST CHRFILESAVETIME:;%%
RETCODE = 0  操作成功

结果如下
--------
是否开启存留期功能  =  启用存留期控制
  文件最大保留天数  =  180
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释             |
|:----------|:------------------|
| 是否开启存留期功能 | 该参数用于描述存留期设置是否生效。 |
| 文件最大保留天数  | 该参数用于描述文件最大存留期限。  |
