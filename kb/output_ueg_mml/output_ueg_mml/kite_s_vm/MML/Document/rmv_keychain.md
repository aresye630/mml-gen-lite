# 删除Keychain的配置（RMV KEYCHAIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除一个Keychain实例。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                       |
|:-------------|:-----------|:-------------------------------------------------------------------------------------------|
| KEYCHAINNAME | Keychain名称 | 可选必选说明：必选参数 参数含义：该参数用于指定Keychain名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。不含问号或空格，大小写不敏感。 默认值：无 |

#### 使用实例

删除Keychain实例：

```
RMV KEYCHAIN:KEYCHAINNAME="ospf";
```
