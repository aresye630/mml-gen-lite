# 删除TLS参数（RMV TLSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一组TLS参数。

## 注意事项

- 该命令执行后立即生效。

- 删除TLS参数后，如果该条配置关联的设备证书场景或CA证书场景没有被其他TLS参数配置关联，则需要通过**RMV TLSSCENE**命令删除对应的TLS证书场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定TLS参数索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：  与ADD HTTPLE中配置的TLS参数索引保持一致。 |

## 使用实例

若运营商想删除索引为1的TLS配置，可以用如下命令：

```
RMV TLSPARA: INDEX=1;
```
