# 删除消息跟踪限制（RMV MTSPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令后，会删除对消息跟踪能力的限制，请谨慎使用该命令。

本命令用于删除对消息跟踪能力的限制。

## 注意事项

- 请勿同时执行本命令和批量删除任务，否则可能会导致本次批量删除部分任务失败。请在批量删除任务流程结束后再执行本命令。
- 当用户执行本命令时，若仅选择“网元ID”与“规则类型”，将删除当前“规则类型”下的所有策略限制，请谨慎操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID        | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST MELST ME命令查询获取。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                 |
| POLICYTYPE  | 规则类型   | 可选必选说明：必选参数。 参数含义：限制消息跟踪的规则类型。 取值范围： DISABLE_BY_TYPE(限制跟踪类型)DISABLE_BY_SERVICE(限制服务名称) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                        |
| TRACETYPE   | 跟踪类型   | 可选必选说明：该参数在“规则类型”配置为“DISABLE_BY_TYPE(限制跟踪类型)”或“DISABLE_BY_SERVICE(限制服务名称)”时为条件可选参数。 参数含义：跟踪类型，可以通过DSP MTSMODEL命令查询获取。 取值范围：整数类型，取值范围0~2147483647。 默认值：无。 配置原则： 当“规则类型”配置为“DISABLE_BY_TYPE(限制跟踪类型)”时，本参数需要与DSP MTSMODEL命令的“跟踪类型”输出项保持一致。如果不填写本参数，执行命令时将删除所有跟踪类型的策略限制。“规则类型”配置为“DISABLE_BY_SERVICE(限制服务名称)”时，本参数需要与DSP MTSMODEL命令的“拓展跟踪类型”输出项保持一致。如果不填写“跟踪类型”与“服务名称”，执行命令时将删除当前“规则类型”下的所有策略限制。 |
| SERVICENAME | 服务名称   | 可选必选说明：该参数在“规则类型”配置为“DISABLE_BY_SERVICE(限制服务名称)”时为条件可选参数。 参数含义：跟踪类型，可以通过DSP MTSMODEL命令查询获取。 取值范围：字符串类型，长度为0~512。 默认值：无。 配置原则：一次配置仅支持单个服务。如果不填写“跟踪类型”与“服务名称”，执行命令时将删除当前“规则类型”下的所有策略限制。                                                                                                                                                                                                        |

## 使用实例

1. 删除跟踪类型消息限制：

   ```
   %%RMV MTSPOLICY: MEID=10, POLICYTYPE=DISABLE_BY_TYPE, TRACETYPE=1005;%%
   RETCODE = 0  操作成功
   ---    END
   ```
2. 删除指定服务消息限制：

   ```
   %%RMV MTSPOLICY: MEID=12, POLICYTYPE=DISABLE_BY_SERVICE, SERVICENAME="A";%%
   RETCODE = 0  操作成功
   ---    END
   ```
3. 删除指定跟踪类型下某个服务的消息限制：

   ```
   %%RMV MTSPOLICY: MEID=12, POLICYTYPE=DISABLE_BY_SERVICE, SERVICENAME="A", TRACETYPE=1;%%
   RETCODE = 0  操作成功
   ---    END
   ```
4. 删除指定跟踪类型下全部订阅服务的消息限制：

   ```
   %%RMV MTSPOLICY: MEID=12, POLICYTYPE=DISABLE_BY_SERVICE, TRACETYPE=60904;%%
   RETCODE = 0  操作成功
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，无输出项。

命令执行异常，会返回提示对应的失败信息。错误码列表如表1所示。

|    错误码 | 消息解释          | 原因分析                 | 处理建议         |
|-------:|:--------------|:---------------------|:-------------|
| 101601 | 系统异常          | 服务离线、数据库异常、操作冲突等。    | 请等待几分钟后重试。   |
| 101602 | 网元不存在         | “网元ID”输入非法，与实际环境不一致。 | 修改网元ID后重试。   |
| 101603 | 请求消息错误        | 请求消息错误。              | 请联系华为技术支持处理。 |
| 101604 | 跟踪类型不存在       | 跟踪类型输入非法，与当前模型不一致。   | 更正跟踪类型后重试。   |
| 101606 | 该跟踪类型没有被限制    | 当前跟踪类型没有被限制。         | 无需处理。        |
| 101610 | 该服务没有被限制      | 当前服务没有被限制。           | 无需处理。        |
| 101611 | 该跟踪类型下该服务没有限制 | 对应的跟踪类型下该服务没有限制。     | 无需处理。        |
