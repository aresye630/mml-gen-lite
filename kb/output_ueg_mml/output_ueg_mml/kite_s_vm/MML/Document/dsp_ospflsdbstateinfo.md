# 查询OSPF LSDB的状态信息（DSP OSPFLSDBSTATEINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示OSPF LSDB的状态信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                                                      |
|:------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID      | OSPF进程号       | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                                                                                                    |
| LSATYPE     | LSA类型         | 可选必选说明：可选参数 参数含义：LSA类型。 数据来源：本端规划 取值范围：枚举类型。 Router：Router LSA。Network：Network LSA。Sum_Net：ABR Summary LSA。Sum_Asbr：ASBR Summary LSA。External：AS-External LSA。NSSA：NSSA LSA。Opq_Link：Opaque Link LSA。Opq_Area：Opaque Area LSA。Opq_As：Opaque AS LSA。 默认值：无 |
| LINKSTATEID | LSA报头中的链路状态ID | 可选必选说明：可选参数 参数含义：LSA报头中的链路状态ID。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                                                                                                                                    |

#### 使用实例

显示OSPF进程1下LSDB的状态信息：

```
DSP OSPFLSDBSTATEINFO:PROCID=1;
```

#### 输出结果说明

| 输出项名称          | 输出项解释                                                                                                                                            |
|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| OSPF进程号        | 该参数用于表示OSPF进程号。                                                                                                                                  |
| 区域号            | 该参数用于表示OSPF区域号，当LSA类型为ASE时，AreaID填成0.0.0.0，实际不生效。                                                                                                |
| 路由器标识          | 该参数用于表示OSPF路由器标识。                                                                                                                                |
| LSA类型          | 该参数用于表示LSA类型。                                                                                                                                    |
| LSA报头中的链路状态ID  | 该参数用于表示LSA报头中的链路状态ID，与LSA类型一起描述路由域中唯一一个LSA。                                                                                                      |
| 发布或产生LSA的路由器标识 | 该参数用于表示发布或产生LSA的路由器标识，当配置了共网段接口时，一些LSA的发布路由器标识为共网段接口的虚router-id，建议共网段端设备上，手动配置OSPF进程的实router-id且与接口IP地址不同的，虚router-id优先借用接口IP地址，不会与实router-id冲突。 |
| LSA的老化时间       | 该参数用于表示LSA的老化时间。                                                                                                                                 |
| LSA长度          | 该参数用于表示LSA的长度。                                                                                                                                   |
| LSA选项          | 该参数用于表示LSA选项。                                                                                                                                    |
| LSA序列号         | 该参数用于表示LSA序列号，其他路由器根据这个值可以判断哪个LSA是最新的。                                                                                                           |
| LSA校验和         | 该参数用于表示LSA校验和，除了LSA的老化时间外其它各域的校验和。                                                                                                               |
