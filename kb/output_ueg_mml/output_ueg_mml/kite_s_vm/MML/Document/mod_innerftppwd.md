# 修改内部FTPS账号密码（MOD INNERFTPPWD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，可能会导致网元内部FTPS服务通信故障，请谨慎使用并联系华为技术支持协助操作。

该命令用于修改内部FTPS账号（如：ftpvrpv8\_x，x是VNFC实例的ID）的密码。

#### 注意事项

- 该命令执行后立即生效。
- 执行该操作后，内部FTPS账号的密码将被修改。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                                                                                                                       |
|:----------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USER            | 内部FTPS账号的用户名  | 可选必选说明：必选参数 参数含义：该参数用于指定内部FTPS账号的用户名。 数据来源：本端规划 取值范围：字符串类型，长度为8～32的字符串。 默认值：无                                                                                                                                                                                              |
| PWD             | 内部FTPS账号的密码   | 可选必选说明：必选参数 参数含义：该参数用于指定内部FTPS账号的密码。 数据来源：本端规划 取值范围：密码类型，长度为8～64的字符串。 默认值：无 配置原则： 密码区分大小写。密码必须包含数字、大写字母、小写字母、特殊字符（`~!@#$%^&*()-_+\|[{}]:<.>/）这四类字符集中的两种字符集合的组合，不包括逗号、分号、等号，双引号、单引号，问号和空格。密码中不建议包含如下字符串：“%%”、“+++”。密码不能与操作系统用户名或用户名倒写字符串相同，密码与用户名比较时不区分大小写。采用256位AES算法加密。   |
| CFM             | 内部FTPS账号的确认密码 | 可选必选说明：必选参数 参数含义：该参数用于指定内部FTPS账号的确认密码。 数据来源：本端规划 取值范围：密码类型，长度为8～64的字符串。 默认值：无 配置原则： 密码区分大小写。密码必须包含数字、大写字母、小写字母、特殊字符（`~!@#$%^&*()-_+\|[{}]:<.>/）这四类字符集中的两种字符集合的组合，不包括逗号、分号、等号，双引号、单引号，问号和空格。密码中不建议包含如下字符串：“%%”、“+++”。密码不能与操作系统用户名或用户名倒写字符串相同，密码与用户名比较时不区分大小写。采用256位AES算法加密。 |
| SERVICEINSTANCE | 服务实例          | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                                                                               |

#### 使用实例

修改内部FTPS账号（如：ftpvrpv8\_x，x是VNFC实例的ID）的密码：

```
MOD INNERFTPPWD:USER="ftpvrpv8_x",PWD="*****",CFM="*****",SERVICEINSTANCE="vnfc";
```
