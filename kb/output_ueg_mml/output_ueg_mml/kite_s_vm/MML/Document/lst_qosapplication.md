# 查询流策略（LST QOSAPPLICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询接口上应用流量策略的配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                               |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| DIRECTION  | 报文方向   | 可选必选说明：可选参数 参数含义：该参数用于指定在接口入方向还是出方向应用流量策略。 数据来源：本端规划 取值范围：枚举类型。 inbound：入方向报文。outbound：出方向报文。 默认值：无                |
| IFNAME     | 接口名称   | 可选必选说明：可选参数 参数含义：该参数用于指定应用流量策略的接口，以太主接口/子接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。 |
| POLICYNAME | 策略名称   | 可选必选说明：可选参数 参数含义：该参数用于指定应用的流量策略。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                           |
| LAYER      | 层信息    | 可选必选说明：可选参数 参数含义：该参数用于指定应用的流量策略。 数据来源：本端规划 取值范围：枚举类型。 default：此策略应用在IP层。link_layer：此策略应用在链路层。 默认值：无                |

#### 使用实例

查询应用在接口上的所有流量策略：

```
LST QOSAPPLICATION:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
报文方向  =  入方向
接口名称  =  Ethernet66/0/3
策略名称  =  p1
  层信息  =  默认值
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 报文方向    | 该参数表示入方向和出方向。 |
| 接口名称    | 该参数表示接口名称。    |
| 策略名称    | 该参数表示流策略名称。   |
| 层信息     | 该参数表示流策略层信息。  |
