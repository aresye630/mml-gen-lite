# 删除高级ACL规则（RMV ACLRULEADV4IPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除高级ACL规则，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除高级ACL规则。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                   |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME     | ACL规则组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定规则属于哪个规则组。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是3000～3999。  默认值：无  配置原则：无 |
| ACLRULENAME | 规则名称     | 可选必选说明：必选参数  参数含义：该参数用于指定规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，区分大小写。  默认值：无  配置原则：无                                                                          |

## 使用实例

删除高级ACL规则组3000下的规则名称为"rule\_6"的规则：

```
RMV ACLRULEADV4IPSEC: ACLNAME="3000",ACLRULENAME="rule_6";
```
