# 设置PST广播开关状态（SET FEIPSTSEND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当可能会导致业务故障，请谨慎使用并联系华为技术支持协助操作。

该命令在系统调测的场景，用于设置资源单元PST（Port Status Table）广播开关状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| ISSEND | 发送状态   | 可选必选说明：必选参数 参数含义：该参数用于表示开启或关闭PST广播发送状态。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无            |

#### 使用实例

设置资源单元PST广播开关状态：

```
SET FEIPSTSEND: RUNAME="VNODE_VNRS_VNFC_IPU_0066", ISSEND=FALSE;
RETCODE = 0  操作成功。
```
