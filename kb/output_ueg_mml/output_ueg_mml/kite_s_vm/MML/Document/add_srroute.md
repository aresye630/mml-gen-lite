# 增加IPv4静态路由（ADD SRROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加IPv4静态路由。

静态路由是一种需要管理员手工配置的特殊路由。

当网络结构比较简单时，只需配置静态路由就可以使网络正常工作。当设备不能使用动态路由协议或者不能建立到达目的网络时，也可以使用静态路由。合理的静态路由可以改进网络性能，并为重要业务保证带宽。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100000。
- 添加该静态路由时，要保证该路由未添加过。
- 不能在VPN实例\_\_mpp\_vpn\_inner\_\_和\_\_mpp\_vpn\_inner\_server\_\_下添加默认静态路由。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                 |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AFTYPE      | 地址族       | 可选必选说明：必选参数 参数含义：该参数用来指定VPN实例的地址族信息。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                                                                                                  |
| PREFIX      | 路由前缀      | 可选必选说明：必选参数 参数含义：该参数用来指定前缀信息。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                                                                                                         |
| MASKLENGTH  | 路由掩码长度    | 可选必选说明：必选参数 参数含义：该参数用来指定掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无                                                                                                                                   |
| VRFNAME     | VPN实例名称   | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则： 不配置时默认为_public_。_public_表示公网。通过LST L3VPNINST查看当前已存在的VPN实例。                                                    |
| DESTVRFNAME | 下一跳VPN名字  | 可选必选说明：可选参数 参数含义：该参数用来指定路由的下一跳所属VPN实例的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：该参数不输入的情况下，如果没有配置出接口，参数值默认和VRFNAME一致；如果配置了出接口，参数值默认和出接口所属VPN一致。                                               |
| IFNAME      | 路由出接口名字   | 可选必选说明：可选参数 参数含义：该参数用来指定路由的出接口名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 不配置时默认为Invalid0，不区分大小写。请使用LST INTERFACE命令查看可用接口。                                                                     |
| NEXTHOP     | 路由下一跳     | 可选必选说明：可选参数 参数含义：该参数用来指定下一跳IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：如果接口类型为广播接口类型，NEXTHOP必须要输入；如果接口类型为非广播接口类型，NEXTHOP可以不输入。                                                                         |
| PREFERENCE  | 路由优先级     | 可选必选说明：可选参数 参数含义：该参数用来指定路由优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：60 配置原则： 不配置时默认为60。优先级值越小优先级越高，优先级值越大优先级越低。                                                                                       |
| BFDENABLE   | 动态BFD使能标识 | 可选必选说明：可选参数 参数含义：动态BFD使能标识。为静态路由绑定动态BFD会话。通过动态BFD会话检测链路状态，为静态路由提供检测机制，可以快速感知链路变化，提高网络可靠性。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE 配置原则：必须通过ADD SRBFDTEMPLET配置了相应的动态BFD模板，默认为FALSE。       |
| SESSIONNAME | 静态BFD会话名  | 可选必选说明：可选参数 参数含义：该参数用来指定静态路由所联动的静态BFD的会话名。为静态路由绑定静态BFD会话。通过静态BFD会话检测链路状态，为静态路由提供检测机制，可以快速感知链路变化，提高网络可靠性。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。 默认值：无 配置原则：必须通过ADD BFDSESSION建立了联动的BFD，与动态BFD是互斥的，不区分大小写。 |
| TAG         | 路由Tag值    | 可选必选说明：可选参数 参数含义：该参数用于表示路由的tag属性值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：0 配置原则：不配置时默认为0。                                                                                                       |
| DESCRIPTION | 路由描述      | 可选必选说明：可选参数 参数含义：该参数用来指定路由的描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～35。 默认值：无                                                                                                                             |
| DHCPENABLE  | DHCP使能标识  | 可选必选说明：可选参数 参数含义：该参数用于指定DHCP使能标志。 数据来源：本端规划 取值范围：枚举类型。 FALSE：否。TRUE：是。 默认值：FALSE 配置原则：通过ADD DHCPCLIENT将接口下DHCP使能，静态路由联动DHCP才能生效。                                                                     |

#### 使用实例

添加一条目的地址为10.0.0.1，掩码为32，出接口是NULL0口的公网IPv4静态路由：

```
ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="10.0.0.1",MASKLENGTH=32,VRFNAME="_public_",DESTVRFNAME="_public_",IFNAME="NULL0";
```
