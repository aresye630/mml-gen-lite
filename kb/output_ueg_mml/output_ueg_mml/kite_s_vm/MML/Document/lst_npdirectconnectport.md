# 查询多框级联配置（LST NPDIRECTCONNECTPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

查询多框级联配置。

## 注意事项

该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询多框级联配置：

```
LST NPDIRECTCONNECTPORT:;
RETCODE = 0  操作成功

结果如下
--------
框号  槽位号  端口号  

0     1       P1      
1     1       P1      
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| 框号      | 该参数用于表示多框级联配置的框号。  |
| 槽位号     | 该参数用于表示多框级联配置的槽位号。 |
| 端口号     | 该参数用于表示多框级联配置的端口号。 |
