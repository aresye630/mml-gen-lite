# 修改网关转发地址（MOD PAEPORTGATEWAY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

内联口网关IP配置错误，或者网关MAC地址学习失败，将会导致内联口报文无法跨子网通信，业务会出现呼损，同时会产生告警“ALM-100338 Fabric平面状态为Down”。请联系华为技术支持协助操作。

该命令用于修改指定网段索引下的内联口的网关地址信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                       |
|:--------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| NETWORKINDEX  | 网段索引     | 可选必选说明：必选参数  参数含义：该参数用于指定网段索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：无                                                                     |
| PLANEID       | 平面ID     | 可选必选说明：必选参数  参数含义：该参数用于指定平面ID。可以通过DSP PAEPORTGROUPINFO指令查询。  数据来源：全网规划  取值范围：整数类型，取值范围是0~1，3~6。  默认值：无  配置原则：无                                             |
| IPVERSION     | IP地址类型   | 可选必选说明：必选参数  参数含义：该参数用于指定IP地址的类型。  数据来源：全网规划 取值范围： IPv4（IPv4）IPv6（IPv6）  默认值：无  配置原则：  参考当前环境使用的IP类型。                                                      |
| GATEWAYIPV4   | 网关IPv4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定网关IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  网关地址必须与平面内的端口IP地址同网段。可通过DSP PAEPORTINFO命令查看。     |
| IPV4MASK      | IPv4地址掩码 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定网关IPv4地址的网络掩码。  数据来源：本端规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.254。  默认值：无  配置原则：  使用网络规划的接口IP所属网段的掩码。 |
| GATEWAYIPV6   | 网关IPv6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定网关IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  网关地址必须与平面内的端口IP同网段。可以通过DSP PAEPORTINFO命令查看。      |
| IPV6PREFIXLEN | IPv6地址前缀 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定网关IPv6地址前缀。  数据来源：本端规划  取值范围：整数类型，取值范围是1~127。  默认值：无  配置原则：无                                         |
| DESC          | 描述       | 可选必选说明：可选参数  参数含义：该参数用于描述逻辑IP地址的其他信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                  |

## 使用实例

修改网段索引为1，平面ID为0的内联口的IPv4网关地址为192.168.1.1，且该网关地址的掩码为255.255.0.0：

```
MOD PAEPORTGATEWAY: NETWORKINDEX=1, PLANEID=0, IPVERSION=IPv4, GATEWAYIPV4="192.168.1.1", IPV4MASK="255.255.0.0";
```
