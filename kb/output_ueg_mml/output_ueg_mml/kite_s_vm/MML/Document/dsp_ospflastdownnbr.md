# 查询OSPF上次Down的邻居（DSP OSPFLASTDOWNNBR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示OSPF断开的邻居信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| PROCID | 进程号    | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

显示设备OSPF进程号为1的所有断开的路由信息：

```
DSP OSPFLASTDOWNNBR: PROCID=1;
```

#### 输出结果说明

| 输出项名称       | 输出项解释              |
|:------------|:-------------------|
| 进程号         | 该参数指定用户创建的OSPF进程号。 |
| 路由器标识       | 该参数指定本地路由器标识。      |
| 邻居区域标识      | 该参数指定邻居所在的区域标识。    |
| 接口名         | 该参数指定本端建立邻居的接口名称。  |
| 邻居IP地址      | 该参数指定邻居IP地址。       |
| 邻居路由器标识     | 该参数指定邻居路由器标识。      |
| 邻居Down的直接原因 | 该参数指定邻居Down的直接原因。  |
| 邻居Down的次要原因 | 该参数指定邻居Down的次要原因。  |
| 邻居Down的时间   | 该参数指定邻居Down的时间点。   |
