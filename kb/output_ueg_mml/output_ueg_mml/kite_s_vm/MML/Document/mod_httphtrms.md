# 修改HTR流控安全边界配置（MOD HTTPHTRMS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改HTR流控安全边界配置。

## 注意事项

- 未处于HTR过载状态的局向立即生效。

- 已经处于HTR过载状态的局向仍按照修改前安全边界值生效，解控后重新起控按照修改后安全边界值生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改本端网元类型为NFTypeAMF，对端网元类型为NFTypeUDM配置HTR流控安全边界，最小流控速率修改为210（个/秒），可以用如下命令：

```
MOD HTTPHTRMS: LOCALNFTYPE=NFTypeAMF, PEERNFTYPE=NFTypeUDM, MINTHD=210;
```
