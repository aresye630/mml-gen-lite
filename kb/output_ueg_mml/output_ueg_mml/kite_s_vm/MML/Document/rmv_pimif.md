# 删除PIM接口配置（RMV PIMIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除接口下PIM相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，不携带可选参数的作用是删除配置。
- 执行该命令时，携带可选参数的作用是恢复指定参数为默认值。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

PIM接口删除配置：

```
RMV PIMIF:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,IFNAME="Ethernet64/0/3";
```
