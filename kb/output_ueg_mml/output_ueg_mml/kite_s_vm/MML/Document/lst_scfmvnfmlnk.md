# 查询超时时间配置（LST SCFMVNFMLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询VNFM-VNF之间同步消息超时时间配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

LST SCFMVNFMLNK

```
%%LST SCFMVNFMLNK:;%%
RETCODE = 0  操作成功

结果如下
------------------------
同步消息超时时间  =  180
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                         |
|:---------|:------------------------------|
| 同步消息超时时间 | 该参数用于表示VNFM-VNF之间同步消息的最大等候时间。 |
