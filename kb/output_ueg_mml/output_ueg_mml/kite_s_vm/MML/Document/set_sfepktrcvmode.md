# 配置SFE收包模式（SET SFEPKTRCVMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来配置SFE收包模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                   |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| MODE   | SFE收包模式 | 可选必选说明：必选参数 参数含义：该参数用于表示SFE收包模式信息。 数据来源：本端规划 取值范围：枚举类型。 ABSOLUTE_PRIORITY：绝对优先级收包模式。RELATIVE_PRIORITY：相对优先级收包模式。 默认值：无 |

#### 使用实例

配置SFE收包模式为相对优先级：

```
SET SFEPKTRCVMODE:MODE=RELATIVE_PRIORITY;
```
