# 查询业务服务ID与隧道组ID的关系（DSP LBTNBINDPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询对端异地容灾实例的服务和隧道组关系，通过查询结果判断隧道组的绑定策略是否已经下发给CSLB，辅助定位隧道转发失败问题。

#### 注意事项

该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                |
|:---------|:-----------|:------------------------------------------------------------------------------------|
| GRINSTID | 对端异地容灾实例ID | 可选必选说明：可选参数 参数含义：对端异地容灾实例ID。 数据来源：对端协商 取值范围：整数类型，取值范围为0~4294967295。 默认值：无           |
| SRVID    | 服务ID       | 可选必选说明：可选参数 参数含义：该参数用于指定对端异地容灾实例的服务ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 |

#### 使用实例

查询指定对端异地容灾实例的服务和隧道组的关系。

`DSP LBTNBINDPLY: GRINSTID=4;`

```
%%DSP LBTNBINDPLY: GRINSTID=4;%%
RETCODE = 0  操作成功。

操作结果如下：
-------------------------
对端异地容灾实例ID 服务ID  隧道组ID 
4                  0       0 
4                  1       1 
(结果个数 = 2)
--- END
```

| 输出项名称      | 输出项解释                                         |
|:-----------|:----------------------------------------------|

| 服务ID       | 参数含义：服务标识。 取值范围：整数类型，取值范围为0~4294967295。       |
