# 查询扩缩容开关（LST SCALINGSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询扩缩容开关参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

LST SCALINGSWITCH:;

```
%%LST SCALINGSWITCH:;%%
RETCODE = 0  操作成功 
结果如下 
-------- 
扩缩容开关 = MANO触发的扩缩容
  监控周期 = 50
  取样间隔 = 2
  时间单位 = Sec
(结果个数 = 1) 
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                 |
|:--------|:----------------------------------------------------------------------------------------------------------------------|
| 扩缩容开关   | 该参数用于表示扩缩容的触发方式，值为VNF表示VNF触发的自动扩缩容，值为VNFM表示MANO触发的扩缩容，值为OFF表示弹性开关关闭。值为DISABLE_AUTO表示关闭MANO触发的自动扩缩容， 但仍支持MANO触发的手工扩缩容。 |
| 监控周期    | 该参数用于表示监控周期。在监控周期内，每一个采样周期均获取一次当前的系统负载，将其与扩容水线阈值和缩容水线阈值进行比较。 若在一个监控周期内的每个采样间隔里，系统负载均超过了扩容水线阈值，或均低于缩容水线阈值，则触发扩容或缩容动作。  |
| 取样间隔    | 该参数用于表示取样间隔。在监控周期内，每一个采样周期均获取一次当前的系统负载，将其与扩容水线阈值和缩容水线阈值进行比较。 若在一个监控周期内的每个采样间隔里，系统负载均超过了扩容水线阈值，或均低于缩容水线阈值，则触发扩容或缩容动作。  |
| 时间单位    | 该参数用于表示取样间隔的时间单位。                                                                                                     |
