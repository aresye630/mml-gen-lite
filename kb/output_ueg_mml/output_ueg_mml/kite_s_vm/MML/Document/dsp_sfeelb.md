# 显示ELB表项（DSP SFEELB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ELB表项。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------|
| MGID     | 组播组ID  | 可选必选说明：必选参数 参数含义：该参数表示组播叶子ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                    |
| SEQNUM   | 序号     | 可选必选说明：必选参数 参数含义：该参数表示叶子序号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                           |
| WORKMODE | 工作模式   | 可选必选说明：必选参数 参数含义：该参数表示工作模式；0为主，1为备。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1。 默认值：无                                       |
| RUNAME   | RU名称   | 可选必选说明：必选参数 参数含义：该参数表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

显示指定资源单元、指定组播组ID、序列号、主备模式的ELB表项：

```
DSP SFEELB:MGID=100,SEQNUM=1024,WORKMODE=1,RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```

