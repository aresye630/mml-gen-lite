# 查询NP表项简要信息（DSP NPTABSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询指定RU上NP表项的简要信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。
- Tunnel-IPV4、Tunnel-IPV6资源仅包含GRE资源，不包括IPSEC资源。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| RUID   | RU编号   | 可选必选说明：必选参数。 参数含义：RU编号。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967294。 默认值：无。 配置原则：使用DSP RU命令查询RU编号。 |

`DSP NPTABSTAT: RUID=68;`

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 表名称     | 资源表名称。       |
| 表索引     | 资源表索引。       |
| 子表索引    | 资源表子表索引。     |
| 资源总数    | 资源表可以存储的总数。  |
| 已分配资源   | 当前资源表存储的资源数。 |
