# 查询Pod Fabric平面亚健康诊断参数（LST FABDIAGPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用来显示Pod Fabric平面亚健康诊断参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示Pod Fabric平面亚健康诊断参数

```
%%LST FABDIAGPARA:;%%
RETCODE = 0  操作成功

结果如下
--------
POD亚健康阈值 = 50
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                            |
|:------------|:---------------------------------|
| POD亚健康阈值(%) | 该参数用于指定Pod级fabric平面亚健康诊断阈值，单位：%。 |
