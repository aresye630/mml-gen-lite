# 查询MML服务连接信息（LST MMLLINKINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询MMLService直连通道的连接信息。

## 注意事项

无

## 参数说明

无。

## 使用实例

查询MMLService连接信息：

```
%%LST MMLLINKINFO:;%%
RETCODE = 0  操作成功  

操作结果如下 
------------ 
        连接端口号  =  9000 
        并发连接数  =  16
连接超时时间（分）  =  5
(结果个数 = 1) 
 
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出项如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称     | 输出项解释                   |
|:----------|:------------------------|
| 连接端口号     | 第三方工具或网管与MML建立连接时的端口号。  |
| 并发连接数     | 同时支持第三方工具或网管与MML键链的个数。  |
| 连接超时时间（分） | 第三方工具或网管与MML建立连接后的超时时间。 |

|    错误码 | 错误码解释          | 原因分析                      | 处理建议       |
|-------:|:---------------|:--------------------------|:-----------|
| 100000 | 内部错误           | MMLService内部处理异常。         | 请联系华为技术支持。 |
| 100066 | 查询MML服务连接端口号失败 | MMLService连接端口号查询接口，调用失败。 | 请联系华为技术支持。 |
