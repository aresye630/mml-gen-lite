# 修改对端NF服务实例信息（MOD UPPNFSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改本地配置的对端NF实例支持的服务实例信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID    | NF实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定NF实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是0~50。NFINSTANCEID参数建议满足以下约束规则： 1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。 2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：10.107.65.183、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：本参数取值与ADD UPPNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。                           |
| SRVINSTANCEID   | 服务实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定服务实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是0~50。大小写不敏感。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                      |
| SERVICENAME     | 服务名称   | 可选必选说明：可选参数 参数含义：该参数用于指定服务名称。 数据来源：全网规划 取值范围： NudmSdm：UDM提供的Nudm_SDM服务。NudmUecm：UDM提供的Nudm_UEContextManagement服务。NamfComm：AMF提供的Namf_Communication Service服务。NamfLoc：AMF提供的Namf_Location服务。NlmfLoc：LMF提供的Nlmf_Location服务。 默认值：无 配置原则：无                                                                                                                                                                     |
| SCHEMA          | 协议模式   | 可选必选说明：可选参数 参数含义：该参数用于指定协议模式。 数据来源：全网规划 取值范围： NULL：NULL。http：http。https：https。 默认值：无 配置原则：本端和对端要配置保持一致，如不一致，会导致HTTP的链路建立失败。                                                                                                                                                                                                                                                                                |
| NFSERVICESTATUS | 服务实例状态 | 可选必选说明：可选参数 参数含义：该参数用于指定服务实例状态。 数据来源：全网规划 取值范围： Invalid：表示当前NF实例处于无效态，如果配置成该值，NF选择时不会选择此类NF。Registered：表示当前NF实例处于注册态，如果配置成该值，NF选择时只会选择此类NF。Suspended：表示当前NF实例处于挂起态。当NF实例处于运维状态下，比如正在进行用户迁移等，不希望在NF发现流程中被选中时，可以置为此状态，迁移完毕后通过该命令对应的MOD命令修改为注册态即可。UnDiscoverable：表示当前NF实例处于不可被发现状态，如果配置成该值，NF选择时不会选择此类NF。DeRegistered：表示当前NF实例处于去注册态，如果配置成该值，NF选择时不会选择此类NF。 默认值：无 配置原则：建议配置成Registered，如果配置成其它状态NF服务发现时不会被选中。 |
| PRIORITY        | 优先级    | 可选必选说明：可选参数 参数含义：本参数用于指定服务实例的优先级（与其他同类型NF实例的NFS相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越小优先级越高。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                |
| CAPACITY        | 容量     | 可选必选说明：可选参数 参数含义：本参数用于指定NFS的相对权重（与其他同类型NF实例的NFS相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越大表示容量越大。 默认值：100。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                      |
| LOAD            | 负载     | 可选必选说明：可选参数 参数含义：本参数用于指定NFS的负载。系统可能会将此参数作为NF选择的依据。 数据来源：全网规划 取值范围：整数类型，取值范围是0~100。值越大表示负载越大。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                  |

#### 使用实例

修改对端NF的服务实例信息，NF实例标识为LMF\_Instance\_0，服务实例标识为Service\_Instance\_0，服务名为NlmfLoc，支持的协议为http：

```
MOD UPPNFSERVICE: NFINSTANCEID="LMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NlmfLoc, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
```
