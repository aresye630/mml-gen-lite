# 查询AS路径过滤节点（LST ASPATHFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询一个AS路径过滤器表项。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                         |
|:-------|:------------|:-----------------------------------------------------------------------------|
| NAME   | AS路径过滤器名字或号 | 可选必选说明：可选参数 参数含义：该参数用于指定AS路径过滤器名字或号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～51。 默认值：无 |

#### 使用实例

查询AS路径过滤器：

```
LST ASPATHFILTERNODE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
AS路径过滤器名字或号  =  a
  AS路径过滤器节点号  =  10
            匹配模式  =  允许
          正则表达式  =  [1-9]
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释            |
|:------------|:-----------------|
| AS路径过滤器名字或号 | 用于指定AS路径过滤器名字或号。 |

其余输出项请参见ADD ASPATHFILTERNODE的参数说明。
