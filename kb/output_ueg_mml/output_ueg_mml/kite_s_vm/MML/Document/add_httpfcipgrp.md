# 增加HTTP流控组（ADD HTTPFCIPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加HTTP固定速率流控的IP地址组信息。出于可靠性目的，NF的服务化接口一般会通过多个HTTP链路和周边NF进行交互，每条链路会有自己的IP地址，在流控场景下，可以通过将多条链路绑定在一起（即流控组），系统对流控组执行统一的流控策略（如流控门限等）。

## 注意事项

- 该命令执行后立即生效。

- 添加该命令后通过执行**ADD HTTPFIXEDFC**命令设置对应的门限值。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX    | IP地址索引 | 可选必选说明：必选参数  参数含义：该参数用于标识具有相同前缀的一组IP地址。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                                                                                                                                                                                                                                      |
| GROUP    | 流控组    | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP固定速率流控组的唯一标识。一个流控组中可以包括多个IP地址索引。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                                                                                                                                                                                                                |
| IPTYPE   | IP地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指定输入的IP地址类型。  数据来源：全网规划 取值范围： “IPv4（IPv4）”：IPv4地址“IPv6（ IPv6）”：IPv6地址  默认值：无  配置原则：无                                                                                                                                                                                                                                    |
| IPV4ADDR | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定HTTP固定速率流控组内一个或一组IPv4地址。本端发送请求时，使用对端IP与此参数值（一个或一组IPv4地址）进行匹配，成功则进行固定速率流控。本端接收请求时，优先使用本端IP与此参数值进行匹配，成功则进行固定速率流控，失败则再使用对端IP与此参数值进行匹配。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。  IPv4地址不能为组播地址（如：224.x.y.z）和环回地址（如：127.x.y.z）。  IPv4地址必须是A、B或者C类地址。 |
| IPV4MASK | IPv4掩码 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定流控IPv4地址的掩码。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                                                                                                                                 |
| IPV6ADDR | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定HTTP固定速率流控组内一个或一组IPv6地址。本端发送请求时，使用对端IP与此参数值（一个或一组IPv6地址）进行匹配，成功则进行固定速率流控。本端接收请求时，优先使用本端IP与此参数值进行匹配，成功则进行固定速率流控，失败则再使用对端IP与此参数值进行匹配。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。     |
| IPV6MASK | IPv6前缀 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定流控IPv6地址的前缀。  数据来源：全网规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：  0是无效的掩码。                                                                                                                                                                                                                      |
| DESC     | 描述     | 可选必选说明：可选参数  参数含义：该参数用于填写HTTP固定速率流控地址组的描述信息，建议包含NF类型，实例名等，例如UDM_UDM001。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                    |

## 使用实例

在重大节日期间，为避免大量用户同时发起5G业务流程导致系统拥塞，需要在AMF侧对AMF和SMF间的消息进行流控。可以将AMF和SMF间的链路添加到一个流控组。假设AMF和SMF间HTTP链路IP地址为一个IPv4的地址段（IPv4：192.168.4.15，掩码：255.255.255.0），IP地址索引为1，流控组为1。AMF发送消息流控门限设为500， 接收消息流控门限为600。配置如下：

```
ADD HTTPFCIPGRP: INDEX=1, GROUP=1, IPTYPE=IPv4, IPV4ADDR="192.168.4.15", IPV4MASK="255.255.255.0";
ADD HTTPFIXEDFC: GROUP=1, SENDTHD=500, RECVTHD=600, STATUSCODE=ServiceUnavailable;
```
