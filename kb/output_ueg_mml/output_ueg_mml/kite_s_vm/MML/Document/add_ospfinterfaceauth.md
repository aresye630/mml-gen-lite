# 创建OSPF接口认证配置（ADD OSPFINTERFACEAUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建OSPF接口认证配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 创建OSPF接口认证，请确保和邻居认证配置相同，否则会导致邻接关系中断，影响业务。
- 只有执行ADD OSPFINTERFACE配置了OSPF接口后才能使用此命令。
- 区域验证方式的优先级低于接口验证方式的优先级。
- 当前支持配置的认证算法及密码长度均符合IETF标准规定。
- 如果配置的认证算法是Simple，MD5或者HMAC-MD5，则有安全隐患，推荐使用HMAC-SHA256算法。
- 配置的密码至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于8。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                        | 参数说明                                                                                                                                                                                                                                       |
|:---------------|:----------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID         | OSPF进程号                     | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。                                                                                                                                                  |
| AREAID         | 区域号                         | 可选必选说明：必选参数 参数含义：区域号。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                                                                                                                               |
| IFNAME         | 接口名                         | 可选必选说明：必选参数 参数含义：接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST OSPFINTERFACE命令查看可用OSPF接口。                                                                                                                                        |
| AUTHENMODE     | 认证模式                        | 可选必选说明：必选参数 参数含义：认证模式。 数据来源：本端规划 取值范围：枚举类型。 keychain：Keychain认证模式。hmac-sha256：HMAC-SHA256密文验证模式。null：Null验证模式。simple：简单验证模式。md5：MD5密文验证模式。hmac-md5：HMAC-MD5密文验证模式。 默认值：无 配置原则：Simple、MD5或HMAC-MD5为不安全认证算法，推荐使用HMAC-SHA256。                 |
| AUTHTEXTTYPE   | 密文口令类型                      | 可选必选说明：条件可选参数 前提条件：该参数在“AUTHENMODE”配置为“hmac-sha256”、“simple”、“md5” 或 “hmac-md5”时为可选参数。 参数含义：认证密码类型。 数据来源：本端规划 取值范围：枚举类型。 cipher：密文类型。 默认值：cipher 配置原则：cipher类型可以键入简单口令或密文口令，但在查看配置文件时均以密文方式显示口令。                                           |
| AUTHTEXTSIMPLE | 简单认证密码                      | 可选必选说明：条件可选参数 前提条件：该参数在“AUTHENMODE”配置为“simple”时为可选参数。 参数含义：简单认证密码。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～8。 默认值：无 配置原则： 字符不允许包括“？”和空格。配置密码时，使用明文格式，长度范围为1~8。配置的密码建议至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于8。                                                 |
| AUTHTEXTMD5    | MD5/HMAC-MD5/HMAC-SHA256 密码 | 可选必选说明：条件可选参数 前提条件：该参数在“AUTHENMODE”配置为“hmac-sha256”、“md5” 或 “hmac-md5”时为可选参数。 参数含义：MD5/HMAC-MD5/HMAC-SHA256密码。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～255。 默认值：无 配置原则： 字符不允许包括“？”和空格。配置密码时，使用明文格式，长度范围为1~255。配置的密码建议至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于8。 |
| KEYID          | 密文验证字标识符                    | 可选必选说明：条件可选参数 前提条件：该参数在“AUTHENMODE”配置为“hmac-sha256”、“md5” 或 “hmac-md5”时为可选参数。 参数含义：密文验证字标识符。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无 配置原则： 密文验证字标识符和加密认证密码必须同时配置。KeyID需要跟对端保持一致。如果不输入该参数，则表示密文验证字标识符不参与认证加密。                                 |
| KEYCHAINNAME   | KeyChain名称                  | 可选必选说明：条件必选参数 前提条件：该参数在“AUTHENMODE”配置为“keychain”时为必选参数。 参数含义：KeyChain名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则： 不区分大小写，并且字符不允许包括“？”和空格。Keychain需要在Keychain模块已经配置。Keychain可以使用的安全认证算法有sha-256及hmac-sha-256。                          |

#### 使用实例

在接口Ethernet64/0/4配置OSPF keychain认证模式：

```
ADD OSPFINTERFACEAUTH:PROCID=1,AREAID="0.0.0.0",IFNAME="Ethernet64/0/4",AUTHENMODE=keychain,KEYCHAINNAME="KcName1";
```
