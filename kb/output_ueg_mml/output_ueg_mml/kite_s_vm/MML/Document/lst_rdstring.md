# 查询RD字符（LST RDSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询RD属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                               |
|:-------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | RD过滤器索引  | 可选必选说明：可选参数 参数含义：该参数用于指定RD过滤器索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1024。 默认值：无                                                                                                                                            |
| NODESEQUENCE | RD过滤器节点号 | 可选必选说明：可选参数 参数含义：该参数用于指定RD过滤器节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                                                     |
| STRINGVALUE  | 字符值      | 可选必选说明：可选参数 参数含义：该参数用于指定RD属性值，支持如下4种格式： 1. IPv4地址:nn，如10.1.1.1:200。 2. aa:nn，如100:1。 3. IPv4地址:*，通配格式。如10.1.1.1:*表示匹配所有以10.1.1.1开头的RD。 4. aa:*，通配格式。如100:*表示匹配所有以100开头的RD。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～21。 默认值：无 |

#### 使用实例

查询RD属性：

```
LST RDSTRING:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
  RD过滤器索引  =  55
RD过滤器节点号  =  10
        字符值  =  1:1
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释         |
|:---------|:--------------|
| RD过滤器索引  | 用于指定RD过滤器索引。  |
| RD过滤器节点号 | 用于指定RD过滤器节点号。 |

其余输出项请参见ADD RDSTRING的参数说明。
