# 显示FABRIC内联口亚健康信息（DSP FABRICSUBHEALTHY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示Fabric平面亚健康信息。

#### 注意事项

- 该命令执行后立即生效。
- 此命令显示两个资源之间的链路亚健康信息，Bonding模式不支持基于链路的亚健康统计，在Bonding模式下此命令无回显结果。可以使用**DSP PAEPORTINFO**命令查看是否Bonding模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |
| REMOTERETB   | 远端节点TB | 可选必选说明：可选参数 参数含义：该参数用于指定远端节点的资源ID。 数据来源：本端规划 取值范围：整数类型，0~4294967295。 默认值：无                                                                                              |

#### 使用实例

- 显示微服务类型为“aa”微服务实例为“aa”的亚健康信息：

  ```
  DSP FABRICSUBHEALTHY:CELLTYPE="aa", CELLINSTANCE="aa";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
  本端节点TB  远端节点TB   本端端口名称   远端端口名称     是否亚健康    丢包率（‰）    错包率（‰）    亚健康值 

  1035         1034             eth1           eth1             FALSE         0               0               0   
  1035         1034             eth2           eth2             FALSE         0               0               0
  (结果个数 = 2)
  ---    END
  ```
- 显示微服务类型为“aa”微服务实例为“aa”到远端资源“1034”的亚健康信息：

  ```
  DSP FABRICSUBHEALTHY:CELLTYPE="aa", CELLINSTANCE="aa",REMOTERETB=1034;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
  本端节点TB  远端节点TB   本端端口名称   远端端口名称     是否亚健康    丢包率（‰）    错包率（‰）    亚健康值 

  1035         1034             eth1           eth1             FALSE         0               0               0   
  1035         1034             eth2           eth2             FALSE         0               0               0
  (结果个数 = 2)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                         |
|:--------|:------------------------------|
| 本端节点TB  | 用于指定本端的端点资源ID。                |
| 远端节点TB  | 用于指定远端的端点资源ID。                |
| 本端端口名称  | 用于指定本端端口名称。                   |
| 远端端口名称  | 用于指定远端端口名称。                   |
| 是否亚健康   | 该链路是否亚健康。                     |
| 丢包率（‰）  | 显示链路的丢包率，千分比形式。               |
| 错包率（‰）  | 显示链路的错包率，千分比形式。               |
| 亚健康值    | 显示链路的亚健康值，取值范围{0~4294967295}。 |
