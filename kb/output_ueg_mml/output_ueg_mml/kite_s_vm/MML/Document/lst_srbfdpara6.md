# 查询IPv6 BFD模板（LST SRBFDPARA6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询IPv6 BFD模板。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                          |
|:------------|:--------|:------------------------------------------------------------------------------|
| AFTYPE      | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv6unicast：IPv6单播。 默认值：无 |
| DESTVRFNAME | 网关地址VPN | 可选必选说明：可选参数 参数含义：该参数用于指定网关地址所属VPN。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无    |

#### 使用实例

查询IPv6 BFD模板：

```
LST SRBFDPARA6:AFTYPE=ipv6unicast;
```
