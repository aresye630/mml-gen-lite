# 创建OSPFv3 接口的安全联盟SA（ADD OSPFV3IFIPSECSA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建OSPFv3 接口的安全联盟SA。

#### 注意事项

该命令最大记录数为8000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                  |
|:-------|:-----------|:----------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名        | 可选必选说明：必选参数 参数含义：接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST OSPFV3INTERFACE命令查看可用OSPFv3接口。               |
| SANAME | IPsec SA名称 | 可选必选说明：必选参数 参数含义：IPsec SA的名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则： IPsec SA必须已经存在。不能直接修改，需要先删除再配置。不能和认证同时配置。 |

#### 使用实例

创建OSPFv3 接口的安全联盟SA：

```
ADD OSPFV3IFIPSECSA:IFNAME="Ethernet64/0/3",SANAME="sa1";
```
