# 增加OM转发路由 (ADD OMFWDRT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

此命令用于增加外部访问内部指定服务的OM转发路由。

#### 注意事项

该命令仅限角色为Administrators的用户执行。

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                      |
|:------------|:-------|:----------------------------------------------------------|
| MEID        | 网元ID   | 可选必选说明：必选参数 参数含义：网元ID（用来标识网元） 取值范围：0~65535 默认值：无 配置原则：无   |
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：管道服务名称 取值范围：OMG 默认值：OMG 配置原则：无           |
| PORT        | 端口     | 可选必选说明：必选参数 参数含义：OMLB外出网络端口 取值范围：17100~17199 默认值：无 配置原则：无 |
| BACKENDPORT | 后端端口   | 可选必选说明：必选参数 参数含义：转发目标服务端口 取值范围：22，2022 默认值：2022 配置原则：无    |

#### 使用实例

增加新的OM转发路由：

```
%%ADD OMFWDRT: MEID=0, SERVICENAME="OMG", PORT=17100, BACKENDPORT=22;%%
RETCODE = 0  操作成功

---    END
```
