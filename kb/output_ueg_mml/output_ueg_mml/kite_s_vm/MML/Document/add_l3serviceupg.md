# 增加服务升级进度（ADD L3SERVICEUPG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

灰度升级中，执行此命令，用于添加新的服务升级进度。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入100000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                            |
|:----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------|
| L3SERVICE | L3Service | 可选必选说明：必选参数  参数含义：该参数用于标识一个微服务。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                             |
| POSITION  | Position  | 可选必选说明：必选参数  参数含义：该参数用于标识位于哪一层。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                            |
| MODE      | Mode      | 可选必选说明：必选参数  参数含义：该参数用于标识模式。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                               |
| STATUS    | Status    | 可选必选说明：必选参数  参数含义：该参数用于标识状态。  数据来源：本端规划 取值范围： PreUpgrade（PreUpgrade）InUpgrade（InUpgrade）PostUpgrade（PostUpgrade）  默认值：无  配置原则：无 |
| PROGRESS  | Progress  | 可选必选说明：必选参数  参数含义：该参数用于标识进度。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100。  默认值：无  配置原则：无                                                   |

## 使用实例

为服务AM增加新的升级进度：

```
%%ADD L3SERVICEUPG: L3SERVICE="AM", POSITION="Service", MODE="Gray", STATUS=PreUpgrade, PROGRESS=0;%%
RETCODE = 0  操作成功

---    END
```
