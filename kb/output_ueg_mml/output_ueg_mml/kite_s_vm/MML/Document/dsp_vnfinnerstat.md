# 显示网元内部状态（DSP VNFINNERSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网元的内部状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

当运营商需要对网元进行操作（如升级、补丁等）时，可以使用该命令查询网元内部状态，提前识别风险。

```
%%DSP VNFINNERSTAT:;%%
RETCODE = 0  操作成功

结果如下
--------
分类      状态  备注  

POD状态   正常  NULL  
服务状态  正常  NULL  
规格状态  正常  NULL  
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                              |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 分类      | 状态分类。 取值说明： “PODSTAT（POD状态）”：代表网元内的POD状态，由SCF感知到的POD内容器状态、心跳监测等状态汇集。“SRVSTAT（服务状态）”：代表网元内服务平面上的服务状态。“SPECSTAT（规格状态）”：代表网元规格是否处于稳态。 |
| 状态      | 状态。 取值说明： “Normal（正常）”：状态正常“Abnormal（异常）”：状态异常                                                                                     |
| 备注      | 备注说明。                                                                                                                              |
