# 显示LDP会话管理模块的下游信息（DSP LDPSSMGDSCB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示LDP会话管理模块的下游信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                            |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_                                 |
| FECFLAG      | 目的地址标志位    | 可选必选说明：可选参数 参数含义：该参数用于表示LSP的目的地址标志位。 数据来源：本端规划 取值范围：枚举类型。 FECADDR：指定目的地址。 默认值：无                                 |
| FECADDR      | 目的地址       | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“FECADDR”时为必选参数。 参数含义：该参数用于指定LSP的目的地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无        |
| PREFIXLENGTH | 前缀长度       | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“FECADDR”时为必选参数。 参数含义：该参数用于指定目的地址的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 |
| PEERID       | 对等体的LSR ID | 可选必选说明：可选参数 参数含义：该参数用于指定对等体的LSR ID。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                              |

#### 使用实例

显示LDP会话管理模块的下游信息：

```
DSP LDPSSMGDSCB:VRFNAME="_public_",FECFLAG=FECADDR,FECADDR="10.10.10.10",PREFIXLENGTH=32;
```
