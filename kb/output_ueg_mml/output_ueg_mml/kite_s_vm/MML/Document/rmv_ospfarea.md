# 删除OSPF区域配置（RMV OSPFAREA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用于在OSPF进程下删除区域。

#### 注意事项

- 该命令执行后立即生效。
- 删除区域前应该先删除本区域下的相关配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| PROCID | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| AREAID | 区域号    | 可选必选说明：必选参数 参数含义：OSPF区域号。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无       |

#### 使用实例

删除OSPF进程下1区域0.0.0.0：

```
RMV OSPFAREA: PROCID=1, AREAID="0.0.0.0";
```

#### 参考信息

OSPF采用分区域计算，将网络中所有OSPF路由器划分成不同的区域，每个区域负责各自区域精确的LSA传递与路由计算，然后再将一个区域的LSA简化和汇总之后转发到另外一个区域。
