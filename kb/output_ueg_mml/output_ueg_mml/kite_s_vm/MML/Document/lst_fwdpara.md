# 查询转发参数（LST FWDPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询转发参数。

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询转发参数。

LST FWDPARA:;

```
%%LST FWDPARA:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
    报文重组超时时长（秒）  =  6
IPv6报文重组超时时长（秒）  =  6
          分片报文转板开关  =  开
                批量收包数  =  128
              批量收包次数  =  4
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET FWDPARA**的参数说明。
