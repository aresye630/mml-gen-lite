# 增加CSDB RU内存信息(ADD DBRUMEM)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该操作将修改CSDB RU上数据备份内存大小，不合理的修改将导致CSDB异常，修改后需要重启CSDB生效。

该命令通过增加CSDB RU内存信息，来修改RU内存大小。

#### 注意事项

- 有两种方式可以控制CSDB RU的内存大小，一种是环境配置的模板，另一种是内存信息，内存信息默认为空，内存信息控制的优先级高于模板。
- 同一集群类型和RU类型下，只能存在一条RU内存信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                            |
|:------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------|
| CLUSTERTYPE | 集群类型    | 可选必选说明：必选参数 参数含义: 该参数用于指定集群类型，分为普通集群和XSF集群。 数据来源：本端规划 取值范围： “COMMON_CLUSTER”：普通集群。“XSF_CLUSTER”：XSF集群。 默认值：无 配置原则：无             |
| RUTYPE      | RU类型    | 可选必选说明：必选参数 参数含义：该参数用于指定RU类型，可以通过DSP RU: SERVICEINSTANCE="CSDB_VNFC_999";命令查询获取。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |
| MEMSIZE     | 内存大小(G) | 可选必选说明：必选参数。 参数含义：该参数用于设定RU的内存大小。 数据来源：本端规划 取值范围：整型，0~255。 默认值：无 配置原则：无                                                         |

#### 使用实例

设置**“集群类型”**为“COMMON\_CLUSTER”，“**RU类型**”为“CSDB\_SD\_RU”的RU内存大小为5G：

```
ADD DBRUMEM: CLUSTERTYPE=COMMON_CLUSTER, RUTYPE="CSDB_SD_RU", MEMSIZE=5;
```
