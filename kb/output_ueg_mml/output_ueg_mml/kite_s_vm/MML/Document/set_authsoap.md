# 设置网管登录认证策略（SET AUTHSOAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

- “ALL(普通认证和增强认证)”采用的认证算法强度较低，系统可能会受到安全风险。
- “ENHANCED(增强认证)”会导致系统禁止普通认证登录CSP，网管以普通认证的方式无法登录CSP。

本命令用于设置网管登录CSP的认证策略。

#### 注意事项

- “认证策略”的系统初始值为“ALL(普通认证和增强认证)”。“ALL(普通认证和增强认证)”采用的认证算法强度较低。“ENHANCED(增强认证)”采用高强度认证算法，建议使用。
- “认证策略”配置为“ENHANCED(增强认证)”时，系统会禁止普通认证登录CSP，网管以普通认证的方式无法登录CSP。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| AUTHPOL | 认证策略   | 可选必选说明：必选参数。 参数含义：指定网管登录CSP的认证策略。 取值范围： “ALL(普通认证和增强认证)”：系统支持网管使用普通认证和增强认证登录CSP。 “ENHANCED(增强认证)”：系统支持网管使用增强认证登录CSP。 默认值：无。 配置原则：无。 |

#### 使用实例

设置网管登录认证策略：

```
%%SET AUTHSOAP: AUTHPOL=ALL;%%
RETCODE = 0  操作成功

---    END
```
