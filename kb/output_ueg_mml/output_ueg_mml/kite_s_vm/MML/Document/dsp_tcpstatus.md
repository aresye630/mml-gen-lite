# 查询TCP状态（DSP TCPSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看当前TCP连接状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                 |
|:----------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION       | IP版本       | 可选必选说明：可选参数 参数含义：该参数用于指定TCP socket实例的IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：IPv4                                  |
| LOCALADDRESS    | 本端地址       | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定本端地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                  |
| REMOTEADDRESS   | 远端地址       | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定远端地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                  |
| LOCALPORT       | 本端端口号      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4” 或 “IPv6”时为可选参数。 参数含义：该参数用于指定本端端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无               |
| REMOTEPORT      | 远端端口号      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4” 或 “IPv6”时为可选参数。 参数含义：该参数用于指定远端端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无               |
| APPCID          | APP组件CID   | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4” 或 “IPv6”时为可选参数。 参数含义：该参数用于指定APP组件CID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无 |
| SOCKETFD        | Socket实例ID | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4” 或 “IPv6”时为可选参数。 参数含义：该参数用于指定Socket实例ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147418111。 默认值：无     |
| LOCALV6ADDRESS  | IPv6本端地址   | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定IPv6本端地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                              |
| REMOTEV6ADDRESS | IPv6远端地址   | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定IPv6远端地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                              |

#### 使用实例

- 显示当前系统IPv4协议下的TCP状态信息：

  ```
  DSP TCPSTATUS: APPCID="0x8093042C", SOCKETFD=1;
  ```

  ```
          RETCODE = 0  操作成功

          结果如下
          ----------------------
            APP组件CID  =  0x8093042C
          Socket实例ID  =  1
              本端地址  =  0.0.0.0
              远端地址  =  0.0.0.0
            本端端口号  =  6000
            远端端口号  =  0
               TCP状态  =  侦听
                VPN ID  =  1
          (结果个数 = 1)
      ---    END
  ```
- 显示当前系统IPv6协议下的TCP状态信息：

  ```
  DSP TCPSTATUS:IPVERSION=IPv6,APPCID="0x80130080",SOCKETFD=1;
  ```

  ```
          结果如下
          ----------------------
         APP组件CID  =  0x80130080
       Socket实例ID  =  1
       IPv6本端地址  =  ::
       IPv6远端地址  =  2001:db8::11
         本端端口号  =  179
         远端端口号  =  0
            TCP状态  =  侦听
             VPN ID  =  1
    (结果个数 = 1)
      ---    END
  ```
