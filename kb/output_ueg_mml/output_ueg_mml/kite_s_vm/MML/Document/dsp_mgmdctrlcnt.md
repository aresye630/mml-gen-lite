# 查询IGMP报文统计计数（DSP MGMDCTRLCNT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IGMP报文统计计数。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                               |
|:--------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME       | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| IFNAME        | 接口名称    | 可选必选说明：可选参数 参数含义：该参数用来指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。               |

#### 使用实例

显示IGMP报文统计计数：

```
DSP MGMDCTRLCNT: VRFNAME="_public_", ADDRESSFAMILY=ipv4unicast, IFNAME="Ethernet64/0/3 ";
```
