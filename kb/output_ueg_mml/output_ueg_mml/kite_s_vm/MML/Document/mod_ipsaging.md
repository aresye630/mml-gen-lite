# 修改IPS老化配置（MOD IPSAGING）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改IPS老化配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                               |
|:---------------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| ENABLEAGING    | 开启老化功能 | 可选必选说明：必选参数  参数含义：该参数用于开启老化功能。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：  Boolean。                    |
| AGINGTHRESHOLD | 老化阈值   | 可选必选说明：可选参数  参数含义：该参数用于设定老化轮次阈值，达到阈值数量同步轮次未接收到更新或同步的数据将会被老化。  数据来源：本端规划  取值范围：整数类型，取值范围是1~255，单位是次。  默认值：5  配置原则：无 |
| SYNCBATCHSIZE  | 同步打包包数 | 可选必选说明：可选参数  参数含义：该参数用于设定数据同步消息打包包数。  数据来源：本端规划  取值范围：整数类型，取值范围是1~10，单位是条。  默认值：10  配置原则：无                         |

## 使用实例

- 开启IPS老化功能，老化阈值为5。

  ```
  MOD IPSAGING: ENABLEAGING=TRUE, AGINGTHRESHOLD=5;
  ```
- 设置同步打包包数为5。

  ```
  MOD IPSAGING: ENABLEAGING=FALSE, SYNCBATCHSIZE=5;
  ```
