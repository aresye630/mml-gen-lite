# 查询接口下ARP配置信息（LST ARPINTERFACE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

在监控ARP表项或APP出现故障时，可以使用此命令查看ARP表项的统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：可选参数 参数含义：该参数用于指定接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：以太网接口名称由接口类型和接口编号组成。 |

#### 使用实例

查询Ethernet64/0/5的接口配置：

```
LST ARPINTERFACE:IFNAME="Ethernet64/0/5";
```
