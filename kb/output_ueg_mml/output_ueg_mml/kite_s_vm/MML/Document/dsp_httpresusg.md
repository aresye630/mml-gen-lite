# 显示HTTP资源使用信息（DSP HTTPRESUSG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示HTTP资源使用信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                      |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE  | 查询资源类型   | 可选必选说明：必选参数  参数含义：该参数用于指定查询资源使用信息的类型。  数据来源：本端规划 取值范围： “BYPEERIP（对端IP）”：对端IP“BYPOD（POD名称）”：POD名称  默认值：无  配置原则：无                                           |
| PODNAME    | POD名称    | 可选必选说明：该参数在"QUERYTYPE"配置为"BYPOD"时为条件必选参数。  参数含义：该参数用于指定HTTP资源所在的POD名称。该POD名称可通过DSP HTTPPROCESS命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| PID        | PID      | 可选必选说明：该参数在"QUERYTYPE"配置为"BYPOD"时为条件必选参数。  参数含义：该参数用于指定查询的进程标识。该进程标识可通过DSP HTTPPROCESS命令查询获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无     |
| PEERIPTYPE | 对端IP地址类型 | 可选必选说明：该参数在"QUERYTYPE"配置为"BYPEERIP"时为条件必选参数。  参数含义：该参数用于指定查询对端IP地址的类型。  数据来源：本端规划 取值范围： “IPv4（IPv4地址）”：IPv4地址“IPv6（IPv6地址）”：IPv6地址  默认值：无  配置原则：无         |
| PEERIPV4   | 对端IPv4地址 | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定对端IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                |
| PEERIPV6   | 对端IPv6地址 | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定对端IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                |

## 使用实例

## 输出结果说明

| 输出项名称    | 输出项解释                                                                |
|:---------|:---------------------------------------------------------------------|
| 资源类型     | 该参数用于显示查询的HTTP资源类型。 取值说明： “REQCB（REQCB）”：REQCB                       |
| POD名称    | 该参数用于指定HTTP资源所在的POD名称。该POD名称可通过DSP HTTPPROCESS命令查询获取。                |
| PID      | 该参数用于指定查询的进程标识。该进程标识可通过DSP HTTPPROCESS命令查询获取。                        |
| 对端IP地址类型 | 该参数用于指定查询对端IP地址的类型。 取值说明： “IPv4（IPv4地址）”：IPv4地址“IPv6（IPv6地址）”：IPv6地址 |
| 对端IPv4地址 | 该参数用于指定对端IPv4地址。                                                     |
| 对端IPv6地址 | 该参数用于指定对端IPv6地址。                                                     |
| 本端实体类型   | 该参数用于显示HTTP本端实体的类型。 取值说明： “CLIENT（客户端）”：客户端“SERVER（服务端）”：服务端         |
| 资源门限     | 该参数用于显示该资源门限值。                                                       |
| 令牌使用率(%) | 该参数用于显示该worker上对端令牌独占池令牌使用率。                                         |
| 令牌总数     | 该参数用于显示该worker上对端令牌独占池所有令牌数量。                                        |
| 空闲态令牌数量  | 该参数用于显示该worker上对端令牌独占池空闲态令牌数量。                                       |
| 占用态令牌数量  | 该参数用于显示该worker上对端令牌独占池占用态令牌数量。                                       |
| 共享令牌数量   | 该参数用于显示该worker上共享令牌数量。                                               |
