# 查询IPv6安全配置（LST IPV6ICMPSECURITY）

- 命令功能

- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv6安全配置。

若不指定IFNAME参数时，则显示所有接口的IPv6安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv6安全配置：

```
LST IPV6ICMPSECURITY:;
```

