# 查询IPsec统计信息（DSP IPSECSTATISTIC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPsec处理报文统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| SANAME | 安全联盟名称 | 可选必选说明：可选参数 参数含义：安全联盟名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。不区分大小写。 默认值：无                |
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用DSP RU命令查看可用接口。 |

```
DSP IPSECSTATISTIC: SANAME="1";
```
