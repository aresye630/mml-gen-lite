# 查询静态路由自动化配置模板（LST AUTOSCALINGSRROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询静态路由自动化配置模板。

#### 注意事项

如果地址族取值为IPv4，则路由掩码长度取值范围为0到32，如果地址族取值为IPv6，则路由掩码长度取值范围为0到128。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                         |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称     | 可选必选说明：可选参数 参数含义：该参数用来表示接口自动化配置服务模板名称。要求和ADD AUTOSCALINGSERVICE命令中配置的SERVICENAME参数保持一致。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无     |
| IPVERSION   | 地址族      | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例的地址族信息。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4地址族。IPv6：IPv6地址族。 默认值：无                                                   |
| VRFNAME     | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无 配置原则：公网需要输入_public_，默认查询所有VPN。                            |
| PREFIX4     | 路由前缀IPv4 | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用来指定IPv4前缀信息。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                      |
| PREFIX6     | 路由前缀IPv6 | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用来指定IPv6前缀信息。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                      |
| MASKLENGTH  | 路由掩码长度   | 可选必选说明：可选参数 参数含义：IPv4场景，该参数用于表示路由的掩码长度；IPv6场景，该参数用于表示路由的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无 配置原则：不可单独以掩码查询静态路由自动化配置服务模板。掩码需要和前缀一起配置。 |

#### 使用实例

查询静态路由自动化配置模板信息：

```
LST AUTOSCALINGSRROUTE: SERVICENAME="abc";
```
