# 修改组播负载分担配置（MOD MCASTLOADSPLIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改组播负载分担配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                        |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| ADDRESSFAMILY | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                               |
| LOADSPLITTING | 负载分担方式  | 可选必选说明：必选参数 参数含义：该参数用来表示负载分担方式。 数据来源：本端规划 取值范围：枚举类型。 BALANCE：稳定优先方式的组播路由负载分担。 默认值：无                         |

#### 使用实例

修改组播负载分担类型为稳定优先：

```
MOD MCASTLOADSPLIT:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,LOADSPLITTING=BALANCE;
```
