# 查询状态核查参数（LST STATUSCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当前版本配置此命令不生效。

该命令用于查询状态核查配置参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询状态核查参数的配置。

```
LST STATUSCHECK:;
```

## 输出结果说明

| 输出项名称      | 输出项解释          |
|:-----------|:---------------|
| 状态核查开关     | 该命令用于设置状态核查开关。 |
| 状态核查周期(分钟) | 该命令用于设置状态核查周期。 |
