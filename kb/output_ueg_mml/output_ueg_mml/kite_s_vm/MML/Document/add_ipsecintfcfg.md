# 创建IPsec隧道接口（ADD IPSECINTFCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建IPsec隧道。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1024。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                               |
|:--------------|:------------|:-----------------------------------------------------------------------------------|
| INTERFACENAME | 接口名称        | 可选必选说明：必选参数 参数含义：配置接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                    |
| TNLTYPE       | Tunnel口协议类型 | 可选必选说明：必选参数 参数含义：Tunnel口协议类型。 数据来源：本端规划 取值范围：枚举类型。 IPSEC：IP安全。IPSEC6：IPv6安全。 默认值：无 |

#### 使用实例

创建接口名为“Tunnel1/1/1”的安全隧道：

```
ADD IPSECINTFCFG:INTERFACENAME="Tunnel1/1/1",TNLTYPE=IPSEC;
```
