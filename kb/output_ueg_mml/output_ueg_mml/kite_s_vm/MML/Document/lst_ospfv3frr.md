# 查询OSPFv3 IP FRR配置（LST OSPFV3FRR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3 IP FRR（快速重路由）配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                     |
|:-------|:----------|:-------------------------------------------------------------------------|
| PROCID | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

查询OSPFv3进程号为1的IP FRR（快速重路由）配置信息：

```
LST OSPFV3FRR: PROCID=1;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
                OSPFv3进程号  =  1
                 LFA是否使能  =  FALSE
              节点保护优先级  =  40
          最小开销路径优先级  =  20
   LDP联动最大开销路径优先级  =  10
                路由策略类型  =  无策略
                路由策略名称  =  NULL
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称          | 输出项解释                                               |
|:---------------|:----------------------------------------------------|
| OSPFv3进程号      | 该参数用于表示OSPFv3进程号。                                   |
| LFA是否使能        | 该参数用于表示LFA是否使能，使能此参数后，OSPFv3 IP FRR功能才会生效，生成无环备份路由。 |
| 节点保护优先级        | 该参数用于表示备份路径节点保护优先级。                                 |
| 最小开销路径优先级      | 该参数用于表示备份路径最小开销路径优先级。                               |
| LDP联动最大开销路径优先级 | 该参数用于表示优选LDP联动通告最大开销路径为备份下一跳的优先级。                   |
| 路由策略类型         | 该参数用于表示路由策略的类型，包含两种类型：无策略、路由策略。                     |
| 路由策略名称         | 该参数用于表示一个路由策略的名称。                                   |
