# 查询BFD会话自动化配置模板（LST AUTOSCALINGBFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询FD会话自动化配置模板。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                   |
|:-------------|:-------|:---------------------------------------------------------------------------------------|
| TEMPLATENAME | 模板名称   | 可选必选说明：可选参数 参数含义：该参数用于指定BFD自动化配置模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～59。不支持空格和中文。 默认值：无 |

#### 使用实例

查询BFD会话自动化配置模板：

```
LST AUTOSCALINGBFD:;
```
