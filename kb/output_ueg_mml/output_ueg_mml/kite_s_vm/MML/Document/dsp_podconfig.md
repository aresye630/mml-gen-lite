# POD配置查询（DSP PODCONFIG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统修复Pod功能的开关状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询系统修复Pod功能的开关状态：

```
%%DSP PODCONFIG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
修复开关  =  ON
(结果个数 = 1)
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1 输出项解释所示。

命令执行失败则返回相应的错误，参见表2；命令执行异常，请联系华为技术支持处理。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 修复开关    | 用于返回系统修复Pod功能的开关状态。 ON：打开状态。OFF：关闭状态。 |

|    错误码 | 错误码解释    | 原因分析      | 处理建议        |
|-------:|:---------|:----------|:------------|
| 140002 | MML命令不存在 | 系统内部错误。   | 联系华为技术支持处理。 |
| 140019 | 其他错误     | 系统内部错误。   | 联系华为技术支持处理。 |
| 140037 | 配置中心不可用  | 配置中心运行异常。 | 联系华为技术支持处理。 |
