# 显示注册的服务实例信息（DSP SERVICEINST）

- 命令功能

- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在CMF上注册的服务实例信息。

若需要查询指定网元在CMF上注册的服务实例信息，请输入“网元ID”参数。若不输入“网元ID”参数，表示查询所有网元在CMF上注册的服务实例信息。

若需要查询在CMF上注册的所有服务实例信息，请将输入参数中的“查询类型”选择为“所有”。

若需要通过服务名称查询在CMF上注册的服务实例信息，请将输入参数中的“查询类型”选择为“通过服务名称”，并输入“服务名称”参数。

若需要通过服务实例ID查询在CMF上注册的服务实例信息，请将输入参数中的“查询类型”选择为“通过服务实例ID”，并输入“服务实例ID”参数。

若需要通过服务实例标签查询在CMF上注册的服务实例信息，请将输入参数中的“查询类型”选择为“通过服务实例标签”，并输入“服务实例标签键”和“服务实例标签值”参数。其中，键为必选参数，值为可选参数。

若需要根据节点ID、Pod ID或进程ID查询在CMF上注册的服务实例信息，请将输入参数中的“查询类型”选择为“通过服务实例标签”，然后在“服务实例标签键”参数中输入“Node ID”、“Pod ID”或“Cell ID”，并输入“服务实例标签值”，注意此时“服务实例标签值”不能为空。

## 注意事项

当输入参数中的“查询类型”选择为“通过服务实例标签”时，“服务实例标签键”和“服务实例标签值”只支持通过服务实例单个标签的键和值查询，不支持同时通过服务实例多个标签的键和值查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                   |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 查询类型    | 可选必选说明：必选参数  参数含义：该参数用于指定查询在CMF上注册的服务实例信息的方式。  数据来源：本端规划 取值范围： “ALL（所有）”：查询所有在CMF上注册的服务实例信息“BYNAME（通过服务名称）”：通过服务名称查询在CMF上注册的服务实例信息“BYID（通过服务实例ID）”：通过服务实例ID查询在CMF上注册的服务实例信息“BYLABEL（通过服务实例标签）”：通过服务实例标签查询在CMF上注册的服务实例信息  默认值：无  配置原则：无 |
| SERVICENAME | 服务名称    | 可选必选说明：该参数在"TYPE"配置为"BYNAME"时为条件必选参数。  参数含义：该参数用于表示服务名称。服务名称可通过DSP SERVICENAME命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：  当按服务名称查询实例信息时，该参数支持模糊匹配。                                                               |
| INSTANCEID  | 服务实例ID  | 可选必选说明：该参数在"TYPE"配置为"BYID"时为条件必选参数。  参数含义：该参数用于表示服务实例ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                                                                                                                            |
| LABELKEY    | 服务实例标签键 | 可选必选说明：该参数在"TYPE"配置为"BYLABEL"时为条件必选参数。  参数含义：该参数用于表示服务实例标签的键。服务实例标签是KV键值对。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~128。服务实例标签键不允许输入以下字符：,（逗号）、;（分号）、=（等号）、"（双引号）、'（单引号）。  默认值：无  配置原则：无                                                        |
| LABELVALUE  | 服务实例标签值 | 可选必选说明：该参数在"TYPE"配置为"BYLABEL"时为条件可选参数。  参数含义：该参数用于表示服务实例标签的值。服务实例标签是KV键值对。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。服务实例标签值不允许输入以下字符：,（逗号）、;（分号）、=（等号）、"（双引号）、'（单引号）。  默认值：无  配置原则：无                                                        |
| MEID        | 网元ID    | 可选必选说明：该参数在"TYPE"配置为"BYID"、"BYNAME"、"BYLABEL"、"ALL"时为条件可选参数。  参数含义：该参数用于指定网元来查询在CMF上注册的服务实例信息，可通过LST ME命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：  该参数若不输入，则表示查询所有网元在CMF上注册的服务实例信息。                                     |

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                 |
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| 服务名称     | 该参数用于表示服务名称。服务名称可通过DSP SERVICENAME命令查询获取。                                                                                                             |
| 服务实例ID   | 该参数用于表示服务实例ID。                                                                                                                                        |
| 状态       | 该参数用于表示服务实例状态，若显示为 “NULL” ，则表示服务实例无状态信息。 取值说明： “Unknown（未知状态）”：服务实例是未知状态“Normal（正常状态）”：服务实例启动正常“Fault（异常状态）”：服务实例是故障状态“Ready（就绪状态）”：服务实例启动正常，并且可以提供服务 |
| 进程ID     | 该参数用于表示服务实例所在的进程ID。进程ID可通过DSP MSPROCESS命令查询。                                                                                                          |
| 进程类型名称   | 该参数用于表示微服务进程所属的进程类型名称。进程类型名可以通过DSP MSPROCTYPE命令查询。                                                                                                    |
| Pod ID   | 该参数用于表示服务实例的进程所在的Pod ID。                                                                                                                              |
| 节点ID     | 该参数用于表示服务实例的进程所在的节点ID。                                                                                                                                |
| 网元ID     | 该参数用于指定网元来查询在CMF上注册的服务实例信息，可通过LST ME命令查询获取。                                                                                                           |
| 版本       | 该参数用于表示服务实例的版本信息。                                                                                                                                     |
| 地址       | 该参数用于表示服务实例的地址。                                                                                                                                       |
| 注册时间     | 该参数用于表示服务实例的注册时间。                                                                                                                                     |
| 服务实例所有标签 | 该参数用于表示服务实例所有的标签。                                                                                                                                     |
