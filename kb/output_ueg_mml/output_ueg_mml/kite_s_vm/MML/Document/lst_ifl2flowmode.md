# 查询主接口二层透传模式（LST IFL2FLOWMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询接口的二层透传模式。在不指定接口名时，查询所有使能了二层透传模式的主接口；指定接口名时，只查询该接口的二层透传模式是否使能。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：可选参数 参数含义：接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

- 查询指定主接口下的二层透传模式：

  ```
  LST IFL2FLOWMODE:IFNAME="Ethernet65/0/6";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
    接口名称  =  Ethernet65/0/6
  流模式使能  =  TRUE
  (结果个数 = 1)
  ---    END
  ```
- 查询所有主接口下的二层透传模式：

  ```
  LST IFL2FLOWMODE:;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  接口名称          流模式使能 

  Ethernet66/0/4    TRUE             
  Ethernet66/0/5    TRUE             
  Ethernet65/0/6    TRUE             
  (结果个数 = 3)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 流模式使能   | 二层透传模式使能。 |

其余输出项请参见ADD IFL2FLOWMODE的参数说明。
