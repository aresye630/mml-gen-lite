# 设置CSLB软件调试参数表（SET LBSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置CSLB系统软件参数。

#### 注意事项

- 系统初次上电运行时，会执行系统初始设置值。
- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                     |
|:----------|:-------|:---------------------------------------------------------|
| PARAID    | 参数标识   | 可选必选说明：必选参数 参数含义：软件参数ID 数据来源：本端规划 取值范围：0~1023 默认值：无      |
| PARAVALUE | 参数值    | 可选必选说明：必选参数 参数含义：软件参数值 数据来源：本端规划 取值范围：0~4294967295 默认值：无 |

#### 使用实例

设置系统软件参数ID为1023的参数值为2:

`SET LBSOFTPARA: PARAID=1023, PARAVALUE=2;`
