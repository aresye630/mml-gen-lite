# 清除攻击防范统计信息（RTR ATTACKDEFENDSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除攻击防范统计计数。

不指定参数时，清除所有攻击类型的统计信息；当指定参数时，可以清除指定攻击类型的统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                   |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ATTACKTYPE | 攻击类型   | 可选必选说明：可选参数 参数含义：该参数用于设置攻击类型。 数据来源：本端规划 取值范围：枚举类型。 ABNORMAL：畸形报文。FRAGMENT：分片报文。TCP-SYN：TCP-SYN报文。UDP-FLOOD：UDP泛洪报文。ICMP-FLOOD：ICMP泛洪报文。 默认值：无 配置原则：如果不输入该参数，则表示所有攻击类型。 |

#### 使用实例

清除攻击防范统计计数信息：

```
RTR ATTACKDEFENDSTC:;
```
