# 查询服务ID与服务实例的关系（DSP LBSRVINSTIDREL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询业务VNFC对应的CSLB服务实例，通过查询结果判断业务是否已经下发负载均衡服务的绑定策略，辅助定位隧道转发失败问题。

#### 注意事项

该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID | 业务VNFCID | 可选必选说明：可选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在业务VNFC下执行LST NODE获得，所得NODE ID（节点ID）即为业务VNFC ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 |
| APPINSTID | 业务服务实例ID | 可选必选说明：可选参数 参数含义：该参数用于业务VNFC定义的服务实例ID，通过DSP LBSRVINST获取。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无                               |

#### 使用实例

查询指定业务VNFC的所有业务类型对应的服务实例ID。

`DSP LBSRVINSTIDREL: SRVVNFCID=4;`

```
%%DSP LBSRVINSTIDREL: SRVVNFCID=4;%%
RETCODE = 0  操作成功。

操作结果如下：
-------------------------
业务VNFCID 业务服务实例ID  CSLB_VNFC服务实例ID  服务ID     服务类型   
4          0               0                    0          0
4          1               1                    1          0
(结果个数 = 2)
--- END
```

#### 输出结果说明

| 输出项名称           | 输出项解释                                                     |
|:----------------|:----------------------------------------------------------|
| 业务VNFCID        | 参数含义：业务VNFC的唯一标识。 取值范围：整数类型，取值范围为0~4294967295。            |
| 业务服务实例ID        | 参数含义：业务VNFC定义的服务实例ID。 取值范围：整数类型，取值范围为0~4294967295。        |
| CSLB_VNFC服务实例ID | 参数含义：CSLB服务实例ID。 取值范围：整数类型，取值范围为0~4294967295。             |
| 服务ID            | 参数含义：业务VNFC定义的CSLB服务实例的服务ID。 取值范围：整数类型，取值范围为0~4294967295。 |
| 服务类型            | 参数含义：业务VNFC定义的CSLB服务实例的服务类型。 取值范围：整数类型，取值范围为0~255。        |
