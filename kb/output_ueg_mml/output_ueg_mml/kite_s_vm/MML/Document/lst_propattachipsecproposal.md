# 查询IPsec策略绑定提议（LST PROPATTACHIPSECPROPOSAL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IPsec策略的提议。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                 |
|:---------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 策略名称        | 可选必选说明：必选参数  参数含义：IPsec策略的名字。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无                                                              |
| SEQUENCENUMBER | 序列号         | 可选必选说明：必选参数  参数含义：序列号。  数据来源：对端协商  取值范围：整数类型，取值范围是1~10000。  默认值：无  配置原则：无                                                                            |
| POLICYMODE     | 策略模式        | 可选必选说明：必选参数  参数含义：策略模式： ISAKMP：表明使用IKE建立IPsec安全联盟。  数据来源：对端协商 取值范围： “Isakmp（ISAKMP模式）”：使用IKE建立IPsec安全联盟的模式  默认值：无  配置原则：无                            |
| TEMPLATEMODE   | 模板模式        | 可选必选说明：必选参数  参数含义：模板模式-绑定一个策略模板到ISAKMP（使用策略模板建立IPsec安全联盟）。  数据来源：对端协商 取值范围： None（无）“PolicyTemplate（策略模板模式）”：使用策略模板模式创建策略，仅支持用户级IPsec。  默认值：无  配置原则：无 |
| IPSECPROPNAME  | IPsec安全提议名称 | 可选必选说明：可选参数  参数含义：Proposal名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无                                                              |

## 使用实例

查询IPsec策略的提议：

```
LST PROPATTACHIPSECPROPOSAL:POLICYNAME="pol2",SEQUENCENUMBER=1,POLICYMODE=Isakmp,TEMPLATEMODE=None;

RETCODE = 0  操作成功

结果如下
-------------------------
         策略名称  =  pol2
           序列号  =  1
         策略模式  =  ISAKMP模式
         模板模式  =  无
IPsec安全提议名称  =  ipsecpsl37
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                                    |
|:------------|:-----------------------------------------|
| 策略名称        | IPsec策略的名字。                              |
| 序列号         | 序列号。                                     |
| 策略模式        | 策略模式： ISAKMP：表明使用IKE建立IPsec安全联盟。         |
| 模板模式        | 模板模式-绑定一个策略模板到ISAKMP（使用策略模板建立IPsec安全联盟）。 |
| IPsec安全提议名称 | Proposal名称。                              |
