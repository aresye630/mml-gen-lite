# 查询升级观察期(LST UPGRADEWATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询所有网元升级观察期数据。

## 注意事项

查询到的升级观察期数据对所有网元有效，不区分网元。

## 参数说明

无。

## 使用实例

查询升级观察期剩余天数和天数设置。

```
%%LST UPGRADEWATCH:;%%
RETCODE = 0  操作成功

升级观察期信息
--------------
      剩余天数  =  0
观察期天数设置  =  180
    观察期类型  =  USCDB插件升级
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回操作成功的提示信息和相关参数，各参数含义请参见表1所示。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释                                  |
|:--------|:---------------------------------------|
| 剩余天数    | 用于返回所有网元的升级观察期剩余天数。如果处于永久观察期，则显示65535。 |
| 观察期天数设置 | 用于返回网元设置的观察期天数。如果处于永久观察期，则显示65535。     |
| 观察期类型   | 用于区分插件观察期与升级观察期，只存在插件观察期时返回此项。         |

|    错误码 | 错误码解释   | 原因分析           | 处理建议         |
|-------:|:--------|:---------------|:-------------|
| 112004 | 内部错误    | 升级工具处理MML命令异常。 | 请联系华为技术支持处理。 |
