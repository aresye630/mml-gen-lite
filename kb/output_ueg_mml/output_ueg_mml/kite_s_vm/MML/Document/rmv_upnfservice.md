# 删除NF服务实例（RMV UPNFSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于在NF实例下删除服务实例信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                          |
|:---------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定NF实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~64。 默认值：无 配置原则：本参数来源于ADD UPNFUUID命令中的“NF实例名称”参数。                                |
| SRVINSTANCEID  | 服务实例标识 | 可选必选说明：必选参数 参数含义：本参数用于指定NF服务实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~50。 默认值：无 配置原则：本参数构成字符只能是字母A～Z或a～z、数字0～9、中划线“-”和下划线“_”，例如，Service_Instance_0。 |

#### 使用实例

运营商A需要删除NF实例名称为LMF\_Instance\_0，服务实例标识为Service\_Instance\_0的服务实例：

```
RMV UPNFSERVICE: NFINSTANCENAME="LMF_Instance_0", SRVINSTANCEID="Service_Instance_0";
```
