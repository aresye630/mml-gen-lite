# 删除L3VPN实例地址族（RMV VPNINSTAF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会删除所有该VPN实例地址族下的关联配置，请谨慎使用并联系华为技术支持协助操作。

该命令用于删除指定L3VPN实例下的地址族。

#### 注意事项

- 该命令执行后立即生效。
- 该操作会删除所有该VPN实例地址族下的关联配置。
- 不能删除VPN实例\_public\_、\_\_mpp\_vpn\_inner\_\_、\_\_mpp\_vpn\_inner\_server\_\_的地址族。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                      |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定L3VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST L3VPNINST命令查看可用VPN。 |
| AFTYPE  | 地址族类型   | 可选必选说明：必选参数 参数含义：该参数用于指定VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：无           |

#### 使用实例

删除名称为“vrf1”的VPN实例下的IPv4单播地址族：

```
RMV VPNINSTAF:VRFNAME="vrf1", AFTYPE=ipv4uni;
```
