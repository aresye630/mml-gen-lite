# 显示LDP的IID信息（DSP LDPLSPMGIID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示LDP的IID信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                           |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_                                                |
| FECFLAG      | 目的地址标志位 | 可选必选说明：可选参数 参数含义：该参数用于表示LSP的目的地址标志位。 数据来源：本端规划 取值范围：枚举类型。 IIDINDEX：指定IID索引。FECADDR：指定目的地址。 默认值：无                               |
| FECADDR      | 目的地址    | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“FECADDR”时为必选参数。 参数含义：该参数用于指定LSP的目的地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                       |
| PREFIXLENGTH | 前缀长度    | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“FECADDR”时为必选参数。 参数含义：该参数用于指定目的地址的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无                |
| IIDINDEX     | IID索引   | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“IIDINDEX”时为必选参数。 参数含义：该参数用于指定LSP的IID索引。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无 |

#### 使用实例

显示LDP的IID信息：

```
DSP LDPLSPMGIID:VRFNAME="_public_",FECFLAG=IIDINDEX,IIDINDEX="100000F";
```


|:-------------|:-----------------------------------------------------|

| IP地址族        | 该参数用于指定IP地址族，包括： IPv4地址族。IPv6地址族。                    |
| 平滑版本号        | 用于指定平滑版本号。                                           |
| 备份版本号        | 用于指定备份版本号。                                           |
| 下一跳地址        | 用于指定下一跳地址。                                           |
| 下一跳对应的邻居ID   | 用于指定下一跳对应的邻居ID。                                      |
| 出接口名称        | 用于指定出接口名称。                                           |
