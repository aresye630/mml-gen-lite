# 添加IGMP SSM映射配置（ADD MGMDSSMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来创建IGMP SSM映射配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 需要首先在公网或VPN实例下配置ADD MCASTENABLE命令。
- 当主机不支持IGMPv3，只支持IGMPv1或IGMPv2组报告时，无法加入SSM范围的组播组。
- 只有在接口下使能了SSM映射，即执行ADD MGMDIF命令且SSMAPENABLE为TRUE之后，配置的SSM源/组地址映射表项才能生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                               |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY   | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| ISSSMMAPINGMASK | 掩码递增    | 可选必选说明：必选参数 参数含义：该参数用于表示是否配置掩码递增。 数据来源：本端规划 取值范围：枚举类型。 FALSE：配置组地址掩码长度。TRUE：配置组地址掩码地址。 默认值：无                       |
| VRFNAME         | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| SSMMAPINGGRP    | 组地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于表示组地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无      |
| SSMMAPINGMASK   | 组播地址掩码  | 可选必选说明：条件必选参数 前提条件：该参数在“ISSSMMAPINGMASK”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示组播地址掩码。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无        |
| MASKLEN         | 组地址掩码长度 | 可选必选说明：条件必选参数 前提条件：该参数在“ISSSMMAPINGMASK”配置为“FALSE”时为必选参数。 参数含义：该参数用于表示掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为4～32。 默认值：无   |
| SRCADDR         | 源地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于表示源地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无      |

#### 使用实例

创建IGMP SSM映射配置(10.8.8.8, 239.5.5.5)：

```
ADD MGMDSSMAP:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,ISSSMMAPINGMASK=TRUE,SSMMAPINGGRP="239.5.5.5",SRCADDR="10.8.8.8",SSMMAPINGMASK="255.255.255.0";
```
