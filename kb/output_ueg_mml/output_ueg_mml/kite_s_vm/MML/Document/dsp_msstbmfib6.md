# 通过关键字查询第六版因特网协议转发表的结果（DSP MSSTBMFIB6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于关键字查询第六版因特网协议转发表的结果。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                   |
|:------------|:----------------|:-------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称            | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| TABLEID     | 表号              | 可选必选说明：必选参数 参数含义：该参数用于表示表号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                               |
| IPV6VPN     | 第六版因特网协议地址虚拟专用网 | 可选必选说明：必选参数 参数含义：该参数用于表示第六版因特网协议地址虚拟专用网。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                  |
| IPV6ADDRESS | 第六版因特网协议地址      | 可选必选说明：必选参数 参数含义：该参数用于表示第六版因特网协议地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                     |
| MASKLEN     | 第六版因特网协议地址掩码长度  | 可选必选说明：必选参数 参数含义：该参数用于表示第六版因特网协议地址掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无                          |
| MATCHTYPE   | 匹配类型            | 可选必选说明：必选参数 参数含义：该参数用于表示匹配类型。 数据来源：本端规划 取值范围：枚举类型。 exact：精确匹配。noexact：模糊匹配。 默认值：无                      |

#### 使用实例

查询使用关键字查询第六版因特网协议转发表的结果：

```
DSP MSSTBMFIB6:TABLEID = 1,IPV6VPN = 1,IPV6ADDRESS = "2001:DB8::1",MASKLEN = 64,MATCHTYPE = exact,RUNAME  = "VNODE_VNRS_VNFC_IPU_0064";
```

```

结果如下

---    END
```
