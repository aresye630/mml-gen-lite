# 查询DB启动参数值(LST DBSTARTPARAS)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询当前配置的CSDB启动参数值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLUSTERTYPE | 集群类型   | 可选必选说明：可选参数 参数含义: 该参数用于指定集群类型，分为普通集群和XSF集群。 数据来源：本端规划 取值范围： “COMMON_CLUSTER”：普通集群。“XSF_CLUSTER”：XSF集群。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| PARA        | 参数     | 可选必选说明：可选参数 参数含义: 该参数用于指定需要查询的CSDB启动参数。 数据来源：本端规划 取值范围： “AGING_SCAN_INTERVAL(对象老化扫描间隔)”：数据老化扫描的时间间隔。“AGING_TIME_THRESHOLD(老化时间阈值)”：数据老化时间阈值。如果数据在设定时间内没有更新，则会被推送至对应的订阅者。“CLUSTER_AGING_THRESHOLD(集群间老化时间阈值)”：集群间老化时间阈值。老化阈值需要大于集群间核查周期“CLUSTER_CHECK_PERIOD”，否则未核查到的数据会被当成老化数据删除。一般大于2个周期。“CLUSTER_CHECK_INTERVAL(集群核查间隔)”：集群间核查间隔。“CLUSTER_CHECK_PERIOD(集群间核查周期)”：集群间核查周期，1个周期包括多个间隔。“CLUSTER_INCONSIS_RATIO(集群数据不一致比例)”：集群数据不一致比例。当取值为x时，表示当前节点核查数据的不一致数量超过扫描总数量的x%时，就会上报“ALM-82615” 容灾实例间数据不一致告警。“CLUSTER_INCONSIS_COUNT(集群数据不一致个数)”：集群数据不一致个数。当取值为x时，表示当前节点核查数据的不一致总数超过x时，就会上报“ALM-82615” 容灾实例间数据不一致告警。“FORCE_AGING_DURATION(强制老化时长)”：强制老化时长，强制老化长时间未更新且无法删除的所有数据。默认不开启，如果开启需要为数据老化时间阈值“AGING_TIME_THRESHOLD”的2倍。“INDEX_CHECK_PERIOD(索引核查周期)”：集群内主本和副本的核查周期。“TABLE_COMPRESSION_SWITCH(表压缩开关)”：是否开启表压缩。“BANDWIDTH_COMPRESSION_SWITCH(带宽压缩开关)”：是否开启带宽压缩。“NWAY_REP_PARTITION_SWITCH(nway副本分区分布开关)”：是否开启nway副本分区分布。 默认值：无 |

RETCODE = 0  操作成功
