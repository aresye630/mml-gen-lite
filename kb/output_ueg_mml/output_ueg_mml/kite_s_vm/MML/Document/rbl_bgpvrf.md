# 复位BGP VPN实例（RBL BGPVRF）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会重置实例下所有的地址族和邻居，请谨慎使用并联系华为技术支持协助操作。

该命令会重置实例下所有的地址族、邻居信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令用于重置BGP VPN实例信息，执行该命令会重置实例下所有的地址族、邻居信息。
- VRFNAME和AFTYPE不输入参数时表示复位所有公私网实例。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                       |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户所配置的VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST L3VPNINST命令查看可用VPN。              |
| AFTYPE  | 地址族类型   | 可选必选说明：可选参数 参数含义：该参数用于指定VRF的地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：无 配置原则：如果不输入该参数，默认复位所有地址族下邻居。 |

#### 使用实例

重置路由器中的BGPVRF：

```
RBL BGPVRF: VRFNAME="_public_", AFTYPE=ipv4uni;
```
