# 增加对端NF的GPSI信息（ADD UPPNFGPSI）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加本地配置的对端NF实例支持的GPSI信息。该命令用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关的信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1000。
- 除参数INDEX外，其它参数的组合输入必须唯一。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                 |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引     | 可选必选说明：必选参数 参数含义：该参数用于指定GPSI的索引。 数据来源：本端规划 取值范围：整数类型，取值范围是0~65535。 默认值：无 配置原则：请执行LST UPPNFGPSI命令查询，确定增加记录的索引值，如果该索引值未被使用，则使用该索引值，否则分配一个未使用过的索引值。                                                                                                                                                                                                                     |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定GPSI对应的NF实例标识。 数据来源：全网规划 取值范围：NfInstanceId参数建议满足以下约束规则： 1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。 2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：本参数取值与ADD UPPNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| QUERYTYPE    | 查询方式   | 可选必选说明：必选参数 参数含义：该参数用于指定GPSI的配置号段的方式。 数据来源：本端规划 取值范围： START_END：号段。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                     |
| RANGESTART   | 起始号段   | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“START_END”时为必选参数。 参数含义：该参数用于指定GPSI的起始号段。当QUERYTYPE参数设置为START_END模式时有效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~15。长度全匹配，包括国家码。 默认值：无 配置原则：当查询类型为号段时，起始号段应不大于终止号段，且起始号段和终止号段的长度应保持一致。                                                                                                                                                     |
| RANGEEND     | 终止号段   | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“START_END”时为必选参数。 参数含义：该参数用于指定GPSI的终止号段。当QUERYTYPE参数设置为START_END模式时有效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~15。长度全匹配，包括国家码。 默认值：无 配置原则：当查询类型为号段时，终止号段应不小于起始号段，且终止号段和起始号段的长度应保持一致。                                                                                                                                                     |

#### 使用实例

新增对端NF实例支持的GPSI信息，其中索引为1，NF实例标识为udm\_instance\_0，查询类型为号段，起始号段为138100000000000，终止号段为138100000000001：

```
ADD UPPNFGPSI: INDEX=1, NFINSTANCEID="udm_instance_0", QUERYTYPE=START_END, RANGESTART="138100000000000", RANGEEND="138100000000001";
```
