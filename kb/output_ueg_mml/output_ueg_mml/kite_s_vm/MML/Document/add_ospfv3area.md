# 创建OSPFv3区域配置（ADD OSPFV3AREA）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 参考信息

#### 命令功能

该命令用于在OSPFv3进程下创建区域。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 只有在执行ADD OSPFV3配置了OSPFv3进程后才能使用此命令。
- OSPFv3区域实例数规格默认为单进程2000，实际以服务规格文件为准。
- 如果AREATYPE为NSSA，则必须配置Loopback地址并在OSPFv3进程中发布出去，否则会造成负载分担不生效，极端情况下会造成业务受损。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

配置OSPFv3进程下1新增区域0.0.0.0：

```
ADD OSPFV3AREA: PROCID=1, AREAID="0.0.0.0";
```

#### 参考信息

OSPFv3采用分区域计算，将网络中所有OSPFv3路由器划分成不同的区域，每个区域负责各自区域精确的LSA传递与路由计算，然后再将一个区域的LSA简化和汇总之后转发到另外一个区域。
