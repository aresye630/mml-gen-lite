# 查询全局NP交换网口检测配置（LST NPLINKCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询全局NP交换网口检测配置：包括端口检测使能、端口检测周期、端口检测超时检测倍数。

## 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询全局NP交换网口检测配置

```
LST NPLINKCHECK:;
RETCODE = 0  操作成功

结果如下
--------
        NP交换网口检测功能  =  使能
        NP交换网口检测周期  =  100
NP交换网口检测超时检测倍数  =  15
(结果个数 = 1)

---    END
```
