# 显示属性订阅信息（DSP DEVATTRSUB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示资源单元上指定组件的设备属性订阅信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                          |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| COMPTYPE        | 组件类型   | 可选必选说明：必选参数 参数含义：该参数表示组件类型。 数据来源：本端规划 取值范围：枚举类型。 DEVMA：DEVMA组件，该组件用于收集本资源单元设备属性、运行状态和设备事件数据上报给总控模块，同时执行来自总控模块的各种设备操作。LDEVM：LDEVM组件，该组件用于给APP提供设备属性订阅功能。 默认值：无 |
| RUNAME          | RU名称   | 可选必选说明：必选参数 参数含义：该参数表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。                                                        |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                  |

#### 使用实例

显示资源单元上指定组件的设备属性订阅信息：

```
DSP DEVATTRSUB:COMPTYPE=LDEVM,RUNAME="CSDB_OM_RU_0001",SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                               |
|:--------|:------------------------------------------------------------------------------------|
| 属性编号    | 表示属性编号。                                                                             |
| 位置      | 表示设备的位置信息。                                                                          |
| 设备类型    | 表示设备类型，具体在模型中定义。                                                                    |
| 序列号     | 表示设备序列号。                                                                            |
| 订阅者PID  | 表示订阅者的组件PID。                                                                        |
| 订阅模式    | 表示订阅模式。 0：常规订阅。1：转发节点订阅。2：端口索引订阅。3：TB/TP订阅。4：设备管理内部订阅。5：端口组订阅。6：批量订阅。8：通过NETCONF订阅。 |
| 分发方式    | 表示分发方式。 0： 常规分发。1： 消息分发。2： 告警分发。                                                    |
| 信息表ID   | 表示信息表ID。若为0，表示系统未给该表分配ID值。                                                          |
| 订阅时间    | 表示订阅时间。                                                                             |
