# 显示系统配置恢复结果（DSP CFGRECOVERRESULT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示系统配置恢复结果。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示系统配置恢复结果：

```
DSP CFGRECOVERRESULT:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
--------
配置恢复类型  =  CFG方式启动
配置恢复结果  =  配置恢复成功
    配置文件  =  nps_configuration.cfg
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                               |
|:--------|:------------------------------------|
| 配置恢复类型  | 用于表示配置恢复类型，包含三种类型：DB类型、CFG类型和空配置类型。 |
| 配置恢复结果  | 用于表示配置恢复结果：成功或失败。                   |
| 配置文件    | 用于表示配置文件。                           |
