# 查询全局协议报文统计配置（LST HOSTSTCGLB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询全局协议报文统计配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局协议报文统计配置：

```
LST HOSTSTCGLB:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
协议报文统计功能状态  =  使能
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释              |
|:-----------|:-------------------|
| 协议报文统计功能状态 | 该参数用于表示协议报文统计功能状态。 |
