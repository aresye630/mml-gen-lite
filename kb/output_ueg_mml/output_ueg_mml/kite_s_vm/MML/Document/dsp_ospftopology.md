# 查询OSPF拓扑信息（DSP OSPFTOPOLOGY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF拓扑信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                   |
|:-------|:--------|:-----------------------------------------------------------------------|
| PROCID | OSPF进程号 | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| AREAID | 区域号     | 可选必选说明：可选参数 参数含义：OSPF区域号。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无       |

#### 使用实例

查询OSPF进程1的拓扑信息：

```
DSP OSPFTOPOLOGY:PROCID=1;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
 OSPF进程号  =  1
     区域号  =  0.0.0.0
 路由器标识  =  10.10.10.1
    SPF类型  =  Router
SPF节点标识  =  10.10.10.1
   节点类型  =  -|-|-|-
     开销值  =  0
     下一跳  =  0.0.0.0
     出接口  =  NULL
(Number of results = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                          |
|:--------|:-------------------------------------------------------------------------------|
| OSPF进程号 | 该参数用于表示OSPF进程号。                                                                |
| 区域号     | 该参数用于表示OSPF区域号。                                                                |
| 路由器标识   | 该参数用于表示OSPF路由器标识。                                                              |
| SPF类型   | 该参数用于表示SPF类型-Router节点、Network节点。                                               |
| SPF节点标识 | 该参数用于表示SPF节点标识，当SPF类型为Router时，取得是生成LSA的Router ID；当SPF类型为Network时，取得是DR的接口IP地址。 |
| 节点类型    | 该参数用于表示该节点的路由能力（比如ASR、ASBR、NSSA等）。                                             |
| 开销值     | 该参数用于表示链路的开销值。                                                                 |
| 下一跳     | 该参数用于表示下一跳地址。                                                                  |
| 出接口     | 该参数用于表示出接口名称。                                                                  |
