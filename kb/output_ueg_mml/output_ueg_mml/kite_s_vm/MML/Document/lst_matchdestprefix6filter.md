# 查询匹配IPv6地址前缀列表（LST MATCHDESTPREFIX6FILTER）

#### 命令功能

该命令用于查询基于IPv6信息的前缀过滤器匹配目的地址的配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                   |
|:-----------|:-------|:-----------------------------------------------------------------------|
| POLICYNAME | 路由策略名字 | 可选必选说明：可选参数 参数含义：配置操作的路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |

#### 使用实例

查询匹配前缀过滤器配置信息：

```
LST MATCHDESTPREFIX6FILTER:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
    路由策略名字  =  a
  路由策略节点号  =  19
IPv6前缀列表名字  =  a
(结果个数 = 1)
---    END
```

#### 参考信息

为实现路由策略，首先定义将要实施路由策略的路由特征，即定义一组匹配规则和设置规则，然后将它们应用于路由的发布、接收和引入等过程的路由策略中。
