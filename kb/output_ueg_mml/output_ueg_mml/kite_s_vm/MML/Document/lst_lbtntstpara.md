# 查询CSLB隧道探测参数（LST LBTNTSTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB隧道探测参数。

#### 注意事项

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CSLB隧道探测参数。

LST LBTNTSTPARA:;

```
%%LST LBTNTSTPARA:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
  隧道时延探测周期（秒）  =  10
隧道丢包率统计周期（秒）  =  5
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET LBTNTSTPARA的参数说明。
