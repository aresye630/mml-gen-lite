# 增加POD资源告警阈值（ADD PODALMTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加POD资源告警阈值。

该命令的使用场景：POD根据本命令配置的阈值上报和恢复ALM-100441 POD CPU过载告警、ALM-100442 POD内存过载告警。

## 注意事项

- 该命令执行后立即生效。

- 该命令仅在FusionStage裸机场景下生效。

- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                          |
|:--------|:----------|:------------------------------------------------------------------------------------------------------------------------------|
| PODTYPE | POD类型     | 可选必选说明：必选参数  参数含义：本参数用于指定POD类型。该值来自于DSP PODCPUSTAT/PODMEMSTAT返回结果中的POD类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：无 |
| THTYPE  | 阈值类型      | 可选必选说明：必选参数  参数含义：该参数用于指定告警阈值类型。  数据来源：本端规划 取值范围： “CPU（阈值类型为CPU）”：阈值类型为CPU“MEMORY（阈值类型为内存）”：阈值类型为内存  默认值：无  配置原则：无            |
| WARNTHD | 告警上报阈值(%) | 可选必选说明：必选参数  参数含义：该参数用于指定告警上报阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100。  默认值：无  配置原则：无                                             |
| RECVTHD | 告警恢复阈值(%) | 可选必选说明：必选参数  参数含义：该参数用于指定告警恢复阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100。  默认值：无  配置原则：无                                             |

## 使用实例

给POD类型为sfm-pod的POD添加一条阈值配置，阈值类型为CPU，上报阈值为80，恢复阈值为70。

```
ADD PODALMTH: PODTYPE="sfm-pod",THTYPE=CPU,WARNTHD=80, RECVTHD=70;
```
