# 删除服务化接口本端实体（RMV SBIAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令用于删除服务化接口本端实体，该命令执行后系统中配置的服务化接口本端实体删除，对应的HTTP链路删除，影响基于该服务化接口的业务。

该命令用于删除服务化接口本端实体。

## 注意事项

- 该命令执行后立即生效。

- 删除服务化接口本端实体后，基于该服务化接口的业务将中断。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定服务化接口本端实体的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

若运营商想删除索引是2的服务化接口本端实体，可以执行如下命令：

```
RMV SBIAPLE: INDEX=2;
```
