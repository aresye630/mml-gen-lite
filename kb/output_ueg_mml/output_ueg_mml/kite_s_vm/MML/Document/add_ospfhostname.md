# 创建OSPF主机名配置（ADD OSPFHOSTNAME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建OSPF主机名。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 只有执行ADD OSPF配置了OSPF进程后才能使用该命令。
- 如果配置了hostname参数，则以hostname作为动态主机名发布，如果只执行hostname命令，不配置hostname参数，则以sysname命令输入的设备名称作为动态主机名发布。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                               |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| PROCID   | OSPF进程号 | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。 |
| HOSTNAME | 主机名     | 可选必选说明：可选参数 参数含义：主机名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无                                                     |

#### 使用实例

OSPF进程1下创建主机名“BLR”：

```
ADD OSPFHOSTNAME:PROCID=1, HOSTNAME="BLR";
```
