# 显示组件状态通知记录（DSP COMPSTATNOTIFY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询组件状态通知历史记录。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| COMPCID         | 组件ID   | 可选必选说明：必选参数 参数含义：该参数表示组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                               |
| PROCESS         | 进程ID   | 可选必选说明：必选参数 参数含义：该参数表示进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                     |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询组件状态通知历史记录：

```
DSP COMPSTATNOTIFY:COMPCID="80CF0010",PROCESS=2,SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
------------------------

01-19 14:30:04.670568    COMP-UPDATE STATE: 1    PRIMARY       
(结果个数 = 4)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| 时间      | 表示记录发生时间。   |
| 状态通知    | 表示目标组件状态通知。 |
| 运行状态    | 表示目标组件运行状态。 |
