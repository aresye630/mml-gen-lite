# 查询正常状态网元的占比阈值（LST MONNFTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询与当前网元具有容灾关系的其他网元中，状态正常的网元数目在所有网元数目的占比阈值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询正常状态网元的占比阈值。

```
%%LST MONNFTHR:;%%
RETCODE = 0  操作成功

结果如下
--------
正常状态网元占比阈值（%）  =  100
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                   |
|:--------------|:----------------------------------------|
| 正常状态网元占比阈值（%） | 当前网元具有容灾关系的其他网元中，状态正常的网元数目在所有网元数目的占比阈值。 |
