# 删除进程频繁故障监控参数（RMV CELLMULFAULTTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除进程频繁故障监控参数值。

## 注意事项

- 该命令执行后立即生效。

- 当系统不存在CELL\_SSG的故障告警监控配置时，CELL\_SSG默认开启监控，故障告警监控时间为1440分钟，故障告警故障次数为5次，恢复告警监控时间为10分钟，恢复告警监控次数为0次。
- 如果通过本命令删除已经添加的CELL\_SSG记录，会恢复对CELL\_SSG的默认监控行为。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                 |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| PROCESSNAME | 进程名称   | 可选必选说明：必选参数  参数含义：该参数用于表示微服务的进程类型名称。进程类型名称可以通过DSP MSPROCTYPE命令查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无 |

## 使用实例

删除进程名称为CELL\_SSG的服务进程频繁告警参数配置。

```
RMV CELLMULFAULTTHD: PROCESSNAME="CELL_SSG";
```
