# 增加HTTP本端实体组（ADD HTTPLEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加HTTP本端实体组信息，可将多个HTTP本端实体配置关联到一个组。

## 注意事项

- 该命令执行后立即生效。

- 在一个HTTP本端实体组下最多只能配置32个HTTP本端实体。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP本端实体组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~64。  默认值：无  配置原则：无     |
| DESC   | 描述     | 可选必选说明：可选参数  参数含义：该参数用于指定HTTP本端实体组的描述。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

若想添加一组HTTP本端实体组，索引为1，描述信息为nrf：

```
ADD HTTPLEGRP: INDEX=1, DESC="nrf";
```
