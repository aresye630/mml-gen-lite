# 修改LDP接口（MOD LDPIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改LDP接口。

#### 注意事项

- 该命令执行后立即生效。
- 如果修改Keepalive保持定时器值、传输地址接口名、本地LSR ID绑定接口或标签发布模式，相关LDP实例的会话重建。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称                     | 参数说明                                                                                                                                                                                                                                                                                                                                            |
|:--------------|:-------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称                  | 可选必选说明：必选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                                                                                                                                                                                        |
| IFNAME        | 接口名                      | 可选必选说明：必选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                                                                                                                                                                                                             |
| HELLOSENDTIME | Hello定时器发送时间间隔（s）        | 可选必选说明：可选参数 参数含义：该参数用于指定Hello定时器发送时间间隔。LSR使用Hello定时器周期性地发送Hello消息，向邻居LSR通告它在网络中的存在，并建立Hello邻接关系。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535，单位是秒。 默认值：无 配置原则： 缺省情况下，Hello发送定时器的值是Hello保持定时器值的1/3。当配置的Hello发送定时器的值大于Hello保持定时器的值的1/3时，实际生效的值等于Hello保持定时器的值的1/3。                                                                                            |
| HELLOHOLDTIME | Hello保持定时器值（s）           | 可选必选说明：可选参数 参数含义：该参数用于指定Hello保持定时器值。建立了Hello邻接关系的LDP对等体之间，通过周期性发送Hello报文表明自己希望继续维持这种邻接关系。如果Hello保持定时器超时，没有收到新的Hello报文，则拆除Hello邻接关系。 数据来源：本端规划 取值范围：整数类型，取值范围为3～65535，单位是秒。 默认值：无 配置原则：如果LDP会话两端Hello保持定时器协商后的值小于9秒，则按照9秒处理。                                                                                                                     |
| KASENDTIME    | Keepalive发送时间间隔（s）       | 可选必选说明：可选参数 参数含义：该参数用于指定Keepalive发送时间间隔。LDP会话建立以后，LSR启动KeepAlive发送定时器周期性地发送KeepAlive消息，用于保持LDP会话。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535，单位是秒。 默认值：无 配置原则： 缺省情况下，Keepalive发送定时器的值是Keepalive保持定时器值的1/3。当配置的Keepalive发送定时器的值大于Keepalive保持定时器的值的1/3时，实际生效的值等于Keepalive保持定时器的值的1/3。                                                                       |
| KAHOLDTIME    | Keepalive保持定时器值（s）       | 可选必选说明：可选参数 参数含义：该参数用于指定Keepalive保持定时器值。LDP对等体之间通过LDP会话连接传送的LDP协议报文（PDU）维持LDP会话，如果会话保持定时器超时，没有收到任何LDP PDU，则关闭连接，结束LDP会话。 数据来源：本端规划 取值范围：整数类型，取值范围为30～65535，单位是秒。 默认值：无 配置原则： 修改Keepalive保持定时器的值会导致相关LDP实例的会话重建。当两台设备之间有多条链路维持一个会话或本地会话和远端会话共存时，多条链路或本地和远端的Keepalive保持定时器配置的值需要保持一致，否则LDP会话可能不稳定。                                                |
| TPORTIFNAME   | 传输地址接口名                  | 可选必选说明：可选参数 参数含义：该参数用于指定传输地址接口名。传输地址是用来与对等体建立TCP连接的，因此对等体需存在到此传输地址的路由。通常使用LSR ID（Loopback接口地址）作为传输地址。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。修改LDP传输地址会导致LDP会话中断。请使用LST INTERFACE命令查看可用接口。当两台设备之间存在多条链路时，若要在多条链路上建立LDP会话，会话同一端的接口都应采用默认的传输地址，或者配置相同的传输地址。如果会话的一端接口配置了不同的传输地址，将导致LDP会话只能建立在一条链路上。                        |
| IGPSYNCDELAY  | 接口配置的IgpSynDelayTimer（s） | 可选必选说明：可选参数 参数含义：该参数用于指定IGP联动延迟时间。故障链路的LDP会话重新建立以后，LDP会启动Delay定时器等待LSP的建立，当Delay定时器超时以后，LDP都会通知IGP同步流程结束。当取值为4294967295时，表示IGPSYNCDELAY取LDP实例下配置的IGP联动延迟时间，具体取值可通过LST LDPINSTANCE命令查看。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535，4294967295，单位是秒。 默认值：无                                                                                                  |
| LSRIDIFNAME   | 本地LSR ID绑定接口             | 可选必选说明：可选参数 参数含义：该参数用于指定本地LSR ID绑定接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。修改此参数会导致LDP会话中断。请使用LST INTERFACE命令查看可用接口。                                                                                                                                                                                                  |
| LABELADVMODE  | 标签发布模式                   | 可选必选说明：可选参数 参数含义：在MPLS体系中，由下游LSR决定将标签分配给特定FEC，再通知上游LSR。即标签由下游指定，标签的分配按从下游到上游的方向分发。 具有标签分发邻接关系的上游LSR和下游LSR必须对使用的标签发布方式达成一致。 数据来源：本端规划 取值范围：枚举类型。 DU：下游自主向上游分配标签。 对于一个特定的FEC，LSR无须从上游获得标签请求消息即进行标签分配与分发。DOD：上游按需向下游请求标签。 对于一个特定的FEC，LSR获得标签请求消息之后才进行标签分配与分发。 默认值：无 配置原则： 修改此参数会导致LDP会话中断。当两台设备之间有多条链路维持一个会话或本地会话和远端会话共存时，多条链路或本地和远端的标签发布模式需要保持一致。 |

#### 使用实例

修改LDP接口：

```
MOD LDPIF:VRFNAME="_public_",IFNAME="Ethernet64/0/5",HELLOSENDTIME=15,KASENDTIME=45,KAHOLDTIME=45,TPORTIFNAME="Ethernet64/0/4",IGPSYNCDELAY=10,LSRIDIFNAME="Ethernet64/0/6",LABELADVMODE=DU;
```
