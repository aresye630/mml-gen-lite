# 清除FES操作统计信息（RTR FESOPERATIONSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除FES TABLE，PATH，RELATION的操作统计信息，以便进行重新统计。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                             |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IDENTITYFLAG | 身份标志位  | 可选必选说明：可选参数 参数含义：该参数用于表示身份标志位。 数据来源：本端规划 取值范围：枚举类型。 RUNAME：表示输入资源单元名称。COMPID：表示输入组件ID。 默认值：无 配置原则：如果不输入该参数，则表示清除所有FES操作统计信息。                                     |
| FLAGALL      | 清除类型   | 可选必选说明：可选参数 参数含义：该参数用来表示数据清除的操作类型。 数据来源：本端规划 取值范围：枚举类型。 ALL：所有类型。TABLE：Table类型。PATH：Path类型。RELATION：Relation类型。 默认值：ALL                                          |
| COMPONENTID  | 组件ID   | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAG”配置为“COMPID”时为必选参数。 参数含义：该参数用来表示组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                     |
| RUNAME       | 资源单元名称 | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAG”配置为“RUNAME”时为必选参数。 参数含义：该参数用来表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU查看资源单元信息。 |

#### 使用实例

重置FES操作统计信息：

```
RTR FESOPERATIONSTC:;
```
