# 删除IKE对等体（RMV IKEPEER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除IKE对等体，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除IKE对等体。

## 注意事项

- 该命令执行后立即生效。

- 当IKE对等体被IPsec策略引用时，IKE对等体不能被删除。如果需要删除IKE对等体，必须先删除IKE对等体的引用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------|
| PEERNAME | 对等体名称  | 可选必选说明：必选参数  参数含义：对端名字。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除名称为“peer1”的IKE对等体：

```
RMV IKEPEER:PEERNAME="peer1";
```
