# 查询CSLB VPN对应的MPE或SFE拓扑(DSP LBVPNTOPO)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询CSLB服务侧VPN对应的转发拓扑。转发拓扑由高字节TB、低字节TB以及TP信息表示，分为VPN对应的VNRS转发拓扑与VPN对应的CSLB转发拓扑

#### 注意事项

- 该命令仅限于开发和测试使用。
- 该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                  |
|:---------|:-------|:------------------------------------------------------------------------------------------------------|
| VPNNAME  | VPN名称  | 可选必选说明：必选参数 参数含义：VPN名称 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0~63 配置原则：公网填“_public_” 默认值：无                      |
| TOPOTYPE | 拓扑类型   | 可选必选说明：必选参数 参数含义：改参数用于指定是查询VNRS的拓扑还是查询CSLB的拓扑 数据来源：本端规划 取值范围：“MPE(CSLB的转发面拓扑)”“SFE(VNRS的转发面拓扑)” 默认值：无 |
| HTB      | 高字节TB  | 可选必选说明：可选参数 参数含义：表示TB的高16位。TB全称是Target Blade，即目标板 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无         |
| LTB      | 低字节TB  | 可选必选说明：可选参数 参数含义：表示TB的低32位。TB全称是Target Blade，即目标板 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无         |
| TP       | TP     | 可选必选说明：可选参数 参数含义：表示目标端口。TP全称是Target Port 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无                  |

#### 使用实例

- 查询CSLB服务侧VPN对应的转发地址信息

  `DSP LBVPNTOPO: VPNNAME="_public_", TOPOTYPE=SFE, LTB=70;`

  ```
  RETCODE = 0  操作成功

  操作结果如下:
  -------------
     VPN名称  =  _public_
    拓扑类型  =  VNRS Topo
    高字节TB  =  0
    低字节TB  =  70
         TP   =  4098
  	 状态  =  Normal
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| VPN名称   | 参数含义：表示VPN名称                          |
| 拓扑类型    | 参数含义：表示VNRS的拓扑或者是CSLB的拓扑              |
| 高字节TB   | 参数含义：表示TB的高16位。TB全称是Target Blade，即目标板 |
| 低字节TB   | 参数含义：表示TB的低32位。TB全称是Target Blade，即目标板 |
| TP      | 参数含义：表示目标端口。TP全称是Target Port          |
| 状态      | 参数含义：表示此拓扑的状态。                        |
