# 查询灰度升级所处于的阶段（LST 5GGUMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

灰度升级阶段，执行此命令，用于显示灰度升级正在进行的阶段。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示灰度升级阶段：

```
%%LST 5GGUMINFO:;%%
RETCODE = 0  操作成功

结果如下
--------
阶段  =  PreUpgrade
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 阶段      | 该参数用于标识灰度升级所处的阶段。 |
