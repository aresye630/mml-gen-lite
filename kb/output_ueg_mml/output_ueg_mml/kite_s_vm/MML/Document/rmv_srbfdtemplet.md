# 删除BFD模板（RMV SRBFDTEMPLET）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除BFD模板。

#### 注意事项

- 该命令执行后立即生效。
- 删除该BFD模板时，要保证该模板添加过。
- 可能有静态路由正在使用该模板，删除会导致静态路由与BFD取消关联，进而无法感知链路状态。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                     |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| AFTYPE      | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                                            |
| NEXTHOP     | 路由下一跳   | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                                            |
| IFNAME      | 接口名字    | 可选必选说明：可选参数 参数含义：该参数用于指定路由的传输接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 下一跳所在VPN为私网时，应输入Invalid0，不区分大小写。请使用LST INTERFACE命令查看可用接口。 |
| DESTVRFNAME | 网关地址VPN | 可选必选说明：可选参数 参数含义：该参数用于指定网关地址所属VPN。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                               |
| DHCPENABLE  | DHCP使能  | 可选必选说明：可选参数 参数含义：该参数用于指定DHCP使能标志。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                        |

#### 使用实例

删除一个BFD模板，BFD模板的网关地址为10.1.1.1：

```
RMV SRBFDTEMPLET: NEXTHOP="10.1.1.1",AFTYPE=ipv4unicast,DESTVRFNAME="_public_", IFNAME="ethernet64/0/5";
```
