# 查询IPv6 ND系统配置（LST NDGLOBALCONFIG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv6 ND全局配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv6 ND全局配置：

```
LST NDGLOBALCONFIG:;
```

```
RETCODE = 0   操作成功

结果如下
------------------------
     使能预探测  =  关闭
   使能自动探测  =  开启
           跳限  =  101
       速率限制  =  0
  失效时间（s）  =  1200
(结果个数 = 1)
---    END
```
