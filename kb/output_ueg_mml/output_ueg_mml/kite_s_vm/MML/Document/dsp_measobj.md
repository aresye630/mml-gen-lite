# 查询话统测量对象实例(DSP MEASOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

通过DSP MEASOBJ命令可获得网元上的话统测量对象实例，用于**DSP MEASRST**查询网元上的话统测量结果。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                   |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID    | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST MELST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                          |
| MOCID   | 测量对象类ID | 可选必选说明：可选参数。 参数含义：测量对象类ID，可以通过LST MEASUNIT命令查询获取。 取值范围：0~4294967294的整数。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。             |
| MOCNAME | 测量对象类名称 | 可选必选说明：可选参数。 参数含义：测量对象类名称，支持中英文模糊搜索，可以通过LST MEASUNIT命令查询获取。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。 |
| MOIID   | 对象实例ID  | 可选必选说明：可选参数。 参数含义：对象实例ID，支持中英文模糊搜索。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                         |

## 使用实例

1. 查询网元话统测量对象实例信息：

   ```
   %%DSP MEASOBJ: MEID=55, MOCID=1100009;%%
   RETCODE = 0  操作成功

   测量实例信息
   ------------
   测量对象类ID  测量对象类名称  对象实例ID  对象实例名称

   1100009       对象9           Moc9-1      网卡1    
   1100009       对象9           Moc9-2      网卡2  
   1100009       对象9           Moc9-3      网卡3  
   1100009       对象9           Moc9-4      网卡4  
   1100009       对象9           Moc9-5      网卡5  
   1100009       对象9           Moc9-6      网卡6  
   (结果个数 = 6)

   测量实例汇总
   ------------
   对象实例个数  =  6
       提示信息  =  查询结果的数量较多(>1000条),只返回部分结果
   (结果个数 = 1)

   ---    END
   ```
