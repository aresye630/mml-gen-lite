# 显示PAE OAM链路信息（DSP FABRICOAMINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示Fabric OAM链路状态信息。

#### 注意事项

- 该命令执行后立即生效。
- 在sriov bonding模式下链路级探测不再可信，链路探测状态显示为init，此状态无效不代表探测结果。可执行MML命令**DSP PAEPORTINFO**查询绑定模式是否为是。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |
| REMOTERETB   | 远端节点TB | 可选必选说明：可选参数 参数含义：该参数用于指定远端节点的资源ID。 数据来源：本端规划 取值范围：整数类型，0~4294967295。 默认值：无                                                                                              |

#### 使用实例

- 显示微服务类型“CCellCpcSrv”微服务类型实例 "2491301"到所有远端资源的Fabric OAM链路状态信息：

  ```
  DSP FABRICOAMINFO:CELLTYPE="CCellCpcSrv", CELLINSTANCE="2491301";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  -------------------------
  微服务类型   微服务实例号   本端节点TB      远端节点TB  本端端口名称  远端端口名称   链路状态  链路所在平面ID  

  CCellCpcSrv  2491301        1035            1034        uio0          uio1           正常      0         
  CCellCpcSrv  2491301        1035            1034        uio6          uio7           正常      1    
  (结果个数 = 2)

  ---    END
  ```
- 查询微服务类型“CCellCpcSrv”微服务类型实例 "2491301"到远端资源“1034”的Fabric OAM链路状态信息：

  ```
  DSP FABRICOAMINFO:CELLTYPE="CCellCpcSrv", CELLINSTANCE="2491301", REMOTERETB=1034;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  -------------------------
  微服务类型   微服务实例号   本端节点TB      远端节点TB  本端端口名称  远端端口名称   链路状态  链路所在平面ID  

  CCellCpcSrv  2491301        1035            1034        uio0          uio1           正常      0         
  CCellCpcSrv  2491301        1035            1034        uio6          uio7           正常      1    
  (结果个数 = 2)

  ---    END
  ```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                                       |
|:---------|:--------------------------------------------------------------------------------------------|
| 微服务类型    | 用于指定微服务类型。                                                                                  |
| 微服务实例号   | 用于指定微服务实例号。                                                                                 |
| 本端节点TB   | 用于指定本端的端点TB。                                                                                |
| 远端节点TB   | 用于指定远端的端点TB。                                                                                |
| 本端端口名称   | 用于指定本端端口名称。                                                                                 |
| 远端端口名称   | 用于指定远端端口名称。                                                                                 |
| 链路状态     | 用于表示链路当前状态。 注意：于bond模式下链路级探测不再可信，因此不包含OAM及链路级亚健康检测功能 链路状态枚举类型： 初始化：初始化状态。正常：链路已链接。中断：链路已中断。 |
| 链路所在平面ID | 用于表示链路所在平面ID，双平面0或者1。                                                                       |
