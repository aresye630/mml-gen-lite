# 增加HTTP资源流控门限（ADD HTTPRESCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加HTTP资源流控门限信息。

## 注意事项

- 该命令执行后立即生效。

- 执行本命令前，需要确认资源流控功能已开启，可通过**LST HTTPCONF**/xref>查看。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                   |
|:-----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX      | HTTP资源门限索引 | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP资源门限的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4096。  默认值：无  配置原则：无                                                                                |
| RESTYPE    | 资源类型       | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP资源类型。  数据来源：本端规划 取值范围： “REQCB（REQCB）”：REQCB  默认值：无  配置原则：无                                                                                |
| LETYPE     | 本端实体类型     | 可选必选说明：该参数在"RESTYPE"配置为"REQCB"时为条件必选参数。  参数含义：该参数用于指定HTTP本端实体的类型。  数据来源：本端规划 取值范围： “CLIENT（客户端）”：客户端“SERVER（服务端）”：服务端  默认值：无  配置原则：  HTTP本端实体可以作为服务端也可以作为客户端，两者需要分别配置。 |
| PEERIPTYPE | 对端地址IP类型   | 可选必选说明：该参数在"RESTYPE"配置为"REQCB"时为条件必选参数。  参数含义：该参数用于指定配置的对端地址的IP类型。  数据来源：本端规划 取值范围： “IPv4（IPv4地址）”：IPv4地址“IPv6（IPv6地址）”：IPv6地址  默认值：无  配置原则：无                          |
| PEERIPV4   | 对端IPv4地址   | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定对端IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                             |
| PEERIPV6   | 对端IPv6地址   | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定对端IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                             |
| THRESHOLD  | 资源门限       | 可选必选说明：该参数在"RESTYPE"配置为"REQCB"时为条件必选参数。  参数含义：该参数用于指定资源门限。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295，单位是个。  默认值：无  配置原则：  当资源类型为REQCB时，该参数需要配置为1-32640。                  |

## 使用实例

增加HTTP资源流控门限，索引为1，资源类型为REQCB，本端实体类型为CLIENT，对端IP类型为IPv4，对端IP地址为192.168.1.1，资源门限为100，可以用如下命令：

```
ADD HTTPRESCFG: INDEX=1, RESTYPE=REQCB, LETYPE=CLIENT, PEERIPTYPE=IPv4, PEERIPV4="192.168.1.1", THRESHOLD=100;
```
