# 增加TLS预共享密钥组（ADD TLSPSKGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加预共享密钥组。

当需要建立HTTPS链路且使用预共享密钥方式进行认证时，可通过此命令添加预共享密钥组，用于关联一个或多个预共享密钥。

客户端发起建链时会随机选择组内某一个预共享密钥，并在TLS建链消息中携带预共享密钥标识。服务端从TLS建链消息中提取预共享密钥标识，匹配组内预共享密钥标识，获取对应的预共享密钥进行建链协商。

当需要平滑替换某个预共享密钥，可先后在服务端和客户端通过命令**ADD TLSPSK**在同一组内添加新的预共享密钥信息，然后先后在客户端和服务端执行**RMV TLSPSK**命令删除不再使用的预共享密钥信息，保证业务无损。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入128条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                       |
|:----------|:---------|:-------------------------------------------------------------------------------------------|
| PSKGRPIDX | 预共享密钥组索引 | 可选必选说明：必选参数  参数含义：该参数用于指定TLS预共享密钥组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无    |
| DESC      | 描述       | 可选必选说明：可选参数  参数含义：该参数用于指定TLS预共享密钥组的描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

若需要添加一个预共享密钥组，组索引为1，可以执行如下命令：

```
ADD TLSPSKGRP: PSKGRPIDX=1;
```
