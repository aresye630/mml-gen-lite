# 修改服务化接口本端实体（MOD SBIAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改服务化接口本端实体的描述信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------|
| INDEX       | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定服务化接口本端实体的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无      |
| DESCRIPTION | 描述     | 可选必选说明：可选参数  参数含义：该参数用于配置服务化接口本端实体的描述信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

若运营商想修改索引为1的服务化接口本端实体的描述信息为"smf"，可以执行如下命令：

```
MOD SBIAPLE: INDEX=1, DESCRIPTION="smf";
```
