# 修改流行为安全URPF（MOD SQOSURPF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改流行为下的URPF（单播反向路由转发）配置。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                       |
|:-------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 流行为名称    | 可选必选说明：必选参数 参数含义：该参数用于指定流行为名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                     |
| URPFTYPE     | URPF检查类型 | 可选必选说明：必选参数 参数含义：该参数用于指定安全URPF增强型检查。 数据来源：本端规划 取值范围：枚举类型。 strict：严格检查：不但要求在转发表中存在相应表项，还要求接口一定匹配才能通过URPF检查。loose：松散检查：只要在转发表中存在表项就通过URPF检查，不要求接口一定匹配。 默认值：无 |
| URPFDEFAULT  | 匹配默认路由   | 可选必选说明：必选参数 参数含义：该参数用于指定默认安全URPF。 数据来源：本端规划 取值范围：枚举类型。 disallow：不接受。allow：接受。 默认值：无                                                                        |

#### 使用实例

修改流行为下的安全URPF配置：

```
MOD SQOSURPF:BEHAVIORNAME="b1",URPFTYPE=loose,URPFDEFAULT=allow;
```
