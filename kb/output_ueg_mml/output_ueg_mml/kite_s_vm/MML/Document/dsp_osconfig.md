## 命令功能

**须知** 

执行重启，重建，扩容等涉及OS启动的动作后，立即查询相应节点网卡组播开关状态可能与预期配置不同，节点会在OS启动后30分钟内自动同步网卡组播开关配置。如需确认网卡组播开关状态，请30分钟后查询。

执行重启，重建，扩容等涉及OS启动的动作后，立即查询相应节点内存压缩状态可能与预期配置不同，节点会在OS启动后30分钟内自动同步内存压缩状态配置。如需确认内存压缩状态，请30分钟后查询。

执行重启，重建，扩容等涉及OS启动的动作后，立即查询相应节点DHE算法可能与预期配置不同，节点会在OS启动后30分钟内自动同步DHE算法配置。如需确认DHE算法配置，请30分钟后查询。

该命令用于查询OS配置。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 当环境出现网卡变更（例如：新增网卡、网卡故障、新增容器和容器重启等）的情况时，可能会使节点网卡组播状态不一致。建议再次执行**SET OSCONFIG**命令开启/关闭网卡组播能力。
- 查询指定操作类型时，若某一节点状态异常导致查询失败，该节点的查询信息会显示NULL。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                            |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| OPERATETYPE | 操作类型   | 可选必选说明：必选参数。 参数含义：用于查询OS配置的操作类型。 取值范围： “MULTICAST（组播）”：OS配置为组播类型。“MEMSWAP（内存压缩）”：OS配置为内存压缩类型。“DHEALGORITHM（DHE算法）”：OS配置为DHE算法类型。 默认值：无。 配置原则：无。 |
| MEID        | 网元ID   | 可选必选说明：当“操作类型”为“MEMSWAP（内存压缩）”时为条件可选参数。 参数含义：用于指示系统需要设置指定网元ID下的节点数据。“网元ID”可以通过执行LST ME查询。 取值范围：0~65535。 默认值：无。 配置原则：无。                          |

## 使用实例

“操作类型”为“MULTICAST（组播）”时， 结果以进度上报形式展示，此处只显示最终结果数据：

```
%%DSP OSCONFIG: OPERATETYPE=MULTICAST;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
节点IP    操作类型  状态  

10.0.0.0  组播      关闭     
10.0.0.0  组播      关闭     
10.0.0.0  组播      关闭     
10.0.0.0  组播      关闭     
(结果个数 = 4)

共有5个报告
---    END
```

“操作类型”为“MEMSWAP（内存压缩）”时， 结果以进度上报形式展示，此处只显示最终结果数据：

```
%%DSP OSCONFIG: OPERATETYPE=MEMSWAP;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
网元ID  节点IP    虚拟机类型  开关 

0       10.0.0.0  CSP_B       关闭  
0       10.0.0.0  CSP_C       关闭
0       10.0.0.0  CSP_A       关闭   
(结果个数 = 3)

共有5个报告
---    END
```

“操作类型”为“DHEALGORITHM（DHE算法）”时， 结果以进度上报形式展示，此处只显示最终结果数据：

```
%%DSP OSCONFIG: OPERATETYPE=DHEALGORITHM;%% 
RETCODE = 0  操作成功  

操作结果如下 
------------

10.0.0.2     DHE算法   3072          
10.0.0.3     DHE算法   3072          
10.0.0.4     DHE算法   3072          
(结果个数 = 4)  

共有5个报告 
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称   | 输出项解释                                                                                                                                           |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 当“操作类型”为“MEMSWAP（内存压缩）”时输出。节点所属的网元ID。                                                                                                           |
| 节点IP    | 节点网络地址。                                                                                                                                         |
| 操作类型    | 当“操作类型”为“MULTICAST（组播）”或“DHEALGORITHM（DHE算法）”时为输出。 操作类型。 取值范围： “组播”：操作类型为组播类型。 “DHE算法”：操作类型为DHE算法类型。                                            |
| 状态      | 当“操作类型”为“MULTICAST（组播）”时为输出。用于返回本次查询的节点网卡组播状态（不包括lo、veth和gre0网卡）。 取值范围： “开”：节点网卡组播状态为开。“关”：节点网卡组播状态为关。“不一致”：节点网卡组播状态存在多种状态。“NULL”：节点网卡组播状态获取失败。 |
| 虚拟机类型   | 当“操作类型”为“MEMSWAP（内存压缩）”时为输出。 虚拟机类型。                                                                                                             |
| 开关      | 当“操作类型”为“MEMSWAP（内存压缩）”时为输出。 取值范围： “开”：节点内存压缩开关为开。“关”：节点内存压缩开关为关。“NULL”：节点内存压缩开关获取失败。                                                           |
| DHE密钥长度 | 当“操作类型”为“DHEALGORITHM（DHE算法）”时为输出。 取值范围： “2048”：节点DHE算法密钥长度为2048。“3072”：节点DHE算法密钥长度为3072。“NULL”：节点DHE算法密钥长度获取失败。                                |

|    错误码 | 错误码解释   | 原因分析     | 处理建议       |
|-------:|:--------|:---------|:-----------|
| 130013 | 操作失败    | 内部执行报错   | 请联系华为技术支持。 |
| 131501 | 部分成功    | 部分节点操作失败 | 请联系华为技术支持。 |
