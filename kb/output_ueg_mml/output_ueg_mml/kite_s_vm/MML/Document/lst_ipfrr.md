# 查询IP FRR（LST IPFRR）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查看当前设置的IP FRR功能情况。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                           |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：如果不配置此参数，则查询所有VPN的IP FRR功能情况。                                                    |
| AFTYPE  | 地址族     | 可选必选说明：可选参数 参数含义：该参数用于指定地址族类型。支持IPv4和IPv6单播地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 配置原则：如果不配置此参数，则查询IPv4和IPv6单播地址族下的IP FRR功能情况。 |

#### 使用实例

查询IPv4 FRR配置情况：

```
LST IPFRR:AFTYPE=ipv4unicast;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
地址族      VPN实例名称       是否使能FRR
IPv4单播    _public_          FALSE
IPv4单播    __mpp_vpn_inner__ TRUE
(结果个数 = 2)
---    END
```
