# 显示SSH客户端的错误日志（DSP SSHCERRORLOG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询SSH客户端的错误日志。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询SSH客户端的错误日志：

```
DSP SSHCERRORLOG:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
------------------------
    时间  =  2016-08-04, 20:45:32:445
日志信息  =  Session disconnected.(ServiceType=stelnet, UserName=Could not extract user name, IPAddress=10.179.175.55, FailedReason=SSH connection was aborted by user.)
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| 时间      | 日志时间。   |
| 日志信息    | 日志信息。   |
