# 查询转发过载告警参数（LST SFELOADALARM）

#### 命令功能

该命令用于查询转发过载告警参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                      |
|:-------------|:-------|:--------------------------------------------------------------------------|
| OVERLOADTYPE | 过载类型   | 可选必选说明：必选参数 参数含义：该参数用于表示转发过载告警的类型。 数据来源：本端规划 取值范围：枚举类型。 queue：队列告警。 默认值：无 |

#### 使用实例

查询转发过载告警参数：

```
LST SFELOADALARM:OVERLOADTYPE=queue;
```

```
RETCODE = 0 操作成功。

结果如下
-------------------------
  触发阈值（%）= 92
  恢复阈值（%）= 60
 检测间隔（ms）= 1000
      检测次数 = 10
(结果个数 = 1)
--- 结束
```
