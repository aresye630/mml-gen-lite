# 显示dopra相关内存信息（DSP MEMORYINSPECT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示dopra相关内存信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                               |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程ID   | 可选必选说明：必选参数 参数含义：该参数表示进程编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                           |
| COMMAND         | 命令     | 可选必选说明：必选参数 参数含义：该参数表示dopra查询命令。当前支持brief命令，PARAMETER1表示分区号，PARAMETER2无意义。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |
| PARAMETER1      | 参数1    | 可选必选说明：可选参数 参数含义：该参数表示dopra查询命令参数1。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                   |
| PARAMETER2      | 参数2    | 可选必选说明：可选参数 参数含义：该参数表示dopra查询命令参数2。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                   |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。       |

#### 使用实例

显示dopra相关内存信息：

```
DSP MEMORYINSPECT:PROCID=3,COMMAND="brief",PARAMETER1=3,SERVICEINSTANCE="vnfc";
```
