# 修改接口下安全配置（MOD IPV6IFICMPSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改接口下安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                          |
|:-----------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCHOP   | 开关        | 可选必选说明：必选参数 参数含义：该参数用于表示是否使能开关。 数据来源：本端规划 取值范围：枚举类型。 disable：去使能。enable：使能。 默认值：无                                                                                                                                             |
| IFNAME     | 接口名       | 可选必选说明：必选参数 参数含义：该参数用于表示接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                                                                                           |
| ACTION     | 发送还是接收    | 可选必选说明：必选参数 参数含义：该参数用于表示对ICMP数据包采取的操作的类型。 数据来源：本端规划 取值范围：枚举类型。 rcvPkt：接收报文。sndPkt：发送报文。 默认值：无                                                                                                                                 |
| CONFIGTYPE | 配置的类型     | 可选必选说明：必选参数 参数含义：该参数用于表示配置的类型。 数据来源：本端规划 取值范围：枚举类型。 USER：用户自定义。PKTTYPE：报文类型。 默认值：无                                                                                                                                            |
| ICMPTYPE   | 收发报文的TYPE | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数用于表示ICMP6报文类型。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                              |
| ICMPCODE   | 收发报文的CODE | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数用于表示ICMP6报文编码。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                              |
| PKTTYPE    | 报文类型      | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“PKTTYPE”时为必选参数。 参数含义：该参数用于表示报文类型。 数据来源：本端规划 取值范围：枚举类型。 HOST_UNREATCHABLE：主机不可达（Type=1, Code=3）。PORT_UNREATCHABLE：端口不可达（Type=1, Code=4）。HOP_LIMIT_EXCEEDED：TTL超时（Type=3, Code=0）。 默认值：无 |

#### 使用实例

修改接口下安全配置：

```
MOD IPV6IFICMPSECURITY:IFNAME="Ethernet65/0/8",ACTION=sndPkt,CONFIGTYPE=PKTTYPE,PKTTYPE=HOST_UNREATCHABLE,SWITCHOP=enable;
```
