# 显示进程定时器计数信息（DSP RESPROCTIMERSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示进程内的定时器使用信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                             |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| RESOURCENAME | 资源名称   | 可选必选说明：可选参数 参数含义：用于说明节点名称或容器名称。通过DSP RES命令可以查询资源信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：当不输入时显示所有的节点或容器的信息。 |
| PROCID       | 进程ID   | 可选必选说明：可选参数 参数含义：用于说明进程的编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                         |

#### 使用实例

显示进程内的定时器使用情况：

```
DSP RESPROCTIMERSTAT:RESOURCENAME="OMU1";
```

#### 输出结果说明

| 输出项名称    | 输出项解释                              |
|:---------|:-----------------------------------|
| 进程ID     | 用于说明进程的编号。                         |
| 资源名称     | 用于说明节点名称或容器名称。通过DSP RES命令可以查询资源信息。 |
| 绝对定时器数目  | 用于说明进程内的绝对定时器的数目。                  |
| 相对定时器数目  | 用于说明进程内的相对定时器的数目。                  |
| APP定时器数目 | 用于说明进程内的APP定时器的数目。                 |
