# 显示基于表无线路由平滑统计信息（DSP WLRTBLSMTHINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示基于表无线路由统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                           |
|:--------|:--------|:-----------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写。 默认值：_public_            |
| AFTYPE  | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于表示地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |

#### 使用实例

显示基于表无线路由平滑统计信息：

```
DSP WLRTBLSMTHINFO:AFTYPE=ipv4unicast;
```
