# 硬盘分区扩容(ACT DPSCALEUP)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

在硬盘分区自动扩容失败的情况下，可以通过本命令触发硬盘分区扩容。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                             |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUID            | RU ID  | 可选必选说明：可选参数 参数含义：本参数用于指定需要进行硬盘分区扩容的RU ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294 默认值：无                                                                           |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的RU状态查询。 |

#### 使用实例

不指定RU进行硬盘分区扩容：

```
ACT DPSCALEUP:SERVICEINSTANCE="CSLB_VNFC_999";
```
