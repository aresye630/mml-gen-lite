# 设置事件开关状态（SET EVTSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置指定服务指定事件的开关状态。当使用**SET EVTHEALCTRL**命令开启整系统事件自愈功能时，可使用本命令设置指定事件的开关状态。当使用**SET EVTHEALCTRL**命令关闭整系统事件自愈功能时，无法使用本命令开启指定事件的自愈功能。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICE | 服务名称   | 可选必选说明：必选参数  参数含义：该参数表示事件绑定的服务名称。可以通过LST EVTSW命令获取参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~16。  默认值：无。  配置原则：无                                   |
| EVENTID | 事件ID   | 可选必选说明：必选参数  参数含义：该参数用于表示服务名称下的事件ID，可以通过LST EVTSW命令获取参数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无。  配置原则：  只支持配置LST EVTSW命令获取到的服务实例。 |
| SWITCH  | 事件开关   | 可选必选说明：必选参数  参数含义：该参数用于表示事件的开关状态。  数据来源：本端规划 取值范围： “ENABLE（打开）”：自愈使能“DISABLE（不使能）”：自愈不使能  默认值：无。  配置原则：无                                    |

## 使用实例

设置事件1自愈开关为开。

```
%%SET EVTSW: SERVICE="SDRS", EVENTID=1, SWITCH=ENABLE;%%
RETCODE = 0  操作成功
```
