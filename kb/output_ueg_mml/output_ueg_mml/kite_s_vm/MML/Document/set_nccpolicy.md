## 命令功能

**须知** 

该命令设置后可能影响特定微服务的内存，需谨慎执行。

该命令用于设置NCC策略。

## 注意事项

该命令为ACS内部设置策略命令，不支持MML导出功能。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                      |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYITEM  | 策略标识   | 可选必选说明：必选参数。 参数含义：用于指定待设置策略的策略标识。 取值范围：枚举类型。 MemOptFlag(内存优化开关策略)：特定微服务的内存优化功能开关标志，默认开启。 默认值：无。 配置原则： MemOptFlag(内存优化开关策略) 默认打开，只有手动设置关闭的情况下才可能生效。MemOptFlag(内存优化开关策略) 设置关闭后，对应的微服务重启后生效。 |
| POLICYVALUE | 策略内容   | 可选必选说明：该参数在“策略标识”配置为“MemOptFlag(内存优化开关策略)”时为条件必选参数。 参数含义：用于指定对应策略的开关。 取值范围：枚举类型。OFF(关闭)：该策略关闭。ON(开启)：该策略开启。 默认值：无。                                                                        |

## 使用实例

设置NCC内存优化开关“策略内容”为“OFF(关闭)”时，执行以下命令：

```
SET NCCPOLICY: POLICYITEM=MemOptFlag, POLICYVALUE=OFF;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
