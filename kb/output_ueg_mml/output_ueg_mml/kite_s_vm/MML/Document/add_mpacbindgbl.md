# 增加MPAC全局策略（ADD MPACBINDGBL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置全局MPAC策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2。
- MPAC策略全局绑定仅支持绑定IPv4、IPv6策略各一条。
- 不支持修改命令，必须先删除原来绑定的策略，然后重新增加。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION    | IP版本     | 可选必选说明：必选参数 参数含义：该参数用于指定IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：无                                                 |
| POLICYNAMEV4 | IPv4策略名称 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定IPv4策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无 |
| POLICYNAMEV6 | IPv6策略名称 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定IPv6策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无 |

#### 使用实例

配置MPAC全局策略：

```
ADD MPACBINDGBL:IPVERSION=IPv4,POLICYNAMEV4="policyV4";
```
