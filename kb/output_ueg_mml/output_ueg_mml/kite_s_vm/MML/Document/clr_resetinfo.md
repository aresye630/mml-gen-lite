# 清除资源单元复位信息（CLR RESETINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除资源单元复位信息。当不需要查看资源单元的历史复位信息时，执行该命令可以用来清除资源单元复位信息。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令后，用户将无法查到该命令生效时间点之前的资源单元复位信息。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| RUNAME          | 资源单元名称 | 可选必选说明：可选参数 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用DSP RU查看RU名称。                 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

用于清除资源单元复位信息：

```
CLR RESETINFO:RUNAME="CSDB_OM_RU_0001",SERVICEINSTANCE="vnfc";
```
