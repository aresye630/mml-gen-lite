# 清除接收方向协议报文统计计数（RTR HOSTRCVSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除接收方向协议报文统计计数。

当清除类型为IF\_STC，不指定PROTTYPE参数时，清除所有协议类型的统计信息；当指定PROTTYPE参数时，可以清除指定协议类型的统计信息。

当清除类型为PROT\_STC，不指定IFNAME参数时，清除所有接口的统计信息；当指定IFNAME参数时，可以清除指定接口的统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| IFNAME   | 接口名称   | 可选必选说明：条件可选参数 前提条件：该参数在“RSTTYPE”配置为“PROT_STC”时为可选参数。 参数含义：该参数用于表示接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

#### 使用实例

- 清除接收方向所有接口上的协议报文统计计数：

  ```
  RTR HOSTRCVSTC: RSTTYPE=PROT_STC;
  ```
- 清除接收方向指定接口上的协议报文统计计数：

  ```
  RTR HOSTRCVSTC: RSTTYPE=PROT_STC, IFNAME="GigabitEthernet0/0/1";
  ```
- 清除接收方向指定协议类型的协议报文统计计数：

  ```
  RTR HOSTRCVSTC: RSTTYPE=IF_STC, PROTTYPE=ARP;
  ```
