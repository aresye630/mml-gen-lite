# 查询CSDB数据特征（DSP DBDATAFEATURE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB的数据特征信息，包括数据特征值、数据特征在记录的偏移和数据特征的角色。

#### 注意事项

针对参数"CSTYPE" （客户端服务端类型）取值为“CLIENT”的查询，存在如下约束：

- 通过命令**DSP DBINSTANCE**查询CSDB子实例信息时， 返回信息中初始容量和总容量为0的不支持查询。
- 通过命令**DSP DBINSTANCE**查询CSDB子实例信息时， 返回信息中初始容量和总容量不为0，但是通过命令**DSP DBPLUGIN**查询CSDB插件信息时，返回信息为“NLS或插件不存在”的不支持查询。
- 通过命令**DSP DBINSTANCE**查询CSDB子实例信息时， 返回信息中初始容量和总容量不为0，且通过命令**DSP DBPLUGIN**能成功查询到CSDB插件信息时，支持查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                          |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID     | 子实例标识    | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一个子实例，可以通过DSP DBINSTANCE命令查询获取。 数据来源：本端规划 取值范围：1～100。 默认值：无。                                                       |
| CSTYPE         | 客户端服务端类型 | 可选必选说明：必选参数。 参数含义：该参数用于指定客户端还是服务端。 数据来源：本端规划 取值范围：“CLIENT”：显示客户端的数据特征。“SERVER”：显示服务端的数据特征。 默认值：无。                                             |
| TBLID          | 数据表标识    | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一张数据表，可以通过DSP DBTBL命令查询获取。 数据来源：本端规划 取值范围：0～1023。 默认值：无。                                                           |
| DATAFEATUREOPT | 数据特征选项   | 可选必选说明：必选参数。 参数含义：该参数用于指定数据特征选项。 数据来源：本端规划 取值范围：“ALL_FEATURE”：显示所有数据特征。“SPEC_PLUGINID”：显示指定插件的数据特征。“SPEC_FEATURE”：显示指定的数据特征。 默认值：ALL_FEATURE。 |
| PLUGINID       | 插件标识     | 可选必选说明：条件必选参数。 参数含义：该参数用于指定插件标识，可以通过DSP DBPLUGIN命令查询获取。 前提条件：该参数在“DATAFEATUREOPT”参数设置为“SPEC_PLUGINID”后生效。 数据来源：本端规划 取值范围：0～4294967295。 默认值：无。 |
| DATAFEATURE    | 数据特征     | 可选必选说明：条件必选参数。 参数含义：该参数用于指定数据特征。 数据来源：本端规划 前提条件：该参数在“DATAFEATUREOPT”参数设置为“SPEC_FEATURE”后生效。 取值范围：0～4294967295。 默认值：无。                         |

`DSP DBDATAFEATURE: INSTANCEID=1, CSTYPE=SERVER, TBLID=11, DATAFEATUREOPT=SPEC_PLUGINID, PLUGINID=50000022;`

#### 输出结果说明

| 输出项名称       | 输出项解释                              |
|:------------|:-----------------------------------|
| 子实例标识       | 唯一标识一个子实例。 取值范围：1～100。             |
| 数据表标识       | 唯一标识一张数据表。 取值范围：0～1023。            |
| 数据特征        | 数据特征。 取值范围：0～4294967295。           |
| 数据特征偏移      | 数据特征在记录的偏移。 取值范围：0～4294967295。     |
| 数据特征角色      | 数据特征角色。 取值范围： 生产者。消费者。             |
| 虚拟化网络功能组件标识 | 客户端进程所在的VNFC标识。 取值范围：0～4294967295。 |
| 插件标识        | 客户端进程指定的插件标识。 取值范围：0～4294967295。   |
