# 查询NP安全防攻击CAR规则(LST NPSECPOLICYCAR)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询IP的安全防攻击CAR规则。

#### 注意事项

该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CARTYPE | 安全协议类型 | 可选必选说明：可选参数 参数含义：该参数用于指定安全协议类型。 数据来源：本端规划 取值范围：枚举类型 OSPF：OSPF协议。 LDP：LDP协议。IPV6_OSPF：IPV6_OSPF协议。IPV6_BGP：IPV6_BGP协议。IPV6_RA：IPV6_RA协议。IPV6_NS：IPV6_NS协议。GRE：GRE协议。IPV6_NA：IPV6_NA协议。BGP：BGP协议。IPV6_TOO_BIG：IPV6_TOO_BIG协议。Trace：IP Trace协议。UNKNOWN：未知协议。IPV6_RS：IPV6_RS协议。ARP_MISS：ARP_MISS协议。IPV4_MFIB_MISS：IPV4_MFIB_MISS协议。IPV6_ICMP：IPV6_ICMP协议。IGMP：IGMP协议。BFD_Trace：BFD_Trace协议。ARP：ARP协议。IPV6_DHCP：IPV6_DHCP协议。PIM：PIM协议。BFD：BFD协议。ICMP：ICMP协议。DHCP：DHCP协议。TOTAL_CAR：TOTAL_CAR。 默认值：无 |

#### 使用实例

- 查询ARP协议的安全防攻击CAR规则：

  ```
  LST NPSECPOLICYCAR: CARTYPE=ARP;
  ```

  ```
  RETCODE = 0  操作成功

  峰值突发尺寸（bytes）  =  0 
  (结果个数 = 1)

  ---    END
  ```
