# 强制推送集群管理数据（SYN CMFDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行后可能引起性能下降，且频繁操作会导致CPU升高，请谨慎使用并联系华为技术支持协助操作。

该命令用于集群管理服务向客户端强制同步集群管理数据。

## 注意事项

- 等待180s集群管理数据同步完成后生效

- 该命令用于数据不一致导致紧急问题时强制推送全量集群管理数据，非紧急情况下请勿执行。
- 为避免频繁执行对系统性能产生冲击，该命令在三分钟之内只能执行一次。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                 |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| SYNCMODE | 推送模式   | 可选必选说明：必选参数  参数含义：该参数用于指定以何种方式进行强制数据同步。  数据来源：本端规划 取值范围： “ALL（所有）”：CMF向所有客户端强制推送集群管理数据。“BYPODID（Pod ID）”：CMF向指定的Pod强制推送集群管理数据。  默认值：无  配置原则：无        |
| PODID    | Pod ID | 可选必选说明：该参数在"SYNCMODE"配置为"BYPODID"时为条件必选参数。  参数含义：该参数用于指定Pod进行强制数据同步。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：  Pod ID可以通过DSP PODINFO命令查询。 |

## 使用实例

指定Pod同步集群管理数据，PodID为vup-pod-0。

```
%%%%SYN CMFDATA: SYNCMODE=BYPODID, PODID="vup-pod-0";%%
RETCODE = 0  操作成功

---    END
```
