# 文件传输（FTR FILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于使用SFTP协议进行文件传输操作。

#### 注意事项

- SFTP异步传输文件可通过事件日志确认结果。
- 本地文件路径为用户目录下的相对路径或用户设置的路径。
- 该命令仅提供文件传输的通用能力，不提供其他能力（如服务器端文件的类型、大小校验等）。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称      | 参数说明                                                                                                         |
|:------------------|:----------|:-------------------------------------------------------------------------------------------------------------|
| TRANSFERPROTOCOL  | 传输协议      | 可选必选说明：必选参数 参数含义：该参数用于表示传输协议。 数据来源：本端规划 取值范围：枚举类型。 sftp：SFTP传输协议。 默认值：无                                      |
| COMMANDTYPE       | 操作类型      | 可选必选说明：必选参数 参数含义：该参数用于表示操作类型。 数据来源：本端规划 取值范围：枚举类型。 get：get操作。put：put操作。 默认值：无                                |
| IPVERSION         | 服务器地址族    | 可选必选说明：可选参数 参数含义：该参数用于指定服务器地址族。 数据来源：对端协商 取值范围：枚举类型。 IPv4：IPv4。IPv6：IPv6。 默认值：IPv4                           |
| SERVERIPV4ADDRESS | 服务器IPv4地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于表示服务器IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无          |
| SERVERIPV6ADDRESS | 服务器IPv6地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于表示服务器IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无          |
| SERVERPORT        | 服务器端口号    | 可选必选说明：必选参数 参数含义：该参数用于表示服务器端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65535。 默认值：无                                      |
| USERNAME          | 用户名       | 可选必选说明：必选参数 参数含义：该参数用于表示用户名。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～253。 默认值：无                                        |
| PASSWORD          | 密码        | 可选必选说明：可选参数 参数含义：该参数用于表示密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～128。仅支持明文输入。 默认值：无                                  |
| LOCALFILENAME     | 本地文件名称    | 可选必选说明：必选参数 参数含义：该参数用于表示本地文件名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无                                     |
| REMOTEFILENAME    | 服务器端文件名称  | 可选必选说明：必选参数 参数含义：该参数用于表示服务器端文件名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无                                   |
| SERVICEINSTANCE   | 服务实例      | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

使用SFTP协议进行文件传输操作：

```
FTR FILE:TRANSFERPROTOCOL=sftp,COMMANDTYPE=put,IPVERSION=IPv4,SERVERIPV4ADDRESS="192.168.1.11",SERVERPORT=22,USERNAME="root",PASSWORD="*****",LOCALFILENAME="local.sh",REMOTEFILENAME="/var/sftp/remote.sh",SERVICEINSTANCE="vnfc";
```
