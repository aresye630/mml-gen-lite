# 激活流串接功能

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当需要通过部署增值业务提升用户体验或运营收益时，请参考本节激活流串接功能。

## 必备事项

前提条件

- 请仔细阅读流串接功能。
- 已通过OM Portal登录“第三方应用操作维护入口”界面。
- 本特性受License控制，请先完成加载License。
- 已根据网络规划获取表1中数据及表中各参数间的关联关系。

数据

| 参数      | 取值样例                       | 所属页面   | 说明                                                                                 |
|:--------|:---------------------------|:-------|:-----------------------------------------------------------------------------------|
| FG名称    | FG1                        | 创建FG   | -                                                                                  |
| VLAN ID | 800                        | 创建FG   | FG与业务链VLAN的关联关系，业务链VLAN为app External（Chain）平面的VLAN值。                               |
| 应用      | app1、app2                  | 创建FG   | FG包含的app实例范围。                                                                      |
| VPN名称   | VPN_Gi                     | 创建VPN  | 当第三方app部署了NAT功能或者第三方app需要订阅用户信息时，需要创建VPN。 根据网络规划填写与FG关联的APN的名称，该APN已通过命令ADD APN增加。 |
| FG名称    | FG1与VPN_Gi绑定               | 创建VPN  | FG与VPN的关联关系                                                                        |
| IP信息    | 10.10.10.10 ～ 10.10.10.200 | 创建VPN  | 当第三方app部署NAT功能后，需要配置UE IP网段。                                                       |
| SFC名称   | SFC1                       | 创建SFC  | -                                                                                  |
| 应用      | app1、app2                  | 创建SFC  | SFC包含的app实例。                                                                       |

## 操作步骤

1. 在“MML命令行 - UDG”窗口上执行**SET LICENSESWITCH**打开License开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV4ISCFUN02",SWITCH=ENABLE;
   ```
2. 创建FG，同时完成FG绑定业务链VLAN、FG包含的app范围的创建。
   1. 在“第三方应用操作维护入口”界面，选择“业务链”，进入业务链的配置界面。
   2. 在左边导航树选择“FG”。
   3. 单击“创建FG”，弹出“创建FG”的界面。
   4. 输入"FG名称"、"VLAN ID"。

      **说明** 

      此处VLAN ID为app External（Chain）平面的VLAN ID，输入VLAD ID后，显示chain平面VLAN ID为输入值的未绑定到FG下的app全集。
   5. 勾选FG包含的应用的范围。
   6. 单击“确定”，完成创建。

   **图1** 创建FG
3. 创建SFC。
   1. 在左边导航树选择“FG > FG Name > SFC”。
   2. 单击“创建SFC”，弹出“创建SFC”的界面。
   3. 输入“上行首跳ID”、“下行首跳ID”和“SFC名称”。
   4. 鼠标拖动“应用”区域框下的app实例到下方线上。
   5. 单击“确定”，完成创建。

   **图2** 创建SFC
