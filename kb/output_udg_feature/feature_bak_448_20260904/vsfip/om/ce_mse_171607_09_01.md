- 操作场景

## 操作场景

运营商为运维人员提供第三方app智能运维系统时，需要先对第三方app智能运维功能进行激活。

## 必备事项

前提条件

请仔细阅读第三方应用智能运维。

数据

无需准备数据。

## 操作步骤

1. 在“MML命令行 - UDG”窗口上执行**SET LICENSESWITCH**打开license开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV4SSTAPP02",SWITCH=ENABLE;
   ```
