## 操作场景

CloudUDN接收UDG上报的ADR单据，进行可视化呈现，用于分析用户业务故障原因、了解运营商网络、扩展运营商业务等场景。

UDG通过Router A与Router B，以静态路由或动态路由的组网方式与CloudUDN互联。如图1所示，以静态路由作为示例。

**图1** UDG与CloudUDN的组网对接示意图

**说明** 

与CloudUDN的对接支持IPv4和IPv6地址，该配置以IPv4地址举例。

## 对系统的影响

该操作对系统正常运行无影响。

## 操作步骤

1. 配置外联口物理IP、静态路由和BFD组网。

   具体步骤请参见配置静态路由+BFD组网（IPv4）。

   **说明** 

   动态路由具体步骤请参见配置动态路由OSPF+BFD组网（IPv4）。
2. 配置Grp逻辑接口。

   **ADD VPNINST**

   **ADD LOGICINF**
3. 配置报表服务器。

   **ADD RPTSVR**
4. 配置报表服务器的IP接入点。

   **ADD RPTSVRADDR**

## 任务示例

任务描述

配置到报表服务器的数据。

脚本

1. 配置CloudUDN外联口物理IP、静态路由和BFD探测，请参见配置静态路由+BFD组网（IPv4）。
2. 配置Grp逻辑接口。

   ```
   ADD VPNINST: VPNINSTANCE ="VPN_report";
   ```

   ```
   ADD LOGICINF:NAME="grpif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_report";
   ```
3. 配置报表服务器。

   ```
   ADD RPTSVR: RPTSVRNAME="ADR_SERVER",RPTSVRTYPE=ADR,SVRFUNC=SSU-1;
   ADD RPTSVR: RPTSVRNAME="SUB_SERVER",RPTSVRTYPE=SUBSCRIPTION,SVRFUNC=SSU-1;
   ```
4. 配置报表服务器的IP接入点。如果**ADD LOGICINF**命令绑定了VPN实例，那么**ADD RPTSVRADDR**命令也必须绑定VPN实例，否则链路建立不成功。

   //配置ADR上报的报表服务器

   ```
   ADD RPTSVRADDR: ACCESSNAME="rpt_access1", RPTSVRNAME="ADR_SERVER", IPTYPE=IPv4, IPv4_Addr="10.80.128.1",SVRPORT=10700,VPNINSTANCE="VPN_report";
   ```

   ```
   ADD RPTSVRADDR: ACCESSNAME="rpt_access2", RPTSVRNAME="ADR_SERVER", IPTYPE=IPv4, IPv4_Addr="10.80.129.1",SVRPORT=10700,VPNINSTANCE="VPN_report";
   ```

   //配置下发订阅的报表服务器

   ```
   ADD RPTSVRADDR: ACCESSNAME="rpt_access11", RPTSVRNAME="SUB_SERVER", IPTYPE=IPv4, IPv4_Addr="10.80.128.1",SVRPORT=10700,VPNINSTANCE="VPN_report";
   ```

   ```
   ADD RPTSVRADDR: ACCESSNAME="rpt_access12", RPTSVRNAME="SUB_SERVER", IPTYPE=IPv4, IPv4_Addr="10.80.129.1",SVRPORT=10700,VPNINSTANCE="VPN_report";
   ```
