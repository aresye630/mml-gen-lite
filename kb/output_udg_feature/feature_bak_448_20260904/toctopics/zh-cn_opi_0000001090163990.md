## 操作场景

带NP卡的专有硬件之间级联组网时，若VNF实例化后级联口数据与规划不一致，可参考本页面进行修改级联口数据。

## 必备事项

前提条件

- 已经确认现网规划的级联口与VNF实例化后的级联口不同。
- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

数据

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

两框对等板（相同槽位的单板）上NP出级联线完成两框互联，框间NP级联口必须全部直连。

本页面以框0有8块Blade，框1有6块Blade，级联口采用P3口为例。P1~P4与图1中的位置1~4对应，例如位置3与P3对应。

## 操作步骤

1. 执行**ADD NPDIRECTCONNECTPORT**命令，使能级联口。

   框0的Slot1～Slot6上的P3口作为级联口时，需要执行如下配置：

   ```
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_1, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_2, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_3, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_4, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_5, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_0, SLOTID=Slot_6, PORTID=P3;
   ```

   框1的Slot1～Slot6上的P3口作为级联口时，需要执行如下配置：

   ```
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_1, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_2, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_3, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_4, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_5, PORTID=P3;
   ADD NPDIRECTCONNECTPORT: SUBRACK =Subrack_1, SLOTID=Slot_6, PORTID=P3;
   ```

   **说明** 

   - VNF实例化后执行步骤 1，则以步骤 1配置的级联口为准。
   - 先连线再使能级联口场景，使能后会产生外联口DOWN告警，该告警不影响业务。确认由此原因产生的ALM-89005 NP端口状态为Down告警，可手动清除。

## 验证方法

1. 执行**LST NPDIRECTCONNECTPORT**命令，查询级联口配置是否正确。
   - 正确，结束。
   - 不正确，请执行2。
2. 执行**RMV NPDIRECTCONNECTPORT**命令，删除错误的配置，然后执行3。
3. 参考操作步骤重新使能级联口，然后执行4。
4. 重新执行1，检查级联口配置是否正确。
   - 正确，结束。
   - 不正确，请联系华为技术支持工程师。

## 附加信息

相关任务

当前仅支持框0与PE连接，框1通过框0与PE连接。框0整体故障，整个网元故障；框1故障，框0业务不受影响。

框0外联口配置与单框时没有区别。
