## 操作场景

DHCP属于网络层协议，它采用Client/Server模式。DHCP Server负责客户端IP地址的管理和分配，SMF作为Client端，代替UE向DHCP Server申请和租用IP地址。

**说明** 

适用于GGSN、PGW-C、SMF。

## 操作步骤

1. 在SMF上执行如下命令：
   1. 打开本特性的License配置开关。

      **SET LICENSESWITCH**
   2. 配置VPN实例。

      **ADD VPNINST**
   3. 配置DHCP地址池组。

      **ADD ADDRPOOLGRP**
   4. 配置DHCP地址池。

      **ADD ADDRPOOL**
   5. 绑定地址池组和地址池。

      **ADD POOLBINDGRP**
   6. 配置地址池里的IPv4地址段。

      **ADD SECTION**
   7. 配置UPF组。

      **ADD ADDRUPGROUP**
   8. 配置UPF和UPF组的绑定关系。

      **ADD UPFBINDGRP**
   9. 配置APN。

      **ADD APN**
   10. 为该UPF组绑定本地地址池组。

       **ADD POOLGRPMAP**
   11. 配置DHCP地址池的IPv4地址段。

       **ADD AGENTIP**
   12. 配置DHCP服务器组。

       **ADD DHCPSERVERGRP**
   13. 配置主用DHCP服务器的IP地址。

       **ADD DHCPSERVER**
   14. **可选：**配置备用DHCP服务器的IP地址。

       **ADD DHCPSERVER**
   15. 配置DHCP服务器组与地址池组绑定关系。

       **ADD DHCPBINDPOOLGRP**
   16. 配置IP地址分配方式为DHCP分配。

       **SET APNADDRESSATTR**
   17. 配置地址分配规则。

       **SET IPALLOCRULE**
2. 在UPF上执行如下命令：
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置VPN实例。

      **ADD L3VPNINST**

      **ADD VPNINSTAF**
   3. 启动OSPF进程。

      **ADD OSPF**
   4. 添加OSPF区域。

      **ADD OSPFAREA**
   5. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   6. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**

      **说明** 

      采用路由策略方式发布路由时，不能只选择发布WLR\_SP或者WLR\_UD路由，必须选择WLR方式发布所有路由。

## 任务示例

任务描述

配置通过DHCP Server给UE分配地址。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3W9DHCP12",SWITCH=ENABLE;
```

//创建VPN实例。

```
ADD VPNINST:VPNINSTANCE="vpna";
```

//配置地址池组名称。

```
ADD ADDRPOOLGRP: POOLGRPNAME="poolgroup1", POOLGRPTYPE=DHCP;
```

//配置远端地址池。

```
ADD ADDRPOOL:POOLNAME="citya",POOLTYPE=DHCP,HASVPN=ENABLE,VPNINSTANCE="vpna";
```

//配置地址池与地址池组绑定关系。

```
ADD POOLBINDGRP: POOLGRPNAME="poolgroup1", POOLNAME="citya", PRIORITY=15;
```

//配置本地地址池里的IPv4地址段。

```
ADD SECTION: POOLNAME="citya", SECTIONNUM=1, IPVERSION=IPv4, V4STARTIP="10.0.1.1", V4ENDIP="10.0.1.10";
```

//配置UPF组。

```
ADD ADDRUPGROUP: UPFGRPNAME="upfgrp1",UPFGRPTYPE="DHCP";
```

//配置UPF和UPF组的绑定关系。

```
ADD UPFBINDGRP: UPFGRPNAME="upfgrp1", UPFID="upf_instance_1";
```

//配置APN。

```
ADD APN:APN="apn-test";
```

```
SET APNADDRESSATTR:APN="apn-test",IPV4ALLOCTYPE=DHCP,IPV4RADIUSPRIOR=ENABLE;
SET IPALLOCRULE:IPV4FIRSTRULESW=ENABLE, IPV4FIRSTRULE=APN-1&UPNODE-1;
```

//配置地址池组与UPF组的绑定关系。

```
ADD POOLGRPMAP:MAPPINGNAME="one",POOLGRPNAME="poolgroup1", APN="apn-test", UPFGRPNAME="upfgrp1";
```

//配置远端地址池的IPv4地址段。

```
ADD AGENTIP:POOLNAME="citya",SECTIONNUM=0,IPVERSION=IPV4,V4AGENTIP="10.0.1.1";
```

//配置DHCP Server服务器组。

```
ADD DHCPSERVERGRP:GROUPNAME="dgrp",IPVERSION=IPV4,REQLEASETIME=25,HASVPN=ENABLE,VPNINSTANCE="vpna";
```

//配置DHCP服务器。

```
ADD DHCPSERVER:GROUPNAME="dgrp",ISPRIMARY=ENABLE,IPVERSION=IPV4,V4IPADDRESS="10.1.4.51";
```

```
ADD DHCPSERVER:GROUPNAME="dgrp",ISPRIMARY=DISABLE,IPVERSION=IPV4,V4IPADDRESS="10.1.4.52";
```

//配置DHCP服务器组与地址池组绑定关系。

```
ADD DHCPBINDPOOLGRP:POOLGRPNAME="spoolgrp1",GROUPNAME="dgrp";
```

//配置UPF上包含该网段的地址池信息。

```
ADD VPNINST:VPNINSTANCE="vpna";
```

//配置手机下行路由。

```
ADD L3VPNINST:VRFNAME="vpna";
```

```
ADD VPNINSTAF:VRFNAME="vpna",AFTYPE=ipv4uni;
```

```
ADD OSPF:PROCID=100,VRFNAME="vpna",SCHEMAROUID="10.10.10.1",LSAARRMAXINTV=1000,LSAARRSTARINTV=500,LSAARRHLDINTV=500;
```

```
ADD OSPFAREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFNETWORK:PROCID=100,AREAID="0.0.0.0", IPADDRESS="10.13.21.0", WILDCARDMASK="0.0.0.255";
```

```
ADD OSPFIMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```
