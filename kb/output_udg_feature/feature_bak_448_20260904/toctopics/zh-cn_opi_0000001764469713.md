## 操作场景

UPF和NWDAF对接的场景，在UPF（UDG）上需要配置本页面。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE或登录OM Portal）。
- 已完成**安装SSU服务**和**安装SBIM服务**。

数据

在UDG上配置Nupf接口数据，为UPF与NWDAF之间建立逻辑连接。

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

## 操作步骤

1. 进入“MML命令行-UDG”窗口。
2. 增加UPF服务化接口Nupf的IP地址。

   ```
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.1.20.1", VPNINSTNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_server";
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.1.20.2", VPNINSTNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_client";
   ```

   ```
   ADD LOGICIP: IPVERSION=IPv6, LOGICIPV6="FC00::10:1:20:1", VPNINSTNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_server";
   ADD LOGICIP: IPVERSION=IPv6, LOGICIPV6="FC00::10:1:20:2", VPNINSTNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_client";
   ```
3. 配置HTTP本端实体组。

   ```
   ADD HTTPLEGRP: INDEX=1, DESC="UPF";
   ```
4. 配置HTTP本端实体。

   //UPF作为HTTP Server。

   ```
   ADD HTTPLE: INDEX=1, HTTPLEGRPIDX=1, LETYPE=SERVER, PORT=80, TLSFLG=NO, IPTYPE=IPv4, IPV4="10.1.20.1", VPNNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_server";
   ```

   ```
   ADD HTTPLE: INDEX=11, HTTPLEGRPIDX=1, LETYPE=SERVER, PORT=80, TLSFLG=NO, IPTYPE=IPv6, IPV6="FC00::10:1:20:1", VPNNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_server";
   ```

   //UPF作为HTTP Client。

   ```
   ADD HTTPLE: INDEX=2, HTTPLEGRPIDX=1, LETYPE=CLIENT, IPTYPE=IPv4, IPV4="10.1.20.2", VPNNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_client";
   ```

   ```
   ADD HTTPLE: INDEX=12, HTTPLEGRPIDX=1, LETYPE=CLIENT, IPTYPE=IPv6, IPV6="FC00::10:1:20:2", VPNNAME="VRF_NupfGPRS_Gn_C", DESC="UPF_client";
   ```
5. 配置UPF使用的HTTP本端实体组。

   ```
   ADD SBIAPLE: INDEX=1, HTTPLEGRPIDX=1, NFTYPE=NFTypeUPF, DESCRIPTION="UPF";
   ```
6. 设置HTTP属性。使用样例值即可。

   ```
   SET HTTPCONF: INITLINKINTVL=500, LINKAGINGTIME=120;
   ```

## 验证方法

1. 执行**NGPING**命令，查看UPF与NWDAF之间的逻辑接口IP能否互通。

   ```
   //IPv4
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_NupfGPRS_Gn_C", SRCIPV4ADDR="10.1.20.1", DSTIPV4ADDR="NWDAF的Nupf接口IP";
   ```

   ```
   //IPv6
   NGPING: IPTYPE=IPv6, VPNNAME="VRF_NupfGPRS_Gn_C", SRCIPV6ADDR="FC00::10:1:20:1", DSTIPV6ADDR="NWDAF的Nupf接口IP";
   ```

   - 如果收到NWDAF的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，表明连接异常，请执行2。
2. 执行**PING**命令，查看UPF与NWDAF的外联口IP能否互通。

   ```
   //IPv4
   PING:IPVERSION=IPv4,VPNNAME="VRF_NupfGPRS_Gn_C",SOURCEIPV4ADDRESS="UPF Nupf对应的外联口IP",DESTIPV4ADDRESS="NWDAF Nupf逻辑接口对应的外联口IP";
   ```

   ```
   //IPv6
   PING: IPVERSION=IPv6, VPNNAME="VRF_NupfGPRS_Gn_C", SOURCEIPV6ADDRESS="UPF Nupf对应的外联口IP", DESTIPV6ADDRESS="NWDAF Nupf逻辑接口对应的外联口IP";
   ```

   - 如果收到NWDAF的响应且响应报文中有成功收发包的个数，请执行3。
   - 如果连续出现timeout，表明连接异常，请执行4。
3. 检查直连路由器上是否存在到UPF（Nupf接口IP）的路由，下一跳是外联口IP。
   - 是，请执行4。
   - 否，请联系路由器工程师，增加相关路由后重新调测。
4. 请参考初始配置与调测 > 配置VNF侧IP路由数据进行调测，修正配置后请重新执行1。
   - 如果收到NWDAF的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，请执行5。
5. 收集信息并寻求技术支持。
   1. 在“MML命令行-UDG”窗口上执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
