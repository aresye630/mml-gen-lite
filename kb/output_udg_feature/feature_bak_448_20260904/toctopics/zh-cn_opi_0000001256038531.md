# 激活HTTPS业务行为识别特性

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当前加密协议的业务识别主要基于SNI和Domain进行，对于未携带SNI的场景无法准确识别业务。在UDG开启HTTPS业务行为识别功能后，UDG会对HTTPS业务报文做TLS指纹识别，提升识别精度。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-110404 HTTPS业务行为识别。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。
- 完成业务感知配置。

数据

| 类别              | 参数名称                 | 取值样例            | 获取方法   | 说明                                                                                          |
|:----------------|:---------------------|:----------------|:-------|:--------------------------------------------------------------------------------------------|
| LOD SIGNATUREDB | 特征库加载模式 （LOADMODE）   | SPECIFIC        | 本端规划   | 该参数用于指定特征库的加载模式。 SPECIFIC：指定特定的特征库版本加载。LATEST：指定最新的特征库版本加载。REFRESH：指定最新的特征库版本更新，但不改变配置保存方式。 |
| LOD SIGNATUREDB | 特征库版本号（VERSION）      | 01.0002.1061.01 | 本端规划   | 该参数在“LOADMODE”配置为“SPECIFIC”时为必选参数。                                                          |
| ADD FINGERIDENT | 协议配置方式 （CFGPROTMODE） | ALL             | 本端规划   | 该参数用于设置SA指纹识别功能协议的配置方式。 ALL：所有协议。SPECIFIC：指定协议。                                             |

## 操作步骤

1. 打开本特性的License特性配置开关。

   **SET LICENSESWITCH**
2. 加载特定的完整的特征库文件。指纹库内置在特征库中。如果已经加载特征库，则升级新特征库文件。

   **LOD SIGNATUREDB**
3. 开启HTTPS业务行为识别功能。

   **ADD FINGERIDENT**

   **说明** 

   可通过**LST SUPPFINGERIDEN**命令查询系统内哪些协议支持指纹识别功能。

## 任务示例

任务描述

在UDG开启HTTPS业务行为识别功能，并加载特定的知识库版本，指定所有SA协议进行指纹识别功能。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5HSBI01",SWITCH=ENABLE;
```

//加载知识库的版本为01.0002.1061.01。

```
LOD SIGNATUREDB:LOADMODE=SPECIFIC,VERSION="01.0002.1061.01";
```

//开启所有协议SA指纹识别功能。

```
ADD FINGERIDENT:CFGPROTMODE=ALL;
```
