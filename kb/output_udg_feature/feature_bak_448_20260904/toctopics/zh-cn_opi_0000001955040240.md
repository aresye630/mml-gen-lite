## 操作场景

本指导描述UNC上某些可选离线计费功能的配置过程。

UNC上的话单可选功能包含：

- CCFH后强制产生话单

  在系统测试时，如果UNC上设置的话单产生条件未到，还不具备自动产生话单时，可采用命令强制产生话单。
- 最后活动时间（LastActivity）计费

  基于时长的计费模式下，用户可能由于idle去激活而较长时间没有业务访问，如果按当前时长计费会有向用户多收费嫌疑。可通过在话单的扩展字段RecordExtensions中记录最后一个业务报文通过的时间，由此计算用户访问业务的实际时长且据此收费，可优化时长计费模式。
- 抑制零流量话单

  为减少无效话单的数量，如果用户一段时间内未进行业务，即业务访问流量为零，则忽略本次产生话单的计费事件，不产生中间话单。
- 费率切换后强制生成话单

  离线计费模板参数CDRTRIGMAXCHNG配置为ENABLE，参数CONDITIONCHANGE参数配置为1时，UNC处理费率切换时会对费率切换前的使用量产生一张话单后，如果费率切换后的用量不强制产生一张话单，会导致费率切换后大量用户时间阈值同时触发，产生大量话单，导致UNC CPU使用率大幅波动，同时对CG产生冲击。为避免此现象发生，建议配置费率切换后强制生成话单。

## 操作步骤

1. 配置在线计费CCFH处理时是否强制产生话单，以及强制产生话单时话单中charging characteristic字段的取值、R6版本的eG-CDR是否支持CCFH处理。

   **SET OFCCDRPARA**
2. 配置最后活动时间（LastActivity）计费。
   1. 配置OFCTemplate使产生话单的时间格式为UTC时间。

      **ADD OFCTEMPLATE**

      **说明** 

      LastActivity计费话单时间格式只支持UTC时间。
   2. 配置使能离线计费使用LastActivity计费功能。

      **SET OFCCDRPARA**
3. 配置抑制零流量话单产生开关。

   **SET ZEROCHGSKIPSW**
4. 费率切换后强制生成话单。

   **SET OFCCDRPARA**

## 任务示例

任务描述

执行配置实现以下功能：

- 配置在线计费CCFH处理时是否强制产生话单。
- 激活LastActivity计费功能。
- 开启抑制零流量话单产生功能。
- 费率切换后强制生成话单

脚本

- 配置在线计费CCFH处理时强制产生话单。

  ```
  SET OFCCDRPARA: CCFHCDRSW=ENABLE,CCFHCDRCC="0x1000", PSFCIFORMAT=HEX, R6EGCDRCCFHSW=DISABLE;
  ```
- 配置最后活动时间（LastActivity）计费。

  ```
  MOD OFCTEMPLATE: OFCTEMPLATENAME="offlinecharge-test",TQM=QCT,QCTVALUE=0,CDRTIMEFORMAT=UTC;
  SET OFCCDRPARA: LASTACTIVITYSW=ENABLE;
  ```

- 配置抑制零流量话单产生开关。

  ```
  SET ZEROCHGSKIPSW:ZEROCHGSKIPSW=ENABLE;
  ```
- 费率切换后强制生成话单。

  ```
  SET OFCCDRPARA: CDRAFTERTCSW=ENABLE, CDRAFTERTCCAUSE=MANAGEMENT_INTERVENTION;
  ```
