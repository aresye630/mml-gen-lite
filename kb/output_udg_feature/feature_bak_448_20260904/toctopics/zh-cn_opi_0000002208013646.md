# 增加媒体中继全局配置

- 操作场景
- 必备事项
- 任务示例

## 操作场景

媒体中继业务需要在UPF上开启License，并设置媒体中继业务使用的IP地址等全局参数。本章节用于指导如何配置媒体中继业务的全局配置。

## 必备事项

前提条件

- 请提前了解媒体中继方案实现原理。
- 已完成License加载。
- 已完成框间级联部署及扩容。

## 任务示例

任务描述

打开媒体中继功能License开关，同时配置签约套餐名称等全局配置。

脚本

//打开license开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5SMRB01", SWITCH=ENABLE;
```

//配置回源DNS服务器。

```
ADD RELAYDNSSERVER: DNSSERVERNAME="relay_dns_server", VPNNAME="VRF_Internet", MDNSSRVIPV4="10.200.100.101", SDNSSRVIPV4="10.200.100.102",MDNSSRVIPV6="2409:8028:2000::3333", SDNSSRVIPV6="2409:8028:2000::1111",DNSDETECTSW=ENABLE, DETECTDOMAINNM="www.huawei.com", IPSELECTMODE=IPv6First;
```

//配置回源地址池，回源地址池IP地址段。

**注意** 

配置的回源地址如果是内网地址时，需要在防火墙上对这些地池段进行放通，并审视是否需要增加公网IP地址。

```
ADD RELAYIPPOOL: POOLNAME="relay_ip_pool_cmnet", VPNNAME="VRF_Internet";
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", SECTIONID=0, INSTID=0, IPVERSION=IPV4, IPV4ADDR="10.201.0.0", IPV4MASKLEN=21;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", SECTIONID=1, INSTID=1, IPVERSION=IPV4, IPV4ADDR="10.201.16.0", IPV4MASKLEN=21;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", SECTIONID=2, INSTID=2, IPVERSION=IPV4, IPV4ADDR="10.201.32.0", IPV4MASKLEN=21;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", SECTIONID=3, INSTID=3, IPVERSION=IPV4, IPV4ADDR="10.201.64.0", IPV4MASKLEN=21;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", INSTID=0, SECTIONID=100, IPVERSION=IPV6, IPV6ADDR="2409:892B:A80:1000:1000:1000:1000:2000", IPV6MASKLEN=115;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", INSTID=1, SECTIONID=101, IPVERSION=IPV6, IPV6ADDR="2409:892B:A80:1000:1000:1000:1000:4000", IPV6MASKLEN=115;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", INSTID=2, SECTIONID=102, IPVERSION=IPV6, IPV6ADDR="2409:892B:A80:1000:1000:1000:1000:6000", IPV6MASKLEN=115;
ADD RELAYIPSECTION: POOLNAME="relay_ip_pool_cmnet", INSTID=3, SECTIONID=103, IPVERSION=IPV6, IPV6ADDR="2409:892B:A80:1000:1000:1000:1000:8000", IPV6MASKLEN=115;
```

//设置直播资源空闲老化参数。

```
SET DCSLIVEPARAS: PUBTIMEOUT=12000, PUBVERIFYPERIOD=3, LIVEAGINGPERIOD=2;
```

//设置在网管上显示的UPF支持的可选服务类型。

```
SET UPFSERVICETYPE: SERVICETYPE1="Relay";
```

//（条件必选）当需要进行计费一致性检查时，开启媒体中继流量单独统计计费流量功能。

**说明** 

中继流量单独统计计费流量功能用于计费准确性测试场景进行Relay流量核减，需要SMF和CHF网元同时升级到20.16.2版本后才能开启。

```
SET UPGLBCHGPARA: RELAYCHSW=ENABLE;
```

//（条件必选）当网元与NWDAF对接上报保障用户或体验用户单据，需要用户单据携带媒体中继用户标识时，开启如下配置。

**说明** 

用户单据携带媒体中继用户标识，需要NWDAF升级到20.16.2后才能开启。

```
SET VVIPEXTRPT: MEDIARELAYSW=ENABLE;
SET EXPEXTRPT: MEDIARELAYSW=ENABLE;
```
