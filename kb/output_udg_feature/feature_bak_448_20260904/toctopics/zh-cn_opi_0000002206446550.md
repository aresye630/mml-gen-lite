# 配置UPF容灾和一跳入家开关

- 操作场景
- 必备事项
- 任务示例

## 操作场景

该任务旨在指导操作人员完成SMF上的UPF主备容灾配置和一跳入家开关配置。

## 必备事项

前提条件

- 已完成**智网接入**的License加载。
- 已经完成与专网UPF的基础对接配置。
- 已完成一跳入家要求的移动VPN相关配置。

## 任务示例

任务描述

在SMF上配置一跳入家主备UPF的属性和优先级，并设置SMF一跳入家相关的开关参数。

脚本

1. 在SMF上使能专网UPF的一跳入家功能：设置upf\_instance\_1和upf\_instance\_2“是否支持作为智家随行场景To Home会话主锚点”参数为“使能”。

   ```
   LST UPNODE:;
   MOD UPNODE: NFINSTANCENAME="upf_instance_1", TOHPSASW=ENABLE;
   MOD UPNODE: NFINSTANCENAME="upf_instance_2", TOHPSASW=ENABLE;
   ```
2. 配置SMF进行UPF选择时，优先选择主UPF：设置upf\_instance\_1和upf\_instance\_2“优先级功能开关”参数为“指定”，且upf\_instance\_1的“优先级”取值比upf\_instance\_2的小。

   ```
   SET APNUPSELPLY: APN="home.dnn", PRIORITYFLAG=ENABLE;
   LST PNFDNN:;
   MOD PNFDNN: INDEX=1, PRISWITCH=SPECIFIC, PRIORITY=1;
   MOD PNFDNN: INDEX=2, PRISWITCH=SPECIFIC, PRIORITY=2;
   ```
3. 配置主UPF故障恢复后，SMF回迁业务会话至主UPF。**注意此处的主备UPF务必和2中定义的主备UPF保持一致，否则会导致无法回迁。**

   ```
   ADD APNUPRECOVER: APN="home.dnn", MASTERUPFID="upf_instance_1", HANDLINGMODE=BACKMIGRATION, BACKUPFID="upf_instance_2";
   ```
4. 打开SMF上的一跳入家功能开关。注意“APN”值已经在**ADD APN**中配置。

   ```
   ADD APNTOHCTRL: APN="home.dnn", FWASW=ENABLE;
   ```
5. 设置SMF向UDM查询家庭组ID对应的VnGroupData。用户会话建立时，当UDM返回的签约数据中包括家庭组ID和SharedDataID，SMF会基于SharedDataID向UDM发送一次查询消息来再次确认该家庭组ID对应的VnGroupData，以确保家庭组ID的准确性。

   ```
   SET SMFFUNC: VNGROUPDATASW=Support;
   ```
6. 打开SMF上一跳入家相关的私有信元开关。

   ```
   SET PFCPPVTEXT: FEATURE=Session_Delete_Cause, SWITCH=ENABLE;//配置PFCP Session Deletion Request消息中携带Session级私有信元Session Delete Cause（指示删除备UPF的会话）。
   SET PFCPPVTEXT: FEATURE=NGLAN, SWITCH=ENABLE;//配置PFCP Session Establishment Request消息中携带私有信元5GLan Session Type（标识智家业务）和5G VN Instance（家庭组ID）。
   ```
