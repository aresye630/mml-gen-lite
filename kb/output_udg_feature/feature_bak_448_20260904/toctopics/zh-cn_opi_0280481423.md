# 基于BGP over 静态路由配置实例（SDN+IPv4）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

本任务实例实现以下场景配置：

UDG与对端设备（gNodeB/eNodeB、ULCL UPF/BP UPF/I-UPF/SGW-U、SGSN、PSA UPF/PGW-U、SMF/PGW-C/SGW-C、DN/PDN）通过BGP over 静态路由+BFD单臂echo实现网络互通。

- 网络形态：SDN场景+2/3/4/5G融合网络
- 网元形态：PGW-U/UPF
- 路由协议：BGP over 静态路由
- 组网IP格式：IPv4组网
- 接入用户：IPv4单栈用户

## 必备事项

前提条件

- 请了解UDG各类接口的类型及命名规范，可参见逻辑接口介绍。
- IP路由组网和业务接口配置子任务在前述章节已有详细描述，可参见BGP over静态路由+BFD(IPv4)和配置业务接口数据。本文针对典型的任务场景举例说明整网脚本配置。

数据

可参考各子任务的数据规划准备。

## 操作步骤

1. 配置基础数据。

   配置基础数据包括：修改网元名称、网元浮动IP。详细配置与组网无关，具体请参见基础数据配置。
2. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      - 如果“自动配置开关”值为“TRUE”，需要执行4.b和4.c关闭自动配置开关。
      - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到步骤 5。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 配置UDG到无线侧(R)AN（gNodeB）的IP路由数据。
   1. 配置外联口的VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Access";
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv4uni;
      ```
   2. 添加以太网隧道多虚拟网卡自动化配置模板。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1, VNICLIST="4 5";
      ```
   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v4", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=1, VLANID=100;
      ```
   4. 增加BFD会话自动部署模板。

      “DESTADDR4”配置的是Leaf节点的IP地址，采用的是单臂BFD。

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_41", BFDTYPE=Static, SERVICENAME="ServName_Access_100_v4", IPVERSION=IPv4, DESTADDR4="10.10.85.110", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```
   5. 增加静态路由自动部署模板。静态路由用于实现VNF的BGP Loopback接口IP和BGP PEER IP之间的互通。默认路由的优先级要低于对端发布的路由优先级，当对端发布默认路由时，不需要配置默认路由。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="10.10.20.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_41";
      ```

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=255, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_41";
      ```
   6. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack1";
      ADD IPBINDVPN:IFNAME="LoopBack1",VRFNAME="VRF_Access";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack1",IFIPADDR="192.168.235.130",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```
   7. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Access", DEFAULTAFTYPE=noaf, ROUTERID="192.168.235.130";
      ```
   8. 增加BGP VPN实例地址族。UDG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```
   9. 配置BGP对等体。

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="10.10.20.78", REMOTEAS="60002", LOCALIFADDR="192.168.235.130", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
      ```
   10. 配置BGP引入wlr路由。

       ```
       ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
       ```
