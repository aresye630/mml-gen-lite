# 激活入不转板功能

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

- 中心云场景非SDN组网，若专有硬件+第三方底层平台场景下业务单板转发性能低（交换带宽不足），则可通过配置入不转板功能，减少东西流量，从而提升性能。
- 华为SDN组网，若业务单板交换带宽不足，则可通过配置入不转板功能，减少东西流量，从而提升性能。

请参考本页面配置入不转板功能。

**说明** 

ISU POD部署模式和APU POD部署模式都支持入不转板功能。为简化描述，如下以ISU POD描述为例。

## 必备事项

前提条件

- 软件安装任务中，部署的POD类型是ISU POD或APU POD。
- 已仔细阅读GWFD-020482 入不转板功能特性概述。

**图1** ISU POD和IP Suit绑定示意图（上行入不转板）

SGi/N6接口支持下行入不转板功能。UDG给UE分配IP地址时需要规划表3中的数据，部署下行入不转板功能时，请关注如下参数（其他参数与普通场景无差异）：

- **ADD POOL**命令中的“地址池类型（POOLTYPE）”参数必须设置为“LOCAL”。
- **ADD SECTION**命令中的“MASK”参数取值范围为5~15，请根据ISU POD数量合理规划“MASK”及地址段起始IP和结束IP。

  例如，“MASK”取值为“5”时，地址子段中的IP个数为2的5次方，即32个。

## 操作步骤

1. 配置BGP over静态路由+BFD探测。

   **说明** 

   入不转板场景，还必须配置其专有配置（**ADD AUTOSCALINGBGPLF**和**ADD AUTOSCALINGIPREACH**等）。

   - 非SDN组网，详细请参见配置VNF侧IP路由数据（无NP卡\_非SDN）。
   - SDN组网，详细请参见配置VNF侧IP路由（SDN）。
2. 开启入不转板全局开关。

   **注意** 

   开启入不转板的命令是**SET DATAPLANEINFMODE**，不是**SET DATAPLANEGIINFMODE**。

   如误使用**SET DATAPLANEGIINFMODE**，则下行业务入不转板，上行业务入转板。

   **SET DATAPLANEINFMODE**
3. 配置逻辑接口。

   **ADD LOGICINF**
4. 配置用户面分配地址。
   1. 配置LOCAL类型的地址池。

      **ADD POOL**
   2. 配置地址池里的地址段。必须配置“MASK”参数。

      **ADD SECTION**
   3. 配置地址池组。

      **ADD POOLGROUP**
   4. 配置地址池绑定到地址池组。

      **ADD POOLBINDGROUP**
   5. 配置APN/DNN实例与地址池组的映射关系。

      **ADD POOLGRPMAP**
   6. 配置全局地址分配规则。

      **SET IPALLOCRULE**

## 任务示例

任务描述

开启入不转板功能。

- 开启入不转板全局开关。
- 配置上行入不转板的逻辑接口，此处仅以Saif接口为例。其他逻辑接口配置方法同Saif接口。
- 配置下行入不转板的用户面地址分配功能。

脚本

//开启入不转板全局开关。此处以开启路由增强功能为例。

```
SET DATAPLANEINFMODE: MODE=Instance, ROUTEENHANCEDSW=ENABLE;
```

//配置Saif逻辑接口。此处以Saif接口为例，其他接口配置类似。

```
ADD LOGICINF:NAME="Saif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.10.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access"; 
ADD LOGICINF:NAME="Saif1/2/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.10.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access"; 
ADD LOGICINF:NAME="Saif1/3/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.10.3",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access";
```

//配置用户面地址分配。

```
ADD POOL:POOLNAME="testpool",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="VPN_Internet";
ADD SECTION:POOLNAME="testpool",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.0",V4ENDIP="10.10.127.255",MASK=9;
ADD POOLGROUP: POOLGRPNAME="poolgroup1", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup1", POOLNAME="testpool", PRIORITY=10;
ADD POOLGRPMAP: MAPPINGNAME="mapping1", APN="apn-op", POOLGROUPNAME="poolgroup1";
SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE;
```
