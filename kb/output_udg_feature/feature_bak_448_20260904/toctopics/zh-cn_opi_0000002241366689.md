## 操作场景

该任务旨在指导操作人员给用户配置一跳入家签约数据。

完成了一跳入家基础的业务部署，网络就具备了为用户开通一跳入家的能力。当用户有开通业务诉求时，可以通过如下方式完成数据签约和业务开通。

- 家庭成员和家庭CPE在运营商BOSS系统进行签约。签约完成后BOSS系统通过运维接口下发签约信息到UDM上 。
- 如果BOSS系统和UDM之间的运维接口尚未支持，请参考本章节在UDM上人工配置签约数据。

## 必备事项

前提条件

- 操作人员具有PGW Web LMT的操作权限。
- 已完成**5G LAN签约用户数**和**一跳入家3GPP接入签约用户数**的License加载。
- 一跳入家家庭CPE的IMSI号码已开户。用户A和用户B已分别完成5G开户。

## 任务示例

任务描述

为某家庭的1个CPE、2个家庭成员进行一跳入家业务签约。

脚本

1. 登录UDM的“UDM业务管理”窗口。
2. 配置使用的DNN信息。

   //创建5G QoS模板。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="tphome01", NGQI=9, ARPPRILEVEL=1, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=FALSE, NGQIPRILEVEL=1;
   ```

   //创建DNN QoS模板。

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=2, TPLNAME="tphome01", PDUTYPE=IPV4, SSCMODE=SSC_MODE_1, NGCQOSTPLID=1, AMBRUP=5, UPUNIT=Gbps, AMBRDW=5, DWUNIT=Gbps, CHARGE="0800";
   ```
3. //签约切片数据。

   ```
   ADD SNSSAI: IMSI="460081000000001", SNSSAI="1-010101", DEFAULT=TRUE;
   ADD SNSSAI: IMSI="460081000000011", SNSSAI="1-010101", DEFAULT=TRUE;
   ADD SNSSAI: IMSI="460081000000111", SNSSAI="1-010101", DEFAULT=TRUE;
   ```
4. 签约会话管理数据。

   ```
   ADD SMDATA: IMSI="460081000000001", SNSSAI="1-010101", DNN="home.dnn", DEFAULT=TRUE, DNNQOSTPLID=2, MOBILE_HOME=TRUE;
   ADD SMDATA: IMSI="460081000000011", SNSSAI="1-010101", DNN="home.dnn", DEFAULT=TRUE, DNNQOSTPLID=2, MOBILE_HOME=TRUE;
   ADD SMDATA: IMSI="460081000000111", SNSSAI="1-010101", DNN="home.dnn", DEFAULT=TRUE, DNNQOSTPLID=2, MOBILE_HOME=TRUE;
   ```
5. 增加一跳入家使用的5G LAN群组（家庭组）。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei01", SNSSAI="1-010101", DNN="home.dnn", PDUTYPES=IPV4;
   ```
6. 增加5G LAN组成员（家庭成员和CPE）。

   ```
   ADD GROUPID: IMSI="460081000000001", INGROUPID="1001-46008-01";
   ADD GROUPID: IMSI="460081000000011", INGROUPID="1001-46008-01";
   ADD GROUPID: IMSI="460081000000111", INGROUPID="1001-46008-01";
   ```
