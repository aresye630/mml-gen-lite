## 操作场景

当运营商想要激活拥塞小区分析功能时，需要配置本页面。

**说明** 

适用于UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-111701 拥塞小区分析特性概述。
- 已完成业务感知配置。
- 已完成配置到CloudUDN的数据。
- 已完成加载License。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置报表功能开关。

   **SET RPTGLBCFG**
3. 配置指定策略的业务报表功能开关。

   **ADD RPTPOLICY**
4. 配置流抽样率。

   **SET RPTGLBPARA**

   **说明** 

   当业务全样分析上报特性的License开关打开时，按照**SET RPTGLBPARA**命令配置的抽样率进行抽样。
5. 配置小区拥塞优化业务大流速率。

   **SET SSUBIGFLOWCTRL**
6. 设置主动触发用户位置实时通知功能。

   **SET USRREALLOCNTY**
7. **可选**：配置vTCP\_OPT功能，生效拥塞小区分析功能。
   1. 完成**安装vTCP\_OPT服务**。
   2. 对于5G SA/NSA用户，需要开启软参BIT1241 控制5G SA用户是否支持TCP优化、BIT1242 控制5G NSA用户是否支持TCP优化。
   3. 配置一个空的FlowFilter，并绑定到子策略名称为to的Rule。

      **ADD FLOWFILTER**

      **ADD RULE**

## 任务示例

任务描述

配置开启拥塞小区分析功能。

脚本

1. 开启相关License。

   //配置拥塞小区分析功能开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5OBCCS1",SWITCH=ENABLE;
   ```

   //配置相关特性的功能开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5IARG01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV3G5FSFR01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV3G5TDIR01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV3G5SARS01",SWITCH=ENABLE;
   ```

   //基于小区的业务指标汇聚上报场景需开启系统级智能分析记录生成特性的功能开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5SIAR01",SWITCH=ENABLE;
   ```

   //执行拥塞控制时需开启相关功能开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5TCSA01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV3G5SBTS01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV4TCPBSS01",SWITCH=ENABLE;
   ```
2. 配置报表功能开关。

   ```
   SET RPTGLBCFG:TCPINSIGHTSW=ENABLE,UDPINSIGHTSW=ENABLE,SUBSPOLICYSW=ENABLE,SUBSCONFIGSW=ENABLE;
   ```
3. 配置指定策略的业务报表功能开关。

   ```
   ADD RPTPOLICY:POLICYNAME="policy01",SWITCH=ENABLE,USERSELPLYTYPE=ANY;
   ```
4. 配置抽样率。

   ```
   SET RPTGLBPARA:FLOWSAMPLERATE=1000,NEID=1,TCPINSIGHTSAMRT=1000;
   ```
5. 配置拥塞小区分析业务大流速率。

   ```
   SET SSUBIGFLOWCTRL:CCOFLOWRATE=100;
   ```
6. 配置主动触发用户位置实时通知功能。

   ```
   SET USRREALLOCNTY: SWITCH=ENABLE,USRSAMPLINGRATE=10;
   ```
7. 可选：配置vTCP\_OPT特性生效拥塞小区分析功能。

   ```
   SET SOFTPARA:DT=BIT,BITNUM=1241,BITVALUE=1;//对于5G SA/NSA用户，需要开启该软参。
   SET SOFTPARA:DT=BIT,BITNUM=1242,BITVALUE=1;//对于5G SA/NSA用户，需要开启该软参。
   ADD FLOWFILTER: FLOWFILTERNAME="flowfilter_zxm", TETHERDETFLAG=NONE, FLOWFILTERTYPE=USERCONFIG;
   ADD RULE: RULENAME="rule_zxm_to", POLICYTYPE=WORKER, FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="flowfilter_zxm", WORKERNAME="to";
   ```
