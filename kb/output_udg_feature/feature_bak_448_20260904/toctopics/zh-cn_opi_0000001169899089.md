# 卸载vTCP\_OPT服务

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当运营商不需要vTCP\_OPT服务或vTCP\_OPT服务动态上线失败时，可以单独卸载vTCP\_OPT pod，从而下线vTCP\_OPT服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线vTCP\_OPT pod的类型和数量。

数据

| 类别                      | 参数名称                      | 取值样例/说明                                                                        | 获取方法   |
|:------------------------|:--------------------------|:-------------------------------------------------------------------------------|:-------|
| UDG OM Portal帐户         | IP地址                      | 192.168.1.1 操作维护接口IP，即“VNFD模板”中的“MNG_IP”或“MNG_IPv6”参数。                         | 本端规划   |
| UDG OM Portal帐户         | 端口号                       | 31943                                                                          | 本端规划   |
| UDG OM Portal帐户         | 用户名                       | admin                                                                          | 本端规划   |
| UDG OM Portal帐户         | 密码                        | Changeme_123                                                                   | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | Pod类型列表（PODTYPE）          | to-pod/toctrl-pod或toc56-pod/toctrl-pod或toc56m-pod/toctrl-pod pod类型，用/分割。不要带空格。 | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | 下线方式（DISABLETYPE）         | Normal                                                                         | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | FUNCTIONSETNAME （网络功能集名称） | TO                                                                             | 固定取值   |

## 操作步骤

1. 登录UDG OM Portal。
2. 执行命令，动态下线vTCP\_OPT pod。以PBU\_E-T虚拟机为例，PBU\_E-T\_C56\_ARM或PBU\_E-T\_C56\_M\_ARM虚拟机请替换为配套pod。

   ```
   OPR FEATUREDISABLE:PODTYPE="to-pod/toctrl-pod", DISABLETYPE=Normal, FUNCTIONSETNAME="TO";
   ```
3. 执行命令，确认已经成功下线vTCP\_OPT pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="to-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="toctrl-pod";
   ```

   回显为“查询Pod不存在”。
4. 若动态下线vTCP\_OPT服务后，不再上线vTCP\_OPT服务，则需要缩容vTCP\_OPT自身VM（PBU\_B1、PBU\_E-T或PBU\_E-T\_C56\_ARM或PBU\_E-T\_C56\_M\_ARM），释放VM资源。

   若后续还需要上线vTCP\_OPT服务，则不必缩容vTCP\_OPT自身VM。

   **缩容VM**：请参见《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》。
