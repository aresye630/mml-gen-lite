# 配置UDM-UIM与专网UPF的对接数据（直联）

- 操作场景
- 必备事项
- 任务示例

## 操作场景

本页面用于指导操作员配置UDM-UIM通过Diameter信令与专网UPF的对接数据，UDM-UIM与专网UPF以直联方式对接。

## 必备事项

前提条件

- 操作人员具有管理员权限。
- CSP与服务器端通信正常。
- 本端实体侧已完成软件安装和基础数据的配置。
- 对端实体侧已完成基础数据配置。
- 本端实体与对端实体的对接信令数据已经协商。

## 任务示例

任务描述

本范例配置UDM-UIM与专网UPF的对接数据。

脚本

1. 登录“UDM MML命令”界面。
2. 使用**ADD DMLE**命令增加Diameter本端实体。

   ```
   ADD DMLE: EN="AAA", LOCTYPE=AAA, DN="huawei.com", HN="UDM.huawei.com";
   ```
3. 使用**ADD DMPE**命令增加Diameter对端实体。

   ```
   ADD DMPE: EN="UPF", PEERTYPE=ePDG, HN="peer.huawei.com", PEPRI=15;
   ```
4. 使用**ADD DMLKS** 命令增加Diameter链路集。

   ```
   ADD DMLKS: LINKSNAM="Diameter_aaa", LOCALNAM="AAA", PEERNAM="UPF", LNKMOD=ACTIVE;
   ```
5. 使用**ADD DMLNK**命令增加Diameter链路。

   ```
   ADD DMLNK: LNKNAME="LINK_AAA001", LINKSNAM="Diameter_aaa", HSFMID=55, PTYPE=TCP, WMODE=SERVER, IPNAM1="HSFIP1", LPT=3868, PIPVER=IPV4, PIPV4="192.168.1.1", PPT=19865, LINKPRI=15;
   ```

   ```
   ADD DMLNK: LNKNAME="LINK_AAA002", LINKSNAM="Diameter_aaa", HSFMID=55, PTYPE=TCP, WMODE=SERVER, IPNAM1="HSFIP1", LPT=3869, PIPVER=IPV4, PIPV4="192.168.2.1", PPT=19865, LINKPRI=15;
   ```

   **说明** 

   - 配置UDM-UIM的Diameter链路时，一般都配置2条链路，两条链路的HSF模块使用不同虚拟机上面的HSF模块。
   - 链路增加后会自动激活，但是如果对链路进行了修改，则需要使用**DEA DMLNK**命令去激活链路，再使用**ACT DMLNK**命令激活链路。
   - 为保证各IPU（Interface Processing Unit）之间实现负载均衡，需要在HSF模块上配置多个IP。同时，在配置链路时需要将链路均分到多个IP上。
   - 当本命令中的“工作模式”参数设为“SERVERMULTPORT(服务端多端口)”时，由于本端端口与HSF模块一一对应，为保证各HSF模块之间实现负载均衡，在配置链路时需要在多个HSF模块上配置不同的本端端口。同时，将对端的链路配置均分到多个本端端口上。
   - 执行**ADD DMLNK**命令，“传输协议类型”参数为“TCP”时，增加的每个链路的“本端端口号”参数需确保不相同。
