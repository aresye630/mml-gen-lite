## 操作场景

该任务用于指导操作人员完成Bi口的IP资源数据的配置。配置Bi口后可以通过PULL或者PUSH模式向计费中心分发话单。

PULL模式下计费中心主动到NCG取话单。此时NCG作为FTP/SFTP的服务器端，计费中心作为FTP/SFTP的客户端；PUSH模式下NCG采用FTP/SFTP协议分发第二份最终话单到计费中心。此时NCG作为FTP/SFTP的客户端，计费中心作为FTP/SFTP的服务器端。大多数情况下，NCG采用PULL方式分发话单。

PULL方式下，NCG默认开放“/opt/CG\_VNFC/run/vrpv8/product/backsave/”目录下的话单给计费中心，下级相对目录因运营商不同而不同。

## 操作步骤

1. 配置本端服务端IP信息。

   ```
   ADD IPRESOURCE: IPRID="biV4", IPRPURPOSE=Bi, RUID=64, IPTYPE=IPV4, IPV4="172.16.1.10", VPNNAME="Bi-test";
   ADD IPRESOURCE: IPRID="biV6", IPRPURPOSE=Bi, RUID=64, IPTYPE=IPV6, IPV6="fc01:f111:2222:3333:4444:5555:2111:161", VPNNAME="Bi-test";
   ```

   **说明** 

   CG\_VNFC的每个RU都需要配置BI IP。
2. 重启CG服务。

   ```
   RST VNFC: SERVICEINSTANCE="CG_VNFC_999", ISFORCEOPER=TRUE;
   ```
3. 配置话单分发任务。

   ```
   ADD CDRDISTR: CDRDISTRID="test_monitor_5G", ISSINGLEBI=NO, TRANSMODE=PULL, OTPTYPE=FTP, OUSERNAME="ftpuser", OPASSWORD="*****", CPASSWD="*****";
   ```

   **说明** 

   - PULL模式下，登录用户名和密码可以自行规划。
   - 使用FTP传输协议方式时，传输数据时不加密，安全性低。使用SFTP传输协议方式时，会对传输数据进行加密，安全性较高。建议和计费中心协商选择SFTP协议。
