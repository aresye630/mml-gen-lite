# 配置归属地智能分流SMF

- 操作场景
- 对系统的影响
- 必备事项
- 任务示例

## 操作场景

本操作用于指导当智能分流SMF与专网UPF未建立连接时，配置智能分流SMF对接专网UPF。当专网UPF已在智能分流SMF上配置时，无需进行此操作。

## 对系统的影响

智能分流SMF需要新增与专网UPF的PFCP会话交互，并且需要从PCF获取智能分流规则，因此会造成与周边网元消息交互增加，导致CPU使用率升高。

## 任务示例

任务描述

配置智能分流SMF对接专网UPF。

脚本

1. 配置Profile实例。

   ```
   ADD PNFPROFILE:NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080;
   ```
2. 配置用户面节点支持的切片与DNN信息。

   ```
   ADD PNFNS: INDEX=3, NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", SST=1, SD="000000"; 
   ADD PNFDNN:INDEX=3, NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", DNN="stjwt.gd", PNFNSINDEX=3;
   ```
3. 配置用户面节点的位置特征和分流能力。

   ```
   ADD UPNODE: NFINSTANCENAME="5EA7F228-47CC-2032-03A3-0E1313000001", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, VPNNAME="VRF_CP",PDUESTWITHOUTN9=ENABLE;
   ```
4. 配置用户面支持的PDU会话类型。

   ```
   ADD PNFUPFINFO: NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1;
   ```
5. 配置UPF的迁移间隔为60s，控制用户面迁移任务的扫描速率为6个/秒。

   ```
   ADD UPFPFCPPARA: UPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", DACTINTERVAL=100, MIGINTERVAL=60;
   SET UPCSCANRATE: SCANTYPE=MIGRATE, RATE=6;
   ```
