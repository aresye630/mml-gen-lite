# 配置直播业务的媒体中继域名（直播域名）

- 操作场景
- 必备事项
- 任务示例

## 操作场景

使用媒体中继业务时，需要配置媒体中继模板使用的媒体中继域名。本章节用于指导如何配置媒体中继模板使用的直播域名。

## 必备事项

已参考增加媒体服务商基础配置完成媒体中继模板配置。

## 任务示例

任务描述

配置媒体中继的直播域名为**relay.spliving.com**，并为直播域名绑定URL鉴权规则。

**说明** 

URL鉴权密钥信息属于敏感数据，不支持查询或配置导出，请管理员妥善保管。

脚本

//增加直播域名配置，支持FLV类型的直播为业务。

```
ADD RELAYDOMAIN: RELAYTPLNAME="sp_relay_tpl", RELAYDOMAINNAME="sp_relay_dm_live_001", DOMAINVALUE="relay.spliving.com", UESERVICEPROTO=HTTPS, ORIGINPULLPROTO=HTTPS, SERVICETYPE=LIVE, LIVEPROTOTYPE=FLV-1, UNSPTMEDIAACT=REDIRECT, PRIORITY=1000;
```

//配置直播URL鉴权规则。以鉴权算法为“TypeA"、加密算法为“SHA256为例。

```
ADD RELAYAUTHKEY: RELAYAUTHKEYNAME="relay_ak_sp_live_001", MASTERAUTHKEY="***", MASTERKEYCONFIRM="***"，SLAVEAUTHKEY="***", SLAVEKEYCONFIRM="***";
ADD RELAYURLAUTH: RELAYURLAUTHNM="relay_ur_sp_live_001", RELAYAUTHKEYNM="relay_ak_sp_live_001", URLAUTHMETHOD=TYPEA, ALGORITHM=SHA256, TIMESTAMPFMT=DEFAULT, AUTHFAILACT=FORBIDDEN, DASHAUTHEXTSW=DISABLE;
MOD RELAYDOMAIN: RELAYDOMAINNAME="sp_relay_dm_live_001", URLAUTHNAME="relay_ur_sp_live_001";
```

//配置HTTP头域字段，并绑定到域名下。

```
ADD RELAYHTTPMCTL: HTTPMSGCTRLNAME="sp_relay_hhd_live_001"; 
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Cache-Control", HEADERVALUE="no-cache"; 
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Credentials", HEADERVALUE="true";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Headers", HEADERVALUE="range";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Methods", HEADERVALUE="GET";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Origin", HEADERVALUE="*";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Expose-Headers", HEADERVALUE="Content-Length,Content-Range,content-type,expires,last-modified,via,X-Cache,X-Request-ID";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_live_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Max-Age", HEADERVALUE="3600";
MOD RELAYDOMAIN: RELAYDOMAINNAME="sp_relay_dm_live_001", HTTPMSGCTRLNAME="sp_relay_hhd_live_001";
```
