# 开启媒体中继业务总开关

- 操作场景
- 必备事项
- 任务示例

## 操作场景

在完成上述配置后，需要参考本章节在媒体中继UPF上开启媒体中继业务总开关。开启此开关后，媒体中继UPF会对配置进行校验，如果配置存在缺失会上报**ALM-81203 媒体中继配置不完整**告警。

## 必备事项

前提条件

已完成媒体中继业务增加媒体中继全局配置~增加媒体服务商配置（基于OTT应用）的相关配置。

数据

| 类别            | 参数名称              | 取值样例   | 获取方法   | 说明        |
|:--------------|:------------------|:-------|:-------|:----------|
| SET RELAYFUNC | 媒体中继功能开关（RELAYSW） | ENABLE | 固定取值   | 此开关为全局开关。 |

## 任务示例

任务描述

开启媒体中继功能的业务总开关。

脚本

```
SET RELAYFUNC: RELAYSW=ENABLE;
```
