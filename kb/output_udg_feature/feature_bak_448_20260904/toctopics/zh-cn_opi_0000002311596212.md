# 配置N40消息携带媒体中继流量

- 操作场景
- 必备事项
- 任务示例

## 操作场景

在N40计费场景下，当运营商需要核对话单流量时，请参考本章节进行配置。

## 必备事项

前提条件

- 请提前了解话单流量核对方案。
- SMF已升级到20.16.2及后续版本。

数据

| 类别             | 参数名称                             | 取值样例   | 获取方法   | 说明                    |
|:---------------|:---------------------------------|:-------|:-------|:----------------------|
| SET N40MSGCTRL | N40消息支持携带媒体中继流量开关（RELAYREPORTSW） | ENABLE | 全网规划   | 配置在N40消息中携带媒体中继上下行流量。 |

## 任务示例

任务描述

配置在N40消息中携带媒体中继上下行流量。

脚本

```
SET N40MSGCTRL: RELAYREPORTSW=ENABLE;
```
