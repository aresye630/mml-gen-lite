# 卸载RELAY服务

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当运营商不需要RELAY服务或RELAY服务动态上线失败时，可以单独卸载RELAY的pod，从而下线RELAY服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线RELAY pod的类型和数量。

数据

| 类别              | 参数名称   | 取值样例/说明                                                | 获取方法   |
|:----------------|:-------|:-------------------------------------------------------|:-------|
| UDG OM Portal帐户 | IP地址   | 192.168.1.1 操作维护接口IP，即“VNFD模板”中的“MNG_IP”或“MNG_IPv6”参数。 | 本端规划   |
| UDG OM Portal帐户 | 端口号    | 31943                                                  | 本端规划   |
| UDG OM Portal帐户 | 用户名    | admin                                                  | 本端规划   |
| UDG OM Portal帐户 | 密码     | Changeme_123                                           | 本端规划   |

## 操作步骤

1. 下线RELAY堆栈。

   1. 登录MANO（MAE/VNF LCM）业务面客户端。
      1. 在浏览器地址栏中输入以下地址后按回车键，弹出MANO（MAE/VNF LCM）客户端界面。

         **https://MANO（MAE/VNF LCM）业务的IP地址:端口号/**（例如https://10.50.12.104:31943/）
      2. 输入用户名和密码。

         系统默认的用户名和密码是“admin/Changeme\_123”，如果已修改MANO（MAE/VNF LCM）客户端用户名和密码，请使用新设置的用户名和密码登录。
      3. 单击“登录”，在MAE主界面的“应用”区域，单击“VNF LCM”，进入MANO（MAE/VNF LCM）系统界面。
   2. 卸载RELAY堆栈。
      1. 选择菜单栏“VNF生命周期管理 >扩缩容管理 > 手动扩缩容”，进入“手动扩缩容”窗口。
      2. 选择待操作的VNF，单击右侧“操作”列的“堆栈上下线”图标。
      3. 在弹出的界面中“操作”选择“下线”，选择需要下线的“堆栈名称”，**注意不需要勾选**“进行虚拟机扩缩容”。
      4. 单击“下一步”后，在弹出的确认界面点击“确认”，自动跳转到“扩缩容任务”界面，可以查看下线堆栈进度。如果下线堆栈失败，请联系华为技术支持解决。
      5. 执行命令，确认已经成功下线RELAY服务pod。

         ```
         DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="relayctrl-pod";
         DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="relay-pod";
         ```

         回显“查询Pod不存在”。
2. 若动态下线RELAY服务后，不再上线RELAY服务，则需要缩容RELAY自身VM（PBU\_E-R\_ARM），释放VM资源。若后续还需要上线RELAY服务，则不必缩容RELAY自身VM。**缩容VM**：请参见《UDG边缘侧扩缩容指导书（扩容单板）》。
