# 配置UPF动态分配IP地址

- 操作场景
- 必备事项
- 任务示例

## 操作场景

运营商规划UPF为UE分配IP地址，可基于APN/DNN、位置、SMF或其任意组合分配地址，在多DNN分流场景下，主要使用基于APN/DNN的IP地址分配。

## 任务示例

任务描述

UE接入核心网，采用专网UPF为UE动态分配IP地址。其中第一优先级按照从APN/DNN映射的地址范围内分配地址，如果第一优先级匹配不上，则分配地址失败。本任务以某个专网UPF举例，其他负荷分担的专网UPF配置逻辑相同。

脚本

1. 配置VPN和DNN，如已完成VPN和专用DNN创建，请跳过本步骤。该VPN实例与专网UPF的N6接口VPN实例保持一致。

   ```
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD APN:APN="stjwt.gd",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP",HASVPNIPV6=ENABLE,VPNINSTANCEIPV6="VRF_N6_Local_2B_APP",PSEUDOACTSWITCH=INHERIT;
   ```
2. 配置地址池和地址段。

   ```
   ADD POOL: POOLNAME="pool_enterprise_ipv4", POOLTYPE=LOCAL, IPVERSION=IPV4, IPLEASE=DISABLE, RELEASETIME=60, SINGLEIPFLAG=DISABLE,  HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_APP", ALARMSWITCH=ENABLE, IMSSW=DISABLE;
   ADD POOL: POOLNAME="pool_enterprise_ipv6", POOLTYPE=LOCAL, IPVERSION=IPV6, IPLEASE=DISABLE, RELEASETIME=360, SINGLEIPFLAG=DISABLE, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_APP", ALARMSWITCH=ENABLE, IMSSW=DISABLE;
   ```

   ```
   ADD SECTION: POOLNAME="pool_enterprise_ipv4", SECTIONNUM=0, IPVERSION=IPV4, V4STARTIP="10.1.1.0", V4ENDIP="10.1.1.255";
   ADD SECTION: POOLNAME="pool_enterprise_ipv6", SECTIONNUM=0, IPVERSION=IPV6, V6PREFIXSTART="fc00:1::1", V6PREFIXEND="fc00:1::1111", V6PREFIXLENGTH=64;
   ```
3. 配置地址池组。

   ```
   ADD POOLGROUP: POOLGRPNAME="pgrp_enterprise", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
   ```
4. 将地址池绑定到地址池组。

   ```
   ADD POOLBINDGROUP: POOLGROUPNAME="pgrp_enterprise", POOLNAME="pool_enterprise_ipv4", PRIORITY=10;
   ADD POOLBINDGROUP: POOLGROUPNAME="pgrp_enterprise", POOLNAME="pool_enterprise_ipv6", PRIORITY=10;
   ```
5. 配置APN与地址池组的映射关系。

   ```
   ADD POOLGRPMAP: MAPPINGNAME="mapping_enterprise", APN="stjwt.gd", POOLGROUPNAME="pgrp_enterprise";
   ```
6. 配置地址分配规则。

   ```
   SET APNIPALLOCRULE: APN="stjwt.gd", ALLOCATTR=LOCAL, FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE, IPV6ALLOCATTR=LOCAL, IPV6FIRSTRULESW=ENABLE, IPV6FIRSTRULE=APN-1&LOCATION-0&SMF-0, IPV6SECRULESW=DISABLE, IPV6THIRDRULESW=DISABLE;
   ```
7. （条件必选）当专网UPF通过VPN专线对接园区时，需要配置本步骤，引入wlr路由。

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_APP", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_APP", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```
