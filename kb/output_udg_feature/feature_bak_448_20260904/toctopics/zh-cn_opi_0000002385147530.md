# 激活用户QoE智能信息采集特性

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当运营商需要采集签约了业务体验感知套餐的重点用户和普通抽样用户这两类用户群的智能业务体验感知信息时，需要配置本页面。

## 必备事项

前提条件

- 请仔细阅读GWFD-111525 重点用户QoE智能监测和保障特性概述。
- 使用用户QoE智能信息采集特性时，需要确保已完成CoreMind与IISA可选服务的安装，请参考安装CoreMind服务、安装IISA服务。

数据

| 类别                | 参数名称                      | 取值样例         | 获取方法   | 说明                        |
|:------------------|:--------------------------|:-------------|:-------|:--------------------------|
| SET LICENSESWITCH | License项（LICITEM）         | LKV3G5EXPQ01 | 固定取值   | 开启用户QoE智能信息采集的License控制项。 |

| SET QOEBASICFUNC  | QoE智能分析开关（INQOESWITCH）    | ENABLE       | 固定取值   | 设置基于智能业务感知进行QoE推理。        |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 打开QoE模型子类开关。

   **SET QOEBASICFUNC**
3. 打开业务识别模型子类开关。

   **SET IISABASICFUNC**
4. 开启应用大类模型子类相关配置。

   **SET EXPBASICFUNC**

## 任务示例

任务描述

本章节仅介绍用户QoE智能信息采集特性的配置，其他体验感知配置及策略请根据实际使用情况酌情配置。

脚本

1. 开启用户QoE智能信息采集License开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5EXPQ01",SWITCH=ENABLE;
   ```
2. 打开QoE模型子类开关。

   ```
   SET QOEBASICFUNC: QOESWITCH=ENABLE, INQOESWITCH=ENABLE, MODE=IISA;
   ```
3. 打开业务识别模型子类开关。

   ```
   SET IISABASICFUNC: SWITCH=ENABLE;
   ```
4. 在开启重点业务保障功能命令中配置基于应用大类上报单据的开关。

   ```
   SET EXPBASICFUNC: SWITCH=ENABLE, ANARPTPERIOD=300, SRVPORT=15000, CATEGORYRPT=ENABLE;
   ```
