# 配置专用DNN基本数据

- 操作场景
- 对系统的影响
- 必备事项
- 任务示例

## 操作场景

本操作用于指导在专网SMF上开启通用DNN漫游分流特性，配置专用DNN下的专用UPF属性等基本数据。

## 对系统的影响

无。

## 任务示例

任务描述

在专网SMF上开启专用DNN的基本数据。

脚本

1. 打开“跨域互联互通-SMF”的License配置开关，当UE进行跨区域移动超出SMF的服务范围可插入I-SMF为UE提供服务。

   ```
   SET LICENSESWITCH: LICITEM="LKV2ASLSR02", SWITCH=ENABLE;
   ```
2. 配置VPN和DNN，如已完成VPN和专用DNN创建，请跳过本步骤。建议该VPN实例与专网UPF的N6接口VPN实例保持一致。

   ```
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD APN:APN="stjwt.gd",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP",HASVPNIPV6=ENABLE,VPNINSTANCEIPV6="VRF_N6_Local_2B_APP";
   ```
3. 特性约束专用会话不支持AOI，PRA，实时位置上报等特性，设置专用DNN不支持位置上报，设置专用SMF不支持兴趣区。请使用LST SMFFUNC查询系统是否有该配置记录，若无记录请配置SET SMFFUNC命令，若已有记录请按照SET SMFFUNC命令参数核查并调整。

   ```
   MOD APN:APN="stjwt.gd",LOCREPORT=DISABLE,LADN=NotSupport;
   LST SMFFUNC:;
   SET SMFFUNC:AOI=NotSupport;
   ```
4. 关闭APN空闲上下文定时器配置。

   **说明** 

   如果是一跳入家场景，且开启业务触发专用DNN分流会话时，需要打开APN空闲上下文定时器配置。

   ```
   SET APNIDLETIME:APN="stjwt.gd",INHERIT=NO,HCTXCHKSW=DISABLE;
   ```
5. 配置专用DNN下的切片信息，建议专网业务使用通用DNN的切片策略。
   1. 如果专网SMF和公网SMF合一部署，配置专网SMF在专用DNN下支持的切片时，请使用LST NSDNN查询公用DNN下网络切片索引并通过ADD NSDNN配置。如果专网SMF独立部署，没有配置common.dnn，则使用LST NFNS命令查询切片索引再通过ADD NSDNN配置。

      ```
      LST NSDNN: DNN="common.dnn";
      LST NFNS: NFTYPE=NfSMF;
      ADD NSDNN:NSIDX=0, DNN="stjwt.gd";
      ```
   2. 配置专网UPF在专用DNN下支持的切片。请使用LST PNFPROFILE查询专网UPF的实例，LST PNFNS查询专网UPF支持的切片索引。并通过ADD PNFDNN配置。

      ```
      LST PNFPROFILE: NFTYPE=NfUPF;
      LST PNFNS:;
      ADD PNFDNN: INDEX=100, NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", DNN="stjwt.gd", PNFNSINDEX=3; 
      ADD PNFDNN: INDEX=101, NFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000002", DNN="stjwt.gd", PNFNSINDEX=4;
      ```
6. 配置专网UPF在专用DNN下的属性。

   ```
   ADD APNUPFINFO:APN="stjwt.gd",UPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001",LOCATION=CENTERONLY;
   ADD APNUPFINFO:APN="stjwt.gd",UPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000002",LOCATION=CENTERONLY;
   ```
7. 配置DNN用户的动态PCC规则开关。

   ```
   SET APNPCCFUNC: APN="stjwt.gd", HOMEPCCSWITCH=ENABLE;
   ```
8. （条件必选）如果未完成2/3/4G融合，需要配置本步骤，限制ratType为2G/3G的用户接入。如果已完成2/3/4G融合，不需要配置本步骤。

   SGSN IPv4地址举例为1.1.1.1，IPv6地址举例为0000:0000:0000:0000:0000:0000:0000:0001。

   ```
   SET SRVNODERATPRI: NODETYPE=GGSN, FIRSTPRIORITY=SGSN_IP, SECONDPRIORITY=RAT;
   ADD SRVNODERAT: IPVERSION=IPV4, SRVNODESTARTV4="1.1.1.1", SRVNODEENDV4="255.255.255.255", RATTYPE=UTRAN;
   ADD SRVNODERAT: IPVERSION=IPV6, SRVNODESTARTV6="0000:0000:0000:0000:0000:0000:0000:0001", SRVNODEENDV6="FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF", RATTYPE=UTRAN;
   LCK APN: APN="stjwt.gd", LOCKED=ENABLE, LCKRATTYPE=UTRAN-1&GERAN-1&WLAN-0&GAN-0&HSPA-0&EUTRAN-0&VIRTUAL-0&EUTRAN_NB_IoT-0&LTE_M-0&NR-0;
   ```
