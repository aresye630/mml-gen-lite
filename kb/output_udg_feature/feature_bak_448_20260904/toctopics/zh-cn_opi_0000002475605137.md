# 配置不同区域下发相同DNN（方案一）

- 操作场景

- 任务示例

## 操作场景

该任务旨在指导操作人员在5G网络中配置不同区域下发相同DNN，配置独立开户模板。

**说明** 

- 运营商大网SMF POOL业务均质，POOL中所有SMF作为智能分流SMF时，UDM使用此章节方式进行配置。
- 如果现网已配置5G用户数据，无需执行此章节的步骤。

## 必备事项

前提条件

- 已完成园区专网UDM的基础配置并与周边网元完成对接。

- 操作人员具有PGW Web LMT客户端业务发放权限。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD NGCQOSTPL**命令增加5GS QoS模板。
3. 执行**ADD DNNQOSTPL**命令增加5GS DNN QoS模板。
4. 执行**ADD SMDATATPL**和**MOD SMDATATPL**命令配置5G SMDATA模板。
5. 执行**ADD NGSUSERTPL**命令增加5GS用户模板。
6. 给用户签约会话管理数据。

   - 对于新用户，需要开户后再执行**ADD TPLNGS**命令签约5G数据。
   - 如果用户已签约5G数据且在网，则使用**MOD TPLNGS**命令签约。

## 任务示例

任务描述

在5G网络中配置通用DNN下发功能所需的相关数据。

脚本

/\*登录“UDM业务管理”窗口\*/

/\*配置5GS QoS模板\*/

```
ADD NGCQOSTPL: HLRSN=1, TPLID=5, NGQI=1, ARPPRILEVEL=1;
```

/\*配置5GS DNN QoS模板，IWKEPSIND为TRUE\*/

```
ADD DNNQOSTPL: HLRSN=1, TPLID=5, PDUTYPE=IPV4, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2&SSC_MODE_3, IWKEPSIND=TRUE, LADN=FALSE, LBO=FALSE, NGCQOSTPLID=5, AMBRUP=104857600, UPUNIT=bps, AMBRDW=1073741824, DWUNIT=bps, CHARGE="0400", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED, SECONDARYAUTH=ABSENT, AAAIPALLOCATION=ABSENT, SAMESMFIND=ABSENT;
```

/\*配置5GS DNN QoS模板，IWKEPSIND为FALSE\*/

```
ADD DNNQOSTPL: HLRSN=1, TPLID=6, PDUTYPE=IPV4, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2&SSC_MODE_3, IWKEPSIND=FALSE, LADN=FALSE, LBO=FALSE, NGCQOSTPLID=5, AMBRUP=104857600, UPUNIT=bps, AMBRDW=1073741824, DWUNIT=bps, CHARGE="0400", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED, SECONDARYAUTH=ABSENT, AAAIPALLOCATION=ABSENT, SAMESMFIND=ABSENT;
```

/\*配置5G SMDATA模板\*/

```
ADD SMDATATPL: HLRSN=1, TPLID=5, SNSSAI="1-000000", DEFSNSSAI=TRUE, DNN="common.dnn", DNNQOSTPLID=5;
```

```
MOD SMDATATPL: HLRSN=1, TPLID=5, SNSSAI="1-000000", PROV=ADD_DNN, DNN="stjwt.gd", DNNQOSTPLID=6, DEFAULT=FALSE;
```

/\*配置5GS用户模板\*/

```
ADD NGSUSERTPL: HLRSN=1, TPLID=6, TPLNAME="5G开通", AMBRUP=150, UPUNIT=Mbps, AMBRDW=2, DWUNIT=Gbps, RFSPINDEX=0, SUBSREGTIMER=0, MPS=FALSE, ACTIVETIME=0, DLBUFFERIND=NOT_REQUESTED, AUTHTYPE=5G-AKA, MICOALLOWED=FALSE, MCS=FALSE, SMDATATPLID=5, SMSSUBSCRIBED=FALSE;
```

/\*为用户签约会话管理数据，包括common.dnn和stjwt.gd两个DNN，其中默认DNN为common.dnn\*/

/\*对于新用户，需要开户后执行**ADD TPLNGS**命令签约5G数据\*/

```
ADD TPLNGS: IMSI="46100000912345", NGSUSERTPLID=6;
```

/\*如果用户已签约5G数据且在网，则使用**MOD TPLNGS**命令签约，执行命令会触发数据变更通知\*/

```
MOD TPLNGS: IMSI="46100000912345", NGSUSERTPLID=6;
```
