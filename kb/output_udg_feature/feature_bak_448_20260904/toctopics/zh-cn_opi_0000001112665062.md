## 操作场景

当运营商设置了DNS免费策略时，为了避免黑客将用户原始数据报文隐匿在DNS报文中进行计费欺诈，需要部署DNS tunnel计费防欺诈功能阻止该类行为的发生。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读DNS计费防欺诈原理。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 任务示例

任务描述

开启DNS tunnel计费防欺诈功能，以DNS Type为“10”、“16”“11”作为欺诈举例，进行头域字段检查。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5DCAS01",SWITCH=ENABLE;
```

//配置指定APN下使能计费防欺诈。

```
SET APNAFFUNC:APN="apn-test",ISENABLE=ENABLE;
```

//配置使能DNS计费防欺诈功能。

```
SET ANTIFRAUD:ISNULLRECEN=ENABLE,ISTEXTEN=ENABLE,ISHEURISTICEN=DISABLE;
```

//配置需要进行防欺诈检查的DNS报文类型。

```
ADD AFDNSCHECKTYPE: TYPEVALUE=11;
```

//配置URR组和策略。

```
ADD URR:URRNAME="urr_fraud_online", URRID=1000, USAGERPTMODE=ONLINE;
ADD URR:URRNAME="urr_fraud_offline", URRID=2000, USAGERPTMODE=OFFLINE;
ADD URRGROUP: URRGROUPNAME="urrg_fraud", UPURRNAME1="urr_fraud_online", UPURRNAME2="urr_fraud_offline", DOWNURRNAME1="urr_fraud_online", DOWNURRNAME2="urr_fraud_offline";
ADD PCCACTIONPROP:PCCACTPROPNAME="ap_fraud",UPINITUPGATE=PASS;
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pg_fraud",PCCACTPROPNAME="ap_fraud",URRGROUPNAME="urrg_fraud";
```

//配置DNS欺诈报文的策略。

```
ADD AFPOLICY:AFPOLICYTYPE=DNS,PCCPOLICYGRPNM="pg_fraud";
```
