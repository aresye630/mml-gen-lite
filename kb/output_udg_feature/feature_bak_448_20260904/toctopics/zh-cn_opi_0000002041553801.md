# 卸载IPSecUIKE服务

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当运营商不需要IPSecUIKE服务或IPSecUIKE服务动态上线失败时，可以单独卸载IPSecUIKE的pod，从而下线IPSecUIKE服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线IPSecUIKE pod的类型和数量。

数据

| 类别                      | 参数名称                      | 取值样例/说明                                                | 获取方法   |
|:------------------------|:--------------------------|:-------------------------------------------------------|:-------|
| UDG OM Portal帐户         | IP地址                      | 192.168.1.1 操作维护接口IP，即“VNFD模板”中的“MNG_IP”或“MNG_IPv6”参数。 | 本端规划   |
| UDG OM Portal帐户         | 端口号                       | 31943                                                  | 本端规划   |
| UDG OM Portal帐户         | 用户名                       | admin                                                  | 本端规划   |
| UDG OM Portal帐户         | 密码                        | Changeme_123                                           | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | Pod类型列表（PODTYPE）          | uikectl-pod/uike-pod                                   | 固定取值   |
| 特性下线 OPR FEATUREDISABLE | 下线方式（DISABLETYPE）         | Normal                                                 | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | FUNCTIONSETNAME （网络功能集名称） | Uike                                                   | 固定取值   |

## 操作步骤

1. 登录UDG OM Portal。
2. 执行命令，动态下线IPSecUIKE的pod。

   ```
   OPR FEATUREDISABLE: PODTYPE="uikectl-pod/uike-pod", DISABLETYPE=Normal, FUNCTIONSETNAME="Uike";
   ```
3. 执行命令，确认已经成功下线IPSecUIKE pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="uikectl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="uike-pod";
   ```

   回显“查询Pod不存在”。
4. 若动态下线IPSecUIKE服务后，不再上线IPSecUIKE服务，则需要缩容IPSecUIKE自身VM（X86为：PBU\_P-I\_C4\_UIKE；ARM为：PBU\_P-I\_C4\_UIKE\_ARM），释放VM资源。

   若后续还需要上线IPSecUIKE服务，则不必缩容IPSecUIKE自身VM。

   **缩容VM**：请参见《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》。
