## 操作场景

NAT功能的业务流通过在UDG上配置规则后，匹配规则的数据流会流经NAT，完成NAT功能。

## 对系统的影响

该特性因增加分流过程，对性能有一定的影响，详细性能影响请联系华为技术支持获取。

## 操作步骤

1. 配置过滤器信息。

   **ADD FILTER**

   **SET REFRESHSRV**
2. 配置流过滤器信息。

   **ADD FLOWFILTER**
3. 配置流过滤器与过滤器绑定关系。

   **ADD FLTBINDFLOWF**
4. 配置用户模板。

   **ADD USERPROFILE**
5. 配置规则。

   **ADD RULE**
6. 配置用户模板和规则的绑定。

   **ADD RULEBINDING**

## 任务示例

任务描述

NAT规则配置。

脚本

//配置过滤器信息。

```
ADD FILTER: FILTERNAME="l34filter", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置流过滤器信息。

```
ADD FLOWFILTER: FLOWFILTERNAME="l34flowfilter";
```

//配置流过滤器与过滤器绑定关系。

```
ADD FLTBINDFLOWF: FLOWFILTERNAME="l34flowfilter", FILTERNAME="l34filter";
```

//配置用户模板。

```
ADD USERPROFILE: USERPROFILENAME="userprofile";
```

//配置规则。

```
ADD RULE: RULENAME="nat",POLICYTYPE=WORKER,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="l34flowfilter",WORKERNAME="nat";
```

//配置用户模板和规则的绑定。

```
ADD RULEBINDING: USERPROFILENAME="userprofile", RULENAME="nat",POLICYTYPE=WORKER;
```
