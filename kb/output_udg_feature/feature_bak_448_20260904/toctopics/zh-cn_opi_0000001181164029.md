# 卸载IPAPM服务

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当运营商不需要IPAPM服务或IPAPM服务动态上线失败时，可以单独卸载IPAPM pod，从而下线IPAPM服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线IPAPM pod的类型和数量。

数据

| 类别                      | 参数名称                      | 取值样例/说明                                                | 获取方法   |
|:------------------------|:--------------------------|:-------------------------------------------------------|:-------|
| UDG OM Portal帐户         | IP地址                      | 192.168.1.1 操作维护接口IP，即“VNFD模板”中的“MNG_IP”或“MNG_IPv6”参数。 | 本端规划   |
| UDG OM Portal帐户         | 端口号                       | 31943                                                  | 本端规划   |
| UDG OM Portal帐户         | 用户名                       | admin                                                  | 本端规划   |
| UDG OM Portal帐户         | 密码                        | Changeme_123                                           | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | Pod类型列表（PODTYPE）          | ipapmctrl-pod/ipapmexec-pod                            | 固定取值   |
| 特性下线 OPR FEATUREDISABLE | 下线方式（DISABLETYPE）         | Normal                                                 | 本端规划   |
| 特性下线 OPR FEATUREDISABLE | FUNCTIONSETNAME （网络功能集名称） | IPAPM                                                  | 固定取值   |

## 操作步骤

1. 登录UDG OM Portal。
2. 执行命令，删除配置数据。

   在动态下线IPAPM服务前，需要将安装过程中产生的配置数据（实例）进行清除，再执行动态下线命令。清除配置数据需要先查询是否存在实例，如已存在实例，需要进行实例删除。请按如下顺序进行数据清除：

   1. 执行命令，查询发送端实例。

      ```
      LST TWAMPSENDER:;
      ```
   2. 执行命令，删除发送端实例。

      ```
      RMV TWAMPSENDER: CLIENTID="客户端ID";
      ```
   3. 执行命令，查询客户端实例。

      ```
      LST TWAMPCLIENT:;
      ```
   4. 执行命令，删除客户端实例。

      ```
      RMV TWAMPCLIENT: CLIENTID="客户端ID";
      ```
   5. 执行命令，查询响应端实例。

      ```
      LST TWAMPRESPONDER:;
      ```
   6. 执行命令，删除响应端实例。

      ```
      RMV TWAMPRESPONDER: RESPONDERID="客户端ID";
      ```
   7. 执行命令，查询本端逻辑接口实例。

      ```
      LST TWAMPLOGICINF:;
      ```
   8. 执行命令，删除逻辑接口实例。

      ```
      RMV TWAMPLOGICINF: NAME="逻辑接口名称";
      ```
   9. 执行命令，查询vpn实例。

      ```
      LST TWAMPVPNINST:;
      ```
   10. 执行命令，删除vpn实例。

       ```
       RMV TWAMPVPNINST: VRFNAME="VPN实例名称";
       ```
3. 执行命令，动态下线IPAPM pod。

   ```
   OPR FEATUREDISABLE: PODTYPE="ipapmctrl-pod/ipapmexec-pod", DISABLETYPE=Normal, FUNCTIONSETNAME="IPAPM";
   ```
4. 执行命令，确认已经成功下线IPAPM pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="ipapmctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="ipapmexec-pod";
   ```

   回显“查询Pod不存在”。
5. 若动态下线IPAPM服务后，不再上线IPAPM服务，则需要缩容IPAPM自身VM（PBU\_P-T），释放VM资源。

   若后续还需要上线IPAPM服务，则不必缩容IPAPM自身VM。

   **缩容VM**：请参见《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》。
