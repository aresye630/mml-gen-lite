## 操作场景

当运营商设置了DNS免费策略，为了避免黑客用专用的客户端将原始报文的端口修改为DNS知名端口53，伪装成免费的DNS报文实现免费上网。DNS端口防欺诈方案不再仅通过端口号对DNS数据报文进行解析，而是通过增强的DNS报文识别功能对DNS数据报文进行深度解析，判断DNS报文的协议一致性，将真正的用户DNS报文按照原来的规则记为免费，而对伪造的DNS报文按照正常的流量进行计费。

- 服务器端口53，L7识别为DNS报文，则判断为正常DNS报文。
- 服务器端口53，L7识别为非DNS报文，则判断为使用DNS 53端口欺诈报文。

**说明** 

适用于PGW-U、UPF。

## 任务示例

任务描述

配置DNS的报文识别，将满足端口号为53且协议识别为DNS的报文设置为免费。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5DCAS01",SWITCH=ENABLE;
```

//配置三四层过滤条件，报文满足端口号为53时才会命中该过滤条件。

```
ADD FILTER:FILTERNAME="filter_dns",L34PROTTYPE=STRING,L34PROTOCOL=UDP,SVRSTARTPORT=53,SVRENDPORT=53;
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_dns";
ADD FLTBINDFLOWF:FLOWFILTERNAME="filter_dns",FILTERNAME="flowfilter_dns";
```

//配置七层过滤条件，报文满足七层协议是DNS时才会命中该过滤条件。

```
ADD L7FILTER:L7FILTERNAME="l7filter_dns",SUBL7FLTNAME="1",URL="*/*"; 
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_dns", PROTOCOLNAME="dns", L7FILTERNAME="l7filter_dns";
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置免费的DNS报文使用的URR组和策略。

```
ADD URR:URRNAME="urr_dns",URRID=2000,USAGERPTMODE=ONLINE,OFFMETERINGTYPE=FREE;
ADD URRGROUP:URRGROUPNAME="cp_dns",UPURRNAME1="urr_dns",DOWNURRNAME1="urr_dns";
ADD PCCACTIONPROP:PCCACTPROPNAME="ap_dns",UPINITUPGATE=PASS;
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pg_dns",PCCACTPROPNAME="ap_dns",URRGROUPNAME="cp_dns";
```

//配置免费的DNS报文使用的规则。

```
ADD RULE:RULENAME="rule_dns",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="filter_dns",POLICYNAME="pg_dns";
```

//配置免费的DNS报文的规则绑定用户模板。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_red";
```
