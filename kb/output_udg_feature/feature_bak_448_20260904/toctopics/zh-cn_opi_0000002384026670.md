## 操作场景

当运营商需要对签约了重点业务保障套餐的用户业务流量进行QoE智能监测和保障时，需要配置本页面。

## 必备事项

前提条件

- 请仔细阅读GWFD-111525 重点用户QoE智能监测和保障特性概述。
- 使用重点用户QoE智能监测和保障特性时，需要确保已完成CoreMind与IISA可选服务的安装，请参考安装CoreMind服务、安装IISA服务。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 打开QoE模型子类开关。

   **SET QOEBASICFUNC**
3. 打开业务识别模型子类开关。

   **SET IISABASICFUNC**
4. 配置保障策略。

   **SET VVIPBASICFUNC**

   **ADD POLICYCONDITION**

   **ADD SSUPROTCOLGROUP**

   **ADD APPPOLICYCTRL**
5. 若需要开启大类检测时，开启应用大类模型子类相关策略及配置。

   **ADD CATEPOLICYCTRL**
6. 开启抽样率为100%。

   **SET RPTGLBPARA**
7. 开启TCP UDP分析。

   **SET RPTGLBCFG**
8. 开启NWDAF专有承载使用配置预定义规则进行计费PCC控制功能。

   **SET SOFTPARA**

## 任务示例

任务描述

本章节仅介绍重点用户QoE智能监测和保障特性的配置，其他保障配置及质差策略请根据实际使用情况酌情配置。

脚本

1. 开启重点用户QoE智能监测和保障License开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5ANAQ01",SWITCH=ENABLE;
   ```
2. 打开QoE模型子类开关。

   ```
   SET QOEBASICFUNC: QOESWITCH=ENABLE, INQOESWITCH=ENABLE, MODE=IISA;
   ```
3. 打开业务识别模型子类开关。

   ```
   SET IISABASICFUNC: SWITCH=ENABLE;
   ```
4. 配置保障策略。配置脚本示例如下，具体参数取值请根据现网业务调整。

   配置重点业务保障基本功能相关参数。若需要开启基于应用大类检测时，需开启CATEGORYRPT开关，否则不需要开启。

   ```
   //以上报4G及5G用户单据为例
   SET VVIPBASICFUNC: SWITCH=ENABLE, QOERPTPERIOD=5, NONQOERPTPERIOD=300, REPORTSCOPE=ALL_QOE_REPORT, SAMPLEPERIOD=5, RPTUSERTYPE=RPT_FOR45GUSER, CATEGORYRPT=ENABLE;
   ```

   ```
   ADD POLICYCONDITION: POLICYCNDNAME="policytestname", UPLINKAVGRATE=300, UPFLOWTHRD=15, MULTIKPIJUDGE=SOME_COND_NOT_MATCHED;
   ADD SSUPROTCOLGROUP: DEFPRTGRPNAME="live_video", PROTOCOLNAME="taobao_live", POLICYCNDNAME="policytestname", QOEDETECTCOND=UP_BIGFLOW_CHECK;
   ```

   配置基于应用的质差策略。

   ```
   ADD APPPOLICYCTRL: APPIDNAME="appgroup1", SUBAPPIDNAME="app1", DEFPRTGRPNAME="live_video", MOS="4", ASSURANCELEVEL=SUB_APP;
   ```
5. 需要开启基于应用大类检测时，执行本步骤配置基于应用大类的质差策略。

   ```
   ADD CATEPOLICYCTRL: APPIDNAME="appgroup1", CATEGORYID=105, QOEDETPRD=5, MOS=20, QOERPTPOLICY=QOE_REPORT_ONCE, ENDDELAY=100;
   ```
6. 开启抽样率为100%。

   ```
   SET RPTGLBPARA: FLOWSAMPLERATE=1000;
   ```
7. 开启TCP UDP分析。

   ```
   SET RPTGLBCFG: TCPINSIGHTSW=ENABLE, UDPINSIGHTSW=ENABLE;
   ```
8. 开启NWDAF专有承载使用配置预定义规则进行计费PCC控制功能。

   **说明** 

   - 当选择保障流量归一化计费时，需要配置该参数。
   - 当选择保障流量独立计费方案时，无需配置该参数。

   ```
   SET SOFTPARA:DT=BIT,BITNUM=2576,BITVALUE=1;
   ```
