# 配置用户面会话过载控制

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

为了避免UDG上EPS承载/PDU会话资源残留从而出现用户面会话过载，需要配置会话核查功能，及时清除残留的EPS承载/PDU会话信息。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

请仔细阅读GWFD-020162 用户面会话过载控制特性概述。

数据

| 类别              | 参数名称                            | 取值样例   | 获取方法   | 说明                                                         |
|:----------------|:--------------------------------|:-------|:-------|:-----------------------------------------------------------|
| SET SESSCHKFUNC | 会话创建核查开关（ESTABLISHCHK）          | ENABLE | 本端规划   | 控制新的EPS承载/PDU会话创建时对UDG上已经存在的相同IMSI的EPS承载/PDU会话是否触发核查。默认使能。 |
| SET SESSCHKFUNC | 会话创建核查阈值（SESSNUMTHD）            | 4      | 本端规划   | 配置存在几个相同IMSI的EPS承载/PDU会话数时触发会话核查。默认4个。                     |
| SET SESSCHKFUNC | 路径断核查开关（PATHDWNCHK）             | ENABLE | 本端规划   | 控制N4链路从断到正常后是否触发与SGW-C/PGW-C/SMF之间的会话信息核查。默认使能。            |
| SET SESSCHKFUNC | 每日核查开关（DAYCHK）                  | ENABLE | 本端规划   | 控制系统每天是否触发与SGW-C/PGW-C/SMF之间的会话信息核查。默认使能。                  |
| SET SESSCHKFUNC | Session SG恢复核查开关（SGRECOVERYCHK） | ENABLE | 本端规划   | 控制系统进程故障恢复后是否触发与SGW-C/PGW-C/SMF之间的会话信息核查。默认使能。             |
| SET SESSCHKFUNC | 会话规格限制核查开关（SESSLIMITCHK）        | ENABLE | 本端规划   | 控制会话资源达到阈值90%时是否触发跟SGW-C/PGW-C/SMF的会话信息核查。默认使能。            |

## 操作步骤

1. 设置会话核查配置。

   **SET SESSCHKFUNC**

## 任务示例

任务描述

设置会话核查配置，打开会话核查开关。

脚本

//设置会话核查配置，打开会话核查开关。

```
SET SESSCHKFUNC:ESTABLISHCHK=ENABLE, SESSNUMTHD=4, PATHDWNCHK=ENABLE, DAYCHK=ENABLE, SGRECOVERYCHK=ENABLE, SESSLIMITCHK=ENABLE;
```
