## 操作场景

**说明** 

适用于PGW-U、UPF。

当运营商规划检测利用计费漏洞进行欺诈的用户行为时，需要配置防欺诈业务规则数据库功能，进而对欺诈行为进行评估和策略控制。

## 必备事项

前提条件

- 请仔细阅读HTTP计费防欺诈。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

- 防欺诈业务规则数据库文件和防欺诈业务规则数据库数字签名文件已经上载到SSGCTRL容器下的“/opt/sf\_filetrans/SessionSGCtrlSvc”目录。

## 操作流程

**图1** 配置逻辑

**说明** 

以下软参打开时，对应的防欺诈功能开启。

- BIT577 用于控制HTTP业务通过防欺诈特征库识别为欺诈后，该业务使用的策略
- BIT713 控制是否支持HTTP请求行Method和Version字段小写字符欺诈检测
- BIT714 控制是否支持HTTP请求行多空格或制表符欺诈检测
- BYTE629 控制HTTP协议防欺诈相关功能
- BYTE841 控制HTTP协议防欺诈增强功能
- BIT1086 控制系统是否开启欺诈代理业务的识别功能

## 任务示例

任务描述

本例描述一新建局点，配置通过部署防欺诈业务规则数据库的方式检测用户是否存在欺诈行为，并通过配置可信的DNS Server、代理服务器IP地址及重点费率组的形式进行全面的防欺诈检测。针对检测为欺诈的用户，采用计费矫正的策略。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5HCAS01",SWITCH=ENABLE;
```

//加载防欺诈特征库。

```
LOD AFDB:VERSION="0001.01.0086.0001.001";
```

//配置防欺诈判断规则。

```
ADD AFDNSSERVER:IPVERSION=IPV4,IPV4ADDR="192.168.0.1";
```

```
ADD AFPROXYSERVER:IPVERSION=IPV4,IPV4ADDR="192.168.0.2";
```

//配置HTTP防欺诈功能。

```
SET ANTIFRAUD:HTTPAFSWITCH=ENABLE;
```

//配置APN防欺诈功能。

```
SET APNAFFUNC:APN="apn-af",ISENABLE=ENABLE;
```

//配置欺诈用户的URR组和策略。

```
ADD URR:URRNAME="urr_test",URRID=1000,USAGERPTMODE=OFFLINE;
```

```
ADD URRGROUP:URRGROUPNAME="cp_test",UPURRNAME1="urr_test",DOWNURRNAME1="urr_test";
```

```
ADD PCCACTIONPROP:PCCACTPROPNAME="pap_test";
```

```
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="ppg_test",PCCACTPROPNAME="pap_test",URRGROUPNAME="cp_test";
```

//绑定欺诈用户的控制策略。

```
ADD AFPOLICY:AFPOLICYTYPE=HTTP,PCCPOLICYGRPNM="ppg_test";
```

//配置特殊URR组列表，选择对免费RG进行判断。

```
ADD SPECURRGRPLIST:URRGROUPNAME="cp_free";
```
