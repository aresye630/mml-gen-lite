- 操作场景

## 操作场景

**说明** 

适用于SGW-U、PGW-U、UPF。

当运营商部署了链接页面与主页面的关联计费和策略控制时，可以激活关联URL核减功能。

## 必备事项

前提条件

- 请仔细阅读GWFD-020304 关联URL核减。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

配置关联URL核减功能。

1. 配置关联URL核减使用的URR。

   1. 配置URR。

      **ADD URR**
   2. 配置上行和下行发起的业务对应的URR。

      **ADD URRGROUP**
2. 配置内容计费使用的PCC策略组。

   **ADD PCCPOLICYGRP**
3. 配置过滤条件。

   1. 配置七层过滤条件，开启Referer关联计费开关。

      **ADD L7FILTER**
   2. 配置流过滤器。

      **ADD FLOWFILTER**
   3. 绑定七层过滤条件。

      **ADD PROTBINDFLOWF**
4. 配置关联URL核减使用的业务规则。

   **ADD RULE**
5. 配置关联URL核减使用的业务规则绑定用户模板。

   1. 创建UserProfile实例。

      **ADD USERPROFILE**
   2. 将已配置的计费规则绑定到UserProfile。

      **ADD RULEBINDING**

## 任务示例

任务描述

本例中，用户通过点击“www.example.com”上的链接访问网站“www.huawei.com”，产生的流量计入网站“www.example.com”中。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5RUCF01",SWITCH=ENABLE;
```

//配置关联URL核减使用的费率标识。

```
ADD URR:URRNAME="urr_red",URRID=1000,USAGERPTMODE=OFFLINE;
ADD URRGROUP:URRGROUPNAME="cp_red",UPURRNAME1="urr_red",DOWNURRNAME1="urr_red";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="cg_red",URRGROUPNAME="cp_red";
```

//配置关联URL核减使用的七层过滤条件。

```
ADD L7FILTER:L7FILTERNAME="l7-test",SUBL7FLTNAME="sl7-test",URL="www.example.com",ISREFEREREN=ENABLE;
ADD FLOWFILTER:FLOWFILTERNAME="fg_red";
ADD PROTBINDFLOWF:FLOWFILTERNAME="fg_red",PROTOCOLNAME="http",L7FILTERNAME="l7-test";
```

//配置内容计费规则。

```
ADD RULE:RULENAME="rule_red",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="fg_red",POLICYNAME="cg_red";
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置内容计费规则绑定用户模板。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_red";
```
