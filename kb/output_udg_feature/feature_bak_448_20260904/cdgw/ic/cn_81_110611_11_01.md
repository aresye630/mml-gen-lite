# 激活SRVCC

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

在UDG上开启特性的License开关激活SRVCC功能。

**说明** 

适用于SGW-U、PGW-U。

## 必备事项

前提条件

- 请仔细阅读GWFD-020252 SRVCC。
- 完成配置VoLTE基础语音业务。
- 完成**加载license**（如果有需求，请联系华为技术支持工程师处理）。

数据

无

## 操作步骤

打开本特性的License配置开关。

**SET LICENSESWITCH**

## 任务示例

任务描述

打开本特性的License配置开关，使能SRVCC功能。

脚本

打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM ="LKV3G5RVCC01",SWITCH=ENABLE;
```
