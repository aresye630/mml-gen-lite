## 操作场景

**说明** 

适用于PGW-U、UPF。

当运营商能获取业务Server IP的情况下，部署免费套餐包时，为防止黑客计费欺诈行为，需要配置HTTP计费防欺诈功能，将服务器IP设置为提前获取的免费业务服务器IP，实现报文过滤。

## 必备事项

前提条件

- 请仔细阅读HTTP计费防欺诈。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 任务示例

任务描述

本例中以一新建局点为例，用户访问huawei业务的流量记入URR ID为1008的免费URR中，其他业务记入1009的通用URR中。huawei业务的服务器IP为10.1.2.3/24。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5HCAS01",SWITCH=ENABLE;
```

//配置HTTP计费防欺诈使用的绑定三四层过滤规则。

```
ADD FILTER:FILTERNAME="filter_host_huawei",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=IP,SVRIP="10.1.2.3",SVRIPMASKTYPE=LENGTHTYPE,SVRIPMASKLEN=24,SVRSTARTPORT=80,SVRENDPORT=80;
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_host_huawei";
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_host_huawei",FILTERNAME="filter_host_huawei";
SET REFRESHSRV:REFRESHTYPE=ALL;
```

//配置七层解析数据，设置协议类型为“http”。

```
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_host_huawei",PROTOCOLNAME="http";
```

//配置URR组和PCC策略组。

```
ADD URR:URRNAME="urr_huawei",URRID=1008, USAGERPTMODE=OFFLINE, OFFMETERINGTYPE=FREE;
ADD URR:URRNAME="urr_common",URRID=1009, USAGERPTMODE=OFFLINE;
ADD URRGROUP:URRGROUPNAME="cp_huawei",UPURRNAME1="urr_huawei",DOWNURRNAME1="urr_huawei";
ADD URRGROUP:URRGROUPNAME="cp_common",UPURRNAME1="urr_common",DOWNURRNAME1="urr_common";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pcc_huawei",URRGROUPNAME="cp_huawei";
```

//配置HTTP免费报文使用的规则。

```
ADD RULE:RULENAME="rule_huawei",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="flowfilter_host_huawei",PRIORITY=10,POLICYNAME="pcc_huawei";
```

//配置HTTP免费报文使用的业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_huawei";
```

//配置HTTP欺诈报文使用的默认URR组。

```
SET URRGRPBINDING:USERPROFILENAME="up_test",DFTURRGRPNAME="cp_common";
```
