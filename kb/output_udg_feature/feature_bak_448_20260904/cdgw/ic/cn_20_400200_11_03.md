# 配置用户Portal

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

UDG在用户上线后被自动重定向到个人门户网站，然后通过个人门户网站访问各种业务，以实现对用户的信息进行管理。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-110281 用户Portal。
- UDG与周边网元的互通配置已经完成。

**说明** 

如果要配置IPv4用户Portal规则，IP Farm、Virtual IP、VPN、Server IP、心跳检测接口IP和Filter都要使用IPv4形式的命令配置。

该配置实例是配置IPv4用户Portal规则，因此以上IP地址均是IPv4形式。可以执行**DSP RULECHECK**命令对指定规则的所有IP地址取值的IP版本一致性进行检查。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置用户Portal业务的整机参数。

   **SET IPFARMGLOBAL**
3. 配置IP Farm使用的心跳检测接口。

   **ADD LOGICINF**
4. 配置IP Farm。
   1. 创建重定向的IP Farm。

      **ADD IPFARM**

      **说明** 

      不同IP Farm下的服务器需要配置不同的心跳检测接口。
   2. 配置IP Farm中的IP Farm服务器地址，作为重定向Server的目标地址和心跳检测地址。

      **ADD IPFARMSERVER**

   **说明** 

   IP Farm配置完成后，执行命令**LST IPFARMSERVER**查询IP Farm中server的状态。为确保业务正常进行，需保证至少有一个server的状态为up。

   因UDG不支持HTTPS协议报文的重定向处理，若重定向URL采用HTTPS协议且命中了重定向规则，则可以采用黑名单规则**ADD BLACKLISTRULE**配置不执行重定向功能，放行重定向报文，保证用户重定向后的业务可以正常处理。

   在用户发起HTTP承载请求时，如果当前的业务报文无法做重定向，缺省情况下，UDG直接阻塞该业务报文。如果无法做重定向动作时的报文需要正常转发，可以使用**ADD IPFARMSERVER**/**MOD IPFARMSERVER**命令将“DEFAULTACT”参数设置为“PASS”。

   使用**SET SRVCOMMONPARA**命令开启内嵌IPv4地址的IPv6业务处理功能时，为确保正确触发重定向，建议在IP Fram下配置URL。
5. 配置用户Portal业务使用的三四层过滤条件。
   1. 配置用户Portal业务使用的三四层过滤条件。

      **ADD FILTER**
   2. 配置FlowFilter。

      **ADD FLOWFILTER**
   3. 将Filter绑定到FlowFilter。

      **ADD FLTBINDFLOWF**
6. 配置特征库识别HTTP协议。

   **LOD SIGNATUREDB**
7. 配置用户Portal业务的七层过滤条件。
   1. 配置七层过滤器。

      **ADD L7FILTER**
   2. 绑定七层过滤信息。

      **ADD PROTBINDFLOWF**
   3. **可选：**将新配置的Filter和L7Filter置为生效。

      **SET REFRESHSRV**

      **说明** 

      系统自动在60s后将配置的L7Filter置为生效。如果需要将新配置的L7Filter立即生效，可执行本步骤。
8. 配置用户Portal业务使用的计费属性。
   1. 配置URR。

      **ADD URR**
   2. 配置计费属性。

      **ADD URRGROUP**
9. 配置用户Portal业务使用的PCC策略组。

   **ADD PCCPOLICYGRP**
10. 配置用户Portal业务使用的规则。

    **ADD RULE**

    **说明** 

    如果运营商希望基于流过滤器组设置过滤条件时，配置“流过滤器或流过滤器组选择(FILTERINGMODE)”为“FLOWFILTERGRP”，并且使用**ADD FLOWFILTERGRP**命令配置流过滤器组。
11. 配置用户Portal业务使用的业务策略组合。
    1. 配置User Profile

       **ADD USERPROFILE**
    2. 将配置的Rule绑定到User Profile

       **ADD RULEBINDING**
    3. 添加APN

       **ADD APN**

## 任务示例

任务描述

本实例中，操作员在UDG上进行数据配置实现以下要求：

- UDG使用最小负荷server方式实现用户Portal功能。
- UDG将用户首次发往“www.huawei.com”的IPv4报文重定向到“www.example.com”或“www.vmall.com”服务器上。
- UDG与重定向服务器之间进行心跳检测。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5CPPT01",SWITCH=ENABLE;
```

//配置整机的用户Portal参数。

```
SET IPFARMGLOBAL:SERVERTYPE=REDIRECT,TIMETHRESHOLD=10,HEALTHSUCCLIMIT=2,HEALTHFAILLIMIT=4,LBMETHOD=LEAST_LOAD;
```

//配置IP Farm使用的心跳检测接口。

```
ADD LOGICINF:NAME="phif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="10.10.10.10",IPV4MASK1="255.255.255.255";
```

//配置IP Farm。

```
ADD IPFARM:IPFARMNAME="farm_test",IPVERSION=IPV4,HEALTHCHECKFLAG=ENABLE,INTERFACENAME="phif1/0/0";
```

```
ADD IPFARMSERVER:IPFARMNAME="farm_test",IPVERSION=IPV4,SERVERIPV4="192.168.10.123",URL="www.example.com";
```

```
ADD IPFARMSERVER:IPFARMNAME="farm_test",IPVERSION=IPV4,SERVERIPV4="192.168.10.124",URL="www.vmall.com";
```

//配置用户Portal业务使用的三四层过滤条件。

```
ADD FILTER:FILTERNAME="filter_test",L34PROTTYPE=STRING,L34PROTOCOL=TCP;
```

```
ADD FLOWFILTER:FLOWFILTERNAME="ff_test1";
```

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="ff_test1",FILTERNAME="filter_test";
```

//配置协议识别。

```
LOD SIGNATUREDB:LOADMODE=LATEST;
```

//配置用户Portal业务使用的七层过滤条件。

```
ADD L7FILTER:L7FILTERNAME="l7-test",SUBL7FLTNAME="sub-l7-test",URL="www.huawei.com/*";
```

```
ADD PROTBINDFLOWF:FLOWFILTERNAME="ff_test1",PROTOCOLNAME="http",L7FILTERNAME="l7-test";
```

//将新配置的信息置为生效。

```
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置用户Portal业务使用的计费属性。

```
ADD URR:URRNAME="cbb_test",URRID=1000,USAGERPTMODE=ONLINE;
```

```
ADD URRGROUP:URRGROUPNAME="cp_test",UPURRNAME1="cbb_test",DOWNURRNAME1="cbb_test";
```

//配置用户Portal业务使用的PCC策略组。

```
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pcc-pg_test",URRGROUPNAME="cp_test";
```

//配置用户Portal业务使用的业务规则。

```
ADD RULE:RULENAME="rule_test1",POLICYTYPE=SMARTREDIRECT,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="ff_test1",PRIORITY=10,POLICYNAME="farm_test";
```

```
ADD RULE:RULENAME="rule_test2",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="ff_test1",PRIORITY=20,POLICYNAME="pcc-pg_test";
```

//配置用户Portal业务使用的业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test",CAPMODETHRES=6;
```

```
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test1";
```

```
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test2";
```

```
ADD APN:APN="apn-test";
```
