# 配置HTTP计费防欺诈（不能获取Server IP）

## 操作场景

**说明** 

适用于PGW-U、UPF。

当运营商在不能获取业务Server IP的情况下部署免费套餐包，即未指定Server IP指定了七层Host/URL免费规则、或者指定了七层URL充值页面免费规则时，为防止黑客计费欺诈行为，需要配置HTTP计费防欺诈功能。

用户访问HTTP业务时，客户端会先发起DNS域名解析流程，以获取Server IP，然后再携带Server IP发起HTTP业务请求消息，本示例以DNS请求消息和优惠的HTTP业务请求消息均采用免费的计费策略进行举例。

- UDG解析DNS的数据报文，并形成指定host服务器和IP地址的映射表。
- 当用户访问的业务时，如果报文目的IP地址没有包含在这个host服务器地址映射表中，则其访问的业务将被记录费用。

## 必备事项

前提条件

- 请仔细阅读HTTP计费防欺诈。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 任务示例

任务描述

用户访问DNS报文计入记入URR ID为1008的免费URR中，访问example业务记入URR ID为1008的免费URR中，其他业务计入URR ID为1009的通用URR中。

由于无法获取example业务服务器的IP列表，为了防止examplebook免费流量，开启HTTP计费防欺诈功能，对example业务报文进行精确匹配。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5HCAS01",SWITCH=ENABLE;
```

//配置DNS业务的三四层解析规则。

```
ADD FILTER:FILTERNAME="filter_dns",L34PROTTYPE=STRING,L34PROTOCOL=UDP,SVRSTARTPORT=53,SVRENDPORT=53;
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_dns";
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_dns",FILTERNAME="filter_dns";
```

//配置DNS业务的七层解析规则。

```
ADD L7FILTER:L7FILTERNAME="l7filter_dns",SUBL7FLTNAME="1",URL="*/*";
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_dns",PROTOCOLNAME="dns",L7FILTERNAME="l7filter_dns";
SET REFRESHSRV:REFRESHTYPE=ALL;
```

//配置Host。

```
ADD HOST:HOSTNAME="h_example",DOMAINVALUE="*example.com";
```

//配置HTTP免费业务使用的三四层解析规则。

```
ADD FILTER:FILTERNAME="filter_example",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=HOSTNAME,HOSTNAME="h_example",SVRSTARTPORT=80;
SET REFRESHSRV:REFRESHTYPE=ALL;
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_example";
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_example",FILTERNAME="filter_example";
```

//配置HTTP免费业务使用的七层解析规则。

```
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_example",PROTOCOLNAME="http";
```

//配置URR组和策略。

```
ADD URR:URRNAME="urr_common",URRID=1009, USAGERPTMODE=OFFLINE;
ADD URR:URRNAME="urr_example",URRID=1008, USAGERPTMODE=OFFLINE, OFFMETERINGTYPE=FREE;
ADD URRGROUP:URRGROUPNAME="cp_common",UPURRNAME1="urr_common",DOWNURRNAME1="urr_common";
ADD URRGROUP:URRGROUPNAME="cp_example",UPURRNAME1="urr_example",DOWNURRNAME1="urr_example";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pcc_dns",URRGROUPNAME="cp_example";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pcc_example",URRGROUPNAME="cp_example";
```

//配置DNS报文和HTTP免费报文使用的规则。

```
ADD RULE:RULENAME="rule_dns",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfilter_dns",POLICYNAME="pcc_dns";
ADD RULE:RULENAME="rule_example",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfilter_example",POLICYNAME="pcc_example";
```

//配置HTTP计费防欺诈使用的业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_example";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_dns";
```

//配置UserProfile下的默认URR组。

```
SET URRGRPBINDING:USERPROFILENAME="up_test",DFTURRGRPNAME="cp_common",DFTSIGURRGNAME="cp_common";
```
