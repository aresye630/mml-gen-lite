# 修改Echo消息的重发数据

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

在组网改变、网络调整中修改调整系统参数中Echo消息的重发时间的间隔和最大尝试发送次数。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 对系统的影响

该配置除了影响Echo消息外，还影响UDG发送的去活请求消息和更新请求消息。

## 必备事项

前提条件

- 请仔细阅读GWFD-010102 路径管理
- 完成配置GTP/PFCP路径管理参数。

数据

| 类别            | 参数名称                        |   取值样例 | 获取方法   | 说明   |
|:--------------|:----------------------------|-------:|:-------|:-----|
| SET UPGTPPATH | GTP请求消息的重发时间间隔(T3RESPONSE)  |     10 | 本端规划   | -    |
| SET UPGTPPATH | GTP请求消息的最大尝试发送次数(N3REQUEST) |      3 | 本端规划   | -    |

| 类别            | 参数名称                               |   取值样例 | 获取方法   | 说明   |
|:--------------|:-----------------------------------|-------:|:-------|:-----|
| SET UPN4UPATH | N4接口的GTP请求消息的重发时间间隔(N4T3RESPONSE)  |     10 | 本端规划   | -    |
| SET UPN4UPATH | N4接口的GTP请求消息的最大尝试发送次数(N4N3REQUEST) |      3 | 本端规划   | -    |

## 操作步骤

1. 设置UDG非N4/Sxb接口的GTP请求消息的重发时间间隔和最大尝试发送次数。

   **SET UPGTPPATH**
2. 设置UDGN4/Sxb接口的GTP请求消息的重发时间间隔和最大尝试发送次数。

   **SET UPN4UPATH**

## 任务示例

任务描述

将Echo消息的重发时间的间隔设置为“10秒”和最大尝试发送次数设置为“3次”。

脚本

//设置非N4/Sxb接口的GTP请求消息的重发时间间隔和最大尝试发送次数。

```
SET UPGTPPATH:T3RESPONSE=10,N3REQUEST=3;
```

//设置N4/Sxb接口的GTP请求消息的重发时间间隔和最大尝试发送次数。

```
SET UPN4UPATH:N4T3RESPONSE=10,N4N3REQUEST=3;
```
