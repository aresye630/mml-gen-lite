# 修改IPFarm的心跳检测参数

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

修改心跳检测成功与失败转换的次数以及心跳检测的间隔。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-110281 用户Portal。
- 完成配置用户Portal。

数据

| 类别               | 参数名称                      | 取值样例     | 获取方法   | 说明   |
|:-----------------|:--------------------------|:---------|:-------|:-----|
| SET IPFARMGLOBAL | 服务器类型（SERVERTYPE）         | REDIRECT | 本端规划   | -    |
| SET IPFARMGLOBAL | 时间阈值（秒）（TIMETHRESHOLD）    | 6        | 本端规划   | -    |
| SET IPFARMGLOBAL | 健康检查成功次数（HEALTHSUCCLIMIT） | 3        | 本端规划   | -    |
| SET IPFARMGLOBAL | 健康检查失败次数（HEALTHFAILLIMIT） | 2        | 本端规划   | -    |

## 操作步骤

1. 配置整机的IPFarm心跳检测功能的相关参数。

   **SET IPFARMGLOBAL**

## 任务示例

任务描述

修改心跳检测成功次数为3，失败次数为2，时间的间隔为6s。

脚本

//配置整机的IPFarm心跳检测功能的相关参数。

```
SET IPFARMGLOBAL:SERVERTYPE=REDIRECT,TIMETHRESHOLD=6,HEALTHSUCCLIMIT=3,HEALTHFAILLIMIT=2;
```
