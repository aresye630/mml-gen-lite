# 配置Sa/N3/S1-U接口数据

- 操作场景
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

运营商在部署5G或4G/5G互操作的分组交换网或2/3/4/5G融合组网时新增ULCL UPF/BP UPF/I-UPF/SGW-U中的任一独立设备或融合设备，在完成配置UDG到无线(R)AN侧的路由数据后，可在UDG上配置Sa/N3/S1-U接口数据使UDG与无线(R)AN侧建立逻辑连接。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。
- 请了解UDG各类接口的类型及命名规范，具体内容请参见逻辑接口介绍。
- 请阅读并熟悉特性GWFD-010234 Single IP。
- 已完成组网路由配置。

数据

在UDG上配置Sa/N3/S1-U接口数据，为UDG与eNodeB/gNodeB之间的数据路径建立逻辑连接。

**说明** 

本文以IPv4组网为例说明。

- 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
- 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

中心云上下行入不转板场景：

- 不支持逻辑接口与切片绑定。
- 除了规划上述表格中的1/1/0接口（也可以是1/1/X接口，X取值范围1~31）外，还需要规划1/Y/0接口（Y取值范围2~64，每个ISU POD上需要1个逻辑接口IP）。
- 1/Y/0接口（Y取值范围2~64）和1/1/0接口绑定的VPN实例相同。

## 操作步骤

1. 进入“MML命令行-UDG”窗口。
2. 配置Sa/N3/S1-U逻辑接口所属的VPN实例。

   **说明** 

   逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
3. 配置Sa/N3/S1-U逻辑接口。

   - 配置抽象接口Sa。

     配置不和网络切片绑定的Saif接口。

     ```
     ADD LOGICINF:NAME="Saif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access",SLICEATTRSW=DISABLE;
     ```

     配置和网络切片绑定的Saif接口。

     ```
     ADD LOGICINF:NAME="Saif1/1/1",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access_001",SLICEATTRSW=ENABLE;
     ```

     **说明** 

     网络切片需要规划独立的N3逻辑接口时：

     - 该网络切片不与非网络切片用户共享该逻辑接口地址时，“SLICEATTRSW”需设置为“ENABLE”。

       和网络切片绑定前，若该Saif接口的“SLICEATTRSW”设置为“DISABLE”，则该接口会被当作不绑定网络切片的Saif接口使用，可能导致PDU Session建立失败。
     - 配置Saif接口后，还需要通过**ADD SNSSAIUPINTF**命令将网络切片和Saif接口绑定。
   - 配置N3if和S1-U接口。
     - 配置N3接口。

       配置不和网络切片绑定的N3if接口。

       ```
       ADD LOGICINF:NAME="N3if1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access",SLICEATTRSW=DISABLE;
       ```

       配置和指定网络切片绑定的N3if接口。

       ```
       ADD LOGICINF:NAME="N3if1/1/1",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access_001",SLICEATTRSW=ENABLE;
       ```

       **说明** 

       网络切片需要规划独立的N3逻辑接口时：

       - 该网络切片不与非网络切片用户共享该逻辑接口地址时，“SLICEATTRSW”需设置为“ENABLE”。

         和网络切片绑定前，若该N3if接口的“SLICEATTRSW”设置为“DISABLE”，则该接口会被当作不绑定网络切片的N3if接口使用，可能导致PDU Session建立失败。
       - 配置独立的N3if接口后，还需要通过**ADD SNSSAIUPINTF**命令将网络切片和N3if接口绑定。
     - 配置S1-U接口。

       ```
       ADD LOGICINF:NAME="s1-uif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.2.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access";
       ```

## 验证方法

1. 进入“MML命令行-UDG”窗口。
2. 执行**LST LOGICINF**命令，查询逻辑接口信息是否与规划数据一致。
   - 一致，请执行3。
   - 不一致，请参考“操作步骤”重新配置，与规划数据一致后执行3。
3. 执行**SRVPING**命令，调测UDG到eNodeB/gNodeB的数据通信路径。

   **说明** 

   - 如下“LOGICINFNAME”/“SRCIPV4ADDR”/“SRCIPV6ADDR”参数值仅为举例，实际调测时，请注意修改成**LST LOGICINF**查询到的Saif/N3if/S1-uif接口数据。
   - 如下“DSTIPV4ADDR”/“DSTIPV6ADDR”参数值仅为举例，实际调测时，请注意修改成对接的eNodeB/gNodeB地址。

   //IPv4地址：

   ```
   SRVPING: SRCIPTYPE=LOGICINF, LOGICINFNAME="Saif1/1/0", IPVERSION=IPv4, SRCIPV4ADDR="10.1.1.1", DSTIPV4ADDR="10.2.1.1";
   ```

   //IPv6地址：

   ```
   SRVPING: SRCIPTYPE=LOGICINF, LOGICINFNAME="Saif1/1/0", IPVERSION=IPv6, SRCIPV6ADDR="FC00::10:1:1:1", DSTIPV6ADDR="FC00::10:2:1:1";
   ```

   - 返回“0.00% packet loss”，表明通信正常，调测结束。
   - 返回“100.00% packet loss”或其他非零丢包率，表明通信异常，请执行4。
4. 执行**SRVTRACERT**命令，查询通信路径中的故障点。

   //IPv4地址：

   ```
   SRVTRACERT: SRCIPTYPE=LOGICINF, LOGICINFNAME="Saif1/1/0", IPVERSION=IPv4, SRCIPV4ADDR="10.1.1.1", DSTIPV4ADDR="10.2.1.1";
   ```

   //IPv6地址：

   ```
   SRVTRACERT: SRCIPTYPE=LOGICINF, LOGICINFNAME="Saif1/1/0", IPVERSION=IPv6, SRCIPV6ADDR="FC00::10:1:1:1", DSTIPV6ADDR="FC00::10:2:1:1";
   ```

   - 返回“1 \* \* Request timed out.”，请执行5。
   - 返回“n \* \* Request timed out.”，请联系最后1个地址所属的网元进行处理。
5. 执行**DSP ROUTE**/**DSP ROUTE6**命令，检查是否存在到对端IP的路由。
   - 存在，请执行7。
   - 不存在，请执行6。
6. 请检查外联口IP及路由配置是否正确。

   检查外联口IP及路由配置的详细步骤，请参见组网路由配置。

   - 是，请执行7。
   - 否，请修改配置后执行3。
7. 收集信息并寻求技术支持。

   1. 在OM Portal上创建“UDG用户跟踪”任务，执行3~6并保存报文和查询结果。
   2. 在“MML命令行-UDG”窗口上执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   3. 收集并保存上述所有查询信息。
   4. 查看并收集对端设备配置及接口状态信息。
   5. 收集归纳所有信息并联系华为技术支持解决。
