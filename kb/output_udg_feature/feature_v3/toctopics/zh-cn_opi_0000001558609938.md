## 操作场景

本操作指导介绍在5G网络下激活eDRX功能的操作过程。

适用于UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110661 5G eDRX模式。
* 完成加载License（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置5G eDRX模式所使用的APN。

   **ADD APN**
3. **可选：**配置APN下的5G eDRX参数。
   1. 配置APN的下行数据缓存时长。

      **SET APNDLBUFTIME**
   2. 配置APN的下行数据长时间缓存配置。

      **SET APNDLLTBUFFER**
4. **可选：**配置全局的5G eDRX参数。
   1. 配置全局下行数据缓存时长。

      **SET GLBDLBUFTIME**
   2. 配置全局下行数据长时间缓存配置。

      **SET GLBDLLTBUFFER**

      如果全局和APN下同时配置了缓存时长和长时间缓存配置参数，生效优先级：APN>全局。

## 任务示例

任务描述

在本实例中，在UDG上开启eDRX模式，并且配置基于APN的和全局的用户下行数据缓存时长和长时间缓存配置。

脚本

//打开本特性License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5EDRX01", SWITCH=ENABLE;
```

//配置5G eDRX模式所使用的APN。

```
ADD APN: APN="apn-test";
```

//配置基于APN的用户下行数据缓存时长。

```
SET APNDLBUFTIME: APN="apn-test", REDCAPNRUSER=10;
```

//配置基于APN的用户下行数据长时间缓存配置。

```
SET APNDLLTBUFFER: APN="apn-test", MAXBUFFERNUM=4, BUFFERMODE=BUFF_MODE_RING;
```

//配置全局用户的下行数据缓存时长。

```
SET GLBDLBUFTIME: REDCAPNRUSER=20;
```

//配置全局用户的下行数据长时间缓存配置。

```
SET GLBDLLTBUFFER: MAXBUFFERNUM=16, BUFFERMODE=BUFF_MODE_RING;
```
