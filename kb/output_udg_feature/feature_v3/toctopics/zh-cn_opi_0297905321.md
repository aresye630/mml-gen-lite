# 公共参数配置

* 操作场景

## 操作场景

本页面涉及的公共参数均有默认值，请根据网设LLD规划的值进行调整。

网设LLD中未描述的参数，一般情况下是使用系统初始值。如有疑问，请联系华为技术支持工程师。对于使用系统初始值的参数，为了避免被误修改，建议参考本页面重新配置。

## 必备事项

前提条件

具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

数据

无。

文档

获取网设LLD文档。

## 操作步骤

1. 配置N4接口PFCP协议信令报文的DSCP值。

   设置的DSCP值，用于UDG填充报文中的ToS字段。

   系统初始值为“46”。

   ```
   SET SIGDSCP:PROTOCOL=PFCP,DSCPV=46;
   ```
2. 配置UDG发送的UDP报文中是否携带CheckSum。

   IPv6报文时须设置为“ENABLE”。此处以携带CheckSum为例。

   系统初始值为“DISABLE”。

   ```
   SET UDPCHECKSUM:UDPTYPE=PFCP,SWITCH=ENABLE;
   ```
3. 设置每用户的最大五元组个数。

   此处以每用户的最大五元组个数为1000且其他参数使用系统初始值为例。

   系统初始值为“600”。

   ```
   SET SRVCOMMONPARA: FDMAXNUM=1000;
   ```
4. 设置QoS CAR。

   RAT类型后的-1代表使能这个RAT类型用户的QoS CAR功能，-0代表不使能。

   系统初始值为“NULL”，表示不使能所有RAT类型。

   //配置本地用户的上下行CAR功能。

   ```
   SET QOSCAR: USERTYPE=HOME, ULRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&lte_m-1&nr-1&unknown-1&utran-1&wlan-1, DLRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&nr-1&unknown-1&utran-1&wlan-1;
   ```

   //配置漫游用户的上下行CAR功能。

   ```
   SET QOSCAR: USERTYPE=ROAMING, ULRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&lte_m-1&nr-1&unknown-1&utran-1&wlan-1, DLRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&nr-1&unknown-1&utran-1&wlan-1;
   ```

   //配置拜访用户的上下行CAR功能。

   ```
   SET QOSCAR: USERTYPE=VISITING, ULRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&lte_m-1&nr-1&unknown-1&utran-1&wlan-1, DLRAT=eutran-1&eutran_nb_iot-1&gan-1&geran-1&hspae-1&nr-1&unknown-1&utran-1&wlan-1;
   ```
5. 设置IPv6报文分片策略。

   “INNERIPV4FRAGPLCY”参数系统初始值为“OUTERFRAG”；“INNERIPV6FRAGPLCY”参数系统初始值为“TOOBIG\_PKTDROP”。

   “INNERIPV6FRAGPLCY”参数值为“TOOBIG\_PKTDROP”时，若UPF处理并封装报文后，报文长度大于MTU值，则丢弃该报文，并回复Too big报文。UPF封装后的报文长度大于MTU值的场景，需要执行如下脚本，由UPF对报文做外层IPv6分片，避免业务异常。

   ```
   SET IPV6FRAGPLCY: INNERIPV4FRAGPLCY=OUTERFRAG, INNERIPV6FRAGPLCY=OUTERFRAG;
   ```
6. 配置用户面支持分配F-TEID。

   不同CP分配给同一个UP的TEID-U可能重复，因此需要将“SWITCH”设置为“DISABLE”，由用户面分配TEID-U。

   系统初始值为“DISABLE”。

   ```
   SET CPTEIDUALLOC: SWITCH=DISABLE;
   ```
7. 配置时区。

   此处以东八区，不执行夏令时为例。

   ```
   SET TZ: TZONE=E0800, DST=NO;
   ```
8. 设置防欺诈配置。

   此处以运营商不希望开启FUI防欺诈功能，希望开启HTTP防欺诈功能，其他参数为系统初始值为例。

   ```
   SET ANTIFRAUD:ISNULLRECEN=DISABLE, ISTEXTEN=DISABLE, ISHEURISTICEN=DISABLE, FUIAFSWITCH=DISABLE, HTTPAFSWITCH=ENABLE, URLREDAFSWITCH=DISABLE;
   ```
9. 设置转发参数。

   该命令属于高危命令，操作不当会导致业务故障，请谨慎使用并联系华为技术支持协助操作。

   报文重组超时时长设置过小，分片可能不完整；设置过大，会降低设备的性能。

   系统初始值为“3”。

   ```
   SET FWDPARA:RSTIME=6, IPV6RSTIME=6, FWDSWITCH=ON;
   ```
10. 设置头增强全局参数。

    此处以“HEADENSALTTYPE”参数设置为“TIMESTAMP”，其他参数为系统初始值为例。

    “HEADENSALTTYPE”参数系统初始值为“RANDNUM”。

    ```
    SET HEADENGLBPARA:RC4KEYMD5EN=DISABLE, MSISDNMINLEN=0, RSANODEAGETIME=10, RSAEXPIREDALM=ENABLE, RSACERTEXPALMDAYS=30, HEADENSALTTYPE=TIMESTAMP;
    ```
11. 设置告警开关。

    “SUPPRESSENABLE”参数系统初始值为“TRUE”；“SUPPRESSTIME”参数系统初始值为“300”。

    ```
    SET MSFAULTALARM: SUPPRESSENABLE=TRUE, SUPPRESSTIME=300;
    ```
