# 配置到CHF(OCS)的Local NRF

## 操作场景

该任务用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关的信息。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

* UNC软件安装已完成。

## 操作步骤

1. 配置主备CHF(OCS)的NF Profile。

   ```
   ADD PNFPROFILE: NFINSTANCEID="CHF_Instance_0", NFTYPE= NfCUSTOM_OCS, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS1="fd11:f111:2222:3333:4444:5555:2111:151", PORT=8080, CAPACITY=100, PRIORITY=10;
   ADD PNFPROFILE: NFINSTANCEID="CHF_Instance_1", NFTYPE= NfCUSTOM_OCS, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS1="fd11:f111:2222:3333:4444:5555:2111:152", PORT=8080, CAPACITY=100, PRIORITY=20;
   ```

   NFINSTANCEID参数需要填写对端NF的UUID，如果无法获得，也可以使用长度小于18的字符串，该字符串不能是IPv4或IPv6地址格式的字符串。
2. 配置主备CHF(OCS)的服务。

   ```
   ADD PNFSERVICE: NFINSTANCEID="CHF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NocsConvCharg, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=10, CAPACITY=100;
   ADD PNFSERVICE: NFINSTANCEID="CHF_Instance_1", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NocsConvCharg, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=20, CAPACITY=100;
   ```
3. 配置对端CHF(OCS)的支持的GPSI号段范围。

   ```
   ADD PNFGPSI: INDEX=1, NFINSTANCEID="CHF_Instance_0", QUERYTYPE=START_END, RANGESTART="123001200100001",    RANGEEND="123001200109999";
   ADD PNFGPSI: INDEX=2, NFINSTANCEID="CHF_Instance_1", QUERYTYPE=START_END, RANGESTART="123001200100001",    RANGEEND="123001200109999";
   ```
