# 配置UDM-UIM支持一跳入家功能

* 操作场景
* 必备事项
* 任务示例

## 操作场景

本页面用于指导操作员配置UDM-UIM支持一跳入家功能。

## 必备事项

前提条件

操作人员具有登录OM Portal的操作权限。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **MOD INSP** | 软件参数类型（INSPT） | AAA | 固定配置 | - |
|  | 软件参数名称（INSPN） | SUPP\_TOHOME | 固定配置 | - |
|  | 软件参数值（INSPV） | 1 | 本端规划 | 用于标识需要修改的软件参数的参数值。  * 0：不支持一跳入家业务 * 1：支持一跳入家业务 |

## 任务示例

任务描述

本范例配置UDM-UIM支持一跳入家功能。

脚本

1. 登录“UDM MML命令”界面。
2. 执行**MOD INSP**命令设置UDM-UIM支持一跳入家功能。

   ```
   MOD INSP: INSPT=AAA, INSPN=SUPP_TOHOME, INSPV=1;
   ```
