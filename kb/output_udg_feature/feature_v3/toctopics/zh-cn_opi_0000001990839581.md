## 操作场景

本指导描述UNC对于OCS故障或者OCS的响应消息携带的特定结果码配置相就的处理动作的配置过程。

在线计费会话过程中，对于各种正常和异常场景，可以在UNC本地设置一些处理动作对DCC流程进行干预。这里的正常和异常场景，主要是指OCS响应UNC请求消息的状况，及响应消息的返回码值。

## 必备事项

前提条件

* 请仔细阅读Ga/Gy接口离线/在线计费。

* 已完成计费属性、APN、User Profile创建。
* 已根据配置在线计费模板完成在线计费模板创建和绑定，根据配置在线计费的费率标识完成在线计费费率标识配置。

## 操作步骤

* 配置用户激活后OCS故障的处理动作。
  1. 配置Tx定时器超时以后的处理方式。

     **ADD DCCTEMPLATE**

     **MOD DCCTEMPLATE**

     参数“CCFH”用于non-IEC计费 模式下在线计费Tx定时器超时后的动作处理。

     Tx定时器超时后有三种动作处理方式：

     + “TERMINATE”：表示去激活用户。
     + “RETRY\_AND\_TERM”：表示UNC会向备OCS重发一次请求消息，如果能收到响应，则与备OCS交互；如果Tx定时器超时仍然未得到响应，则去激活用户。选择该种方式时，需要一方面部署主备OCS，一方面主OCS组支持failover，即在CCA消息中CC-Session-Failover AVP支持failover，另一方面还需要在UNC本地配置支持failover功能，即配置了步骤 2，该动作才能生效。
     + “CONTINUE”：表示UNC会向备OCS重发一次请求消息，如果能收到响应，则与备OCS交互；如果Tx定时器超时仍然未得到响应，则转离线计费，继续进行业务。选择该种方式时，同上需要一方面部署主备OCS组，一方面主OCS组支持failover，即在CCA消息中CC-Session-Failover AVP支持failover，另一方面还需要在UNC本地配置支持failover功能，即配置步骤 2，步骤 7，该动作才能生效。
  2. 配置在线计费是否支持failover，配置“FAILOVERSUP”参数为“ENABLE”。当Tx定时器超时后的处理方式为“RETRY\_AND\_TERM”或者“CONTINUE”时，需要配置该步骤。

     **ADD DCCTEMPLATE**

     **MOD DCCTEMPLATE**
  3. **可选：**配置在线计费是否支持自动failback。

     **ADD DCCTEMPLATE**

     **MOD DCCTEMPLATE**

     “FAILOVERSUP”和“AUTOFAILBACK”是协议定义的两种OCS故障容错方式，“FAILOVERSUP”是指在主OCS故障的情况下，UNC会发送DCC消息给备OCS服务器组进行处理。“AUTOFAILBACK”是指当主OCS链路故障恢复后，DCC业务切换回到主OCS服务器上。
  4. 配置在线计费和离线计费同时使能的用户进行在线计费时，发生CCFH之后是否在离线话单中添加ccfh标志位。

     **ADD DCCTEMPLATE**

     **MOD DCCTEMPLATE**

     本命令只针对在线计费用户生效，且根据用户归属属性配置的离线计费开关**SET CHARGECTRL**必须使能。
  5. 配置Tx定时器的时长。

     **SET TXTIMER**
  6. 配置在线计费CCFH处理时是否强制产生话单，强制产生话单时话单中charging characteristics字段的取值；配置R6版本的eG-CDR是否支持CCFH处理。

     **SET OFCCDRPARA**
  7. 配置业务持续时长。

     **SET HOLDINGTIME**

     + 使用命令**SET DEACTIVERATE**可以去激活在线计费转为离线计费且Holding Time定时器值为0的用户。
     + 当Tx定时器超时后的处理方式为“CONTINUE”时，允许用户保持业务的时长，超出该时长则去激活用户。当配置为0分钟表示允许用户永久保持在线进行业务。
* 配置用户激活时OCS故障的处理动作。
  1. **可选：**配置转离线后业务持续时长。

     **SET HOLDINGTIME**

     当**SET OCSDOWNACTION**命令**OCSDNACTION**参数值为“PERMIT”并且“HOLDINGTMFLAG”参数值为“ENABLE”时，需要首先配置**HOLDINGTIME**。
  2. 配置OCS故障时是否允许用户激活。

     **SET OCSDOWNACTION**
* 配置command层消息码为异常返回码时的处理动作。
  1. 配置command层消息码为异常返回码时的处理动作。

     **ADD CMDRCACT**

     + 返回码DIAMETER\_SUCCESS (2001)，DIAMETER\_LIMITED\_SUCCESS (2002)的动作不可配置，属于正常返回码，业务动作取决于MSCC层的返回码动作控制。
     + 当在线计费用户本地配置用户转离线时，UNC支持开启Holding Time定时器，Holding Time定时器超时之后再进行用户去活。
     + 如果某返回码没有单独配置对应的动作，则采用步骤 2的**SET CMDLEVDFTBEH**配置的动作进行处理。
     + 部分协议规定了标准处理的特殊返回码缺省值为固定处理，如果这部分返回码对应的动作没有配置，缺省值为特殊的处理流程，不会采用**SET CMDLEVDFTBEH**配置的动作；如果配置了返回码对应的动作，则按照配置的动作处理。这部分返回码及缺省动作处理请参见命令帮助的说明。
  2. 配置command层消息码为异常返回码时的默认处理动作。

     **SET CMDLEVDFTBEH**
* 配置MSCC层消息码为异常返回码时的处理动作。
  1. 配置MSCC层消息码为异常返回码时的处理动作。

     **ADD MSCCRCACT**

     + 返回码DIAMETER\_SUCCESS (2001)，DIAMETER\_LIMITED\_SUCCESS (2002)的动作不可配置，属于正常返回码，正常转发报文并计费。
     + 如果某返回码没有单独配置对应的动作，则采用步骤 2的**SET MSCCLEVDFTBEH**配置的动作进行处理。
     + 部分协议规定了标准处理的特殊返回码缺省值为固定处理，如果这部分返回码对应的动作没有配置，缺省值为特殊的处理流程，不会采用**SET MSCCLEVDFTBEH**配置的动作；如果配置了返回码对应的动作，则按照配置的动作处理。这部分返回码及缺省动作处理请参见命令帮助的说明。
  2. 配置MSCC层消息码为异常返回码时的默认处理动作。

     **SET MSCCLEVDFTBEH**

  UNC支持针对OCS返回的特殊返回码设置动作，包括重定向动作。当UNC收到这些特殊返回码时，会根据配置的动作进行重定向处理。重定向处理动作可以由OCS下发，也可以在UNC本地配置。其优先级关系是：

  + OCS下发的动作优先级最高。
  + 其次是在UNC本地为Command层特殊返回码配置的动作**ADD CMDRCACT**。
  + 再者是在UNC本地为MSCC层特殊返回码配置的动作**ADD MSCCRCACT**。
  + 然后是UNC本地默认的Command层特殊返回码处理动作**SET CMDLEVDFTBEH**。
  + 优先级最低的是UNC本地默认的MSCC层特殊返回码处理动作**SET MSCCLEVDFTBEH**。
* 配置UNC收到OCS的CCA消息中携带FUI Terminate时的处理动作，配置“FUATERMINATE”参数。

  **ADD DCCTEMPLATE**

  **MOD DCCTEMPLATE**

## 任务示例

任务描述

普通在线计费会话过程中的处理动作。

脚本

//修改DCC template模板dcc-test的CCFH相关参数。

```
MOD DCCTEMPLATE:DCCTMPLTNAME="dcc-test", CCFH=CONTINUE, CCFHOFFLINE=ENABLE, FAILOVERSUP=ENABLE;
SET OFCCDRPARA:PSFCIFORMAT=HEX, CCFHCDRSW=DISABLE, CCFHCDRCC="0xFFFF", R6EGCDRCCFHSW=DISABLE;
```

//配置Txtimer和Holding timer。

```
SET TXTIMER:DCCTMPLTNAME="dcc-test",TXTIMERFLAG=TXTIMER_VALUE,TXTIMER=3;
```

```
SET HOLDINGTIME:DCCTMPLTNAME="dcc-test",HOLDINGTIME=30,RANGETIME=10;
```

//配置用户激活时OCS故障的处理动作。

```
SET OCSDOWNACTION:DCCTMPLTNAME="dcc-test",OCSDNACTION=PERMIT,HOLDINGTMFLAG=ENABLE;
```

//配置消息码为异常返回码时的处理动作。

```
ADD CMDRCACT:DCCTMPLTNAME="dcc-test",CMDRC="4012",CMDRCACT=TERM_WITH_CCRT;
```

```
SET CMDLEVDFTBEH:DCCTMPLTNAME="dcc-test",CMDLEVDFTBEH=TERM_WITH_CCRT;
```

```
ADD MSCCRCACT:DCCTMPLTNAME="dcc-test",MSCCRC="4012",MSCCRCACT=BLOCK;
```

```
SET MSCCLEVDFTBEH:DCCTMPLTNAME="dcc-test",MSCCLEVDFTBEH=BLOCK;
```

//配置UNC与对端OCS重建TCP链接的间隔时长。

```
SET TCTIMER:TCTIMERLEN=1,TCMODE=MULTIPLY;
```

//配置DWR消息响应超时次数达到上限后UNC的处理动作。

```
SET TWTIMER:TWTIMERLEN=30,TWNORESPTIMES=3,TWRSTTCP=DISABLE;
```
