## 操作场景

仅当UDG网元需要部署“GWFD-111286 VVIP用户质差监测和保障”特性时，才需要安装SBIM服务。

仅部分VNFD模板支持SBIM服务。如需安装SBIM服务，请先联系华为技术支持确认使用的VNFD模板是否支持。

安装SBIM服务场景：

* **场景一****（静态上线）**：UDG网元和SBIM服务**同时实例化**。实例化UDG前填写如下VNFD参数。
  + 配置VM：基于X86虚拟机（PBU\_P-S\_Num和PBU\_P-S Redundancy Num）。基于ARM虚拟机(PBU\_P-S\_ARM\_Num和PBU\_P-S\_ARM Redundancy Num)。
  + 配置Pod：“SBIM\_Instance\_Num”，“HTTPCTRL\_Instance\_Num”。
* **场景二****（动态上线）**：**先**实例化UDG，**然后**再参考本章节，动态上线SBIM服务。

## 必备事项

前提条件

* 已经实例化UDG。已经安装后检查，UDG正常工作。
* SBIM服务依赖的软件包为UDG\_xx.x.x\_DockerSF\_X86.zip或UDG\_xx.x.x\_DockerSF\_ARM.zip。在安装UDG时已经上传本软件包，因此无需再次上传软件包。

* 当系统进行动态上下线操作期间，不允许再同时进行扩缩容操作。同理，当系统进行扩缩容期间，不允许再进行动态上下线操作。
* 上下线本服务时，不能同时上下线其他部件。
* 当动态上线一个服务的任务失败；必须先动态下线此服务，再重新触发动态上线任务。如果是动态下线失败，继续重新触发动态下线任务。

## 操作步骤

1. 动态上线本服务前，必须根据客户的业务容量和设备现状进行严格的**扩容评估**。

   确保上线服务所需的I层资源、License资源、各类网络资源（如外联口网络）是充足的，如果不充足，则要**先扩容这些资源**，然后**再上线本服务**。

   由华为网设工程师进行网络设计，规划计算资源、存储资源、网络资源。

   将规划数据合入《NFV LLD文档》，作为后续操作的输入。

   * **计算资源**：承载虚拟机的主机（服务器）、主机组、虚拟机名称、虚拟机个数、容器名称、容器个数。
   * **存储资源**：承载本服务的磁盘空间。
   * **网络资源**：承载虚拟机的网络。承载容器的网络。承载业务的物理网口、业务网络。例如虚拟机的Base网络、容器Base网络、外联口网络、外联口Subport。
2. 检查**软件包**，确保已经上传依赖的软件包。

   登录MAE-VNF LCM/U2020 VNF LCM，单击“包管理 > VNFD > 单击VNFD模板，查看VNFD模板详情 > 依赖的服务镜像”。

   * 若“UDG\_xx.x.x\_DockerSF\_X86.zip”“UDG\_xx.x.x\_DockerSF\_ARM.zip”的状态为“已经存在”，说明已经上传软件包，则跳过3，执行后续步骤。
   * 若软件包的状态为“等待上传”，则需要执行3。
3. **上传服务镜像文件**。

   如果执行LST ME命令查询的架构模式为X86，且LCM上提示ARM的包为必选时，可以忽略“是否必需上传”的提示，无需上传ARM后缀的依赖的服务镜像。

   1. 在“依赖的服务镜像”区域，单击“上传”，弹出“上传服务镜像”窗口。
   2. 在“单包”页面，单击“选择文件”，选择依赖的服务镜像包和对应的cms文件。
   3. 单击“完成”。
   4. 上传完成后，“状态”均显示为“已经存在”。上传时长依赖于现场网络情况。

   上传镜像后需要同步镜像包到边缘站点。

   1. 在“VNFD”窗口中，**选择已导入的VNFD**。
   2. 单击图标。
   3. 在“边缘站点列表”区域中选择目标站点。
   4. 单击“确定”。

      **图1** 同步文件到边缘站点
4. 参考《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》，完成扩容操作，扩容出计算资源、存储资源、网络资源、VM和POD。上线可选服务时可只扩容VM，无需扩容POD。可选服务所用VM可参见扩容指导书内非基础业务扩容规格确定章节**。**

   由华为工程师登录华为Support网站，在技术支持>知识库>云核心网>Mobile Packet Core>5G Packet Core>UDG>技术指导，中搜索《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》。

   非SDN组网模式下使用《UDG中心侧扩缩容指导书(基于LCM)》，SDN组网模式请使用《UDG中心侧扩缩容指导书(基于NFVO)》。
5. 登录UDG OM Portal。
6. 执行命令，查询pod是否存在。

   ```
   DSP POD: TYPE=byType, PODTYPE="sbim-pod";
   DSP POD: TYPE=byType, PODTYPE="httpctrl-pod";
   ```

   * 如果所查到的原Pod数**为0**；说明系统中并没有实例化该服务，请执行后续步骤，进行实例化该服务。
   * 如果所查到的原Pod数为**非0**；则说明该Pod已实例化完毕。
     1. 当查询pod个数为**非0**，且**不等于规划值**，请参考《UDG基于LCM的扩缩容指导》，**在VNF LCM上扩容**pod个数为规划值。
     2. 当查询pod个数为**非0**，且**与规划值相等**，表示当前服务已完成实例化，无需执行后续步骤。
7. 执行命令，动态上线SBIM Pod。

   ```
   OPR FEATUREENABLE: PODINSTANCENUM="httpctrl-pod:pod个数/sbim-pod:pod个数", FUNCTIONSETNAME="SBIM";
   ```

   （1）无需配置“EXTENDEDATTR(扩展属性)”参数。

   （2）参数“FUNCTIONSETNAME”填写为“SBIM”。

   （3）参数“PODINSTANCENUM”填写为网设规划值，例如：pod1:num1/pod2:num2/pod3:num3
8. 执行命令，确认已经成功实例化SBIM Pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="httpctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="sbim-pod";
   ```

   回显pod个数和规划一致，且“Pod状态”为“Running”。
9. 执行命令，查询进程的状态。

   ```
   DSP CELLSTAT: OBJECT=PODTYPE, PODTYPE="httpctrl-pod";
   DSP CELLSTAT: OBJECT=PODTYPE, PODTYPE="sbim-pod";
   ```

   预期结果：“未就绪进程数”和“故障进程数”均为0。

## 任务示例

任务描述

已经参考《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》扩容好计算资源、存储资源、网络资源。例如已在VNF LCM或NFVO上扩容出SBIM服务自身VM（X86为：PBU\_P-S；ARM为：PBU\_P-S\_ARM）。

在上述场景中动态上线SBIM服务。

脚本

1. 执行命令，pod是否存在。

   ```
   DSP POD: TYPE=byType, PODTYPE="sbim-pod";
   DSP POD: TYPE=byType, PODTYPE="httpctrl-pod";
   ```
2. 执行命令，动态上线SBIM Pod。

   ```
   OPR FEATUREENABLE: PODINSTANCENUM="httpctrl-pod:2/sbim-pod:2", FUNCTIONSETNAME="SBIM";
   ```
3. 执行命令，确认已经成功实例化SBIM Pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="0", TYPE=byType, PODTYPE="httpctrl-pod";
   DSP POD: MEID="0", TYPE=byType, PODTYPE="sbim-pod";
   ```

   回显pod个数和规划一致，且“Pod状态”为“Running”。
4. 执行命令，查询进程的状态。

   ```
   DSP CELLSTAT: OBJECT=PODTYPE, PODTYPE="httpctrl-pod";
   DSP CELLSTAT: OBJECT=PODTYPE, PODTYPE="sbim-pod";
   ```

   预期结果：“未就绪进程数”和“故障进程数”均为0。
