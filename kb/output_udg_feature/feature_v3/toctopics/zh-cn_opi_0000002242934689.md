# 配置点播业务的媒体中继域名（点播域名）

* 操作场景
* 必备事项

## 操作场景

使用媒体中继业务时，需要配置媒体中继模板使用的媒体中继域名。本章节用于指导如何配置媒体中继模板使用的点播域名。

## 必备事项

前提条件

已参考增加媒体服务商基础配置完成媒体中继模板配置。

数据

**表1** 媒体中继域名数据规划

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD RELAYDOMAIN** | 媒体中继模板名称（RELAYTPLNAME） | sp\_relay\_tpl | 已配置数据中获取 | 已通过**ADD RELAYTEMPLATE**完成配置。 |

|  | UE业务请求协议（UESERVICEPROTO） | HTTPS | 全网规划 | 该参数用于设置UE请求支持的协议。 |
|  | 业务回源协议（ORIGINPULLPROTO） | HTTPS | 全网规划 | 该参数用于设置业务从CDN回源时使用的协议。 |

## 任务示例

任务描述

配置媒体中继的点播域名为**relay.spvod.com**，配置点播识别规则，并为点播域名绑定URL鉴权规则。

URL鉴权密钥信息属于敏感数据，不支持查询或配置导出，请管理员妥善保管。

脚本

//增加点播域名配置

```
ADD RELAYDOMAIN: RELAYTPLNAME="sp_relay_tpl", RELAYDOMAINNAME="sp_relay_dm_vod_001", DOMAINVALUE="relay.spvod.com", UESERVICEPROTO=HTTPS, ORIGINPULLPROTO=HTTPS, SERVICETYPE=VOD, VODPROTOTYPE=DASH-1&MP4-1, DEFAULTVODSW=ENABLE, UNSPTMEDIAACT=REDIRECT, PRIORITY=11000;
```

//配置点播MP4协议识别规则

```
ADD RELAYPROTODEF: RELAYPROTODEFNM="relay_p_d_sp_vod_000", RELAYPROTORULE="douyin_mp4_video", PRIORITY=1000, RELAYPROTOTYPE=MP4, DETECTTYPE=BYQRYPARA, QUERYPARAVALUE="mime_type=video_mp4";
ADD RELAYPROTODEF: RELAYPROTODEFNM="relay_p_d_sp_vod_000", RELAYPROTORULE="douyin_mp4_audio", PRIORITY=1001, RELAYPROTOTYPE=MP4, DETECTTYPE=BYQRYPARA, QUERYPARAVALUE="mime_type=audio_mp4";
MOD RELAYDOMAIN: RELAYDOMAINNAME="sp_relay_dm_vod_001", RELAYPROTODEFNM="relay_p_d_sp_vod_000";
```

//配置点播URL鉴权规则。以鉴权算法为“TYPEC1"、加密算法为“SHA256为例。

```
ADD RELAYAUTHKEY: RELAYAUTHKEYNAME="relay_ak_sp_vod_001", MASTERAUTHKEY="***", MASTERKEYCONFIRM="***"，SLAVEAUTHKEY="***", SLAVEKEYCONFIRM="***";
ADD RELAYURLAUTH: RELAYURLAUTHNM="relay_ur_sp_vod_001", RELAYAUTHKEYNM="relay_ak_sp_vod_001", URLAUTHMETHOD=TYPEC1, ALGORITHM=SHA256, TIMESTAMPFMT=DEFAULT, AUTHFAILACT=FORBIDDEN, DASHAUTHEXTSW=ENABLE;
MOD RELAYDOMAIN: RELAYDOMAINNAME="sp_relay_dm_vod_001", URLAUTHNAME="relay_ur_sp_vod_001";
```

//配置HTTP头域字段，并绑定到域名下。

```
ADD RELAYHTTPMCTL: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Cache-Control", HEADERVALUE="max-ge=2592000";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Credentials", HEADERVALUE="true";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Headers", HEADERVALUE="range";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Methods", HEADERVALUE="GET";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Allow-Origin", HEADERVALUE="*";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Expose-Headers", HEADERVALUE="Content-Length,Content-Range,content-type,expires,last-modified,via,X-Cache,X-Request-ID";
ADD RELAYHTTPMHD: HTTPMSGCTRLNAME="sp_relay_hhd_vod_001", MSGTYPE=UEHTTPRSP, HEADERNAME="Access-Control-Max-Age", HEADERVALUE="3600";
MOD RELAYDOMAIN: RELAYDOMAINNAME="sp_relay_dm_vod_001", HTTPMSGCTRLNAME="sp_relay_hhd_vod_001";
```
