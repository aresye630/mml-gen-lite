# 配置专网UPF

* 操作场景
* 必备事项
* 任务示例

## 操作场景

该任务旨在指导操作人员完成一跳入家相关业务配置。

一跳入家业务专网UPF上无需额外配置，只需打开对应License。

## 必备事项

前提条件

* 已完成**智网接入**的License加载。
* 已经完成专网UPF的基础配置。
* 已完成一跳入家要求的移动VPN相关配置。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****SET LICENSESWITCH**** | License项（LICITEM） | LKV3G5SNAC01 | 本端规划 | 打开智网接入的License。 |
|  | 开关（SWITCH） | ENABLE | 固定配置 | - |
| **SET SOFTPARA** | 软参记录数据类型（DT） | BYTE | 固定配置 | 手机后路由场景，按需配置地址冲突检测机制。 |
|  | Byte索引（BYTENUM） | 44 | 固定配置 |  |
|  | Byte值（BYTEVALUE） | 4 | 本端规划 |  |

## 任务示例

任务描述

打开专网UPF上的智网接入License开关。

手机后路由场景，按需配置地址冲突检测机制。

脚本

//打开专网UPF上的智网接入License开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5SNAC01",SWITCH=ENABLE;
```

//手机后路由场景，按需配置地址冲突检测机制。

```
SET SOFTPARA:DT=BYTE, BYTENUM=44, BYTEVALUE=4;
```
