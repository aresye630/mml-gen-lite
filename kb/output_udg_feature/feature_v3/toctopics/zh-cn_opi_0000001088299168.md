## 操作场景

UDG通过对用户三四层数据报文进行分析和检测，识别出TCP重传报文，并根据配置对重传报文流量实施灵活的计费策略。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

请仔细阅读GWFD-020307 TCP重传识别。

数据

详细配置请参考部署UPF，此处仅描述差异配置。

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****SET URRGRPBINDING**** | 用户模板名称（USERPROFILENAME） | up\_test | 已配置数据中获取 | 为用户模板添加TCP重传使用量上报规则，并打开TCP重传计费。 |
|  | TCP重传计费标识（TCPCHGPROFLAG） | CHARGING | 本端规划 |  |
|  | TCP重传URR组名称（TCPURRGRPNAME） | cp\_tcp | 已配置数据中获取 |  |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 请参考部署UPF配置，配置的差异在于UserProfile绑定TCP重传使用量上报规则组，为用户模板添加TCP重传使用量上报规则，并打开TCP重传计费。

   **SET URRGRPBINDING**

## 任务示例

任务描述

UDG将TCP重传业务报文记入URR ID为1100的URR中，进行离线计费。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5TCPR01",SWITCH=ENABLE;
```

//参考部署UPF配置，配置的差异在于UserProfile绑定TCP重传使用量上报规则组。

```
SET URRGRPBINDING:USERPROFILENAME="userprofile001", TCPCHGPROFLAG=CHARGING, TCPURRGRPNAME="cp_tcp";
```
