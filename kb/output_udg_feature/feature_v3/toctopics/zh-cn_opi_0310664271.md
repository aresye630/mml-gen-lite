## 操作场景

当运营商需要提高对用户数据的溯源效率，可以开启NAT端口预分配和增量分配功能。

系统初始已有端口预分配配置默认值，操作人员可参考本章节修改配置取值。

## 必备事项

前提条件

* 已通过**ADD APN**完成APN的相关配置。
* 已登录OM Portal。
* 已完成配置NAT基本功能License开关。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ip pool** | pool-name | pbaname | 本端规划 | 设置NAT转换地址池的名称。 |
|  | **mode** | pba | 全网规划 | 配置NAT转换地址池的模式，有三种：No-PAT、NAPT和PBA。 |
| **vpn-instance** | vpn-instance-name | testvpn1 | 全网规划 | 配置VPN实例名称，该VPN是数据转发相关的VPN。 |
| **nat-ratio** | ratio-value | 2 | 本端规划 | 设置NAT ratio值，该值表示一个公网IP可以映射的私网IP数。 |
| **port** | port-start | 1024 | 全网规划 | 设置地址池的起始端口。 |
|  | port-end | 65535 | 全网规划 | 设置地址池的终止端口。 |
| **pba block-size** | **pba block-size** | 16 | 本端规划 | 设置pba地址池的block size。 |
|  | block-num | 2 | 本端规划 | 设置pba地址池的最大block值。 |
| **section** | section-num | 0 | 全网规划 | 设置地址段的编号。 |
|  | start-ip-address | 10.10.11.10 | 全网规划 | 配置NAT地址池的起始IPv4地址。 |
|  | end-ip-address | 10.10.11.254 | 全网规划 | 配置NAT地址池的结束IPv4地址。 |

## 操作步骤

1. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
2. 配合NAT转换地址池。

   1. 进入系统视图。

      **sy****stem-view**
   2. 配置pba模式地址池。

      **ip pool**
   3. 配置NAT地址池所属的VPN实例。

      **vpn-instance**
   4. 配置端口预分配功能。
      1. 配置单个公网对应的私网地址最大数。

         **nat-ratio**
      2. 配置端口大段和端口小段的大小和小段个数。

         **port**
      3. 配置端口预分配和增量分配。

         **pba block-size *X* max-block-num *X***
   5. 配置NAT地址池的地址段。

      **section**
   6. 返回系统视图。

      **quit**

## 任务示例

任务描述

NAT44场景下，配置端口预分配功能。

脚本

```
<NAT>system-view
[NAT]ip pool pbaname mode pba
[NAT-ip-pool-pbaname]vpn-instance testvpn1
[NAT-ip-pool-pbaname]nat-ratio 2
[NAT-ip-pool-pbaname]port 1024 65535
[NAT-ip-pool-pbaname]pba block-size 16 max-block-num 2
[NAT-ip-pool-pbaname]section 0 10.10.11.10 10.10.11.254
[NAT-ip-pool-pbaname]q
```
