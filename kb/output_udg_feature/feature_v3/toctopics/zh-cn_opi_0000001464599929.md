# 配置APN上下行防欺诈

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

为避免用户通过UDG非法访问数据业务，UDG会对指定APN接入的上下行报文进行检查，如果报文中携带的用户IP不是在UDG上合法的IP地址，则判断用户存在欺诈行为，丢弃用户报文。

* 适用于PGW-U、UPF。
* 本功能不适用于GWFD-110910 支持Routing Behind MS特性。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET APNADDRESSATTR** | APN名称（APN） | apn1.com | 全网规划 | - |
|  | 上行防欺诈（ANTISPOOFINGUL） | ENABLE | 固定取值 | - |
|  | 下行防欺诈（ANTISPOOFINGDL） | ENABLE | 固定取值 | - |

## 操作步骤

1. 配置APN上下行防欺诈。

   **SET APNADDRESSATTR**

## 任务示例

任务描述

开启APN上下行报文防欺诈功能，避免非法用户的数据业务。

脚本

配置APN上下行报文防欺诈功能。

```
SET APNADDRESSATTR:APN="apn1.com", ANTISPOOFINGUL=ENABLE, ANTISPOOFINGDL=ENABLE;
```
