# 卸载SAPO服务

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要SAPO服务或SAPO服务动态上线失败时，可以单独卸载SAPO的pod，从而下线SAPO服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线SAPO的pod类型和数量。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| UDG OM Portal帐户 | IP地址 | 192.168.1.1  操作维护接口IP，即“VNFD模板”中的“MNG\_IP”或“MNG\_IPv6”参数。 | 本端规划 |
|  | 端口号 | 31943 | 本端规划 |
|  | 用户名 | admin | 本端规划 |
|  | 密码 | Changeme\_123 | 本端规划 |
| 特性下线  OPR FEATUREDISABLE | Pod类型列表（PODTYPE） | aipo-pod/aipoctrl-pod  pod类型，用/分割。不要带空格。 | 本端规划 |
|  | 下线方式（DISABLETYPE） | Normal | 本端规划 |
|  | FUNCTIONSETNAME  （网络功能集名称） | AIPO | 固定取值 |

## 操作步骤

1. 登录UDG OM Portal。
2. 执行命令，动态下线SAPO的pod。

   ```
   OPR FEATUREDISABLE:PODTYPE="aipo-pod/aipoctrl-pod", DISABLETYPE=Normal, FUNCTIONSETNAME="AIPO";
   ```

   在异构场景下，由于SAPO服务的X86虚拟机和ARM虚拟机不会同时存在，SAPO服务对应的POD只有aipoctrl-pod和aipo-pod。
3. 执行命令，确认已经成功下线SAPO的pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="aipo-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="aipoctrl-pod";
   ```

   回显为“查询Pod不存在”。
4. 如果无法通过人工导入方式维护SA性能优化库，则建议关闭Intelligence加速功能。

   执行命令查询Intelligence加速是否开启。

   ```
   LST AIFUNCPARA:;
   ```

   当查询结果为“SA AI 功能开关  =  不使能（关闭）”时，无需进行关闭，直接进行步骤5。  
   当查询结果为“SA AI 功能开关  =  使能（开启）”时，需要执行命令关闭Intelligence加速。

   ```
   SET AIFUNCPARA: SAAIENABLER=DISABLE;
   ```
5. 若动态下线SAPO服务后，不再上线SAPO服务，则需要缩容SAPO自身VM（PBU\_AI），释放VM资源。

   若后续还需要上线SAPO服务，则不必缩容SAPO自身VM。

   **缩容VM**：请参见《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》
