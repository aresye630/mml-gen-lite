## 操作场景

DHCP属于网络层协议，它采用Client/Server模式。DHCP Server负责客户端IP地址的管理和分配，SMF作为Client端，代替UE向DHCP Server申请和租用IP地址。

适用于GGSN、SGW-C、PGW-C、SMF。

## 操作步骤

1. 在SMF上执行如下命令：
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置DHCP地址池组。

      **ADD ADDRPOOLGRP**
   3. 配置DHCP地址池。

      **ADD ADDRPOOL**
   4. 绑定地址池组和地址池。

      **ADD POOLBINDGRP**
   5. 配置地址池里的IPv6地址段。

      **ADD SECTION**
   6. 配置逻辑IP地址。

      * 此逻辑IP地址为DHCP代理IP，被**ADD AGENTIP**命令引用。
      * 代理IP同DHCP地址池里的地址段属于同一网段，DHCP服务器从与该代理IP相同网段的地址池中为用户分配一个IP地址。
      * 当地址池有多个网段时，代理IP也要配置多个。

      **ADD LOGICIP**
   7. 配置UPF组。

      ****ADD ADDRUPGROUP****
   8. 配置UPF和UPF组的绑定关系。

      ****ADD UPFBINDGRP****
   9. 配置APN。

      **ADD APN**
   10. 为该UPF组绑定本地地址池组。

       **ADD POOLGRPMAP**
   11. 配置DHCP地址池的IPv6地址段。

       代理IP需要先通过**ADD LOGICIP**配置。

       **ADD AGENTIP**
   12. 配置DHCP服务器组。

       **ADD DHCPSERVERGRP**
   13. 配置主用DHCP服务器的IP地址。

       **ADD DHCPSERVER**
   14. **可选：**配置备用DHCP服务器的IP地址。

       **ADD DHCPSERVER**
   15. 配置DHCP服务器组与地址池绑定关系。

       **ADD DHCPBINDPOOLGRP**
   16. 配置IP地址分配方式为DHCP分配。

       **SET APNADDRESSATTR**
   17. 配置地址分配规则。

       **SET IPALLOCRULE**
2. 在UPF上执行如下命令：
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置VPN实例。

      **ADD L3VPNINST**

      **ADD VPNINSTAF**
   3. 启动OSPF进程。

      **ADD OSPF**
   4. 添加OSPF区域。

      **ADD OSPFAREA**
   5. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   6. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**

      采用路由策略方式发布路由时，不能只选择发布WLR\_SP或者WLR\_UD路由，必须选择WLR方式发布所有路由。

## 任务示例

任务描述

配置通过DHCPv6 Server给UE分配地址。

脚本

//创建VPN实例。

```
ADD VPNINST:VPNINSTANCE="vpn6_dhcp";
```

//配置地址池组名称。

```
ADD ADDRPOOLGRP: POOLGRPNAME="poolgroup1", POOLGRPTYPE=DHCP;
```

//配置远端地址池。

```
ADD ADDRPOOL:POOLNAME="remotepool",POOLTYPE=DHCP,HASVPN=ENABLE,VPNINSTANCE="vpn6_dhcp";
```

//配置地址池与地址池组绑定关系。

```
ADD POOLBINDGRP: POOLGRPNAME="poolgroup1", POOLNAME="remotepool", PRIORITY=15;
```

//配置本地地址池里的IPv6地址段。

```
ADD SECTION:POOLNAME="remotepool", SECTIONNUM=2, IPVERSION=IPv6, V6PREFIXSTART="2001:DB8:0001:0001:0:0:0:0", V6PREFIXEND="2001:DB8:0001:0001:0:0:0:10", V6PREFIXLENGTH=64;
```

//配置逻辑IP。

```
ADD LOGICIP: IPVERSION=IPv6, LOGICIPV6="2001:DB8:0001:0001:0:0:0:1", IPV6MTU=1500, VPNINSTNAME="vpn6_dhcp", DESC="dhcp agent ip";
```

//配置UPF组。

```
ADD ADDRUPGROUP: UPFGRPNAME="upfgrp1",UPFGRPTYPE="DHCP";
```

//配置UPF和UPF组的绑定关系。

```
ADD UPFBINDGRP: UPFGRPNAME="upfgrp1", UPFID="upf_instance_1";
```

//配置APN。

```
ADD APN:APN="apn-test";
```

```
SET APNADDRESSATTR:APN="apn-test",IPV6ALLOCTYPE=DHCP,IPV6RADIUSPRIOR=ENABLE;
SET IPALLOCRULE:IPV6FIRSTRULESW=ENABLE, IPV6FIRSTRULE=APN-1&UPNODE-1;
```

//配置地址池组与UPF组的绑定关系。

```
ADD POOLGRPMAP:MAPPINGNAME="one",POOLGRPNAME="poolgroup1", APN="apn-test", UPFGRPNAME="upfgrp1";
```

//配置远端地址池的IPv6地址段。

```
ADD AGENTIP:POOLNAME="remotepool",SECTIONNUM=0,IPVERSION=IPV6,V6AGENTIP="2001:DB8:0001:0001:0:0:0:1";
```

//配置DHCP Server服务器组。

```
ADD DHCPSERVERGRP:GROUPNAME="dv6grp",IPVERSION=IPV6,HASVPN=ENABLE,VPNINSTANCE="vpn6_dhcp";
```

//配置DHCP服务器。

```
ADD DHCPSERVER:GROUPNAME="dv6grp",ISPRIMARY=ENABLE,IPVERSION=IPV6,V6IPADDRESS="2001:DB8:0002:0001:0:0:0:1";
```

```
ADD DHCPSERVER:GROUPNAME="dv6grp",ISPRIMARY=DISABLE,IPVERSION=IPV6,V6IPADDRESS="2001:DB8:0003:0001:0:0:0:1";
```

//配置DHCP服务器组与地址池组绑定关系。

```
ADD DHCPBINDPOOLGRP:POOLGRPNAME="poolgrp1",GROUPNAME="dv6grp";
```

//配置UPF上包含该网段的地址池信息。

```
ADD VPNINST:VPNINSTANCE="vpn6_dhcp";
```

//配置手机下行路由。

```
ADD L3VPNINST:VRFNAME="vpn6_dhcp";
```

```
ADD VPNINSTAF:VRFNAME="vpn6_dhcp",AFTYPE=ipv6uni;
```

```
ADD OSPFV3: VRFNAME="vpn6_dhcp",PROCID=1,ROUTERID="10.10.10.1";
```

```
ADD OSPFV3AREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFV3IMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```
