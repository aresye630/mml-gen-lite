## 操作场景

当运营商规划部署基于上下行解耦的视频承载信令控制功能时，需执行本操作。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110302 基于上下行解耦的视频承载信令控制。
* 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置三四层过滤条件。

   **ADD FILTER**
3. 配置流过滤器，绑定三四层、七层过滤条件。
   1. 配置流过滤器。

      **ADD FLOWFILTER**
   2. 配置三四层过滤条件与流过滤器的绑定关系。

      **ADD FLTBINDFLOWF**
   3. 配置七层过滤条件与流过滤器的绑定关系。

      **ADD PROTBINDFLOWF**
   4. 将新配置的Filter置为生效。

      **SET REFRESHSRV**
4. 配置QoS属性。
   1. 配置QoS类型URR。

      **ADD URR**
   2. 配置QoS属性，打开基于上下行解耦的视频差异化调度功能开关。

      **ADD QOSPROP**
5. 配置PCC策略组。

   **ADD PCCPOLICYGRP**
6. 配置业务规则。

   **ADD RULE**

   如果运营商希望基于流过滤器组设置过滤条件时，配置“流过滤器或流过滤器组选择(FILTERINGMODE)”为“FLOWFILTERGRP”，并且使用**ADD FLOWFILTERGRP**命令配置流过滤器组。
7. 配置业务策略组合。
   1. 创建UserProfile。

      **ADD USERPROFILE**
   2. 将已配置的Rule绑定到UserProfile。

      **ADD RULEBINDING**

## 任务示例

任务描述

配置七层业务触发的基于下行链路的专有承载/QoS Flow创建，并使能example\_video协议触发基于上下行解耦的视频承载信令控制功能。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5SCUD01",SWITCH=ENABLE;
```

//配置三四层过滤条件。

```
ADD FILTER:FILTERNAME="filter_test",L34PROTTYPE=STRING,L34PROTOCOL=ANY;
```

//配置流过滤器，绑定三四层、七层过滤条件。

```
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_test1";
```

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_test1",FILTERNAME="filter_test";
```

```
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_test1",PROTOCOLNAME="example_video";
```

```
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置QoS属性，打开基于上下行解耦的视频差异化调度功能开关。

```
ADD URR: URRNAME="urr_1", URRID=1, USAGERPTMODE=QOS;
```

```
ADD QOSPROP:QOSPROPNAME="qos-property1", QOSURRNAME="urr_1",DECOUPLINGSW=ENABLE;
```

//配置PCC策略组。当需要计费时，请配置参数URRGROUPNAME。

```
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="ppg1",QOSPROPNAME="qos-property1",URRGROUPNAME="urrgp_test";
```

//配置业务规则。

```
ADD RULE:RULENAME="rule_test",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="flowfilter_test1", POLICYNAME="ppg1",PRIORITY=10;
```

//配置业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
```

```
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test";
```
