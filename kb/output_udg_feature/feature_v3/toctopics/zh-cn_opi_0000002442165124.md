## 操作场景

本操作用于指导在专网SMF上开启通用DNN漫游分流特性。

## 对系统的影响

无。

## 必备事项

前提条件

已参考运营商配置规范完成网元的基本配置。

## 任务示例

任务描述

在专网SMF上开启通用DNN漫游分流功能。

脚本

1. 打开“公网会话UE IP地址处理开关。当N16a口携带了公网会话的UE IP地址（扩展私有字段），专网SMF会将公网会话的UE IP地址下发给专网会话的锚点UPF，指示专网UPF做UE IP地址NAT转换。

   ```
   SET SMFFUNC: N16AUEIPSW=Support;
   ```
2. 配置左侧AMF或I-SMF携带的selectedDNN作为用户请求DNN使用。

   ```
   SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1039, VALUE=VALUE_1, POSITION=21;
   ```
3. 配置UPF支持UE IP地址NAT转换功能。

   ```
   MOD UPNODE: NFINSTANCENAME="5EA7F228-47CC-2032-03A3-0E1313000001", UEIPNATFUNC=ENABLE;
   MOD UPNODE: NFINSTANCENAME="5EA7F228-47CC-2032-03A3-0E1313000002", UEIPNATFUNC=ENABLE;
   ```
