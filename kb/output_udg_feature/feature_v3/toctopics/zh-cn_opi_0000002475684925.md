## 操作场景

用户访问归属地园区业务时，数据会通过智能分流UPF转发至园区的专网UPF，从而使用户可以访问园区业务。本章节主要介绍在园区专网UPF上配置专用DNN的基本数据。

## 必备事项

前提条件

已参考运营商配置规范完成网元的基本配置。

数据

|  | 绑定IPv6 VPN（HASVPNIPV6） | ENABLE | 本端规划 | 该参数用于指定是否给APN实例绑定IPv6 VPN。 |
|  | IPv6 VPN实例名（VPNINSTANCEIPV6） | VRF\_common\_dnn | 本端规划 | 该参数用于指定IPv6 VPN实例名。 |
|  | 支持假激活用户开关（PSEUDOACTSWITCH） | INHERIT | 本端规划 | 该参数是用来配置APN是否支持假激活用户的开关。 |

## 任务示例

任务描述

在园区内专网UPF上配置通用DNN漫游分流。

脚本

1. 配置VPN和DNN，如已完成VPN和专用DNN创建，请跳过本步骤。该VPN实例与专网UPF的N6接口VPN实例保持一致。

   ```
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD APN:APN="stjwt.gd",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP",HASVPNIPV6=ENABLE,VPNINSTANCEIPV6="VRF_N6_Local_2B_APP",PSEUDOACTSWITCH=INHERIT;
   ```
2. 设置APN单通检测开关。如果检测到用户数据流量发生单通故障，会触发设备内环回探测，开启用户数据跟踪，可以跟踪到探测报文。

   ```
   SET APNSGLPASS:APN="stjwt.gd",SWITCH=PF_ACT_ENABLE;
   ```
3. 对APN地址分配属性进行配置。

   ```
   SET APNADDRESSATTR:APN="stjwt.gd",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE,FRAMEDROUTE=DISABLE,ANTISPOOFINGDL=ENABLE,ANTISPOOFINGUL=ENABLE,IPTYPEFORDUALIP=IPV4V6,SINGLEADDRCAUSE=1,CPCTRL=DISABLE,IPV6RAMTUSW=DISABLE,IPV6RALIFETIME=65535,HOSTROUTEIP=ENABLE;
   ```
4. 开启APN的TCP MSS调整功能并配置TCP MSS的值。

   ```
   ADD TCPMSS:APN="stjwt.gd",ROAMINGTYPE=HOME-1&ROAMING-1&VISITING-1,V4TCPMSSVALUE=1380,V6TCPMSSVALUE=1300;
   ```
5. 开启计费防欺诈。

   ```
   SET APNAFFUNC:APN="stjwt.gd",ISENABLE=ENABLE;
   ```
