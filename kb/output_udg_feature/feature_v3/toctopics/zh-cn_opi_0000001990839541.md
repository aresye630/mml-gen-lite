## 操作场景

本指导描述计费属性的相关配置过程。

计费属性Charging Characteristics（CC）是3GPP协议定义的一种用户签约付费属性，不属于计费功能。计费属性的取值有热计费(Hot Billing 0x0100)、统一费率（Flat Rate 0x0200）、预付费（Prepaid Service 0x0400）、普通计费(Normal Billing 0x0800)和自定义取值。

计费属性可以由RADIUS Server下发，可以在UDM\HSS\HLR上签约，也可以在UNC上本地配置，UNC支持基于User Profile、DNN、全局配置三种计费属性。其中，RADIUS Server下发计费属性优先级高于UNC本地配置（通过配置可以决定使用签约的计费属性还是本地配置的计费属性），UNC上配置的计费属性的优先级从高到低依次是：UserProflie下的配置 > DNN下的配置 > 全局配置 > normal（缺省：普通计费）。如果高级别的计费属性没有配置，则依次使用低一级别的计费属性。

**图1** Charging Characteristics选择图

* 当UDM下发签约计费属性（或者2/3/4G会话激活请求中携带了计费属性）、并且本地基于User Profile、DNN配置计费属性场景下，由**ADD CHARGECHAR**命令的HOMESGSN、ROAMSGSN、VISITSGSN控制本地、漫游、拜访用户是否使用签约的计费属性。
  + 当对应参数配置为ENABLE时，表示使用UDM签约下发的计费属性（或者2/3/4G会话激活请求中携带了计费属性）。此时，如果**SET CHARGECHARCHK**命令的“CHARGECHARCHK”参数值为“ENABLE”时，SMF/GW-C/GGSN会检查UDM签约下发的计费属性（或者2/3/4G会话激活请求中携带了计费属性）的第一个字节的低4个bit是否为1、2、4、8中一个，如果是，则使用将其第一个字节高4个bit位置0，并使用该校正后的计费属性；否则，使用本地配置的计费属性。如果“CHARGECHARCHK”参数值为“DISABLE”时，使用UDM下发签约计费属性（或者2/3/4G会话激活请求中携带了计费属性）。
  + 当配置为DISABLE时，表示使用本地配置的计费属性。
* 当UDM下发签约计费属性（或者2/3/4G会话激活请求中携带了计费属性）、并且本地基于全局配置计费属性场景下，由**SET GLBCHARGECHAR**命令的HOMESGSN、ROAMSGSN、VISITSGSN控制本地、漫游、拜访用户是否使用签约的计费属性。
  + 当对应参数配置为ENABLE时，表示使用UDM签约下发的计费属性（或者2/3/4G会话激活请求中携带了计费属性）。此时，如果**SET CHARGECHARCHK**命令的“CHARGECHARCHK”参数值为“ENABLE”时，SMF/GW-C/GGSN会检查UDM签约下发的计费属性（或者2/3/4G会话激活请求中携带了计费属性）的第一个字节的低4个bit是否为1、2、4、8中一个，如果是，则使用将其第一个字节高4个bit位置0，并使用该校正后的计费属性；否则，使用本地配置的计费属性。如果“CHARGECHARCHK”参数值为“DISABLE”时，使用UDM下发签约计费属性（或者2/3/4G会话激活请求中携带了计费属性）。
  + 当配置为DISABLE时，表示使用本地配置的计费属性。

* SMF根据本地配置的计费属性选择NCG/CHF(OCS)时，需要配置计费属性。
* 4G网络中，在SP合设场景，即UNC作为SGW-C和PGW-C时，由左侧MME携带计费属性（MME从HSS获取的签约计费属性）；在SP分离部署场景，当UNC单独作为SGW-C时由左侧MME携带计费属性（MME从HSS获取的签约计费属性），当UNC单独作为PGW-C时由左侧SGW-C携带计费属性（SGW-C通过MME得到签约计费属性）。即4G网络中签约计费属性由左侧MME/SGW-C携带。
* 2/3G网络中，UNC作为GGSN，由左侧SGSN携带签约计费属性（SGSN从HLR获取得签约计费属性）。

## 操作步骤

* 配置全局计费属性。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置全局计费属性。如已配置全局计费属性，请跳过该步骤。

     **SET GLBCHARGECHAR**
* 配置DNN下的计费属性。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置计费属性实例。

     **ADD CHARGECHAR**
  3. 将计费属性绑定到DNN上。

     **SET APNCHARGECTRL**
* 配置User Profile下的计费属性。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置计费属性实例。

     **ADD CHARGECHAR**
  3. 将计费属性绑定到User Profile上。

     **SET USRPROFCHARGE**
* 配置是否检查Serving Node携带的对本地用户、漫游用户、拜访用户所采用的计费属性。

  **SET CHARGECHARCHK**

## 任务示例

任务描述

任务一：配置全局用户的计费属性，包括对本地用户、漫游用户、拜访用户所采用的计费属性。

任务二：配置APN实例apn-test的计费属性。

任务三：配置User Profile实例up-test的计费属性。

任务四：配置检查Serving Node携带的对本地用户、漫游用户、拜访用户所采用的计费属性。

脚本

//任务一：配置对本地用户、漫游用户、拜访用户所采用的全局计费属性。

```
SET GLBCHARGECHAR: HOME="0x0100", ROAM="0x0100", VISIT="0x0100", HOMESGSN=DISABLE, ROAMSGSN=DISABLE, VISITSGSN=DISABLE;
```

//任务二：配置计费属性实例testchgcha，并将计费属性绑定到APN实例apn-test上。

```
ADD CHARGECHAR: CCNAME="testchgcha", HOME="0x0800", ROAM="0x0800", VISIT="0x0800", HOMESGSN=DISABLE, ROAMSGSN=DISABLE, VISITSGSN=DISABLE;
SET APNCHARGECTRL: APN="apn-test", CCNAME="testchgcha";
```

//任务三：配置计费属性实例testchgcha，并将计费属性绑定到User Profile实例up-test上。

```
ADD CHARGECHAR: CCNAME="testchgcha", HOME="0x0800", ROAM="0x0800", VISIT="0x0800", HOMESGSN=DISABLE, ROAMSGSN=DISABLE, VISITSGSN=DISABLE;
SET USRPROFCHARGE: USRPROFNAME="up-test", CCNAME="testchgcha";
```

//任务四：配置检查Serving Node携带的对本地用户、漫游用户、拜访用户所采用的计费属性。

```
SET CHARGECHARCHK: CHARGECHARCHK=ENABLE;
```
