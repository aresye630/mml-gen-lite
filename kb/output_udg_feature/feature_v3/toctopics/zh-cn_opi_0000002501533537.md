# 配置N40、Bx接口话单支持媒体中继流量字段

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

在N40计费场景下，当运营商需要核对话单流量时，请参考本章节进行配置。

## 必备事项

前提条件

* 请提前了解话单流量核对方案。
* CHF已升级到20.16.2及后续版本。

## 操作步骤

1. 停止N40口业务，执行**SET NCGSOFTPARAOFBIT**命令停止话单接收功能。

   ```
   SET NCGSOFTPARAOFBIT: DT=Dw, DWORDNUM=4, VALUE=VALUE_1, POSITION=24;
   ```
2. 停止Ga口业务，执行**STP CDRRECEIVE**命令停止话单接收功能。

   ```
   STP CDRRECEIVE: AGID="PS_X";
   ```
3. 查看停止接收话单是否成功。

   DSP CCL命令结果显示”原始话单采集速度”和”原始话单保存速度”均为0时，表示停止接收话单成功。

   ```
   DSP CCL:;
   ```
4. 打开控制话单是否携带媒体中继Relay字段的软参。

   ```
   SET NCGSOFTPARAOFBIT: DT=Dw, DWORDNUM=23, VALUE=VALUE_1, POSITION=32;
   ```
5. 添加格式引擎包软参配置媒体中继功能后存盘补丁、生成的Relay通道下的话单格式和话单是否压缩。

   ```
   ADD FMTPKGCFG: PRFNAME="PS_R15_VF80_NorthChina_CMCC.tar.gz", CFGNAME="BackSavePatchName", CFGTYPE=FEM_PARA_STRING, CFG_STR_VALUE="r15_vf80_cmcc_relay";
   ADD FMTPKGCFG: PRFNAME="PS_R15_VF80_NorthChina_CMCC.tar.gz", CFGNAME="RelayCdrType", CFGTYPE=FEM_PARA_UINT, CFG_UINT_VALUE=0;
   ADD FMTPKGCFG: PRFNAME="PS_R15_VF80_NorthChina_CMCC.tar.gz", CFGNAME="RelayCdrCompress", CFGTYPE=FEM_PARA_UINT, CFG_UINT_VALUE=1;
   ```
6. 添加本地话单分发，用于观测Relay目录下生成的话单。

   ```
   ADD CDRDISTR: CDRDISTRID="task_offline", ISSINGLEBI=NO, TRANSMODE=LOCAL, AGID="PS_X", MNAME="ALL", ISCUTOMDISTR=NO, SOURCECHL="Tianjin/OFFLINE", DESTPATH="./Relay/OFFLINE", ISADDAPNAME=YES, ISADDCHLNAME=YES, TRANSPER=EVERYDAY, CMRRULE=UNCOMPRESS, LOGAUDIT=NO;
   ADD CDRDISTR: CDRDISTRID="task_online", ISSINGLEBI=NO, TRANSMODE=LOCAL, AGID="PS_X", MNAME="ALL", ISCUTOMDISTR=NO, SOURCECHL="Tianjin/ONLINE", DESTPATH="./Relay/ONLINE", ISADDAPNAME=YES, ISADDCHLNAME=YES, TRANSPER=EVERYDAY, CMRRULE=UNCOMPRESS, LOGAUDIT=NO;
   ```
7. 执行**RST VNFC**命令使添加的引擎包软参生效。

   ```
   RST VNFC: ISFORCEOPER=FALSE, SERVICEINSTANCE="CG_VNFC_999";
   ```
8. 等待3-5分支，执行DSP SERVICE命令查看模块是否处于激活状态，激活则加载成功。

   ```
   DSP SERVICE:;
   ```
9. 恢复N40口业务，执行**SET NCGSOFTPARAOFBIT**命令恢复接收话单功能。

   Ga口业务在7执行**RST VNFC**后直接恢复，无需单独恢复。

   ```
   SET NCGSOFTPARAOFBIT: DT=Dw, DWORDNUM=4, VALUE=VALUE_0, POSITION=24;
   ```
