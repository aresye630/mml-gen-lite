# 卸载SBIM服务

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要SBIM服务或SBIM服务动态上线失败时，可以单独卸载SBIM pod，从而下线SBIM服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线SBIM pod的类型和数量。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| UDG OM Portal帐户 | IP地址 | 192.168.1.1  操作维护接口IP，即“VNFD模板”中的“MNG\_IP”或“MNG\_IPv6”参数。 | 本端规划 |
|  | 端口号 | 31943 | 本端规划 |
|  | 用户名 | admin | 本端规划 |
|  | 密码 | Changeme\_123 | 本端规划 |
| 特性下线  OPR FEATUREDISABLE | Pod类型列表（PODTYPE） | httpctrl-pod/sbim-pod | 固定取值 |
|  | 下线方式（DISABLETYPE） | Normal | 本端规划 |
|  | FUNCTIONSETNAME  （网络功能集名称） | SBIM | 固定取值 |

## 操作步骤

1. 登录UDG OM Portal。
2. 执行命令，动态下线SBIM pod。

   ```
   OPR FEATUREDISABLE: PODTYPE="httpctrl-pod/sbim-pod", DISABLETYPE=Normal, FUNCTIONSETNAME="SBIM";
   ```
3. 执行命令，确认已经成功下线SBIM pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="httpctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="sbim-pod";
   ```

   回显“查询Pod不存在”。
4. 若动态下线SBIM服务后，不再上线SBIM服务，则需要缩容SBIM自身VM（X86为：PBU\_P-S；ARM为：PBU\_P-S\_ARM），释放VM资源。

   若后续还需要上线SBIM服务，则不必缩容SBIM自身VM。

   **缩容VM**：请参见《UDG中心侧扩缩容指导书(基于LCM)》或《UDG中心侧扩缩容指导书(基于NFVO)》。
