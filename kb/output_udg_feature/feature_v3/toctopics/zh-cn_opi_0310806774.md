## 操作场景

若运营商需要查看更详细的日志信息，精准定位不同用户的地址转换过程，则需要开启溯源日志携带用户标志特性。

## 必备事项

前提条件

* 已完成激活溯源日志上报。
* 已完成UDG与日志服务器之间IPSEC安全传输通道的建立，详情可参考“IPFD-016000 IPSec功能”特性。
* 已登录OM Portal。
* 已完成配置NAT基本功能License开关。

数据

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（ LICITEM） | LKV4NATUSR01 | 本端规划 | 打开溯源日志携带用户标志License开关。 |
|  | 开关（SWITCH） | ENABLE | 本端规划 |  |
| **natlog-syslog template** | **template** *templatename* | syslog | 本端规划 | 配置日志内容模板名称。 |
|  | **format** *format* | $date\_utc $time\_utc $rcd\_type source=$src\_ip source\_nat=$src\_nat\_ip:$src\_nat\_port dest=$dest\_ip:$dest\_port vpn=$vpn\_id imsi=$imsi msisdn=$msisdn | 全网规划 | 配置用户自定义日志内容格式，当发送会话日志或者端口预分配日志会根据自定义格式将日志内容发送到日志服务器。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
3. 进入NAT系统视图。

   **sy****stem-view**
4. 进入natlog-view视图。

   **nap-view**

   **natlog-view**
5. 自定义syslog日志的内容格式。

   **natlog-syslog template**

## 任务示例

任务描述

配置NAT溯源日志中增加携带用户的IMSI和MSISDN标志。

脚本

```
SET LICENSESWITCH: LICITEM="LKV4NATUSR01", SWITCH=ENABLE;
<NAT> system-view
[NAT] nap-view
[NAT-nap]natlog-view
[NAT-nap-natlog]natlog-syslog template syslog format "$date_utc $time_utc $rcd_type source=$src_ip source_nat=$src_nat_ip:$src_nat_port dest=$dest_ip:$dest_port vpn=$vpn_id imsi=$imsi msisdn=$msisdn"
```
