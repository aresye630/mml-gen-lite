## 操作场景

当运营商想要部署VVIP用户质差监测和保障**、**小区拥塞优化等智能业务时，需要配置本页面，完成智能板业务相关部署。

适用于UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-111283 智能板订阅和采集特性概述。
* 已完成业务感知配置。
* 已完成激活报表功能。
* 已完成**软件安装**手册中的**安装SSU服务**。
* 已完成加载License。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET SSUAGINGCFG** | FLOWAGINGTIME（业务流老化时间） | 30 | 本端规划 | 用于设置业务流老化时间。整数类型，取值范围5~7200，单位为秒，缺省值30。 |
|  | SESSAGINGTIME（Session表老化时间） | 60 | 本端规划 | 用于设置Session表老化时间。整数类型，取值范围5~7200，单位为分钟，缺省值60。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置SSU老化参数。

   **SET SSUAGINGCFG**

## 任务示例

任务描述

配置SSU老化参数。

脚本

//配置开启智能板订阅和采集功能开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5IBIC01",SWITCH=ENABLE;
```

//配置SSU老化参数。

```
SET SSUAGINGCFG:FLOWAGINGTIME=30, SESSAGINGTIME=60;
```
