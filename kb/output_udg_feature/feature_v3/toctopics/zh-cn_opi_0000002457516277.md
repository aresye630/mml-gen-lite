## 操作场景

当SMF无法下发媒体中继用户标识及规则的场景下，需要基于拨测用户在UPF上开启媒体中继功能进行调测，或调测完成后删除拨测用户时，可以参考本章节进行配置。

## 必备事项

前提条件

已完成媒体中继业务增加媒体中继全局配置~开启媒体中继业务总开关的相关配置。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD RELAYTESTUSER** | 拨测用户名称（TESTUSERNAME） | relaytestuser01 | 本端规划 | - |
|  | APN名称（APNNAME） | huawei.com | 全网规划 | 此APN为测试用户所在的APN。 |
|  | 用户类型  （USERTYPE） | IMSI | 全网规划 | - |
|  | IMSI（IMSI） | 460011223344551 | 全网规划 | - |
|  | 媒体中继功能开关（RELAYFUNC） | ENABLE | 固定取值 | - |
|  | 用户模板名称（USERPROFILENAME） | testuserprofilename | 全网规划 | 该规则与SMF下发的规则保持一致。 |
| **RMV RELAYTESTUSER** | 拨测用户名称（TESTUSERNAME） | relaytestuser01 | 本端规划 | 已通过**ADD RELAYTESTUSER**配置。 |

## 操作步骤

1. 增加媒体中继拨测用户。

   **ADD RELAYTESTUSER**
2. 调测完成后，删除拨测用户。

   **RMV RELAYTESTUSER**

## 任务示例

任务描述

拨测用户relaytestuser01，所在的APN为huawei.com，IMSI为460011223344551，基于此用户开启媒体中继功能。

脚本

```
ADD RELAYTESTUSER:TESTUSERNAME="relaytestuser01",APNNAME="huawei.com",USERTYPE=IMSI,IMSI="460011223344551",RELAYFUNC=Enable,USERPROFILENAME="testuserprofilename";
```

## 任务示例

任务描述

拨测用户relaytestuser01，用户测试完成后删除拨测用户。

脚本

```
RMV RELAYTESTUSER:TESTUSERNAME="relaytestuser01";
```
