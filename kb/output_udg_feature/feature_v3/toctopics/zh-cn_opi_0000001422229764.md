# 配置禁止UE向逻辑接口发起PING报文

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

UE与UDG不需要通过PING报文调试网络的联通性时，为避免UE通过PING报文非法访问UDG，配置禁止UE向UDG逻辑接口发送PING报文功能。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET UEPINGINF** | Ping开关（PINGSWITCH） | DISABLE | 固定取值 | 仅对通过**ADD LOGICINF**添加的逻辑接口生效。 |

## 操作步骤

1. 配置禁止UE向逻辑接口发起PING报文。

   **SET UEPINGINF**

## 任务示例

任务描述

为避免UE通过大量PING报文向UDG发起攻击，配置禁止UE向逻辑接口发送PING报文功能。

脚本

配置禁止UE向逻辑接口发送PING报文功能。

```
SET UEPINGINF:PINGSWITCH=DISABLE;
```
