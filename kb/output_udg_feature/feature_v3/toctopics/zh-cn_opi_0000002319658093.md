# 模块级KPI异常检测与恢复人工执行解除隔离操作

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本操作用于指导在运行网络中调测模块级KPI异常检测与恢复功能，人工执行解除隔离操作。

构造单主机拥塞场景会对业务造成影响，建议在测试环境中进行该功能验证。

## 必备事项

前提条件

* 请仔细阅读GWFD-110494 模块级KPI异常检测与恢复特性概述。
* 已完成激活模块级KPI异常检测与恢复。
* 已完成调测模块级KPI异常检测与恢复

数据

该操作无需准备数据。

工具

OM Portal

## 操作步骤

1. 登录网元OM Portal。
2. 查看是否存在“**ALM-100384 Host Fabric平面故障**”、“**ALM-100494 Pod故障隔离**”或“**ALM-100628 复杂故障场景下Pod故障隔离**”告警。

   * 是 => 3
   * 否 => 4
3. 根据对应告警处理步骤恢复告警。
4. 执行**DSP SGLDETECTION**命令，查询“**隔离结果**”是否为“隔离成功”。

   * 是 =>5
   * 否 => 请联系华为技术支持处理。
5. 人工排除Fabric通信亚健康或CPU过载故障。
6. 执行**STR RCISOLATION**命令解除已隔离的Pod。
7. 执行**DSP SGLDETECTION**命令查看是否存在对应Pod的隔离记录。

   * 是 => Pod未被解除隔离，请联系华为技术支持处理。
   * 否 => Pod解除隔离，功能调测结束。
