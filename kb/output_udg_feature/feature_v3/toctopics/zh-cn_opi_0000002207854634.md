# 增加媒体服务商基础配置

* 操作场景
* 必备事项
* 任务示例

## 操作场景

使用媒体中继业务时，需要基于媒体服务商（OTT）规划媒体中继业务使用的IP地址及媒体中继模板等全局配置。本章节用于指导如何增加媒体中继服务商相关的基础配置。

## 必备事项

前提条件

* 已完成License加载。
* 已完成框间级联部署及扩容。

数据

## 任务示例

任务描述

新增媒体中继模板，绑定媒体中继板的Relay IP及媒体中继地址池，并增加基于APP的观测指标。

脚本

//配置Relay服务的IP地址。

```
ADD RELAYIPINFO: RELAYIPNAME="sp_relay_ip_001", IPSERVICETYPE=GROUPIP, IPV4ADDR="10.100.5.100", IPV6ADDR="2409:892B:A80:1000:1000:1000:1000:0001", VPNINSTANCE="VRF_Internet";
```

//配置Relay模板信息。

```
ADD RELAYTEMPLATE: RELAYTPLNAME="sp_relay_tpl", DNSCNAME="www.3gpp.eupf.com", DNSIPNOTMTACT=RETNOTFOUND, UNKNOWNDMACT=FORBIDDEN, VENDORID=1, MEDIAAGETIME=168, MEDIAAUTHTIME=5, MEDIAAUTHMETHOD=GET, LIVESRVFAILCODE=NOTFOUND,VODSRVFAILCODE=SERVICEUNABAILABLE;
```

//配置Relay服务的IP信息绑定到Relay模板下。

```
ADD RELAYIPBINDING: RELAYTPLNAME="sp_relay_tpl", RELAYIPNAME="sp_relay_ip_001";
```

//配置Relay服务的地址池绑定到Relay模板下。

```
SET RELAYIPPOOLBD: RELAYTPLNAME="sp_relay_tpl", IPPOOLNAME="relay_ip_pool_cmnet";
```

//增加基于APP观测指标。

开启前准备：

* 需要先将知识库版本升级到“SA signature database package V100R020C00SPH295”（01.0002.1688.01）及以上版本。
* 需要在MAE上提前下发测量对象。

```
ADD PROTOCOLGROUP:PROTGROUPNAME="proto_group_douyin_live", PROTOCOLNAME="tiktok_live";
ADD PROTOCOLGROUP:PROTGROUPNAME="proto_group_douyin_vod", PROTOCOLNAME="tiktok_video";
ADD APPPERFSTAT:APPNAME="app_douyin_live", FILTERMODE=PROTOCOLGROUP, PROTGROUPNAME="proto_group_douyin_live", PRIORITY=1001;
ADD APPPERFSTAT:APPNAME="app_douyin_vod", FILTERMODE=PROTOCOLGROUP, PROTGROUPNAME="proto_group_douyin_vod", PRIORITY=1002;
```

//增加签约媒体中继套餐配置。

```
ADD USERPROFILE: USERPROFILENAME="testuserprofilename", ALIASMARKFLAG=DISABLE, DDOSCHECK=DISABLE, LOCRPTSWITCH=INHERIT;
```
