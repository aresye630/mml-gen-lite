## 操作场景

为保护用户上网安全，免受网络恶意报文攻击，需要激活NAT个人应用防护功能。

## 必备事项

前提条件

* 已通过**ADD APN**完成APN的相关配置。
* 已登录OM Portal。
* 已完成配置NAT基本功能License开关。

## 操作步骤

1. 打开本特性的License（内置安全增强）配置开关。

   **SET LICENSESWITCH**
2. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
3. 配置个人应用防护过滤条件。

   1. 进入nap视图。

      **nap****-view**
   2. 配置三四层NAT过滤条件。

      **nap-filter** *xxx* **l34-protocol** *xxx*
   3. 配置NAT过滤条件组，可绑定已配置的NAT filter。当配置了多个NAT filter时，满足其中一个过滤条件即可。

      **nap-filter-group** *xxx* **nap-filter** *xxx*
   4. 生效NAT过滤条件。

      **nap-refresh-service**
4. 配置个人应用防护策略。

   1. 配置数据包过滤策略，引用步骤3配置的过滤条件、以及配置的策略生效时间，并指定对报文的动作。

      **packet-policy**
   2. 配置用户自定义的STUN策略，引用步骤3配置的过滤条件。

      **detect-policy**
   3. 配置三元组ASPF策略，引用步骤3配置的过滤条件、指定对报文的动作。

      **aspf-policy**
   4. 配置长连接策略，引用步骤3配置的长连接过滤条件。

      **long-link-policy**
   5. 配置长连接流量的五元组老化时间。

      **nap-flow-node-agetime**
   6. 配置L7 ASPF支持的应用层协议类型。

      **detect-protocol**
   7. 配置数据包的默认过滤动作。

      **packet-policy-default**

      对于nap-template下的新建流的报文根据**packet-policy**的配置，确定报文是否可以通过。

      * 对于匹配上**packet-policy**配置的过滤规则的报文，按照配置的动作进行处理。
      * 对于未匹配上**packet-policy**配置的过滤规则的报文，则按照**packet-policy-default**配置的动作进行处理。

      若未配置**packet-policy-default**，则按系统的默认动作进行处理：上行报文允许通过，下行报文拒绝通过。
   8. 配置五元组流节点最大个数。

      **nap-flow-node-max**

      该命令用于对单个用户的流数进行控制，防止单个用户建立过多的流数占用系统资源。数据报文达到时，NAT在新建流时首先判断该用户下的流数是否达到配置上限。
      * 如果达到上限，则丢弃报文。
      * 如果未达到上限，则创建流表，允许报文进行后续处理。

      针对手机后路由用户，如果开启了用户的流数控制，则该用户及手机后所有IP的总流数之和受**nap-flow-node-max**命令限制。

## 任务示例

任务描述

在NAT上开启个人应用防护功能。当PDN侧服务器69端口发起的下行报文可以通过，其余端口拒绝通过。

脚本

打开NAT内置安全增强License配置开关：

```
SET LICENSESWITCH: LICITEM="LKV4EN4SCY01", SWITCH=ENABLE;
```

NAT侧配置：

```
[NAT]nap-view
[NAT-nap]nap-filter fhfilter l34-protocol udp
[NAT-nap]nap-filter-group fhgfilter nap-filter fhfilter
[NAT-nap]nap-refresh-service
[NAT-nap]packet-policy name nap-filter-group fhgfilter uplink action permit priority 10
[NAT-nap]detect-policy dectname user-defined nap-filter-group fhgfilter uplink priority 10
[NAT-nap]aspf-policy test1-aspf nap-filter-group fhgfilter uplink action permit priority 10
[NAT-nap]long-link-policy longlink nap-filter-group fhgfilter uplink priority 10
[NAT-nap]nap-flow-node-agetime service-type tcp aging-time 600
[NAT-nap]detect-protocol ftp h323 pptp
[NAT-nap]packet-policy-default uplink action permit
[NAT-nap]nap-flow-node-max max-num 100
```
