## 操作场景

本操作用于指导在智能分流SMF上基于专用DNN配置园区内专网UPF分流功能。

## 对系统的影响

智能分流SMF需要新增与专网UPF的PFCP会话交互，并且需要从PCF获取智能分流规则，因此会造成与周边网元消息交互增加，导致CPU使用率升高。

## 任务示例

任务描述

在智能分流SMF上开启专用UPF分流功能。

脚本

1. 增加5G类型的TAI服务区域。

```
ADD APNAREA: AREANAME="dnarea1", AREATYPE=N2TAI;
```

2. 增加服务区域的TAI绑定范围。

```
ADD APNAREABNDN2TAI: AREANAME="dnarea1", N2BEGINTAI="123003000001", N2ENDTAI="123003123456";
```

3. 绑定专网DNN和服务区域。

```
ADD MULDNNBINDAREA: DEDDNN="stjwt.gd", AREANAME="dnarea1";
```

4. 配置智能分流专网DNN的ULCL部署模式。

```
ADD MULDNNULCLMODE: DEDDNN="stjwt.gd", ULCLDEPLOYMODE=AREADEDUPFPREFER;
```

5. 配置UPF虚拟实例标识。请使用LST VIRTUALUPFID查询UPF是否有配置虚拟实例ID，“UPFINSTANCEID”为智能分流UPF和专网UPF的实例ID。

* 若未配置虚拟实例ID则执行ADD VIRTUALUPFID和ADD VUPFIDBINDFUNC配置虚拟实例ID和开启多DNN开关。
* 若已配置虚拟实例ID则执行ADD VUPFIDBINDFUNC开启多DNN开关，虚拟实例ID请使用LST VIRTUALUPFID命令查询到的“虚拟UPF实例标识”。

```
LST VIRTUALUPFID:UPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001";

ADD VIRTUALUPFID:UPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E1313000001", VUPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E131300000A";
ADD VUPFIDBINDFUNC:VUPFINSTANCEID="5EA7F228-47CC-2032-03A3-0E131300000A",FUNCNAME=MulDNN;
```
