# 配置专网会话支持Ga/Gy接口

## 操作场景

本章节用于指导配置在用户4G/5G NSA接入时，专网SMF基于Ga/Gy接口选择计费网元CG/OCS并完成对用户流量的计费。

根据用户接入网络类型的不同（4G/5G NSA/5G SA），用户的公网会话可以是4G会话，也可以是5G会话，但是在创建用户专网会话时，智能分流PGW-C会将默认将4G信息转换为5G信息，再触发专网会话的建立，因此用户专网会话默认都是5G会话。这种情况下，当运营商的计费网络未改造，仅支持Ga/Gy的组网方式，不支持基于5G SA的N40组网时，需要专网SMF能够基于Gy/Ga接口传递4G计费的关键信息给OCS或CG，如携带4G格式的位置信息/QoS信息/用户接入网元类型等。

## 对系统的影响

无。

## 必备事项

前提条件

* 已完成专网SMF基于Ga/Gy接口和CG/OCS的对接配置。

## 任务示例

任务描述

运营商计费组网采用Ga/Gy接口组网，该组网方式下为某园区开通基于通用DNN漫游分流方案的专线业务，园区APN为stjwt.gd。

脚本

1. 激活5G SA计费的增强型GaGy接口的License。

   ```
   SET LICENSESWITCH: LICITEM="LKV3EGAGY5G01", SWITCH=ENABLE;
   ```
2. 配置基于园区APN的计费接口选择方式。

   ```
   ADD APNCHGMODE: APN="stjwt.gd",TMACCTYPE=UE5G_RAT5G, FORCED=GaGyMode;
   ```
3. 配置Ga接口组网方式下专网SMF给CG携带计费信息类型。

   ```
   ADD APNGA5GREUSEAVP: APN="stjwt.gd", RAT=ENABLE, ULI=ENABLE, SERVINGNODETYPE=ENABLE;
   ```
4. 配置Gy接口组网方式下专网SMF给OCS携带计费信息类型。

   ```
   ADD APNGY5GREUSEAVP: APN="stjwt.gd", RAT=ENABLE, ULI=ENABLE, SERVINGNODETYPE=ENABLE;
   ```
