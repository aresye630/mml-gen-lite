## 操作场景

该任务旨在指导操作人员在UIM上完成家庭CPE的后路由网段配置以及UE的配置。

## 必备事项

前提条件

* 已完成UIM的本局数据。
* 已完成UIM和SMF之间的对接配置。
* 已完成**三层VPN**的License加载。

## 任务示例

任务描述

* 为某家庭CPE和UE配置用户信息。
* 为某家庭的CPE配置后路由网段。

脚本

//添加REALM模板。

```
ADD UREALM: REALM="huawei.com", AUTHMODE=USERNAME_PASSWORD;
```

//配置APN信息。

```
ADD UAPN: APN="home.dnn", MSGTYPE=BOTH, AUTHMODE=USERNAME, TYPE=Static;
```

//登录到UIM MML命令界面，配置CPE和UE配置用户信息。

```
ADD UUSER: ACCESSNETWORK=WCDMA, USERNAME="8613900000001", REALM="huawei.com", PASSWORD="*****", APN="home.dnn";
ADD UUSER: ACCESSNETWORK=WCDMA, USERNAME="8613900000002", REALM="huawei.com", PASSWORD="*****", APN="home.dnn";
ADD UUSER: ACCESSNETWORK=WCDMA, USERNAME="8613900000003", REALM="huawei.com", PASSWORD="*****", APN="home.dnn";
```

//配置家庭CPE后路由网段。

```
ADD UIPROUTE: ACCESSNETWORK=WCDMA, USERNAME="8613900000001", REALM="huawei.com", APN="home.dnn", IPROUTE="10.1.1.1/24";
```
