## 操作场景

当运营商的公网用户需要访问私网服务器时，需要激活目的地址的NAT44转换特性。

## 必备事项

前提条件

* 已通过**ADD APN**完成APN的相关配置。
* 已登录OM Portal。
* 已完成配置NAT基本功能License开关。

## 操作步骤

1. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
2. 配置源地址NAT转换地址池。

   1. 进入系统视图。

      **sy****stem-view**
   2. 配置NAT地址池，有三种模式：No-PAT、NAPT和PBA。

      **ip pool**
   3. 配置NAT地址池的地址段。

      **section**
   4. 返回系统视图。

      **quit**
3. 配置目的地址NAT转换地址池。

   1. 进入系统视图。

      **sy****stem-view**
   2. 配置NAT地址池

      **ip pool**

      当前目的地址的NAT转换地址池仅支持配置为No-PAT模式。
   3. 配置NAT地址池所属的VPN实例。

      **vpn-instance**
   4. 配置地址池使能DNAT功能。

      **dnat**
   5. 配置NAT地址池的地址段。

      **section**
   6. 返回系统视图。

      **quit**
4. 配置NAT过滤条件

   1. 进入nap视图。

      **nap****-view**
   2. 配置三四层NAT过滤条件。

      **nap-filter** *xxx* **l34-protocol** *xxx*
   3. 配置NAT过滤条件组，可绑定已配置的NAT filter。当配置了多个NAT filter时，满足其中一个过滤条件即可。

      **nap-filter-group** *xxx* **nap-filter** *xxx*
   4. 生效NAT过滤条件。

      **nap-refresh-service**
5. 配置NAT策略。

   **nat-policy** *xxx* **nap-filter-group** *xxx* **vpn-instance** *xxx* **action source-nat nat-address-pool** *xxx* **destination-nat nat-address-pool** *xxx* **priority** *x*

   此处VPN需要与业务VPN实例名称保持一致。

## 任务示例

任务描述

激活目的地址的NAT44转换。

脚本

```
<NAT>system-view
[NAT]ip pool poolnat1 mode pba
[NAT-ip-pool-poolnat1]section 0 10.1.1.1 10.1.1.10
[NAT-ip-pool-poolnat1]q
[NAT]ip pool poolnat2 mode no-pat
[NAT-ip-pool-poolnat2]vpn-instance vpn1
[NAT-ip-pool-poolnat2]dnat enable
[NAT-ip-pool-poolnat2]section 0 192.168.1.1 192.168.1.10
[NAT-ip-pool-poolnat2]q
[NAT]nap-view
[NAT-nap]nap-filter nap-testfilter l34-protocol any
[NAT-nap]nap-filter-group testfiltergroupname nap-filter nap-testfilter
[NAT-nap]nap-refresh-service
[NAT-nap]nat-policy testpolicyname nap-filter-group testfiltergroupname vpn-instance vpn1 action source-nat nat-address-pool poolnat1 destination-nat nat-address-pool poolnat2 priority 5
```
