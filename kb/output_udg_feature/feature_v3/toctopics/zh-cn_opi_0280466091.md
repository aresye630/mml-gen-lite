# BGP over静态路由+BFD(IPv4v6)

* 操作场景
* 必备事项
* 操作步骤
* 验证方法

## 操作场景

SDN场景，VNF和DC-GW间通过Loopback IP建立eBGP邻居，用于业务路由的学习和发布。Loopback IP之间通过静态路由互通。

## 必备事项

前提条件

* 请阅读并熟悉特性IPFD-014003 静态路由、IPFD-014002 支持BGP特性概述和IPFD-104403 BFD特性概述。
* 具备管理员权限的操作人员已经登录华为操作维护系统。
* VNF与网络实体之间的网络环境已经构建完成。

数据

* 本文以一组外联口子接口（对应一个逻辑接口）为例进行描述，实际场景需要配置多组外联口，请根据网设规划进行配置。
* 如下数据表中取值样例仅为举例，实际请按LLD文档中的规划值进行配置。“VPN实例名称（VRFNAME）”、“虚拟网卡ID（VNICID）”、“VLAN ID（VLANID）”、“BGP自治域号（ASNUM）”、“路由器ID（ROUTERID）”和IP地址等必须以LLD文档为准（执行命令前请再次核对），否则配置后可能导致无法DHCP获取到外联口IP，BGP引入WLR路由失败等。
* SDN场景，外联口IP从DHCP Server获取。开局或扩容场景，请确保DHCP Server的IP段内有足够的IP地址可以分配给VNF的外联口。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST: VRFNAME="VRF_Access";
   ADD VPNINSTAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni;
   MOD VPNINSTAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, VRFRD="10.10.10.78:100";
   ADD VPNINSTAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni;
   MOD VPNINSTAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, VRFRD="10.10.10.78:100";
   ```

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、BGP相关的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. DHCP分配IPv6地址时 （如：SDN场景），必须设置“DUID生成方式（DUIDTYPE）”为“MAC\_PLUS\_VLAN”。

   ```
   SET DHCP6CLIENTDUID: DUIDTYPE=MAC_PLUS_VLAN;
   ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      * 如果“自动配置开关”值为“TRUE”，需要执行4.b和4.c关闭自动配置开关。
      * 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到步骤 5。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 接口采用SR-IOV bonding组网时，添加以太网隧道多虚拟网卡自动化配置模板。

   ```
   ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1, VNICLIST="4 5";
   ```

   * 在SR-IOV Bonding组网场景下，必须配置该模板。非SR-IOV bonding组网场景下，请跳过本步骤。
   * 如果要实现SR-IOV接口bonding功能，那么一个Eth-trunk接口下的两个成员接口必须MAC相同，且ID号连续。即：“VNICLIST”中配置的ID号为MAC相同且连续的两个以太网接口的ID。可使用**LST INTERFACE**命令查询以太网接口的mac地址与以太网接口名称。
6. 配置外联口自动部署模板。

   * 非SR-IOV bonding组网场景下：

     ```
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v4", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=VNIC, VNICID=4, VLANID=100, NETWORKINSTID=0;  
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_200_v4", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=VNIC, VNICID=5, VLANID=200, NETWORKINSTID=0;
     ```

     ```
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v6", VPNNAME="VRF_Access", AFTYPE=IPv6, IPALLOCTYPE6=DHCP, AUTOCFGIFTYPE=VNIC, VNICID=4, VLANID=100, NETWORKINSTID=0, ADDRMODE=NETWOKSEGMENT_MODE;  
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_200_v6", VPNNAME="VRF_Access", AFTYPE=IPv6, IPALLOCTYPE6=DHCP, AUTOCFGIFTYPE=VNIC, VNICID=5, VLANID=200, NETWORKINSTID=0, ADDRMODE=NETWOKSEGMENT_MODE;
     ```
   * SR-IOV bonding组网场景下：

     ```
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v4", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=1, VLANID=100, NETWORKINSTID=0;  
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_200_v4", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=1, VLANID=200, NETWORKINSTID=0;
     ```

     ```
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v6", VPNNAME="VRF_Access", AFTYPE=IPv6, IPALLOCTYPE6=DHCP, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=1, VLANID=100, NETWORKINSTID=0, ADDRMODE=NETWOKSEGMENT_MODE;  
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_200_v6", VPNNAME="VRF_Access", AFTYPE=IPv6, IPALLOCTYPE6=DHCP, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=1, VLANID=200, NETWORKINSTID=0, ADDRMODE=NETWOKSEGMENT_MODE;
     ```

   * 如果规划外联口使用IPv4v6双栈地址，则分别执行该命令对同一vNIC配置IPv4和IPv6地址。
   * 外联口配置IPv6地址时，“ADDRMODE”必须设置为“NETWOKSEGMENT\_MODE”。
7. 增加BFD会话自动部署模板。

   “DESTADDR4”/“DESTADDR6”配置的是Leaf节点的IP地址，采用的是单臂BFD。

   ```
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_1", BFDTYPE=Static, SERVICENAME="ServName_Access_100_v4", IPVERSION=IPv4, DESTADDR4="10.10.85.130", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2", BFDTYPE=Static, SERVICENAME="ServName_Access_200_v4", IPVERSION=IPv4, DESTADDR4="10.10.90.130", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ```

   ```
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_3", BFDTYPE=Static, SERVICENAME="ServName_Access_100_v6", IPVERSION=IPv6, DESTADDR6="FC00::85:130", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_4", BFDTYPE=Static, SERVICENAME="ServName_Access_200_v6", IPVERSION=IPv6, DESTADDR6="FC00::90:130", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ```
8. 增加静态路由自动部署模板。

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="10.10.20.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_1";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_200_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="10.10.30.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_2";
   ```

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_1";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_200_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_2";
   ```

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="FC00::20:78", MASKLENGTH=128, NEXTHOPALLOCTYPE6=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_3";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_200_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="FC00::30:78", MASKLENGTH=128, NEXTHOPALLOCTYPE6=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_4";
   ```

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_100_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="0:0:0:0:0:0:0:0", MASKLENGTH=0, NEXTHOPALLOCTYPE6=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_3";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_200_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="0:0:0:0:0:0:0:0", MASKLENGTH=0, NEXTHOPALLOCTYPE6=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_4";
   ```
9. 打开自动部署开关。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```
10. 全局激活BGP。

    ```
    SET BGP: BGPENABLE=TRUE, ASNUM="60001";
    ```

    “ASNUM”参数若需要变更，则需先去使能BGP功能。去使能BGP时，BGP VPN实例等配置会被同步删除。必须按照LLD规划的“ASNUM”值进行配置。
11. 配置Loopback接口地址（BGP本端IP）。
    1. 配置Loopback接口。

       ```
       ADD INTERFACE: IFNAME="Loopback1";
       ```
    2. 配置接口绑定VPN。

       ```
       ADD IPBINDVPN: IFNAME="Loopback1", VRFNAME="VRF_Access";
       ```
    3. 配置接口IP地址。

       ```
       ADD IFIPV4ADDRESS:IFNAME="Loopback1",IFIPADDR="10.10.10.78",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
       ```

       ```
       SET IFIPV6ENABLE: IFNAME="Loopback1",ENABLEFLAG=TRUE;
       ADD IFIPV6ADDRESS: IFNAME="Loopback1", IPV6ADDRESS="FC00::10:78", PREFIXLEN=128;
       ```
12. 配置BGP。
    1. 增加BGP VPN实例。

       ```
       ADD BGPVRF: VRFNAME="VRF_Access", DEFAULTAFTYPE=noaf, ROUTERID="10.10.10.78";
       ```

       * 此处配置的“ROUTERID”是BGP VPN实例级别的ROUTERID。

         IPv4v6双栈时，IPv4 BGP VPN实例地址族和IPv6 BGP VPN实例地址族共用此处配置的“ROUTERID”值。
       * 已配置IPv4v6双栈的BGP VPN实例地址族，若需删除IPv4的BGP VPN实例地址族配置，则：

         1、删除IPv4的配置前需查询并记录“ROUTERID”值。

         2、删除IPv4的配置后需查询“ROUTERID”值是否存在，若不存在则需通过**MOD BGPVRF**命令将“ROUTERID”参数设置为删除IPv4的配置前记录的“ROUTERID”值。否则IPv6 BGP重新协商时会因无“ROUTERID”值可用而导致协商失败。
    2. 增加BGP VPN实例地址族。VNF对接两个负荷分担的BGP peer时，“MAXIMUMLOADBALANCE”设置为“2”。

       ```
       ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
       ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
       ```
    3. 增加BGP对等体。

       ```
       ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="10.10.20.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="10.10.30.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ```

       ```
       ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::20:78", REMOTEAS="60002", LOCALIFADDR="FC00::10:78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::30:78", REMOTEAS="60002", LOCALIFADDR="FC00::10:78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ```
    4. 增加BGP引入路由。

       ```
       ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
       ```

       ```
       ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
       ```

       由于BGP协议自身不能发现路由，所以需要引入其他协议的路由（如OSPF、静态路由或WLR等）注入到BGP路由表中，从而将这些路由在AS之内和AS之间传播。
    * 网设规划不开启下行入不转板，也不开启入不转板时，请跳过步骤 13~步骤 16。
    * 网设规划开启下行入不转板时，请执行步骤 13、步骤 14和步骤 16。
    * 网设规划开启入不转板时，请执行步骤 13、步骤 15和步骤 16。
13. 参考步骤 4，关闭自动配置开关。
14. 网设规划开启下行入不转板时，配置下行入不转板。否则，请跳过本步骤。

    * 仅N6/SGi接口需要配置，其他接口不需要配置。
    * 开启下行入不转板的命令是**SET DATAPLANEGIINFMODE**，不是**SET DATAPLANEINFMODE**。

      若误使用**SET DATAPLANEINFMODE**，则会上报ALM-81210 ISU或APU不可用告警。

    1. 开启下行入不转板开关。此处以开启路由增强功能为例。

       ```
       SET DATAPLANEGIINFMODE: MODE=RU, ROUTEENHANCEDSW=ENABLE;
       ```
    2. 开启路由增强功能时，修改BGP对等体地址族。

       开启路由增强功能时，必须将“ADVERTISECOMMUNITY”设置为“TRUE”。其他参数值此处仅为举例，请通过**LST BGPPEER**获取。

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.20.78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.30.78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="FC00::20:78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="FC00::30:78", ADVERTISECOMMUNITY=TRUE;
       ```
    3. 增加入不转板策略自动化配置模板。

       ```
       ADD AUTOSCALINGBGPLF: POLICYNAME="bgppolicy1_v4", IPVERSION=IPv4, SERVICENAME="ServName_Access_100_v4", PEERIP="10.10.20.78", PEERCOMMUNITY=1, UDADVCOMENABLE=TRUE, UDADVCOM="200";
       ```

       ```
       ADD AUTOSCALINGBGPLF: POLICYNAME="bgppolicy2_v4", IPVERSION=IPv4, SERVICENAME="ServName_Access_100_v4", PEERIP="10.10.30.78", PEERCOMMUNITY=1, UDADVCOMENABLE=TRUE, UDADVCOM="200";
       ```

       ```
       ADD AUTOSCALINGBGPLF: POLICYNAME="bgppolicy1_v6", IPVERSION=IPv6, SERVICENAME="ServName_Access_100_v6", PEERIPV6="FC00::20:78", PEERCOMMUNITY=1, UDADVCOMENABLE=TRUE, UDADVCOM="200";
       ```

       ```
       ADD AUTOSCALINGBGPLF: POLICYNAME="bgppolicy2_v6", IPVERSION=IPv6, SERVICENAME="ServName_Access_100_v6", PEERIPV6="FC00::30:78", PEERCOMMUNITY=1, UDADVCOMENABLE=TRUE, UDADVCOM="200";
       ```
    4. 增加IP可达性检测自动化配置模板。

       ```
       ADD AUTOSCALINGIPREACH: SERVICENAME="ServName_Access_100_v4", IPVERSION=IPv4, DESTADDR4="10.10.20.78", BFDTEMPLATENAME="BFD_1";
       ```

       ```
       ADD AUTOSCALINGIPREACH: SERVICENAME="ServName_Access_100_v4", IPVERSION=IPv4, DESTADDR4="10.10.30.78", BFDTEMPLATENAME="BFD_1";
       ```

       ```
       ADD AUTOSCALINGIPREACH: SERVICENAME="ServName_Access_100_v6", IPVERSION=IPv6, DESTADDR6="FC00::20:78", BFDTEMPLATENAME="BFD_3";
       ```

       ```
       ADD AUTOSCALINGIPREACH: SERVICENAME="ServName_Access_100_v6", IPVERSION=IPv6, DESTADDR6="FC00::30:78", BFDTEMPLATENAME="BFD_3";
       ```
15. 网设规划开启入不转板时，配置入不转板。否则，请跳过本步骤。

    * 仅如下逻辑接口对应的外联口需要配置，其他接口不需要配置。
      + s1-uif（S1-U）、n3if（N3）、saif（S1-U和N3）。
      + s5-sif（S5/S8-S）、n9cif（N9c）、scif（S5/S8-S和N9c）。
      + paif（N9a/S5-P/S8-P/S2b/Gn-U/Gp-U）。
    * 开启入不转板的命令是**SET DATAPLANEINFMODE**，不是**SET DATAPLANEGIINFMODE**。

      如误使用**SET DATAPLANEGIINFMODE**，则下行业务入不转板，上行业务入转板。

    1. 开启入不转板开关。此处以开启路由增强功能为例。

       ```
       SET DATAPLANEINFMODE: MODE=Instance, ROUTEENHANCEDSW=ENABLE;
       ```
    2. 将接口模板设置为在保护组上生效。

       //“ISBACKUP”设置为“TRUE”时，表示在保护组上生效；“ISBACKUP”设置为“FALSE”时，表示在非保护组上生效。

       ```
       MOD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v4", ISBACKUP=TRUE;
       ```

       ```
       MOD AUTOSCALINGSERVICE: SERVICENAME="ServName_Access_100_v6", ISBACKUP=TRUE;
       ```
    3. 开启路由增强功能时，修改BGP对等体地址族。

       开启路由增强功能时，必须将“ADVERTISECOMMUNITY”设置为“TRUE”。其他参数值此处仅为举例，请通过**LST BGPPEER**获取。

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.20.78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.30.78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="FC00::20:78", ADVERTISECOMMUNITY=TRUE;
       ```

       ```
       MOD BGPPEERAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="FC00::30:78", ADVERTISECOMMUNITY=TRUE;
       ```
    4. 增加入不转板策略自动化配置模板。


## 验证方法

IPv4单栈组网，不需要执行IPv6独有的检查。

IPv6单栈组网，不需要执行IPv4独有的检查。

IPv4v6双栈组网，如下检查均需要执行。

1. 执行命令**LST INTERFACE**命令，检查子接口是否生成。

   子接口的接口名格式为EthernetX/0/Y.Z，其中：Z取值是**ADD AUTOSCALINGSERVICE**配置中的“VLANID”值。

   子接口必须是某个存在的接口的子接口，EthernetX/0/Y接口在软件安装完成后已存在。

   * 子接口生成正常，请执行2。
   * 子接口生成异常，请联系华为技术支持工程师处理（例如检查软件安装是否正常等）。
2. 执行命令**LST IFIPV4ADDRESS**/**DSP IFIPV6ADDRESS**/**LST IPBINDVPN**，检查对应子接口上是否获取到IP地址及绑定的VPN是否与规划一致。

   本步骤的显示结果中的子接口与1中生成的子接口是否完全一致，且子接口均已存在IP地址。

   * 是，请执行4。
   * 否，请执行3。
3. 修改外联口自动部署模板。
   1. 关闭自动化配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=FALSE;
      ```
   2. 查询需要修改的外联口自动部署模板并记录服务名称、起始地址和结束地址等参数。

      ```
      LST AUTOSCALINGSERVICE:;
      ```
   3. 查询需要修改的子接口并记录查询结果。记录哪些接口的IP地址在3.b中记录的起始地址和结束地址范围内。

      ```
      LST IFIPV4ADDRESS:;
      ```

      ```
      DSP IFIPV6ADDRESS:;
      ```
   4. 查询需要修改的静态路由自动部署模板并记录服务名称、VPN实例名称、路由前缀、路由掩码长度和路由下一跳等参数。

      ```
      LST AUTOSCALINGSRROUTE:;
      ```
   5. 查询需要修改的静态路由并记录查询结果。通过和3.d中的记录结果对比，记录待删除的静态路由。

      ```
      LST SRROUTE:;
      ```

      ```
      LST SRROUTE6:;
      ```
   6. 删除3.c中记录的所有子接口。

      **RMV INTERFACE**

      IPv4v6双栈场景，删除子接口时，会同时删除IPv4和IPv6地址。
   7. 删除配置错误的静态路由。

      **RMV SRROUTE**/**RMV SRROUTE6**
   8. 删除配置错误的静态路由自动化配置模板。

      **RMV AUTOSCALINGSRROUTE**
   9. 删除配置错误的BFD自动化配置模板。

      **RMV AUTOSCALINGBFD**（BFD echo）/**RMV AUTOSCALINGSRBFD**（BFD双向检测）
   10. 删除配置错误的外联口自动化配置模板。

       **RMV AUTOSCALINGSERVICE**
   11. 重新配置外联口自动化配置模板。

       **ADD AUTOSCALINGSERVICE**
   12. 重新配置BFD自动化配置模板。

       **ADD AUTOSCALINGBFD**（BFD echo）/**ADD AUTOSCALINGSRBFD**（BFD双向检测）
   13. 配置静态路由自动化配置模板。

       **ADD AUTOSCALINGSRROUTE**
   14. 打开自动化配置开关。

       ```
       SET AUTOCONFIG: SWITCHFLAG=TRUE;
       ```

       修改配置后，请重新执行1。
4. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，请执行6。
   * 如果为其他状态，请执行5。
5. 执行**PING**命令，在VNF上检查VNF外联口IP与DC-GW接口IP之间是否路由可达。
   * 是，请执行11。
   * 否，请联系华为技术支持工程师处理（例如检查Leaf节点IP与VNF外联口IP是否路由可达，Leaf节点与DC-GW接口IP之间是否路由可达）。
6. 执行**PING**命令，在DC-GW上检查DC-GW与VNF Loopback接口IP之间是否路由可达。
   * 是，请执行7。
   * 否，请联系华为技术支持工程师处理（例如检查是否存在到VNF BGP IP的路由，下一跳分别是VNF的负荷分担关系的每个外联口的IP）。
7. 执行**PING**命令，在VNF上检查VNF BGP本端IP与BGPPEER IP之间是否路由可达。

   需要在VNF上分别PING BGP PEER IP，出接口是VNF上负荷分担关系的每个子接口，且能PING通。

   * 是，请执行8。
   * 否，请联系华为技术支持工程师处理。
8. 执行**DSP BGPPEERINFO**命令，检查BGP对等体条数是否正确及BGP对等体状态是否为Established。

   本步骤的显示结果中的BGP对等体的条数与LST BGPPEER中查询的对等体的条数相等，且“对等体状态”为“Established”。

   * 是且未开启入不转板功能，调测结束。
   * 是且开启了入不转板功能，请执行9。
   * 否，请执行11。
9. 开启入不转板功能时，查看BGP入不转板自动部署模板配置是否与规划数据一致。
   * 一致，请执行10。
   * 不一致，请参考如下子步骤修改BGP入不转板自动部署模板。

   BGP入不转板自动部署模板的“策略名称”参数取值以“bgppolicy1”为例，实际请执行**LST AUTOSCALINGBGPLF**命令获取。
