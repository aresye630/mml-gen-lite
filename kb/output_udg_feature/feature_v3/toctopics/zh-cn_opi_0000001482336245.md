# 激活网络加速卡流量加速单元

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

在UDG上开启特性的License开关激活网络加速卡流量加速单元。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-111201 网络加速卡流量加速单元特性概述。
* 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。

数据

无。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

在UDG上开启本特性的License开关，激活网络加速卡流量加速单元。

脚本

```
SET LICENSESWITCH: LICITEM="LKV3G5NPTO01", SWITCH=ENABLE;
```
