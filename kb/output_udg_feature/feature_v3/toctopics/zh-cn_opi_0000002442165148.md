# 配置专用DNN策略数据

* 操作场景
* 必备事项
* 任务示例

## 操作场景

对于专用DNN（stjwt.gd）接入场景，需要将已配置的增值类业务改造为专网业务，并在PCF配置园区RG预定义规则、DNS重定向预定义规则，预定义规则名称需要与对端SMF网元协商一致。

## 必备事项

前提条件

* 已完成通用DNN数据配置，专网用户已签约业务MulDNN\_Service01。
* 确认园区RG预定义规则、DNS重定向预定义规则标识，与对端SMF协商一致。

数据

PCF给专用DNN下发园区RG预定义规则、DNS重定向预定义规则，业务配置关系如表1所示。

**表1** 配置关系解释

| 名称 |  |  | 需求分解 | 基本原则 |
| --- | --- | --- | --- | --- |
| 业务MulDNN\_Service01 |  |  | 此业务为PCF下发的专网业务，业务类型为INTRANET\_SERVICE（专网业务），包含以下参数：   * 专网会话隔离条件组：用户携带专用DNN（stjwt.gd）上线。 * 策略：MulDNN\_Policy01。 | 已在配置通用DNN策略数据配置，本章节将配置的VALUE\_ADDED\_SERVICE类型业务改造为INTRANET\_SERVICE业务。  专网业务必须配置“专网会话隔离条件组”，对于满足此条件的会话，PCF仅下发专网业务，不下发大网业务。“专网会话隔离条件组”仅支持关联SmfSession下的DNN列表（SmfSession.DNNList）、DNN对象(SmfSession.Dnn)、切片条件（SmfSession.SnssaiSst，SmfSession.SnssaiSd）。  说明：  如果没有任一专网业务的隔离条件匹配上，则所有专网业务都视为普通业务，都可以生效。 |
| 策略MulDNN\_Policy01 |  |  | 此策略在用户上线时被调用，触发器为IPCAN\_EST，已包含规则MulDNN\_Rule01，新增PrePCC\_Rule01、PrePCC\_Rule02。 | 已在配置通用DNN策略数据完成配置。 |
| 规则PrePCC\_Rule01 |  |  | * 条件组：用户携带stjwt.gd上线。 * 5G动作组：PrePCC\_5GAG01，用于关联园区计费费率预定义规则相关动作参数信息。 | 可选配置，在PCF需要下发预定义规则时需要配置。预定义规则名称需提前与对端SMF协商配置一致，具体上下行带宽控制规则由SMF进行配置。 |
| 规则PrePCC\_Rule02 |  |  | * 条件组：用户携带stjwt.gd上线。 * 5G动作组：PrePCC\_5GAG02，用于关联DNS重定向预定义规则相关动作参数信息。 | 可选配置，在PCF需要下发预定义规则时需要配置。预定义规则名称需提前与对端SMF协商配置一致，具体上下行带宽控制规则由SMF进行配置。 |

预定义规则的条件组参数和5G动作组参数规划如表2所示。

**表2** 预定义规则数据规划

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ADD CONDITION | 对象属性 | * 对象：SmfSession * 属性：Dnn | - | UPCF WebUI配置项。 |
|  | 右值 | stjwt.gd | 全网规划 | 用于设置归属地园区专用DNN信息。当用户从此DNN接入时，触发PCF下发园区RG预定义规则及DNS重定向预定义规则。  取值范围：长度为1～64的字符串。 |
| ADD NGACTIONATTR | 名称  （预定义规则标识01） | pccRuleId | - | UPCF WebUI配置项。 |
|  | 值 | u\_p\_multi\_default | 全网规划 | 用于控制园区的费率，实际费率按照园区客户规划决定。  取值范围：长度为1～128的字符串，且不能输入的特殊字符为<>[]%&"+=,;/'  说明：  * 当园区计费采用缺省费率时，PCF基于园区DNN信息，下发u\_p\_multi\_default。该预定义规则在SMF和UPF均需要配置。 * 当园区计费采用特定费率时，PCF基于园区DNN信息，下发u\_p\_<01>\_multi。其中<01>是变量，基于费率的不同而变化，该预定义规则在SMF和UPF均需要同步配置。 |
|  | 名称  （预定义规则标识02） | pccRuleId | - | UPCF WebUI配置项。 |
|  | 值 | u\_p\_enterprise\_dns | 全网规划 | 用于控制DNS重定向。  取值范围：长度为1～128的字符串，且不能输入的特殊字符为<>[]%&"+=,;/'  说明：  当园区有DNS重定向动作时，PCF基于园区DNN信息，下发u\_p\_<enterprise>\_dns。其中<enterprise>建议为企业业务缩写，该预定义规则在SMF和UPF均需要同步配置。 |

## 任务示例

任务描述

本章节将配置通用DNN策略数据已配置的业务（MulDNN\_Service01）类型修改为专网业务，将专用DNN（stjwt.gd）添加至专网会话隔离条件组，对于匹配上的专用DNN仅能下发专网业务。同时配置针对专用DNN（stjwt.gd）下发的园区RG预定义规则、园区DNS重定向预定义规则，并添加至配置通用DNN策略数据已配置的策略MulDNN\_Policy01中。

脚本

登录UPCF WebUI界面进行业务配置，在“系统管理 > 批处理 > CLI导入”界面执行以下CLI命令。

1. 添加专网会话隔离条件组（Intranet\_CG01），用户携带专用DNN（stjwt.gd）上线。此处操作符OPERATOR支持选择Equal、Not Equal、Like、Matchpostfix等。对于满足此条件的会话，PCF仅下发专网业务，不下发大网业务。

   ```
   ADD CONDITIONGROUP:CONDITIONGROUPNAME="Intranet_CG01",RELATION=OR,USETIMEZONE=No;
   ADD CONDITION:CONDITIONGROUPNAME="Intranet_CG01",CONDITIONNAME="Intranet_C01",OBJECTATTRIBUTE="SmfSession.Dnn",OPERATOR=Equal,RIGHTVALUETYPE=Value,RIGHTVALUE="stjwt.gd";
   ```
2. 将配置通用DNN策略数据已配置的业务MulDNN\_Service01改造为专网业务，改造后的业务类型为INTRANET\_SERVICE，同时关联1中配置的专网会话隔离条件组。

   ```
   MOD SERVICE:SERVICENAME="MulDNN_Service01",ISSETSHAREDMODE=Yes,SHAREDMODE=NotShared,SERVICETYPE=INTRANET_SERVICE,DEDICATEDSRVCONGRP="Intranet_CG01";
   ```
3. 添加5G动作组（PrePCC\_5GAG01）及动作组子参数。

   ```
   ADD NGACTION:ACTIONNAME="PrePCC_5GAG01",TYPE="PredefinedPccRule";
   ADD NGACTIONATTR:ACTIONNAME="PrePCC_5GAG01",ATTRNAME="pccRuleId",TYPE=Value,VALUE="u_p_multi_default";
   ```
4. 添加园区RG预定义规则（PrePCC\_Rule01），用于关联1配置的条件组和3配置的动作组。

   ```
   ADD RULE:RULENAME="PrePCC_Rule01",TYPE=Smf Pcc Rule 5G,PRECEDENCE=0,VOLUMEUSAGEROUNDING=No,EDR=OFF,RELATION=AND;
   ADD RULECONDITIONGROUP:RULENAME="PrePCC_Rule01",CONDITIONGROUPNAME="Intranet_CG01";
   ADD RULENGACTION:RULENAME="PrePCC_Rule01",ACTIONNAME="PrePCC_5GAG01";
   ```
5. 添加5G动作组（PrePCC\_5GAG02）及动作组子参数。

   ```
   ADD NGACTION:ACTIONNAME="PrePCC_5GAG02",TYPE="PredefinedPccRule";
   ADD NGACTIONATTR:ACTIONNAME="PrePCC_5GAG02",ATTRNAME="pccRuleId",TYPE=Value,VALUE="u_p_enterprise_dns";
   ```
6. 添加DNS重定向预定义规则（PrePCC\_Rule02），用于关联1配置的条件组和5配置的动作组。

   ```
   ADD RULE:RULENAME="PrePCC_Rule02",TYPE=Smf Pcc Rule 5G,PRECEDENCE=0,VOLUMEUSAGEROUNDING=No,EDR=OFF,RELATION=AND;
   ADD RULECONDITIONGROUP:RULENAME="PrePCC_Rule02",CONDITIONGROUPNAME="Intranet_CG01";
   ADD RULENGACTION:RULENAME="PrePCC_Rule02",ACTIONNAME="PrePCC_5GAG02";
   ```
7. 将预定义规则关联到已配置的通用DNN策略中。策略MulDNN\_Policy01已在配置通用DNN策略数据完成配置。

   ```
   ADD POLICYRULE:POLICYNAME="MulDNN_Policy01",RULENAME="PrePCC_Rule01";
   ADD POLICYRULE:POLICYNAME="MulDNN_Policy01",RULENAME="PrePCC_Rule02";
   ```

   此为新增的CLI脚本，需叠加至配置通用DNN策略数据已配置的脚本中。
