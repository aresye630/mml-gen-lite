# 配置SWm接口对接数据（DRA转接）

* 操作场景
* 对系统的影响
* 必备事项
* 任务示例

## 操作场景

UPF与Non-SIM AAA UDM-UIM间存在直连、非直连路径。图1表示经DRA的非直连路径。

**图1** DRA组网

当UPF与Non-SIM AAA之间直连路径故障或者未配置直连路径时，可以配置到DRA，DRA在UPF与Non-SIM AAA间转交消息，提供非3GPP鉴权认证功能。UPF与Non-SIM AAA交互时，优先选择直连路径发送消息。

* SWm接口当前版本仅支持IPv4栈类型。
* 专网UPF配置SWm接口时，不支持开启入不转板功能特性。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* UPF软件安装已完成。
* UPF初始配置已完成。
* 已完成一跳入家依赖功能的License加载。
* 已完成一跳入家要求的移动VPN相关配置。

## 任务示例

任务描述

UPF到DRA的数据配置。

VPN和路由的配置操作流程与UDG产品的初始配置流程基本相同，详细配置步骤请参见“UDG产品文档”>“网络部署”>“初始配置”手册。

**任务1**：TCP over DRA配置。

**任务2**：SCTP over DRA配置。

脚本

**任务1，TCP over DRA配置脚本：**

1. 创建VPN实例。可选配置，如果已配置VPN跳过此步骤。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_Signaling";
   ADD L3VPNINST: VRFNAME="VPN_Signaling";
   ADD VPNINSTAF: VRFNAME="VPN_Signaling", AFTYPE=ipv4uni;
   ```
2. 配置SWm逻辑接口，VPN实例名称为VPN\_Signaling。

   ```
   ADD LOGICINF: NAME="swmif1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="192.168.3.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_Signaling";
   ```
3. 配置SWm接口的集中点模式为本端端口模式。

   ```
   SET UPCONCENPOINT: SWMCONCENMODE=LOCALPORT;
   ```
4. 配置DRA数据。配置DRA主机名以及地址信息。

   ```
   ADD UPDRA: HOSTNAME="dra01.huawei.com", VPNINSTANCE="VPN_Signaling";
   ADD UPDRA: HOSTNAME="dra02.huawei.com", VPNINSTANCE="VPN_Signaling";
   ADD UPDIAMPEERADDR: HOSTNAME="dra01.huawei.com", ADDRTYPE=IPv4, IPV4ADDRESS="172.17.251.66", PORT=3868;
   ADD UPDIAMPEERADDR: HOSTNAME="dra02.huawei.com", ADDRTYPE=IPv4, IPV4ADDRESS="172.17.251.106", PORT=3868;
   ```
5. 配置对接数据。
   1. 配置本端端点的主机信息。

      ```
      ADD UPDIAMLOCINFO: HOSTNAME="udg_1", REALMNAME="peer.huawei.com", PRODUCTNAME="udg@huawei.com", ORIGINSTATEID=DISABLE, SUPPORTVENDORID=DISABLE;
      ```
   2. 配置网元对接。

      ```
      ADD UPDIAMCONNGRP:CONNGROUPNAME="udgaaagrp1", LOCALHOSTNAME="udg_1", APPLICATION=SWM, PEERHOSTNAME="dra01.huawei.com", SELECTMODE=SESSION_ID;
      ADD UPDIAMCONNGRP:CONNGROUPNAME="udgaaagrp2", LOCALHOSTNAME="udg_1", APPLICATION=SWM, PEERHOSTNAME="dra02.huawei.com", SELECTMODE=SESSION_ID;
      ADD UPDIAMCONN: DIAMCONNGRP="udgaaagrp1", LOCINTERFACE="swmif1/0/0", PEERADDRTYPE=IPv4, PEERIPV4ADDR="172.16.251.66", PEERPORT=3868, LOCALPORT=19865;
      ADD UPDIAMCONN: DIAMCONNGRP="udgaaagrp2", LOCINTERFACE="swmif1/0/0", PEERADDRTYPE=IPv4, PEERIPV4ADDR="172.16.251.106", PEERPORT=3868, LOCALPORT=19865;
      ADD UPDIAMRTREALM:REALMNAME="huawei.com", APPLICATION=SWM, SELECTMODE=SESSION_ID, FAILOVERSW=DISABLE, AUTOFAILBACKSW=DISABLE;
      ADD UPDIAMRTNEXTHOP:REALMNAME="huawei.com", APPLICATION=SWM, NEXTHOP="dra01.huawei.com", SEQUENCE=1;
      ADD UPDIAMRTNEXTHOP:REALMNAME="huawei.com", APPLICATION=SWM, NEXTHOP="dra02.huawei.com", SEQUENCE=2;
      ```
6. 配置会话激活路由选取方式。
   1. 开启路由功能开关。

      ```
      SET UPDIAMETERPARA: REALMBASEROUTE=ENABLE;
      ```
   2. 选取路由。选取路由时，基于APN选路配置比基于全局配置的优先级高。
      1. 基于全局配置选取路由。

         ```
         ADD UPGLBDIAMREALM: APPLICATION=SWM, CONSTBYIMSISW=DISABLE, REALM="huawei.com";
         ```
      2. 基于APN配置选取路由。

         增加APN。同一个APN只能配置TCP/SCTP中的一种场景，不允许两种场景同时配置到同一APN下。

         ```
         ADD APN: APN="032apn1.com";
         ```

         基于APN绑定关系选取路由。

         ```
         ADD UPREALMBINDAPN: APN="032apn1.com", APPLICATION=SWM, CONSTBYIMSISW=DISABLE, REALMNAME="huawei.com";
         ```

**任务2，SCTP over DRA配置脚本：**

1. 创建VPN实例。可选配置，如果已配置VPN跳过此步骤。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_Signaling";
   ADD L3VPNINST: VRFNAME="VPN_Signaling";
   ADD VPNINSTAF: VRFNAME="VPN_Signaling", AFTYPE=ipv4uni;
   ```
2. 配置SWm逻辑接口，VPN实例名称为VPN\_Signaling。

   ```
   ADD LOGICINF:NAME="swmif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="192.168.3.1",IPV4MASK1="255.255.255.255",IPV4ADDRESS2="192.168.3.2",IPV4MASK2="255.255.255.255",VPNINSTANCE="VPN_Signaling";
   ```
3. 配置SWm接口的集中点模式为本端端口模式。

   ```
   SET UPCONCENPOINT: SWMCONCENMODE=LOCALPORT;
   ```
4. 配置DRA数据。
   1. 配置SCTP模板参数。

      ```
      ADD UPSCTPTEMPLATE: SCTPTEMPLNAME="dra_template",HEARTBEATINTVAL=30000,MAXASSOCRETRY=5,MAXPATHRETRY=4,CHECKSUMTYPE=CRC32;
      ```
   2. 配置SCTP端点信息，并将模板分别与SCTP端点绑定。

      ```
      ADD UPSCTPENDPOINT: ENDPOINTNAME="endpoint0", IPVERSION=IPV4, IPV4ADDRESS1="192.168.10.1", IPV4ADDRESS2="192.168.10.2", PORT=3868, SCTPTEMPLNAME="dra_template";
      ADD UPSCTPENDPOINT: ENDPOINTNAME="endpoint1", IPVERSION=IPV4, IPV4ADDRESS1="192.168.20.1", IPV4ADDRESS2="192.168.20.2", PORT=3868, SCTPTEMPLNAME="dra_template";
      ```
   3. 配置SCTP重传超时（RTO，Retransmission Time-Out）参数和SCTP偶联内使用路径的模式。

      ```
      SET UPGLBSCTPPARA: PATHSELECTMODE=ALL, RTOMINVALUE=500, RTOMAXVALUE=1500, RTOINITVALUE=500;
      ```
   4. 配置DRA主机名以及地址信息。

      ```
      ADD UPDRA: HOSTNAME="dra01.huawei.com", VPNINSTANCE="VPN_Signaling";
      ADD UPDRA: HOSTNAME="dra02.huawei.com", VPNINSTANCE="VPN_Signaling";
      ADD UPDIAMPEERADDR: HOSTNAME="dra01.huawei.com", ADDRTYPE=SCTP, SCTPENDPOINT="endpoint0";
      ADD UPDIAMPEERADDR: HOSTNAME="dra02.huawei.com", ADDRTYPE=SCTP, SCTPENDPOINT="endpoint1";
      ```
5. 配置对接数据。
   1. 配置本端端点的主机信息。

      ```
      ADD UPDIAMLOCINFO: HOSTNAME="udg_1", REALMNAME="peer.huawei.com", PRODUCTNAME="udg@huawei.com", ORIGINSTATEID=DISABLE, SUPPORTVENDORID=DISABLE;
      ```
   2. 配置网元对接。

      ```
      ADD UPDIAMCONNGRP:CONNGROUPNAME="udgaaagrp1", LOCALHOSTNAME="udg_1", APPLICATION=SWM, PEERHOSTNAME="dra01.huawei.com", SELECTMODE=SESSION_ID;
      ADD UPDIAMCONNGRP:CONNGROUPNAME="udgaaagrp2", LOCALHOSTNAME="udg_1", APPLICATION=SWM, PEERHOSTNAME="dra02.huawei.com", SELECTMODE=SESSION_ID;
      ADD UPDIAMCONN: DIAMCONNGRP="udgaaagrp1", LOCINTERFACE="swmif1/0/0", PEERADDRTYPE=SCTP, PEERSCTPENDPT="endpoint0", REVERSEIP=DISABLE, LOCALPORT=19865;
      ADD UPDIAMCONN: DIAMCONNGRP="udgaaagrp2", LOCINTERFACE="swmif1/0/0", PEERADDRTYPE=SCTP, PEERSCTPENDPT="endpoint0", REVERSEIP=DISABLE, LOCALPORT=19865;
      ```
