## 操作场景

SDN场景，UDG与企业网对接时，由于企业APN数量多，且各个企业APN之间有业务隔离诉求，故可采用BGP/MPLS VPN组网。UDG作为PE设备接入MPLS骨干网，通过MP-EBGP（Multi-protocol Extensions for Border Gateway Protocol）与其他PE之间传播VPN信息和VPN-IPv4路由。UDG采用OptionB方式实现跨域VPN。

如图1所示，UDG和PE间通过Loopback IP建立eBGP邻居，用于交换私网VPN路由。Loopback IP之间通过静态路由/OSPF互通。

## 必备事项

前提条件

* 请阅读并熟悉特性GWFD-020411 MPLS VPN、IPFD-014002 支持BGP和IPFD-012003 BFD特性概述。
* 具备管理员权限的操作人员已经登录华为操作维护系统。
* UDG与网络实体之间的网络环境已经构建完成。

VM扩容场景，需要将新扩容的VM上的相关接口，配置为MPLS接口。

* 扩容前通过**ADD MPLSIF**命令手动添加为MPLS接口时，仍需要手动将新扩容的VM上新增的接口通过**ADD MPLSIF**命令手动添加为MPLS接口。例如，新扩容的VM上新增了Eth-trunk6801.100用于传输MPLS报文，则需要通过**ADD MPLSIF**命令将Eth-trunk6801.100配置为MPLS接口。
* 扩容前通过**ADD AUTOSCALINGMPLS**命令自动生成MPLS接口时，不需要通过**ADD MPLSIF**命令手动将新增的接口添加为MPLS接口。**ADD AUTOSCALINGMPLS**命令会自动将新增加的接口添加为MPLS接口。

## 操作步骤

1. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 全局激活BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```

   “ASNUM”参数若需要变更，则需先去使能BGP功能。去使能BGP时，BGP VPN实例等配置会被同步删除。必须按照LLD规划的“ASNUM”值进行配置。
3. 配置MPLS全局配置。

   ```
   SET MPLSSITE: MPLSLSRID="10.10.10.78", MPLSENABLE=ENABLE, LDPENABLE=DISABLE;
   ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      * 如果“自动配置开关”值为“TRUE”，需要执行4.b和4.c关闭自动配置开关。
      * 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到步骤 5。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 接口采用SR-IOV bonding组网时，添加以太网隧道多虚拟网卡自动化配置模板。

   ```
   ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1, VNICLIST="4 5";
   ```

   * 在SR-IOV Bonding组网场景下，必须配置该模板。非SR-IOV bonding组网场景下，请跳过本步骤。
   * 如果要实现SR-IOV接口bonding功能，那么一个Eth-trunk接口下的两个成员接口必须MAC相同，且ID号连续。即：“VNICLIST”中配置的ID号为MAC相同且连续的两个以太网接口的ID。可使用**LST INTERFACE**命令查询以太网接口的MAC地址与以太网接口名称。
6. 配置外联口自动部署模板。

   * 非SR-IOV bonding组网场景下：

     ```
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_N6_100", VPNNAME="_public_", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, AUTOCFGIFTYPE=VNIC, VNICID=4, VLANID=100, BEGINADDR4="192.168.89.2", ENDADDR4="192.168.89.126", MASKLEN=25;  
     ADD AUTOSCALINGSERVICE: SERVICENAME="ServName_N6_200", VPNNAME="_public_", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, AUTOCFGIFTYPE=VNIC, VNICID=5, VLANID=200, BEGINADDR4="192.168.89.130", ENDADDR4="192.168.89.254", MASKLEN=25;
     ```
   * SR-IOV bonding组网场景下：


## 验证方法

1. 执行命令**LST INTERFACE**命令，检查子接口是否生成。

   子接口的接口名格式为EthernetX/0/Y.Z，其中：Z取值是**ADD AUTOSCALINGSERVICE**配置中的“VLANID”值。

   子接口必须是某个存在的接口的子接口，EthernetX/0/Y接口在软件安装完成后已存在。

   * 子接口生成正常，请执行2。
   * 子接口生成异常，请联系华为技术支持工程师处理（例如检查软件安装是否正常等）。
2. 执行命令**LST IFIPV4ADDRESS**，检查对应子接口上是否获取到IP地址及绑定的VPN是否为“\_public\_”。

   本步骤的显示结果中的子接口与1中生成的子接口是否完全一致，且子接口均已存在IP地址。

   * 是，请执行4。
   * 否，请执行3。
3. 修改外联口自动部署模板。
   1. 关闭自动化配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=FALSE;
      ```
   2. 查询需要修改的外联口自动部署模板并记录服务名称、起始地址和结束地址等参数。

      ```
      LST AUTOSCALINGSERVICE:;
      ```
   3. 查询需要修改的子接口并记录查询结果。记录哪些接口的IP地址在3.b中记录的起始地址和结束地址范围内。

      ```
      LST IFIPV4ADDRESS:;
      ```
   4. 查询需要修改的静态路由自动部署模板并记录服务名称、VPN实例名称、路由前缀、路由掩码长度和路由下一跳等参数。

      ```
      LST AUTOSCALINGSRROUTE:;
      ```
   5. 查询需要修改的静态路由并记录查询结果。通过和3.d中的记录结果对比，记录待删除的静态路由。

      ```
      LST SRROUTE:;
      ```
   6. 删除3.c中记录的所有子接口。

      **RMV INTERFACE**
   7. 删除配置错误的静态路由。

      **RMV SRROUTE**
   8. 删除配置错误的静态路由自动化配置模板。

      **RMV AUTOSCALINGSRROUTE**
   9. 删除配置错误的BFD自动化配置模板。

      **RMV AUTOSCALINGBFD**（BFD echo）
   10. 删除配置错误的外联口自动化配置模板。

       **RMV AUTOSCALINGSERVICE**
   11. 重新配置外联口自动化配置模板。

       **ADD AUTOSCALINGSERVICE**
   12. 重新配置BFD自动化配置模板。

       **ADD AUTOSCALINGBFD**（BFD echo）
   13. 配置静态路由自动化配置模板。

       **ADD AUTOSCALINGSRROUTE**
   14. 打开自动化配置开关。

       ```
       SET AUTOCONFIG: SWITCHFLAG=TRUE;
       ```

       修改配置后，请重新执行1。
4. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，请执行6。
   * 如果为其他状态，请执行5。
5. 执行**PING**命令，在VNF上检查VNF外联口IP与网关设备（如PE/DC-GW）接口IP之间是否路由可达。
   * 是，请执行6。
   * 否，请联系华为技术支持工程师处理。
6. 执行**PING**命令，在网关设备（如PE/DC-GW）上检查网关设备接口IP与VNF Loopback接口IP之间是否路由可达。
   * 是，请执行7。
   * 否，请联系华为技术支持工程师处理。
7. 执行**PING**命令，在VNF上检查VNF BGP本端IP与BGPPEER IP之间是否路由可达。

   需要在VNF上分别PING BGP PEER IP，出接口是VNF上负荷分担关系的每个子接口，且能PING通。

   * 是，请执行8。
   * 否，请联系华为技术支持工程师处理。
8. 执行**DSP BGPPEERINFO**命令，检查BGP对等体条数是否正确及BGP对等体状态是否为Established。

   本步骤的显示结果中的BGP对等体的条数与LST BGPPEER中查询的对等体的条数相等，且“对等体状态”为“Established”。

   * 是，调测结束。
   * 否，请执行9。
9. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
