## 操作场景

当需要在报表服务器上查询UDG的各种业务报表时，需要在UDG上激活业务报表功能。激活此功能后，在报表服务器上可基于APN、位置、用户、应用、终端、服务器、接入网多个维度对业务做流量分析或者TOPN分析，满足运营商对网络可视化的需求。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-111301 智能分析记录生成、GWFD-111302 业务全样分析上报、GWFD-111303 阻塞流量分析上报、GWFD-111304 TCP/UDP传输分析上报、GWFD-111305 用户实时位置分析上报、GWFD-111306 VOIP业务分析上报、GWFD-111307 Web业务分析上报、GWFD-111308 VoLTE业务质量上报、GWFD-111309 PCC规则报表上报、GWFD-111310 QUIC业务分析上报、GWFD-111311 业务分析上报订阅、GWFD-111312 系统级智能分析记录生成、GWFD-111313 业务实时分析上报、GWFD-111315 VoNR业务质量上报。
* 完成业务感知配置。
* 完成配置到报表服务器的数据。
* 完成**加载license**（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 配置智能分析记录生成/业务全样分析上报/阻塞流量分析上报/TCP/UDP传输分析上报/用户实时位置分析上报/VOIP业务分析上报/Web业务分析上报/VoLTE业务质量上报/PCC规则报表/QUIC业务分析上报/业务分析上报订阅/系统级智能分析记录生成/业务实时分析上报/VoNR业务质量上报等特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置全局报表功能开关。

   **SET RPTGLBCFG**
3. 配置指定策略的业务报表功能开关。

   **ADD RPTPOLICY**

   在报表功能开关被关闭的情况下，所有报表配置都将无效，所以要开启此特性，需要使用**SET RPTGLBCFG**和**ADD RPTPOLICY**命令打开报表功能开关。
4. 配置流抽样率。

   **SET RPTGLBPARA**

   * 当业务全样分析上报特性的License开关关闭时，缺省抽样率为10%，当**SET RPTGLBPARA**命令配置的抽样率超过10%时，则按照抽样率为10%进行抽样，配置的抽样率小于10%时就按照命令配置的抽样率进行抽样。
   * 当业务全样分析上报特性的License开关打开时，按照**SET RPTGLBPARA**命令配置的抽样率进行抽样。
5. **可选：**配置在QUIC SA协议识别状态确定后进行策略匹配的开关。

   **SET SACOMMONPARA**
6. 设置基础单据上报配置开关。

   **SET RPTBASICRECCFG**
7. **可选：**开启VoLTE业务质量上报功能。
   1. 开启VoLTE业务质量检测功能。

      **SET APNVOLTEMONFUNC**
   2. **可选：**开启VoLTE吞字断续检测和上报功能。

      **SET VOLTESWALBRK**
   3. **可选：**开启单通检测功能。

      **SET VOLTEONEWAYSIL**
8. **可选：**开启VoNR业务质量上报功能。
   1. 设置VoNR语音质量监控功能开关。

      **SET APNVONRMONFUNC**
   2. **可选：**指定MOS值的异常门限值。

      **SET VONRABNORMOS**
   3. **可选：**配置MOS分类的区间值。

      **SET VONRMOSCLASS**
   4. **可选：**设置MOS计算值的补偿因子。

      **SET VONRMOSFACTOR**
   5. **可选：**设置单通检测信息。

      **SET VONRONEWAYSIL**
   6. **可选：**配置理想到达报文的最小时延偏差、固定传输时延。

      **SET VONRPERFTDELAY**
   7. **可选：**设置VoLTE滑窗相关的参数。

      **SET VONRSWALBRK**
9. 可选：配置软参“BIT1557”为1，向CloudUDN上报的报表UFDR单据包含Charging TLV、QoS TLV、Charging\_ID TLV、GTP\_Path TLV相关字段。

   **SET SOFTPARA**

## 任务示例

任务描述

UDG完成网络或者用户业务基本信息的采集，生成网络或者用户业务使用信息的基本数据记录。通过与报表服务器之间的私有Grp接口上报业务信息记录给外部的报表服务器。

脚本

1. 配置智能分析记录生成功能开关

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5IARG01",SWITCH=ENABLE;
   ```
2. **可选：**配置业务全样分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5FSFR01",SWITCH=ENABLE;
   ```
3. **可选：**配置阻塞流量分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5TTIR01",SWITCH=ENABLE;
   ```
4. **可选：**配置TCP/UDP传输分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5TDIR01",SWITCH=ENABLE;
   ```
5. **可选：**配置用户实时位置分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5RSLR01",SWITCH=ENABLE;
   ```
6. **可选：**配置VOIP业务分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5VOIR01",SWITCH=ENABLE;
   ```
7. **可选：**配置Web业务分析上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5WBIR01",SWITCH=ENABLE;
   ```
8. **可选：**配置VoLTE业务质量上报功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5VOSR01",SWITCH=ENABLE;
   ```
9. **可选：**配置PCC规则报表功能。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5PCRR01",SWITCH=ENABLE;
   ```
10. **可选：**配置QUIC业务分析上报功能。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5RPQC01",SWITCH=ENABLE;
    ```
11. **可选：**配置业务分析上报订阅功能。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5SARS01",SWITCH=ENABLE;
    ```
12. **可选：**配置系统级智能分析记录生成功能。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5RTSR01",SWITCH=ENABLE;
    ```
13. **可选：**配置业务实时分析上报功能。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5SIAR01",SWITCH=ENABLE;
    ```
14. **可选：**VoNR业务质量上报功能。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5VRSR01",SWITCH=ENABLE;
    ```
15. 配置全局报表功能开关。

    ```
    SET RPTGLBCFG:GLOBALSWITCH=ENABLE,DNSINSIGHTSW=ENABLE,TCPINSIGHTSW=ENABLE,UDPINSIGHTSW=ENABLE,SUBSPOLICYSW=ENABLE,SUBSCONFIGSW=ENABLE,CACHESW=ENABLE,SIPINSIGHTSW=ENABLE,VOLTEINSIGHTSW=ENABLE,VONRINSIGHTSW=ENABLE;
    ```
16. 配置指定策略的业务报表功能开关。

    ```
    ADD RPTPOLICY:POLICYNAME="policy01",SWITCH=ENABLE,USERSELPLYTYPE=ANY;
    ```
17. 配置抽样率。

    ```
    SET RPTGLBPARA:FLOWSAMPLERATE=1000,NEID=1,TCPINSIGHTSAMRT=1000;
    ```
18. **可选：**配置在QUIC SA协议识别状态确定后进行策略匹配的开关。

    ```
    SET SACOMMONPARA:QUICSASW=ENABLE;
    ```
19. 设置基础单据上报配置开关。

    ```
    SET RPTBASICRECCFG：USERINFOSW = ENABLE;
    ```
20. **可选：**开启VoLTE业务质量上报功能。

    ```
    SET APNVOLTEMONFUNC: APN="apn.internet", SWITCH=ENABLE;
    ```
21. **可选：**开启VoNR业务质量上报功能。

    ```
    SET APNVONRMONFUNC: APN="apn.internet", SWITCH=ENABLE;
    ```
22. **可选：**配置软参“BIT1557”为1，向CloudUDN上报的报表UFDR单据包含Charging TLV、QoS TLV、Charging\_ID TLV、GTP\_Path TLV相关字段。

    ```
    SET SOFTPARA:DT=BIT,BITNUM=1557,BITVALUE=1;
    ```
