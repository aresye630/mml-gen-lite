# 基于OSPF路由自动部署融合UDG配置实例（IPv4）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本任务实例实现以下场景配置：

UDG与对端设备（gNodeB/eNodeB、ULCL UPF/BP UPF/I-UPF/SGW-U/ePDG、SGSN、PSA UPF/PGW-U、SMF/PGW-C/SGW-C、DN/PDN）通过OSPF动态路由绑定动态BFD实现网络互通。

* 网络形态：2/3/4/5G融合网络
* 网元形态：UDG融合网元
* 路由协议：OSPF动态路由自动部署
* 组网IP格式：IPv4组网
* 接入用户：IPv4单栈用户

本文所描述的UDG为融合部署形态，融合I-UPF和PSA UPF，对于不同的组网用户接入时，其承担的角色不同。

## 必备事项

前提条件

* 请了解UDG各类接口的类型及命名规范，可参见逻辑接口介绍。
* IP路由组网和业务接口配置子任务在前述章节已有详细描述，可参见配置VNF侧IP路由数据（无NP卡\_非SDN）和配置业务接口数据。本文针对典型的任务场景举例说明整网脚本配置。

数据

可参考各子任务的数据规划准备。

文档

获取网设LLD文档。

## 操作步骤

1. 关闭自动配置开关。
   1. 查询自动配置开关状态。

      ```
      LST AUTOCONFIG:;
      ```

      如果自动配置开关值为“TRUE”，需要执行如下步骤关闭自动配置开关。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
2. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 配置UDG到与对端设备无线侧(R)AN（gNodeB/eNodeB）的IP路由数据。
   1. 配置外联口的VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VPN_Access";
      ADD VPNINSTAF:VRFNAME="VPN_Access",AFTYPE=ipv4uni;
      ```
   2. 配置OSPF路由。

      1. 创建OSPF进程。

         ```
         ADD OSPF:PROCID=6,VRFNAME="VPN_Access",SCHEMAROUID="192.168.35.210",BFDALLINTFFLG=TRUE,LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA:PROCID=6,AREAID="0.0.0.5";
         ```

         如果参数“AREATYPE（区域类型）”配置为“NSSA”时，需要配置Loopback地址，这样设备会自动选取该Loopback地址作为FA。当有其他设备存在多条开销值相同的路径到NSSA设备时，可以形成负载分担。
      3. 设置OSPF引入路由类型。

         ```
         ADD OSPFIMPORTROUTE:PROCID=6,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
         ```
   3. 添加以太网隧道多虚拟网卡自动化配置模板。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1, VNICLIST="4 5";
      ```
   4. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_100",VPNNAME="VPN_Access",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=1,VLANID=100, BEGINADDR4="192.168.89.2", ENDADDR4="192.168.89.126", MASKLEN=25, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="0.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_200",VPNNAME="VPN_Access",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=1,VLANID=200, BEGINADDR4="192.168.89.130", ENDADDR4="192.168.89.254", MASKLEN=25, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="0.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```
4. 配置UDG到与对端设备核心侧UPF/PGW-U（PSA UPF/PGW-U）的IP路由数据。
   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VPN_Sc";

      ```
   2. 配置OSPF路由。

      1. 创建OSPF进程。

      2. 增加OSPF区域。

         ```

         ```
      3. 设置OSPF引入路由类型。

   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Sc_101",VPNNAME="VPN_Sc",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=1,VLANID=101, BEGINADDR4="192.168.88.2", ENDADDR4="192.168.88.126", MASKLEN=25, OSPFENABLE=TRUE, OSPFPROCID=7, OSPFAREAID="0.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Sc_201",VPNNAME="VPN_Sc",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=1,VLANID=201, BEGINADDR4="192.168.88.130", ENDADDR4="192.168.88.254", MASKLEN=25, OSPFENABLE=TRUE, OSPFPROCID=7, OSPFAREAID="0.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```

   从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行**DSP OPSASSISTSTATE**命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。
9. 配置逻辑接口数据。
   1. 配置Sa/N3/S1-U逻辑接口。

      1. 配置Sa/N3/S1-U逻辑接口所属的VPN实例。

         ```
         ADD VPNINST: VPNINSTANCE ="VPN_Access";
         ```
      2. 配置Sa/N3/S1-U逻辑接口。

         ```
         ADD LOGICINF:NAME="Saif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Access";
         ```
   2. 配置Sc/N9c/S5-S/S8-S逻辑接口。

      1. 配置Sc/N9c/S5-S/S8-S逻辑接口所属的VPN实例。

         ```
         ADD VPNINST: VPNINSTANCE ="VPN_Sc";
         ```
      2. 配置Sc/N9c/S5-S/S8-S逻辑接口。

         ```
         ADD LOGICINF:NAME="Scif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Sc";
         ```
   3. 配置Pa（N9a/S5-P/S8-P/S2b/Gn-U/Gp-U）逻辑接口。

      1. 配置Pa（N9a/S5-P/S8-P/S2b/Gn-U/Gp-U）逻辑接口所属的VPN实例。

         ```

         ```
      2. 配置Pa（N9a/S5-P/S8-P/S2b/Gn-U/Gp-U）逻辑接口。

         ```
         ADD LOGICINF:NAME="Paif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.3.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Pa";
         ```
   4. 配置N4（N4/Sxa/Sxb）逻辑接口。

      1. 配置N4（N4/Sxa/Sxb）逻辑接口所属的VPN实例。

         ```
         ADD VPNINST: VPNINSTANCE="VPN_Signaling";
         ```
      2. 配置N4（N4/Sxa/Sxb）逻辑接口。

      3. 配置UDG信息。

         ```
         SET UPINFO: HOSTNAME="UP_001";
         ```
10. 配置会话接入数据。
    1. 配置APN/DNN实例。

       ```
       ADD VPNINST: VPNINSTANCE ="VPN_Internet";
       ADD APN:APN="apn-op",HASVPN=ENABLE,VPNINSTANCE="VPN_Internet";
       ```
    2. 配置UDG分配地址，此处以基于APN/DNN分配地址为例。其他网元分配地址时，请跳过本步骤。

       ```
       ADD POOL:POOLNAME="testpool",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="VPN_Internet";
       ADD SECTION:POOLNAME="testpool",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.1",V4ENDIP="10.10.1.254";
       ADD POOLGROUP: POOLGRPNAME="poolgroup1", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
       ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup1", POOLNAME="testpool", PRIORITY=10;
       ADD POOLGRPMAP: MAPPINGNAME="mapping1", APN="apn-op", POOLGROUPNAME="poolgroup1";
       SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE;
       ```
