# 修改IPFarm的VIRTUALIP

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该IPFarm被用于重定向时，修改该IPFarm的VIRTUALIP。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110281 用户Portal。
* 完成配置用户Portal。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **MOD IPFARM** | IP-Farm名称（IPFARMNAME） | farm\_test | 已配置数据中获取 | 配置的IPFarm名称，已通过**ADD IPFARM**命令配置完成，可以使用**LST IPFARM**命令进行查询。 |
|  | IP协议版本（IPVERSION） | IPV4 | 本端规划 | - |
|  | 虚拟IP地址（VIRTUALIP） | 10.1.2.3 | 本端规划 |  |

## 操作步骤

1. 修改IPFARM对应的VIRTUALIP。

   **MOD IPFARM**

## 任务示例

任务描述

将farm\_test的虚拟IP地址修改为10.1.2.3。

脚本

//修改IPFARM对应的VIRTUALIP。

```
RMV RULE:RULENAME="rule_test1";
```

```
MOD IPFARM:IPFARMNAME="farm_test",IPVERSION=IPV4,VIRTUALIP="10.1.2.3";
```

```
ADD RULE:RULENAME="rule_test1",POLICYTYPE=SMARTREDIRECT,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="ff_test1",PRIORITY=10,POLICYNAME="farm_test";
```
