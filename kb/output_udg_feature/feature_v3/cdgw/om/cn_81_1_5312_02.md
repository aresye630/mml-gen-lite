# 配置GTP路径管理黑白名单

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

当运营商在部署分组交换网，新增UDG时，需要配置GTP路径管理黑白名单。UDG可以通过GTP路径管理黑白名单区分是否需要对网络中的对端网元进行探测。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-010102 路径管理。
* 完成配置GTP/PFCP路径管理参数。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET UPGTPPATH** | EchoList 开关（ECHOLISTSWITCH） | ENABLE | 本端规划 | - |
|  | EchoList 类型（ECHOLISTTYPE） | WHITE | 本端规划 |  |
| **ADD ECHOIPLIST** | IP地址版本类型（IPVERSION） | IPV4  IPV6 | 本端规划 | - |
|  | IPv4地址（IPV4ADDR） | 192.168.1.10  192.168.10.10  192.168.100.10 |  |  |
|  | IP掩码（IPV4MASK） | 24 |  |  |
|  | IPv6地址(IPV6ADDR) | fc00::1 |  |  |
|  | IP掩码(IPV6MASK) | 64 |  |  |

## 操作步骤

1. 开启GTP路径管理的黑白名单开关，配置GTP路径管理名单属性为白名单。

   **SET UPGTPPATH**
2. 配置需要探测的对端网元的GTP信令面或者数据面IP地址段。

   **ADD ECHOIPLIST**

## 任务示例

任务描述

1. 配置UDG向IPv4地址段为192.168.1.10/24、192.168.10.10/24和192.168.100.10/24的对端网元进行echo探测。
2. 配置UDG向IPv6地址段为fc00::1/64的对端网元进行echo探测。

脚本

//开启GTP路径管理的黑白名单开关，配置GTP路径管理名单属性为白名单。

```
SET UPGTPPATH:ECHOLISTSWITCH=ENABLE,ECHOLISTTYPE=WHITE;
```

//配置需要探测IPv4地址段。

```
ADD ECHOIPLIST:IPVERSION=IPV4,IPV4ADDR="192.168.1.10",IPV4MASK=24;
```

```
ADD ECHOIPLIST:IPVERSION=IPV4,IPV4ADDR="192.168.10.10",IPV4MASK=24;
```

```
ADD ECHOIPLIST:IPVERSION=IPV4,IPV4ADDR="192.168.100.10",IPV4MASK=24
```

//配置需要探测IPv6地址段。

```
ADD ECHOIPLIST:IPVERSION=IPV6,IPv6ADDR="fc00::1",IPv6MASK=64;
```
