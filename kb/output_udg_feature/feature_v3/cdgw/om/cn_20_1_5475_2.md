# 修改被IPFarm绑定的心跳检测接口

* 操作场景
* 必备事项

* 任务示例

## 操作场景

IP Farm绑定的心跳检测接口需要修改。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110282 Web Proxy。
* 完成配置Web Proxy。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD LOGICINF** | 逻辑接口名称（NAME） | phif1/0/1 | 本端规划 | - |
|  | 逻辑接口的IP版本（IPVERSION） | IPV4 | 本端规划 |  |
|  | 逻辑接口的IPv4地址1（IPV4ADDRESS1） | 10.10.16.16 | 本端规划 |  |
|  | 逻辑接口的IPv4掩码1（IPV4MASK1） | 255.255.255.255 | 本端规划 |  |
| **MOD IPFARM** | IP-Farm名称（IPFARMNAME） | farm\_test | 已配置数据中获取 | 配置的IPFarm名称，已通过**ADD IPFARM**命令配置完成，可以使用**LST IPFARM**命令进行查询。 |
|  | 心跳检测接口名称（INTERFACENAME） | phif1/0/1 | 已配置数据中获取 | 配置的心跳接口名称，已通过**ADD LOGICINF**命令配置完成，可以使用**ADD LOGICINF**命令进行查询。 |

## 操作步骤

1. 配置IPFarm的心跳检测接口。

   **ADD LOGICINF**
2. 修改心跳检测接口。

   **MOD IPFARM**

## 任务示例

任务描述

farm\_test的心跳检测接口改为phif1/0/1。

脚本

//配置IPFarm的心跳检测接口。

```
ADD LOGICINF:NAME="phif1/0/1",IPVERSION=IPV4,IPV4ADDRESS1="10.10.16.16",IPV4MASK1="255.255.255.255";
```

//修改心跳检测接口。

```
RMV RULE:RULENAME="rule_test1";
```

```
MOD IPFARM:IPFARMNAME="farm_test",HEALTHCHECKFLAG=ENABLE,INTERFACENAME="phif1/0/1";
```

```
ADD RULE:RULENAME="rule_test1",POLICYTYPE=WEBPROXY,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flow-l34",PRIORITY=10,POLICYNAME="farm_test";
```
