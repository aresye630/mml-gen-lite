# 修改Captive模式时间的间隔

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

captive模式时间的间隔需要修改。

适用于PGW-U、UPF。

## 必备事项

前提条件

该操作无需具备特殊条件。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **MOD USERPROFILE** | 用户模板名称（USERPROFILENAME） | up\_test | 已配置数据中获取 | 用户模板名称，已通过**ADD USERPROFILE**配置完成，可以通过**LST USERPROFILE**命令查询。 |
|  | Captive模式时间阈值（分）（CAPMODETHRES） | 5 | 本端规划 | - |

## 操作步骤

1. 配置Captive模式时间阈值。

   **MOD USERPROFILE**

## 任务示例

任务描述

修改UserProfile为“profile-tmd4000”的Captive模式时间阈值为5分钟。

脚本

//配置Captive模式时间阈值。

```
MOD USERPROFILE:USERPROFILENAME="up_test",CAPMODETHRES=5;
```
