## 操作场景

在UDG上激活HTTP3.0 Host分析功能。当用户访问的业务采用HTTP3.0协议承载时，需要部署HTTP3.0 Host分析特性，从而实现对业务实施计费与策略控制。

此配置实例以离线计费为例，进行七层业务的内容计费配置。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110252 HTTP3.0 Host分析特性概述。
* UDG完成与周边网元的对接。

## 操作步骤

1. 执行**SET SOFTPARA**命令设置软参“BYTE975”的值为“3”。

   **SET SOFTPARA**
2. 打开QUIC增强解析功能的开关

   **SET SACOMMONPARA**
3. 配置内容计费使用的URR和URR Group。
   1. 配置URR。

      **ADD URR**
   2. 配置上行和下行发起的业务对应的URR。

      **ADD URRGROUP**
4. 配置内容计费使用的PCC策略组。

   **ADD PCCPOLICYGRP**
5. 配置过滤条件。
   1. 配置七层过滤条件。

      **ADD L7FILTER**
   2. 配置流过滤器。

      **ADD FLOWFILTER**
   3. 绑定七层过滤条件。

      **ADD PROTBINDFLOWF**
6. 配置内容计费使用的规则。

   **ADD RULE**
7. 配置内容计费规则绑定用户模板。
   1. 创建UserProfile实例。

      **ADD USERPROFILE**
   2. 将已配置的内容计费规则绑定到UserProfile。

      **ADD RULEBINDING**

   如果进行HTTP3.0 Host分析功能，需解析SNI或者证书字段以获取Host，再基于此Host进行计费和业务控制。

## 任务示例

任务描述

开启UDG的HTTP3.0 Host分析功能，UDG将访问quic业务且URL为graph.facebook.com的用户业务报文记入使用量上报规则名称urr\_red，进行离线计费。

脚本

//执行**SET SOFTPARA**命令设置软参“BYTE975”的值为“3”。

```
SET SOFTPARA: DT=BYTE, BYTENUM=975,BYTEVALUE=3;
```

//打开QUIC增强解析功能的开关。

```
SET SACOMMONPARA: QUICPSRFUNCEN=ENABLE;
```

//配置离线计费的费率标识。

```
ADD URR:URRNAME="urr_red",URRID=12002,USAGERPTMODE=OFFLINE;
ADD URRGROUP:URRGROUPNAME="cp_red",UPURRNAME1="urr_red",DOWNURRNAME1="urr_red";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="cg_red",URRGROUPNAME="cp_red";
```

//配置七层信息。

```
ADD L7FILTER:L7FILTERNAME="l7-test",SUBL7FLTNAME="sl7-test",URL="graph.facebook.com";
ADD FLOWFILTER:FLOWFILTERNAME="fg_red";
ADD PROTBINDFLOWF:FLOWFILTERNAME="fg_red",PROTOCOLNAME="quic",L7FILTERNAME="l7-test";
```

//配置内容计费规则。

```
ADD RULE:RULENAME="rule_red",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="fg_red",POLICYNAME="cg_red";
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置内容计费规则绑定用户模板。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_red";
```
