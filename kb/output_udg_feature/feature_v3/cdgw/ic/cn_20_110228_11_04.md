## 操作场景

当需要根据返回的错误码进行URL纠错，并将用户访问的HTTP页面重定向到第三方服务器时，需要开启HTTP智能重定向功能。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-110284 HTTP智能重定向。
* UDG上已经加载了支持业务解析SA-Basic/SA-Web Browsing的License。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置HTTP智能重定向业务使用的三四层过滤条件。
   1. 配置HTTP智能重定向业务使用的三四层过滤规则。

      **ADD FILTER**
   2. 配置流过滤器。

      **ADD FLOWFILTER**
   3. 绑定三四层过滤信息。

      **ADD FLTBINDFLOWF**
   4. 将新配置的Filter置为生效。

      **SET REFRESHSRV**
3. 配置HTTP智能重定向使用的扩展过滤器。

   **ADD EXTENDEDFILTER**

   重复执行本步骤可以增加多个不同过滤条件的扩展过滤器。
4. 配置HTTP智能重定向错误码。

   **ADD ERRORCODE**
5. 配置HTTP智能重定向动作策略。

   **ADD REDIRAPPENDINFO**

   **ADD SMARTHTTPREDIR**
6. 配置HTTP智能重定向使用的业务规则。

   **ADD RULE**

   如果运营商希望基于流过滤器组设置过滤条件时，配置“流过滤器或流过滤器组选择(FILTERINGMODE)”为“FLOWFILTERGRP”，并且使用**ADD FLOWFILTERGRP**命令配置流过滤器组。

## 任务示例

任务描述

本例采用SMF下发预定义规则的方式进行说明。

对于用户发起的URL为www.huawei.com/\*，并且user agent为Mozilla/\* HTTP请求，当HTTP服务器返回的错误码值大于400时，UDG进行HTTP智能重定向，重定向之后URL为www.example.com，并在重定向动作中携带request-url-name和imsi-name。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5SHPR01",SWITCH=ENABLE;
```

//配置HTTP智能重定向使用的三四层过滤条件。

```
ADD FILTER:FILTERNAME="f-any",L34PROTTYPE=STRING,L34PROTOCOL=ANY;
```

```
ADD FLOWFILTER:FLOWFILTERNAME="flow-filter1";
```

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="flow-filter1",FILTERNAME="f_any";
```

```
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置HTTP智能重定向使用的扩展过滤器。

```
ADD EXTENDEDFILTER:EXTFLTNAME="filter_http-redirect1",URL="www.huawei.com/*";
```

```
ADD EXTENDEDFILTER:EXTFLTNAME="filter_http-redirect2",USERAGENT="Mozilla/*";
```

//配置HTTP智能重定向错误码。

```
ADD ERRORCODE: ERRORCODENAME="httperrorcode", ERRORCODEOP=GT, ERRORCODESTART=400;
```

//配置HTTP智能重定向动作策略。

```
ADD REDIRAPPENDINFO:APPENDINFONAME="testredirappendinfo",REQURLFLAG=ENABLE,IMSIFLAG=ENABLE;
```

```
ADD SMARTHTTPREDIR:SMTHTTPREDINAME="http-redirect_test", SERVERURL="www.example.com", EXTFLTTYPE1=AND, EXTFLTNAME1="filter_http-redirect1", EXTFLTTYPE2=AND, EXTFLTNAME2="filter_http-redirect2", APPENDINFONAME="testredirappendinfo", BINDERRCODENAME="httperrorcode";
```

//配置HTTP智能重定向使用的业务规则。

```
ADD RULE:RULENAME="rule_test",POLICYTYPE=SMARTREDIRECT,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flow-filter1",PRIORITY=1,POLICYNAME="http-redirect_test";
```
