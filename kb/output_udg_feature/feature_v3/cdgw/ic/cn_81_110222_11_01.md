## 操作场景

运营商规划基于小区负荷状态对某些用户或某些业务进行策略控制以解除小区拥塞状况，需要激活基于小区负荷上报的无线资源优化功能。

适用于PGW-U。

## 必备事项

前提条件

* 请仔细阅读GWFD-110332 基于小区负荷上报的无线资源优化。
* 完成**加载license**（如果有需求，请联系华为技术支持工程师处理）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET APNREPORTATTR** | APN名称（APN） | apn-test | 本端规划 | 开启小区负荷上报功能。  UDG开启本功能后，要求RAN侧和PCRF同时也支持该功能。 |
|  | 拥塞控制（CONGESTIONRPT） | ENABLE | 全网规划 |  |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 开启指定APN的小区负荷上报功能。

   **SET APNREPORTATTR**

## 任务示例

任务描述

在UDG上使能APN“apn-test”的基于小区负荷上报的无线资源优化功能。

脚本

1. 打开本特性的License配置开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5WOCR01",SWITCH=ENABLE;
   ```
2. 开启小区负荷上报功能。

   ```
   SET APNREPORTATTR:APN="apn-test",CONGESTIONRPT=ENABLE;
   ```
