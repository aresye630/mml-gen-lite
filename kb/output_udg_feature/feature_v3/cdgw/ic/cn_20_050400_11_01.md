## 操作场景

当移动IP网络中部署了具有实时性特点的会话类业务时，要求移动IP网络转发时延低、抖动小，因此需要提供端到端的QoS保证。

适用于PGW-U。

## 必备事项

前提条件

* 请仔细阅读GWFD-020381 会话类QoS保证。
* 已申请特性所需的License控制项。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置Alias Marking使能标记，缺省使用默认值。

   **ADD USERPROFILE**
3. 配置带宽控制功能。
   1. 配置APN实例。

      **ADD APN**
   2. 配置带宽控制功能。

      **SET APNQOSATTR**
4. **可选：**使能QoS的CAR功能。

   **SET QOSCAR**
5. **可选：**配置用户上下行shaping功能的全局开关。

   **SET QOSSHAPE**

## 任务示例

任务描述

激活会话类QoS保证的功能。

脚本

//打开本特性License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5TCQS01", SWITCH=ENABLE;
```

//使能QoS的CAR功能。

```
SET QOSCAR:USERTYPE=ROAMING,ULRAT=geran-1;
```

//配置AliasMarking使能标记，缺省使用默认值。

```
ADD USERPROFILE:USERPROFILENAME="profile1",ALIASMARKFLAG=ENABLE;
```

//配置带宽控制功能。

```
ADD APN:APN="apn1";
```

```
SET APNQOSATTR:APN="apn1",CARSHAPESWUL=ENABLE,CARSHAPEUL=CAR,CARSHAPESWDL=ENABLE,CARSHAPEDL=CAR;
```

//配置用户上下行shaping功能的全局开关。

```
SET QOSSHAPE:USERTYPE=VISITING, ULRAT=geran-1;
```
