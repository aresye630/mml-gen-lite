## 操作场景

非SDN场景，UEG与企业网对接时，由于企业APN数量多，且各个企业APN之间有业务隔离诉求，故可采用BGP/MPLS VPN组网。UEG作为PE设备接入MPLS骨干网，通过MP-EBGP（Multi-protocol Extensions for Border Gateway Protocol）与其他PE之间传播VPN信息和VPN-IPv4路由。UEG采用OptionB方式实现跨域VPN。

如图1所示，UEG和PE间通过Loopback IP建立eBGP邻居，用于交换私网VPN路由。Loopback IP之间通过静态路由/OSPF互通。

## 必备事项

前提条件

* 请阅读并熟悉特性GWFD-023001 MPLS VPN、IPFD-020502 支持BGP和IPFD-020403 BFD特性概述。
* 具备管理员权限的操作人员已经登录华为操作维护系统。
* UEG与网络实体之间的网络环境已经构建完成。

VM扩容场景，需要将新扩容的VM上的相关接口，配置为MPLS接口。

* 扩容前通过**ADD MPLSIF**命令手动添加为MPLS接口时，仍需要手动将新扩容的VM上新增的接口通过**ADD MPLSIF**命令手动添加为MPLS接口。例如，新扩容的VM上新增了Eth-trunk6801.100用于传输MPLS报文，则需要通过**ADD MPLSIF**命令将Eth-trunk6801.100配置为MPLS接口。
* 扩容前通过**ADD AUTOSCALINGMPLS**命令自动生成MPLS接口时，不需要通过**ADD MPLSIF**命令手动将新增的接口添加为MPLS接口。**ADD AUTOSCALINGMPLS**命令会自动将新增加的接口添加为MPLS接口。

## 操作步骤

1. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 全局激活BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```

   “ASNUM”参数若需要变更，则需先去使能BGP功能。去使能BGP时，BGP VPN实例等配置会被同步删除。必须按照LLD规划的“ASNUM”值进行配置。
3. 配置MPLS全局配置。

   ```
   SET MPLSSITE: MPLSLSRID="10.10.10.78", MPLSENABLE=ENABLE, LDPENABLE=DISABLE;
   ```
4. 配置外联口IP、BFD会话、和BFD绑定静态路由（到BGP PEER IP的静态路由）。

   N6外联口IP及路由数据，与非MPLS组网的差异点如下。其他配置与非MPLS组网没有差异，此处不再详细描述。
   * MPLS使用的N6外联口绑定的VPN实例名称是\_public\_。
   * 不需要配置IPv6数据（MP-EBGP组网时，使用IPv4 eBGP，传递IPv6私网路由）。

   UEG支持通过静态路由或OSPF动态路由实现与BGP PEER IP的互通：

   * BGP over静态路由时，请参见配置静态路由+BFD组网（IPv4）。
   * BGP over OSPF时，请参见配置动态路由OSPF+BFD组网（IPv4）。
5. 使能接口的MPLS功能。
   * （标卡）非SR-IOV bonding组网场景下：

     ```
     ADD MPLSIF:IFNAME="Ethernet66/0/4.100";
     ADD MPLSIF:IFNAME="Ethernet66/0/5.200";
     ADD MPLSIF:IFNAME="Ethernet67/0/4.100";
     ADD MPLSIF:IFNAME="Ethernet67/0/5.200";
     ```
   * （标卡）SR-IOV bonding组网场景下：

     ```
     ADD MPLSIF:IFNAME="Eth-trunk6604.100";
     ADD MPLSIF:IFNAME="Eth-trunk6604.200";
     ADD MPLSIF:IFNAME="Eth-trunk6704.100";
     ADD MPLSIF:IFNAME="Eth-trunk6704.200";
     ```
   * （NP卡省交换直连PE）Ethernet子接口组网场景下：

     ```
     ADD MPLSIF:IFNAME="100GE66/0/9.1";
     ADD MPLSIF:IFNAME="100GE67/0/9.1";
     ```
   * （NP卡省交换直连PE，跨板Eth-trunk）Eth-trunk子接口组网场景下：

     ```
     ADD MPLSIF:IFNAME="Eth-trunk1.1";
     ADD MPLSIF:IFNAME="Eth-trunk1.2";
     ```
   * （网络加速卡直连DCGW，本板Eth-trunk）Eth-trunk子接口组网场景下：

     ```
     ADD MPLSIF:IFNAME="Eth-trunk1.1";
     ADD MPLSIF:IFNAME="Eth-trunk1.2";
     ADD MPLSIF:IFNAME="Eth-trunk1.3";
     ADD MPLSIF:IFNAME="Eth-trunk1.4";
     ```
6. 配置VPN实例及VPN实例地址族。

   ```
   ADD L3VPNINST: VRFNAME="VRF_PDN1";
   ADD L3VPNINST: VRFNAME="VRF_PDN2";
   ADD L3VPNINST: VRFNAME="VRF_PDN3";
   ADD L3VPNINST: VRFNAME="VRF_PDN4";
   ADD L3VPNINST: VRFNAME="VRF_PDN5";
   ```

   //IPv4组网或IPv4v6组网，请执行如下脚本：

   ```
   ADD VPNINSTAF: VRFNAME="VRF_PDN1", AFTYPE=ipv4uni, VRFRD="100:100", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN2", AFTYPE=ipv4uni, VRFRD="200:200", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN3", AFTYPE=ipv4uni, VRFRD="300:300", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN4", AFTYPE=ipv4uni, VRFRD="400:400", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN5", AFTYPE=ipv4uni, VRFRD="500:500", VRFLABELMODE=perInstance;
   ```

   //IPv6组网或IPv4v6组网，请执行如下脚本：

   ```
   ADD VPNINSTAF: VRFNAME="VRF_PDN1", AFTYPE=ipv6uni, VRFRD="100:100", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN2", AFTYPE=ipv6uni, VRFRD="200:200", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN3", AFTYPE=ipv6uni, VRFRD="300:300", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN4", AFTYPE=ipv6uni, VRFRD="400:400", VRFLABELMODE=perInstance;
   ADD VPNINSTAF: VRFNAME="VRF_PDN5", AFTYPE=ipv6uni, VRFRD="500:500", VRFLABELMODE=perInstance;
   ```
7. 配置VPN Target。

   ```
   ADD VPNTARGET: VRFNAME="VRF_PDN1", AFTYPE=ipv4uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="1:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN2", AFTYPE=ipv4uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="2:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN2", AFTYPE=ipv4uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="2:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN3", AFTYPE=ipv4uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="3:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN3", AFTYPE=ipv4uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="3:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN4", AFTYPE=ipv4uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="4:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN4", AFTYPE=ipv4uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="4:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN5", AFTYPE=ipv4uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="5:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN5", AFTYPE=ipv4uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="5:1";
   ```

   //IPv6组网或IPv4v6组网，请执行如下脚本：

   ```
   ADD VPNTARGET: VRFNAME="VRF_PDN1", AFTYPE=ipv6uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="1:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN1", AFTYPE=ipv6uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="1:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN2", AFTYPE=ipv6uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="2:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN2", AFTYPE=ipv6uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="2:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN3", AFTYPE=ipv6uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="3:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN3", AFTYPE=ipv6uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="3:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN4", AFTYPE=ipv6uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="4:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN4", AFTYPE=ipv6uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="4:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN5", AFTYPE=ipv6uni, VRFRTTYPE=export_extcommunity, VRFRTVALUE="5:1";
   ADD VPNTARGET: VRFNAME="VRF_PDN5", AFTYPE=ipv6uni, VRFRTTYPE=import_extcommunity, VRFRTVALUE="5:1";
   ```
8. 配置Loopback接口（BGP本端IP）。
   1. 配置Loopback接口。

      ```
      ADD INTERFACE: IFNAME="Loopback1";
      ```
   2. 增加接口IPv4地址。

      ```
      ADD IFIPV4ADDRESS: IFNAME="Loopback1", IFIPADDR="10.10.10.78", SUBNETMASK="255.255.255.255";
      ```

      MP-EBGP组网中：

      * Loopback接口不绑定VPN实例。
      * BGP对等体地址仅支持IPv4类型，即不需要配置IPv6地址。
9. 配置BGP。
   1. 修改公网BGP VPN实例。

      ```
      MOD BGPVRF: VRFNAME="_public_", ROUTERID="10.1.1.1";
      ```
   2. 增加BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_PDN1", DEFAULTAFTYPE=noaf;
      ADD BGPVRF: VRFNAME="VRF_PDN2", DEFAULTAFTYPE=noaf;
      ADD BGPVRF: VRFNAME="VRF_PDN3", DEFAULTAFTYPE=noaf;
      ADD BGPVRF: VRFNAME="VRF_PDN4", DEFAULTAFTYPE=noaf;
      ADD BGPVRF: VRFNAME="VRF_PDN5", DEFAULTAFTYPE=noaf;
      ```
   3. 增加BGP VPN实例地址族（使能MP-EBGP功能）。“VRFNAME”使用默认值“\_public\_”。

      //IPv4组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD BGPVRFAF: VRFNAME="_public_", AFTYPE=ipv4vpn, APPLYLABELMODE=perNexthop;
      ```

      //IPv6组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD BGPVRFAF: VRFNAME="_public_", AFTYPE=ipv6vpn, APPLYLABELMODE=perNexthop;
      ```

      “AFTYPE”设置为“ipv4vpn”/“ipv6vpn”。
   4. 增加BGP VPN地址族。VNF对接2个负荷分担的BGP邻居时，“MAXIMUMLOADBALANCE”设置为“2”。

      //IPv4组网或IPv4v6组网，请执行如下脚本：

      ```

      ADD BGPVRFAF: VRFNAME="VRF_PDN2", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN3", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN4", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN5", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```

      //IPv6组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD BGPVRFAF: VRFNAME="VRF_PDN1", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN2", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN3", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN4", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ADD BGPVRFAF: VRFNAME="VRF_PDN5", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 增加BGP对等体。

      //“VRFNAME”使用默认值“\_public\_”。使用IPv4 BGP传递IPv6路由，不需要配置IPv6的BGP对等体。

      ```
      ADD BGPPEER: VRFNAME="_public_", ADDRESSTYPE=ipv4, PEERADDR="10.10.20.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="_public_", ADDRESSTYPE=ipv4, PEERADDR="10.10.30.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
      ```

      //（可选）执行**ADD BGPPEER**时，若“VRFNAME”使用默认值“\_public\_”，则会自动生成ipv4uni类型的对等体地址族。如局点不需要创建ipv4uni类型的对等体地址族，可执行如下脚本进行删除。

      ```
      RMV BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.20.78";
      RMV BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv4uni, REMOTEADDRESS="10.10.30.78";
      ```
   6. 配置BGP对等体地址族。

      //IPv4组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv4vpn, REMOTEADDRESS="10.10.20.78";
      ADD BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv4vpn, REMOTEADDRESS="10.10.30.78";
      ```

      //IPv6组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv6vpn, REMOTEADDRESS="10.10.20.78";
      ADD BGPPEERAF: VRFNAME="_public_", AFTYPE=ipv6vpn, REMOTEADDRESS="10.10.30.78";
      ```
   7. 增加BGP引入wlr路由。

      //IPv4组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_PDN1", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN2", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN3", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN4", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN5", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      //IPv6组网或IPv4v6组网，请执行如下脚本：

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_PDN1", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN2", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN3", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN4", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ADD IMPORTROUTE: VRFNAME="VRF_PDN5", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      由于BGP协议自身不能发现路由，所以需要引入其他协议的路由（如OSPF、静态路由或WLR等）注入到BGP路由表中，从而将这些路由在AS之内和AS之间传播。

## 验证方法

1. 执行命令**LST IFIPV4ADDRESS**，检查对应子接口上是否获取到IP地址及绑定的VPN是否为“\_public\_”。
   * 是，请执行3。
   * 否，请执行2。
2. 修改外联口IP数据。
   1. 查询需要修改的子接口并记录查询结果。

      ```
      LST IFIPV4ADDRESS:;
      ```
   2. 查询需要修改的静态路由并记录查询结果。

      ```
      LST SRROUTE:;
      ```
   3. 删除2.a中记录的所有子接口。

      **RMV INTERFACE**
   4. 删除配置错误的静态路由。

      **RMV SRROUTE**
   5. 参考配置步骤，增加正确的配置。
3. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，请执行5。
   * 如果为其他状态，请执行4。
4. 执行**PING**命令，在VNF上检查VNF外联口IP与网关设备（如PE/DC-GW）接口IP之间是否路由可达。
   * 是，请执行5。
   * 否，请联系华为技术支持工程师处理。
5. 执行**PING**命令，在网关设备（如PE/DC-GW）上检查网关设备接口IP与VNF Loopback接口IP之间是否路由可达。
   * 是，请执行6。
   * 否，请联系华为技术支持工程师处理。
6. 执行**PING**命令，在VNF上检查VNF BGP本端IP与BGPPEER IP之间是否路由可达。

   需要在VNF上分别PING BGP PEER IP，出接口是VNF上负荷分担关系的每个子接口，且能PING通。

   * 是，请执行7。
   * 否，请联系华为技术支持工程师处理。
7. 执行**DSP BGPPEERINFO**命令，检查BGP对等体条数是否正确及BGP对等体状态是否为Established。

   本步骤的显示结果中的BGP对等体的条数与LST BGPPEER中查询的对等体的条数相等，且“对等体状态”为“Established”。

   * 是，调测结束。
   * 否，请执行8。
8. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
