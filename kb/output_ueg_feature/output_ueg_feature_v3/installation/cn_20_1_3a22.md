# 配置动态路由OSPF+BFD组网（IPv4）

## 操作场景

VNF与对端设备可通过OSPF动态路由绑定动态BFD探测的方式进行组网连接，该方式适用于IPv4组网的网络中。

在网络拓扑结构复杂、设备与IP路由繁多的网络部署时，通常使用OSPF动态路由方式发布路由。同时，利用BFD双向转发检测机制为链路提供双向、轻负荷且持续时间短的快速检测功能，提高链路可靠性。

如图1所示为VNF与周边网元的OSPF动态路由互通组网示意图。VNF和网关运行动态路由协议而接入运营商/企业网络。PE（Provider Edge）的路由配置请参考运营商的网络规划配置。

**图1** OSPF动态路由+BFD组网

## 必备事项

前提条件

* 请阅读并熟悉特性IPFD-020501 支持OSPF特性概述和IPFD-020403 BFD特性概述。

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

* VNF与网络实体之间的网络环境已经构建完成。

数据

VNF使用OSPF动态路由绑定动态BFD检测功能与对端设备建立可靠的IP连接。

* 在VNF上配置OSPF动态路由与对端建立链路。
* 在VNF上配置动态BFD功能增强链路检测可靠性。
* 在VNF上推荐采用子接口的外联口与外部网络对接。

本文以一组外联口子接口为例进行说明，一组外联口（对应一个逻辑接口）分别规划在2个CSLB上，每个CSLB上各规划2个子接口负荷分担承载流量。实际场景可根据网设规划进行适配。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VPN_Access";
   ADD VPNINSTAF:VRFNAME="VPN_Access",AFTYPE=ipv4uni;
   ```

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、网关上的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 非SR-IOV bonding组网时，配置外联口IP地址。

   1. 查询接口名，确认CSLB上可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet66/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/5",IFADMINSTATUS=up;
      ```
   3. 配置以太网子接口。

      ```
      ADD INTERFACE:IFNAME="Ethernet66/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/5.1";
      ```
   4. 增加接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Ethernet66/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/5.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/5.1",VRFNAME="VPN_Access";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Ethernet66/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/5.1",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/5.1",VLANTYPEVID=200;
      ```

      子接口配置了VLAN，则需要在交换机、对接网关上调整VLAN的配置。
   6. 配置外联口IP地址。

      ```
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/4.1",IFIPADDR="192.168.89.2",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/5.1",IFIPADDR="192.168.89.34",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet67/0/4.1",IFIPADDR="192.168.89.3",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet67/0/5.1",IFIPADDR="192.168.89.35",SUBNETMASK="255.255.255.224";
      ```

      如果规划外联口使用IPv4v6双栈地址，则分别执行**ADD IFIPV4ADDRESS**和**ADD IFIPV6ADDRESS**对同一外联口配置IPv4和IPv6地址。
3. SR-IOV bonding组网时，配置外联口IP地址。

   1. 查询接口名，确认CSLB上可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet66/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/5",IFADMINSTATUS=up;
      ```
   3. 配置以太Trunk接口。

      ```
      ADD INTERFACE:IFNAME="Eth-trunk1";
      ADD INTERFACE:IFNAME="Eth-trunk2";
      ```
   4. 配置Eth-trunk接口的工作模式并添加成员端口。

      ```
      MOD TRUNKIF:IFNAME="Eth-Trunk1",WORKMODE=Manual;
      MOD TRUNKIF:IFNAME="Eth-Trunk2",WORKMODE=Manual;
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet66/0/4";
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet66/0/5";
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet67/0/4";
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet67/0/5";
      ```
   5. 配置以太Trunk子接口。

      ```
      ADD INTERFACE:IFNAME="Eth-trunk1.1";
      ADD INTERFACE:IFNAME="Eth-trunk1.2";
      ADD INTERFACE:IFNAME="Eth-trunk2.1";
      ADD INTERFACE:IFNAME="Eth-trunk2.2";
      ```
   6. 增加接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Eth-trunk1.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Eth-trunk1.2",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Eth-trunk2.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Eth-trunk2.2",VRFNAME="VPN_Access";
      ```
   7. 在以太Trunk子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Eth-trunk1.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Eth-trunk1.2",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Eth-trunk2.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Eth-trunk2.2",VLANTYPEVID=200;
      ```

      子接口配置了VLAN，则需要在交换机、对接网关上调整VLAN的配置。
   8. 配置外联口IP地址。

      ```
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.1",IFIPADDR="192.168.89.2",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.2",IFIPADDR="192.168.89.34",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.1",IFIPADDR="192.168.89.3",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.2",IFIPADDR="192.168.89.35",SUBNETMASK="255.255.255.224";
      ```

      如果规划外联口使用IPv4v6双栈地址，则分别执行**ADD IFIPV4ADDRESS**和**ADD IFIPV6ADDRESS**对同一外联口配置IPv4和IPv6地址。
4. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
5. 配置OSPF路由数据。

   1. 创建OSPF进程。

      ```
      ADD OSPF:PROCID=6,VRFNAME="VPN_Access",SCHEMAROUID="192.168.35.210",BFDALLINTFFLG=TRUE, BFDRXCFGFLAG=TRUE, BFDMINRXINTV=500, BFDTXCFGFLAG=TRUE, BFDMINTXINTV=500, SCHEMABFDDETMUL=4, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
      ```

      * VNF支持VPN多实例，因此需要取消环路检查（参数“VPNINSCAPSIMFLG”配置为“TRUE”），否则会导致OSPF路由引入失败。
      * 路由器标识Router ID（“SCHEMAROUID”）的选择策略：优选用户配置的Router ID，如果未配置，则选择OSPF进程所在VRF内或者公网内的最大接口IP地址。
      * 如果需要为OSPF动态路由绑定BFD会话，则配置参数“BFDALLINTFFLG（使能BFD）”为“TRUE”。
      * 当OSPF路由配置共网段时，需要将参数“VIRTUALSYSFLAG（OSPF共网段虚拟系统使能标志）”配置为“TRUE”。
   2. 增加OSPF区域。

      ```
      ADD OSPFAREA:PROCID=6,AREAID="0.0.0.5", AREATYPE=NSSA, MAXCOSTFLAG=FALSE;
      ```

      如果参数“AREATYPE（区域类型）”配置为“NSSA”时，需要配置Loopback地址，这样设备会自动选取该Loopback地址作为FA。当有其他设备存在多条开销值相同的路径到NSSA设备时，可以形成负载分担。
   3. **（可选）**配置OSPF区域认证。

      **ADD OSPFAREAAUTH**: PROCID=进程号, AREAID=区域号, AUTHENMODE=认证模式;

      * 参数“AUTHENMODE”（认证模式），选择“keychain”、“simple”、“md5”、“hmac-sha256”或“hmac-md5”。
      * 使用区域验证时，一个区域中所有设备的接口上所配置的认证模式和口令必须一致。
   4. 配置OSPF协议的接口属性。
      * 非SR-IOV bonding组网场景下：

        ```
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet66/0/4.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet66/0/5.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet67/0/4.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet67/0/5.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ```
      * SR-IOV bonding组网场景下：

        ```
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Eth-trunk1.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Eth-trunk1.2",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Eth-trunk2.1",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ADD OSPFINTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Eth-trunk2.2",DRPRI=0,VIRTUALSYSFLAG=TRUE, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
        ```

      * 参数“NETWORKTYPE”（网络类型）选择“broadcast”、“nbma”、“p2p”或“p2mp”。
      * 广播或NBMA网络中，根据此接口优先级选举DR和BDR路由器，“优先级”设置为“0”表示不参与DR和BDR的选举。为避免VNF被选为DR或BDR，建议将VNF“优先级”配置为0，对端配置为非0。
   5. 增加运行OSPF协议的接口。

      ```
      ADD OSPFNETWORK:PROCID=6,AREAID="0.0.0.5",IPADDRESS="192.168.89.0",WILDCARDMASK="0.0.0.31";
      ADD OSPFNETWORK:PROCID=6,AREAID="0.0.0.5",IPADDRESS="192.168.89.32",WILDCARDMASK="0.0.0.31";
      ```
   6. **（可选）**配置OSPF接口验证参数。

      根据不同的接口验证类型选择不同的配置。

      * 不配置认证模式。

        **ADD OSPFINTERFACEAUTH**: PROCID=进程号, AREAID=区域号, IFNAME="接口名称", AUTHENMODE=null;
      * 配置认证模式。

        **ADD OSPFINTERFACEAUTH**: PROCID=进程号, AREAID=区域号, IFNAME="接口名称", AUTHENMODE=认证模式;

        + 参数“AUTHENMODE”（认证模式）可以选择“keychain”、“hmac-sha256”、“simple”、“md5”或“hmac-md5”。
        + 参数“IFNAME”（接口名称）引用5.d中的接口名称。
   7. 设置OSPF引入路由类型。

      ```
      ADD OSPFIMPORTROUTE:PROCID=6,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
      ```
6. （可选）5中**ADD OSPFAREA**命令的参数“AREATYPE（区域类型）”配置为“NSSA”时，设置Loopback接口。

   1. 配置Loopback接口。

      ```
      ADD INTERFACE:IFNAME="LoopBack605";
      ```
   2. 增加Loopback接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="LoopBack605",VRFNAME="VPN_Access";
      ```
   3. 配置Loopback的IPv4地址。

      ```
      ADD IFIPV4ADDRESS:IFNAME="LoopBack605",IFIPADDR="192.168.235.130",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```
   4. 使能Loopback接口到OSPF进程的区域下。
      * 通过**ADD OSPFINTERFACE**配置。

        ```
        ADD OSPFINTERFACE: PROCID=6, AREAID="0.0.0.5", IFNAME="LoopBack605";
        ```
      * 通过**ADD OSPFNETWORK**配置。

        ```
        ADD OSPFNETWORK: PROCID=6, AREAID="0.0.0.5", IPADDRESS="192.168.235.130", WILDCARDMASK="0.0.0.0";
        ```

      推荐使用**ADD OSPFINTERFACE**命令进行配置。使用**ADD OSPFNETWORK**命令配置时，请将“WILDCARDMASK(反掩码)”设置为“0.0.0.0”。

      参数“PROCID（进程号）”与5中的“PROCID（进程号）”的取值相一致；参数“AREAID（区域号）”与5中的“AREAID（区域号）”的取值相一致。

## 验证方法

1. 查看接口状态及信息是否与规划数据一致。

   ```
   LST INTERFACE:;
   ```

   ```
   LST IFIPV4ADDRESS:;
   ```

   ```
   LST IFIPV6ADDRESS:;
   ```

   ```
   LST IPBINDVPN:;
   ```

   * 如果一致，请执行2。
   * 如果不一致，请先删除错误的配置，然后参考“操作步骤”重新配置。
2. 调测OSPF动态路由。

   1. 检查接口是否已添加到OSPF区域中。

      **DSP OSPFINTERFACE**: PROCID=OSPF进程号;

      **DSP OSPFV3INTERFACE**: PROCID=OSPFv3进程号;

      * 如果是，请执行2.b。
      * 如果否，请执行1。
   2. 检查OSPF邻居状态是否正常。

      邻居应包括邻居设备的ROUTER ID、接口的IP地址以及邻居的状态。

      **DSP OSPFPEER**: PROCID=OSPF进程号;

      **DSP OSPFV3PEER**: PROCID=OSPFv3进程号;

      * 如果是，请执行3。
      * 如果否，请执行2.c。
   3. 执行**PING**，查看VNF外联口IP与DCGW接口IP能否互通。

      ```
      PING:IPVERSION=IPv4,VPNNAME="VPN_Access",DESTIPV4ADDRESS="对端网关地址";
      ```

      ```
      PING:IPVERSION=IPv6,VPNNAME="VPN_Access",DESTIPV6ADDRESS="对端网关地址";
      ```

      * 丢包率为0%，请执行4。
      * 丢包率不是0%，请检查物理接口及连线是否正常。正常后重新执行2.b。
3. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，调测结束。
   * 如果为其他状态，请执行4。
4. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
