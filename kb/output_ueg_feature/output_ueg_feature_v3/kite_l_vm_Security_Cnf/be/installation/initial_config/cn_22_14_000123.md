# 修改PGW Web LMT操作员密码

#### 操作场景

* 在开局结束后，系统管理员必须及时修改PGW Web LMT操作员的密码，确保系统安全。
* 在日常维护中，系统管理员必须定期修改PGW Web LMT操作员的密码，确保系统安全。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

首次登录请参考LLD文档中“账号管理设计”页签获取登录密码，之后维护请向系统管理员获取PGW Web LMT的admin帐号的密码。

**数据**

执行该操作前，规划好PGW Web LMT操作员的新密码。

如果未执行过**SET SECPOLICY**命令或执行**SET SECPOLICY**时，密码安全策略均采用默认值时，密码安全策略如下。

密码区分大小写，其复杂度需同时满足下列条件：

* 密码至少包含以下四个类别中的三类：
  + 英文大写字母。
  + 英文小写字母。
  + 数字：0～9。
  + 特殊字符：` ~ ! @ # $ % ^ \* ( ) \_ + - { } | [ ] : > ? . \ / （包含空格）。
* 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。
* 密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。
* 不允许使用三个或三个以上连续的相同字符（例如：AAA）。
* 密码长度最长为64个字符，人机账号的密码默认最短长度为10个字符，机机账号的密码默认最短长度为16个字符。
* 密码不能与最近的5个历史密码重复。

如果已执行**SET SECPOLICY**命令修改了密码安全策略，则密码策略以修改后的为准。

#### 操作步骤

1. 使用admin帐号登录PGW Web LMT，登录PGW Web LMT MML命令界面。用户的默认密码请参见USCDB应用用户默认帐号。
2. 在PGW Web LMT主界面点击“个人设置”按钮，进入个人设置页面。

   **图1** PGW Web LMT主界面
3. 在个人设置页面，如图2所示，点击“修改密码”按钮，修改当前登录的操作员密码。

   **图2** 个人设置页面
4. 未登录的普通操作员可通执行**MOD OPR**命令修改密码。

   ```
   MOD OPR: SYSNO=系统序列号, OPNAME=操作员名称, PWD=密码, CFM=确认密码;
   ```

   “系统序列号”和“操作员名称”必须已通过**ADD OPR**命令添加。
