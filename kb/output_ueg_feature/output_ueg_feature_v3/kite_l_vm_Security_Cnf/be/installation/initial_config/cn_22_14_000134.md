# 修改用户操作时段

#### 操作场景

在PGW日常的管理和维护中，当需要对操作员的操作时段进行控制时，系统管理员可以使用该操作修改用户的操作时段。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

只有具有管理员权限的用户才能修改用户的操作时段。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 操作员名称
* 操作员的操作时间段

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 执行命令**MOD OPR**修改用户操作时段。

   ```
    MOD OPR: SYSNO=1, OPNAME="pgwguest", DATE=LIMIT, STARTDATE=2009&08&10, ENDDATE=2009&12&31, TIME=LIMIT, STARTTIME=10&22&30, ENDTIME=20&22&32, WEEK=LIMIT, WK=SUN&TUE&THU&SAT;
   ```

   通过参数“日期限制开关”、“时间限制开关”和“星期限制开关”设置用户的操作时段。
