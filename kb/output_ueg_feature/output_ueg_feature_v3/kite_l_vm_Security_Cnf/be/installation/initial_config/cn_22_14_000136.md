# 修改用户状态

#### 操作场景

在日常的管理和维护中，系统管理员可以根据实际需要修改用户状态，即控制是否允许用户登录PGW系统。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

只有具有管理员权限的用户才能修改用户状态。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 操作员名称

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 执行命令**MOD OPR**修改操作员状态。

   ```
    MOD OPR: SYSNO=1, OPNAME="pgwguest", STATUS=INACTIVE;
   ```

   通过参数“操作员状态”设置操作员的状态。
