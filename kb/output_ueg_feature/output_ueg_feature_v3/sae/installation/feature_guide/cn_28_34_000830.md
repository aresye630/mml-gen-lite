## 操作场景

该任务实现如下操作：

* 大网UDM实现园区数据管理功能。
* 大网UDM实现用户数据的分拣功能。
* USCDB实现园区定制导出功能。
* 添加SFTP用户，用于与PGW、DMA的交互功能。
* 实现定时导出功能。

## 对系统的影响

对系统正常运行无影响。

## 必备事项

数据

**数据配置建议：**

大网UDM配置一套独立的K4密钥和OP数据用于园区UEG。

1. 大网UDM维护大网和园区UEG两套K4密钥、OP数据，为所有园区UEG统一分配相同的且与大网不同的K4密钥、OP数据，可减少后续新增每个园区需要安全人员在大网配置园区k4密钥、OP数据，只需要首个园区对接时在大网同步配置即可。
2. 园区UEG配置的“AMF值”需要和大网UDM配置保持一致，大网UDM配置命令为：**ADD AMF**。
3. 园区UEG配置的“SUCI密钥值”需要和大网UDM配置保持一致，大网UDM配置命令为：**ADD SUCIKEY**。

## 操作步骤

1. PGW侧园区数据配置步骤。

   1. 登录“UDM业务管理”窗口。
   2. 设置园区用户数据导出的过滤条件。

      执行**ADD CAMPUSDATAFILTER**命令，通过“过滤条件名称”、“过滤条件类型”和“过滤条件值”参数设置一条用户数据导出的过滤条件。
   3. 在大网UDM中增加一条园区配置数据记录。

      执行**ADD CAMPUSCFG**命令，调用**ADD CAMPUSDATAFILTER**命令配置的过滤条件，设置一条园区配置数据记录。
2. USCDB侧数据配操作步骤。

   1. 登录“USCDB MML命令”界面。
   2. 大网UDM导出配置步骤不同，具体有以下两种情况：
      * 如果大网UDM将SFTP Server作为服务端，供园区下载数据。
        1. 设置SFTP Server的园区子目录。

           执行**ADD SFTPUSER**命令，添加SFTP用户，通过“子工作路径名称”参数指定SFTP用户的子工作目录，该参数必须与**ADD CAMPUSCFG**命令设置的“园区名称”保持一致，确保每个园区只能访问自己园区的数据，不能访问其它园区的数据，为园区导出提供安全隔离能力。
        2. 添加园区定制导出配置。

           执行**ADD CUSEXPCFG**命令，为不同园区的导出结果文件使用不同的密码加密。此时需要设置“SFTP类型”参数为“SERVER”。
      * 如果大网UDM将SFTP Server作为客户端，将园区数据上传到第三方SFTP文件服务器。
        1. 设置SFTP服务器。

           执行**ADD RSFTPSERVER**命令，添加远端SFTP服务器，通过“远端服务器类型”和“远端服务器名称”来指定SFTP服务器。

           + 参数“服务端IPV4地址”为服务器IP地址，参数“本端IPV4地址”为DMA地址，可通过**LST SRVIPADDR**命令获取。
           + 参数“SFTP远端工作目录”必须与**ADD CAMPUSCFG**命令设置的“园区名称”保持一致，确保每个园区只能访问自己园区的数据。
        2. 添加园区定制导出配置。

           执行**ADD CUSEXPCFG**命令，为不同园区的导出结果文件使用不同的密码加密。此时需要设置“SFTP类型”参数为“CLIENT”。
3. 登录“系统管理”窗口，执行**ADD EXPTASK**命令启动定时导出任务。

## 任务示例

任务描述

配置UDM与UEG用户数据协同高可用特性数据。

脚本

```
/*---------登录PGW Web LMT MML命令界面，进入“UDM业务管理”窗口---------*/ 
/*设置园区用户数据导出的过滤条件*/
ADD CAMPUSDATAFILTER: FILTERNAME="FILTERNAME", FILTERTYPE=IMSIPRE, FILTERVALUE="963589125423";

/*增加一条园区配置数据记录*/
ADD CAMPUSCFG: CAMPUSNAME="campus1", FILTERNAME="FILTERNAME", K4SNO=1, OPSNO=1, EXPDATATYPE=5G, FEATURETYPE=REDCAP;

/*---------登录OM Portal命令界面，进入“USCDB MML命令”窗口---------*/ 
/*如果大网UDM将SFTP Server作为服务端，供园区下载数据，则配置如下*/
/*设置SFTP Server的园区子目录*/
ADD SFTPUSER: USERTYPE=DATAMTN, USERNAME="testname", PWD="***********", CFM="***********", WORKPATH="DOWNLOADEXPORTFILE", SUBPATH="campus1" , PERMISSION=UPLOAD-0&DOWNLOAD-1, DESCRIPTION="userinfo";

/*添加园区定制导出配置*/
ADD CUSEXPCFG: FETYPE=SUP-FE, CAMPUSNAME="campus1", SFTPTYPE=SERVER, SFTPUSERNAME="sftpserver2", PWD="***********", CFM="***********";

/*如果大网UDM将SFTP Server作为客户端，将园区数据上传到第三方SFTP文件服务器，则配置如下*/
/*设置SFTP服务器*/
ADD RSFTPSERVER: SERVERTYPE=DATAMTN, SERVERNAME="unicomserver", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=22, USERNAME="name", AUTHTYPE=PASSWORD, PWD="***********", CFM="***********", RWORKDIR="campus1", LWORKDIR="UPLOADEXPORTFILE", AUTOCREATEDIR=TRUE, TRANSDIRECTION=UPLOAD, LOCALIPV4="10.93.1.131";

/*添加园区定制导出配置*/
ADD CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="campus1", SFTPTYPE=CLIENT, SFTPSERVERNAME="sftpserver1", PWD="***********", CFM="***********";

/*---------登录PGW Web LMT MML命令界面，进入“系统管理”窗口---------*/ 
/*启动定时导出任务*/
ADD EXPTASK: FETYPE="SUP-FE", TPLNAME="mem_exp_ueg_common_data", TASKTYPE=CYCLE, CYCLEUNIT=DAY, CYCLEVALUE=1, TIME="2021&09&23&12&00&00";
```
