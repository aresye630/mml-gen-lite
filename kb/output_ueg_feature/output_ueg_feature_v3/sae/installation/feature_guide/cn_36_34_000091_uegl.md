# 配置支持P-CSCF恢复机制

## 操作场景

该任务指导操作人员配置HSS支持P-CSCF恢复机制。

## 必备事项

前提条件

* 已完成基础数据配置。
* 操作人员具有数据配置权限。
* 操作人员具有PGW Web LMT客户端业务发放权限。
* 操作人员具有OM Portal权限。
* 操作人员已完全了解支持P-CSCF恢复机制功能。
* 已加载P-CSCF恢复机制业务的相关License。

数据

执行该任务前需要规划的数据如表1所示。

**表1** 配置支持P-CSCF恢复机制数据规划

| 类别 | 参数 | 取值样例 | 说明 |
| --- | --- | --- | --- |
| **SET HSYSTEMPARA** | 是否支持P-CSCF恢复机制 | TRUE | 用于标识HSS是否支持P-CSCF恢复机制。 |
| **SET MAPCONF** | 用户在IMS未注册但IP-SM-GW地址有效时是否转发SRI\_FOR\_SM消息给IP-SM-GW | TRUE | 用于标识在短消息终结流程中，用户在IMS网络未注册，但IP-SM-GW地址有效时，HSS是否转发SRI\_FOR\_SM消息给IP-SM-GW。 |
| **MOD INSP** | 软件参数类型 | HSS9860 | 用于标识当IMS用户注销时，是否保留IP-SM-GW地址。  取值范围：  * 0：表示当IMS用户注销时，清除IP-SM-GW地址。 * 1：表示当IMS用户注销时，保留IP-SM-GW地址。  默认值：0 |
|  | 软件参数名称 | N\_DEL\_IPSMGW |  |
|  | 软件参数值 | 1 |  |

## 操作步骤

1. 登录“IMS-HSS业务管理”窗口。
2. 执行**SET HSYSTEMPARA**命令配置P-CSCF恢复机制。
3. 登录“UDM业务管理”窗口。
4. 执行**SET MAPCONF**配置在短消息终结流程中，用户在IMS网络未注册，但IP-SM-GW地址有效时，转发SRI\_FOR\_SM消息给IP-SM-GW。
5. 登录“UEG MML命令”界面。
6. 执行**MOD INSP**将软参“N\_DEL\_IPSMGW(IMS用户注销时是否保留IP-SM-GW地址)”配置为“1”。

## 任务示例

任务描述

在IMS-HSS上设置“是否支持P-CSCF恢复机制”参数支持P-CSCF恢复机制。

脚本

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*配置P-CSCF恢复机制\*/

```
SET HSYSTEMPARA: P_CSCF_RESTORE_SUPP=TRUE;
```

/\*----------登录“UDM业务管理”窗口----------\*/

/\*配置在短消息终结流程中，用户在IMS网络未注册，但IP-SM-GW地址有效时，转发SRI\_FOR\_SM消息给IP-SM-GW\*/

```
SET MAPCONF: FORWARDING_SMS=TRUE;
```

/\*----------登录“UEG MML命令”窗口----------\*/

/\*配置当IMS用户注销时，是否保留IP-SM-GW地址\*/

```
MOD INSP: INSPT=HSS9860, INSPN=N_DEL_IPSMGW, INSPV=1;
```
