## 操作场景

运营商在部署MEC解决方案或时新增UPF/SGW-U/PGW-U中的任一独立设备或融合设备，完成配置UEG到SMF/SGW-C/PGW-C的路由数据后，可通过配置N4（N4/Sxa/Sxb）接口使UEG与SMF/SGW-C/PGW-C建立逻辑连接。

* 考虑到4G/5G互操作和平滑演进，5GC需要支持4G/5G融合接入和互操作，因此协议规定了三类网元需要原生融合部署。
  + 用户数据：HSS+UDM融合，保证用户数据一致性。
  + 策略数据：PCRF+PCF融合，保证策略一致性、连续性。
  + 会话管理锚点：SMF+PGW-C融合，UPF+PGW-U融合，锚点不变保证数据连续性。从简化网络拓扑，优化转发路径考虑，一般建议EPC侧SGW-C融合到SMF+PGW-C、SGW-U融合到UPF+PGW-U。

  因此部署4G/5G互操作的网络时，SMF、PGW-C需要融合部署在同一VNF上。
* 考虑到4G/5G互操作时移动锚点不变，SMF+PGW-C融合部署时N4、Sxa、Sxb接口使用的协议相同，遵循3GPP TS 29.244标准。因此UEG上只支持使用合一抽象接口配置N4if，不支持独立配置Sxa、Sxb接口。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
* 请了解UEG各类接口的类型及命名规范，具体内容请参见逻辑接口介绍（风筝L）。
* 请阅读并熟悉特性GWFD-021312 Single IP。
* SMF/PGW-C上要求UPF上必须配置N9接口才能作为主锚点UPF激活时，还需要在UPF上完成配置Pa(N9a/S5-P/S8-P/S2b)接口数据。
* 配置N4接口数据后，UEG上至少还需要存在一个数据面的逻辑接口IP（如Paif、Scif或s5-sif或n9cif、Saif或N3if或S1-Uif、S11-uif等），否则，SMF与UPF之间的N4偶联状态异常。

数据

在UEG上配置N4（N4/Sxa/Sxb）接口数据，为UEG与SMF之间的信令路径建立逻辑连接。

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

**如下数据仅为举例，请注意修改成局点规划的数据。**

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置N4（N4/Sxa/Sxb）逻辑接口所属的VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_Signaling";
   ```

   逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
3. 配置N4（N4/Sxa/Sxb）逻辑接口。

   ```
   ADD LOGICINF: NAME="N4if1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.6.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_Signaling";
   ```

   UEG上N4、Sxa、Sxb接口不支持独立配置，只支持使用合一抽象接口名称N4if进行配置。
4. 配置UEG信息。

   ```
   SET UPINFO: HOSTNAME="UP_001";
   ```
5. （风筝S/风筝M非应急场景）一个UPF对接多个SMF场景，还需要进行CU Full Mesh特性配置及相关License申请。

   CU Full Mesh特性配置的详细指导，请参见GWFD-021701 CU Full Mesh组网特性概述。

## 验证方法

1. 进入“MML命令行-UEG”窗口。
2. 执行**LST LOGICINF**命令，查询逻辑接口信息是否与规划数据一致。
   * 一致，请执行3。
   * 不一致，请参考“操作步骤”重新配置，与规划数据一致后执行3。
3. 执行**SRVPING**命令，调测UEG到SMF/SGW-C/PGW-C的数据通信路径。

   * 如下“LOGICINFNAME”/“SRCIPV4ADDR”/“SRCIPV6ADDR”参数值仅为举例，实际调测时，请注意修改成**LST LOGICINF**查询到的N4if接口数据。
   * 如下“DSTIPV4ADDR”/“DSTIPV6ADDR”参数值仅为举例，实际调测时，请注意修改成对接的SMF/SGW-C/PGW-C地址。

   //IPv4地址：

   ```
   SRVPING: SRCIPTYPE=LOGICINF, LOGICINFNAME="N4if1/0/0", IPVERSION=IPv4, SRCIPV4ADDR="10.1.6.1", DSTIPV4ADDR="10.2.6.1";
   ```

   //IPv6地址：

   ```
   SRVPING: SRCIPTYPE=LOGICINF, LOGICINFNAME="N4if1/0/0", IPVERSION=IPv6, SRCIPV6ADDR="FC00::10:1:6:1", DSTIPV6ADDR="FC00::10:2:6:1";
   ```

   * 返回“0.00% packet loss”，请执行4。
   * 返回“100.00% packet loss”或其他非零丢包率，表明通信异常，请执行6。
4. 检查SMF/PGW-C与UPF/GW-U之间的N4偶联状态是否正常。
   * N4偶联状态正常，调测结束。
   * N4偶联状态异常，请执行5。
5. 执行**LST LOGICINF**命令，检查UEG上是否已配置Paif接口。
   * 是，请执行9。
   * 否，请添加Paif逻辑接口后，重新执行4。

     添加Paif逻辑接口的详细操作，请参见配置Pa(N9a/S5-P/S8-P/S2b)接口数据。
6. 执行**SRVTRACERT**命令，查询通信路径中的故障点。

   //IPv4地址：

   ```
   SRVTRACERT: SRCIPTYPE=LOGICINF, LOGICINFNAME="N4if1/0/0", IPVERSION=IPv4, SRCIPV4ADDR="10.1.6.1", DSTIPV4ADDR="10.2.6.1";
   ```

   //IPv6地址：

   ```
   SRVTRACERT: SRCIPTYPE=LOGICINF, LOGICINFNAME="N4if1/0/0", IPVERSION=IPv6, SRCIPV6ADDR="FC00::10:1:6:1", DSTIPV6ADDR="FC00::10:2:6:1";
   ```

   * 返回“1 \* \* Request timed out.”，请执行7。
   * 返回“n \* \* Request timed out.”，请联系最后1个地址所属的网元进行处理。
7. 执行**DSP ROUTE**/**DSP ROUTE6**命令，检查是否存在到对端IP的路由。
   * 存在，请执行9。
   * 不存在，请执行8。
8. 请检查外联口IP及路由配置是否正确。

   检查外联口IP及路由配置的详细步骤，请参见组网路由配置。

   * 是，请执行9。
   * 否，请修改配置后执行3。
9. 收集信息并寻求技术支持。

   1. 在OM Portal上创建“UEG用户跟踪”任务，执行3~8并保存报文和查询结果。
   2. 在“MML命令行-UEG”窗口上执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   3. 收集并保存上述所有查询信息。
   4. 查看并收集对端设备配置及接口状态信息。
   5. 收集归纳所有信息并联系华为技术支持解决。
