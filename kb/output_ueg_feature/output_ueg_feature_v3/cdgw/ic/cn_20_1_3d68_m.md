# 针对HTTP应用基于用户的带宽控制

## 操作场景

为了保护带宽资源不被HTTP流量吞噬，确保应用公平分享带宽资源，UEG基于用户对HTTP流量进行流量监管。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-022701 基于业务感知的带宽控制。
* UEG与网络实体之间的网络环境已经构建完成。
* 完成SIG知识库加载。
* 知名端口已经配置完成。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置BWM业务。
   1. 用HTTP协议定义BWM业务。

      **ADD BWMSERVICE**
   2. 配置两个BWM控制器，设置CAR参数并配置带宽控制算法。

      **ADD BWMCONTROLLER**

      进行用户级/用户组级/整机级带宽控制时，如果要优先保证用户组内标识为绿色的用户流量，则需要配置**ADD BWMCONTROLLER**“COLORISAWARE”为“ENABLE”。

      进行用户级/用户组级/整机级带宽控制时，如果要对不同业务区分优先级时，则需要配置**ADD BWMCONTROLLER**“PRIORITYISAWARE”为“ENABLE”，且通过**ADD BWMRULE**命令参数“BWMRULEPRI”为不同的业务配置不同的优先级。
3. 配置带宽管理用户组。
   1. 定义带宽管理用户组，配置优先级和业务类型。

      **ADD BWMUSERGROUP**
   2. 配置一条用户级带宽控制规则。

      **ADD BWMRULE**
   3. 将APN下的用户包含到该用户组。

      **ADD APNBINDBWMUSRG**

## 任务示例

任务描述

本实例中，操作员在UEG上进行数据配置实现以下要求：

UEG对一个用户组下的每个用户的HTTP业务流进行流量监管。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5TCSA01",SWITCH=ENABLE;
```

//配置BWM业务。

```
ADD BWMSERVICE:BWMSERVICENAME="bs_test",BWMSERVICETYPE=NONTOS,NONTOSSRVTYPE=PROTOCOL,PROTOCOLNAME="http";
```

```
ADD BWMCONTROLLER:BWMCNAME="bc-up",CTRLTYPE=CAR,CIR=300,CBS=10000,PIR=500,PBS=12000,GREEN=PASS,YELLOW=PASS,RED=DISCARD,PRIORITYISAWARE=DISABLE;
```

```
ADD BWMCONTROLLER:BWMCNAME="bc-down",CTRLTYPE=CAR,CIR=300,CBS=10000,PIR=500,PBS=12000,GREEN=PASS,YELLOW=PASS,RED=DISCARD,PRIORITYISAWARE=DISABLE;
```

//配置带宽管理用户组。

```
ADD BWMUSERGROUP:USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="ug_test",USERGROUPPRI=1,USERLEVSRVTYPE=NONTOS;
```

```
ADD BWMRULE:USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="ug_test",BWMRULETYPE=SUBSCRIBER_SPECIFIC,BWMRULENAME="br_test",BWMSERVICENAME="bs_test",UPBWMCTRLNAME1="bc-up",DNBWMCTRLNAME1="bc-down",BWMRULEPRI=1;
```

```
ADD APNBINDBWMUSRG:USERGROUPNAME="ug_test",APN="apn-test";
```
