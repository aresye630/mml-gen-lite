## 操作场景

设备出口跟踪中能够显示消息，不代表跟踪到的消息一定从本设备向外发送成功，请关注系统其他异常告警和性能统计。

* 系统运行出现故障需要进行接口消息跟踪定位排除故障。
* 维护人员调试设备运行情况。

* 适用于SGW-U、PGW-U、UPF。
* 跟踪功能主要用于保障网络运营和服务、检测通信传输中的故障和错误，该功能涉及使用或存储个人用户标识和用户通信内容。建议您只有在所适用法律法规允许的目的和范围内方可启用相应的功能。在使用、存储用户通信内容的过程中，您应采取足够的措施以确保用户的通信内容受到严格保护。
* 操作员在现场使用跟踪功能时，消息跟踪中的IMSI、IP地址等信息仍然是用户的真实信息，是未被加密的。跟踪信息将自动保存到“跟踪管理文件”中。保存到“跟踪管理文件”中的用户IMSI、MSISDN、IMEI、IP地址将被OM Portal做假名化处理（即被加密）。IMSI字段标准定义由0-9的数字组成，假名化后可能出现A-F字母。
* OMU倒换可能造成跟踪任务丢失，请在倒换后检查跟踪任务是否存在，如果不存在，请重新创建。
* OMU倒换可能造成OM Portal断连，请在倒换后检查OM Portal是否断连。如果是，请重新登录OM Portal，并重新创建跟踪任务。
* 当软参BIT2548设置为0，并且平台启用了跟踪流控功能（可通过命令LST MTSCFG: TYPE=FLOW\_CONTROL\_SWITCH, MEID=0查询是否开启），同时CPU使用率超过80%，系统将暂停上报跟踪信息。一旦CPU使用率降至70%以下，或者跟踪流控开关被关闭，跟踪信息将恢复常态上报。
* 不用POD之间时间同步或TICK存在误差，无法完全一致，因此不同POD上报跟踪消息在跟踪界面上呈现按时间戳或TICK排序可能有先后顺序不符合预期的现象，无功能影响。

## 必备事项

前提条件

* 具备管理员权限的操作员已经登录OM Portal。
* 维护人员具有接口消息跟踪权限。
* 有承载报文激活。
* N4接口相关信元请参考N4接口协议简介。

## 操作步骤

1. 在OM Portal主窗口的“监控分析”页签中，单击“消息跟踪”按钮，依次点击“接口跟踪”>“N4接口跟踪”>“创建跟踪任务”按钮，弹出如图1所示。

   **图1** “N4接口跟踪”参数配置对话框
2. 对话框中进行参数配置，参数说明如表1所示。

   最多支持32个接口跟踪任务。

   **表1** “N4接口跟踪”参数配置说明

   | 字段名 | 说明 |
   | --- | --- |
   | 任务名称 | 该参数表示任务名称的自定义部分，用于用户区分和查找不同的跟踪任务。 说明：  * 任务名命名方式：“自定义任务名\_年月日\_时分秒毫秒\_任务序列号”，如“test2\_20170116\_154201632\_0”。自定义任务名仅支持数字，字母和下划线。 * 默认情况下，依据跟踪类型、跟踪开始日期及时间（含夏令时标志）和当前跟踪任务的序列号作为跟踪任务的名称。 |
   | 跟踪时长 | 该参数用于设置跟踪任务的时长，用户可以根据需要自定义跟踪任务时长。 说明：  跟踪时长默认值是1小时，最多设置720小时59分钟。 |
   | 选项 | 取值为“INTERFACE”、“LOCALIPv4”和“LOCALIPv6”。  * INTERFACE：表示按照接口类型跟踪消息。 * “LOCALIPv4”：表示按照UEG侧逻辑接口IPv4地址跟踪消息。 * “LOCALIPv6”：表示按照UEG侧逻辑接口IPv6地址跟踪消息。 |
   | 逻辑接口 | 当“选项”值为“INTERFACE”时，该参数会显示，表示需跟踪的UEG N4逻辑接口。取值样例：n4if1/0/0。 |
   | 本端IP地址 | 当“选项”值为 “LOCALIPv4”或“LOCALIPv6”时，该参数会显示，表示需跟踪的UEG N4接口所在的逻辑接口地址。 |
   | 对端IP地址 | 当“选项”值为 “LOCALIPv4”或“LOCALIPv6”时，该参数会显示，表示需跟踪的UEG N4接口所在的对端逻辑接口地址。 |
   | VPN实例名 | 当“选项”值为“LOCALIPv4”或“LOCALIPv6”时，该参数会显示，表示需跟踪的UEG N4接口所在的VPN。 |
   | 消息类型 | * **PFCP NODE MESSAGE**：用于控制跟踪N4接口NODE级消息。缺省：选中。 * **PFCP SESSION** **MESSAGE**：用于控制跟踪N4接口SESSION级消息。缺省：选中。 * **EMS PFCP** **MESSAGE**：用于控制跟踪N4接口EMS消息。**EMS Rule Installation Failure**：用于控制跟踪N4接口Rule安装失败的EMS消息。 * **GTP-U MESSAGE**：用于控制跟踪N4接口GTP-U消息。 * **EMS DROP**：用于开启EMS丢包跟踪。 说明：  EMS消息如果无源端口和目的IP信息，csp显示为空，网管显示为NA。 |
3. 单击“确定”或“完成”，启动跟踪任务。
