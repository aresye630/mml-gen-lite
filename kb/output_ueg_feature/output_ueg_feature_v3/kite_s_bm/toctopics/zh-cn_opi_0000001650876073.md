## 操作场景

软件安装阶段，已完成网元名称和浮动IP地址的配置以及OM物理端口设置。在开局阶段或者现网使用时，如果需要修改，可参考本页面调整登录网元OM Portal的网元名称、浮动IP地址、OM物理端口。

网元名称、浮动IP地址需要与网管上配置的名称和IP地址属性一致，如果本端修改了网元名称和浮动IP地址，需要在网管上同步修改该网元的名称和IP地址属性。

## 对系统的影响

* 修改网元浮动IP地址后，OM Portal将会退出，需要使用新浮动IP地址重新登录。
* 修改网元浮动IP地址后，网管与网元之间的连接将中断，需要在网管上重新对接网元。
* 调整OM物理端口后，可能会导致OM Portal断链以及网管断链。
* 调整OM物理端口后，需重启调整后的OM物理端口所在的单板。

## 必备事项

前提条件

* 已经确认现网规划的网元名称、浮动IP地址与网元生产预安装的预设参数值不同。
* 已登录网元OM Portal。

  硬件服务器可通过192.168.6.10登录：

  将调测PC连接到服务器的级联网口，并将调测PC的IP配置为192.168.6.10/24同网段的IP，登录网元OM Portal。例如将调测PC的IP配置为192.168.6.11/24，通过https://192.168.6.10:31943登录OM Portal。
* 已从网管侧获取网管登录信息。

## 操作步骤

1. 登录网元OM Portal，选择“应用管理 > MML”。
2. 调整OM物理端口。仅UEG采用刀片式服务器2U硬件时，支持调整OM物理端口。
   1. 执行**SET INSTPARA**调整OM物理端口。

      * 执行**SET INSTPARA**命令前，请跳转到该命令仔细阅读该命令的注意事项。
      * 该命令若执行不当，会导致所有业务中断。请确认参数正确后，再执行此操作。
      * 调整OM物理端口后需重启对应的单板。

      //规划的OM物理端口采用bonding口时：

      ```
      SET INSTPARA: PARATYPE=OMPORT, SERVERNAME="paas-192-168-2-2", PORTTYPE=1, PORTNAME="Eth-trunk1", SUBPORT="eth11:eth21", BONDMODE=4, LACPRATE=1, HASHPOLICY=1;
      ```

      //规划的OM物理端口采用单端口时：

      ```
      SET INSTPARA: PARATYPE=OMPORT, SERVERNAME="paas-192-168-2-2", PORTTYPE=0, PORTNAME="eth93";
      ```
   2. 重启调整后的OM物理端口所在的单板。

      重启单板的详细操作请参见管理刀片服务器。
   3. 重新登录OM Portal，并重新对接网管。

      执行**SET INSTPARA**命令后可能会导致OM Portal断链以及网管断链，重启单板后需重新登录OM Portal，并重新对接网管。
3. 执行**MOD ME**将网元名称修改为现网规划的网元名称，脚本示例如下。

   ```
   MOD ME: MEID=0, MENAME="APP";
   ```
4. 执行**LST NETWORK**检查VLANID是否配置正确。
   * VLANID配置正确 ，执行6。
   * VLANID配置不正确，执行5。
5. 执行**MOD NETWORK**修改系统网络的网卡VLANID。

   ```
   MOD NETWORK: IPTYPE=IPV4, NWNAME="OM", VLANID=2002, CONFIRM=Y;
   ```

   修改扩展域VLANID后需重启节点生效。
6. 执行**LST OMIP**检查物理IP地址、浮动IP地址等与网设规划的数据是否一致。
   * 一致，执行8。
   * 不一致，执行7。
7. 执行**SET OMIP**设置系统IP地址。

   * “OM IP模式”是“精简”模式：浮动IP地址不正确时，执行**SET OMIP**将浮动IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1";
     ```

     “OM IP模式”是“精简”模式时，可不配置物理IP1或将物理IP1地址设置为与浮动IP地址相同。若配置的物理IP1与浮动IP取值不同，则命令执行失败。此处以不配置物理IP1为例。

   * “OM IP模式”不是“精简”模式：未配置物理IP地址或已配置的物理IP地址与现网规划的IP地址不一致，执行**SET OMIP**将浮动IP地址、物理IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1", OMHOST1IPV4="10.145.27.174";
     ```

     “OM IP模式”不是“精简”模式时，物理IP1须与浮动IP在同一网段。
8. 如果已在网管上创建网元，则需要登录网管客户端，修改网管上网元名称、IP地址属性为现网规划的信息。

   操作方法请参见MAE产品文档，“操作与维护 > MAE-Access操作与维护 > 拓扑管理 > 维护拓扑对象 > 修改拓扑对象”。
9. UEG直连DCGW场景，执行**SET OMNICSWAPSWITCH**命令，支持备OM口进行业务容灾。

   ```
   SET OMNICSWAPSWITCH: SWITCH=ON;
   ```
