#### 操作场景

为了避免操作员一个人执行高危命令时，由于个人疏忽、误操作产生严重事故，系统提供了对高危命令的二次授权能力，即操作员执行被二次授权的高危命令时必须经过二次授权用户的授权确认，保证操作安全。

在开局或日常维护过程中，系统默认关闭高危命令二次授权功能，建议用户对高危命令开通二次授权功能，并配置二次授权用户和二次授权命令。被添加到二次授权命令列表中的命令，在执行时均需经过二次授权用户的授权确认。

高危命令二次授权功能同时支持在网元OM Portal或者网管进行配置操作，本章节主要以OM Portal操作为例介绍。

#### 前提条件

在普通域，使用admin用户登录OM Portal。

在扩展域，使用系统管理员权限用户登录OM Portal。如果登录OM Portal用户无系统管理员权限，请在OM Portal的“安全 > 用户管理 > 角色”为用户添加系统管理员权限。

#### 操作步骤

1. 选择“应用管理 > MML”，选择需要执行MML的应用窗口。
2. 执行**SET SECAUTH**命令开启二次授权功能开关。

   ```
   SET SECAUTH: STATUS=ON;
   ```
3. 执行**ADD USRSECAUTH**命令增加二次授权用户，该用户需已在OM Portal的“安全 > 用户管理”创建。

   ```
   ADD USRSECAUTH: USRNAME="User01";
   ```
4. 当用户需要增加二次授权命令时执行，执行**ADD SECAUTHMEM**命令。

   ```
   ADD SECAUTHMEM: MEID=0, COMMAND="LST ME";
   ```

#### 验证方法

1. 在“应用管理 > MML”，执行已添加需二次授权的命令**LST ME**。
2. MML操作界面弹出二次授权命令提示，参考图1输入操作步骤3中已配置的二次授权用户名和密码，单击“确定”。

   **图1** 二次授权弹窗
3. MML操作界面向操作员返回MML执行结果。

#### 相关参考

为保证操作安全，系统提供了二次授权命令的管理功能。凡是在二次授权命令列表中的命令，在执行时均需要经过二次授权确认。同时，系统将一部分高危命令作为默认的二次授权命令，且系统默认的二次授权命令不允许删除。

**表1** CSP默认的二次授权命令

| 网元类型 | MML名称 | 说明 |
| --- | --- | --- |
| CSP | **MOD VIRTUALIP** | 用于修改登录OM Portal的浮动IP地址。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **SET OMIP** | 用于修改系统OM网络配置参数。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **MOD NETWORK** | 该命令仅适用于部分场景，具体请参考命令帮助。  用于修改系统OM网络的网卡VLANID。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **MOD OMNWCONF** | 用于配置OM网络故障探测参数。  该命令仅限角色为Administrators的用户执行。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **RMV HPATCH** | 该命令用于删除指定网元微服务进程的热补丁。  执行该命令操作不当会影响系统的正常运行，需要进行二次授权。 |
| CSP | **RST MESYS** | 该命令用于对网元下的Pod进行重建。  执行该命令会导致Pod复位期间部分服务可能不可用，需要进行二次授权。 |
| CSP | **SET CNTTMPDIR** | 该命令用于设置容器引擎临时目录。  执行该命令会复位容器引擎，可能导致业务受损，需要进行二次授权。 |
| CSP | **RST CASCADELINK** | 该命令用于复位多框级联链路。  执行该命令可能会导致业务受损，需要进行二次授权。 |
| CSP | **MOD DBPWD** | 该命令用于修改数据库密码。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **SET OMSWITCH** | 用于设置OM功能开关的开关状态。  执行该命令可能会导致通信中断，需要进行二次授权。 |
| CSP | **SET CLTVFYSWITCH** | 用于修改双向认证开关。  执行该命令可能会导致通信中断，需要进行二次授权。 |
