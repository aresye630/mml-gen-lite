## 操作场景

为方便用户对日志进行分析和审计，CSP支持与Syslog日志收集服务器对接，将日志上传到指定的Syslog日志收集服务器。其中，CSP支持对接一个网管Syslog日志收集服务器及最多三个第三方或华为Syslog日志收集服务器。

本章节介绍CSP与Syslog日志收集服务器通过OM Portal上的“系统 > Syslog管理”进行对接的方法。该对接方式支持TLS协议、TCP协议和UDP协议，如果CSP与第三方或华为Syslog日志收集服务器使用TLS协议对接，也可采用MML方式对接。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* 已登录OM Portal。
* Syslog日志收集服务器已配置Server端数字证书。

  如果Syslog日志收集服务器是华为公司的设备，则Syslog日志收集服务器使用系统初始证书即可，无需再配置。

数据

* 已获取要对接的Syslog日志收集服务器IP地址、端口以及协议类型（TLS、TCP或UDP）。
* 已获取CSP侧使用的Client端数字证书。

  + 如果CSP对接的是华为公司的Syslog日志收集服务器，则CSP使用系统初始证书即可，无需再配置。
  + 如果用户没有数字证书，请提前向华为公司或者其他有颁发证书权限的机构申请。
  + 如果协议配置错误或者网络异常会使Syslog“连接状态”为“断开”。
  + 在使用UDP协议的情况下，由于其单向通信特性，配置错误的Syslog服务器的IP地址或端口，前端页面显示的Syslog任务“连接状态”仍会显示“连接”。因此，针对UDP协议的“连接状态”可不予关注。
  + 在使用TCP协议的情况下，由于业务探测机制发送心跳，对端TCP服务器不会解析，会导致心跳乱码，第三方服务器应丢弃乱码数据，并按照Syslog日志格式进行解析。
  + 相关算法、协议由Syslog日志收集服务器配置决定。
  + 如果CSP对接的是第三方的Syslog日志收集服务器，需要服务器支持设置TCP流“CRLF”分隔符，用于Syslog日志内容分隔正确。
  + 配置Syslog任务生效需要一定时间，建议配置Syslog任务操作时间间隔1分钟。
  + 配置网管Syslog任务时，建议在关联CA证书场景之前，先把设备场景上面对应的证书激活（单击操作列的“关联证书”按钮，然后，直接点击“确认”即可）。
  + 操作日志、安全日志、事件日志和系统日志，首次配置下发后，日志产生到上报时间间隔不超过2分钟，后续间隔30秒上报；Web日志、DB日志、OS日志和OS安全日志，首次配置下发后，日志产生到上报时间间隔不超过10分钟，后续间隔2分钟上报；运行日志首次配置下发后，日志产生到上报时间间隔不超过2分钟，后续实时上报。

## 操作步骤

1. 确认CSP与Syslog日志收集服务器的对接协议类型。

   * 如果是TLS协议 => 请执行2。
   * 如果是TCP或UDP协议 => 请执行4。
2. 选择“安全 > 证书管理 > 证书与证书集管理”，依次上传设备证书 、CA证书。
3. 选择“安全 > 证书管理 > 证书应用场景关联”，依次将2中上传的设备证书、CA证书分别按照表1进行场景关联。

   **表1** 可关联的证书场景

   | 场景证书类型 | 场景描述 |
   | --- | --- |
   | Device | 对接syslog服务器用户设备证书 |
   |  | 对接syslog拓展服务器1用户设备证书 |
   |  | 对接syslog拓展服务器2用户设备证书 |
   |  | 对接syslog拓展服务器3用户设备证书 |
   | CA | 对接syslog服务器用户CA证书 |
   |  | 对接syslog拓展服务器1用户CA证书 |
   |  | 对接syslog拓展服务器2用户CA证书 |
   |  | 对接syslog拓展服务器3用户CA证书 |

   * 待关联场景的证书可关联对应“场景证书类型”中的任意可选择的证书场景。
   * 每一个场景的CA和设备证书必须匹配。
4. 在OM Portal上选择“系统 > Syslog管理”。
5. 单击“创建Syslog转发配置”，设置如下参数后，单击“保存”。

   **表2** Syslog配置

   | 参数名 | 参数含义 | 参数取值 |
   | --- | --- | --- |
   | IP类型 | CSP对接的Syslog日志收集服务器IP类型。 | 取值范围：  * IPv4 * IPv6 默认值：IPv4。 |
   | 服务器IP | CSP对接的Syslog日志收集服务器IP。 | 取值范围：必须为有效IP地址。  默认值：无。 |
   | 服务器端口 | Syslog日志收集服务器侧的端口。 | 取值范围：1~65535。  默认值：无。 |
   | 协议类型 | CSP与Syslog日志收集服务器的对接协议。 | 取值范围：  * TLS * TCP * UDP 默认值：TLS。 |
   | 日志类型 | CSP上传到Syslog日志收集服务器的日志类型。 | 取值范围：  * 操作日志：日志审计中的紧急和重要的操作日志及查询类日志。 * 安全日志：日志审计中的紧急、重要和次要的安全日志。 * Web日志：服务日志中的Web接口调用的网关日志。 * DB日志：服务日志中的用户访问业务数据库的操作日志。 * OS日志：记录Linux操作系统内核及OS服务的操作日志。 * 运行日志：服务日志中的服务运行日志。 * 事件日志：日志审计中的次要的操作日志。 * OS安全日志：OS日志中记录后台用户登录认证及会话操作的系统安全日志。 * 系统日志：日志审计中的紧急、警报、严重、错误、警告、通知、信息、调试级别的系统日志。 * FW日志：业务防火墙日志。 说明：  * 如果第三方Syslog服务器不支持解析“系统日志”，则“创建Syslog转发配置”时不建议勾选“系统日志”。 * “OS日志”、“OS安全日志”和“系统日志”仅在Full-stack虚机场景下支持。 * “FW日志”需要业务注册后界面展示，非通用类型日志，不支持通过MML命令**SET SYSLOGTASK****SET SYSLOGTASK**、**LST SYSLOGTASK****LST SYSLOGTASK**、**RMV SYSLOGTASK****RMV SYSLOGTASK**进行配置操作。  默认值：操作日志。 |
   | 是否启用 | 是否将日志上传至Syslog日志收集服务器。 | 取值范围：  * 启用 * 停用 默认值：启用。 |
   | 是否启用不安全加密算法 | AuditLog是否使用不安全加密算法与对端建立连接。  须知：  启用不安全加密算法可能存在安全风险。 | 取值范围：  * 启用 * 停用 默认值：停用。 |
   | 开启Syslog服务器端SAN校验 | CSP是否对Syslog日志收集服务器证书的SAN（Subject Alternative Names）校验。  须知：  开启CSP对Syslog日志收集服务器证书的SAN校验时，若Syslog日志收集服务器侧证书的SAN不合法，则SAN校验不通过 ，可能会导致CSP与Syslog日志收集服务器通信异常。 | 取值范围：  * 开启 * 关闭 默认值：关闭。 |
   | 描述 | Syslog配置的描述信息。 | 取值范围：不超过100字符。  默认值：无。 |

   当“日志类型”设置为“运行日志”时，可能会上报“ALM-5525 容器资源过载”告警，设置为其他值后告警恢复，产生该告警对系统无影响。
6. 查看新增加的Syslog配置行的“连接状态”列。

   * 如果“连接状态”为“连接” => 说明CSP与Syslog日志服务器之间的网络连接成功。
   * 如果“连接状态”为“断开” => 请联系技术支持。
