## 操作场景

**接口介绍**

N4接口是SMF与UPF之间的接口，用于传输SMF和UPF间的控制面及用户面信息，通过该接口使控制面和用户面配合完成用户面规则下发和隧道建立功能。

N4接口协议栈如图1所示。

**图1** N4接口协议栈

* PFCP（Packet Forwarding Control Protocol）：SMF与UPF间控制面的数据转发协议。
* GTP-U（GPRS Tunnelling Protocol for the user plane）：利用隧道协议在骨干网的GSN间传输用户数据，使用隧道协议传输数据，屏蔽上层协议影响，同时提供会话级的双向快速传输通道。GTP协议用户面除数据包外，还包括数据传输出错指示、支持的扩展头列表等用户面传输辅助信令。

园区风筝方案采用盒式部署时，SMF只连接本DC UEG内的业务网元，不跨UEG与对接DC的业务网元对接。

以下配置数据以及步骤均以UEG双DC组网UPF fullmesh连接场景的配置规划为例进行介绍。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。
* 已完成组网路由配置。

* 如果本接口采用IPv6组网，则需要开通逻辑接口支持IPv6特性，即加载对应的License项“81203214 LKV3G5V6LI01 逻辑接口支持IPv6”。
* 在双DC部署场景下如果两个DC的UEG内的UPF采用主、备模式组网，SMF需要和两个DC内的UPF FullMesh组网，需要开通FullMesh相关特性，需要加载对应的License项“82209861 LKV3G5CUFM01 CU FullMesh组网”。
* 已经获取网设LLD文档。

数据

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

## 操作步骤

1. 配置N4接口的IP地址。

   ```
   //DC1
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.26.0.5", VPNINSTNAME="VRF_CN", DESC="FOR N4 Interface";
   //DC2
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.26.0.6", VPNINSTNAME="VRF_CN", DESC="FOR N4 Interface";
   ```
2. 配置控制面节点实例。

   ```
   //DC1
   ADD CPNODE: CPNODEINDEX=0, NODEIDTYPE=CpIPv4, NODEIDIPV4VALUE="10.26.0.5", CPFUNCTION=0;
   ADD CPPOINT:CPPOINTINDEX=0,CPNODEINDEX=0,IPVERSION=IPv4,IPV4="10.26.0.5", VPNNAME="VRF_CN";
   //DC2
   ADD CPNODE: CPNODEINDEX=0, NODEIDTYPE=CpIPv4, NODEIDIPV4VALUE="10.26.0.6", CPFUNCTION=0;
   ADD CPPOINT:CPPOINTINDEX=0,CPNODEINDEX=0,IPVERSION=IPv4,IPV4="10.26.0.6", VPNNAME="VRF_CN";
   ```
3. 配置用户面节点实例。

   1. 配置Profile实例。

      ```
      //DC1
      ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.10", PORT=8080, CAPACITY=1;
      //DC2
      ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf02.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080, CAPACITY=0;
      ```
   2. 配置用户面节点支持的切片与DNN信息，SMF可以基于切片、DNN选择UPF。

      ```
      //DC1
      ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_0", SST=1, SD="000001";
      ADD PNFDNN:INDEX=3, NFINSTANCEID="UPF_Instance_0", DNN="huawei.com", PNFNSINDEX=3;
      //DC2
      ADD PNFNS: INDEX=4, NFINSTANCEID="UPF_Instance_1", SST=1, SD="000001";
      ADD PNFDNN:INDEX=4, NFINSTANCEID="UPF_Instance_1", DNN="huawei.com", PNFNSINDEX=4;
      ```
4. 配置用户面节点的位置特征和分流能力。

   ```
   //DC1
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_0", VPNNAME="VRF_CN",PDUESTWITHOUTN9=ENABLE;
   //DC2
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", VPNNAME="VRF_CN",PDUESTWITHOUTN9=ENABLE;
   ```
5. 配置用户面支持的为SMF提供服务区域的信息，并将服务区与位置区TAI绑定，SMF可以基于位置信息选择UPF。

   ```
   //DC1
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA1";
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12303260101", N2ENDTAI="12303260102";
   //DC2
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA1";
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12303260101", N2ENDTAI="12303260102";
   ```

## 验证方法

检查到UPF的链路状态。

```
DSP PFCPASSOC: QUERYTYPE=NfInstanceName, NFINSTANCENAME="UPF_Instance_1";
```

* **预期结果**：“偶联状态”为“NORMAL”，且“链路状态”为“NORMAL”。
* **异常结果**：“偶联状态”为“UNKNOWN”或者“ERROR”，或“链路状态”为“UNKNOWN”或者“ERROR”。
