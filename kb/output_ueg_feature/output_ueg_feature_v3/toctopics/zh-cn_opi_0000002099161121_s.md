当存在如下情况时，可以参考本页面进行配置。

* CPE下挂多个终端（最多16个）。
* 同一个二层广播域内的终端IP必须不同。
* 支持如下几种典型业务场景：
  + 5G LAN层二终端与Server（Main PLC/MES/...）需要互通。

    Server（Main PLC/MES/...）部署在N6侧。
  + 同一5G LAN组层二终端之间通过同一UPF互通。
  + 同一5G LAN组层二终端之间通过不同UPF互通，即总部园区2个UEG-L之间、总部园区UEG-L与子园区各UEG-S之间。

    子园区交换机与UPF之间建立VXLAN隧道的场景下，需要根据LSW的能力判断是否需要多对LSW（用于建立VXLAN隧道）。LSW支持VXLAN进VXLAN出（接收VXLAN报文，处理后重新封装成VXLAN报文发出）时，可只部署一对LSW。否则，需要每台UEG对接一对LSW。

    两个UPF仅对接一对企业侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。

## 任务示例

任务描述

子园区企业侧交换机与UPF之间建立VXLAN隧道的场景，两个VXLAN交换机是堆叠组网或M-LAG组网时，两个VXLAN交换机都是只需要提供一个VTEP IP。

总部园区的UPF和子园区的UPF对接同一对企业侧VXLAN交换机时，支持UPF之间建立VXLAN隧道，用于实现跨UPF的终端互访。两端UPF作为VXLAN隧道端点，都必须配置上本端的VTEP IP，用于对端UPF互通的端点信息。本任务以一个UPF配置VXLAN隧道为例。

不同的5G LAN组共用VTEP，一个5G LAN组对应一个VNI。如图4所示。

UEG-S独立部署场景参考“5GC toB 原子能力-5G LAN>网络部署>配置实例>层二5G LAN配置实例（UEG-S）”章节配置，可以支持子园区5G LAN终端接入子园区UEG-S，以及5G LAN终端在子园区UEG-S的互访。本任务示例用于支持同一5G LAN组的层二终端在子园区UEG-S与总部园区UEG-L之间互通。

**图4** VXLAN隧道数据规划图

脚本

1. 配置VXLAN隧道远端端点（VTEP：UPF），VTEPIPV4为远端端点IP，来源于另一UPF的VXLAN隧道端点IP地址。对端UPF必须对接到同一对企业侧VXLAN交换机。

   //远端为总部园区UEG-L的VXLAN隧道端点IP地址。

   ```
   ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.1.50.1"; 
   ADD VTEP: VTEPNAME="VTEP2", IPVERSION=IPV4, VTEPIPV4="10.1.51.1";
   ```

   //配置VXLAN隧道端点绑定VXLAN隧道组。

   ```
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP1", PRIFLAG=PRIMARY;
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP2", PRIFLAG=PRIMARY;
   ```
