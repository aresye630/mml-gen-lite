## 操作场景

**接口介绍**

N2接口是5G系统中(R)AN和AMF之间的控制面接口，N2接口的信令连接功能为无线网络信令提供可靠的传输。

N2接口协议栈如图1所示。

**图1** N2接口协议栈图

* NG-AP（NG Application Protocol）：gNodeB与AMF之间的应用层协议。
* SCTP（Stream Control Transmission Protocol）：此协议用于保证gNodeB与AMF之间的信令消息传送。
* N2接口支持IPSec（Internet Protocol Security）和DTLS（Datagram Transport Layer Security），以保证数据传输的安全。
* N2接口支持SCTP数据绑定，把多个接口消息组合在一个SCTP包中发给gNodeB，减少寻呼消息数。

**配置建议**

AMF的N2接口业务IP地址不能和AMF其他接口业务IP地址共用（除S1接口）。

以下配置数据以及步骤均以UEG双DC组网场景的配置规划为例进行介绍。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* 已完成组网路由配置。
* 如果本接口采用IPv6组网，则需要开通逻辑接口支持IPv6特性，即加载对应的License项“81203214 LKV3G5V6LI01 逻辑接口支持IPv6”。
* 已经获取网设LLD文档。

## 操作步骤

1. 配置N2接口业务IP地址。

   ```
   //DC1
   ADD SERVICEIP: IPVERSION=IPv4, SERVICEIPV4="172.16.2.3", VPNINSTNAME="VRF_Access";
   ADD SERVICEIP: IPVERSION=IPv4, SERVICEIPV4="172.16.2.4", VPNINSTNAME="VRF_Access";
   //DC2
   ADD SERVICEIP: IPVERSION=IPv4, SERVICEIPV4="172.16.2.5", VPNINSTNAME="VRF_Access";
   ADD SERVICEIP: IPVERSION=IPv4, SERVICEIPV4="172.16.2.6", VPNINSTNAME="VRF_Access";
   ```
2. 配置SCTP协议参数及SCTP本端实体。

   ```
   //DC1
   ADD CPSCTPPARA: SCTPPARAINDEX=0, CHKSUMTX=YES, CHKSUMRX=YES;
   ADD SCTPLEGRP: SCTPGROUPID=1;
   ADD SCTPLE: SCTPLEIDX=0, SCTPGROUPID=1, IPVERSION=IPV4, LOCALIPV41="172.16.2.3", LOCALIPV42="172.16.2.4", PORT=38412, SCTPPARAIDX=0;
   //DC2
   ADD CPSCTPPARA: SCTPPARAINDEX=0, CHKSUMTX=YES, CHKSUMRX=YES;
   ADD SCTPLEGRP: SCTPGROUPID=1;
   ADD SCTPLE: SCTPLEIDX=0, SCTPGROUPID=1, IPVERSION=IPV4, LOCALIPV41="172.16.2.5", LOCALIPV42="172.16.2.6", PORT=38412, SCTPPARAIDX=0;
   ```
3. 配置NGAP本端实体。

   ```
   //DC1
   ADD NGAPPARA: NGAPPARAIDX=1, AMFCFGUPTTMR=20, AMFCFGUPTCNT=3, RESETTMR=20, RESETCNT=3, TIMETOWAITFLG=Yes, TIMETOWAITTMR=Sixty;
   ADD NGAPLE: NGAPLEIDX=1, SCTPGROUPID=1, NGAPPARAIDX=1;
   //DC2
   ADD NGAPPARA: NGAPPARAIDX=1, AMFCFGUPTTMR=20, AMFCFGUPTCNT=3, RESETTMR=20, RESETCNT=3, TIMETOWAITFLG=Yes, TIMETOWAITTMR=Sixty;
   ADD NGAPLE: NGAPLEIDX=1, SCTPGROUPID=1, NGAPPARAIDX=1;
   ```
4. 开启无用户上下文处理基站消息增强开关。

   ```
   //DC1
   SET NGMMFUNC: NOUECTXOPTSW=ON;
   //DC2
   SET NGMMFUNC: NOUECTXOPTSW=ON;
   ```

## 验证方法

1. 在N2接口中检查对端是否可达，目的地址为NG-RAN的地址。

   ```
   INNERPING: IPVERSION=IPv4, VPNNAME="VRF_Access", SOURCEIPV4ADDRESS="172.16.2.5", DESTIPV4ADDRESS="172.16.14.7", SERVICEINSTANCE="LINK_VNFC";
   ```

   * **预期结果**：看到响应报文，并且报文中有成功收发包的个数。
   * **异常结果**：无法收到对端的响应报文。检查服务化接口链路状态。
2. 检查到NG-RAN的配置。检查到NG-RAN之间的链路状态。

   ```
   DSP NGAPLINK: OUTPUTTYPE=Screen, NGAPLEIDX=1;
   ```

   * **预期结果**：“链路状态”为“CONNECTED”。
   * **异常结果**：“链路状态”为“RELEASING”。
3. 检查系统的NG寻呼表信息。

   ```
   DSP NGPAGING: QUERYTYPE=QUERYALL;
   ```

   * **预期结果**：NG寻呼表中包含已配置的NG-RAN信息。
   * **异常结果**：NG寻呼表中没有包含已配置的NG-RAN信息。
