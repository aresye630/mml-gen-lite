# 配置Diameter信令数据（与MME对接）

## 操作场景

接入4G/5G NSA用户时，Diameter信令数据用于EPC HSS和MME对接。

HSS（UDM）通过Diameter信令与对端网元（如MME）互通时，需要配置该页面。

HSS（UDM）和MME直联对接，即不通过DRA设备。

## 必备事项

前提条件

* 已完成配置UDM基础数据。
* HSS（UDM）和MME之间外联口通信正常。

数据

**如下数据仅为举例，请注意修改成局点规划的数据。**

* 主备容灾模式组网中，同一UEG内的HSS和MME对接，不同UEG内不交叉对接。即：DC1的HSS和DC1的MME对接；DC2的HSS和DC2的MME对接。
* 负荷分担容灾模式组网中，HSS需要和同一UEG内的MME对接，也需要与不同UEG内的MME交叉对接。即：DC1的HSS和DC1的MME对接，也和DC2的MME对接；DC2的HSS和DC2的MME对接，也和DC1的MME对接。
  + 网元选择时，MME仅选择同一UEG内的HSS。
  + 由于无线信号的原因，用户A尝试接入其他网络并被其他网络拒绝接入后，基站会清除用户A从哪个MME（例如MME01）接入的记录，但此时MME上仍存在用户A的上下文信息。用户A重新接入时，若基站选择另一个MME（例如MME02），MME02选择HSS02，HSS02需要能够通知MME01删除残留的用户A的上下文信息，否则用户A业务失败。

红色字体的取值样例，是负荷分担容灾模式组网时需要规划的数据，主备容灾模式组时不需要规划。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 增加Diameter本端实体。

   //DC1：

   ```
   ADD DMLE: EN="HSS01", LOCTYPE=SAE-HSS, DN="huawei.com", HN="HSS01.huawei.com";
   ```

   //DC2：

   ```
   ADD DMLE: EN="HSS02", LOCTYPE=SAE-HSS, DN="huawei.com", HN="HSS02.huawei.com";
   ```
3. 增加Diameter对端实体。

   //DC1：

   ```
   ADD DMPE: EN="MME01", PEERTYPE=OTHER, HN="MME01.huawei.com";
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   ADD DMPE: EN="MME02", PEERTYPE=OTHER, HN="MME02.huawei.com";
   ```

   //DC2：

   ```
   ADD DMPE: EN="MME02", PEERTYPE=OTHER, HN="MME02.huawei.com";
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   ADD DMPE: EN="MME01", PEERTYPE=OTHER, HN="MME01.huawei.com";
   ```
4. 增加Diameter链路集。

   //DC1：

   ```
   ADD DMLKS: LINKSNAM="Diameter01", LOCALNAM="HSS01", PEERNAM="MME01", LNKMOD=ACTIVE;
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   ADD DMLKS: LINKSNAM="Diameter02", LOCALNAM="HSS01", PEERNAM="MME02", LNKMOD=ACTIVE;
   ```

   //DC2：

   ```
   ADD DMLKS: LINKSNAM="Diameter02", LOCALNAM="HSS02", PEERNAM="MME02", LNKMOD=ACTIVE;
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   ADD DMLKS: LINKSNAM="Diameter01", LOCALNAM="HSS02", PEERNAM="MME01", LNKMOD=ACTIVE;
   ```
5. 增加Diameter链路。

   当UEG在煤矿等场景下使用2U1选型时，无需配置以下“DMlink02”和“DMlink04”链路。

   //DC1：

   ```
   //MME01:
   ADD DMLNK: LNKNAME="DMlink01", LINKSNAM="Diameter01", HSFMID=201, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", IPNAM2="HSFIP2", LPT=5000, PIPVER=IPV4, PIPV4="10.200.200.58", SPIPVER=IPV4, SPIPV4="10.200.200.59", PPT=5000, LINKPRI=15, CROSSPATHFLAG=NO; 
   ADD DMLNK: LNKNAME="DMlink02", LINKSNAM="Diameter01", HSFMID=204, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP2", IPNAM2="HSFIP1", LPT=5001, PIPVER=IPV4, PIPV4="10.200.200.59", SPIPVER=IPV4, SPIPV4="10.200.200.58", PPT=5001, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   //MME02:
   ADD DMLNK: LNKNAME="DMlink03", LINKSNAM="Diameter02", HSFMID=201, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", IPNAM2="HSFIP2", LPT=5000, PIPVER=IPV4, PIPV4="10.201.200.58", SPIPVER=IPV4, SPIPV4="10.201.200.59", PPT=5000, LINKPRI=15, CROSSPATHFLAG=NO; 
   ADD DMLNK: LNKNAME="DMlink04", LINKSNAM="Diameter02", HSFMID=204, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP2", IPNAM2="HSFIP1", LPT=5001, PIPVER=IPV4, PIPV4="10.201.200.59", SPIPVER=IPV4, SPIPV4="10.201.200.58", PPT=5001, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   //DC2：

   ```
   //MME02:
   ADD DMLNK: LNKNAME="DMlink03", LINKSNAM="Diameter02", HSFMID=201, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", IPNAM2="HSFIP2", LPT=5000, PIPVER=IPV4, PIPV4="10.201.200.58", SPIPVER=IPV4, SPIPV4="10.201.200.59", PPT=5000, LINKPRI=15, CROSSPATHFLAG=NO; 
   ADD DMLNK: LNKNAME="DMlink04", LINKSNAM="Diameter02", HSFMID=204, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP2", IPNAM2="HSFIP1", LPT=5001, PIPVER=IPV4, PIPV4="10.201.200.59", SPIPVER=IPV4, SPIPV4="10.201.200.58", PPT=5001, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   //UEG负荷分担模式容灾组网时需要配置：

   ```
   //MME01:
   ADD DMLNK: LNKNAME="DMlink01", LINKSNAM="Diameter01", HSFMID=201, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", IPNAM2="HSFIP2", LPT=5000, PIPVER=IPV4, PIPV4="10.200.200.58", SPIPVER=IPV4, SPIPV4="10.200.200.59", PPT=5000, LINKPRI=15, CROSSPATHFLAG=NO; 
   ADD DMLNK: LNKNAME="DMlink02", LINKSNAM="Diameter01", HSFMID=204, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP2", IPNAM2="HSFIP1", LPT=5001, PIPVER=IPV4, PIPV4="10.200.200.59", SPIPVER=IPV4, SPIPV4="10.200.200.58", PPT=5001, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   链路增加后会自动激活，但是如果对链路进行了修改，则需要使用**DEA DMLNK**命令去激活链路，再使用**ACT DMLNK**命令激活链路。

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**DSP DMLNK**命令，查看Diameter链路是否正常。
   * “Diameter链路”状态为“Diam链路断开”，请执行3。
   * “Diameter链路”状态为“Diam链路正常”，则说明状态正常，调测结束。
3. 请参考**Diameter链路故障告警**进行处理。

   处理后重新执行2，如Diameter链路仍异常，请联系华为技术支持工程师。
