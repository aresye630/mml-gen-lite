# 配置组网路由（直连PE）

## 操作场景

UEG-L部署在总部园区，作为SMF/GW-C/MME需要对接子园区UEG-S的UPF/GW-U。UEG-L对接PE时，每个Eth-trunk的两个成员端口连接到同一个PE设备。

UEG通过静态路由+BFD与对端网元（UPF/GW-U）实现网络互通，组网规划如图1所示。

对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

## 任务示例

任务描述

* 总部园区UEG-L的N4和S11-U接口推荐共用VPN，UEG-L采用PE对接方式。
* UEG-L的SMF/GW-C/MME到PE为静态路由+BFD组网。
* 对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST: VRFNAME="VRF_PS_N4",VRFDESCRIPTION="N4";
   ADD VPNINSTAF: VRFNAME="VRF_PS_N4",AFTYPE=ipv4uni, VRFRD="192.168.225.136:100";
   ADD VPNINSTAF: VRFNAME="VRF_PS_N4",AFTYPE=ipv6uni, VRFRD="192.168.225.136:100";
   ```
3. 配置外联口IP地址。
   1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up; 
      MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet64/0/12",IFADMINSTATUS=up; 
      MOD INTERFACE:IFNAME="Ethernet64/0/13",IFADMINSTATUS=up;
      ```
   3. 添加Eth-trunk接口及Eth-trunk子接口。成员端口数量以网设规划的为准。

      ```
      ADD INTERFACE: IFNAME="Eth-trunk1"; 
      MOD TRUNKIF: IFNAME="Eth-Trunk1",WORKMODE=Manual; 
      ADD TRUNKMEMBER: TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/4"; 
      ADD TRUNKMEMBER: TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/5"; 
      ADD INTERFACE: IFNAME="Eth-trunk1.2";
      ```

      ```
      ADD INTERFACE: IFNAME="Eth-trunk2"; 
      MOD TRUNKIF: IFNAME="Eth-Trunk2",WORKMODE=Manual; 
      ADD TRUNKMEMBER: TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/12"; 
      ADD TRUNKMEMBER: TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/13"; 
      ADD INTERFACE: IFNAME="Eth-trunk2.2";
      ```
   4. 增加子接口绑定VPN。

      ```
      ADD IPBINDVPN: IFNAME="Eth-trunk1.2",VRFNAME="VRF_PS_N4";
      ADD IPBINDVPN: IFNAME="Eth-trunk2.2",VRFNAME="VRF_PS_N4";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF: IFNAME="Eth-trunk1.2",VLANTYPEVID=2006;
      ADD ETHSUBIF: IFNAME="Eth-trunk2.2",VLANTYPEVID=2016;
      ```
   6. 配置IPv6使能。

      ```
      SET IFIPV6ENABLE: IFNAME="Eth-trunk1.2", ENABLEFLAG=TRUE;
      SET IFIPV6ENABLE: IFNAME="Eth-trunk2.2", ENABLEFLAG=TRUE;
      ```
   7. 配置外联口IP地址。

      ```
      ADD IFIPV4ADDRESS: IFNAME="Eth-trunk1.2",IFIPADDR="192.168.86.2",SUBNETMASK="255.255.255.248";
      ADD IFIPV4ADDRESS: IFNAME="Eth-trunk2.2",IFIPADDR="192.168.186.2",SUBNETMASK="255.255.255.248";
      ```

      ```
      ADD IFIPV6ADDRESS: IFNAME="Eth-trunk1.2",IPV6ADDRESS="FC00::86:2",PREFIXLEN=125;
      ADD IFIPV6ADDRESS: IFNAME="Eth-trunk2.2",IPV6ADDRESS="FC00::186:2",PREFIXLEN=125;
      ```
4. 新建BFD会话，配置BFD双向探测。PE需支持BFD探测且使用双向BFD探测。

   ```
   ADD BFDSESSION: SESSNAME="BfdName861_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.86.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_PS_N4",LOCALDISCR=8861,REMOTEDISCR=8862,IFNAME="Eth-trunk1.2";
   ADD BFDSESSION: SESSNAME="BfdName1861_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.186.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_PS_N4",LOCALDISCR=8863,REMOTEDISCR=8864,IFNAME="Eth-trunk2.2";
   ```

   ```
   ADD BFDSESSION: SESSNAME="BfdName861_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_PS_N4",LOCALDISCR=8041,REMOTEDISCR=8042,IFNAME="Eth-trunk1.2",DESTADDR6="FC00::86:1";
   ADD BFDSESSION: SESSNAME="BfdName1861_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_PS_N4",LOCALDISCR=8043,REMOTEDISCR=8044,IFNAME="Eth-trunk2.2",DESTADDR6="FC00::186:1";
   ```
5. 采用静态路由+BFD时，配置静态路由并绑定BFD会话。

   //“PREFIX”/“MASKLENGTH”是UEG-S UPF N4接口的IP地址及所在网段掩码长度，请根据网设文档替换。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk1.2",NEXTHOP="192.168.86.1",SESSIONNAME="BfdName861_v4";
   ADD SRROUTE: AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk2.2",NEXTHOP="192.168.186.1",SESSIONNAME="BfdName1861_v4";
   ```

   ```
   ADD SRROUTE6: AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk1.2",NEXTHOP="FC00::86:1",SESSIONNAME="BfdName861_v6";
   ADD SRROUTE6: AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk2.2",NEXTHOP="FC00::186:1",SESSIONNAME="BfdName1861_v6";
   ```
