## 操作场景

当PCF接纳应用层业务请求时，例如应用服务器发起的带宽资源预留请求，PCF需要对接AF（Application Function）实体，以实现应用侧发起的策略控制功能。

* 园区PCF支持PTT业务，且PCF与PTT Server之间通过Rx接口对接时，请参考配置PCF与AF（基于Diameter协议）的对接数据进行配置。
* 园区PCF支持PTT业务，且PCF与PTT Server之间通过N5接口对接时，请参考本页面进行配置。

园区PCF不支持与NRF通信，因此需要手动配置PCF和AF（PTT Server）之间的服务发现。

## 必备事项

前提条件

本端及AF侧已完成基础数据配置。

数据

**如下数据仅为举例，请注意修改成局点规划的数据。**

**表1** 对接的AF信息

文档

获取网设LLD文档。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 增加AF服务发现网元实例信息。

   //DC1和DC2都需要配置。

   ```
   //AF01:
   ADD DISCNFPROFILE: NFINSNAME="AF01", NFINSID="4946a69a-f6b8-4bc1-b9da-47c9c5d148fd", NFTYPE=AF, NFPROFILE="{\"nfInstanceId\":\"4946a69a-f6b8-4bc1-b9da-47c9c5d148fd\",\"nfType\":\"AF\",\"nfStatus\":\"REGISTERED\",\"ipv4Addresses\":[\"172.16.1.50\"]}";
   ```

   ```
   //AF02:
   ADD DISCNFPROFILE: NFINSNAME="AF02", NFINSID="4946a69a-f6b8-4bc1-b9da-47c9c5d148fe", NFTYPE=AF, NFPROFILE="{\"nfInstanceId\":\"4946a69a-f6b8-4bc1-b9da-47c9c5d148fe\",\"nfType\":\"AF\",\"nfStatus\":\"REGISTERED\",\"ipv4Addresses\":[\"172.17.1.50\"]}";
   ```

   园区PCF无法与NRF通信，需要手动配置PCF与AF的服务发现。

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**NGPING**命令，查询PCF与AF之间能否互通。
   * 正常，调测结束。
   * 不正常，请联系华为技术支持工程师。
