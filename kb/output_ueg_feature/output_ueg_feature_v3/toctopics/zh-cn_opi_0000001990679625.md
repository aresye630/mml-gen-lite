# 配置计费方式

## 操作场景

本指导用于描述UNC支持融合的离线计费的操作过程。

**GGSN-C/PGW-C/SMF**

对于SMF，计费方式的选择有PCF下发和本地配置，PCF下发的优先级高于本地配置。对于GGSN-C/PGW-C，计费方式的选择有PCRF下发、RADIUS Server下发和本地配置，优先级从高到低依次为：PCRF下发>RADIUS Server下发>本地配置。

GGSN-C/PGW-C/SMF本地配置计费方式开关有三种粒度：User Profile、DNN和计费属性，优先级依次降低。

根据用户归属属性（本地用户，漫游用户和拜访用户）配置的开关**SET CHARGECTRL**是控制GGSN-C/PGW-C/SMF本地配置的计费开关是否有效的总开关，当总开关使能了某种计费，其他开关的配置才能生效。默认情况下，总开关同时使能在线/离线/融合计费。

## 操作步骤

1. 基于用户归属属性配置GGSN-C/PGW-C/SMF的计费方式。

   **SET CHARGECTRL**

   **SET CHARGECTRL**根据用户漫游属性设置计费方式，**ADD CHARGEMETHOD**根据计费属性设置计费方式，针对同一个用户，两者规划的计费方式要一致，否则用户计费会出错。例如，针对计费属性是normal的本地用户，如果设置本地用户进行在线计费，又设置normal用户进行离线计费，那用户最终计费结果将出错。
2. **可选：**基于User Profile配置GGSN-C/PGW-C/SMF的计费方式。

   **SET USRPROFCHARGE**
3. **可选：**基于DNN配置GGSN-C/PGW-C/SMF的计费方式。

   **SET APNCHARGECTRL**
4. **可选：**基于用户计费属性配置GGSN-C/PGW-C/SMF的计费方式。

   **ADD CHARGEMETHOD**

## 任务示例

任务描述

* 任务一：在GGSN-C/PGW-C/SMF上配置使能融合计费，不使能在线计费和离线计费。
* 任务二：在GGSN-C/PGW-C/SMF上配置计费属性为0x0400的用户融合计费开关使能，融合计费仅允许离线计费RG可以向CHF进行业务申请和上报，在线计费开关和离线计费开关不使能。
* 任务三：在GGSN-C/PGW-C/SMF上配置APN为apn-test的用户融合计费开关使能，融合计费仅允许离线计费RG可以向CHF进行业务申请和上报，在线计费开关和离线计费开关不使能。
* 任务四：在GGSN-C/PGW-C/SMF上配置User Profile为up-test的用户融合计费开关使能，融合计费仅允许离线计费RG可以向CHF进行业务申请和上报，在线计费开关和离线计费开关不使能。

脚本

**任务一**

```
SET CHARGECTRL:HOMECONVERGED=ENABLE, HOMEONLINE=DISABLE, HOMEOFFLINE=DISABLE, VISITONLINE=DISABLE, VISITOFFLINE=DISABLE, VISITCONVERGED=ENABLE, ROAMONLINE=DISABLE, ROAMOFFLINE=DISABLE, ROAMCONVERGED=ENABLE;
```

**任务二**

```
SET CHARGECTRL:HOMECONVERGED=ENABLE, HOMEONLINE=DISABLE, HOMEOFFLINE=DISABLE, VISITONLINE=DISABLE, VISITOFFLINE=DISABLE, VISITCONVERGED=ENABLE, ROAMONLINE=DISABLE, ROAMOFFLINE=DISABLE, ROAMCONVERGED=ENABLE;
ADD CHARGEMETHOD:CHARGECHARACT=SPECIFIC_VALUE, CCVALUE="0x0400", MASK="0xFFFF", PRIORITY=1, ONLINE=DISABLE, OFFLINE=DISABLE, CONVERGED=ENABLE, RGAPPLIED=OFFLINERGONLY;
```

**任务三**

```
SET CHARGECTRL:HOMECONVERGED=ENABLE, HOMEONLINE=DISABLE, HOMEOFFLINE=DISABLE, VISITONLINE=DISABLE, VISITOFFLINE=DISABLE, VISITCONVERGED=ENABLE, ROAMONLINE=DISABLE, ROAMOFFLINE=DISABLE, ROAMCONVERGED=ENABLE;
SET APNCHARGECTRL:APN="apn-test", ONLINESW=DISABLE, OFFLINESW=DISABLE, CONVERGEDSW=ENABLE, RGAPPLIED=OFFLINERGONLY;
```

**任务四**

```
SET CHARGECTRL:HOMECONVERGED=ENABLE, HOMEONLINE=DISABLE, HOMEOFFLINE=DISABLE, VISITONLINE=DISABLE, VISITOFFLINE=DISABLE, VISITCONVERGED=ENABLE, ROAMONLINE=DISABLE, ROAMOFFLINE=DISABLE, ROAMCONVERGED=ENABLE;
SET USRPROFCHARGE:USRPROFNAME="up-test", ONLINESW=DISABLE, OFFLINESW=DISABLE, CONVERGEDSW=, RGAPPLIED=OFFLINERGONLY;
```
