# 配置GRE Over GRE（跨级容灾+GRE专线）

## 操作场景

跨级容灾场景下，当地市与园区之间通过GRE专线打通，且存在静态地址路由冗余情况下，从主锚点UPF2看，存在GRE over GRE（外层GRE专线中有GRE路由冗余隧道）的情况，需要将内层GRE路由冗余隧道的报文路由到外层的GRE专线中，组网规划如图1所示，数据规划如图2所示。

## 必备事项

前提条件

无。

数据

**表1** 主锚点UPF2配置数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SRROUTE** | 地址族（AFTYPE） | ipv4unicast | 固定取值 | 增加静态路由，使得内层的GRE路由冗余隧道的报文路由到外层的GRE专线中。 |
|  | 路由前缀（PREFIX） | 10.10.0.1 | 全网规划 | 内层GRE路由冗余隧道UPF1侧GRE地址。 |
|  | 路由掩码长度（MASKLENGTH） | 32 | 全网规划 | - |
|  | VPN实例名称（VRFNAME） | VRF\_N6\_Local\_2B | 从已配置数据中获取 | - |
|  | 下一跳VPN名字（DESTVRFNAME） | VRF\_N6\_Local\_2B\_001 | 从已配置数据中获取 | - |
|  | 路由出接口名字（IFNAME） | Tunnel12 | 从已配置数据中获取 | 外层GRE专线UPF2侧隧道接口。 |

## 任务示例

任务描述

跨级容灾场景下，当地市与园区之间通过GRE专线打通，且存在静态地址路由冗余情况下，从主锚点UPF2看，存在GRE over GRE（GRE专线中有GRE路由冗余隧道）的情况，需要将内层GRE报文路由到外层的GRE隧道中，主锚点UPF2上配置如下。

GRE专线一端的UPF2配置如下，另一端在企业GW上，需完成对应的配置。

脚本

1. 配置静态路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.10.0.1", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B", ,DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel12";
   ```
