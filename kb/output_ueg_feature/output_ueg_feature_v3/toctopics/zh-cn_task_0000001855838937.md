# 配置ClickHouse TLS数字证书

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

Clickhouse服务端和NDF、PGW、DMA和DBG模块使用TLS协议进行通信时需要加载证书文件。

长期使用同一数字证书，可能存在安全风险，为了提高系统安全性，强烈建议运营商定期更新证书。证书文件加载成功后，需要手动删除服务器上的证书文件。

#### 对系统的影响

不涉及。

#### 必备事项

**前提条件**

客户已申请证书文件并已获取对应的证书密码。

**数据**

不涉及。

#### 操作步骤

1. 登录OM Portal界面。
2. 进入“系统 > 文件传输”页面。
3. 在左侧“文件传输”菜单中选择“CGPLite文件 > 网元文件”。
4. 单击“添加文件”，选择需要上传的证书文件并上传。

   **图1** 上传证书文件
5. 登录“USCDB MML命令”界面。
6. 执行**LOD VERIF**命令分别加载服务端和客户端的CA证书、设备证书和密钥文件。
7. 执行**RST MODULE**命令重启模块使配置生效。

   * 加载服务端证书后，需要执行**RST MODULE**命令，依次重启全部的NDF模块。
   * 加载客户端证书后，需要执行**RST MODULE**命令，依次重启全部的NDF、PGW、DMA和DBG模块，不重启全部的NDF、PGW、DMA和DBG模块会上报ALM-14011 连接物理库失败告警。
