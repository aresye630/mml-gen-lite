# 配置UDM数据

## 操作场景

该任务旨在指导操作人员在5G网络中配置5G LAN群组管理特性。

## 必备事项

前提条件

* 请仔细阅读WHFD-800030 5G LAN群组管理特性概述。
* 操作人员具有数据配置权限。
* 操作人员具有PGW Web LMT的操作权限。
* 需要加入5G虚拟网络组的用户已参考配置实例开户，并且签约的5GS DNN QoS模板中“默认PDU类型”参数取值要设置为“ETHER”。
* 阅读配置前的必读信息如表1所示。

  **表1** 阅读配置前必读

  | 参数颜色 | 来源 |
  | --- | --- |
  |  | 信息收集参数，指工程设计、部署前需要向客户收集的参数。 |
  |  | 网设决定参数，指根据运营商现网的不同方案，选择不同的参数配置。 |

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD VNGROUP** | HLR序列号（HLRSN） | 1 | 全网规划 | 用于标识一个HLR序列号。该参数必须先由**ADD HLRSN**命令定义，然后才能在此处引用。 |
|  | 内部组ID（INGROUPID） | * 1001-46008-01 * 1001-46008-02 | 本端规划 | 用于标识移动网络内部设备之间通信时互相传递的组ID。 |
|  | 外部组ID（EXTGROUPID） | * group01@huawei.com * group02@huawei.com | 本端规划 | 用于标识移动网络对外能力开放接口中提供的组ID。 |
|  | 共享数据ID（SHAREDID） | * 46008-huawei01 * 46008-huawei02 | 本端规划 | 用于标识为内部组创建的共享数据的ID。 |
|  | 组名称（GROUPNAME） | Huawei | 本端规划 | 用于标识5G虚拟网络组名称。 |
|  | 切片标识（SNSSAI） | 1-010101 | 本端规划 | 用于标识5G系统中的网络切片。 |
|  | 数据网名称（DNN） | cmnet | 本端规划 | 用于标识数据网名称。 |
|  | 允许的PDU类型（PDUTYPES） | ETHER | 本端规划 | 用于标识允许的PDU类型。  层二5G LAN组时，使用样例值。 |
|  | 是否需要二次认证（SECONDARYAUTH） | TRUE | 本端规划 | 用于标识SMF在用户PDU会话建立时是否需要二次认证授权。 |
|  | DN-AAA的IPv4地址（AAAIPV4ADDR） | 10.20.30.100 | 本端规划 | 用于标识二次认证授权的DN-AAA服务器IPv4地址。 |
|  | DN-AAA的IPv6地址（AAAIPV6ADDR） | 2001:0db8::1234 | 本端规划 | 用于标识二次认证授权的DN-AAA服务器IPv6地址。 |
| **ADD GROUPID** | IMSI（IMSI） | * 460081000000001 * 460082000000002 | 已配置数据中获取 | 用于标识需要加入5G虚拟网络组的用户的IMSI号码。 |
|  | 内部组ID（INGROUPID） | * 1001-46008-01 * 1001-46008-02 | 已配置数据中获取 | 用于标识移动网络内部设备之间通信时互相传递的组ID。该参数必须由**ADD VNGROUP**命令定义后才能在此处引用。 |

* 配置本特性涉及的“内部组ID（INGROUPID）”参数即UDM个人数据说明表中的IGI（Internal Group Identifier）。
* 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。
* 风筝S/M时，中心UDM需支持给5G LAN用户签约离线计费属性，计费属性值为“0800”。

## 任务示例

任务描述

* 为IMSI为“460081000000001”的用户签约5G虚拟网络组数据。
* 为IMSI为“460082000000002”的用户签约5G虚拟网络组数据。
* IMSI为“460081000000001”的用户和IMSI为“460082000000002”的用户签约同一个APN且同一个切片SNSSAI，但属于不同的5G LAN组。

脚本

1. 配置5G LAN使用的DNN信息。

   //创建5G QoS模板。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="tp5glan01", NGQI=9, ARPPRILEVEL=1, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=FALSE, NGQIPRILEVEL=1;
   ```

   //创建DNN QoS模板。

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="tp5glan01", PDUTYPE=ETHER, SSCMODE=SSC_MODE_1, NGCQOSTPLID=1, AMBRUP=5, UPUNIT=Gbps, AMBRDW=5, DWUNIT=Gbps;
   ```
2. 签约会话管理数据。

   ```
   ADD SMDATA: IMSI="460081000000001", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=1;
   ```

   ```
   ADD SMDATA: IMSI="460082000000002", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=1;
   ```
3. 创建5G LAN组。

   //如下以配置2个5G LAN组为例。规划多个5G LAN组时，“INGROUPID”、“EXTGROUPID”、“SHAREDID”取值必须不同。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei01", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-02", EXTGROUPID="group02@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```
4. 增加5G LAN组成员。

   ```
   ADD GROUPID: IMSI="460081000000001", INGROUPID="1001-46008-01";
   ```

   ```
   ADD GROUPID: IMSI="460082000000002", INGROUPID="1001-46008-02";
   ```
