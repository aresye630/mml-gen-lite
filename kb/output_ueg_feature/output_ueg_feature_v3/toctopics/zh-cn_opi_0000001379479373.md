# 配置容灾模式（1+1主备）

* 操作场景
* 必备事项
* 操作步骤
* 验证方法

## 操作场景

为避免单点故障，园区需部署两套UEG实现容灾。

两套UEG采用1+1主备容灾时，需要参考本页面进行配置。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

* 已完成各NF选择本UEG内NF的数据配置。
* 已完成UEG间容灾消息传输使用的外联口IP及路由数据。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 检查负荷分担容灾功能的使能开关是否为“NO”。

   ```
   LST DRCOUPLINGRESET:;
   ```

   * “COUPLINGRESET”值为“YES”时，请执行3。
   * “COUPLINGRESET”值为“NO”时，执行4。
3. 关闭负荷分担容灾功能开关。

   ```
   SET DRCOUPLINGRESET: COUPLINGRESET=NO;
   ```
4. 增加VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_DCI";
   ```
5. 增加容灾组信息。

   //DC1：

   ```
   ADD DRGROUPINFO: DRGROUPID=1, DRGROUPNAME="DRGROUP01", LDRINSTID=0, DFTMODE=ACTIVE, PDRINSTID=1;
   ```

   //DC2：

   ```
   ADD DRGROUPINFO: DRGROUPID=1, DRGROUPNAME="DRGROUP01", LDRINSTID=1, DFTMODE=STANDBY, PDRINSTID=0;
   ```
6. 增加DC间通信通道信息。

   //DC1：

   ```
   ADD DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.198.8", PDCIP="10.10.199.8", VPNINSTANCE="VPN_DCI", DATABKMODE=Active-Standby;
   ```

   //DC2：

   ```
   ADD DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.199.8", PDCIP="10.10.198.8", VPNINSTANCE="VPN_DCI", DATABKMODE=Active-Standby;
   ```
7. 设置容灾定时器。

   //DC1：

   ```
   SET DRHBNEGOTIMER: DRGROUPID=1, HELLOINTERVAL=10, NEGOINTERVAL=10, TIMES=30;
   ```

   //DC2：

   ```
   SET DRHBNEGOTIMER: DRGROUPID=1, HELLOINTERVAL=10, NEGOINTERVAL=10, TIMES=30;
   ```
8. 设置监控的关键部件信息。

   * 此处以UEG监控MME、AMF、HSS、UDM、SMF、GWC、UPF、UDR，未监控PCF/PCRF为例。实际请以网设规划为准。
   * 开启容灾功能的UEG出现设备异常，需要通过重新实例化操作进行恢复的场景：若MML文件中**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值存在“YES”，则在导入MML文件进行配置恢复前，需要先修改MML文件，将**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值“YES”修改为“NO”；待HSS、UDM、PCRF、PCF、UDR服务的配置恢复完成后，再按照修改前的**SET DRKEYNF**配置重新开启对这些服务的监控。

   ```
   SET DRKEYNF: MME=YES, AMF=YES, HSS=YES, UDM=YES, SMF=YES, GWC=YES, PCF=NO, PCRF=NO, UPF=YES, UDR=YES;
   ```
9. 设置软参。

   ```
   SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=400, VALUE=VALUE_1, POSITION=1;
   ```

   ```
   SET SOFTPARAOFBIT: DT=DWORD_EX_B, PARANUM=61, VALUE=VALUE_1, POSITION=1;
   ```

   ```
   SET UPSOFTPARA: DT=BIT, BITNUM=3001, BITVALUE=1;
   ```

## 验证方法

1. 执行对应的LST命令，检查配置是否与规划一致。
   * 检查容灾组信息

     执行**LST DRGROUPINFO**命令进行检查，如配置错误，则先执行**RMV DRDCI**，再执行**RMV DRGROUPINFO**命令，删除错误的配置后，然后重新执行5进行设置。
   * 检查DC间通信通道信息

     执行**LST DRDCI**命令进行检查，如配置错误，则先执行**RMV DRDCI**命令，删除错误的配置后，然后重新执行6进行设置。
   * 检查容灾定时器设置

     执行**LST DRHBNEGOTIMER**命令进行检查，如配置错误，则重新执行7进行设置。
   * 检查监控的关键部件信息

     执行**LST DRKEYNF**命令进行检查，如配置错误，则重新执行8进行设置。
   * 检查软参

     ```
     LST AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=400, POSITION=1;
     ```

     ```
     LST SOFTPARAOFBIT: DT=DWORD_EX_B, PARANUM=61, POSITION=1;
     ```

     ```
     LST UPSOFTPARA: DT=BIT, DATANUM=3001;
     ```

     软参值为1时正常，否则请重新执行9进行设置。
2. 执行如下脚本，检查容灾组的运行状态及心跳状态是否符合预期。

   ```
   DSP DRGROUPSTATUS:;
   ```

   预期结果：主用UEG上“本端容灾实例运行状态”为“容灾实例运行状态为主”；备用UEG上“本端容灾实例运行状态”为“容灾实例运行状态为备”；主备用UEG上“主备容灾实例之间的心跳状态”为“主备容灾实例之间握手成功，处于连接状态”。
