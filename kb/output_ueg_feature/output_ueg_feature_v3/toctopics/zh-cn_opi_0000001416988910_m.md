# 配置Restful接口数据

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

统一定义5G网络激活与UDM能力接口的设计原则、交互场景、接口方法和参数模型等，实现5G网络激活与UDM能力标准化，支持集约管理和业务快速上线。

5G核心网网元能力接口由设备厂商按Restful接口规范标准封装，通过接收5G业务激活请求，实现5G核心网网元激活。

UDM网元支持Restful接口协议，当需要与对端业务发放系统的Restful接口对接时，参考本页面内容对Restful接口进行适配。

## 必备事项

前提条件

* 具有访问http://support.huawei.com网站及下载软件包的权限。
* 已完成软件安装及基础数据配置。
* 已完成配置PGW与业务发放系统的对接数据（风筝M）。
* 已获取营帐适配指导书。
* 已获取营帐适配包。

数据

执行操作前规划的数据如表1所示。

**表1** 数据规划

| 类别 | 参数名称 | 取值样例 | 说明 |
| --- | --- | --- | --- |
| **LOD PKG** | FNM（文件名称） | AdpConfig\_HSS9860\_XXXX\_REST\_V500R020C20.tar | 与实际获取的营帐适配包名称一致。 |
| **LOD ADPPLUG** | UPFILENAME（适配插件包名称） | AdpConfig\_HSS9860\_XXXX\_REST\_V500R020C20.tar | 与实际获取的营帐适配包名称一致。 |
| **ADD PORT** | PORTNO（端口号） | 8002 | 指定增加的PGW开放给业务发放系统和Web LMT使用的端口的编号。当参数“端口类型”为“PORT\_FOR\_PROV”时，端口号取值范围为：1～65535，建议端口范围为1025～65535。由运营商统一规划。 |
|  | PORTTYPE（端口类型） | PORT\_FOR\_PROV | PGW开放给业务发放系统的端口。 |
|  | PORTTYPENAME（端口子类型） | PORT\_FOR\_REST | PGW开放给业务发放系统的REST服务端口。 |
|  | DISABLEPORT（是否屏蔽本端口） | NO | 系统不对此端口进行屏蔽，端口可正常工作。 |
|  | PORTBUSSTYPE（端口业务类型） | HSS9860 | 用于指定PGW开放给业务发放系统的端口对应的业务类型。 |
|  | HEADERAUTH（是否使用头域鉴权） | NO | 此参数需要根据对端的业务发放系统的要求进行设置。NO表示PGW不需要对SOAP或REST消息头域中携带的登录信息进行登录鉴权。 |
| **RST MODULE** | MID（模块号） | * 7 * 8 | 指定待复位的模块。根据现网实际规划配置。需要重启所有的PGW模块。 |

文档

获取网设LLD文档。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 上传获取的营帐适配包到“CGPLite文件 > SOFTWARE PACKAGE”目录下。上传的详细操作请参见文件传输。
3. 在“CSP MML命令”界面，执行**LOD PKG**命令加载包文件。

   ```
   LOD PKG: FNM="AdpConfig_HSS9860_XXXX_REST_V500R020C20.tar";
   ```
4. 执行**LST PKG**查询包文件是否加载成功。

   ```
   LST PKG:;
   ```
5. 在“USCDB MML命令”界面，执行**LOD ADPPLUG**命令添加适配插件。

   ```
   LOD ADPPLUG: UPFILENAME="AdpConfig_HSS9860_XXXX_REST_V500R020C20.tar";
   ```
6. 执行**ADD PORT**命令添加PGW业务消息端口。

   ```
   ADD PORT: PORTNO=8002, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_REST, DISABLEPORT=NO, PORTBUSSTYPE="HSS9860", HEADERAUTH=NO;
   ```
7. 执行**RST MODULE**命令复位模块。

   ```
   RST MODULE: MID=7, MT=PGW; 
   RST MODULE: MID=8, MT=PGW;
   ```

   此处重启模块的“MID”仅作为样例，需要重启所有的PGW模块。
8. 重启完成后，执行**DSP ADPPLUG**命令查看PGW模块均为“加载成功”状态，则表示适配包加载成功。

   ```
   %%DSP ADPPLUG:;%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------
                模块号  =  7
      适配文件加载状态  =  加载成功
    定制插件包加载状态  =  加载成功
    融合插件包加载状态  =  NULL
          适配包文件名  =  AdpConfig_HSS9860_XXXX_REST_V500R020C20.tar
   OMU加载的适配包描述  =  NULL
   OMU加载的适配包版本  =  NULL
   PGW加载的适配包描述  =  NULL
   PGW加载的适配包版本  =  NULL
   (结果个数 = 1)
   ---    END
   ```
