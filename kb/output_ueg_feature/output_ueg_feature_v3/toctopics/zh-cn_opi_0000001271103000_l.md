## 操作场景

开局时，配置USCDB基础数据。

PCF/PCRF从逻辑上划分为FE（Front End）和BE（Back End）两个业务网元：

* FE（Front End）网元也称为PCF/PCRF网元，实现PCF/PCRF功能实体的功能，包括协议处理、业务处理以及数据管理。
* BE（Back End）网元也称为USCDB网元（Unified Subscriber Center DataBase），实现UDR（Unified Data Repository）功能实体的功能，提供用户数据的增加、删除、更新和查询服务，为FE提供数据存储、数据管理、数据服务等功能支撑。

  PCF/PCRF部署在园区网络时，用户数据的增加、删除和更新通过业务发放系统或在PGW本地（在PGW Web LMT上执行MML批操作文件）进行业务发放。在一个UDR（USCDB）上进行开户，该UDR（USCDB）会将用户数据自动备份到另一个UDR（USCDB）。

## 必备事项

前提条件

具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

数据

**如下数据仅为举例，请注意修改成局点规划的数据。**

园区UEG中规划同时部署UDM和PCF实体功能时：

* 对接UDM和对接PCF的PGW类型的业务IP复用，即只需要规划一套数据即可。
* 对接UDM和对接PCF的DSG类型的IP地址及VPN相同，“SRVINDEX（业务IP索引）”、“SERVICETYPE（业务类型）”取值不同。即，需要规划两套数据。
* 如下表格中，含“UPCF”的参数需要单独规划。

| 类别 | 参数名称 | 取值样例  （DC1） | 取值样例  （DC2） | 获取方法 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **ADD SRVIPADDR** | SRVINDEX（业务IP索引） | * 21 * 22 * 3 |  | 全网规划 | 用于指定业务IP地址对应的索引。  “业务IP类型”为“DSG”时，“SRVINDEX”和“DPU模块号”不能相同，配置前可以通过**LST MODULE**查询DPU模块号。 |
|  | SRVIPTYPE（业务IP类型） | * DSG * DSG * PGW |  | 全网规划 | 用于指定业务IP类型。   * DSG类型用于和PCF/PCRF对接。 * PGW类型用于业务发放及访问PGW Web LMT。IP1用于连接业务发放系统，IP2用于连接PGW Web LMT。 |

|  | IPVER（IP类型） | IPV4 | IPV4 | 全网规划 | 业务IP地址。  园区UEG中同时部署UDM和PCF实体功能时，对接PCF的DSG类型的IP地址复用对接UDM的DSG类型的IP地址。  双DC场景，两个DC的业务IP地址不能重复，如DC1用样例值，DC2用10.201.200.32等。 |
|  | IPV4IP1（本地Location IPV4地址1） | * 10.200.200.32 * 10.200.200.32 * 10.200.200.36 | * 10.201.200.32 * 10.201.200.32 * 10.201.200.36 | 全网规划 |  |
|  | IPV4IP2（本地Location IPV4地址2） | * 10.200.200.33 * 10.200.200.33 * 10.200.200.37 | * 10.201.200.33 * 10.201.200.33 * 10.201.200.37 | 全网规划 |  |
|  | IPV4MASK1（本地Location IPV4子网掩码1） | 255.255.255.255 | 255.255.255.255 | 固定取值 |  |
|  | IPV4MASK2（本地Location IPV4子网掩码2） | 255.255.255.255 | 255.255.255.255 | 固定取值 |  |
|  | SERVICETYPE（业务类型） | * UPCF * UPCF-SESSION |  | 本端规划 | 用于定义待增加模块的业务类型，即对应的插件包类型。当“SRVIPTYPE”设置为“DSG”时，业务类型配置为样例值。 |

## 操作步骤

1. 登录“USCDB MML命令”界面。

   * 已完成园区UDM的基础数据配置，则只需要配置含“UPCF”的脚本。
   * 如采用中心UDM或园区UDM未完成基础数据配置，请按如下步骤顺序执行。
2. 虚机容器场景下，设置物理数据库的安装环境类型为“LocalDisk”。裸机容器不需要执行该步骤。

   ```
   STR INSTENV: ENVTYPE=LocalDisk;
   ```
3. 执行**LST MODULE**命令查询DPU模块号。

   ```
   LST MODULE: MT=DPU, SERVICETYPE="USCDB";
   ```

   查看是否存在模块类型为DPU，业务类型为USCDB的模块：

   * 存在=>5
   * 不存在=>4。
4. 执行**ADD MODULE**命令添加DPU模块。

   * 参数“VMNAME1”与参数“VMNAME2”通过**LST PODINFO**命令查询，采用应用类型为USDID3的Pod名称。
   * “MID”不能与已存在的模块号重复。

   ```
   ADD MODULE: MID=3, MT=DPU, SERVICETYPE="USCDB", VMNAME1="usdid3aservice14-0", VMNAME2="usdid3bservice14-0", MNAME="DPU3";
   ```
5. 增加业务IP地址，以参数“IPVER”值为“IPV4”为例。

   //DC1：

   ```
   ADD SRVIPADDR: SRVINDEX=21, SRVIPTYPE=DSG, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.200.200.32", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.200.200.33", IPV4MASK2="255.255.255.255", SERVICETYPE="UPCF";
   ADD SRVIPADDR: SRVINDEX=22, SRVIPTYPE=DSG, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.200.200.32", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.200.200.33", IPV4MASK2="255.255.255.255", SERVICETYPE="UPCF-SESSION";
   ADD SRVIPADDR: SRVINDEX=3, SRVIPTYPE=PGW, DPUMID=3, IPVER=IPV4, IP1VPNNAME="VRF_provisioning", IPV4IP1="10.200.200.36", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_OM", IPV4IP2="10.200.200.37", IPV4MASK2="255.255.255.255";
   ```

   //DC2：

   ```
   ADD SRVIPADDR: SRVINDEX=21, SRVIPTYPE=DSG, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.201.200.32", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.201.200.33", IPV4MASK2="255.255.255.255", SERVICETYPE="UPCF";
   ADD SRVIPADDR: SRVINDEX=22, SRVIPTYPE=DSG, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.201.200.32", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.201.200.33", IPV4MASK2="255.255.255.255", SERVICETYPE="UPCF-SESSION";
   ADD SRVIPADDR: SRVINDEX=3, SRVIPTYPE=PGW, DPUMID=3, IPVER=IPV4, IP1VPNNAME="VRF_provisioning", IPV4IP1="10.201.200.36", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_OM", IPV4IP2="10.201.200.37", IPV4MASK2="255.255.255.255";
   ```
6. 检查Location标识是否与规划一致。

   * 执行**LST LOCATION**命令，检查“LOCID”参数值是否与规划一致。
   * 主用局PCF/PCRF、主用局USCDB、容灾局PCF/PCRF、容灾局USCDB的Location标识各不相同。

   * 一致，请执行7。
   * 不一致，请联系华为技术支持工程师处理。

   //DC1：

   ```
   %%LST LOCATION:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   Location标识  =  14     
       网元类型  =  USCDB 
   (结果个数 = 1)  
   ---    END
   ```

   //DC2：

   ```
   %%LST LOCATION:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   Location标识  =  16     
       网元类型  =  USCDB 
   (结果个数 = 1)  
   ---    END
   ```
7. 激活插件包。

   ```
   ACT FEPLUG: FETYPENAME="UPCF";
   ACT FEPLUG: FETYPENAME="UPCF-SESSION";
   ```

   执行7后，至少等待10s，然后再执行8。
8. 初始化数据库。

   执行如下命令，会清除内存数据库数据，请在华为技术支持人员指导下使用。

   ```
   STR INITDATA: SERVICETYPE="USCDB";
   STR INITDATA: SERVICETYPE="UPCF";
   STR INITDATA: SERVICETYPE="UPCF-SESSION";
   ```
9. 设置软参“IP限制开关”。请根据局点规划设置。

   ```
   MOD INSP: INSPT=PGW, INSPN=GRANTIPSWITCH, INSPV=0;
   ```
10. 修改PGW业务消息侦听端口。如不修改，则使用默认端口。

    ```
    MOD PORT: PORTNO=7776, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_MML, DISABLEPORT=NO, PORTBUSSTYPE="USCDB";
    MOD PORT: PORTNO=7778, PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_LMT_MML, DISABLEPORT=NO;
    MOD PORT: PORTNO=8001, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_SOAP, DISABLEPORT=NO, PORTBUSSTYPE="USCDB";
    ```
11. 登录“CSP MML命令”界面。
12. 执行**RST MDUTYPE**命令重启PGW模块。

    ```
    RST MDUTYPE: MEID=14, DESC="pgw", HAST=ALL;
    ```

    重启PGW模块的操作需要在登录PGW Web LMT之前进行，否则PGW Web LMT界面的Service Management MML导航树显示为空。登录PGW Web LMT的详细操作，请参见登录与退出PGW Web LMT。

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**NGPING**命令，查看平面“VRF\_DATA”配置的业务IP是否与外联口IP互通。

   ```
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="ADD SRVIPADDR所定义的业务IP", DSTIPV4ADDR="ADD IFIPV4ADDRESS所定义的外联口IP";
   样例：
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.32", DSTIPV4ADDR="192.168.48.59";
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.33", DSTIPV4ADDR="192.168.48.59";
   ```

   * 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   * 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请联系华为技术支持。
