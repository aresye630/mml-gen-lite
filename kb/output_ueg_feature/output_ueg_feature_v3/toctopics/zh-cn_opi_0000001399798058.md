# 配置4G业务故障恢复后的用户迁移

* 必备事项

## 操作场景

在负荷分担容灾模式下，为避免故障恢复后两套UEG上网络负载不均衡的情况，需要参考本页面进行用户迁移操作。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

两套UEG已完成负荷分担容灾模式配置。

数据

**假设需要将部分用户从UEG2迁移到UEG****1，****如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例  （DC2） | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****SET OFFLOADINF**** | 第一阶段迁移时间（FIRSTTM） | 0 | 全网规划 | 第一阶段迁移时间需要配置为0。 |
| ****SET CPSYS**** | 设备能力（CAP） | 0 | 本端规划 | 当UEG支持MME POOL时，在启动迁移任务时，需将此参数设置为0，避免新用户接入。 |
| ****STR OFFLOADBYEDGEMME**** | 迁移比率（OFFLOADRATE） | 50 | 本端规划 | 根据实际情况进行配置，两套UEG上需达到负载均衡。 |
|  | 目标MME编码（MMEC） | 01 | 已配置数据中获取 | UEG1中的MME编码，可通过****LST MMEID****查询。 |
| （可选）****STR NBOFFLOADBYEDGEMME**** | 迁移比率（OFFLOADRATE） | 50 | 本端规划 | 根据实际情况进行配置，两套UEG上需达到负载均衡。 |
|  | 目标MME编码（MMEC） | 01 | 已配置数据中获取 | UEG1中的MME编码，可通过**LST MMEID**查询。 |
| ****SET CPSYS**** | 设备能力（CAP） | 255 | 本端规划 | 当迁移任务结束后，需要恢复MME原设备能力。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 设置迁移配置信息。

   ```
   SET OFFLOADINF: FIRSTTM=0;
   ```
3. 修改需要迁移的MME的设备能力为0。

   ```
   SET CPSYS: CAP=0;
   ```
4. 对需要迁移的MME下发启动迁移命令，向目标MME迁移50%用户。

   ```
   STR OFFLOADBYEDGEMME: OFFLOADRATE=50, MMEC="01";
   ```

   ```
   STR NBOFFLOADBYEDGEMME: OFFLOADRATE=50, MMEC="01";
   ```

   如果想停止用户迁移，可通过**STP OFFLOAD**命令主动停止当前正在进行的迁移任务。
5. 当迁移任务结束后，恢复迁移的MME原设备能力。

   ```
   SET CPSYS: CAP=255;
   ```

## 验证方法

1. 进入“MML命令行-UEG”窗口。
2. 执行对应的LST命令，检查配置是否与规划一致。
   * 查询MMEID配置表中是否将MME设备能力设置为“0”。

     执行**LST CPSYS**命令进行检查，如与预期结果不一致，请执行3重新进行配置。

     预期结果：“设备能力”为“0”。
   * 查询MME迁移配置信息。

     执行**LST OFFLOADINF**命令进行检查，如与预期结果不一致，请执行2重新进行配置。

     预期结果：“第一阶段迁移时间(min)”与规划一致。
3. 查询MME迁移进度。
   * 执行**DSP OFFLOAD**命令进行检查。

     预期结果：迁移完成后，“迁移状态”为“结束完成”。
