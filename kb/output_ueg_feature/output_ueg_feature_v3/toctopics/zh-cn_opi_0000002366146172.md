# 广域5G LAN基础配置

## 操作场景

当存在如下情况时，可以参考本页面进行配置。

* CPE下挂多个终端（最多16个）。
* 同一个二层广播域内的终端IP必须不同。
* 支持如下几种典型业务场景：
  + 同一5G LAN组的层二终端之间通过同一UPF互通。
  + 同一5G LAN组的层二终端之间通过不同UPF互通。

## 必备事项

前提条件

* 除5G LAN业务外，UEG-S支持的5G SA业务运行正常。
* 已加载License文件，且包含如下License控制项：
  + UDM：LKQ7UDMBE15 5G LAN签约用户数
  + SMF：LKV2SALANSM01 5G LAN业务基本功能-USM、LKV2CUFMN01 CU FullMesh组网
  + UPF：LKV3G5LANB01 5G LAN基础功能、LKV3G5CUFM01 CU Full Mesh组网
  + PCF：LRM0PCFTC137 N7接口（使用HTTP协议）策略控制

## 操作步骤

配置UDM数据

中心UDM（UDM）需支持给5G LAN用户签约离线计费属性，计费属性值以“0800”为例，可通过BOSS修改。请根据是否对5G LAN用户进行离线计费按需规划。

+ **ADD NGCQOSTPL**命令存在多条时，“TPLID”不能重复。
+ **ADD DNNQOSTPL**命令存在多条时，“TPLID”不能重复。
+ **ADD DNNQOSTPL**命令中的“NGCQOSTPLID” 参数索引**ADD NGCQOSTPL**命令中的“TPLID”参数值。
+ **ADD SMDATA**命令中的“DNNQOSTPLID”参数索引**ADD DNNQOSTPL**命令中的“TPLID”参数值。
+ 5G LAN QoS参数（5QI、ARP等）仅用于举例，实际请根据具体业务模型规划。
+ 在“UDM业务管理”窗口下执行**LST NGS**命令和**LST VNGROUP**可查询5G LAN用户的“SNSSAI”、“DNN”、“INGROUPID”、“SHAREDID”、“PDUTYPES”等开户信息。
+ 1.b~1.e是在“UDM业务管理”窗口下执行。具体为：先登录PGW WEBUI，然后在“应用类型”下拉框选择“UDM业务管理”。

1. 检查5G LAN License项是否开启。

   //显示信息中存在“LKQ7UDMBE15”控制项且取值不为0时，说明已开启5G LAN License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```
2. 配置5G LAN使用的DNN信息。

   //创建5G QoS模板。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="tp5glan01", NGQI=9, ARPPRILEVEL=1, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=FALSE, NGQIPRILEVEL=1;
   ```

   //创建DNN QoS模板。

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=2, TPLNAME="tp5glan01", PDUTYPE=ETHER, SSCMODE=SSC_MODE_1, NGCQOSTPLID=1, AMBRUP=5, UPUNIT=Gbps, AMBRDW=5, DWUNIT=Gbps, CHARGE="0800";
   ```
3. 签约会话管理数据。

   ```
   ADD SMDATA: IMSI="460081000000001", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=2;
   ```

   ```
   ADD SMDATA: IMSI="460082000000002", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=2;
   ```
4. 创建5G LAN组。

   //如下以配置2个5G LAN组为例。规划多个5G LAN组时，“INGROUPID”、“EXTGROUPID”、“SHAREDID”取值必须不同。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei01", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-02", EXTGROUPID="group02@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```
5. 增加5G LAN组成员。

   ```
   ADD GROUPID: IMSI="460081000000001", INGROUPID="1001-46008-01";
   ```

   ```
   ADD GROUPID: IMSI="460082000000002", INGROUPID="1001-46008-02";
   ```

配置AMF数据

AMF上配置的切片参数SST、SD与UDM开户时切片参数一致。可以复用已有切片，复用已有切片时，不需要执行如下配置。可通过**LST PLMNNS**查询。

1. 配置PLMN支持的切片。复用已有切片时，不需要重复配置。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="010101";
   ```
2. 配置AMF切片信息。复用已有切片时，不需要重复配置。

   ```
   ADD NFNS: NFTYPE=NfAMF, NSIDX=1;
   ```
3. 配置AMF对5G LAN切片下的DNN纠正。如现网已涉及DNN纠正功能（可通过**LST LOCALNSDNN**查询），则需要执行如下配置；否则，请跳过如下配置。

   //用户请求APN与签约APN不匹配时，优先纠正为签约数据中的Default DNN，如果未签约Default DNN，则纠正为dnn5glan01。

   ```
   ADD LOCALNSDNN: SUBRANGE=HOME_USER, CORRECTTYPE=DNN_CORRECTION, SST=1, SD="010101", DNN="dnn5glan01", DNNPLCY=Default_DNN_preferred, DISFAILPLCY=STANDARD_MODEL, DESC="5GLAN_DNN_Correction";
   ```
4. 配置对端SMF实例支持的切片。可以基于切片选择SMF。复用已有切片时，不需要重复配置。

   ```
   ADD PNFNS: INDEX=5, NFINSTANCEID="SMF_Instance_1", SST=1, SD="010101";
   ```

配置NSSF数据

同一区域内，不是所有AMF都支持5G LAN业务切片时，需配置NSSF数据。否则，不需要配置。

AMF收到5G LAN业务报文后，如本AMF未配置5G LAN业务切片信息，则可通过与NSSF交互实现AMF重定向，即将5G LAN业务报文重定向到配置了5G LAN业务切片信息的AMF上。

1. 在NSSF上增加5G LAN业务切片信息。

   ```
   ADD CFGSNSSAI: INDEX=1, MCC="123", MNC="03", SST=1, SD="010101", ISACTIVE=TRUE, DESC="5G_LAN";
   ```
2. 在跟踪区域码分组中增加跟踪区域码。

   ```
   ADD TACGROUPINNSSF: INDEX=1, TACGROUPNAME="1-010101", TACSTART="290100", TACEND="290110";
   ```
3. 将切片、AMF、TAC组进行绑定。

   ```
   ADD AMFSETID: INDEX=1, SST=1, SD="010101", MCC="123", MNC="03", REGIONID="08", AMFSETID="088", TACGROUPNAME="1-010101";
   ```

配置SMF数据

+ **ADD PNFNS**命令存在多条时，“INDEX”不能重复。
+ 5G LAN SMF-UPF Fullmesh组网时，支持5G LAN的多个SMF上的5G LAN业务配置相同。

1. 检查5G LAN License项是否开启。

   //显示信息中存在“LKV2SALANSM01”控制项时，说明已开启5G LAN License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```

   //显示信息中存在“LKV2CUFMN01”控制项时，说明已开启5G LAN SMF-UPF Fullmesh License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```
2. 配置SMF 5G LAN全局参数。

   //配置支持建立5G LAN会话。

   ```
   SET SMFFUNC: NGLANSWITCH=Support;
   ```

   //配置对5G LAN UPF的选择机制。

   ```
   SET UPSELECTFLAG: NGLANUPFSELSW=LOCALABILITY;
   ```

   //配置5G LAN关键信元。

   ```
   SET PFCPPVTEXT: FEATURE=NGLAN,SWITCH=ENABLE;
   ```
3. 配置5G LAN使用的切片和专用DNN信息。

   //配置SMF支持的切片信息。可以复用已有切片，复用已有切片时，不需要执行如下配置。可通过**LST PLMNNS**查询。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="010101",STATE=ACTIVE;
   ADD NFNS: NFTYPE=NfSMF, NSIDX=1;
   ```

   //配置SMF支持的DNN（APN）信息。

   ```
   ADD APN:APN="dnn5glan01";
   ```

   //配置网络切片支持DNN。

   ```
   ADD NSDNN: NSIDX=1, DNN="dnn5glan01";
   ```
4. 配置支持5G LAN的SMF对端UPF实例信息。

   //配置对端UPF节点信息。同一个UPF对端只能配置一条ADD PNFPROFILE记录。如已配置对应的UPF节点信息，则不需要重复配置。

   ```
   ADD PNFPROFILE:NFINSTANCEID="upf_instance_1", NFTYPE=NfUPF, FQDN="5glan01.upf1", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="119.5.52.2", PORT=8805;
   ```

   ```
   ADD PNFPROFILE:NFINSTANCEID="upf_instance_2", NFTYPE=NfUPF, FQDN="5glan01.upf2", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="119.5.52.3", PORT=8805;
   ```

   //配置对端UPF支持的切片信息。如复用已有的对端UPF的切片信息，则不需要重复配置。推荐复用。

   ```
   ADD PNFNS:INDEX=1, NFINSTANCEID="upf_instance_1", SST=1, SD="010101";
   ```

   ```
   ADD PNFNS:INDEX=2, NFINSTANCEID="upf_instance_2", SST=1, SD="010101";
   ```

   //配置对端UPF支持5G LAN功能。

   ```
   MOD UPNODE: NFINSTANCENAME="upf_instance_1", NGLANSW=ENABLE;
   ```

   ```
   MOD UPNODE: NFINSTANCENAME="upf_instance_2", NGLANSW=ENABLE;
   ```

   //配置对端UPF的位置区域信息。如已配置的对端UPF的位置区域信息包含5G LAN业务对应的基站的TAI范围，则不需要重复配置。一个UPF服务区域可以绑定多个TAI范围，如利旧UPF服务区，且需要增加TAI范围，则可只通过**ADD UPAREABINDN2TAI**命令增加TAI范围。此处以两个UPF的位置区域信息相同为例。

   ```
   ADD UPAREA:AREANAME="area01", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="area01", N2BEGINTAI="46008000000", N2ENDTAI="46008FFFFFF";
   ```

   //配置对端UPF的SMF服务区域信息。如利旧UPF服务区（area01），则不需要重复配置。一个UPF实例可以和多个UPF服务区绑定。

   ```
   ADD PNFSMFSERAREA: NFINSTANCEID="upf_instance_1", SMFSERVINGAREA="area01";
   ```

   ```
   ADD PNFSMFSERAREA: NFINSTANCEID="upf_instance_2", SMFSERVINGAREA="area01";
   ```

   //配置按优先级选择UPF。

   ```
   SET APNUPSELPLY: APN="dnn5glan01", PRIORITYFLAG=ENABLE, COMBINEDSELSTG=APNPRI;
   ```
5. 配置5G LAN业务与用户模板组绑定。

   //配置PCC策略组。

   ```
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccpolicy_group", FUPSESSIONEXC=DISABLE;
   ```

   //配置5G LAN业务的APN与用户模板组绑定。

   ```
   ADD USRPROFGROUP: USERPROFGNAME="profilegroupfglan"; 
   ADD USERPROFILE: USERPROFILENAME="fglan_u_p_any", UPTYPE=PCC, UPSPECTYPE=DEFAULT;
   ADD UPBINDUPG: USERPROFGNAME="profilegroupfglan", UPBINDTYPE=DEFAULT, USERPROFILENAME="fglan_u_p_any", LOCALPCCSELECT=INHERIT;
   ADD APNUSRPROFG: APN="dnn5glan01", USERPROFGNAME="profilegroupfglan";
   ```

   //配置规则和用户模板绑定。“POLICYNAME”采用**ADD PCCPOLICYGRP**命令中的“PCCPOLICYGRPNM”参数值。

   ```
   ADD RULE:RULENAME="fglan_r_any", POLICYTYPE=PCC, POLICYNAME="pccpolicy_group", PRIORITY=65535, RULERANGE=ALL, RULESPECTYPE=DEFAULT;
   ADD RULEBINDING: USERPROFILENAME="fglan_u_p_any", RULENAME="fglan_r_any", POLICYTYPE=PCC;
   ```

配置PCF数据

+ 广域5G LAN使用离线计费，在离线计费场景下，基于PCF下发的预定义规则进行离线计费时，需要参考配置基于预定义规则的计费（推荐）页面中的PCF相关配置，否则不需要配置PCF数据。
+ 需在BOSS上签约业务后，PCF配置的计费业务才能生效。

配置锚点UPF数据

1. 打开CU Fullmesh的License项。

   //开启CU Fullmesh的License配置开关。

   ```
   SET LICENSESWITCH: LICITEM="LKV3G5CUFM01", SWITCH=ENABLE;
   ```
2. 配置UPF 5G LAN全局参数。

   //开启5G LAN特性的License配置开关。

   ```
   SET LICENSESWITCH: LICITEM="LKV3G5LANB01", SWITCH=ENABLE;
   ```

   //开启5G LAN功能。

   ```
   SET NGLANFUNC: NGLANSW=ENABLE;
   ```
3. 配置UPF支持的DNN（APN）信息。

   //支持层二 5G LAN业务的DNN（APN）不需要绑定VPN实例。

   ```
   ADD APN: APN="dnn5glan01";
   ```
4. 配置UPF支持的5G LAN组。

   //如下以配置2个5G LAN组为例。规划多个5G LAN组时，“VNINSTANCE”取值必须不同。

   ```
   ADD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, MACIDLESW=DISABLE, IGMPSNOOPINGSW=DISABLE, IGMPPARSESW=DISABLE, MULTIFLOODSW=ENABLE, MULTIFLOODRATE=20, BCASTFLOWCTRLSW=ENABLE, UNICASTFLOODSW=DISABLE, N6MACIDLESW=DISABLE;
   ```

   ```
   ADD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-02", PDNTYPE=ETHERNET, MACIDLESW=DISABLE, IGMPSNOOPINGSW=DISABLE, IGMPPARSESW=DISABLE, MULTIFLOODSW=ENABLE, MULTIFLOODRATE=20, BCASTFLOWCTRLSW=ENABLE, UNICASTFLOODSW=DISABLE, N6MACIDLESW=DISABLE;
   ```
5. 配置缺省PCC规则。

   //配置PCC策略组。

   ```
   ADD PCCPOLICYGRP:PCCPOLICYGRPNM="5glan_pcc_p_g", FUPSESSIONEXC=DISABLE, EVENTCHARGEFLAG=DISABLE, EVENTCHGPOINT=RESPONSE, MMSCHARGETYPE=SINGLE, SIGNALASSOCIATE=ENABLE, ADCMUTEFLAG=ENABLE, HTTP2DEGRADESW=INHERIT, TOKENFUNCFLAG=DISABLE;
   ```

   //配置流过滤器，any-to-any。

   ```
   ADD FILTER:FILTERNAME="any", L34PROTTYPE=STRING, L34PROTOCOL=ANY, MSSTARTPORT=0, MSENDPORT=65535, SVRSTARTPORT=0, SVRENDPORT=65535;
   ADD FILTERIPV6:FILTERNAME="any_ipv6", L34PROTTYPEV6=STRING, L34PROTOCOL=ANY, MSSTARTPORT=0, MSENDPORT=65535, SVRSTARTPORT=0, SVRENDPORT=65535;
   ADD FLOWFILTER:FLOWFILTERNAME="any_f_f", TETHERDETFLAG=NONE, FLOWFILTERTYPE=USERCONFIG;
   ADD FLTBINDFLOWF:FLOWFILTERNAME="any_f_f", FILTERNAME="any";
   ADD FLTBINDFLOWF:FLOWFILTERNAME="any_f_f", FILTERNAME="any_ipv6";
   ```

   //配置5G LAN业务相关的rule和userprofile。

   ```
   ADD RULE: RULENAME="fglan_r_any", POLICYTYPE=PCC, FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="any_f_f", POLICYNAME="5glan_pcc_p_g";
   ADD USERPROFILE: USERPROFILENAME="fglan_u_p_any";
   ADD RULEBINDING: USERPROFILENAME="fglan_u_p_any", RULENAME="fglan_r_any";
   SET REFRESHSRV: REFRESHTYPE=ALL;
   ```
