# 配置SMF惯性运行数据

## 操作场景

用户面业务通道保活是指，企业园区场景下，当园区gNodeB、UPF跟园区外部署的AMF、SMF失联时，即N2/N4接口不可用但N3接口可用时，弱移动性（不跨gNodeB切换）连接态用户的数传业务能够继续进行（惯性运行）。

适用于SMF。

## 必备事项

前提条件

* 请仔细阅读WSFD-217001 用户面业务通道保活特性概述。
* 完成加载License。

数据

| 类别 | 参数 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **MOD UPNODE** | UPF实例名称 （NFINSTANCENAME） | upf1 | 全网规划 | 该命令用于设置园区惯性运行开关。 |
|  | 惯性运行开关（IOSWITCH） | ENABLE |  |  |
|  | 园区UPF开关（CAMPUSSW） | ENABLE |  |  |
| **SET PFCPPARA** | 惯性运行定时器(秒)（IOINTERVAL） | 60 | 本端规划 | 该命令用于设置链路惯性运行定时器，UPF心跳异常后开启该定时器，定时器超时后心跳仍未恢复，该链路惯性运行定时器超时。 |
| **SET UPCSCANRATE** | 扫描任务类型（SCANTYPE） | INERTIALOPERATION | 本端规划 | 该命令用于设置控制面扫描用户的速率。 |
|  | 扫描速率(个/秒)（RATE） | 30 |  |  |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. **可选：**增加园区策略，设置园区惯性运行开关。

   **MOD UPNODE**
3. 设置SMF和园区UPF间链路惯性运行定时器。

   **SET PFCPPARA**
4. 设置控制面扫描用户的速率。

   **SET UPCSCANRATE**

## 任务示例

任务描述

开启业务园区惯性运行开关，当N2和N4接口同时故障时，连接态用户惯性运行。

脚本

//设置园区惯性运行开关。

```
MOD UPNODE: NFINSTANCENAME="upf1", IOSWITCH=ENABLE, CAMPUSSW=ENABLE;
```

//设置SMF和园区UPF间链路惯性运行定时器。

```
SET PFCPPARA: IOINTERVAL=60;
```

//设置控制面扫描用户的速率。

```
SET UPCSCANRATE: SCANTYPE=INERTIALOPERATION, RATE=30;
```
