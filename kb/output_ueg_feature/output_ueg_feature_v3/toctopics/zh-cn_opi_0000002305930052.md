# 配置接续时延优化

## 操作场景

该任务用于指导操作人员根据华为网优报告的操作建议配置基本数据，缩短用户从拨打电话到开始振铃之间的时延，以实现接续时延优化的目标。

## 对系统的影响

* 会导致CPU占用率上升10%左右。
* 可能需要增加Pod数量。

## 必备事项

前提条件

操作人员具有业务发放权限。

数据

执行该任务前需要规划的数据，此处以CSCF网元为例（ATS网元类似），如表1所示。

**表1** 接续时延优化数据规划（配置时请结合华为网优报告的操作建议，以下数据规划以配置Q.922链路优化功能为例）

| 使用命令 | 参数 | 取值样例 | 说明 |
| --- | --- | --- | --- |
| ****MOD OPTCFG**** | 优化类型 | Q922(Q922) | 用于指定接续时延优化配置数据记录的优化类型。  取值范围：   * “Q922(Q922)”：Q.922链路优化功能。 * “ADJUST(ADJUST)”：调整时延功能。 * “SELECT(SELECT)”：select优化功能。   默认值：无。 |

|  | 自适应模式 | SELFADAPT(自适应) | 仅当本命令中的“优化类型”参数为“Q922(Q922)”或“SELECT(SELECT)”时该参数有效，用于指定接续时延优化配置数据记录的自适应状态。  取值范围：   * “CLOSE(关闭)”：关闭接续时延优化功能。 * “OPEN(打开)”：打开接续时延优化功能。 * “SELFADAPT(自适应)”：根据CPU动态调整接续时延优化功能。   默认值：无。 |
|  | CPU阈值1 | 10 | 用于指定低CPU阈值，单位为百分比。仅当本命令中的“优化模式”参数为“OPEN(打开)”或“自适应模式”参数为“SELFADAPT(自适应)”时该参数有效。“CPU阈值1”必须小于“CPU阈值2”。  说明：  当CPU低于“CPU阈值1”的次数达到10次以上时，系统会自动开启接续时延优化功能。此后，若CPU在“CPU阈值1”和“CPU阈值2”之间，接续时延优化功能处于开启状态；直至CPU高于“CPU阈值2”的次数达到10次以上时，系统会自动关闭接续时延优化功能。  取值范围：1～99  默认值： 无。 |
|  | CPU阈值2 | 20 | 用于指定高CPU阈值，单位为百分比。仅当本命令中的“优化模式”参数为“OPEN(打开)”或“自适应模式”参数为“SELFADAPT(自适应)”时该参数有效。“CPU阈值1”必须小于“CPU阈值2”。  说明：  当CPU高于“CPU阈值2”的次数达到10次以上时，系统会自动关闭接续时延优化功能。此后，若CPU在“CPU阈值1”和“CPU阈值2”之间，接续时延优化功能处于关闭状态；直至CPU低于“CPU阈值1”的次数达到10次以上时，系统会自动开启接续时延优化功能。  取值范围：1～99  默认值： 无。 |
|  | 时延值1 | — | 用于指定低时延的值，单位为毫秒。仅当本命令中的“优化模式”参数为“OPEN(打开)”时该参数有效。当CPU低于“CPU阈值1”的次数达到10次以上时，系统会自动调整时延为“时延值1”。  说明：  当CPU低于“CPU阈值1”的次数达到10次以上时，系统会自动调整时延为“时延值1”。此后，若CPU在“CPU阈值1”和“CPU阈值2”之间，时延为“时延值1”；直至CPU高于“CPU阈值2”的次数达到10次以上时，系统会自动调整时延为“时延值2”。  取值范围：1～10  默认值： 无。 |
|  | 时延值2 | — | 用于指定高时延的值，单位为毫秒。仅当本命令中的“优化模式”参数为“OPEN(打开)”时该参数有效。当CPU高于“CPU阈值2”的次数达到10次以上时，系统会自动调整时延为“时延值2”。  说明：  当CPU高于“CPU阈值2”的次数达到10次以上时，系统会自动调整时延为“时延值2”。此后，若CPU在“CPU阈值1”和“CPU阈值2”之间，时延为“时延值2”；直至CPU低于“CPU阈值1”的次数达到10次以上时，系统会自动调整时延为“时延值1”。  取值范围：1～10  默认值： 无。 |

## 操作步骤

配置Q.922链路优化功能

1. 进入OM Portal“应用管理>MML>UCN”窗口。
2. 执行****MOD OPTCFG****命令，选择“优化类型”为“Q922(Q922)”。
3. 选择“自适应模式”为“SELFADAPT(自适应)”。
4. 选择“CPU阈值1”为“10”。
5. 选择“CPU阈值2”为“20”。

## 任务示例

任务描述

配置Q.922链路优化功能。

脚本

/\*----------在OM Portal“应用管理>MML>UCN”窗口----------\*/

/\*配置Q.922链路优化功能\*/

```
MOD OPTCFG: OT=Q922, SAM=SELFADAPT, CPUTHD1=10, CPUTHD2=20;
```
