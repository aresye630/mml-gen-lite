# 配置N4（N4/Sxa/Sxb）接口

## 操作场景

用于配置总部园区UPF/GW-U的N4/Sxa/Sxb接口数据。由于SMF/GW-C侧的N4接口规划外出对接子园区UPF/GW-U的VPN，因此总部园区UPF/GW-U侧的N4/Sxa/Sxb接口需要与SMF/GW-C侧的N4接口绑定的VPN一致。

对于容灾的两个UEG-S而言，此配置没有区别，仅以一个UEG-S做配置举例。

## 必备事项

前提条件

无。

数据

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD VPNINST** | VPN实例名称（VPNINSTANCE） | VRF\_PS\_N4 | 全网规划 | 逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。 |
| **ADD LOGICINF** | 逻辑接口名称（NAME） | N4if1/0/0 | 全网规划 | UEG上N4、Sxa、Sxb接口不支持独立配置，只支持使用合一抽象接口名称N4if进行配置。  N4接口名称唯一，为N4if1/0/0。 |
|  | 逻辑接口的IP版本（IPVERSION） | IPVER\_ALL | 全网规划 | 如果规划逻辑接口使用IPv4v6双栈组网，则该参数取值为“IPVER\_ALL”，分别配置IPv4和IPv6地址。 |
|  | 逻辑接口的IPv4地址1（IPV4ADDRESS1） | 10.1.4.1 | 全网规划 |  |
|  | 逻辑接口的IPv4掩码1（IPV4MASK1） | 255.255.255.255 | 固定取值 |  |
|  | 逻辑接口的IPv6地址1（IPV6ADDRESS1） | FC00::4:1 | 全网规划 |  |
|  | IPv6前缀长度1（IPV6PREFIXLEN1） | 128 | 全网规划 |  |
|  | VPN实例名称（VPNINSTANCE） | VRF\_PS\_N4 | 全网规划 | - |
| **SET UPINFO** | HOSTNAME（HostName） | UP\_001 | 本端规划 | UPF标识。不同UPF，该参数不能相同。  如不配置该参数，则偶联会建立失败。 |

## 任务示例

任务描述

配置总部园区UPF/GW-U的N4/Sxa/Sxb接口数据。

脚本

1. 配置N4（N4/Sxa/Sxb）逻辑接口所属的VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE="VRF_PS_N4";
   ```
2. 配置N4（N4/Sxa/Sxb）逻辑接口。

   ```
   ADD LOGICINF: NAME="N4if1/0/0", IPVERSION=IPVER_ALL, IPV4ADDRESS1="10.1.4.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VRF_PS_N4",IPV6ADDRESS1="FC00::4:1", IPV6PREFIXLEN1=128;
   ```
3. 配置UEG信息。

   ```
   SET UPINFO: HOSTNAME="UP_001";
   ```
