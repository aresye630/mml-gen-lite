# 配置UEG间直连口

## 操作场景

本章节适用于UEG裸机设备直连PE，UEG之间存在直连物理口对接的组网场景。两个UEG之间使用OSPF协议对接。

本章节配置的UEG间直连口，用于传输激活在另一UEG上的用户业务报文（与企业园区服务器/App交互的报文除外），如图1所示。

**图1** UEG间直连口传输用户业务报文示意

## 必备事项

前提条件

* 必须是UEG 21.10.0及后续版本。
* UEG间直连口已通过光纤连接。

数据

* 如下数据仅为举例，请注意修改成局点规划的数据。
* 此处以图1中的相关业务报文为例，实际请以局点具体业务规划。

**表1** OSPF关键参数

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 逻辑接口 | N2 （适用于风筝M/L） | N4  （适用于风筝M） | N9  （适用于风筝M） | S6a/N8/N10/N12/N14  （与中心UDM互通）  （适用于风筝M/L） |
| VRF名称 | VRF_CN | VRF_Pa | VRF_SBI | VRF_SBI |
| OSPF进程号 | 110 | 120 | 130 | 130 |

| 区域类型 | Normal | Normal | Normal | Normal |

## 操作步骤

1. UEG和PE之间使用静态路由+BFD(auto)方案对接时，在UEG上配置全局BFD的“会话延迟Up时间（DELAYUPTIMER）”。若UEG与PE使用静态路由+BFD(echo)方案对接，则需要在PE上配置BFD会话延迟Up时间。

   ```
   SET BFD: BFDENABLE=TRUE, DELAYUPTIMER=60;
   ```
2. 配置UEG间的IP路由数据，用于传输激活在另一UEG上的用户的N2（风筝M/L）/N3（风筝S/M/L）业务报文。
   1. 配置外联口IP地址。

      1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

         ```
         LST INTERFACE:;
         ```
      2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

         ```
         MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up;
         MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
         ```
      3. 添加Eth-trunk接口及Eth-trunk子接口。成员端口数量以网设规划的为准。

         //添加Eth-trunk接口及成员接口。如已配置，则不需要重复配置。

         ```
         ADD INTERFACE:IFNAME="Eth-trunk1";
         MOD TRUNKIF:IFNAME="Eth-Trunk1",WORKMODE=Manual;
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/4";
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/5";
         ```

         //添加Eth-trunk子接口。

         ```
         ADD INTERFACE:IFNAME="Eth-trunk1.2050";
         ```
      4. 增加接口绑定VPN。

         ```
         ADD IPBINDVPN:IFNAME="Eth-trunk1.2050",VRFNAME="VRF_Access";
         ```
      5. 在以太网子接口上关联VLAN ID。

         ```
         ADD ETHSUBIF:IFNAME="Eth-trunk1.2050",VLANTYPEVID=2050;
         ```
      6. 配置IPv6使能。

         ```
         SET IFIPV6ENABLE: IFNAME="Eth-trunk1.2050", ENABLEFLAG=TRUE;
         ```
      7. 配置外联口IP地址。

         ```
         ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.2050",IFIPADDR="192.168.150.2",SUBNETMASK="255.255.255.248";
         ```

         ```
         ADD IFIPV6ADDRESS:IFNAME="Eth-trunk1.2050",IPV6ADDRESS="FC00::150:2",PREFIXLEN=125;
         ```
   2. 配置OSPF路由数据。该步骤适用于IPv4组网或IPv4v6双栈组网。

      1. 创建OSPF进程。

         ```
         ADD OSPF:PROCID=100,VRFNAME="VRF_Access",SCHEMAROUID="192.168.225.150",BFDALLINTFFLG=FALSE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=FALSE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA: PROCID=100, AREAID="0.0.0.5", AREATYPE=Normal, MAXCOSTFLAG=FALSE;
         ```
      3. 配置OSPF协议的接口属性。

         ```
         ADD OSPFINTERFACE: PROCID=100, AREAID="0.0.0.5", IFNAME="Eth-trunk1.2050", VIRTUALSYSFLAG=FALSE, BFDENABLE=TRUE, MINRXRECVINTV=1000, MINTXTRANINTV=1000, DETECTMULINTV=5, CFGROUTERIDFLAG=FALSE, MAXCOSTFLAG=FALSE;
         ```
      4. 设置OSPF引入的路由类型。

         ```
         ADD OSPFIMPORTROUTE: PROCID=100, TOPOID=0, PROTOCOL=Static, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ADD OSPFIMPORTROUTE: PROCID=100, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ADD OSPFDEFAULTROUTE: PROCID=100, TOPOID=0;
         ```
   3. 配置OSPFv3路由数据。该步骤适用于IPv6组网或IPv4v6双栈组网。

      1. 创建OSPFv3进程。

         ```
         ADD OSPFV3:PROCID=100,VRFNAME="VRF_Access",ROUTERID="192.168.225.150",BFDALLINTFFLG=FALSE,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=FALSE;
         ```
      2. 增加OSPFv3区域。

         ```
         ADD OSPFV3AREA: PROCID=100, AREAID="0.0.0.5", AREATYPE=Normal;
         ```
      3. 配置OSPFv3协议的接口属性。

         ```
         ADD OSPFV3INTERFACE: PROCID=100, AREAID="0.0.0.5", IFNAME="Eth-trunk1.2050", VIRTUALSYSFLAG=FALSE, BFDENABLE=TRUE, MINRXRECVINTV=1000, MINTXTRANINTV=1000, DETECTMULINTV=5, CFGROUTERIDFLAG=FALSE;
         ```
      4. 设置OSPFv3引入的路由类型。

         ```
         ADD OSPFV3IMPORTROUTE: PROCID=100, TOPOID=0, PROTOCOL=Static, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ADD OSPFV3IMPORTROUTE: PROCID=100, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ADD OSPFV3DEFAULTROUTE: PROCID=100, TOPOID=0;
         ```
