## 操作场景

当运营商为了均衡APP的负荷，部署了多台APP Server进行负荷分担，采用负载均衡机制对外呈现单一的虚拟IP地址时，MPF需要部署负载均衡机制，将通过Nxu接口的VXLAN-GPE（Generic Protocol Extension for VXLAN）隧道转发到MPF上的数据报文分流到具体的APP Server。

适用于MPF。

## 必备事项

前提条件

* 请仔细阅读负载均衡机制原理。
* 已完成加载License。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置IPFarm全局参数。

   **SET IPFARMGLOBAL**

   负载均衡模式通过**SET IPFARMGLOBAL**命令的“LBMETHOD”参数配置：

   * ROUND\_ROBIN：指定为轮询方式，即在一个IPfarm内对所有APP Server进行轮询，跳过状态为down的APP Server。
   * LEAST\_LOAD：指定为选择最小负荷APP Server方式，即在一个IPfarm内，记录每个APP Server上的实时负荷量，当负荷分担时选择负荷量最小的APP Server。当有APP Server状态为down，则将该APP Server负荷量清零。
   * LEAST\_RECENTLY\_USED：指定为选择最久未被使用的APP Server。在一个IPfarm内，记录每个APP Server被选择的时间，负荷分担时选择最久未被使用的APP Server，并更新其被选择的时间。当有APP Server状态为down，则将该APP Server的被选择时间清零。
3. 配置IP Farm使用的心跳检测接口。
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置IP Farm使用的心跳检测接口。

      **ADD LOGICINF**
4. 配置IP Farm。
   1. 创建重定向的IP Farm，不同IP Farm下的服务器需要配置不同的心跳检测接口。

      **ADD IPFARM**
   2. 为该ip-farm绑定已配置的心跳检测接口，通过该接口发送接收心跳检测消息。

      **ADD IPFARMSERVER**

      IP Farm配置完成后，可以执行命令**LST IPFARMSERVER**查询IP Farm中Server的状态。为确保业务正常进行，需保证至少有一个Server的状态为up。
5. 配置触发负载均衡机制的三四层过滤条件。
   1. 配置负载均衡机制使用的三四层过滤条件，IP地址为APP Server的虚拟IP地址。

      **ADD FILTER**
   2. 配置FlowFilter。

      **ADD FLOWFILTER**
   3. 将Filter绑定到FlowFilter。

      **ADD FLTBINDFLOWF**
   4. 刷新Filter配置。

      **SET REFRESHSRV**
6. 配置负载均衡机制使用的规则。

   **ADD RULE**
7. 配置负载均衡机制使用的业务策略组合。
   1. 配置User Profile。

      **ADD USERPROFILE**
   2. 将配置的Rule绑定到User Profile。

      **ADD RULEBINDING**
   3. 将User Profile指定为全局User Profile。

      **ADD LOCALUSERPROF**

      **ADD LOCALUSERPROF**命令的“USERPROFILENAME”和**ADD USERPROFILE**命令的“USERPROFILENAME”必须配置为相同值。

## 任务示例

任务描述

本实例中，操作员在MPF上进行数据配置实现以下要求：

* MPF使用轮询方式实现APP Server负载均衡。
* MPF将用户发往“10.1.1.1”服务器的IPv4报文转换到“10.1.2.1”或“10.1.2.2”或“10.1.2.3”或“10.1.2.4”服务器上。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5LBAN02",SWITCH=ENABLE;
```

//配置IP Farm全局参数。

```
SET IPFARMGLOBAL:SERVERTYPE=REDIRECT,TIMETHRESHOLD=6,HEALTHSUCCLIMIT=3,HEALTHFAILLIMIT=3,LBMETHOD=ROUND_ROBIN;
```

//配置IP Farm使用的心跳检测接口。

```
ADD VPNINST:VPNINSTANCE="VPN_phif";
```

```
ADD LOGICINF:NAME="phif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="10.10.10.10",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_phif";
```

//配置IP Farm。

```
ADD IPFARM:HEALTHCHECKFLAG=ENABLE,IPFARMNAME="farm_test",IPVERSION=IPV4,SERVERTYPE=REDIRECT,VPNINSTANCE="VPN_phif",VIRTUALIP="10.1.1.1",INTERFACENAME="phif1/0/0";
```

```
ADD IPFARMServer:IPFARMNAME="farm_test",IPVERSION=IPV4,ServerIPV4="10.1.2.1";
```

```
ADD IPFARMServer:IPFARMNAME="farm_test",IPVERSION=IPV4,ServerIPV4="10.1.2.2";
```

```
ADD IPFARMServer:IPFARMNAME="farm_test",IPVERSION=IPV4,ServerIPV4="10.1.2.3";
```

```
ADD IPFARMServer:IPFARMNAME="farm_test",IPVERSION=IPV4,ServerIPV4="10.1.2.4";
```

//配置负载均衡机制使用的三四层过滤条件，过滤器的IP地址为负载均衡的APP Server的虚拟IP地址。

```
ADD FILTER:FILTERNAME="filter_test",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=IP,SVRIP="10.1.1.1",SVRIPMASKTYPE=IPTYPE,SVRIPMASK="0.0.0.0";
```

```
ADD FLOWFILTER:FLOWFILTERNAME="flow-l34";
```

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="flow-l34",FILTERNAME="filter_test";
```

```
SET REFRESHSRV:REFRESHTYPE=ALL;
```

//配置负载均衡机制使用的规则。

```
ADD RULE:RULENAME="rule_test1",POLICYTYPE=WEBPROXY,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flow-l34",PRIORITY=10,POLICYNAME="farm_test";
```

//配置负载均衡机制使用的业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
```

```
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test1";
```

```
ADD LOCALUSERPROF:USERPROFILENAME="up_test";
```

//配置软参**BIT596**和**BIT1541**，保证用户业务报文可以采用负载均衡机制进行分流。

```
SET SOFTPARA:DT=BIT,BITNUM=596,BITVALUE=0;
SET SOFTPARA:DT=BIT,BITNUM=1541,BITVALUE=1;
```
