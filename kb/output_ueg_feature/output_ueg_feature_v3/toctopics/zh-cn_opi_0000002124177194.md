# 配置5G LAN层二环路消除（UPF）

## 操作场景

同一5G LAN终端组成员之间或5G LAN终端组的成员和数据网络中的应用之间进行以太通信时，可通过部署5G LAN层二环路消除，避免二层环路的危害。

## 必备事项

前提条件

* 请仔细阅读GWFD-031104 5G LAN层二环路消除特性概述。
* 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。
* 已完成配置5G LAN基本功能。

数据

**表1** UPF上环路检测及消除相关数据（层二5G LAN）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET NGLOOPDETFUNC** | 5G LAN组名称（VNINSTANCE） | 000003e9-460-08-02 | 已配置数据中获取 | 采用**ADD NGVNINSTANCE**命令定义的VNINSTANCE。 |
|  | 环路检测开关（ETHLOOPDETECTSW） | ENABLE | 本端规划 | 开启环路检测时，使用样例值。 |
|  | 环路检测方式（  DETECTMETHOD  ） | SEND\_DETECT\_MSG | 本端规划 | * 推荐采用主动检测，主动检测时，使用样例值。 * 当CPE不支持UPF发送的主动环路检测消息等不兼容场景，可采用被动检测，“环路检测方式”参数值设置为“MAC\_FLAP\_NUM”。 * 主动检测和被动检测均不适用的特殊场景，需关闭环路检测开关。默认关闭环路检测开关。 |
|  | MAC地址漂移次数（MACFLAPNUM） | 10 | 本端规划 | “环路检测方式”设置为“MAC\_FLAP\_NUM”时，UPF根据设置的MAC地址漂移次数阈值，判断是否去活会话。 |
| **SET UPETHSRVPARA** | 用户面以太业务开关（UPETHSRVSW） | ENABLE | 本端规划 | 环路检测方式采用主动检测时，使用样例值。 |
|  | 用户面以太业务MAC（UPETHSRVMAC） | FA-16-3E-A0-04-D6 | 本端规划 | 此处配置的是UPF发送的环路探测报文的源MAC地址，建议采用N3逻辑接口对应的物理接口的MAC地址，避免MAC地址冲突。  可通过执行**LST LOGICINF**命令，获取N3if或Saif接口绑定的VPN实例，然后再执行**LST INTERFACE**命令获取对应的外联口的MAC地址。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 采用主动检测方案时，配置基于5G LAN组粒度的环路检测及环路消除功能。采用被动检测方案时，请跳过本步骤。
   1. 配置环路检测方式。

      **SET NGLOOPDETFUNC**
   2. 配置环路探测报文的源MAC地址。

      **SET UPETHSRVPARA**
3. 采用被动检测方案时，配置基于5G LAN组粒度的环路检测及环路消除功能。采用主动检测方案时，请跳过本步骤。

   **SET NGLOOPDETFUNC**

## 验证方法

1. 执行**LST LICENSESWITCH**命令，查询UEG上对应的License配置开关是否打开。

   ```
   LST LICENSESWITCH: LICITEM="LKV3G5LAN2LE";
   ```

   * 如果“SWITCH”为“ENABLE”，请执行3。
   * 如果“SWITCH”为“DISABLE”，则执行**SET LICENSESWITCH**命令打开本特性对应的License配置开关。
2. 在UPF上开启N4消息跟踪，在SMF上开启N4消息跟踪和用户跟踪。
3. 参考图2构造环路。
4. 使用行业终端发送广播报文。
5. 检查UPF上是否产生ALM-81245 5G LAN MAC地址冲突告警。
   * 是，请执行7。
   * 否，请执行6。
6. 检查UPF上环路消除配置是否正确。
   * 正确，请执行11。
   * 不正确，请参考操作步骤修改为正确的配置后重新调测。
7. 检查UPF是否通过N4消息向SMF发送去活5G LAN用户的请求。
   * 是，请执行8。
   * 否，请执行11。
8. 检查SMF是否基于UPF的请求去活用户。
   * 是，请执行9。
   * 否，请执行11。
9. 检查去活的用户是否符合预期。主动检测时执行本步骤，被动检测时请跳过本步骤。

   ```
   DSP NGLOOPDETDEAUE: VNINSTANCE="000003e9-460-08-02";
   ```

   * 是，请执行10。
   * 否，请执行11。
10. 拆除构造环路的连线，调测结束。
11. 收集信息并寻求技术支持。
    1. 在UEG命令行窗口执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
    2. 收集并保存上述所有查询信息。
    3. 查看并收集对端设备配置及接口状态信息。
    4. 收集归纳所有信息并联系华为技术支持解决。

## 任务示例

任务描述

CPE支持UPF发送的主动检测环路的报文，该场景下，采用主动检测方案，请参考任务实例一。

CPE不支持UPF发送的主动检测环路报文，该场景下，可采用被动检测方案，请参考任务实例二。

脚本

**//任务实例一：采用主动检测方案**

//开启本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5LAN2LE", SWITCH=ENABLE;
```

//开启基于5G LAN组的主动探测开关。

```
SET NGLOOPDETFUNC: VNINSTANCE="000003e9-460-08-02", ETHLOOPDETECTSW=ENABLE, DETECTMETHOD=SEND_DETECT_MSG;
```

//此处配置的是UPF发送的环路探测报文的源MAC地址，建议采用N3逻辑接口对应的物理接口的MAC地址，避免MAC地址冲突。可通过执行**LST LOGICINF**命令，获取N3if或Saif接口绑定的VPN实例，然后再执行**LST INTERFACE**命令获取对应的外联口的MAC地址。

```
SET UPETHSRVPARA: UPETHSRVSW=ENABLE, UPETHSRVMAC="FA-16-3E-A0-04-D6";
```

**//任务实例二：采用被动检测方案**

//开启本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5LAN2LE", SWITCH=ENABLE;
```

//配置基于5G LAN组的被动检测参数。

```
SET NGLOOPDETFUNC: VNINSTANCE="000003e9-460-08-02", ETHLOOPDETECTSW=ENABLE, DETECTMETHOD=MAC_FLAP_NUM, MACFLAPNUM=10;
```
