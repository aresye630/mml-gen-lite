# 配置组网路由（直连DCGW）

## 操作场景

UEG-L部署在总部园区，作为SMF/GW-C/MME需要对接子园区UEG-S的UPF/GW-U。推荐UEG-L对接DCGW（交换机），DCGW之间使用M-LAG组网。UEG采用Eth-trunk接口，每个Eth-trunk下分别有2个成员端口，每个成员端口，分别连接到2个DCGW上。

UEG通过BGP over静态路由+BFD单臂echo与对端网元（UPF/GW-U）实现网络互通，组网规划如图1所示。

对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

## 任务示例

任务描述

* 总部园区UEG-L的N4和S11-U接口推荐共用VPN，UEG-L对接DCGW（交换机）。
* UEG-L的SMF/GW-C/MME到DCGW采用BGP over 静态路由+BFD组网。
* 对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_PS_N4",VRFDESCRIPTION="N4";
   ADD VPNINSTAF:VRFNAME="VRF_PS_N4",AFTYPE=ipv4uni, VRFRD="192.168.225.136:100";
   ADD VPNINSTAF:VRFNAME="VRF_PS_N4",AFTYPE=ipv6uni, VRFRD="192.168.225.136:100";
   ```
3. VRF\_PS\_N4配置Loopback接口IP。用于建立BGP邻居。

   ```
   ADD INTERFACE:IFNAME="LoopBackv4"; 
   ADD IPBINDVPN:IFNAME="LoopBackv4",VRFNAME="VRF_PS_N4"; 
   ADD IFIPV4ADDRESS:IFNAME="LoopBackv4",IFIPADDR="192.168.225.136",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
   ADD INTERFACE:IFNAME="LoopBack6"; 
   ADD IPBINDVPN:IFNAME="LoopBack6",VRFNAME="VRF_PS_N4"; 
   SET IFIPV6ENABLE: IFNAME="LoopBack6", ENABLEFLAG=TRUE; 
   ADD IFIPV6ADDRESS:IFNAME="LoopBack6",IPV6ADDRESS="FC00::225:136",PREFIXLEN=128;
   ```
4. 配置BGP VPN实例。

   ```
   ADD BGPVRF: VRFNAME="VRF_PS_N4", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.136";
   ```
5. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

   ```
   ADD BGPVRFAF: VRFNAME="VRF_PS_N4", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
   ADD BGPVRFAF: VRFNAME="VRF_PS_N4", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
   ```
6. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

   ```
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.6", REMOTEAS="60002", LOCALIFADDR="192.168.225.136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.6", REMOTEAS="60002", LOCALIFADDR="192.168.225.136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ```

   ```
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:6", REMOTEAS="60002", LOCALIFADDR="FC00::225:136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:6", REMOTEAS="60002", LOCALIFADDR="FC00::225:136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ```
7. 配置BGP引入wlr路由。

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_PS_N4", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_PS_N4", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```
8. 配置外联口IP地址。
   1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up; 
      MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet64/0/12",IFADMINSTATUS=up; 
      MOD INTERFACE:IFNAME="Ethernet64/0/13",IFADMINSTATUS=up;
      ```
   3. 添加Eth-trunk接口及Eth-trunk子接口。成员端口数量以网设规划的为准。

      ```
      ADD INTERFACE:IFNAME="Eth-trunk1"; 
      MOD TRUNKIF:IFNAME="Eth-Trunk1",WORKMODE=Manual; 
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/4"; 
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/5"; 
      ADD INTERFACE:IFNAME="Eth-trunk1.2";
      ```

      ```
      ADD INTERFACE:IFNAME="Eth-trunk2"; 
      MOD TRUNKIF:IFNAME="Eth-Trunk2",WORKMODE=Manual; 
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/12"; 
      ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/13"; 
      ADD INTERFACE:IFNAME="Eth-trunk2.2";
      ```
   4. 增加子接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Eth-trunk1.2",VRFNAME="VRF_PS_N4";
      ADD IPBINDVPN:IFNAME="Eth-trunk2.2",VRFNAME="VRF_PS_N4";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Eth-trunk1.2",VLANTYPEVID=2006;
      ADD ETHSUBIF:IFNAME="Eth-trunk2.2",VLANTYPEVID=2016;
      ```
   6. 配置IPv6使能。

      ```
      SET IFIPV6ENABLE: IFNAME="Eth-trunk1.2", ENABLEFLAG=TRUE;
      SET IFIPV6ENABLE: IFNAME="Eth-trunk2.2", ENABLEFLAG=TRUE;
      ```
   7. 配置外联口IP地址。

      ```
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.2",IFIPADDR="192.168.86.2",SUBNETMASK="255.255.255.248";
      ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.2",IFIPADDR="192.168.186.2",SUBNETMASK="255.255.255.248";
      ```

      ```
      ADD IFIPV6ADDRESS:IFNAME="Eth-trunk1.2",IPV6ADDRESS="FC00::86:2",PREFIXLEN=125;
      ADD IFIPV6ADDRESS:IFNAME="Eth-trunk2.2",IPV6ADDRESS="FC00::186:2",PREFIXLEN=125;
      ```
9. 新建BFD会话，配置BFD单臂echo探测。

   ```
   ADD BFDSESSION: SESSNAME="BfdName861_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.86.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_PS_N4",MINECHORXINT=500,LOCALDISCR=8861,IFNAME="Eth-trunk1.2";
   ADD BFDSESSION: SESSNAME="BfdName861_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_PS_N4",LOCALDISCR=8041,IFNAME="Eth-trunk1.2",DESTADDR6="FC00::86:1";
   ```

   ```
   ADD BFDSESSION: SESSNAME="BfdName1861_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.186.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_PS_N4",MINECHORXINT=500,LOCALDISCR=8862,IFNAME="Eth-trunk2.2";
   ADD BFDSESSION: SESSNAME="BfdName1861_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_PS_N4",LOCALDISCR=8042,IFNAME="Eth-trunk2.2",DESTADDR6="FC00::186:1";
   ```
10. 采用BGP over静态路由+BFD时，配置静态路由并绑定BFD会话。

    //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

    ```
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.6",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk1.2",NEXTHOP="192.168.86.1",SESSIONNAME="BfdName861_v4";
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.78.6",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk1.2",NEXTHOP="192.168.86.1",SESSIONNAME="BfdName861_v4";
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk1.2",NEXTHOP="192.168.86.1",SESSIONNAME="BfdName861_v4";
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.6",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk2.2",NEXTHOP="192.168.186.1",SESSIONNAME="BfdName1861_v4";
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.78.6",MASKLENGTH=32,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk2.2",NEXTHOP="192.168.186.1",SESSIONNAME="BfdName1861_v4";
    ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_PS_N4",DESTVRFNAME="VRF_PS_N4",IFNAME="Eth-trunk2.2",NEXTHOP="192.168.186.1",SESSIONNAME="BfdName1861_v4";
    ```

