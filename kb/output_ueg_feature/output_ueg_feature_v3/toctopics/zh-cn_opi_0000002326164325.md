# 配置Radius功能（AAA灵活调整5G LAN组ID）

## 操作场景

企业产线部署5G LAN业务后，存在根据业务实际需要，灵活调整CPE（5G模组）/5G LAN终端（5G模组）签约的5G LAN组的需求。

产线需要灵活调整时，若仅依赖在UDM上修改5G LAN组签约数据，则存在申请周期较长等问题。故需支持灵活调整时，可基于AAA服务器调整用户所属的5G LAN组。

基于AAA服务器实现5G LAN组ID的灵活调整，依赖如下功能：

* SMF支持基于二次鉴权流程，从AAA服务器（Radius服务器）获取签约的5G LAN组ID。
* SMF支持基于APN配置以从AAA服务器（Radius服务器）获取签约的5G LAN组ID为准，不使用从UDM获取签约的5G LAN组ID。

该任务旨在指导操作人员完成SMF与AAA（Radius Server）的对接配置和功能配置。从组网上看，SMF与AAA对接支持如下两种方式：

* 直连方式：SMF与AAA直接互通，不经由UPF中转二次鉴权消息。组网示意如图1所示。

  **图1** 直连方式组网示意
* 非直连方式：SMF与AAA不能直接互通，需经由UPF中转二次鉴权消息。组网示意如图2所示。

  **图2** 非直连方式组网示意

## 必备事项

前提条件

* 已完成配置SMF数据。
* 已申请并加载License控制项“LKV2SECAA01 终端二次鉴权”和“LKV2UNCCOA1 支持CoA功能”。
* 二次鉴权消息经由UPF中转时，必须先配置UPF上的相关数据，详细请参见配置终端二次鉴权（风筝S，通过AAA灵活调整5G LAN组ID）。
* 对需由AAA调整5G LAN组ID的用户，UDM上仍需初始签约5G LAN组ID。

数据

* 采用直连方式时，需要规划表1~表5的数据。
* 采用非直连方式时，需要规划表1~表9的数据。

* 表1~表4与5G LAN不强相关，参数规划遵循Radius功能中的原则。
* 表5是5G LAN专有数据，必须遵循表5中的参数规划原则。
* 表6~表9与5G LAN不强相关，参数规划遵循终端二次鉴权功能中的原则。

## 任务示例

任务描述

任务示例一：SMF与AAA直接互通，不经由UPF中转二次鉴权消息。

任务示例二：SMF与AAA不能直接互通，需经由UPF中转二次鉴权消息。

脚本

**//****公共数据：任务示例一和任务示例二均需要的配置。**

//打开License开关。

```
SET LICENSESWITCH: LICITEM="LKV2UNCCOA1", SWITCH=ENABLE;
```

//创建L3VPN实例。

```
ADD L3VPNINST:VRFNAME="VRF_AAA";
ADD VPNINSTAF: VRFNAME="VRF_AAA", AFTYPE=ipv4uni, VRFLABELMODE=perRoute;
```

//创建VPN实例。

```
ADD VPNINST: VPNINSTANCE ="VRF_AAA";
```

//配置Gi接口。

```
ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.8.20.1", VPNINSTNAME="VRF_AAA"; 
ADD LOGICINF:NAME="giif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="10.8.20.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_AAA";
```

//配置Radius服务器组和Radius服务器。

```
ADD RDSSVRGRP: RDSSVRGRPNAME="radius_001", MODE=MASTER_SLAVE, ACCTTOAUTH=DISABLE, SIGOPTACCTMSG=DISABLE, ACCTTIMEOUT=10, ACCTRETRANSMIT=5;
ADD RDSSVR: RDSSVRGRPNAME="radius_001", SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="10.168.10.1", PORT=1812, VPNINSTANCE="VRF_AAA", CIPHERKEY="*****", CONGESTION=DISABLE, PRIFLAG=PRIMARY, WALVALUE=0, CIPHERKEYCNFM="*****", UDPCHECKSUMSW=ENABLE;
```

//配置Gi接口鉴权。

```
ADD RADIUSCLIENTIP: RDSSVRGRPNAME="radius_001", AUTHORACCT=AUTHENTICATION, INTFNAME="giif1/0/0";
```

//配置APN级Gi接口鉴权。

```
ADD APNRDSCLIENTIP: APN="dnn5glan01", AUTHORACCT=AUTHENTICATION, INTFNAME="giif1/0/0";
```

//配置access request消息鉴权属性。

```
SET APNAUTHATTR: APN="dnn5glan01", ACCESSMODE=NON_TRANS, AUTHMODE=MSISDN, PASSWORD="*****", COMMONUSERNAME="admin", COMMONUSERPASS="*****", COASWITCH=ENABLE, CFMCOMMUSERPASS="*****", CFMPASSWORD="*****";
```

//配置APN绑定Radius服务器组。

```
ADD APNRDSSVRGRP:APN="dnn5glan01", RDSSVRGRPNAME="radius_001";
```

//配置鉴权请求携带的属性。脚本仅为示例，实际能力需与对端AAA服务器协商。

```
SET RDSAUTHREQATTR: RDSSVRGRPNAME="radius_001", ACCTSESSIONID=ENABLE, NASID=ENABLE, NASIDTYPE=APN, IMSI=DISABLE, CHARGINGID=DISABLE, PREPAIDIND=DISABLE, GGSNIP=ENABLE, SGSNIP=ENABLE, REQUESTAPN=DISABLE, GGSNVENDOR=ENABLE, GGSNVERION=ENABLE, RQAUTHTICATOR=DISABLE, ACCTMULSESSID=ENABLE, EVENTTIME=ENABLE, NASPORTIDSW=ENABLE, NASPORTID="UNC", WLANADDR=DISABLE;
```

//配置鉴权请求携带的私有扩展属性。脚本仅为示例，实际能力需与对端AAA服务器协商。

```
SET RDSAUTHREQVSA:RDSSVRGRPNAME="radius_001", THREEGPP=ENABLE, IMSI=ENABLE, CHARGINGID=ENABLE, PDPTYPE=ENABLE, CGADDRESS=ENABLE, NEGOTIAEDQOS=ENABLE, SGSNSGWADDRESS=ENABLE, GGSNADDRESS=ENABLE, IMSIMCCMNC=ENABLE, GGSNMCCMNC=ENABLE, NSAPI=ENABLE, SELECTIONMODE=ENABLE, CHARGINGCHAR=ENABLE, SGSNSGWMCCMNC=ENABLE, IMEISV=ENABLE, RATTYPE=ENABLE, ULI=ENABLE, MSTIMEZONE=ENABLE, NEGOTIAEDDSCP=ENABLE, SGSNIPV6ADDRESS=ENABLE, GGSNIPV6ADDRESS=ENABLE, CGIPV6ADDRESS=ENABLE;
```

//配置Radius域名相关参数。

```
SET APNRADIUSATTR: APN="dnn5glan01", DOMAINNAMEACT=ADD_ENABLE_STRIP_DISABLE, DOMAINNAMEPOS=SUFFIX;
```

//配置SMF从Radius服务器（AAA）获取5G LAN组ID信息。

```
ADD APNSMCOMFUNC:APN="dnn5glan01", GETPOLICYFIRST=DISABLE, VNGRPIDSRC=Radius;
```

//配置允许Radius服务器（AAA）调整的5G LAN组ID白名单。Radius服务器（AAA）调整后的5G LAN组ID不在该白名单中时，调整失败。

```
ADD NGLANGRPSUB:GROUPID="000003e9-460-08-01", DNN="dnn5glan01";
```

```
ADD NGLANGRPSUB:GROUPID="000003e9-460-08-02", DNN="dnn5glan01";
```

**//专有数据：仅任务示例二（SMF与AAA不能直接互通，需经由UPF中转二次鉴权消息的场景）需要的配置。**

//增加与UPF对接的本端GTP-U地址。复用SMF N4信令接口的IP和VPN。

```
ADD CPGTPUADDR: IPVERSION=IPV4, IPV4ADDR="192.168.0.20", VPN="VRF_CN";
```

//配置中转使用的UPF列表。规划多个中转UPF时，需要配置多条数据。

```
ADD UPLIST4RDS: UPLISTNAME="uplist1", UPINSTANCEID="upf_instance_1";
```

//同一UP列表中存在多个中转UPF时，配置UPF实例的优先级。“PREFERENCE”值越大优先级越高，“LOCKED”使用样例值。

```
ADD RDSUPFCTRL: UPLISTNAME="uplist1", UPINSTANCEID="upf_instance_1", PREFERENCE=100, LOCKED=DISABLE;
```

//配置UPF与Radius服务器（AAA）绑定。需先在UPF上执行ADD NETWORKINSTVPNMAP命令否则SMF尝试建立N4-U会话失败，需延迟一段时间后才会自动重试，UPF上的配置请参见配置终端二次鉴权（风筝S，通过AAA灵活调整5G LAN组ID）。

```
ADD UPFRDSSVR: SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="10.168.10.1", UPLISTNAME="uplist1";
```

//配置UPF与Radius客户端（SMF Gi接口）绑定。

```
ADD UPFRDSCLIENTIP: CLIENTYPE=AUTHENTICATION, IPVERSION=IPV4, CLIENTIPV4="10.8.20.1", UPLISTNAME="uplist1", VPNINSTANCE="VRF_LocalDN";
```
