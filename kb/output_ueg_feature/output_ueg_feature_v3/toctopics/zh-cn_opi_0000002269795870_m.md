# 配置组网路由（DCGW）

## 操作场景

UEG-L部署在总部园区，作为SMF需要对接子园区UEG-M的UPF。UEG-L对接DCGW（路由器）或DCGW（交换机）。DCGW之间使用E-Trunk+EVPN或M-LAG组网，UEG使用Eth-trunk接口，一个Eth-trunk接口的成员端口，连接到同一台DCGW上。

UEG-L通过BGP over静态路由+BFD单臂echo与对端网元（UPF）实现网络互通，组网规划如图1所示。

对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

## 任务示例

任务描述

* 总部园区UEG-L的N4接口采用独立VPN，UEG-L对接DCGW（路由器）或DCGW（交换机）。
* UEG-L的SMF到DCGW为eBGP+BFD组网：BGP over静态路由，采用静态路由绑定BFD会话，BFD检测时间配置为500ms\*4。
* 对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

   ```
   SET AUTOCONFIG:SWITCHFLAG=FALSE;
   ```
3. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_PS_N4",VRFDESCRIPTION="N4";
   ADD VPNINSTAF:VRFNAME="VRF_PS_N4",AFTYPE=ipv4uni, VRFRD="192.168.225.136:100";
   ADD VPNINSTAF:VRFNAME="VRF_PS_N4",AFTYPE=ipv6uni, VRFRD="192.168.225.136:100";
   ```
4. VRF\_PS\_N4配置Loopback接口IP。用于建立BGP邻居。

   ```
   ADD INTERFACE:IFNAME="LoopBackv4"; 
   ADD IPBINDVPN:IFNAME="LoopBackv4",VRFNAME="VRF_PS_N4"; 
   ADD IFIPV4ADDRESS:IFNAME="LoopBackv4",IFIPADDR="192.168.225.136",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
   ADD INTERFACE:IFNAME="LoopBack6"; 
   ADD IPBINDVPN:IFNAME="LoopBack6",VRFNAME="VRF_PS_N4"; 
   SET IFIPV6ENABLE: IFNAME="LoopBack6", ENABLEFLAG=TRUE; 
   ADD IFIPV6ADDRESS:IFNAME="LoopBack6",IPV6ADDRESS="FC00::225:136",PREFIXLEN=128;
   ```
5. 配置BGP VPN实例。

   ```
   ADD BGPVRF: VRFNAME="VRF_PS_N4", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.136";
   ```
6. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

   ```
   ADD BGPVRFAF: VRFNAME="VRF_PS_N4", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
   ADD BGPVRFAF: VRFNAME="VRF_PS_N4", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
   ```
7. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

   ```
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.6", REMOTEAS="60002", LOCALIFADDR="192.168.225.136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.6", REMOTEAS="60002", LOCALIFADDR="192.168.225.136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ```

   ```
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:6", REMOTEAS="60002", LOCALIFADDR="FC00::225:136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ADD BGPPEER: VRFNAME="VRF_PS_N4", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:6", REMOTEAS="60002", LOCALIFADDR="FC00::225:136", LOCALIFNAME="Loopback6", EBGPMAXHOP=10;
   ```
8. 配置BGP引入wlr路由。

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_PS_N4", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_PS_N4", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```
9. 添加以太网隧道多虚拟网卡自动化配置模板。与N3共用物理口时，请跳过本步骤。

   ```
   ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
   ```
10. 配置外联口自动部署模板。

    ```
    ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_CN_2006_v4",VPNNAME="VRF_PS_N4",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2006, BEGINADDR4="192.168.86.2", ENDADDR4="192.168.86.30", MASKLEN=27;
    ```

    ```
    ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_CN_2006_v6",VPNNAME="VRF_PS_N4",AFTYPE=IPv6,IPALLOCTYPE6=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2006, BEGINADDR6="FC00::86:2", ENDADDR6="FC00::86:1E", MASKLEN=123;
    ```
11. 增加BFD会话自动部署模板。

    ```
    ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2006_v4", BFDTYPE=Static, SERVICENAME="ServName_CN_2006_v4", IPVERSION=IPv4, DESTADDR4="192.168.86.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
    ```

    ```
    ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2006_v6", BFDTYPE=Static, SERVICENAME="ServName_CN_2006_v6", IPVERSION=IPv6, DESTADDR6="FC00::86:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
    ```
12. 增加静态路由自动部署模板。

    //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

    ```
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v4", VRFNAME="VRF_PS_N4", IPVERSION=IPv4, PREFIX4="192.168.79.6", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.86.1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v4"; 
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v4", VRFNAME="VRF_PS_N4", IPVERSION=IPv4, PREFIX4="192.168.78.6", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.86.1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v4";
    ```

    //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

    ```
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v4", VRFNAME="VRF_PS_N4", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.86.1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v4";
    ```

    //“PREFIX6”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

    ```
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v6", VRFNAME="VRF_PS_N4", IPVERSION=IPv6, PREFIX6="FC00::79:6", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::86:1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v6"; 
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v6", VRFNAME="VRF_PS_N4", IPVERSION=IPv6, PREFIX6="FC00::78:6", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::86:1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v6";
    ```

    //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX6”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

    ```
    ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_CN_2006_v6", VRFNAME="VRF_PS_N4", IPVERSION=IPv6, PREFIX6="0:0:0:0:0:0:0:0", MASKLENGTH=0, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::86:1", BFDENABLE=TRUE, DESCRIPTION="VRF_PS_N4", BFDTEMPLATENAME="BFD_2006_v6";
    ```
