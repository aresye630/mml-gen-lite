## 操作场景

为避免单点故障造成业务中断，需部署两套UEG进行容灾。两套UEG间采用热备容灾模式时，需要参考本页面进行配置。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

* 已完成两套UEG初始配置与调测。
* 已完成UEG间容灾消息传输使用的外联口IP及路由数据
* 已完成加载License，热备容灾对应license为：82200FFV LKV3G5SLHB01 会话热备容灾会话数（如果有需求，请联系华为技术支持工程师处理）。

## 操作流程

## 操作步骤

1. 在主用UEG进行配置，进入“MML命令行-UEG”窗口。
2. 检查负荷分担容灾功能的使能开关是否为“NO”。

   ```
   LST DRCOUPLINGRESET:;
   ```

   * “COUPLINGRESET”值为“YES”时，请执行3。
   * “COUPLINGRESET”值为“NO”时，执行4。
3. 关闭负荷分担容灾功能开关。

   ```
   SET DRCOUPLINGRESET: COUPLINGRESET=NO;
   ```
4. 检查是否存在冗余的主备容灾模式的配置。
   1. 执行**LST DRGROUPINFO**命令，查询是否存在容灾组信息。
   2. 执行**LST DRDCI**命令，查询是否存在DCI通道信息。
   * 存在冗余的主备容灾模式的配置，请执行5。
   * 不存在冗余的主备容灾模式的配置，请执行9。
5. 删除主备容灾模式配置。
   1. 执行**RMV DRDCI**命令，删除DCI通道信息。
   2. 执行**RMV DRGROUPINFO**命令，删除容灾组信息。
6. 设置监控的关键部件信息。

   ```
   SET DRKEYNF: UPF=YES;
   ```
7. 设置容灾控制通道TLS模式。

   ```
   SET DRTLSMODE: TLSMODE=OFF;
   ```
8. 设置快速故障检测。

   ```
   SET FAULTCHECKBYFABRIC: ENABLE=ON, PROTECTDURATION=10, WAITRPTDURATION=3000;
   ```
9. 使能热备容灾组。

   ```
   SET DRGROUPABLEMENT:DRGROUPABLEMENT=ENABLE;
   ```
10. 增加VPN实例。

    ```
    ADD VPNINST: VPNINSTANCE="VPN_DCI";
    ```
11. 增加容灾组信息。

    ```
    ADD DRGROUPINFO: DRGROUPID=1, DRGROUPNAME="DRGROUP01", LDRINSTID=1, DFTMODE=ACTIVE, PDRINSTID=2, IPVERSION=IPV4, PGRCIP="10.10.1.2";
    ```
12. 设置容灾定时器。

    ```
    SET DRHBNEGOTIMER: DRGROUPID=1, HELLOINTERVAL=5, NEGOINTERVAL=10, TIMES=5, OMHBTIMES=5, OMHBINTERVAL=5;
    ```
13. 使能自动倒回功能。

    ```
    SET DRAUTOSWOVER: AUTOSWOVER=ENABLE;
    ```
14. 增加DC间通信通道信息。

    ```
    ADD DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.198.8", PDCIP="10.10.199.8", VPNINSTANCE="VPN_DCI", DATABKMODE=Active-Standby_Hot_Backup, HBINTERVAL=5,  HBTIMES=4;
    ```
15. 在备用UEG进行配置，进入“MML命令行-UEG”窗口。
16. 检查负荷分担容灾功能的使能开关是否为“NO”。

    ```
    LST DRCOUPLINGRESET:;
    ```

    * “COUPLINGRESET”值为“YES”时，请执行17。
    * “COUPLINGRESET”值为“NO”时，执行18。
17. 关闭负荷分担容灾功能开关。

    ```
    SET DRCOUPLINGRESET: COUPLINGRESET=NO;
    ```
18. 检查是否存在冗余的主备容灾模式的配置。
    1. 执行**LST DRDCI**命令，查询是否存在DCI通道信息。
    2. 执行**LST DRGROUPINFO**命令，查询是否存在容灾组信息。
    * 存在冗余的主备容灾模式的配置，请执行19。
    * 不存在冗余的主备容灾模式的配置，请执行22。
19. 删除主备容灾模式配置。
    1. 执行**RMV DRDCI**命令，删除DCI通道信息。
    2. 执行**RMV DRGROUPINFO**命令，删除容灾组信息。
20. 设置监控的关键部件信息。

    ```
    SET DRKEYNF: UPF=YES;
    ```
21. 设置快速故障检测。

    ```
    SET FAULTCHECKBYFABRIC: ENABLE=ON, PROTECTDURATION=10, WAITRPTDURATION=3000;
    ```
22. 使能热备容灾组。

    ```
    SET DRGROUPABLEMENT:DRGROUPABLEMENT=ENABLE;
    ```
23. 增加VPN实例。

    ```
    ADD VPNINST: VPNINSTANCE="VPN_DCI";
    ```
24. 增加容灾组信息。

    ```
    ADD DRGROUPINFO: DRGROUPID=1, DRGROUPNAME="DRGROUP01", LDRINSTID=2, DFTMODE=STANDBY, PDRINSTID=1, IPVERSION=IPV4, PGRCIP="10.10.1.1";
    ```
25. 设置容灾定时器。

    ```
    SET DRHBNEGOTIMER: DRGROUPID=1, HELLOINTERVAL=5, NEGOINTERVAL=10, TIMES=5, OMHBTIMES=5, OMHBINTERVAL=5;
    ```
26. 使能自动倒回功能。

    ```
    SET DRAUTOSWOVER: AUTOSWOVER=ENABLE;
    ```
27. 增加DC间通信通道信息。

    ```
    ADD DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.199.8", PDCIP="10.10.198.8", VPNINSTANCE="VPN_DCI", DATABKMODE=Active-Standby_Hot_Backup, HBINTERVAL=5, HBTIMES=4;
    ```

    备用UEG配置完成后会自动重启。重启后概率性出现“U2020到网元的配置同步失败”，请联系华为技术支持处理。
