# 配置SMF公共数据

## 操作场景

用于配置SMF与UPF对接的公共数据。

此配置页面中的命令仅在新建UPF时配置。

## 任务示例

任务描述

用于配置SMF与UPF对接的公共数据。

脚本

1. 配置用户面节点实例。配置Profile实例。

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf00.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080;
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.12", PORT=8080;
   ```
2. 配置用户面节点支持的切片与DNN信息。

   ```
   ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_0", SST=1, SD="000001";
   ADD PNFNS: INDEX=4, NFINSTANCEID="UPF_Instance_1", SST=1, SD="000001";
   ADD PNFDNN:INDEX=5, NFINSTANCEID="UPF_Instance_0", DNN="APN1", PNFNSINDEX=3;
   ADD PNFDNN:INDEX=6, NFINSTANCEID="UPF_Instance_1", DNN="APN1", PNFNSINDEX=4;
   ```
3. 配置用户面节点的位置特征和分流能力。

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_0", LOCATION=Central, SUPULCLBPONLY=Enable, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_CP";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", LOCATION=Central, SUPULCLBPONLY=Enable, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_CP";
   ```
4. 配置用户面节点的位置区信息，将位置区与TAI绑定。

   ```
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12301000001", N2ENDTAI="12301123456";
   ```
5. 配置用户面节点支持的为SMF提供服务区域的信息。

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA1";
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA1";
   ```
6. 配置用户面与EPS的互通以及支持的PDU会话类型。

   ```
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_1", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ```
7. （可选）配置UPF绑定到特定的IP Domain，仅当UPF间地址池重叠时需要配置。请确保 参数“DNN”已在**ADD APN**中定义。

   ```
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_0", IPDOMAIN="APP-HDNJIHzjSAEGWC1BHW-08AHW011.zj.jih.node.epc.mnc000.mcc460.3gppnetwork.org", DNNSWITCH=ENABLE,DNN=APN1;
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_1", IPDOMAIN="APP-HDNJIHzjSAEGWC1BHW-08AHW011.zj.jih.node.epc.mnc000.mcc460.3gppnetwork.org", DNNSWITCH=ENABLE,DNN=APN1;
   ```
