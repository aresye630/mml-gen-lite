## 操作场景

用户面业务通道保活是指，企业园区场景下，当园区gNodeB、UPF跟园区外部署的AMF、SMF失联时，即N2/N4接口不可用但N3接口可用时，弱移动性（不跨gNodeB切换）连接态用户的数传业务能够继续进行（惯性运行）。

适用于AMF。

## 必备事项

前提条件

* 请仔细阅读WSFD-217001 用户面业务通道保活特性概述。
* 完成加载License。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置DNN群组。

   **ADD DNNGRP**
3. 为DNN群组添加DNN成员。

   **ADD DNNGRPMEM**
4. 增加区域编码。

   **ADD AREACODE**
5. 为指定的区域增加跟踪区成员。

   **ADD AREAMEM**
6. **可选：**增加园区策略，设置园区惯性运行开关。

   **ADD NGPARKPLCY**

## 任务示例

任务描述

开启业务园区惯性运行开关，当N2和N4接口同时故障时，连接态用户惯性运行。

脚本

//配置惯性运行DNN和区域。

```
ADD DNNGRP: DNNGRPID="1";
ADD DNNGRPMEM: DNNGRPID="1", DNN="DNNa";
ADD AREACODE: AREACODE="1";
ADD AREAMEM: AREACODE="1", MCC="460", MNC="03", BGNTAC="120101", ENDTAC="999999";
```

//设置园区惯性运行开关。

```
ADD NGPARKPLCY: PARKID="park", AREACODE="huawei", DNNGRPID="BIG_GROUP", INERTIA=ON;
```
