# 配置静态地址路由冗余数据

## 操作场景

当终端地址采用静态签约方式时，网络中需部署冗余的主备两台UEG，并建立GRE Tunnel，确保网络正常运行，保证静态地址签约用户正常进行业务。配置举例如图1所示。

**图1** 静态地址路由冗余GRE数据规划图

## 必备事项

前提条件

主备UEG之间LoopBack接口的路由互通配置已完成。

数据

* 当存在多个专线时（多个DNN），重定向IP是共享的，全局唯一；内层隧道数据是与专线一一对应，有独立配置；外层loopback可以唯一，也可以与专线一一对应。
* 两个UPF间的GRE隧道需要配置专有子接口IP，此部分配置与专线的子接口配置过程相同，仅子接口名称、IP地址、VLAN ID和VRF不同。如果现网条件不允许，可以复用N6口子接口。

## 任务示例

任务描述

分别配置主备UPF，并配置GRE Tunnel，UE的IP地址采用静态签约，地址段分为IPv4和IPv6两类。

* 专线（仅连接，地市共享式）：支持风筝S
* 专网（仅连接，园区入驻式）：支持风筝S、风筝M、风筝L
* 云网（连接+计算，共享式+入驻式）：支持风筝S、风筝M

脚本

1. 配置主用UPF的静态地址用户路由冗余功能，静态地址段分为IPv4和IPv6两类。

   1. 修改静态地址池，打开地址池的冗余备份开关。

      //风筝S

      ```
      MOD POOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
      MOD POOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
      ```

      //风筝M或风筝L

      ```
      MOD UPPOOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
      MOD UPPOOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
      ```
   2. 配置冗余备份重定向IP。

      ```
      ADD REDUNDRDTIP: IPVERSION=IPv4, IPV4ADDRESS="192.168.0.1";
      ADD REDUNDRDTIP: IPVERSION=IPv6, IPV6ADDRESS="fc00:3::1";
      ```
   3. 配置LoopBack接口。

      ```
      ADD INTERFACE: IFNAME="LoopBack1", IFADMINSTATUS=up;
      ADD IPBINDVPN: IFNAME="LoopBack1", VRFNAME="VRF_N6_Local_2B";
      ADD IFIPV4ADDRESS: IFNAME="LoopBack1", IFIPADDR="10.11.1.1", SUBNETMASK="255.255.255.255";
      ```
   4. 配置GRE Tunnel。

      ```
      ADD INTERFACE: IFNAME="Tunnel1", IFMTU=1500;
      ADD GRETUNNEL: TNLNAME="Tunnel1", SRCTYPE=if_name, DSTIPADDR="10.10.0.1", TNLTYPE=gre, SRCIFNAME="LoopBack1", DSTVPNNAME="VRF_N6_Local_2B", GREKEYEN=TRUE, GREKEY="200", REDUNDANCYEN=TRUE, KEEPALVEN=TRUE;
      ADD IPBINDVPN: IFNAME="Tunnel1", VRFNAME="VRF_N6_Local_2B_001";
      ADD IFIPV4ADDRESS: IFNAME="Tunnel1", IFIPADDR="10.11.1.3", SUBNETMASK="255.255.255.0";
      SET IFIPV6ENABLE: IFNAME="Tunnel1", ENABLEFLAG=TRUE, MTU=1500;
      ADD IFIPV6ADDRESS: IFNAME="Tunnel1", IPV6ADDRESS="fc00:2::1", PREFIXLEN=64;
      ```
   5. 配置IPv4静态路由。

      ```
      ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.0.1", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel1";
      ```
   6. 配置IPv6静态路由。

      ```
      ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:3::1", MASKLENGTH=64, VRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel1";
      ```
   7. （可选）PGW-U/UPF与PDN/DN之间配置GRE隧道，并且由PDN/DN侧服务器端配置高低优先级路由。此场景下应在主UEG配置下行缺省低优先级静态地址用户网段路由入冗余GRE隧道。

      ```
      ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.1.1.0", MASKLENGTH=24, VRFNAME="vpn1", IFNAME="Tunnel1", BFDENABLE=FALSE, DHCPENABLE=FALSE;
      ```

      ```
      ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:1::1", MASKLENGTH=64, VRFNAME="vpn1", IFNAME="Tunnel1", BFDENABLE=FALSE, DHCPENABLE=FALSE;
      ```
   8. 使能静态地址用户路由冗余功能。

      ```
      SET REDUNDUSER: SWITCH=ENABLE;
      ```
2. 配置备用UPF的静态地址用户路由冗余功能。

   1. 配置地址池信息。
