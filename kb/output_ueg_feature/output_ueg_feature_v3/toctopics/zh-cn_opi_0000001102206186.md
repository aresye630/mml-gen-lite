## 任务示例

任务描述

配置用户的基础开户数据及业务数据。

脚本

1. 配置5G QoS模板。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=13, TPLNAME="5QI", NGQI=9, ARPPRILEVEL=14, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=TRUE, NGQIPRILEVEL=90;
   ```
2. 配置5G DNN QoS模板。

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=153, TPLNAME="8-0480-80-5", PDUTYPE=IPV4V6, ALLOWEDPDUTYPE=IPV4&IPV6, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2&SSC_MODE_3, NGCQOSTPLID=13, AMBRUP=60, UPUNIT=Mbps, AMBRDW=5, DWUNIT=Mbps, CHARGE="0480";
   ```
3. 配置加载终端鉴权秘钥。

   ```
   ADD KI: HLRSN=1,IMSI="460020000000001",OPERTYPE=ADD,KIVALUE="******",K4SNO=1,CARDTYPE=USIM,ALG=MILENAGE,OPSNO=1,AMFSNO=1;
   ```
4. 配置终端开户数据。

   ```
   ADD SUB: HLRSN=1, IMSI="460020000000001", ISDN="86106000001", CARDTYPE=USIM, NAM=BOTH, DEFAULTCALL=TS11, TS=TS11&TS21&TS22&TS61&TS62;
   ```
5. 配置AMF签约数据。

   ```
   MOD AMDATA: IMSI="460010000000001", PROV=TRUE, AUTHTYPE=5G-AKA;
   ```
6. 配置切片数据。

   ```
   ADD SNSSAI: IMSI="460010000000001", SNSSAI="1-131313", DEFAULT=TRUE;
   ```
7. 配置SMF签约数据。

   ```
   ADD SMDATA: IMSI="460010000000001",SNSSAI="1-131313",DNN="net",DEFAULT=TRUE,DNNQOSTPLID=153;
   ```
