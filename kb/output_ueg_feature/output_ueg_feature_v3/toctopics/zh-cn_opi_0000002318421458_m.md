# 配置静态地址用户路由冗余功能

## 操作场景

**对于风筝M/风筝L**：

两套UEG间采用负荷分担模式容灾场景，终端采用静态签约的IP时，需要在园区的两个UPF之间部署静态地址用户路由冗余功能，保证两个UPF都正常时，SGi/N6侧发布低优先级路由的UPF上激活的用户业务连续。

对于风筝M/风筝L，配置举例如图1所示。

**图1** 静态地址路由冗余GRE数据规划图

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
* VNF与网络实体之间的网络环境已经构建完成。

## 操作步骤

1. 配置主UPF到备UPF的IP路由数据。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Redundancy";
      ADD VPNINSTAF:VRFNAME="VRF_Redundancy", AFTYPE=ipv4uni, VRFRD="192.168.225.150:100";
      ```

      步骤1.b~步骤1.f是BGP相关数据，仅采用BGP over静态路由+BFD时需要配置。采用静态路由+BFD时不需要配置。
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack100";
      ADD IPBINDVPN:IFNAME="LoopBack100",VRFNAME="VRF_Redundancy";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack100",IFIPADDR="192.168.225.150",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Redundancy", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.150";
      ```
   4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Redundancy", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。此处以对接2个BGP对等体为例。

      ```
      ADD BGPPEER: VRFNAME="VRF_Redundancy", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.20", REMOTEAS="60002", LOCALIFADDR="192.168.225.150", LOCALIFNAME="Loopback100", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Redundancy", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.20", REMOTEAS="60002", LOCALIFADDR="192.168.225.150", LOCALIFNAME="Loopback100", EBGPMAXHOP=10;
      ```
   6. 配置BGP引入到10.11.1.1的IP路由，即对外发布到Tunnel隧道的源接口IP的路由。

      ```
      ADD NETWORKROUTE:VRFNAME="VRF_Redundancy",AFTYPE=ipv4uni,NETWORKADDRESS="10.11.1.1",MASKLEN=32;
      ```

      对于风筝L：N6外联口使用的是以太网子接口。
   7. 配置外联口IP地址。

      1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

         ```
         LST INTERFACE:;
         ```
      2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

         ```
         MOD INTERFACE:IFNAME="Ethernet64/0/6",IFADMINSTATUS=up;
         MOD INTERFACE:IFNAME="Ethernet64/0/9",IFADMINSTATUS=up;
         ```
      3. 添加以太网子接口。

         ```
         ADD INTERFACE:IFNAME="Ethernet64/0/6.2"; 
         ADD INTERFACE:IFNAME="Ethernet64/0/9.2";
         ```
      4. 增加接口绑定VPN。

         ```
         ADD IPBINDVPN:IFNAME="Ethernet64/0/6.2",VRFNAME="VRF_Redundancy";
         ADD IPBINDVPN:IFNAME="Ethernet64/0/9.2",VRFNAME="VRF_Redundancy";
         ```
      5. 在以太网子接口上关联VLAN ID。

         ```
         ADD ETHSUBIF:IFNAME="Ethernet64/0/6.2",VLANTYPEVID=2100;
         ADD ETHSUBIF:IFNAME="Ethernet64/0/9.2",VLANTYPEVID=2200;
         ```
      6. 配置外联口IP地址。

         ```
         ADD IFIPV4ADDRESS:IFNAME="Ethernet64/0/6.2",IFIPADDR="192.168.100.2",SUBNETMASK="255.255.255.248";
         ADD IFIPV4ADDRESS:IFNAME="Ethernet64/0/9.2",IFIPADDR="192.168.100.10",SUBNETMASK="255.255.255.248";
         ```
   8. 新建BFD会话。

      //配置双向BFD探测。

      ```
      ADD BFDSESSION: SESSNAME="BfdName1001_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.100.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_Redundancy",LOCALDISCR=10041,REMOTEDISCR=10042,IFNAME="Ethernet64/0/6.2";
      ADD BFDSESSION: SESSNAME="BfdName1002_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.100.9",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_Redundancy",LOCALDISCR=10043,REMOTEDISCR=10044,IFNAME="Ethernet64/0/9.2";
      ```

      //配置BFD单臂echo探测。

      ```
      ADD BFDSESSION: SESSNAME="BfdName1001_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.100.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_Redundancy",MINECHORXINT=500,LOCALDISCR=10041,IFNAME="Ethernet64/0/6.2";
      ADD BFDSESSION: SESSNAME="BfdName1002_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.100.9",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_Redundancy",MINECHORXINT=500,LOCALDISCR=10043,IFNAME="Ethernet64/0/9.2";
      ```
   9. 采用静态路由+BFD时，配置静态路由并绑定BFD会话。采用BGP over静态路由+BFD时，请跳过该步骤。

      * 直连PE时，根据PE能力选择使用“BGP over静态路由+BFD”或“静态路由+BFD”。
      * 直连DCGW时，推荐采用“BGP over静态路由+BFD”。

      //“PREFIX”/“MASKLENGTH”是Tunnel隧道对端的源接口IP地址，请根据网设文档替换。

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="10.10.0.1",MASKLENGTH=32,VRFNAME="VRF_Redundancy",DESTVRFNAME="VRF_Redundancy",IFNAME="Ethernet64/0/6.2",NEXTHOP="192.168.100.1",SESSIONNAME="BfdName1001_v4";
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="10.10.0.1",MASKLENGTH=32,VRFNAME="VRF_Redundancy",DESTVRFNAME="VRF_Redundancy",IFNAME="Ethernet64/0/9.2",NEXTHOP="192.168.100.9",SESSIONNAME="BfdName1002_v4";
      ```
   10. 采用BGP over静态路由+BFD时，配置静态路由并绑定BFD会话。采用静态路由+BFD时，请跳过该步骤。

       //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.20",MASKLENGTH=32,VRFNAME="VRF_Redundancy",DESTVRFNAME="VRF_Redundancy",IFNAME="Ethernet64/0/6.2",NEXTHOP="192.168.100.1",SESSIONNAME="BfdName1001_v4";
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.78.20",MASKLENGTH=32,VRFNAME="VRF_Redundancy",DESTVRFNAME="VRF_Redundancy",IFNAME="Ethernet64/0/9.2",NEXTHOP="192.168.100.9",SESSIONNAME="BfdName1002_v4";
       ```
   11. 配置Loopback接口IP。用作Tunnel隧道的源接口。

       ```
       ADD INTERFACE:IFNAME="LoopBack10";
       ADD IPBINDVPN:IFNAME="LoopBack10",VRFNAME="VRF_Redundancy";
       ADD IFIPV4ADDRESS:IFNAME="LoopBack10",IFIPADDR="10.11.1.1",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
       ```
2. 配置虚拟重定向IP。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD REDUNDRDTIP: IPVERSION=IPv4, IPV4ADDRESS="192.168.0.1";
   ```

   ```
   ADD REDUNDRDTIP: IPVERSION=IPv6, IPV6ADDRESS="fc00:3::1";
   ```
3. 配置GRE Tunnel。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD INTERFACE: IFNAME="Tunnel1", IFMTU=1500;
   ADD GRETUNNEL: TNLNAME="Tunnel1", SRCTYPE=if_name, DSTIPADDR="10.10.0.1", TNLTYPE=gre, SRCIFNAME="LoopBack10", DSTVPNNAME="VRF_Redundancy", GREKEYEN=TRUE, GREKEY="200", REDUNDANCYEN=TRUE, KEEPALVEN=TRUE;
   ```

   ```
   ADD IPBINDVPN: IFNAME="Tunnel1", VRFNAME="VRF_LocalDN";
   ADD IFIPV4ADDRESS: IFNAME="Tunnel1", IFIPADDR="10.11.1.3", SUBNETMASK="255.255.255.0";
   SET IFIPV6ENABLE: IFNAME="Tunnel1", ENABLEFLAG=TRUE, MTU=1500;
   ADD IFIPV6ADDRESS: IFNAME="Tunnel1", IPV6ADDRESS="fc00:2::1", PREFIXLEN=64;
   ```
4. 配置到虚拟重定向IP的路由。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.0.1", MASKLENGTH=32, VRFNAME="VRF_LocalDN", IFNAME="Tunnel1";
   ```

   ```
   ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:3::1", MASKLENGTH=128, VRFNAME="VRF_LocalDN", IFNAME="Tunnel1";
   ```
5. 使能静态地址用户路由冗余功能。主备UPF上均需要执行本步骤。

   ```
   SET REDUNDUSER: SWITCH=ENABLE;
   ```
6. 修改静态地址池，打开地址池的冗余备份开关。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   MOD UPPOOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
   ```

   ```
   MOD UPPOOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
   ```
7. 开启APN路由冗余上行报文隧道转发功能。仅在备用UEG配置，主UPF上不配置。

   ```
   SET APNREDUNDUPSW: APN="apn-op1", IPV4SWITCH=ENABLE, IPV6SWITCH=ENABLE;
   ```
8. 配置CU Full Mesh数据。在主备UPF上均需要执行本步骤。

   //打开本特性的License配置开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5CUFM01",SWITCH=ENABLE;
   ```

   //配置用户面支持分配F-TEID。

   ```
   SET CPTEIDUALLOC: SWITCH=DISABLE;
   ```
