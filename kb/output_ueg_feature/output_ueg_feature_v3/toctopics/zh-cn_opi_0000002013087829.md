# 激活RedCap终端标准接入（UPF）

## 操作场景

本操作用于指导网元激活RedCap终端标准接入（UPF）功能的操作过程。

适用于UPF。

## 对系统的影响

该操作对系统正常运行没有影响。

## 必备事项

前提条件

* 请仔细阅读WSFD-010110 支持RedCap接入特性概述及实现原理。
* 完成加载License（如果有需求，请联系华为技术支持工程师处理）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（LICITEM） | LKV3G5RED001 | 固定取值 | 打开本特性的License配置开关。 |
|  | 开关（SWITCH） | ENABLE | 固定取值 |  |

## 操作步骤

1. 打开本特性的License配置开关：

   **SET LICENSESWITCH**

## 任务示例

任务描述

配置UPF支持RedCap用户接入核心网。

脚本

```
SET LICENSESWITCH: LICITEM="LKV3G5RED001", SWITCH=ENABLE;
```
