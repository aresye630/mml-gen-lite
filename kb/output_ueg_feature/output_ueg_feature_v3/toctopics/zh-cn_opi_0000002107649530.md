# 查询5G LAN用户是否已在UDM上完成5G LAN组签约

## 操作场景

必须在UDM上先完成用户的5G LAN组签约，才支持本地调整该用户所属的5G LAN组。

本地调整5G LAN用户签约的5G LAN组ID前，可参考本页面查询5G LAN用户在UDM上是否已签约5G LAN组ID。

## 必备事项

前提条件

* 已获取登录PGW Web LMT界面的用户名和密码。
* 已获取登录PGW Web LMT界面的IP地址。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| 5G LAN用户信息 | IMSI号码（IMSI） | 46000876543210 | 终端自带 | 需要规划待查询的5G LAN用户的IMSI号码。 |
| 连续IMSI的CPE个数 | 用户个数（RECORDCOUNT） | 100 | 本端规划 | 需要查询连续IMSI号码的多个5G LAN用户时需要规划，系统将从已制定的IMSI号码开始查询。 |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**LST GROUPID**命令，查询5G LAN用户签约的5G LAN组ID。

   仅支持基于单个IMSI或基于单个MSISDN查询，选择一种方案查询即可。

   * 基于单个IMSI查询

     ```
     LST GROUPID: IMSI="46000876543210";
     ```

     //IMSI存在对应的“内部组ID（INGROUPID ）”参数值时，说明该5G LAN用户已在UDM上完成5G LAN组签约。否则，未在UDM上完成5G LAN组签约。

     ```
     ...
             IMSI = 46000876543210                           
                 ...                       
        INGROUPID = 1001-46008-01
                 ...
     ```
   * 基于单个MSISDN查询

     ```
     LST GROUPID: ISDN="8613912345678";
     ```

     //MSISDN存在对应的“内部组ID（INGROUPID ）”参数值时，说明该5G LAN用户已在UDM上完成5G LAN组签约。否则，未在UDM上完成5G LAN组签约。

     ```
     ...                                  
                 ...
             ISDN = 8613912345678                       
        INGROUPID = 1001-46008-01                       
                 ...
     ```

   5G LAN用户未在UDM上签约5G LAN组ID时，请先联系华为工程师进行开户。
