# 直连CE/PE

## 操作场景

开通到园区的业务时，UPF到园区采用VPN专线，直连PE，通过静态路由绑定静态BFD探测的方式进行组网连接。对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例，组网规划如图1所示。

* 此场景适用于**机架服务器-ARM**和**刀片式服务器2U-x86**。
* 当对接的网关设备（如FW）不支持BFD时，UEG与对端设备可通过OSPF动态路由进行组网连接。

## 任务示例

任务描述

* 开通到园区业务时，UPF到园区采用VPN专线，直连PE。
* UPF到PE采用静态路由+BFD组网。
* 对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001",VRFDESCRIPTION="N6";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni;
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni;
   ```
3. 配置主接口的管理状态为up。

   ```
   MOD INTERFACE: IFNAME="Ethernet64/0/6", IFADMINSTATUS=up;
   MOD INTERFACE: IFNAME="Ethernet64/0/7", IFADMINSTATUS=up;
   ```
4. 配置子接口。

   ```
   ADD INTERFACE: IFNAME="Ethernet64/0/6.1", IFDF=FALSE;
   ADD INTERFACE: IFNAME="Ethernet64/0/7.1", IFDF=FALSE;
   ```
5. 接口绑定VPN。

   ```
   ADD IPBINDVPN: IFNAME="Ethernet64/0/6.1", VRFNAME="VRF_N6_Local_2B_001";
   ADD IPBINDVPN: IFNAME="Ethernet64/0/7.1", VRFNAME="VRF_N6_Local_2B_001";
   ```
6. 在以太网子接口上关联VLAN ID。

   ```
   ADD ETHSUBIF: IFNAME="Ethernet64/0/6.1", SUBIFTYPE=VlanType, VLANTYPEVID=104;
   ADD ETHSUBIF: IFNAME="Ethernet64/0/7.1", SUBIFTYPE=VlanType, VLANTYPEVID=204;
   ```
7. 配置外联口IPv4地址。

   ```
   ADD IFIPV4ADDRESS: IFNAME="Ethernet64/0/6.1", IFIPADDR="192.168.85.2", SUBNETMASK="255.255.255.248", ADDRTYPE=main;
   ADD IFIPV4ADDRESS: IFNAME="Ethernet64/0/7.1", IFIPADDR="192.168.85.10", SUBNETMASK="255.255.255.248", ADDRTYPE=main;
   ```
8. 配置IPv6使能。

   ```
   SET IFIPV6ENABLE: IFNAME="Ethernet64/0/6.1", ENABLEFLAG=TRUE;
   SET IFIPV6ENABLE: IFNAME="Ethernet64/0/7.1", ENABLEFLAG=TRUE;
   ```
9. 配置外联口IPv6地址。

   ```
   ADD IFIPV6ADDRESS: IFNAME="Ethernet64/0/6.1", IPV6ADDRESS="FC00::40C2", PREFIXLEN=123, ADDRTYPE=global;
   ADD IFIPV6ADDRESS: IFNAME="Ethernet64/0/7.1", IPV6ADDRESS="FC00::40E2", PREFIXLEN=123, ADDRTYPE=global;
   ```
10. 新建静态BFD会话。

    ```
    ADD BFDSESSION: SESSNAME="N6if_1_1", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=FALSE, DESTADDR4="192.168.85.1", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=322, IFNAME="Ethernet64/0/6.1";
    ADD BFDSESSION: SESSNAME="N6if_1_2", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=FALSE, DESTADDR4="192.168.85.9", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=323, IFNAME="Ethernet64/0/7.1";
    ADD BFDSESSION: SESSNAME="N6if_IPv6_1", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=FALSE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=324, IFNAME="Ethernet64/0/6.1", DESTADDR6="FC00::40C1";
    ADD BFDSESSION: SESSNAME="N6if_IPv6_2", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=FALSE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=325, IFNAME="Ethernet64/0/7.1", DESTADDR6="FC00::40E1";
    ```
11. 配置静态路由数据。

    ```
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="0.0.0.0", MASKLENGTH=0, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Ethernet64/0/6.1", NEXTHOP="192.168.85.1", SESSIONNAME="N6if_1_1";
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="0.0.0.0", MASKLENGTH=0, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Ethernet64/0/7.1", NEXTHOP="192.168.85.9", SESSIONNAME="N6if_1_2";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="0:0:0:0:0:0:0:0", MASKLENGTH=0, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Ethernet64/0/6.1", NEXTHOP="FC00::40C1", SESSIONNAME="N6if_IPv6_1";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="0:0:0:0:0:0:0:0", MASKLENGTH=0, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Ethernet64/0/7.1", NEXTHOP="FC00::40E1", SESSIONNAME="N6if_IPv6_2";
    ```
