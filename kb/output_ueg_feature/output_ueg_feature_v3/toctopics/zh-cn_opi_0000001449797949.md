## 操作场景

去使能1+1主备容灾模式时（比如进行网元卸载、容灾模式改造等），需要参考本页面进行配置。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 将使能主备容灾功能的软参设置为不使能。

   ```
   SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=400, VALUE=VALUE_0, POSITION=1;
   ```

   ```
   SET SOFTPARAOFBIT: DT=DWORD_EX_B, PARANUM=61, VALUE=VALUE_0, POSITION=1;
   ```

   ```
   SET UPSOFTPARA: DT=BIT, BITNUM=3001, BITVALUE=0;
   ```
3. 删除容灾控制通道相关信息。

   //DC1：

   ```
   RMV DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.198.8", PDCIP="10.10.199.8", VPNINSTANCE="VPN_DCI";
   ```

   //DC2：

   ```
   RMV DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.199.8", PDCIP="10.10.199.8", VPNINSTANCE="VPN_DCI";
   ```
4. 删除容灾组信息。

   //DC1：

   ```
   RMV DRGROUPINFO: DRGROUPID=1;
   ```

   //DC2：

   ```
   RMV DRGROUPINFO: DRGROUPID=1;
   ```
5. 将监控的服务都设置为不监控。

   ```
   SET DRKEYNF: MME=NO, AMF=NO, HSS=NO, UDM=NO, SMF=NO, GWC=NO, PCF=NO, PCRF=NO, UPF=NO, UDR=NO;
   ```

## 验证方法

1. 检查使能主备容灾功能的软参配置是否正确。
   * 查询是否不使能网元内AMF服务主备容灾功能。

     执行**LST AMFSOFTPARAOFBIT**命令进行检查，如果使能，则重新执行2进行设置。
   * 查询是否不使能网元内MME服务主备容灾功能。

     执行**LST SOFTPARAOFBIT**命令进行检查，如果使能，则重新执行2进行设置。
   * 查询是否不使能网元内UPF服务主备容灾功能。

     执行**LST UPSOFTPARA**命令进行检查，如果使能，则重新执行2进行设置。
2. 执行对应的LST命令，检查是否存在主备容灾模式的配置。
   * 查询是否存在DCI通道信息。

     执行**LST DRDCI**命令进行检查，如果存在，则重新执行3进行设置。
   * 查询是否存在容灾组信息。

     执行**LST DRGROUPINFO**命令进行检查，如果存在，则重新执行4进行设置。
3. 执行对应的LST命令，检查配置是否与规划一致。
   * 检查监控的服务设置是否正确。

     执行**LST DRKEYNF**命令进行检查，如配置错误，则重新执行5进行设置。
