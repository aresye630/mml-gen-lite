# 配置HLB数字证书

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

HLB服务作为HTTPS服务端或客户端，当需要通过Https与SMF、AMF、NRF等NF对接时，需要加载HLB证书集。HLB服务使用到的华为证书详见表1。

**表1** HLB数字证书说明

| 数字证书 | 关联场景 | 证书类型 | 私钥文件 | 私钥密码 | 证书应用场景 |
| --- | --- | --- | --- | --- | --- |
| HLB服务端证书 | HLB 服务证书集  （UPCF\_HLB\_Lcert） | * 设备证书：HLBcert.pem * 根CA：Huawei\_Equipment\_Root\_CA.der * 二级CA：Huawei Cloud Core Network Product CA.cer | HLBcert.key | 联系华为技术支持。 | 用于通过Https访问HLB服务时需要一起加载。 |
| HLB客户端证书 |  |  |  |  |  |

* 华为证书获取路径：https://support.huawei.com/ >技术支持>产品支持>云核心网>Mobile Packet Core>5G Convergent Data>UPCF>UPCF。在“产品软件”界面选择对应的UPCF版本，“设备证书”、“私钥文件”和提供给对端设备的“CA证书”均存放在UPCF\_Cert\_Tools.zip里，UPCF\_Cert\_Tools.zip包含在UPCF\_2\*.\*\*\*.\*\*\*.\*\*\*\_Tools.zip当中。
* 华为证书仅用于测试环境，不能用于商用环境。商用环境请替换为商用证书，并通过OM Portal的证书管理功能删除华为证书。若客户将华为证书用于商用环境，则需承担相关安全风险和责任。为了提高系统安全性，需定期更新证书和密钥。
* 加载CA证书时，需要加载完整的CA证书链。
* 加载CRL文件时，需要加载完整的CA链签发的CRL文件，即CA证书链中每个CA证书签发的CRL文件都要加载。

#### 必备事项

**前提条件**

* 证书文件已经经过授权和认证。
* 若使用华为证书，证书密码已经通过华为技术工程师获取。
* 若使用运营商自身的证书，证书密码已经从运营商处获取。

**数据**

* 当需要上传、更新CA证书时，已获取根证书*如\*\*\*.der*。
* 当需要上传、更新设备证书时，已获取设备证书、私钥文件和私钥密码。例如：
  + 设备证书：*\*\*\*\*\*\*.pem*
  + 私钥文件：*\*\*\*.key*
  + 私钥密码：*\*\*\*\*\*\**

#### 操作步骤

* 在CSP界面配置新的数字证书后，对于服务端数字证书，需要重启对应的服务；对于客户端数字证书，需要重启对应的链路，新的证书才能生效。
* 重启操作属于产品慎用操作，如果操作不当，会引发业务中断等严重后果。请操作员在华为技术支持指导下谨慎操作。

配置HLB数字证书需加载证书集（包括设备证书和CA证书），将证书集关联到“HLB 服务证书集（UPCF\_HLB\_Lcert）”场景下。

1. 登录CSP Portal界面，选择**安全** > **证书管理** > **证书与证书集管理**，点击上传证书。
2. 选择“证书集”，加载HLB数字证书集，界面配置参数如表2所示。详细操作请参见证书与证书集管理。

   **表2** 配置证书集

   | 界面参数 | 取值示例 | 取值原则 |
   | --- | --- | --- |
   | 证书集 | HLB\_CertSet | 自行命名，保证系统内命名唯一即可。 |
   | 设备证书 | HLBcert.pem | 上传设备证书文件HLBcert.pem，解压UPCF\_Cert\_Tools.zip，在HLB文件夹下获取。 |
   | 私钥文件 | HLBcert.key | 上传私钥文件HLBcert，解压UPCF\_Cert\_Tools.zip，在HLB文件夹下获取。 |
   | 私钥密码 | *\*\*\*\*\*\** | 联系华为技术支持。 |
   | CA证书 | Huawei\_Equipment\_Root\_CA.der | 上传CA证书Huawei\_Equipment\_Root\_CA.der，解压UPCF\_Cert\_Tools.zip，在HLB文件夹下获取。 |

3. 上传证书完成后，选择证书应用场景关联，为证书场景“HLB 服务证书集（UPCF\_HLB\_Lcert）”关联刚加载的HLB证书集。详细的关联证书操作请参见证书应用场景关联。
4. 执行**ADD HLBTLSCFG**命令，增加TLS配置信息。

   ```
   ADD HLBTLSCFG: TLSCFGID=TLS配置ID, TLSCFGNAME="TLS配置名称", PROTOCOLVER=TLS1_2;
   ```
5. 执行**MOD HLBDEVADDR**命令，配置HLB数字证书。

   ```
   MOD HLBDEVADDR: DEVAID=设备地址标识, HTTPSFUNC=ON, CERTSCENE=UPCF_HLB_Lcert, TLSCFGID=TLS配置ID;
   ```
6. 仅当现网存在静态链路时，才需要执行本步骤，否则跳过本步骤。

   执行**ADD HLBPEER**命令，配置HLB数字证书。以“类型”为“SMF”举例：

   ```
   ADD HLBPEER: ID=索引, NAME="名称", TYPE=SMF, HTTPSFUNC=ON, CERTSCENE=UPCF_HLB_Lcert, TLSCFGID=TLS配置ID;
   ```
