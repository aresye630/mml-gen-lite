# 配置VPN专线对接数据（UEG虚机容器，NP卡直连CE/PE）

## 操作场景

本场景用于配置无线侧到UPF的VPN传输专线数据。其中，UPF采用NP卡直连CE/PE，CE/PE再与无线侧对接实现互通，组网如图1所示。

**图1** NP卡直连CE或PE

## 对系统的影响

无。

## 任务示例

任务描述

配置UPF到园区的VPN专线，UPF使用NP卡直连CE/PE。

* 专线（仅连接，地市共享式）：支持风筝S
* 专网（仅连接，园区入驻式）：支持风筝S、风筝M、风筝L
* 云网（连接+计算，共享式+入驻式）：支持风筝S、风筝M

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N3_Local_2B_001",VRFDESCRIPTION="N3";
   ADD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni;
   MOD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,VRFRD="172.20.9.4:100";
   ADD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni;
   MOD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni,VRFRD="172.20.9.4:100";
   ```
3. 配置主接口的管理状态为up。

   ```
   MOD INTERFACE: IFNAME="100GE65/0/9", IFADMINSTATUS=up;
   MOD INTERFACE: IFNAME="100GE66/0/9", IFADMINSTATUS=up;
   ```
4. 配置子接口。

   ```
   ADD INTERFACE: IFNAME="100GE65/0/9.2003", IFDF=FALSE;
   ADD INTERFACE: IFNAME="100GE66/0/9.2003", IFDF=FALSE;
   ```
5. 接口绑定VPN。

   ```
   ADD IPBINDVPN: IFNAME="100GE65/0/9.2003", VRFNAME="VRF_N3_Local_2B_001";
   ADD IPBINDVPN: IFNAME="100GE66/0/9.2003", VRFNAME="VRF_N3_Local_2B_001";
   ```
6. 在以太网子接口上关联VLAN ID。

   ```
   ADD ETHSUBIF: IFNAME="100GE65/0/9.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ADD ETHSUBIF: IFNAME="100GE66/0/9.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ```
7. 配置外联口IPv4地址。

   ```
   ADD IFIPV4ADDRESS: IFNAME="100GE65/0/9.2003", IFIPADDR="192.168.246.130", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ADD IFIPV4ADDRESS: IFNAME="100GE66/0/9.2003", IFIPADDR="192.168.246.131", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ```
8. 配置IPv6使能。

   ```
   SET IFIPV6ENABLE: IFNAME="100GE65/0/9.2003", ENABLEFLAG=TRUE;
   SET IFIPV6ENABLE: IFNAME="100GE66/0/9.2003", ENABLEFLAG=TRUE;
   ```
9. 配置外联口IPv6地址。

   ```
   ADD IFIPV6ADDRESS: IFNAME="100GE65/0/9.2003", IPV6ADDRESS="fc00:8028:5000:43::9542", PREFIXLEN=123, ADDRTYPE=global;
   ADD IFIPV6ADDRESS: IFNAME="100GE66/0/9.2003", IPV6ADDRESS="fc00:8028:5000:43::9543", PREFIXLEN=123, ADDRTYPE=global;
   ```
10. 创建OSPF/OSPFv3进程。

    ```
    ADD OSPF:PROCID=2,VRFNAME="VRF_N3_Internet_2B",SCHEMAROUID="172.20.7.2",BFDALLINTFFLG=TRUE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
    ADD OSPFV3:PROCID=2,VRFNAME="VRF_N3_Internet_2B",ROUTERID="172.20.7.2",BFDALLINTFFLG=TRUE,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
    ```
11. 增加OSPF/OSPFv3区域。

    ```
    ADD OSPFAREA:PROCID=2,AREAID="0.0.0.5", AREATYPE=Normal, MAXCOSTFLAG=FALSE;
    ADD OSPFV3AREA:PROCID=2,AREAID="0.0.0.5", AREATYPE=Normal;
    ```
12. 创建OSPF/OSPFv3接口配置。

    ```
    ADD OSPFINTERFACE: PROCID=2, AREAID="0.0.0.5", IFNAME="100GE65/0/9.2003", DRPRI=0, NETWORKTYPE=p2p, P2MPMASKIGN=FALSE, SMARTDISCOVER=FALSE, BFDENABLE=FALSE,FRRBINDINGFLAG=FALSE, FRRBLOCKFLAG=FALSE, BFDBLOCK=FALSE, SUPPEREACH=Not-Configured, MTUENABLE=FALSE, MPLSLDPAUTOCFG=None, LDPSYNCENABLE=FALSE, LDPSYNCBLOCK=FALSE, VIRTUALSYSFLAG=FALSE, MAXCOSTFLAG=FALSE;
    ADD OSPFINTERFACE: PROCID=2, AREAID="0.0.0.5", IFNAME="00GE66/0/9.2003", DRPRI=0, NETWORKTYPE=p2p, P2MPMASKIGN=FALSE, SMARTDISCOVER=FALSE, BFDENABLE=FALSE, FRRBINDINGFLAG=FALSE, FRRBLOCKFLAG=FALSE, BFDBLOCK=FALSE, SUPPEREACH=Not-Configured, MTUENABLE=FALSE, MPLSLDPAUTOCFG=None, LDPSYNCENABLE=FALSE, LDPSYNCBLOCK=FALSE, VIRTUALSYSFLAG=FALSE, MAXCOSTFLAG=FALSE;
    ADD OSPFV3INTERFACE: PROCID=2, AREAID="0.0.0.5", IFNAME="100GE65/0/9.2003", MTUENABLE=TRUE, NETWORKTYPE=POINT-TO-POINT, BFDENABLE=FALSE, FRRBINDINGFLAG=FALSE, FRRBLOCKFLAG=FALSE, BFDBLOCK=FALSE, DRPRI=0, VIRTUALSYSFLAG=FALSE;
    ADD OSPFV3INTERFACE: PROCID=2, AREAID="0.0.0.5", IFNAME="100GE66/0/9.2003", MTUENABLE=TRUE, NETWORKTYPE=POINT-TO-POINT, BFDENABLE=FALSE, FRRBINDINGFLAG=FALSE, FRRBLOCKFLAG=FALSE, BFDBLOCK=FALSE, DRPRI=0, VIRTUALSYSFLAG=FALSE;
    ```
13. 配置OSPF network。

    ```
    ADD OSPFNETWORK:PROCID=2,AREAID="0.0.0.5",IPADDRESS="192.168.246.128",WILDCARDMASK="0.0.0.31";
    ```
14. 设置OSPF/OSPFv3引入路由类型。

    ```
    ADD OSPFIMPORTROUTE:PROCID=2,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
    ADD OSPFV3IMPORTROUTE:PROCID=2,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
    ```
15. 配置VPN实例。

    //风筝S

    ```
    ADD VPNINST: VPNINSTANCE="VRF_N3_Local_2B_001";
    ```

    //风筝M或风筝L

    ```
    ADD CPVPNINST: VPNINSTANCE="VRF_N3_Local_2B_001";
    ```
16. 配置UPF锁定状态。

    ```
    LCK NF: LOCKSWITCH=ENABLE;
    ```

    该命令属于高危命令，会改变UPF的锁定状态。如果配置为锁定，会导致用户接入失败，需要配置切片和N3接口绑定后，立即解锁。
17. 配置N3接口。

    //风筝S

    ```
    ADD LOGICINF: NAME="N3IF1/1/1", IPVERSION=IPV4, IPV4ADDRESS1="10.178.61.7", IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_N3_Local_2B_001";
    ```

    //风筝M或风筝L

    ```
    ADD CPLOGICINF: NAME="N3IF1/1/1", IPVERSION=IPV4, IPV4ADDRESS1="10.178.61.7", IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_N3_Local_2B_001";
    ```
