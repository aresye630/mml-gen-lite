# 配置UPF到MPF的GRE专线相关数据

## 操作场景

跨级容灾场景下，当园区部署MPF，地市无MPF时，需配置地市UPF的Nxuc接口与园区MPF通过VXLAN（VXLAN-GPE）隧道互通，组网规划如图1所示。

若此场景下，地市到园区采用GRE专线方式，则会存在VXLAN over GRE（GRE专线中有VXLAN隧道）以及MP2 over GRE的情况，需要将内层VXLAN隧道的报文/MP2报文路由到外层的GRE隧道中，如图2所示。

## 必备事项

前提条件

* 此场景的配置是在UPF/MPF初始配置（包括MP2逻辑接口相关配置）之后，增加的容灾相关配置，因此，需确保UPF、MPF均已完成初始配置。
* 两个MEC之间的路由互通配置已完成。

数据

在UPF上配置Nxuc逻辑接口数据（表1）、配置VXLAN隧道数据（表2），为UPF与MPF之间的数据路径建立逻辑连接。

**表1** Nxuc逻辑接口数据（UPF2配置）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD VPNINST** | VPN实例名（VPNINSTANCE） | VPN\_Nxuc | 本端规划 | 逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。 |
| **ADD LOGICINF** | 逻辑接口名称（NAME） | Nxucif1/1/0 | 本端规划 | 一个VNF上最多可以配置31个Nxuc接口，最后一个数字取值范围是0～31。 |
|  | 逻辑接口的IP版本（IPVERSION） | IPv4 | - | 如果规划逻辑接口使用IPv4v6双栈组网，则该参数取值为“IPVER\_ALL”，分别配置IPv4和IPv6地址。 |
|  | 逻辑接口的IPv4地址1（IPV4ADDRESS1） | 10.1.9.1 | 全网规划 |  |
|  | 逻辑接口的IPv4掩码1（IPV4MASK1） | 255.255.255.255 | 固定取值 |  |
|  | VPN实例名称（VPNINSTANCE） | VPN\_Nxuc | 已配置数据中获取 | - |

**表2** VXLAN隧道数据（UPF2配置）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD VXLANGRP** | Vxlan隧道组名称（GRPNAME） | vxlan\_grp01 | 本端规划 | Vxlan链路组名称，网元内不能重复。 |
|  | 隧道源接口（SRCINTF） | Nxucif1/1/0 | 已配置数据中获取 | UPF与MPF互通场景，此处使用的是UPF上Nxuc接口。 |
|  | 健康检查标记（HEARTBEAT） | ENABLE | 本端规划 | 使能心跳检查功能。 |
|  | 时间阈值（秒）（TIMETHRESHOLD） | 6 | 本端规划 | 两次心跳检测间的时间阈值。 |
|  | 心跳检查成功次数（HEARTSUCCLIMIT） | 3 | 本端规划 | 设置隧道状态为up所需的心跳检测连续成功次数。 |
|  | 心跳检查失败次数（HEARTFAILLIMIT） | 3 | 本端规划 | 设置隧道状态为down所需的心跳检测连续失败次数。 |
|  | Ping探测超时时长（秒）（TIMEOUT） | 2 | 本端规划 | 设置心跳检测的超时时长，该值需要小于TimeThreshold。 |
| **ADD VTEP** | Vxlan隧道端点名称（VTEPNAME） | VTEP1 | 本端规划 | 设置UPF到MPF的Vxlan隧道名称，网元内不能重复。 |
|  | IP协议版本（IPVERSION） | IPV4 | 全网规划 | UPF与MPF互通场景，此处使用的是MPF上Nxua逻辑接口的IP地址。 |
|  | 隧道端点的IPv4地址（VTEPIPV4） | 10.10.100.1 | 与对端协商 |  |
| **ADD VTEPBINDGRP** | Vxlan组名称（VXLANGRPNAME） | vxlan\_grp01 | 本端规划 | VTEP绑定Vxlan隧道组，并指定隧道主备类型。 |
|  | VTEP名称（VTEPNAME） | VTEP1 | 已配置数据中获取 |  |
|  | 主备用类型（PRIFLAG） | PRIMARY | 本端规划 |  |
| **ADD VXLANBINDAPN** | APN（APN） | apn1 | 已配置数据中获取 | 基于APN绑定一个链路组。UPF和MPF互通场景，链路组对端地址配置为MPF的Nxua接口地址，将命中Rule的报文发送到MPF的Nxua接口。 |
|  | Vxlan组名称（VXLANGRPNAME） | vxlan\_grp01 | 已配置数据中获取 |  |
| **ADD VPNVNIMAP** | VPN实例（VPNINSTANCE） | VRF\_N6\_Local\_2B\_001 | 已配置数据中获取 | 与APN绑定的VPN实例相同。 |
|  | Rule开关（RULESWITCH） | DISABLE | 本端规划 | 此处以基于用户VPN映射到VNI为例。 |
|  | VNI（VNI） | 1 | 本端规划 | 配置VxLan隧道标识。  Vxlan隧道当前不支持配置隧道端口号，端口号统一固定使用默认端口号4790。 |

|  | VPN实例名称（VRFNAME） | VPN\_Nxuc | 从已配置数据中获取 | - |
|  | 下一跳VPN名字（DESTVRFNAME） | VPN\_Nxuc | 从已配置数据中获取 | - |

## 任务示例

任务描述

跨级容灾场景下，UPF1和UPF2对接MPF，地市到园区采用GRE专线方式，UPF2上需配置VXLAN over GRE和MP2 over GRE，将内层VXLAN隧道的报文/MP2的报文路由到外层的GRE隧道中。

**图3** 组网图

脚本

* VXLAN隧道相关配置，两个UPF上的配置仅Nxuc的逻辑接口IP地址不同，其他配置取值无差别，所以仅以UPF1上配置举例。
* MPF上VXLAN over GRE的相关配置，与UPF2上的配置原理和逻辑相同，仅需将IP地址和路由做本端和对端的互换。

1. 配置Nxuc逻辑接口所属的VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE ="VPN_Nx";
   ```
2. 配置Nxuc逻辑接口。

   ```
   ADD LOGICINF:NAME="Nxucif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.8.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VPN_Nx";
   ```
3. 配置VXLAN隧道组。

   ```
   ADD VXLANGRP: GRPNAME="vxlan_grp01", SRCINTF="Nxucif1/1/0", HEARTBEAT=ENABLE, TIMETHRESHOLD=6, HEARTSUCCLIMIT=3, HEARTFAILLIMIT=3, TIMEOUT=2;
   ```
4. 配置到MPF的VXLAN隧道端点（VTEP）。

   ```
   ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.10.100.1";
   ```
5. 配置VXLAN端点绑定VXLAN隧道组。

   ```
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_grp01", VTEPNAME="VTEP1", PRIFLAG=PRIMARY;
   ```
6. 配置VXLAN隧道组绑定APN。

   ```
   ADD VXLANBINDAPN: APN="apn1", VXLANGRPNAME="vxlan_grp01";
   ```
7. 配置VPN到VNI的映射。

   ```
   ADD VPNVNIMAP: VPNINSTANCE="VRF_N6_Local_2B_001", RULESWITCH=DISABLE, VNI=1;
   ```
8. 配置UPF2上的VXLAN over GRE路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.10.100.1", MASKLENGTH=32, VRFNAME="VPN_Nxuc" ,DESTVRFNAME="VPN_Nxuc", IFNAME="Tunnel12";
   ```
9. 配置UPF2上的MP2 over GRE路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.1.17.1", MASKLENGTH=32, VRFNAME="VPN_mp2" ,DESTVRFNAME="VPN_mp2", IFNAME="Tunnel15";
   ```
