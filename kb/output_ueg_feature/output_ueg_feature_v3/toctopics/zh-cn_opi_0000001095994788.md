## 必备事项

前提条件

* UPF侧已完成N6口的路由相关配置，可参考“配置独立VPN专线”章节配置。
* UEG与企业侧路由器之间的路由互通配置已完成。

## 任务示例

任务描述

配置UPF到园区的GRE专线，地址池双栈。

脚本

1. 配置VPN信息。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B",VRFDESCRIPTION="loopback_vpn";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B",AFTYPE=ipv4uni;
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B",AFTYPE=ipv6uni;
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001",VRFDESCRIPTION="for_tunnel12_vpn";
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,VRFRD="172.16.255.1:101";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,VRFRD="172.16.255.1:101";
   SET BGP:ASNUM="100", BGPENABLE=TRUE;
   ADD BGPVRF: VRFNAME="VRF_N6_Local_2B", DEFAULTAFTYPE=ipv4uni, VRFRIDAUTOSEL=FALSE;
   ```
2. 配置LoopBack接口。

   ```
   ADD INTERFACE: IFNAME="LoopBack212", IFADMINSTATUS=up;
   ADD IPBINDVPN: IFNAME="LoopBack212", VRFNAME="VRF_N6_Local_2B";
   ADD IFIPV4ADDRESS: IFNAME="LoopBack212", IFIPADDR="10.12.255.12", SUBNETMASK="255.255.255.255";
   ```
3. 配置GRE Tunnel。

   ```
   ADD INTERFACE: IFNAME="Tunnel12", IFMTU=1500;
   ADD GRETUNNEL: TNLNAME="Tunnel12", SRCTYPE=if_name, DSTIPADDR="10.13.255.12", TNLTYPE=gre, SRCIFNAME="LoopBack212", DSTVPNNAME="VRF_N6_Local_2B", KEEPALVEN=TRUE;
   ADD IPBINDVPN: IFNAME="Tunnel12", VRFNAME="VRF_N6_Local_2B_001";
   ADD IFIPV4ADDRESS: IFNAME="Tunnel12", IFIPADDR="172.16.255.1", SUBNETMASK="255.255.255.255";
   SET IFIPV6ENABLE: IFNAME="Tunnel12", ENABLEFLAG=TRUE, MTU=1500;
   ADD IFIPV6ADDRESS: IFNAME="Tunnel12", IPV6ADDRESS="fc00:12:255::1", PREFIXLEN=128;
   ```
4. 配置隧道间静态路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="172.16.255.2", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001" ,DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel12";
   ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:12:255::2", MASKLENGTH=128, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel12";
   ```
5. 配置到对端网关静态路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.0.0.172", MASKLENGTH=24, VRFNAME="VRF_N6_Local_2B_001" ,DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel12";
   ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:12:12::12", MASKLENGTH=56, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel12";
   ```
6. 配置发布LoopBack路由。

   ```
   ADD NETWORKROUTE: VRFNAME="VRF_N6_Local_2B", AFTYPE=ipv4uni, NETWORKADDRESS="10.12.255.12", MASKLEN=32;
   ```
