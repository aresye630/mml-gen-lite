# 标卡+DCGW

## 操作场景

新增企业，开通业务时，UPF到园区采用VPN专线，UPF使用标卡，对接DCGW（路由器）或DCGW（交换机），组网规划如图1和图2所示。

对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例。

**图2** 标卡+DCGW（交换机）规划示意图

## 任务示例

任务描述

* 新增企业，开通业务时，UPF到园区采用VPN专线，UPF使用标卡，对接DCGW。
* UPF到DCGW为eBGP+BFD组网：eBGP绑定BFD会话，BFD检测时间配置为500ms\*4。
* 对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

   ```
   SET AUTOCONFIG:SWITCHFLAG=FALSE;
   ```
3. 配置bond组网以太Trunk。

   ```
   ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=6, VNICLIST="6 7";
   ```
4. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001",VRFDESCRIPTION="N6";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni;
   MOD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,VRFRD="172.20.9.4:100";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni;
   MOD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,VRFRD="172.20.9.4:100";
   ```
5. 增加自动配置服务。

   ```
   ADD AUTOSCALINGSERVICE:SERVICENAME="VRF_N6_Local_2B_001_2005",VPNNAME="VRF_N6_Local_2B_001",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID =6,VLANID=915, BEGINADDR4="192.168.246.130",ENDADDR4="192.168.246.158", MASKLEN=27;
   ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_N6_Local_2B_001_2005_IPv6", VPNNAME="VRF_N6_Local_2B_001", AFTYPE=IPv6, IPALLOCTYPE6=USER_CONFIG, AUTOCFGIFTYPE=ETHTRUNK, ETHTRUNKTMPID=6, VLANID=917, BEGINADDR6="fc00:8028:5000:43:0:0:0:9542", ENDADDR6="fc00:8028:5000:43:0:0:0:955E", MASKLEN=123, OSPFENABLE=FALSE, TPINENABLE=FALSE, TPOUTENABLE=FALSE, OSPFGRPENABLE=FALSE;
   ```
6. 配置动态BFD自动化配置模板。

   ```
   ADD AUTOSCALINGBFD: TEMPLATENAME="N6_BFD_1", BFDTYPE=Static, SERVICENAME="VRF_N6_Local_2B_2005", IPVERSION=IPv4, DESTADDR4="192.168.11.11", MINECHORXINT=500, DETECTMULTI=4;
   ADD AUTOSCALINGBFD: TEMPLATENAME="N6_BFD_2", BFDTYPE=Static, SERVICENAME="VRF_N6_Local_2B_2005_IPv6", IPVERSION=IPv6, DESTADDR6="fc00:187:C28C:0:0:0:0:1", MINECHORXINT=500, DETECTMULTI=4;
   ```
7. 配置静态路由自动化配置模板。

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="VRF_N6_Local_2B_001_2005", VRFNAME="VRF_N6_Local_2B_001", IPVERSION=IPv4, PREFIX4="192.168.11.1", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.11.11", BFDENABLE=TRUE, BFDTEMPLATENAME="N6_BFD_1";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="VRF_N6_Local_2B_001_2005", VRFNAME="VRF_N6_Local_2B_001", IPVERSION=IPv4, PREFIX4="192.168.11.2", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.11.11", BFDENABLE=TRUE, BFDTEMPLATENAME="N6_BFD_1";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="VRF_N6_Local_2B_001_2005_IPv6", VRFNAME="VRF_N6_Local_2B_001", IPVERSION=IPv6, PREFIX6="fc00:187:C289::1", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="fc00:187:C28C::1", BFDENABLE=TRUE, BFDTEMPLATENAME="N6_BFD_2";
   ADD AUTOSCALINGSRROUTE: SERVICENAME="VRF_N6_Local_2B_001_2005_IPv6", VRFNAME="VRF_N6_Local_2B_001", IPVERSION=IPv6, PREFIX6="fc00:187:C289::2", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="fc00:187:C28C::1", BFDENABLE=TRUE, BFDTEMPLATENAME="N6_BFD_2";
   ```
8. 打开自动化配置服务。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```
9. 添加loopback接口。

   ```
   ADD INTERFACE:IFNAME="LoopBack14",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
   ADD IPBINDVPN:IFNAME="LoopBack14",VRFNAME="VRF_N6_Local_2B_001";
   ADD IFIPV4ADDRESS:IFNAME="LoopBack14",IFIPADDR="172.20.9.7",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
   ADD INTERFACE:IFNAME="LoopBack13",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
   ADD IPBINDVPN:IFNAME="LoopBack13",VRFNAME="VRF_N6_Local_2B_001";
   SET IFIPV6ENABLE:IFNAME="Loopback13",ENABLEFLAG=TRUE;
   ADD IFIPV6ADDRESS:IFNAME="Loopback13",IPV6ADDRESS="fc00:187:C281::1",PREFIXLEN=128;
   ```
10. 设置BGP。

    ```
    SET BGP: BGPENABLE=TRUE, ASNUM="64986";
    ```
11. 添加BGP VPN。

    ```
    ADD BGPVRF:VRFNAME="VRF_N6_Local_2B_001",DEFAULTAFTYPE=noaf,ROUTERID="172.20.7.2";
    ```
12. 增加BGP VPN地址族。

    ```
    ADD BGPVRFAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,MAXLOADEBGPNUM=2;
    ADD BGPVRFAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,MAXLOADEBGPNUM=2;
    ```
13. （负荷分担UPF场景下）增加指定协议中的入口路由配置。

    ```
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,IMPORTPROTOCOL=wlr;
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,IMPORTPROTOCOL=wlr;
    ```
14. （GRE路由冗余隧道场景下）增加指定协议中的入口路由配置。

    ```
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,IMPORTPROTOCOL=wlr,MEDENABLE=TRUE,MED=0;
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,IMPORTPROTOCOL=wlr,MEDENABLE=TRUE,MED=0;
    ```
15. 增加BGP对等体。

    ```
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.1", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.2", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::1", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::2", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ```
16. 增加BGP对等体地址族。

    ```
    MOD BGPPEERAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,REMOTEADDRESS="192.168.11.1";
    MOD BGPPEERAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,REMOTEADDRESS="192.168.11.2";
    MOD BGPPEERAF: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="fc00:187:C289:0:0:0:0:1";
    MOD BGPPEERAF: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="fc00:187:C289:0:0:0:0:2";
    ```
