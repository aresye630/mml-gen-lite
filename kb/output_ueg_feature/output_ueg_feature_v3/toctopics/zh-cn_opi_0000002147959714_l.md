# 配置4G业务的用户迁回

## 操作场景

子园区UEG-L故障恢复后必须要尽快在总部园区UEG-L上将故障期间激活的用户回迁至子园区UEG-L，本章节介绍4G用户的迁回操作。

* 本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。
* 如果多个子园区UEG-L同时故障，由于接入总部园区UEG-L的用户容量受限，因此可能导致故障子园区的新用户接入总部园区UEG-L失败。
* 如果多个子园区UEG-L同时故障，建议子园区UEG-L均恢复后，再进行用户迁回操作。
* 在总部园区UEG-L上将在线用户去激活后，用户业务发生中断，业务重新在子园区UEG-L上恢复的时间取决于终端业务行为。

## 必备事项

前提条件

两套UEG-L已完成跨级容灾模式配置。

数据

**假设需要将在总部园区激活的子园区A用户从总部园区UEG-L1迁回到子园区A的UEG-L2****，****如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例  （UEG-L1） | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****SET OFFLOADINF**** | 第一阶段迁移时间（FIRSTTM） | 0 | 全网规划 | 第一阶段迁移时间需要配置为0。 |
| ****SET CPSYS**** | 设备能力（CAP） | 0 | 本端规划 | 当UEG支持MME POOL时，在启动迁移任务时，需将此参数设置为0，避免新用户接入。设备能力值越低，用户接入优先级越低 |
| ****STR OFFLOADBYEDGEMME**** | 迁移比率（OFFLOADRATE） | 100 | 本端规划 | 根据实际情况进行配置，两套UEG上需达到负载均衡。 |
|  | 目标MME编码（MMEC） | 子园区MME编码 | 已配置数据中获取 | UEG1中的MME编码，可通过****LST MMEID****查询。 |
| ****SET CPSYS**** | 设备能力（CAP） | 255 | 本端规划 | 当迁移任务结束后，需要恢复MME原设备能力。 |

## 操作步骤

1. 进入子园区的UEG-L“MML命令行-UEG”窗口。
2. 执行**LST MMEID**查询“MME编码（起始值）”值。
3. 进入总部园区的UEG-L“MML命令行-UEG”窗口。
4. 设置迁移配置信息。

   ```
   SET OFFLOADINF: FIRSTTM=0;
   ```
5. 修改MME的设备能力为0。

   ```
   SET CPSYS: CAP=0;
   ```
6. 下发启动迁移命令，向子园区MME迁移100%用户，其中MMEC为2查询的“MME编码（起始值）”值。

   ```
   STR OFFLOADBYEDGEMME: OFFLOADRATE=100, MMEC="子园区MME编码";
   ```

   如果想停止用户迁移，可通过**STP OFFLOAD**命令主动停止当前正在进行的迁移任务。
7. 执行以下命令查询用户迁移的进度信息，每隔30s执行一次，确保“迁移状态”为“结束完成”，并且“需要卸载用户数”为0。

   ```
   DSP OFFLOAD:;
   ```
8. 执行以下命令查询网元的承载上下文，确保“GTPv2承载上下文总数”为0。

   ```
   DSP SMPDPNUM:;
   ```
9. 恢复迁移的MME原设备能力。

   ```
   SET CPSYS: CAP=255;
   ```
