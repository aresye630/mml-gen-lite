# 配置PCF与AF（基于Diameter协议）的对接数据

## 操作场景

当PCF接纳应用层业务请求时，例如应用服务器发起的带宽资源预留请求，PCF需要对接AF（Application Function）实体，以实现应用侧发起的策略控制功能。

* 园区PCF支持语音业务，且PCF与P-CSCF（SBC）之间通过Rx接口对接时，请参考本页面进行配置。
* 园区PCF支持PTT业务，且PCF与PTT Server之间通过Rx接口对接时，请参考本页面进行配置。

## 必备事项

前提条件

本端及AF侧已完成基础数据配置。

数据

表1中，是与AF对接的本端IP，如已完成配置PCF基础数据中的和AF（基于Diameter协议）互通的Diameter信令IP数据， 则不需要重复规划。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 配置Diameter信令IP，用于和AF（基于Diameter协议）通信。如已完成配置PCF基础数据中的和AF（基于Diameter协议）互通的Diameter信令IP数据， 则不需要重复配置。

   //DC1：

   ```
   ADD DLBVPN: VPNINDEX=4, VPNNAME="VRF_AF";
   ADD DLBDEVADDR: DEVAID=4, VPNINDEX=4, IPVER=IPV4, IP="172.21.100.2";
   ADD DLBDEVADDR: DEVAID=5, VPNINDEX=4, IPVER=IPV4, IP="172.21.100.3";
   ```

   //DC2：

   ```
   ADD DLBVPN: VPNINDEX=4, VPNNAME="VRF_AF";
   ADD DLBDEVADDR: DEVAID=4, VPNINDEX=4, IPVER=IPV4, IP="172.21.100.102";
   ADD DLBDEVADDR: DEVAID=5, VPNINDEX=4, IPVER=IPV4, IP="172.21.100.103";
   ```
3. 默认的能力字典不满足要求时，配置对端AF能力字典。

   ```
   ADD AFABIDICT: ABILITYDICTID=88, ABILITYDICTNAME="AF00";
   ```

   * 规划关闭SCTP双归属时，执行4和5。

     如下以容灾的两个AF对外提供的业务数据不同为例。
   * 规划开启SCTP双归属时，请执行6和7。

     如下以容灾的两个AF对外提供的业务数据不同为例。
4. 增加对端AF实体。关闭SCTP双归属时需要执行本步骤。

   ```
   //af0
   ADD PAF: PCRFID=1, AFID=0, PN="af0", DN="ucn.3gppnetwork.org", HN="pcscf01.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   //af1
   ADD PAF: PCRFID=1, AFID=1, PN="af1", DN="ucn.3gppnetwork.org", HN="pcscf03.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   ```
5. 增加PCF与对端AF的链路。关闭SCTP双归属时需要执行本步骤。

   //DC1：

   ```
   //af0
   ADD PAFL: PCRFID=1, AFID=0, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.2", LPT=3868, PIP="172.16.100.2", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ADD PAFL: PCRFID=1, AFID=0, LNKID=1, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.3", LPT=3868, PIP="172.16.100.3", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   //af1
   ADD PAFL: PCRFID=1, AFID=1, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.2", LPT=3868, PIP="172.16.100.102", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ADD PAFL: PCRFID=1, AFID=1, LNKID=1, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.3", LPT=3868, PIP="172.16.100.103", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

   //DC2：

   ```
   //af0
   ADD PAFL: PCRFID=1, AFID=0, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.102", LPT=3868, PIP="172.16.100.2", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ADD PAFL: PCRFID=1, AFID=0, LNKID=1, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.103", LPT=3868, PIP="172.16.100.3", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   //af1
   ADD PAFL: PCRFID=1, AFID=1, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.102", LPT=3868, PIP="172.16.100.102", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ADD PAFL: PCRFID=1, AFID=1, LNKID=1, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=OFF, IPVER=IPV4, LIP="172.21.100.103", LPT=3868, PIP="172.16.100.103", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```
6. 增加对端AF实体。开启SCTP双归属时需要执行本步骤。

   //DC1：

   ```
   ADD PAF: PCRFID=1, AFID=0, PN="af0", DN="ucn.3gppnetwork.org", HN="pcscf01.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   ```

   ```
   ADD PAF: PCRFID=1, AFID=1, PN="af1", DN="ucn.3gppnetwork.org", HN="pcscf03.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   ```

   //DC2：

   ```
   ADD PAF: PCRFID=1, AFID=0, PN="af0", DN="ucn.3gppnetwork.org", HN="pcscf02.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   ```

   ```
   ADD PAF: PCRFID=1, AFID=1, PN="af1", DN="ucn.3gppnetwork.org", HN="pcscf04.ucn.3gppnetwork.org", PT=DIAMETER, LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=OFF, ABILITYDICTID=0;
   ```
7. 增加PCF与对端AF的链路。开启SCTP双归属时需要执行本步骤。

   //DC1：

   ```
   ADD PAFL: PCRFID=1, AFID=0, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=OFF, DIPVER=IPV4, DLIP="172.21.100.3", LIP="172.21.100.2", LPT=3868, DPIP="172.16.100.3", PIP="172.16.100.2", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

   ```
   ADD PAFL: PCRFID=1, AFID=1, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=OFF, DIPVER=IPV4, DLIP="172.21.100.3", LIP="172.21.100.2", LPT=3868, DPIP="172.16.100.103", PIP="172.16.100.102", PPT=3870, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

   //DC2：

   ```
   ADD PAFL: PCRFID=1, AFID=0, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=OFF, DIPVER=IPV4, DLIP="172.21.100.103", LIP="172.21.100.102", LPT=3868, DPIP="172.16.100.3", PIP="172.16.100.2", PPT=3868, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

   ```
   ADD PAFL: PCRFID=1, AFID=1, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=OFF, DIPVER=IPV4, DLIP="172.21.100.103", LIP="172.21.100.102", LPT=3868, DPIP="172.16.100.103", PIP="172.16.100.102", PPT=3870, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**DSP PAFL**命令，检查“链路状态”参数项的返回结果。

   * “链路状态”值为“LINKUP” => PCF-AF链路正常，PCF-AF设备对接调测结束。
   * “链路状态”值不是“LINKUP” => 3。
3. 执行**LST PAF**/**LST PAFL**，检查数据配置是否与规划一致。
   * 是 => 4。
   * 否 => 修正配置后重新执行2。
4. 请联系华为技术支持处理。
