## 操作场景

该任务指导操作人员配置IMS-HSS与SAE-HSS/HLR融合部署场景下的IMS AKA（Authentication and Key Agreement）鉴权业务。

举例的数据将实现如下功能：开户模型为1个IMPI（IP Multimedia Private Identity）、1个IMPU（IP Multimedia PUblic Identity），并增加IMPI和IMSI（International Mobile Subscriber Identity）的关联关系，为IMPI配置了SIM/USIM卡鉴权数据，用户携带IMS AKA鉴权模式到IMS域进行注册，如果配置IMS AKA鉴权数据正确，则用户在IMS网络上注册成功。

## 必备事项

前提条件

* 操作人员具有OM Portal管理员权限。
* 操作人员具有PGW Web LMT客户端业务发放权限。
* 用户IMSI已在SAE-HSS/HLR上开户并签约AKA（Authentication and Key Agreement）鉴权特性。
* IMS-HSS和SAE-HSS/HLR之间的链路已经配置完成，具体可参见配置Diameter信令数据。

## 操作步骤

1. 登录“IMS-HSS业务管理”窗口。

   在HSS上进行操作之前需要确保表1中所列CSC上的参数按表中样例配置。
2. 执行**ADD HIMSI**命令增加IMSI、IMPI、ISDN三者的关联关系。
3. 执行**SET HEAA**命令为指定的IMPI设置Early AKA鉴权模式。
4. 执行**ADD HSUB**命令开户，增加一个IMPI和一个IMPU。
5. 设置IMPU的IMS漫游权限检查标志。执行**SET HVNCFLAG**命令，设置IMPU的IMS漫游权限检查标志为“FALSE”，不进行漫游检查。

   如果要进行漫游检查需要把漫游权限检查标志设置为“TRUE”，漫游限制配置详细请参见配置IMS漫游限制。
6. 执行**SET HREGAUTH**命令，设置IMPU的注册权限为“TRUE”，允许注册。
7. 登录“UEG MML命令”界面。
8. 执行**MOD INSP**命令设置Early AKA鉴权处理方式。

## 验证方法

1. 登录“IMS-HSS业务管理”窗口。
2. 使用开户的SIP号码在终端进行注册，验证终端是否可以成功注册。执行**LST HDYNDATA**命令查询IMS用户的动态数据，查看返回结果参数“IMSUSERST”是否为“REGISTERED”。
   * 是 => 表示注册成功。
   * 否 => 表示注册失败。
3. 查看用户是否已签约IMS AKA鉴权业务。执行**LST HAUTHINF**命令，查看返回的参数“AKAFLAG”是否为“1”。
   * 是 => 表示数据配置成功，且用户已经签约了IMS AKA鉴权业务。
   * 否 => 表示数据配置失败，且用户没有签约IMS AKA鉴权业务。

## 任务示例

任务描述

支持IMS AKA鉴权的终端用户“sip:user@huawei.com”可以接入IMS网络，如果成功注册，则说明配置IMS AKA鉴权数据成功。下面给出一个具体配置IMS AKA鉴权的样例。

脚本

/\*----------在SPG Web Portal界面上的S-CSCF网元实例界面下----------\*/

```
MOD SREG: NA=Y;
```

```
/*----------登录“IMS-HSS业务管理”窗口----------*/
```

/\*增加IMSI号码和IMPI的关联。\*/

```
ADD HIMSI: IMPI="user@huawei.com", IMSI="460001234567890", ISDN="8613988888888";
```

/\*设置Early AKA鉴权模式。\*/

```
SET HEAA: IMPI="user@huawei.com", EAAFLAG=TRUE;
```

/\*开户。\*/

```
ADD HSUB: SUBID="subinfo", IMPI="user@huawei.com", IMPU="sip:user@huawei.com";
```

/\*设置IMPU的IMS漫游权限检查标志。\*/

```
SET HVNCFLAG: IMPU="sip:user@huawei.com", VNCFLAG=FALSE;
```

/\*设置IMPU的注册权限。\*/

```
SET HREGAUTH: IMPU="sip:user@huawei.com", REGAUTH=TRUE;
```

/\*----------登录“UEG MML命令”界面----------\*/

/\*设置Early AKA鉴权处理方式。\*/

```
MOD INSP: INSPT=IMS-HSS, INSPN=EARLY_AKA_MODE, INSPV=0;
```
