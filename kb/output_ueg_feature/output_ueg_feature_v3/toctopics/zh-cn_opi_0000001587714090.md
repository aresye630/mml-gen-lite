# 配置网元和交换机对接（裸机容器）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

表1中指定型号的华为交换机作为DC-GW时，CSP支持纳管该交换机并支持告警上报功能。

一个CSP最大支持纳管4个交换机。需要在交换机和CSP分别配置，才能完成对接。

## 必备事项

前提条件

* 已登录网元OM Portal。
* 交换机运行正常。
* 交换机本端已经配置对接依赖的SNMP功能。华为交换机做GW的场景下，SNMP功能是基线配置。

  交换机上配置SNMP功能举例如下，该示例仅用于参考，请以交换机的实际配置为准。命令行详细的配置方法请参考对应型号的交换机产品文档*。*

  ```
   #-------配置网络设备SNMP功能--------
  #
  acl number 2001      //配置SNMP ACL 
  rule 5 permit  vpn-instance <管理VPN名称> source <IPv4地址> <反掩码>      //网元管理面IPv4地址和反掩码，绑定管理VPN
  rule 500 deny      //Deny其它访问
  #
  acl ipv6 number 2001      //配置SNMP ACL
  rule 5 permit  vpn-instance <管理VPN名称> source <IPv6地址> <反掩码>      //网元管理面IPv6地址和反掩码，绑定管理VPN 
  rule 500 deny      //Deny其它访问
  #
  snmp-agent
  snmp-agent sys-info version v3      //统一使用v3
  snmp-agent sys-info location <设备安装局址>  
  snmp-agent mib-view included myview iso
  snmp-agent group v3 dc-admin privacy read-view myview write-view myview notify-view myview
  snmp-agent usm-user v3 uhmroot      //账号与网元一致
  snmp-agent usm-user v3 uhmroot group dc-admin
  snmp-agent usm-user v3 uhmroot acl XXXX      //关联上述创建的ACL
  snmp-agent usm-user v3 uhmroot authentication-mode SHA512      //配置认证协议：与网元一致
  XXXX              
  XXXX      //要求连续输入两次认证密钥，与网元一致
  snmp-agent usm-user v3 uhmroot privacy-mode AES256      //配置加密协议：与网元一致 
  XXXX              
  XXXX      //要求连续输入两次认证密钥，与网元一致
  snmp-agent trap enable
  snmp-agent protocol source-status all-interface
  snmp-agent protocol source-status ipv6 all-interface
  snmp-agent protocol vpn-instance <管理VPN名称>
  snmp-agent protocol ipv6 vpn-instance <管理VPN名称>
  snmp-agent target-host trap address udp-domain <IPv4地址> udp-port <port-id> vpn-instance <管理VPN名称> params securityname uhmroot v3 privacy private-netmanager ext-vb      //如果对接的其他厂商设备，则不需要配置private-netmanager ext-vb参数。port-id与网元保持一致
  snmp-agent target-host trap ipv6 address udp-domain <IPv6地址> :: udp-port <port-id> vpn-instance <管理VPN名称> params securityname uhmroot v3 privacy private-netmanager ext-vb      //如果对接的其他厂商设备，则不需要配置private-netmanager ext-vb参数。port-id与网元保持一致
    #
  ```

## 操作步骤

1. 登录交换机，检查SNMP配置已经完成。

   在华为技术支持网站，下载交换机产品文档。支持的产品型号及版本号请参见表1。

   **表1** 网元支持纳管的产品

   | 产品名称 | 版本号 |
   | --- | --- |
   | CE6865E | V2R22C00及以上版本。 |
   | CE6863E | V2R22C00及以上版本。 |
   | NetEngine 8000 F1A | V800R021C00及以上版本。 |
   | FM6865-SI | V2R22C00&最新补丁版本。 |
   | CE6863H | V2R22C00及以上版本。 |
2. 登录网元OM Portal，选择“应用管理 > MML”。
3. 执行**OMPING**，检查交换机和CSP之间网络是否正常。

   ```
   OMPING: IPTYPE=IPV4, SRCIPV4="10.145.27.173", DSTIPV4="10.145.27.176";
   ```

   * 交换机与CSP之间网络正常，请执行4。
   * 交换机与CSP之间网络异常，若IP地址与规划数据不一致，请修正为规划的数据后重新执行**OMPING**。
   * 交换机与CSP之间网络异常，若IP地址与规划数据一致，请联系华为技术支持工程师处理。
4. 执行**ADD LSW**添加交换机，命令执行示例如下。

   ```
   %%ADD LSW: LSNAME="LSW1", IPTYPE=IPV4, LSIP="10.145.27.176", USER="AdminUser", PORT="161", PROTVER=SNMPv3, AUTHPROT=SHA512, AUTHKEY="*****", PRVPROT=AES256, PRVKEY="*****";%%
   RETCODE = 0  操作成功
   ---    END
   ```
5. 执行**LST LSW**查询交换机，状态显示为“正常”，说明交换机对接成功。

   ```
   %%LST LSW:;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------   
     以太网交换机名称  =  LSW1
   以太网交换机IP地址  =  10.145.27.176               
                 状态  =  正常               
                 用户  =  AdminUser               
                 端口  =  161           
             协议版本  =  SNMPv3           
             认证协议  =  SHA512           
             加密协议  =  AES256 
   (结果个数 = 1)

   ---    END
   ```
