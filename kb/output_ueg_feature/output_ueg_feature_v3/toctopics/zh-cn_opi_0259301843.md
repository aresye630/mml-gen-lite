# 配置OMU OS管理维护接口

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

网元提供OMU OS管理维护接口用于与外部服务器对接，例如网元需要对接外部系统进行安全扫描时，可以参考本章节添加物理IP地址。

* 当网元使用IPV4地址部署，对接外部系统使用IPV6地址时，网元需要为首节点（物理IP1）和第二管理节点（物理IP2）分别添加物理IPV6地址。
* 当网元使用IPV6地址部署，对接外部系统使用IPV4地址时，网元需要为首节点和第二管理节点分别添加物理IPV4地址。
* 当网元和对接外部系统均使用IPV4地址，或者均使用IPV6地址，或者网元为IPV4和IPV6双栈部署时，网元可以使用已配置物理IP地址与外部系统对接，可以通过执行**LST OMIP**查询物理IP信息。

## 操作步骤

1. 登录网元OM Portal，选择“应用管理 > MML”。
2. 执行**LST OMIP**（虚机容器）/**LST OMIP**查询系统当前物理IP地址，脚本示例如下。

   ```
   LST OMIP:;
   ```
3. 当需要添加IP地址时，执行**SET OMIP**（虚机容器）/**SET OMIP**添加物理IP地址。例如系统需要添加IPV4地址时，脚本示例如下。

   ```
   SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMHOST1IPV4="10.10.10.10", OMHOST2IPV4="10.10.10.20";
   ```
4. 添加物理IP地址后，网元可以使用新增IP地址和默认维护用户“mtuser”对接外部系统。如果需要创建新用户对接外部系统，可参考如下步骤创建OS用户。

   仅可以在两个管理节点创建OS用户。操作员可以登录OM Portal执行**LST OMIP**命令查看管理节点所在的IP地址。

   1. Windows操作系统通过“putty.exe”工具登录系统管理节点，Linux操作系统通过终端模拟器登录系统管理节点，执行**su - root**切换至root用户。
   2. 执行**bash /usr/bin/create\_out\_sshduser.sh -a "*<待添加用户名>*"** （添加的用户名称需要满足Linux用户名要求，不能含有~!@$%&等特殊符号）。
   3. 界面提示“please input password:”后，输入待添加用户的密码（密码需要满足复杂度要求，至少一个大写字母，一个小写字母，一个数字和一个特殊符号，长度14位以上）。
   4. 界面提示“Are you sure you want to change the password upon your first login (yes/no)?”后，输入**yes**开启登录强制修改密码功能（此用户用于对接第三方系统，开启后需要第三方系统对接配合修改，如果第三方无法支持此功能可输入**no**）；输入**no**关闭登录强制修改密码功能。
   5. 界面提示：“add user ***<新创建用户名>*** success”则添加用户成功。若添加失败，请根据提示信息检查添加的用户名是否含有特殊字符，密码是否满足复杂度要求。
   6. 添加完成后，可执行**cat /etc/passwd**查看用户相关信息。

   * 以上步骤添加的用户默认具有**su - root**以及远程登录系统的权限。
   * 新创建的OS用户如果需要删除可以执行：**bash /usr/bin/create\_out\_sshduser.sh -d "*<待删除用户名>*"。（**删除操作，会将用户相关的目录内容全部删除，如需保留请提前备份如下目录内容：/home/用户名; /var/mail/用户名; /var/spool/mail/用户名 ）
   * 可以使用**bash /usr/bin/create\_out\_sshduser.sh -h查看脚本使用的帮助信息。**
