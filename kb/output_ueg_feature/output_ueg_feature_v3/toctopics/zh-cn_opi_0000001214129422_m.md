## 操作场景

为保证在边缘网络与中心网络传输中断时用户能保持惯性运行、业务不中断，新用户能在本地应急接入，需要开启本特性，并设置相应控制参数。

## 对系统的影响

对系统无影响。

## 必备事项

前提条件

* 请仔细阅读GWFD-023901 本地应急接入。
* 完成UPF、应急AMF、应急SMF、应急UDM与周边网元的对接配置及基础全局数据配置，具体配置见《初始配置与调测》。
* 完成License加载。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本地应急接入特性的License配置开关。

   **SET LICENSESWITCH**
3. 配置应急AMF在收到基站消息，本地无用户上下文时的处理策略。

   **SET NGMMFUNC**
4. 配置惯性运行功能对数据面非连接态用户不生效，PFCP路径断后连接态用户进入惯性运行状态的等待时长和非5G用户支持惯性运行。

   **SET INERTIALOPER**
5. （可选）设置惯性运行/应急接入授权开关及时长，避免用户在边缘网络与中心网络恢复后长期在边缘应急控制面接入运行。

   **SET EMERGAUTHTIMER**
6. 5中“惯性运行/应急接入授权开关（SWITCH）”参数设置为“ENABLE”时，配置应急SMF的NODE信息。

   **ADD CPNODEID**

## 任务示例

任务描述

* 开启本地应急接入特性。
* 设置应急AMF在查找应急接入园区的用户上下文失败时回复基站UE CONTEXT RELEASE COMMAND消息，使基站快速释放上下文，触发用户重新注册，提高用户业务恢复速度。
* 设置连接态用户PFCP路径断超过30秒后进入惯性运行。
* 设置数据面非连接态用户不进入惯性运行。
* 设置非5G用户支持惯性运行。
* 开启惯性运行/应急接入授权开关，并设置惯性运行/应急接入授权时长。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5IOIF01",SWITCH=ENABLE;
```

//配置应急AMF在收到基站消息，本地无用户上下文时的处理策略。

```
SET NGMMFUNC: NOUECTXOPTSW=ON;
```

//配置惯性运行功能对数据面非连接态用户不生效，非5G用户支持惯性运行和路径断后连接态用户进入惯性运行状态的等待时长。

```
SET INERTIALOPER: IDLEUSRIGNORE=ENABLE, DELAYTIME=30, NON5GUSRIGNORE=DISABLE;
```

//设置惯性运行/应急接入授权开关及时长。

```
SET EMERGAUTHTIMER: SWITCH=ENABLE, HOURS=48;
```

//配置应急SMF的NODE信息。如已配置应急SMF的NODE信息，此处不需要重复配置。

* //“CPNODEIDTYPE”设置为“IPV4”时：

  ```
  ADD CPNODEID: CPNAME="smfnode1", CPNODEIDTYPE=IPV4, IPV4NODEID="10.0.0.1", LOCALEMERNODE=TRUE;
  ```
* //“CPNODEIDTYPE”设置为“IPV6”时：

  ```
  ADD CPNODEID: CPNAME="smfnode2", CPNODEIDTYPE=IPV6, IPV6NODEID="FC00:0:0:0:10:0:0:1", LOCALEMERNODE=TRUE;
  ```
* //“CPNODEIDTYPE”设置为“FQDN”时：

  ```
  ADD CPNODEID: CPNAME="smfnode3", CPNODEIDTYPE=FQDN, FQDNNODEID="consumer.huawei.com", LOCALEMERNODE=TRUE;
  ```
