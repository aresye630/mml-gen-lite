# 配置MME数据（可选）

## 操作场景

NB-IoT场景，用于配置MME侧配置S11-U接口。其中S11-U和N4接口共用VPN。

对于容灾的两个UEG-S而言，此配置没有区别，仅以一个UEG-S做配置举例。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SERVICEIP** | IP版本（IPVERSION） | VRF\_PS\_N4 | 全网规划 | 配置业务IP参数。  S11-U和S11-C的VPN实例相同。 |
|  | 业务IPv4地址（SERVICEIPV4） | 192.168.140.20 | 全网规划 |  |
|  | VPN实例名称（VPNINSTNAME） | VRF\_PS\_N4 | 全网规划 |  |
| **ADD GTPULE** | 组号（GROUPID） | 0 | 全网规划 | 配置本端的S11接口的GTP-U IP。  GTP数据绑定的VPN实例与上面业务IP绑定的VPN实例相同。 |
|  | IP地址类型（IPTYPE） | TPTADDR\_TYPE\_IPV4 | 全网规划 |  |
|  | IPv4地址（LEIPV4） | 192.168.140.20 |  |  |
|  | VPN名称（vpnName） | VRF\_PS\_N4 | 全网规划 |  |

## 任务示例

任务描述

NB-IoT场景，配置MME侧配置S11-U接口。其中S11-U和N4接口共用VPN。

脚本

1. 配置S11-U接口业务IP。

   ```
   ADD SERVICEIP: IPVERSION=IPv4, SERVICEIPV4="192.168.140.20", VPNINSTNAME="VRF_PS_N4";
   ```
2. 配置GTP IP数据，其中S11-U接口推荐与其他接口共部署，GTPU本端实体对应的组号配置为0。

   ```
   ADD GTPULE: GROUPID=0, IPTYPE=TPTADDR_TYPE_IPV4, LEIPV4="192.168.140.20",VPNNAME="VRF_PS_N4";
   ```
