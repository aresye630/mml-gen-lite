# 配置Diameter信令数据（与I-CSCF/S-CSCF/ATS对接）

## 操作场景

接入4G/5G NSA用户并部署语音业务时，Diameter信令数据用于IMS-HSS和I-CSCF/S-CSCF/AS对接。

HSS（UDM）通过Diameter信令与对端网元（如I-CSCF/S-CSCF/AS）互通时，需要配置该页面。

HSS（UDM）和I-CSCF/S-CSCF/AS直联对接，即不通过DRA设备。

## 必备事项

前提条件

* 已完成配置UDM基础数据。
* HSS（UDM）和I-CSCF/S-CSCF/AS之间外联口通信正常。

文档

获取网设LLD文档。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 增加Diameter本端实体。

   //DC1：

   ```
   ADD DMLE: EN="HSS03", LOCTYPE=IMS-HSS, DN="ucn.3gppnetwork.org", HN="imshss1.ucn.3gppnetwork.org";
   ```

   //DC2：

   ```
   ADD DMLE: EN="HSS04", LOCTYPE=IMS-HSS, DN="ucn.3gppnetwork.org", HN="imshss2.ucn.3gppnetwork.org";
   ```
3. 增加Diameter对端实体。

   ```
   ADD DMPE: EN="I-CSCF01", PEERTYPE=I-CSCF, HN="icscf01.ucn.3gppnetwork.org", PEPRI=15;
   ADD DMPE: EN="I-CSCF02", PEERTYPE=I-CSCF, HN="icscf02.ucn.3gppnetwork.org", PEPRI=15;
   ADD DMPE: EN="S-CSCF01", PEERTYPE=S-CSCF, HN="scscf01.ucn.3gppnetwork.org", PEPRI=15;
   ADD DMPE: EN="S-CSCF02", PEERTYPE=S-CSCF, HN="scscf02.ucn.3gppnetwork.org", PEPRI=15;
   ADD DMPE: EN="AS01", PEERTYPE=AS, HN="as01.ucn.3gppnetwork.org", DN="ucn.3gppnetwork.org", PEPRI=15;
   ADD DMPE: EN="AS02", PEERTYPE=AS, HN="as02.ucn.3gppnetwork.org", DN="ucn.3gppnetwork.org", PEPRI=15;
   ```
4. 设置对端实体能力。

   ```
   SET DMPECAP: PEERNAME="I-CSCF01", PEERTYPE=I-CSCF, CSCFFEATURELIST=SharedIFC-1&AliasInd-1&CscfDisaster-1, HN="icscf01.ucn.3gppnetwork.org";
   SET DMPECAP: PEERNAME="I-CSCF02", PEERTYPE=I-CSCF, CSCFFEATURELIST=SharedIFC-1&AliasInd-1&CscfDisaster-1, HN="icscf02.ucn.3gppnetwork.org";
   SET DMPECAP: PEERNAME="S-CSCF01", PEERTYPE=S-CSCF, CSCFFEATURELIST=SharedIFC-1&AliasInd-1&CscfDisaster-1, HN="scscf01.ucn.3gppnetwork.org";
   SET DMPECAP: PEERNAME="S-CSCF02", PEERTYPE=S-CSCF, CSCFFEATURELIST=SharedIFC-1&AliasInd-1&CscfDisaster-1, HN="scscf02.ucn.3gppnetwork.org";
   SET DMPECAP: PEERNAME="AS01", PEERTYPE=AS, PR=REPOSITORYDATA-1&IMSPUBLICIDENTITY-1&IMSUSERSTATE-1&SCSCFNAME-1&IFC-1&LOCATIONINFORMATION-1&USERSTATE-1&CHARGINGINFORMATION-1&MSISDN-1&PSIACTIVATION-1&ALIASREPOSITORY-1&SMSREGISTRATIONINFO-1&TADSINFORMATION-1&STN_SR-1&UESRVCCCAPABILITY-1&CSRN-1&REFERENSELOCATIONINFORMAION-1&IMSI-1&IPADDRSECUREBINDINGINFOR-1&IMSPRIVATEUSERIDENTITY-1, UR=REPOSITORYDATA-1&PSIACTIVATION-1&ALIASREPOSITORY-1&SMSREGISTRATIONINFO-1&STN_SR-1, NR=REPOSITORYDATA-1&IMSUSERSTATE-1&SCSCFNAME-1&IFC-1&PSIACTIVATION-1&ALIASREPOSITORY-1&IMSPUBLICIDENTITY-1&UEREACHABILITYFORIP-1&UESRVCCCAPABILITY-1&CHARGINGINFORMATION-1&IPADDRSECUREBINDINGINFOR-1&IMSPRIVATEUSERIDENTITY-1, ASFEATURELIST=Notif-Eff-1, HN="as01.ucn.3gppnetwork.org", DN="ucn.3gppnetwork.org";
   SET DMPECAP: PEERNAME="AS02", PEERTYPE=AS, PR=REPOSITORYDATA-1&IMSPUBLICIDENTITY-1&IMSUSERSTATE-1&SCSCFNAME-1&IFC-1&LOCATIONINFORMATION-1&USERSTATE-1&CHARGINGINFORMATION-1&MSISDN-1&PSIACTIVATION-1&ALIASREPOSITORY-1&SMSREGISTRATIONINFO-1&TADSINFORMATION-1&STN_SR-1&UESRVCCCAPABILITY-1&CSRN-1&REFERENSELOCATIONINFORMAION-1&IMSI-1&IPADDRSECUREBINDINGINFOR-1&IMSPRIVATEUSERIDENTITY-1, UR=REPOSITORYDATA-1&PSIACTIVATION-1&ALIASREPOSITORY-1&SMSREGISTRATIONINFO-1&STN_SR-1, NR=REPOSITORYDATA-1&IMSUSERSTATE-1&SCSCFNAME-1&IFC-1&PSIACTIVATION-1&ALIASREPOSITORY-1&IMSPUBLICIDENTITY-1&UEREACHABILITYFORIP-1&UESRVCCCAPABILITY-1&CHARGINGINFORMATION-1&IPADDRSECUREBINDINGINFOR-1&IMSPRIVATEUSERIDENTITY-1, ASFEATURELIST=Notif-Eff-1, HN="as02.ucn.3gppnetwork.org", DN="ucn.3gppnetwork.org";
   ```
5. 与AS对接时，配置“ASID”与对接AS数据的绑定关系。
   1. 登录PGW Web LMT MML命令界面。
   2. 设置“ASID管理方式”为“STORE\_IN\_USCDB”。

      ```
      SET HSYSTEMPARA: ASIDMODE=STORE_IN_USCDB;
      ```
   3. 配置ASID与对接AS数据的绑定关系。

      ```
      ADD HASHOST: ASID=0, HOSTNAME="as01.ucn.3gppnetwork.org", REALMNAME="ucn.3gppnetwork.org";
      ```

      ```
      ADD HASHOST: ASID=1, HOSTNAME="as02.ucn.3gppnetwork.org", REALMNAME="ucn.3gppnetwork.org";
      ```

   ```
   ADD DMLKS: LINKSNAM="Diameter13", LOCALNAM="HSS03", PEERNAM="S-CSCF02", LNKMOD=POLLING;
   ADD DMLKS: LINKSNAM="Diameter14", LOCALNAM="HSS03", PEERNAM="AS01", LNKMOD=POLLING;
   ADD DMLKS: LINKSNAM="Diameter15", LOCALNAM="HSS03", PEERNAM="AS02", LNKMOD=POLLING;
   ```

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**DSP DMLNK**命令，查看Diameter链路是否正常。
   * “Diameter链路”状态为“Diam链路断开”，请执行3。
   * “Diameter链路”状态为“Diam链路正常”，则说明状态正常，调测结束。
3. 请参考**Diameter链路故障告警**进行处理。

   处理后重新执行2，如Diameter链路仍异常，请联系华为技术支持工程师。
