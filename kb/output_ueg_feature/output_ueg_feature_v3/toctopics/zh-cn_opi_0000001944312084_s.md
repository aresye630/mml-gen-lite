# 配置S11-U接口数据（可选）

## 操作场景

NB-IoT场景，用于配置SGW-U侧配置S11-U接口。其中S11-U和N4接口共用VPN。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD VPNINST** | VPN实例名（VPNINSTANCE） | VRF\_PS\_N4 | 全网规划 | 逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。 |
| **ADD LOGICINF** | 逻辑接口名称（NAME） | S11-uif1/1/0 | 全网规划 | 最后一位数字取值范围是0~31。 |
|  | 逻辑接口的IP版本（IPVERSION） | IPv4 | - | 如果规划逻辑接口使用IPv4v6双栈组网，则该参数取值为“IPVER\_ALL”，分别配置IPv4和IPv6地址。 |
|  | 逻辑接口的IPv4地址1（IPV4ADDRESS1） | 10.1.1.22 | 全网规划 |  |
|  | 逻辑接口的IPv4掩码1（IPV4MASK1） | 255.255.255.255 | 固定取值 |  |
|  | VPN实例名称（VPNINSTANCE） | VRF\_PS\_N4 | 全网规划 | - |

## 任务示例

任务描述

NB-IoT场景，配置SGW-U侧配置S11-U接口。其中S11-U和N4接口共用VPN。

脚本

1. 配置S11-U接口的VPN。

   ```
   ADD VPNINST: VPNINSTANCE ="VRF_PS_N4";
   ```
2. 配置S11-U接口的IP地址。

   ```
   ADD LOGICINF:NAME="S11-uif1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.22",IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_PS_N4";
   ```
