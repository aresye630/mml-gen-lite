# 配置SMF公共数据

## 操作场景

图1中，主锚点UPF下沉边缘侧，正常情况下用户按照位置区优先选择UPF1，当UPF1故障的情况下希望用户可以选到UPF0上以确保边缘侧业务不受损。

该方案中上述UPF需要配置边缘相关联的位置信息，确保SMF在用户会话激活过程中根据位置信息优选UPF1，在UPF1故障的情况下可以选到UPF0上。

**图1** 容灾组网示意

此配置页面中的命令仅在新建UPF时配置。

## 必备事项

前提条件

无。

数据

## 任务示例

任务描述

如图1所示，UPF0服务的区域为“1230320101”~“1230320111”和“1230320105”~“1230320115”，UPF1服务的区域为“1230320101”~“1230320111”。

UPF0和UPF1对应的UPF实例标志分别为UPF\_Instance\_0和UPF\_Instance\_1，对应的IP地址为192.168.126.11和192.168.126.12。

脚本

1. SMF本端添加UPF。

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_0", NFTYPE=NfUPF, NFSTATUS=Registered,FQDN="upf00.node.mnc003.mcc123.3gppnetwork.org",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11";
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered,FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.12", LOCALITY="DataCenter1";
   ```
2. 配置用户面支持的服务切片信息。

   ```
   ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_0", SST=1, SD="000001";
   ADD PNFNS: INDEX=4, NFINSTANCEID="UPF_Instance_1", SST=1, SD="000001";
   ```
3. 配置UPF的DNN属性。

   ```
   ADD PNFDNN:INDEX=5, NFINSTANCEID="UPF_Instance_0", DNN="APN1", PNFNSINDEX=3;
   ADD PNFDNN:INDEX=6, NFINSTANCEID="UPF_Instance_1", DNN="APN1", PNFNSINDEX=4;
   ```
4. 配置UPF的属性**。**

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_0", LOCATION=Central, SUPULCLBPONLY=Enable, UPFUNCTION=None, LOCK=FALSE, VPNNAME="VRF_CP";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", LOCATION=Central, SUPULCLBPONLY=Enable, UPFUNCTION=None, LOCK=FALSE, VPNNAME="VRF_CP";
   ```
5. 配置用于SMF本端判定UPF归属区域的区域类型。

   ```
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREA:AREANAME="UPAREA2", AREATYPE=N2TAI;
   ```
6. 配置UPF归属区域对应的区域范围。

   ```
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12303201001", N2ENDTAI="12303201004";
   ADD UPAREABINDN2TAI:AREANAME="UPAREA2", N2BEGINTAI="12303201005", N2ENDTAI="12303201115";
   ```
7. SMF本端配置UPF所覆盖的区域。

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA1";
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA2";
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA1";
   ```
8. 配置用户面与EPS的互通以及支持的PDU会话类型。

   ```
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_1", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ```
9. 配置UPF位置信息与该UPF优先支持的服务区的绑定关系。

   ```
   ADD LOCBINDAREA: LOCALITY="DataCenter1",AREANAME="UPAREA1";
   ```
10. 打开UPF按位置区的优先级开关。

    ```
    SET UPSELECTFLAG: LOCALITYFLAG=ENABLE;
    ```
11. （可选）配置UPF绑定到特定的IP Domain，仅当UPF间地址池重叠时需要配置。请确保参数“DNN”已在**ADD APN**中定义。

    ```
    ADD UPIPDOMAIN:UPNODE="UPF_Instance_0", IPDOMAIN="APP-HDNJIHzjSAEGWC1BHW-08AHW011.zj.jih.node.epc.mnc000.mcc460.3gppnetwork.org", DNNSWITCH=ENABLE,DNN=APN1;
    ADD UPIPDOMAIN:UPNODE="UPF_Instance_1", IPDOMAIN="APP-HDNJIHzjSAEGWC1BHW-08AHW011.zj.jih.node.epc.mnc000.mcc460.3gppnetwork.org", DNNSWITCH=ENABLE,DNN=APN1;
    ```
