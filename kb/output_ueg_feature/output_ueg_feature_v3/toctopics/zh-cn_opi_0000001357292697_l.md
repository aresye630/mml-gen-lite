# 配置切片业务数据（风筝L）

## 操作场景

本场景用于配置风筝L场景切片相关的业务数据。

## 对系统的影响

无。

## 必备事项

前提条件

无。

## 任务示例

任务描述

完成风筝L场景切片业务数据配置。

脚本

1. 配置PLMN支持的切片。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="131313";
   ```
2. 配置AMF切片信息。

   ```
   ADD NFNS: NFTYPE=NfAMF, NSIDX=1;
   ```
3. 配置SMF支持的切片信息。

   ```
   ADD NFNS: NFTYPE=NfSMF, NSIDX=1;
   ```
4. 配置SMF对接的UPF支持的切片信息。

   ```
   ADD PNFNS:INDEX=1, NFINSTANCEID="upf_instance_0", SST=1, SD="131313";
   ```
5. 配置SMF对接的UPF切片支持的DNN。

   ```
   ADD PNFDNN:INDEX=0, NFINSTANCEID="upf_instance_0", DNN="kite2ul", PNFNSINDEX=10;
   ```
6. 配置AMF对接的SMF支持的切片信息。

   ```
   ADD PNFNS: INDEX=11, NFINSTANCEID="smf_instance_0", SST=1, SD="131313";
   ```
7. 配置AMF对接的SMF切片支持的DNN。

   ```
   ADD PNFDNN: INDEX=11, NFINSTANCEID="smf_instance_0", DNN="kite2ul", PNFNSINDEX=1;
   ```
8. 配置UPF切片信息。

   ```
   ADD SNSSAI: SST=1, SD="131313";
   ```
9. 配置切片和N3接口绑定。

   ```
   ADD SNSSAIUPINTF: SST=1, SD="131313", N3LOGICINF="N3IF1/1/1";
   ```
