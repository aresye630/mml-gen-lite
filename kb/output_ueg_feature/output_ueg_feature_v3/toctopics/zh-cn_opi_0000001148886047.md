# 配置切片业务数据（SMF）

## 操作场景

本场景用于在SMF上配置切片相关的业务数据。

## 对系统的影响

无。

## 必备事项

前提条件

无。

## 任务示例

任务描述

在SMF上完成切片业务数据配置：切片ID、N4接口。

脚本

1. 配置PLMN支持的切片。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="131313",STATE=INACTIVE;
   ```
2. 配置SMF支持的切片信息。

   ```
   ADD NFNS: NFTYPE=NfSMF, NSIDX=1;
   ```
3. 配置SMF切片支持的DNN。

   ```
   ADD NSDNN:NSIDX=1, DNN="net";
   ```
4. 配置SMF对接的UPF支持的切片信息。

   ```
   ADD PNFNS:INDEX=1, NFINSTANCEID="81304a9d-0202-41db-8272-59159a70c123", SST=1, SD="131313";
   ```
5. 配置SMF对接的UPF切片支持的DNN。

   ```
   ADD PNFDNN:INDEX=0, NFINSTANCEID="81304a9d-0202-41db-8272-59159a70c123", DNN="net", PNFNSINDEX=1;
   ```
