## 任务示例

任务描述

在NSSF上完成切片业务数据配置：切片ID、切片选择。

脚本

1. （可选）配置区域分组。

   ```
   ADD TACGROUPINNSSF: INDEX=0, TACGROUPNAME="TACGROUP0", TACSTART="00138d", TACEND="00138d";
   ```
2. （可选）配置候选AMF。

   ```
   ADD CANDIDATEAMF: INDEX=0, AMFINSTANCEID="a671e53f-115f-4969-be66-f89fb301d718", MCC="460", MNC="02", REGIONID="00", AMFSETID="001";
   ```
3. 配置NSSF支持的切片信息。

   ```
   ADD CFGSNSSAI: INDEX=0, MCC="460", MNC="02", SST=1, SD="131313", ISACTIVE=TRUE;
   ```
4. 配置AMF集与切片的关系。

   ```
   ADD AMFSETID: INDEX=0, SST=1, SD="131313", MCC="460", MNC="02", REGIONID="00", AMFSETID="001", TACGROUPNAME="TACGROUP0";
   ```
