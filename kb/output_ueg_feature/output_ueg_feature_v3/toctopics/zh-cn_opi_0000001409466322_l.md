# 层二5G LAN配置实例（UEG-L）

## 操作场景

园区部署两套UEG-L，两套UEG-L是负荷分担容灾模式或主备容灾模式。不同业务场景下，5G LAN相关组网及报文路径差异如表1所示。

* 企业侧交换机与UPF之间建立VXLAN隧道的场景，图1~图8中的DCGW、Firewall仅用于举例，5G LAN业务对DCGW、Firewall数量无特殊要求。
* DCGW与UPF之间建立VXLAN隧道的场景，图2~图8中的Firewall、LSW仅用于举例，5G LAN业务对Firewall、LSW数量无特殊要求。

**表1** 5G LAN组网及报文路径

| 业务场景 | 负荷分担容灾模式 | 主备容灾模式（冷备/热备） |
| --- | --- | --- |
| 场景一：5G LAN层二终端与Server（Main PLC/MES/...）互通 | 组网如图1/图2所示。  负荷分担容灾模式时，两个UEG-L均处理业务，5G LAN层二终端通过某一UEG-L与Server（Main PLC/MES/...）互通。  说明：  5G LAN层二终端与Server（Main PLC/MES/...）在不同网段时，层二终端所在PC上需要配置网关IP，网关IP配置在企业侧VXLAN交换机上或独立的网关设备上。 | 组网如图6所示。  主备容灾模式时，同一时刻，只有一套UEG-L处理业务，5G LAN层二终端通过运行状态为主的UEG-L与Server（Main PLC/MES/...）互通。另一套UEG-L不处理业务（冷备状态）。  说明：  5G LAN层二终端与Server（Main PLC/MES/...）在不同网段时，层二终端所在PC上需要配置网关IP，网关IP配置在企业侧VXLAN交换机上或独立的网关设备上。 |
| 场景二：同一5G LAN组的层二终端之间互通 | 组网如图3所示。  两套UEG-L是负荷分担容灾模式时，同一5G LAN组下不同终端通过**同一UEG-L或不同UEG-L**接入。如同一5G LAN组下无线接入的终端通过不同UPF互通：  * 企业侧交换机与UPF之间建立VXLAN隧道的场景，则需要根据LSW的能力判断是否需要多对LSW。两个UPF仅对接一对企业侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。 * DCGW与UPF之间建立VXLAN隧道的场景，两个UPF对接一对DCGW时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。  说明：  * LSW支持VXLAN进VXLAN出（接收VXLAN报文，处理后重新封装成VXLAN报文发出）时，可只部署一对LSW。否则，需要两对LSW。图3以两对LSW为例。 * 同一5G LAN层二终端IP在不同网段且存在互通诉求时，层二终端所在PC上需要配置网关IP，网关IP配置在企业侧VXLAN交换机上或独立的网关设备上。 | 组网如图8所示。  两套UEG-L是主备容灾模式时，同一5G LAN组下无线接入的终端可通过同一UPF直接互通，不需要经过LSW/DCGW。  说明：  同一5G LAN层二终端IP在不同网段且存在互通诉求时，层二终端所在PC上需要配置网关IP，网关IP配置在企业侧VXLAN交换机上或独立的网关设备上。 |

当存在如下情况时，可以参考本页面进行配置。

* CPE下挂多个终端（最多16个）。
* 同一个二层广播域内的终端IP必须不同。
* 支持如下几种典型业务场景：
  + 5G LAN层二终端与Server（Main PLC/MES/...）需要互通。

    Server（Main PLC/MES/...）部署在N6侧。
  + 同一5G LAN组层二终端之间通过同一UPF互通。
  + 同一5G LAN组层二终端之间通过不同UPF互通。
    - 企业侧交换机与UPF之间建立VXLAN隧道的场景

      该业务场景下，需要根据LSW的能力判断是否需要多对LSW（用于建立VXLAN隧道）。LSW支持VXLAN进VXLAN出（接收VXLAN报文，处理后重新封装成VXLAN报文发出）时，可只部署一对LSW。否则，需要每台UEG对接一对LSW。

      两个UPF仅对接一对企业侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。
    - DCGW与UPF之间建立VXLAN隧道的场景

      两个UPF是负荷分担关系，且仅对接一对DCGW时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。每个UPF独自对接一对DCGW时，可通过DCGW与UPF之间的VXLAN隧道实现跨UPF的终端互访。

## 必备事项

前提条件

* 除5G LAN业务外，UEG-L支持的5G SA业务运行正常。
* 企业侧交换机与UPF之间建立VXLAN隧道的场景，UPF和LSW之间的VXLAN隧道路径中存在防火墙时，防火墙需要放通VXLAN隧道IP地址（端口any，动态分配端口）对应的流量。
* 5GC与N6侧网络环境已构建完成。
  + 企业侧交换机与UPF之间建立VXLAN隧道的场景

    两个UEG-L是负荷分担容灾模式，且同一5G LAN组内的终端存在互通诉求时，若LSW不支持将通过VXLAN隧道接收的报文再通过VXLAN隧道转发出去，则每个UEG-L需对接2个LSW用于建立VXLAN隧道，那么两个UEG-L需要4个LSW。如图3所示。
  + DCGW与UPF之间建立VXLAN隧道的场景

    两个UPF是负荷分担关系，且仅对接一对DCGW/企业侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。每个UPF独自对接一对DCGW时，可通过DCGW与UPF之间的VXLAN隧道实现跨UPF的终端互访。
* 已加载License文件，且包含如下License控制项：
  + UDM：LKQ7UDMBE15 5G LAN签约用户数
  + SMF：LKV2SALANSM01 5G LAN业务基本功能-USM
  + UPF：LKV3G5LANB01 5G LAN基础功能

    如下几个License控制项需基于实际业务申请：
    - LKV3G5L2SMUL 层二静态组播
    - LKV3G5LADFSR 5G LAN双发选收会话数
    - LKV3G5LAN2LE 5G LAN层二环路消除

## 操作步骤

配置UDM数据

+ **ADD NGCQOSTPL**命令存在多条时，“TPLID”不能重复。
+ **ADD DNNQOSTPL**命令存在多条时，“TPLID”不能重复。
+ **ADD DNNQOSTPL**命令中的“NGCQOSTPLID”参数索引**ADD NGCQOSTPL**命令中的“TPLID”参数值。
+ **ADD SMDATA**命令中的“DNNQOSTPLID”参数索引**ADD DNNQOSTPL**命令中的“TPLID”参数值。
+ 5G LAN QoS参数（5QI、ARP等）仅用于举例，实际请根据具体业务模型规划。
+ 在“UDM业务管理”窗口下执行**LST NGS**命令和**LST VNGROUP**可查询5G LAN用户的“SNSSAI”、“DNN”、“INGROUPID”、“SHAREDID”、“PDUTYPES”等开户信息。
+ 2~5是在“UDM业务管理”窗口下执行。具体为：先登录PGW WEBUI，然后在“应用类型”下拉框选择“UDM业务管理”。

从中心UDM（UDM）同步用户数据时，中心UDM（UDM）和园区UDM（UEG）配置说明如表5所示。

**表5** 中心UDM（UDM）/园区UDM（UEG）配置说明

| 配置项 | 中心UDM（UDM） | 园区UDM（UEG） |
| --- | --- | --- |
| 开启5G LAN License、配置5G LAN使用的DNN信息（5G QoS模板、DNN QoS模板） | 需要配置 | 需要配置 |
| 签约会话管理数据、创建5G LAN组和增加5G LAN组成员 | 需要配置 | 不需要配置 |

1. 检查5G LAN License项是否开启。

   //显示信息中存在“LKQ7UDMBE15”控制项且取值不为0时，说明已开启5G LAN License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```
2. 配置5G LAN使用的DNN信息。

   //创建5G QoS模板。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="tp5glan01", NGQI=9, ARPPRILEVEL=1, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=FALSE, NGQIPRILEVEL=1;
   ```

   //创建DNN QoS模板。

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=2, TPLNAME="tp5glan01", PDUTYPE=ETHER, SSCMODE=SSC_MODE_1, NGCQOSTPLID=1, AMBRUP=5, UPUNIT=Gbps, AMBRDW=5, DWUNIT=Gbps, CHARGE="0800";
   ```
3. 签约会话管理数据。

   ```
   ADD SMDATA: IMSI="460081000000001", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=2;
   ```

   ```
   ADD SMDATA: IMSI="460082000000002", SNSSAI="1-010101", DNN="dnn5glan01", DEFAULT=TRUE, DNNQOSTPLID=2;
   ```
4. 创建5G LAN组。

   //如下以配置2个5G LAN组为例。规划多个5G LAN组时，“INGROUPID”、“EXTGROUPID”、“SHAREDID”取值必须不同。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei01", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-02", EXTGROUPID="group02@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="dnn5glan01", PDUTYPES=ETHER;
   ```
5. 增加5G LAN组成员。

   ```
   ADD GROUPID: IMSI="460081000000001", INGROUPID="1001-46008-01";
   ```

   ```
   ADD GROUPID: IMSI="460082000000002", INGROUPID="1001-46008-02";
   ```

配置AMF数据

AMF上配置的切片参数SST、SD与UDM开户时切片参数一致。可以复用已有切片，复用已有切片时，不需要执行如下配置。可通过**LST PLMNNS**查询。

1. 配置PLMN支持的切片。复用已有切片时，不需要重复配置。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="010101";
   ```
2. 配置AMF切片信息。复用已有切片时，不需要重复配置。

   ```
   ADD NFNS: NFTYPE=NfAMF, NSIDX=1;
   ```
3. 配置AMF对5G LAN切片下的DNN纠正。如现网已涉及DNN纠正功能（可通过**LST LOCALNSDNN**查询），则需要执行如下配置；否则，请跳过如下配置。

   //用户请求APN与签约APN不匹配时，优先纠正为签约数据中的Default DNN，如果未签约Default DNN，则纠正为dnn5glan01。

   ```
   ADD LOCALNSDNN: SUBRANGE=HOME_USER, CORRECTTYPE=DNN_CORRECTION, SST=1, SD="010101", DNN="dnn5glan01", DNNPLCY=Default_DNN_preferred, DISFAILPLCY=STANDARD_MODEL, DESC="5GLAN_DNN_Correction";
   ```
4. 配置对端SMF实例支持的DNN。可以基于DNN选择SMF。

   ```
   ADD PNFDNN: INDEX=5, NFINSTANCEID="SMF_Instance_1", DNN="dnn5glan01";
   ```
5. 配置对端SMF实例支持的切片。可以基于切片选择SMF。复用已有切片时，不需要重复配置。

   ```
   ADD PNFNS: INDEX=5, NFINSTANCEID="SMF_Instance_1", SST=1, SD="010101";
   ```

配置SMF数据

+ **ADD PNFNS**命令存在多条时，“INDEX”不能重复。
+ **ADD PNFDNN**命令存在多条时，“INDEX”不能重复。
+ **ADD PNFDNN**命令中的“PNFNSINDEX”取值与**ADD PNFNS**命令定义的“INDEX”参数值一致。

1. 检查5G LAN License项是否开启。

   //显示信息中存在“LKV2SALANSM01”控制项时，说明已开启5G LAN License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```

   //显示信息中存在“LKV2CUFMN01”控制项时，说明已开启5G LAN SMF-UPF Fullmesh License。

   ```
   DSP LICENSE: DSPBBOM=CONTROLITEM;
   ```
2. 配置SMF 5G LAN全局参数。

   //配置支持建立5G LAN会话。

   ```
   SET SMFFUNC: NGLANSWITCH=Support;
   ```

   //配置对5G LAN UPF的选择机制。

   ```
   SET UPSELECTFLAG: NGLANUPFSELSW=LOCALABILITY;
   ```

   //配置5G LAN关键信元。

   ```
   SET PFCPPVTEXT: FEATURE=NGLAN,SWITCH=ENABLE;
   ```
3. 配置5G LAN使用的切片和专用DNN信息。

   //配置SMF支持的切片信息。可以复用已有切片，复用已有切片时，不需要执行如下配置。可通过**LST PLMNNS**查询。


配置UPF数据

企业侧交换机与UPF之间建立VXLAN隧道的场景，两个VXLAN交换机是堆叠组网或M-LAG组网时，两个VXLAN交换机都是只需要提供一个VTEP IP。DCGW与UPF之间建立VXLAN隧道的场景，一对DCGW是M-LAG组网，一对DCGW只需要提供一个VTEP IP。

两个UPF是负荷分担容灾关系，且仅对接一对企业侧VXLAN交换机/DCGW时，支持两个UPF之间建立VXLAN隧道，用于实现跨UPF的终端互访。两个UPF之间建立VXLAN隧道时，需要分别在两个UPF上进行配置，VTEP IP是另一UPF的VXLAN隧道IP，如下以配置一个UPF为例。

不同的5G LAN组共用VTEP，一个5G LAN组对应一个VNI。如图9所示，VNI为5010和VNI为5011的两个VNI共用VTEP。

**图9** VXLAN隧道数据规划图

4. 配置VXLAN隧道。

   //配置VXLAN逻辑接口，作为隧道本端。冷备容灾场景，两个UPF上的本端地址必须不同。
   + DCGW与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”必须设置为“\_public\_”。

     不存在绑定VPN实例为“\_public\_”的外联口及路由数据时，可参考N6接口配置用于传输UPF和DCGW之间VXLAN报文的外联口IP、路由数据（VPN实例为“\_public\_”）。

     ```
     ADD LOGICINF: NAME="vxlanif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="_public_";
     ```
   + 企业侧交换机与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”按需配置。此处以“VRF\_LocalDN01”为例。

     此处以复用N6接口的VPN实例为例。如使用独立的VPN实例，则需要执行**ADD VPNINST**命令及参考N6接口配置对应的外联口IP、路由数据（外联口绑定的VPN与VXLAN接口绑定的VPN相同）。

     ```
     ADD LOGICINF: NAME="vxlanif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VRF_LocalDN01";
     ```

   + DCGW与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”必须设置为“\_public\_”。
   + 企业侧交换机与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”按需配置。
   + UPF与另一UPF之间建立VXLAN隧道的场景，复用UPF与DCGW/企业侧交换机之间建立VXLAN隧道的vxlanif接口。

   //配置VXLAN隧道组。

   + 路径中的网络设备和对端都支持心跳消息（PING报文）时，请执行：

     ```
     ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0", HEARTBEAT=ENABLE, TIMETHRESHOLD=6, HEARTSUCCLIMIT=3, HEARTFAILLIMIT=3, TIMEOUT=2;
     ```
   + 路径中的网络设备或对端不支持心跳消息（PING报文）时，请执行：

     ```

     ```

   //配置VXLAN隧道远端端点（VTEP：VXLAN交换机/DCGW），VTEPIPV4为远端端点IP，来源于企业侧交换机/DCGW的VXLAN隧道端点IP地址。
