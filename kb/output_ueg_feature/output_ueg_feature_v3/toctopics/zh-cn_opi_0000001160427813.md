# 配置UPF公共数据

## 操作场景

本场景用于在UPF上配置DNN和APN相关的基础数据。

## 必备事项

前提条件

无

## 任务示例

任务描述

配置UPF的DNN、APN基础数据，两个UPF均需配置。

* 专线（仅连接，地市共享式）：支持风筝S
* 专网（仅连接，园区入驻式）：支持风筝S、风筝M、风筝L
* 云网（连接+计算，共享式+入驻式）：支持风筝S、风筝M

脚本

1. 配置APN信息。

   ```
   ADD VPNINST: VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD APN:APN="APN1",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_001",HASVPNIPV6=ENABLE,VPNINSTANCEIPV6="VRF_N6_Local_2B_001",PSEUDOACTSWITCH=INHERIT;
   ```
2. 配置APN单通检测。

   ```
   SET APNSGLPASS:APN="APN1",SWITCH=PF_ACT_ENABLE;
   ```
3. 配置APN地址分配属性。

   ```
   SET APNADDRESSATTR:APN="APN1",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE,FRAMEDROUTE=DISABLE,ANTISPOOFINGDL=ENABLE,ANTISPOOFINGUL=ENABLE,IPTYPEFORDUALIP=IPV4V6,SINGLEADDRCAUSE=1,CPCTRL=DISABLE,IPV6RAMTUSW=DISABLE,IPV6RALIFETIME=65535,HOSTROUTEIP=ENABLE;
   ```
4. 配置地址池（当终端地址是静态签约、网段路由时）。

   //风筝S

   ```
   ADD POOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, IPVERSION=IPV4, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD POOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, IPVERSION=IPV6, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ```

   //风筝M或风筝L

   ```
   ADD UPPOOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, IPVERSION=IPV4, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD UPPOOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, IPVERSION=IPV6, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ```
5. 配置地址池（当终端地址是动态分配时）。

   //风筝S

   ```
   ADD POOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=LOCAL, IPVERSION=IPV4, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD POOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=LOCAL, IPVERSION=IPV6, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ```

   //风筝M或风筝L

   ```
   ADD UPPOOL: POOLNAME="pool_ipv4_APN1", POOLTYPE=LOCAL, IPVERSION=IPV4, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ADD UPPOOL: POOLNAME="pool_ipv6_APN1", POOLTYPE=LOCAL, IPVERSION=IPV6, HASVPN=ENABLE, VPNINSTANCE="VRF_N6_Local_2B_001";
   ```
6. 配置本地地址池里的地址段。

   ```
   ADD SECTION: POOLNAME="pool_ipv4_APN1", SECTIONNUM=1, IPVERSION=IPV4, V4STARTIP="10.1.1.0", V4ENDIP="10.1.1.225";
   ADD SECTION: POOLNAME="pool_ipv6_APN1", SECTIONNUM=2, IPVERSION=IPV6, V6PREFIXSTART="fc00:1::1", V6PREFIXEND="fc00:1::1111", V6PREFIXLENGTH=64;
   ```
7. 配置地址池组。

   ```
   ADD POOLGROUP: POOLGRPNAME="pgrp_APN1", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
   ```
8. 配置绑定地址池到地址池组。

   ```
   ADD POOLBINDGROUP:POOLGROUPNAME="pgrp_APN1", POOLNAME="pool_ipv4_APN1";
   ADD POOLBINDGROUP:POOLGROUPNAME="pgrp_APN1", POOLNAME="pool_ipv6_APN1";
   ```
9. 配置APN与地址池组映射关系。

   ```
   ADD POOLGRPMAP: MAPPINGNAME="mapping_APN1", APN="APN1", POOLGROUPNAME="pgrp_APN1";
   ```
10. 配置地址分配规则。

    ```
    SET APNIPALLOCRULE: APN="APN1", ALLOCATTR=LOCAL, FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE, IPV6ALLOCATTR=LOCAL, IPV6FIRSTRULESW=ENABLE, IPV6FIRSTRULE=APN-1&LOCATION-0&SMF-0, IPV6SECRULESW=DISABLE, IPV6THIRDRULESW=DISABLE;
    ```
11. 配置添加Tcp Mss配置。

    ```
    ADD TCPMSS: APN="APN1", ROAMINGTYPE=HOME-1&ROAMING-1&VISITING-1, V4TCPMSSVALUE=1380, V6TCPMSSVALUE=1300;
    ```
12. 配置开启终端互访（可选）。

    ```
    SET APNUEMUTACC: APN="APN1", INNERAPNS=DISABLE, INTERAPNS=DISABLE;
    ```
13. 配置计费、PCC等相关业务。

    业务发放后，还需要配置计费、PCC等相关业务配置，请参考“风筝S/M/L（UEG）> 业务配置”章节。
