# 配置N4接口

## 操作场景

用于配置总部园区UEG-L SMF网元的N4接口数据。

对于容灾的两个UEG-L而言，此配置没有区别，仅以一个UEG-L做配置举例。

## 必备事项

前提条件

无。

数据

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD LOGICIP** | IP地址类型（IPVERSION） | IPV4 | 全网规划 | 配置N4接口的逻辑IP地址。 |
|  | IPv4地址（LOGICIPV4） | 10.26.0.5 |  |  |
|  | VPN实例名称（VPNINSTNAME） | VRF\_PS\_N4 | 全网规划 |  |
|  | 描述（DESC） | FOR N4 Interface | 本端规划 |  |
| **ADD CPNODE** | CP节点索引（CPNODEINDEX） | 0 | 全网规划 | 配置控制面SMF的端点信息。 |
|  | CP节点ID类型（NODEIDTYPE） | CpIPv4 | 全网规划 | - |
|  | CP节点IPv4地址（NODEIDIPV4VALUE） | 10.26.0.5 | 全网规划 |  |
|  | CP节点功能（CPFUNCTION） | 0 | 全网规划 | 当前产品暂未实现协议定义的负载控制等相关功能，建议配置为0即可。 |
| **ADD CPPOINT** | CP端点索引（CPPOINTINDEX） | 0 | 本端规划 | - |
|  | CP节点索引（CPNODEINDEX） | 0 | 固定取值 | 一个CP端点归属于一个CP节点，一个CP节点下可以有多个CP端点。该参数用于指定这个CP端点所属的CP节点，只支持CP节点索引固定取值为0。  已通过**ADD CPNODE**配置，可以通过**LST CPNODE**查询。 |
|  | IP类型（IPVERSION） | IPV4 | 本端规划 | - |
|  | IPv4地址（IPV4） | 10.26.0.5 | 已配置数据中获取 | CP节点中的IPv4地址和**ADD CPNODE**中的IPv4地址需要相同。 |
|  | VPN名称（VPNNAME） | VRF\_PS\_N4 | 全网规划 | - |

## 任务示例

任务描述

配置总部园区UEG-L SMF网元的N4接口数据。

脚本

1. 配置N4接口的IP地址。

   ```
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.26.0.5", VPNINSTNAME="VRF_PS_N4", DESC="FOR N4 Interface";
   ```
2. 配置控制面节点实例。

   ```
   ADD CPNODE: CPNODEINDEX=0, NODEIDTYPE=CpIPv4, NODEIDIPV4VALUE="10.26.0.5", CPFUNCTION=0;
   ADD CPPOINT:CPPOINTINDEX=0,CPNODEINDEX=0,IPVERSION=IPv4,IPV4="10.26.0.5", VPNNAME="VRF_PS_N4";
   ```
