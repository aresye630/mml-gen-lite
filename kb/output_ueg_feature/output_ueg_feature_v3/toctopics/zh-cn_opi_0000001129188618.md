# 直连DCGW（交换机）

## 操作场景

开通到园区的业务时，UPF到园区采用VPN专线，直连DCGW，通过BGP over 静态路由+BFD互通的方式进行组网连接。对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例，组网规划如图1所示。

* 本页面适用于**机架服务器-ARM**直连DCGW**。**
* **刀片式服务器2U-x86**直连DCGW的配置需参见直连CE/PE。

## 任务示例

任务描述

* 开通到园区业务时，UPF到园区采用VPN专线，直连DCGW。
* UPF到DCGW采用BGP over 静态路由+BFD组网。
* 对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```
3. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001",VRFDESCRIPTION="N6";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni;
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni;
   ```
4. 配置Loopback接口IP。用于建立BGP邻居。

   ```
   ADD INTERFACE:IFNAME="LoopBack8"; 
   ADD IPBINDVPN:IFNAME="LoopBack8",VRFNAME="VRF_N6_Local_2B_001"; 
   ADD IFIPV4ADDRESS:IFNAME="LoopBack8",IFIPADDR="192.168.225.138",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
   SET IFIPV6ENABLE: IFNAME="Loopback8", ENABLEFLAG=TRUE;
   ADD IFIPV6ADDRESS:IFNAME="Loopback8",IPV6ADDRESS="FC00::225:138",PREFIXLEN=128;
   ```
5. 配置BGP VPN实例。

   ```
   ADD BGPVRF: VRFNAME="VRF_N6_Local_2B_001", DEFAULTAFTYPE=noaf;
   ```
6. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

   ```
   ADD BGPVRFAF: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2, ROUTERID="192.168.225.138";
   ADD BGPVRFAF: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2, ROUTERID="192.168.225.138";
   ```
7. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

   ```
   ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.8", REMOTEAS="60002", LOCALIFADDR="192.168.225.138", LOCALIFNAME="Loopback8", EBGPMAXHOP=10; 
   ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.8", REMOTEAS="60002", LOCALIFADDR="192.168.225.138", LOCALIFNAME="Loopback8", EBGPMAXHOP=10;
   ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:8", REMOTEAS="60002", LOCALIFADDR="FC00::225:138", LOCALIFNAME="Loopback8", EBGPMAXHOP=10; 
   ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:8", REMOTEAS="60002", LOCALIFADDR="FC00::225:138", LOCALIFNAME="Loopback8", EBGPMAXHOP=10;
   ```
8. （UPF负荷分担场景下）配置BGP引入wlr路由。

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
   ```
9. （GRE路由冗余隧道场景下）配置BGP引入wlr路由。

   ```
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=TRUE, MED=0;
   ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=TRUE, MED=0;
   ```
10. 配置主接口的管理状态为up。

    ```
    MOD INTERFACE: IFNAME="Ethernet64/0/6", IFADMINSTATUS=up;
    MOD INTERFACE: IFNAME="Ethernet64/0/7", IFADMINSTATUS=up;
    ```
11. 配置Eth-trunk接口及Eth-trunk子接口，当静态地址路由冗余场景下，需要单独为两个UPF之间的GRE隧道规划子接口相关配置。

    ```
    ADD INTERFACE:IFNAME="Eth-trunk2"; 
    MOD TRUNKIF:IFNAME="Eth-Trunk2",WORKMODE=Manual; 
    ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/6"; 
    ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/7"; 
    ADD INTERFACE:IFNAME="Eth-trunk2.1";
    ```
12. 接口绑定VPN。

    ```
    ADD IPBINDVPN: IFNAME="Eth-trunk2.1", VRFNAME="VRF_N6_Local_2B_001";
    ```
13. 在以太网子接口上关联VLAN ID。

    ```
    ADD ETHSUBIF: IFNAME="Eth-trunk2.1", VLANTYPEVID=104;
    ```
14. 配置外联口IPv4地址。

    ```
    ADD IFIPV4ADDRESS: IFNAME="Eth-trunk2.1", IFIPADDR="192.168.85.2", SUBNETMASK="255.255.255.248", ADDRTYPE=main;
    ```
15. 配置IPv6使能。

    ```
    SET IFIPV6ENABLE: IFNAME="Eth-trunk2.1", ENABLEFLAG=TRUE;
    ```
16. 配置外联口IPv6地址。

    ```
    ADD IFIPV6ADDRESS:IFNAME="Eth-trunk2.1",IPV6ADDRESS="FC00::40C2",PREFIXLEN=123;
    ```
17. 新建静态BFD会话。

    ```
    ADD BFDSESSION: SESSNAME="N6if_1_1",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.85.1",LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_N6_Local_2B_001",LOCALDISCR=137,IFNAME="Eth-trunk2.1";
    ADD BFDSESSION: SESSNAME="N6if_IPv6_1",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_N6_Local_2B_001",LOCALDISCR=637,IFNAME="Eth-trunk2.1",DESTADDR6="FC00::40C1";
    ```
18. 配置静态路由数据。

    ```
    ADD SRROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4unicast,PREFIX="192.168.79.8",MASKLENGTH=32,DESTVRFNAME="VRF_N6_Local_2B_001",NEXTHOP="192.168.85.1",IFNAME="Eth-trunk2.1",SESSIONNAME="N6if_1_1";
    ADD SRROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4unicast,PREFIX="192.168.78.8",MASKLENGTH=32,DESTVRFNAME="VRF_N6_Local_2B_001",NEXTHOP="192.168.85.1",IFNAME="Eth-trunk2.1",SESSIONNAME="N6if_1_1";
    ADD SRROUTE6:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6unicast,PREFIX="FC00::79:8",MASKLENGTH=128,DESTVRFNAME="VRF_N6_Local_2B_001",NEXTHOP="FC00::40C1",IFNAME="Eth-trunk2.1",SESSIONNAME="N6if_IPv6_1";
    ADD SRROUTE6:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6unicast,PREFIX="FC00::78:8",MASKLENGTH=128,DESTVRFNAME="VRF_N6_Local_2B_001",NEXTHOP="FC00::40C1",IFNAME="Eth-trunk2.1",SESSIONNAME="N6if_IPv6_1";
    ```
