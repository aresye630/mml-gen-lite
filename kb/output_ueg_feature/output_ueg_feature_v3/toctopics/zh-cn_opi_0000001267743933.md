# 配置AMF数据

## 操作场景

本场景用于在AMF上配置切片相关的业务数据。

## 对系统的影响

无。

## 必备事项

前提条件

无。

## 任务示例

任务描述

在AMF上完成切片业务数据配置、APN纠正配置和对端SMF实例支持的DNN及切片。

脚本

1. 配置PLMN支持的切片。复用已有切片时，不需要重复配置。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="010101";
   ```
2. 配置AMF切片信息。复用已有切片时，不需要重复配置。

   ```
   ADD NFNS: NFTYPE=NfAMF, NSIDX=1;
   ```
3. 配置AMF对5G LAN切片下的DNN纠正。如现网已涉及DNN纠正功能（可通过**LST LOCALNSDNN**查询），则需要执行如下配置；否则，请跳过如下配置。

   //用户请求APN与签约APN不匹配时，优先纠正为签约数据中的Default DNN，如果未签约Default DNN，则纠正为dnn5glan01。

   ```
   ADD LOCALNSDNN: SUBRANGE=HOME_USER, CORRECTTYPE=DNN_CORRECTION, SST=1, SD="010101", DNN="dnn5glan01", DNNPLCY=Default_DNN_preferred, DISFAILPLCY=STANDARD_MODEL, DESC="5GLAN_DNN_Correction";
   ```
4. 配置对端SMF实例支持的DNN。可以基于DNN选择SMF。

   ```
   ADD PNFDNN: INDEX=5, NFINSTANCEID="SMF_Instance_1", DNN="dnn5glan01";
   ```
5. 配置对端SMF实例支持的切片。可以基于切片选择SMF。复用已有切片时，不需要重复配置。

   ```
   ADD PNFNS: INDEX=5, NFINSTANCEID="SMF_Instance_1", SST=1, SD="010101";
   ```
