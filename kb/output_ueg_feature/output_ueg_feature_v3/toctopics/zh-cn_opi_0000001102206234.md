# 配置切片业务数据（UPF）

## 操作场景

本场景用于在UPF上配置切片相关的业务数据。

## 对系统的影响

无。

## 必备事项

前提条件

无。

数据

**表1** UPF切片业务数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SNSSAI** | 切片/服务类型（SST） | 1 | 全网规划 | 配置UPF支持的切片。 |
|  | 切片区分码（SD） | 131313 | 全网规划 |  |
| **ADD SNSSAIUPINTF** | 切片/服务类型（SST） | 1 | 全网规划 | 配置切片和逻辑接口的绑定关系。   * 仅当需要支持N3接口隔离时需要配置。 * 参数“N3LOGICINF”不能为缺省N3口：n3if1/1/0。 |
|  | 切片区分码（SD） | 131313 | 全网规划 |  |
|  | N3逻辑接口名称（N3LOGICINF） | N3IF1/1/1 | 全网规划 |  |
| **LCK NF** | NF锁定状态开关（LOCKSWITCH） | DISABLE | 本端规划 | 当配置UPF锁定状态时，需执行此命令解锁UPF。 |

## 任务示例

任务描述

在UPF上完成切片业务数据配置。

脚本

1. 配置切片信息。

   ```
   ADD SNSSAI: SST=1, SD="131313";
   ```
2. （可选）配置切片和N3接口绑定。

   ```
   ADD SNSSAIUPINTF: SST=1, SD="131313", N3LOGICINF="N3IF1/1/1";
   ```
3. （可选）配置UPF解锁状态。

   ```
   LCK NF: LOCKSWITCH=DISABLE;
   ```
