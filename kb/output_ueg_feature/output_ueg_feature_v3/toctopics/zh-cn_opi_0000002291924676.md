# 配置终端二次鉴权（风筝S，通过AAA灵活调整5G LAN组ID）

## 操作场景

基于AAA服务器实现5G LAN组ID的灵活调整时，依赖二次鉴权流程。

如图1所示，SMF与AAA不能直接互通，需经由UPF中转二次鉴权消息的场景，需要配置本页面。

**图1** 非直连方式组网示意

## 必备事项

前提条件

* 二次鉴权消息经由UPF中转时，还需申请并加载License控制项“LKV3G5SAFT01 终端二次鉴权”。
* 已完成N6外联口及路由配置，UPF通过该N6外联口与AAA互通。

数据

当SMF上与AAA互通的Gi接口绑定的VPN实例，与 UPF上与AAA互通的N6接口绑定的VPN实例不一致时，需要规划表1中的数据，否则不需要规划。

**表1** 网络实例数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD NETWORKINSTVPNMAP** | 网络实例名称（NETWORKINSTANCE） | VRF\_AAA | 从对端获取 | SMF上与AAA互通的Gi接口绑定的VPN实例。 |
|  | 绑定VPN（HASVPN） | ENABLE | 本端规划 | 固定取值。 |
|  | VPN实例名（VPNINSTANCE） | VRF\_LocalDN | 本端规划 | UPF上与AAA互通的N6接口绑定的VPN实例。 |

**表2** 冲突IP数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD CONFLICTIP** | 地址池名称（POOLNAME） | ippool01 | 已配置数据中获取 | AAA服务器IP与UPF上某个IP地址池中的IP地址冲突时需要配置。  配置后，该IP不会再分配给用户。 |
|  | 冲突IPv4地址（IPADDRESS） | 10.168.10.1 | 从对端获取 |  |

## 任务示例

任务描述

在UPF上开启终端二次鉴权功能。该举例场景如下：

* 以SMF上与AAA互通的Gi接口绑定的VPN实例，与UPF上与AAA互通的N6接口绑定的VPN实例不一致为例。
* 以AAA服务器IP与UPF上地址池存在冲突为例。

脚本

//开启终端二次鉴权的License开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5SAFT01", SWITCH=ENABLE;
```

//配置网络实例数据。

```
ADD NETWORKINSTVPNMAP: NETWORKINSTANCE="VRF_AAA", HASVPN=ENABLE, VPNINSTANCE="VRF_LocalDN", HASVPNIPV6=DISABLE;
```

//配置冲突IP数据。

```
ADD CONFLICTIP: POOLNAME="ippool01", IPADDRESS="10.168.10.1";
```
