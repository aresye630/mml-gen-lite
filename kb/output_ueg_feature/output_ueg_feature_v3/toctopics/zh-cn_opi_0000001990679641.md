# 配置计费消息缓存（融合计费）

## 操作场景

本指导描述融合计费场景计费消息缓存功能的相关配置过程。

融合计费场景中，当主备NCG/CHF(OCS)均故障时，为避免用户体验变差，UNC(GGSN/PGW-C/SMF)可以采用不做配额管理的计费方式，允许用户继续使用业务，并缓存计费信息；随着NCG/CHF(OCS)的恢复，UNC(GGSN/PGW-C/SMF)可以将缓存的计费信息回放到对应的NCG/CHF(OCS)。

此功能为定制能力，要求对端NCG/CHF(OCS)为华为公司NCG。

## 必备事项

前提条件

* 请仔细阅读融合计费原理。
* 完成加载License。
* 已完成融合计费模板创建。

## 操作步骤

1. 配置当NCG/CHF(OCS)故障，UNC(GGSN/PGW-C/SMF)放通业务，不进行配额管理和配额上报；配置当NCG/CHF(OCS)故障恢复后重建计费会话功能。

   如果在配置（可选）配置异常返回码动作时已经配置了如下内容，则此步骤可以跳过：

   * 当NCG/CHF(OCS)故障，UNC(GGSN/PGW-C/SMF)放通业务；当NCG/CHF(OCS)故障恢复后重建计费会话功能：**SET FAILHANDLING**命令的“FHACTION”参数为“CONTINUE”，“UPDCONTTERM”参数值为“ENABLE”，“CNVCHGRECOVER”参数值为“ENABLE”。
   * UNC(GGSN/PGW-C/SMF)收到NCG/CHF(OCS)的PDU级异常返回码时的动作为failover或者continue：**MOD PDUSCACT**命令的“SCACT”参数值为“FAILOVER”或者“CONTINUE”。

   **SET FAILHANDLING**
2. 配置当UNC(GGSN/PGW-C/SMF)收到NCG/CHF(OCS)的PDU级异常返回码时的动作。

   如果在配置（可选）配置异常返回码动作时已经配置了如下内容，则此步骤可以跳过：

   * 当NCG/CHF(OCS)故障，UNC(GGSN/PGW-C/SMF)放通业务；当NCG/CHF(OCS)故障恢复后重建计费会话功能：**SET FAILHANDLING**命令的“FHACTION”参数为“CONTINUE”，“UPDCONTTERM”参数值为“ENABLE”，“CNVCHGRECOVER”参数值为“ENABLE”。
   * UNC(GGSN/PGW-C/SMF)收到NCG/CHF(OCS)的PDU级异常返回码时的动作为failover或者continue：**MOD PDUSCACT**命令的“SCACT”参数值为“FAILOVER”或者“CONTINUE”。

   **ADD PDUSCACT**
3. 配置计费消息缓存功能。

   **SET N40MSGSTG**
4. 配置计费消息缓存期间的trigger。

   **SET STGTRIGGER**
5. 配置由SMF生成ChargingDataRef。

   **SET CNVRGDCHGPARA**
6. 配置缓存话单文件的超期时长。

   **SET CDRSTORAGECTRL**
7. 配置融合计费**“ALM-81025 话单缓存”**告警上报的控制参数。

   ****SET STGALARMCTRL****

   * **SET STGALARMCTRL**命令的“ALMTHD”参数控制UNC(GGSN/PGW-C/SMF)上报**“ALM-81025 话单缓存”**告警的缓存话单文件占用空间阈值。缓存话单文件超过该阈值时，上报告警；缓存话单全部被回放后，清除告警。
   * **SET STGALARMCTRL**命令的“MONITORTIME”参数控制告警监控时长，当UNC(GGSN/PGW-C/SMF)检查到缓存话单文件存在且不超过占用空间阈值时，超过告警监控时长后，UNC(GGSN/PGW-C/SMF)上报**“ALM-81025 话单缓存”**告警。建议该参数配置为**SET N40MSGSTG**命令配置的“REPLAYINTERVAL”的2倍以上。

     如果“MONITORTIME”参数配置为0，则告警监控时长受软参**DWORD507**控制，该软参用于控制扫描硬盘上缓存话单文件的周期。
8. 配置N4接口计费消息相关控制参数。当阈值配置过小，比如流量阈值较低，会导致UPF在N4接口频繁上报计费消息，当NCG/CHF(OCS)性能不足响应较慢时，会导致UNC(GGSN/PGW-C/SMF)的N4接口上报消息堆积，超过最大可缓存的消息规格，会话被去激活。

   ****SET N4CHGMSGCTRL****

## 任务示例

任务描述

配置主备NCG/CHF(OCS)故障后，UNC(GGSN/PGW-C/SMF)缓存计费消息，待NCG/CHF(OCS)恢复，回放计费信息并重建计费会话。

脚本

//配置当NCG/CHF(OCS)故障，UNC(GGSN/PGW-C/SMF)放通业务，不进行配额管理和配额上报；配置当NCG/CHF(OCS)故障恢复后重建计费会话功能。

```
SET FAILHANDLING: CCTMPLTNAME="cct-test", FHACTION=CONTINUE, TXTIMER=5, UPDCONTTERM=ENABLE, CNVCHGRECOVER=ENABLE, RECOVERINTERVAL=5;
```

//配置当UNC(GGSN/PGW-C/SMF)收到NCG/CHF(OCS)的PDU级异常返回码时的动作。

```
MOD PDUSCACT: CCTMPLTNAME="cct-test", CODETYPE=VALUE, STATUSCODE=502, SCACT=FAILOVER;
```

//配置计费消息缓存功能。

```
SET N40MSGSTG: STGSWITCH=ENABLE, REPLAYINTERVAL=30, REPLAYRATE=500;
```

//配置计费消息缓存期间的trigger。

```
SET STGTRIGGER:TIMELIMIT=IMMEDIATE, PDUTIMELIMIT=30, VOLUMELIMIT=IMMEDIATE, PDUVOLUMELIMIT=500, RATCHG=IMMEDIATE, SRVNDCHG=IMMEDIATE, ULCHG=DEFERRED, QOSCHG=DEFERRED;
```

//配置由SMF生成ChargingDataRef。

```
SET CNVRGDCHGPARA: CHGDATAREFGEN=SMF;
```

//配置缓存话单文件的超期时长。

```
SET CDRSTORAGECTRL:CDREXPIREDAY=2,CDREXPIREWEEK=4;
```

//配置融合计费话单缓存告警上报的控制参数。

```
SET STGALARMCTRL: ALMTHD=5120, MONITORTIME=60;
```

//配置N4接口计费消息相关控制参数消息缓存池扩展功能使能、缓存池满的动作为用户转离线。

```
SET N4CHGMSGCTRL: MSGCACHEEPDSW=ENABLE, CACHEFULLACT=CONTINUE;
```
