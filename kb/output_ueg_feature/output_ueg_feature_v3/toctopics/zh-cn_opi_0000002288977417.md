# 配置上报APN属性（有语音业务+相同DNN）

## 操作场景

当总部园区和各子园区采用相同语音DNN和数据DNN业务接入时，如果总部园区UPF向周边网元发送信息携带用户签约DNN，则需要执行本章节配置；如果向周边网元发送信息携带真实DNN，则无需执行本操作。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET APNREPORTATTR** | APN名称（APN） | Real.data.APN1 | 已配置数据中获取 | 映射后真实DNN名称。 |
|  | 上报给头增强的APN名（HEADERENRICH） | REQUESTED | 全网规划 | UPF向周边网元发送信息使用映射前DNN。 |
|  | 上报给话统的APN名（PERFORMANCE） | REQUESTED | 全网规划 |  |
|  | 业务报表使用的APN名（SERVICEREPORT） | REQUESTED | 全网规划 |  |

## 任务示例

任务描述

总部园区和子园区数据业务DNN为data.APN1，语音业务DNN为IMS，总部园区用户使用data.APN1接入SMF后，将data.APN1映射为真实DNN（Real.data.APN1）后，SMF将数据业务分发到总部UPF。总部UPF向周边设备发送信息时携带DNN为映射前DNN，即data.APN1。

脚本

1. 配置上报APN属性。

   ```
   SET APNREPORTATTR: APN="Real.data.APN1", HEADERENRICH=REQUESTED, PERFORMANCE=REQUESTED, SERVICEREPORT=REQUESTED;
   ```
