# 修改网元基本信息

## 操作场景

软件安装阶段，已完成网元名称和浮动IP地址的配置。在生产预安装场景或者现网使用时，如果需要修改，可参考本页面调整登录网元OM Portal的网元名称和浮动IP地址。

网元名称、浮动IP地址需要与网管上配置的名称和IP地址属性一致，如果本端修改了网元名称和浮动IP地址，需要在网管上同步修改该网元的名称和IP地址属性。

## 对系统的影响

* 修改网元浮动IP地址后，OM Portal将会退出，需要使用新浮动IP地址重新登录。
* 修改网元浮动IP地址后，网管与网元之间的连接将中断，需要在网管上重新对接网元。

## 必备事项

前提条件

* 已经确认现网规划的网元名称、浮动IP地址与网元生产预安装的预设参数值不同。
* 已登录网元OM Portal。

  硬件服务器可通过192.168.6.10登录：

  将调测PC连接到服务器的级联网口，并将调测PC的IP配置为192.168.6.10/24同网段的IP，登录网元OM Portal。例如将调测PC的IP配置为192.168.6.11/24，通过https://192.168.6.10:31943登录OM Portal。
* 已从网管侧获取网管登录信息。

## 操作步骤

1. 登录网元OM Portal，选择“应用管理 > MML”。
2. 执行**SET INSTPARA**设置安装参数。

   该命令执行后可能会导致OM Portal断链以及网管断链，执行后需重新登录OM Portal，并重新对接网管。该命令若执行不当，会导致所有业务中断。请确认参数正确后，再执行此操作。

   ```
   SET INSTPARA: PARATYPE=OMPORT, SERVERNAME="paas-192-168-2-3", PORTTYPE=1, PORTNAME="bond1", SUBPORT="eth60:eth61", BONDMODE=4, LACPRATE=1, HASHPOLICY=1;
   ```

   * 当单板故障或现网网络调整时，可通过该命令设置安装参数。
   * 执行完此命令之后，需要重启对应的单板。
3. 执行**MOD ME**将网元名称修改为现网规划的网元名称，脚本示例如下。

   ```
   MOD ME: MEID=0, MENAME="APP";
   ```
4. 执行**LST NETWORK**检查VLANID是否配置正确。
   * VLANID配置正确 ，执行6。
   * VLANID配置不正确，执行5。
5. 执行**MOD NETWORK**修改系统网络的网卡VLANID。

   ```
   MOD NETWORK: IPTYPE=IPV4, NWNAME="OM", VLANID=2002;
   ```

   修改扩展域VLANID后需重启节点生效。
6. 执行**LST OMIP**查询系统是否已配置物理IP地址且符合现网规划的IP地址。
7. 执行**SET OMIP**设置系统IP地址。

   * 如果系统已配置物理IP地址且符合现网规划的IP地址，执行**SET OMIP**将浮动IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1";
     ```

     若DeployTool工具安装参数“OM IP模式”配置为“精简”，则浮动IP地址与物理IP地址取值相同，无需执行该步骤。

   * 如果系统未配置物理IP地址或已配置的物理IP地址与现网规划的IP地址不符，执行**SET OMIP**将浮动IP地址、物理IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1", OMHOST1IPV4="10.145.27.174", OMHOST2IPV4="10.145.27.175";
     ```

     若DeployTool工具安装参数“OM IP模式”配置为“精简”，则需配置浮动IP地址与物理IP地址取值相同，否则命令执行失败，返回错误码。
8. 如果已在网管上创建网元，则需要登录网管客户端，修改网管上网元名称、IP地址属性为现网规划的信息。

   操作方法请参见MAE产品文档，“操作与维护 > MAE-Access操作与维护 > 拓扑管理 > 维护拓扑对象 > 修改拓扑对象”。
