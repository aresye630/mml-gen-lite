# 配置5G业务故障恢复后的用户迁移

* 操作场景
* 必备事项
* 操作步骤
* 验证方法

## 操作场景

在负荷分担容灾模式下，为避免故障恢复后两套UEG上网络负载不均衡的情况，需要参考本页面进行用户迁移操作。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

两套UEG已完成负荷分担容灾模式配置。

数据

**假设需要将部分用户从UEG2迁移到UEG****1，****如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例  （DC2） | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****MOD AMFINFO**** | AMF实例名称（AMFINSTANCENAME） | AMF\_Instance\_0 | 已配置数据中获取 | 进行用户迁移的UEG中的AMF实例名称。 |
|  | 相对容量（CAPACITY） | 0 | 本端规划 | 在启动迁移任务前，需将此参数设置为0，避免新用户接入。 |
| ****MOD CPNFPROFILE**** | NF实例名称（NFINSTANCENAME） | AMF\_Instance\_0 | 已配置数据中获取 | 进行用户迁移的UEG中的AMF实例名称。 |
|  | 容量（CAPACITY） | 0 | 本端规划 | 在启动迁移任务前，需将此参数设置为0。 |
| ****STR OFFLOADAMF**** | 迁移类型（TYPE） | RATE | 本端规划 | 根据实际情况进行配置，两套UEG上需达到负载均衡。 |
|  | 迁移比率（%）（OFFLOADRATE） | 50 | 本端规划 |  |
|  | 目标AMF名称（TAMF） | AMF1 | 已配置数据中获取 | UEG1中的AMF名称，可通过****LST AMFINFO****查询。 |
| ****MOD AMFINFO**** | AMF实例名称（AMFINSTANCENAME） | AMF\_Instance\_0 | 已配置数据中获取 | 进行用户迁移的UEG中的AMF实例名称。 |
|  | 相对容量（CAPACITY） | 255 | 本端规划 | 当迁移任务结束后，需要恢复AMF原相对容量。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 修改需要迁移的AMF的相对容量设置为0。

   ```
   MOD AMFINFO: AMFINSTANCENAME="AMF_Instance_0", CAPACITY=0;
   ```
3. 修改需要迁移的AMF实例信息。

   ```
   MOD CPNFPROFILE: NFINSTANCENAME="AMF_Instance_0", CAPACITY=0;
   ```
4. 对需要迁移的AMF下发启动迁移命令，向目标AMF迁移50%用户。

   ```
   STR OFFLOADAMF: TYPE=RATE, OFFLOADRATE=50, TAMF="AMF1";
   ```
5. 当迁移任务结束后，恢复迁移的AMF原相对容量。

   ```
   MOD AMFINFO: AMFINSTANCENAME="AMF_Instance_0", CAPACITY=255;
   ```

## 验证方法

1. 进入“MML命令行-UEG”窗口。
2. 执行**LST AMFINFO**、****LST CPNFPROFILE****命令，查询AMF信息中的“相对容量”是否正确。
   * 如果查询到AMF信息中的“相对容量”与规划一致，请执行3。
   * 如果查询到AMF信息中的“相对容量”与规划不一致，请执行2、3重新配置，并再次验证。
3. 执行****DSP OFFLOADAMF****命令，查询AMF用户迁移进度信息。
   * 如果查询到AMF用户迁移进度信息中的“迁移状态”为“迁移中”时，则等待“剩余时间(分钟)”结束后再次执行该步骤。
   * 如果查询到AMF用户迁移进度信息中的“迁移状态”为“已结束”时，则迁移任务已结束。
   * 如果未查询到AMF用户迁移进度信息中的“迁移状态”，请参考配置5G业务故障恢复后的用户迁移重新配置，并再次验证，仍不能解决请执行4。
4. 收集归纳所有信息并联系华为技术支持解决。
