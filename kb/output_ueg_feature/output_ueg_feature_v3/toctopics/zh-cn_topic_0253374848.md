# 配置NTS数字证书

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

NTS服务作为HTTPS客户端，当需要通过Https与SOAP/SMPP/CMPP/SMTP通知服务器对接时，需要加载CA证书。NTS服务使用到的证书详见表1。

**表1** NTS数字证书说明

| 数字证书 | 关联场景 | 证书类型 | 私钥文件 | 私钥密码 | 证书应用场景 |
| --- | --- | --- | --- | --- | --- |
| NTS客户端证书 | 通用SOAP通知链路客户端证书（UPCF\_NTS\_certForComSOAP） | CA证书：由对端SOAP服务器提供 | - | - | 用于通过Https与SOAP通知服务器对接需要加载。 |
|  | NTS SMPP通知链路客户端证书（UPCF\_NTS\_certForSMPP） | CA证书：由对端SMPP服务器提供 | - | - | 用于通过Https与SMPP通知服务器对接需要加载。 |
|  | NTS CMPP通知链路客户端证书（UPCF\_NTS\_certForCMPP） | CA证书：由对端CMPP服务器提供 | - | - | 用于通过Https与CMPP通知服务器对接需要加载。 |
|  | NTS SMTP通知链路客户端证书（UPCF\_NTS\_certForSMTP） | CA证书：由对端SMTP服务器提供 | - | - | 用于通过Https与SMTP通知服务器对接需要加载。 |

* 华为证书获取路径：https://support.huawei.com/ >技术支持>产品支持>云核心网>Mobile Packet Core>5G Convergent Data>UPCF>UPCF。在“产品软件”界面选择对应的UPCF版本，“设备证书”、“私钥文件”和提供给对端设备的“CA证书”均存放在UPCF\_Cert\_Tools.zip里，UPCF\_Cert\_Tools.zip包含在UPCF\_2\*.\*\*\*.\*\*\*.\*\*\*\_Tools.zip当中。
* 华为证书仅用于测试环境，不能用于商用环境。商用环境请替换为商用证书，并通过OM Portal的证书管理功能删除华为证书。若客户将华为证书用于商用环境，则需承担相关安全风险和责任。为了提高系统安全性，需定期更新证书和密钥。
* 加载CA证书时，需要加载完整的CA证书链。
* 加载CRL文件时，需要加载完整的CA链签发的CRL文件，即CA证书链中每个CA证书签发的CRL文件都要加载。

#### 必备事项

**前提条件**

* 证书文件已经经过授权和认证。
* 已经从运营商获取对端SOAP/SMPP/CMPP/SMTP服务器CA证书。

**数据**

当需要上传、更新CA证书时，已获取根证书*如\*\*\*.der*。

#### 操作步骤

* 在CSP界面配置新的数字证书后，对于服务端数字证书，需要重启对应的服务；对于客户端数字证书，需要重启对应的链路，新的证书才能生效。
* 重启操作属于产品慎用操作，如果操作不当，会引发业务中断等严重后果。请操作员在华为技术支持指导下谨慎操作。

配置NTS数字证书需加载CA证书，并将证书关联到证书应用场景下。

1. 登录OM Portal，选择**安全** > **证书管理** > **证书与证书集管理**，单击“上传证书”。
2. 选择“CA证书”，加载NTS数字证书，界面配置参数如表2所示。详细操作请参见证书与证书集管理。

   **表2** 配置CA证书

   | 界面参数 | 取值示例 | 取值原则 |
   | --- | --- | --- |
   | 证书名称 | NTS\_CACert | 自行命名，保证系统内命名唯一即可。 |
   | CA证书 | \*\*\*.der | 上传的CA证书文由待对接的SOAP/CMPP/SMPP/SMTP通知服务器提供。 |

3. 上传证书完成后，选择“证书应用场景关联”，为证书场景关联加载的CA证书。详细的关联证书操作请参见证书应用场景关联。
   * “通用SOAP通知链路客户端证书”需关联2中加载的SOAP通知服务器提供的CA证书。
   * “NTS SMPP通知链路客户端证书”需关联2中加载的SMPP通知服务器提供的CA证书。
   * “NTS CMPP通知链路客户端证书”需关联2中加载的CMPP通知服务器提供的CA证书。
   * “NTS SMTP通知链路客户端证书”需关联2中加载的SMTP通知服务器提供的CA证书。
4. 执行**ADD PMSTLSCFG**命令，增加TLS配置信息。

   ```
   ADD PMSTLSCFG: TLSCFGID=TLS配置ID, TLSCFGNAME="TLS配置名称", PROTOCOLVER=协议版本, PROTOCOLVER=强加密套件;
   ```
5. 执行**ADD NTSPEERLINKCFG**命令，配置NTS客户端数字证书。
   * 选择“本地角色”为“SOAPClient(SOAP客户端)”，“WSDL文件”为“Common(Common)”进行配置。

     ```
     ADD NTSPEERLINKCFG: LINKID="链路ID", PEERID="对端服务器ID", LOCALROLE=SOAPClient, WSDL=Common, IPVER=IPV4, LOCALIP="本端IP地址",PEERIP="对端IP地址", PEERPORT="对端端口", SOAPURL="SOAP服务器URL", DEFLINK=YES,CERTSCENE=UPCF_NTS_certForComSOAP, DESCRIPTION="描述", TLSCFGID=TLS配置ID;
     ```
   * 选择“本地角色”为“CMPPClient(CMPP客户端)”，“是否支持加密”配置为“YES(YES)”进行配置。

     ```
     ADD NTSPEERLINKCFG: LINKID="链路ID", PEERID="对端服务器ID", LOCALROLE=CMPPClient, IPVER=IPV4, LOCALIP="本端IP地址",PEERIP="对端IP地址", PEERPORT="对端端口", USRNAME="用户名", PASSWD="密码", CFM="确认密码", ISENCRYPTED=YES,CERTSCENE=UPCF_NTS_certForCMPP, DESCRIPTION="描述", TLSCFGID=TLS配置ID;
     ```
   * 选择“本地角色”为“SMPPClient(SMPP客户端)”，“是否支持加密”配置为“YES(YES)”进行配置。

     ```
     ADD NTSPEERLINKCFG: LINKID="链路ID", PEERID="对端服务器ID", LOCALROLE=SMPPClient, IPVER=IPV4, LOCALIP="本端IP地址",PEERIP="对端IP地址", PEERPORT="对端端口", SENDER="发送人", USRNAME="用户名", PASSWD="密码", CFM="确认密码", ISENCRYPTED=YES,CERTSCENE=UPCF_NTS_certForSMPP, DESCRIPTION="描述", TLSCFGID=TLS配置ID;
     ```
   * 选择“本地角色”为“SMTPClient(SMTP客户端)”，“是否支持加密”配置为“YES(YES)”进行配置。

     ```
     ADD NTSPEERLINKCFG: LINKID="链路ID", PEERID="对端服务器ID", LOCALROLE=SMTPClient, IPVER=IPV4, LOCALIP="本端IP地址",PEERIP="对端IP地址", PEERPORT="对端端口", SENDER="发送人", USRNAME="用户名", PASSWD="密码", CFM="确认密码", ISENCRYPTED=YES,CERTSCENE=UPCF_NTS_certForSMTP, DESCRIPTION="描述", TLSCFGID=TLS配置ID;
     ```
