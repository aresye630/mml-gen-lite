# 配置SMF数据

## 操作场景

本操作用于指导在SMF侧开通5G LAN相关业务，完成相关配置。

## 必备事项

前提条件

* 操作人员已了解本功能的原理。
* 已完成加载License，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

数据

**表1** 5G LAN数据规划

| 类别 | 参数 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET SMFFUNC** | 支持是否建立5G LAN会话（NGLANSWITCH） | Support | 本端规划 | 配置开启5G LAN功能开关。 |
| **SET UPSELECTFLAG** | 5G LAN UPF选择开关（NGLANUPFSELSW） | LOCALABILITY | 本端规划 | 配置对5G LAN UPF的选择机制。  SMF根据本地配置判断UPF是否支持5G LAN功能时，设置为“LOCALABILITY”。  设置为“LOCALABILITY”后，SMF根据**ADD UPNODE**/**MOD UPNODE**中的“NGLANSW”配置判断某个UPF实例是否支持5G LAN功能，当“NGLANSW”值为“ENABLE”，则说明该UPF实例支持5G LAN功能。 |
| **SET PFCPPVTEXT** | 特性名称（FEATURE） | NGLAN | 本端规划 | 配置5G LAN关键信元。  涉及的关键信元请参见**SET PFCPPVTEXT**。 |
|  | 私有信元携带开关（SWITCH） | ENABLE | 本端规划 |  |
| ****ADD NFNS**** | NF类型（NFTYPE） | NfSMF | 本端规划 | 增加SMF支持的网络切片。 |
|  | 网络切片索引（NSIDX） | 0 | 本端规划 |  |
| **MOD UPNODE** | UPF实例名称（NFINSTANCENAME） | upf\_instance\_1 | 全网规划 | 配置对端UPF支持5G LAN。  说明：  UPF实例与**ADD PNFPROFILE**命令中的“NF实例标识”参数取值保持一致。 |
|  | 是否支持5G LAN（NGLANSW） | ENABLE | 本端规划 |  |

## 任务示例

任务描述

某行业用户签约了5G LAN业务，该用户涉及多个分支机构，地理范围跨越了两个UPF（UPF\_Instance0和UPF\_Instance1）的范围，两个分支机构的终端基于两个UPF的N6接口实现数据转发互通。

脚本

1. 配置SMF 5G LAN全局参数。

   //配置支持建立5G LAN会话。

   ```
   SET SMFFUNC: NGLANSWITCH=Support;
   ```

   //配置对5G LAN UPF的选择机制。

   ```
   SET UPSELECTFLAG: NGLANUPFSELSW=LOCALABILITY;
   ```

   //配置5G LAN关键信元。

   ```
   SET PFCPPVTEXT: FEATURE=NGLAN,SWITCH=ENABLE;
   ```
2. 配置5G LAN使用的切片和专用DNN信息。

   //配置SMF支持的切片信息。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="010101";
   ADD NFNS: NFTYPE=NfSMF, NSIDX=1;
   ```

   //配置SMF支持的DNN（APN）信息。
   * 园区SMF（UEG-M/UEG-L）时：

     ```
     ADD CPAPN:APN="dnn5glan01";
     ```
   * 中心SMF（UEG-S/UEG-M）时：

     ```
     ADD APN:APN="dnn5glan01";
     ```

   //配置网络切片支持DNN。

   ```
   ADD NSDNN: NSIDX=1, DNN="dnn5glan01";
   ```
3. 配置支持5G LAN的SMF对端UPF实例信息。

   //配置对端UPF节点信息。同一个UPF对端只能配置一条ADD PNFPROFILE记录。如已配置对应的UPF节点信息，则不需要重复配置。

   ```
   ADD UPNODE: NFINSTANCENAME="upf_instance_1", LOCATION=Central, UPFUNCTION=None, VPNNAME="VRF_CN";
   ```

   ```
   ADD PNFPROFILE:NFINSTANCEID="upf_instance_1", NFTYPE=NfUPF, FQDN="5glan01.upf", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.5.52.2", PORT=8805;
   ```

   //配置对端UPF支持的切片信息。如复用已有的对端UPF的切片信息，则不需要重复配置。推荐复用。

   ```
   ADD PNFNS:INDEX=1, NFINSTANCEID="upf_instance_1", SST=1, SD="010101";
   ```

   //配置对端UPF支持的DNN信息。

   ```
   ADD PNFDNN:INDEX=0, NFINSTANCEID="upf_instance_1", DNN="dnn5glan01", PNFNSINDEX=1;
   ```

   //配置对端UPF支持5G LAN功能。

   ```
   MOD UPNODE: NFINSTANCENAME="upf_instance_1", NGLANSW=ENABLE;
   ```

   //配置对端UPF的位置区域信息。如已配置的对端UPF的位置区域信息包含5G LAN业务对应的基站的TAI范围，则不需要重复配置。一个UPF服务区域可以绑定多个TAI范围，如利旧UPF服务区，且需要增加TAI范围，则可只通过**ADD UPAREABINDN2TAI**命令增加TAI范围。

   ```
   ADD UPAREA:AREANAME="area01", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="area01", N2BEGINTAI="46008000000", N2ENDTAI="46008FFFFFF";
   ```

   //配置对端UPF的SMF服务区域信息。如利旧UPF服务区（area01），则不需要重复配置。一个UPF实例可以和多个UPF服务区绑定。

   ```
   ADD PNFSMFSERAREA: NFINSTANCEID="upf_instance_1", SMFSERVINGAREA="area01";
   ```
4. 配置5G LAN业务的缺省PCC规则。
   * 园区SMF（UEG-M/UEG-L）时：

     //配置离线计费策略。此处仅用于举例，如已配置离线计费策略且“CCVALUE”为“0x0800”、RG与计费网元上5G LAN业务的RG值一致，则不需要重复配置。推荐复用。

     ```
     ADD CPURR: URRNAME="5glan_urr", URRID=2222, USAGERPTMODE=OFFLINE, OFFCOMPOUNDTYPE=ONLYRG, RG=2222, OFFMETERINGTYPE=VOLUME, N40AGESW=ENABLE;
     ADD CPURRGROUP: URRGROUPNAME="5glan_urrgroup", UPURRNAME1="5glan_urr", DOWNURRNAME1="5glan_urr";
     ADD CPPCCPOLICYGRP: PCCPOLICYGRPNM="pccpolicy_group", URRGROUPNAME="5glan_urrgroup", FUPSESSIONEXC=DISABLE;
     ADD CHARGEMETHOD: CHARGECHARACT=SPECIFIC_VALUE, CCVALUE="0x0800", ONLINE=DISABLE, OFFLINE=ENABLE, CONVERGED=ENABLE, RGAPPLIED=OFFLINERGONLY, QBCSW=ENABLE;
     ```

     //配置5G LAN业务的APN与用户模板组绑定。

     ```
     ADD USRPROFGROUP: USERPROFGNAME="profilegroupfglan"; 
     ADD CPUSERPROFILE: USERPROFILENAME="testuserprofilename", UPTYPE=PCC;
     ADD UPBINDUPG: USERPROFGNAME="profilegroupfglan", UPBINDTYPE=DEFAULT, USERPROFILENAME="testuserprofilename", LOCALPCCSELECT=INHERIT;
     ADD APNUSRPROFG: APN="dnn5glan01", USERPROFGNAME="profilegroupfglan";
     ```

     //配置规则和用户模板绑定。“POLICYNAME”采用**ADD CPPCCPOLICYGRP**命令中的“PCCPOLICYGRPNM”参数值。

     ```
     ADD CPRULE:RULENAME="rule_test", POLICYTYPE=PCC, PRIORITY=65535, POLICYNAME="pccpolicy_group";
     ADD CPRULEBINDING: USERPROFILENAME="testuserprofilename", RULENAME="rule_test", POLICYTYPE=PCC;
     ```
   * 中心SMF（UEG-S/UEG-M）时：

     //配置离线计费策略。此处仅用于举例，如已配置离线计费策略且“CCVALUE”为“0x0800”、RG与计费网元上5G LAN业务的RG值一致，则不需要重复配置。推荐复用。

     ```
     ADD URR: URRNAME="5glan_urr", URRID=2222, USAGERPTMODE=OFFLINE, OFFCOMPOUNDTYPE=ONLYRG, RG=2222, OFFMETERINGTYPE=VOLUME, N40AGESW=ENABLE;
     ADD URRGROUP: URRGROUPNAME="5glan_urrgroup", UPURRNAME1="5glan_urr", DOWNURRNAME1="5glan_urr";
     ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccpolicy_group", URRGROUPNAME="5glan_urrgroup", FUPSESSIONEXC=DISABLE;
     ADD CHARGEMETHOD: CHARGECHARACT=SPECIFIC_VALUE, CCVALUE="0x0800", ONLINE=DISABLE, OFFLINE=ENABLE, CONVERGED=ENABLE, RGAPPLIED=OFFLINERGONLY, QBCSW=ENABLE;
     ```

     //配置5G LAN业务的APN与用户模板组绑定。

     ```
     ADD USRPROFGROUP: USERPROFGNAME="profilegroupfglan"; 
     ADD USERPROFILE: USERPROFILENAME="testuserprofilename", UPTYPE=PCC;
     ADD UPBINDUPG: USERPROFGNAME="profilegroupfglan", UPBINDTYPE=DEFAULT, USERPROFILENAME="testuserprofilename", LOCALPCCSELECT=INHERIT;
     ADD APNUSRPROFG: APN="dnn5glan01", USERPROFGNAME="profilegroupfglan";
     ```

     //配置规则和用户模板绑定。“POLICYNAME”采用**ADD PCCPOLICYGRP**命令中的“PCCPOLICYGRPNM”参数值。

     ```
     ADD RULE:RULENAME="rule_test", POLICYTYPE=PCC, PRIORITY=65535, POLICYNAME="pccpolicy_group";
     ADD RULEBINDING: USERPROFILENAME="testuserprofilename", RULENAME="rule_test", POLICYTYPE=PCC;
     ```
