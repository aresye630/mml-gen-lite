# 配置NSSF数据

## 操作场景

同一区域内，不是所有AMF都支持5G LAN业务切片时，需配置NSSF数据。

初始AMF收到5G LAN业务报文后，如本AMF未配置5G LAN业务切片信息，则可通过与NSSF交互实现AMF重定向，即将5G LAN业务报文重定向到配置了5G LAN业务切片信息的AMF上。

## 对系统的影响

无。

无。

## 任务示例

任务描述

同一区域内，不是所有AMF都支持5G LAN业务切片时，在NSSF上完成5G LAN切片业务数据配置。

脚本

1. 在NSSF上增加5G LAN业务切片信息。

   ```
   ADD CFGSNSSAI: INDEX=1, MCC="123", MNC="03", SST=1, SD="010101", ISACTIVE=TRUE, DESC="5G_LAN";
   ```
2. 在跟踪区域码分组中增加跟踪区域码。

   ```
   ADD TACGROUPINNSSF: INDEX=1, TACGROUPNAME="1-010101", TACSTART="290100", TACEND="290110";
   ```
3. 将切片、AMF、TAC组进行绑定。

   ```
   ADD AMFSETID: INDEX=1, SST=1, SD="010101", MCC="123", MNC="03", REGIONID="08", AMFSETID="088", TACGROUPNAME="1-010101";
   ```
