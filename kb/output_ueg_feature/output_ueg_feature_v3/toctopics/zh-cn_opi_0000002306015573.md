# 配置5G LAN层二环路消除（SMF）

## 操作场景

同一5G LAN终端组成员之间或5G LAN终端组的成员和数据网络中的应用之间进行以太通信时，可通过部署5G LAN层二环路消除，避免二层环路的危害。

## 必备事项

前提条件

已在SMF上完成5G LAN基本配置。

数据

**表1** SMF上环路检测及消除相关数据（层二5G LAN）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD GRPNGLANFUNC** | 5G LAN组ID（GROUPID） | 000003e9-460-08-02 | 全网规划 | 与UPF上**ADD NGVNINSTANCE**命令定义的VNINSTANCE一致。 |
|  | 环路检测开关（LDRSW） | Support | 本端规划 | UPF上的同一5G LAN组开启环路检测时，SMF上该参数设置为“Support”；否则设置为“NotSupport”。 |

## 操作步骤

1. 执行**LST GRPNGLANFUNC**命令，查看指定5G LAN组的“环路检测开关（LDRSW）”参数值。

   * “环路检测开关（LDRSW）”参数值为“Support”，已开启环路检测开关，配置结束。

   * “环路检测开关（LDRSW）”参数值为“NotSupport”，请执行2。

   * 未查询到该5G LAN组的信息，请执行3。
2. 执行**MOD GRPNGLANFUNC**命令，开启环路检测开关。
3. 执行**ADD GRPNGLANFUNC**命令，开启环路检测开关。

## 任务示例

任务描述

开启5G LAN层二环路检测功能。

脚本

//使用**MOD GRPNGLANFUNC**命令，开启环路检测开关。

```
MOD GRPNGLANFUNC: GROUPID="000003e9-460-08-02", LDRSW=SUPPORT;
```

//使用**ADD GRPNGLANFUNC**命令，开启环路检测开关。

```
ADD GRPNGLANFUNC: GROUPID="000003e9-460-08-02", LDRSW=SUPPORT;
```
