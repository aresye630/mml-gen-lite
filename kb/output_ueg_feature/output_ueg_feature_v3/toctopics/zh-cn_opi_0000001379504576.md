# 关闭UEG计费功能

## 操作场景

风筝L模式下，不支持计费功能，需要在UEG的SMF上关闭计费功能开关。若已在UEG初始配置 > 配置SMF服务化接口数据（N10/N11/N7）中执行关闭计费功能开关，则无需执行本任务。

## 必备事项

前提条件

具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

数据

| 类别 | 参数名称 | DC1取值样例 | DC2取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **SET CHARGECTRL** | 归属地在线用户计费控制（HOMEONLINE） | DISABLE |  | 固定取值 | 风筝L模式下不进行计费，需要关闭计费开关。 |
|  | 归属地融合用户计费控制（HOMECONVERGED） | DISABLE |  |  |  |
|  | 归属地离线用户计费控制（HOMEOFFLINE） | DISABLE |  |  |  |
|  | 拜访地在线用户计费控制（VISITONLINE） | DISABLE |  |  |  |
|  | 拜访地融合用户计费控制（VISITCONVERGED） | DISABLE |  |  |  |
|  | 拜访地离线用户计费控制（VISITOFFLINE） | DISABLE |  |  |  |
|  | 漫游在线用户计费控制（ROAMONLINE） | DISABLE |  |  |  |
|  | 漫游融合用户计费控制（ROAMCONVERGED） | DISABLE |  |  |  |
|  | 漫游离线用户计费控制（ROAMOFFLINE） | DISABLE |  |  |  |

## 操作步骤

1. **关闭计费功能**

   园区风筝方案不进行计费，需要关闭计费功能。

   1. 关闭计费功能。

      ```
      SET CHARGECTRL: HOMEONLINE=DISABLE, HOMECONVERGED=DISABLE, HOMEOFFLINE=DISABLE, VISITONLINE=DISABLE, VISITCONVERGED=DISABLE, ROAMONLINE=DISABLE, ROAMOFFLINE=DISABLE, ROAMCONVERGED=DISABLE;
      ```
