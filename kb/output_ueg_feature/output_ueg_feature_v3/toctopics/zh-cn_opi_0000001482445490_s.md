# 卸载NAT服务

## 操作场景

当运营商不需要NAT服务或NAT服务动态上线失败时，可以单独卸载NAT服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线NAT服务。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| UEG OM Portal帐户 | IP地址 | 192.168.1.1  操作维护接口IP，即“VNFD模板”中的“MNG\_IP”或“MNG\_IPv6”参数。 | 本端规划 |
|  | 端口号 | 31943 | 本端规划 |
|  | 用户名 | admin | 本端规划 |
|  | 密码 | Changeme\_123 | 本端规划 |

## 操作步骤

1. 登录OM Portal。
2. 执行**SET FWSOFTPARA**命令，开启Service Fabric软参。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=1;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为1。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为1，请执行后续步骤。如果软参值不是1，请联系华为技术支持。
3. 选择“应用管理> 应用部署”，在应用部署下找到ueg-nat的堆栈名称，单击“操作”列的“删除”。
4. 在弹出的警告对话框中，单击“确定”。当ueg-nat堆栈从“应用部署”界面消失，即完成NAT的卸载。
5. 执行命令，确认POD已下线。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natom-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natgcpssgc20-pod";
   ```

   回显为“查询Pod不存在”。
6. 执行**SET FWSOFTPARA**命令，关闭Service Fabric软参。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=0;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为0。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为0，请执行后续步骤。如果软参值不是0，请联系华为技术支持。
