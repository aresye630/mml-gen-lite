# 配置GRE专线数据（内外双层GRE隧道场景）

## 操作场景

UPF到CPE采用GRE专线，FM CPE至主备CPE也建立GRE隧道时，单UPF场景下数据规划如图2所示，主备UPF容灾组网场景下数据规划如图1所示。本操作指导数据准备以单UPF场景下配置GRE专线为例进行数据准备及配置示例，主备UPF场景下，因主备UPF的GRE隧道至CPE网关1和CPE网关2的目的地址均相同，需在备UPF上将主UPF所配置的GRE隧道数据信息重复配置即可（备UPF的GRE隧道源地址需修改为备UPF所规划的隧道源IP地址）。

* 该场景仅支持IPv4地址池。
* 现网实际部署时请参考图1进行容灾场景的数据规划及部署，单UPF场景仅用于辅助理解本章节配置原理。

## 必备事项

前提条件

* UPF侧已完成N6口的路由相关配置，可参考“配置独立VPN专线”章节配置。
* UEG与企业侧路由器之间的路由互通配置已完成。
* CPE1与CPE网关之间的内层GRE隧道已由数通侧工程师配置完成。

数据

本页面配置中的字体颜色（黑色和蓝色）区分不同类别的参数：

* 黑色：黑色字体标识的参数为固化参数。固化参数是指推荐使用的参数取值，使用时一般不允许改变。如需改变，请联系研发技术支持做好充分评估。
* **蓝色加粗**：蓝色字体标识的参数为需要从客户侧收集的参数。这类参数是指在工程设计、部署前需要向客户收集的参数。

## 任务示例

任务描述

配置单UPF到园区的GRE专线，地址池单栈IPv4。

主备UPF场景下，因主备UPF的GRE隧道至CPE网关1和CPE网关2的目的地址均相同，需在备UPF上将主UPF所配置的GRE隧道数据信息重复配置即可（备UPF的GRE隧道源地址需修改为备UPF所规划的隧道源IP地址）。

脚本

1. 配置Tunnel内层使用的VPN信息。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001";
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_001";
   ```
2. 配置LoopBack接口。

   对于共享式MEC场景：GRE隧道承载在公共VPN上，一般选择N6\_Local或者N6\_Internet，依据园区与公网互通情况而定。以**VRF\_N6\_Local\_2B**举例。

   ```
   ADD INTERFACE: IFNAME="LoopBack10", IFADMINSTATUS=up;
   ADD IPBINDVPN: IFNAME="LoopBack10", VRFNAME="VRF_N6_Local_2B";
   ADD IFIPV4ADDRESS: IFNAME="LoopBack10", IFIPADDR="10.14.255.12", SUBNETMASK="255.255.255.255";
   ```
3. 配置GRE Tunnel。

   ```
   ADD INTERFACE: IFNAME="Tunnel111", IFMTU=1500;
   ADD INTERFACE: IFNAME="Tunnel112", IFMTU=1500;
   ADD GRETUNNEL: TNLNAME="Tunnel111", SRCTYPE=if_name, DSTIPADDR="10.11.255.12", TNLTYPE=gre, SRCIFNAME="LoopBack10", DSTVPNNAME="VRF_N6_Local_2B", KEEPALVEN=TRUE;
   ADD GRETUNNEL: TNLNAME="Tunnel112", SRCTYPE=if_name, DSTIPADDR="10.11.255.13", TNLTYPE=gre, SRCIFNAME="LoopBack10", DSTVPNNAME="VRF_N6_Local_2B", KEEPALVEN=TRUE;
   ADD IPBINDVPN: IFNAME="Tunnel111", VRFNAME="VRF_N6_Local_2B_001";
   ADD IPBINDVPN: IFNAME="Tunnel112", VRFNAME="VRF_N6_Local_2B_001";
   ADD IFIPV4ADDRESS: IFNAME="Tunnel111", IFIPADDR="172.16.255.1", SUBNETMASK="255.255.255.255";
   ADD IFIPV4ADDRESS: IFNAME="Tunnel112", IFIPADDR="172.16.255.2", SUBNETMASK="255.255.255.255";
   ```
4. 配置隧道间静态路由。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.13.255.12", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001" ,DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel111";
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="10.13.255.13", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001" ,DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Tunnel112";
   ```
5. 配置发布LoopBack路由。

   ```
   ADD NETWORKROUTE: VRFNAME="VRF_N6_Local_2B", AFTYPE=ipv4uni, NETWORKADDRESS="10.14.255.12", MASKLEN=32;
   ```
