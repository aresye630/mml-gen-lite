# 配置SMF/GW-C公共数据（有语音业务+相同DNN/APN）

## 操作场景

当企业部署语音业务时，且所有园区仅采用2个DNN/APN接入业务，一个DNN/APN用于接入业务数据，一个DNN/APN用于接入语音数据，参考本章节进行SMF/GW-C与UPF/GW-U对接公共数据配置。此处仅以一套UEG-L的SMF/GW-C对接一个子园区主备UEG-S为例。新增子园区请参考本章节中对接子园区UPF/GW-U部分的配置。

## 必备事项

前提条件

无。

## 任务示例

任务描述

用于配置SMF/GW-C与UPF/GW-U对接公共数据。其中

* 总部园区和子园区数据业务DNN/APN为data.APN1。
* 总部园区和子园区语音业务DNN/APN为IMS，且SMF均需要转发到总部园区UPF/GW-U处理业务。
* 总部园区UPF实例为UPF\_Instance\_0。
* 子园区2个UPF实例为主备热备，对于SMF/GW-C仅呈现一个UPF实例UPF\_Instance\_A0。

* SMF/GW-C基于DNN/APN+TAC选择UPF实例。其中总部园区和子园区PLMN相同，为12301。

脚本

1. 配置用户面节点实例。配置Profile实例。

   //对接总部园区UPF/GW-U配置

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf00.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.125.11", PORT=8080;
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_A0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upfa00.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080;
   ```
2. 配置用户面节点的位置特征和分流能力。

   //对接总部园区UPF/GW-U配置

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_0", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_PS_N4";
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_A0", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_PS_N4";
   ```
3. 总部园区部署语音业务后，配置总部园区数据业务DNN/APN（data.APN1）配置为虚拟DNN/APN，将data.APN1映射为Real.data.APN1。
   1. 增加5G位置区映射信息。

      //对接总部园区UPF/GW-U配置

      ```
      ADD CPTACGROUP: TACGROUPNAME="UPAREA1", TACTYPE=N2Tac;
      ADD CPN2TACID: TACSECNUM=0, TACSTARTID="0x000001", TACENDID="0x000002", TACGROUPNAME="UPAREA1";
      ```
   2. 增加4G位置区映射信息。

      //对接总部园区UPF/GW-U配置

      ```
      ADD CPTACGROUP: TACGROUPNAME="GWUAREA1", TACTYPE=S1Tac;
      ADD CPS1TACID:TACSECNUM=2,TACSTARTID="0x0000",TACENDID="0x0001",TACGROUPNAME="GWUAREA1";
      ```
   3. 使能虚拟APN映射功能。

      //对接总部园区UPF/GW-U配置，其中Real.data.APN1与data.APN1绑定的用户模板一致。

      ```
      ADD CPAPN: APN="Real.data.APN1";
      ADD APNUSRPROFG: APN="Real.data.APN1",USERPROFGNAME="data_apn1_userpro";
      MOD CPAPN: APN="data.APN1", VIRTUALAPN=ENABLE;
      ```
   4. 增加虚拟DNN/APN（data.APN1）映射策略，将data.APN1映射为Real.data.APN1。

      //对接总部园区UPF/GW-U配置

      ```
      ADD VIRTUALAPNRULE: VIRTUALAPN="data.APN1", MAPPINGTYPE=TAC_GROUP, MAPPINGVALUE="UPAREA1", REALAPN="Real.data.APN1";
      ADD VIRTUALAPNRULE: VIRTUALAPN="data.APN1", MAPPINGTYPE=TAC_GROUP, MAPPINGVALUE="GWUAREA1", REALAPN="Real.data.APN1";
      ```
   5. 增加默认虚拟DNN/APN（data.APN1）映射策略。

      //对接总部园区UPF/GW-U配置

      ```
      ADD VIRTUALAPNRULE: VIRTUALAPN="data.APN1", MAPPINGTYPE=VDEFAULT_APN, REALAPN="data.APN1";
      ```
4. 配置用户面节点支持的切片与DNN/APN信息。

   //对接总部园区UPF/GW-U配置

   ```
   ADD PNFNS: INDEX=2, NFINSTANCEID="UPF_Instance_0", SST=1, SD="010101"; 
   ADD PNFDNN:INDEX=5, NFINSTANCEID="UPF_Instance_0", DNN="Real.data.APN1", PNFNSINDEX=2; 
   ADD PNFDNN:INDEX=8, NFINSTANCEID="UPF_Instance_0", DNN="IMS", PNFNSINDEX=2;
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_A0", SST=1, SD="010101"; 
   ADD PNFDNN:INDEX=6, NFINSTANCEID="UPF_Instance_A0", DNN="data.APN1", PNFNSINDEX=3;
   ```
5. 配置映射后APN（Real.data.APN1）的上报属性。

   //对接总部园区UPF配置

   ```
   SET CPAPNREPORTATTR: APN="Real.data.APN1", AAAACCT=REQUESTED, AAAAUTH=REQUESTED, CG=REQUESTED, DIAMETERAAA=REQUESTED, OCS=REQUESTED, CHF=REQUESTED, PCRF=REQUESTED, PCF=REQUESTED, PERFORMANCE=REQUESTED, UPF=SERVICE;
   ```
6. 配置5G用户面节点的位置区信息，将位置区与TAI绑定。

   //对接总部园区UPF配置

   ```
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12301000001", N2ENDTAI="12301000002";
   ```

   //对接子园区UPF配置

   ```
   ADD UPAREA:AREANAME="UPAREA2", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA2", N2BEGINTAI="12301000003", N2ENDTAI="12301000004";
   ```
7. 配置5G用户面节点支持的为SMF提供服务区域的信息。

   //对接总部园区UPF配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA1";
   ```

   //对接子园区UPF配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A0", SMFSERVINGAREA="UPAREA2";
   ```
8. 配置4G用户面节点的位置区信息，将位置区与TAI绑定。

   //对接总部园区GW-U配置

   ```
   ADD UPAREA:AREANAME="GWUAREA1", AREATYPE=S1TAI;
   ADD UPAREABINDS1TAI:AREANAME="GWUAREA1", S1BEGINTAI="123010000", S1ENDTAI="123010001";
   ```

   //对接子园区GW-U配置

   ```
   ADD UPAREA:AREANAME="GWUAREA2", AREATYPE=S1TAI;
   ADD UPAREABINDS1TAI:AREANAME="GWUAREA2", S1BEGINTAI="123010002", S1ENDTAI="123010003";
   ```
9. 配置4G用户面节点支持的为GW-C提供服务区域的信息。

   //对接总部园区GW-U配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="GWUAREA1";
   ```

   //对接子园区GW-U配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A0", SMFSERVINGAREA="GWUAREA2";
   ```
10. 配置用户面与EPS的互通以及支持的PDU会话类型。

    //对接总部园区UPF/GW-U配置

    ```
    ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
    ```

    //对接子园区UPF/GW-U配置

    ```
    ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_A0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
    ```
