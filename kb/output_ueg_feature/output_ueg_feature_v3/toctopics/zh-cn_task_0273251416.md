# 修改PT数据库帐户密码

* 操作场景
* 对系统的影响
* 前提条件
* 操作步骤

#### 操作场景

* 在开局结束后，系统管理员必须及时修改PT数据库帐户的密码，确保系统安全。
* 在日常维护中，系统管理员需要定期修改PT数据库帐户的密码，确保系统安全。

#### 对系统的影响

直接登录PT数据库修改密码会导致系统不稳定或其他未知后果，必须在使用**MOD DBPWD**命令进行修改。

#### 前提条件

* 向系统管理员获取PT数据库用户的旧密码。
* 准备新密码。新密码必须满足**MOD DBPWD**命令参数“新密码”的配置原则和取值范围。

#### 操作步骤

1. 登录OM Portal，在“应用管理 > MML”菜单执行**MOD DBPWD**命令。
2. 选择需要修改的数据库帐号类型，并输入密码。

   帐号类型分为应用帐号和系统帐号：

   * 应用帐号：应用程序的数据库帐号，如“cgp”。

     修改“应用帐号”密码时不需要输入旧密码。
   * 系统帐号：数据库的系统帐号“sys”。

     修改“系统帐号”密码时需要输入旧密码，默认密码请参见CSP系统默认帐号。
