# 配置PMS数字证书

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

PMS作为HTTPS服务端，在完成网元部署和基础数据配置后，必须要配置PMS设备证书，保证UPCF Web UI功能正常使用。此外，当局点涉及使用PMS通过Https的SOAP链路对接POP等第三方服务时，需要进一步配置CA证书。

PMS服务使用到的华为证书详见表1。根据业务需求，若需要配置新的证书，可通过OM Portal页面进行配置和更新。

**表1** PMS数字证书说明

| 数字证书 | 关联场景 | 证书类型 | 私钥文件 | 私钥密码 | 证书应用场景 |
| --- | --- | --- | --- | --- | --- |
| PMS服务端证书 | PMS WEB服务端证书（UPCF\_PMS\_Lcert） | 设备证书：PMScert.pem | PMScert.key | 联系华为技术支持。 | 用于访问PMS服务，UPCF全新部署完成后，必须加载PMS设备证书。 |
|  | PM接口服务端证书（UPCF\_PMS\_certForPM） |  |  |  | 用于Https对接PM接口时，需要关联此场景。 |
|  | SCLI接口服务端证书（UPCF\_PMS\_certForSCLI） |  |  |  | 用于Https对接SCLI接口时，需要关联此场景。 |
| PMS客户端证书 | POP SOAP接口链路客户端证书（UPCF\_PMS\_certForPOPSOAP） | * 根CA：Huawei\_Equipment\_Root\_CA.der * 二级CA：Huawei Cloud Core Network Product CA.cer | - | - | 用于通过Https的SOAP链路对接POP等第三方服务时，需要关联此场景。 |

* 华为证书获取路径：https://support.huawei.com/ >技术支持>产品软件>云核心网>Mobile Packet Core>5G Packet Core>UEG>UEG。在“产品软件”界面选择对应的UEG版本，“设备证书”、“私钥文件”和提供给对端设备的“CA证书”均存放在UEG-Plus\_XXX\_Tools.zip中的UPCF\_Cert\_Tools.zip里。
* 华为证书仅用于测试环境，不能用于商用环境。商用环境请替换为商用证书，并通过OM Portal的证书管理功能删除华为证书。若客户将华为证书用于商用环境，则需承担相关安全风险和责任。为了提高系统安全性，需定期更新证书和密钥。
* 加载CA证书时，需要加载完整的CA证书链。
* 加载CRL文件时，需要加载完整的CA链签发的CRL文件，即CA证书链中每个CA证书签发的CRL文件都要加载。

#### 必备事项

**前提条件**

* 证书文件已经经过授权和认证。
* 若使用华为证书，证书密码已经通过华为技术工程师获取。
* 若使用运营商自身的证书，证书密码已经从运营商处获取。

**数据**

* 当需要上传、更新CA证书时，已获取根证书*如\*\*\*.der*。
* 当需要上传、更新设备证书时，已获取设备证书、私钥文件和私钥密码。例如：
  + 设备证书：*\*\*\*\*\*\*.pem*
  + 私钥文件：*\*\*\*.key*
  + 私钥密码：*\*\*\*\*\*\**

#### 操作步骤

* 在CSP界面配置新的数字证书后，对于服务端数字证书，需要重启对应的服务；对于客户端数字证书，需要重启对应的链路，新的证书才能生效。
* 重启操作属于产品慎用操作，如果操作不当，会引发业务中断等严重后果。请操作员在华为技术支持指导下谨慎操作。

**配置PMS服务端数字证书**

配置PMS服务端证书需加载设备证书：PMScert.pem，并根据所需的应用场景，将证书关联到对应的关联场景。

1. 登录CSP Portal界面，选择**安全** > **证书管理** > **证书与证书集管理**，点击上传证书。
2. 选择“设备证书”，加载PMS设备证书，界面配置参数如表2所示。详细操作请参见证书与证书集管理。

   **表2** 配置设备证书

   | 界面参数 | 取值示例 | 取值原则 |
   | --- | --- | --- |
   | 证书名称 | PMS\_DeviceCert | 自行命名，保证系统内命名唯一即可。 |
   | 设备证书 | PMScert.pem | 上传设备证书文件PMScert.pem，解压UPCF\_Cert\_Tools.zip，在PMS文件夹下获取。 |
   | 私钥文件 | PMScert.key | 上传私钥文件PMScert.key，解压UPCF\_Cert\_Tools.zip，在PMS文件夹下获取。 |
   | 私钥密码 | *\*\*\*\*\*\** | 联系华为技术支持。 |
3. 上传证书完成后，选择证书应用场景关联，基于各种应用场景，关联刚加载的PMS设备证书。详细的关联证书操作请参见证书应用场景关联。
   * **为证书场景“PMS WEB服务端证书”关联刚加载的PMS设备证书。**

     UPCF网元全新部署完成后，必须加载PMS设备证书，PMS Web UI才可基于Https正常登录。此证书场景必须关联PMS设备证书。
   * **为证书场景“****PM接口服务端证书****”关联刚加载的PMS设备证书。**

     用于Https对接PM接口时，需要关联此场景，否则无需进行关联。
   * **为证书场景“****SCLI接口服务端证书****”关联刚加载的PMS设备证书。**

     用于Https对接SCLI接口时，需要关联此场景，否则无需进行关联。
4. 执行**MOD PMSFUNC**命令，配置PMS服务端数字证书。
   * **关联****证书场景“PMS WEB服务端证书”****后，执行以下命令：**

     `MOD PMSFUNC: TYPE=Server, ITEMN=cert, CERTSCENE=UPCF_PMS_Lcert;`
   * **关联****证书场景“PM接口服务端证书”****后，执行以下命令，否则跳过此步骤：**

     ```
     MOD PMSFUNC: TYPE=Server, ITEMN=certForPM, CERTSCENE=UPCF_PMS_certForPM;
     ```
   * **关联****证书场景“****SCLI接口服务端证书****”****后，执行以下命令，****否则跳过此步骤****：**

     ```
     MOD PMSFUNC: TYPE=Server, ITEMN=certForSCLI, CERTSCENE=UPCF_PMS_certForSCLI;
     ```
5. 在CSP Portal界面选择“应用管理 > MML”，进入MML命令界面。选择UEG网元，执行如下命令，进行重启PMS服务。

   ```
   RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_PcfPms";
   ```
6. 复位服务后，等待4分钟左右，待服务重启生效，操作完成。

**配置PMS客户端数字证书**

当需要通过Https的SOAP链路对接POP等第三方服务时，才需要加载PMS客户端数字证书，否则无需执行本操作。

1. 登录CSP Portal界面，选择**安全** > **证书管理** > **证书与证书集管理**，点击上传证书。
2. 选择“CA证书”，加载CA证书，界面配置参数如表3所示。详细操作请参见证书与证书集管理。

   **表3** 配置CA证书

   | 界面参数 | 取值示例 | 取值原则 |
   | --- | --- | --- |
   | 证书名称 | PMS\_CACert | 自行命名，保证系统内命名唯一即可。 |
   | CA证书 | Huawei\_Equipment\_Root\_CA.der | 上传CA证书文件Huawei\_Equipment\_Root\_CA.der，解压UPCF\_Cert\_Tools.zip，在PMS文件夹下获取。 |
3. 上传证书完成后，选择证书应用场景关联，为证书场景“POP SOAP接口链路客户端证书”关联刚加载的PMS CA证书。详细的关联证书操作请参见证书应用场景关联。
4. 执行**ADD PMSTLSCFG**命令，增加TLS配置信息。

   ```
   ADD PMSTLSCFG: TLSCFGID=TLS配置ID, TLSCFGNAME="TLS配置名称", PROTOCOLVER=协议版本, PROTOCOLVER=强加密套件;
   ```
5. 执行**ADD PMSPEERLINKCFG**命令，配置PMS客户端数字证书。

   选择“本地角色”为“SOAPClient(SOAP客户端)”，“WSDL文件”为“POP(POP)”进行配置。

   ```
   ADD PMSPEERLINKCFG: LINKID=链路ID, PEERID=对端服务器ID, LOCALROLE=SOAPClient, WSDL=POP, PEERIP="对端IP地址", PEERPORT=对端端口, LOGONURL="认证服务器URL", CERTSCENE=UPCF_PMS_certForPOPSOAP, DESCRIPTION="描述", TLSCFGID=TLS配置ID;
   ```
