# 配置切片业务数据（AMF）

## 操作场景

本场景用于在AMF上配置切片相关的业务数据。

## 对系统的影响

无。

## 必备事项

前提条件

无。

数据

**表1** AMF切片业务数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD PLMNNS** | 网络切片索引（NSIDX） | 1 | 全网规划 | 配置切片的基本信息。其中，“NSIDX”不能重复且“PLMNIDX”由命令**LST NGSRVPLMN**查询。 |
|  | PLMN索引（PLMNIDX） | 0 | 已有配置中获取 |  |
|  | 切片业务类型（SST） | 1 | 全网规划 |  |
|  | 切片细分标识（SD） | 131313 | 全网规划 |  |
|  | 激活状态（STATE） | INACTIVE | 本端规划 |  |
| **ADD NFNS** | NF类型（NFTYPE） | NfAMF | 本端规划 | 配置AMF支持的切片。   * 参数“NFTYPE”固定取值为“NfAMF”。 * 参数“NSIDX”在**ADD PLMNS**的参数“NSIDX”中定义，此处引用。 |
|  | 网络切片索引（NSIDX） | 1 | 已有配置中获取 |  |

## 任务示例

任务描述

在AMF上完成切片业务数据配置：切片ID。

脚本

1. 配置PLMN支持的切片。

   ```
   ADD PLMNNS: NSIDX=1,PLMNIDX=0,SST=1,SD="131313",STATE=INACTIVE;
   ```
2. 配置AMF切片信息。

   ```
   ADD NFNS: NFTYPE=NfAMF, NSIDX=1;
   ```
