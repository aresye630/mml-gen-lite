# 在园区UEG上配置接入限制区域列表

## 操作场景

本操作指导介绍在园区UEG-L下配置接入限制区域列表（配置白名单），使得大网终端接入园区网络时，返回#15失败原因值，大网终端把当前TAI记录为禁止TAI，搜索同覆盖下的其他TAI接入，最终接入大网。

## 必备事项

前提条件

* 已完成加载License，对应的License项为“82206572 LKV2RRR02 区域漫游限制”。
* 详细原理请参考UEG产品文档中“**GWFD-020911 区域漫游限制**”特性。

## 任务示例

任务描述

5G场景下，运营商在核电园区部署了专网，跟踪区编码为010101-010102，园区2B终端只允许接入园区网络，大网拒绝接入。2B终端从属的用户组ID为888，IMSI前缀为123456，由园区UEG本地配置的接入限制区域控制大网终端的接入，拒绝原因值为#15 （No suitable cells in tracking area）。

脚本

//开启区域漫游限制功能开关。

```
SET LICENSESWITCH: LICITEM="LKV2RRR02", SWITCH=ENABLE;
```

//开启区域漫游限制功能增强开关。

```
SET NGMMFUNC: AREARSTENSW=ON;
```

//配置区域范围。

```
ADD AREACODE：AREACODE="nuclear power.area1";
ADD AREAMEM：AREACODE="nuclear power.area1",MCC="123", MNC="456", BGNTAC="010101", ENDTAC="010102";
```

//配置用户群组。

```
ADD NGUSRGRP：USRGRPID=888;
ADD NGUSRGRPMEM: USRGRPID=888, IMSIPRE="123456";
```

//UEG本地配置限制区域信息、控制模式（白名单）以及拒绝原因值。

```
ADD NGACCAREALST: AREARANGE=AREA_CODE, AREACODE="nuclear power.area1",  CTRLMODE=WHITELIST, SUBRANGE=USER_GROUP, SUBGRPID=888, REJCAUSE=15;
```

## 任务示例

任务描述

4G场景下，运营商在核电园区部署了专网，跟踪区编码为0x7603-0x7614，园区2B终端只允许接入园区网络，大网拒绝接入。2B终端从属的用户组ID为1，IMSI前缀为123456，由园区UEG本地配置的接入限制区域控制大网终端的接入，拒绝原因值为#15 （No suitable cells in tracking area）。

脚本

//开启区域漫游限制功能开关。

```
SET LICENSESWITCH: LICITEM="LKV2RRR02", SWITCH=ENABLE;
```

//配置区域范围。

```
ADD AREAGP: AREAID=1, AREAN="nuclear power";
ADD AREAGPMEM: AREAID=1, IDTYPE=TA, MCC="123", MNC="456", TAC="0x7603", TACRANGE="0x7614";
```

//配置用户群组。

```
ADD SUBGP: SUBID=1, SUBN="for usergroup";
ADD SUBGPMEM: SUBID=1, IMSIPRE="12345";
```

//MME本地配置限制区域信息、控制模式以及拒绝原因值。

```
ADD S1ACCAREALST: AREA=AG, AREAID=1, SUBRANGE=ALL_USER, CTRLTYPE=REJECT, CAUSE=CUSTOMER_DEFINED, SDCAUSE=15;
ADD S1ACCAREALST: AREA=AG, AREAID=1, SUBRANGE=USER_GROUP, SUBID=1, CTRLTYPE=ALLOW;
```
