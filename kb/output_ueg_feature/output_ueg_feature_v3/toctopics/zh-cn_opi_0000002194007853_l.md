# 配置5G业务的用户迁回

## 操作场景

子园区UEG-L故障恢复后必须要尽快在总部园区UEG-L上将故障期间激活的用户回迁至子园区UEG-L，本章节介绍5G用户的迁回操作。

* 本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。
* 如果多个子园区UEG-L同时故障，由于接入总部园区UEG-L的用户容量受限，因此可能导致故障子园区的新用户接入总部园区UEG-L失败。
* 如果多个子园区UEG-L同时故障，建议子园区UEG-L均恢复后，再进行用户迁回操作。
* 在总部园区UEG-L上将在线用户去激活后，用户业务发生中断，业务重新在子园区UEG-L上恢复的时间取决于终端业务行为。

## 操作步骤

1. 进入子园区的UEG-L“MML命令行-UEG”窗口。
2. 执行**LST GUAMI**查询并记录“AMF指示符”。
3. 进入总部园区的UEG-L“MML命令行-UEG”窗口。
4. 执行以下命令，查询并记录相关参数。

   //查询并记录参数“相对容量”和“AMF实例名称”

   ```
   LST AMFINFO:;
   ```

   //查询并记录“NF类型”为“NfAMF”的参数“容量”和“NF实例名称”

   ```
   LST CPNFPROFILE:;
   ```
5. 修改AMF的“相对容量”，建议修改为1。

   ```
   MOD AMFINFO: AMFINSTANCENAME="AMF实例名称", CAPACITY=1;
   ```
6. 修改AMF的“容量”，建议修改为0。

   ```
   MOD CPNFPROFILE: NFINSTANCENAME="AMF实例名称", CAPACITY=0;
   ```
7. 如果仅一个子园区故障，且该园区已恢复，下发启动迁移命令，向子园区的AMF迁移100%用户。其中“AMFPOINTER”是在子园区的UEG设备执行**LST GUAMI**查询到的“AMF指示符”。

   ```
   STR OFFLOADBYEDGEAMF: OFFLOADTYPE=RATE, TACSTART=100, AMFPOINTER="子园区UEG的AMF指示符";
   ```
8. 如果1个以上子园区故障，且该园区已恢复，则通过设置TAC区域迁移用户。

   ```
   STR OFFLOADBYEDGEAMF: OFFLOADTYPE=TAIRANGE, OFFLOADRATE=12301000003, TACEND=12301000004, AMFPOINTER="子园区UEG的AMF指示符";
   ```
9. 执行以下命令查询用户迁移的进度信息，每隔30s执行一次，确保“迁移状态”为“迁移任务已经结束”，并且“待迁移用户数”为0。

   ```
   DSP OFFLOADAMF:;
   ```
10. 执行以下命令查询AMF的会话上下文数，确保“SA会话上下文总数”为0。

    ```
    DSP SMSESSIONNUM:;
    ```
11. 修改AMF的“相对容量”。其中“相对容量”为4中记录的值。

    ```
    MOD AMFINFO: AMFINSTANCENAME="AMF实例名称", CAPACITY=相对容量;
    ```
12. 修改AMF的“容量”。其中“容量”为4中记录的值。

    ```
    MOD CPNFPROFILE: NFINSTANCENAME="AMF实例名称", CAPACITY=容量;
    ```
