# 配置命令触发的主备倒换

* 操作场景
* 必备事项
* 操作步骤
* 验证方法

## 操作场景

通过命令主动触发主备倒换时，需参考本页面进行配置。

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

两套UEG已完成1+1主备容灾模式配置。

数据

| 类别 | 参数名称 | 取值样例  （DC1） | 取值样例  （DC2） | 获取方法 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **SWAP DR** | 容灾组标识（DRGROUPID） | 1 |  | 已配置数据中获取 | 引用**ADD DRGROUPINFO**定义的容灾组标识。可通过**LST DRGROUPINFO**命令查询。 |
|  | 是否强制倒换（FORCE） | NO |  | 本端规划 | - |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 执行容灾实例主备倒换。

   如下以DC1运行状态为主，DC2运行状态为备为例，在UEG1上下发主备倒换命令。

   ```
   SWAP DR: DRGROUPID=1, FORCE=NO;
   ```

## 验证方法

1. 命令返回成功后可使用**DSP DRGROUPSTATUS**命令查询倒换结果。

   ```
   DSP DRGROUPSTATUS: DRGROUPID=1;
   ```

   预期结果：DC1的UEG“本端容灾实例运行状态”为“容灾实例运行状态为备”；DC2的UEG上“本端容灾实例运行状态”为“容灾实例运行状态为主”；主备用UEG上“主备容灾实例之间的心跳状态”为“主备容灾实例之间握手成功，处于连接状态”。

   当不符合上述预期时，请联系华为技术支持工程师。
