# 配置SMF业务数据

## 操作场景

本场景用于在SMF上配置DNN和APN相关的基础数据和静态路由冗余数据。

## 对系统的影响

无。

## 必备事项

前提条件

需要与UPF配合使用，要求SMF上配置的用户静态地址网段信息必须在包含在UPF上配置的地址池内，如果对端UPF是华为UEG产品，详细请参考**静态地址用户路由冗余**特性。

## 任务示例

任务描述

配置SMF的DNN、APN基础数据。

* 专线（仅连接，地市共享式）：支持风筝S
* 专网（仅连接，园区入驻式）：支持风筝S、风筝M、风筝L
* 云网（连接+计算，共享式+入驻式）：支持风筝S、风筝M

脚本

1. 配置APN信息。

   //风筝S

   ```
   ADD VPNINST:VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD APN: APN="APN1",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ```

   //风筝M或风筝L

   ```
   ADD CPVPNINST:VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD CPAPN: APN="APN1",HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ```
2. 配置DNN切片绑定关系。

   ```
   /*需要使用命令LST NFNS查询SMF支持的网络切片索引。*/
   ADD NSDNN:NSIDX=0, DNN="APN1";
   ```
3. 配置指定APN的本地用户、漫游用户、拜访地用户动态PCC功能。

   ```
   SET APNPCCFUNC: APN="APN1", HOMEPCCSWITCH=DISABLE, ROAMPCCSWITCH=DISABLE, VISITPCCSWITCH=DISABLE;
   ```
4. （可选）配置服务区域。如果当前业务发放不涉及区域调整则无需随DNN开通时重复配置。

   ```
   ADD UPAREA: AREANAME="huzhou_12A303", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI: AREANAME="huzhou_12A303", N2BEGINTAI="4600312A301", N2ENDTAI="4600312A303";
   ```
5. （可选）配置SMF本端主锚点UPF所覆盖的区域。如果当前业务发放不涉及区域调整则无需随DNN开通时重复配置。

   ```
   ADD PNFSMFSERAREA: NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="huzhou_12A303";
   ADD PNFSMFSERAREA: NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="huzhou_12A303";
   ```
6. 配置将UserProfile Group绑定到APN。参数“USERPROFGNAME”已在PCC业务配置的**ADD USRPROFGROUP**命令中定义。

   ```
   ADD APNUSRPROFG:APN="APN1", USERPROFGNAME="up_group_iot5g";
   ```
7. （可选）配置主锚点UPF的DNN属性。如果新增业务场景需要新增DNN可通过本命令添加。参数“PNFNSINDEX”已在**ADD PNFNS**中定义，当存在切片发放场景时，此参数引用切片发放对应的参数。

   ```
   ADD PNFDNN: INDEX=100, NFINSTANCEID="UPF_Instance_0", DNN="APN1", PNFNSINDEX=3;
   ADD PNFDNN: INDEX=100, NFINSTANCEID="UPF_Instance_1", DNN="APN1", PNFNSINDEX=4;
   ```
8. 创建本地地址池。

   //风筝S

   ```
   ADD ADDRPOOL: POOLNAME="pool_ipv4_APN1", IPVERSION=IPv4, POOLTYPE=UDM, CHECKIPVALID=Enable,HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD ADDRPOOL: POOLNAME="pool_ipv6_APN1", IPVERSION=IPv6, POOLTYPE=UDM, CHECKIPVALID=Enable,HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ```

   //风筝M或风筝L

   ```
   ADD CPADDRPOOL: POOLNAME="pool_ipv4_APN1", IPVERSION=IPv4, POOLTYPE=UDM, CHECKIPVALID=Enable,HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ADD CPADDRPOOL: POOLNAME="pool_ipv6_APN1", IPVERSION=IPv6, POOLTYPE=UDM, CHECKIPVALID=Enable,HASVPN=ENABLE,VPNINSTANCE="VRF_N6_Local_2B_APP";
   ```
9. 开启静态地址用户的白名单检查功能。

   ```
   ADD POOLBINDAPN: POOLNAME="pool_ipv4_APN1", APN="APN1";
   ADD POOLBINDAPN: POOLNAME="pool_ipv6_APN1", APN="APN1";
   ```
10. 配置本地地址池里的地址段。

    //风筝S

    ```
    ADD SECTION: POOLNAME="pool_ipv4_APN1", SECTIONNUM=1, IPVERSION=IPv4, V4STARTIP="10.0.0.0", V4ENDIP="10.1.2.3";
    ADD SECTION: POOLNAME="pool_ipv6_APN1", SECTIONNUM=1, IPVERSION=IPv6, V6PREFIXSTART="fc00:1::1", V6PREFIXEND="fc00:1::1111", V6PREFIXLENGTH="64";
    ```

    //风筝M或风筝L

    ```
    ADD CPSECTION: POOLNAME="pool_ipv4_APN1", SECTIONNUM=1, IPVERSION=IPv4, V4STARTIP="10.0.0.0", V4ENDIP="10.1.2.3";
    ADD CPSECTION: POOLNAME="pool_ipv6_APN1", SECTIONNUM=1, IPVERSION=IPv6, V6PREFIXSTART="fc00:1::1", V6PREFIXEND="fc00:1::1111", V6PREFIXLENGTH="64";
    ```
11. 配置地址池组名称。

    ```
    ADD ADDRPOOLGRP: POOLGRPNAME="pool_APN1", POOLGRPTYPE=UDM;
    ```
12. 配置地址池与地址池组绑定。

    ```
    ADD POOLBINDGRP: POOLGRPNAME="pool_APN1", POOLNAME="pool_ipv4_APN1";
    ADD POOLBINDGRP: POOLGRPNAME="pool_APN1", POOLNAME="pool_ipv6_APN1";
    ```
13. 配置静态地址用户使用的UPF组。

    ```
    ADD ADDRUPGROUP: UPFGRPNAME="upfgroupp1", UPFGRPTYPE=UDM;
    ```
14. 配置主、备UPF与UPF组绑定。

    ```
    ADD UPFBINDGRP: UPFGRPNAME="upfgroup1", UPFID="UPF_Instance_0", PRIORITY=0;
    ADD UPFBINDGRP: UPFGRPNAME="upfgroup1", UPFID="UPF_Instance_1", PRIORITY=1;
    ```
15. 配置地址池组与UPF组绑定。

    //风筝S

    ```
    ADD POOLGRPMAP: MAPPINGNAME="mapping01", POOLGRPNAME="pool_APN1", UPFGRPNAME="upfgroup1";
    ```

    //风筝M或风筝L

    ```
    ADD CPPOOLGRPMAP: MAPPINGNAME="mapping01", POOLGRPNAME="pool_APN1", UPFGRPNAME="upfgroup1";
    ```
16. 配置计费、PCC相关业务。

    业务发放后，还需要配置计费、PCC等相关业务配置，请参考“风筝S/M/L（UEG）> 业务配置”章节。
