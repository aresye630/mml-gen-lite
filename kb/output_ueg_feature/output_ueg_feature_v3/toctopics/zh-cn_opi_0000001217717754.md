# 配置AMF和LMF/GMLC对接（NLs/NLg，用于LCS）

## 操作场景

本章节用于指导AMF和LMF/GMLC的对接操作，LMF/GMLC主要用于LCS相关业务。

在总部园区为风筝L，子园区为风筝L的跨级容灾场景下，总部园区AMF除了需要跟本设备的LMF/GMLC对接，同时还需要和子园区的LMF/GMLC进行对接。

LCS通过网络设备控制面的信令流程来完成定位的交互，从而获取目标UE位置的定位方案，是基于通信网络实现的方案。LCS系统结构如图1所示。

**图1** LCS系统结构示意图

GMLC和LRF可以是融合部署，也可以独立部署。AMF通过NLg和NLs分别和GMLC以及LMF对接。

|  |  |
| --- | --- |
| LCS（Location Service） | 位置服务 |
| LMF（Location Management Function） | 位置管理功能实体 |
| GMLC（Gateway Mobile Location Centre） | 网关移动定位中心 |
| LRF（Location Retrieval Function） | 位置获取功能实体 |
| LCS Client | 位置服务客户端 |

从3GPP TS 23.273 V0.2.0起，协议规定AMF和LMF之间的NLs接口修改为NL1接口，AMF和GMLC之间的NLg接口修改为NL2接口。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置LMF/GMLC实例基础信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="LMF_Instance_0", NFTYPE=NfLMF, NFSTATUS=Registered, FQDN="huawei.com", INTERPLMNFQDN="huawei1.com", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.107.65.183", PORT=8080, LOCALITY="SHANGHAI";
   ADD PNFPROFILE: NFINSTANCEID="GMLC_Instance_0", NFTYPE=NfGMLC, NFSTATUS=Registered, FQDN="huawei.com", INTERPLMNFQDN="huawei1.com", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.107.65.184", PORT=8080, LOCALITY="SHANGHAI";
   ADD PNFPLMN: NFINSTANCEID="LMF_Instance_0", MCC="460",MNC="03";
   ADD PNFPLMN: NFINSTANCEID="GMLC_Instance_0", MCC="460",MNC="03";
   ```
3. **可选：**配置LMF/GMLC实例特有信息。

   根据现网业务需要配置LMF/GMLC的特有属性信息，例如针对LMF/GMLC如果只支持某种特有外部客户端类型，则需要配置如下命令。

   ```
   ADD PNFLMFINFO: NFINSTANCEID="LMF_Instance_0", LMFID="0001";
   ```

   ```
   ADD PNFGMLCINFO: NFINSTANCEID="GMLC_Instance_0", CLIENTTYPES=EMERGENCY_SERVICES-0&PLMN_OPERATOR_SERVICES-0&LAWFUL_INTERCEPT_SERVICES-0&PLMN_OPERATOR_BROADCAST_SERVICES-0&PLMN_OPERATOR_OM-0&PLMN_OPERATOR_ANONYMOUS_STATISTI-0&PLMN_OPERATOR_TARGET_MS_SERVICE_SUPPORT-0;
   ```
4. 配置LMF/GMLC支持的服务实例信息。

   ```
   ADD PNFSERVICE: NFINSTANCEID="LMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NlmfLoc, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="GMLC_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NgmlcLoc, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ```
5. **可选：**配置LMF/GMLC支持的服务实例回调信息。

   此配置适用于订阅通知场景，如果LMF/GMLC订阅了AMF，则AMF通过此配置向对应的回调信息发送订阅通知。

   ```
   ADD PNFSRVNTFSUBS: NFINSTANCEID="LMF_Instance_0", SRVINSTANCEID="Service_Instance_0", NTFICATIONTYPE=LocNty, CALLBACKURI="http://10.60.103.60:19999/nlmf-loc/hlmf/v1/provide-location", N1MESSAGECLASS=Lpp, N2INFOCLASS=Nrppa;
   ADD PNFSRVNTFSUBS: NFINSTANCEID="GMLC_Instance_0", SRVINSTANCEID="Service_Instance_1", NTFICATIONTYPE=LocNty, CALLBACKURI="http://10.60.103.18:19999/ngmlc-loc/hgmlc/v1/provide-location", N1MESSAGECLASS=Lpp, N2INFOCLASS=Nrppa;
   ```
6. 总部园区为UEGL、子园区为UEGL的多园区跨级容灾场景，当前设备为总部园区时，请参考步骤2~5配置总部园区AMF与子园区LMF/GMLC的对接。
