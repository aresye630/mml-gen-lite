# 配置层二静态组播功能

## 操作场景

5G LAN业务存在静态组播业务时，请参考本页面配置静态组播功能。

UPF收到组播报文后，根据5G LAN组ID+组播目的MAC匹配组播组，匹配到静态组播组后，根据配置的静态组播组及静态组播组成员的映射关系建立层二组播转发表项，控制组播数据报文仅在该组播组内转发。

仅适用于层二5G LAN场景。

## 必备事项

前提条件

* 已完成配置5G LAN基本功能。
* 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。

数据

规划时注意：

* 一个静态组播组，只能和一个5G LAN实例绑定。
* 和不同5G LAN实例绑定的静态组播组，组播MAC地址可以相同。
* 和同一个5G LAN实例绑定的多个静态组播组，组播MAC地址必须不同。

**表1** 静态组播组数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD MULTICASTGRP** | 组播组名称（MCASTGRPNAME） | MCASTGRP01 | 本端规划 | 5G LAN终端发送组播报文时，报文中的目的MAC必须与此处配置的组播MAC一致。  UPF收到该目的MAC的报文，则认为是组播报文，会向该组播组内的所有成员转发该组播报文。 |
|  | 组播MAC地址（MCASTMACADDR） | 11-11-11-11-11-fc | 本端规划 |  |
| **ADD NGBINDMCASTGRP** | 5G LAN实例名称（VNINSTANCE） | 000003e9-460-08-01 | 已配置数据中获取 | 采用**ADD NGVNINSTANCE**命令定义的VNINSTANCE。 |
|  | 组播组名称（MCASTGRPNAME） | MCASTGRP01 | 已配置数据中获取 | 采用**ADD MULTICASTGRP**命令定义的MCASTGRPNAME。 |
| **ADD MCASTGRPMEM** | 组播组名称（MCASTGRPNAME） | MCASTGRP01 | 已配置数据中获取 | 采用**ADD MULTICASTGRP**命令定义的组播组名称。 |
|  | 成员类型（MEMTYPE） | * IMSI * VTEP | 本端规划 | 根据局点需要，规划组播组成员类型。 |
|  | IMSI（IMSI） | 460123123456789 | 与对端协商 | “MEMTYPE”设置为“IMSI”时需要规划。  静态组播组成员的IMSI。一个IMSI可以加入多个组播组。  IMSI长度范围1～15，每个字符必须为0~9的数字。 |
|  | VXLAN隧道端点名称（VTEPNAME） | VTEP1 | 已配置数据中获取 | “MEMTYPE”设置为“VTEP”时需要规划。  采用**ADD VTEP**命令定义的“VTEPNAME”。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 增加静态组播组。

   **ADD MULTICASTGRP**
3. 配置静态组播组和5G LAN组的绑定关系。

   **ADD NGBINDMCASTGRP**
4. 增加静态组播组成员。

   **ADD MCASTGRPMEM**

## 验证方法

1. 执行**LST LICENSESWITCH**命令，查询UEG上对应的License配置开关是否打开。

   ```
   LST LICENSESWITCH: LICITEM="LKV3G5L2SMUL";
   ```

   * 如果“SWITCH”为“ENABLE”，请执行2。
   * 如果“SWITCH”为“DISABLE”，则执行**SET LICENSESWITCH**命令打开本特性对应的License配置开关。
2. 选择三个测试终端（终端D、E、F），将这三个测试终端添加到UPF的同一个静态组播组中。
3. 执行**DSP MCASTGRPMEM**命令，查询静态组播组成员状态是否已激活。

   “状态”为“Active”说明静态组播组成员已激活；“状态”为“Inactive”说明静态组播组成员未激活。

   * 已激活，请执行4。
   * 未激活，请联系华为技术支持处理。。
4. 使用终端D发送组播业务报文，观测终端E和终端F是否收到该报文。
   * 是，静态组播业务正常，调测结束。
   * 否，请联系华为技术支持处理。

## 任务示例

任务描述

层二5G LAN场景，需要通过静态组播功能，实现层二5G LAN组播功能。

组播组成员以IMSI成员和VTEP成员为例。

脚本

//通过静态组播组实现层二5G LAN组播功能时，配置静态组播组。

```
SET LICENSESWITCH: LICITEM="LKV3G5L2SMUL", SWITCH=ENABLE;
```

```
ADD MULTICASTGRP: MCASTGRPNAME="MCASTGRP01", MCASTMACADDR="11-11-11-11-11-fc";
```

```
ADD NGBINDMCASTGRP: VNINSTANCE="000003e9-460-08-01", MCASTGRPNAME="MCASTGRP01";
```

```
ADD MCASTGRPMEM: MCASTGRPNAME="MCASTGRP01", MEMTYPE=IMSI, IMSI="460123123456789";
ADD MCASTGRPMEM: MCASTGRPNAME="MCASTGRP01", MEMTYPE=VTEP, VTEPNAME="VTEP1";
```
