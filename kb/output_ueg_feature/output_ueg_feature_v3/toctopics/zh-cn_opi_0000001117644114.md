# 配置VPN专线对接数据（UEG虚机容器，NP卡+DCGW）

## 操作场景

本场景用于配置无线侧到UPF的VPN传输专线数据。其中，UPF采用NP卡对接DCGW，DCGW再与无线侧对接实现互通，组网如图1所示。

**图1** NP卡+DCGW数通规划示意图

## 对系统的影响

无。

## 任务示例

任务描述

配置UPF到园区的VPN专线，UPF使用NP卡对接DCGW。

* 专线（仅连接，地市共享式）：支持风筝S
* 专网（仅连接，园区入驻式）：支持风筝S、风筝M、风筝L
* 云网（连接+计算，共享式+入驻式）：支持风筝S、风筝M

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N3_Local_2B_001",VRFDESCRIPTION="N3";
   ADD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni;
   MOD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,VRFRD="172.20.9.4:100";
   ADD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni;
   MOD VPNINSTAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni,VRFRD="172.20.9.4:100";
   ```
3. 配置主接口的管理状态为up。

   ```
   MOD INTERFACE: IFNAME="100GE65/0/9", IFADMINSTATUS=up;
   MOD INTERFACE: IFNAME="100GE66/0/9", IFADMINSTATUS=up;
   ```
4. 配置子接口。

   ```
   ADD INTERFACE: IFNAME="100GE65/0/9.2003", IFDF=FALSE;
   ADD INTERFACE: IFNAME="100GE66/0/9.2003", IFDF=FALSE;
   ```
5. 接口绑定VPN。

   ```
   ADD IPBINDVPN: IFNAME="100GE65/0/9.2003", VRFNAME="VRF_N3_Local_2B_001";
   ADD IPBINDVPN: IFNAME="100GE66/0/9.2003", VRFNAME="VRF_N3_Local_2B_001";
   ```
6. 在以太网子接口上关联VLAN ID。

   ```
   ADD ETHSUBIF: IFNAME="100GE65/0/9.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ADD ETHSUBIF: IFNAME="100GE66/0/9.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ```
7. 配置外联口IPv4地址。

   ```
   ADD IFIPV4ADDRESS: IFNAME="100GE65/0/9.2003", IFIPADDR="192.168.246.130", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ADD IFIPV4ADDRESS: IFNAME="100GE66/0/9.2003", IFIPADDR="192.168.246.131", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ```
8. 配置IPv6使能。

   ```
   SET IFIPV6ENABLE: IFNAME="100GE65/0/9.2003", ENABLEFLAG=TRUE;
   SET IFIPV6ENABLE: IFNAME="100GE66/0/9.2003", ENABLEFLAG=TRUE;
   ```
9. 配置外联口IPv6地址。

   ```
   ADD IFIPV6ADDRESS: IFNAME="100GE65/0/9.2003", IPV6ADDRESS="fc00:8028:5000:43::9542", PREFIXLEN=123, ADDRTYPE=global;
   ADD IFIPV6ADDRESS: IFNAME="100GE66/0/9.2003", IPV6ADDRESS="fc00:8028:5000:43::9543", PREFIXLEN=123, ADDRTYPE=global;
   ```
10. 新建静态BFD会话。

    ```
    ADD BFDSESSION: SESSNAME="N3if_2003_1", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.11.11", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N3_Local_2B_001", MINECHORXINT=500, LOCALDISCR=322, IFNAME="100GE66/0/9.2003";
    ADD BFDSESSION: SESSNAME="N3if_2003_2", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.11.11", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N3_Local_2B_001", MINECHORXINT=500, LOCALDISCR=323, IFNAME="100GE65/0/9.2003";
    ADD BFDSESSION: SESSNAME="N3if_IPv6_1", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=TRUE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N3_Local_2B_001", MINECHORXINT=500, LOCALDISCR=324, IFNAME="100GE66/0/9.2003", DESTADDR6="fc00:187:C28C::1";
    ADD BFDSESSION: SESSNAME="N3if_IPv6_2", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=TRUE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N3_Local_2B_001", MINECHORXINT=500, LOCALDISCR=325, IFNAME="100GE65/0/9.2003", DESTADDR6="fc00:187:C28C::1";
    ```
11. 配置静态路由数据。

    ```
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.11.1", MASKLENGTH=32, VRFNAME="VRF_N3_Local_2B_001", DESTVRFNAME="VRF_N3_Local_2B_001", IFNAME="100GE66/0/9.2003", NEXTHOP="192.168.11.11", SESSIONNAME="N3if_2003_1";
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.11.2", MASKLENGTH=32, VRFNAME="VRF_N3_Local_2B_001", DESTVRFNAME="VRF_N3_Local_2B_001", IFNAME="100GE65/0/9.2003", NEXTHOP="192.168.11.11", SESSIONNAME="N3if_2003_2";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:187:C289::1", MASKLENGTH=128, VRFNAME="VRF_N3_Local_2B_001", DESTVRFNAME="VRF_N3_Local_2B_001", IFNAME="100GE66/0/9.2003", NEXTHOP="fc00:187:C28C::1", SESSIONNAME="N3if_IPv6_1";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:187:C289::2", MASKLENGTH=128, VRFNAME="VRF_N3_Local_2B_001", DESTVRFNAME="VRF_N3_Local_2B_001", IFNAME="100GE65/0/9.2003", NEXTHOP="fc00:187:C28C::1", SESSIONNAME="N3if_IPv6_2";
    ```
12. 添加LoopBack接口。

    ```
    ADD INTERFACE:IFNAME="LoopBack14",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
    ADD IFIPV4ADDRESS:IFNAME="LoopBack14",IFIPADDR="172.20.9.7",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
    ADD IPBINDVPN:IFNAME="LoopBack14",VRFNAME="VRF_N3_Local_2B_001";
    ADD INTERFACE:IFNAME="LoopBack13",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
    ADD IPBINDVPN:IFNAME="LoopBack13",VRFNAME="VRF_N3_Local_2B_001";
    SET IFIPV6ENABLE:IFNAME="Loopback13",ENABLEFLAG=TRUE;
    ADD IFIPV6ADDRESS:IFNAME="Loopback13",IPV6ADDRESS="fc00:187:C281::1",PREFIXLEN=128;
    ```
13. 设置BGP。

    ```
    SET BGP: BGPENABLE=TRUE, ASNUM="64986";
    ```
14. 添加BGP VPN。

    ```
    ADD BGPVRF:VRFNAME="VRF_N3_Local_2B_001",DEFAULTAFTYPE=noaf,ROUTERID="172.20.7.2";
    ```
15. 增加BGP VPN地址族。

    ```
    ADD BGPVRFAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,MAXLOADEBGPNUM=2;
    ADD BGPVRFAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni,MAXLOADEBGPNUM=2;
    ```
16. 增加指定协议中的入口路由配置。

    ```
    ADD IMPORTROUTE:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,IMPORTPROTOCOL=wlr;
    ADD IMPORTROUTE:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv6uni,IMPORTPROTOCOL=wlr;
    ```
17. 增加BGP对等体。

    ```
    ADD BGPPEER: VRFNAME="VRF_N3_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.1", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N3_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.2", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N3_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::1", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N3_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::2", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ```
18. 增加BGP对等体地址族。

    ```
    MOD BGPPEERAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,REMOTEADDRESS="192.168.11.1";
    MOD BGPPEERAF:VRFNAME="VRF_N3_Local_2B_001",AFTYPE=ipv4uni,REMOTEADDRESS="192.168.11.2";
    MOD BGPPEERAF: VRFNAME="VRF_N3_Local_2B_001", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="fc00:187:C289:0:0:0:0:1";
    MOD BGPPEERAF: VRFNAME="VRF_N3_Local_2B_001", AFTYPE=ipv6uni, ADDRESSTYPE=ipv6, REMOTEADDRESSV6="fc00:187:C289:0:0:0:0:2";
    ```
19. 配置VPN实例。

    //风筝S

    ```
    ADD VPNINST: VPNINSTANCE="VRF_N3_Local_2B_001";
    ```

    //风筝M或风筝L

    ```
    ADD CPVPNINST: VPNINSTANCE="VRF_N3_Local_2B_001";
    ```
20. 配置UPF锁定状态。

    ```
    LCK NF: LOCKSWITCH=ENABLE;
    ```

    该命令属于高危命令，会改变UPF的锁定状态。如果配置为锁定，会导致用户接入失败，需要配置切片和N3接口绑定后，立即解锁。
21. 配置N3接口。

    //风筝S

    ```
    ADD LOGICINF: NAME="N3IF1/1/1", IPVERSION=IPV4, IPV4ADDRESS1="10.178.61.7", IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_N3_Local_2B_001";
    ```

    //风筝M或风筝L

    ```
    ADD CPLOGICINF: NAME="N3IF1/1/1", IPVERSION=IPV4, IPV4ADDRESS1="10.178.61.7", IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_N3_Local_2B_001";
    ```
