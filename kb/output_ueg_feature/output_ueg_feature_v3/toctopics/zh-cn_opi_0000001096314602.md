# NP卡+DCGW

## 操作场景

新增企业，开通业务时，UPF到园区采用VPN专线，UPF使用NP卡，对接DCGW。对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例，组网规划如图1。

**图1** NP卡+DCGW规划示意图

## 任务示例

任务描述

* 新增企业，开通业务时，UPF到园区采用VPN专线，UPF使用NP卡，对接DCGW。
* UPF到DCGW为eBGP+BFD组网：eBGP绑定BFD会话，BFD检测时间配置为500ms\*4。
* 对于容灾的两个UPF而言，此配置没有区别，仅以一个UPF做配置举例。

脚本

1. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
2. 配置VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_N6_Local_2B_001",VRFDESCRIPTION="N6";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni;
   MOD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,VRFRD="172.20.9.4:100";
   ADD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni;
   MOD VPNINSTAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,VRFRD="172.20.9.4:100";
   ```
3. 配置主接口的管理状态为up。

   ```
   MOD INTERFACE: IFNAME="100GE65/0/9", IFADMINSTATUS=up;
   MOD INTERFACE: IFNAME="100GE66/0/9", IFADMINSTATUS=up;
   ```
4. 配置Eth-trunk接口。

   ```
   ADD INTERFACE: IFNAME="Eth-trunk65";
   ADD INTERFACE: IFNAME="Eth-trunk66";
   ```
5. 配置Eth-trunk接口的工作模式并添加成员端口。

   ```
   MOD TRUNKIF:IFNAME="Eth-Trunk65", WORKMODE=Lacp, LEASTACTLINKNUM=1;
   MOD TRUNKIF:IFNAME="Eth-Trunk66", WORKMODE=Lacp, LEASTACTLINKNUM=1;
   ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk65", MEMBERIFNAME="100GE65/0/9";
   ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk66", MEMBERIFNAME="100GE66/0/9";
   ```
6. 配置以太Trunk子接口。

   ```
   ADD INTERFACE: IFNAME="Eth-trunk65.2003";
   ADD INTERFACE: IFNAME="Eth-trunk66.2003";
   ```
7. 接口绑定VPN。

   ```
   ADD IPBINDVPN: IFNAME="Eth-trunk65.2003", VRFNAME="VRF_N6_Local_2B_001";
   ADD IPBINDVPN: IFNAME="Eth-trunk66.2003", VRFNAME="VRF_N6_Local_2B_001";
   ```
8. 在以太网Trunk子接口上关联VLAN ID。

   ```
   ADD ETHSUBIF: IFNAME="Eth-trunk65.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ADD ETHSUBIF: IFNAME="Eth-trunk66.2003", SUBIFTYPE=VlanType, VLANTYPEVID=2003;
   ```
9. 配置外联口IPv4地址。

   ```
   ADD IFIPV4ADDRESS: IFNAME="Eth-trunk65.2003", IFIPADDR="192.168.246.130", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ADD IFIPV4ADDRESS: IFNAME="Eth-trunk66.2003", IFIPADDR="192.168.246.110", SUBNETMASK="255.255.255.224", ADDRTYPE=main;
   ```
10. 配置IPv6使能。

    ```
    SET IFIPV6ENABLE: IFNAME="Eth-trunk65.2003", ENABLEFLAG=TRUE;
    SET IFIPV6ENABLE: IFNAME="Eth-trunk66.2003", ENABLEFLAG=TRUE;
    ```
11. 配置外联口IPv6地址。

    ```
    ADD IFIPV6ADDRESS: IFNAME="Eth-trunk65.2003", IPV6ADDRESS="fc00:8028:5000:43::9542", PREFIXLEN=123, ADDRTYPE=global;
    ADD IFIPV6ADDRESS: IFNAME="Eth-trunk66.2003", IPV6ADDRESS="fc00:8028:5000:43::9590", PREFIXLEN=123, ADDRTYPE=global;
    ```
12. 新建静态BFD会话。

    ```
    ADD BFDSESSION: SESSNAME="N6if_2003_1", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.11.11", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=322, IFNAME="Eth-trunk65.2003";
    ADD BFDSESSION: SESSNAME="N6if_2003_2", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.11.11", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=323, IFNAME="Eth-trunk66.2003";
    ADD BFDSESSION: SESSNAME="N6if_IPv6_1", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=TRUE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=324, IFNAME="Eth-trunk65.2003", DESTADDR6="fc00:187:C28C::1";
    ADD BFDSESSION: SESSNAME="N6if_IPv6_2", ADDRTYPE=IPv6, CREATETYPE6=SESS_STATIC, ONEARMECHO6=TRUE, LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VRF_N6_Local_2B_001", MINECHORXINT=500, LOCALDISCR=325, IFNAME="Eth-trunk66.2003", DESTADDR6="fc00:187:C28C::1";
    ```
13. 配置静态路由数据。

    ```
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.11.1", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Eth-trunk65.2003", NEXTHOP="192.168.11.11", SESSIONNAME="N6if_2003_1";
    ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.11.2", MASKLENGTH=32, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Eth-trunk66.2003", NEXTHOP="192.168.11.11", SESSIONNAME="N6if_2003_2";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:187:C289::1", MASKLENGTH=128, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Eth-trunk65.2003", NEXTHOP="fc00:187:C28C::1", SESSIONNAME="N6if_IPv6_1";
    ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:187:C289::2", MASKLENGTH=128, VRFNAME="VRF_N6_Local_2B_001", DESTVRFNAME="VRF_N6_Local_2B_001", IFNAME="Eth-trunk66.2003", NEXTHOP="fc00:187:C28C::1", SESSIONNAME="N6if_IPv6_2";
    ```
14. 添加LoopBack接口。

    ```
    ADD INTERFACE:IFNAME="LoopBack14",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
    ADD IFIPV4ADDRESS:IFNAME="LoopBack14",IFIPADDR="172.20.9.7",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
    ADD IPBINDVPN:IFNAME="LoopBack14",VRFNAME="VRF_N6_Local_2B_001";
    ADD INTERFACE:IFNAME="LoopBack13",IFADMINSTATUS=up,IFMTU=1500,IFDF=FALSE,IFSTATIENABLE=TRUE,IFTRAPENABLE=TRUE;
    ADD IPBINDVPN:IFNAME="LoopBack13",VRFNAME="VRF_N6_Local_2B_001";
    SET IFIPV6ENABLE:IFNAME="Loopback13",ENABLEFLAG=TRUE;
    ADD IFIPV6ADDRESS:IFNAME="Loopback13",IPV6ADDRESS="fc00:187:C281::1",PREFIXLEN=128;
    ```
15. 设置BGP。

    ```
    SET BGP: BGPENABLE=TRUE, ASNUM="64986";
    ```
16. 添加BGP VPN。

    ```
    ADD BGPVRF:VRFNAME="VRF_N6_Local_2B_001",DEFAULTAFTYPE=noaf,ROUTERID="172.20.7.2";
    ```
17. 增加BGP VPN地址族。

    ```
    ADD BGPVRFAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,MAXLOADEBGPNUM=2;
    ADD BGPVRFAF:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,MAXLOADEBGPNUM=2;
    ```
18. （负荷分担UPF场景下）配置BGP引入wlr路由。

    ```
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv4uni,IMPORTPROTOCOL=wlr;
    ADD IMPORTROUTE:VRFNAME="VRF_N6_Local_2B_001",AFTYPE=ipv6uni,IMPORTPROTOCOL=wlr;
    ```
19. （GRE路由冗余隧道场景下）配置BGP引入wlr路由。

    ```
    ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=TRUE, MED=0;
    ADD IMPORTROUTE: VRFNAME="VRF_N6_Local_2B_001", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=TRUE, MED=0;
    ```
20. 增加BGP对等体。

    ```
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.1", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv4, PEERADDR="192.168.11.2", REMOTEAS="64813", LOCALIFADDR="172.20.9.7", LOCALIFNAME="LoopBack14", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::1", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ADD BGPPEER: VRFNAME="VRF_N6_Local_2B_001", ADDRESSTYPE=ipv6, PEERADDRV6="fc00:187:C289::2", REMOTEAS="64813", LOCALIFADDR="fc00:187:C281::1", LOCALIFNAME="LoopBack13", EBGPMAXHOP=2, CONNECTMODE=null, PSWDTYPE=null;
    ```
