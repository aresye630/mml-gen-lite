# 激活基于PCRF/PCF的VoLTE业务快速恢复

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

在UEG上激活基于PCRF/PCF的VoLTE业务快速恢复功能，降低P-CSCF服务器故障时，对用户业务的影响。

适用于PGW-C、PCRF、PCF。

## 必备事项

前提条件

* 请仔细阅读GWFD-025502 基于PCRF/PCF的VoLTE业务快速恢复特性概述。
* 完成激活P-CSCF故障时IMS业务恢复。
* 已完成加载License。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET CPAPNREPORTATTR** | APN名称（APN） | ims.real | 本端规划 | 将真实使用的APN与终端上报的APN配置映射关系。 |
|  | 上报给PCRF的APN名  （PCRF） | REQUESTED |  |  |
| **SET SMFSOFTPARAOFBIT** | DT（数据类型） | Dw | 本端规划 | 设置SMF软件参数比特位，配置PGW-C基于PCRF/PCF的P-CSCF故障恢复会重新激活会话。 |
|  | DWORDNUM（Dword索引） | 1017 |  |  |
|  | VALUE（软参记录值） | VALUE\_1 |  |  |
|  | POSITION（比特位） | 30 |  |  |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 将真实使用的APN与终端上报的APN配置映射关系。
3. 配置PGW-C基于PCRF/PCF的P-CSCF故障恢复会重新激活会话。

   **SET SMFSOFTPARAOFBIT**

## 任务示例

任务描述

开启基于PCRF/PCF的VoLTE业务快速恢复功能开关。

脚本

//进入“MML命令行-UEG”窗口。

//将真实使用的APN与终端上报的APN配置映射关系。参数APN使用ADD CPAPN命令配置生成。执行该命令前请先通过LST CPAPN查询当前是否已添加该APN配置。根据查询结果，选择是否配置该参数。

```
SET CPAPNREPORTATTR: APN="ims.real", PCRF=REQUESTED;
```

//配置PGW-C基于PCRF/PCF的P-CSCF故障恢复会重新激活会话。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1017, VALUE=VALUE_1, POSITION=30;
```
