# 配置SMF/GW-C公共数据（无语音业务）

## 操作场景

当企业不部署语音业务时，参考本章节进行SMF/GW-C与UPF/GW-U对接公共数据配置。此处仅以一套UEG-L的SMF/GW-C对接一个子园区主备UEG-S为例。

* 新增子园区请参考本章节中对接子园区UPF/GW-U部分的配置。
* 如果总部园区UPF/GW-U不承载数据业务，则无需执行对接总部园区UPF/GW-U的配置。

无。

## 任务示例

任务描述

用于配置SMF/GW-C与UPF/GW-U对接公共数据。其中

* 总部园区和子园区共用DNN/APN（APN1）。
* 总部园区UPF实例为UPF\_Instance\_0。
* 子园区2个UPF实例，分别为UPF\_Instance\_A0和UPF\_Instance\_A1。
* SMF/GW-C基于DNN/APN+TAC选择UPF实例。用户访问子园区时，UPF\_Instance\_A0优先级高于UPF\_Instance\_A1。其中总部园区和子园区PLMN相同，为12301。

脚本

1. 配置用户面节点实例。配置Profile实例。

   //对接总部园区UPF/GW-U配置

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf00.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.125.11", PORT=8080, PRIORITY=0;
   ```

   //开启基于优先级选择UPF/GW-U

   ```
   SET UPSELECTFLAG: PRIORITYFLAG=ENABLE;
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_A0", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upfa00.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080, PRIORITY=0;
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_A1", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upfa01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.12", PORT=8080, PRIORITY=1;
   ```
2. 配置用户面节点的位置特征和分流能力。

   //对接总部园区UPF/GW-U配置

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_0", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_PS_N4";
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_A0", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_PS_N4";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_A1", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, ADDRALLOCMODE=INHERIT, VPNNAME="VRF_PS_N4";
   ```
3. 配置用户面节点支持的切片与DNN信息。

   //对接总部园区UPF/GW-U配置

   ```
   ADD PNFNS: INDEX=2, NFINSTANCEID="UPF_Instance_0", SST=1, SD="010101"; 
   ADD PNFDNN:INDEX=5, NFINSTANCEID="UPF_Instance_0", DNN="APN1", PNFNSINDEX=2;
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_A0", SST=1, SD="010101"; 
   ADD PNFNS: INDEX=4, NFINSTANCEID="UPF_Instance_A1", SST=1, SD="010101"; 
   ADD PNFDNN:INDEX=6, NFINSTANCEID="UPF_Instance_A0", DNN="APN1", PNFNSINDEX=3;
   ADD PNFDNN:INDEX=7, NFINSTANCEID="UPF_Instance_A1", DNN="APN1", PNFNSINDEX=4;
   ```
4. 配置5G用户面节点的位置区信息，将位置区与TAI绑定。

   //对接总部园区UPF配置

   ```
   ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12301000001", N2ENDTAI="12301000002";
   ```

   //对接子园区UPF配置

   ```
   ADD UPAREA:AREANAME="UPAREA2", AREATYPE=N2TAI;
   ADD UPAREABINDN2TAI:AREANAME="UPAREA2", N2BEGINTAI="12301000003", N2ENDTAI="12301000004";
   ```
5. 配置5G用户面节点支持的为SMF提供服务区域的信息。

   //对接总部园区UPF配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="UPAREA1";
   ```

   //对接子园区UPF配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A0", SMFSERVINGAREA="UPAREA2";
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A1", SMFSERVINGAREA="UPAREA2";
   ```
6. 配置4G用户面节点的位置区信息，将位置区与TAI绑定。

   //对接总部园区GW-U配置

   ```
   ADD UPAREA:AREANAME="GWUAREA1", AREATYPE=S1TAI;
   ADD UPAREABINDS1TAI:AREANAME="GWUAREA1", S1BEGINTAI="123010000", S1ENDTAI="123010001";
   ```

   //对接子园区GW-U配置

   ```
   ADD UPAREA:AREANAME="GWUAREA2", AREATYPE=S1TAI;
   ADD UPAREABINDS1TAI:AREANAME="GWUAREA2", S1BEGINTAI="123010002", S1ENDTAI="123010003";
   ```
7. 配置4G用户面节点支持的为GW-C提供服务区域的信息。

   //对接总部园区GW-U配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_0", SMFSERVINGAREA="GWUAREA1";
   ```

   //对接子园区GW-U配置

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A0", SMFSERVINGAREA="GWUAREA2";
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_A1", SMFSERVINGAREA="GWUAREA2";
   ```
8. 配置用户面与EPS的互通以及支持的PDU会话类型。

   //对接总部园区UPF/GW-U配置

   ```
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ```

   //对接子园区UPF/GW-U配置

   ```
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_A0", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ADD PNFUPFINFO: NFINSTANCEID="UPF_Instance_A1", IWKEPSIND=TRUE, PDUSESSIONTYPE=IPV4-1&IPV6-1&IPV4V6-1&UNSTRUCTURED-1&ETHERNET-1;
   ```
