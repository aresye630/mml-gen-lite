# 配置UPF数据

## 操作场景

总部园区部署两套UEG-L，两套UEG-L是负荷分担容灾模式。子园区UEG-S均故障后，不同业务场景下，5G LAN相关组网及报文路径差异如表1所示。

子园区交换机与UPF之间建立VXLAN隧道的场景，图1~图3中的DCGW、Firewall仅用于举例，5G LAN业务对DCGW、Firewall数量无特殊要求。

**表1** 5G LAN组网及报文路径

| 业务场景 | 负荷分担容灾模式 |
| --- | --- |
| 场景一：子园区5G LAN层二终端与子园区Server（Main PLC/MES/...）互通 | 组网如图1所示。  子园区UEG-S均故障后，总部园区UEG-L之间采用负荷分担容灾模式，两个UEG-L均处理子园区用户数据业务，5G LAN层二终端通过某一UEG-L与Server（Main PLC/MES/...）互通。  说明：  5G LAN层二终端与Server（Main PLC/MES/...）在不同网段时，层二终端所在PC上需要配置网关IP，网关IP配置在子园区侧VXLAN交换机上或独立的网关设备上。 |
| 场景二：同一5G LAN组的层二终端互通 | * 组网如图2所示。子园区UEG-S均故障后，总部园区UEG-L之间采用负荷分担容灾模式，子园区用户在总部园区UEG-L上激活，同一5G LAN组下不同终端通过**同一UEG-L或不同UEG-L**接入。 * 组网如图3所示。子园区UEG-S故障恢复后，子园区用户在子园区UEG-S激活，子园区UEG-S故障恢复前在UEG-L上激活的用户还未下线，同一5G LAN组下不同终端通过**UEG-L与UEG-S**接入。   子园区交换机与总部、子园区UPF之间建立VXLAN隧道的场景，则需要根据LSW的能力判断是否需要多对LSW。总部园区和子园区UPF仅对接一对子园区企业侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。  说明：  * LSW支持VXLAN进VXLAN出（接收VXLAN报文，处理后重新封装成VXLAN报文发出）时，可只部署一对LSW。否则，需要两对LSW。图2以2对LSW为例。图3以1对LSW为例。 * 同一5G LAN层二终端IP在不同网段且存在互通诉求时，层二终端所在PC上需要配置网关IP，网关IP配置在子园区企业侧VXLAN交换机上或独立的网关设备上。 * 两组LSW之间，通过直连线互通或者其他LSW互通。 |

当存在如下情况时，可以参考本页面进行配置。

* CPE下挂多个终端（最多16个）。
* 同一个二层广播域内的终端IP必须不同。
* 支持如下几种典型业务场景：
  + 5G LAN层二终端与Server（Main PLC/MES/...）需要互通。

    Server（Main PLC/MES/...）部署在N6侧。
  + 同一5G LAN组层二终端之间通过同一UPF互通。
  + 同一5G LAN组层二终端之间通过不同UPF互通，即总部园区2个UEG-L之间、总部园区UEG-L与子园区各UEG-S之间。

    子园区交换机与UPF之间建立VXLAN隧道的场景下，需要根据LSW的能力判断是否需要多对LSW（用于建立VXLAN隧道）。LSW支持VXLAN进VXLAN出（接收VXLAN报文，处理后重新封装成VXLAN报文发出）时，可只部署一对LSW。否则，需要每台UEG对接一对LSW。

    两个UPF仅对接一对子园区侧VXLAN交换机时，可通过UPF间的VXLAN隧道实现跨UPF的终端互访。

**图1** 子园区UEG-S均故障时，5G LAN层二终端与子园区Server（Main PLC/MES/...）互通）

**图2** 子园区UEG-S故障时，同一5G LAN组的层二终端在总部园区UEG-L互通

**图3** 子园区UEG-S恢复，同一5G LAN组的层二终端在总部园区UEG-L与子园区UEG-S之间互通

## 任务示例

任务描述

子园区交换机与UPF之间建立VXLAN隧道的场景，两个VXLAN交换机是堆叠组网或M-LAG组网时，两个VXLAN交换机都是只需要提供一个VTEP IP。

总部园区的UPF和子园区的UPF对接同一对子园区VXLAN交换机时，支持UPF之间建立VXLAN隧道，用于实现跨UPF的终端互访。两端UPF作为VXLAN隧道端点，都必须配置上本端的VTEP IP，用于对端UPF互通的端点信息。本任务以一个UPF配置VXLAN隧道为例。

不同的5G LAN组共用VTEP，一个5G LAN组对应一个VNI。如图4所示。

相对于UEG-L独立部署场景下的5G LAN功能配置，UDM、AMF、SMF、子园区LSW、无线基站、CPE终端数据配置均可以参考“5GC toB 原子能力-5G LAN>网络部署>配置实例>层二5G LAN配置实例（UEG-L）”章节。此处仅提供UPF侧数据配置。

**图4** VXLAN隧道数据规划图

脚本

1. 公共5G LAN配置。
   1. 配置UPF 5G LAN全局参数。总部园区5G LAN终端接入功能已配置，则无需重复配置。

      //开启5G LAN特性的License配置开关。

      ```
      SET LICENSESWITCH: LICITEM="LKV3G5LANB01", SWITCH=ENABLE;
      ```

      //开启5G LAN功能。

      ```
      SET NGLANFUNC: NGLANSW=ENABLE;
      ```
   2. 配置5G LAN业务的缺省PCC规则。如总部园区5G LAN终端接入功能已配置规则，则不需要重复配置。推荐复用。

      //配置URR。

      ```
      ADD URR:URRNAME="5glan_urr_offline", URRID=2222, USAGERPTMODE=OFFLINE, OFFMETERINGTYPE=VOLUME;
      ADD URR:URRNAME="5glan_urr_online", URRID=1111, USAGERPTMODE=ONLINE, ONLMETERINGTYPE=VOLUME, DFTQUOTAPARA=Byte; 
      ADD URR:URRNAME="ycll_01_cbb_offline", URRID=10002, USAGERPTMODE=OFFLINE, OFFMETERINGTYPE=VOLUME; 
      ADD URR:URRNAME="ycll_01_cbb_online", URRID=2, USAGERPTMODE=ONLINE, ONLMETERINGTYPE=VOLUME, DFTQUOTAPARA=Byte; 
      ADD URRGROUP:URRGROUPNAME="5glan_urrgroup", UPURRNAME1="5glan_urr_offline", DOWNURRNAME1="5glan_urr_offline", UPURRNAME2="5glan_urr_online", DOWNURRNAME2="5glan_urr_online"; 
      ADD URRGROUP:URRGROUPNAME="ycll_01_ch_p", UPURRNAME1="ycll_01_cbb_online", DOWNURRNAME1="ycll_01_cbb_online", UPURRNAME2="ycll_01_cbb_offline", DOWNURRNAME2="ycll_01_cbb_offline"; 
      ADD PCCPOLICYGRP:PCCPOLICYGRPNM="5glan_pcc_p_g", FUPSESSIONEXC=DISABLE, EVENTCHARGEFLAG=DISABLE, EVENTCHGPOINT=RESPONSE, MMSCHARGETYPE=SINGLE, SIGNALASSOCIATE=ENABLE, ADCMUTEFLAG=ENABLE, HTTP2DEGRADESW=INHERIT, TOKENFUNCFLAG=DISABLE, URRGROUPNAME="5glan_urrgroup", SIGURRGRPNAME="ycll_01_ch_p";
      ```

      //预定义规则场景，配置流过滤器，any-to-any。

      ```
      ADD FILTER:FILTERNAME="any", L34PROTTYPE=STRING, L34PROTOCOL=ANY, MSSTARTPORT=0, MSENDPORT=65535, SVRSTARTPORT=0, SVRENDPORT=65535; 
      ADD FILTERIPV6:FILTERNAME="any_ipv6", L34PROTTYPEV6=STRING, L34PROTOCOL=ANY, MSSTARTPORT=0, MSENDPORT=65535, SVRSTARTPORT=0, SVRENDPORT=65535; 
      ADD FLOWFILTER:FLOWFILTERNAME="any_f_f", TETHERDETFLAG=NONE, FLOWFILTERTYPE=USERCONFIG; 
      ADD FLTBINDFLOWF:FLOWFILTERNAME="any_f_f", FILTERNAME="any"; ADD FLTBINDFLOWF:FLOWFILTERNAME="any_f_f", FILTERNAME="any_ipv6";
      ```

      //配置5G LAN业务相关的rule和userprofile。

      ```
      ADD RULE: RULENAME="fglan_r_any", POLICYTYPE=PCC, FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="any_f_f", POLICYNAME="5glan_pcc_p_g"; 
      ADD USERPROFILE: USERPROFILENAME="fglan_u_p_any"; 
      ADD RULEBINDING: USERPROFILENAME="fglan_u_p_any", RULENAME="fglan_r_any"; 
      SET URRGRPBINDING:USERPROFILENAME="fglan_u_p_any", TCPCHGPROFLAG=NOTCONFIG, DFTSIGURRGNAME="ycll_01_ch_p"; 
      SET REFRESHSRV: REFRESHTYPE=ALL;
      ```
   3. DCGW与UEG之间建立VXLAN隧道的场景，修改外联口MTU值。如下IFNAME值仅为举例，实际请修改为传输VXLAN隧道报文的外联口名称。

      //Eth-trunk接口组网时，不需要修改成员接口的MTU值。若规划的成员接口在加入Eth-trunk前修改了MTU值，则会导致添加成员接口失败。

      ```
      MOD INTERFACE:IFNAME="Eth-trunk1.100",IFMTU=1600;
      ```
2. 新增一个子园区UPF的5G LAN配置。
   1. 配置UPF支持的DNN（APN）信息。

      //支持层二 5G LAN业务的DNN（APN）不需要绑定VPN实例。该APN为子园区用于5G LAN业务的专有DNN（APN）。

      ```
      ADD UPAPN: APN="dnn5glan01";
      ```
   2. 配置UPF支持的5G LAN组。

      //如下仅配置1个5G LAN组。规划多个5G LAN组时，“VNINSTANCE”取值必须不同。

      ```
      ADD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, MACIDLESW=DISABLE, IGMPSNOOPINGSW=DISABLE, IGMPPARSESW=DISABLE, MULTIFLOODSW=DISABLE, BCASTFLOWCTRLSW=ENABLE, UNICASTFLOODSW=DISABLE, N6MACIDLESW=DISABLE;
      ```
   3. 配置VXLAN逻辑接口所属的VPN实例。该VPN为子园区用于5G LAN业务的独立VPN。此处以“VRF\_Enterprise”为例。

      ```
      ADD VPNINST: VPNINSTANCE="VRF_Enterprise";
      ```
   4. 配置VXLAN逻辑接口。子园区交换机与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”按需配置。

      UPF与另一UPF之间建立VXLAN隧道的场景，复用UPF与子园区交换机之间建立VXLAN隧道的vxlanif接口。

      ```
      ADD LOGICINF: NAME="vxlanif2/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VRF_Enterprise";
      ```
   5. 配置VXLAN隧道组。
      * 路径中的网络设备和对端都支持心跳消息（PING报文）时，请执行：

        ```
        ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0", HEARTBEAT=ENABLE, TIMETHRESHOLD=6, HEARTSUCCLIMIT=3, HEARTFAILLIMIT=3, TIMEOUT=2;
        ```
      * 路径中的网络设备或对端不支持心跳消息（PING报文）时，请执行：

        ```
        ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0", HEARTBEAT=DISABLE;
        ```
   6. 配置VXLAN隧道远端端点（VTEP：子园区VXLAN交换机），VTEPIPV4为远端端点IP，来源于子园区交换机的VXLAN隧道端点IP地址。

      //远端为子园区交换机的VXLAN隧道端点IP地址。

      ```
      ADD VTEP: VTEPNAME="VTEPA", IPVERSION=IPV4, VTEPIPV4="10.10.100.1";
      ```

      //配置VXLAN隧道端点绑定VXLAN隧道组。

      ```
      ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEPA", PRIFLAG=PRIMARY;
      ```
   7. 配置VXLAN隧道远端端点（VTEP：UPF），VTEPIPV4为远端端点IP，来源于隧道对端UPF的VXLAN隧道端点IP地址。对端UPF必须对接到同一对企业侧VXLAN交换机。

      //远端为总部园区UEG-L的VXLAN隧道端点IP地址。

      ```
      ADD VTEP: VTEPNAME="VTEP2", IPVERSION=IPV4, VTEPIPV4="10.1.51.1";
      ```

      //远端为子园区UEG-S的VXLAN隧道端点IP地址。

      ```
      ADD VTEP: VTEPNAME="VTEPA1", IPVERSION=IPV4, VTEPIPV4="10.1.60.1";
      ```

      //配置VXLAN隧道端点绑定VXLAN隧道组。

      ```
      ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP2", PRIFLAG=PRIMARY;
      ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEPA1", PRIFLAG=PRIMARY;
      ```
   8. 绑定5G LAN组与VXLAN隧道组。

      ```
      ADD NGVNBINDVXLAN: VNINSTANCE="000003e9-460-08-01", VXLANGRPNAME="vxlan_01", VNI=5010;
      ```
