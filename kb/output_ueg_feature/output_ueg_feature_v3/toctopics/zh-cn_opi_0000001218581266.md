# 配置UPF数据

## 操作场景

层二终端组成员之间或层二终端组的成员和数据网络中的应用之间进行以太通信时，需要配置5G LAN功能。

## 必备事项

前提条件

* 请仔细阅读GWFD-030701 支持5G LAN组以太通信特性概述和GWFD-030702 支持网络侧基于VxLAN的以太通信特性概述。
* 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。
* UEG已完成与周边网元的对接。

数据

* 配置支持5G LAN组以太通信时，仅需要规划表1和表2中的数据。
* 配置支持网络侧基于VXLAN的以太通信时，需要规划表1~表4中的数据。
* 配置支持5G LAN组以太通信+网络侧基于VXLAN的以太通信时，请规划表1~表4中的数据。
* 配置N6侧免VxLAN隧道层二以太通信时，需要规划表1~表2、表5~表7中的数据和配置N6侧免VxLAN隧道层二以太通信，不需要规划VxLAN隧道相关（表3和表4）的数据。
* 配置支持5G LAN组层三通信时，请规划表8~表9中的数据。

**如下数据仅为举例，请注意修改成局点规划的数据。**

## 任务示例

任务描述

配置5G LAN组标识为“000003e9-460-08-01”的组成员之间及组成员与数据网络中的应用之间提供以太类型的通信服务。

脚本

1. 配置UPF 5G LAN全局参数。

   //开启5G LAN特性的License配置开关。

   ```
   SET LICENSESWITCH: LICITEM="LKV3G5LANB01", SWITCH=ENABLE;
   ```

   //开启5G LAN功能。

   ```
   SET NGLANFUNC: NGLANSW=ENABLE;
   ```
2. 配置UPF支持的DNN（APN）信息。
   * UEG-S时：

     ```
     ADD APN:APN="dnn5glan01";
     ```
   * UEG-M/UEG-L时：

     ```
     ADD UPAPN:APN="dnn5glan01";
     ```
3. 配置UPF支持的5G LAN组。

   ```
   ADD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, MACIDLESW=DISABLE, IGMPSNOOPINGSW=DISABLE, IGMPPARSESW=DISABLE, MULTIFLOODSW=ENABLE, MULTIFLOODRATE=20, BCASTFLOWCTRLSW=ENABLE, UNICASTFLOODSW=DISABLE, N6MACIDLESW=DISABLE;
   ```
4. 配置5G LAN的VXLAN隧道。

   //配置vxlan逻辑接口所属的VPN实例。企业侧交换机与UPF之间建立VXLAN隧道场景按需配置；采用“\_public\_”的VPN实例时，不需要再执行**ADD VPNINST**命令。采用已存在的VPN实例时，不需要重复执行**ADD VPNINST**命令。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_vxlan";
   ```

   //配置VXLAN逻辑接口，作为隧道本端。
   * DCGW与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”必须设置为“\_public\_”。

     ```
     ADD LOGICINF: NAME="vxlanif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="_public_";
     ```
   * 企业侧交换机与UPF之间建立VXLAN隧道的场景，“VPNINSTANCE”按需配置。此处以“VRF\_LocalDN01”为例。

     ```
     ADD LOGICINF: NAME="vxlanif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_vxlan";
     ```

   //配置VXLAN隧道组。

   ```
   ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0";
   ```

   //配置VXLAN隧道远端端点，VTEPIPV4为远端端点IP，来源于企业侧交换机的VTEP地址。

   ```
   ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.10.100.1";
   ```

   //配置VXLAN隧道端点绑定VXLAN隧道组。

   ```
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP1";
   ```

   //配置VXLAN隧道远端端点（VTEP：另一UPF）。两个UPF是负荷分担关系，且仅对接到同一对DCGW/企业侧VXLAN交换机场景，同一5G LAN组内成员跨UPF的互访通过UPF间的VxLAN隧道实现时需要配置，否则不需要配置。VTEPIPV4为远端端点IP，来源于另一UPF的VXLAN隧道端点IP地址。

   ```
   ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.1.50.2";
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP2", PRIFLAG=PRIMARY;
   ```

   //绑定5G LAN组与VXLAN隧道组。

   ```
   ADD NGVNBINDVXLAN: VNINSTANCE="000003e9-460-08-01", VXLANGRPNAME="vxlan_01", VNI=5010;
   ```

   //配置UPF基于5G LAN组粒度支持学习的总MAC地址数。

   ```
   SET NGLANATTR: VNINSTANCE="000003e9-460-08-01", TOTALMACNUM=6000;
   ```

   //配置基于5G LAN组粒度的环路检测功能。此处以采用主动检测为例。

   ```
   SET LICENSESWITCH: LICITEM="LKV3G5LAN2LE", SWITCH=ENABLE;
   ```

   ```
   SET NGLOOPDETFUNC: VNINSTANCE="000003e9-460-08-01", ETHLOOPDETECTSW=ENABLE, DETECTMETHOD=SEND_DETECT_MSG;
   ```

   ```
   SET UPETHSRVPARA: UPETHSRVSW=ENABLE, UPETHSRVMAC="FA-16-3E-A0-04-D6";
   ```

   //DCGW与UEG之间建立VXLAN隧道的场景，修改外联口MTU值。如下IFNAME值仅为举例，实际请修改为传输VXLAN隧道报文的外联口名称。
   * Ethernet接口组网时，主接口和子接口均需要修改：

     ```
     MOD INTERFACE:IFNAME="Ethernet64/0/4",IFMTU=1600;
     MOD INTERFACE:IFNAME="Ethernet64/0/4.100",IFMTU=1600;
     ```
   * Eth-trunk接口组网时，主接口和子接口均需要修改：

     //Eth-trunk接口组网时，不需要修改成员接口的MTU值。若规划的成员接口在加入Eth-trunk前修改了MTU值，则会导致添加成员接口失败。

     ```
     MOD INTERFACE:IFNAME="Eth-trunk1",IFMTU=1600;
     MOD INTERFACE:IFNAME="Eth-trunk1.100",IFMTU=1600;
     ```
5. 配置故障定界所需数据（执行**NGVNVIFPING**获取时延时依赖的数据）。

   //此处配置的是UPF发送的ping探测报文的源MAC地址，建议采用N3逻辑接口对应的物理接口的MAC地址，避免MAC地址冲突。可通过执行**LST LOGICINF**命令，获取N3if或Saif接口绑定的VPN实例，然后再执行**LST INTERFACE**命令获取对应的外联口的MAC地址。

   ```
   SET UPETHSRVPARA: UPETHSRVSW=ENABLE, UPETHSRVMAC="FA-16-3E-A0-04-D6";
   ```

   //基于5G LAN组配置ping探测报文的源IP地址。从DHCP Server获取，该IP地址等同于DHCP Server分配给5G LAN层二终端的IP地址，与5G LAN层二终端的IP地址在同一网段，且不能与5G LAN层二终端的IP地址冲突。

   ```
   ADD NGVNVIF: VNINSTANCE="000003e9-460-08-01", VIFIPTYPE=IPV4, VIFIPV4ADDR="10.99.99.99";
   ```
6. 配置企业DN侧VXLAN隧道数据，请参考配置企业DN侧交换机。
