# 漫游场景5G LAN终端互访控制配置

## 操作场景

* 漫游场景，当运营商禁止终端通过锚点UPF的N9口互访但同一5G LAN组成员存在互访诉求时，可通过本功能允许漫游5G LAN终端与同一5G LAN组的其他终端之间的互访。
* 漫游组网，当运营商禁止终端通过锚点UPF的N9口互访且同一5G LAN组成员不存在互访诉求时，可通过本功能禁止漫游5G LAN终端与同一5G LAN组的其他终端之间的互访。

* 本功能中描述的漫游场景，是指5G LAN终端（主叫或被叫或主叫+被叫）通过I-UPF与锚点UPF交互的场景。
* 同一个层二5G LAN组成员之间默认不禁止互访，同一个层三5G LAN组成员之间默认不禁止互访。

数据

## 操作步骤

1. 设置5G LAN终端漫游互访控制开关。

   **SET NGVNUEMUTACC**
2. 需要基于白名单进行精细化控制时，配置允许5G LAN终端漫游互访的白名单。
   1. 配置白名单。

      **ADD UEMUTACCWLIST**
   2. 配置白名单和5G LAN组绑定。

      **ADD NGBINDUEMUTWL**
3. 将BIT2682软参设置为1。否则，用户N2/Xn切换后下行业务不通。

   ```
   SET SOFTPARA: DT=BIT, BITNUM=2682, BITVALUE=1;
   ```

## 任务示例

任务描述

* 任务示例1：漫游场景，运营商禁止漫游终端互访且5G LAN终端之间没有互访诉求时，配置基于5G LAN组禁止漫游5G LAN终端与该5G LAN组中的其他终端互访。
* 任务示例2：漫游场景，运营商禁止漫游终端互访但5G LAN终端之间存在互访诉求，且无论漫游5G LAN终端通过哪个I-UPF的N9口与锚点UPF交互时，配置基于5G LAN组允许漫游5G LAN终端与该5G LAN组中的其他终端互访。
* 任务示例3：漫游场景，运营商禁止漫游终端互访但5G LAN终端之间存在互访诉求，且漫游5G LAN终端仅可能通过某些I-UPF的N9口与锚点UPF交互时，配置基于5G LAN组+白名单方案允许漫游5G LAN终端与该5G LAN组中的其他终端互访。

脚本

**//任务示例1**

//此处以禁止漫游5G LAN终端与该5G LAN组中的其他终端互访为例，禁止所有漫游互访的报文（单播、组播、广播）。

```
SET NGVNUEMUTACC: VNINSTANCE="000003e9-460-08-01", N9AUE2UEUNIPOL=FORBID_FWD, N9AUE2UEMULPOL=FORBID_FWD, N9AUE2UEBROPOL=FORBID_FWD;
```

**//任务示例2**

//此处以允许漫游5G LAN终端与该5G LAN组中的其他终端互访，互访报文包括单播、组播和广播为例。请根据局点实际业务规划允许哪类报文。

```
SET NGVNUEMUTACC: VNINSTANCE="000003e9-460-08-01", N9AUE2UEUNIPOL=ALLOW_FWD, N9AUE2UEMULPOL=ALLOW_FWD, N9AUE2UEBROPOL=ALLOW_FWD;
```

**//任务示例3**

//此处以基于5G LAN组+白名单方案允许漫游5G LAN终端与该5G LAN组中的其他终端互访，互访报文包括单播、组播和广播为例。

```
SET NGVNUEMUTACC: VNINSTANCE="000003e9-460-08-01", N9AUE2UEUNIPOL=WHITELIST_FWD, N9AUE2UEMULPOL=WHITELIST_FWD, N9AUE2UEBROPOL=WHITELIST_FWD;
```

//此处以允许漫游5G LAN终端通过2个I-UPF的N9口与锚点UPF交互为例，实际请根据局点实际业务规划配置白名单。

```
ADD UEMUTACCWLIST: WLISTNAME="I-UPF-01", IPVERSION=IPV4, IPV4START="192.168.111.1", IPV4END="192.168.111.1";
ADD NGBINDUEMUTWL: VNINSTANCE="000003e9-460-08-01", WLISTNAME="I-UPF-01";
```

```
ADD UEMUTACCWLIST: WLISTNAME="I-UPF-02", IPVERSION=IPV4, IPV4START="192.168.112.1", IPV4END="192.168.112.1";
ADD NGBINDUEMUTWL: VNINSTANCE="000003e9-460-08-01", WLISTNAME="I-UPF-02";
```

//（**公共配置**）将BIT2682软参设置为1。否则，用户N2/Xn切换后下行业务不通。

```
SET SOFTPARA: DT=BIT, BITNUM=2682, BITVALUE=1;
```
