# 激活基于5G的网络共享（MOCN）

## 操作场景

本操作指导介绍在运行网络中激活基于5G的网络共享（MOCN）特性的操作过程。

适用于AMF。

## 必备事项

前提条件

* 请仔细阅读基于5G的网络共享（MOCN）特性概述。
* 到AMF的基本数据已经配置完成，配置方法请参见《初始配置与调测》。
* 已完成加载License。

数据

该操作无需准备数据。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开基于5G的网络共享（MOCN）功能开关。

   SET LICENSESWITCH

## 任务示例

任务描述

运营商A采用自己的核心网设备，但A租用运营商X的接入设备进行组网建设。

脚本

//开启5G的网络共享（MOCN）功能。

```
SET LICENSESWITCH: LICITEM="LKV2MOCN04", SWITCH=ENABLE;
```
