#### 操作场景

实例化网元是根据VNFD文件中的配置数据，加载镜像和业务软件包的过程。网元完成实例化后，才可以正常工作。

运营商网络中实例化网元时，需要保证网元与FusionStage间有足够的带宽（建议不小于5MB/s） ，如果带宽过小，会导致VNF下载文件超时引起网元实例化失败。

**当网元部署后没有立刻进行使用，再次使用时可能会出现“调用服务超时，请检查网络是否正常”报错，如出现该报错，请联系华为工程师解决。**

在实例化网元前，如果在FusionSphere OpenStack OM上创建了逻辑网络，则必须先在MAE-VNF LCM/U2020 VNF LCM上同步云服务，将FusionSphere OpenStack OM的配置数据同步到MAE-VNF LCM/U2020 VNF LCM，然后再实例化网元。

#### 操作步骤

1. 登录MAE-VNF LCM/U2020 VNF LCM业务面客户端。

   1. 在浏览器地址栏中输入以下地址后按回车键。

      **https://MAE-VNF LCM/U2020 VNF LCM业务的IP地址:端口号/**（例如https://10.50.12.104:31943/）
   2. 输入用户名和密码。

      系统默认的用户名和密码是“admin/Changeme\_123”，如果已修改MAE-VNF LCM/U2020 VNF LCM客户端用户名和密码，请使用新设置的用户名和密码登录。
   3. 单击“登录”，在MAE主界面的“应用”区域，单击“VNF LCM”，进入MAE-VNF LCM/U2020 VNF LCM系统界面。
2. 单击图标，选择“VNF总览”。
3. 进入“VNF生命周期管理”窗口，单击“VNF部署”。
4. 确认CSPVNFD的“状态”是“可用”的情况下，勾选中对应的VNFD。

   **在UEG-M场景下，****可以将三个网元并行部署；如果需要单独部署网元，则需要****遵循先部署CSP再并行拉起UEG和USCDB。**

   * **方案一（三个网元并行部署）：****需****同时勾选****CSP VNFD、UEG VNFD和USCDB VNFD，****再****执行5。**
   * **方案二（先部署CSP再并行拉起UEG和USCDB）：****先****勾选CSP VNFD，待CSP VNF部署完成后，****再同时****勾选UEG VNFD和USCDB VNFD，执行5。**
5. 单击“部署”，进入“VNF部署”页面。

   **图1** 进入“VNF部署”页面
6. 设置VNF部署页面的参数：
   1. 设置“任务名称”（系统会默认生成任务名称，用户也可以自行定义）。
   2. **（可选）**选择节点。

      仅当VNF LCM为融合部署形态时，有此菜单。

      * **场景一**：直接用VNF LCM部署VNF时（即没有VNFM Agent时），无需配置本参数，本参数为“--”。
      * **场景二**：仅当中心VNF LCM对接VNFM Agent，部署边缘站点时，需要将本参数配置为边缘站点。
   3. 单击“部署计划”的下拉框，选择待部署VNF对应的规格，随之界面参数会随VNFD模板自动加载到本页面。

      规格选择原则同Plan文件的选取原则。

      在VNF的部署界面，选择部署计划Plan的时候，可用的部署Plan用户可以单击选择，不可用的部署Plan显示为灰色，用户只能看见不能选择。
   4. 调整“输入参数”取值。
      * 在MAE-VNF LCM/U2020 VNF LCM界面可以修改VNFD模板数据，选择“输入参数”区域框，请参见VNFD参考，在对应的参数后输入设置值。

        参数输入原则：

        + 密码类参数：允许输入~!@#$?()\_-+|:./特殊字符 、数字字符、英文字符（包括大小写）。
        + 非密码类参数：限定长度 40个字符。允许输入\_\*:/-,.特殊字符 、数字字符、英文字符（包括大小写）。
      * VNFM\_PASSWD的密码类参数，必须在MAE-VNF LCM/U2020 VNF LCM界面输入正确后才有效。
   5. 之后单击“下一步”，系统开始对VNFD参数进行校验。VNFD参数校验过程中，存在以下两种情况：

      * 如果在界面上输入的“VlanId”值相同，或者VNFD配置时中多处网络引用同一个VlanId，则会弹出“确认”对话框，提示用户“VlanId”的值重复。
      * 如果在界面上输入的“VlanId”值，是I层已经存在的“VlanId”，会弹出“确认”对话框，提示用户“VlanId”的值已经存在。

      用户根据配置需要，选择“是”或者“否”。

      * 单击“下一步”后，系统会校验VNFD模板中部分参数 （例如VNFM帐户信息VNFM\_USERNAME、DC\_ID）填写是否正确。如果正确，则继续实例化；否则提示报错，终止实例化过程。
      * 如果VNFD模板中与I层配置有关联的参数填写有误，VM创建的时候会显示失败，并提示失败相关信息。
      * 先进行CSP网元部署如图2所示，再按照设置VNF部署页面的参数进行其他网元部署。

      **图2** 设置VNF部署页面的参数
7. 确认参数设置无误后，单击“确定”，网元开始执行实例化。
8. 系统跳转到首页，可以监控解决方案、网元和虚拟机的部署过程。如果安装失败，请参见基于VNF LCM安装VNF失败后的操作。

   **图3** 查看VNF部署进度与日志
9. 实例化完成后（进度为100%），查看部署任务状态显示“部署成功”。

   实际VNF实例化的过程用时与网络状况有关系。一般情况下大约需要40~60分钟。

   实例化完成后，请等待10分钟让系统加载MML服务和跟踪服务，然后再下发MML命令，创建消息跟踪。从而验证MML服务和跟踪功能已正常。

   若功能异常，请联系华为工程师解决。
10. 部署成功后，运行RMV MODULE，删除2/3/4G使用的HSF和BSG的Module。

    **图4** 删除2/3/4G使用的HSF和BSG的Module
11. **（可选）**检查VNF已经归属到规划的EMS。

    仅当VNF LCM为独立部署形态时，需要在VNF LCM上检查，VNF已经归属到规划EMS。

    **图5** 检查VNF已经归属到规划的EMS
