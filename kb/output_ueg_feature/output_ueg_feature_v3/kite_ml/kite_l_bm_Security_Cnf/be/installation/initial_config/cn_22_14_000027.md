# 配置PGW的接入权限

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

客户端通过IP地址与PGW服务器进行连接时，为了保证USCDB中存储的数据安全，PGW服务器需要支持通过客户端的IP地址对客户端进行鉴权，只有鉴权通过的客户端才允许接入到PGW服务器。

客户端包括以下几种：

* PGW Web LMT：提供文件管理、用户管理、业务发放功能。
* 业务发放系统：提供用户管理、业务发放功能。
* DMS WebUI：提供数据的灵活导出和统计模板的管理功能。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

向系统管理员获取OM Portal帐号的密码。

**数据**

执行该操作前，规划好允许接入PGW的IP地址。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**ADD PROVISIONIP**命令，添加允许接入PGW的IP地址。

   以IP类型为IPv4举例：

   ```
   ADD PROVISIONIP: ADDRID=IP地址索引, ADDRNAME=IP地址名称, IPVER=IP类型, IPV4ADDR=IPV4地址, IPTYPE=IP地址类型;
   ```
3. 执行**SET GRANTIPSWITCH**命令，关闭不需要的端口。

   以关闭SOAP端口举例：

   ```
   SET GRANTIPSWITCH: PORTTYPE=SOAP, SWITCH=OFF;
   ```
4. 执行**MOD INSP**命令，打开IP限制开关。

   ```
   MOD INSP: INSPT=PGW, INSPN=GRANTIPSWITCH, INSPV=1;
   ```
