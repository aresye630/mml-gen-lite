# 删除用户

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

在日常的操作维护活动中，系统管理员可以删除不再使用或者已过期的用户，以提高系统的安全性。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

只有具有管理员权限的用户才能删除其他用户。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 操作员名称

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 执行命令**RMV OPR**删除操作员。

   ```
    RMV OPR: SYSNO=1, OPNAME="pgwuser";
   ```
