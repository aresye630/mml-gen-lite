# 切换PGW Web LMT访问方式

#### 操作场景

当USCDB与PGW Web LMT对接时，PGW Web LMT提供两种访问方式：HTTP和HTTPS。USCDB通过WEBLMTHTTPSSWITCH（weblmt https控制开关）控制PGW Web LMT访问PGW服务器的方式，在传输数据时HTTPS会建立一个信息安全通道，该通道用于提供加密通讯及对网络服务器身份的鉴定，因此出于安全考虑，推荐使用HTTPS方式。

* 新安装的场景，默认采取HTTPS方式访问。软参“weblmt https控制开关”默认设置为“1”，在浏览器地址栏中输入PGW服务器IP地址后，采取HTTPS方式访问。
* 升级场景，保留升级前的访问方式。

  + 如果升级前软参“weblmt https控制开关”设置为“1”，升级后在浏览器地址栏中输入https://IP:port（port为“PORT\_FOR\_CLIENT”类型端口的值，默认为“80”），采取HTTPS方式访问。
  + 如果升级前软参“weblmt https控制开关”设置为“0”，升级后在浏览器地址栏中输入http://IP:port（port为“PORT\_FOR\_CLIENT”类型端口的值，默认为“80”），采取HTTP方式访问，请按照操作步骤将HTTP访问方式切换到HTTPS方式。

#### 对系统的影响

* 配置完成后需要重启PGW模块，将导致短暂的业务发放指令执行失败。
* PGW的处理速度将会下降10%。

#### 必备事项

**前提条件**

* 已获取OM Portal的帐号和密码。
* 确认已加载“连接类型”为“WEBLMT”的“CAVERIF(CA证书)”或“ROOTVERIF(根证书)”、“DEVVERIF(设备证书)”和“KEYFILE(密钥文件)”的证书文件。可通过在“USCDB MML命令”界面执行**LST VERIF**命令查询。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令修改软参“WEBLMTHTTPSSWITCH”的值为“1”，打开“weblmt https控制开关”。

   ```
   MOD INSP: INSPT=PGW, INSPN=WEBLMTHTTPSSWITCH, INSPV=1;
   ```
3. 执行**MOD PORT**命令修改端口信息，将“PORT\_FOR\_CLIENT”端口值更改为HTTPS登录端口。

   ```
   MOD PORT: PORTNO=443, PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_CLIENT;
   ```
4. 执行**ADD PORT**命令添加HTTP访问方式的端口，“端口类型”为“PORT\_FOR\_REDIRECT”。

   ```
   ADD PORT: PORTNO=80, PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_REDIRECT;
   ```
5. 执行**LST MODULE**命令查询PGW的模块号。

   ```
   LST MODULE: MT=PGW;
   ```
6. 重启PGW进程会导致短暂的业务发放指令执行失败，因此推荐此操作在夜间执行，请运营商客户提前做好准备。

   执行**RST MODULE**命令重启PGW模块。

   ```
   RST MODULE: MID=模块号, MT=PGW;
   ```
7. 执行**LST SRVIPADDR** 命令查询PGW Web LMT的IP地址。

   ```
   LST SRVIPADDR: SRVIPTYPE=PGW;
   ```
8. 在浏览器地址栏输入查询到的PGW Web LMT的IP地址及端口号（默认端口号为80）、http://IP：80或https://IP：443，以HTTPS方式访问PGW Web LMT界面。

#### 附加信息

**相关任务**

PGW Web LMT访问方式为HTTPS，PGW的处理速度将会下降10%。如运营商客户评估后需将访问方式切换为HTTP方式，按如下步骤进行切换。

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令修改软参“WEBLMTHTTPSSWITCH”的值为“0”，关闭“weblmt https控制开关”。

   ```
   MOD INSP: INSPT=PGW, INSPN=WEBLMTHTTPSSWITCH, INSPV=0;
   ```
3. 执行**LST PORT**命令查询到“端口类型”为“PORT\_FOR\_WEBLMT”，“端口子类型”为“PORT\_FOR\_REDIRECT”的端口号。

   ```
   LST PORT: PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_REDIRECT;
   ```
4. 执行**RMV PORT**命令删除查询到的端口号。

   ```
   RMV PORT: PORTNO=端口号;
   ```
5. 执行**MOD PORT**命令修改“端口子类型”为“PORT\_FOR\_CLIENT”的端口号。

   ```
   MOD PORT: PORTNO=80, PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_CLIENT;
   ```
6. 执行**LST MODULE**命令查询PGW模块号。

   ```
   LST MODULE: MT=PGW;
   ```
7. 重启PGW进程会导致短暂的业务发放指令执行失败，因此推荐此操作在夜间执行，请运营商客户提前做好准备。

   执行**RST MODULE**命令重启PGW模块。

   ```
   RST MODULE: MID=模块号, MT=PGW;
   ```
8. 执行**LST SRVIPADDR**命令查询PGW Web LMT的IP地址。

   ```
   LST SRVIPADDR: SRVIPTYPE=PGW;
   ```
9. 在浏览器地址栏输入http://IP:port（port为“PORT\_FOR\_CLIENT”类型端口的值，默认为“80”），以HTTP方式访问PGW Web LMT界面。
