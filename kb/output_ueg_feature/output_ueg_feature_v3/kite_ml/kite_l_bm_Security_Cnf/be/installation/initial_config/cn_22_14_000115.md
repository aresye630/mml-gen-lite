# 配置业务发放系统的安全接入策略

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

当USCDB与业务发放系统均完成硬件数据和基础数据的配置后，需要配置业务发放系统的安全接入策略。

业务发放系统的安全策略包括以下两方面：

* 当局点只使用MML协议接入业务发放系统，建议关闭SOAP协议接入的端口。
* 当局点只使用SOAP协议接入业务发放系统，建议关闭MML协议接入的端口。

#### 对系统的影响

* 若关闭MML类型的端口，只能关闭**LST PORT**命令查询出来的“端口类型”为“PORT\_FOR\_PROV”，“端口子类型”为“PORT\_FOR\_SOAP”的端口，不能关闭WEBLMT的服务端口，否则无法登录维护界面，且系统无法通过MML连接PGW服务器进行业务发放。
* 若关闭SOAP类型的端口，则系统无法通过SOAP连接PGW服务器进行业务发放。

#### 必备事项

**前提条件**

已获取OM Portal的帐号和密码。

**数据**

执行此操作前，规划好关闭MML协议和SOAP协议接入端口的参数的取值。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
   * 若该局点只使用MML协议接入营帐，则关闭SOAP协议接入的端口：
     1. 执行**LST PORT**命令查询所有“端口类型”为“PORT\_FOR\_PROV”， “端口子类型”为“PORT\_FOR\_SOAP”的端口。

        ```
        LST PORT: PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_SOAP;
        ```
     2. 执行**MOD PORT**命令将该端口的“是否屏蔽本端口”置为“YES”。

        ```
        MOD PORT: PORTNO=端口号, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_SOAP, DISABLEPORT=YES, PORTBUSSTYPE=端口业务类型;
        ```
   * 若该局点只使用SOAP协议接入营帐，关闭MML协议接入的端口：
     1. 执行**LST PORT**命令查询所有“端口类型”为“PORT\_FOR\_WEBLMT”， “端口子类型”为“PORT\_FOR\_LMT\_MML”的端口。

        ```
        LST PORT: PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_LMT_MML;
        ```
     2. 执行**MOD PORT**命令将该端口的“是否屏蔽本端口”置为“YES”。

        ```
        MOD PORT: PORTNO=端口号, PORTTYPE=PORT_FOR_WEBLMT, PORTTYPENAME=PORT_FOR_LMT_MML, DISABLEPORT=YES,PORTBUSSTYPE=端口业务类型;
        ```
2. 重启PGW进程会导致短暂的业务发放指令执行失败，因此推荐此操作在夜间执行，请运营商客户提前做好准备。

   重启所有PGW模块使修改生效。
   1. 执行**LST MODULE**命令查出所有PGW模块号。

      ```
      LST MODULE: MT=PGW;
      ```
   2. 按查询得到的PGW模块号依次执行**RST MODULE**命令重启模块。连续的命令间请间隔一分钟，以等待上一模块启动后再重启下一模块。

      ```
      RST MODULE: MID=模块号, MT=PGW;
      ```
