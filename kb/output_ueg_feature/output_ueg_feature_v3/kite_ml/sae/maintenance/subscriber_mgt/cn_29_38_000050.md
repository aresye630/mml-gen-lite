# 批操作

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该任务指导操作人员通过PGW Web LMT客户端完成批操作。

批操作可以完成以下任务：

* 同时为多个用户提供加载KI、开户、改号、补卡等业务操作
* 批量执行MML命令

## 必备事项

前提条件

连续/非连续号段批操作和文件批操作需要在执行任务前准备批操作文件。

数据

按照批操作资源文件格式编辑批操作文件，批操作文件的后缀名为.txt。

文件批操作使用的批操作资源文件是纯文本文件(如\*.txt类型)，将一些常用任务的操作命令或者完成特定任务的一组命令用文本形式保存，以后运行时无须再手动输入单条命令，直接执行该文本文件中的命令即可。

## 操作步骤

1. 登录PGW Web LMT MML命令界面。
2. 执行批操作。

   《用户管理》手册开户、销户、补卡、改号等页面提到的批操作，均可参考以下四种批操作之一。

   * **非连续号段批操作**

     1. 单击“文件管理器”，上传批操作文件到指定目录。

        上传的具体操作请参见上传文件。

        如果需要下载或删除批操作文件，操作方法请参见下载文件或删除文件。
     2. 执行批操作。

        当为多个非连续号段用户进行鉴权数据管理、用户管理以及签约各种业务时，执行相应命令，输入批操作文件名和其他相关参数。

        命令举例：

        ```
        ADD KI: HLRSN=1, FNAME="ADDKI.txt", K4SNO=2, CARDTYPE=SIM, ALG=COMP128_3;
        ```

        上述举例完成为多个非连续号段用户通过批操作加载KI，批操作文件格式请参见**必备事项**中的**数据**。
   * **连续号段批操作**

     当为多个连续号段用户进行鉴权状态管理、用户管理以及签约各种业务时，执行相应命令，输入“IMSI”或“MSISDN”、“用户个数”和其他相关参数。

     命令举例：

     ```
     LST AUCSTATUS: IMSI="460000009012345", RECORDCOUNT=10;
     ```

     上述举例完成查询IMSI起始号码为460000009012345的10个连续号码用户的鉴权状态。
   * **文件批操作**

     1. 单击“文件管理器”，上传批操作文件到指定目录。

        上传的具体操作请参见上传文件。

        如果需要下载或删除批操作文件，操作方法请参见下载文件或删除文件。
     2. 执行**BAT**命令，输入“文件名”和“执行时间”。
   * **批处理MML**

     PGW WebUI上的操作请参见批处理。
