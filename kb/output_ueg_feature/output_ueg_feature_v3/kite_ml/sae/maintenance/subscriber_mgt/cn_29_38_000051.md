# 开户

## 操作场景

运营商通过PGW Web LMT可以为用户开户。

PGW提供强大的开户功能，不仅可以为单个用户开户，而且可以同时为多个用户批开户。为了简化操作，还提供了模板开户功能。

常见的开户方法有两种：

* 执行**ADD SUB**命令开户，适用于为单个用户开户或大量用户批开户的情况。
* 事先设置各种开户模板，执行**ADD TPLSUB**命令进行模板开户。此种开户方式适用于有约定功能的用户进行开户的情况。同时，为了简化操作，增加或者修改各种业务也可以通过事先设置业务模板，然后采用模板进行增加或者修改。

## 必备事项

前提条件

* 操作员需要收集用户开户涉及的参数并根据实际情况规划配置参数。
* 操作员具有PGW Web LMT客户端业务发放权限。
* 操作员有登录PGW Web LMT的用户名和密码。

数据

需要开户的MSISDN和IMSI号码。

开户需要规划以下数据：

* 鉴权数据，如鉴权算法、K4值、KI值
* 模板数据，包括开户模板或者业务模板

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 配置鉴权数据。
   1. 执行**LST KI**命令，查询用户的KI是否已经加载。

      * 是 => 3
      * 否 => 2.b
   2. 加载KI。

      * GSM/UMTS用户加载KI的过程请参见配置GSM鉴权（2G鉴权）和配置UMTS鉴权（3G鉴权）。
      * EPS用户加载KI的过程请参见配置EPS-AKA鉴权和配置EAP-AKA和EAP-AKA'鉴权。
      * 5GS用户加载KI的过程请参见配置5G鉴权数据。

      * 使用开户模板进行开户，请执行3～4。
      * 不使用开户模板，仅进行普通开户，请执行5～6。
3. 执行**ADD SUBTPL**命令，制作开户模板。

   使用**LST SUBTPL**命令查询，如果要使用的开户模板已经存在，该步骤可以省略。
4. 执行**ADD TPLSUB**命令进行模板开户。
5. 如果需要提供CAMEL业务、LCS业务、GPRS业务、漫游限制业务、VBS、VGCS和5G等业务，设置相应的业务模板请参见配置5G模板数据、配置SAE-HSS模板数据、配置IMS-HSS模板数据和配置5G模板数据。
6. 执行命令**ADD SUB**进行开户。
