# 配置NB-IoT鉴权数据

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该操作指导工程师在开局阶段， 新建UDM作为SAE-HSS网元时，完成NB-IoT鉴权数据的配置。

## 必备事项

前提条件

* 已经完成UDM的OMU侧的硬件数据和基础数据的配置。
* 已经完成NB-IoT的用户数据规划。

数据

执行操作前需要规划的数据如表1所示。

**表1** NB-IoT鉴权数据

| 命令 | 参数名称 | 取值样例 | 说明 |
| --- | --- | --- | --- |
| **ADD AMF** | HLRSN (HLR序列号) | 1 | 与**ADD KI**中的“HLR序列号”保持一致。 |
|  | AMFSNO (AMF序列号) | 3 | 运营商统一规划。 |
|  | AMFVALUE (AMF值) | 1111 | 鉴权管理域，用于计算MAC。 |
| **ADD K4** | HLRSN (HLR序列号) | 1 | 与**ADD KI**中的“HLR序列号”保持一致。 |
|  | K4SNO (K4序列号) | 4 | 运营商统一规划。 |
|  | K4VALUE (K4值) | 1234567890abcdef | 用于标识K4密钥值。 |
| **ADD OP** | HLRSN (HLR序列号) | 1 | 与**ADD KI**中的“HLR序列号”保持一致。 |
|  | OPSNO (OP序列号) | 1 | 运营商统一规划。 |
|  | OPVALUE (OP值) | 1234567890abcdef1234567890abcde1 | MILENAGE鉴权算法的一个输入参数，需与USIM卡中烧制的OP值一致。 |
| **ADD KI** | HLRSN (HLR序列号) | 1 | 需通过命令**ADD HLRSN**添加后才可在此引用。 |
|  | IMSI(IMSI) | 460000009123456 | IMSI号码。 |
|  | OPERTYPE (操作类型) | ADD | 运营商统一规划。 |
|  | KIVALUE (KI值) | 1234567890ABCDEF1234567890ABCDEF | 运营商统一规划。 |
|  | K4SNO (K4序列号) | 4 | 与**ADD K4**中的“K4序列号”保持一致。 |
|  | CARDTYPE (卡类型) | USIM | 运营商统一规划。 |
|  | ALG (鉴权算法类型) | MILENAGE | 运营商统一规划。 |
|  | OPSNO (OP序列号) | 1 | 与**ADD OP**中的“OP序列号”保持一致。 |
|  | AMFSNO (AMF序列号) | 3 | 与**ADD AMF**中的“AMF序列号”保持一致。 |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD AMF**命令设置AMF值。
3. 执行**ADD K4**命令设置用于加密KI的K4值。
4. 如果USIM卡中烧制了OP，执行**ADD OP**命令设置OP值。

   在WCDMA/TD-SCDMA网络中，设置OP值时，要注意以下几点：

   * USIM卡中烧制了OP时，要设置OP值。
   * USIM卡中烧制了OPC时，不用设置OP值。
5. 如果需要进行批量操作，编写KI批操作文件，并上传到PGW Server指定位置。

   编写KI批操作文件时，要注意以下几点：

   * KI批操作文件的格式和上传位置请参见批操作管理。

     使用MILENAGE算法时:
     + USIM卡中烧制了OPC时，KI批操作文件中要包含参数OPC。
     + USIM卡中烧制了OP时，KI批操作文件中不包含参数OPC。
   * KI批操作文件的上传方法请参见管理文件。
6. 执行**ADD KI**命令加载KI。

   * 参数“卡类型”设置为“USIM”。
   * 参数“鉴权算法类型”根据实际需求进行设置。
