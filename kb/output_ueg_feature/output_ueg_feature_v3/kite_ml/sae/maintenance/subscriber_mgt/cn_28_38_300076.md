## 操作场景

该操作指导工程师在开局阶段，新建UDM作为SAE-HSS网元时，完成NB-IoT全局数据的配置。

NB-IoT是一种新型窄带无线技术，用以满足物联网需求。

## 必备事项

前提条件

* 已经完成UDM的OMU侧的硬件数据和基础数据的配置。
* 已经完成NB-IoT的用户数据规划。

数据

执行操作前需要规划的数据如表1所示。

**表1** NB-IoT全局数据

| 类别 | 参数名称 | 取值样例 | 说明 |
| --- | --- | --- | --- |
| **ADD SYSHLRSN** | SYSHLRSN (系统HLR序列号) | 1 | 工程设计输出  该参数取值与USCDB MML命令界面上的**SET SYSNO**命令配置的“SYSTEMNO”参数的取值相同 |
|  | HLRNAME (系统HLR名称) | HLR01 | 工程设计输出 |
|  | STATUS (状态) | MASTER | 单局点时，该参数固定取值为“MASTER” |
| **ADD VHLRSN** | HLRSN （虚拟HLR序列号） | 1 | 工程设计输出 |
|  | HLRNAME (虚拟HLR名称) | VHLR01 | 工程设计输出 |
| **ADD HLRSN** | HLRSN (HLR序列号) | 1 | 该参数的取值需要与系统管理MML命令界面上的**ADD VHLRSN**命令配置的“HLRSN”的取值一一对应 |
|  | HLRNO (HLR号码) | 8613910000 | 根据运营商要求配置。容灾局的“HLR号码”会同步主用局的“HLR号码”。 |
|  | STATUS (状态) | MASTER | 单局点时，该参数固定取值为“MASTER” |
|  | CCODE (国家码) | 86 | 根据运营商要求配置 |

## 操作步骤

1. 登录系统管理命令界面。
2. 执行**ADD SYSHLRSN**命令增加系统HLR。
3. 执行**ADD VHLRSN**命令增加虚拟HLR。

   每个SYSHLRSN至少指定一个虚拟HLR。
4. 登录“UDM业务管理”窗口。
5. 执行**ADD HLRSN**命令增加HLR序列号。
