# 补卡

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当用户的SIM/USIM卡遗失或者损坏，同时希望MSISDN号和签约业务保持不变，运营商可以通过PGW Web LMT可以为用户办理补卡业务。

补卡业务更改用户的IMSI，保证用户的MSISDN号码和签约业务不变。

该操作适用于为GSM用户、UMTS用户、EPS用户和5GS用户补卡。

## 必备事项

前提条件

* 要补卡的用户已经成功开户。
* 补卡所用的新IMSI号码要在操作员管理的IMSI号段中。

数据

* 用户的MSISDN号码或者旧IMSI号码。
* 新IMSI号码。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 如果需要进行非连续用户的批操作，编写IMSIFILE或ISDNFILE批操作资源文件，并上传到PGW Server指定位置。

   * ISDNFILE、IMSIFILE批操作资源文件的格式和上传位置请参见批操作管理。
   * 批操作资源文件的上传方法请参见管理文件。
3. 如果新IMSI号码没有加载KI，执行加载KI操作。

   * 为SIM卡用户加载KI的方法请参见2G鉴权的配置GSM鉴权。
   * 为USIM卡用户加载KI的方法请参见3G鉴权的配置UMTS鉴权、EPS-AKA鉴权的配置EPS-AKA鉴权以及EAP-AKA和EAP-AKA'鉴权的配置EAP-AKA和EAP-AKA'鉴权。
   * 为USIM卡的5GS用户加载KI的方法请参见配置5G鉴权数据。
4. 执行**MOD IMSI**命令为指定用户补卡。

   * 如要重新设置用户的鉴权算法，需要根据“卡类型”设置对应的“鉴权算法类型”。
   * 如要为用户签约自动换卡功能，需要设置“签约/去签约自动换卡功能”为“TRUE”，并通过“有效期限”设置自动换卡的生效日期。

     自动换卡功能支持：
     + 在“有效期限”内的任意时刻，如果未使用新卡，则旧卡仍然能正常使用。
     + 在“有效期限”内的任意时刻，一旦用户使用了一次新卡，则自动完成换卡操作，旧卡失效。
     + 在“有效期限”设置的日期之后，换卡操作自动完成，旧卡失效，用户需要启用新卡。

     该功能提供了一种快速的补卡方法，运营商预先为用户备份一张与原MSISDN号码相同的卡，一旦用户的SIM卡/USIM卡丢失或损坏，可以快速换卡使用。

   补卡后，旧IMSI号码对应的KI仍然保留在数据库中，会成为垃圾数据，运营商可以根据情况决定是否执行该步骤删除。

   * 是：执行5。
   * 否：结束。
5. 执行**RMV KI**命令删除旧IMSI号码对应的KI。
