# 改号

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

运营商通过PGW Web LMT可以为用户改号。

## 必备事项

前提条件

要改号的用户已经成功开户。

数据

要改号用户的MSISDN号码。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 如果需要进行非连续用户的批操作，编写IMSIFILE或ISDNFILE批操作资源文件，并上传到PGW Server指定位置。

   * ISDNFILE、IMSIFILE批操作资源文件的格式和上传位置请参见批操作管理。
   * 批操作资源文件的上传方法请参见管理文件。
3. 执行**MOD ISDN**命令为指定用户改号。
