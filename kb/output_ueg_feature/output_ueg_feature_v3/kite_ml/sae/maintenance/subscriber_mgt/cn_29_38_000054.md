# 用户主动申请停机和开机（SABLCK）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

运营商通过PGW Web LMT可以对主动申请停机/开机的用户进行停机/开机。

## 必备事项

前提条件

* 要停机/开机的用户已经开户。
* 要开机的用户已经停机。

数据

要停机/开机的MSISDN或IMSI号码。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 如果需要进行非连续用户的批操作，编写IMSIFILE或ISDNFILE批操作资源文件，并上传到PGW Server指定位置。

   * ISDNFILE、IMSIFILE批操作资源文件的格式和上传位置请参见批操作管理。
   * 批操作资源文件的上传方法请参见管理文件。
3. 执行**MOD SABLCK**命令为指定用户停机或开机。

   * 参数“是否提供锁呼入业务”或“是否提供锁呼出业务”设置为“TRUE”，为用户停机。
   * 参数“是否提供锁呼入业务”或“是否提供锁呼出业务”设置为“FALSE”，为用户开机。
