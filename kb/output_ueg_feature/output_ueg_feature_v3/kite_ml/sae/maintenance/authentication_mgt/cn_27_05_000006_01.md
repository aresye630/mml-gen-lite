## 操作场景

该任务旨在指导操作人员通过PGW Web LMT配置EPS-AKA鉴权相关数据。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* 操作人员已完全了解EPS-AKA鉴权功能。
* 已经完成基础数据的配置。
* 操作人员具有数据配置权限。
* 操作人员具有业务发放权限。
* 操作人员具有PGW Web LMT的用户名和密码。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**SET MAPSERV**命令设置与EPS-AKA鉴权相关的MAP业务数据。
3. 执行**SET MAPCONF**命令设置与EPS-AKA鉴权相关的MAP功能流程数据。
4. 执行**ADD AMF**命令设置AMF值。
5. 执行**ADD K4**命令设置KI的传输密钥K4。
6. 如果USIM卡中烧制了OP，执行**ADD OP**命令设置OP值。

   如果USIM卡中烧制了OPC，则跳过此步骤，并在执行7时输入“OPC值”。
7. 执行**ADD KI**命令加载KI。

   如果需要进行批量操作，编写KI批操作文件，并上传PGW Server指定位置。

   编写KI批操作文件时，要注意以下几点：

   * KI批操作文件的格式和上传位置请参见批操作管理。
   * KI批操作文件的上传方法请参见管理文件。
   * 如果USIM卡中烧制了OPC，KI批操作文件中要包含参数OPC；如果USIM卡中烧制了OP，KI批操作文件中不包含参数OPC。

## 任务示例

任务描述

为IMSI号码为“460456303001002”的用户配置EPS-AKA鉴权功能。

脚本

/\*-------------登录“UDM业务管理”窗口-------------\*/

/\*配置与EPS-AKA鉴权相关的MAP业务数据\*/

```
SET MAPSERV: AUTH_MILENAGE_C1="00000000000000000000000000000000", AUTH_MILENAGE_C2="00000000000000000000000000000001", AUTH_MILENAGE_C3="00000000000000000000000000000002", AUTH_MILENAGE_C4="00000000000000000000000000000004", AUTH_MILENAGE_C5="00000000000000000000000000000008", AUTH_MILENAGE_R1="40", AUTH_MILENAGE_R2="00", AUTH_MILENAGE_R3="20", AUTH_MILENAGE_R4="40", AUTH_MILENAGE_R5="60", LTESQNIND=16;
```

/\*配置与EPS-AKA鉴权相关的MAP功能流程数据\*/

```
SET MAPCONF: SENDALLQUINTUPLET=TRUE, AKSWITCH=TRUE;
```

/\*为用户配置EPS-AKA鉴权数据\*/

```
ADD AMF: HLRSN=1, AMFSNO=1, AMFVALUE="*****";
ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=ClearKey, ALGTYPE=AES256, K4VALUE="*****";
ADD OP: HLRSN=1, OPSNO=1, OPVALUE="*****";
ADD KI: HLRSN=1, IMSI="460456303001002", OPERTYPE=ADD, KIVALUE="*****", K4SNO=1, CARDTYPE=USIM, ALG=MILENAGE, OPSNO=1, AMFSNO=1;
```
