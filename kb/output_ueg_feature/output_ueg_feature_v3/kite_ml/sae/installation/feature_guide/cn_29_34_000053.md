## 操作场景

该任务旨在指导操作人员通过PGW Web LMT签约或去签约LTE移动性管理。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* 操作人员已完全了解LTE移动性管理。
* 操作人员具有业务发放权限。
* 操作人员具有PGW Web LMT的用户名和密码。
* 准备签约EPS APN数据的用户已经开户。
* 准备去签约EPS APN数据的用户已经签约LTE移动性管理。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD APNTPL**命令，增加APN模板。
3. 执行**ADD EPSQOSTPL**命令，增加EPS QoS模板。
4. 执行**MOD EPS**命令，为用户签约/去签约LTE移动性管理。
5. 执行**MOD OPTGPRS**命令，为用户签约/去签约EPS APN数据。

   如果需要进行非连续用户的批操作，编写IMSIFILE或ISDNFILE批操作资源文件，并上传到PGW Server指定位置。
   * ISDNFILE、IMSIFILE批操作资源文件的格式和上传位置请参见批操作管理。
   * 批操作资源文件的上传方法请参见管理文件。

## 任务示例

任务描述

为IMSI号码为“460000009123456”的用户配置LTE移动性管理。

脚本

/\*-------------登录“UDM业务管理”窗口-------------\*/

/\*增加APN模板\*/

```
ADD APNTPL: HLRSN=1, TPLID=100, APN="abc.com", PDNGWALLOCTYPE=STATIC, MIPHAHOST="PDN-GW", MIPHAREALM="abc.com", MIPHAADDRIPV4="10.144.98.135";
```

/\*增加EPS QoS模板\*/

```
ADD EPSQOSTPL: HLRSN=1, TPLID=100, TPLNAME="EPS-QoS", QOSCLASUID=5, EXTQCI=130, PRILEVEL=1, PREEMPTIONCAP=ENABLE, PREEMPTIONVUL=ENABLE, AMBRMAXREQBWUL=100000, AMBRMAXREQBWDL=200000;
```

/\*为用户签约LTE移动性管理\*/

```
MOD EPS: IMSI="460000009123456", PROV=TRUE, AMBRMAXUL=500000, AMBRMAXDL=100000;
```

/\*为用户签约EPS APN数据\*/

```
MOD OPTGPRS: IMSI="460000009123456", PROV=ADDPDPCNTX, CNTXID=1, APN_TYPE=EPS_APN, APNTPLID=100, DEFAULTCFGFLAG=TRUE, EPS_QOSTPLID=100, PDPTYPE=IPV6, ADDIND=STATIC, PDPADD="2001:0DB8:0000:034B:0034:0006:FFFF:0001", VPLMN=FALSE, CHARGE=NORMAL;
```

/\*为用户去签约LTE移动性管理\*/

```
MOD EPS: IMSI="460000009123456", PROV=FALSE;
```

/\*为用户去签约EPS APN数据\*/

```
MOD OPTGPRS: IMSI="460000009123456", PROV=RMVPDPCNTX, CNTXID=1;
```
