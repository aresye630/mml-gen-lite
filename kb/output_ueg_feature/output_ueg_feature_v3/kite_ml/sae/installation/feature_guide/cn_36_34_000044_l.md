## 操作场景

该任务指导操作人员配置支持S-CSCF数据备份。

举例的数据将实现如下功能：在HSS上打开软参“CSCFDISASRSWITCH”支持S-CSCF容灾，并为对端S-CSCF配置了CSCF的容灾特性。在注册过程中，HSS会更新用户信息并保存S-CSCF发送过来的容灾数据；会话过程中，由于S-CSCF的重启或者故障HSS会支持下发S-CSCF容灾数据。

## 必备事项

前提条件

* 操作人员具有OM Portal权限。
* 操作人员具有PGW Web LMT客户端业务发放权限。
* 已完成软件安装和初始配置。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. **MOD INSP**是软参修改命令，误操作会对整个系统的正常运行造成严重影响，请谨慎操作。

   执行**MOD INSP**命令修改容灾配置的软参信息，设置HSS支持S-CSCF数据备份的功能。

   ```
   MOD INSP: INSPT=IMS-HSS, INSPN=CSCFDISASRSWITCH, INSPV=1;
   ```
3. 执行**ADD DMLE**命令增加一条Diameter本端实体记录
4. 执行**ADD DMPE**命令增加备用S-CSCF的设备记录，
5. 执行**SET DMPECAP**命令增加特性列表设置记录，“Cx特性列表”参数要选择“CscfDisaster(CSCF容灾)”。
6. 执行**ADD DMLKS**命令增加备用S-CSCF的链路集记录。
7. 执行**ADD DMLNK**命令增加备用S-CSCF的链路记录。
8. 登录“IMS-HSS业务管理”窗口。
9. 执行**SET HSYSTEMPARA**命令配置S-CSCF容灾数据存储最大长度。

## 验证方法

验证前提：

* 用户合法，可正常注册和会话。
* 如果支持符合3GPP协议的S-CSCF网络容灾，则需要激活License。

**验证注册/重注册流程**

验证HSS和S-CSCF间的SAR（Server Assignment Request）/SAA（Server Assignment Answer）消息交互是否正常。分为华为私有接口和符合3GPP协议的S-CSCF网络容灾。

* 如果S-CSCF支持华为私有接口的S-CSCF网络容灾，步骤如下：
  1. S-CSCF向HSS发送SAR消息，携带Server-Assignment-Type AVP：RESTORE\_USER。
  2. HSS向S-CSCF返回SAA消息：
     + 若Result-Code：DIAMETER\_SUCCESS或DIAMETER\_ERROR\_IDENTITY\_NOT\_REGISTERED，则支持S-CSCF网络容灾。若注册状态为REGISTERED的关联IMPI（IP Multimedia Private Identity）存在华为私有接口的备份数据，则通过SAA消息的Associated-Back-Info AVP下发用户备份数据。
     + 若Result-Code：DIAMETER\_INVALID\_AVP\_VALUE，则HSS不支持华为私有接口的S-CSCF网络容灾。
* 如果S-CSCF支持符合3GPP协议的S-CSCF网络容灾，步骤如下：
  1. S-CSCF向HSS发送SAR消息，携带Server-Assignment-Type AVP：NO\_ASSIGNMENT。
  2. HSS向S-CSCF返回SAA消息：
     + 若注册状态为REGISTERED的关联IMPI存在符合3GPP协议的备份数据，则通过SAA消息的SCSCF-Restoration-Info AVP下发用户备份数据。
     + 若SAA消息的Result-Code AVP是DIAMETER\_SUCCESS，但SAA消息中没有SCSCF-Restoration-Info AVP，则HSS不支持符合3GPP协议的S-CSCF网络容灾。

**验证会话流程**

验证HSS和I-CSCF间的LIR（Location Information Request）/LIA（Location Information Answer）消息交互是否正常，步骤如下：

1. I-CSCF向HSS发送LIR消息，携带Originating-Request AVP：RESTORE\_USER（255）。
2. HSS向I-CSCF返回LIA消息：
   * 若Result-Code：DIAMETER\_SUCCESS或DIAMETER\_ERROR\_IDENTITY\_NOT\_REGISTERED，则支持S-CSCF网络容灾。
   * 若Result-Code：DIAMETER\_INVALID\_AVP\_VALUE，则HSS不支持S-CSCF网络容灾。

## 任务示例

任务描述

在“UEG MML命令”界面上打开软参“CSCFDISASRSWITCH”支持S-CSCF容灾，并为对端S-CSCF配置了CSCF的容灾特性。下面给出该配置脚本。

脚本

/\*----------登录“UEG MML命令”界面----------\*/

/\*打开CSCF的容灾开关\*/

```
MOD INSP: INSPT=IMS-HSS, INSPN=CSCFDISASRSWITCH, INSPV=1;
```

/\*增加一条本端HSS实体的设备记录\*/

```
ADD DMLE: EN="HSS_0", LOCTYPE=SAE-HSS, DN="huawei.com", HN="as.huawei.com";
```

/\*增加S-CSCF实体的设备记录\*/

```
ADD DMPE: EN="scscf", PEERTYPE=OTHER, HN="scscf.huawei.com";
```

/\*增加特性列表设置记录\*/

```
SET DMPECAP: PEERNAME="HSS_0", OPTYPE=ADD, PEERTYPE=S-CSCF, CSCFFEATURELIST=SharedIFC-1&CscfDisaster-1, HN="scscf.huawei.com", DN="huawei.com";
```

/\*增加S-CSCF链路集记录\*/

```
ADD DMLKS: LINKSNAM="hss-scscf", LOCALNAM="HSS_0", PEERNAM="SCSCF", LNKMOD=POLLING;
```

/\*增加S-CSCF链路记录\*/

```
ADD DMLNK: LNKNAME="LINK_SCSCF", LINKSNAM="HSS-SCSCF", HSFMID=202, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSF211", PIPVER=IPV4, PIPV4="10.1.182.2", PPT=4200;
```

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*配置S-CSCF容灾数据存储最大长度\*/

```
SET HSYSTEMPARA: SCSCF_BACKUP_DATA_SIZE=8K;
```
