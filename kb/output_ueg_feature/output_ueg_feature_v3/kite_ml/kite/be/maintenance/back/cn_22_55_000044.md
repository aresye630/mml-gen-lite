# 关闭/启动物理数据库自动备份功能

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤
* 附加信息

#### 操作场景

系统默认启动物理数据库自动备份功能，缺省情况下物理库备份默认启动时间在每天04:00:00。

系统升级时，需要关闭物理数据库自动备份功能，该操作在升级时会自动设定关闭，无需单独设定。

在完成手动操作之后，需要重新打开物理数据库自动备份功能。

#### 对系统的影响

物理数据库的备份操作会占用系统大量资源，请在系统低业务量的时段下进行。

#### 必备事项

**前提条件**

该操作无需具备特殊条件。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD BACKUP**命令关闭/启动物理数据库自动备份功能。

   ```
   MOD BACKUP: BAKSWH=ON/OFF（开/关）;
   ```
3. 执行**LST BACKUP**命令查询备份开关状态是否与2操作结果一致。

   ```
   LST BACKUP:;
   ```

#### 附加信息

**相关命令**

* **MOD BACKUP**
* **LST BACKUP**
