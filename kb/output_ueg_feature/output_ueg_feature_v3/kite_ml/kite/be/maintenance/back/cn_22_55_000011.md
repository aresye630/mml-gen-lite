# 调整物理数据库的自动备份存储方式

#### 操作场景

物理数据库备份能够将数据备份到虚拟机硬盘或者第三方备份服务器，系统默认将数据备份到虚拟机硬盘上。运营商出于对数据安全的考虑，或是根据现网要求，调整物理数据库的自动备份存储方式：

* 将物理数据库备份设置到第三方备份服务器上，可以拥有较大的存储空间以存储更多的备份文件。
* 将物理数据库备份设置到第三方备份服务器上，以便集中对于备份数据统一管理。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

用于提供备份服务的第三方服务器的运行状态正常且没有安全漏洞，如果是FTP服务器要求支持SSL加密。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD BACKUP**命令设置备份文件存放的第三方备份服务器。

   以IP类型为IPv4举例：

   ```
   MOD BACKUP: BAKSWH=自动备份开关, BAKDAY=自动备份时间点, STOTIM=保存的最大周期的个数, STOTYP=备份数据保存方式, IPVER=IP类型,LIPV4=本地IPV4地址, IPVPNNAME=IP地址的VPN名称, FTPIPV4=服务器IPV4地址, FTPUSR=服务器用户名, FTPPAS=服务器密码, FTPPATH=服务器路径, FTPPORT=服务器端口号;
   ```
3. 执行**LST BACKUP**命令对物理库自动备份存储方式进行查询修改是否成功。

   ```
   LST BACKUP:;
   ```

#### 附加信息

**相关命令**

* **MOD BACKUP**
* **LST BACKUP**
