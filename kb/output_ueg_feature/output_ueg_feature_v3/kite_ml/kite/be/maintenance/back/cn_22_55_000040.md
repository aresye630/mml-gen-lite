# 从指定目录恢复内存数据库

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

与华为技术支持确认可以从指定目录加载恢复内存数据库时，可参考此指导。

从指定目录恢复内存数据库场景，加载的文件目录由**SET RESTOREDIR**命令的参数“DIRECTORY”决定：

* 当参数“DIRECTORY”设置为“UPGPLANE1”、“UPGPLANE0”或“EMGRST”，则恢复时加载的是紧急恢复目录下的备份文件，不加载当前最新Redo。
* 当参数“DIRECTORY”设置为“CURRENT”或“LAST”，
  + 软参“EMGRSTMODE”为“0”，则优先从Master节点加载恢复，如果失败则从本地目录下加载备份文件以及全量Redo。
  + 软参“EMGRSTMODE”非“0”，则恢复时加载的是本地目录下的备份文件以及备份期间生成的Redo。

#### 对系统的影响

* 恢复内存数据库过程中业务不可用，操作前请联系华为技术支持确认。
* 从指定目录恢复内存数据库时，会导致从开始备份文件到执行恢复操作相隔的时间，内存库存储的用户数据丢失。此操作为高危操作，操作前请联系华为技术支持。
* 从指定目录加载数据覆盖本地最新的备份文件前，系统将最新的备份文件拷贝到DRU/DSU所在容器的/opt/uscdb/SNP\_BKP目录下，会占用磁盘空间。

#### 必备事项

**前提条件**

* 节点状态异常导致存在业务呼损，并已通过维护手段定位出需要进行重新加载数据的异常DRU/DSU节点。
* 如果需要指定目录从“EMGRST(紧急恢复目录)”加载恢复内存数据库，那么需要确保在现网重大操作前，登录PGW Web LMT MML命令界面执行**BKP DB**命令手工备份内存数据库到紧急恢复目录，命令关键参数配置如下：
  + “业务类型” 配置为对应网元类型。
  + “目录”配置为“EMGRST”。
  + “位置信息”配置为“Local”。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令，修改参数的取值来设置指定目录恢复开关。

   * “INSPT”取值为“FE”。
   * “INSPN”取值为“SPCFDIRRSTSWT”。
   * “INSPV”取值为“1”。
   * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

   ```
   MOD INSP: INSPT=FE, INSPN=SPCFDIRRSTSWT, INSPV=1, FETYPEN="网元类型";
   ```
3. 执行**MOD INSP**命令，修改参数的取值来关闭定时备份开关。

   * “INSPT”取值为“FE”。
   * “INSPN”取值为“TIMEBACKUPFLAG”。
   * “INSPV”取值为“0”。
   * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

   ```
   MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=0, FETYPEN="网元类型";
   ```
4. 执行**SET RESTOREDIR**命令，设置待加载目录。

   * “SERVICETYPE”取值为具体的服务类型。
   * “DIRECTORY”取值为待加载的目录。

   * 从指定目录加载恢复场景下，参数“DIRECTORY”常用的取值：

     EMGRST(紧急恢复目录)：目录“/opt/uscdb/emgRst”中的备份文件。

     CURRENT(今日周期备份)：目录“/opt/uscdb/snp”中当天周期性备份文件。

     LAST(昨日周期备份)：目录“/opt/uscdb/snp”中前一天周期性备份文件。
   * 可执行**CHK RESTOREDIR**命令检查待加载目录下的文件是否完整。

   ```
   SET RESTOREDIR: SERVICETYPE="SUP-FE", DIRECTORY=待加载的目录;
   ```
5. 执行**MOD INSP**命令，修改参数的取值来设置紧急修复模式。

   * “INSPT”取值为“FE”。
   * “INSPN”取值为“EMGRSTMODE”。
   * “INSPV”取值说明如下。

     + 如果步骤4中“DIRECTORY”配置为“EMGRST”：
       - 软参“EMGRSTMODE”为“0”，则从紧急恢复目录中加载最新FDB和全量Redo恢复静态数据。
       - 软参“EMGRSTMODE”为“1”，则从紧急恢复目录中加载最新FDB和备份期间生成的Redo恢复静态数据。
       - 软参“EMGRSTMODE”为“2”，则先从紧急恢复目录中加载最新FDB和备份期间生成的Redo恢复静态数据，再恢复增量的营帐MML数据。
       - 软参“EMGRSTMODE”为“3”，则先从紧急恢复目录中加载最新FDB和备份期间生成的Redo恢复静态数据，再向Master节点发送加载最新数据的请求更新动态数据，最后恢复增量的营帐MML数据。
       - 软参“EMGRSTMODE”为“4”，则先从紧急恢复目录中加载最新FDB和备份期间生成的Redo恢复静态数据，再向Master节点发送加载最新数据的请求更新动态数据。
     + 如果步骤4中“DIRECTORY”配置为“CURRENT”或“LAST”：
       - 软参“EMGRSTMODE”为“0”，则优先从Master节点加载恢复，如果失败则从本地目录下加载FDB以及全量Redo。
       - 软参“EMGRSTMODE”为“1”，则从本地目录中加载FDB和备份期间生成的Redo恢复静态数据。
       - 软参“EMGRSTMODE”为“2”，则先从本地目录中加载FDB和备份期间生成的Redo恢复静态数据，再恢复增量的营帐MML数据。
       - 软参“EMGRSTMODE”为“3”，则先从本地目录中加载FDB和备份期间生成的Redo恢复静态数据，再向Master节点发送加载最新数据的请求更新动态数据，最后恢复增量的营帐MML数据。
       - 软参“EMGRSTMODE”为“4”，则先从本地目录中加载FDB和备份期间生成的Redo恢复静态数据，再向Master节点发送加载最新数据的请求更新动态数据。
   * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。
6. 执行**MOD INSP**命令，修改参数的取值来设置加载源。

   * “INSPT”取值为“FE”。
   * “INSPN”取值为“LDRSOURCE”。
   * “INSPV”取值为“3”。
   * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

   ```
   MOD INSP: INSPT=FE, INSPN=LDRSOURCE, INSPV=3, FETYPEN="网元类型";
   ```
7. 执行**MOD INSP**命令关闭内存数据库的校验开关。

   需要关闭的校验开关如下：
   * FWDVFYSWT（正向校验开关）
   * REVVFYSWT（反向校验开关）
   * FWDRTVFYSWT（正向路由校验开关）
   * REVRTVFYSWT（反向路由校验开关）

   参数具体取值如下：

   * “INSPT”取值为“FE”。
   * “INSPN”取值分别为“FWDVFYSWT”、“REVVFYSWT”、“FWDRTVFYSWT”和“REVRTVFYSWT”。
   * “INSPV”取值为“0”。
   * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**命令查看节点所属“业务类型”。

   ```
   MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=0, FETYPEN="网元类型";
   MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=0, FETYPEN="网元类型";
   MOD INSP: INSPT=FE, INSPN=FWDRTVFYSWT, INSPV=0, FETYPEN="网元类型";
   MOD INSP: INSPT=FE, INSPN=REVRTVFYSWT, INSPV=0, FETYPEN="网元类型";
   ```
8. 当局点为主备局点时，分别在主备局点执行**LST INSP**命令，查询此时的“REDUNDANCYSWITCH（容灾开关）”软参取值是否为“1”，并记录此时取值。

   ```
   LST INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH;
   ```

   * 是 => 10
   * 否 => 9
9. 分别在主备局点执行**MOD INSP**命令修改“REDUNDANCYSWITCH（容灾开关）”的取值为“1”。

   参数具体取值如下：
   * “INSPT”取值为“FE”。
   * “INSPN”取值分别为“REDUNDANCYSWITCH”。
   * “INSPV”取值为“1”。
   * “FETYPEN”取值分别为异常节点所属“业务类型”和“USCDB”，可以通过**LST NODE**命令查看节点所属“业务类型”。

   ```
   MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=1, FETYPEN="网元类型";
   MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=1, FETYPEN="USCDB";
   ```
10. 执行**RST MODULE**命令将指定Slave节点从指定目录重新加载。

    * 单个DRU/DSU节点的加载时长大约为3min。
    * 如需加载数据到对应模块的缓存中，请在节点复位完成后再次执行**RST MODULE**命令重启该模块。需重启的模块类型根据FE的具体场景决定。

    ```
    RST MODULE: MID=模块号, MT=模块类型;
    ```
11. 待接近加载完成的时间时，执行**DSP NODE**命令查看节点的数据加载状态。

    ```
    DSP NODE:;
    ```

    查看各节点的“节点状态”信息：

    * 如果为“初始化”、“加载中”、“加载完毕 ”或“初始化完成”表示节点还处在数据加载状态。
    * 如果为“Master”或“Slave”表示节点的数据已经加载完。
12. 执行**DSP LOADINFO**命令确认节点的“加载源”预与期的待加载目录一致，并且检查“加载的最后一个redolog文件名称”和“加载的最后一条redolog的时间”与预期加载的一致。

    ```
    DSP LOADINFO:;
    ```

    从指定目录恢复内存数据库的加载源与**SET RESTOREDIR**命令参数“DIRECTORY”的取值和软参“EMGRSTMODE”的取值有关：

    * “EMGRSTMODE”软参的取值为“0”时：
      + “DIRECTORY”的取值为“EMGRST(紧急恢复目录)”时，加载源为“本地指定目录加载”。
      + “DIRECTORY”的取值为“CURRENT(今日周期备份)”或“LAST(昨日周期备份)”时，优先从加载源“Master”进行加载，如果加载失败则会从加载源“本地备份目录”进行加载。
    * “EMGRSTMODE”软参的取值不为“0”时：
      + “DIRECTORY”的取值为“EMGRST(紧急恢复目录)”时，加载源为“数据紧急修复备份目录”。
      + “DIRECTORY”的取值为“CURRENT(今日周期备份)”时，加载源为“今日周期备份”。
      + “DIRECTORY”的取值为“LAST(昨日周期备份)”时，加载源为“昨日周期备份”。
13. 执行**MOD INSP**命令恢复节点数据加载源的默认值。参数具体取值如下：

    * “INSPT”取值为“FE”。
    * “INSPN”取值为“LDRSOURCE”。
    * “INSPV”取值为“0”。
    * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

    ```
    MOD INSP: INSPT=FE, INSPN=LDRSOURCE, INSPV=0, FETYPEN="网元类型";
    ```
14. 执行**RST MODULE**命令将指定Master节点重新加载。

    * 单个DRU/DSU节点的加载时长大约为3min。
    * 如需加载数据到对应模块的缓存中，请在节点复位完成后再次执行**RST MODULE**命令重启该模块。需重启的模块类型根据FE的具体场景决定。

    ```
    RST MODULE: MID=模块号, MT=模块类型;
    ```
15. 待接近加载完成的时间时，执行**DSP NODE**命令查看节点的数据加载状态。

    ```
    DSP NODE:;
    ```

    查看各节点的“节点状态”信息：

    * 如果为“初始化”、“加载中”、“加载完毕 ”或“初始化完成”表示节点还处在数据加载状态。
    * 如果为“Master”或“Slave”表示节点的数据已经加载完。
16. 执行**DSP LOADINFO**命令确认节点的“加载源”与预期的待加载目录一致，并且检查“加载的最后一个redolog文件名称”和“加载的最后一条redolog的时间”与预期加载的一致。

    ```
    DSP LOADINFO:;
    ```

    从指定目录恢复内存数据库的加载源与**SET RESTOREDIR**命令参数“DIRECTORY”的取值和软参“EMGRSTMODE”的取值有关：

    * “EMGRSTMODE”软参的取值为“0”时：
      + “DIRECTORY”的取值为“EMGRST(紧急恢复目录)”时，加载源为“本地指定目录加载”。
      + “DIRECTORY”的取值为“CURRENT(今日周期备份)”或“LAST(昨日周期备份)”时，优先从加载源“Master”进行加载，如果加载失败则会从加载源“本地备份目录”进行加载。
    * “EMGRSTMODE”软参的取值不为“0”时：
      + “DIRECTORY”的取值为“EMGRST(紧急恢复目录)”时，加载源为“数据紧急修复备份目录”。
      + “DIRECTORY”的取值为“CURRENT(今日周期备份)”时，加载源为“今日周期备份”。
      + “DIRECTORY”的取值为“LAST(昨日周期备份)”时，加载源为“昨日周期备份”。
17. 执行**MOD INSP**命令打开内存数据库的校验开关。参数具体取值如下：

    * “INSPT”取值为“FE”。
    * “INSPN”取值分别为“FWDVFYSWT”、“REVVFYSWT”、“FWDRTVFYSWT”和“REVRTVFYSWT”。
    * “INSPV”取值为“1”。
    * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

    ```
    MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=1, FETYPEN="网元类型";
    MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=1, FETYPEN="网元类型";
    MOD INSP: INSPT=FE, INSPN=FWDRTVFYSWT, INSPV=1, FETYPEN="网元类型";
    MOD INSP: INSPT=FE, INSPN=REVRTVFYSWT, INSPV=1, FETYPEN="网元类型";
    ```
18. 执行**MOD INSP**命令，修改参数的取值来打开定时备份开关。

    * “INSPT”取值为“FE”。
    * “INSPN”取值为“TIMEBACKUPFLAG”。
    * “INSPV”取值为“1”。
    * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

    ```
    MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=1, FETYPEN="网元类型";
    ```
19. 执行**MOD INSP**命令，还原“REDUNDANCYSWITCH（容灾开关）”软参取值。参数具体取值如下：

    * “INSPT”取值为“FE”。
    * “INSPN”取值分别为“REDUNDANCYSWITCH”。
    * “INSPV”取值为8中查询的软参取值。
    * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

    ```
    MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=VALUE, FETYPEN="网元类型";
    ```

    ```
    MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=VALUE, FETYPEN="USCDB";
    ```
20. 执行**MOD INSP**命令，修改参数的取值来关闭指定目录恢复开关。

    * “INSPT”取值为“FE”。
    * “INSPN”取值为“SPCFDIRRSTSWT”。
    * “INSPV”取值为“0”。
    * “FETYPEN”根据异常节点所属“业务类型”进行取值，可以通过**LST NODE**查看节点所属“业务类型”。

    ```
    MOD INSP: INSPT=FE, INSPN=SPCFDIRRSTSWT, INSPV=0, FETYPEN="网元类型";
    ```
21. 执行**CLR RESTOREDIR**命令，删除恢复目录，“SERVICETYPE”取值为4设置的服务类型。

    ```
    CLR RESTOREDIR: SERVICETYPE="SUP-FE";
    ```
