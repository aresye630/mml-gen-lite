# DRU/DSU cluster异常后内存数据库恢复

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

DRU/DSU cluster异常即Cluster中的两个DRU/DSU节点发生异常，节点都异常后会自动重新启动，并按照以下次序自动加载数据：

1. 从虚拟机硬盘加载数据。
2. 如果从虚拟机硬盘加载数据失败会选择从指定目录进行加载。

DRU/DSU节点自动加载数据后可通过查询命令对节点的加载状态进行查询。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

DRU/DSU节点发生异常。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**DSP NODE**命令查看节点的数据加载状态。

   ```
   DSP NODE:;
   ```

   查看各节点的“节点状态”信息：

   * 如果为“初始化”、“加载中”、“加载完毕 ”或“初始化完成”表示节点还处在数据加载状态。
   * 如果为“Master”或“Slave”表示节点的数据已经加载完。
