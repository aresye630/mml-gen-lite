# 调整内存数据库的自动备份时间

#### 操作场景

自动备份内存数据库是USCDB确保数据可靠性和完整性的机制，USCDB会定期将内存数据库的数据备份到虚拟硬盘，以防止内存库出现故障导致的数据丢失。

缺省情况下，对于DRU节点系统每天03:38:00开始自动备份，DSU节点比DRU节点晚一个小时启动备份。

* 缺省备份时间不符合运营商要求时，可对自动备份内存数据库的时间进行重新配置。
* 出于方便维护的考虑，系统管理人员可以通过修改自动备份时间以贴合实际备份时间，满足维护需求。

#### 对系统的影响

当自动备份内存数据库时，会对系统性能产生影响，请将内存数据库的自动备份时间调整为业务低峰期间。

#### 必备事项

**前提条件**

该操作无需具备特殊条件。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令对BACKUPHOUR（定时备份起始时）和BACKUPMINUTE（定时备份起始分）软参进行定时备份启动时间设置。

   DSU节点定时备份的启动时间无需手工配置，在DRU时间配置后自动设置比DRU节点定时备份启动时间晚一小时。

   ```
   MOD INSP: INSPT=FE, INSPN=BACKUPHOUR, INSPV=软件参数值, FETYPEN="网元类型";
   MOD INSP: INSPT=FE, INSPN=BACKUPMINUTE, INSPV=软件参数值, FETYPEN="网元类型";
   ```
3. 执行**LST INSP**命令对BACKUPHOUR（定时备份起始时）和BACKUPMINUTE（定时备份起始分）状态进行查询修改是否成功。

   ```
   LST INSP: INSPT=FE, INSPN=BACKUPHOUR, FETYPEN="网元类型";
   LST INSP: INSPT=FE, INSPN=BACKUPMINUTE, FETYPEN="网元类型";
   ```

#### 附加信息

**相关软参**

* BACKUPHOUR（定时备份起始时）
* BACKUPMINUTE（定时备份起始分）
