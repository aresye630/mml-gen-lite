# 手工备份内存数据库到自带空间

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

重大操作前（主要包括扩容虚拟机、业务改造等）为了系统的安全性需要手工对内存数据库进行备份，以保证在操作过程中出现异常时可以快速使系统恢复到操作前的运行状态。除了上述的手工备份内存数据库到虚拟机硬盘，还可以手工备份内存数据库到网关类型为DMA的DPU模块所在Pod的虚拟机自带空间中。

#### 对系统的影响

备份内存数据库对系统有以下影响，备份内存数据库请在系统业务低峰期（例如凌晨2:00～4:00）进行:

备份操作会占用系统较多的资源，对系统的性能有影响。

#### 必备事项

**前提条件**

* 已通过PGW Web LMT的“系统管理”窗口执行在**DSP DB**命令查询“State”为“NOBACKUP”、“TASK FINISH”、“TASK ABNORMAL”或“TASK TIMEOUT”。
* 网元需要先在“CSP MML命令”界面先执行**DSP MODULE**查询所有DPU模块，然后以“模块类型”为“DMA”的条件再次执行**DSP MODULE**命令查询网关类型为DMA对应的DPU模块。该DPU模块所在Pod对应的虚拟机规划预留备份用的硬盘空间才可以进行自带空间备份。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令，通过设置SELFSPACEBACKUP（自带空间备份开关）来打开内存数据库备份到自带空间功能。

   ```
   MOD INSP: INSPT=FE, INSPN=SELFSPACEBACKUP, INSPV=1, FETYPEN="网元类型";
   ```
3. 执行**LST INSP**命令查询软参SELFSPACEBACKUP状态查询备份开关状态是否与步骤2操作结果一致，如果不一致，请重复步骤2。

   ```
   LST INSP: INSPT=FE, INSPN=SELFSPACEBACKUP, FETYPEN="网元类型";
   ```
4. 登录PGW Web LMT MML命令界面，进入“系统管理”窗口。
5. 执行**BKP DB**命令备份本局的内存数据库到自带空间，其中参数“位置信息”为“Local”，参数“UPSELFSPACE”为“YES”。

   * 当“业务类型”为FE时：

     ```
     BKP DB: SERVICETYPE="SUP-FE", DIRECTORY=EMGRST, LOCINFO=Local, UPSELFSPACE=YES;
     ```
   * 当“业务类型”为USCDB时：

     ```
     BKP DB: SERVICETYPE="USCDB", DIRECTORY=EMGRST, LOCINFO=Local, UPSELFSPACE=YES;
     ```

   * 备份时长受FE业务模型、局点容量和网络带宽的影响。总备份时长 = 文件写磁盘时长 + 文件传输时长 + 各模块中间处理环节耗时 +节点备份预留时长。
   * 此处以一组数据计算备份时长的参考值：
     + DRU 3GB，DSU 9GB节点内存库大小，备份文件大小分别约为1GB和3GB。DRU/DSU的比例为1:3，每个DSU开户100W，对于3000W的局点大概部署30个DSU Cluster，10个DRU Cluster。磁盘IO带宽约 80MB/s，网络带宽（1Gb网卡）为1Gb/s，即128MB/s。
     + 文件写磁盘时长 = (30\*3 + 10\*1)\*1024 / 80 = 1280s。DMA与DPU之间文件传输时长 = (30\*3 + 10\*1)\*1024 / 128 = 800s。每个文件在各模块中间处理环节耗时60秒，共30\*60 = 1800s。节点备份时长预留900s。备份到自带空间的总时长 = 1280 + 800 + 1800 + 900 = 4060s = 79分钟。
6. 待接近备份完成的时间时，执行**DSP DB**命令查看备份状态。

   * 当“业务类型”为FE时：

     ```
     DSP DB: SERVICETYPE="SUP-FE";
     ```
   * 当“业务类型”为USCDB时：

     ```
     DSP DB: SERVICETYPE="USCDB";
     ```

   查看本局的内存数据库“State”信息：

   * 如果为“TASK FINISH”表示已经备份完。
   * 如果不是“TASK FINISH”表示还没有备份完或备份失败。
