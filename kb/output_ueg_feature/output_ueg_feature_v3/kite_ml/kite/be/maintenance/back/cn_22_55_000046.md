# 从容灾局恢复主用局内存库数据

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

如果容灾局上报了ALM-12088 暂停主备局间对不一致数据的校正告警，则表示主用局发生存储BYPASS并伴随主机重启导致节点双平面重启的异常场景，此时主用局将缺少在存储BYPASS期间的增量数据。为了恢复主用局数据，可参考此指导从容灾局通过数据校验机制对主用局异常数据进行校正。

#### 对系统的影响

从容灾局通过数据校验机制对主用局异常数据进行校验的时长受设备用户数量影响，用户数据越多则校验时长越长，时长计算公式如下：

校验时长={（单Cluster用户总数）/[（获取DSU正向校验的个数）/（正向校验周期）]}/60

* 单Cluster用户总数：登录USCDB所在的CSP OM Portal，在“USCDB MML命令”界面下，执行**DSP NODE**命令，获取报文输出项中“节点对象数量”的最大取值。

  时长计算公式中以最大“节点对象数量”对应“节点标识”为DSU模块举例。若最大“节点对象数量”对应“节点标识”为DRU模块，则公式中“获取DSU正向校验的个数”需替换为“获取DRU正向校验的个数”
* 获取DSU正向校验的个数：DSUFRWDVFYUNITNUM（获取DSU正向校验的个数）的取值。
* 获取DRU正向校验的个数：DRUFRWDVFYUNITNUM（获取DRU正向校验的个数）的取值。
* 正向校验周期：PRDFWDVFY（正向校验周期）的取值。

#### 必备事项

**前提条件**

* 已参考ALM-12088 暂停主备局间对不一致数据的校正中“原因定位”确认告警并非误报。
* 主用局状态正常，存储BYPASS问题已完成处理。
* 网元满足容灾倒换操作要求。

  由于当前容灾倒换操作是为了从容灾局通过数据校验机制对主用局异常数据进行校正，因此容灾倒换操作前主用局、容灾局间数据不一致为正常现象，ALM-12083 局间记录数存在不一致告警会在操作完成后自动清除。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 确认是否能在告警上报后的24小时（此处时间由VERIFYPAUSETIME（校验暂停时间）软参控制）内完成数据恢复操作。

   * 能够完成 => 执行3。
   * 无法完成 => 执行2。
2. 延长校验暂停时间。

   延长ALM-12088 暂停主备局间对不一致数据的校正告警持续时间基于不同场景有如下两种方式：

   * 方法一：在告警上报后的72小时内完成数据恢复操作。

     分别登录主用局和容灾局USCDB网元所在的CSP OM Portal，在“USCDB MML命令”界面下执行**LST INSP**命令查询VERIFYPAUSETIME（校验暂停时间）取值并记录。

     ```
     LST INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, FETYPEN="SUP-FE";
     LST INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, FETYPEN="USCDB";
     ```

     执行**MOD INSP**命令修改VERIFYPAUSETIME（校验暂停时间）取值为72。

     ```
     MOD INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, INSPV=72, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, INSPV=72, FETYPEN="USCDB";
     ```
   * 方法二：在告警上报后的72小时内无法完成数据恢复操作。

     分别登录主用局和容灾局USCDB网元所在的CSP OM Portal，在“USCDB MML命令”界面下执行**LST INSP**命令查询FWDVFYSWT（正向校验开关）、REVVFYSWT（反向校验开关）取值并记录。

     ```
     LST INSP: INSPT=FE, INSPN=FWDVFYSWT, FETYPEN="SUP-FE";
     LST INSP: INSPT=FE, INSPN=FWDVFYSWT, FETYPEN="USCDB";

     LST INSP: INSPT=FE, INSPN=REVVFYSWT, FETYPEN="SUP-FE";
     LST INSP: INSPT=FE, INSPN=REVVFYSWT, FETYPEN="USCDB";
     ```

     执行**MOD INSP**命令修改FWDVFYSWT（正向校验开关）、REVVFYSWT（反向校验开关）取值为0。

     ```
     MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=0, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=0, FETYPEN="USCDB";

     MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=0, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=0, FETYPEN="USCDB";
     ```
3. 参考网元的容灾倒换指导书，完成USCDB容灾倒换操作，将原容灾局USCDB升为主用USCDB，原主用局USCDB降为容灾USCDB。

   在上报ALM-12088 暂停主备局间对不一致数据的校正告警的局上执行**RST MDBVERIFY**命令将恢复局间校验功能，可能导致容灾局的数据被主用局校验脏写，因此在容灾倒换操作过程中应避免执行**RST MDBVERIFY**命令。
4. 是否执行过2的操作。

   * 是 => 执行5。
   * 否 => 执行6。
5. 恢复软参配置。

   恢复软参需要与2中修改的软参保持一致。

   * 若在2中使用的是方法一：

     分别登录原主用局和原容灾局USCDB网元所在的CSP OM Portal，在“USCDB MML命令”界面下执行**MOD INSP**命令恢复VERIFYPAUSETIME（校验暂停时间）配置。“INSPV”的值为2中记录软参取值

     ```
     MOD INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, INSPV=XX, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=VERIFYPAUSETIME, INSPV=XX, FETYPEN="USCDB";
     ```
   * 若在2中使用的是方法二：

     分别登录原主用局和原容灾局USCDB网元所在的CSP OM Portal，在“USCDB MML命令”界面下执行**MOD INSP**命令恢复FWDVFYSWT（正向校验开关）、REVVFYSWT（反向校验开关）配置。“INSPV”的值为2中记录软参取值

     ```
     MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=XX, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=XX, FETYPEN="USCDB";

     MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=XX, FETYPEN="SUP-FE";
     MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=XX, FETYPEN="USCDB";
     ```
6. 登录原容灾局USCDB网元所在的CSP OM Portal，在“USCDB MML命令”界面下执行**DSP NODE**命令，获取报文输出项中“节点对象数量”的最大取值。

   ```
   DSP NODE:;
   ```
7. 在原容灾局和原主用局分别执行**RST MDBVERIFY**命令重置内存库校验，并记录命令执行时间。

   ```
   RST MDBVERIFY: VERIFYNUM=340, VERIFYPRD=1;
   ```

   命令执行过程中系统可能上报ALM-12034 数据存在不一致，告警无需额外处理，在内存库校验操作完成后告警将自动清除。
8. 等待内存库校验完成，等待时长由公式“校验时长（分钟）={（6中获取“节点对象数量”最大取值）/[（7中“VERIFYNUM”取值）/（7中“VERIFYPRD”取值）]}/60”计算。
9. 在原容灾局和原主用局分别执行**DSP MDBVERIFY**命令查询局间校验结果，若查询结果报文中“校验启动时间”等于或晚于7中记录命令执行时间，则表明已完成局间校验，此时“不一致对象”值大于50为正常现象。

   ```
   DSP MDBVERIFY: MDBVT=OUTERREDUN, MDBVR=LASTFR, UDT=GBLDATA;
   DSP MDBVERIFY: MDBVT=OUTERREDUN, MDBVR=LASTFR, UDT=USERDATA;
   ```
10. 在原容灾局和原主用局分别执行**RST MDBVERIFY**命令再次重置内存库校验。

    ```
    RST MDBVERIFY: VERIFYNUM=340, VERIFYPRD=1;
    ```
11. 等待内存库校验完成，等待时长与8相同。
12. 在原容灾局和原主用局分别执行**DSP MDBVERIFY**命令查询局间校验结果，确认结果报文中“不一致对象”值。

    ```
    DSP MDBVERIFY: MDBVT=OUTERREDUN, MDBVR=LASTFR, UDT=GBLDATA;
    DSP MDBVERIFY: MDBVT=OUTERREDUN, MDBVR=LASTFR, UDT=USERDATA;
    ```

    * 若“不一致对象”值小于50 => 执行13。
    * 若“不一致对象”值大于等于50 => 请联系华为技术支持工程师。
13. 选择“监控分析 > 告警管理 > 活动告警”，确认当前不存在ALM-12034 数据存在不一致、ALM-12083 局间记录数存在不一致与ALM-12088 暂停主备局间对不一致数据的校正告警，则表示主用局与容灾局间数据已恢复一致。
