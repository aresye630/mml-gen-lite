# 关闭/启动内存数据库自动备份功能

#### 操作场景

系统默认为启动内存数据库自动备份功能，缺省情况下，系统对于DRU节点、DSU节点每天03:38开始自动备份。

当进行一些对系统有较大影响的操作时，需要关闭内存数据库自动备份功能。

* 系统升级时，需要关闭内存数据库自动备份功能，该操作在升级时会自动关闭，无需单独设定。
* 割接导入用户数据前和扩容虚拟机时，若涉及用户数据迁移则需要关闭自动备份内存数据库功能。

在完成上述操作之后，需要重新手动打开内存数据库自动备份功能。

#### 对系统的影响

* 当启动自动备份内存数据库时，会对系统性能产生影响，请在业务低峰期间进行自动内存数据库的备份。
* 当关闭自动备份内存数据库时，会降低系统的可靠性，同时降低系统对于意外故障发生时的恢复能力。此操作为高危操作，操作前请联系华为技术支持。

#### 必备事项

**前提条件**

* 如果需要备份到自带空间，需要做如下准备：

  网关类型为DMA的DPU模块所在Pod对应的虚拟机预留充裕的用于备份的硬盘空间。
* 如果需要备份到第三方服务器，需要做如下准备：
  + 已通过登录“USCDB MML命令”界面执行**ADD RFTPSERVER**/**ADD RSFTPSERVER**命令配置第三方服务器。在该场景下配置规则如下：
    - “远端服务器类型” 配置为“DATAMTN(维护)”。
    - “FTP本端工作目录”/“SFTP本端工作目录”配置为“BACKUPNODE”。
    - “本端IPV4地址”/“本端IPV6地址”配置为业务IP类型为DMA的DPU模块的IPv4/IPv6地址，该IP地址由**ADD SRVIPADDR**命令配置。
    - “传输方向”需分别配置对应的“上传”和“下载”两条数据。
    - 当远端服务器支持FTP时，通过**ADD RFTPSERVER**配置第三方服务器。

      ```
      ADD RFTPSERVER: SERVERTYPE=DATAMTN, SERVERNAME="ftpserver1", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=21, USERNAME="name", PWD="***********", CFM="***********", RWORKDIR="realtime", LWORKDIR="BACKUPNODE", TRANSDIRECTION=DOWNLOAD, LOCALIPV4="10.93.1.131";
      ```

      ```
      ADD RFTPSERVER: SERVERTYPE=DATAMTN, SERVERNAME="ftpserver2", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=21, USERNAME="name", PWD="***********", CFM="***********", RWORKDIR="realtime", LWORKDIR="BACKUPNODE", TRANSDIRECTION=UPLOAD, LOCALIPV4="10.93.1.131";
      ```
    - 当远端服务器支持SFTP时，通过**ADD RSFTPSERVER**配置第三方服务器。

      ```
      ADD RSFTPSERVER: SERVERTYPE=DATAMTN, SERVERNAME="sftpserver1", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=22, USERNAME="name", PWD="******", CFM="******", RWORKDIR="realtime", LWORKDIR="BACKUPNODE", TRANSDIRECTION=DOWNLOAD, LOCALIPV4="10.93.1.131";
      ```

      ```
      ADD RSFTPSERVER: SERVERTYPE=DATAMTN, SERVERNAME="sftpserver2", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=22, USERNAME="name", PWD="******", CFM="******", RWORKDIR="realtime", LWORKDIR="BACKUPNODE", TRANSDIRECTION=UPLOAD, LOCALIPV4="10.93.1.131";
      ```
  + 第三方服务器预留充裕的用于备份的硬盘空间。

    备份文件大小受FE业务模型和局点容量的影响，此处以一组数据计算备份文件大小的参考值：DRU节点内存库大小3GB，DSU节点内存库大小9GB，备份文件大小分别约为1GB和3GB。在OM Portal的“USCDB MML命令”界面执行**LST CLUSTER**命令查询DRU和DSU个数，例如查询到DRU为10个，DSU为30个，则总的备份文件大小为10\*1+30\*3 =100G。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。

   执行下一步操作会对系统性能和可靠性产生影响，如需修改请在华为工程师指导下进行。
2. 执行**MOD INSP**命令，通过设置TIMEBACKUPFLAG（定时备份开关）来关闭/启动内存数据库自动备份功能。

   * 当“ 网元类型”为FE时：

     ```
     MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=0/1（关/开）, FETYPEN="SUP-FE";
     ```
   * 当“ 网元类型”为USCDB时：

     ```
     MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=0/1（关/开）, FETYPEN="USCDB";
     ```
3. 执行**LST INSP**命令对TIMEBACKUPFLAG（定时备份开关）状态查询备份开关状态是否与2操作结果一致，如果不一致，请重复2。

   ```
   LST INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, FETYPEN="网元类型";
   ```
4. 执行**MOD INSP**命令，通过设置SELFSPACEBACKUP（自带空间备份开关）和THIRDSPACEBACKUP（第三方备份开关）来关闭/启动内存数据库自带空间备份和第三方服务器备份。

   * 备份到自带空间：
     + 当“ 网元类型”为FE时：

       ```
       MOD INSP: INSPT=FE, INSPN=SELFSPACEBACKUP, INSPV=0/1（关/开）, FETYPEN="SUP-FE";
       ```
     + 当“ 网元类型”为USCDB时：

       ```
       MOD INSP: INSPT=FE, INSPN=SELFSPACEBACKUP, INSPV=0/1（关/开）, FETYPEN="USCDB";
       ```
   * 备份到第三方服务器：
     + 当“ 网元类型”为FE时：

       ```
       MOD INSP: INSPT=FE, INSPN=THIRDSPACEBACKUP, INSPV=0/1（关/开）, FETYPEN="SUP-FE";
       ```
     + 当“ 网元类型”为USCDB时：

       ```
       MOD INSP: INSPT=FE, INSPN=THIRDSPACEBACKUP, INSPV=0/1（关/开）, FETYPEN="USCDB";
       ```

#### 附加信息

**相关软参**

TIMEBACKUPFLAG（定时备份开关）

SELFSPACEBACKUP（自带空间备份开关）

THIRDSPACEBACKUP（第三方备份开关）
