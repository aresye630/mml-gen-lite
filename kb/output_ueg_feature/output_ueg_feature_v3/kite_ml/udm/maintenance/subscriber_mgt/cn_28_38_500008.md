# 配置5G全局数据

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成5G全局数据的配置。

## 必备事项

前提条件

* 已经完成UDM的CSP OM Portal侧的硬件数据和基础数据的配置。
* 已经完成5G的用户数据规划。

数据

执行操作前需要规划的数据如表1所示。

**表1** 5G全局数据

| 命令 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SYSHLRSN** | SYSHLRSN (系统HLR序列号) | 1 | 已配置数据中获取 | 统一规划。  该参数取值与USCDB MML命令界面上的**SET SYSNO**命令配置的“SYSTEMNO”参数的取值相同。 |
|  | HLRNAME(系统HLR名称) | HLR01 | 本端规划 | 统一规划。 |
|  | STATUS (状态) | master | 固定取值 | 单局点时，该参数固定取值为“MASTER”。 |
| **ADD VHLRSN** | SYSHLRSN (系统HLR序列号) | 1 | 本端规划 | 统一规划。 |
|  | HLRSN （虚拟HLR序列号） | 1 | 本端规划 | 统一规划。 |
|  | HLRNAME(虚拟HLR名称) | VHLR01 | 本端规划 | 统一规划。 |
| **ADD HLRSN** | HLRSN (HLR序列号) | 1 | 已配置数据中获取 | 该参数的取值需要与系统管理MML命令界面上的**ADD VHLRSN**命令配置的“HLRSN”的取值一一对应。 |
|  | HLRNO (HLR号码) | 8613910000 | 本端规划 | 根据运营商要求配置。容灾局的“HLR号码”会同步主用局的“HLR号码”。 |
|  | STATUS (状态) | master | 固定取值 | 单局点时，该参数固定取值为“MASTER” |
|  | CCODE (国家码) | 86 | 本端规划 | 根据运营商要求配置。 |

## 操作步骤

1. 登录PGW Web LMT MML命令界面。
2. 执行**ADD SYSHLRSN**命令增加系统HLR。
3. 执行**ADD VHLRSN**命令增加虚拟HLR。
4. 登录“UDM业务管理”窗口。
5. 执行**ADD HLRSN**命令增加HLR序列号。
