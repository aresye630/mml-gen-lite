# 配置5G鉴权数据

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成UDM鉴权数据的配置。

## 必备事项

前提条件

* 已完成UDM的CSP OM Portal侧基础数据的配置。
* 已完成5G的用户数据规划。
* 操作人员具有PGW Web LMT的操作权限。

数据

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD AMF**命令设置AMF值。
3. 执行**ADD K4**命令设置用于加密KI的K4值。
4. 如果USIM卡中烧制了OP，执行**ADD OP**命令设置OP值。

   设置OP值时，要注意以下几点：
   * USIM卡中烧制了OP时，要设置OP值。
   * USIM卡中烧制了OPC时，不用设置OP值，需要在5中设置OPC值。
5. 执行**ADD KI**命令加载KI。

   * 参数“卡类型”设置为“USIM”。
   * 参数“鉴权算法类型”根据实际需求进行设置。
