# 配置基于UDM的P-CSCF故障恢复特性

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

该任务指导操作人员配置UDM支持P-CSCF恢复机制。

## 必备事项

前提条件

请仔细阅读GWFD-025807 基于UDM的P-CSCF故障恢复特性概述功能。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET HSYSTEMPARA** | 是否支持P-CSCF恢复机制（P\_CSCF\_RESTORE\_SUPP） | TRUE | 固定取值 | 用于标识HSS是否支持P-CSCF恢复机制。 |
| **SET UDMSERV** | P-CSCF容灾模式（NGC\_PCSCF\_RSD\_MODE） | SMF | 本端规划 | 用于标识当UDM/UTA同时存储AMF和SMF上报的P-CSCF Restore Callback URI时，UDM/UTA向哪个网元发起P-CSCF故障恢复消息Nudm\_UECM\_PCscfRestoration通知。 |

## 操作步骤

1. 登录“IMS-HSS业务管理”窗口。
2. 执行**SET HSYSTEMPARA**命令开启支持P-CSCF恢复机制。
3. 执行**SET UDMSERV**命令配置P-CSCF容灾模式。

## 任务示例

任务描述

在UDM上设置支持P-CSCF恢复机制。

脚本

/\*登录“IMS-HSS业务管理”窗口\*/

/\*配置P-CSCF恢复机制\*/

```
SET HSYSTEMPARA: P_CSCF_RESTORE_SUPP=TRUE;
SET UDMSERV: NGC_PCSCF_RSD_MODE=SMF;
```
