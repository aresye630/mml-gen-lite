## 操作场景

本任务旨在指导操作人员配置5G-AKA鉴权特性功能。

## 必备事项

前提条件

* 请仔细阅读5G-AKA鉴权特性功能。
* 操作人员具有PGW Web LMT的操作权限。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD AMF**配置鉴权管理域。
3. 执行**ADD K4**设置KI的传输密钥K4。
4. 执行**ADD KI**配置用户鉴权密钥。
5. 执行**ADD SUB**为用户开户。
6. 执行**MOD AMDATA**为用户签约5G数据，配置用户的鉴权策略为5G-AKA鉴权。
7. （可选）执行**ADD SUCIKEY**增加SUCI私钥。

   若AUSF/UDM接收到的消息中，用户标识为SUCI，并且加密类型是PROFILEA或PROFILEB时，执行本命令增加SUCI私钥。

## 任务示例

任务描述

为用户配置5G-AKA鉴权功能。

脚本

/\*登录“UDM业务管理”窗口\*/

/\*配置鉴权管理域\*/

```
ADD AMF: HLRSN=1, AMFSNO=1, AMFVALUE="1111";
```

/\*设置KI的传输密钥K4\*/

```
ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=ClearKey, ALGTYPE=AES256, K4VALUE="*****";
```

/\*配置用户鉴权密钥。\*/

```
ADD KI: HLRSN=1, IMSI="460011365811111", KIVALUE="*****", K4SNO=0, CARDTYPE=USIM, ALG=MILENAGE, OPCVALUE="*****", AMFSNO=1, KEYTYPE=ClearKey;
```

/\*用户开户。\*/

```
ADD SUB: HLRSN=1,IMSI="460011365811111", ISDN="8611365801021", CARDTYPE=USIM, NAM=BOTH, EPS=TRUE, DEFAULTCALL=TS11, AMBRMAXUL=50000000, AMBRMAXDL=50000000;
```

/\*配置用户鉴权策略。\*/

```
MOD AMDATA: IMSI="460011365811111", PROV=TRUE, AMBRUP=50000000, UPUNIT=bps, AMBRDW=50000000, DWUNIT=bps, AUTHTYPE=5G-AKA;
```

/\*（可选）增加SUCI私钥\*/

```
ADD SUCIKEY: KEYNAME="key1", KEYTYPE=PROFILEA, KEYID=1, SAVEMODE=LOCAL, KEYVALUE="*****";
```
