# 配置PMS服务器的接入权限

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

客户端通过IP地址与PMS服务器进行连接时，为了确保PMS的数据安全，需要支持通过客户端IP地址对客户端进行鉴权，只有鉴权通过的客户端才允许接入到PMS服务器。

客户端包括以下三种：

* UPCF Web UI：提供业务策略配置、通知发送等功能。
* POP：POP生成策略脚本时，会通过该接口发送SOAP消息通知到UPCF。
* CLI客户端：通过CLI/SCLI接口提供UPCF策略数据配置功能。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

向系统管理员获取OM Portal帐号的密码。

**数据**

执行该操作前，规划好允许接入PMS服务器的IP地址。

#### 操作步骤

1. 登录“UEG MML命令”界面。
2. 配置UPCF Web UI接入PMS服务器的权限。

   执行**ADD PMSADMINIP**命令，添加允许接入PMS服务器的IP地址。以参数“IPVER”值为“IPV4”为例：

   ```
   ADD PMSADMINIP: IPID=IP地址索引, IPVER=IPV4, IP=IPv4地址, NETMASK=子网掩码, DESCRIPTION=描述;
   ```
