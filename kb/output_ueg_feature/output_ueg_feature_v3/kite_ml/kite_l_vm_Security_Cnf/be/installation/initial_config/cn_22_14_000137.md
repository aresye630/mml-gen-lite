# 手动解锁用户

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

当用户登录PGW客户端，输入密码的次数超过限制的次数时，系统将自动锁定帐户。系统管理员可以执行该操作手工解锁用户。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

只有具有管理员权限的用户才能解锁被锁定的操作员。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 操作员名称

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 在“应用类型”的下拉菜单中选择“系统管理”。
3. 执行命令**SET UNLCK**手工解锁用户。

   ```
    SET UNLCK: SYSNO=1, OPNAME="opr1";
   ```
