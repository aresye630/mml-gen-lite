# 配置HTTPS安全协议（SOAP）

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

当USCDB使用SOAP接口与业务发放系统对接时，SOAP接口支持HTTP和HTTPS两种传输方式。

在传输数据时，HTTPS会建立一个信息安全通道，该通道用于提供加密通讯及对网络服务器身份的鉴定，因此出于安全的考虑，推荐在SOAP接口上配置HTTPS安全协议。

#### 对系统的影响

* 配置完成后需要重启PGW模块，将导致短暂的业务发放指令执行失败。
* PGW的处理速度将会下降。

#### 必备事项

**前提条件**

* 向系统管理员获取OM Portal的帐号的密码。
* 确认已加载“连接类型”为“SOAP”的“CAVERIF(CA证书)”或“ROOTVERIF(根证书)”、“DEVVERIF(设备证书)”和“KEYFILE(密钥文件)”的证书文件。可通过在“USCDB MML命令”界面执行**LST VERIF**命令查询。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**LST FEPLUG**命令查询网元类型。
3. 执行**MOD INSP**命令，打开TLS工作模式。

   ```
   MOD INSP: INSPT=FE, INSPN=TLSMODE, INSPV=3, FETYPEN=网元类型;
   ```
4. 执行**LST MODULE**命令，查询所有PGW模块的模块号。
5. 执行**RST MODULE**命令，重启所有的PGW模块。

   重启PGW进程会导致短暂的业务发放指令执行失败，因此推荐此操作在话务低峰期执行，并提前通知客户做好准备。

   ```
   RST MODULE: MID=模块号, MT=PGW;
   ```
