## 操作场景

本任务旨在指导操作人员在IMS-HSS上增加和查询透明数据。

本配置实例在PGW Web客户端上为IMPU（“sip:impu\_test\_01@huawei.com”）增加透明数据和别名透明数据。

配置前需要确保“IMPU别名组ID”为“1”的别名IMPU组已经存在，且“sip:impu\_test\_01@huawei.com”属于此别名IMPU组。请参考配置别名IMPU组页面配置别名组。

## 必备事项

前提条件

* 操作人员已完全了解透明数据的存储和管理。
* 操作人员具有OM Portal权限。
* 操作人员具有PGW Web LMT客户端业务发放权限。
* 已经完成IMPU为“sip:impu\_test\_01@huawei.com”的用户开户。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 执行**SET DMPECAP**命令设置对端AS的实体能力。
3. 登录“IMS-HSS业务管理”窗口。
4. 执行**SET HSYSTEMPARA**设置系统支持通过“datareference”取值为“0”来处理别名透明数据。

   Sh接口所有消息对透明数据和别名透明数据的处理，通过该命令中的参数“别名透明数据是否支持datareference为0”来设置。

   * TRUE：IMS-HSS支持通过“datareference”取值为“0”来处理别名透明数据。
   * FALSE：IMS-HSS不支持通过“datareference”取值为“0”来处理别名透明数据，只能通过“datareference”取值为“20”来处理。
5. 执行**SET HREPDATA**命令为IMPU（sip:impu\_test\_01@huawei.com）增加一个透明数据。 参数“REPTYPE”取值为“REPDATA”。
6. 执行**SET HREPDATA**命令，给别名IMPU组新增一个别名透明数据。参数“REPTYPE”取值为“ALIASREPDATA”。

## 任务示例

任务描述

此示例包含配置和查询IMS-HSS透明数据的操作。

脚本

登录“UEG MML命令”界面

/\*设置对端AS的实体能力\*/

```
SET DMPECAP: PEERNAME="HSS_AS", OPTYPE=ADD, PEERTYPE=AS, PR=REPOSITORYDATA-1&ALIASREPOSITORY-1, UR=REPOSITORYDATA-1&ALIASREPOSITORY-1, NR=REPOSITORYDATA-1&ALIASREPOSITORY-1, HN="as111.huawei.com", DN="huawei.com";
```

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*设置系统支持通过datareference取值为0来处理别名透明数据\*/

```
SET HSYSTEMPARA: SH_ALIASREPDATA_SUPPORT_DATAREFERENCE0=TRUE;
```

/\*配置透明数据\*/

```
SET HREPDATA: IMPU="sip:impu_test_01@huawei.com", REPDATA="<?xml version\=\"1.0\"?><Sh-Data><RepositoryData><ServiceIndication>SI_01</ServiceIndication><SequenceNumber>0</SequenceNumber><ServiceData><any>SH_RSI_DATA</any></ServiceData></RepositoryData></Sh-Data>", REPTYPE=REPDATA;
```

/\*配置别名透明数据\*/

```
SET HREPDATA: IMPU="sip:impu_test_01@huawei.com", REPDATA="<?xml version\=\"1.0\"?><Sh-Data><Sh-Data-Extension><AliasesRepositoryData><ServiceIndication>ALIASI_SI_01</ServiceIndication><SequenceNumber>0</SequenceNumber><ServiceData><any>alias_repositdata_01</any></ServiceData></AliasesRepositoryData></Sh-Data-Extension></Sh-Data>", REPTYPE=ALIASREPDATA;
```
