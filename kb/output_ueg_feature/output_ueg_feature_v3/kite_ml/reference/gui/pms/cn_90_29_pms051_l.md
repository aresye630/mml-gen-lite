# 登录UPCF WebUI界面

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

本文主要介绍如何登录UPCF WebUI界面。登录UPCF WebUI界面可以完成UPCF策略数据配置，以实现UPCF的核心业务功能。

#### 必备事项

**前提条件**

* 已安装UPCF WebUI界面兼容的浏览器，如表1所示。

  **表1** 支持的浏览器

  | 浏览器类型 | 版本 |
  | --- | --- |
  | Google Chrome（推荐使用） | 需要使用Google Chrome v95.0（32位/64位）及以上版本，否则会影响系统功能的正常使用。推荐安装最新版本浏览器。 |
  | Internet Explorer | 需要Internet Explorer 11（32位/64位）及以上版本，否则会影响系统功能的正常使用。推荐安装最新版本浏览器。 |
* 在UPCF网元中安装并启用了PMS服务（在CSP OM Portal “UEG MML命令”界面，执行“DSP MSPROCESS”命令操作类型为“PROCNAME”下配置“PROCNAME”的取值为“CELL\_PcfPms”，查看其“进程状态”为“Ready”）。
* 配置PMS系统加密套件（初始安装UPCF）。
* 设置IE浏览器及PC（首次登录UPCF WebUI）或设置Google Chrome浏览器及PC（首次登录UPCF WebUI）。

#### 操作步骤

1. 在浏览器中使用https进入UPCF WebUI界面。端口号为8443，登录地址为：***https://UPCF WebUI的登录IP地址******:8443***。登录界面如图1所示。
   * IPv4类型，如：UPCF WebUI的登录IP地址为10.164.18.243，则登录地址为***https://10.164.18.243******:8443***。
   * IPv6类型，如：UPCF WebUI的登录IP地址为fd0e:135:159:36::150，则登录地址为***https://[fd0e:135:159:36::150]:8443***。

   UPCF WebUI的登录IP地址可以通过在“UEG MML命令”界面执行LST PMSDEVADDR命令查询得到。

   **图1** UPCF WebUI登录页面
2. 登录UPCF WebUI页面，选择“用户类型”。

   您可以在UPCF WebUI页面右上角“选择语言”参数下拉框中对界面语言进行设置。

   * “用户类型”为“Local”
     1. 首次登录输入用户名admin，无需输入密码或者输入任意密码，均会跳转出如修改初始密码提示。单击“确定”，进入重新设置密码界面。

        **图2** 修改初始密码提示内容
     2. 设置新密码，如图3所示。输入新密码和确认密码，单击“确定”即可。新密码配置原则参考“配置UPCF Web UI的安全策略 ”。

        **图3** 重设密码提示内容
     3. 修改完密码后，跳转回登录界面，再次输入正确的用户名、密码和验证码，用户名仍为admin，密码为修改后的新密码，单击“登录”，进入UPCF WebUI界面。

        如果开启了授权提示功能，单击“登录”后会弹出授权提示，如图4所示。请用户根据实际情况选择是否继续登录。

        **图4** 授权提示内容

        连续两次登录UPCF WebUI失败后，再次登录时系统会启用验证码校验机制。
   * “用户类型”为“SSO”

     + 采用SSO方式登录需要先根据配置UPCF与SSO服务器的对接数据指导完成相关配置。
     + 通过SSO方式登录，UPCF WebUI界面的展示和修改功能由SSO类型的用户决定，如果SSO类型的用户关联的角色未在UPCF WebUI系统中预置或者自定义的角色中，则鉴权失败，不会给SSO类型的用户显示任何UPCF WebUI相关信息。
     + UPCF WebUI中“我的账户”界面不会对SSO类型的用户显示。

     1. 选择“用户类型”为“SSO”，登录界面如图5所示，单击“登录”。

        **图5** SSO用户类型登录
     2. 系统会跳转进入网管登录界面，如图6所示。输入网管的“用户名”和“密码”后，单击“登录”。

        **图6** 登录网管界面
