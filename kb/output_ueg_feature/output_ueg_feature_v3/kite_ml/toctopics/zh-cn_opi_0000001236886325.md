# 激活UDM全故障业务保活特性

* 操作场景

## 操作场景

为提升UDM全故障场景下的业务连续性，可以激活本特性。UDM全故障业务保活特性需要在AMF和SMF侧分别开启UDM全故障业务保活特性。

适用于AMF、SMF

## 必备事项

前提条件

* 请仔细阅读GWFD-021408 UDM全故障业务保活特性概述。
* 完成加载License。

## 操作步骤

* AMF侧配置

  1. 打开本特性的License配置开关。

     **SET LICENSESWITCH**
  2. 开启AMF的UDM全故障Bypass功能。

     **SET AMFUDMBYPASS**
  3. 增加UDM Bypass后的最小签约数据配置。

     **ADD UDMBYPASSSUB**
  4. （可选）设置AMF在匹配用户当前安全上下文时，忽略TSC标识，解决由于手机TSC携带错误导致用户安全检查失败而无法接入的问题。

     **SET AMFSOFTPARAOFBIT**
  5. （可选）配置故障设备的网元实例标识和故障码。

     **ADD BYPASSFAULTCODE**

     AMF收到UDM/AUSF返回的5xx故障码允许用户进入UDM Bypass状态，如果需要增加其他故障码作为进入UDM Bypass状态的原因值，或者应急场景下配置指定的故障码进入UDM Bypass状态，可以通过**ADD BYPASSFAULTCODE**命令配置。

     **ADD BYPASSFAULTCODE**命令仅在已明确存在AUSF或UDM全故障的场景下应急使用，默认不配置。配置前需要先收集故障码信息，根据实际情况可进行如下四种配置：

     + 基于全局设备的所有故障码：“网元实例标识”和“自定义故障码”配置为“\*”,不配置“错误信息”。
     + 基于全局设备的指定故障码：“网元实例标识”配置为“\*”，“自定义故障码”配置为具体的故障码，不配置“错误信息”或者配置具体的“错误信息”。
     + 基于具体UDM/AUSF网元实例所有故障码：“网元实例标识”配置为具体的某些网元实例，“自定义故障码”配置为“\*”,不配置“错误信息”。
     + 基于具体UDM/AUSF网元实例、具体的故障码和错误信息组合：“网元实例标识”配置为具体的某些网元实例，“自定义故障码”配置为具体的故障码，不配置“错误信息”或者配置具体的“错误信息”。
  6. 配置对端AUSF返回5xx错误码时，AMF在对ProblemDetails校验失败后是否重选AUSF以及重选后的AUSF响应消息携带ProblemDetails再次校验失败是否进入UDM Bypass状态。

     **SET AMFPEERSELFUNC**
  7. **可选：**如果是Model D组网，将软参DWORD68 BIT9设置为0，配置AMF在Model D模式下向AUSF及UDM发送的首消息头域中不携带3gpp-Sbi-Target-apiRoot。

     **SET AMFSOFTPARAOFBIT**
  8. **可选：**通过软参DWORD68 BIT3配置AMF服务发现AUSF或UDM失败且本地没有AUSF或UDM的缓存信息时，是否支持根据NRF返回的NoProfileMatchReason判断用户进入UDM BYPASS状态。

     **SET AMFSOFTPARAOFBIT**
  9. **可选：**通过软参DWORD68 BIT5配置AMF与AUSF或UDM交互时是否使用对端原始响应信息。

     **SET AMFSOFTPARAOFBIT**
  10. 配置是否支持通过N26接口向MME传递MSISDN。涉及消息有：Identification Response、Context Response、Forward Relocation Request。

      **ADD N26MMECHAR**

      **MOD N26MMECHAR**
  11. 若N26接口支持携带MSISDN信元（参考配置**ADD MMECHARACT**/**MOD MMECHARACT**/**ADD N26MMECHAR**/**MOD N26MMECHAR**），建议将软参DWORD80 BIT20配置为1。

      **SET AMFSOFTPARAOFBIT**
* SMF侧配置

  1. 打开本特性的License配置开关。

     **SET LICENSESWITCH**
  2. 增加UDM Bypass后的用户签约QoS属性。

     **ADD 5GCSUBQOS**
  3. 设置UDM Bypass后指定APN的QoS属性。

     **ADD APNQOSBYPASS**
  4. **可选：**配置UDM Bypass后通用的QoS属性。

     **SET COMMQOSBYPASS**
  5. 开启SMF的UDM全故障Bypass功能。

     **SET SMFUDMBYPASS**
  6. 开启UDM静态IP功能。

     **SET EDGESMCOMMFUNC**
  7. 为静态IP用户配置UDM静态IP信息。

     **ADD RDSSTATICIPPARA**
  8. （可选）基于IMSI为5G LAN用户配置5G LAN组。

     **ADD RDSSTATICIPPARA**
  9. （可选）基于DNN为5G LAN用户配置5G LAN组。

     **ADD EDGENGLANGROUP**
  10. （可选）配置故障设备的网元实例标识和故障码。

      **ADD BYPASSFAULTCODE**

      SMF收到UDM返回的5xx故障码允许会话进入UDM Bypass状态，如果需要增加其他故障码作为进入UDM Bypass状态的原因值，或者应急场景下配置指定的故障码进入UDM Bypass状态，可以通过**ADD BYPASSFAULTCODE**命令配置。

      **ADD BYPASSFAULTCODE**命令仅在已明确存在UDM全故障的场景下应急使用，默认不配置。配置前需要先收集故障码信息，根据实际情况可进行如下四种配置：

      + 基于全局设备的所有故障码：“网元实例标识”和“自定义故障码”配置为“\*”,不配置“错误信息”。
      + 基于全局设备的指定故障码：“网元实例标识”配置为“\*”，“自定义故障码”配置为具体的故障码，不配置“错误信息”或者配置具体的“错误信息”。
      + 基于具体UDM网元实例所有故障码：“网元实例标识”配置为具体的某些网元实例，“自定义故障码”配置为“\*”,不配置“错误信息”。
      + 基于具体UDM网元实例、具体的故障码和错误信息组合：“网元实例标识”配置为具体的某些网元实例，“自定义故障码”配置为具体的故障码，不配置“错误信息”或者配置具体的“错误信息”。
  11. 配置DNN对应的默认切片。

      **ADD NSDNN**

      **MOD NSDNN**
  12. **可选：**配置当SMF服务发现UDM失败时，是否支持根据SMF上UDM的缓存信息判断进入UDM BYPASS状态，以及不存在缓存UDM时，是否支持根据NRF返回的NoProfileMatchReason判断用户会话进入UDM BYPASS状态。

      **SET SOFTPARAOFBIT**

## 任务示例

任务描述

* 任务1：开启基础的UDM全故障业务保活特性，在AMF侧增加UDM Bypass时使用的最小签约数据，在SMF侧增加UDM Bypass时指定APN的QoS属性。
* 任务2：如果已明确AUSF或UDM全故障，运营商期望UDM/AUSF网元返回除5XX之外的错误码时也允许用户进入UDM Bypass状态，或者应急场景下UDM/AUSF网元返回指定的故障码或者故障码和错误信息组合时允许用户进入UDM Bypass状态，在任务1的基础上增加BYPASS故障状态码配置。
* 任务3：手动触发AMF上用户退出UDM Bypass状态。
* 任务4：手动触发SMF上会话退出UDM Bypass状态。

脚本

任务1的脚本:

* AMF侧配置

  //开启AMF的UDM全故障特性license。

  ```
  SET LICENSESWITCH: LICITEM="LKV2UDMBPMM01",SWITCH=ENABLE;
  ```

  //开启AMF的UDM故障Bypass功能。

  ```
  SET AMFUDMBYPASS:SWITCH=ON,RECOVERYACT=DEREG,FAULTDETECTRATE=3,SCANINTERVAL=600,RPTFAILCHR=ON,DEPLOYMENTMODE=CO_DEPLOYMENT,AUTOEXITSW=ON;
  ```

  //设置UDM Bypass最小签约数据配置。

  ```
  ADD UDMBYPASSSUB:SUBRANGE=ALL_USER,SNSSAIINFOSSW=ON,SNSSAIINFOS="1-D143A5:test";
  ```

  //（可选）设置AMF在匹配用户当前安全上下文时，忽略TSC标识，解决由于手机TSC携带错误导致用户安全检查失败而无法接入的问题。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=14, VALUE=VALUE_1, POSITION=20;
  ```

  //配置对端AUSF返回5xx错误码时，AMF在对ProblemDetails校验失败后重选AUSF以及重选后的AUSF响应消息携带ProblemDetails再次校验失败进入UDM Bypass状态。

  ```
  SET AMFPEERSELFUNC:AUSFRESELEN=ON;
  ```

  //（可选）如果是Model D组网，将软参DWORD68 BIT9设置为0，配置AMF在Model D模式下向AUSF及UDM发送的首消息头域中不携带3gpp-Sbi-Target-apiRoot。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=68, VALUE=VALUE_0, POSITION=9;
  ```

  //（可选）通过软参DWORD68 BIT3配置AMF服务发现AUSF或UDM失败且本地没有AUSF或UDM的缓存信息时，是否支持根据NRF返回的NoProfileMatchReason判断用户进入UDM BYPASS状态。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=68, VALUE=VALUE_0, POSITION=3;
  ```

  //（可选）通过软参DWORD68 BIT5配置AMF与AUSF或UDM交互时是否使用对端原始响应信息。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=68, VALUE=VALUE_0, POSITION=5;
  ```

  //配置支持通过N26接口向MME通过私有信元传递MSISDN。涉及消息有：Identification Response、Context Response、Forward Relocation Request。

  ```
  MOD N26MMECHAR: RANGE=ALL_MME, MSISDNSW=YES, PVTMSISDNSW=YES;
  ```

  //（可选）若N26接口支持携带MSISDN信元（参考配置**ADD MMECHARACT**/**MOD MMECHARACT**/**ADD N26MMECHAR**/**MOD N26MMECHAR**），建议将软参DWORD80 BIT20配置为1。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=80, VALUE=VALUE_1, POSITION=20;
  ```
* SMF侧配置

  //开启SMF的UDM全故障特性license。

  ```
  SET LICENSESWITCH: LICITEM="LKV2UDMBPSM01",SWITCH=ENABLE;
  ```

  //增加UDM Bypass后的用户签约QoS属性。

  ```
  ADD 5GCSUBQOS:SUBQOSINDEX=1,FIVEQI=5,AMBRDL=1000000,AMBRUL=1000000,ARPPL=1;
  ```

  //设置UDM Bypass后指定APN的QoS属性。

  ```
  ADD APNQOSBYPASS:APN="apn1",SUBQOSINDEX=1;
  ```

  //设置UDM Bypass后通用的QoS属性。

  ```
  SET COMMQOSBYPASS:DEFSW=ENABLE,SUBQOSINDEX=1;
  ```

  //开启SMF的UDM故障Bypass功能。

  ```
  SET SMFUDMBYPASS:UDMBYPASS=ON,FAULTDETECTRATE=3,SCANINTERVAL=600,RPTFAILCHR=ON,AUTOEXITSW=ON;
  ```

  //存在静态IP用户时，开启UDM静态IP功能。

  ```
  SET EDGESMCOMMFUNC: UDMSTATICIPSW=ENABLE,UDMIPTYPE=SINGLE_STACK;
  ```

  //为静态IP用户配置UDM静态IP信息。

  ```
  ADD RDSSTATICIPPARA: IMSI="123000123456789", APN="apn1", ADDRTYPE=IPV4, IPV4ADDRESS="192.168.1.10";
  ```

  //（可选）基于IMSI为5G LAN用户配置5G LAN组。

  ```
  ADD RDSSTATICIPPARA: IMSI="123001123456789", APN="apn1", ADDRTYPE=Ethernet, GROUPID="A0000001-123-003-01";
  ```

  //（可选）基于DNN为5G LAN用户配置5G LAN组。

  ```
  ADD EDGENGLANGROUP: DNN="apn1", SST=1, SD="010101", PDUSESSIONTYPE=Ethernet, GROUPID="A0000001-123-003-02";
  ```

  //配置DNN对应的默认切片。

  ```
  MOD NSDNN: NSIDX=0, DNN="apn1", DEFIWKIND=YES;
  ```

  //（可选）配置SMF根据NRF返回的NoProfileMatchReason判断用户会话是否进入UDM BYPASS状态。如果NoProfileMatchReason为TARGET\_NF\_SUSPENDED则进入UDM BYPASS状态；否则不进入UDM BYPASS状态。

  ```
  SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1059, VALUE=VALUE_0, POSITION=9;
  SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1043, VALUE=VALUE_0, POSITION=5;
  ```

* AMF侧配置

  //配置故障设备的网元实例标识和故障码。

  AMF收到UDM/AUSF返回的5xx故障码允许用户进入UDM Bypass状态，如果需要增加其他故障码作为进入UDM Bypass状态的原因值，或者应急场景下配置指定的故障码进入UDM Bypass状态，可以通过**ADD BYPASSFAULTCODE**命令配置。

  **ADD BYPASSFAULTCODE**命令仅在已明确存在AUSF或UDM全故障的场景下应急使用，默认不配置。配置前需要先收集故障码信息，根据实际情况可进行如下四种配置：
