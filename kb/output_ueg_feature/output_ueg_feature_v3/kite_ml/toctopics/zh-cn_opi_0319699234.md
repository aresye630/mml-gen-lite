# 模板开户

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成5G模板开户数据的配置。

## 必备事项

前提条件

* 已经完成UDM的CSP OM Portal侧基础数据的配置。

* 已完成5G用户数据配置。

数据

5G模板户及签约业务数据配置关键参数说明，如表1所示。

**表1** 关键参数说明

| 命令 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SMDATATPL** | HLRSN(HLR序列号) | 1 | 已配置数据中获取 | 该参数的取值需要与系统管理MML命令界面上的**ADD VHLRSN**命令配置的“HLRSN”的取值一一对应。 |
|  | TPLID(模板ID) | 1 | 本端规划 | 统一规划。 |
|  | SNSSAI(切片标识) | 1-D143A5 | 本端规划 | 标识5G系统中的网络切片。 |
|  | DEFSNSSAI(是否默认S-NSSAI) | TRUE | 本端规划 | 统一规划。 |
|  | DNN(数据网名称) | huawei.com | 与对端协商 | 数据网名称，需与UNC侧配置一致。从UNC侧获取进行配置。 |
|  | DNNQOSTPLID(5GS DNNQOS模板ID) | 1 | 本端规划 | 该参数必须先由**ADD DNNQOSTPL**命令定义，然后才能在此处引用。 |
| **ADD NGSUSERTPL** | HLRSN(HLR序列号) | 1 | 已配置数据中获取 | 与**ADD SMDATATPL**中的“HLRSN(HLR序列号)”保持一致。 |
|  | TPLID(模板ID) | 1 | 本端规划 | 统一规划。 |
|  | AMBRUP(UE级别上行速率) | 200 | 与对端协商 | 统一规划。  表示5G网络UE级别上行带宽，需与UNC侧配置一致。从UNC侧获取进行配置。 |
|  | UPUNIT(UE级别上行速率单位) | bps | 与对端协商 | - |
|  | AMBRDW(UE级别下行速率) | 500 | 与对端协商 | 统一规划。  表示5GUE级别下行带宽，需与UNC侧配置一致。从UNC侧获取进行配置。 |
|  | DWUNIT(UE级别下行速率单位) | bps | 与对端协商 | - |
|  | FORBIDTPLID(禁止区域模板ID) | 1 | 已配置数据中获取 | 该参数必须先由**ADD FORBIDAREATPL**命令定义，然后才能在此处引用。 |
|  | SERAREATPLID(业务区域限制模板ID) | 99 | 已配置数据中获取 | 该参数必须先由**ADD SERAREATPL**命令定义，然后才能在此处引用。 |

|  | MICOALLOWED(是否支持MICO模式) | FALSE | 本端规划 | 统一规划。 |

|  | ISDN(MSISDN) | 86111111113 | 本端规划 | 与UE卡数据一致。 |
|  | TPLTYPE(模板类型) | EPS\_SEPARATE | 本端规划 | 统一规划。 |
|  | NGSUSERTPLID(5G用户模板ID) | 1 | 本端规划 | 统一规划。 |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD SMDATATPL**命令，增加5G会话信息模板数据记录。
3. 执行**ADD NGSUSERTPL**命令，增加5GS用户模板数据记录。
4. 执行**ADD TPLSUB**命令，为用户模板开户。

   还可以通过**ADD TPLUSCSUB**或者**ADD SCARD**命令为用户进行模板开户。
