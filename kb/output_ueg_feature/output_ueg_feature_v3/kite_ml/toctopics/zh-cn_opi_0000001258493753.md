# 检查活动告警

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

为了保证系统的正常运行，维护人员需要每天检查并及时处理系统产生的故障告警，保证系统的持续正常运行。

## 必备事项

前提条件

已经登录OM Portal，或者已登录MAE并进入Access子系统。

数据

该操作无需准备数据。

## 操作步骤

1. 通过OM Portal或U2020/MAE查看活动告警，根据告警帮助及时处理系统产生的紧急告警和重要告警。

   告警级别为紧急的，会影响到系统提供的服务，需要紧急处理。如某资源完全不可用，需立即采取措施，进行恢复。
