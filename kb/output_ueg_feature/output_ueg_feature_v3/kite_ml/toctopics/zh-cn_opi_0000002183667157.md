## 操作场景

当支持eDRX功能的用户，在支持eDRX基站覆盖范围内接入5G核心网时，AMF会进行eDRX能力协商。当需要AMF进行eDRX能力协商，AMF优先使用UDM下发的eDRX参数时，请参考本章节进行配置。

适用于AMF。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 设置H-SFN参考时间（时间类型GPS或者UTC请与gNodeB对齐）：

   **SET HSFNTIME**
3. 配置5G M2M策略参数：

   **ADD NGM2MPLCY**
4. 配置5G M2M控制参数：

   **SET NGM2MCTRL**

## 任务示例

任务描述

支持eDRX功能的UE接入核心网时，AMF与gNodeB协商使用同一时间UTC，并且AMF提前默认值3s发起寻呼。AMF优先使用UDM下发的eDRX参数。

脚本

//配置AMF和gNodeB使用同一时间类型UTC。

```
SET HSFNTIME: TIMETYPE=UTC, DATE=2010/01/01, TIME=00：00：00;
```

//关闭eDRX短周期使能开关，NR模式寻呼窗口差值配置为3s。

```
SET NGM2MCTRL: SHORTECLSW=NO, NREDRXPAGDIFF=MAX_DIFF_3_SECOND, REACHEVENTNSSW=YES, INTRAUSRPLANOPT=YES, INTRAUSRPLANOPT=YES;
```

//配置5G M2M终端省电策略：AMF优先使用UDM签约的eDRX参数。

```
ADD NGM2MPLCY: SUBRANGE=HOME_USER, FEATURECOND=DNN, DNNNI=huawei.com, EDRXSW=ON, NREDRXSUBPRI=YES;
```
