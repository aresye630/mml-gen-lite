## 操作场景

根据网络情况需要设置主控与业务节点之间的故障检测方式为HA+ETCD时，需要进行如下配置。

## 必备事项

前提条件

请仔细阅读SFFD-010030 分布式集群防脑裂。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET ELECTSERVICE** | LIGHTHOUSESWITCH | ENABLE | 本端规划 | 配置主控与业务节点之间的故障检测方式为HA+ETCD。 |
|  | SERVICEINSTANCE | "VNRS\_VNFC\_999" | 本端规划 |  |
| **SET BASESUBHEALTH** | ENABLEFLAG | Enable | 本端规划 | 配置Base链路亚健康信息。 |
|  | SERVICEINSTANCE | "VNRS\_VNFC\_999" | 本端规划 |  |

## 操作步骤

1. 已经登录OM Portal，或者已登录MAE并进入Access子系统。
2. 使用**LST VNFC**命令查询系统上部署的所有VNFC。
3. 在步骤2查询出的所有VNFC上都执行如下两条命令：

   * 使用**SET BASESUBHEALTH**命令配置Base平面Base链路亚健康信息。
   * 使用命令**SET ELECTSERVICE**配置主控与业务节点之间的故障检测方式为HA+ETCD。

## 任务示例

任务描述

在所有VNFC和VNFP下执行下面的命令开启ETCD灯塔功能：

脚本

根据网络情况需要更改主控与业务节点之间的故障检测方式为HA+ETCD时，开启灯塔开关。

1. 在MML命令行执行如下命令，查询ETCD灯塔功能是否开启。

   ```
   LST ELECTSERVICE:SERVICEINSTANCE="VNRS_VNFC_999";
   ```
2. 在MML命令行执行如下命令，开启ETCD灯塔功能。

   ```
   SET ELECTSERVICE:SERVICESWITCH=ENABLE,LIGHTHOUSESWITCH=ENABLE,SERVICEINSTANCE="VNRS_VNFC_999";
   ```
3. 在MML命令行执行如下命令，开启Base平面亚健康检查功能。

   ```
   SET BASESUBHEALTH:ENABLEFLAG=Enable,SERVICEINSTANCE="VNRS_VNFC_999";
   ```
