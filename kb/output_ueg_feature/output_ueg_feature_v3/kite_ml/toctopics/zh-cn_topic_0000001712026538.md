# 配置LDAP数字证书

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

证书加载完成后，LDAP服务通过TLS协议与LDAP服务器通信时，如果是首次与对端系统进行对接，请根据如下操作完成配置。

如果已经配置过对端链路对接信息，本次操作仅替换已有信任证书时，请跳过该章节。

#### 必备事项

已完成设备证书或信任证书的加载。如需了解加载证书的场景，请参考UPCF证书应用场景；关于加载或更新网元证书的方法，请参考证书方案介绍。

#### 操作步骤

1. 在OM Portal界面选择“应用管理 > MML”，进入MML命令界面，选择UEG网元。
2. 执行**ADD COMTLSCFG**命令，增加TLS配置信息。

   ```
   ADD COMTLSCFG: TLSCFGID=TLS配置ID, TLSCFGNAME="TLS配置名称", PROTOCOLVER=协议版本, STRONGSUITE=TLS加密套件;
   ```
3. 执行**ADD LDAPLNK**命令，配置LDAP客户端数字证书。

   选择“TLS功能”为“ON(打开)”，“证书应用场景”为“UPCF\_LDAP\_certForLDAPLNK(LDAP接口链路客户端证书)”进行配置。

   ```
   ADD LDAPLNK: LINKID=链路ID, LNKNAME=链路名称, IPVER=IPV4, LOCALPORT=本端端口, PEERIP=对端IPV4地址, PEERPORT=对端端口, USERNAME=用户名, PWD=密码, CFM=确认密码, DSPRI=数据源优先级, TLSFUNC=ON, CERTSCENE=UPCF_LDAP_certForLDAPLNK, CRLPOLICY=CRL策略, TLSCFGID=TLS配置ID;
   ```
