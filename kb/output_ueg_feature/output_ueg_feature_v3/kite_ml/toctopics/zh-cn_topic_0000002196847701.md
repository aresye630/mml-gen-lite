# 证书独立恢复

* 操作场景
* 前提条件
* 操作步骤

#### 操作场景

当系统出现异常或紧急事故时，可使用保存在本地的证书备份文件或者将保存在U2020/MAE、远程SFTP服务器的证书备份包下载到本地，然后选择使用保存在本地的证书备份文件进行恢复。

* 扩展域不支持备份恢复功能，扩展域证书独立恢复操作可以在普通域进行。
* 在有其他备份或恢复任务处于正在运行状态时，恢复数据任务会失败。
* 安装补丁后备份操作生成的备份包不能用于补丁卸载后做系统恢复。
* 若升级到高版本（21.6.0及之后版本）后进行过备份操作且在观察期内回退到低版本（21.6.0之前版本），此时会存在高版本备份包配套低版本软件场景，低版本OM Portal不支持上传、下载和手动恢复高版本备份包内容。高版本备份包也不支持手动删除，7天后会自动删除。

#### 前提条件

已登录OM Portal。

#### 操作步骤

1. 在主菜单选择“应用管理 > 备份恢复”。
2. 在左侧导航栏单击“恢复”，主页面显示备份任务列表。
3. 查看需要恢复的备份文件是否在备份任务列表中。

   * 是 => 5
   * 否 => 4
4. 单击“上传本地文件”，然后单击“添加文件”，选择本地的目标备份文件，并单击“上传”，完成上传的备份文件会出现在备份任务列表中。

   * 当需要使用保存在远程SFTP服务器的备份包时，可采用WinSCP、FileZilla等工具登录远程SFTP服务器并将备份包下载到本地，然后上传备份包。
   * 备份包名不支持手动修改，修改后会导致文件名称校验失败。
5. 在备份任务列表中，选择用来进行恢复操作的证书独立备份任务，单击对应任务左侧的按钮，展开的页面中显示该任务的所有应用及具体服务，如图1所示。

   **图1** 选择备份任务及服务
6. 勾选证书独立备份任务及任务中需要恢复的CertMgr服务。请确认需要恢复的服务勾选完整后，单击左上方的“创建恢复任务”，并在弹出的“警告”窗口中确认弹窗描述后单击“确定”。

   * 要同时勾选备份任务及任务中的需要恢复的服务，才能成功创建恢复任务。
   * 请选择备份任务中应用的“应用版本”与当前环境版本一致的备份包进行恢复。
   * 当勾选的备份包不全时，可能会导致恢复后的备份数据不完整，请谨慎选择“确认”。
   * 在弹窗中单击“确定”后，系统将恢复到备份任务对应的备份时间的状态，该备份时间之后的数据和配置将全部丢失。
   * 当勾选的备份包是证书独立备份包时，证书数据才能够独立恢复。
   * 非三方场景下，如果系统中存在CGPLite大颗粒服务证书应用场景（当执行MML命令**LST CERSCENE**返回结果为“操作成功”且不为空时），还需要勾选“CGPBroker”服务。
7. 等待出现如图2所示的询问弹窗，单击“是”。

   **图2** 容器重建提示
8. 等待界面弹窗如图 复位确认所示。

   * 确认 => 等待系统复位后，重新登录系统后执行10。
   * 取消 => 9。

   **图3** 复位确认

   如果选择了“取消”，恢复结束后，需要在OM Portal的“应用管理 >MML”界面中网元ID为0的网元下，执行**RST MESYS**命令，先复位系统中网元ID为非0的网元，再复位网元ID为0的网元，确保恢复数据完全生效。
9. 等待界面弹窗如图4所示，单击“是”。

   **图4** 恢复结束
10. 在主菜单选择“应用管理 > 备份恢复 > 查看恢复报告”，单击“查看报告”，查看系统恢复结果。

    * 状态为“成功” => 恢复完成。
    * 状态为“失败” => 请联系华为技术支持。

    系统复位总时长约需要15分钟。具体时长与系统容量相关。
11. 对可能出现的恢复后问题进行处理。

    使用非当天的备份包执行系统恢复任务的过程中或系统恢复后，会产生“ALM-7501 系统备份失败”告警，第二天自动备份成功后该告警会自动清除。
