## 操作场景

当运营商期望根据UEG本地配置的层二规则和QoS参数为指定5G LAN业务提供专有QoS Flow时，需要参考本页面进行配置。

适用于SMF。

## 必备事项

前提条件

* 请仔细阅读GWFD-031101 支持层二QoS特性概述。
* 完成加载License（如果有需求，请联系华为技术支持工程师）。
* 完成配置APN**ADD CPAPN**。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 配置IMSI号码段。

   **ADD IMSIMSISDNSEG**
4. 配置QoS属性，“QOSTYPE”设置为“QOS\_L2\_PARA”。

   **ADD CPQOSPROP**
5. 查询指定APN实例，查询结果为huawei.com。

   **LST CPAPN**
6. 配置SMF上的本地L2Filter（层二过滤器）。

   **ADD L2FILTER**
7. 绑定L2Filter（层二过滤器）与QoS属性的关系，“QOSPROPNAME”使用**ADD CPQOSPROP**命令配置的“QOSPROPNAME”参数值。

   **ADD L2RULE**
8. 配置SMF上的本地L2RULEGROUP（层二规则组）。

   **ADD L2RULEGROUP**
9. 绑定L2RULEGROUP（层二规则组）与L2Rule（层二规则）的关系，一个L2RULEGROUP支持绑定多个L2Rule。

   **ADD L2RULEBINDGRP**
10. 绑定L2RULEGROUP（层二规则组）与指定用户群的关系，“SEGMENTNAME”使用**ADD IMSIMSISDNSEG**命令配置的“SEGMENTNAME”参数值。

    **ADD L2RULEGRPBIND**

## 任务示例

任务描述

配置SMF上的本地层二规则和QoS参数，需要进行如下配置（数据规划原则及含义请参见必备事项），才能根据层二规则触发专有QoS Flow的建立。

脚本

* 打开本特性的License配置开关。

  ```
  SET LICENSESWITCH: LICITEM="LKV2LAYER2SM01", SWITCH=ENABLE;
  ```
* 配置IMSI或MSISDN号码段。

  ```
  ADD IMSIMSISDNSEG: SEGMENTNAME="imsi1", SEGMENTTYPE=IMSI, SEGSTART="189000000000000", SEGEND="189499999999999";
  ```
* 配置QoS属性。

  ```
  ADD CPQOSPROP: QOSPROPNAME="qosprop_501_L2", EMPCAP=DISABLE, EMPVUL=ENABLE, GBRUPLKVALUE=600, GBRDNLKVALUE=6000, MBRUPLKVALUE=1000, MBRDNLKVALUE=10000, QOSTYPE=QOS_L2_PARA, ARPVALUE=5, FQI=2;
  ```
* 查询指定的APN实例，查询结果为huawei.com。

  ```
  LST CPAPN:;
  ```
* 配置SMF上的本地L2Filter（层二过滤器）。

  ```
  ADD L2FILTER: FILTERNAME="filter1", SRCMACADDR="00E0-FC12-3456", DESTMACADDR="00E0-FC12-3457", VID=1, PCP=1, DEI=ENABLE, ETHERTYPE=PROFINET;
  ```
* 绑定L2Filter（层二过滤器）与QoS属性的关系。

  ```
  ADD L2RULE: L2RULENAME="rule1", QOSPROPNAME="qosprop_501_L2", L2FILTERNAME="filter1";
  ```
* 配置SMF上的本地L2RULEGROUP（层二规则组）。

  ```
  ADD L2RULEGROUP: L2RULEGROUPNAME="rulegrp1";
  ```
* 绑定L2RULEGROUP（层二规则组）与L2Rule（层二规则）的关系。

  ```
  ADD L2RULEBINDGRP: L2RULEGROUPNAME="rulegrp1", L2RULENAME="rule1";
  ```
* 绑定L2RULEGROUP（层二规则组）与指定用户群的关系。

  ```
  ADD L2RULEGRPBIND: GRPBINDNAME="bind1", SEGMENTNAME="imsi1", APN="huawei.com", SST=1, SD="010101", L2RULEGRPNAME="rulegrp1";
  ```
