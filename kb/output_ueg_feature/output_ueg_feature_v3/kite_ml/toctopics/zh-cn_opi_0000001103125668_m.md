* 操作步骤

## 操作场景

UEG部署在园区，作为企业专用UL CL UPF+辅锚点UPF。企业园区终端签约专有DNN（APN），UPF到企业园区采用VPN专线，与MPF无关。

* UEG作为高可用边缘网关（风筝M），承载网故障（N2&N4同时传输中断）后，UEG作为主锚点UPF的业务可以接续，UEG作为UL CL UPF + 辅锚点UPF的业务无法接续。
* UEG作为高可用边缘网关（风筝M），对于需要高可用保证的业务，必须由主锚点UPF承担；对于不需要高可用保证的业务，可以由UL CL UPF + 辅锚点UPF承担。
* UEG作为高可用边缘网关（风筝M）时，推荐所有业务都由主锚点UPF承担。

UEG使用标卡与DCGW连接。DCGW之间使用E-Trunk+EVPN或M-LAG组网，UEG使用Eth-trunk接口，一个Eth-trunk接口的成员端口，连接到同一台DCGW上。

UEG通过BGP over静态路由+BFD单臂echo与对端网元（gNodeB/SMF/主锚点UPF/企业服务器）实现网络互通，如下以UEG与gNodeB之间的网络互通为例给出组网示意（如图1所示）。

## 操作步骤

1. 配置基础数据。

   配置基础数据包括：修改网元浮动IP、修改公共参数等。详细配置与组网无关，具体请参见基础数据配置。
2. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      * 如果“自动配置开关”值为“TRUE”，需要执行4.b和4.c关闭自动配置开关。
      * 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到5。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 配置UPF（UEG）到无线侧(R)AN（gNodeB）的IP路由数据。
   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Access";
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv4uni, VRFRD="192.168.225.135:100";
      ```

      ```
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv6uni, VRFRD="192.168.225.135:100";
      ```
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack5";
      ADD IPBINDVPN:IFNAME="LoopBack5",VRFNAME="VRF_Access";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack5",IFIPADDR="192.168.225.135",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```

      ```
      SET IFIPV6ENABLE: IFNAME="Loopback5", ENABLEFLAG=TRUE;
      ADD IFIPV6ADDRESS:IFNAME="Loopback5",IPV6ADDRESS="FC00::225:135",PREFIXLEN=128;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Access", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.135";
      ```
   4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```
   6. 配置BGP引入wlr路由。

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```
   7. 添加以太网隧道多虚拟网卡自动化配置模板。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
      ```
   8. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_2005_v4",VPNNAME="VRF_Access",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2005, BEGINADDR4="192.168.85.2", ENDADDR4="192.168.85.30", MASKLEN=27;
      ```

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_2005_v6",VPNNAME="VRF_Access",AFTYPE=IPv6,IPALLOCTYPE6=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2005, BEGINADDR6="FC00::85:2", ENDADDR6="FC00::85:1E", MASKLEN=123;
      ```
   9. 增加BFD会话自动部署模板。

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2005_v4", BFDTYPE=Static, SERVICENAME="ServName_Access_2005_v4", IPVERSION=IPv4, DESTADDR4="192.168.85.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2005_v6", BFDTYPE=Static, SERVICENAME="ServName_Access_2005_v6", IPVERSION=IPv6, DESTADDR6="FC00::85:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```
   10. 增加静态路由自动部署模板。

       //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="192.168.79.5", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.85.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4"; 
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="192.168.78.5", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.85.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4";
       ```

       //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

       ```
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.85.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4";
       ```

       //“PREFIX6”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="FC00::79:5", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::85:1", BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v6"; 
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v6", VRFNAME="VRF_Access", IPVERSION=IPv6, PREFIX6="FC00::78:5", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::85:1", BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v6";
       ```

       //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX6”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

       ```

       ```
