## 操作场景

该任务旨在指导操作人员通过PGW Web LMT设置M2M用户的机卡绑定功能。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* 已完成对接数据配置。
* 操作人员已完全了解WHFD-220000 M2M应用特性概述。
* 操作人员具有业务发放权限。
* 已完成开户数据配置。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 根据现网实际情况，开启EPS域或5GC域IMEI检查。

   * EPS域
     1. 执行**SET MAPSERV**命令，设置开启EPS域IMEI检查。
     2. 执行**SET MAPCONF**命令，设置用户位置更新不携带IMEI时，位置更新流程返回成功响应。
   * 5GC域

     执行**SET UDMSERV**命令，设置开启5GC域IMEI检查，并设置AMF未携带PEI时允许用户接入5GC网络。
3. 执行**MOD IMEIBIND**命令为用户签约M2M绑定业务。

## 任务示例

任务描述

为IMSI号码为“460000000000000”的用户签约M2M机卡绑定业务。

脚本

/\*设置开启EPS域IMEI检查及全局参数\*/

```
SET MAPSERV: EPC_CHECK_IMEI=Check_S6aS6d;
SET MAPCONF: UPLFAILED_NOIMEI=FALSE;
```

/\*设置开启5GC域IMEI检查及全局参数\*/

```
SET UDMSERV: NGC_CHECK_IMEI=TRUE, NGC_FAILED_NOIMEI=FALSE;
```

/\*为用户签约M2M机卡绑定业务\*/

```
MOD IMEIBIND: IMSI="460000000000000", OPTIONTYPE=PROVIDE, IMEI="12345678901234", DELAYCANCEL=FALSE;
```
