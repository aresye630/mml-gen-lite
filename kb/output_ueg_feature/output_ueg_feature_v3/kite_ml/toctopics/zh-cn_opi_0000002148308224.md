## 操作场景

该任务旨在指导操作人员在5G网络中配置5G eDRX模式功能。

## 必备事项

前提条件

* 请仔细阅读实现原理。
* 操作人员具有PGW Web LMT的操作权限。

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD SERAREATPL**命令增加5G业务区域信息模板。
3. 执行**ADD FORBIDAREATPL**命令增加5G禁止区域模板。
4. 执行**ADD DNNQOSTPL**命令增加5GS DNN QoS模板。
5. 执行**MOD AMDATA**命令签约AMF数据。
6. 执行**ADD SNSSAI**命令签约切片管理数据。
7. 执行**ADD SMDATA**命令签约SMF数据。

## 任务示例

任务描述

在5G网络中配置支持5G eDRX模式功能所需的相关数据。

脚本

/\*登录“UDM业务管理”窗口\*/

/\*增加5G业务区域信息模板\*/

```
ADD SERAREATPL: HLRSN=1, TPLID=199, SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"4445\"]}]\,\"maxNumOfTAs\":6}";
```

/\*增加5G禁止区域模板\*/

```
ADD FORBIDAREATPL: HLRSN=1, TPLID=199, FORBIDDENAREAS="[{\"areaCode\":\"4305\"}\,{\"tacs\":[\"63F84B\"]}]";
```

/\*增加5GS DNN QoS模板\*/

```
ADD DNNQOSTPL: HLRSN=1, TPLID=199, PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV4V6&IPV6&UNSTR&ETHER, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2&SSC_MODE_3, IWKEPSIND=TRUE, LADN=TRUE, LBO=TRUE, NGCQOSTPLID=199, AMBRUP=1, UPUNIT=bps, AMBRDW=2, DWUNIT=bps, CHARGE="2134", UPINTEGR=PREFERRED, UPCONFID=REQUIRED;
```

/\*签约AMF数据\*/

```
MOD AMDATA: IMSI="460000009123456", PROV=TRUE, AMBRUP=11111111, UPUNIT=bps, AMBRDW=111111111, DWUNIT=bps, RATRESTRICT=WLAN&VIRTUAL, RFSPINDEX=255, SUBSREGTIMER=11111, MPS=TRUE, ACTIVETIME=11111,DLBUFFERIND=REQUESTED, DLBUFFER=1, AUTHTYPE=5G-AKA, NREDRXVALUE=4, NRREDCAPEDRXVALUE=4, NRN1EXPTWVALUENRN1EXPTWVALUE=3;
```

/\*签约切片管理数据\*/

```
ADD SNSSAI: IMSI="460000009123456", SNSSAI="1-111111", DEFAULT=TRUE;
```

/\*签约SMF数据\*/

```
ADD SMDATA: IMSI="460000009123456", SNSSAI="1-111111", DNN="test", DNNQOSTPLID=199, DEFAULT=TRUE, IPV4ADDR="192.168.31.43", IPV6ADDR="2001:db8::10", SUGGESTEDPACKETNUMDL=10;
```
