## 操作场景

本操作指导介绍在运行网络中激活区域漫游限制特性的操作过程。

## 必备事项

前提条件

* 请仔细阅读GWFD-020911 区域漫游限制特性概述（适用于AMF/UDM）。

## 操作步骤

**根据用户接入和移动签约数据中的“禁止区域（Forbidden Area）”信息控制用户的接入。**

1. 进入“MML命令行-UEG”窗口。
2. 配置某个区域信息，以及AreaCode与TAI之间的映射关系。
   + 配置区域编码

     **ADD AREACODE**
   + 为指定的区域增加跟踪区成员

     **ADD AREAMEM**

**AMF针对指定的区域在本地配置用户接入的策略，然后基于策略控制用户的接入。**

1. 进入“MML命令行-UEG”窗口。
2. 开启本特性的功能控制开关。

   **SET LICENSESWITCH**
3. 开启区域漫游限制功能增强开关，将“AREARSTENSW”设置为“ON”。

   **SET NGMMFUNC**
4. 需要限制用户在禁止区域内进行Xn切换以及周期性注册流程时，设置DWORD11中BIT2的取值为“1”。如果用户在禁止区域内发起Xn切换或者周期性注册，AMF会拒绝该流程。

   **SET AMFSOFTPARAOFBIT**
5. 配置某个区域信息，以及AreaCode与TAI之间的映射关系。
   + 配置区域编码

     **ADD AREACODE**
   + 为指定的区域增加跟踪区成员

     **ADD AREAMEM**
6. 配置某个用户群组信息。
   + 配置5G用户群标识

     **ADD NGUSRGRP**
   + 配置用户群成员

     **ADD NGUSRGRPMEM**
7. （可选）配置区域漫游限制增强功能，当开关打开时周期性注册更新、服务请求、切换流程中AMF根据本地配置做区域接入限制检查。

   **SET NGMMFUNC**
8. 配置拒绝的原因值（由用户签约的“禁止区域（ForbiddenArea）”控制用户的接入）。

   **SET NGMMPROCTRL**
9. AMF本地配置限制区域信息、用户信息、控制模式以及拒绝原因值（由AMF本地配置的接入限制区域控制用户的接入）。

   **ADD NGACCAREALST**

   + 限制区域之间不允许存在交叉和重叠，“所有区域”例外。
   + 当同时存在“指定区域”和“所有区域”时，以“指定区域”的策略为准，除非UE当前不在“指定区域”。
   + 对于同一个用户，可能匹配“指定区域”内的多个用户号段，该场景下，AMF按照最长匹配的方式优选。

## 任务示例

任务描述

启用区域漫游限制功能，运营商在“MyTown”区域（跟踪区编码为010101-010102）部署了企业网络，只允许企业员工接入，企业员工从属的用户组ID为888，IMSI前缀为123456，由AMF本地配置的接入限制区域控制用户的接入，拒绝原因值为#15 （No suitable cells in tracking area）。由用户签约的“禁止区域（ForbiddenArea）”控制用户的接入，拒绝原因值为#15 （No suitable cells in tracking area）。

脚本

//开启区域漫游限制功能开关。

```
SET LICENSESWITCH: LICITEM="LKV2RRR02", SWITCH=ENABLE;
```

//开启区域漫游限制功能增强开关。

```
SET NGMMFUNC: AREARSTENSW=ON;
```

//限制用户在禁止区域内进行Xn切换以及周期性注册流程。如果用户在禁止区域内发起Xn切换或者周期性注册，AMF会拒绝该流程。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=11, VALUE=VALUE_1, POSITION=2;
```

//配置区域范围。

```
ADD AREACODE：AREACODE="MyTown";
ADD AREAMEM：AREACODE="MyTown",MCC="123", MNC="456", BGNTAC="010101", ENDTAC="010102";
```

//配置用户群组。

```
ADD NGUSRGRP：USRGRPID=888;
ADD NGUSRGRPMEM: USRGRPID=888, IMSIPRE="123456";
```

//由于签约的禁止区域受限拒绝的原因值

```
SET NGMMPROCTRL: PROT=OTHER_PROC, AREARST=0;
```

//AMF本地配置限制区域信息、控制模式以及拒绝原因值。

```
ADD NGACCAREALST: AREARANGE=AREA_CODE, AREACODE="MyTown",  CTRLMODE=WHITELIST, SUBRANGE=USER_GROUP, SUBGRPID=888, DESC="for employees";
```
