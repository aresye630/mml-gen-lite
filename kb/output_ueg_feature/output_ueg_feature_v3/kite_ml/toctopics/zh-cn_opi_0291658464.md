## 操作场景

以一个典型的N7接口PDU上线、SMF发起的会话更新及会话删除为例，详细介绍PCF侧的业务配置。操作场景为，当5G网络中用户配额状态正常时，可享受正常高速带宽，当配额耗尽时，运营商可调整用户的访问带宽。

以典型的上网流量包月业务为例：

* 配额为1000MB。
* 每月1号01:00:00进行配额复位，剩余配额采用清零方式。
* 带宽控制：
  + 当配额消耗小于100%时，上行带宽为10 Mbit/s，下行带宽为10 Mbit/s。
  + 当配额消耗大于等于100%时，上行带宽降为1 Mbit/s，下行带宽降为1 Mbit/s。
* UPCF进行配额累积。
* 不配置消息通知。

## 对系统的影响

大量在线用户的配额在同一时间点复位时会消耗系统资源，使得系统CPU负荷上升，用户的配额复位时间请尽量设置在非业务高峰期。

      ```
      ADD PSUB: USRIDENTIFIER="46010381012****", USRMSISDN="1234567****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB;
      ```
   2. 执行**ADD PSRV**给用户签约业务。

      ```
      ADD PSRV: USRIDENTIFIER="46010381012****", SRVNAME="Service_FUP_N7", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
      ```
