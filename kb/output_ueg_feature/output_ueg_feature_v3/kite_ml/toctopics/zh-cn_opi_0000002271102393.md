## 操作场景

当运营商规划需要为指定业务提供专有承载/专有QoS Flow时，需要参考本页面进行配置。

适用于PGW-C、SMF

## 必备事项

前提条件

* 请仔细阅读GWFD-022307 业务触发的QoS保证。
* 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置QoS URR。

   **ADD CPURR**
3. 配置QoS属性。

   **ADD CPQOSPROP**
4. 规则通过PCC策略组绑定QoS属性时，配置PCC策略组。规则直接绑定QoS属性时，请跳过本步骤。

   **ADD CPPCCPOLICYGRP**
5. 配置SMF上的本地rule。

   **ADD CPRULE**

   * 规则通过PCC策略组绑定QoS属性时，“POLICYTYPE”设置为“PCC”，“POLICYNAME”使用**ADD CPPCCPOLICYGRP**命令配置的“PCCPOLICYGRPNM”参数值。
   * 规则直接绑定QoS属性时，“POLICYTYPE”设置为“QOS”“POLICYNAME”使用**ADD CPQOSPROP**命令配置的“QOSPROPNAME”参数值。
   * PCC类型的“RULENAME”值与QOS类型的“RULENAME”值不能相同。
6. （无可用PCRF/PCF或预定义规则组时使用）配置SMF上的UserProfile，将本地rule绑定到UserProfile上。用于动态PCC时PCF下发预定义规则组，或本地PCC时的静态规则组。
   1. 配置UserProfile。

      **ADD CPUSERPROFILE**
   2. 将rule绑定到UserProfile。

      **ADD CPRULEBINDING**
7. **可选：**（无可用PCRF/PCF时使用）配置UserProfile组，将UserProfile绑定到UserProfile组，再将UserProfile组绑定到DNN实例上。用于本地PCC的静态规则。如UserProfile已配置，请跳过本步骤。
   1. 配置UserProfile Group。

      **ADD USRPROFGROUP**
   2. 将UserProfile绑定到UserProfile Group。

      **ADD UPBINDUPG**
   3. 将UserProfile Group绑定到DNN。

      **ADD APNUSRPROFG**

## 任务示例

任务描述

SMF支持业务触发的QoS保证。指定业务的业务特征在PGW-U/UPF上配置，UEG上需要进行如下配置（数据规划原则及含义请参见**必备事项**），才能将相应的预定义规则的Rule下发给PGW-U/UPF，并根据PGW-U/UPF上报的PFCP Session Request Report（QoS）触发专有QoS Flow/专有承载创建。QoS Flow/专有承载创建后，PGW-U/UPF通过业务识别，将指定的业务使用专有QoS Flow/专有承载传输，从而进行QoS保证。

网络中存在PCRF/PCF时，UPF、SMF、PCRF/PCF上配置的预定义规则名称必须一致，否则不能达到预期效果。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3W9STQE11",SWITCH=ENABLE;
```

//配置QoS URR。

```
ADD CPURR: URRNAME="urr_1", URRID=1001, USAGERPTMODE=QOS;
```

//配置业务特定的QoS信息。

```
ADD CPQOSPROP: QOSPROPNAME="qos-property1", GBRUPLKVALUE=110, GBRDNLKVALUE=110, MBRUPLKVALUE=220, MBRDNLKVALUE=220, QOSTYPE=QOS_FLOW_PARA, ARPVALUE=5, FQI=2, QOSURRNAME="urr_1";
```

//（方式一，通过PCC规则实现）配置QoS属性、PCC策略组和规则的绑定关系。

```
ADD CPPCCPOLICYGRP:PCCPOLICYGRPNM="ppg1",QOSPROPNAME="qos-property1";
ADD CPRULE:RULENAME="rule_test",POLICYTYPE=PCC,POLICYNAME="ppg1";
```

//（方式二，通过QoS规则实现）配置QoS属性与规则的绑定关系。

```
ADD CPRULE:RULENAME="rule_test",POLICYTYPE=QOS,POLICYNAME="qos-property1";
```

//（无可用PCRF/PCF或预定义规则组时使用）配置UserProfile并绑定Rule。

```
ADD CPUSERPROFILE:USERPROFILENAME="up_test",UPTYPE=PCC;
ADD CPRULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test",POLICYTYPE=QOS;
```

//（无可用的PCRF/PCF时使用）配置UserProfile组并和APN绑定。

```
ADD USRPROFGROUP:USERPROFGNAME="upg_test";
ADD UPBINDUPG:USERPROFGNAME="upg_test",UPBINDTYPE=DEFAULT,USERPROFILENAME="up_test";
ADD APNUSRPROFG:APN="huawei.com",USERPROFGNAME="upg_test";
```
