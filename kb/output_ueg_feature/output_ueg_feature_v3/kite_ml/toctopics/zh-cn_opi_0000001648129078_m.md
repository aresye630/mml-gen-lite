## 操作场景

应急UDM不支持开户，其用户数据是以加密文件的方式从中心UDM同步的。因此，应急UDM必须配置用户数据文件同步，否则新开机、移动切换及周期性注册刷新的用户业务失败。

配置后，应急UDM支持定时自动从SFTP服务器同步用户数据文件。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 增加VPN信息配置。

   ```
   ADD VPNINFO: VPNINFONAME="vpndsm", VPNNAME="VRF_DSM", VPNID=2;
   ```
3. 配置用于访问SFTP服务器的本端IP。

   ```
   ADD EDGEUDMIP: IPNAME="edgeudmip01", IPTYPE=DSM, IPVERSION=IPV4, IPV4ADDRESS="10.100.20.20", IPV4MTU=1500, VPNINSTANCE="VRF_DSM";
   ```
4. 增加远端用户数据同步服务器。

   此处配置的是SFTP服务器认证SFTP客户端（园区UDM）使用的认证方式。

   * 密码认证

     ```
     ADD RDATASYNSERVER: SERVERNAME="Rserver_01", GROUPID=1, PRIORITY=1, PROTOCOL=SFTP, IPVERSION=IPV4, SERVERIPV4="10.110.20.20", SERVERPORT=22, USERNAME="localudm", AUTHTYPE=PASSWORD, PWD="sftp123#", PWDCFM="sftp123#", RWORKDIR="D:\sftpserver", DETECTSWITCH=ENABLE;
     ```
   * 公钥认证（推荐）

     ```
     ADD RDATASYNSERVER: SERVERNAME="Rserver_01", GROUPID=1, PRIORITY=1, PROTOCOL=SFTP, IPVERSION=IPV4, SERVERIPV4="10.110.20.20", SERVERPORT=22, USERNAME="localudm", AUTHTYPE=PUBLICKEY, RWORKDIR="D:\sftpserver", DETECTSWITCH=ENABLE;
     ```
5. 4中“AUTHTYPE”设置为“PUBLICKEY”时，加载远端用户数据同步用户认证的密钥文件。“AUTHTYPE”设置为“PASSWORD”时，请跳过本步骤。
   1. 获取并上传用户公私钥文件。

      * 密钥文件为OPENSSH格式或PEM格式。私钥文件须使用加密格式。
      * 需要将公私钥文件上传到“数据同步客户端用户密钥”文件夹中。上传的详细操作请参见文件传输。
   2. 加载远端用户数据同步用户认证的密钥文件。

      ```
      LOD RDATASYNUSERKEY: SERVERNAME="Rserver_01", USERNAME="localudm", KEYNAME="key1", PUBKEYFILE="rsa_key.pub", PRIVATEKEYFILE="rsa_key", PRIVATEKEYPWD="*****";
      ```
   3. 检查密钥加载状态。

      ```
      LST RDATASYNUSERKEY: SERVERNAME="Rserver_01", USERNAME="localudm", KEYNAME="key1";
      ```

      ```
      RETCODE = 0  操作成功
       
      结果如下
      -------------------------
                  服务器名称 = Rserver_01
                    用户名称 = localudm
                    密钥名称 = key1
                  公钥文件名 = rsa_key.pub
                  私钥文件名 = rsa_key
                    密钥状态 = 正常
      (结果个数 = 1) 
      ---   END
      ```

      “密钥状态”为“正常”时，说明密钥文件加载成功。否则，请联系华为技术支持工程师处理。

   园区UDM认证SFTP服务器时，推荐配置为认证SFTP服务器的公钥。

   * 认证SFTP服务器的公钥时，执行6。
   * 不认证SFTP服务器的公钥时，执行7。
6. 配置认证SFTP服务器的公钥。
   1. 使能认证SFTP服务器的公钥。

      ```
      SET RSFTPFIRSTTIME: FIRSTTIMEENABLE=DISABLE;
      ```
   2. 增加SFTP服务器的公钥。

      ```
      ADD RSFTPPUBLICKEY: KEYNAME="rsa1", PUBKEYTYPE=RSA, KEYCODE="MIICIqhkiG9wEAAQ==";
      ```
   3. 配置SFTP服务器公钥与SFTP服务器的绑定关系。

      ```
      ADD RSFTPBINDPUBLICKEY: SERVERNAME ="Rserver_01", KEYNAME="rsa1";
      ```
7. 配置不认证SFTP服务器的公钥。

   ```
   SET RSFTPFIRSTTIME: FIRSTTIMEENABLE=ENABLE;
   ```
8. 设置用户数据文件同步策略。

   ```
   SET EDGEDSPOLICY: CYCLE=1D, STARTTIME=00:00, ENDTIME=01:00, RETRYINTVL=5, ALMTHESTIMES=3, FILTERPREFIX="Campus1", FILTERSUFFIX="tar.gz", PREFIXSEPARATOR="_", PREFIXFORMAT=Common, FILEEXPIRE=3;
   ```
9. 设置解密用户数据文件所需的数据。

   用户数据文件包含用户签约信息，中心UDM对园区用户数据文件先加密再压缩，因此，园区应急UDM（风筝M）需要支持解密用户数据文件。

   //中心UDM加密用户数据文件时，涉及“KEYGENALGO”、“ITERATION”、“MD”或“ENCODEMODE”参数。

   ```
   SET EDGEDECRYPT: DECRYALGO=AES256-CBC, PASSWORD="edgedecrypt123#", PWDCFM="edgedecrypt123#", OPTIONALPARA=ENABLE, KEYGENALGO=Default, ITERATION=0, MD=sha256, ENCODEMODE=Base64;
   ```

   //中心UDM加密用户数据文件时，不涉及“KEYGENALGO”、“ITERATION”、“MD”和“ENCODEMODE”参数。

   ```
   SET EDGEDECRYPT: DECRYALGO=AES256-CBC, PASSWORD="edgedecrypt123#", PWDCFM="edgedecrypt123#", OPTIONALPARA=DISABLE;
   ```

## 验证方法

1. 执行**NGPING**命令，查看平面“VRF\_DSM”配置的业务IP是否与SFTP服务器IP互通。

   ```
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DSM", SRCIPV4ADDR="ADD EDGEUDMIP所定义的业务IP", DSTIPV4ADDR="SFTP服务器IP";
   样例：
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DSM", SRCIPV4ADDR="10.100.20.20", DSTIPV4ADDR="10.110.20.20";
   ```

   * 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，请执行2。
   * 如果连续出现timeout，表明链路不通，联系华为技术支持工程师。
2. 执行**DSP ROUTE**/**DSP ROUTE6**命令，查看平面“VRF\_DSM”到SFTP服务器的路由是否正常。

   //IPv4:

   ```
   DSP ROUTE: VPNNAME="VRF_DSM";
   ```

   //IPv6:

   ```
   DSP ROUTE6: VPNNAME="VRF_DSM";
   ```

   * 正常，请执行4。
   * 不正常，请执行3。
3. 请检查本端或承载网是否存在物理接口故障或者路由配置错误。
   * 是，请处理该问题后重新执行2。

     如问题仍存在，请联系华为技术支持。
   * 否，请执行4。
4. 执行**DSP EDGEDSSTATUS**命令，查看用户数据文件同步是否符合预期。
   * 开户/修改/销户等用户数与预期一致，请执行6。
   * 开户/修改/销户等用户数与预期不一致，请5。
5. 查是否存在告警ALM-100426 远端服务器数据同步失败或ALM-100427 园区业务服务异常。
   * 是，请先按照告警处理后，重新调测本功能。
   * 否，请执行7。
6. 执行**LST SUB**命令，查询指定用户数据同步是否符合预期。
   * 是，调测结束。
   * 否，请执行7。
7. 收集信息并寻求技术支持。
   1. 在“MML命令行-UEG”窗口上执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。

相关任务

外置同步服务器（SFTP Server）从中心UDM获取用户数据，园区UDM从外置同步服务器（SFTP Server）同步用户数据的场景，对外置SFTP Server和中心UDM的相关要求如表1所示。

**表1** 对外置SFTP Server和中心UDM的要求（外置SFTP Server场景）

| 场景 | 外置SFTP Server | 中心UDM |
| --- | --- | --- |
| 新建场景 | * 外置SFTP Server目录要求：手动创建一级目录和二级目录。 * 一级目录用于区分不用的园区。有N个园区时，需要有N个一级目录。 * 二级目录用于分别存放各个中心UDM导出的数据文件。某个园区在M对中心UDM开户时，需要创建M个二级目录。 * 外置主备SFTP Server上同一园区的二级目录要求一致。 | * 中心主UDM仅对接主外置同步服务器（SFTP Server），中心备UDM仅对接备外置同步服务器（SFTP Server）。 * 中心UDM需将导出的用户数据文件，存放到外置SFTP Server的对应二级目录下。 * 中心UDM上某个园区业务下线时，需要手动删除外置同步服务器（SFTP Server）上对应园区的二级目录。否则，园区UDM按照最后一次同步的签约数据提供业务，不会删除用户签约数据。 |
| 扩容/改造（某一园区用户由在单对UDM开户-->在多对UDM开户） | 参考新建场景要求，创建一级目录和二级目录。 | 中心UDM需将导出的用户数据文件，存放到对应的二级目录下。  所有给园区用户开户的中心UDM均涉及。 |
| 扩容/改造（某一园区用户由在两对UDM开户-->在多对UDM开户） | 在对应的一级目录下，新建二级目录。每新增一对中心UDM，需要在主备外置SFTP Server的园区目录（一级目录）下分别创建一个二级目录。 | 中心UDM需将导出的用户数据文件，存放到对应的二级目录下。  仅新增的给园区用户开户的中心UDM涉及。 |
| 园区签约用户在中心UDM上迁移，如从一个UDM到另外一个UDM（某一园区用户由在单对UDM开户-->在多对UDM开户） | 参考新建场景要求，创建一级目录和二级目录。 | 中心UDM需将导出的用户数据文件，存放到对应的二级目录下。  所有给园区用户开户的中心UDM均涉及。 |
| 园区签约用户在中心UDM上迁移，如从一个UDM到另外一个UDM（某一园区用户由在两对UDM开户-->在多对UDM开户） | 在对应的一级目录下，新建二级目录。每新增一对中心UDM，需要在主备外置SFTP Server的园区目录（一级目录）下分别创建一个二级目录。 | 中心UDM需将导出的用户数据文件，存放到对应的二级目录下。  仅新增的给园区用户开户的中心UDM涉及。 |
| 园区签约用户在中心UDM上迁移，如从一个UDM到另外一个UDM（未新增中心UDM） | 不涉及。 | 不涉及。 |
