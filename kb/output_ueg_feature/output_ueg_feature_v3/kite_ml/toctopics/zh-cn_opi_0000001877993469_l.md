## 操作场景

本操作指导用于指导开启AMF重定向特性。

本特性是指在大网和园区共享基站场景下，大网AMF可以将园区用户通过基站重定向给园区UEG L的AMF、园区UEG L的AMF可以将大网用户通过基站重定向给大网AMF以及园区之间共享基站场景下，园区和大网失联时UEG L、UEG M上的AMF可以将用户通过基站重定向到对应的UEG L、UEG M上的AMF处理业务。

## 对系统的影响

该操作对系统正常运行没有影响。

## 必备事项

前提条件

* 请仔细阅读GWFD-020914 基站重定向特性概述。
* 完成加载License。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 设置AMF区域重选功能控制参数。

   **SET NGAREARESELCTRL**
4. 基于运营商规划的区域进行AMF重选功能的差异化控制。

   **ADD RESELAREACODE**

   **ADD RESELAREAMEM**
5. 增加AMF区域重选功能控制策略。

   **ADD NGAREARESELPLCY**

## 任务示例

任务描述

以配置TAC+指定用户为例，用户群组标识已通过**ADD NGUSRGRP**进行添加，群组内的用户标识列表已通过**ADD NGUSRGRPMEM**进行添加。在大网设备上配置，匹配该命令的用户需要重定向到目标AMF SET，其他用户允许接入本设备。

脚本

```
//打开本特性的License配置开关。
```

```
SET LICENSESWITCH: LICITEM="LKV2AREARERT", SWITCH=ENABLE;
```

```
//设置AMF区域重选功能控制参数。
```

```
SET NGAREARESELCTRL: AREARERT=ON, MULTIRERT=OFF, RERTVOICEPRE=ON;
```

```
//基于运营商规划的区域进行AMF重选功能的差异化控制。
```

```
ADD RESELAREACODE: RESELAREACODE="ReSelZone", DESC="for zone1";
ADD RESELAREAMEM: RESELAREACODE="ReSelZone", MCC="123", MNC="45", BGNTAC="120101";
```

```
//增加AMF区域重选功能控制策略。
```

```
ADD NGAREARESELPLCY: AREARANGE=AREA_CODE, RESELAREACODE="ReSelZone", CTRLOBJECT=USER_GROUP, SUBGRPID=1, CTRLMODE=RE_ROUTE, TGTAMFSET="111";
```
