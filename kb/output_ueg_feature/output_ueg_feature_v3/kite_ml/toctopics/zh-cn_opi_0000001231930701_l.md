## 操作场景

在系统负荷较重的情况下，建议开启流控策略。通过控制系统接入业务量来保证系统过载情况下业务的正常进行，避免造成整系统瘫痪。

## 对系统的影响

UEG启动流控保护，首要目的是确保UEG和周边网元的安全运行，其次才是业务的尽量接入。因此超出系统处理能力时，流控机制启动，会丢弃部分消息，导致部分用户激活失败。

## 必备事项

前提条件

请仔细阅读GWFD-021401 系统过载控制。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET APNACCESSWAL** | APN名称（APN） | apn1 | 本端规划 | APN下用户的接入速率 |
|  | 用户的接入速率（WALNUMBER） | 30 | 本端规划 |  |
| **SET DEACTIVERATE** | 去活速率（RATE） | 25 | 本端规划 | 去激活流控速率 |
| **SET UPSOFTPARA** | 软参记录数据类型（DT） | DWORD | 本端规划 | 每秒发送的最大Error Indication消息数 |
|  | DWord索引（DWORDNUM） | 47 | 本端规划 |  |
|  | Dword值（DWORDVALUE） | 35 | 本端规划 |  |

## 操作步骤

1. 配置APN实例。

   **ADD UPAPN**
2. 配置APN下用户的接入速率。

   **SET APNACCESSWAL**
3. 配置用户去激活流控速率。

   **SET DEACTIVERATE**
4. 配置每个VMPod每秒发送的最大Error Indication消息数。

   **SET UPSOFTPARA**

## 任务示例

任务描述

配置系统过载控制功能。

脚本

//配置APN实例。

```
ADD UPAPN:UPAPN="apn1";
```

//配置APN下用户的接入速率。

```
SET APNACCESSWAL:APN="apn1",WALNUMBER=30;
```

//配置用户去激活流控速率。

```
SET DEACTIVERATE:RATE=25;
```

//配置每个VMPod每秒发送的最大Error Indication消息数。

```
SET UPSOFTPARA: DT=DWORD, DWORDNUM=47, DWORDVALUE=35;
```
