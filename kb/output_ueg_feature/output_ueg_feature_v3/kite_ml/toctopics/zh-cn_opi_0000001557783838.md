## 操作场景

为降低网络安全风险，建议开启SBI接口加密特性。

适用于AMF、SMF、NRF、NSSF、SMSF。

## 必备事项

前提条件

* 请仔细阅读GWFD-021507 SBI接口加密特性概述。
* 已规划全网预共享密钥ID和预共享密钥值。

## 操作步骤

1. 配置AMF、SMF的TLS参数和相关服务化接口参数。各个NF的配置方法相同，此处以配置AMF为例。
   1. 进入“MML命令行-UEG”窗口。
   2. 增加AMF的PSK组信息。

      **ADD TLSPSKGRP**
   3. 增加AMF作为服务端的PSK参数。其中，“模式”配置为“SERVER”，"**PSK组索引**"与1.b中的"**PSK组索引**"一致。"**预共享密钥ID**"和"**预共享密钥值**"全网规划。

      **ADD TLSPSK**
   4. 增加AMF作为客户端的PSK参数。其中，“模式”配置为“CLIENT”，"**PSK组索引**"与1.b中的"**PSK组索引**"一致。"**预共享密钥ID**"和"**预共享密钥值**"全网规划。**ADD TLSPSK**
   5. 增加AMF作为服务端的TLS参数。其中，“模式”配置为“SERVER”，"**身份验证方式**"配置为"PSK"，"**PSK组索引**"与1.b中的"**PSK组索引**"一致。"**加密套件集合**"勾选TLS1.2的PSK相关加密套件或TLS1.3的加密套件。

      **ADD TLSPARA**
   6. 增加AMF作为客户端的TLS参数。其中，“模式”配置为“CLIENT”，"**身份验证方式**"配置为"PSK"，"**PSK组索引**"与1.b中的"**PSK组索引**"一致。"**加密套件集合**"勾选TLS1.2的PSK相关加密套件或TLS1.3的加密套件。

      **ADD TLSPARA**
   7. 增加AMF HTTP本端地址组信息。

      **ADD HTTPLEGRP**
   8. 增加逻辑IP地址。"**IPv4地址"**、"**IPv6地址**"以及**"VPN实例名称"**全网规划。

      ****ADD LOGICIP****
   9. 增加AMF作为服务端的HTTP本端实体。其中，“本端实体类型”配置为“SERVER”，“TLS索引”需要与1.e中配置的“索引”相同。"**IPv4地址"**、"**IPv6地址**"以及**"VPN名称"**分别与1.h。中保持一致。

      **ADD HTTPLE**
   10. 增加AMF作为客户端的HTTP本端实体。其中，“本端实体类型”配置为“CLIENT”，“TLS索引”需要与1.f中配置的“索引”相同。"**IPv4地址"**、"**IPv6地址**"以及**"VPN名称"**分别与1.h。中保持一致。

       **ADD HTTPLE**
   11. 增加AMF服务化接口的接入点信息。

       **ADD SBIAPLE**

## 任务示例

任务描述

以AMF侧的配置为例。

脚本

* AMF侧配置

//增加AMF的PSK组信息。

```
ADD TLSPSKGRP:PSKGRPIDX=1, DESC="pskgrp_desc";
```

//增加AMF作为服务端的PSK参数。

```
ADD TLSPSK: PSKIDX=1, PSKGRPIDX=1, MODE=Server, PSKID="psk_01", PSKTYPE=HEXADECIMAL, PSKVALUE="485750534b56414c554554455354", DESC="pskgrp_desc";
```

//增加AMF作为客户端的PSK参数。

```
ADD TLSPSK: PSKIDX=2, PSKGRPIDX=1, MODE=Client, PSKID="psk_01", PSKTYPE=HEXADECIMAL, PSKVALUE="485750534b56414c554554455354", DESC="pskgrp_desc";
```

//增加AMF作为服务端的TLS参数。

```

//增加AMF HTTP本端地址组信息。

```
ADD HTTPLEGRP: INDEX=1, DESC="AMF";
```

//增加逻辑IP地址。

```
ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.16.1.5", VPNINSTNAME="_public_", DESC="test";

```

//增加AMF作为服务端的HTTP本端实体。

```

//增加AMF作为客户端的HTTP本端实体。

```
ADD HTTPLE: INDEX=2, HTTPLEGRPIDX=1, LETYPE=CLIENT, TLSIDX=2, IPTYPE=IPv4, IPV4="10.16.1.6",VPNNAME="_public_";
```

//增加AMF服务化接口的接入点信息。

```
ADD SBIAPLE: INDEX=1, HTTPLEGRPIDX=1, NFTYPE=NFTypeAMF, DESCRIPTION="AMF";
```
