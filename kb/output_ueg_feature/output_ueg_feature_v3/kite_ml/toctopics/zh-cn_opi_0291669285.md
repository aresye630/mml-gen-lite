## 操作场景

专有QoS Flow用于为特定业务提供特定的QoS（Quality of Service）。当5G网络中需要为特定业务提供端到端的可靠的质量保证时，部署此特性可以为用户的特定业务提供QoS保证。例如：当用户访问某个特性IP时，比如第三方视频网站，能优先保障访问该网站的服务质量，当访问其他网站仅做网页浏览时不需要提供高服务质量保证也能顺利浏览，此场景设置如下：

* 带宽控制：
  + 访问第三方视频网站（假设IP地址为：172.28.82.102）时，建立专有QoS Flow，高带宽保障服务质量，上行10 Mbit/s，下行10 Mbit/s；
  + 访问非第三方视频网站时，使用默认QoS Flow，普通带宽，上行1 Mbit/s，下行1 Mbit/s；
* 配置动态规则

## 对系统的影响

本特性对系统无影响。

## 必备事项

前提条件

操作员已了解GWFD-025909 专有QoS流特性概述，且通过4G/5G业务配置差异介绍已经了解5G规则配置原理。

数据

5G的专有QoS Flow业务配置逻辑与4G类似，专有QoS Flow与默认QoS Flow的最大区别就在于5QI、ARP的取值，如果同一个业务配置中，专有QoS Flow与默认QoS Flow的5QI、ARP对应相等，那么就不会建专有QoS Flow，如果但凡其中有一个参数没有一一相等，就会建立专有QoS Flow。5G专有QoS Flow的配置逻辑如图1所示。

| 策略P\_DedicatedQoS | 此策略在用户上线时被调用，触发器为IPCAN\_EST，包含规则：Default\_SessionRule1、Default\_DynamicRule2、Dedicated\_DynamicRule3 | 三个规则中，Default\_SessionRule1、Default\_DynamicRule2用来建立默认QoS Flow，Dedicated\_DynamicRule3用来建立专有QoS Flow。 |

| 规则Default\_DynamicRule2 | * 条件：userStatus=Normal。 * 动作：    + QoSData：5QI为8，ARP为1。   + Flowinformation：全选“any”。 | 若对端是华为UNC，建立缺省QoS Flow的同时必须下发规则，否则QoS Flow无法建立成功。 |
| 规则Dedicated\_DynamicRule3 | * 条件：无。 * 动作：    + QoSData：5QI为5，ARP为1。   + Flowinformation：SourceIP=172.28.82.102，其余均为“any”。 | 该规则用于建立专有QoS Flow。 |

## 操作步骤

1. 登录UPCF Web UI界面。
2. 配置条件组。

   导航入口为“策略管理 > 策略 > 条件组”。

   * 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
   * 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与/或关系由参数“关系”的取值决定。

   此场景仅配置1个条件组。条件组的数据规划如表2所示，详细参数说明请参见条件组参数表。

   **表2** 条件组

   | 类别 | 参数 |  | 取值样例 |

   |  |  | 关系 | AND |
   |  | 条件 | 名称 | CG\_DedicatedQoS |
   |  |  | 对象属性 | * 对象：Subscriber * 属性：Status |
   |  |  | 操作符 | Equal |
   |  |  | 右值类型 | Value |
   |  |  | 右值 | Normal |
3. 配置动作组。

   导航入口为“策略管理 > 策略 > 动作组”。

   此场景需配置动作：Arp、Ambr、DefaultQosInformation、SessionRuleAction、FlowDescription、FlowInformation、QoSData、DynamicPccRule，相关应用场景如下：

   * FlowInformation：当需要下发流信息时需配置此动作。
   * QoSData：需要进行带宽控制时，配置此动作。

   请增加如下动作组和动作：

   * 动作组AG1\_Default\_Session：动作Arp、Ambr、DefaultQosInformation、SessionRuleAction
   * 动作组AG2\_Default\_Dynamic：动作Arp、FlowDescription、FlowInformation、QoSData、DynamicPccRule
