## 操作场景

保护带宽资源不被P2P/VoIP流量吞噬，确保应用公平分享带宽资源。

适用于PGW-C、SMF

## 必备事项

前提条件

* 完成激活PCC基本功能。
* 完成加载License。

## 操作步骤

1. 配置SMF上的本地rule。用于动态PCC时PCF下发预定义规则，或本地PCC时的静态规则。

   **ADD CPRULE**

   规则用于带宽控制时，“策略类型（POLICYTYPE）”设置为“BWM”。
2. 配置SMF上的UserProfile，将本地rule绑定到UserProfile上。用于动态PCC时PCF下发预定义规则组，或本地PCC时的静态规则组。
   1. 配置UserProfile。如已配置，请跳过本步骤。

      **ADD CPUSERPROFILE**
   2. 将rule绑定到UserProfile。

      **ADD CPRULEBINDING**
3. 配置UserProfile组，将UserProfile绑定到UserProfile组，再将UserProfile组绑定到DNN实例上。用于动态PCC或本地PCC。
   1. 配置UserProfile Group。如已配置，请跳过本步骤。

      **ADD USRPROFGROUP**
   2. 将UserProfile绑定到UserProfile Group。如已配置，请跳过本步骤。

      **ADD UPBINDUPG**
   3. UserProfile Group绑定到DNN。如已配置，请跳过本步骤。

      **ADD APNUSRPROFG**

## 任务示例

任务描述

配置指定P2P业务的带宽控制的规则名称为rule\_test，优先级为10。

脚本

//配置带宽控制规则。

```
ADD CPRULE: RULENAME="rule_test", POLICYTYPE=BWM, PRIORITY=10;
```

//配置业务策略组合。

```
ADD CPUSERPROFILE:USERPROFILENAME="up_test",UPTYPE=PCC;
ADD CPRULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test";
ADD USRPROFGROUP:USERPROFGNAME="upg_test";
ADD UPBINDUPG:USERPROFGNAME="upg_test",UPBINDTYPE=DEFAULT,USERPROFILENAME="up_test";
ADD APNUSRPROFG:APN="huawei.com",USERPROFGNAME="upg_test";
```
