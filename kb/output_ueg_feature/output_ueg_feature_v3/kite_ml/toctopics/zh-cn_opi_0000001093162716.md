## 操作场景

本操作指导介绍配置UEG和CHR服务器的对接，以及激活CHR功能的操作过程。

* 完成UEG上IP路由数据的配置，具体流程参见《UEG初始配置与调测》手册>配置VNF侧IP路由数据。
* (可选)安装部署IPsec，建议部署IPSec保证传输通道安全、数据安全。
* 配置UCF与CHR服务器对接数据。
* 开启CHR功能，配置CHR服务器类型以及发送策略。

## 操作步骤

步骤一：（可选）安装部署IPsec

1. 安装IPsec服务，具体流程参见《UEG软件安装》手册>安装可选服务>安装IPSec服务。
2. 配置IPsec，具体参见《UEG安全配置》手册>可选配置>网络安全配置>配置IPsec功能。

步骤二：配置UCF和CHR服务器对接数据。

1. 进入“MML命令行-UEG”窗口。
2. 配置UCF报表本地IP资源池。

   **ADD UCFIP**
3. 配置UCF报表服务器接入点IP地址等信息。

   **ADD UCFSVRIP**

步骤三：配置整系统CHR上报策略、存储策略以及CHR服务器类型。

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的CHR功能License配置开关。

   **SET LICENSESWITCH**

   CHR License仅控制整系统的正常流程CHR单据。
3. 配置全局粒度的整系统CHR上报开关。

   **SET GLBCHRFUNC**
4. APN粒度的整系统CHR上报开关。

   **ADD APNCHRFUNC**
5. 配置整系统CHR的成功/失败业务流程和信令事件。

   **ADD SESSNCHRPRCTMPL**
6. 配置整系统CHR单据上报的高性能CHR服务器以及CHR单据中的设备号。

   **SET SESSNCHRCFG**
7. 配置整系统正常CHR、整系统异常CHR是否保存至UCF。

   **SET SESSNCHRSTORECFG**

步骤四：（可选）配置小范围CHR上报策略以及存储策略。

1. 进入“MML命令行-UEG”窗口。
2. 配置小范围CHR单据上报开关，并配置小范围CHR是否保存到OMU和UCF。

   **SET SESSNCHRSTORECFG**
3. 配置小范围CHR的过滤条件。

   **ADD CPCHRRPTSUBID**或**ADD CHRRPTLOCINFO**
4. 配置小范围CHR单据上报的业务流程和信令事件。

   **ADD SESSNCHRPRCTMPL**

步骤五：（可选）配置基于APN上报策略以及存储策略。

1. 进入“MML命令行-UEG”窗口。
2. 配置基于APN的CHR单据上报的业务流程和信令事件。

   **ADD SESSNCHRPRCTMPL**
3. 配置基于APN的CHR存储表单。

   **ADD CHRRPTSUBAPN**

## 任务示例

任务描述

此处以UEG作为SMF网元为例。

步骤一：配置UCF和CHR服务器对接数据。

步骤二：激活CHR功能，配置整系统CHR上报策略、存储策略以及CHR服务器类型。

* 打开CHR功能License，打开全局粒度的整系统CHR上报开关，打开APN为“HUAWEI.COM”的整系统CHR上报开关。

  CHR License仅控制整系统的正常流程CHR单据。
* 设置PDU Session Release/Registration Update流程成功和失败时均上报CHR单据，流程控制模板索引设置为10，并且上报至高性能CHR服务器。
* 配置整系统正常CHR、整系统异常CHR保存至UCF。

步骤三：（可选）配置小范围CHR上报策略以及存储策略。

* 配置小范围CHR单据上报的业务流程和信令事件。设置PDU Session Release/Registration Update流程成功和失败时均上报CHR单据，流程控制模板索引设置为11。
* 打开小范围CHR单据上报开关，并配置小范围CHR保存到OMU和UCF。

脚本

步骤一：配置UCF和CHR服务器对接数据。

//配置UCF报表本地IP资源池。

```
ADD UCFIP: PROTOCOLTYPE=TCP, IPTYPE=IPv4, IPV4="10.181.23.253", PORTSTART=6000, PORTEND=6031, INDEX=1;
```

//配置CHR服务器接入点IP地址等信息。

```
ADD UCFSVRIP: PROTOCOLTYPE=TCP, ACCESSNAME="ACCESS1", UCFSVRNAME="UCFSVR1", IPTYPE=IPv4, IPV4="10.80.128.1", SVRPORT=10500;
```

步骤二：激活CHR功能，配置整系统CHR上报策略、存储策略以及CHR服务器类型。

//打开CHR功能License，打开全局粒度的整系统CHR上报开关，打开APN为“HUAWEI.COM”的整系统CHR上报开关。

```
SET LICENSESWITCH: LICITEM="LKV2CHR04", SWITCH=ENABLE;
```

```
SET GLBCHRFUNC: CHRREPORTSW=ENABLE;
```

```
ADD APNCHRFUNC: APN="HUAWEI.COM", CHRREPORTSW=ENABLE;
```

//设置PDU Session Release/Registration Update流程失败时上报CHR单据，流程控制模板索引设置为10，并且上报至高性能CHR服务器。

```
ADD SESSNCHRPRCTMPL: TMPLIDX=10, SESSNCHRFAILPRC=PDUSESSNREL-1&MOBILREGUPDATE-1;
```

```
SET SESSNCHRCFG: HISRVPRCTMPLIDX=10;
```

//配置整系统异常CHR保存至UCF。

```
SET SESSNCHRSTORECFG: CHRFAILSAVE=ENABLE, CHRALLSAVE=DISABLE;
```

步骤三：（可选）配置小范围CHR上报策略以及存储策略。

//打开小范围CHR单据上报开关，并配置小范围CHR保存到OMU。

```
SET SESSNCHRSTORECFG: CHRSPESUBSAVE=ENABLE, CHRSAVEPATH=SAVE_OMU;
```

（可选1）//配置小范围CHR的过滤条件为IMSI为“123030123456789”的用户。

```
ADD CPCHRRPTSUBID: IMSI="460030123456789", TMPLIDX=11;
```

（可选2）//配置针对位置N2TAC为0x123123的 用户进行本地存储。

```
ADD CHRRPTLOCINFO: LOCTYPE=N2TAC,TAC="123123";
```

1、可选1（根据用户标识IMSI上报CHR单据）和可选2（根据用户的位置信息上报CHR单据）选其一进行配置。

2、开启基于位置信息的小范围CHR用户上报时，一定要开启软参流控。软参流控的配置参考如下：

* DWORD1016 BIT24~BIT26 控制是否进行CHR流控及流控的上限，设置值为1(bit26: 0, Bit25: 0, bit24: 1)。
* DWORD509 BIT20~BIT22 控制是否进行Gx接口消息的CHR流控及流控的上限，设置值为1(bit22: 0, Bit21: 0, bit20: 1)。
* DWORD509 BIT23~BIT25 控制是否进行Gy接口消息的CHR流控及流控的上限，设置值为1(bit25: 0, Bit24: 0, bit23: 1)。
* DWORD509 BIT26~BIT28 控制是否进行Gi接口消息的CHR流控及流控的上限，设置值为1(bit28: 0, Bit27: 0, bit26: 1)。

//配置小范围CHR单据上报的业务流程和信令事件。设置PDU Session Release/Registration Update流程失败时上报CHR单据，流程控制模板索引设置为11。

```
ADD SESSNCHRPRCTMPL: TMPLIDX=11, SESSNCHRFAILPRC=PDUSESSNREL-1&MOBILREGUPDATE-1;
```

步骤四：配置基于APN的CHR存储表单。

//配置基于APN的CHR单据上报的业务流程和信令事件。

```
ADD SESSNCHRPRCTMPL: TMPLIDX=2, SESSNCHRSUCCPRC=UEINITCREATESMCTX-1&PDUSESSNREL-1;
```

//配置基于APN的CHR存储表单。

```
ADD CHRRPTSUBAPN: APN="HUAWEI.COM", TMPLIDX=2, CHRFAILSAVE=SAVE_OMU, CHRALLSAVE=SAVE_UCF;
```
