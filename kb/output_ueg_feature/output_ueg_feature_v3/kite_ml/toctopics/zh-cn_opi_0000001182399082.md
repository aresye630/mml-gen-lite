## 操作场景

用户可以在OM Portal上创建维护用户，用于对系统进行操作维护。创建完成后，也可根据实际情况对维护用户进行修改。

用户也可以执行系统命令创建新OS用户，用于操作员远程登录操作系统进行操作维护。

* 创建用户成功后，“使用状态”为“锁定”，需要在“安全 > 用户管理 > 角色”，关联对应的角色，该用户才可以正常登录OM Portal。
* 对普通用户“重置密码”后，“使用状态”为“锁定”，需要在“安全 > 用户管理 > 用户”的“操作”列，选择“更多 > 解锁”，该用户才可以正常登录OM Portal。

## 对系统的影响

该操作对系统无影响。

## 必备事项

前提条件

* 已登录OM Portal。
* 操作员拥有系统管理员权限。（启用/停用/解锁用户需要安全管理员权限。）

数据

如果需要修改用户密码，请提前准备用户的新密码。

## 操作步骤

1. 选择“安全 > 用户管理”，在左侧导航栏中选择“用户”，进入“用户”界面。
2. 在用户界面，查看系统默认帐号，并对默认帐号进行操作。

   * admin用户：支持编辑和停启用操作。
   * emscomm、internaluser、mmlinternaluser、thirdPartyUser用户：支持“编辑”和“重置密码”操作。

   * admin用户被停用后无法登录OM Portal，且登录中的admin用户会被注销。
   * 系统会在每月一号凌晨一点重置mmlinternaluser用户密码。
   * admin用户被停用后无法登录OM Portal，且登录中的admin用户会被注销。
   * 修改emscomm密码的时侯，需要注意特殊字符不能包含逗号、分号、等号、双引号、单引号、问号和空格。
   * 系统会在每月一号凌晨一点重置mmlinternaluser用户密码。

   |  | 对机机用户emscomm、internaluser、mmlinternaluser、thirdPartyUser及自定义系统对接用户。  勾选并设置该参数后，当密码有效期小于10天，或者密码已过期时，系统将上报ALM-136076 应用账号密码过期告警。 | 取值范围：  * 勾选：通过此参数设置该用户的密码有效期。输入值必须在10~999之间。 * 去勾选：该用户的默认密码永久有效。 默认值：去勾选。 |
   | 达到最大在线会话数后的登录方式 | 同一用户在同一时间段登录的会话数达到设定值时，可以限制用户登录的方式。  说明：  仅当“用户类型”为“普通用户”时，显示该参数。 | 取值范围：  * 限制登录：达到最大在线会话数后，系统会限制新的用户登录。此时可以设置“最大在线会话数”。 * 注销会话：达到最大在线会话数后，系统会注销之前已经登录的用户。选中后“最大在线会话数”默认为1。 默认值：限制登录。 |
3. 在用户界面，单击“创建”。
4. 在“基本信息”页面，按照要求填写用户名、密码等信息，单击“下一步”。

5. 在系统已有的登录时间控制策略中，勾选需要的登录时间控制策略。

   * 如果系统已有的登录时间控制策略不满足需要，可选择“安全 > 安全策略 > 登录时间控制”创建新的登录时间控制策略。
   * 当“用户类型”为“系统对接用户”时，仅支持勾选“默认策略”。
6. 在系统已有的可登录的IP地址区间中，勾选需要的登录IP区间。

   * 如果系统已有的可登录IP地址区间不满足需要，可选择“安全 > 安全策略 > 登录IP地址控制”创建新的登录IP地址控制策略。
   * 当“用户类型”为“系统对接用户”时，不支持对登录IP地址区间进行设置。
7. 确认勾选上登录时间控制策略和限制可登录的IP地址区间，单击界面右下方的“完成”。

   可不选择限制可登录的IP地址区间，如果不选择，则创建的用户将不受可登录IP地址区间的限制。
8. 创建完成后自动返回用户管理页面，可查看到刚创建的用户信息，则创建维护帐号成功。

   * 新建普通用户后：普通用户“使用状态”默认为“锁定”，请选择“安全 > 用户管理 > 角色”，单击需要赋予权限对应的角色“操作”列的“编辑”后，在“用户列表”中勾选新增用户，将新增用户添加至对应角色后，“使用状态”变为“正常”。
   * 新建系统对接用户后：系统对接用户“使用状态”默认为“锁定”，请选择“安全 > 用户管理 > 角色”，单击角色MMAdministrators“操作”列的“编辑”后，在“用户列表”中勾选新增用户，将新增用户添加至该角色后，“使用状态”变为“正常”。
   * 用户重置密码后：普通用户“使用状态”会变更为“锁定”，单击“操作”列“更多 > 解锁”后，“使用状态”变为“正常”。系统对接用户“使用状态”默认为“正常”。
9. 维护帐号创建后，在用户管理界面可对帐号的信息进行修改。

   对于自定义用户，当“用户类型”为“普通用户”时，支持编辑、重置密码、删除、停用和解锁操作。

   对于自定义用户，当“用户类型”为“系统对接用户”时，仅支持编辑、重置密码和删除操作。
10. 如果需要创建新OS用户，可以执行如下命令。

    仅可以在两个管理节点创建OS用户。操作员可以登录OM Portal执行**LST OMIP**命令查看管理节点所在的IP地址。

    1. Windows操作系统通过“putty.exe”工具登录系统管理节点，Linux操作系统通过终端模拟器登录系统管理节点，执行**su - root**切换至root用户。
    2. 执行**bash /usr/bin/create\_out\_sshduser.sh -a "*<待添加用户名>*"** （添加的用户名称需要满足Linux用户名要求，不能含有~!@$%&等特殊符号）。
    3. 界面提示“please input password:”后，输入待添加用户的密码（密码需要满足复杂度要求，至少一个大写字母，一个小写字母，一个数字和一个特殊符号，长度14位以上）。
    4. 界面提示“Are you sure you want to change the password upon your first login (yes/no)?”后，输入**yes**开启登录强制修改密码功能（此用户用于对接第三方系统，开启后需要第三方系统对接配合修改，如果第三方无法支持此功能可输入**no**）；输入**no**关闭登录强制修改密码功能。
    5. 界面提示：“add user ***<新创建用户名>*** success”则添加用户成功。若添加失败，请根据提示信息检查添加的用户名是否含有特殊字符，密码是否满足复杂度要求。
    6. 添加完成后，可执行**cat /etc/passwd**查看用户相关信息。

    * 以上步骤添加的用户默认具有**su - root**以及远程登录系统的权限。
    * 新创建的OS用户如果需要删除可以执行：**bash /usr/bin/create\_out\_sshduser.sh -d "*<待删除用户名>*"。（**删除操作，会将用户相关的目录内容全部删除，如需保留请提前备份如下目录内容：/home/用户名; /var/mail/用户名; /var/spool/mail/用户名 ）
    * 可以使用**bash /usr/bin/create\_out\_sshduser.sh -h查看脚本使用的帮助信息。**
