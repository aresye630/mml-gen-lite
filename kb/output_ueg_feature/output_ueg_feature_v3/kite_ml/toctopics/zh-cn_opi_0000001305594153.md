## 操作场景

为提升HSS全故障场景下的业务连续性，可以激活本特性。

适用于MME。

## 必备事项

前提条件

* 请仔细阅读GWFD-021409 HSS全故障业务保活特性概述。
* 完成加载License。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置HSS Bypass功能开关和策略。

   **SET HSSBYPASS**
3. 增加HSS Bypass后的最小签约数据。

   **ADD HSSBPAPNSUB**

   **ADD HSSBPAPNGRP**

   **ADD HSSBPUSRSUB**
4. 当希望HSS/DRA全故障后，系统收到HSS/DRA返回某个特定原因值时，用户进入HSS Bypass状态，可通过此命令配置该原因值为HSS Bypass原因值，需配置该原因值为HSS Bypass原因值。

   **ADD HSSBPFAULTCODE**
5. （可选）域路由组网方式下，当希望MME收到对端的错误码后进行路由重选时，需要配置触发重选路由的错误码。

   **ADD DMFOVERCODE**
6. （可选）当所有HSS已经故障但MME还未检测到时，可配置故障的HSS。

   **ADD HSSBPOFC**
7. 由于链路故障等原因发送Diameter消息失败时，开启软参BYTE\_EX\_B324 bit1使MME能够接收失败响应并进行响应处理，避免直连DRA故障场景无法触发用户进入HSS Bypass。

   **SET SOFTPARAOFBIT**
8. （可选）开启软参BYTE\_EX\_B47 bit3，配置MME在匹配用户当前安全上下文时，忽略TSC标识。解决由于终端携带TSC错误导致用户安全检查失败而无法接入的问题。

   **SET SOFTPARAOFBIT**
9. 配置S10/N26接口向MME/AMF传递MSISDN的消息。

   **ADD MMECHARACT**

   **MOD MMECHARACT**

## 任务示例

任务描述

任务1：域路由组网方式下，开启MME的HSS全故障业务保活特性，且希望MME探测到HSS全故障后自动标识用户为HSS Bypass状态。

任务2：开启MME的HSS全故障业务保活特性，手动配置故障HSS，使用户进入HSS Bypass状态。

任务3：手动触发用户退出HSS Bypass状态。

任务4：域路由组网方式下，开启MME的HSS全故障业务保活特性，且希望DRA回复5012故障码时使用户进入HSS Bypass状态。

脚本

**任务1的脚本：**

//开启HSS全故障业务保活特性license。

```
SET LICENSESWITCH: LICITEM="LKV2HSSBP01",SWITCH=ENABLE;
```

//开启HSS Bypass功能开关并配置相关策略。

```
SET HSSBYPASS: BPSW=ON, RECOVERYACT=GRACEFUL_DEREG, SCANRATE=0, SCANINTERVAL=600, AUTOEXITSW=ON, IWKSUBEN=ON;
```

//配置HSS Bypass最小签约数据配置。

```
ADD HSSBPAPNSUB: APNSUBIDX=1, APNNI="cmnet", PDNTYPE=IPV4, APNAMBRULK=1000, APNAMBRDLK=1000, QCI=9, PRIORITY=1;
ADD HSSBPAPNGRP: APNGRPID=1, APNSUBIDX=1, DEFAULTAPN=YES;
ADD HSSBPUSRSUB: SUBRANGE=ALL_USER, APNGRPID=1;
```

//配置HSS故障返回码。

```
ADD HSSBPFAULTCODE: RANGE=ALL, FAULTCODE=3002;
ADD HSSBPFAULTCODE: RANGE=ALL, FAULTCODE=5012;
```

//配置触发重选路由的错误码。

```
ADD DMFOVERCODE:ERRCODE=3002;
ADD DMFOVERCODE:ERRCODE=5012;
```

//由于链路故障等原因发送Diameter消息失败时，开启软参BYTE\_EX\_B324 bit1使MME能够接收失败响应并进行响应处理，避免直连DRA故障场景无法触发用户进入HSS Bypass。

```
SET SOFTPARAOFBIT: DT=BYTE_EX_B, PARANUM=324, VALUE=VALUE_1, POSITION=1;
```

//（可选）开启软参BYTE\_EX\_B47 bit3，配置MME在匹配用户当前安全上下文时，忽略TSC标识。解决由于终端携带TSC错误导致用户安全检查失败而无法接入的问题。

```
SET SOFTPARAOFBIT: DT=BYTE_EX_B, PARANUM=47, VALUE=VALUE_1, POSITION=3;
```

//配置S10/N26接口向MME/AMF传递MSISDN的消息。

```
MOD MMECHARACT: RANGE=ALL_MME, MSISDNSW=YES, PVTMSISDNSW=YES;
```

**任务2的脚本：**

//开启HSS全故障业务保活特性license。
