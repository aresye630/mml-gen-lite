# 5G LAN单用户本地签约配置

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

5G LAN单用户本地签约操作。

* 仅UEG 风筝L支持本地调整用户所属的5G LAN组。
* 必须在UDM上先完成用户的5G LAN组签约，才支持本地调整该用户所属的5G LAN组。

#### 对系统的影响

该操作对系统无影响。

#### 必备事项

**前提条件**

* 已登录 OM Portal。
* 操作员拥有5G LAN用户本地签约权限。

**数据**

在MML命令窗口，UEG视图下执行**SET EDGESMCOMMFUNC**开启5G LAN用户本地签约功能。

#### 操作步骤

1. 选择“应用配置 > 业务运维”，在左侧导航栏中选择“ 5G LAN用户本地签约配置”-> "5G LAN单用户本地签约配置"。
2. 输入5G LAN用户本地签约配置参数。

   **图1** **5G LAN单用户本地签约**

   **表1** 5G LAN单用户本地签约参数

   | 参数名 | 参数含义 | 参数取值 |
   | --- | --- | --- |
   | IMSI | 用户的IMSI号码 | 字符串类型。5～15位的十进制数字。 |
   | APN | 该参数用于指定APN实例名 | 字符串类类型，输入长度范围为1~63。只能由"-"、数字、大小写字母和“.”组成，不能以“.”开头且不能出现两个连续的“.”。不支持空格及“\_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。 |
   | 5G LAN组ID输入方式 | 5G LAN组输入模式  说明：  支持选择输入和手工输入。  * 选择输入：5G LAN用户激活在风筝L上时，采用选择输入方式，通过下拉框选择5G LAN组ID（UEG获取的5GLAN组ID来自UPF上已配置5GLAN组ID）。 * 手工输入：仅在L+S多园区场景存在。由于UEG-L无法通过N4接口获取UEG-S配置的5G LAN组ID。（手工输入的5GLAN组ID来自UEG-S上已配置5GLAN组ID）。 | 枚举类型。  * 选择输入：输入的5G LAN组ID为UPF上已配置的5G LAN组ID。 * 手工输入：手工输入5G LAN组ID时，若输入不存在的5G LAN组ID，则用户激活失败。 |
   | 选择5G LAN组ID | 选择本地签约的5G LAN组ID  说明：  增加5G LAN组的配置，在MML界面UEG视图下执行**ADD NGVNINSTANCE**命令。 | 枚举类型。 |
   | 输入5G LAN组ID | 手工输入本地签约的5G LAN组ID | 字符串类型，输入长度范围是18~37。 |
3. 点击“提交”完成5G LAN单用户本地签约。
