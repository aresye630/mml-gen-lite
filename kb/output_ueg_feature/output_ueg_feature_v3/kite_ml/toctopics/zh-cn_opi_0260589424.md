# 激活SMF支持DDN流控功能

## 操作场景

SMF的周边AMF存在过载风险时，SMF能够根据本地配置控制向各AMF发送DDN消息的速率，从而保护周边AMF。

适用于SMF。

## 必备事项

前提条件

请仔细阅读GWFD-021404 周边网元过载保护特性概述（SMF支持DDN流控）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET DDNFLOWCTRL** | wal值 | 1000 | 本端规划 | 设置SMF每秒发送给AMF的最大DDN消息数 |
| **ADD DDNPRIORITYARP** | ARP数值（ARP） | 1  2  3 |  | 添加DDN消息的ARP优先级规则。 |
|  | 优先级（PRIORITY） | DDN\_HIGH |  |  |
| **ADD DDNPRIORITYAPN** | APN名称（APN） | ims |  | 设置DDN消息的APN优先级规则。 |
|  | 优先级（PRIORITY） | DDN\_HIGH |  |  |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 设置SMF每秒发送给AMF的最大DDN消息数。

   **SET DDNFLOWCTRL**
3. 配置高优先级DDN消息的ARP。

   **ADD DDNPRIORITYARP**
4. 配置高优先级DDN消息的APN。

   **ADD DDNPRIORITYAPN**

## 任务示例

任务描述

设置SMF到周边AMF的DDN消息的wal值，以保护周边AMF，避免其系统过载。同时，设置高优先级DDN消息的ARP和APN。

脚本

//设置SMF每秒发送给AMF的最大DDN消息数。

```
SET DDNFLOWCTRL: WALVALUE=1000;
```

//配置高优先级DDN消息的ARP为**1**、**2**、**3**。

```
ADD DDNPRIORITYARP: ARP=1,PRIORITY=DDN_HIGH;
```

```
ADD DDNPRIORITYARP: ARP=2,PRIORITY=DDN_HIGH;
```

```
ADD DDNPRIORITYARP: ARP=3,PRIORITY=DDN_HIGH;
```

//配置高优先级DDN消息的APN为**ims**。

```
ADD DDNPRIORITYAPN: APN="ims",PRIORITY=DDN_HIGH;
```
