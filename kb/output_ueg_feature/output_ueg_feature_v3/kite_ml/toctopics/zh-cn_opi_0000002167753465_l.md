# 本地调整用户所属的5G LAN组（通过MML）

* 操作场景
* 必备事项
* 操作步骤
* 验证方法

## 操作场景

企业产线部署5G LAN业务后，存在根据业务实际需要，灵活调整CPE（5G模组）/5G LAN终端（5G模组）签约的5G LAN组的需求。

产线需要灵活调整时，若仅依赖在UDM上修改5G LAN组签约数据，则存在申请周期较长等问题。故需要灵活调整时，可本地调整用户所属的5G LAN组。

本地调整用户所属的5G LAN组，指的是在SMF（UEG-L）上修改用户的5G LAN组。对于风筝L，优先使用SMF上设置的用户的5G LAN组。

* 仅UEG 风筝L支持本地调整用户所属的5G LAN组。
* 必须在UDM上先完成用户的5G LAN组签约，才支持本地调整该用户所属的5G LAN组。

## 必备事项

前提条件

* 5G LAN业务已交付且运行正常。
* 5G LAN用户在UDM上已完成5G LAN组签约，且存在调整所属5G LAN组的诉求。
* 操作员拥有相关MML的配置权限。

数据

**表1** 5G LAN用户本地签约配置

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD RDSSTATICIPPARA** | 用户IMSI号（IMSI） | 46000876543210 | 从对端获取 | CPE（5G模组）/5G LAN终端（5G模组）的IMSI信息。 |
|  | APN名称（APN） | dnn5glan01 | 已配置数据中获取 | CPE（5G模组）/5G LAN终端（5G模组）签约的APN。 |
|  | 地址类型（ADDRTYPE） | Ethernet | 固定取值 | - |
|  | 5G LAN组ID（GROUPID） | 000003e9-460-08-01 | 已配置数据中获取 | 此处规划的是调整后的5G LAN组ID。   * 5G LAN用户激活在风筝L上时，在风筝L上执行**LST NGVNINSTANCE**获取5G LAN组ID（获取的5GLAN组ID来自UEG风筝L的UPF上已配置5GLAN组ID）。 |

5G LAN用户本地签约时，单个UEG设备上不限制单个5G LAN组下的本地签约用户数，但单个UEG设备上的单个5G LAN组支持激活的最大会话数是256个。

## 操作步骤

1. 登录OM Portal。
2. 进入“MML命令行-UEG”窗口。

   * 5G LAN用户已存在本地签约5G LAN组ID时，如需再次调整本地签约的5G LAN组ID，则须先删除用户本地签约的5G LAN组ID，然后再重新设置用户本地签约的5G LAN组ID。
   * 可参考验证方法中的1~2进行查询及删除。
3. 执行**ADD RDSSTATICIPPARA**命令，设置用户本地签约的5G LAN组ID。

   //采用数据中的样例值时，配置脚本如下：

   ```
   ADD RDSSTATICIPPARA: IMSI="46000876543210", APN="dnn5glan01", ADDRTYPE=Ethernet, GROUPID="000003e9-460-08-01";
   ```
4. 联系企业运维人员，将修改本地签约的5G LAN组ID的5G LAN用户重新接入网络。

   修改本地签约的5G LAN组ID后，5G LAN用户必须重新接入网络，否则本地签约的5G LAN组ID不生效。

## 验证方法

1. 执行**LST RDSSTATICIPPARA**命令，查询5G LAN用户本地签约的5G LAN组ID是否正确。
   * 是，请执行4。
   * 否，请执行2。
2. 执行**RMV RDSSTATICIPPARA**命令，删除错误的配置。
3. 参考**操作步骤**，重新设置用户本地签约的5G LAN组ID，然后重新验证。
4. 拨测调整5G LAN组后的用户业务是否正常。
   * 正常，调测结束。
   * 不正常，请联系华为技术支持工程师处理。
