## 操作场景

本操作指导介绍激活P-CSCF故障时IMS业务恢复功能，降低P-CSCF服务器故障时对用户业务的影响。

适用于PGW-C、SMF

## 必备事项

前提条件

* 已阅读GWFD-025501 P-CSCF故障时IMS业务恢复特性概述。
* 完成激活VoLTE基础语音业务（适用于SGW-C/PGW-C）。
* 完成激活PCC基本功能。
* 已确认周边网元支持P-CSCF故障恢复的处理。
* UEG上已完成IP FARM管理相关配置。
* 已完成加载License。
* 已完成IMS配置。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开该功能的License配置开关。

   **SET LICENSESWITCH**
3. 修改APN参数。

   **SET CPAPNIMSATTR**
4. 添加P-CSCF组配置。

   **ADD PCSCFGROUP**
5. 添加P-CSCF地址配置。

   **ADD PCSCFIP**
6. 增加IMSI和MSIDSN号段

   **ADD PCSCFIMSISDNSEG**
7. 添加P-CSCF组和APN的绑定关系，可以整APN绑定，或者按照IMSI/MSISDN号段绑定。

   **ADD PCSCFGRPBNDAPN**
8. 配置通知对端NF状态变化的抑制时间。

   **SET PNFNTFPLCY**
9. 配置软参。将软参DWORD1017 BIT29、DWORD1017 BIT30取值设置为1。

   **SET SMFSOFTPARA**

## 任务示例

任务描述

使能APN为“ims”的IMS业务恢复功能。

脚本

//进入“MML命令行-UEG”窗口。

//该功能SMF的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3W9IMSR11", SWITCH=ENABLE;
```

//修改IMS APN的参数。

```
SET CPAPNIMSATTR: APN="ims", IMSSWITCH=ENABLE;
```

//添加P-CSCF组配置。

```
ADD PCSCFGROUP: GROUPNAME="vonr", IPVERSION=IPV4, ALLOCTYPE=LOCAL;
```

//添加P-CSCF地址配置。

```
ADD PCSCFIP: GROUPNAME="vonr", IPVERSION=IPV4, PCSCFIPV4="10.28.236.11", WEIGHT=10, ALLOCTYPE=LOCAL, PAIRID=1;
```

//增加IMSI和MSIDSN号段。

```
ADD PCSCFIMSISDNSEG: SEGMENTNAME="vonr", SEGMENTTYPE=IMSI, SEGSTART="123031200100026", SEGEND="123031200100027";
```

//将APN绑定到P-CSCF组。

```
ADD PCSCFGRPBNDAPN: APN="ims", DEFAULTFLAG=DEFAULT, MPCSCFGRPIPV4="vonr";
```

//在APN下将某指定号段绑定到P-CSCF组。

```
ADD PCSCFGRPBNDAPN: APN="ims", DEFAULTFLAG=IMSI_MSISDN_SEG, IMSIMSISDNSEG="vonr", PRIORITY=1, MPCSCFGRPIPV4="vonr";
```

//配置通知对端NF状态变化的抑制时间，用于抑制向本端NF通知对端NF状态变化的频率。

```
SET PNFNTFPLCY: NFTYPE=NfPCSCF, NTFTIME=1;
```

SMF形态基于UPF和PCF的PCSCF故障恢复，按照协议根据UE能力0012H(P-CSCF Re-selection support)选择是否重新激活会话。如果UE支持P-CSCF地址更新则发更新消息给UE，不重新激活会话；否则删除会话后UE重新接入激活会话。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1017, VALUE=VALUE_1, POSITION=29;
```

PGW-C、GGSN和S/PGW-C形态基于UPF和PCRF/PCF的P-CSCF故障恢复，按照协议根据UE能力0012H(P-CSCF Re-selection support)选择是否重新激活会话。如果UE支持P-CSCF地址更新则发更新消息给UE，不重新激活会话；否则删除会话后UE重新接入激活会话。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1017, VALUE=VALUE_1, POSITION=30;
```
