## 操作场景

以一个典型的N7接口PDU上线、PCF发起的会话更新及会话删除为例，详细介绍PCF侧的业务配置。操作场景为，当5G网络中用户上线状态正常时，可享受正常高速带宽，当状态不正常时，运营商可调整用户的访问带宽。

场景具体描述如下：

* PDU会话上线阶段：用户上线，根据上线状态做带宽控制，
  + 当上线状态正常时，上行带宽为10 Mbit/s，下行带宽为10 Mbit/s。
  + 当上线状态不正常时，上行带宽降为1 Mbit/s，下行带宽降为1 Mbit/s。
* PDU会话更新：PCF侧修改用户状态不为“Normal”。
* 不配置消息通知。
* PDU会话删除：用户主动下线。

## 对系统的影响

该特性对系统无影响。

**表1** 配置关系解释

| 名称 | 需求分解 | 基本原则 |
| --- | --- | --- |
| 业务Service\_N7 | 此用户仅包含一个业务，业务名称为：Service\_N7 | 该业务不区分DNN，仅针对用户上线访问业务时做管控，当用户上线状态为Normal时，享受高带宽，当状态变更为非Normal时，带宽受限。 |
| 策略Policy\_N7 | 此策略在用户上线时被调用，触发器为IPCAN\_EST，包含4个规则：Default\_Normal、Dynamic\_Normal、Default\_NotNormal、Dynamic\_NotNormal | 四个规则中，当用户状态为Normal时，匹配规则Default\_Normal、Dynamic\_Normal；当用户状态不为Normal时，匹配规则Default\_NotNormal、Dynamic\_NotNormal。 |
| 规则Default\_Normal | * 条件：userStatus=Normal。 * 动作：SessionRuleAction（5QI=8，ARP=1）。 | - |
| 规则Dynamic\_Normal | * 条件：userStatus=Normal。 * 动作：    + QoSData：5QI为8，ARP为1。   + Flowinformation：全选“any”。 | 若对端是华为UEG，建立缺省QoS Flow的同时必须下发规则，否则QoS Flow无法建立成功。 |
| 规则Default\_NotNormal | * 条件：userStatus不等于Normal。 * 动作：SessionRuleAction（5QI=8，ARP=1）。 | - |
| 规则Dynamic\_NotNormal | * 条件：userStatus不等于Normal。 * 动作：    + QoSData：5QI为8，ARP为1。   + Flowinformation：全选“any”。 | 若对端是华为UEG，建立缺省QoS Flow的同时必须下发规则，否则QoS Flow无法建立成功。 |

7. 登录“UPCF 业务管理”窗口。
8. 发放业务。
   1. 执行**ADD PSUB**增加一个用户。

      “USRIDENTIFIER”的参数类型受软参VRM\_SUBSRCIPTIONIDTYPE（系统支持的用户类型）控制，默认为“IMSI”。

      ```
      ADD PSUB: USRIDENTIFIER="46010381012****", USRMSISDN="1234567****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA;
      ```
   2. 执行**ADD PSRV**给用户签约业务。

      ```
      ADD PSRV: USRIDENTIFIER="46010381012****", SRVNAME="Service_N7", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
      ```
   3. PDU会话更新时，执行**MOD PSUB**修改用户状态。

      ```
      MOD PSUB: USRIDENTIFIER="46010381012****", USRSTATE=SubStatusA, USRRSTCATEGORY=No, USRCLRHOMESRVZONE=No;
      ```
