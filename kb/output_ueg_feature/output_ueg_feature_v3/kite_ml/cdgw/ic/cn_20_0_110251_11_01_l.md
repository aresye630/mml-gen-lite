## 操作场景

运营商规划UEG基于位置区为UE分配IP地址时，可激活本特性。

适用于PGW-U、UPF。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 基于APN/DNN实例使能地址分配属性。
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置APN/DNN实例。

      **ADD UPAPN**
   3. 使能该APN的地址分配属性。

      **SET APNADDRESSATTR**
3. 配置地址池绑定到地址池组。
   1. 配置LOCAL类型地址池。

      **ADD UPPOOL**

      * 配置本地地址池的时候，选择参数“LOCAL”类型。
      * UEG本地分配双栈地址时，需要在本地分别规划配置IPv4类型和IPv6类型的POOL。
   2. 配置地址池里的地址段。

      **ADD SECTION**
   3. 配置地址池组。

      **ADD POOLGROUP**
   4. 配置地址池绑定到地址池组。

      **ADD POOLBINDGROUP**
4. （可选）基于TAC位置区分配地址的时候需要配置本步骤。配置TAC位置区组。
   1. 配置TAC位置区组。

      **ADD TACGROUP**
   2. （可选）在S1TAC组内绑定S1TAC号段。

      **ADD S1TACID**
   3. （可选）在N2TAC组内绑定N2TAC号段。

      **ADD N2TACID**
5. （可选）基于LAC位置区分配地址的时候需要配置本步骤。配置LAC位置区组。
   1. 配置LAC位置区组。

      **ADD LACGROUP**
   2. **可选：**在LAC组内添加一个LAC。

      **ADD LACID**
6. 配置TAC-Group/LAC-Group与地址池组的映射关系。

   **ADD POOLGRPMAP**
7. 配置地址分配规则。

   地址分配规则支持两级控制：基于全局和基于APN。默认使用全局地址分配规则。如果配置了使用基于APN的地址分配规则，则使用APN的地址分配规则。

   1. 配置全局地址分配规则。

      **SET IPALLOCRULE**

      每级优先级规则中所选的条件之间为“与”的关系，表示从所选条件映射的地址范围内分配地址，此处设置的规则需要与地址池的映射条件一致。例如此处按照位置区（APN-0&LOCATION-1&SMF-0）设置条件，则规划的地址池组也需绑定LOC。
   2. （可选）如果某一APN的地址分配规则不同于全局地址分配规则，则需执行配置基于APN的地址分配规则优先级。

      **SET APNIPALLOCRULE**
8. 配置基于位置区分配地址的开关。

   基于位置区分配地址的开关支持两级控制：基于全局和指定位置区。

   1. 配置基于位置区分配地址的全局开关。

      **SET IPALLOCBYLOCGLBSW**
   2. （可选）如果某一指定位置区的地址分配开关不同于全局位置区地址分配开关，则需执行配置基于指定位置区分配地址的开关。

      **SET IPALLOCBYLOCSW**
9. 配置手机下行路由。
   1. 启动OSPF进程。

      **ADD OSPF**
   2. 添加OSPF区域。

      **ADD OSPFAREA**
   3. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   4. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**
10. 配置基于位置区分配IP地址的白名单，在白名单范围中的用户不参与基于位置区的IP地址分配。

    **ADD ADRLOCWHITELST**

## 任务示例

任务描述

UE接入核心网，UEG基于用户激活位置为UE分配IPv4地址。分配地址时第一优先级按照从LAC位置区映射的地址范围内分配地址，如果第一优先级的规则匹配不上，则分配地址失败。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5LBAA01",SWITCH=ENABLE;
```

//基于APN使能地址分配属性。

```
ADD VPNINST:VPNINSTANCE="vpn1";
ADD UPAPN:APN="apn-test1",HASVPN=ENABLE,VPNINSTANCE="vpn1";
SET APNADDRESSATTR:APN="apn-test1",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE;
```

//配置地址池。

```
ADD UPPOOL:POOLNAME="testpool1",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="vpn1";
ADD SECTION:POOLNAME="testpool1",SECTIONNUM=0,IPVERSION=IPV4,V6PREFIXSTART="10.10.1.11",V6PREFIXEND="10.10.1.20";
```

//配置地址池绑定到地址池组。

```
ADD POOLGROUP: POOLGRPNAME="poolgroup1";
```

```
ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup1", POOLNAME="testpool1";
```

//配置LAC位置区组与地址池组的映射关系。

```
ADD LACGROUP:LACGROUPNAME="lac1";
ADD LACID:LACGROUPNAME="lac1",LACSECNUM=2,LACSTARTID="0x000a",LACENDID="0x000b";
ADD POOLGRPMAP: MAPPINGNAME="mapping1", LOCATIONGRPTYPE=LAC, LOCATIONGRPNAME="lac1", POOLGROUPNAME="poolgroup1";
```

//配置地址分配规则。

```
SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-0&LOCATION-1&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE;
```

//配置基于位置区分配地址的开关。

```
SET IPALLOCBYLOCGLBSW: SWITCH=ENABLE;
```

//配置手机下行路由。

```
ADD OSPF:PROCID=100,VRFNAME="vpn1",SCHEMAROUID="10.10.10.1";
```

```
ADD OSPFAREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFNETWORK:PROCID=100,AREAID="0.0.0.0", IPADDRESS="10.13.21.0", WILDCARDMASK="0.0.0.255";
```

```
ADD OSPFIMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```

//配置基于位置区域地址分配用户白名单，白名单中的用户不基于位置区分配IP地址。

```
ADD ADRLOCWHITELST: MSISDN="123456";
```
