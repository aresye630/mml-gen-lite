# 管理机架服务器

## 操作场景

CSP支持通过OM Portal对机架服务器进行管理，包括查看和修改服务器的基本信息，查看各部件的详细信息，以及查看服务器的运行状态和重启服务器等操作。

同时，CSP支持通过执行MML命令**LST SERVER**查询服务器基本信息。

## 对系统的影响

本操作对系统无影响。

## 必备事项

前提条件

已登录OM Portal。

数据

该操作无需准备数据。

## 操作步骤

1. 选择“设备管理 > 机架服务器 > 服务器信息”，查看机架式服务器基本信息。
2. 单击机架服务器的序列号，查看对应服务器的详细信息，包括：

   * 基础信息：可查看和修改服务器的基础信息，并可以查看服务器状态信息，支持在“控制面板”对服务器进行重启、收集硬件信息、对iBMC进行重启及跳转iBMC等操作。

     + 服务器与iBMC的重启均是高危操作，会影响系统当前业务的正常运行，请谨慎操作。
     + 当服务器固件正在升级时，需等待5~10分钟后再执行“重启服务器”或“重启iBMC”操作。

     服务器的状态按照部件的运行情况可分为如下4种状态。

     + 紧急：指示系统未正常运行，且存在影响到系统服务质量的故障，需要紧急处理。
     + 警告：指示系统未正常运行，且存在未影响到服务质量的故障，但为了避免更严重的故障，需要在适当时候进行处理或进一步观察。
     + 正常：指示系统正在正常运行。
     + 未知：指示系统未检测到部件的运行状态。
   * 部件详情：可查看服务器各部件的详细信息。默认显示处理器的详细信息。
