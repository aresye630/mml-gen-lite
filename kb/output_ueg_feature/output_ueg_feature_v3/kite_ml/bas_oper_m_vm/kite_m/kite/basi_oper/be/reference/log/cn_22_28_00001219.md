# 查看PGW操作日志

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

PGW操作日志记录了操作执行的记录，主要用于运营商处理投诉和技术人员故障定位。通过查看一个操作员在PGW Web LMT界面进行的相关操作，以帮助解决问题。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

该操作无需具备特殊条件。

**数据**

该操作无需准备数据。

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 执行命令**LST LOG**查看操作日志。

   ```
    LST LOG: STARTTIME=2011&02&28&19&00&00, ENDTIME=2011&02&28&20&13&44;
   ```
