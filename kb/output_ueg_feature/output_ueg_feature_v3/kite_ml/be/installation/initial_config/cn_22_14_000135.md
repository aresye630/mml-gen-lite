# 修改用户重复登录权限

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

在PGW日常的管理和维护中，系统管理员可以根据实际需要修改用户的重复登录权限，即控制是否允许用户重复登录系统。

#### 对系统的影响

机机账号启用限制用户重复登录时，系统必须启用PGW模块间命令串行化功能，启用限制用户重复登录才会生效。启用PGW模块间命令串行化功能会影响系统正常运行。

机机账号关闭限制用户重复登录和人机账号启用或关闭限制用户重复登录，则不依赖其他功能，不影响系统正常运行。

#### 必备事项

**前提条件**

只有具有管理员权限的用户才能修改用户的重复登录权限。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 操作员名称

#### 操作步骤

1. 通过**LST OPR**命令的输出项“ATP”的取值确认待修改的用户账号类型。

   * 机机账号 => 2
   * 人机账号 => 3
2. 机机账号修改用户重复登录权限的步骤如下。

   * 启用限制用户重复登录：
     1. 登录“USCDB MML命令”界面。
     2. 执行如下命令查询软参PGWSERIALSWITCH（PGW串行化开关）的值。

        ```
        LST INSP: INSPT=PGW, INSPN=PGWSERIALSWITCH;
        ```

        若查询结果不是“1”，则执行2.c；否则，跳过2.c。
     3. 执行修改命令，将软参PGWSERIALSWITCH（PGW串行化开关）的值设为“1”。

        ```
        MOD INSP: INSPT=PGW, INSPN=PGWSERIALSWITCH, INSPV=1;
        ```
     4. 登录PGW客户端。

        登录方法请参见登录与退出PGW Web LMT。
     5. 执行命令**MOD OPR**，通过参数“重复登录限制开关”设置用户的重复登录权限。

        ```
        MOD OPR: SYSNO=1, OPNAME="xxx", RELGI=LIMIT;
        ```
   * 关闭限制用户重复登录：
     1. 登录PGW客户端。

        登录方法请参见登录与退出PGW Web LMT。
     2. 执行命令**MOD OPR**，通过参数“重复登录限制开关”设置用户的重复登录权限。

        ```
        MOD OPR: SYSNO=1, OPNAME="xxx", RELGI=NOLIMIT;
        ```
3. 人机账号修改用户重复登录权限的步骤如下。

   * 启用限制用户重复登录：
     1. 登录“USCDB MML命令”界面。
     2. 执行如下命令查询软参MANMACHINERELGISWT（人机账号重复登录限制开关）的值。

        ```
        LST INSP: INSPT=PGW, INSPN=MANMACHINERELGISWT;
        ```

        若查询结果不是“1”，则执行3.c；否则，跳过3.c。
     3. 执行修改命令，将软参MANMACHINERELGISWT（人机账号重复登录限制开关）的值设为“1”。

        ```
        MOD INSP: INSPT=PGW, INSPN=MANMACHINERELGISWT, INSPV=1;
        ```
     4. 登录PGW客户端。

        登录方法请参见登录与退出PGW Web LMT。
     5. 执行命令**MOD OPR**，通过参数“重复登录限制开关”设置用户的重复登录权限。

        ```
        MOD OPR: SYSNO=1, OPNAME="xxx", RELGI=LIMIT;
        ```
   * 关闭限制用户重复登录：
     1. 登录PGW客户端。

        登录方法请参见登录与退出PGW Web LMT。
     2. 执行命令**MOD OPR**，通过参数“重复登录限制开关”设置用户的重复登录权限。

        ```
        MOD OPR: SYSNO=1, OPNAME="xxx", RELGI=NOLIMIT;
        ```
