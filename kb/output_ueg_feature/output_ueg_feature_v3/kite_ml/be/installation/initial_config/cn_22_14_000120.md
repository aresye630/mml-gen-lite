# 配置LAS TLS数字证书

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

第三方FE和LAS之间的LDAP接口使用TLS协议进行通信时需要加载证书文件。

长期使用同一数字证书，可能存在安全风险，为了提高系统安全性，强烈建议运营商定期更新证书。证书文件加载成功后，需要手动删除服务器上的证书文件。

#### 对系统的影响

不涉及。

#### 必备事项

**前提条件**

客户已申请证书文件并已获取对应的证书密码。

**数据**

不涉及。

#### 操作步骤

1. 登录OM Portal界面。
2. 上传证书。

   1. 选择“安全 > 证书管理”，进入“证书与证书集管理”界面。
   2. 单击“上传证书”，进入证书创建向导界面，选择证书类型为“证书集”。

      **图1** 选择证书类型
   3. 根据需要选择证书类型后，单击“下一步”。
   4. 填写“证书集名称”、选择“CA证书”、“设备证书”、“私钥文件”、填写“私钥密码”后，单击“确定”，上传证书文件。

      **图2** 上传证书文件
   5. 返回“证书与证书集管理”界面，查看已上传的证书。

      **图3** 证书与证书集管理
3. 登录CSP Portal页面，在对应证书场景关联正确的证书。

   1. 选择“安全 > 证书管理”，进入“证书应用场景关联”界面。

      **图4** 证书应用场景关联界面
   2. 单击“关联证书”，为“场景名称”为“UDRLas\_LDAP\_Cert”的应用场景关联所需证书。
   3. 选择对应类型的证书后，单击“确定”。

      **图5** 关联证书
   4. 返回“证书应用场景关联”界面，可查看到应用场景的“关联证书”，则表示证书应用场景关联成功。
4. 登录“USCDB MML命令”界面，执行如下命令重启所有LAS服务。

   ```
   RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrLas";
   ```
