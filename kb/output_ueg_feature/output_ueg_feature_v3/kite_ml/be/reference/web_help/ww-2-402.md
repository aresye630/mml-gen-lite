# 登录与退出PGW Web LMT

* 操作场景
* 必备事项
* 操作步骤

#### 操作场景

本操作介绍从本地直接登录或退出PGW Web LMT客户端的过程。

#### 必备事项

**前提条件**

登录PGW Web LMT客户端的前提条件包括：

* 使用PGW Web LMT的计算机需要满足的硬件配置要求如表1所示。

  **表1** 硬件配置要求

  | 配置项 | 数量 | 推荐配置 | 最低配置 |
  | --- | --- | --- | --- |
  | CPU | 1 | 3.2GHz | 2GHz |
  | RAM | 1 | 32GB | 512M |
  | 硬盘 | 1 | 1TB | 10GB |
  | 网卡 | 1 | 1000Mbit/s | 10Mbit/s |
  | 其他设备 | 2×1 | 键盘、鼠标 | — |
* 使用PGW Web LMT的计算机支持软件配置如表2所示。

  **表2** 软件配置支持

  | 配置项 | 配置要求 |
  | --- | --- |
  | 操作系统 | Microsoft Windows 10 Professional。 |
  | 操作系统默认语言 | 中文（简体）/English(United States)。 |
  | Web浏览器 | + Google Chrome 84（64位）及以上版本。 + Microsoft Edge 98（64位）及以上版本。 |
* 使用PGW Web LMT的计算机应当支持TCP/IP协议。
* OMU服务器正常运行。
* PGW模块正常运行。
* 当“WEBLMTHTTPSSWITCH（weblmt https控制开关）”取值为“1”时，确认已加载“连接类型”为“WEBLMT”的“CAVERIF(CA证书)”或“ROOTVERIF(根证书)”、“DEVVERIF(设备证书)”和“KEYFILE(密钥文件)”的证书文件。可通过在“USCDB MML命令”界面执行**LST VERIF**命令查询。

**数据**

登录前需要向系统管理员获取以下数据：

* PGW Web LMT的IP地址。
* 登录PGW Web LMT使用的用户名和密码。

#### 操作步骤

1. 在浏览器地址栏中输入**PGW的地址**，按“Enter”键。是否使用https安全协议登录由软参“WEBLMTHTTPSSWITCH”控制。
   1. 当软参“WEBLMTHTTPSSWITCH”取值为“0”时，在浏览器的地址栏输入地址**http://*****PGW服务IP地址***。
   2. 当软参“WEBLMTHTTPSSWITCH”取值为“1”时，在浏览器的地址栏输入地址**https://*****PGW服务IP地址:80*。**

   系统弹出PGW Web LMT的登录界面，如图1、图2或图3所示。

   PGW Web LMT登录界面的显示由软参MVNOSWITCH(MVNO开关)和APPLICATIONTYPE（应用模式）控制。

   * 当软参“APPLICATIONTYPE（应用模式）”取值为“1”且“MVNOSWITCH(MVNO开关)”取值为“0”时，登录界面如图1所示。
   * 当软参“APPLICATIONTYPE（应用模式）”取值为“1”且“MVNOSWITCH(MVNO开关)”取值为“1”时，登录界面如图2所示。
   * 当软参“APPLICATIONTYPE（应用模式）”取值为“0”时，登录界面如图3所示。

   **图1** PGW Web LMT登录界面（完整模式HLR）

   **图2** PGW Web LMT登录界面（完整模式MVNO）

   **图3** PGW Web LMT登录界面（简单模式）

   由于开放的Web Server的端口可配置，对于使用了非默认端口(80)的局点，请在浏览器地址栏中输入**PGW的IP地址:端口**。
2. 选择“用户类型”。

   * Local

     输入“HLRSN”或“MVNO”、“用户名”、“登录密码”、“验证码”后，单击“立即登录”。

     + 首次登录PGW Web LMT界面时不需要输入验证码，连续两次输入密码错误后再次登录需要输入验证码。
     + 若验证码没有显示或难以辨认，可以单击验证码图片刷新验证码。
     + “HLRSN”或“MVNO”为可选参数。
       - 当不输入该参数时，默认为在USCDB MML界面上执行**SET SYSNO**命令设置的“系统序列号”。
       - 当输入该参数时，“HLRSN”必须为在系统管理界面上执行**ADD SYSHLRSN**命令添加的“系统HLR序列号”或在USCDB MML界面上执行**SET SYSNO**命令设置的“系统序列号”，“MVNO”必须为在系统管理界面上执行**ADD SYSNO**命令添加的“系统序列号”或在USCDB MML界面上执行**SET SYSNO**命令设置的“系统序列号”。
     + 系统配置了默认的“用户名”为“admin”，“登录密码”请从运营商的操作维护人员处获得，“默认密码”请参考《USCDB应用用户默认账号》。
     + 当帐户的密码有效天数小于“密码过期前提示天数”，每次登录PGW Web LMT系统时，系统将会提示修改密码。帐户的密码在到达“密码有效期天数”后将会失效，必须重新修改密码后才能重新登录PGW Web LMT。
   * SSO

     单击“立即登录”后跳转到网管登录页面，输入“用户名”和“密码”后，单击“登录”。

     + 使用SSO登录时，输入的“用户名”所属的系统序列号必须为在USCDB MML界面上执行**SET SYSNO**设置的“系统序列号”。
     + 当软参“THIRDSYSTEMSSOMODE（第三方系统SSO模式）”取值为“1”时，PGW Web LMT登录页面只支持SSO登录。

   当软参“GRANTIPSWITCH（IP限制开关）”取默认值“1”，登录PGW客户端时系统提示“IP地址不在允许登录的范围之内”，需要通过执行**ADD PROVISIONIP**添加的IP地址才能访问PGW。
3. 系统进入PGW Web LMT MML命令界面，如图4所示。

   **图4** PGW Web LMT命令页面

   需要等PGW Web LMT MML命令界面加载完成后才可以切换到其它页面，避免PGW Web LMT MML命令界面未加载完成时切换到其他页面后再切换回来时界面内容加载不完整。如界面内容加载不完整，请刷新当前页面重新加载进入。

   系统默认不显示Banner信息界面，但如果用户通过**SET SECPOLICY**命令设置了“显示Banner”为“TRUE”且输入了要显示的“Banner信息”，则会首先出现Banner信息界面。以输入的“Banner信息”为“警告！本系统仅允许授权用户访问，严禁未经授权使用。”为例，出现的Banner信息界面如图5所示。

   **图5** Banner信息
4. 单击主页面右上角的用户图标，再单击“注销”，即可退出PGW Web LMT。

   **图6** 注销PGW Web LMT命令页面
