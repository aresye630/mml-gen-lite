#### 操作场景

UPCF支持根据用户签约的属性信息进行策略控制，如针对不同的用户类别提供差异化的QoS。同时，当4G或2G/3G/4G融合组网在线用户的签约数据被更改时，例如修改用户的属性、为该用户增删业务，如果签约数据的更改会使用户当前正在使用的策略发生变化，则UPCF会立刻根据修改后的属性值重新进行策略判断，并下发新生成的规则给PCEF（Policy and Charging Enforcement Function），使得用户的业务签约变化能够实时生效。

以用户类别不同，UPCF下发不同的策略控制为例：

* 金牌用户接入网络时，上下行带宽为2 Mbit/s。
* 银牌用户接入网络时，上下行带宽为1 Mbit/s。
* 配置动态规则。

#### 对系统的影响

在线用户的签约数据更改的实时生效处理会消耗系统资源。如果需要大量修改在线用户的签约数据，请尽量在非业务高峰期执行。

#### 操作步骤

1. 修改对端PCEF能力字典项。
   1. 登录“UEG MML命令”界面。
   1. 执行**MOD PCEFABIITEM**，调整对端PCEF能力字典，使其支持R8标准的QoS。

      命令举例：

      ```
      MOD PCEFABIITEM: ABILITYDICTID=68, ABILITYITEMID=R8QoS, ABLITYVALUE=SupportedR8QoS;
      ```

      在4G或2G/3G/4G融合组网中，UPCF与华为UEG对接时，“ABILITYDICTID”需设置为“68”。实际的值可以通过如下方式查询：
      * 当UPCF与PCEF直连时，“能力字典ID”可以通过**LST PPCEF**命令查询。
      * 当UPCF与PCEF通过DRA准直连时，“能力字典ID”可以通过**LST PDHOSTCFG**查询。
   2. 执行**MOD PCEFABIITEM**，调整对端PCEF能力字典，使其支持RAR变更策略。

      命令举例：

      ```
      MOD PCEFABIITEM: ABILITYDICTID=68, ABILITYITEMID=ChangePolicyByRAR, ABLITYVALUE=SupportedChangePolicyByRAR;	
      ```
2. 登录UPCF Web UI界面。
3. 配置条件组。

   导航入口为“策略管理 > 策略 > 条件组”。

   * 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
   * 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与或关系由参数“关系”决定。

   需要配置两个条件组，用于判断用户为银牌用户或金牌用户。条件组的数据规划如表2所示，详细参数说明请参见条件组参数表。

   |  | 条件 | 名称 | Condition\_gold |

   |  |  | 右值类型 | Value |
   |  |  | 右值 | gold  说明：  “gold”：表示用户类别为金牌用户。 |
4. 配置动作组。

   导航入口为“策略管理 > 策略 > 动作组”。

   * 若配置的规则为动态规则，则必须配置动作组。
   * 此场景配置动态规则且需要考虑默认承载的QoS、调整带宽和计费动作，则每个动作组需配置动作：DefaultBearerQoS、QoSAction和ChargingAction。相关应用场景如下：

     + DefaultBearerQoS：当需要建立默认承载时必须配置此动作。
     + QoSAction：当需要进行带宽控制时均需配置此动作，若不配置则表示不限制QoS。
     + ChargingAction：当需要做计费策略控制时，配置此动作（若对端为华为UEG，此动作必须配置）。

   需要配置三个动作组，用于在金牌用户或银牌用户接入网络时动作的下发。动作组的数据规划如表3所示，详细参数说明请参见动作组参数表。

       ```
       ADD PSUB: USRIDENTIFIER="460103810123***", USRMSISDN="123456788***", USRSTATE=Normal, USRPAIDTYPE=NULL, USRCATEGORY="silver", USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=MBB;

       ```

       ```

       ```
