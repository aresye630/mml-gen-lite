#### 操作场景

Gx接口位于PCEF（Policy and Charging Enforcement Function）功能实体与PCF（Policy Charging Function）功能实体之间。UPCF支持基于Diameter协议的Gx接口，完成PCC（Policy and Charging Control）策略控制功能。PCF允许PCEF发起的IP-CAN会话建立请求，并下发装载动态PCC规则 。

下面以用户在PCF侧的开户的用户状态不同，则匹配不同的策略信息为例：

* 用户状态为“Normal”时，上行带宽为1 Mbit/s，下行带宽为1 Mbit/s；
* 用户状态变为“SubStatusA”时，PDN连接会更新，此次带宽更新为上行带宽为500 Kbit/s，下行带宽为500 Kbit/s；
* 用户状态变为“SubStatusB”时，用户禁止访问网络，PDN连接下线。

#### 操作步骤

1. 登录UPCF WebUI界面。
2. 配置条件组。

   导航入口为“策略管理 > 策略 > 条件组”。

   * 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
   * 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与/或关系由参数“关系”的取值决定。

9. 发放业务。
   1. 执行**ADD PSUB**增加一个用户。

      “USRIDENTIFIER”的参数类型受软参VRM\_SUBSRCIPTIONIDTYPE（系统支持的用户类型）控制，默认为“IMSI”

      ```
      ADD PSUB:USRIDENTIFIER="46010381012****", USRMSISDN="12345678901", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=MBB;
      ```
   2. 执行**ADD PSRV**给用户签约业务。

      ```
      ADD PSRV: USRIDENTIFIER="46010381014****", SRVNAME="FUP_Service", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
      ```
