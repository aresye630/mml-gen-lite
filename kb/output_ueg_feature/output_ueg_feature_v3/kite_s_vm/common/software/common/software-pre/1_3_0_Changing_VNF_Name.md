# 修改网元名称

#### 操作场景

如果生产发货时VNF已做过预安装，发货到一线设备上电后，一线工程师要修改网元名称为实际现网的值。

#### 必备事项

**前提条件**

* 已经确认现场网络规划的网元名称与UEG生产预安装的预设参数值不同。
* 已通过OSS(MAE)或UEG OMPortal登录华为操作维护系统。本文以UEG OMPortal为例说明调整过程。

**数据**

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| 网元名称 | 网元ID（MEID） | 20 | 本端规划 | UEG上的命令：  **MOD ME** |
|  | 网元本地名称（MELN） | UEGABC | 本端规划 |  |
|  | 网元名称（MENAME） | UEG123 | 本端规划 |  |

#### 操作步骤

1. 登录UEG OMPortal，选择“应用管理 > MML”。
2. 进入“MML命令行-UEG”窗口。
3. 修改网元名称。

   ```
   MOD ME: MEID=20, MELN="UEGABC", MENAME="UEG123";
   ```
4. 修改MAE-VNF LCM/U2020 VNF LCM中的VNFD模板。
   1. 登录MAE-VNF LCM/U2020 VNF LCM，在MAE主界面的“应用”区域，单击“VNF-LCM”，进入MAE-VNF LCM主界面。在主菜单中选择“VNF生命周期管理 > VNF总览 ”。
   2. 在“VNF总览”页面中，单击VNF“操作”列的，手动更新VNFD。
   3. 在参数输入区域修改VNFD参数，例如“VNF\_Name”。
   4. 单击“确定”。
   5. 在弹出的高危提示对话框中，勾选“我已明确该操作的风险。”，单击“确定”。
