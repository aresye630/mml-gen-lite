## 操作场景

网络同时部署主用备用两台UEG。当主用UEG故障或者主用UEG通信链路故障的时候通过备份tunnel，将静态地址用户的下行数据备份到备用UEG上。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-020807 静态地址用户路由冗余。
* 已通过初始配置完成主备LoopBack接口的路由互通配置。
* 静态地址用户路由冗余特性开启和关闭前都要确保APN下无使用静态路由冗余功能的用户。
* 风筝S场景下，本特性与UNC配合使用生效，请参考UNC中的**WSFD-107021 静态地址用户路由冗余**。

## 操作步骤

1. 配置主用UEG静态地址用户路由冗余功能。
   1. 如果用户为静态IP地址用户或RADIUS分配地址用户，执行以下配置。

      1. 配置EXTERNAL类型地址池。

         **ADD POOL**

         * 主备UPF是针对地址池发布的路由优先级而定的，地址池发布的路由优先级高，所在的UPF就是主UPF。
         * 当使能上行转发功能，且需要具备UE互访能力时，需在主UPF上将MASTERFLAG配置为ENABLE。
      2. 配置静态地址池的地址段。
         * 配置IPV4地址段。

           **ADD SECTION**
         * 配置IPV6地址段。

           **ADD SECTION**

         * 静态地址池下需要配置地址段，一个静态地址池最多可以配置64个地址段。
         * 配置地址池后，必须配置地址段。如果不配置地址段，将导致用户激活失败。
         * 静态地址池在配置时，建议尽量使用完整的网段地址。
      3. 配置地址池组。

         **ADD POOLGROUP**
      4. 将地址池绑定地址池组。

         **ADD POOLBINDGROUP**
      5. 配置APN名称。

         **ADD APN**
      6. 配置地址池组与APN的映射关系。

         **ADD POOLGRPMAP**
   2. 配置冗余备份重定向IP，将业务流重定向到GRE Tunnel。

      **ADD REDUNDRDTIP**
   3. 配置LoopBack接口。

      **ADD INTERFACE**
   4. 将LoopBack接口绑定VPN实例。Loopback接口和Tunnel接口绑定的VPN实例不同，完成物理和业务上的划分。

      **ADD IPBINDVPN**
   5. 配置GRE Tunnel接口。

      **ADD INTERFACE**

      针对IPv4生效，MTU配置原则：封装GRE隧道出外联口不会再次分片。
   6. 配置备份GRE Tunnel。

      **ADD GRETUNNEL**
   7. 将Tunnel接口绑定VPN实例。

      **ADD IPBINDVPN**
   8. 配置逻辑接口的IP地址。

      * 配置IPV4地址。

        **ADD IFIPV4ADDRESS**
      * 配置IPV6地址。

        **SET IFIPV6ENABLE**

        针对IPv6生效，MTU配置原则：封装GRE隧道出外联口不会再次分片。

        **ADD IFIPV6ADDRESS**
   9. 配置IPv4静态路由。

      **ADD SRROUTE**
   10. 配置IPv6静态路由。

       **ADD SRROUTE6**
   11. （可选）配置下行缺省低优先级静态地址用户网段路由入冗余GRE隧道。

       **ADD SRROUTE**

       **ADD SRROUTE6**
   12. 主备LoopBack接口的路由需要打通，当使用OSPF路由时，可以使用**ADD OSPFINTERFACE**或**ADD OSPFNETWORK**命令打通路由，静态路由或BGP请按照对应配置增加，具体路由方式对应的配置命令可以参见“初始配置”中的“组网路由配置”。

       **ADD OSPFINTERFACE**
   13. 对于N6口路由，要检查路由发布优先级，主UPF优先级要高于备UPF优先级。

       **MOD OSPFIMPORTROUTE**

       **MOD IMPORTROUTE**
   14. 配置使能静态地址用户路由冗余功能。

       **SET REDUNDUSER**
2. 配置备用UEG静态地址用户路由冗余功能。
   1. 重复主用UEG配置1。

      主备UEG的VPN实例配置可以一致也可以不一致，因为主备UEG的地址池完全相同，因此可以绑定相同的VPN实例；同时，主备UEG是两个设备，两者配置互不影响，也可配置为不同的VPN。

      下行缺省低优先级静态地址用户网段路由入冗余GRE隧道仅在主用UEG配置。
   2. 配置使能IPv4/IPv6上行报文隧道转发功能。

      **SET APNREDUNDUPSW**

      使能IPv4/IPv6上行报文隧道转发功能仅在备UPF上配置。

## 任务示例

任务描述

配置主用UEG和备用UEG的静态地址用户路由冗余功能，UEG上规划IPv4和IPv6两个静态地址池。

脚本

1. 配置主用UEG的静态地址用户路由冗余功能，静态地址段分为IPv4和IPv6两类。

   1. 配置地址池信息。

      ```
      ADD POOL: POOLNAME="pool1", POOLTYPE=EXTERNAL, IPVERSION=IPV4, HASVPN=ENABLE, VPNINSTANCE="vpn1", REDUNDFUNC=ENABLE;
      ```

      ```
      ADD POOL: POOLNAME="pool2", POOLTYPE=EXTERNAL, IPVERSION=IPV6, HASVPN=ENABLE, VPNINSTANCE="vpn1", REDUNDFUNC=ENABLE;
      ```

      ```
      ADD SECTION: POOLNAME="pool1", SECTIONNUM=1, IPVERSION=IPV4, V4STARTIP="10.1.1.0", V4ENDIP="10.1.1.225";
      ```

      ```
      ADD SECTION: POOLNAME="pool2", SECTIONNUM=2, IPVERSION=IPV6, V6PREFIXSTART="fc00:1::1", V6PREFIXEND="fc00:1::1111", V6PREFIXLENGTH=64;
      ```

      ```
      ADD POOLGROUP: POOLGRPNAME="poolgroup1", IPV4ALLOCPRIALG=ENABLE;
      ```

      ```
      ADD POOLBINDGROUP:POOLGROUPNAME="poolgroup1", POOLNAME="pool1";
      ```

      ```
      ADD POOLBINDGROUP:POOLGROUPNAME="poolgroup1", POOLNAME="pool2";
      ```

      ```
      ADD APN: APN="test", HASVPN=ENABLE, VPNINSTANCE="vpn1";
      ```

      ```
      ADD POOLGRPMAP: MAPPINGNAME="mapping1", APN="test", POOLGROUPNAME="poolgroup1";
      ```
   2. 配置冗余备份重定向IP。

      ```
      ADD REDUNDRDTIP: IPVERSION=IPv4, IPV4ADDRESS="192.168.0.1";
      ```

      ```
      ADD REDUNDRDTIP: IPVERSION=IPv6, IPV6ADDRESS="fc00:3::1";
      ```
   3. 配置loopBack接口。

      ```
      ADD INTERFACE: IFNAME="LoopBack1", IFADMINSTATUS=up;
      ```

      ```
      ADD IPBINDVPN: IFNAME="LoopBack1", VRFNAME="vpn2";
      ```
