## 操作场景

当MPF通过API GW对APP开放网络能力，APP通过调用API接口访问MPF内部服务时，需要配置本页面相关功能。

适用于MPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-023502 支持能力开放框架特性概述。
* 虚机场景：完成配置Mp1接口数据。
* 已完成加载License。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET RATELIMIT** | 流控类型（RATELIMIT\_TYPE） | GLOBAL | 本端规划 | 配置全局API GW访问次数控制。 |
|  | 每秒请求限制（SECOND） | 5000 | 本端规划 | 控制APP单位时间内对API GW的访问频率。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. **可选：**配置限流策略，控制APP单位时间内对API GW的访问频率。

   **SET RATELIMIT**

## 任务示例

任务描述

配置限流策略。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5APIG01",SWITCH=ENABLE;
```

//配置全局API限流策略，控制APP单位时间内对API GW的访问频率。

```
SET RATELIMIT: RATELIMIT_TYPE=GLOBAL, SECOND=5000;
```
