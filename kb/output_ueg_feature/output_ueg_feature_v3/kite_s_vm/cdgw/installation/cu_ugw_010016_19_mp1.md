# 配置Mp1接口数据

* 操作场景
* 必备事项

## 操作场景

当MPF（UEG）与APP对接，APP通过调用API接口访问MPF内部服务时，需要配置本页面。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
* 请了解UEG各类接口的类型及命名规范，具体内容请参见逻辑接口介绍（MPF）。
* APP已完成相关配置。
* MPF APIGW、APP各自的CA证书和设备证书需要客户提前申请。
* MPF APIGW与内部服务之间认证的CA证书和设备证书操作参考加载网元内服务间证书。

数据

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

## 操作步骤

1. 上传证书文件。
   1. 登录OM Portal。
   2. 选择“安全 > 证书管理 > 证书与证书集管理”，单击“上传证书”，分别上传CA证书和设备证书文件。
   3. （可选）如果存在CA证书对应的证书吊销列表（CRL文件），则根据需要上传CRL文件。

      选择“安全 > 证书管理 > 上传证书吊销列表”，单击“上传证书吊销列表”，上传CRL文件。

      CA证书与CRL文件一一对应，如果存在多个CA证书，则需要分别上传其对应的CRL文件。
2. 关联证书业务场景。
   1. 选择“安全 > 证书管理 > 证书应用场景关联”，在证书场景列表中选择证书场景，单击“关联证书”。
   2. 选择需要与该场景关联的证书，比如设备证书场景则选择对应的设备证书进行关联，CA证书场景则选择对应的CA证书和CRL文件进行关联。

      Mp1接口证书关联场景名称为“API网关MP1设备证书”和“API网关MP1接口CA证书”。

      CA证书与CRL文件一一对应。当一个证书场景关联了多个CA证书时，如果需要启用CRL功能，那么还需要一一关联这些CA证书所对应的CRL文件。
3. 进入“MML命令行-UEG”窗口。
4. 执行**DSP APPFHEALTH**命令，查询MPF下各服务的健康状态。

   ```
   DSP APPFHEALTH:;
   RETCODE = 0  操作成功

   appf服务健康状态
   ----------------
   服务名  状态   
   apigw   Normal  
   asr     Normal  
   etcd    Normal  
   (结果个数 = 3)

   ---    END
   ```

   * 如果服务状态都为“Normal”，则表示MPF服务正常，请执行5。
   * 如果服务状态存在“Abnormal”，则表示MPF服务不可用，请联系华为技术支持处理。
5. 配置Mp1逻辑接口所属的VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE ="VRF_Mp1";
   ```

   逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
6. 配置Mp1逻辑接口。

   ```
   ADD MPFLOGICINF: NAME="capif1/0/0", IPVERSION=IPV4, IPV4ADDRESS="10.1.7.1", VPNINSTANCE="VRF_Mp1";
   ```

   * **ADD MPFLOGICINF**命令中“NAME”仅支持配置为“capif1/0/0” 。
   * Mp1接口的默认端口号为8443。
7. 配置Mp1反向代理功能，完成MPF作为服务端接收内部服务的通知请求，作为客户端将通知消息转发给APP。
   1. 打开本特性的License配置开关。

      ```
      SET LICENSESWITCH:LICITEM="LKV3G5APIG01",SWITCH=ENABLE;
      ```
   2. 配置MPF APIGW与内部服务之间采用的TLS参数。

      ```
      ADD MEPTLSPARA: TLSPARANAME="tls-inner", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=INNER_DEV_CERT_SCENE, CACERTSCENE=INNER_CA_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1;
      ```
   3. 配置MPF APIGW作为客户端与APP之间采用的TLS参数。

      ```
      ADD MEPTLSPARA: TLSPARANAME="tls02-mp1client1", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=MP1_DEV_CERT_SCENE, CACERTSCENE=MP1_CA_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1;
      ```
   4. 配置MPF APIGW作为客户端时，APIGW与服务端的通信参数。推荐采用通信参数默认值。

      ```
      ADD MEPCLIENTCOMMPARA: PARANAME="DefaultClientPara", CONNTIMEOUT=60, SENDREQTIMEOUT=60, WAITRSPTIMEOUT=60;
      ```
   5. 配置MPF APIGW客户端，其中客户端IP地址为Mp1接口IP地址。

      ```
      ADD MEPHTTPCLIENTGRP: GROUPNAME="clientgrp01";
      ADD MEPHTTPCLIENT: CLIENTNAME="mp1-notifyMES", MEPHTTPCLIENTGRP="clientgrp01", CLIENTTYPE=TO_CONNECT_EXTERNAL_NE, IPV4="10.1.7.1", TLSFLG=ENABLE, TLSPARANAME="tls02-mp1client1", CLIENTCOMMPARANAME="DefaultClientPara", PEERSERVICETAG=MP1SERVICE;
      ```
   6. 配置MPF APIGW作为服务端时，APIGW与客户端的通信参数。推荐采用通信参数默认值。

      ```
      ADD MEPSERVERCOMMPARA: PARANAME="DefaultServerPara", WAITREQHEADERTIMEOUT=60, WAITREQBODYTIMEOUT=60, SENDRSPTIMEOUT=60, KEEPALIVETIMEOUT=75, KEEPALIVEMAXREQNUM=1000;
      ```
   7. 配置MPF APIGW服务端。

      ```
      ADD MEPHTTPSERVERGRP: GROUPNAME="servergrp01";
      ADD MEPHTTPSERVER: SERVERNAME="mp1-notifyMES", MEPHTTPSERVERGRP="servergrp01", SERVERTYPE=FOR_INTERNAL_NOTIFY_MES,  TLSFLG=ENABLE, TLSPARANAME="tls-inner", ,SERVERCOMMPARANAME="DefaultServerPara";
      ```
   8. 配置反向代理，通过MPF的APIGW完成APP与MPF内部服务互通。

      ```
      ADD MEPREVERSEPROXY: PROXYNAME="proxy-notifyMES2APP", MEPHTTPSERVERGRP="servergrp01", MEPHTTPCLIENTGRP="clientgrp01";
      ```
8. **可选：**配置Mp1反向代理功能，在APP访问MPF时，完成MPF作为服务端接收APP注册请求，作为客户端将消息转发给内部服务。在APP互访场景中，完成MPF作为服务端接收APP1访问APP2的请求，然后作为客户端将请求转发给APP2。如果不存在APP互访场景，无需进行本配置。
   1. 配置MPF作为客户端与APP之间采用的TLS参数。

      ```
      ADD MEPTLSPARA: TLSPARANAME="tls02-mp1client2", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=MP1_DEV_CERT_SCENE, CACERTSCENE=MP1_CA_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1, CONFIRM=Y;
      ```
   2. 配置MPF APIGW作为服务端与APP之间采用的TLS参数。

      ```
      ADD MEPTLSPARA: TLSPARANAME="tls03-mp1server2", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=MP1_DEV_CERT_SCENE, CACERTSCENE=MP1_CA_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1;
      ```
   3. 配置MPF APIGW客户端与外部APP互通，其中客户端IP地址为Mp1接口IP地址。

      ```
      ADD MEPHTTPCLIENTGRP: GROUPNAME="clientgrp03";
      ADD MEPHTTPCLIENT: CLIENTNAME="mp1-extNE", MEPHTTPCLIENTGRP="clientgrp03", CLIENTTYPE=TO_CONNECT_EXTERNAL_NE, IPV4="10.1.7.1", TLSFLG=ENABLE, TLSPARANAME="tls02-mp1client2", CLIENTCOMMPARANAME="DefaultClientPara", PEERSERVICETAG=MP1SERVICE;
      ```
   4. 配置MPF APIGW客户端与内部服务互通。

      ```
      ADD MEPHTTPCLIENT: CLIENTNAME="mp1-innerMES", MEPHTTPCLIENTGRP="clientgrp03", CLIENTTYPE=TO_CONNECT_INTERNAL_MES, TLSFLG=ENABLE, TLSPARANAME="tls-inner", CLIENTCOMMPARANAME="DefaultClientPara", PEERSERVICETAG=MEPSERVICE;
      ```
   5. 配置MPF APIGW服务端与外部APP互通，其中服务端IP地址为Mp1接口IP地址。

      ```
      ADD MEPHTTPSERVERGRP: GROUPNAME="servergrp03";
      ADD MEPHTTPSERVER: SERVERNAME="mp1-extNE", MEPHTTPSERVERGRP="servergrp03", SERVERTYPE=FOR_EXTERNAL_NE, IPV4="10.1.7.1", PORT=8443,TLSFLG=ENABLE, TLSPARANAME="tls03-mp1server2", ,SERVERCOMMPARANAME="DefaultServerPara";
      ```
   6. 配置反向代理，通过MPF的APIGW完成APP与MPF内部服务、其他APP之间交互。

      ```
      ADD MEPREVERSEPROXY: PROXYNAME="proxy-APP2MES-APP2APP", MEPHTTPSERVERGRP="servergrp03", MEPHTTPCLIENTGRP="clientgrp03";
      ```

## 验证方法

1. 执行**NGPING**命令，查看Mp1接口IP与APP的Mp1接口IP能否互通。

   ```
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_Mp1", SRCIPV4ADDR="10.1.7.1", DSTIPV4ADDR="APP的Mp1接口IP";
   ```

   * 如果收到APP的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   * 如果连续出现timeout，表明连接异常，请执行2。
2. 执行**PING**命令，查看Mp1对应的外联口IP与APP的外联口IP能否互通。

   ```
   PING:IPVERSION=IPv4,VPNNAME="VRF_Mp1",SOURCEIPV4ADDRESS="Mp1对应的外联口IP",DESTIPV4ADDRESS="APP的外联口IP";
   ```

   * 如果收到APP的响应且响应报文中有成功收发包的个数，请执行3。
   * 如果连续出现timeout，表明连接异常，请执行4。
3. 检查直连路由器上是否存在到Mp1逻辑接口IP的路由，下一跳是外联口IP。
   * 是，请执行5。
   * 否，请联系路由器工程师，增加相关路由后重新调测。
4. 请参考配置VNF侧IP路由数据（无NP卡）进行调测，修正配置后请重新执行1。
   * 如果收到APP的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   * 如果连续出现timeout，请执行5。
5. 收集信息并寻求技术支持。
   1. 在“MML命令行-UEG”窗口上执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
