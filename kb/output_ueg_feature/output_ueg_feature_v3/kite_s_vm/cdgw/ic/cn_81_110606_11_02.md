# 激活语音PCF/PCRF故障Bypass

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

在UEG上激活语音PCF/PCRF故障Bypass功能，降低PCF/PCRF双故障对用户业务的影响。

适用于PGW-U、UPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-021410 语音PCF/PCRF故障Bypass。
* 依赖的特性已完成配置，相关特性参见与其他特性的交互。
* 已完成APN、User Profile、User Profile group创建，以及三者之间的关系绑定。
* 完成**加载license**，对应的License项见License支持。

数据

* 下面数据表格中的URRID、USAGERPTMODE、PCCPOLICYGRPNM、 RULENAME、POLICYTYPE、POLICYNAME、USERPROFILENAME要与SMF保持一致。
* 语音承载的静态PCC规则中的RG与PCF下发的动态规则中的RG相同。
* PCF下发的用于创建语音专有QoS Flow/专有承载的规则的优先级高于本地配置的用于创建语音专有QoS Flow/专有承载的规则；本地配置的用于创建语音专有QoS Flow/专有承载的规则优先级高于PCF下发的any to any的动态规则和本地配置的any to any的预定义规则。

## 操作步骤

1. 配置语音缺省QoS Flow/缺省承载静态PCC策略。配置三四层过滤条件。

   仅当局点未配置语音缺省QoS Flow/缺省承载静态PCC策略时，执行本步骤。否则，跳过本步骤。

   1. 配置三四层过滤条件。

      **ADD FILTER**

      **ADD FILTERIPV6**
   2. 配置流过滤器。

      **ADD FLOWFILTER**

      流过滤器必须至少绑定一个filter或一个l7filter，否则所有报文都匹配不上该流过滤器。
   3. 配置三四层过滤条件与流过滤器的绑定关系。

      **ADD FLTBINDFLOWF**
   4. 增加使用量上报规则信息。

      **ADD URR**
   5. 配置上行和下行业务对应的URR。

      **ADD URRGROUP**
   6. 配置PCC策略组。

      **ADD PCCPOLICYGRP**
   7. 配置规则。

      **ADD RULE**
   8. 创建UserProfile。

      如果已配置了APN ims使用的用户模板，则跳过本步骤。

      **ADD USERPROFILE**
   9. 将已配置的rule绑定到UserProfile。

      **ADD RULEBINDING**
   10. 将新配置的Filter跟UserProfile置为生效。

       **SET REFRESHSRV**
2. 配置语音专有QoS Flow/专有承载静态PCC策略。
   1. 配置三四层过滤条件。

      **ADD FILTER**

      **ADD FILTERIPV6**
   2. 配置流过滤器。

      **ADD FLOWFILTER**
   3. 配置三四层过滤条件与流过滤器的绑定关系。

      **ADD FLTBINDFLOWF**
   4. 将新配置的Filter置为生效。

      **SET REFRESHSRV**
   5. 增加使用量上报规则信息。

      **ADD URR**
   6. 增加使用量上报规则组。

      **ADD URRGROUP**
   7. 配置静态PCC策略的QoS参数。

      **ADD QOSPROP**
   8. 配置PCC策略组。

      **ADD PCCPOLICYGRP**
   9. 配置业务策略规则。

      **ADD RULE**
   10. 将已配置的Rule绑定到UserProfile。

       **ADD RULEBINDING**
   11. 将新配置的Filter和UserProfile置为生效。

       **SET REFRESHSRV**
3. 配置PCF bypas条件。

   **SET UPSOFTPARA**

   **SET IMSBYPASS**

## 任务示例

任务描述

激活语音PCF/PCRF故障Bypass功能。

任务一：没有配置语音缺省QoS Flow/缺省承载静态PCC策略，在UPF上激活语音PCF故障bypass功能。

任务二：已配置语音缺省QoS Flow/缺省承载静态PCC策略，在当前配置基础上激活语音PCF故障bypass功能。

脚本

* **任务一：没有配置语音缺省QoS Flow/缺省承载静态PCC策略，在UPF上激活语音PCF故障bypass功能。**
  1. 配置语音缺省QoS Flow/缺省承载静态PCC策略。

     //配置流过滤器和三四层过滤条件。

     ```
     ADD FILTER: FILTERNAME="filter_test", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
     ADD FILTERIPV6: FILTERNAME="filter_testV6", L34PROTTYPEV6=STRING, L34PROTOCOL=ANY;
     ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_test";
     ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_test",FILTERNAME="filter_test";
     ADD FLTBINDFLOWF: FLOWFILTERNAME="flowfilter_test", FILTERNAME="filter_testV6";
     ```

     //增加使用量上报规则信息。

     ```
     ADD URR: URRNAME="urr_signaling_offline", URRID=2005, USAGERPTMODE=OFFLINE, OFFMETERINGTYPE=VOLUME, RG=20;
     ADD URR: URRNAME="urr_signaling_online", URRID=2015, USAGERPTMODE=ONLINE, ONLMETERINGTYPE=VOLUME, DFTQUOTAPARA=Byte, RG=25;
     ```
