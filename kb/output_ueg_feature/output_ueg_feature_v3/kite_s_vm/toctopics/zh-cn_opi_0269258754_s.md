## 操作场景

本操作指导介绍在运行网络中激活基于信令面的数据传输特性的操作过程。

适用于SGW-U。

## 必备事项

前提条件

* 请仔细阅读GWFD-026105 基于信令面的数据传输。
* 已开启NB-IoT基本接入功能（详见激活NB-IoT终端标准接入）。
* 完成加载License（本特性完整的功能需要同时在用户面和控制面开启License，如果有需求，请联系华为技术支持工程师处理）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD POOL** | APN名称（APN） | apncp | 本端规划 | - |
| **ADD LOGICINF** | 逻辑接口名称（NAME） | s11-uif1/1/0 | 本端规划 | - |
|  | 逻辑接口的IP版本（IPVERSION） | IPv4 | 全网规划 |  |
|  | 逻辑接口的IPv4地址1（IPV4ADDRESS1） | 10.2.151.15 | 本端规划 | S11-U接口的地址。 |
|  | 逻辑接口的IPv4掩码1（IPV4MASK1） | 255.255.255.255 | 本端规划 | - |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置APN。

   **ADD POOL**
3. 配置S11-U接口。

   **ADD LOGICINF**

## 任务示例

任务描述

开启基于信令面的数据传输功能。在本例中，使用的S11-U接口地址类型为IPv4，地址为10.2.151.15，掩码为255.255.255.255。

脚本

//打开本特性的License开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5DOVN01", SWITCH=ENABLE;
```

//配置APN。

```
ADD APN: APN="apncp";
```

//配置信令面数据传输使用的S11-U接口。

```
ADD LOGICINF: NAME="s11-uif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.2.151.15", IPV4MASK1="255.255.255.255";
```
