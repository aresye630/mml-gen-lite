## 操作步骤

1. 配置LoopBack接口。

   **ADD INTERFACE**

   **ADD IPBINDVPN**

   **ADD IFIPV4ADDRESS**
2. 配置GRE Tunnel。

   **ADD INTERFACE**

   **ADD GRETUNNEL**

   **ADD IPBINDVPN**

   **ADD IFIPV4ADDRESS**
3. 配置发布LoopBack路由。

   **ADD NETWORKROUTE**
4. 配置OSPF。

   **ADD OSPF**

   **ADD OSPFAREA**

   **ADD OSPFINTERFACE**

   **ADD OSPFIMPORTROUTE**

   **ADD OSPFDEFAULTROUTE**

## 任务示例

任务描述

园区外UPF（UDG或UEG）与园区内UPF（UEG）之间配置OSPFv2 over GREv4隧道。

脚本

* **园区外UPF（UDG或UEG）配置**

  //配置LoopBack接口

  ```
  ADD INTERFACE: IFNAME="LoopBack88", IFADMINSTATUS=up; 
  ADD IPBINDVPN: IFNAME="LoopBack88", VRFNAME="VRF_DC12_N9"; 
  ADD IFIPV4ADDRESS: IFNAME="LoopBack88", IFIPADDR="172.16.12.8", SUBNETMASK="255.255.255.255";
  ```

  //配置GRE Tunnel

  ```
  ADD INTERFACE: IFNAME="Tunnel66", IFMTU=1500; 
  ADD GRETUNNEL: TNLNAME="Tunnel66", SRCTYPE=if_name, DSTIPADDR="172.16.11.8", TNLTYPE=gre, SRCIFNAME="LoopBack88", DSTVPNNAME="VRF_DC11_N9", KEEPALVEN=TRUE; 
  ADD IPBINDVPN: IFNAME="Tunnel66", VRFNAME="VRF_DC12_N6_local_001"; 
  ADD IFIPV4ADDRESS: IFNAME="Tunnel66", IFIPADDR="172.16.1.1", SUBNETMASK="255.255.255.252";
  ```

  //配置发布LoopBack路由

  ```
  ADD NETWORKROUTE: VRFNAME="VRF_DC12_N9", AFTYPE=ipv4uni, NETWORKADDRESS="172.16.12.8", MASKLEN=32;
  ```

  //配置OSPF

  ```
  ADD OSPF:PROCID=66, VRFNAME="VRF_DC12_N6_local_001", SILENTALLFLAG=FALSE, BFDALLINTFFLG=FALSE, BFDRXCFGFLAG=FALSE, BFDTXCFGFLAG=FALSE, RFC1583COMPFLG=TRUE, BANDWIDTHREF=100, RXMTLIMITENABLE=FALSE, OPAQCAPFLG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500, LSAARRINTVFLAG=FALSE, LSAORIGINTV=5, LSAORIGMAXINTV=5000, LSAORIGSTARINTV=500, LSAORIGHLDINTV=1000, LSAORIGINSTFLAG=FALSE, VPNINSCAPSIMFLG=TRUE, STUBROUFLG=NoConfig, SAFESYNCFLG=FALSE, SHAMHELLOFLAG=FALSE, ROUTAGFLAG=FALSE, RTTAGDISFLAG=FALSE, ECAROUTEFLAG=FALSE, DOMAINNULLFLAG=FALSE, SCHEMAROUID="172.18.1.1", SUPPREACH=FALSE, SCHEMABFDDETMUL=3, SPFCONSERVFLAG=FALSE, MPLSLDPAUTOCFG=None, VIRTUALSYSFLAG=FALSE, FRRBINDINGFLAG=FALSE;
  ADD OSPFAREA:PROCID=66, AREAID="0.0.0.0", AREATYPE=Normal, MAXCOSTFLAG=FALSE;
  ADD OSPFINTERFACE:PROCID=66, AREAID="0.0.0.0", IFNAME="Tunnel66", NETWORKTYPE=p2p, HOLDDOWNITVL=10, FRRBLOCKFLAG=FALSE, FRRBINDINGFLAG=FALSE, TIMERCONSERFLAG=FALSE;
  ADD OSPFIMPORTROUTE:PROCID=66, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
  ```
