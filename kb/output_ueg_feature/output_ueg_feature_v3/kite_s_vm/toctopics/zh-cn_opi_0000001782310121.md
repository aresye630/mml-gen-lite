# 配置NAT基本功能License开关

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

本操作指导您打开NAT基本功能的License开关。

## 必备事项

前提条件

已登录OM Portal。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（ LICITEM） | LKV4NATBSS01 | 本端规划 | 打开NAT基本功能License开关。 |
|  | 开关（SWITCH） | ENABLE | 本端规划 |  |

## 操作步骤

1. 打开NAT基本功能的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

配置NAT基本功能License开关。

脚本

打开NAT基本功能的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV4NATBSS01", SWITCH=ENABLE;
```
