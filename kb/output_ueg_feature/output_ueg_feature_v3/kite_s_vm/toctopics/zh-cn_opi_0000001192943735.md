## 操作场景

UPF下沉，DN-AAA部署到企业或园区，SMF与DN-AAA之间不能直接互通，需要UPF转发SMF与DN-AAA之间二次鉴权的消息。

适用于UPF。

## 必备事项

前提条件

* 请仔细阅读终端二次鉴权特性概述。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD NETWORKINSTVPNMAP** | 网络实例名称（NETWORKINSTANCE） | net1 | 本端规划 | 网络实例标识。客户进行网络部署时自行规划，与SMF端规划的网络实例保持一致。  取值范围：字符串类型，输入长度范围为1～100，单位是字节。由“\_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 |
|  | VPN实例名（VPNINSTANCE） | VPN2auto | 本端规划 | 用于指定IPv4 VPN实例名。本特性中该参数取值是与DN-AAA共同规划的VPN实例名称。  取值范围：字符串类型，输入长度范围为1～31。 |
|  | IPv6 VPN实例名（VPNINSTANCEIPV6） | vnp1 | 本端规划 | 用于指定IPv6 VPN实例名。本特性中该参数取值是与DN-AAA共同规划的VPN实例名称。  取值范围：字符串类型，输入长度范围为1～31。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口
2. 添加网络实例。用于规划UPF与DN-AAA之间的VPN。

   **ADD NETWORKINSTVPNMAP**

## 验证方法

具体步骤请参见调测终端二次鉴权。

## 任务示例

任务描述

配置网络实例，用于打通二次鉴权消息转接通道。

脚本

//添加一个新的网络实例。

```
ADD NETWORKINSTVPNMAP: NETWORKINSTANCE="net1", HASVPN=ENABLE, VPNINSTANCE="VPN2auto", HASVPNIPV6=DISABLE;
```
