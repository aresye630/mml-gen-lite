# 一键式下线NAT服务（UPF）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要NAT服务或NAT服务一键式动态上线失败时，可以单独卸载NAT pod，从而一键式下线NAT服务。

## 必备事项

前提条件

* LCM版本不低于V100R024C10。
* 已经完成网络设计，已规划下线NAT pod的类型和数量。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| 服务一键式部署  OPR ONECLICKDEPLOY | 操作类型（OPRTYPE） | INDEPSTACKDISABLE | 固定取值 |
|  | 节点类型列表（NODETYPELIST） | 样例：PBU\_E-N\_C6\_ARM:0  VM类型:下线后的VM个数。   * X86的VM类型：PBU\_E-N。 * ARM的VM类型：PBU\_E-N\_C6、PBU\_E-N\_C6\_ARM、PBU\_E-N\_C6\_M、PBU\_E-N\_C6\_M\_ARM。 | 本端规划 |
|  | 堆栈名称  （STACKNAME） | ueg-nat-***xx*** | 本端规划 |

## 操作步骤

1. 登录UEG OM Portal。
2. 执行**SET FWSOFTPARA**命令，开启Service Fabric的**DWORD\_521**软参，即系统故障时不触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=1;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为1。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为1，请执行后续步骤。如果软参值不是1，请联系华为技术支持。
3. 执行**DSP VNFSTACKNAMES**命令，查询出前缀为“ueg-nat”的NAT堆栈名称。
4. 执行**OPR ONECLICKDEPLOY**命令，一键式下线NAT的VM和Pod。以PBU\_E-N\_C6\_ARM虚拟机为例，其他虚拟机请替换为配套pod。

   ```
   OPR ONECLICKDEPLOY: OPRTYPE=INDEPSTACKDISABLE, NODETYPELIST="PBU_E-N_C6_ARM:0", STACKNAME="ueg-nat-xx";
   ```
5. 执行**DSP ONECLICKDEPLOYHIST**命令，确认一键式下线NAT服务的回显为“处理结果=处理成功”。
6. 执行命令，确认POD已下线。

   **X86场景：**

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natom-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natgcp-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natssg-pod";//以natssg-pod为例，natssgm-pod类似
   ```

   **ARM场景：**

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natom-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natctrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="natgcpssgc6-pod";//以natgcpssgc6-pod为例，natgcpssgc6m-pod类似
   ```

   回显为“查询Pod不存在”。
7. 执行**SET FWSOFTPARA**命令，关闭Service Fabric的**DWORD\_521**软参，即系统故障时触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=0;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为0。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为0，请执行后续步骤。如果软参值不是0，请联系华为技术支持。
