# 激活源地址的NAT44转换

* 必备事项

* 任务示例

## 操作场景

当运营商给用户分配了私网IPv4地址，用户需要访问公网Internet业务时，需要激活源地址的NAT44特性。

## 必备事项

前提条件

* 已通过**ADD APN**完成APN的相关配置。
* 已登录OM Portal。
* 已完成配置NAT基本功能License开关。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ip pool** | pool-name | testpool | 本端规划 | 配置地址池的名称。 |
|  | **mode** | pba | 全网规划 | 配置NAT转换地址池的模式，有三种：No-PAT、NAPT和PBA。 |
| **vpn-instance** | vpn-instance-name | testvpn1 | 全网规划 | 配置VPN实例名称，该VPN是数据转发相关的VPN。 |
| **section** | section-num | 0 | 本端规划 | 配置地址段的编号。 |
|  | start-ip-address | 10.10.10.2 | 全网规划 | 配置地址段的起始IPv4地址。 |
|  | end-ip-address | 10.10.10.254 | 全网规划 | 配置地址段的结束IPv4地址。 |
| **nap-filter** | nap-filter-name | testnapfilter | 本端规划 | 配置过滤器的名称。 |
|  | l34-protocol-value | tcp | 全网规划 | 配置三四层协议类型。 |
| **nap-filter-group** | nap-filter-group-name | testfiltergroupname | 本端规划 | 配置过滤器组名称。 |
|  | nap-filter-name | testnapfilter | 本端规划 | 配置过滤器名称。 |
| **nat-policy** | nat-policy-name | testpolicy | 本端规划 | 配置策略的名称。 |
|  | nap-filter-group-name | testfiltergroupname | 本端规划 | 配置策略的过滤规则组名称。 |
|  | vpn-instance-name | srvvpn | 全网规划 | 配置生效的VPN，该VPN是用户激活的VPN。 |
|  | **source-nat nat-address-pool** *nat-address-pool-name* | testpool | 本端规划 | 针对IPv4的报文做源NAT44转换，配置NAT转换使用的IPv4源地址池。 |
|  | priority-value | 5 | 本端规划 | 配置该策略的优先级。 |

## 操作步骤

1. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
2. 配置NAT转换地址池。

   1. 进入系统视图。

      **sy****stem-view**
   2. 配置NAT地址池，有三种模式：No-PAT、NAPT和PBA。

      **ip pool**
   3. 配置NAT地址池所属的VPN实例。

      **vpn-instance**
   4. **可选：**配置NAT地址池下pod最大地址个数。

      **pod-max-ip-number**

      * 21.5.0之前版本建议使用**vm-max-ip-number**进行该配置操作。
      * 该配置仅适用于**NAPT**和**PBA**类型地址池。
      * 该配置修改会引起回收/分配地址资源，影响当前业务，建议按照现网规划进行对应配置。
   5. 配置NAT地址池的地址段。

      **section**
   6. 返回系统视图。

      **quit**
3. 配置NAT过滤条件。

   1. 进入nap视图。

      **nap****-view**
   2. 配置三四层NAT过滤条件。

      **nap-filter** *xxx* **l34-protocol** *xxx*
   3. 配置NAT过滤条件组，可绑定已配置的NAT filter。当配置了多个NAT filter时，满足其中一个过滤条件即可。

      **nap-filter-group** *xxx* **nap-filter** *xxx*
   4. 生效NAT过滤条件。

      **nap-refresh-service**
4. 配置NAT策略。

   **nat-policy** *xxx* **nap-filter-group** *xxx* **vpn-instance** *xxx* **action source-nat nat-address-pool** *xxx* **priority** *x*

   此处VPN需要与业务VPN实例名称保持一致。

## 任务示例

任务描述

激活源地址的NAT44转换。

脚本

```
<NAT>system-view
[NAT]ip pool testpool mode pba  //模式也可以选择为NAPT
[NAT-ip-pool-poolname]vpn-instance testvpn1
[NAT-ip-pool-poolname]section 0 10.10.10.2 10.10.10.254
[NAT-ip-pool-poolname]q
[NAT]nap-view
[NAT-nap]nap-filter testnapfilter l34-protocol tcp
[NAT-nap]nap-filter-group testfiltergroupname nap-filter testnapfilter
[NAT-nap]nap-refresh-service
[NAT-nap]nat-policy testpolicy nap-filter-group testfiltergroupname vpn-instance srvvpn action source-nat nat-address-pool testpool priority 5
```
