# 检查License占用情况

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

检查系统License占用情况，在使用率过高情况下，确认过高的原因以及是否需要进行License扩容。

## 必备事项

前提条件

已经登录OM Portal，或者登录MAE并进入Access子系统。

数据

该操作无需准备数据。

## 操作步骤

1. 通过****DSP LICENSERES****命令查看License资源数目以及使用情况。
2. 通过****DSP LICENSEPEAK****命令查看话务高峰内的过载License项目以及剩余可用次数。
