## 操作场景

前提条件

* 请仔细阅读GWFD-030601 GRE跨域转发特性概述。
* 完成**License****加载**（如果有需求，请联系华为技术支持工程师处理）。
* 已完成园区外UPF，园区内UPF整体网络及业务部署。

## 操作步骤

1. 配置LoopBack接口。

   **ADD INTERFACE**

   **ADD IPBINDVPN**

   **SET IFIPV6ENABLE**

   **ADD IFIPV6ADDRESS**
2. 配置GRE Tunnel。

   **ADD INTERFACE**

   **ADD IPBINDVPN**

   **SET IFIPV6ENABLE**

   **ADD GRETUNNEL**
3. 配置OSPF。

   **ADD OSPFV3**

   **ADD OSPFV3AREA**

   **ADD OSPFV3INTERFACE**

   **ADD OSPFV3IMPORTROUTE**

## 任务示例

任务描述

园区外UPF（UDG或UEG）与园区内UPF（UEG）之间配置OSPFv3 over GREv6隧道。

脚本

* **园区外UPF（UDG或UEG）配置**

  //配置LoopBack接口

  ```
  ADD INTERFACE: IFNAME="LoopBack85", IFADMINSTATUS=up, IFDF=FALSE;
  ADD IPBINDVPN: IFNAME="LoopBack85", VRFNAME="VRF_DC12_N9";
  SET IFIPV6ENABLE: IFNAME="LoopBack85", ENABLEFLAG=TRUE;
  ADD IFIPV6ADDRESS: IFNAME="LoopBack85", IPV6ADDRESS="fc00:1:0:0:0:0:0:100", PREFIXLEN=64, ADDRTYPE=global, IDGENTYPE=none;
  ```

  //配置GRE Tunnel

  ```
  ADD INTERFACE: IFNAME="Tunnel85", IFDF=FALSE;
  ADD IPBINDVPN: IFNAME="Tunnel85", VRFNAME="VRF_DC12_N6_local_001";
  SET IFIPV6ENABLE: IFNAME="Tunnel85", ENABLEFLAG=TRUE;
  ADD IFIPV6ADDRESS: IFNAME="Tunnel85", IPV6ADDRESS="fc00:100:0:0:0:0:0:1", PREFIXLEN=64, ADDRTYPE=global, IDGENTYPE=none;
  ADD GRETUNNEL: TNLNAME="Tunnel85", TNLTYPE=gre6, SRCTYPE6=if_name, SRCIFNAME="LoopBack85", DSTIPV6ADDR="fc00:1:0:0:0:0:0:200", KEEPALVEN=FALSE, GREKEYEN=FALSE, CHECKSUMEN=FALSE, STATENABLE=FALSE, REDUNDANCYEN=FALSE;
  ```

  //配置OSPF

  ```
  ADD OSPFV3: PROCID=85, ROUTERID="10.100.100.100", VRFNAME="VRF_DC12_N6_local_001", SILENTALLFLAG=FALSE, BFDALLINTFFLG=FALSE, BFDRXCFGFLAG=FALSE, BFDTXCFGFLAG=FALSE, FRRBINDINGFLAG=FALSE, ROUTAGFLAG=FALSE, RXMTLIMITENABLE=FALSE, VPNINSCAPSIMFLG=TRUE, RTTAGDISFLAG=FALSE, STUBROUFLG=NoConfig, DOMAINNULLFLAG=FALSE, VIRTUALSYSFLAG=TRUE;
  ADD OSPFV3AREA: PROCID=85, AREAID="0.0.0.0", AREATYPE=Normal;
  ADD OSPFV3INTERFACE: PROCID=85, AREAID="0.0.0.0", IFNAME="Tunnel85", MTUENABLE=TRUE, TIMERCONSERFLAG=FALSE, BFDENABLE=FALSE, FRRBINDINGFLAG=FALSE, FRRBLOCKFLAG=FALSE, BFDBLOCK=FALSE, VIRTUALSYSFLAG=FALSE;
  ADD OSPFV3IMPORTROUTE: PROCID=85, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE, INHERITCOSTCFG=FALSE;
  ```
