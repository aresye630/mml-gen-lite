# 卸载NAT服务（UPF）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要NAT服务或NAT服务动态上线失败时，可以单独卸载NAT pod，从而下线NAT服务。

## 必备事项

前提条件

已经完成网络设计，已规划下线NAT pod的类型和数量。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| UEG OM Portal帐户 | IP地址 | 192.168.1.1  操作维护接口IP，即“VNFD模板”中的“MNG\_IP”或“MNG\_IPv6”参数。 | 本端规划 |
|  | 端口号 | 31943 | 本端规划 |
|  | 用户名 | admin | 本端规划 |
|  | 密码 | Changeme\_123 | 本端规划 |

## 操作步骤

1. 执行**SET FWSOFTPARA**命令，开启Service Fabric的**DWORD\_521**软参，即系统故障时不触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=1;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为1。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为1，请执行后续步骤。如果软参值不是1，请联系华为技术支持。
2. 下线NAT堆栈。

   1. 登录MANO（MAE/VNF LCM）业务面客户端。
      1. 在浏览器地址栏中输入以下地址后按回车键，弹出MANO（MAE/VNF LCM）客户端界面。

         **https://MANO（MAE/VNF LCM）业务的IP地址:端口号/**（例如https://10.50.12.104:31943/）
      2. 输入用户名和密码。

         系统默认的用户名和密码是“admin/Changeme\_123”，如果已修改MANO（MAE/VNF LCM）客户端用户名和密码，请使用新设置的用户名和密码登录。
      3. 单击“登录”，在MAE主界面的“应用”区域，单击“VNF LCM”，进入MANO（MAE/VNF LCM）系统界面。
   2. 卸载NAT堆栈。
      1. 选择菜单栏“VNF生命周期管理 >扩缩容管理 > 手动扩缩容”，进入“手动扩缩容”窗口。
      2. 选择待操作的VNF，单击右侧“操作”列的“堆栈上下线”图标。
      3. 在弹出的界面中“操作”选择“下线”，选择需要下线的“堆栈名称”，**不需要勾选**“进行虚拟机扩缩容”。
      4. 单击“下一步”后，在弹出的确认界面点击“确认”，自动跳转到“扩缩容任务”界面，可以查看下线堆栈进度。
3. 执行**SET FWSOFTPARA**命令，关闭Service Fabric的**DWORD\_521**软参，即系统故障时触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=0;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为0。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为0，请执行后续步骤。如果软参值不是0，请联系华为技术支持。
4. 若动态下线NAT服务后，不再上线NAT服务，则需要缩容NAT自身VM，释放VM资源。
