# 配置FRER双发选收

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

工业应用中，存在高可靠性要求的行业应用时需要部署。

## 必备事项

前提条件

* 已完成配置5G LAN基本功能。
* 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。

数据

**如下数据仅为举例，请注意修改成局点规划的数据。**

**表1** 双发选收开关

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET NGDFSRFUNC** | 5G LAN组名称（VNINSTANCE） | 000003e9-460-08-01 | 已配置数据中获取 | 5G LAN组标识，不同5G LAN组的VNINSTANCE取值不能重复。  对于同一个5G LAN组，UDM、SMF和UPF上配置的5G LAN组标识必须一致。 |
|  | 双发选收功能开关（DFSRSWITCH） | ENABLE | 本端规划 | 默认值为DISABLE。  基于5G LAN组粒度配置。 |
| **SET DFSRATTR** | 网元主备标识（NEPRIFLAG） | PRIMARY | 本端规划 | 主备冷备部署时需要配置该参数。此处的主用UPF，是SMF选择的高优先级UPF；备用UPF，是SMF选择的低优先级UPF。   * 主用UPF上需要设置为“PRIMARY”。 * 备用UPF上需要设置为“SECONDARY”。 |
|  | 双发选收结对内用户激活时长（PAIRUEACTTIME） | 30 | 本端规划 | 指定备用UPF上双发选收结对内两个成员（如CPE）激活的最大时间间隔（单位是秒），当激活间隔超过配置的时长时，备用UPF会主动去活先激活的成员。  该参数在“NEPRIFLAG”配置为“SECONDARY”时需要配置。 |

**表2** 双发选收结对数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD DFSRPAIR** | 双发选收结对ID（DFSRPAIRID） | 10 | 本端规划 | 同一UPF内不能重复。  取值范围1~2048。 |
|  | 双发选收模式（DFSRPAIRMODE） | FRER\_PAIR | 本端规划 | * FRER\_SRC\_MAC：基于源MAC的FRER双发选收模式。 * FRER\_PAIR：基于结对的FRER双发选收模式。   与工业冗余协议交换机上配置的双发选收模式一致，此处以“FRER\_PAIR”为例。 |
|  | 结对描述信息（PAIRDESCRIPTION） | pair | 本端规划 | 用于方便了解结对信息。 |
| **ADD DFSRPAIRMEM** | 双发选收结对ID（DFSRPAIRID） | 10 | 已配置数据中获取 | 采用**ADD DFSRPAIR**命令定义的DFSRPAIRID。 |
|  | IMSI（IMSI） | * 460123123456789 * 460123123456788 | 从对端获取 | 单个结对最大配置两个IMSI。 |
| **ADD NGBINDDFSRPAIR** | 5G LAN实例名称（VNINSTANCE） | 000003e9-460-08-01 | 已配置数据中获取 | 采用**ADD NGVNINSTANCE**命令定义的VNINSTANCE。 |
|  | 双发选收结对ID（DFSRPAIRID） | 10 | 已配置数据中获取 | 采用**ADD DFSRPAIR**命令定义的DFSRPAIRID。 |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 为指定5G LAN组开启双发选收开关。

   **SET NGDFSRFUNC**
3. 设置双发选收属性。

   **SET DFSRATTR**
4. 增加双发选收结对。

   **ADD DFSRPAIR**
5. 添加双发选收结对成员。

   **ADD DFSRPAIRMEM**
6. 将双发选收结对绑定到5G LAN组。

   **ADD NGBINDDFSRPAIR**

## 任务示例

任务描述

开启双发选收功能，双发选收模式以“FRER\_PAIR”为例。其他相关数据请参见表1和表2。

双发选收模式采用“FRER\_SRC\_MAC”时，将如下脚本中的“DFSRPAIRMODE”参数值由“FRER\_PAIR”修改为“FRER\_SRC\_MAC”，其他配置不变。

脚本

//在主用UPF上开启本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5LADFSR", SWITCH=ENABLE;
```

//在主用UPF上进行如下配置：

```
SET NGDFSRFUNC: VNINSTANCE="000003e9-460-08-01", DFSRSWITCH=ENABLE;
SET DFSRATTR: NEPRIFLAG=PRIMARY;
ADD DFSRPAIR: DFSRPAIRID=10, DFSRPAIRMODE=FRER_PAIR, PAIRDESCRIPTION="pair";
ADD DFSRPAIRMEM: DFSRPAIRID=10, IMSI="460123123456789";
ADD DFSRPAIRMEM: DFSRPAIRID=10, IMSI="460123123456788";
ADD NGBINDDFSRPAIR: VNINSTANCE="000003e9-460-08-01", DFSRPAIRID=10;
```

//在备用UPF上开启本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5LADFSR", SWITCH=ENABLE;
```

//在备用UPF上进行如下配置：

```
SET NGDFSRFUNC: VNINSTANCE="000003e9-460-08-01", DFSRSWITCH=ENABLE;
SET DFSRATTR: NEPRIFLAG=SECONDARY, PAIRUEACTTIME=30;
ADD DFSRPAIR: DFSRPAIRID=10, DFSRPAIRMODE=FRER_PAIR, PAIRDESCRIPTION="pair";
ADD DFSRPAIRMEM: DFSRPAIRID=10, IMSI="460123123456789";
ADD DFSRPAIRMEM: DFSRPAIRID=10, IMSI="460123123456788";
ADD NGBINDDFSRPAIR: VNINSTANCE="000003e9-460-08-01", DFSRPAIRID=10;
```
