# 配置跟踪匿名化功能和CHR匿名化功能（通过MAE）

## 操作场景

UEG支持通过MAE对所有网元设置跟踪匿名化功能、CHR匿名化功能的启停状态，并配置HMAC密钥。

为保证个人隐私数据的安全性，建议开启该功能。请运营商遵从所在国家的相关法律开启该功能。

## 对系统的影响

* 用户标识在UEG设备上做加密处理。
* 由于MAE上配置的假名化/匿名化功能状态和HMAC密钥对所有网元生效，开启前请联系华为技术支持工程师评估对所有网元的影响。

## 必备事项

前提条件

请仔细阅读个人隐私数据保护。

数据

无。

## 操作步骤

1. 详细操作步骤请参见MAE产品文档的“假名化策略管理”。

   * MAE上假名化/匿名化开关默认开启，建议运营商遵从所在国家的相关法律。
   * 为更好地保护用户个人隐私，请定期更新并妥善保存HMAC密钥，避免被他人获取。密钥的长度建议符合安全要求，提升安全性。
2. 通过MML命令开启报表的假名化功能。

   ****SET RPTENCRYPT****:ENCRYMODE=USER\_DEFINED,ENCRYALGORI=SHA256,PSWDKEY="\*\*\*\*\*",PSWDKEYCONFIRM="\*\*\*\*\*";
3. 通过软件参数打开CHR的匿名化功能。

   通过MML命令**SET SOFTPARA**设置软件参数“BIT1588”为1。

   ```
   SET SOFTPARA: DT=BIT, BITNUM=1588, BITVALUE=1;
   ```

## 验证方法

* 如果用户标识假名化和匿名化功能已开启，则UEG保存的跟踪消息、CHR中不再含有原始的用户标识信息。
* 如果用户标识假名化和匿名化功能未生效，则UEG保存的跟踪消息、CHR中的用户标识仍是明文。
