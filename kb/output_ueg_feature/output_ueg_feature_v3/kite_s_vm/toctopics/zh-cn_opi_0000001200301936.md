## 操作场景

MPF能力开放满足基本安全要求，包括API认证授权、传输加密，对APP进行认证鉴权时需要配置鉴权开关等信息。

适用于MPF。

## 必备事项

前提条件

* 请仔细阅读GWFD-023504 支持APP认证鉴权特性概述。
* 虚机场景：完成配置Mp1接口数据。
* 已完成加载License。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 打开API GW的Oauth2.0鉴权开关。

   **SET APIAUTH**
3. 配置API GW的鉴权模式。

   * 如果采用AK/SK进行Oauth2.0鉴权，“授权模式”设置为“BYAPPD”，配置结束。
   * 如果采用APPID和APIKey进行Oauth2.0鉴权，“授权模式”设置为“BYLOCALPARA”，则执行4。

   **SET MEPAUTHMODE**
4. 增加授权服务列表。

   **ADD AUTHSERVLIST**
5. 增加APP授权服务，其中“授权服务名称”需要由服务提供商提供。

   **ADD AUTHSERV**
6. 增加APP授权信息，包含鉴权的APPID、APIKey信息和授权服务。

   **ADD APPAUTHINFO**
7. 建议一个APP实例绑定一个APPID，即每个APP实例独享一个APPID身份，否则共享APPID之间的APP实例均存在互相仿冒身份的风险。

   **ADD AUTHAPPINSTANCE**

## 任务示例一：通过AK/SK信息鉴权

任务描述

开启Oauth2.0鉴权功能，MPF通过AK/SK信息鉴权。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5APIG01",SWITCH=ENABLE;
```

//打开Oauth2.0鉴权开关。

```
SET APIAUTH:ISAUTH=ENABLE;
```

//配置Oauth2.0鉴权模式。

```
SET MEPAUTHMODE:AUTHMODE=BYAPPD;
```

## 任务示例二：通过APPID/APIKey信息鉴权

任务描述

开启Oauth2.0鉴权功能，MPF通过APPID/APIKey信息鉴权。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5APIG01",SWITCH=ENABLE;
```

//打开Oauth2.0鉴权开关。

```
SET APIAUTH:ISAUTH=ENABLE;
```

//配置Oauth2.0鉴权模式。

```
SET MEPAUTHMODE:AUTHMODE=BYLOCALPARA;
```

//增加授权服务列表。

```
ADD AUTHSERVLIST: NAME="serviceList";
```

//增加授权服务。

```
ADD AUTHSERV: SERVICENAME="servicename", SERVICELISTNAME="serviceList", AUTHVALIDTIME=2022&01&13&11&02&59;
ADD AUTHSERV: SERVICENAME="asr", SERVICELISTNAME="serviceList", AUTHVALIDTIME=2022&01&13&11&02&59;
```

//增加APP授权信息。

```
ADD APPAUTHINFO: APPID="appid_123", APIKEY="keyjfljiosajfwefiofsaffsdfsfssaffsfsffsf", SERVICELISTNAME="serviceList";
```

//将APP instanceID与APPID绑定。

```
ADD AUTHAPPINSTANCE: APPINSTANCEID="appid_1232435", APPID="appid_123";
```
