## 操作场景

可以在本地配置静态IP地址网段与UPF的绑定关系，当用户接入网络时，对静态IP地址用户、Radius分配IP地址用户可以基于配置的网段绑定关系为用户选择指定的UPF。

适用于GGSN、PGW-C、SMF、PGW-U、UPF。

## 操作步骤

1. 在UEG上执行如下命令：
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置EXTERNAL类型地址池。

      **ADD POOL**
   3. 配置地址池里的IPv4地址段。

      **ADD SECTION**
2. 在SMF上执行如下命令：
   1. 创建本地静态地址地址池。

      **ADD ADDRPOOL**
   2. 如果需要开启静态地址用户的白名单检查功能，需要配置地址池与APN/DNN的绑定关系。接入该APN的静态地址用户激活时，根据用户地址查找对应的地址池，然后根据地址池为用户选择对应的UPF。

      **ADD POOLBINDAPN**
   3. 配置本地地址池里的地址段。

      **ADD SECTION**

      * 本地地址池：本地负责分配地址的地址池。本地地址池下需要配置地址段，一个本地地址池最多可以配置64个地址段。
      * 配置地址池后，必须配置地址段。如果不配置地址段，将导致用户激活失败。
   4. 配置地址池组名称。

      **ADD ADDRPOOLGRP**
   5. 配置地址池与地址池组绑定。

      **ADD POOLBINDGRP**
   6. 配置静态地址用户使用的UPF。

      **ADD UPNODE**
   7. 配置静态地址用户使用的UPF组。

      **ADD ADDRUPGROUP**
   8. 配置UPF与UPF组绑定。

      **ADD POOLGRPMAP**
   9. 配置地址池组与UPF组绑定。

      **ADD POOLGRPMAP**
3. 在UEG上执行如下命令：
   1. 配置VPN实例。

      **ADD L3VPNINST**

      **ADD VPNINSTAF**
   2. 启动OSPF进程。

      **ADD OSPF**
   3. 添加OSPF区域。

      **ADD OSPFAREA**
   4. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   5. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**

      采用路由策略方式发布路由时，不能只选择发布WLR\_SP或者WLR\_UD路由，必须选择WLR方式发布所有路由。

## 任务示例

任务描述

某企业用户接入网络时，为用户分配的IP地址采用静态IP地址分配方式。开启静态地址用户的白名单检查功能，需要为10.10.1.1~10.10.1.10地址段内的用户选择到UPF名称为UPF\_Instance\_1的园区UPF。

脚本

UPF上配置如下命令：

//配置UPF上包含该网段的地址池信息。

```
ADD VPNINST:VPNINSTANCE="vpn1";
```

```
ADD POOL:POOLNAME="pool01",POOLTYPE=EXTERNAL,HASVPN=ENABLE,VPNINSTANCE="vpn1";
```

```
ADD SECTION:POOLNAME="pool01",SECTIONNUM=1,IPVERSION=IPv4,V4STARTIP="10.10.1.1",V4ENDIP="10.10.1.10";
```

SMF上配置如下命令：

//创建本地地址池。

```
ADD ADDRPOOL: POOLNAME="pool01", IPVERSION=IPv4, POOLTYPE=UDM, CHECKIPVALID=Enable;
```

//配置地址池与APN/DNN的绑定关系。

```
ADD POOLBINDAPN:APN="huawei.com",POOLNAME="pool01";
```

//配置本地地址池里的IPv4地址段。

```
ADD SECTION: POOLNAME="pool01", SECTIONNUM=1, IPVERSION=IPv4, V4STARTIP="10.10.1.1", V4ENDIP="10.10.1.10";
```

//配置地址池组名称。

```
ADD ADDRPOOLGRP: POOLGRPNAME="poolgroup1", POOLGRPTYPE=UDM;
```

//配置地址池与地址池组绑定。

```
ADD POOLBINDGRP: POOLGRPNAME="poolgroup1", POOLNAME="pool01";
```

//配置静态地址用户使用的UPF。

```
ADD UPNODE: NFINSTANCENAME="UPF_Instance_1", ADDRALLOCMODE=INHERIT;
```

//配置静态地址用户使用的UPF组。

```
ADD ADDRUPGROUP: UPFGRPNAME="upfgroup1", UPFGRPTYPE=UDM;
```

//配置UPF与UPF组绑定。

```
ADD UPFBINDGRP: UPFGRPNAME="upfgroup1", UPFID="UPF_Instance_1";
```

//配置地址池组与UPF组绑定。

```
ADD POOLGRPMAP: MAPPINGNAME="mapping01", POOLGRPNAME="poolgroup1", UPFGRPNAME="upfgroup1";
```

UPF上配置如下命令：

//配置手机下行路由。

```
ADD L3VPNINST:VRFNAME="vpn1";
```

```
ADD VPNINSTAF:VRFNAME="vpn1",AFTYPE=ipv4uni;
```

```
ADD OSPF:PROCID=100,VRFNAME="vpn1",SCHEMAROUID="10.10.10.1",LSAARRMAXINTV=1000,LSAARRSTARINTV=500,LSAARRHLDINTV=500;
```

```
ADD OSPFAREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFNETWORK:PROCID=100,AREAID="0.0.0.0", IPADDRESS="10.13.21.0", WILDCARDMASK="0.0.0.255";
```

```
ADD OSPFIMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```
