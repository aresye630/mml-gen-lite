# 一键式下线IPSec服务（UPF）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要IPSec服务或IPSec服务一键式动态上线失败时，可以单独卸载IPSec pod，从而一键式下线IPSec服务。

## 必备事项

前提条件

* LCM版本不低于V100R024C10。
* 已经完成网络设计，已规划下线IPsec pod的类型和数量。
* 已经规划IPsec pod关联的其他组件的类型和数量，卸载IPsec服务后，请联系华为技术支持工程师缩容关联组件。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| 服务一键式部署  OPR ONECLICKDEPLOY | 操作类型（OPRTYPE） | FEATUREDISABLE | 固定取值 |
|  | 节点类型列表（NODETYPELIST） | 样例：PBU\_P-I\_C4\_ARM:0  VM类型:下线后的VM个数。   * X86的VM类型：PBU\_P-I\_M（仅UEG S）、PBU\_P-I、PBU\_P-I\_C4。 * ARM的VM类型：PBU\_P-I\_M\_ARM（仅UEG S）、PBU\_P-I\_ARM、PBU\_P-I\_C4\_ARM。 | 本端规划 |
|  | 方法集名称（FUNCTIONSETNAME） | IPSec | 固定取值 |
|  | 处理方式  （PROCESSTYPE） | Normal | 本端规划 |

## 操作步骤

1. 登录UEG OM Portal。
2. 执行**SET FWSOFTPARA**命令，开启Service Fabric的**DWORD\_521**软参，即系统故障时不触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=1;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为1。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为1，请执行后续步骤。如果软参值不是1，请联系华为技术支持。
3. 执行**OPR ONECLICKDEPLOY**命令，一键式下线IPSec的VM和Pod。以PBU\_P-I\_C4虚拟机为例，其他虚拟机请替换为配套pod。

   ```
   OPR ONECLICKDEPLOY: OPRTYPE=FEATUREDISABLE, NODETYPELIST="PBU_P-I_C4:0", FUNCTIONSETNAME="IPSec", PROCESSTYPE=Normal;
   ```
4. 执行**DSP ONECLICKDEPLOYHIST**命令，确认一键式下线IPSec服务的回显为“处理结果=处理成功”。
5. 执行命令，确认pod已下线

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="ipsecctl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="ipsecexec-c4-pod";
   ```

   回显为“查询Pod不存在”。
6. 执行**SET FWSOFTPARA**命令，关闭Service Fabric的**DWORD\_521**软参，即系统故障时触发容灾导致的联动复位。

   ```
   SET FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521, DWORDVALUE=0;
   ```

   执行**LST FWSOFTPARA**命令，确认Service Fabric软参值是否为0。

   ```
   LST FWSOFTPARA: PARAMETERSTYPE=DWORD, DWORDINDEX=521;
   ```

   如果软参值为0，请执行后续步骤。如果软参值不是0，请联系华为技术支持。
