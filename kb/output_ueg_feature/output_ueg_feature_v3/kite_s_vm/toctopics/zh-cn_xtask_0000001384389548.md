# 恢复默认值

* 操作场景
* 对系统的影响
* 必备事项
* 操作步骤

#### 操作场景

清空开站配置，恢复默认值。

如果恢复默认值时比极简开站时加载的补丁版本低，请联系华为技术支持协助操作。

#### 对系统的影响

* 清空开站配置会导致业务中断。
* 清空开站配置会导致生成ESN的“IP地址+主机名＋GT地址”序列中IP地址、主机名或GT地址修改，可能会触发“ALM-18805 ESN即将失效”告警上报。重新极简开站后，在“MML命令行-UEN”窗口下执行**DSP ESN**命令触发自动校验功能，查看告警是否恢复，如未恢复请参考“ALM-18805 ESN即将失效”进行处理。

#### 必备事项

**前提条件**

* 已登录 OM Portal。
* 操作员拥有系统管理员权限。

**数据**

无

#### 操作步骤

1. 选择“应用配置”> “业务运维”，在左侧导航栏中选择“开站”-> "恢复默认值"，进入“配置恢复”界面，如图1。

   **图1** 配置恢复
2. 单击“一键清除开站信息”，弹出“警告”确认框，如图2。

   **图2** 清空开站配置提示信息确认框
3. 确认当前环境符合提示信息，单击“确定”。
