# 入驻式或共享式MPF配置实例（共部署）

* 操作场景

* 操作步骤

## 操作场景

MPF VNF和UPF VNF共部署在高密度框式服务器 4U-ARM上时，可参考本页面配置MPF。

UEG部署在园区或地市中心，作为企业专用MPF或共享MPF。企业园区终端签约专有DNN（APN），MPF到UPF采用VXLAN隧道，MPF到APP采用VPN专线。

UEG使用标卡与DCGW连接。DCGW之间使用E-Trunk+EVPN或M-LAG组网，UEG使用SR-IOV bonding组网（Eth-trunk接口），一个Eth-trunk接口的成员端口，分别与两个DCGW连接。

UEG通过BGP over静态路由+BFD单臂echo与对端网元（UPF/APP）实现网络互通，如下以MPF（UEG）与APP之间的网络互通为例给出组网示意（如图1所示）。

**图1** UEG与APP之间的组网示意（标卡+DCGW）

* VNF与网络实体之间的网络环境已经构建完成。

## 操作步骤

1. 配置基础数据。

   基础数据包括：修改网元浮动IP等。详细配置与组网无关，具体请参见基础数据配置。
2. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60003";
   ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      * 如果“自动配置开关”值为“TRUE”，需要执行4.b和4.c关闭自动配置开关。
      * 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到5。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 配置MPF（UEG）到UPF的IP路由数据（传输Mp2接口报文）。
   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Mp2";
      ADD VPNINSTAF:VRFNAME="VRF_Mp2", AFTYPE=ipv4uni, VRFRD="192.168.225.142:100";
      ```

      ```
      ADD VPNINSTAF:VRFNAME="VRF_Mp2", AFTYPE=ipv6uni, VRFRD="192.168.225.142:100";
      ```
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack2";
      ADD IPBINDVPN:IFNAME="LoopBack2",VRFNAME="VRF_Mp2";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack2",IFIPADDR="192.168.225.142",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```

      ```
      SET IFIPV6ENABLE: IFNAME="Loopback2", ENABLEFLAG=TRUE;
      ADD IFIPV6ADDRESS:IFNAME="Loopback2",IPV6ADDRESS="FC00::225:142",PREFIXLEN=128;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Mp2", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.142";
      ```
   4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Mp2", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Mp2", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

      ```
      ADD BGPPEER: VRFNAME="VRF_Mp2", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.12", REMOTEAS="60002", LOCALIFADDR="192.168.225.142", LOCALIFNAME="Loopback2", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Mp2", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.12", REMOTEAS="60002", LOCALIFADDR="192.168.225.142", LOCALIFNAME="Loopback2", EBGPMAXHOP=10;
      ```

      ```
      ADD BGPPEER: VRFNAME="VRF_Mp2", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:12", REMOTEAS="60002", LOCALIFADDR="FC00::225:142", LOCALIFNAME="Loopback2", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Mp2", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:12", REMOTEAS="60002", LOCALIFADDR="FC00::225:142", LOCALIFNAME="Loopback2", EBGPMAXHOP=10;
      ```
   6. 配置BGP引入wlr路由。

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Mp2", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Mp2", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```
   7. 添加以太网隧道多虚拟网卡自动化配置模板。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
      ```
   8. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Mp2_2012_v4",VPNNAME="VRF_Mp2",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4, VLANID=2012, BEGINADDR4="192.168.92.2", ENDADDR4="192.168.92.30", MASKLEN=27;
      ```

      ```

      ```
   9. 增加BFD会话自动部署模板。

      ```

      ```

