## 操作场景

在UEG上部署通用DNN漫游分流功能，需要开启通用DNN漫游分流功能开关。

## 必备事项

前提条件

* 请仔细阅读GWFD-030205 通用DNN漫游分流。
* UEG完成与周边网元的对接。
* 已完成分流业务相关的部署。
* 完成**License****加载**（如果有需求，请联系华为技术支持工程师处理）。

数据

**表1** 专网UPF配置

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（LICITEM） | LKV3G5MVCA01 | 固定取值 | 该参数用于指定“移动VPN园区接入”License项。 |
|  | 开关（SWITCH） | ENABLE | 固定取值 | 该参数用于表示License项的配置开关是否已经打开。 |
| **SET RTSDNNPARA** | 专网通用DNN漫游分流开关（PRIVATENETSW） | ENABLE | 固定取值 | 用于指定系统是否开启专网的通用DNN漫游分流功能。 |
|  | IPv4 NAT ALG协议（NATALGPROTV4） | FTP-1&RTSP-1 | 本端规划 | 用于指定系统是否开启通用DNN漫游分流特定协议类型NAT ALG的IPv4地址替换。 |
|  | IPv6 NAT ALG协议（NATALGPROTV6） | FTP-1 | 本端规划 | 用于指定系统是否开启通用DNN漫游分流特定协议类型NAT ALG的IPv6 地址替换。 |

## 操作步骤

1. 在专网UPF上打开特性License开关。

   **SET LICENSESWITCH**
2. 在专网UPF上配置通用DNN漫游分流开关。

   **SET RTSDNNPARA**
3. （可选）在专网UPF上配置针对指定协议的地址替换。

   **SET RTSDNNPARA**

## 任务示例

任务描述

在专网UPF上开启通用DNN漫游分流功能，打开需要支持的license开关。

脚本

//开启专网UPF的通用DNN漫游分流功能相关的License。

```
SET LICENSESWITCH:LICITEM="LKV3G5MVCA01",SWITCH=ENABLE;
```

//开启专网UPF的通用DNN漫游分流功能开关。

```
SET RTSDNNPARA: PRIVATENETSW=ENABLE;
```

//（可选）专网UPF开启针对FTP和RTSP协议的IPv4地址替换，针对FTP协议的IPv6地址替换。

```
SET RTSDNNPARA: NATALGPROTV4=FTP-1&RTSP-1, NATALGPROTV6=FTP-1;
```
