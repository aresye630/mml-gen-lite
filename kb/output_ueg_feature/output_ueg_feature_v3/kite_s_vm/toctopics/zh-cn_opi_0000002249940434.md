## 操作场景

软件安装阶段，已完成网元名称和浮动IP地址的配置。在生产预安装场景或者现网使用时，如果需要修改，可参考本页面调整登录网元OM Portal的网元名称和浮动IP地址。

* 网元名称、浮动IP地址需要与网管上配置的名称和IP地址属性一致，如果本端修改了网元名称和浮动IP地址，需要在网管上同步修改该网元的名称和IP地址属性。
* 修改浮动IP时，请参考网元的改造OM网络方案改造OM网络。

## 对系统的影响

* 修改网元浮动IP地址后，OM Portal将会退出，需要使用新浮动IP地址重新登录。
* 修改网元浮动IP地址后，网管与网元之间的连接将中断，需要在网管上重新对接网元。
* 修改网元浮动IP地址后，VNFM与网元之间的连接将中断，需要在VNFM上修改对应网元的IP地址。

## 必备事项

前提条件

* 已经确认现网规划的网元名称、浮动IP地址与网元生产预安装的预设参数值不同。
* 调测PC需要能够与修改前浮动IP地址通信，已登录网元OM Portal。
* 已从网管侧获取网管登录信息。

## 操作步骤

1. 登录网元OM Portal，选择“应用管理 > MML”。
2. 执行**MOD ME**将网元名称修改为现网规划的网元名称，脚本示例如下。

   ```
   MOD ME: MEID=0, MENAME="APP";
   ```
3. 执行**LST OMIP**查询系统是否已配置物理IP地址且符合现网规划的IP地址。
4. 执行**SET OMIP**设置系统IP地址。

   * 如果系统已配置物理IP地址且符合现网规划的IP地址，执行**SET OMIP**将浮动IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1";
     ```

   * 如果系统未配置物理IP地址或已配置的物理IP地址与现网规划的IP地址不符，执行**SET OMIP**将浮动IP地址、物理IP地址修改为现网规划的IP地址，脚本示例如下。

     ```
     SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="10.145.27.173", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="10.145.27.1", OMHOST1IPV4="10.145.27.174", OMHOST2IPV4="10.145.27.175";
     ```
5. 如果已在网管上创建网元，则需要登录网管客户端，修改网管上网元名称、IP地址属性为现网规划的信息。

   操作方法请参见MAE产品文档，“操作与维护 > MAE-Access操作与维护 > 拓扑管理 > 维护拓扑对象 > 修改拓扑对象”。
