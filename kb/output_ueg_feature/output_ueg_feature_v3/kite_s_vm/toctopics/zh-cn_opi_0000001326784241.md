# 配置大流量防攻击

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

配置大流量防攻击功能，可以防止用户发起大流量报文攻击。

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

无。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| 大流量防攻击开关 | 上行大流量攻击检测开关（UPSWITCH） | ENABLE | 本端规划 | **SET TRFCDFDSWITCH** |
|  | 下行大流量攻击检测开关（DOWNSWITCH） | ENABLE | 本端规划 |  |

## 操作步骤

1. 配置大流量防攻击功能。

   **SET TRFCDFDSWITCH**:UPSWITCH=ENABLE,DOWNSWITCH=ENABLE;

## 任务示例

任务描述

为防止用户发起大流量报文攻击，开启大流量防攻击功能。

脚本

1. 开启大流量防攻击功能开关。

   ```
   SET TRFCDFDSWITCH:UPSWITCH=ENABLE,DOWNSWITCH=ENABLE;
   ```
