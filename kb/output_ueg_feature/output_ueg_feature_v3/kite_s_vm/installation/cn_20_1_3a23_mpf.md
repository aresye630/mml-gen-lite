## 操作场景

VNF与对端设备可通过静态路由绑定静态BFD探测的方式进行组网连接。

在网络拓扑结构比较简单时，通常使用静态路由方式组网，合理的静态路由可以改进网络性能，并为业务保证带宽。同时，利用单臂Echo转发检测机制为链路提供单向、轻负荷且持续时间短的快速检测功能，提高链路可靠性。

如图1所示为VNF与周边网元的静态路由互通组网示意图。VNF与网关运行静态路由协议而接入运营商网络/企业网络，DC-GW作网关。VNF和DC-GW之间采用单臂BFD探测。DC-GW的配置请参考对应型号设备的产品文档。

## 必备事项

前提条件

* 请阅读并熟悉特性IPFD-020503 静态路由和IPFD-020403 BFD特性概述。

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

* VNF与网络实体之间的网络环境已经构建完成。

数据

VNF使用静态路由绑定静态BFD检测功能与对端设备建立可靠的IP连接。

* 在VNF上配置静态路由与对端建立链路。
* 在VNF上配置静态BFD功能增强链路检测可靠性。
* 在VNF上推荐采用子接口的外联口与外部网络对接。

本文以一组外联口子接口为例进行说明，一组外联口（对应一个逻辑接口）分别在每个ISU虚拟机上各规划3个子接口负荷分担承载流量。实际场景可根据网设规划进行适配。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VRF_Mp1";
   ADD VPNINSTAF:VRFNAME="VRF_Mp1",AFTYPE=ipv4uni;
   ```

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、网关上的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 配置外联口IP地址。

   1. 查询接口名，确认CSLB上可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet64/0/6",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet65/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet65/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet65/0/6",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/6",IFADMINSTATUS=up;
      ```
   3. 配置以太网子接口。

      ```
      ADD INTERFACE:IFNAME="Ethernet64/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet64/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet64/0/6.1";
      ADD INTERFACE:IFNAME="Ethernet65/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet65/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet65/0/6.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/6.1";
      ```
   4. 增加接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Ethernet64/0/4.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet64/0/5.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet64/0/6.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet65/0/4.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet65/0/5.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet65/0/6.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/4.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/5.1",VRFNAME="VRF_Mp1";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/6.1",VRFNAME="VRF_Mp1";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Ethernet64/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet64/0/5.1",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Ethernet64/0/6.1",VLANTYPEVID=300;
      ADD ETHSUBIF:IFNAME="Ethernet65/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet65/0/5.1",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Ethernet65/0/6.1",VLANTYPEVID=300;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/5.1",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/6.1",VLANTYPEVID=300;
      ```

      子接口配置了VLAN，则需要在交换机、对接网关上调整VLAN的配置。
   6. 配置外联口IP地址。

      ```
      ADD IFIPV4ADDRESS:IFNAME="Ethernet64/0/4.1",IFIPADDR="192.168.89.2",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet64/0/5.1",IFIPADDR="192.168.89.34",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet64/0/6.1",IFIPADDR="192.168.89.66",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet65/0/4.1",IFIPADDR="192.168.89.3",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet65/0/5.1",IFIPADDR="192.168.89.35",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet65/0/6.1",IFIPADDR="192.168.89.67",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/4.1",IFIPADDR="192.168.89.4",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/5.1",IFIPADDR="192.168.89.36",SUBNETMASK="255.255.255.224";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/6.1",IFIPADDR="192.168.89.68",SUBNETMASK="255.255.255.224";
      ```

      如果规划外联口使用IPv4v6双栈地址，则分别执行**ADD IFIPV4ADDRESS**和**ADD IFIPV6ADDRESS**对同一外联口配置IPv4和IPv6地址。
3. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
4. 新建BFD会话。

   ```
   ADD BFDSESSION: SESSNAME="BfdName21",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.1",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=121,IFNAME="Ethernet64/0/4.1";
   ADD BFDSESSION: SESSNAME="BfdName22",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.33",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=122,IFNAME="Ethernet64/0/5.1";
   ADD BFDSESSION: SESSNAME="BfdName23",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.65",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=123,IFNAME="Ethernet64/0/6.1";
   ADD BFDSESSION: SESSNAME="BfdName24",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.1",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=124,IFNAME="Ethernet65/0/4.1";
   ADD BFDSESSION: SESSNAME="BfdName25",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.33",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=125,IFNAME="Ethernet65/0/5.1";
   ADD BFDSESSION: SESSNAME="BfdName26",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.65",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=126,IFNAME="Ethernet65/0/6.1";
   ADD BFDSESSION: SESSNAME="BfdName27",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.1",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=127,IFNAME="Ethernet66/0/4.1";
   ADD BFDSESSION: SESSNAME="BfdName28",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.33",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=128,IFNAME="Ethernet66/0/5.1";
   ADD BFDSESSION: SESSNAME="BfdName29",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.89.65",LINKTYPE=IP,VRFNAME="VRF_Mp1",LOCALDISCR=129,IFNAME="Ethernet66/0/6.1";
   ```
5. 配置静态路由并绑定BFD会话。

   ```
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.1",IFNAME="Ethernet64/0/4.1",SESSIONNAME="BfdName21";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.33",IFNAME="Ethernet64/0/5.1",SESSIONNAME="BfdName22";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.65",IFNAME="Ethernet64/0/6.1",SESSIONNAME="BfdName23";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.1",IFNAME="Ethernet65/0/4.1",SESSIONNAME="BfdName24";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.33",IFNAME="Ethernet65/0/5.1",SESSIONNAME="BfdName25";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.65",IFNAME="Ethernet65/0/6.1",SESSIONNAME="BfdName26";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.1",IFNAME="Ethernet66/0/4.1",SESSIONNAME="BfdName27";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.33",IFNAME="Ethernet66/0/5.1",SESSIONNAME="BfdName28";
   ADD SRROUTE:VRFNAME="VRF_Mp1",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VRF_Mp1",NEXTHOP="192.168.89.65",IFNAME="Ethernet66/0/6.1",SESSIONNAME="BfdName29";
   ```

   * 如果需要为静态路由绑定静态BFD会话，通过**ADD SRROUTE**的“静态BFD会话名”来指定静态路由所联动的静态BFD的会话名。
   * 在网关侧配置到VNF的回程路由，目的地址为VNF上各逻辑接口的IP地址，下一跳为VNF上配置的各逻辑接口对应的外联口的IP地址。

     需要说明的是，配置VNF与DN/PDN通信的回程路由时，目的地址为UE的网段地址，下一跳为VNF上外联口的IP地址。

## 验证方法

1. 查看接口状态及信息是否与规划数据一致。

   ```
   LST INTERFACE:;
   ```

   ```
   LST IFIPV4ADDRESS:;
   ```

   ```
   LST IFIPV6ADDRESS:;
   ```

   ```
   LST IPBINDVPN:;
   ```

   * 如果一致，请执行2。
   * 如果不一致，请先删除错误的配置，然后参考“操作步骤”重新配置。
2. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，请执行4。
   * 如果为其他状态，请执行3。
3. 执行**PING**，查看VNF外联口IP与DCGW接口IP能否互通。

   ```
   PING:IPVERSION=IPv4,VPNNAME="VPN_Access",DESTIPV4ADDRESS="对端网关地址";
   ```

   ```
   PING:IPVERSION=IPv6,VPNNAME="VPN_Access",DESTIPV6ADDRESS="对端网关地址";
   ```

   * 丢包率为0%，请执行5。
   * 丢包率不是0%，请检查物理接口及连线是否正常。正常后重新执行2。
4. 检查生成的IPv4静态路由是否与规划数据一致。

   ```
   DSP SRROUTE: AFTYPE=ipv4unicast, VRFNAME="VPN_Access";
   ```

   ```
   DSP SRROUTE6: AFTYPE=ipv6unicast, VRFNAME="VPN_Access";
   ```

   * 如果一致，调测结束。
   * 如果不一致，请执行5。
5. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
