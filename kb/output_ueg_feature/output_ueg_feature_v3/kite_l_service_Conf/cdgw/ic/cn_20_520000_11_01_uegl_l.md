# 配置VoLTE基础语音业务

## 操作场景

当部署GPRS/UMTS/EPC网络接入IMS域，需要配置VoLTE基础语音业务。

适用于SGW-U、PGW-U。

## 必备事项

前提条件

* 请仔细阅读GWFD-025401 VoLTE基础语音业务。
* 完成**加载license**（如果有需求，请联系华为技术支持工程师处理）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD APNIMSSIGFLTR** | APN名称（APN） | ims | 已配置数据中获取 | 已通过命令**ADD UPAPN**进行配置，可以使用命令**LST UPAPN**查询。 |
|  | 优先级（PRIORITY） | 1  2 | 本端规划 | IMS信令专用上下文的Filter。 |
|  | IP地址版本（IPVERSION） | IPV4 | 本端规划 |  |
|  | 源IPv4地址（SRCIPV4ADDR） | 10.1.1.1 | 本端规划 |  |
|  | 源IPv4地址掩码长度（SRCIPV4MASKLEN） | 32 | 本端规划 |  |
|  | 源端口号开始（SRCPORTSTART） | 1 | 本端规划 |  |
|  | 源端口号结束（SRCPORTEND） | 2 | 本端规划 |  |
|  | 协议类型（PROTOCOL） | 6  17 | 本端规划 |  |
| **SET APNIMSATTR** | IMS开关（IMSSWITCH） | ENABLE | 本端规划 | 配置IMS功能开关。 |
|  | APN名称（APN） | ims | 已配置数据中获取 | 已通过命令**ADD UPAPN**进行配置，可以使用命令**LST UPAPN**查询。 |

## 操作步骤

* 打开本特性的License配置开关。

  **SET LICENSESWITCH**
* 基于APN配置IMS业务。

  **ADD APNIMSSIGFLTR**
* 配置IMS使能开关和IMS信令空口增强开关，绑定到指定APN实例下。

  **SET APNIMSATTR**

## 任务示例

任务描述

配置IMS业务。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM ="LKV3G5VLEF01",SWITCH=ENABLE;
```

//基于APN配置IMS业务。

```
ADD APNIMSSIGFLTR: APN="ims", PRIORITY=1, IPVERSION=IPV4, SRCIPV4SPECTYPE=SPECIFY, SRCIPV4ADDR="10.1.1.1", SRCIPV4MASKLEN=32, SRCPORTSPECTYPE=SPECIFY, SRCPORTSTART=1, SRCPORTEND=2, PROSPECTYPE=SPECIFY, PROTOCOL=6;
```

```
ADD APNIMSSIGFLTR: APN="ims", PRIORITY=2, IPVERSION=IPV4, SRCIPV4SPECTYPE=SPECIFY, SRCIPV4ADDR="10.1.1.1", SRCIPV4MASKLEN=32, SRCPORTSPECTYPE=SPECIFY, SRCPORTSTART=1, SRCPORTEND=2, PROSPECTYPE=SPECIFY, PROTOCOL=17;
```

//配置IMS使能开关和IMS信令空口增强开关，绑定到指定APN实例下。

```
SET APNIMSATTR:APN="ims",IMSSWITCH=ENABLE;
```
