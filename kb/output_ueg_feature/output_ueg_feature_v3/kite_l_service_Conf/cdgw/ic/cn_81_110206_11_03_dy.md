# 配置动态PCC功能（UPF）

## 操作场景

当网络中有PCRF/PCF，用户需要激活为PCC用户，为用户或用户业务提供灵活策略控制时，需要配置动态PCC功能。

配置动态PCC功能时，规则分为动态规则和预定义规则：

* 动态规则：PCRF/PCF下发该规则对应的业务流特征及业务的精细化管理动作。SMF和UPF不需要特殊配置。PCF可以随时删除旧规则，安装新规则。
* 预定义规则：UPF/SMF/PCF上需定义相同的规则标识（即**ADD RULE**命令中的“规则名称（RULENAME）”参数值），UPF上定义该规则对应的业务流特征及业务的精细化管理动作。用户注册过程中，由PCF下发规则标识，PCF通过规则标识的方式激活SMF/UPF本地静态配置的规则来实现计费和策略的控制。PCF可以随时删除旧规则，安装新规则。

  预定义规则组与预定义规则类似，区别在于UPF/SMF/PCF上需定义相同的规则组标识（即**ADD USERPROFILE**命令中的“用户模板名称（USERPROFILENAME）”参数值）。

适用于PGW-U、UPF。

配置预定义规则时，UEG上需要配置rule和UserProfile，本页面不关注具体规则内容配置，具体规则内容需要根据具体业务策略确定。

## 必备事项

前提条件

* 请仔细阅读GWFD-022201 PCC基本功能。
* 完成加载license（如果有需求，请联系华为技术支持工程师处理）。
* PGW-U/UPF与PGW-C/SMF配合作为策略执行实体，PGW-C/SMF的配置请参见UNC的初始配置手册和PCC基本功能的配置资料。

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置PCC策略组。

   **ADD PCCPOLICYGRP**
3. 配置流过滤器。

   **ADD FLOWFILTER**

   流过滤器必须至少绑定一个filter或一个l7filter，否则所有报文都匹配不上该流过滤器。
4. 配置三四层过滤条件。
   1. 配置三四层过滤条件。

      **ADD FILTER**
   2. 配置三四层过滤条件与流过滤器的绑定关系。

      **ADD FLTBINDFLOWF**
5. 配置规则。

   **ADD RULE**

   若需配置多个规则，则需要多次执行5。
6. 配置规则与用户模板的绑定关系 。
   1. 创建UserProfile。

      **ADD USERPROFILE**
   2. 将已配置的rule绑定到UserProfile。

      **ADD RULEBINDING**
7. 将新配置的Filter跟UserProfile置为生效。

   **SET REFRESHSRV**

## 任务示例

任务描述

本举例中配置的是3/4层any to any的filter，未配置7层规则，表示所有报文都匹配。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5PCCB01",SWITCH=ENABLE;
```

//配置流过滤器和三四层过滤条件。

```
ADD FILTER: FILTERNAME="filter_test", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_test";
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_test",FILTERNAME="filter_test";
```

//配置PCC策略组。**当需要计费时，请配置参数URRGROUPNAME**。

```
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pg_test",URRGROUPNAME="urrgp_test";
```

//配置规则。

```
ADD RULE:RULENAME="rule_test",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfilter_test",PRIORITY=65535, POLICYNAME="pg_test";
```

//配置规则与用户模板的绑定关系。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test";
```

//将新配置的Filter和UserProfile置为生效。

```
SET REFRESHSRV:REFRESHTYPE=ALL;
```
