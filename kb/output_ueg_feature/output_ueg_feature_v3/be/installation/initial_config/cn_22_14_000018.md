# 更新物理数据库帐户密码

#### 操作场景

* 在调测完成后，系统管理员必须及时更新物理数据库帐号的密码，确保系统安全。
* 在日常维护中，系统管理员必须定期更新物理数据库帐号的密码，确保系统安全。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

无。

#### 操作步骤

**更新pgw\_acc**、**uscdb\_acc**、**sys**、**uscdb**、**pgw**和**uscdb\_maintain**用户的密码。

1. 登录“USCDB MML命令”界面。
2. 执行**SET DB**命令，更新物理数据库用户的密码。

   以更新“uscdb\_acc”用户初始密码为例：

   `SET DB: USERNAME="uscdb_acc";`
