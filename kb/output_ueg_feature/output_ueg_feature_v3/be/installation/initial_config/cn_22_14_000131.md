# 删除命令组

#### 操作场景

当添加的自定义命令组不再被任何用户使用时，ADMINISTRATOR管理员可以执行该操作删除自定义的命令组，以提高系统的安全性。

#### 对系统的影响

该操作对系统正常运行无影响。

#### 必备事项

**前提条件**

* 只有具有管理员权限的操作员才能删除命令组。
* 系统中默认添加的命令组G\_0～G\_7不能被删除。

**数据**

执行该操作前需要准备的数据：

* 系统序列号
* 命令组ID

#### 操作步骤

1. 登录PGW客户端。

   登录方法请参见登录与退出PGW Web LMT。
2. 执行命令**RMV CCG**删除命令组。

   ```
    RMV CCG: SYSNO=1, CG=G_8;
   ```
