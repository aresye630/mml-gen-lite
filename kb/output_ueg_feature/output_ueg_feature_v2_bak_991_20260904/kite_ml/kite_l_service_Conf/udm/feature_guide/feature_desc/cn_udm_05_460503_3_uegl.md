# 配置5G用户位置和状态查询特性

- 操作场景
- 必备事项

## 操作场景

该任务指导操作人员配置5G用户位置与状态查询功能。

## 必备事项

前提条件

- 请仔细阅读WHFD-460503 5G用户位置和状态查询特性概述功能。
- 5G用户已开通VoLTE业务。

数据

| 类别              | 参数名称                                                    | 取值样例                              | 获取方式   | 说明                                                                                                                                             |
|:----------------|:--------------------------------------------------------|:----------------------------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| SET DMPECAP     | 实体名称(PEERNAME)                                          | AS_0                              | 本端规划   | 该参数必须先由ADD DMPE命令的参数“EN”定义，然后才能在此处引用。                                                                                                          |
| SET DMPECAP     | 操作类型(OPTYPE)                                            | ADD                               | 固定取值。  | -                                                                                                                                              |
| SET DMPECAP     | Diameter对端实体类型(PEERTYPE)                                | AS                                | 固定取值。  | -                                                                                                                                              |
| SET DMPECAP     | 允许Sh-pull的数据类型(PR)                                      | LOCATIONINFORMATION-1 USERSTATE-1 | 全网规划   | 用于在UDM的配置数据库中定义一个AS设备能够从UDM读取（sh-pull）操作的数据类型。 LOCATIONINFORMATION为位置信息。 USERSTATE为状态信息。 该参数为一个位域型数据，每一位对应于一种数据类型的操作标志：置为“1”，表示允许。 置为“0”，表示禁止。 |
| SET DMPECAP     | 主机名(HN)                                                 | as.huawei.com                     | 全网规划   | -                                                                                                                                              |
| SET DMPECAP     | 域名(DN)                                                  | huawei.com                        | 全网规划   | -                                                                                                                                              |
| SET HSYSTEMPARA | 控制在Sh接口的5G位置和5G用户状态的XML标签格式(NGC_LOC_USERSTATE_TAG_CTRL) | TRUE                              | 本端规划   | 用于设置5G用户位置和5G用户状态的XML标签为5GSLocationInformation和5GSUserState。                                                                                   |

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 执行**SET DMPECAP**命令，配置支持AS读取5G用户的位置与状态信息功能。
3. 登录“IMS-HSS业务管理”窗口。
4. 执行**SET HSYSTEMPARA**命令，配置Sh接口的5G用户位置和5G用户状态的XML标签格式。

## 任务示例

任务描述

在UEG上设置支持AS读取5G用户的位置与状态信息功能。

脚本

/\*登录“UEG MML命令”界面\*/

/\*配置支持AS读取5G用户的位置与状态信息功能\*/

```
SET DMPECAP: PEERNAME="AS_0", OPTYPE=ADD, PEERTYPE=AS, PR=LOCATIONINFORMATION-1&USERSTATE-1, HN="as.huawei.com", DN="huawei.com";
```

/\*登录“IMS-HSS业务管理”窗口\*/

/\*配置Sh接口的5G用户位置和5G用户状态的XML标签格式\*/

```
SET HSYSTEMPARA: NGC_LOC_USERSTATE_TAG_CTRL=TRUE;
```
