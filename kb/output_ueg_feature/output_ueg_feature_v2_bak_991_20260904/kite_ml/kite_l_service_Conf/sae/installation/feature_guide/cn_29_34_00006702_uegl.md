# 配置VoLTE用户为4G用户

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

该任务指导操作人员配置VoLTE用户改造为GSM/UMTS/EPS融合用户。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

- 操作人员已完全了解支持VoLTE特性。
- 已完成VoLTE用户的业务发放。
- 准备去签约IMS数据的用户已经开户。
- 操作人员具有业务发放权限。
- 操作人员具有PGW Web LMT的用户名和密码

数据

需要规划的数据如表1所示。

| 类别          | 参数名称          | 取值样例            | 说明                                          |
|:------------|:--------------|:----------------|:--------------------------------------------|
| MOD OPTGPRS | IMSI          | 460000009123456 | 用于标识IMSI号码。                                 |
| MOD OPTGPRS | 操作类型          | RMVPDPCNTX      | -                                           |
| MOD OPTGPRS | PDP/PDN上下文索引值 | 2               | PDP/PDN上下文索引值，每个PDP/PDN上下文的索引值不能相同，值域为1～50。 |
| MOD ICSIND  | IMSI          | 460000009123456 | 用于标识IMSI号码。                                 |
| MOD ICSIND  | 是否具备ICS能力     | FALSE           | 用户是否具备ICS能力。TRUE：具备FALSE：不具备                |
| RMV HHSSSUB | SUBID         | +8613912345678  | 用于指定需要删除哪一个签约用户的所有信息。                       |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**MOD OPTGPRS**命令删除IMS数据和信令承载APN。
3. 执行**MOD ICSIND**命令去签约ICS能力。
4. 登录“IMS-HSS业务管理”窗口。
5. 执行**RMV HHSSSUB**命令删除IMS-HSS开户数据。

## 任务示例

任务描述

修改VoLTE用户为4G用户，删除IMS-HSS用户数据。

脚本

/\*----------登录“UDM业务管理”窗口----------\*/

/\*删除EPS用户的IMS数据和信令承载APN上下文\*/

```
MOD OPTGPRS: IMSI="460000009123456", PROV=RMVPDPCNTX, CNTXID=2;
```

/\*去签约ICS能力\*/

```
MOD ICSIND: IMSI="460000009123456", ICSIND=FALSE;
```

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*删除IMS-HSS开户数据\*/

```
RMV HHSSSUB: SUBID="+8613912345678";
```
