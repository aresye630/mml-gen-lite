# 配置OM网络访问控制策略

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

CSP在初始安装完成后，为保证OM网络的安全性，需要在OMPortal上配置OM网络的访问控制策略，支持单条配置，也支持批量导入，策略配置完成后，将会允许或禁止特定IP或特定网段访问OM网络。

**说明** 

- 当运维人员未配置策略信息时，系统不会对访问OM网络的IP做访问限制，此时OM网络存在安全风险。
- 为保证系统故障后的应急维护能力，系统初始预置了OM网络22端口的允许访问控制策略。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

已登录OM Portal。

数据

已根据网络规划获取到与CSP对接的网管（U2020/MAE）、第三方服务器、Syslog服务器、NTP服务器、OM Portal浮动IP网关、运维终端等所有OM网络的五元组信息和网口信息，需要将该数据作为白名单（操作类型为ACCEPT）策略进行配置，除白名单以外的IP信息配置为丢弃策略（操作类型为DROP）。

## 操作步骤

- 选择“安全 > 安全策略 > 访问控制策略”。

配置访问控制策略。

用户可以单条配置控制策略，也可以批量导入控制策略。

“源IP”或“remoteIpv4Address（请求来源IP地址）”为CSP对接设备的IP，“源端口”、“remotePortUp（请求来源端口上限）”、“remotePortDown（请求来源端口下限）”为CSP对接设备的端口；“目的IP”或“localIpv4Address（请求目的IP地址）”是CSP OM的IP，“目的端口”、“localPortUp（请求目的端口上限 ）”、“localPortDown（请求目的端口下限）”是CSP OM的端口。

因策略生效规则为先匹配ACCEPT策略，再匹配DROP策略，所以需先将所有OM网络作为白名单（操作类型为ACCEPT）策略进行配置，再将除白名单以外的IP信息配置为丢弃策略（操作类型为DROP）。

**说明** 

策略生效规则及约束：

- IPv4和IPv6策略相对独立，生效时互不影响。
- 不同网口策略相对独立，生效时互不影响。
- 配置策略的所有参数都匹配上后，策略才会生效。
- 同一个网口及同一种IP类型的策略生效顺序如下：
  - 策略匹配时先匹配ACCEPT策略，再匹配DROP策略。
  - 策略按照用户配置顺序依次匹配，当本条策略不满足要求时，尝试匹配下一条策略。
- 策略添加时需保证生效顺序在前的策略不能等于或者覆盖生效顺序在后的策略。
- 当数据包没有匹配上所有策略时，系统默认接收该数据包。
- 系统最多支持配置1024条策略（含默认策略），为避免策略过多影响系统网络转发性能，同一类型网络端口的策略配置条数不超过32条。

配置单条访问控制策略：单击

“创建”

，设置对应参数，单击

“应用”

，完成单条配置策略的配置。

批量导入控制策略：按照对文件的要求，参考文件内容示例和表2制作批量导入的文件，单击

“批量导入”

，选中文件后，完成策略的批量导入。

**注意** 

批量导入后系统会清空用户已配置的策略，导入前请先执行“导出”操作，避免数据丢失，导出的文件名为ACLPolicy.txt。

**对文件要求如下：**

- 文件格式为普通文本txt格式。
- 文件的编码格式需要为UTF-8格式。
- 文件头以“[ACL RULES]”开始。
- 一行代表一条策略，并以分号结尾。
- 不同参数间使用英文逗号隔开。
- 参数取值填写时严格按照表2“参数取值”列的大小写填写。

**文件内容示例：**

```
[ACL RULES]
aclName=IPv4-8000-ACCEPT,aclOper=ACCEPT,ipType=IPv4,remoteIpv4Address=192.168.10.0,remoteIpv4Mask=24,localIpv4Address=0.0.0.0,localIpv4Mask=0,localPortDown=8000,localPortUp=8000,aclProType=UDP,interfaceName=OM;
aclName=IPv6-31943-DROP,aclOper=ACCEPT,ipType=IPv6,remoteIpv6Address=fe80::0:0:0:0:0,remoteIpv6Prelen=10,localIpv6Address=0:0:0:0:0:0:0:0,localIpv6Prelen=0,localPortDown=31943,localPortUp=31943,aclProType=TCP,interfaceName=OM;
aclName=IPv4-PING-DROP,aclOper=ACCEPT,ipType=IPv4,remoteIpv4Address=192.168.20.0,remoteIpv4Mask=24,localIpv4Address=0.0.0.0,localIpv4Mask=0,aclProType=ICMP,aclIcmpCode=8,interfaceName=OM;
```

- 在2中未设置关联网口时，单击“批量关联网口”批量设置。

- 配置完访问控制策略后，可对控制策略进行编辑修改，单击“编辑”，更新参数值后，单击“应用”完成修改；也可对策略做删除操作，单击“删除”删除已配置的策略；也可对策略做批量导出操作，单击“导出”会导出所有的控制策略。
