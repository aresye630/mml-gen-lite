# 配置模板数据

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成5G模板数据的配置。

## 必备事项

前提条件

具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

数据

| 类别            | 参数名称                           | 取值样例       | 获取方法     | 说明                                         |
|:--------------|:-------------------------------|:-----------|:---------|:-------------------------------------------|
| ADD NGCQOSTPL | HLRSN(HLR序列号)                  | 1          | 已配置数据中获取 | 与系统管理MML命令界面上的ADD VHLRSN命令配置的“HLRSN”的取值相同。 |
| ADD NGCQOSTPL | TPLID(模板ID)                    | 1          | 本端规划     | 统一规划。                                      |
| ADD NGCQOSTPL | NGQI(5QI)                      | 1          | 与对端协商    | NGQI（即：5G QoS的特定参数）与无线/UNC对齐后配置。           |
| ADD NGCQOSTPL | ARPPRILEVEL(优先级)               | 1          | 本端规划     | 用户的优先级分为15个等级，数值越小，优先级越高。                  |
| ADD NGCQOSTPL | PREEMPTIONCAP(是否允许抢占低优先级业务的资源) | FALSE      | 本端规划     | 统一规划。                                      |
| ADD NGCQOSTPL | PREEMPTIONVUL(是否允许资源被高优先级业务抢占) | FALSE      | 本端规划     | 统一规划。                                      |
| ADD NGCQOSTPL | NGQIPRILEVEL(5QI优先级)           | 1          | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | HLRSN(HLR序列号)                  | 1          | 本端规划     | 与系统管理MML命令界面上的ADD HLRSN命令配置的“HLRSN”的取值相同。  |
| ADD DNNQOSTPL | TPLID(QoS模板ID)                 | 1          | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | TPLNAME(QoS模板名)                | test       | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | PDUTYPE(默认PDU类型)               | IPV4       | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | ALLOWEDPDUTYPE(其它允许的PDU类型)     | IPV6       | 本端规划     | 统一规划。 支持5G LAN以太通信时，允许的PDU类型需包含“ETHER”。    |
| ADD DNNQOSTPL | SSCMODE(默认SSC模式)               | SSC_MODE_1 | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | ALLOWEDSCCMODE(其它允许的SSC模式)     | SSC_MODE_2 | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | NGCQOSTPLID(5GC QoS模板ID)       | 1          | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | AMBRUP(DNN级别上行速率)              | 100        | 与对端协商    | 表示DNN级最大请求上行带宽，需与SMF侧配置一致。从SMF侧获取进行配置。     |
| ADD DNNQOSTPL | UPUNIT(DNN级别上行速率单位)            | Mbps       | 本端规划     | 表示DNN级最大请求上行带宽的单位。                         |
| ADD DNNQOSTPL | AMBRDW(DNN级别下行速率)              | 1          | 与对端协商    | 表示DNN级最大请求下行带宽，需与SMF侧配置一致。从SMF侧获取进行配置。     |
| ADD DNNQOSTPL | DWUNIT(DNN级别下行速率单位)            | Mbps       | 本端规划     | 表示DNN级最大请求下行带宽的单位。                         |
| ADD DNNQOSTPL | CHARGE(计费特性)                   | 1111       | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | UPINTEGR(用户面完整性保护策略)           | NOT_NEEDED | 本端规划     | 统一规划。                                      |
| ADD DNNQOSTPL | UPCONFID(用户面机密性保护策略)           | NOT_NEEDED | 本端规划     | 统一规划。                                      |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 增加5G QoS模板。

   //5G QoS模板需要与中心UDM保持一致。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", NGQI=1, ARPPRILEVEL=1, PREEMPTIONCAP=FALSE, PREEMPTIONVUL=FALSE,  NGQIPRILEVEL=1;
   ```
3. 增加5G DNN QoS模板。

   //5G DNN QoS模板需要与中心UDM保持一致。不支持5G LAN时：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV6, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, NGCQOSTPLID=1, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```

   //5G DNN QoS模板需要与中心UDM保持一致。支持5G LAN时：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV6&ETHER, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, NGCQOSTPLID=1, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```
