# 5G LAN用户本地签约配置（风筝L，通过企业网管）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

企业产线部署5G LAN业务后，存在根据业务实际需要，灵活调整CPE（5G模组）/5G LAN终端（5G模组）签约的5G LAN组的需求。

产线需要灵活调整时，若仅依赖在UDM上修改5G LAN组签约数据，则存在申请周期较长等问题。故需要灵活调整时，可通过企业网管调整用户所属的5G LAN组。

通过基于华为API文档开发的企业网管调整用户所属的5G LAN组时，还需要提前在UEG（风筝L）上完成本页面的配置。

**说明** 

- 本章节描述的5G LAN用户本地签约配置，指的仅是调整5G LAN用户本地所属的5G LAN组ID，不包括其他参数调整。
- 开启5G LAN用5G户本地签约功能后，5G LAN用户本地签约的5G LAN组ID，优先级高于UDM上开户时签约的5G LAN组ID。

## 必备事项

前提条件

- 操作员拥有配置权限。
- 5G LAN业务已交付且运行正常。
- 5G LAN用户在UDM上已完成5G LAN组签约，且存在调整所属5G LAN组的诉求。
- CA证书和设备证书需要客户提前申请，申请操作请参考 风筝L的“证书获取与申请”章节。

## 操作步骤

1. 登录OM Portal。
2. 进入“MML命令行-UEG”窗口。
3. 执行**ADD MPFLOGICINF**命令，配置NGVN逻辑接口。

   ```
   ADD MPFLOGICINF: NAME="ngvnif1/0/0", IPVERSION=IPV4, IPV4ADDRESS="10.1.7.111", VPNINSTANCE="VRF_LocalDN";
   ```
4. 配置TLS参数（TLS协议版本、算法套件、证书）。

   //作为服务端：

   ```
   ADD MEPTLSPARA: TLSPARANAME="tls01-server5glan", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=NGVN_DEV_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1, CACERTSCENE=NGVN_CA_CERT_SCENE;
   ```

   ```
   ADD MEPSERVERCOMMPARA: PARANAME="DefaultServerPara5GLAN", WAITREQHEADERTIMEOUT=60, WAITREQBODYTIMEOUT=60, SENDRSPTIMEOUT=60, KEEPALIVETIMEOUT=75, KEEPALIVEMAXREQNUM=1000;
   ```

   //作为客户端

   ```
   ADD MEPTLSPARA: TLSPARANAME="tls01-client5glan", PROTOCOL=TLSv12-1&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=10, DEVCERTSCENE=NGVN_DEV_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1, CACERTSCENE=NGVN_CA_CERT_SCENE;
   ```

   ```
   ADD MEPCLIENTCOMMPARA: PARANAME="DefaultClientPara5GLAN", CONNTIMEOUT=60, SENDREQTIMEOUT=60, WAITRSPTIMEOUT=60;
   ```
5. 增加MEP HTTP服务端组及MEP HTTP服务端。

   ```
   ADD MEPHTTPSERVERGRP: GROUPNAME="servergrp01";
   ```

   ```
   ADD MEPHTTPSERVER: SERVERNAME="ngvn-extNE", MEPHTTPSERVERGRP="servergrp01", SERVERTYPE=FOR_EXTERNAL_NE, IPV4="10.1.7.111", PORT=8443, TLSFLG=ENABLE, TLSPARANAME="tls01-server5glan", SERVERCOMMPARANAME="DefaultServerPara5GLAN";
   ```
6. 增加MEP HTTP客户端组及MEP HTTP客户端。

   ```
   ADD MEPHTTPCLIENTGRP: GROUPNAME="clientgrp01";
   ```

   ```
   ADD MEPHTTPCLIENT: CLIENTNAME="ngvn-extNE", MEPHTTPCLIENTGRP="clientgrp01", CLIENTTYPE=TO_CONNECT_EXTERNAL_NE, IPV4="10.1.7.111", TLSFLG=ENABLE, TLSPARANAME="tls01-client5glan", CLIENTCOMMPARANAME="DefaultClientPara5GLAN", PEERSERVICETAG=MEPSERVICE;
   ```
7. 增加反向代理配置。“校验对端证书（VERIFYPEER）”设置为“ENABLE”时需要配置，否则请跳过本配置。

   ```
   ADD MEPREVERSEPROXY: PROXYNAME="proxy_5glan01", MEPHTTPSERVERGRP="servergrp01", MEPHTTPCLIENTGRP="clientgrp01";
   ```
8. 激活支持认证鉴权License。

   ```
   SET LICENSESWITCH: LICITEM="LKV3G5APIG01", SWITCH=ENABLE;
   ```
9. 打开Oauth2.0鉴权。

   //“SERVICENAME”参数值通过**DSP MECSERVICE**命令查询获取。

   ```
   SET APIAUTH: ISAUTH=ENABLE;
   SET MEPAUTHMODE: AUTHMODE=BYLOCALPARA;
   ADD AUTHSERVLIST: NAME="serviceList";
   ADD AUTHSERV: SERVICENAME="AseMaster", SERVICELISTNAME="serviceList", AUTHVALIDTIME=2022&01&13&11&02&59;
   ADD APPAUTHINFO: APPID="appid_123", APIKEY="*****", SERVICELISTNAME="serviceList";
   ```
10. 执行**SET EDGESMCOMMFUNC**命令，开启5G LAN用户本地签约功能。

    ```
    SET EDGESMCOMMFUNC: LOCVNSUBSW=ENABLE;
    ```

    **说明** 

    调整5G LAN用户本地签约的5G LAN组ID后，运营商可通过**LST RDSSTATICIPPARA**查询多个用户本地签约的5G LAN组ID。
11. 执行**ADD EDGELOCSUBNGVN**命令，配置支持本地签约的5G LAN组。

    ```
    ADD EDGELOCSUBNGVN: GROUPID="000003e9-460-08-01", APN="dnn5glan01", GROUPNAME="5GLAN_for_localsub01";
    ```
