## 操作场景

UPF下沉，DN-AAA部署到企业或园区，SMF与DN-AAA之间不能直接互通，需要UPF转发SMF与DN-AAA之间二次鉴权的消息。

**说明** 

适用于UPF、SMF。

## 必备事项

前提条件

- 请仔细阅读终端二次鉴权特性概述。
- 完成Radius鉴权接入配置。
- 完成Radius功能配置。

**须知** 

激活RADIUS功能中配置到AAA Server的数据（双平面+OSPF动态路由+BFD组网 ）里 步骤5.配置Gi逻辑接口和步骤7.配置APN下的Client-IP在终端二次鉴权场景下为**可选配置**。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 增加与UPF对接的本端GTP-U地址。

   **ADD CPGTPUADDR**
3. 增加中转使用的UP到RADIUS服务器使用的UPF列表。

   **ADD UPLIST4RDS**
4. 可选配置：增加RADIUS服务器使用的UPF列表中指定UPF的功能属性。

   **ADD RDSUPFCTRL**
5. 增加中转UPF与Radius客户端的绑定关系。

   **ADD UPFRDSCLIENTIP**
6. 新增中转UPF与Radius服务器的绑定关系。

   **ADD UPFRDSSVR**
7. 添加网络实例。用于规划UPF与DN-AAA之间的VPN。

   **ADD NETWORKINSTVPNMAP**

## 验证方法

具体步骤请参见调测终端二次鉴权。

## 任务示例

任务描述

配置终端二次鉴权特性。

脚本

//增加与UPF对接的本端GTP-U地址。

```
ADD CPGTPUADDR:IPVERSION=IPV4,IPV4ADDR="192.168.0.20";
```

//向RADIUS服务器使用的UPF列表中增加UPF。

```
ADD UPLIST4RDS: UPLISTNAME="uplist1", UPINSTANCEID="up1";
```

//可选：增加RADIUS服务器的UPF列表中指定UPF的功能属性。

```
ADD RDSUPFCTRL: UPLISTNAME="uplist1", UPINSTANCEID="up1",PREFERENCE=1,LOCKED=ENABLE;
```

//增加中转UPF与Radius客户端的绑定关系。

```
ADD UPFRDSCLIENTIP: CLIENTYPE=AUTHENTICATION, IPVERSION=IPV4, UPLISTNAME="uplist1", VPNINSTANCE="vpnInstance1", CLIENTIPV4="192.168.10.1";
```

```
ADD UPFRDSSVR: SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="192.168.10.2", UPLISTNAME="uplist1";
```

//添加一个新的网络实例。

```
ADD NETWORKINSTVPNMAP: NETWORKINSTANCE="net1", HASVPN=ENABLE, VPNINSTANCE="VPN2auto", HASVPNIPV6=DISABLE;
```
