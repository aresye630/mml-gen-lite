# 配置N6侧免VxLAN隧道层二以太通信

## 操作场景

UEG 裸机容器直连PE免交换组网+企业交换机不支持VXLAN隧道时，UPF支持基于N6层二以太通信（免VXLAN隧道方案），实现层二5G LAN跨UPF的终端互访或与N6侧服务器的互通业务。

该场景下，需要部署N6侧免VxLAN隧道层二以太通信。

## 操作步骤

1. 配置5G LAN基本配置。

   详细配置请参见配置5G LAN基本功能，注意不能配置和VxLAN隧道相关的内容。
2. 修改5G LAN组配置。

   **MOD NGVNINSTANCE**
3. “VLANTYPE”设置为“WHITELIST”时，配置VLAN白名单。

   **ADD NGVNVLANWL**
4. “VLANTYPE”设置为“VLANMAP”时，配置VLAN映射数据。

   **ADD NGVNVLANMAP**
5. 配置主接口允许通过的VLAN。

   **ADD IFALLOWEDVLAN**

## 任务示例

任务描述

- 任务示例1：配置N6层二以太通信，“VLAN类型”为“WHITELIST”。
- 任务示例2：配置N6层二以太通信，“VLAN类型”为“VLANMAP”。
- 任务示例3：配置N6层二以太通信，“VLAN类型”为“UNIQUE”。

脚本

**//任务示例1**

//“VLAN类型”为“WHITELIST”。5G LAN终端携带的Vlan ID以2000为例，且企业服务器所在VLAN的Vlan ID与5G LAN终端携带的Vlan ID相同。

```
MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, PDNCONNECTTYPE=ETHTERNET, VLANTYPE=WHITELIST;
```

```
ADD NGVNVLANWL: VNINSTANCE="000003e9-460-08-01", VLANID=2000;
```

```
ADD IFALLOWEDVLAN: IFNAME="Ethernet64/0/7", IFNAME2="Ethernet64/0/8", VLANBEGIN=2000, VLANEND=2000;
```

**//任务示例2**

//“VLAN类型”为“VLANMAP”。5G LAN终端携带的Vlan ID以500为例，企业服务器所在VLAN以1000为例。

```
MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, PDNCONNECTTYPE=ETHTERNET, VLANTYPE=VLANMAP;
```

```
ADD NGVNVLANMAP: VNINSTANCE="000003e9-460-08-01", ORIGINALVLANID=500, MAPPEDVLANID=1000;
```

```
ADD IFALLOWEDVLAN: IFNAME="Ethernet64/0/7", IFNAME2="Ethernet64/0/8", VLANBEGIN=1000, VLANEND=1000;
```

**//任务示例3**

//“VLAN类型”为“UNIQUE”。5G LAN终端不携带Vlan或携带Vlan0，企业服务器所在VLAN以2000为例。

```
MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, PDNCONNECTTYPE=ETHTERNET, VLANTYPE=UNIQUE, VLANID=2000;
```

```
ADD IFALLOWEDVLAN: IFNAME="Ethernet64/0/7", IFNAME2="Ethernet64/0/8", VLANBEGIN=2000, VLANEND=2000;
```
