## 操作场景

本操作指导介绍在运行网络中激活支持网络切片模式下发的操作过程。

AMF支持基于PLMN（Public Land Mobile Network）配置NSSAI Inclusion Mode信元，来决定AMF控制UE在创建RRC（Radio Resource Control）连接时是否携带网络切片信息及携带此信息的方式。

**说明** 

适用于AMF。

## 必备事项

前提条件

请仔细阅读GWFD-026001 支持网络切片模式下发特性概述。

数据

| 类别              | 参数名称                    | 取值样例                | 获取方法   | 说明                           |
|:----------------|:------------------------|:--------------------|:-------|:-----------------------------|
| SET NGMMFUNC    | 3GPP接入方式下的网络切片包含模式（NIM） | MODE_A              | 本端规划   | AMF配置网络切片包含模式及下发NIM给UE的判断策略。 |
| SET NGMMFUNC    | 网络切片包含模式策略（NIMPLCY）     | STANDARD_MODE（标准模式） | 本端规划   | AMF配置网络切片包含模式及下发NIM给UE的判断策略。 |
| ADD NGMMSUBDATA | 3GPP接入方式下的网络切片包含模式（NIM） | MODE_A              | 本端规划   | AMF配置网络切片包含模式及下发NIM给UE的判断策略。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置网络切片包含模式。

   **ADD NGMMSUBDATA**
3. 配置下发NIM给UE的判断策略。

   **SET NGMMFUNC**

## 任务示例

任务描述

启用支持网络切片模式下发功能，配置网络切片包含模式为模式A，并使用标准模式向UE下发NIM的判断策略。

脚本

//配置网络切片包含模式。

```
ADD NGMMSUBDATA: SUBRANGE=HOME_USER, NIM=MODE_A;
```

//配置下发NIM给UE的判断策略。

```
SET NGMMFUNC: NIMPLCY=STANDARD_MODE;
```
