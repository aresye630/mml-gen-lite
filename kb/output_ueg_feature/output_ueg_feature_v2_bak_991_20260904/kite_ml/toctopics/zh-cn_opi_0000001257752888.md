# 激活NB-IoT终端标准接入（适用于S/PGW-C）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本操作指导介绍在运行网络中激活NB-IoT终端标准接入的操作过程。

**说明** 

适用于SGW-C、PGW-C。

## 必备事项

前提条件

请仔细阅读GWFD-026101 NB-IoT终端标准接入特性概述（适用于S/PGW-C）。

数据

| 类别                | 参数名称              | 取值样例         | 获取方法   | 说明                |
|:------------------|:------------------|:-------------|:-------|:------------------|
| SET LICENSESWITCH | License项（LICITEM） | LKV3WPNBPS11 | 本端规划   | 用于配置License控制项开关。 |
| SET LICENSESWITCH | 开关（SWITCH）        | ENABLE       | 本端规划   | 用于配置License控制项开关。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

启用NB-IoT终端标准接入（S/PGW-C）特性，并配置用户为NB-IoT第一档用户。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3WPNBPS11", SWITCH=ENABLE;
```

//配置用户为NB-IoT第一档用户。

```
SET LICENSESWITCH: LICITEM="LKV3WNBSL111", SWITCH=ENABLE;
```
