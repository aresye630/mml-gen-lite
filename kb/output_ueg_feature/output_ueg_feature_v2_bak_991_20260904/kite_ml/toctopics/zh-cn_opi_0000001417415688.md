# 配置PGW与业务发放系统的对接数据

## 操作场景

用户数据的增加、删除和更新，可支持如下两种方式。

- 通过业务发放系统发放用户数据

  运营商规划通过业务发放系统对PGW中的用户数据进行管理操作的场景，请参考本页面及如下页面进行配置。

  - 配置Restful接口数据
  - 配置全局数据

  **说明** 

  同一个用户5秒内的配置数据需要通过同一个TCP链接发给相同的PGW模块处理。
- 从SFTP服务器（中心UDM或外置SFTP服务器）同步用户数据

  运营商规划从SFTP服务器同步用户数据文件时，请参考如下页面进行操作。

  - 配置用户数据文件同步
  - 配置全局数据
  - 配置鉴权数据
  - 配置模板数据

## 必备事项

前提条件

- UDM和业务发放系统均完成了软件安装和基础数据的配置。
- PGW与运营商的业务发放系统的物理连接正常。

## 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**LST SRVIPADDR**命令查询存在与业务发放系统对接的IP地址。

   ```
   LST SRVIPADDR: SRVIPTYPE=PGW;
   ```

   查看是否存在业务IP类型为PGW的IP地址：

   - 不存在=>5。
   - 存在PGW类型IP，但只有IP1，没有IP2时=>3。
   - 存在PGW类型IP，且是IP1和IP2两个IP时=>6。
3. 确认业务发放系统和PGW Web LMT的IP是否属于同一网段。
   - 是=>6。
   - 否=>4。
4. 业务发放系统和PGW Web LMT的IP属于不同网段时，删除PGW类型的业务IP地址，然后再执行5。

   //执行**RMV SRVIPADDR**命令删除PGW类型的业务IP地址。此处以需删除的PGW类型的IP地址索引是3为例。

   ```
   LST SRVIPADDR: SRVIPTYPE=PGW;
   ```

   ```
   RMV SRVIPADDR: SRVINDEX=3, SRVIPTYPE=PGW;
   ```
5. 增加业务IP地址，以参数“IPVER”值为“IPV4”为例。

   ```
   ADD SRVIPADDR: SRVINDEX=3, SRVIPTYPE=PGW, DPUMID=3, IPVER=IPV4, IP1VPNNAME="VRF_provisioning", IPV4IP1="10.200.200.36", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_OM", IPV4IP2="10.200.200.37", IPV4MASK2="255.255.255.255";
   ```
6. 配置PGW的IP限制功能。
   - PGW不校验管理用户数据的源IP时，关闭IP限制开关。

     ```
     MOD INSP: INSPT=PGW,INSPN=GRANTIPSWITCH, INSPV=0;
     ```
   - PGW校验管理用户数据的源IP时，增加允许的IP地址。设置后，只允许特定IP的客户端能登录PGW。

     ```
     ADD PROVISIONIP: ADDRID=1, ADDRNAME="PRVIP01", IPVER=IPV4, IPV4ADDR="10.10.100.20", IPTYPE=REST, IPV4MASK="255.255.255.255";
     ADD PROVISIONIP: ADDRID=2, ADDRNAME="PRVIP02", IPVER=IPV4, IPV4ADDR="10.10.100.20", IPTYPE=SOAP, IPV4MASK="255.255.255.255";
     ADD PROVISIONIP: ADDRID=3, ADDRNAME="PRVIP03", IPVER=IPV4, IPV4ADDR="10.200.200.37", IPTYPE=WEBLMT, IPV4MASK="255.255.255.255";
     ADD PROVISIONIP: ADDRID=4, ADDRNAME="PRVIP04", IPVER=IPV4, IPV4ADDR="10.10.100.20", IPTYPE=REST, IPV4MASK="255.255.255.255";
     ```

     ```
     MOD INSP: INSPT=PGW,INSPN=GRANTIPSWITCH, INSPV=1;
     ```
7. 设置软参“营帐权限开关”、“TLS工作模式”。请根据局点规划设置。

   ```
   MOD INSP:INSPT=FE,INSPN=PROVRIGHTSWITCH,INSPV=0,FETYPEN="USCDB"; 
   MOD INSP:INSPT=FE,INSPN=PROVRIGHTSWITCH,INSPV=0,FETYPEN="HSS9860"; 

   MOD INSP: INSPT=FE, INSPN=TLSMODE, INSPV=0, FETYPEN="USCDB";
   MOD INSP: INSPT=FE, INSPN=TLSMODE, INSPV=0, FETYPEN="HSS9860";
   ```
8. 重启PGW模块。

   **说明** 

   重启PGW模块的操作需要在登录PGW Web LMT之前进行，否则PGW Web LMT界面的Service Management MML导航树显示为空。

   ```
   RST MODULE: MID=7, MT=PGW; 
   RST MODULE: MID=8, MT=PGW;
   ```
9. 登录PGW Web LMT MML命令界面。

   详细操作请参见登录与退出PGW Web LMT。
10. 增加BOSS账号，用于BOSS登录设备进行业务发放。

    ```
    ADD OPR: SYSHLRSN=1, OPNAME="boospgwuser", DESC="boos in pgw system", PWD="*****", CFM="*****", UG=OPERATOR, STATUS=ACTIVE, ATP=MACHINE-TO-MACHINE;
    ```

## 验证方法

1. 登录“USCDB MML命令”界面。
2. 执行**LST MODULE**命令查询PGW模块，检查是否配置正确。

   ```
   LST MODULE: MT=PGW;
   ```

   - 正确，请执行3。
   - 不正确，请重新添加PGW模块。然后重新查询PGW模块，正确后执行3。
3. 执行**LST SRVIPADDR**命令查询PGW对业务发放系统提供的IP是否正确。

   ```
   LST SRVIPADDR: SRVIPTYPE=PGW;
   ```

   - 正确，请执行4。
   - 不正确，请删除错误的IP后，重新添加正确的IP，然后执行4。
4. 在业务发放系统服务器上，使用ping命令检查PGW与业务发放系统的网络连接情况。

   如果PGW提供给业务发放系统的IP为10.200.200.36，则检查命令举例为：

   ```
   ping 10.200.200.36
   ```

   - 能ping通，且PGW校验管理用户数据的源IP，请执行5。
   - 能ping通，且PGW不校验管理用户数据的源IP，调测结束。
   - 不能ping通，请联系华为技术支持。

   **说明** 

   - 业务发放系统存在的操作系统可能不同，ping命令的使用方法见具体操作系统的帮助说明。
   - 如果出现类似超时如Request time out信息时，说明网络不通，需要检查网络连接。
     - 检查PGW对业务发放系统提供服务的网线物理连接是否正常。
     - 检查PGW与业务发放系统之间路由配置是否正确。
5. 执行**LST PROVISIONIP**命令是否包含业务发放系统/PGW Web LMT的IP地址。

   ```
   LST PROVISIONIP:;
   ```

   - 包含，调测结束。
   - 不包含，请参考6，添加允许的IP地址。
