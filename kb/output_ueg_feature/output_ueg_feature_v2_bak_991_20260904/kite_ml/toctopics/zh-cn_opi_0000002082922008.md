## 操作场景

5G LAN支持基于IGMP Snooping实现层二动态组播功能时，需要配置本页面。

## 必备事项

前提条件

- 请仔细阅读GWFD-030703 支持IGMP Snooping特性概述。
- 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。
- 已完成配置5G LAN基本功能。

## 操作步骤

1. 开启IGMP Snooping功能开关。

   **MOD NGVNINSTANCE**

   - 网络中无查询器，UPF作为查询器时，请执行2。
   - 网络中其他设备作为查询器时，请执行3。
2. 配置UPF支持Query功能。网络中无查询器时，在UPF上配置Query功能。
   1. 配置Query消息的源MAC地址。

      **SET UPETHSRVPARA**
   2. 开启Query查询功能并设置查询参数。

      **SET IGMPSNOOPINGATTR**
3. 网络中其他设备作为查询器时，配置Query参数。基于query参数判断组播组成员的状态。

   **SET IGMPSNOOPINGATTR**
4. 配置N3侧的组播源。组播源在N3侧时需要配置，组播源在N6侧/另一UPF下时，无需配置。

   **ADD MULTICASTSOURCE**

## 验证方法

1. 执行**LST NGVNINSTANCE**命令，检查“IGMP Snooping开关（IGMPSNOOPINGSW）”取值是否为“ENABLE”。
   - 是，请执行2。
   - 否，请参考操作步骤将“IGMP Snooping开关（IGMPSNOOPINGSW）”设置为“ENABLE”后执行2。
2. 选择三个测试终端（终端A、B、C），这三个测试终端设置成属于同一个IGMP组播组。
3. 终端设置正常后，分别发起加入组播组的请求消息。
4. （组播源在N6/N19侧）组播源发送组播业务报文，在UPF上观测是否将该组播报文仅向组播组内的所有终端发送。
   - 是，IGMP组播业务正常。
   - 否，请联系华为技术支持处理。
5. （组播源在N3侧）组播源发送组播业务报文，在UPF上观测是否将该组播报文仅向组播组内的所有终端发送。
   - 是，IGMP组播业务正常。
   - 否，请执行6。
6. 执行**LST MULTICASTSOURCE**命令，检查N3侧组播源是否已配置。
   - 是，请联系华为技术支持处理。
   - 否，请参考操作步骤4配置N3侧组播源后执行5。

## 任务示例

任务描述

- 任务实例一：5G LAN业务存在组播业务，且5G LAN终端支持基于IGMP Snooping协议加入组播组时，开启IGMP Snooping功能。网络中其他设备作为查询器。
- 任务实例二：5G LAN业务存在组播业务，且5G LAN终端支持基于IGMP Snooping协议加入组播组时，开启IGMP Snooping功能。UPF作为查询器。

脚本

**//任务实例一**：网络中其他设备作为查询器

//开启IGMP Snooping功能开关。

```
MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, IGMPSNOOPINGSW=ENABLE;
```

//网络中其他设备作为查询器时，在UPF上配置Query参数。

```
SET IGMPSNOOPINGATTR: VNINSTANCE="000003e9-460-08-01", QUERIERSW=DISABLE, QUERYINTERVAL=60, MAXRSPTIME=10, ROBUSTCOUNT=2;
```

//组播源在N3侧且组播源是IMSI时需要配置。

```
ADD MULTICASTSOURCE: VNINSTANCE="000003e9-460-08-01", MCSOURCETYPE=IMSI, IMSI="460123123456787";
```

//组播源在N3侧且组播源是双发选收结对时需要配置。

```
ADD MULTICASTSOURCE: VNINSTANCE="000003e9-460-08-01", MCSOURCETYPE=DFSRPAIR, DFSRPAIRID=10;
```

**//任务实例二**：UPF作为查询器

//开启IGMP Snooping功能开关。

```
MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, IGMPSNOOPINGSW=ENABLE;
```

//网络中无查询器时，在UPF上配置Query功能。

```
SET UPETHSRVPARA: UPETHSRVSW=ENABLE, UPETHSRVMAC="FA-16-3E-A0-04-D6";
```

```
SET IGMPSNOOPINGATTR: VNINSTANCE="000003e9-460-08-01", QUERIERSW=ENABLE, QUERYINTERVAL=60, MAXRSPTIME=10, ROBUSTCOUNT=2, SOURCEADDR="192.168.0.1";
```

//组播源在N3侧且组播源是IMSI时需要配置。

```
ADD MULTICASTSOURCE: VNINSTANCE="000003e9-460-08-01", MCSOURCETYPE=IMSI, IMSI="460123123456787";
```

//组播源在N3侧且播源是双发选收结对时需要配置。

```
ADD MULTICASTSOURCE: VNINSTANCE="000003e9-460-08-01", MCSOURCETYPE=DFSRPAIR, DFSRPAIRID=10;
```
