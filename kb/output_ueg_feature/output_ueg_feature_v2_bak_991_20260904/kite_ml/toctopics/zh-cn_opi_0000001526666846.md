# 配置容灾模式

- 操作场景
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

为避免单点故障，园区需部署两套UEG实现容灾。

两套UEG采用负荷分担容灾时，需要参考本页面进行配置。

**注意** 

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 必备事项

前提条件

已完成各NF选择本UEG内NF的数据配置。

数据

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别                  | 参数名称                        | 取值样例 （DC1）   | 取值样例 （DC2）   | 获取方法   | 说明                                   |
|:--------------------|:----------------------------|:-------------|:-------------|:-------|:-------------------------------------|
| SET DRCOUPLINGRESET | 是否使能负荷分担容灾功能（COUPLINGRESET） | YES          | YES          | 本端规划   | 两套UEG采用负荷分担容灾时设置为“YES”，其他情况下设置为“NO”。 |
| SET DRKEYNF         | 是否监控MME服务（MME）              | NO           | NO           | 固定取值   | -                                    |
| SET DRKEYNF         | 是否监控AMF服务（AMF）              | NO           | NO           | 固定取值   | -                                    |
| SET DRKEYNF         | 是否监控HSS服务（HSS）              | NO           | NO           | 固定取值   | -                                    |
| SET DRKEYNF         | 是否监控UDM服务（UDM）              | NO           | NO           | 固定取值   | -                                    |
| SET DRKEYNF         | 是否监控SMF服务（SMF）              | NO           | NO           | 固定取值   | -                                    |
| SET DRKEYNF         | 是否监控GW-C服务（GWC）             | NO           | NO           | 固定取值   | -                                    |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 使能负荷分担容灾功能。

   ```
   SET DRCOUPLINGRESET: COUPLINGRESET=YES;
   ```
3. 设置监控的关键部件信息。

   **注意** 

   - UEG作为风筝M时，仅监控UPF。
   - 开启容灾功能的UEG出现设备异常，需要通过重新实例化操作进行恢复的场景：若MML文件中**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值存在“YES”，则在导入MML文件进行配置恢复前，需要先修改MML文件，将**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值“YES”修改为“NO”；待HSS、UDM、PCRF、PCF、UDR服务的配置恢复完成后，再按照修改前的**SET DRKEYNF**配置重新开启对这些服务的监控。

   ```
   SET DRKEYNF: MME=NO, AMF=NO, HSS=NO, UDM=NO, SMF=NO, GWC=NO, PCF=NO, PCRF=NO, UPF=YES, UDR=NO;
   ```

## 验证方法

1. 执行对应的LST命令，检查配置是否与规划一致。
   - 检查是否使能负荷分担容灾功能。

     执行**LST DRCOUPLINGRESET**命令进行检查，如配置错误，则重新执行2进行设置。
   - 检查监控的关键部件设置是否正确。

     执行**LST DRKEYNF**命令进行检查，如配置错误，则重新执行3进行设置。
