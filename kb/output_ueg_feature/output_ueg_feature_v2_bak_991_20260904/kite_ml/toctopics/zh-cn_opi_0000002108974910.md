# 激活IP地址精简

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

UEG风筝L场景，UDM/HSS部署在园区网络时，如下场景下需要激活IP地址精简。

- 4G场景，规划S1-MME与S1-U逻辑接口共用IP地址+VPN实例时，请参考本章节进行配置。
- 5G场景，规划N2与N3逻辑接口共用IP地址+VPN实例时，请参考本章节进行配置。
- 4/5G融合部署场景，规划S1-MME、S1-U、N2、N3逻辑接口共用IP地址+VPN实例时，请参考本章节进行配置。

## 必备事项

前提条件

- 请仔细阅读GWFD-023003 IP地址精简特性概述。
- 请了解UEG各类接口的类型及命名规范，具体内容请参见逻辑接口介绍（风筝L）。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 开启IP地址精简开关。

   ```
   SET CUSINGLEIPATTR: SWITCH=ENABLE;
   ```
3. 配置N2/S1-MME业务接口IP。

   ```
   ADD SERVICEIP:IPVERSION=IPv4, SERVICEIPV4="172.20.1.29",VPNINSTNAME="VRF_Access", DESC="N2&S1-MME";
   ```

   ```
   ADD SERVICEIP:IPVERSION=IPv4, SERVICEIPV4="172.20.1.30", VPNINSTNAME="VRF_Access", DESC="N2&S1-MME";
   ```
4. 4G或者4/5G融合场景，配置S1AP链路本地实体。

   ```
   ADD CPSCTPPARA:SCTPPARAINDEX=1,SCTPPARANAME="For_S1AP";
   ```

   ```
   ADD S1APLE:LLEINDEX=1, IPTYPE=TPTADDR_TYPE_IPV4, LOCALIPV4_1="172.20.1.29", LOCALIPV4_2="172.20.1.30", LOCALPORT=36412, CROSSIPFLAG=NO, SCTPINDEX=6, LLNAME="S1AP-0", VPNNAME="VRF_Access";
   ```
5. 5G或者4/5G融合场景，配置NGAP链路本地实体。

   ```
   ADD NGAPPARA:NGAPPARAIDX=1, AMFCFGUPTTMR=20, AMFCFGUPTCNT=3, RESETTMR=20, RESETCNT=3, TIMETOWAITTMR=Sixty, TIMETOWAITFLG=Yes;
   ```

   ```
   ADD NGAPLE:NGAPLEIDX=1, SCTPGROUPID=1, NGAPPARAIDX=1;
   ```
6. 配置SCTP协议参数及SCTP本端实体。

   ```
   ADD SCTPLEGRP:SCTPGROUPID=1;
   ```

   ```
   ADD SCTPLE:SCTPLEIDX=1, SCTPGROUPID=1, IPVERSION=IPV4, LOCALIPV41="172.20.1.29", LOCALIPV42="172.20.1.30", PORT=38412, CROSSIPFLG=E_SCTP_CROSS_YES, SCTPPARAIDX=0, USAGE=E_SCTP_USAGE_BOTH, WEIGHT=127;
   ```
7. 配置N3/S1-U逻辑接口IP。

   ```
   ADD LOGICINF:NAME="saif1/1/0", IPV4ADDRESS1="172.20.1.29", IPV4MASK1="255.255.255.255", IPV4MTU=1500, VPNINSTANCE="VRF_Access", IPVERSION=IPV4, SLICEATTRSW=DISABLE;
   ```
