# 配置应急AMF和应急SMF

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

高可用边缘网关部署在企业园区，新开局场景，需要配置应急AMF和应急SMF实体功能，以保证应急场景下新注册用户或发生信令交互的已注册用户能够正常开展业务。

**图1** 应急AMF和应急SMF与其他网络实体的逻辑接口

## 必备事项

前提条件

- 已完成软件安装。
- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
- 已加载License文件。

数据

**说明** 

如下数据仅为举例，请注意修改成局点规划的数据。

| 0           | 1                                 | 2               | 3                                 | 4                               | 5               |
|:------------|:----------------------------------|:----------------|:----------------------------------|:--------------------------------|:----------------|
| 逻辑接口/ 服务化接口 | N2                                | 应急N4            | N8/N11/N12（AMF）                   | N10/N11（SMF）                    | Gi              |

| IPv6地址      | FC00::172:16:2:5 FC00::172:16:2:6 | FC00::10:26:0:6 | FC00::172:16:1:5 FC00::172:16:1:6 | FC00::10:16:0:6 FC00::10:16:0:7 | FC00::10:8:20:1 |

- 应急AMF和基站之间传输N2报文的外联口，此处以复用UPF和基站之间传输N3报文的外联口为例。
- 园区部署两套UEG实现容灾时，各NF仅选择本UEG内的NF，不交叉互连。
- 应急SMF与UPF之间，同一UEG内通过内置交换模块互通。不需要规划N4对应的外联口IP&路由数据。

  UEG间的应急SMF与UPF，不需要互通。
- 应急AMF/应急SMF与应急UDM之间，同一UEG内通过内置交换模块互通。不需要规划N8/N10/N12/N11对应的外联口IP&路由数据。

  UEG间的应急SMF与应急UDM、应急AMF与应急SMF，不需要互通。UEG间的应急AMF与应急UDM（包括AUSF）需要互通，仅用于应急UDM通过N8接口主动向另一UEG中的应急AMF发送cancel location报文。
- 传输UEG间N8报文的外联口与传输N3报文的物理口复用。N8外联口IP及路由的配置，请参考N3外联口IP及路由配置。

## 操作步骤

- 关闭自动配置开关。

  1. 查询自动配置开关。

     ```
     LST AUTOCONFIG:;
     ```

     - 如果“自动配置开关”值为“TRUE”，需要执行1.b和1.c关闭自动配置开关。
     - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到3。
  2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

     ```
     DSP OPSASSISTSTATE:;
     ```
  3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

     ```
     SET AUTOCONFIG:SWITCHFLAG=FALSE;
     ```

- 配置UEG间传输N8接口报文的IP路由数据。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_SBI";
     ADD VPNINSTAF:VRFNAME="VRF_SBI",AFTYPE=ipv4uni, VRFRD="192.168.225.205:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_SBI",AFTYPE=ipv6uni, VRFRD="192.168.225.205:100";
     ```

     **说明** 

     步骤2.b~步骤2.f是BGP相关数据，仅采用BGP over静态路由+BFD时需要配置。采用静态路由+BFD时不需要配置。
  2. 配置Loopback接口IP。用于建立BGP邻居。

     ```
     ADD INTERFACE:IFNAME="LoopBack205";
     ADD IPBINDVPN:IFNAME="LoopBack205",VRFNAME="VRF_SBI";
     ADD IFIPV4ADDRESS:IFNAME="LoopBack205",IFIPADDR="192.168.225.205",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
     ```

     ```
     SET IFIPV6ENABLE: IFNAME="Loopback205", ENABLEFLAG=TRUE;
     ADD IFIPV6ADDRESS:IFNAME="Loopback205",IPV6ADDRESS="FC00::225:205",PREFIXLEN=128;
     ```
  3. 配置BGP VPN实例。

     ```
     ADD BGPVRF: VRFNAME="VRF_SBI", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.205";
     ```
  4. 增加BGP VPN实例地址族。

     //UEG对接2个负荷分担的BGP PEER，“MAXIMUMLOADBALANCE”设置为“2”。

     ```
     ADD BGPVRFAF: VRFNAME="VRF_SBI", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
     ```

     ```
     ADD BGPVRFAF: VRFNAME="VRF_SBI", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
     ```
  5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

     ```
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.205", REMOTEAS="60002", LOCALIFADDR="192.168.225.205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.205", REMOTEAS="60002", LOCALIFADDR="192.168.225.205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ```

     ```
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:205", REMOTEAS="60002", LOCALIFADDR="FC00::225:205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:205", REMOTEAS="60002", LOCALIFADDR="FC00::225:205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ```
  6. 配置BGP引入wlr路由。

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_SBI", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_SBI", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```
  7. 添加以太网隧道多虚拟网卡自动化配置模板。如已配置，请跳过本步骤。

     ```
     ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
     ```
  8. 配置外联口自动部署模板。

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_SBI_2205_v4",VPNNAME="VRF_SBI",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2205, BEGINADDR4="192.168.205.2", ENDADDR4="192.168.205.30", MASKLEN=27;
     ```

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_SBI_2205_v6",VPNNAME="VRF_SBI",AFTYPE=IPv6,IPALLOCTYPE6=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2205, BEGINADDR6="FC00::205:2", ENDADDR6="FC00::205:1E", MASKLEN=123;
     ```
  9. 增加BFD会话自动部署模板。

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2205_v4", BFDTYPE=Static, SERVICENAME="ServName_SBI_2205_v4", IPVERSION=IPv4, DESTADDR4="192.168.205.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2205_v6", BFDTYPE=Static, SERVICENAME="ServName_SBI_2205_v6", IPVERSION=IPv6, DESTADDR6="FC00::205:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```
  10. 采用BGP over静态路由时，增加静态路由自动化部署模板。采用静态路由+BFD时，请跳转到2.k。

      //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v4", VRFNAME="VRF_SBI", IPVERSION=IPv4, PREFIX4="192.168.79.205", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.205.1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v4"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v4", VRFNAME="VRF_SBI", IPVERSION=IPv4, PREFIX4="192.168.78.205", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.205.1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v4";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v4", VRFNAME="VRF_SBI", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.205.1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v4";
      ```

      //“PREFIX6”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v6", VRFNAME="VRF_SBI", IPVERSION=IPv6, PREFIX6="FC00::79:205", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::205:1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v6"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2206_v6", VRFNAME="VRF_SBI", IPVERSION=IPv6, PREFIX6="FC00::78:205", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::205:1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v6";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX6”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v6", VRFNAME="VRF_SBI", IPVERSION=IPv6, PREFIX6="0:0:0:0:0:0:0:0", MASKLENGTH=0, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::205:1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v6";
      ```
  11. 采用静态路由+BFD时，增加静态路由自动部署模板。

      //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（另一UEG的S6a/N8/N14逻辑接口IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v4", VRFNAME="VRF_SBI", IPVERSION=IPv4, PREFIX4="10.200.200.27", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.205.1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v4"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v4", VRFNAME="VRF_SBI", IPVERSION=IPv4, PREFIX4="10.200.200.27", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.205.1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v4";
      ```

      //“PREFIX6”和“MASKLENGTH”是目的IP和掩码（另一UEG的S6a/N8/N14逻辑接口IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v6", VRFNAME="VRF_SBI", IPVERSION=IPv6, PREFIX6="FC00::10:200:200:27", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::205:1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v6"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_SBI_2205_v6", VRFNAME="VRF_SBI", IPVERSION=IPv6, PREFIX6="FC00::10:200:200:27", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::205:1", BFDENABLE=TRUE, DESCRIPTION="VRF_SBI", BFDTEMPLATENAME="BFD_2205_v6";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX6”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_AAA_2206_v6", VRFNAME="VRF_AAA", IPVERSION=IPv6, PREFIX6="0:0:0:0:0:0:0:0", MASKLENGTH=0, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::206:1", BFDENABLE=TRUE, DESCRIPTION="VRF_AAA", BFDTEMPLATENAME="BFD_2206_v6";
      ```

- 打开自动部署开关。

  ```
  SET AUTOCONFIG: SWITCHFLAG=TRUE;
  ```

  **说明** 

  从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行**DSP OPSASSISTSTATE**命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。
