## 操作场景

**说明** 

- 两个UPF是负荷分担关系，且连接到同一对DCGW/VxLAN交换机时，同一5G LAN组内成员跨UPF的互访可通过UPF间的VxLAN隧道（VxLAN N19）或UPF间的N19接口（3GPP N19）实现。
- 两个UPF是负荷分担关系，且连接到不同对DCGW/VxLAN交换机时，同一5G LAN组内成员跨UPF的互访可通过UPF与DCGW/VxLAN交换机之间的VxLAN隧道或UPF间的N19接口（3GPP N19）实现。

两个UPF是负荷分担关系，通过UPF间的VxLAN隧道（VxLAN N19）或UPF间的N19接口（3GPP N19）实现同一5G LAN组内成员跨UPF的互访时，需要参考本章节进行配置。

两个UPF是负荷分担关系，通过UPF与DCGW/VxLAN交换机之间的VxLAN隧道实现同一5G LAN组内成员跨UPF的互访时，在UPF仅需上完成配置5G LAN基本功能中的配置支持网络侧基于VXLAN的以太通信，不需要配置本章节，但该方案要求不同对DCGW/VxLAN交换机之间能够互通。

前提条件

- 已完成配置5G LAN基本功能。

## 操作步骤

通过UPF间的VxLAN隧道（VxLAN N19）实现跨UPF的终端互访

1. 配置VXLAN隧道端点（VTEP）。

   **ADD VTEP**

   ```
   ADD VTEP: VTEPNAME="VTEP2", IPVERSION=IPV4, VTEPIPV4="10.1.50.2";
   ```
2. 配置VXLAN端点绑定VXLAN隧道组。

   **ADD VTEPBINDGRP**

   ```
   ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP2", PRIFLAG=PRIMARY;
   ```

通过UPF间的N19（3GPP N19）实现跨UPF的终端互访

3. 配置5G LAN基本配置。

   详细配置请参见配置5G LAN基本功能，注意不能配置UPF之间的VXLAN隧道相关的内容。
4. 开启5G LAN N19功能开关。

   **SET NGLANFUNC**

   ```
   SET NGLANFUNC: NGLANSW=ENABLE, N19FORWARDSW=ENABLE;
   ```
5. 配置N19逻辑接口所属的VPN实例。N19逻辑接口与其他逻辑接口共用VPN实例时，请跳过本步骤。

   **ADD VPNINST**

   ```
   ADD VPNINST: VPNINSTANCE ="VRF_N19";
   ```

   **说明** 

   逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
6. 配置N19逻辑接口。

   **ADD LOGICINF**

   ```
   ADD LOGICINF:NAME="N19if1/1/0",IPVERSION=IPV4,IPV4ADDRESS1="10.1.19.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="VRF_N19";
   ```
7. 修改5G LAN组配置。

   **MOD NGVNINSTANCE**

   ```
   MOD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, PDNCONNECTTYPE=VXLAN, VXLANINTERWORK=NO, ULUKNUCASTFWNX=ENABLE, ULUKNMCASTFWNX=ENABLE, ULBCASTFWNX=ENABLE, MACRPTMODE=ALL_MAC_RPT;
   ```

3GPP N19之间的echo探测功能

8. 查询路径相关属性。

   **LST UPGTPPATH**

   ```
   LST UPGTPPATH:;
   ```

   - “EchoList 类型”取值为“白名单”时，执行9。
   - “EchoList 类型”取值为“黑名单”时，不能执行9。
9. 将对端UPF的N19接口IP添加到IP列表中。

   **ADD ECHOIPLIST**

   ```
   ADD ECHOIPLIST: IPVERSION=IPV4, IPV4ADDR="10.3.3.3", IPV4MASK=32;
   ```

UPF间N6 VxLAN隧道互通探测

- 本端UPF和对端UPF必须是基于同一个5G LAN组的互通探测。
- 如下步骤需要在本端UPF和对端UPF上分别执行。

10. 检查是否已配置以太业务MAC和5G LAN组虚接口。

    **LST UPETHSRVPARA**

    **LST NGVNVIF**

    ```
    LST UPETHSRVPARA:;
    ```

    ```
    LST NGVNVIF: VNINSTANCE="000003e9-460-08-01";
    ```

    如未配置，请参考配置5G LAN基本功能完成**SET UPETHSRVPARA**和**ADD NGVNVIF**配置。
11. 查询5G LAN组会话是否已激活。

    ```
    DSP SESSIONINFO: QUERYTYPE=VNINSTANCE, DISPLAYMODE=SIMPLE, VNINSTANCE="000003e9-460-08-01";
    ```

    如未激活，需要先激活5G LAN组会话。
12. 探测N6 VxLAN隧道能否互通。

    **TST NGVXLANCONNECT**
