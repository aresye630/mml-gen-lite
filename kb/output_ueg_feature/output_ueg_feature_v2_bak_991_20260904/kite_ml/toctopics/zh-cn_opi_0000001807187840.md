# 确定性时延转发特性激活

- 操作场景
- 必备事项

## 操作场景

在UEG需要控制确定性时延转发，需要配置低时延转发功能。

**说明** 

适用于UPF。

## 必备事项

前提条件

- 请仔细阅读确定性时延转发特性概述。
- UEG完成与周边网元的对接。

数据

| 类别            | 参数名称                   | 取值样例      | 获取方法   | 说明                     |
|:--------------|:-----------------------|:----------|:-------|:-----------------------|
| SET DEEPISOSW | 转发线程深度隔离开关（SWITCH）     | ENABLE    | 固定取值   | 指定系统转发核是否需要开启转发线程深度隔离。 |
| SET BATCHPARA | 数据转发阶段名称（STAGENAME）    | FASTSTAGE | 本端规划   | 指定数据转发阶段。              |
| SET BATCHPARA | 最大读取报文次数（MAXREADTIMES） | 2         | 本端规划   | 设置最大读取报文次数。            |
| SET BATCHPARA | 最大读取报文数目（MAXREADNUM）   | 128       | 本端规划   | 设置最大读取报文数目。            |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 打开转发线程深度隔离开关。

   **SET DEEPISOSW**
3. 确认转发线程深度隔离开关已开启。

   **DSP DEEPISOSWINFO**

   **注意** 

   请在执行**DSP DEEPISOSWINFO**后3分钟左右再进行下一步。
4. 重启设备。该操作请联系华为技术支持。
5. （可选）设置批量处理的报文数量。

   **SET BATCHPARA**

   **注意** 

   批量处理的报文数量越小，对CPU影响越大，请根据具体使用场景合理设置转发报文数量。

## 任务示例

任务描述

设置转发线程深度隔离后，减少批量读取转发报文次数和数量，以此减少转发时延。

脚本

//开启确定性时延转发特性license开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5DLAF01", SWITCH=ENABLE;
```

//打开转发线程深度隔离开关。

```
SET DEEPISOSW:SWITCH=ENABLE;
```

//查询转发线程深度隔离开关是否开启，确认开启后再执行下一步骤。

```
DSP DEEPISOSWINFO:;
```

//确定转发线程深度隔离开关开启后，需要设备重启，重启操作请联系华为技术支持。

```
SET BATCHPARA: STAGENAME=FASTSTAGE, MAXREADTIMES=2, MAXREADNUM=128;
```
