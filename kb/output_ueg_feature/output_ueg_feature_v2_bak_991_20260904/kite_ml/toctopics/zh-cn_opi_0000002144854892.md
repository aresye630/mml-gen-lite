# 激活RedCap接入（AMF和SMF，周边部分网元未升级场景）

- 操作场景
- 对系统的影响
- 必备事项

## 操作场景

本操作指导用于gNodeB和部分网元（AMF和SMF）支持RedCap功能的场景下，激活RedCap用户接入。RedCap功能支持周边网元免升级的情况，当部分网元不支持RedCap功能时，会将其当作普通NR用户处理。

**说明** 

适用于AMF和SMF。

## 对系统的影响

该操作对系统正常运行没有影响。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 增加AMF兼容性策略：

   **SET AMFREDCAPFUNC**
3. 设置SMF扩展功能：

   **SET SMFFUNC**
4. 设置RedCap终端接入RAT填写值：

   **SET REDCAPRATVALUE**

## 任务示例

任务描述

在gNodeB和部分网元（AMF和SMF）支持RedCap功能的场景下，激活RedCap用户接入。

脚本

//打开AMF上的RedCap功能开关，RatType周边SMF兼容性开关，配置AMF通知空闲态会话SMF策略为立即通知。

```
SET AMFREDCAPFUNC:REDCAPSW=YES,RATCMPTSW=UDM-0&PCF-0&SMSF-0&SMF-1,NTYSMFPLCY=IMMEDIATELY_NOTIFY_ON_CHANGE-1&CHANNEL_ASSOCIATED_NOTIFY-0;
```

//打开SMF上的RedCap功能开关。

```
SET SMFFUNC: REDCAPSW=Support;
```

//配置SMF向所有周边网元传递RatType的值为NR。

```
SET REDCAPRATVALUE: CHF=NR,PCF=NR,UPF=NR,AAAACCT=NR,AAAAUTH=NR,N16SMF=NR,N16ASMF=NR;
```
