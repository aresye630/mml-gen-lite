# 配置支持NB-IoT eDRX模式特性

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

该任务旨在指导操作人员签约/修改/去签约PTW寻呼时间窗参数。

## 必备事项

前提条件

- 请仔细阅读WHFD-800039 支持NB-IoT eDRX模式特性概述。
- 用户为EPS网络用户。
- 操作人员具有数据配置权限。
- 操作人员具有登录PGW Web LMT的用户名和密码。

数据

阅读配置前的必读信息如表1所示。

|   参数颜色 | 来源                                   |
|-------:|:-------------------------------------|
|    nan | 内部固化参数，指全球所有运营商网络均推荐使用的参数取值，使用时无需改变。 |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 签约PTW寻呼时间窗参数。可以执行**ADD SUB**命令为用户开户时直接进行签约，也可以先在**ADD SUBTPL**/**ADD EPSUSERTPL**开户模板命令中签约后，再执行**ADD SUB**命令为用户进行模板开户。
   - 执行**ADD SUBTPL**命令，定义“用户模板类型”为“NORMAL”的用户开户模板，在开户模板中设置PTW寻呼时间窗参数。
   - 执行**ADD EPSUSERTPL**命令，定义EPS用户开户模板，在开户模板中设置PTW寻呼时间窗参数。
   - 执行**ADD SUB**命令，为用户开户，设置PTW寻呼时间窗参数。
3. 修改PTW寻呼时间窗参数。可以执行**MOD EPS**命令为用户修改PTW参数，也可以执行**MOD SUBTPL**/**MOD EPSUSERTPL**命令修改开户模板中的PTW参数，开户模板中数据修改后，会应用到所有使用模板开户的用户中。
   - 执行**MOD SUBTPL**命令，修改“用户模板类型”为“NORMAL”的用户开户模板中的PTW寻呼时间窗参数。
   - 执行**MOD EPSUSERTPL**命令，修改EPS用户开户模板中的PTW寻呼时间窗参数。
   - 执行**MOD EPS**命令，修改用户的PTW寻呼时间窗参数。
4. 去签约PTW寻呼时间窗参数。可以执行**MOD EPS**命令为用户去签约PTW参数，也可以执行**MOD SUBTPL**/**MOD EPSUSERTPL**命令去签约开户模板中的PTW参数，开户模板中数据去签约后，会应用到所有使用模板开户的用户中。
   - 执行**MOD SUBTPL**命令，在“用户模板类型”为“NORMAL”的用户开户模板中去签约PTW寻呼时间窗参数。
   - 执行**MOD EPSUSERTPL**命令，在EPS用户开户模板中去签约PTW寻呼时间窗参数。
   - 执行**MOD EPS**命令，为用户去签约PTW寻呼时间窗参数。

## 任务示例

任务描述

签约/修改/去签约PTW寻呼时间窗参数。

脚本

/\*-------------登录“UDM业务管理”窗口-------------\*/

**/\*签约PTW寻呼时间窗参数。可以执行**ADD SUB**命令为用户开户时直接进行签约，也可以先在**ADD SUBTPL**/**ADD EPSUSERTPL**开户模板命令中签约后，再执行**ADD SUB**命令为用户进行模板开户。\*/**

/\*在CS/PS用户开户模板中设置PTW寻呼时间窗参数。\*/

```
ADD SUBTPL: HLRSN=1, TPLID=1, TPLTYPE=NORMAL, CARDTYPE=USIM, NAM=NONE, EPS=TRUE, AMBRMAXUL=10000000, AMBRMAXDL=20000000, WBPTW=5, NBPTW=5;
```

```
ADD EPSUSERTPL: HLRSN=1, TPLID=100, AMBRMAXUL=10000000, AMBRMAXDL=20000000, CNTXID=1, EPSAPNQOSTPLID=1, WBPTW=5, NBPTW=5;

/\*为用户开户，设置PTW寻呼时间窗参数。\*/

```
ADD SUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", CARDTYPE=USIM, NAM=NONE, EPS=TRUE, DEFAULTCALL=TS11, AMBRMAXUL=10000000, AMBRMAXDL=20000000, WBPTW=5, NBPTW=5;
