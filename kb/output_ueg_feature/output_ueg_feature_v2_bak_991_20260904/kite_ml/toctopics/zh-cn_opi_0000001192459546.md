## 操作场景

同一5G LAN终端组成员之间或5G LAN终端组的成员和数据网络中的应用之间进行以太通信/IP通信时，需要配置5G LAN功能。

## 必备事项

前提条件

- 请仔细阅读GWFD-030701 支持5G LAN组以太通信特性概述和GWFD-030702 支持网络侧基于VxLAN的以太通信特性概述。
- 完成**加载License**（如果有需求，请联系华为技术支持工程师处理）。
- UEG已完成与周边网元的对接。

数据

- 配置支持5G LAN组以太通信时，仅需要规划表1、表4~表6中的数据。
- 配置支持网络侧基于VXLAN的以太通信时，需要规划表1~表6中的数据。
- 配置支持5G LAN组以太通信+网络侧基于VXLAN的以太通信时，请规划表1~表6中的数据。
- 配置N6侧免VxLAN隧道层二以太通信时，需要规划表1、表4~表6中的数据和配置N6侧免VxLAN隧道层二以太通信，不需要规划VxLAN隧道相关（表2和表3）的数据。
- 配置支持5G LAN组层三通信时，请规划表7~表8中的数据。

## 操作流程

| 配置项目               | 配置说明                                                                                                     |
|:-------------------|:---------------------------------------------------------------------------------------------------------|
| 配置N3逻辑接口及外联口       | 与非5G LAN用户可以共用。 单独规划时，与非5G LAN用户场景没有区别。                                                                  |
| 配置N4逻辑接口及外联口       | 与非5G LAN用户可以共用。 单独规划时，与非5G LAN用户场景没有区别。                                                                  |
| 配置N6外联口            | 与非5G LAN用户可以共用。 单独规划时，与非5G LAN用户场景没有区别。                                                                  |
| 配置APN              | 层二5G LAN需要独立的APN。UPF不需要为5G LAN层二终端分配IP，层二5G LAN使用的独立APN不需要绑定VPN实例。 UPF支持为5G LAN层三终端分配IP。                 |
| 配置vxlan逻辑接口及外联口    | UPF支持5G LAN层二终端时的专有配置，非5G LAN用户场景及5G LAN层三终端时不需要配置。 vxlan逻辑接口绑定的VPN实例名称，与对应的传输VXLAN隧道报文的外联口绑定的VPN实例名称相同。 |
| 配置5G LAN组          | UPF支持5G LAN层二终端/层三终端时的专有配置，非5G LAN用户场景不需要配置。                                                             |
| 配置VXLAN隧道          | 本页面中的VXLAN配置内容，仅用于支持5G LAN层二终端时使用。 5G LAN层二终端和企业内网互通时，需要配置；终端之间跨UPF互通时，需要配置。                             |
| 5G LAN组和VXLAN隧道组绑定 | UPF支持5G LAN层二终端时的专有配置，非5G LAN用户场景及5G LAN层三终端时不需要配置。 5G LAN层二终端和企业内网互通时，需要配置；终端之间跨UPF互通时，需要配置。            |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

   可通过**LST LICENSESWITCH**命令查询“License项（LICITEM）”参数值。

   - 层二5G LAN组时，License名称从GWFD-030701 支持5G LAN组以太通信特性概述和GWFD-030702 支持网络侧基于VxLAN的以太通信特性概述获取。
   - 层三5G LAN组时，license名称从GWFD-030706 支持5G LAN组层三通信特性概述获取。
2. 开启5G LAN功能开关。

   **SET NGLANFUNC**
3. 配置5G LAN组。

   **ADD NGVNINSTANCE**

   **说明** 

   - 层二5G LAN组时，“PDN类型（PDNTYPE）”设置为“ETHERNET”。

     支持网络侧基于VXLAN的以太通信时，还需要配置4和5。
   - 层三5G LAN组时，“PDN类型（PDNTYPE）”设置为“IP”。

     层三终端通过CPE接入网络时，还需要配置8。
4. 配置VXLAN隧道。5G LAN层三通信时，请跳过本步骤。
   1. 配置vxlan逻辑接口所属的VPN实例。

      **ADD VPNINST**

      **说明** 

      - 逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
      - 采用默认VPN实例“\_public\_”时，不需要再执行**ADD VPNINST**命令。
      - 采用已存在的VPN实例时，不需要重复执行**ADD VPNINST**命令。
   2. 配置vxlan逻辑接口。

      **ADD LOGICINF**
   3. 配置VXLAN隧道组。

      **ADD VXLANGRP**
   4. 配置VXLAN隧道端点（VTEP）。

      **ADD VTEP**
   5. 配置VXLAN端点绑定VXLAN隧道组。

      **ADD VTEPBINDGRP**
5. 5G LAN组和VXLAN隧道组绑定。5G LAN层三通信时，请跳过本步骤。

   **ADD NGVNBINDVXLAN**
6. 配置UPF基于5G LAN粒度支持学习的总MAC地址数。5G LAN层三通信时，请跳过本步骤。

   **SET NGLANATTR**
7. 配置故障定界所需数据。5G LAN层三通信时，请跳过本步骤。

   5G LAN业务端到端时延超出预期时，可通过**NGVNVIFPING**命令获取UPF与对端之间的时延。但执行**NGVNVIFPING**命令时，依赖7.a~7.c配置，否则会执行命令失败。

   1. 执行**LST UPETHSRVPARA**命令，查询UPF上是否已配置“用户面以太业务MAC”参数。

      - 是 => 请执行7.c。
      - 否 => 请执行7.b。
   2. 配置设置用户面以太业务参数。配置的MAC地址可作为PING探测的源MAC地址。

      **SET UPETHSRVPARA**
   3. 配置5G LAN组网关IP。配置的IP地址可作为PING探测的源IP地址。

      **ADD NGVNVIF**
8. 层三终端通过CPE接入网络时，配置Routing Behind MS数据。5G LAN层二通信时，请跳过本步骤。
   1. 打开Routing Behind MS特性的License配置开关。

      **SET LICENSESWITCH**
   2. （UPF）基于APN使能Routing Behind MS功能。

      **SET APNADDRESSATTR**
   3. （SMF）基于APN使能Routing Behind MS功能。

      **SET CPAPNADDRESSATTR**
9. DCGW/企业侧交换机与UPF之间建立VXLAN隧道的场景，修改接口MTU。

   **MOD INTERFACE**
10. 风筝S/M场景，配置离线计费功能。
    1. 开启离线计费功能开关。

       **SET NGLANCHGCTRL**
    2. 配置离线计费规则。5G LAN UE会话不支持基于具体业务流的离线计费。

       详细请参见：配置业务数据 > 计费功能。

## 任务示例

任务描述

任务实例一：配置5G LAN组标识为“000003e9-460-08-01”的组成员之间及组成员与数据网络中的应用之间提供**以太类型**的通信服务。

任务实例二：配置5G LAN组标识为“000003e9-460-08-02”的组成员之间及组成员与数据网络中的应用之间提供**IP类型**的通信服务。

脚本

**//任务实例一：**

//开启本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5LANB01", SWITCH=ENABLE;
```

//开启5G LAN功能。全局开关。

```
SET NGLANFUNC: NGLANSW=ENABLE;
```

//配置5G LAN组。此处以关闭N3侧MAC地址老化功能、开启组播泛洪开关、开启广播流控开关、关闭N3侧未知单播泛洪开关、关闭N6学习的MAC地址空闲时长开关为例。

```
ADD NGVNINSTANCE: VNINSTANCE="000003e9-460-08-01", PDNTYPE=ETHERNET, MACIDLESW=DISABLE, MULTIFLOODSW=ENABLE, MULTIFLOODRATE=20, BCASTFLOWCTRLSW=ENABLE, UNICASTFLOODSW=DISABLE, N6MACIDLESW=DISABLE;
```

//配置vxlan逻辑接口所属的VPN实例。

```
ADD VPNINST: VPNINSTANCE="VPN_vxlan";
```

//配置vxlan逻辑接口。

```
ADD LOGICINF: NAME="vxlanif1/1/0", IPVERSION=IPV4, IPV4ADDRESS1="10.1.50.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_vxlan";
```

//配置VXLAN隧道组。

- 路径中的网络设备和对端都支持心跳消息时，请执行：

  ```
  ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0", HEARTBEAT=ENABLE, TIMETHRESHOLD=6, HEARTSUCCLIMIT=3, HEARTFAILLIMIT=3, TIMEOUT=2;
  ```
- 路径中的网络设备或对端不支持心跳消息时，请执行：

  ```
  ADD VXLANGRP: GRPNAME="vxlan_01", SRCINTF="vxlanif1/1/0", HEARTBEAT=DISABLE;
  ```

//配置VXLAN隧道端点（VTEP：VXLAN交换机）。

```
ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.10.100.1", TYPE=N6;
```

//配置VXLAN隧道端点绑定VXLAN隧道组。

```
ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP1", PRIFLAG=PRIMARY;
```

//配置VXLAN隧道端点（VTEP：另一UPF）。两个UPF是负荷分担关系，且仅对接到同一对DCGW/企业侧VXLAN交换机场景，同一5G LAN组内成员跨UPF的互访通过UPF间的VxLAN隧道实现时需要配置，否则不需要配置。VTEPIPV4为远端端点IP，来源于另一UPF的VXLAN隧道端点IP地址。

```
ADD VTEP: VTEPNAME="VTEP1", IPVERSION=IPV4, VTEPIPV4="10.1.50.2", TYPE=N19;
ADD VTEPBINDGRP: VXLANGRPNAME="vxlan_01", VTEPNAME="VTEP2", PRIFLAG=PRIMARY;
```

//配置5G LAN组和VXLAN隧道组绑定。

```
ADD NGVNBINDVXLAN: VNINSTANCE="000003e9-460-08-01", VXLANGRPNAME="vxlan_01", VNI=5010;
```

//配置UPF基于5G LAN组粒度支持学习的总MAC地址数。

```
SET NGLANATTR: VNINSTANCE="000003e9-460-08-01", TOTALMACNUM=6000;
```

//配置故障定界所需数据（执行**NGVNVIFPING**获取时延时依赖的数据）。

```
SET UPETHSRVPARA: UPETHSRVSW=ENABLE, UPETHSRVMAC="FA-16-3E-A0-04-D6";
```

```
ADD NGVNVIF: VNINSTANCE="000003e9-460-08-01", VIFIPTYPTE=IPV4, VIFIPV4ADDR="10.99.99.99";
```

//DCGW/企业侧交换机与UPF之间建立VXLAN隧道的场景，修改接口MTU值。如下IFNAME值仅为举例，实际请修改为传输VXLAN隧道报文的外联口名称。

- Ethernet接口组网时：

  ```
  MOD INTERFACE:IFNAME="Ethernet64/0/4",IFMTU=1600;
  MOD INTERFACE:IFNAME="Ethernet64/0/4.100",IFMTU=1600;
  ```
- Eth-trunk接口组网时：

  //Eth-trunk接口组网时，不需要修改成员接口的MTU值。若规划的成员接口在加入Eth-trunk前修改了MTU值，则会导致添加成员接口失败。

  ```
  MOD INTERFACE:IFNAME="Eth-trunk1",IFMTU=1600;
  MOD INTERFACE:IFNAME="Eth-trunk1.100",IFMTU=1600;
  ```
