## 操作场景

本操作指导介绍在运行网络中激活漫游控制特性的操作过程。

漫游控制，是指UEG提供互连PLMN表的配置，只有配置允许互连的PLMN用户才能够接入本UEG。漫游控制特性使网络具有限制用户移动范围和业务访问的能力。对于非本网的且不在互联PLMN表中的用户，将拒绝其接入，拒绝的原因值可灵活配置。

**说明** 

适用于AMF。

## 对系统的影响

该操作对系统正常运行没有影响。

## 必备事项

前提条件

请仔细阅读GWFD-021102 漫游控制特性概述。

数据

| 类别                | 参数                 | 取值样例       | 获取方法   | 说明          |
|:------------------|:-------------------|:-----------|:-------|:------------|
| ADD NGCONNECTPLMN | 移动国家码（MCC）         | 123        | 全网规划   | 5G互联的PLMN参数 |
| ADD NGCONNECTPLMN | 移动网号（MNC）          | 45         | 全网规划   | 5G互联的PLMN参数 |
| ADD NGCONNECTPLMN | 运营商标识（NOID）        | 0          | 全网规划   | 5G互联的PLMN参数 |
| SET NGMMPROCTRL   | 流程类型（PROT）         | OTHER_PROC | 全网规划   | 设置漫游受限拒绝原因值 |
| SET NGMMPROCTRL   | 漫游受限拒绝原因值（ROAMRST） | 0          | 全网规划   | 设置漫游受限拒绝原因值 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 增加互联的PLMN，并配置允许的业务。

   **ADD NGCONNECTPLMN**
3. 设置漫游受限拒绝原因值。

   **SET NGMMPROCTRL**

## 任务示例

任务描述

增加一个互联的PLMN，PLMN ID为12345，运营商标识为0。

脚本

//PLMN为12345的运营商A与本运营商签署了漫游协议，移动国家码为123，移动网号为45。为了支持该运营商的用户注册到本运营商网络，新增互联PLMN配置如下：

```
ADD NGCONNECTPLMN: NOID=0, MCC="123", MNC="45", DESC="for MNO A";
```

//当非本网的且不在互联PLMN表中的用户注册，将拒绝其接入。拒绝原因值设置为0，表示发生该异常时系统将下发#15（No suitable cells in tracking area）原因值。

```
SET NGMMPROCTRL: PROT=OTHER_PROC,ROAMRST=0;
```
