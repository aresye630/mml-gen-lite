- 必备事项

## 操作场景

本操作指导介绍在运行网络中激活LTE一键通基础功能的操作过程。

**说明** 

适用于MME。

## 必备事项

前提条件

已完成加载License。

数据

| 类别          | 参数名称             |   取值样例 | 获取方法   | 相关命令             |
|:------------|:-----------------|-------:|:-------|:-----------------|
| ADD QCICONV | 扩展QCI基准值(QCIEXT) |     65 | 全网规划   | PTT业务QCI转换为标准QCI |
| ADD QCICONV | 扩展QCI范围(QCISTEP) |      1 | 全网规划   | PTT业务QCI转换为标准QCI |
| ADD QCICONV | 标准QCI值(QCISTD)   |      1 | 全网规划   | PTT业务QCI转换为标准QCI |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开LTE一键通基础功能的License配置开关。

   **SET LICENSESWITCH**
3. 配置PTT业务QCI和标准QCI的映射规则。

   **ADD QCICONV**

## 任务示例

任务描述

激活LTE一键通基础功能。

脚本

//进入“MML命令行-UEG”窗口。

//打开LTE一键通基础功能的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2PPTF01", SWITCH=ENABLE;
```

//配置PTT业务QCI和标准QCI的映射规则。

```
ADD QCICONV: QCIEXT=65, QCISTEP=1, QCISTD=1;
```

```
ADD QCICONV: QCIEXT=69, QCISTEP=1, QCISTD=5;
```

```
ADD QCICONV: QCIEXT=70, QCISTEP=1, QCISTD=6;
```
