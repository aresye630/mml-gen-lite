# 加载网元内服务间证书

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

网元实例化前，必须先通过Fusionstage配置网元内服务间的证书，保证网元内各服务间的通信安全。

## 对系统的影响

该操作对系统无影响。

## 必备事项

前提条件

已登录FusionStage。

数据

已获取证书文件：

- 商用证书：客户申请，包括：CA根证书（信任证书）、公钥证书（包括中间CA证书）、私钥、私钥口令、证书吊销列表（CRL）。使用客户申请的证书时，需要校验证书的有效性，将非pem格式的证书文件转换为pem格式，并生成Secret文件（即inner-comm-cert.yaml文件），详细操作请参见1。

  **说明** 

  私钥口令需要符合如下复杂程度要求：
  - 密码不能少于8个字符且不超过30个字符。
  - 密码必须由如下组合而成：
    - 至少包括一个大写字母（A~Z）；
    - 至少包括一个小写字母（a~z）；
    - 至少包括一个数字字符（0—9）；
    - 至少包括1个特殊字符，如：“~、@、^、\*、-、\_、=、:、.、/、？”；
- 华为证书：随软件提供华为证书，获取路径：技术支持 > 产品软件 > 云核心网 > Mobile Packet Core>5G Packet Core>UEG>UEG。选择使用的版本，从软件包中获取Secret文件（获取CSP-INNER-COMMON-CERT.zip压缩文件，解压后即可获取到inner-comm-cert.yaml文件）。

  **警告** 

  - 软件中含有仅用于部署阶段入网与初始化的华为初始证书，系统部署并初始化完成后客户应对初始证书进行更换。
  - 对于将华为证书作为业务证书使用而导致的安全风险和安全事件，由客户自行处置并承担后果。
  - 该yaml文件包含三份证书内容，其中华为公司CA根证书有效期截止到2041年11月，二级CA证书有效期截止到2041年10月，TLS公钥证书有效期截止到2037年11月。
  - 华为证书过期后，使用华为证书的业务会中断。
  - 华为建议客户通过部署PKI系统对现网设备和软件进行证书的签发，并做好证书的生命周期管理（为保证安全性推荐使用最短有效期的证书）。

工具

校验、转换客户申请的商用证书时，需要使用OpenSSL的二进制可执行程序，请通过OpenSSL官方网站下载适用于本PC操作系统的程序包。

## 操作步骤

1. 使用客户申请的证书时，需要将非PEM格式的证书转换为PEM格式、校验证书的有效性、并生成inner-comm-cert.yaml文件。
   1. 安装OpenSSL，并将“OpenSSL程序安装路径\bin”添加到PC系统环境变量Path中。
   2. 启动命令行程序（本文以windows操作系统的cmd为例），执行如下命令进入证书文件所在路径。

      ```
      CD 证书文件所在路径
      ```

      **注意** 

      证书文件所在路径必须为全英文字符。
   3. 当证书文件不是PEM格式时，需要将其转换为PEM格式。此处以DER格式转换为PEM格式为例进行说明，执行如下命令。其它格式的证书转换，请参考OpenSSL帮助文档或联系华为技术服务工程师。

      - 将DER格式的CA证书和公钥证书转换为PEM格式

        ```
        openssl x509 -in CA证书文件 -inform DER -out 转换后CA证书文件名称.pem -outform PEM
        openssl x509 -in 公钥证书文件 -inform DER -out 转换后公钥证书文件名称.pem -outform PEM
        ```
      - 将DER格式的私钥转换为PEM格式

        ```
        openssl rsa -in 私钥文件 -inform DER -out 转换后私钥文件名称.pem -outform PEM
        ```

      - 将DER格式的证书吊销列表（CRL）转换为PEM格式

        ```
        openssl crl -in CRL文件 -inform DER -out 转换后CRL文件名称.pem -outform PEM
        ```
   4. 校验证书的有效性，执行如下命令：

      - 校验CA证书是否可验证公钥证书

        ```
        openssl verify -CAfile 转换后CA证书文件名称.pem 转换后公钥证书文件名称.pem
        ```

        如果CA证书可以验证公钥证书，执行命令后将返回：*转换后公钥证书文件名称**.pem*: OK。
      - 检查CA证书和公钥证书的有效期

        ```
        openssl x509 -in 转换后CA证书文件名称.pem -noout -dates
        openssl x509 -in 转换后公钥证书文件名称.pem -noout -dates
        ```

        执行命令后将返回证书的有效期，示例如下，请根据实际情况判断有效期是否符合要求。

        ```
        notBefore=Dec 19 06:04:00 2019 GMT
        notAfter=Dec 19 06:04:00 2020 GMT
        ```
      - 查看CA证书和公钥证书的指纹信息

        ```
        openssl x509 -in 转换后CA证书文件名称.pem -noout -fingerprint
        openssl x509 -in 转换后公钥证书文件名称.pem -noout -fingerprint
        ```
      - 检查CRL的有效期

        ```
        openssl crl –in 转换后CRL文件名称.pem -inform pem -lastupdate -nextupdate -noout
        ```

        执行命令后将返回CRL的有效期，示例如下，请根据实际情况判断有效期是否符合要求。

        ```
        lastUpdate=Dec 27 13:52:00 2019 GMT
        nextUpdate=Jan 26 13:52:00 2020 GMT
        ```
      - 检查CA证书是否可验证CRL

        ```
        openssl crl –in 转换后CRL文件名称.pem -inform pem -CAfile 转换后CA证书文件名称.pem –noout
        ```

        如果CA证书可验证CRL，执行命令后将返回：verify OK。
      - 检查公钥证书与私钥是否配对。

        ```
        openssl x509 -in 转换后公钥证书文件名称.pem -noout -modulus | openssl sha1
        openssl rsa -in 转换后私钥文件名称.pem -noout -modulus | openssl sha1
        ```

        如果两条命令执行后返回内容一致，则表示公钥证书与私钥是配对的。
      - 检查证书是否已被吊销。如果证书已被吊销，则需要重新申请证书。

        ```
        //获取公钥证书Serial Number
        openssl x509 -in 转换后公钥证书文件名称.pem -serial -noout
        //检查公钥证书是否已被吊销
        openssl crl -in 转换后CRL文件名称.pem -text -inform PEM | findstr '公钥证书Serial Number'
        ```

        如果在CRL文件中能够找到公钥证书Serial Number，则表示该证书已被吊销，请重新申请。
   5. 制作Secret文件（即inner-comm-cert.yaml文件）。请使用如下模板制作Secret文件，将*红色斜体部分*替换为实际证书信息，并存储为.yaml格式。

      **注意** 

      - 请勿修改模板格式，否则可能导致证书不可用。
      - 修改*红色斜体部分*内容时，每行前请务必保留4个空格（与当前模板格式一致），且不能存在空白行，否则可能导致证书不可用。
      - 换行符必须转换为unix格式。

      ```
      apiVersion: v1
      kind: Secret
      metadata:
        name: inner-comm-cert 
        comment: 描述内部通信证书信息
      type: others
      stringData:
        #配置是否开启内部安全通信，取值true或false，默认值为true，无需修改。
        enable: |-
          true
        #配置内部证书使用模式，取值shared或special，默认值为shared，无需修改。
        mode: |-
          shared
        #配置私钥口令，默认私钥口令为明文，请根据实际值填写。
        privKeyPwd: |-
          YourPrivKeyPwd
        #配置CA根证书。如果只有一个根CA，则只包含一个CA证书信息；如果存在多个根CA，则包含多个CA证书信息。
        ca: |-
          -----BEGIN CERTIFICATE-----
          xxxx    
          -----END CERTIFICATE-----
          -----BEGIN CERTIFICATE-----
          xxxx    
          -----END CERTIFICATE-----  
        #配置TLS公钥证书和中间CA证书。存在多级中间CA时，从低级到高级顺序填写中间CA证书信息，如TLS公钥证书+CA证书+上级CA证书....
        cert: |-
          -----BEGIN CERTIFICATE-----
          xxxx    
          -----END CERTIFICATE-----
          -----BEGIN CERTIFICATE-----
          xxxxx
          -----END CERTIFICATE-----
        #配置TLS私钥
        privKey: |-
          -----BEGIN RSA PRIVATE KEY-----
          xxxx
          -----END RSA PRIVATE KEY-----
        #配置证书吊销列表
        crl: |-
          -----BEGIN X509 CRL-----
          xxxx
          -----END X509 CRL-----
      ```
2. 通过FusionStage上传密钥文件（即inner-comm-cert.yaml文件）。

   **说明** 

   系统中如果已存在inner-comm-cert.yaml文件，请先删除后，再上传。

   1. 以创建本网元项目的租户帐号登录FusionStage，在菜单栏右上角中，切换为需要添加密钥文件的项目。
   2. 在主菜单选择“应用管理 > 应用配置 > Secret”。
   3. 单击“创建Secret”。
   4. 选择“创建方式”为“上传文件”。
   5. 单击“选择文件”，上传密钥文件。
   6. 单击“创建”。
   7. 返回“应用管理 > 应用配置 > Secret”界面，查看已上传的密钥文件。
