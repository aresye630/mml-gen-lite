## 操作场景

本操作指导介绍在运行网络中激活支持SA国际漫游接入的操作过程。当运营商之间签订漫游协议，期望支持漫游用户漫入时，可以使用本特性。

国际漫游是指终端用户在归属运营商网络以外的国家或地区使用业务的场景。5G SA组网场景下，用户离开归属PLMN的覆盖范围时，UEG支持用户从拜访地网络接入使用业务，保证业务的连续性。

## 对系统的影响

该操作对系统正常运行没有影响。

## 必备事项

前提条件

- 请仔细阅读GWFD-021103 支持SA国际漫游接入特性概述。

- 完成加载License。

- 已配置AMF和SMF实体功能。详细请参考UEG产品文档 -> “初始配置与调测 -> 配置实例 -> 配置AMF/SMF/MME/SGW-C/PGW-C”。

本特性不影响逻辑组网，业务组网上需要增加如下接口配置。如表1所示。

| VPLMN   | VPLMN.1   | HPLMN   | HPLMN.1   |
|:--------|:----------|:--------|:----------|
| NF      | 接口        | NF      | 接口        |
| AMF     | SBI（N12）  | AUSF    | SBI（N12）  |
| AMF     | SBI（N8）   | UDM     | SBI（N8）   |
| SMF     | SBI（N16a） | SMF     | SBI（N16a） |
| UPF     | N9c       | UPF     | N9a       |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 配置与SEPP的对接。

   **SET ROAMCOMMPLCY**

   **ADD PNFPROFILE**
4. 配置互联PLMN。

   **ADD NGCONNECTPLMN**
5. 配置漫游切片映射。

   **ADD AMFROAMNSMAP**
6. 配置和对端NF的对接。需要配置对端归属地运营商SMF、UDM、AUSF的信息，包含对端NF的Profile信息、服务信息、PLMN信息、支持的SUPI信息、支持的服务切片信息等。

   **ADD PNFPROFILE**

   **ADD PNFSERVICE**

   **ADD PNFPLMN**

   **ADD PNFROUTEIND**

   **ADD PNFDNN**

   **ADD PNFNS**
7. 打开支持漫游功能开关。

   **SET NGMMFUNC**

   **SET SMFFUNC**

## 任务示例

任务描述

A国运营商A和B国运营商B之间签订了5G漫游协议，运营商A的Home PLMN为123000，运营商B的Home PLMN为456010，期望运营商B的部分用户漫入至运营商A的覆盖区域时依然能使用业务。此时可以在运营商A上激活本特性。

脚本

```
//打开本特性的License配置开关。
```

```
SET LICENSESWITCH: LICITEM="LKV2SAIRA01", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV2SAIRA01", SWITCH=ENABLE;
```

```
//配置和本运营商的SEPP对接。
```

```
SET ROAMCOMMPLCY: ROUTEMODE=SEPP, SEPPMODE=HTTPPROXY;
ADD PNFPROFILE: NFINSTANCEID="SEPP_Instance_0", NFTYPE=NfSEPP, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.182", PORT=80, CAPACITY=100, NFDESCNAME="Roaming_SEPP_00", SCHEME=HTTP;
```

```
//配置与本运营商A签定了漫游协议的运营商B的PLMN。
```

```
ADD NGCONNECTPLMN: NOID=0, MCC="456", MNC="010", SUBRANGE=SPECIFIED_IMSI_RANGE, IMSIPRE="4560106789", DESC="for MNO B";
```

```
//配置漫游用户切片映射。将漫游用户切片映射为本地切片。
```

```
ADD AMFROAMNSMAP: HMCC="456", HMNC="010", HSST=1, HSD="123FFF", VMCC="123", VMNC="000", VSST=1, VSD="FFFFFF";
```
