# 开启5G LAN用户本地签约功能开关

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

部署本地运维5G LAN用户签约的5G LAN组ID时，运营商需要在SMF（UEG-L）上开启5G LAN本地签约功能开关。

**说明** 

关闭5G LAN本地签约功能开关时，无法本地调整用户所属的5G LAN组ID。

## 必备事项

前提条件

操作员拥有配置权限。

数据

无。

## 操作步骤

1. 登录OM Portal。
2. 进入“MML命令行-UEG”窗口。
3. 执行**SET EDGESMCOMMFUNC**命令，开启5G LAN用户本地签约功能。

   ```
   SET EDGESMCOMMFUNC: LOCVNSUBSW=ENABLE;
   ```

   **说明** 

   调整5G LAN用户本地签约的5G LAN组ID后，运营商可通过**LST RDSSTATICIPPARA**查询多个用户本地签约的5G LAN组ID。
