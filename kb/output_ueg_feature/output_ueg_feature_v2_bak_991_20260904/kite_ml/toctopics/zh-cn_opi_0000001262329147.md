# 激活支持多HPLMN功能（适用于SGW-C/PGW-C/SMF）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当网络允许属于不同运营商用户共同接入时，为了判断用户的归属的属性，需要配置支持多HPLMN功能。

**说明** 

适用于SGW-C、PGW-C、SMF

## 必备事项

前提条件

- 请仔细阅读GWFD-023102 支持多HPLMN功能特性概述。
- 已完成加载License。

数据

| 类别          | 参数名称        |   取值样例 | 获取方法   | 说明      |
|:------------|:------------|-------:|:-------|:--------|
| ADD NGHPLMN | 运营商标识（NOID） |      0 | 全网规划   | 新增HPLMN |
| ADD NGHPLMN | 移动国家码（MCC）  |    123 | 全网规划   | 新增HPLMN |
| ADD NGHPLMN | 移动网络号（MNC）  |     11 | 全网规划   | 新增HPLMN |
| ADD NGHPLMN | 描述信息（DESC）  |      0 | 全网规划   | 新增HPLMN |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License控制开关。

   **SET LICENSESWITCH**
3. **可选：**新增HPLMN信息。

   ****ADD NGHPLMN****

## 任务示例

任务描述

激活支持多HPLMN功能，配置MCC号对应的MNC长度为3，增加两个HPLMN为123011和123012。

脚本

//打开功能开关。

```
SET LICENSESWITCH: LICITEM="LKV2MHSM01", SWITCH=ENABLE;
```

//增加两个HPLMN。

```
ADD NGHPLMN: NOID=0,MCC="123",MNC="011",DESC=00;
ADD NGHPLMN: NOID=0,MCC="123",MNC="012",DESC=01;
```
