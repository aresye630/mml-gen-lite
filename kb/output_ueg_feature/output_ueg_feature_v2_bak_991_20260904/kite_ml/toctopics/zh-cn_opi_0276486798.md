# 激活支持Null-MSISDN（适用SMF/SGW-C/PGW-C）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本操作指导介绍在运行网络中激活支持Null-MSISDN特性的操作过程。

支持Null-MSISDN特性是指UEG支持不携带MSISDN（Mobile Station International ISDN Number）的用户进行基本的移动性管理和会话管理业务，如附着、TAU/RAU、激活等。

**说明** 

适用于SGW-C、PGW-C、SMF。

## 必备事项

前提条件

- 请仔细阅读GWFD-020913 支持Null-MSISDN特性概述。
- 已完成加载License，对应的License项为“81202798 LKV3W9NUMD02 支持Null-MSISDN”。
- 移动网络中的相关网元（如P-GW、HSS等）打开Null MSISDN业务功能。

数据

| 类别                  | 参数名称                        | 取值样例     | 获取方法     | 说明              |
|:--------------------|:----------------------------|:---------|:---------|:----------------|
| SET CPAPNACCESSCTRL | APN名称（APN）                  | apn-test | 已配置数据中获取 | 使能Null-MSISDN功能 |
| SET CPAPNACCESSCTRL | 不携带MSISDN用户激活策略（NULLMSISDN） | ENABLE   | 本端规划     | 使能Null-MSISDN功能 |

## 操作步骤

1. 以下命令在“MML命令行-UEG”窗口上执行。打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 使能Null-MSISDN功能。

   **说明** 

   该命令对新接入用户生效，不影响已接入用户。

   **SET CPAPNACCESSCTRL**

## 任务示例

任务描述

使能APN“apn-test”的Null-MSISDN功能。

脚本

//使能Null-MSISDN功能。

```
SET LICENSESWITCH:LICITEM="LKV3W9NUMD02",SWITCH=ENABLE;
```

```
SET CPAPNACCESSCTRL:APN="apn-test",NULLMSISDN=ENABLE;
```
