## 操作场景

本操作指导介绍在运行网络中激活端到端用户跟踪的操作过程。

## 必备事项

前提条件

- 请仔细阅读4G网络端到端跟踪特性概述和5G网络端到端跟踪特性概述。
- 完成加载License。

## 操作步骤

场景一：EMS直接下发

管理面下发跟踪任务，入口界面：监控 > 全网端到端信令跟踪 > 跟踪管理，添加>管理面创建（具体请参考图1）

**图1** 登录界面

1. 打开本功能的License配置开关。

   在“MML命令行-UEG”窗口上执行：

   **SET LICENSESWITCH**
2. （可选）配置跟踪消息上报速率控制（建议使用默认值。如果修改，请联系华为技术支持）。

   在“MML命令行-UEG”窗口上执行：

   **SET FWSOFTPARABITS**

场景二：信令传播下发

**说明** 

风筝L L2组网模式下不支持该场景。

信令面下发跟踪任务，入口界面：监控 > 全网端到端信令跟踪 > 跟踪管理，添加>信令面创建（具体请参考图2）

**图2** 登录界面

UDM作为初始网元

1. 打开本功能的License配置开关。

   在“MML命令行-UEG”窗口上执行：

   **SET LICENSESWITCH**
2. 配置AMF是否向UDM查询或者订阅TraceData。

   在“MML命令行-UEG”窗口上执行：

   **SET NGMMFUNC**

   **说明** 

   当网络中有任意一个UDM不支持Trace Data时，需要通过**LST NGMMFUNC**命令检查**全网跟踪开关**是否为“否”，若开关开启，需要通过**SET NGMMFUNC**命令设置**E2ESW**参数为“否”，以关闭AMF向UDM查询或者订阅TraceData的开关，避免造成业务流程异常。
3. 配置SMF是否向UDM单独获取和订阅Trace Data。

   在“MML命令行-UEG”窗口上执行：

   **SET SMFSOFTPARAOFBIT**
4. （可选）配置跟踪消息上报速率控制（建议使用默认值。如果修改，请联系华为技术支持）。

   在“MML命令行-UEG”窗口上执行：

   **SET FWSOFTPARABITS**

AMF作为初始网元

1. 打开本功能的License配置开关。

   在“MML命令行-UEG”窗口上执行：

   **SET LICENSESWITCH**
2. （可选）关闭AMF向UDM查询或者订阅TraceData的开关。

   在“MML命令行-UEG”窗口上执行：

   **LST NGMMFUNC**

   **SET NGMMFUNC**

   **说明** 

   当网络中有任意一个UDM不支持Trace Data时，需要通过**LST NGMMFUNC**命令检查**全网跟踪开关**是否为“否”，若开关开启，需要通过**SET NGMMFUNC**命令设置**E2ESW**参数为“否”，以关闭AMF向UDM查询或者订阅TraceData的开关，避免造成业务流程异常。
3. 关闭SMF向UDM单独获取和订阅Trace Data，可通过软参控制（软参值设置为0）。

   在“MML命令行-UEG”窗口上执行：

   **SET SMFSOFTPARAOFBIT**
4. （可选）配置跟踪消息上报速率控制（建议使用默认值。如果修改，请联系华为技术支持）。

   在“MML命令行-UEG”窗口上执行：

   **SET FWSOFTPARABITS**

## 任务示例

任务描述

**场景一：EMS直接下发**

1. 开启端到端用户跟踪特性，在网管上创建端到端跟踪任务。

**场景二：信令传播下发，AMF作为初始网元，且存在UDM不支持Trace Data的场景：**

1. 开启端到端用户跟踪特性，在网管上创建端到端跟踪任务，选择AMF网元。
2. 在无I-SMF（SMF直连AMF）场景下，关闭SMF向UDM单独获取和订阅Trace Data（即软参DWORD1001中BIT31=0）。

脚本

**场景一：****EMS直接下发**

//打开端到端用户跟踪的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2ESTAM01", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV3ESTSM02", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV3G5E2ET01", SWITCH=ENABLE;
```

**场景二：信令传播下发，AMF作为初始网元，且存在UDM不支持Trace Data的场景**

//打开端到端用户跟踪的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2ESTAM01", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV3ESTSM02", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV3G5E2ET01", SWITCH=ENABLE;
```

//在无I-SMF（SMF直连AMF）场景下，关闭SMF向UDM单独获取和订阅Trace Data。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1001, VALUE=VALUE_0, POSITION=31;
```
