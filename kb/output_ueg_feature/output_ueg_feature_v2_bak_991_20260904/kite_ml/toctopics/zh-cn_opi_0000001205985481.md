## 操作场景

## 操作步骤

1. 登录“USCDB MML命令”界面。
2. 设置分组开关。

   ```
   SET GROUPSWITCH: GROUPNAME="UPCF", GROUPSWITCH=OPEN;
   ```
3. 增加远端Location信息。

   ```
   ADD RLOCATION: RLOCID=13, RMT="HSS9860", LP=1, REDUNFLAG=No;
   ```
4. 增加远端DBS。

   **说明** 

   参数“RDSGMID”通过在“UEG MML命令”下使用“LST DBSSERVICENO:;”查询。

   ```
   ADD RDSG: RLOCID=13, RDSGMID=301, RDSGST="HSS9860", RDSGTYPE=DBS;
   ADD RDSG: RLOCID=13, RDSGMID=302, RDSGST="HSS9860", RDSGTYPE=DBS;
   ```
5. 增加远端网元IP地址。

   ```
   ADD RIPADDR: RLOCID=13, ID=1, IPVER=IPV4, IPV4IP1="10.200.200.22", IPV4IP2="10.200.200.23", RDPUST="HSS9860";
   ```
6. 增加PGW订阅通知配置。操作员通过PGW修改全局数据或用户数据后，PGW负责通知FE相关的修改内容。

   ```
   ADD NOTIFYCFG: FETYPE="HSS9860", REMOTEID=1, FEID=1, INFTYPE=MCI, SYNCHROSWITCH=ASYNC, LOCATIONID=13;
   ```
7. 配置软参。
   1. 检查如下软参的参数值是否为“1”。

      ```
      LST INSP: INSPT=FE, INSPN=NOTIFYMAPPING, FETYPEN="HSS9860";
      ```

      - 是，请执行8。
      - 否，请执行7.b。
   2. 将如下软参的参数值设置为“1”。

      ```
      MOD INSP: INSPT=FE, INSPN=NOTIFYMAPPING, INSPV=1, FETYPEN="HSS9860";
      ```
8. 登录“UEG MML命令”界面。
9. 设置DBS分组开关。

   ```
   SET DBSGRPSWITCH: GROUPNAME="UPCF", GROUPSWITCH=OPEN;
   ```
10. 增加远端Location信息。

    ```
    ADD DBSRLOCATION: RLOCID=14, RMT=USCDB, LP=1;
    ```
11. 增加远端DSG。

    **说明** 

    在“MML-USCDB”下使用“LST MODULE: MT=DSG;”查询参数“RDSGMID”的值，需要将查询出来的所有DSG模块号配置在此处。如下以查询到DSG模块号为17和18为例。

    ```
    ADD DBSRDSG: RLOCID=14, RDSGMID=17, RDSGST="HSS9860";
    ADD DBSRDSG: RLOCID=14, RDSGMID=18, RDSGST="HSS9860";
    ```
12. 增加远端网元IP地址。

    ```
    ADD DBSRIPADDR: RLOCID=14, ID=1, IPVER=IPV4, IPV4IP1="10.200.200.32", IPV4IP2="10.200.200.33";
    ```
13. 配置软参。
    1. 检查如下软参的参数值是否为“1”。

       ```
       LST INSP: INSPT=HSS9860, INSPN=BECONNECTMODE;
       ```

       - 是，请执行14。
       - 否，请执行13.b。
    2. 将如下软参的参数值设置为“1”。

       ```
       MOD INSP: INSPT=HSS9860, INSPN=BECONNECTMODE, INSPV=1;
       ```
14. 登录“USCDB MML命令”界面。执行如下命令，激活IP链路。

    ```
    ACT IPDISP:;
    ```
15. 登录“UEG MML命令”界面。执行如下命令，激活IP链路。

    ```
    ACT DBSIPDISP:;
    ```

## 验证方法

1. 登录“USCDB MML命令”界面。
2. 执行**DSP DSGSCTP**命令，查询BE和FE之间链路状态是否正常。
   - 正常，请执行3。
   - 不正常，请联系华为技术支持工程师。
3. 登录“UEG MML命令”界面。
4. 执行**DSP DBSSCTP**命令，查询FE和BE之间链路状态是否正常。
   - 正常，结束。
   - 不正常，请联系华为技术支持工程师。
