## 操作场景

当单一PLMN内的用户号段数量无法满足签约用户数量时，运营商可以选择开启本特性来运营多个PLMN，从而为更多签约用户提供服务。且如果运营商要对不同的PLMN内的签约用户采取不同的计费和策略控制等处理，则运营商可通过本特性在UEG上配置多个HPLMN，保证对签约用户进行精准的计费和业务控制。

**说明** 

适用于SGSN、MME。

## 操作步骤

- 一个UEG为一个拥有多PLMN ID的MNO服务。

  **说明** 

  系统缺省会增加一条MNO ID为0的MNO记录，当UEG只被一个MNO使用时，无须再增加MNO。

  1. 进入“MML命令行-UEG”窗口。
  2. 打开本特性的License开关。
  3. 增加运营商网络标识。

     1. 打开运营商网络名称下发开关，当4G终端接入时，系统允许将运营商网络名称携带给终端。

        **SET MMFUNC**

        **说明** 

        若系统中同时存在命令**ADD MNO**和**ADD USRMMINFO**的配置记录，系统会优先将命令**ADD USRMMINFO**配置的运营商网络名称下发给终端。
     2. 当需要特性IMSI范围的用户增加特定网络名称时执行以下步骤。

        **ADD USRMMINFO**
  4. 增加HPLMN记录。

     **ADD HPLMN**
  5. 配置共享MME的PLMN ID。

     **ADD MMESHAREPLMN**
  6. **可选：**当MNO签订了漫游协议时，增加互联PLMN配置信息。

     **ADD CONNECTPLMN**
  7. **可选：**配置本端标识的选择规则。

     **ADD IMSICHAR**

     **说明** 

     对于只有一个MNO的场景，本端标识依次分为两层配置粒度，即第一层指根据IMSI号段配置，第二层轮选系统中所有的缺省配置。
  8. **可选：**增加PLMN对应的RNC信息。当MNO拥有多个HPLMN，且这些PLMN都需要在RNC侧进行广播，需要为每个PLMN配置RNC和寻呼信息。

     **ADD RNC**
  9. **可选：**增加PLMN对应的寻呼信息。

     **ADD IUPAGING**
- 网络中存在多个MNO，一个UEG为多个MNO服务。
  1. 进入“MML命令行-UEG”窗口。
  2. 打开本特性的License开关。
  3. 增加运营商网络标识。

     1. 打开运营商网络名称下发开关，当终端接入时，系统允许将运营商网络名称携带给终端。

        **SET MMFUNC**
     2. 增加运营商网络名称。

        - 增加MNO信息。

          **说明** 

          - 系统缺省已增加一条MNO ID为0的MNO记录，当UEG被多个MNO共享时，需要此步增加多个MNO。
          - 若系统中同时存在命令**ADD MNO**和**ADD USRMMINFO**的配置记录，系统会优先将命令**ADD USRMMINFO**配置的运营商网络名称下发给终端。

          **ADD MNO**
        - **可选：**

          当需要特定IMSI范围的用户增加特定网络名称时执行以下步骤。

          **ADD USRMMINFO**
  4. 增加HPLMN记录。

     **ADD HPLMN**
  5. 配置共享MME的PLMN ID。

     **ADD MMESHAREPLMN**

     **说明** 

     MME侧必须配置该命令，否则可能导致MME不能识别eNodeB发来的S1 Setup Request消息中携带的PLMN，从而返回S1 Setup Failure。
  6. **可选：**当MNO签订了漫游协议时，增加互联PLMN配置信息。

     **ADD CONNECTPLMN**
  7. **可选：**配置本端标识的选择规则。

     **说明** 

     对于存在多个MNO的场景，本端标识依次分为三层配置粒度，即第一层指根据IMSI号段配置，第二层根据MNO/MVNO ID配置，第三层轮选系统中所有的缺省配置。

     - 本端标识是SGSN号码

       - 根据IMSI号段选择本端标识。

         **ADD IMSICHAR**
       - 根据MNO ID选择本端标识

         **ADD HNOINFO**
     - 本端标识是Diameter

       **说明** 

       - 如果系统中配置了多个Diameter本端标识，需要执行如下步骤。
       - 如果系统中仅配置了一个Diameter本端标识，不需要执行如下步骤。

       系统配置的Diameter本端标识可以通过**LST CPDMLE**命令查询。

       - 根据IMSI号段选择本端标识

         **ADD IMSICHAR**
       - 根据MNO ID选择本端标识

         **ADD HNOINFO**
  8. **可选：**增加PLMN对应的RNC信息。当一个MNO拥有多个HPLMN，且这些PLMN都需要在RNC侧进行广播，需要为每个PLMN配置RNC和寻呼信息。

     **ADD RNC**
  9. **可选：**增加PLMN对应的寻呼信息。

     **ADD IUPAGING**

## 任务示例

任务描述

一个UEG为一个拥有2个PLMN ID的MNO服务，两个HPLMN的信息分别如下：

- PLMN1：移动国家码为123，移动网号为002，国家码为86，允许该HPLMN用户使用SMS业务，允许纠正短消息中心，纠正后的短消息中心为861395678956778。
- PLMN2：移动国家码为123，移动网号为003，国家码为86，允许该HPLMN用户使用SMS业务，不允许该HPLMN用户使用纠正短消息中心业务。

脚本

//打开本特性License开关。

```
SET LICENSESWITCH: LICITEM="LKV2HPLMN02", SWITCH=ENABLE;
```

//打开运营商网络名称下发开关，当4G终端接入时，系统允许将运营商网络名称携带给终端。

```
SET MMFUNC: MMINFO=S1_MODE-1, EMMINFOIEPLY=NETWORK_NAME-1;
```

//添加两条HPLMN记录。

```
ADD HPLMN: MCC="123", MNC="02", CC="86", MNOID=0, SM=YES, SMS=YES, SMSCR=YES, SMSCT="861395678956778", LCS=YES, S5S8TYPE=GTP, EMCBS=YES;
ADD HPLMN: MCC="123", MNC="03", CC="86", MNOID=0, SM=YES, SMS=YES, SMSCR=NO, LCS=YES, S5S8TYPE=GTP, EMCBS=YES;
```

**说明** 

增加HPLMN后，还需要进行如下配置：

- （MME）在“MML命令行-UEN”窗口执行**ADD DNSN**命令，配置FQDN与网元接口的对应关系。如下参数值仅为举例，实际请替换成局点规划的数据：

  ```
  ADD DNSN: FQDN="UEN.APN.EPC.MNC02.MCC123.3GPPNETWORK.ORG", HSINDEX=101, ENTITY=PGW, INTYPE=S5, S5PROTOCOL=GTP, S8PROTOCOL=GTP, UEUSGTYPEPLCY=NO, DCNR=YES, SMF=NO;
  ADD DNSN: FQDN="UEN.APN.EPC.MNC03.MCC123.3GPPNETWORK.ORG", HSINDEX=101, ENTITY=PGW, INTYPE=S5, S5PROTOCOL=GTP, S8PROTOCOL=GTP, UEUSGTYPEPLCY=NO, DCNR=YES, SMF=NO;
  ```
- （MME）在“MML命令行-UEN”窗口执行**ADD IMSIHSS**命令，配置IMSI和归属地HSS的映射关系。如下参数值仅为举例，实际请替换成局点规划的数据：

  ```
  ADD IMSIHSS: IMSIPRE="12302", HSSRLM="hss1";
  ADD IMSIHSS: IMSIPRE="12303", HSSRLM="hss1";
  ```
- （PGW-C/SMF）在“MML命令行-UEN”窗口执行**ADD UPAREABINDN2TAI**/**ADD UPAREABINDS1TAI**命令，配置UPF服务区名称绑定的5GTAI范围/4GTAI范围。如下参数值仅为举例，实际请替换成局点规划的数据：

  ```
  ADD UPAREABINDN2TAI: AREANAME="11_uparea_n2_1", N2BEGINTAI="12302000000", N2ENDTAI="12312FFFFFF";
  ADD UPAREABINDN2TAI: AREANAME="11_uparea_n2_1", N2BEGINTAI="12303000000", N2ENDTAI="12313FFFFFF";
  ADD UPAREABINDS1TAI: AREANAME="11_uparea_s1_1", S1BEGINTAI="123020000", S1ENDTAI="12312FFFF";
  ADD UPAREABINDS1TAI: AREANAME="11_uparea_s1_1", S1BEGINTAI="123030000", S1ENDTAI="12313FFFF";
  ```

//增加MME的共享信息。

```
ADD MMESHAREPLMN: MCC="123", MNC="00";
```
