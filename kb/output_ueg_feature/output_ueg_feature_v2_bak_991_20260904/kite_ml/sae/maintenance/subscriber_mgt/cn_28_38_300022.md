# 配置SAE-HSS全局数据

- 操作场景
- 必备事项
- 操作流程
- 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM作为SAE-HSS网元时，完成SAE-HSS全局数据的配置。

## 必备事项

前提条件

- 已经完成UDM的OMU侧的硬件数据和基础数据的配置。
- 已经完成SAE-HSS的用户数据规划。

数据

执行操作前需要规划的数据如表1所示。

| 类别           | 参数名称                | 取值样例       | 说明                                                          |
|:-------------|:--------------------|:-----------|:------------------------------------------------------------|
| ADD SYSHLRSN | SYSHLRSN (系统HLR序列号) | 1          | 工程设计输出 该参数取值与USCDB MML命令界面上的SET SYSNO命令配置的“SYSTEMNO”参数的取值相同 |
| ADD SYSHLRSN | HLRNAME (系统HLR名称)   | HLR01      | 工程设计输出                                                      |
| ADD SYSHLRSN | STATUS (状态)         | MASTER     | 单局点时，该参数固定取值为“MASTER”                                       |
| ADD VHLRSN   | HLRSN （虚拟HLR序列号）    | 1          | 工程设计输出                                                      |
| ADD VHLRSN   | HLRNAME (虚拟HLR名称)   | VHLR01     | 工程设计输出                                                      |
| ADD HLRSN    | HLRSN (HLR序列号)      | 1          | 该参数的取值需要与系统管理MML命令界面上的ADD VHLRSN命令配置的“HLRSN”的取值一一对应         |
| ADD HLRSN    | HLRNO (HLR号码)       | 8613910000 | 根据运营商要求配置。容灾局的“HLR号码”会同步主用局的“HLR号码”。                        |
| ADD HLRSN    | STATUS (状态)         | MASTER     | 单局点时，该参数固定取值为“MASTER”                                       |
| ADD HLRSN    | CCODE (国家码)         | 86         | 根据运营商要求配置                                                   |

## 操作步骤

1. 登录系统管理命令界面。
2. 执行**ADD SYSHLRSN**命令增加系统HLR。
3. 执行**ADD VHLRSN**命令增加虚拟HLR。

   **说明** 

   每个SYSHLRSN至少指定一个虚拟HLR。
4. 登录“UDM业务管理”窗口。
5. 执行**ADD HLRSN**命令增加HLR序列号。
