# 配置NB-IoT模板数据

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM作为SAE-HSS网元时，完成NB-IoT模板数据的配置。

## 必备事项

前提条件

- 已经完成UDM的OMU侧的硬件数据和基础数据的配置。
- 已经完成NB-IoT的用户数据规划。

数据

执行操作前需要规划的数据如表1所示。

| 类别            | 参数名称                          | 取值样例                    | 说明                       |
|:--------------|:------------------------------|:------------------------|:-------------------------|
| ADD EPSQOSTPL | HLRSN (HLR序列号)                | 1                       | 需通过命令ADD HLRSN添加后才可在此引用。 |
| ADD EPSQOSTPL | TPLID (QoS模板ID)               | 10                      | 运营商统一规划。                 |
| ADD EPSQOSTPL | TPLNAME (QoS模板名)              | EPS-QoS                 | 运营商统一规划。                 |
| ADD EPSQOSTPL | QOSCLASUID (QoS分类ID)          | 5                       | 运营商统一规划。                 |
| ADD EPSQOSTPL | PRILEVEL (分配/保留优先级数据)         | 1                       | 运营商统一规划。                 |
| ADD EPSQOSTPL | AMBRMAXREQBWUL(最大请求上行带宽)      | 100000                  | 运营商统一规划。                 |
| ADD EPSQOSTPL | AMBRMAXREQBWDL(最大请求下行带宽)      | 200000                  | 运营商统一规划。                 |
| ADD APNTPL    | HLRSN (HLR序列号)                | 1                       | 需通过命令ADD HLRSN添加后才可在此引用。 |
| ADD APNTPL    | TPLID (模板ID)                  | 1                       | 运营商统一规划。                 |
| ADD APNTPL    | APN (接入点名称)                   | APN1                    | 运营商统一规划。                 |
| ADD APNTPL    | PDNGWALLOCTYPE (PDN GW地址分配类型) | DYNAMIC                 | 运营商统一规划。                 |
| ADD APNTPL    | NONIPDATADELMECH (Non-IP传输模式) | SGi_BASED_DATA_DELIVERY | 运营商统一规划。                 |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD EPSQOSTPL**命令，增加EPS QoS模板。

   **说明** 

   参数“QoS分类ID”和“分配/保留优先级数据”必须同时存在，取值越小，优先级越高。
3. 执行**ADD APNTPL**命令，增加APN模板。

   **说明** 

   参数“接入点名称”必须设置。
