# VoLTE用户改号

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当VoLTE用户希望换号不换卡时，需要对用户进行改号配置。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

- 操作人员已完全了解支持VoLTE特性。
- 已完成VoLTE用户的业务发放。
- 操作人员具有业务发放权限。
- 已完成IMS网络、CS网络、HLR/HSS数据库以及EPC网络各网元的基本数据配置和对接数据配置，各网元运行正常。
- 操作人员具有PGW Web LMT的用户名和密码

数据

需要规划的数据如表1所示。

| 类别         | 参数名称     | 取值样例                                                | 说明                 |
|:-----------|:---------|:----------------------------------------------------|:-------------------|
| MOD ISDN   | 旧MSISDN  | 8613901384321                                       | 用于标识需要修改的旧的MSISDN。 |
| MOD ISDN   | 新MSISDN  | 8613901384331                                       | 用于指定新的MSISDN。      |
| MOD HHSSTN | MSISDN   | 8613901384321                                       | 用于标识需要修改的旧的MSISDN。 |
| MOD HHSSTN | 新的MSISDN | 8613901384331                                       | 用于指定新的MSISDN。      |
| MOD HHSSTN | IMPU     | sip:8613901384321@ims.mnc000.mcc460.3gppnetwork.org | 用于标识改号前的IMPU。      |
| MOD HHSSTN | 新的IMPU   | sip:8613901384331@ims.mnc000.mcc460.3gppnetwork.org | 用于指定新的IMPU。        |
| MOD HHSSTN | IMPU2    | sip:8613901384321@ics.mnc000.mcc460.3gppnetwork.org | 用于标识改号前的IMPU。      |
| MOD HHSSTN | 新的IMPU2  | sip:8613901384331@ics.mnc000.mcc460.3gppnetwork.org | 用于指定新的IMPU。        |

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**MOD ISDN**命令，为用户关联新的MSISDN。
3. 登录“IMS-HSS业务管理”窗口。
4. 执行**MOD HHSSTN**命令，为用户关联新的MSISDN和IMPU。

## 任务示例

任务描述

为VoLTE用户变更MSISDN号码。

脚本

/\*----------登录“UDM业务管理”窗口----------\*/

/\*为用户关联新的MSISDN\*/

```
MOD ISDN: IMSI="460030913121002", NEWISDN="8613901384331";
```

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*为用户关联新的MSISDN和IMPU\*/

```
MOD HHSSTN: ISDN="8613901384321", NEWISDN="8613901384331", IMPU="sip:8613901384321@ims.mnc000.mcc460.3gppnetwork.org", NEWIMPU="sip:8613901384331@ims.mnc000.mcc460.3gppnetwork.org", IMPU2="sip:8613901384321@ics.mnc000.mcc460.3gppnetwork.org", NEWIMPU2="sip:8613901384331@ics.mnc000.mcc460.3gppnetwork.org";
```
