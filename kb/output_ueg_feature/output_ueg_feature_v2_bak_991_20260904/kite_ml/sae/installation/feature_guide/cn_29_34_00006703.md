# VoLTE用户补卡

- 操作场景
- 对系统的影响
- 必备事项

- 任务示例

## 操作场景

用户因手机丢失、USIM卡损坏等原因需要补办手机卡时，需要对用户进行补卡配置。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

- 操作人员已完全了解支持VoLTE特性。
- 已完成VoLTE用户的业务发放。
- 操作人员具有业务发放权限。
- 已完成IMS网络、CS网络、HLR/HSS数据库以及EPC网络各网元的基本数据配置和对接数据配置，各网元运行正常。
- 操作人员具有PGW Web LMT的用户名和密码

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD KI**命令为新的IMSI号码增加鉴权数据。
3. 执行**MOD IMSI**命令为用户关联新的IMSI。
4. 登录“IMS-HSS业务管理”窗口。
5. 执行**MOD HHSSIMSI**命令为用户关联新的IMSI、IMPI和IMPU。

## 任务示例

任务描述

为手机丢失、USIM卡损坏的VoLTE用户补办手机卡。

脚本

/\*----------登录“UDM业务管理”窗口----------\*/

/\*为新的IMSI号码增加鉴权数据\*/

```
ADD KI: HLRSN=1, IMSI="46009000000123", KIVALUE="*****", K2SNO=0, CARDTYPE=USIM, ALG=MILENAGE, OPCVALUE="*****";
```

/\*为用户关联新的IMSI\*/

```
MOD IMSI: IMSI="46009876543210", NEWIMSI="46009000000123";
```

/\*----------登录“IMS-HSS业务管理”窗口----------\*/

/\*为用户关联新的IMSI、IMPI和IMPU\*/

```
MOD HHSSIMSI: IMPI="46009876543210@ims.mnc000.mcc460.3gppnetwork.org", IMPU="sip:46009876543210@ims.mnc000.mcc460.3gppnetwork.org", NEWIMPI="46009000000123@ims.mnc000.mcc460.3gppnetwork.org", NEWIMPIAUTHTYPE=EAA, IMSI="46009000000123", NEWIMPU="sip:46009000000123@ims.mnc000.mcc460.3gppnetwork.org", IMPI2="46009876543210@ics.mnc000.mcc460.3gppnetwork.org", IMPU2="sip:46009876543210@ics.mnc000.mcc460.3gppnetwork.org", NEWIMPI2="46009000000123@ics.mnc000.mcc460.3gppnetwork.org", NEWIMPI2AUTHTYPE=TAA, NEWIMPU2="sip:46009000000123@ics.mnc000.mcc460.3gppnetwork.org";
```
