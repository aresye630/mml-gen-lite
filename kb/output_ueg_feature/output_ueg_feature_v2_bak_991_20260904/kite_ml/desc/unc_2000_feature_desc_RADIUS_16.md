# 配置AAA鉴权的3GPP扩展属性

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

根据要求在UEG上配置AAA鉴权消息中携带的3GPP扩展属性。

**说明** 

适用于PGW-C、SMF

## 对系统的影响

配置的数据，对配置后激活的用户生效。

## 必备事项

前提条件

完成配置RADIUS功能。

数据

| 类别               | 参数名称                        | 取值样例   | 获取方法   | 说明                                       |
|:-----------------|:----------------------------|:-------|:-------|:-----------------------------------------|
| AAA鉴权请求携带的私有扩展属性 | RADIUS服务器组名称（RDSSVRGRPNAME） | ss     | 本端规划   | 鉴权服务器所在的Radius服务器组，已通过ADD RDSSVRGRP进行配置。 |
| AAA鉴权请求携带的私有扩展属性 | 3GPP私有扩展属性开关（THREEGPP）      | ENABLE | 本端规划   | SET RDSAUTHREQVSA                        |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置AAA鉴权消息中携带的3GPP扩展属性。

   **SET RDSAUTHREQVSA**

   **说明** 

   缺省情况下不支持鉴权消息中携带3GPP（26/10415）这组属性。

## 任务示例

任务描述

配置AAA鉴权消息中携带的3GPP扩展属性。

脚本

//配置AAA鉴权消息中携带的3GPP扩展属性。

```
SET RDSAUTHREQVSA: RDSSVRGRPNAME="ss",THREEGPP=ENABLE;
```
