# 激活基于VoLTE的优先语音服务（适用于MME）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本操作指导介绍在运行网络中激活基于VoLTE的优先语音服务业务特性的操作过程，包括两种方案，配置MPS业务功能和配置语音寻呼优先业务功能。

| 方案           | 是否需要用户签约   | 应用业务场景            | 部署建议                                        |
|:-------------|:-----------|:------------------|:--------------------------------------------|
| 语音寻呼优先业务（推荐） | 否          | 仅针对VoLTE/CSFB被叫业务 | VoLTE组网场景下推荐部署本方案，以提升被叫寻呼成功率，提升用户语音业务体验。    |
| MPS业务        | 是          | 针对所有业务            | MPS业务的优先级高于语音寻呼优先业务，该方案可提升特定签约用户享用网络资源的优先级。 |

**说明** 

适用于MME。

## 必备事项

前提条件

- 请仔细阅读GWFD-025402 基于VoLTE的优先语音服务特性概述。
- 已经加载支持该特性的License。
- 本特性需要在MME、eNodeB、SGW-C/PGW-C、PCRF、SPR、P-CSCF等网元上完成基本业务的数据配置。
- 用户需要在HSS签约相应数据。

数据

| 类别         | 参数名称                            | 取值样例   | 获取方法   | 说明          |
|:-----------|:--------------------------------|:-------|:-------|:------------|
| SET MMFUNC | 是否支持语音优先寻呼（VOICEPAGINGPRIORITY） | YES    | 全网规划   | 开启语音寻呼优先功能。 |

| 类别         | 参数名称             | 取值样例   | 获取方法   | 说明         |
|:-----------|:-----------------|:-------|:-------|:-----------|
| SET MPSARP | MPS功能开关（MPSFUNC） | ON     | 全网规划   | 配置MPS业务数据。 |
| SET MPSARP | 优先级（PRILVL）      | 7      | 全网规划   | 配置MPS业务数据。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. **推荐：**部署语音寻呼优先业务。

   **SET MMFUNC**
4. **可选：**部署MPS业务。

   **SET MPSARP**

   **说明** 

   步骤3和步骤4部署时二选一，推荐部署语音寻呼优先业务。

## 任务示例

任务描述

任务一（推荐方案）：启用基于VoLTE的优先语音服务业务，选择语音寻呼优先业务方案。

任务二：启用基于VoLTE的优先语音服务业务，选择MPS业务方案，设置MPS的ARP优先级临界值为7。

脚本

//进入“MML命令行-UEG”窗口。

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2EMPS01", SWITCH=ENABLE;
```

//配置优先级功能。

//方案一（推荐方案）：打开语音寻呼优先功能。

```
SET MMFUNC: VOICEPAGINGPRIORITY=YES;
```

//方案二：开启MPS功能开关，并设置优先级临界值。

```
SET MPSARP: MPSFUNC=ON, PRILVL=7;
```
