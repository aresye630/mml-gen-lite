## 操作场景

当运营商在部署分组交换网，新增UEG时，需配置GTP/PFCP路径管理参数。通过GTP/PFCP路径管理，UEG可以进行到对端网元的路径管理，并控制路径中断后对已激活上下文的处理方式。

**说明** 

- GTP路径管理应用以下对接网元之间。
  - eNodeB与SGW-U之间。
  - SGW-U与PGW-U之间。
  - eNodeB/GnGp-SGSN和PGW-U之间。
  - UPF和UPF之间。
  - R(AN)和UPF之间。
- PFCP路径管理应用以下对接网元之间。
  - SGW-C和SGW-U之间。
  - PGW-C和PGW-U之间。
  - SMF和UPF之间。
- 路径管理在UEG和对端网元间是双向的，如果一方开启了本功能，为节省网络带宽资源，可以关闭另外一端的Echo消息开关。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 操作步骤

1. 配置GTP路径管理参数。

   设置UEG上的Echo开关属性及请求间隔，设置Echo消息的重发时间间隔和最大尝试发送次数，配置GTP路径断开后UEG对该路径上已激活PDP上下文/EPS承载/PDU Session的处理。

   **SET UPGTPPATH**

   **说明** 

   - 只有在UEG启动路径管理功能时，才需执行本配置。
   - 通过配置**SET UPGTPPATH**的“LOGICINFTYPE”参数，可以针对指定类型接口间的路径启动路径探测功能，包括N3、S1-U、S11-U、N9c、S5-S\S8-S、Pa(N9a/S5-P/S8-P/S2b/Gn-U/Gp-U)接口。如果N3和S1-U接口合一为Saif抽象接口时，则仅能针对Saif抽象接口启动路径探测功能；如果N9c和S5-S/S8-S接口合一为Scif抽象接口时，则仅能针对Scif接口启动路径探测功能。如果N3、S1-U、S11-U、N9c、S5-S\S8-S需要启动独立接口间的路径探测功能，则必须按照独立接口配置。
   - 不配置**SET UPGTPPATH**的“LOGICINFTYPE”参数时，则针对所有非N4/Sxb接口间的路径启动路径探测功能。
2. 配置PFCP路径管理参数。

   设置UEG上的PFCP开关属性及请求间隔，设置PFCP Heartbeat消息的重发时间间隔和最大尝试发送次数，配置PFCP路径断开后UEG对该路径上已激活PDP上下文/EPS承载/PDU Session的处理。

   **SET UPPFCPPATH**

## 任务示例

任务描述

- 配置UEG N9c接口的GTP路径探测参数。Echo请求间隔时间为60秒，Echo请求消息的重发时间间隔为10秒，最大尝试发送次数为5次。配置GTP数据路径断告警产生后发送20个Echo请求消息，之后去激活此路径上用户面的所有上下文。
- 配置UEG主动发送PFCP心跳请求的间隔时间为60秒。配置PFCP请求消息的重发时间间隔为3秒，最大尝试发送次数为5次。配置PFCP信令路径断告警产生后发送30个PFCP心跳请求消息，之后去激活此路径上用户面的所有上下文。

脚本

//设置N9c接口的GTP路径探测参数。

```
SET UPGTPPATH:V1DATAECHOSW=ENABLE,ECHOINTERVAL=60,T3RESPONSE=10,N3REQUEST=5,DEACTIVEFLAG=ENABLE,ECHOTIME=20,LOGICINFTYPE=N9c;
```

//设置PFCP路径管理参数。

```
SET UPPFCPPATH:HEARTBEATINTERVAL=60,T3RESPONSE=3,N3REQUEST=5,DEACTIVEFLAG=ENABLE,HEARTBEATTIME=30;
```
