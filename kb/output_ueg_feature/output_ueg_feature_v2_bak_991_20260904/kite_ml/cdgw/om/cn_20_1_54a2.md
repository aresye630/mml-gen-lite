# 修改DDoS流控阈值

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

网络调整需要修改DDoS流控阈值。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 对系统的影响

允许用户发起的TCP建链请求的次数会跟随DDoS检测阈值变化。

## 必备事项

前提条件

请仔细阅读GWFD-021403 防DDoS功能。

数据

| 类别       | 参数名称                |   取值样例 | 获取方法   | 说明                     |
|:---------|:--------------------|-------:|:-------|:-----------------------|
| SET DDOS | DDos防护阈值（THRESHOLD） |    150 | 本端规划   | 每个用户每秒允许转发的TCP建链请求包的个数 |

## 操作步骤

修改DDoS流控阈值。

**SET DDOS**

## 任务示例

任务描述

调整DDoS流控阈值为150。

脚本

//修改DDoS流控阈值。

```
SET DDOS:THRESHOLD=150;
```
