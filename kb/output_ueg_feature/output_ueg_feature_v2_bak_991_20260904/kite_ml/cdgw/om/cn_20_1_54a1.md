# 修改DDoS Check是否使能

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

需要修改DDoS Check是否使能。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 对系统的影响

该操作对系统正常运行没有影响。

## 必备事项

前提条件

请仔细阅读GWFD-021403 防DDoS功能。

数据

| 类别              | 参数名称                    | 取值样例    | 获取方法   | 说明   |
|:----------------|:------------------------|:--------|:-------|:-----|
| MOD USERPROFILE | 用户模板名称（USERPROFILENAME） | up_test | 本端规划   | -    |
| MOD USERPROFILE | 防DDoS攻击标记（DDOSCHECK）    | ENABLE  | 本端规划   | -    |

## 操作步骤

修改UserProfile的DDoS Check使能。

**MOD USERPROFILE**

## 任务示例

任务描述

修改用户模板的DDoS Check使能。

脚本

//修改UserProfile的DDoS Check使能。

```
MOD USERPROFILE:USERPROFILENAME="up_test",DDOSCHECK=ENABLE;
```
