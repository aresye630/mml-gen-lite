# 基于APN/DNN分配地址

- 操作场景

## 操作场景

运营商规划用户面网元（UPF/PGW-U）基于APN/DNN为UE分配IP地址时，可激活本特性。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-020805 用户面地址分配特性概述。
- UEG本端已完成数据面逻辑接口（Sa/Sc/Pa）和N4/Sxa/Sxb逻辑接口的配置，配置过程可参考初始配置手册的配置业务接口数据。

## 操作步骤

1. 基于APN/DNN实例使能地址分配属性。
   1. 创建L3VPN实例。

      **ADD L3VPNINST**

      **ADD VPNINSTAF**
   2. 配置VPN实例。

      **ADD VPNINST**
   3. 配置APN/DNN实例。

      **ADD APN****(风筝S)/ADD UPAPN(风筝M或L)**
   4. 使能该APN的地址分配属性。

      **SET APNADDRESSATTR**
2. 配置地址池绑定到地址池组。
   1. 配置LOCAL类型地址池。

      **ADD POOL****(风筝S)/ADD UPPOOL(风筝M或L)**

      **说明** 

      配置本地地址池的时候，选择参数“LOCAL”类型。
   2. 配置地址池里的地址段。

      **ADD SECTION**
   3. 配置地址池组。

      **ADD POOLGROUP**
   4. 配置地址池绑定到地址池组。

      **ADD POOLBINDGROUP**
   5. （可选）配置本地地址池中的冲突IPv4地址，标识为冲突状态的IPv4地址不会分配给用户。

      **ADD CONFLICTIP**
3. 配置APN与地址池组的映射关系。
   1. 配置APN/DNN实例信息。

      **ADD APN****(风筝S)/ADD UPAPN(风筝M或L)**
   2. 配置APN/DNN实例与地址池组的映射关系。

      **ADD POOLGRPMAP**
4. 配置地址分配规则。

   **说明** 

   地址分配规则支持两级控制：基于全局和基于APN。默认使用全局地址分配规则。如果配置了使用基于APN的地址分配规则，则使用APN的地址分配规则。

   1. 配置全局地址分配规则。

      **SET IPALLOCRULE**

      **说明** 

      每级优先级规则中所选的条件之间为“与”的关系，表示从所选条件映射的地址范围内分配地址，此处设置的规则需要与地址池的映射条件一致。例如此处按照SMF+APN（APN-1&LOCATION-0&SMF-1）设置条件，则规划的地址池组需绑定SMF&APN。
   2. （可选）如果某一APN的地址分配规则不同于全局地址分配规则，则需执行配置基于APN的地址分配规则优先级。

      **SET APNIPALLOCRULE**
5. 配置手机下行路由。
   1. 启动OSPF进程。

      **ADD OSPF**
   2. 添加OSPF区域。

      **ADD OSPFAREA**
   3. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   4. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**

## 任务示例

任务描述

UE接入核心网，UEG采用本地地址池为UE动态分配IPv4地址。其中第一优先级按照从APN/DNN映射的地址范围内分配地址，如果第一优先级的规则匹配不上，则分配地址失败。指定地址池中的10.1.1.1地址为冲突地址。

脚本

//配置VPN实例。

```
ADD L3VPNINST:VRFNAME="vpn1";
ADD VPNINSTAF:VRFNAME="vpn1",AFTYPE=ipv4uni,VRFRD=100:1;
```

//（风筝S）基于APN使能地址分配属性。

```
ADD VPNINST:VPNINSTANCE="vpn1";
ADD APN:APN="apn-test1",HASVPN=ENABLE,VPNINSTANCE="vpn1";
SET APNADDRESSATTR:APN="apn-test1",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE;
```

//（风筝M/L）基于APN使能地址分配属性。

```
ADD VPNINST:VPNINSTANCE="vpn1";
ADD UPAPN:APN="apn-test1",HASVPN=ENABLE,VPNINSTANCE="vpn1";
SET APNADDRESSATTR:APN="apn-test1",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE;
```

//（风筝S）配置地址池。

```
ADD POOL:POOLNAME="testpool1",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="vpn1";
ADD SECTION:POOLNAME="testpool1",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.1",V4ENDIP="10.10.1.10";
```

//（风筝M/L）配置地址池。

```
ADD UPPOOL:POOLNAME="testpool1",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="vpn1";
ADD SECTION:POOLNAME="testpool1",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.1",V4ENDIP="10.10.1.10";
```

//配置地址池绑定到地址池组。

```
ADD POOLGROUP: POOLGRPNAME="poolgroup1";
```

```
ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup1", POOLNAME="testpool1";
ADD CONFLICTIP:POOLNAME="testpool1",IPADDRESS="10.1.1.1";
```

//配置APN与地址池组的映射关系。

```
ADD POOLGRPMAP: MAPPINGNAME="mapping1", APN="apn-test1", POOLGROUPNAME="poolgroup1";
```

//配置地址分配规则。

```
SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE;
```

//配置手机下行路由。

```
ADD OSPF: PROCID=100, VRFNAME="vpn1", SCHEMAROUID="10.10.10.1", LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500;
```

```
ADD OSPFAREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFNETWORK:PROCID=100,AREAID="0.0.0.0", IPADDRESS="10.13.21.0", WILDCARDMASK="0.0.0.255";
```

```
ADD OSPFIMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```
