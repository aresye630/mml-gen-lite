# 激活防DDoS功能

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

为了防止PDN侧网络设备遭受移动用户的DDoS攻击，运营商可以启用UEG的防范DDoS攻击功能。在UEG上配置报文连接最大速率，当UE向PDN侧网络设备发起TCP连接，如果MS发送的SYN报文连接速率超过配置值，UEG将丢弃报文，以保护PDN侧的网络设备。

**说明** 

适用于SGW-U、PGW-U、UPF。

## 必备事项

前提条件

请仔细阅读GWFD-021403 防DDoS功能。

数据

| 类别              | 参数名称                    | 取值样例    | 获取方法   | 说明            |
|:----------------|:------------------------|:--------|:-------|:--------------|
| SET DDOS        | DDoS防护阈值（THRESHOLD）     | 10      | 本端规划   | 允许发起最大TCP连接数。 |
| ADD USERPROFILE | 用户模板名称（USERPROFILENAME） | up_test | 本端规划   | -             |
| ADD USERPROFILE | 防DDoS攻击标记（DDOSCHECK）    | ENABLE  | 本端规划   | -             |

## 操作步骤

1. 设置DDoS攻击防护使用的流控阈值。

   **SET DDOS**
2. 使能UserProfile的防范DDoS功能。

   **ADD USERPROFILE**

## 任务示例

任务描述

为了防止PDN侧网络设备遭受移动用户的DDoS攻击，采用防范DDoS攻击功能。

脚本

//设置防范DDoS攻击的流控阈值。

```
SET DDOS:THRESHOLD=10;
```

//使能UserProfile的防范DDoS功能。

```
ADD USERPROFILE:USERPROFILENAME="up_test",DDOSCHECK=ENABLE;
```
