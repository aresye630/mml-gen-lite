# 激活基于域名的本地分流（DNS域名分流）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

在UEG上部署基于域名的本地分流功能，需要配置七层分流规则。

**说明** 

适用于UPF。

## 必备事项

前提条件

- 请仔细阅读基于域名的本地分流特性概述。
- UEG完成与周边网元的对接。

数据

| 类别                | 参数名称                       | 取值样例                                | 获取方法     | 说明                                                                  |
|:------------------|:---------------------------|:------------------------------------|:---------|:--------------------------------------------------------------------|
| SET COLOCATEDLBO  | ULCL功能开关（ULCLSWITCH）       | ENABLE                              | 本端规划     | 配置UL CL与PSA2共部署的本地分流功能开关。                                           |

| ADD FILTER        | 三四层IPv4协议输入类型（L34PROTOCOL） | UDP ANY                             | 本端规划     | 配置三四层过滤条件。  说明： 匹配DNS报文的过滤条件，三四层协议只能配置为UDP。                         |
| ADD FILTER        | 服务器起始端口号（SVRSTARTPORT）     | 53                                  | 本端规划     | 配置三四层过滤条件。  说明： 匹配DNS报文的过滤条件，三四层协议只能配置为UDP。                         |
| ADD FILTER        | 服务器结束端口号（SVRENDPORT）       | 53                                  | 本端规划     | 配置三四层过滤条件。  说明： 匹配DNS报文的过滤条件，三四层协议只能配置为UDP。                         |
| ADD FILTER        | 服务器IP地址配置模式（SVRIPMODE）     | HOSTNAME                            | 本端规划     | 配置三四层过滤条件。  说明： 匹配DNS报文的过滤条件，三四层协议只能配置为UDP。                         |

| ADD FLTBINDFLOWF  | 过滤器名称（FILTERNAME）          | filter_test01 filter_test02         | 已配置数据中获取 | 过滤器名称已通过ADD FILTER命令配置。                                             |

| ADD L7FILTER      | URL（URL）                   | www.huawei.com                      | 已配置数据中获取 | 该参数取值要和ADD HOST命令配置的域名保持一致。                                         |
| ADD PROTBINDFLOWF | 流过滤器名称（FLOWFILTERNAME）     | flowfilter_ulcl01                   | 已配置数据中获取 | 流过滤器名称已通过ADD FLOWFILTER命令配置。                                        |
| ADD PROTBINDFLOWF | 协议名称（PROTOCOLNAME）         | dns                                 | 本端规划     | 匹配DNS报文的过滤条件需要绑定七层协议。                                               |
| ADD PROTBINDFLOWF | 七层过滤器名字（L7FILTERNAME）      | l7filter-test                       | 已配置数据中获取 | 七层过滤器名字已通过ADD L7FILTER命令配置。                                         |

| ADD FLOWFILTERGRP | 流过滤器逻辑分组（FLWFLTRLOGICGRP）  | OR                                  | 本端规划     | 或组内的任何一个流过滤器命中，则执行分流流程。                                             |

## 操作步骤

1. 配置UL CL与PSA2共部署的本地分流功能开关。

   **SET COLOCATEDLBO**
2. 配置Host信息。

   **ADD HOST**
3. 配置基于域名的本地分流过滤条件。
   1. 配置流过滤器。

      **ADD FLOWFILTER**
   2. 配置三四层过滤条件。

      **ADD FILTER**
   3. 绑定三四层过滤条件。

      **ADD FLTBINDFLOWF**
   4. 配置七层过滤条件。

      **ADD L7FILTER**
   5. 绑定七层过滤条件。

      **ADD PROTBINDFLOWF**
4. 配置本地分流流过滤器组。

   **ADD FLOWFILTERGRP**

   **说明** 

   - 流过滤器组对应SMF下发的AppID。一个流过滤器组中需要绑定基于域名的本地分流过滤条件，才能实现针对一个AppID的分流功能。
   - 匹配中流过滤器组后，根据ApplD检索到分流PDR，然后按照PDR中的转发规则FAR、QoS规则QER执行策略动作。

## 任务示例

任务描述

开启UEG的本地分流功能，UEG将访问URL为www.huawei.com的用户业务报文执行分流动作。

脚本

//配置UL CL与PSA2共部署的本地分流功能开关。

```
SET COLOCATEDLBO: ULCLSWITCH=ENABLE;
```

//配置Host信息。

```
ADD HOST:HOSTNAME="host1",DOMAINVALUE="www.huawei.com";
```

//配置针对DNS报文的L7过滤条件。

```
ADD FLOWFILTER: FLOWFILTERNAME="flowfilter_ulcl01", TETHERDETFLAG=NONE;
ADD FILTER:FILTERNAME="filter_test01",L34PROTTYPE=STRING,L34PROTOCOL=UDP,SVRSTARTPORT=53,SVRENDPORT=53;
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_ulcl01",FILTERNAME="filter_test01";
ADD L7FILTER:L7FILTERNAME="l7filter-test",SUBL7FLTNAME="sl7filter-test",URLTYPE=URL,URL="www.huawei.com";
ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfilter_ulcl01",PROTOCOLNAME="dns",L7FILTERNAME="l7filter-test";
```

//配置针对IP报文的L34过滤条件。

```
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_ulcl02";
ADD FILTER:FILTERNAME="filter_test02",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=HOSTNAME,HOSTNAME="host1";
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_ulcl02",FILTERNAME="filter_test02";
```

//配置本地分流流过滤器组。

```
ADD FLOWFILTERGRP:FLWFLTRGRPNAME="flowfiltergrp_ulcl01",FLOWFILTERNAME="flowfilter_ulcl01",FLWFLTRLOGICGRP=OR;
ADD FLOWFILTERGRP:FLWFLTRGRPNAME="flowfiltergrp_ulcl01",FLOWFILTERNAME="flowfilter_ulcl02",FLWFLTRLOGICGRP=OR;
```
