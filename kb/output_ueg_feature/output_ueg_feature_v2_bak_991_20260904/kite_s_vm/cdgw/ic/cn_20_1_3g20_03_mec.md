# 配置基于七层解析的内容计费

- 操作场景

## 操作场景

UEG通过对用户七层数据报文进行分析和检测，对于匹配到规则的业务采取相应的计费策略。

此配置实例以离线计费为例，进行七层业务的内容计费配置。

**说明** 

适用于SGW-U、PGW-U、UPF。

请仔细阅读GWFD-022102 内容计费基本功能。

## 操作步骤

配置基于七层解析的内容计费。

1. 配置内容计费使用的URR Group。

   1. 配置URR。

      **ADD URR**
   2. 配置上行和下行发起的业务对应的URR。

      **ADD URRGROUP**
2. 配置内容计费使用的PCC策略组。

   **ADD PCCPOLICYGRP**
3. 配置过滤条件。

   1. 配置七层过滤条件。

      **ADD L7FILTER**
   2. 配置流过滤器。

      **ADD FLOWFILTER**
   3. 绑定七层过滤条件。

      **ADD PROTBINDFLOWF**
4. 配置内容计费使用的规则。

   **ADD RULE**
5. 配置内容计费规则绑定用户模板。

   1. 创建UserProfile实例。

      **ADD USERPROFILE**
   2. 将已配置的内容计费规则绑定到UserProfile。

      **ADD RULEBINDING**

## 任务示例

任务描述

UEG将访问http业务且URL为www.huawei.com的用户业务报文记入URR ID为01的URR中，进行在线计费。

脚本

//配置在线计费的费率标识。

```
ADD URR:URRNAME="urr_red",URRID=01,USAGERPTMODE=ONLINE;
ADD URRGROUP:URRGROUPNAME="cp_red",UPURRNAME1="urr_red",DOWNURRNAME1="urr_red";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="cg_red",URRGROUPNAME="cp_red";
```

//配置七层信息。

```
ADD L7FILTER:L7FILTERNAME="l7-test",SUBL7FLTNAME="sl7-test",URL="www.huawei.com";
ADD FLOWFILTER:FLOWFILTERNAME="fg_red";
ADD PROTBINDFLOWF:FLOWFILTERNAME="fg_red",PROTOCOLNAME="http",L7FILTERNAME="l7-test";
```

//配置内容计费规则。

```
ADD RULE:RULENAME="rule_red",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="fg_red",POLICYNAME="cg_red";
```

//配置内容计费规则绑定用户模板。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_red";
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```
