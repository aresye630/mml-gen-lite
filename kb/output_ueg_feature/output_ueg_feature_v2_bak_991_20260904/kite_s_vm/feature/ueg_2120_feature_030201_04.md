## 操作场景

**地市共享UPF组网**场景下，分流到本地DN的数据包和转发到Internet的数据包需要通过绑定不同VPN进行区分。

**说明** 

适用于UPF。

## 必备事项

前提条件

- 请仔细阅读业务访问控制特性概述。
- UEG完成与周边网元的对接。

数据

| 类别       | 参数名称                   | 取值样例         | 获取方法     | 说明                                                                                  |
|:---------|:-----------------------|:-------------|:---------|:------------------------------------------------------------------------------------|
| ADD DNAI | 数据网络接入标识（DNAI）         | test_dnai_01 | 与对端协商    | 在SMF上会配置UPF、UL CL属性和DNAI的映射关系，SMF通过N4接口下发给UL CL+辅锚点UPF，UPF上的DNAI需要与SMF上的DNAI配置保持一致。 |
| ADD DNAI | 绑定VPN（HASVPN）          | ENABLE       | 本端规划     | 当接入用户为IPv4单栈或IPv4v6双栈用户时，要绑定IPv4类型的VPN。                                             |
| ADD DNAI | VPN实例名（VPNINSTANCE）    | VPN_Co       | 已配置数据中获取 | 配置DNAI和VPN的映射关系。VPN实例名称已通过ADD VPNINST命令配置。此VPN实例名不能与DNN（APN）下配置的VPN实例名相同。           |
| ADD DNAI | 绑定IPv6 VPN（HASVPNIPV6） | DISABLE      | 本端规划     | 当接入用户为IPv6单栈或IPv4v6双栈用户时，要绑定IPv6类型的VPN。                                             |

## 操作步骤

1. 基于DNAI配置VPN。

   **ADD DNAI**

   **说明** 

   - UPF上的DNAI需要与SMF上的DNAI配置保持一致。
   - SMF下发给UL CL+辅锚点UPF的DNAI必须配置VPN，并且跟用户激活所在DNN（APN）下绑定的VPN不同。如果SMF针对同一用户下发多个DNAI，则对这些DNAI需要配置相同的VPN。

## 任务示例

任务描述

地市共享UPF组网场景下，接入用户为IPv4单栈用户，针对UL CL用户携带的DNAI配置VPN绑定关系。

脚本

//配置DNAI与VPN的绑定关系。

```
ADD DNAI: DNAI="test_dnai_01", HASVPN=ENABLE, VPNINSTANCE="VPN_Co",HASVPNIPV6=DISABLE;
```
