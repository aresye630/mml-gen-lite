# 配置APN锁定状态上报SMF

- 操作场景
- 必备事项
- 任务示例

## 操作场景

需要在UPF上锁定APN，SMF联动选择其他UPF时，请参考本章节进行操作。

## 必备事项

前提条件

- 请仔细阅读支持APN锁定状态上报SMF功能概述。
- 请参考“UPF选择专题”描述，在SMF上完成相关配置。

数据

| 类别      | 参数名称                 | 取值样例   | 获取方法     | 说明              |
|:--------|:---------------------|:-------|:---------|:----------------|
| LCK APN | APN名称（APN）           | test   | 已配置数据中获取 | 已通过ADD APN命令配置。 |
| LCK APN | 锁定（LOCKED）           | ENABLE | 本端规划     | 配置锁定或解锁定。       |
| LCK APN | N4链路上报状态（N4RPTSTATE） | ENABLE | 本端规划     | 配置锁定状态是否上报SMF。  |

## 任务示例

任务描述

针对已有APN test，配置锁定APN时同时设置锁定状态上报SMF，解锁APN时解除锁定状态上报。

脚本

//锁定APN。

```
LCK APN: APN="test", LOCKED=ENABLE, N4RPTSTATE=ENABLE;
```

//解锁定APN。

```
LCK APN: APN="test", LOCKED=DISABLE, N4RPTSTATE=DISABLE;
```
