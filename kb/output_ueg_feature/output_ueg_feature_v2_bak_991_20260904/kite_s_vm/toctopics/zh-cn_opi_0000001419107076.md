## 操作场景

当存在PGW-U/UPF与数据网络之间的接口故障场景时，可以激活快速业务恢复特性。激活快速业务恢复特性，需要在PGW-U/UPF侧和PGW-C/SMF侧分别进行配置。PGW-U/UPF侧配置请参考本章节进行操作。请在PGW-C/SMF侧完成配置后，然后在PGW-U/UPF侧进行配置。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-021407 快速业务恢复特性概述。
- 完成加载license（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 开启License开关。

   **SET LICENSESWITCH**
2. 配置逻辑口的VPN实例。

   **ADD VPNINST**

   **说明** 

   - 逻辑接口的VPN一定要与其对应的外联口的VPN相同，否则从逻辑接口发出去的报文会查询路由失败。
   - VPN必须与探测路径关联的APN的VPN保持一致。
3. 配置本端逻辑接口。

   **ADD LOGICINF**
4. 配置探测路径。一般建议一个APN下至少配置2条路径。

   **ADD DETECTPATH**
5. 配置DNN/APN实例。

   **ADD APN**
6. 配置DNN/APN与探测路径的关联关系。

   **ADD APNBINDPATH**
7. 使能PGW-U/UPF与数据网络间基于DNN/APN粒度的隧道链路状态上报功能。

   **SET APNTNLSTATUSRPT**
8. 设置APN N6故障状态上报SMF周期。

   **SET RPTPERIOD**
9. 与静态路由冗余特性叠加使用时，需要使能单通检测功能。

   **SET APNSGLPASS**

   **SET APNSOFTPARA**

## 任务示例

任务描述

未部署静态地址路由冗余功能时，以IPv6地址为例，基于APN“huawei.com”在PGW-U/UPF侧配置激活快速业务恢复功能。

脚本

//开启License开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5N6FL01", SWITCH=ENABLE;
```

//配置VPN实例。

```
ADD VPNINST:VPNINSTANCE="VRF_CN";
```

//配置本端逻辑接口。

```
ADD LOGICINF: NAME="phif1/0/1", IPVERSION=IPV6, VPNINSTANCE="VRF_CN",IPV6ADDRESS1="FC00::4:1", IPV6PREFIXLEN1=128;
```

//配置探测路径。

```
ADD DETECTPATH: PATHNAME="testpath1", LOCALINF="phif1/0/1", IPVERSION=IPV6, PEERIPV6="FC00:0:0:0:0:0:0:1";
ADD DETECTPATH: PATHNAME="testpath2", LOCALINF="phif1/0/1", IPVERSION=IPV6, PEERIPV6="FC01:0:0:0:0:0:0:1";
```

//配置DNN/APN实例。

```
ADD APN: APN="huawei.com", HASVPN=ENABLE, VPNINSTANCE= "VRF_CN";
```

//配置DNN/APN与探测路径的关联关系。

```
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath1";
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath2";
```

//使能PGW-U/UPF与数据网络间基于DNN/APN粒度的隧道链路状态上报功能。

```
SET APNTNLSTATUSRPT: APN="huawei.com", SWITCH=ENABLE;
```

//设置APN N6故障状态上报SMF周期。

```
SET RPTPERIOD: RPTPERIOD=4;
```

## 任务示例

任务描述

在部署静态地址路由冗余功能的基础上（激活静态地址用户路由冗余），以IPv6地址为例，基于APN“huawei.com”在备UPF侧配置激活快速业务恢复功能。主UPF上的配置参考任务示例。

备UPF需要申请2个Phif接口IP地址，其中phif1/0/0是备UPF探测本地N6路径使用，phif1/0/1是备UPF经GRE冗余隧道探测企业N6路径使用。

脚本

//开启License开关。

```
SET LICENSESWITCH: LICITEM="LKV3G5N6FL01", SWITCH=ENABLE;
```

//配置VPN实例。

```
ADD VPNINST:VPNINSTANCE="VRF_CN";
```

//配置本端逻辑接口。

```
ADD LOGICINF: NAME="phif1/0/0", IPVERSION=IPV6, VPNINSTANCE="VRF_CN",IPV6ADDRESS1="FC00::5:1", IPV6PREFIXLEN1=128;
ADD LOGICINF: NAME="phif1/0/1", IPVERSION=IPV6, VPNINSTANCE="VRF_CN",IPV6ADDRESS1="FC00::5:2", IPV6PREFIXLEN1=128;
```

//配置探测路径。

```
ADD DETECTPATH: PATHNAME="testpath1", LOCALINF="phif1/0/0", IPVERSION=IPV6, PEERIPV6="FC00:0:0:0:0:0:0:1" , REDUNDRDTSW  = DISABLE;
ADD DETECTPATH: PATHNAME="testpath2", LOCALINF="phif1/0/0", IPVERSION=IPV6, PEERIPV6="FC01:0:0:0:0:0:0:1" , REDUNDRDTSW  = DISABLE;
ADD DETECTPATH: PATHNAME="testpath3", LOCALINF="phif1/0/1", IPVERSION=IPV6, PEERIPV6="FC00:0:0:0:0:0:0:1", REDUNDRDTSW = ENABLE , REDUNDRDTIPV6="fc00:3::1";
ADD DETECTPATH: PATHNAME="testpath4", LOCALINF="phif1/0/1", IPVERSION=IPV6, PEERIPV6="FC01:0:0:0:0:0:0:1", REDUNDRDTSW = ENABLE , REDUNDRDTIPV6="fc00:3::1";
```

//配置DNN/APN实例。

```
ADD APN: APN="huawei.com", HASVPN=ENABLE, VPNINSTANCE= "VRF_CN";
```

//配置DNN/APN与探测路径的关联关系。

```
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath1";
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath2";
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath3";
ADD APNBINDPATH: APN="huawei.com", DETECTPATH="testpath4";
```

//使能PGW-U/UPF与数据网络间基于DNN/APN粒度的隧道链路状态上报功能。

```
SET APNTNLSTATUSRPT: APN="huawei.com", SWITCH=ENABLE;
```

//设置APN N6故障状态上报SMF周期。

```
SET RPTPERIOD: RPTPERIOD=4;
```

//使能单通检测功能。

```
SET APNSGLPASS: APN="huawei.com", SWITCH=PF_ACT_ENABLE;
```
