## 操作场景

动态Traffic Rule和动态DNS Rule在MPF上存在两种状态：ACTIVE（激活状态）、INACTIVE（去激活状态）。在不同场景下或针对不同运营商，支持如下两种方式下发动态Traffic Rule和动态DNS Rule：

1. 第三方管理平台通过MEPM向MPF动态Traffic Rule时，下发的动态Traffic Rule全部是ACTIVE状态。
2. 管理面MEAO/MEPM下发的动态Traffic Rule保存在MPF上时初始状态均被置为INACTIVE。

上述两种下发方式下，MPF均支持通过MPF本地配置的命令修改动态Traffic Rule和动态DNS Rule状态：

- 通过**ACT TRAFFICRULE**命令将动态Traffic Rule的状态从INACTIVE修改为ACTIVE；通过**DEA TRAFFICRULE**命令将动态Traffic Rule的状态从ACTIVE修改为INACTIVE。
- 通过**ACT DNSRULE**命令将动态DNS Rule的状态从INACTIVE修改为ACTIVE；通过**DEA DNSRULE**命令将动态DNS Rule的状态从ACTIVE修改为INACTIVE。

**说明** 

适用于MPF。

## 操作步骤

1. **可选：**激活DNS Rule。

   **ACT DNSRULE**

   **说明** 

   MPF支持激活动态DNS Rule状态。

   - MPF基于appName粒度激活动态DNS Rule时，该指定appName下所有动态DNS Rule的状态将置为ACTIVE。
   - MPF基于appName和appInstanceId粒度激活动态DNS Rule时，该指定appName和appInstanceId下所有动态DNS Rule的状态将置为ACTIVE。
   - MPF基于appName和DNS Rule ID粒度激活动态DNS Rule时，该指定appName下所有指定DNS Rule ID的动态DNS Rule的状态将置为ACTIVE。
   - MPF基于appName、appInstanceId和DNS Rule ID粒度激活动态DNS Rule，该指定appName、appInstanceId下指定DNS Rule ID的动态DNS Rule的状态将置为ACTIVE，该场景仅激活一条DNS Rule。

   MPF支持在MPF上的**SET DNSLITEPARA**命令的“DNSRULESTATSW”参数配置为“ENABLE”时，激活静态DNS Rule状态。

   - MPF基于appName粒度激活静态DNS Rule时，该指定appName下所有静态DNS Rule的状态将置为ACTIVE。
   - MPF基于appName和DNS Rule ID粒度激活静态DNS Rule时，该指定appName下指定静态DNS Rule的状态将置为ACTIVE。
2. **可选：**去激活DNS Rule。

   **DEA DNSRULE**
3. **可选：**激活动态Traffic Rule。

   **ACT TRAFFICRULE**

   **说明** 

   - MPF基于appName粒度激活动态Traffic Rule时，该指定appName下所有动态Traffic Rule的状态将置为ACTIVE。
   - MPF基于appName和appInstanceId粒度激活动态Traffic Rule时，该指定appName和appInstanceId下所有动态Traffic Rule的状态将置为ACTIVE。
   - MPF基于appName和Traffic Rule ID粒度激活动态Traffic Rule时，该指定appName下所有指定Traffic Rule ID的动态Traffic Rule的状态将置为ACTIVE。
   - MPF基于appName、appInstanceId和Traffic Rule ID粒度激活动态Traffic Rule，该指定appName、appInstanceId下指定Traffic Rule ID的动态Traffic Rule的状态将置为ACTIVE，该场景仅激活一条Traffic Rule。
4. **可选：**去激活动态Traffic Rule。

   **DEA TRAFFICRULE**
5. **可选：**用于特殊场景主动推送激活态的分流规则。

   **ACT RULESYN**

## 任务示例

任务描述

任务一：激活指定APP名称，APP实例和DNS Rule ID的动态DNS Rule。

任务二：去激活指定APP名称，APP实例和DNS Rule ID的动态DNS Rule。

任务三：激活指定APP名称，APP实例和Traffic Rule ID的动态Traffic Rule。

任务四：去激活指定APP名称，APP实例和Traffic Rule ID的动态Traffic Rule。

脚本

//任务一：激活指定APP名称，APP实例和DNS Rule ID的动态DNS Rule。

```
ACT DNSRULE: RULETYPE=DYNAMIC, APPNAME="app1", APPINSTANCEID="appInstanceId1", DNSRULEID="rule1";
```

//任务二：去激活指定APP名称，APP实例和DNS Rule ID的动态DNS Rule。

```
DEA DNSRULE: RULETYPE=DYNAMIC, APPNAME="app1", APPINSTANCEID="appInstanceId1", DNSRULEID="rule1";
```

//任务三：激活指定APP名称，APP实例和Traffic Rule ID的动态Traffic Rule。

```
ACT TRAFFICRULE: APPNAME="appName_1", APPINSTANCEID="appInstanceId_1", TRAFFICRULEID="trafficRuleId_0";
```

//任务四：去激活指定APP名称，APP实例和Traffic Rule ID的动态Traffic Rule。

```
DEA TRAFFICRULE: APPNAME="appName_1", APPINSTANCEID="appInstanceId_1", TRAFFICRULEID="trafficRuleId_0";
```
