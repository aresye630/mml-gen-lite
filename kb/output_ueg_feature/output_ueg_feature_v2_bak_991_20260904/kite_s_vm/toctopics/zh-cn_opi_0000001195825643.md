# 激活支持能力开放框架

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当UEG通过API GW对消费者开放网络能力，消费者通过调用API接口访问UEG内部服务时，需要配置本页面相关功能。

**说明** 

适用于PGW-U、UPF。

## 必备事项

前提条件

- 请仔细阅读GWFD-023502 支持能力开放框架（适用于PGW-U/UPF）。
- 风筝S：完成配置Mp2接口数据。
- 已完成加载License。

数据

| 类别            | 参数名称                 | 取值样例   | 获取方法   | 说明                      |
|:--------------|:---------------------|:-------|:-------|:------------------------|
| SET RATELIMIT | 流控类型（RATELIMIT_TYPE） | GLOBAL | 本端规划   | 配置全局API GW访问次数控制。       |
| SET RATELIMIT | 每秒请求限制（SECOND）       | 5000   | 本端规划   | 控制消费者单位时间内对API GW的访问频率。 |

## 操作步骤

1. **可选：**配置限流策略，控制消费者单位时间内对API GW的访问频率。

   **SET RATELIMIT**

## 任务示例

任务描述

配置限流策略。

脚本

//配置全局API限流策略，控制消费者单位时间内对API GW的访问频率。

```
SET RATELIMIT: RATELIMIT_TYPE=GLOBAL, SECOND=5000;
```
