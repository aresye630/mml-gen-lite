## 操作场景

当运营商需要对封装在用户数据部分的IP地址和端口号进行NAT转换时，需要激活NAT-ALG特性。

## 必备事项

前提条件

- 已登录OM Portal。
- 已完成配置NAT基本功能License开关。

数据

| 类别                  | 参数名称                                                       | 取值样例                                | 获取方法   | 说明                                                                         |
|:--------------------|:-----------------------------------------------------------|:------------------------------------|:-------|:---------------------------------------------------------------------------|
| nap-well-known-port | port-name                                                  | testknownport-ftptestknownport-http | 本端规划   | 设置知名端口名称。                                                                  |
| nap-well-known-port | protocol-name                                              | ftphttp                             | 本端规划   | 设置testknownport-ftp端口对应的子协议类型为ftp。设置testknownport-http端口对应的子协议类型为http。     |
| nap-well-known-port | trans–proto                                                | tcp                                 | 本端规划   | 指定传输层协议为TCP。                                                               |
| nap-well-known-port | operatorport                                               | eq 21eq 80                          | 本端规划   | 设置testknownport-ftp端口的值等于21。设置testknownport-http端口的值等于80。                  |
| nap-well-known-port | priority-value                                             | 2021                                | 本端规划   | 设置testknownport-ftp端口的协议识别匹配时优先级为20。 设置testknownport-http端口的协议识别匹配时优先级为21。 |
| detect-protocol     | ftp | h323 | mmsp | pptp | rsh | rtsp | sip | sqlnet | dns | ftp h323 pptp                       | 本端规划   | 表示NAT ALG/七层ASPF功能支持的协议类型。                                                 |

## 操作步骤

1. 选择“应用管理 > NAT”，进入NAT的CLI执行界面。
2. 配置NAT-ALG应用层协议识别。

   **说明** 

   为了确保NAT-ALG功能正常运行，需要配置七层协议识别。NAT支持基于知名端口方式识别用户报文七层协议。如果七层协议具有知名端口特征(如FTP协议对应的知名端口为21和20)，建议配置知名端口可最大限度的保证NAT处理正确，用户业务正常。

   1. 进入系统视图。

      **sy****stem-view**
   2. 进入nap-view视图。

      **nap-view**
   3. 采用知名端口识别协议，配置知名端口识别。

      **nap-well-known-port**
   4. 配置NAT-ALG支持的应用层协议类型。

      **detect-protocol**

## 任务示例

任务描述

激活NAT-ALG特性。

脚本

```
<NAT>system-view
[NAT]nap-view
[NAT-nap]nap-well-known-port testknownport-ftp protocol ftp trans-proto tcp port eq 21 priority 20
[NAT-nap]nap-well-known-port testknownport-http protocol http trans-proto tcp port eq 80 priority 21
[NAT-nap]detect-protocol ftp h323 pptp
```
