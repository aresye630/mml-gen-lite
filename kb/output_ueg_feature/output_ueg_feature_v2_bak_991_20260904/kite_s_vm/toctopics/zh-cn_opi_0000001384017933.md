# BGP over静态路由+BFD (IPv4)

- 操作场景
- 必备事项

- 验证方法

## 操作场景

SDN场景，VNF和DC-GW间通过Loopback IP建立eBGP邻居，用于业务路由的学习和发布。Loopback IP之间通过静态路由互通。

如图1所示为VNF与周边网元的静态路由互通组网示意图。VNF与网关运行BGP over静态路由协议而接入运营商网络/企业网络，DC-GW作网关。VNF和DC-GW之间采用单臂BFD探测。DC-GW的配置请参考对应型号设备的产品文档。

**图1** 静态路由+BFD组网

## 必备事项

前提条件

- 请阅读并熟悉特性IPFD-014003 静态路由、IPFD-014002 支持BGP特性概述和IPFD-104403 BFD特性概述。
- 具备管理员权限的操作人员已经登录华为操作维护系统。
- VNF与网络实体之间的网络环境已经构建完成。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST: VRFNAME="VRF_Mp1";
   ADD VPNINSTAF: VRFNAME="VRF_Mp1", AFTYPE=ipv4uni;
   MOD VPNINSTAF: VRFNAME="VRF_Mp1", AFTYPE=ipv4uni, VRFRD="10.10.10.78:100";
   ```

   **说明** 

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、BGP相关的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      - 如果“自动配置开关”值为“TRUE”，需要执行3.b和3.c关闭自动配置开关。
      - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到4。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
4. 配置外联口自动化配置模板。

   ```
   ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Mp1_100_v4",VPNNAME="VRF_Mp1",AFTYPE=IPv4,IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=VNIC,VNICID=4,VLANID=100;  
   ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Mp1_200_v4",VPNNAME="VRF_Mp1",AFTYPE=IPv4,IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=VNIC,VNICID=5,VLANID=200;
   ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Mp1_300_v4",VPNNAME="VRF_Mp1",AFTYPE=IPv4,IPALLOCTYPE4=DHCP, AUTOCFGIFTYPE=VNIC,VNICID=6,VLANID=300;
   ```
5. 增加BFD会话自动部署模板。

   “DESTADDR4”配置的是Leaf节点的IP地址，采用的是单臂BFD。

   ```
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_Mp1_1_v4", BFDTYPE=Static, SERVICENAME="ServName_Mp1_100_v4", IPVERSION=IPv4, DESTADDR4="192.168.89.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_Mp1_2_v4", BFDTYPE=Static, SERVICENAME="ServName_Mp1_200_v4", IPVERSION=IPv4, DESTADDR4="192.168.89.33", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_Mp1_3_v4", BFDTYPE=Static, SERVICENAME="ServName_Mp1_300_v4", IPVERSION=IPv4, DESTADDR4="192.168.89.65", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
   ```
6. 增加静态路由自动部署模板。

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_100_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_1_v4"; 
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_200_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BBFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_2_v4"; 
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_300_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.78", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BBFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_3_v4";
   ```

   ```
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_100_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.79", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BBFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_1_v4"; 
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_200_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.79", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BBFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_2_v4"; 
   ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Mp1_300_v4", VRFNAME="VRF_Mp1", IPVERSION=IPv4, PREFIX4="10.10.20.79", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=60, BBFDENABLE=TRUE, BFDTEMPLATENAME="BFD_Mp1_3_v4";
   ```
7. 打开自动配置开关。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```

   **说明** 

   - 从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行**DSP OPSASSISTSTATE**命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。
   - 在网关侧上配置到VNF的回程路由，目的地址为VNF上各逻辑接口的IP地址，下一跳为VNF上配置的各逻辑接口对应的外联口的IP地址。

     需要说明的是，配置VNF与DN/PDN通信的回程路由时，目的地址为UE的网段地址。下一跳为VNF上外联口的IP地址，由于自动部署时外联口的IP地址是系统自动分配的，因此建议首先通过命令**LST IFIPV4ADDRESS**查看外联口的IP地址。
8. 全局激活BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```

   **说明** 

   “ASNUM”参数若需要变更，则需先去使能BGP功能。去使能BGP时，BGP VPN实例等配置会被同步删除。必须按照LLD规划的“ASNUM”值进行配置。
9. 配置Loopback接口地址（BGP本端IP）。
   1. 配置Loopback接口。

      ```
      ADD INTERFACE: IFNAME="Loopback1";
      ```
   2. 配置接口绑定VPN。

      ```
      ADD IPBINDVPN: IFNAME="Loopback1", VRFNAME="VRF_Mp1";
      ```
   3. 配置接口IP地址。

      ```
      ADD IFIPV4ADDRESS: IFNAME="Loopback1", IFIPADDR="10.10.10.78", SUBNETMASK="255.255.255.255";
      ```
10. 配置BGP。
    1. 增加BGP VPN实例。

       ```
       ADD BGPVRF: VRFNAME="VRF_Mp1", DEFAULTAFTYPE=noaf, ROUTERID="10.10.10.78";
       ```

       **说明** 

       - 此处配置的“ROUTERID”是BGP VPN实例级别的ROUTERID。

         IPv4v6双栈时，IPv4 BGP VPN实例地址族和IPv6 BGP VPN实例地址族共用此处配置的“ROUTERID”值。
       - 已配置IPv4v6双栈的BGP VPN实例地址族，若需删除IPv4的BGP VPN实例地址族配置，则：

         1、删除IPv4的配置前需查询并记录“ROUTERID”值。

         2、删除IPv4的配置后需查询“ROUTERID”值是否存在，若不存在则需通过**MOD BGPVRF**命令将“ROUTERID”参数设置为删除IPv4的配置前记录的“ROUTERID”值。否则IPv6 BGP重新协商时会因无“ROUTERID”值可用而导致协商失败。
    2. 增加BGP VPN地址族。VNF对接2个负荷分担的BGP邻居时，“MAXIMUMLOADBALANCE”设置为“2”。

       ```
       ADD BGPVRFAF: VRFNAME="VRF_Mp1", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
       ```
    3. 增加BGP对等体。

       ```
       ADD BGPPEER: VRFNAME="VRF_Mp1", ADDRESSTYPE=ipv4, PEERADDR="10.10.20.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ADD BGPPEER: VRFNAME="VRF_Mp1", ADDRESSTYPE=ipv4, PEERADDR="10.10.30.78", REMOTEAS="60002", LOCALIFADDR="10.10.10.78", LOCALIFNAME="Loopback1", EBGPMAXHOP=10;
       ```
    4. 增加BGP引入路由。

       ```
       ADD IMPORTROUTE: VRFNAME="VRF_Mp1", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
       ```

       **说明** 

       由于BGP协议自身不能发现路由，所以需要引入其他协议的路由（如OSPF、静态路由或WLR等）注入到BGP路由表中，从而将这些路由在AS之内和AS之间传播。

## 验证方法

**说明** 

IPv4单栈组网，不需要执行IPv6独有的检查。

IPv6单栈组网，不需要执行IPv4独有的检查。

IPv4v6双栈组网，如下检查均需要执行。

1. 执行命令**LST INTERFACE**命令，检查子接口是否生成。

   子接口的接口名格式为EthernetX/0/Y.Z，其中：Z取值是**ADD AUTOSCALINGSERVICE**配置中的“VLANID”值。

   子接口必须是某个存在的接口的子接口，EthernetX/0/Y接口在软件安装完成后已存在。

   - 子接口生成正常，请执行2。
   - 子接口生成异常，请联系华为技术支持工程师处理（例如检查软件安装是否正常等）。
2. 执行命令**LST IFIPV4ADDRESS**/**LST IFIPV6ADDRESS**/**LST IPBINDVPN**，检查对应子接口上是否获取到IP地址及绑定的VPN是否与规划一致。

   本步骤的显示结果中的子接口与1中生成的子接口是否完全一致，且子接口均已存在IP地址。

   - 是，请执行4。
   - 否，请执行3。
3. 修改外联口自动部署模板。
   1. 关闭自动化配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=FALSE;
      ```
   2. 查询需要修改的外联口自动部署模板并记录服务名称、起始地址和结束地址等参数。

      ```
      LST AUTOSCALINGSERVICE:;
      ```
   3. 查询需要修改的子接口并记录查询结果。记录哪些接口的IP地址在3.b中记录的起始地址和结束地址范围内。

      ```
      LST IFIPV4ADDRESS:;
      ```

      ```
      LST IFIPV6ADDRESS:;
      ```
   4. 查询需要修改的静态路由自动部署模板并记录服务名称、VPN实例名称、路由前缀、路由掩码长度和路由下一跳等参数。

      ```
      LST AUTOSCALINGSRROUTE:;
      ```
   5. 查询需要修改的静态路由并记录查询结果。通过和3.d中的记录结果对比，记录待删除的静态路由。

      ```
      LST SRROUTE:;
      ```

      ```
      LST SRROUTE6:;
      ```
   6. 删除3.c中记录的所有子接口。

      **RMV INTERFACE**

      IPv4v6双栈场景，删除子接口时，会同时删除IPv4和IPv6地址。
   7. 删除配置错误的静态路由。

      **RMV SRROUTE**/**RMV SRROUTE6**
   8. 删除配置错误的静态路由自动化配置模板。

      **RMV AUTOSCALINGSRROUTE**
   9. 删除配置错误的BFD自动化配置模板。

      **RMV AUTOSCALINGBFD**（BFD echo）
   10. 删除配置错误的外联口自动化配置模板。

       **RMV AUTOSCALINGSERVICE**
   11. 重新配置外联口自动化配置模板。

       **ADD AUTOSCALINGSERVICE**
   12. 重新配置BFD自动化配置模板。

       **ADD AUTOSCALINGBFD**（BFD echo）
   13. 配置静态路由自动化配置模板。

       **ADD AUTOSCALINGSRROUTE**
   14. 打开自动化配置开关。

       ```
       SET AUTOCONFIG: SWITCHFLAG=TRUE;
       ```

       修改配置后，请重新执行1。
4. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   - 如果状态为up，请执行6。
   - 如果为其他状态，请执行5。
5. 执行**PING**命令，在VNF上检查VNF外联口IP与DC-GW接口IP之间是否路由可达。
   - 是，请执行9。
   - 否，请联系华为技术支持工程师处理（例如检查Leaf节点IP与VNF外联口IP是否路由可达，Leaf节点与DC-GW接口IP之间是否路由可达）。
6. 执行**PING**命令，在DC-GW上检查DC-GW与VNF Loopback接口IP之间是否路由可达。
   - 是，请执行7。
   - 否，请联系华为技术支持工程师处理（例如检查是否存在到VNF BGP IP的路由，下一跳分别是VNF的负荷分担关系的每个外联口的IP）。
7. 执行**PING**命令，在VNF上检查VNF BGP本端IP与BGPPEER IP之间是否路由可达。

   需要在VNF上分别PING BGP PEER IP，出接口是VNF上负荷分担关系的每个子接口，且能PING通。

   - 是，请执行8。
   - 否，请联系华为技术支持工程师处理。
8. 执行**DSP BGPPEERINFO**命令，检查BGP对等体条数是否正确及BGP对等体状态是否为Established。

   本步骤的显示结果中的BGP对等体的条数与LST BGPPEER中查询的对等体的条数相等，且“对等体状态”为“Established”。

   - 是，调测结束。
   - 否，请执行9。
9. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
