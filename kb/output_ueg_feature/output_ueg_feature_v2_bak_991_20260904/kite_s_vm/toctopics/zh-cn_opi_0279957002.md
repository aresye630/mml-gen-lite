# 修改GaussDB数据库用户密码

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

**注意** 

- 修改GaussDB数据库用户密码属于敏感操作，请联系华为技术人员确认后再执行。
- 升级到当前版本，在未结束升级观察期时，请勿执行该操作。

- 在开局结束后，系统管理员必须及时修改GaussDB数据库用户的密码，为确保GaussDB数据库安全。
- 在日常维护中，系统管理员需要定期修改GaussDB数据库用户的密码，为确保GaussDB数据库安全。

## 对系统的影响

修改GaussDB数据库用户的密码后，会导致业务中断，中断时长取决于使用GaussDB数据库的业务服务。

## 必备事项

前提条件

已登录OM Portal。

数据

- 已获取待修改的GaussDB数据库用户的旧密码。

  **说明** 

  待修改用户的初始密码请参见《CSP数据库用户默认帐号》，如果初始密码已经修改，待修改用户的旧密码请联系系统管理员获取。
- 已准备待修改的GaussDB数据库用户的新密码。

  **说明** 

  新密码符合如下复杂程度要求：
  - 密码不能少于8个字符且不超过30个字符。
  - 在密码重用保护期内不能与旧密码相同（默认60天）。
  - 密码不能和用户名相同。
  - 密码必须由如下组合而成：
    - 至少包括一个大写字母（A~Z）；
    - 至少包括一个小写字母（a~z）；
    - 至少包括一个数字字符（0—9）；
    - 至少包括1个特殊字符，如：“~、@、^、\*、-、\_、=、:、.、/、？”;

## 操作步骤

1. 登录OM Portal，选择“应用配置>服务治理”，展开GaussDB服务列表，光标移动至“属性”列。“status”为“M”的服务为**主GaussDB服务**，“status”为“S”的服务为**备GaussDB服务**，记录该服务实例中的“nodeID”，如图1。

   **图1** 主GaussDB服务实例“属性”信息

   **说明** 

   IPv4场景下，“nodeID”的值即为**GaussDB服务所在的主用节点IP**。

   IPv6场景下，将“nodeID”的值中“-”替换为“:”后为**GaussDB服务所在的主用节点IP**。

   podName：**GaussDB服务实例名称**。
2. Windows操作系统使用mtuser用户通过Putty工具登录GaussDB服务所在的主用节点IP，Linux操作系统通过终端模拟器GaussDB服务所在的主用节点IP，执行**su root**切换至root用户。
3. 通过**which docker**检查容器引擎类型，并进入GaussDB容器。

   - 如果存在docker可执行文件，如下命令所示。

     ```
     dfp07-csp-a-0:/home/mtuser # which docker
     /usr/bin/docker
     ```

     执行**docker ps|grep cspgaussdb**获取GaussDB dockerId。

     执行**docker exec -it -u paas *dockerId* bash**进入GaussDB容器。
   - 如果没有找到docker可执行文件，如下命令所示。

     ```
     inipv6-csp-a-0:/home/mtuser # which docker
     which: no docker in (/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin)
     ```

     执行**crictl ps |grep cspgaussdb**获取GaussDB containerdID。

     ```
     inipv6-csp-a-0:/home/mtuser # crictl ps |grep cspgaussdb
     d7706d396a48a       registry.fusionstage.local:20202/csp/cspgaussdb_docker:23.0.0.B159                About an hour ago    Running             gauss-softwarecomp              0                   6c60ce978ec69
     ```

     执行**crictl exec -it *containerdID* bash**进入GaussDB容器。
4. 执行**bash /opt/host/gaussdb/bin/gaussServer/install/MODGaussDBPWD.sh** ，根据系统提示信息，修改数据库用户的密码。

   ```
   [paas@gaussdb-969ea192-0 /]$ bash /opt/host/gaussdb/bin/gaussServer/install/MODGaussDBPWD.sh //执行修改密码的脚本
   *********************************************************************
   *************************** WARNING *********************************
   *********************************************************************
   * This shell script is used to modify the password of GaussDB user. *
   * You need enter 4 parameters.                                      *
   * If you want to quit, please press "Ctrl + c".                     *
   *********************************************************************
   1. The first parameter is GaussDB user name.
   Note that "dbuser" is the admin of GaussDB.
   Please input the GaussDB user name ended with Enter:
   dbuser                                                                      //根据提示信息输入数据库用户名
   The GaussDB user name input end.

   2. The second parameter is old password.
   Please input the old password ended with Enter:                             //输入旧密码
   The old password input end.

   3. The third parameter is new password.
   Note that the new password must contain numbers, lowercase letters, uppercase letters and special characters.
   Note that the collection of special characters is "~@^*-_=:./?".
   Note that the new password must contain 8 to 30 characters.
   Please input the new password ended with Enter:                            //输入新密码
   The new password input end.

   4. The fourth parameter is confirmation of new password.
   Please re-enter new password ended with Enter:                             //再次输入新密码
   Re-enter new password input end.

   Send request message to adapter.
   true
   Congratulations, modify password success!                                 //修改密码成功
   *********************************************************************
   ```

   - 若屏幕出现“Congratulations, modify password success!”表明数据库用户的密码修改成功。
   - 若屏幕出现“Note, modify password failed! Please check the input parameters.”表明数据库用户的密码修改失败，需要重新执行该脚本并保证输入参数的正确性。
