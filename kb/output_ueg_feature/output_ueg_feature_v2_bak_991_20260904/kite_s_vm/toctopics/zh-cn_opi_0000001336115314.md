# 共享式+主锚点UPF配置实例(含和MPF对接) (SDN)

- 操作场景

- 操作步骤

## 操作场景

UEG部署在地市中心，作为地市共享主锚点UPF。企业园区终端签约专有DNN（APN）。

- 对于app流量过HUAWEI MPF的第三方APP，UPF到MPF采用VXLAN隧道，然后由MPF与第三方APP互通；或UPF到企业园区采用VPN专线，流量不过MPF。
- 对于园区服务器（app流量不过HUAWEI MPF），UPF到企业园区采用VPN专线。

UEG使用标卡与DCGW连接。DCGW之间使用E-Trunk+EVPN或M-LAG组网，UEG使用Eth-trunk接口，一个Eth-trunk接口的成员端口，连接到同一台DCGW上。

UEG通过BGP over静态路由+BFD单臂echo与对端网元（gNodeB/SMF/企业服务器/MPF）实现网络互通。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
- VNF与网络实体之间的网络环境已经构建完成。

## 操作步骤

1. 配置基础数据。

   配置基础数据包括：修改网元浮动IP、修改公共参数等。详细配置与组网无关，具体请参见《参考：详细配置指导 > 配置基础数据》章节。
2. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```
4. DHCP分配IPv6地址时 （如：SDN场景），必须设置“DUID生成方式（DUIDTYPE）”为“MAC\_PLUS\_VLAN”。

   ```
   SET DHCP6CLIENTDUID: DUIDTYPE=MAC_PLUS_VLAN;
   ```
5. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      - 如果“自动配置开关”值为“TRUE”，需要执行5.b和5.c关闭自动配置开关。
      - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到6。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
6. 配置UPF（UEG）到无线侧(R)AN（gNodeB）的IP路由数据。
   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Access";
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv4uni, VRFRD="192.168.225.135:100";
      ```

      ```
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv6uni, VRFRD="192.168.225.135:100";
      ```
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack5";
      ADD IPBINDVPN:IFNAME="LoopBack5",VRFNAME="VRF_Access";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack5",IFIPADDR="192.168.225.135",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```

      ```
      SET IFIPV6ENABLE: IFNAME="Loopback5", ENABLEFLAG=TRUE;
      ADD IFIPV6ADDRESS:IFNAME="Loopback5",IPV6ADDRESS="FC00::225:135",PREFIXLEN=128;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Access", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.135";
      ```
   4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```
   6. 配置BGP引入wlr路由。

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```
   7. 添加以太网隧道多虚拟网卡自动化配置模板。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
      ```
   8. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_2005_v4",VPNNAME="VRF_Access",AFTYPE=IPv4,IPALLOCTYPE4=DHCP,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2005;
      ```

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_2005_v6",VPNNAME="VRF_Access",AFTYPE=IPv6,IPALLOCTYPE6=DHCP,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=4,VLANID=2005, ADDRMODE=NETWOKSEGMENT_MODE;
      ```

      **说明** 

      - 如果规划外联口使用IPv4v6双栈地址，则分别执行该命令对同一vNIC配置IPv4和IPv6地址。
      - 外联口配置IPv6地址时，“ADDRMODE”必须设置为“NETWOKSEGMENT\_MODE”。
   9. 增加BFD会话自动部署模板。

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2005_v4", BFDTYPE=Static, SERVICENAME="ServName_Access_2005_v4", IPVERSION=IPv4, DESTADDR4="192.168.85.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2005_v6", BFDTYPE=Static, SERVICENAME="ServName_Access_2005_v6", IPVERSION=IPv6, DESTADDR6="FC00::85:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```
   10. 增加静态路由自动部署模板。

       //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="192.168.79.5", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4"; 
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="192.168.78.5", MASKLENGTH=32, NEXTHOPALLOCTYPE4=DHCP, BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4";
       ```

       //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

       ```
       ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Access_2005_v4", VRFNAME="VRF_Access", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=DHCP, PREFERENCE=255, BFDENABLE=TRUE, DESCRIPTION="VRF_Access", BFDTEMPLATENAME="BFD_2005_v4";
       ```


       静态签约场景，配置IP地址分配用于对外发布wlr\_ud路由，避免静态用户激活后生成大量主机路由。地址段从UDM签约数据获取。

       //配置全局地址分配规则。

       ```
       SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-1&LOCATION-0&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE, IPV6FIRSTRULESW=ENABLE, IPV6FIRSTRULE=APN-1&LOCATION-0&SMF-0, IPV6SECRULESW=DISABLE, IPV6THIRDRULESW=DISABLE;
       ```

       //配置APN“apn-op1”给UE分配的IP地址段。

       ```
       ADD POOL: POOLNAME="testpool5", POOLTYPE=EXTERNAL, IPVERSION=IPV4, CHECKIPVALID=ENABLE, HASVPN=ENABLE, VPNINSTANCE="VRF_LocalDN1", IMSSW=DISABLE, REDUNDFUNC=ENABLE;
       ADD POOL: POOLNAME="testpool6", POOLTYPE=EXTERNAL, IPVERSION=IPV6, CHECKIPVALID=DISABLE, HASVPN=ENABLE, VPNINSTANCE="VRF_LocalDN1", IMSSW=DISABLE, REDUNDFUNC=ENABLE;
       ADD SECTION:POOLNAME="testpool5",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.1",V4ENDIP="10.10.1.254";
       ADD SECTION:POOLNAME="testpool6",SECTIONNUM=2,IPVERSION=IPV6,V6PREFIXSTART="FC00:1::1:1",V6PREFIXEND="FC00:1::1:254",V6PREFIXLENGTH=64;
       ADD POOLGROUP: POOLGRPNAME="poolgroup3", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
       ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup3", POOLNAME="testpool5", PRIORITY=10;
       ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup3", POOLNAME="testpool6", PRIORITY=10;
       ADD POOLGRPMAP: MAPPINGNAME="mapping3", APN="apn-op1", POOLGROUPNAME="poolgroup3";
       ```

       //配置APN“apn-op2”给UE分配的IP地址段。

       ```
       ADD POOL: POOLNAME="testpool7", POOLTYPE=EXTERNAL, IPVERSION=IPV4, CHECKIPVALID=ENABLE, HASVPN=ENABLE, VPNINSTANCE="VRF_LocalDN2", IMSSW=DISABLE, REDUNDFUNC=ENABLE;
       ADD POOL: POOLNAME="testpool8", POOLTYPE=EXTERNAL, IPVERSION=IPV6, CHECKIPVALID=DISABLE, HASVPN=ENABLE, VPNINSTANCE="VRF_LocalDN2", IMSSW=DISABLE, REDUNDFUNC=ENABLE;
       ADD SECTION:POOLNAME="testpool7",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.2.1",V4ENDIP="10.10.2.254";
       ADD SECTION:POOLNAME="testpool8",SECTIONNUM=2,IPVERSION=IPV6,V6PREFIXSTART="FC00:1::2:1",V6PREFIXEND="FC00:1::2:254",V6PREFIXLENGTH=64;
       ADD POOLGROUP: POOLGRPNAME="poolgroup4", IPV4ALLOCPRIALG=ENABLE, IPV6ALLOCPRIALG=ENABLE;
       ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup4", POOLNAME="testpool7", PRIORITY=10;
       ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup4", POOLNAME="testpool8", PRIORITY=10;
       ADD POOLGRPMAP: MAPPINGNAME="mapping4", APN="apn-op2", POOLGROUPNAME="poolgroup4";
       ```
