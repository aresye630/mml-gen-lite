# 开启本地流量详单功能

- 操作场景
- 对系统的影响
- 必备事项

## 操作场景

风筝L部署本地流量详单功能，进行用户级流量统计。

## 对系统的影响

本特性对系统无影响。

## 必备事项

前提条件

请仔细阅读本地流量详单功能概述。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置EDR Client端的链路配置
   1. 配置UT-EDR业务本端SFTP Client端IP

      **ADD UCFIP**
   2. 配置UT-EDR业务对端SFTP Server端IP。

      **ADD UCFSVRIP**
3. SMF网元配置
   1. 使能流量统计

      **SET CHARGECTRL**
   2. 基于APN配置使能流量详单功能控制配置

      **SET APNCHARGECTRL**
   3. 配置URR

      **ADD CPURR**

      **ADD CPURRGROUP**
   4. 绑定URR和PCCPOLICYGroup

      **MOD CPPCCPOLICYGRP**
   5. 配置模板

      **ADD CCT**
   6. 绑定模板到指定APN下

      **SET APNCHARGECTRL**
   7. 使能流量统计

      **SET EDGETRAFFICSTAT**
   8. 使能注册流程网络侧主动获取设备标识。

      **MOD NGPEIPLCY**

      **MOD S1IMEICFG**
4. **UPF****网元部件配置**
   1. 配置URR

      **ADD URR**

      **ADD URRGROUP**

      **ADD PCCPOLICYGRP**
   2. 配置三四层信息

      **ADD FILTER**

      **ADD FLOWFILTER**
   3. 配置流量统计规则

      **ADD RULE**

      **SET REFRESHSRV**
   4. 配置规则绑定用户模板

      **ADD USERPROFILE**

      **ADD RULEBINDING**

## 任务示例

任务描述

- 启用户流量统计详单功能。流量详单功能详单是否执行匿名化通过MML配置控制，当开启流量详单功能功能且关闭匿名化开关时，则上报UT-EDR文件未做匿名化处理告警。
- 容灾场景下，主备UCF IP不能配置为相同。其他配置均无差异。

脚本

**配置****EDR Client****端的链路**

//配置UT-EDR业务本端SFTP Client端IP。主备UCF IP需规划成不同的IP。

```
ADD UCFIP:INDEX=1,PROTOCOLTYPE=SFTP,IPTYPE=IPv4,IPV4="172.16.10.1",PORTSTART=1025,PORTEND=1029,VPNNAME="VRF_N6_Local_2B",DESC="EDR";
```

//配置UT-EDR业务对端SFTP Server端IP。

```
ADD UCFSVRIP:PROTOCOLTYPE=SFTP,ACCESSNAME="EDRServer",UCFSVRNAME="EDRFTPClient",IPTYPE=IPv4,IPV4="172.16.8.48",SVRPORT=21,USER="ftptest",PWD="*****",AUTHMODE=NOAUTH,SVRPATH="/data/files/csv";
```

**配置SMF****网元**

//使能流量统计。

```
SET CHARGECTRL: HOMECONVERGED=ENABLE, VISITCONVERGED=ENABLE, ROAMCONVERGED=ENABLE;
```

//基于APN配置使能流量详单功能控制配置。

```
SET APNCHARGECTRL: APN=“apn-test”,CONVERGEDSW=ENABLE, RGAPPLIED=OFFLINERGONLY;
```

//配置URR。 注：因为基本接入功能的水平网设中会默认生成U面的URRID，此处需要和U面的URR是一样的。

```
ADD CPURR: URRNAME="offlineURR", URRID=1000, USAGERPTMODE=OFFLINE, OFFCOMPOUNDTYPE=ONLYRG, RG=1300, OFFMETERINGTYPE=VOLUME_TIME;
ADD CPURRGROUP:URRGROUPNAME="urrgroup1",UPURRNAME1="offlineURR",DOWNURRNAME1="offlineURR";
```

//将URR和PCCPOLICYGroup进行绑定。因为基本接入功能的水平网设会默认创建一个ppg\_global\_service，所以这个是修改。

```
MOD CPPCCPOLICYGRP:PCCPOLICYGRPNM="ppg_global_service",URRGROUPNAME="urrgroup1";
```

//配置模板，时间阈值为30min，流量阈值为200MByte。

```
ADD CCT: CCTMPLTNAME="cct_offline", PDUVOLUMELIMIT=200, PDUTIMELIMIT=30;
```

//将模板绑定到指定APN下。

```
SET APNCHARGECTRL: APN="apn-test", CCTEMPLATE="cct_offline";
```

//使能流量统计详单。开启匿名化可能导致第三方工具解析失败，所以默认设置为关闭。

```
SET EDGETRAFFICSTAT: SWITCH=ENABLE , ANONYMIZATION=DISABLE;
```

//（可选）使能注册流程网络侧主动获取设备标识， UT-EDR上报IMEI（International Mobile Equipment Identity）时需要配置。

```
MOD NGPEIPLCY: SUBRANGE=ALL_USER, GETPEIPLCY=GETIMEI;
MOD S1IMEICFG: SUBRANGE=ALL_USER, GETIMEIPLC=IMEI;
```

**配置UPF****网元**

//主备UPF都需要进行以下配置。主备UPF的配置内容相同。

//配置URR，URRID为1000，OFFMETERINGTYPE为VOLUME\_TIME。

```
ADD URR:URRNAME="offlineURR",URRID=1000,USAGERPTMODE=OFFLINE,OFFMETERINGTYPE=VOLUME_TIME;
ADD URRGROUP:URRGROUPNAME="urrgroup1",UPURRNAME1="offlineURR",DOWNURRNAME1="offlineURR";
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="cg-offline",URRGROUPNAME="urrgroup1";
```

//配置三四层信息。

```
ADD FILTER:FILTERNAME="filter_offline",L34PROTTYPE=STRING,L34PROTOCOL=TCP,SVRSTARTPORT=80,SVRENDPORT=80;
ADD FLOWFILTER:FLOWFILTERNAME="fg_offline";
ADD FLTBINDFLOWF:FLOWFILTERNAME="fg_offline",FILTERNAME="filter_offline";
```

//配置流量统计规则。

```
ADD RULE:RULENAME="Rule001",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER, FLOWFILTERNAME="fg_offline",POLICYNAME="cg-offline",PRIORITY=110;
SET REFRESHSRV:REFRESHTYPE=USERPROFILE;
```

//配置规则绑定用户模板。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="Rule001";
```
