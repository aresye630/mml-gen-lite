## 操作场景

开局时，配置UDM基础数据。

**说明** 

应急UDM从逻辑上划分为FE（Front End）和BE（Back End）两个业务网元：

- FE（Front End）网元也称为UDM网元，实现UDM功能实体的功能，包括协议处理、业务处理以及策略数据管理。
- BE（Back End）网元也称为USCDB网元（Unified Subscriber Center DataBase），实现UDR（Unified Data Repository）功能实体的功能，提供用户数据的增加、删除、更新和查询服务，为FE提供数据存储、数据管理、数据服务等功能支撑。

  应急UDM不支持开户，用户数据的增加、删除和更新是通过从中心UDM同步数据文件的方式实现的。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 设置Location信息。
   1. 检查Location标识是否与规划一致。

      **说明** 

      - 执行**LST LOCATION**命令，检查“LOCID”参数值是否与规划一致。
      - 主用局UDM/HSS、主用局USCDB、容灾局UDM/HSS、容灾局USCDB的Location标识各不相同。

      - 一致，请执行2.b。
      - 不一致，请联系华为技术支持工程师处理。

      ```
      %%LST LOCATION:;%% 
      RETCODE = 0  操作成功  
      操作结果如下 
      ------------ 
      Location标识  =  13     
          网元类型  =  HSS9860 
      (结果个数 = 1)  
      ---    END
      ```
   2. 设置DBS Location标识。

      ```
      SET DBSLOCATION: LOCID=13, CNFM=YES;
      ```
3. 设置本端服务ID。

   **说明** 

   参数“PODNAME”，通过以下操作获取：

   1. 在OM Portal界面选择“应用配置>服务治理”，在“应用名称”选项中选择对应FE网元的名称，搜索“UDRDbbroker”服务。
   2. 展开“UDRDbbroker”服务列表，选中“UDRDbbroker”服务实例对应的“属性”列会显示属性信息，属性信息中“podName”对应的值即为POD名称。

   //虚机容器：

   ```
   ADD DBSSERVICENO: SERVICENO=301, PODNAME="dbb-all-pod13-0";
   ADD DBSSERVICENO: SERVICENO=302, PODNAME="dbb-all-pod13-1";
   ```

   //裸机容器：

   ```
   ADD DBSSERVICENO: SERVICENO=301, PODNAME="dbb-all-pod13-0";
   ```
4. 增加业务IP地址，用于和BE进行通信。

   ```
   ADD DBSIPADDR: DBSIPINDEX=1, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.200.200.22", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.200.200.23", IPV4MASK2="255.255.255.255";
   ```
5. 增加VPN信息配置。

   ```
   ADD VPNINFO: VPNINFONAME="vpn13", VPNNAME="VRF_SBI", VPNID=1;
   ```
6. 增加HSF类型的IP地址。必须执行本步骤，否则**DSP ESN**无法获取到UEG的ESN。

   //DC1：

   ```
   ADD IPADDR: IPNAME="HSFIP1", GATEWAYTYPE=HSF, IPTYPE=IPV4, IPV4IP1="10.200.200.28", VPNNAME="VRF_SBI";
   ```

   //DC2：

   ```
   ADD IPADDR: IPNAME="HSFIP1", GATEWAYTYPE=HSF, IPTYPE=IPV4, IPV4IP1="10.201.200.28", VPNNAME="VRF_SBI;
   ```
7. 增加HTTP IP地址。

   ```
   ADD HTTPIP: IPNAME="HLB13", IPVER=IPV4, IPV4IP1="10.200.200.27", VPNINFONAME="vpn13";
   ```
8. 增加本端服务器配置。

   ```
   ADD HTTPLSERVER: LSERVERNANE="HLB", IPNAME="HLB13", PORT=8080, HTTPSFUNC=FALSE;
   ```
9. 查询HttpLink的取值。

   ```
   LST UDMSOFTPARA: TYPE=HttpConfig, ITEMN=HttpLink;
   ```

   查看HttpLink的取值为1还是0：

   - HttpLink取值为0=>结束。
   - HttpLink取值为1=>10。
10. 增加链路集参数配置。

    ```
    ADD HTTPLKSPARA: PARAID=1, LINKNUM=8, LNKMOD=POLLING;
    ```
11. 增加远端服务器配置。

    ```
    ADD HTTPRSRV: RSERVERNAME="abc", LNKTYPE=Dynamic, LIPNAME="HLB13", PARAID=1;
    ```
12. 修改虚机CPU的流控门限。默认“FCSTRG”值为“80”，“FCENDG”值为“70”，请根据局点规划值修改。

    ```
    MOD MSFLOWCTRL: FCTYPE=CPUFC, FCMSTYPE=HLB, FCITEM=NODECPU, FCSTRG=85, FCENDG=75; 
    MOD MSFLOWCTRL: FCTYPE=CPUFC, FCMSTYPE=UDM, FCITEM=NODECPU, FCSTRG=85, FCENDG=75; 
    MOD MSFLOWCTRL: FCTYPE=CPUFC, FCMSTYPE=AUSF, FCITEM=NODECPU, FCSTRG=85, FCENDG=75;
    ```

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**NGPING**命令，查看平面“VRF\_DATA”配置的业务IP是否与外联口IP互通。

   ```
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="ADD DBSIPADDR所定义的业务IP", DSTIPV4ADDR="ADD IFIPV4ADDRESS所定义的外联口IP";
   样例：
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.22", DSTIPV4ADDR="192.168.48.43";
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.23", DSTIPV4ADDR="192.168.48.43";
   ```

   - 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请联系华为技术支持。
