# 公共参数配置（应急AMF/SMF）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

本章节用于指导应急AMF和应急SMF的公共数据配置，包括运营商、切片、DNN等信息。园区应急AMF、应急SMF和中心侧网络的AMF、SMF公共参数保持一致。

以下配置数据以及步骤均以UEG-M双DC组网场景的配置规划为例进行介绍。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

- 已经获取网设LLD文档。

## 操作步骤

1. 配置运营商基础信息。

   **说明** 

   双DC组网场景下，对于DC1和DC2中的AMF和SMF步骤1中的a~e配置完全相同。

   1. 配置运营商信息。当前系统默认有一条“NOID”为0的记录，需使用MOD NGMNO命令增加运营商名称信息 。

      ```
      //DC1
      MOD NGMNO: NOID=0, FULLNAME="Operator A", SHORTNAME="OA";
      //DC2
      MOD NGMNO: NOID=0, FULLNAME="Operator A", SHORTNAME="OA";
      ```
   2. 配置运营商签约用户的Home PLMN信息。

      ```
      //DC1
      ADD NGHPLMN: NOID=0, MCC="123", MNC="03";
      //DC2
      ADD NGHPLMN: NOID=0, MCC="123", MNC="03";
      ```
   3. 配置运营商的Serving PLMN信息，该PLMN表示移动运营商网络中各设备使用的PLMN，AMF和无线对接时使用该PLMN。

      ```
      //DC1
      ADD NGSRVPLMN: PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      //DC2
      ADD NGSRVPLMN: PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      ```
   4. 配置各MCC值所对应的MNC长度。

      ```
      //DC1
      ADD CPMNCLEN:MCC="123",MNCLEN=2;
      //DC2
      ADD CPMNCLEN:MCC="123",MNCLEN=2;
      ```
   5. 配置运营商支持的网络切片。

      ```
      //DC1
      ADD PLMNNS: NSIDX=0, PLMNIDX=0, SST=1, SD="010101", STATE=ACTIVE;
      //DC2
      ADD PLMNNS: NSIDX=0, PLMNIDX=0, SST=1, SD="010101", STATE=ACTIVE;
      ```
   6. 配置AMF全局标识。

      ```
      //DC1
      ADD GUAMI: INDEX=0, PLMNIDX=0, AMFREGIONID="00", AMFSETID="001", AMFPOINTER="01";
      //DC2
      ADD GUAMI: INDEX=0, PLMNIDX=0, AMFREGIONID="00", AMFSETID="001", AMFPOINTER="02";
      ```
2. 配置AMF和SMF实例信息。

   1. 配置AMF和SMF实例的名称。

      ```
      //DC1
      ADD NFUUID: NFTYPE=NfAMF, NFINSTANCENAME="AMF_Instance_0";
      ADD NFUUID: NFTYPE=NfSMF, NFINSTANCENAME="SMF_Instance_0";
      //DC2
      ADD NFUUID: NFTYPE=NfAMF, NFINSTANCENAME="AMF_Instance_1";
      ADD NFUUID: NFTYPE=NfSMF, NFINSTANCENAME="SMF_Instance_1";
      ```
   2. 配置AMF和SMF实例的Profile信息。

      ```
      //DC1
      ADD CPNFPROFILE: NFINSTANCENAME="AMF_Instance_0", NFTYPE=NfAMF, NFSTATUS=Registered;
      ADD CPNFPROFILE: NFINSTANCENAME="SMF_Instance_0", NFTYPE=NfSMF, NFSTATUS=Registered;
      //DC2
      ADD CPNFPROFILE: NFINSTANCENAME="AMF_Instance_1", NFTYPE=NfAMF, NFSTATUS=Registered;
      ADD CPNFPROFILE: NFINSTANCENAME="SMF_Instance_1", NFTYPE=NfSMF, NFSTATUS=Registered;
      ```
   3. 配置AMF和SMF的域名等信息。

      ```
      //DC1
      ADD AMFINFO: AMFINSTANCENAME="AMF_Instance_0", AMFNAME="amf0.cluster1.net2.amf.5gc.mnc003.mcc123.3gppnetwork.org",CAPACITY=0;
      ADD SMFINFO: SMFINSTANCENAME="SMF_Instance_0", SMFNAME="SMF01";
      //DC2
      ADD AMFINFO: AMFINSTANCENAME="AMF_Instance_1", AMFNAME="amf1.cluster1.net2.amf.5gc.mnc003.mcc123.3gppnetwork.org",CAPACITY=0;
      ADD SMFINFO: SMFINSTANCENAME="SMF_Instance_1", SMFNAME="SMF02";
      ```
   4. 配置AMF和SMF提供的服务实例及其版本信息。
      1. 配置AMF和SMF提供的服务实例信息。

         ```
         //DC1
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NamfComm; 
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NamfEvts; 
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_2", SERVICENAME=NamfMt;
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_3", SERVICENAME=NamfLoc;
         ADD CPNFSERVICE: NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_4", SERVICENAME=NsmfPduSes;
         ADD CPNFSERVICE: NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_5", SERVICENAME=NsmfEventExp;
         //DC2
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_1", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NamfComm; 
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_1", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NamfEvts; 
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_1", SRVINSTANCEID="Service_Instance_2", SERVICENAME=NamfMt;
         ADD CPNFSERVICE: NFINSTANCENAME="AMF_Instance_1", SRVINSTANCEID="Service_Instance_3", SERVICENAME=NamfLoc;
         ADD CPNFSERVICE: NFINSTANCENAME="SMF_Instance_1", SRVINSTANCEID="Service_Instance_4", SERVICENAME=NsmfPduSes;
         ADD CPNFSERVICE: NFINSTANCENAME="SMF_Instance_1", SRVINSTANCEID="Service_Instance_5", SERVICENAME=NsmfEventExp;
         ```
      2. 配置服务实例的版本信息。

         ```
         //DC1
         ADD NFSERVICEVER: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_0", APIFULLVERSION="1.R15.0.0";
         ADD NFSERVICEVER: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_1", APIFULLVERSION="1.R15.0.0";
         ADD NFSERVICEVER: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_2", APIFULLVERSION="1.R15.0.0";
         ADD NFSERVICEVER: NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_3", APIFULLVERSION="1.R15.0.0";
         ```
