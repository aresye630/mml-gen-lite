# 配置容灾模式（负荷分担）

- 操作场景
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

为避免单点故障，园区需部署两套UEG实现容灾。

两套UEG采用负荷分担容灾时，需要参考本页面进行配置。

**注意** 

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 检查是否存在冗余的主备容灾模式的配置。
   1. 执行**LST DRDCI**命令，查询是否存在DCI通道信息。
   2. 执行**LST DRGROUPINFO**命令，查询是否存在容灾组信息。
   - 存在冗余的主备容灾模式的配置，请执行3。
   - 不存在冗余的主备容灾模式的配置，请执行4。
3. 删除主备容灾模式配置。
   1. 执行**RMV DRDCI**命令，删除DCI通道信息。
   2. 执行**RMV DRGROUPINFO**命令，删除容灾组信息。
4. 使能负荷分担容灾功能。

   ```
   SET DRCOUPLINGRESET: COUPLINGRESET=YES;
   ```
5. 设置监控的关键部件信息。

   **注意** 

   - 此处以UEG监控MME、AMF、HSS、UDM、SMF、GWC、UPF、UDR，未监控PCF/PCRF为例。实际请以网设规划为准。
   - 开启容灾功能的UEG出现设备异常，需要通过重新实例化操作进行恢复的场景：若MML文件中**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值存在“YES”，则在导入MML文件进行配置恢复前，需要先修改MML文件，将**SET DRKEYNF**命令的HSS、UDM、PCRF、PCF、UDR参数值“YES”修改为“NO”；待HSS、UDM、PCRF、PCF、UDR服务的配置恢复完成后，再按照修改前的**SET DRKEYNF**配置重新开启对这些服务的监控。

   ```
   SET DRKEYNF: MME=YES, AMF=YES, HSS=YES, UDM=YES, SMF=YES, GWC=YES, PCF=NO, PCRF=NO, UPF=YES, UDR=YES;
   ```

## 验证方法

1. 执行对应的LST命令，检查配置是否与规划一致。
   - 检查是否使能负荷分担容灾功能。

     执行**LST DRCOUPLINGRESET**命令进行检查，如配置错误，则重新执行4进行设置。
   - 检查监控的关键部件设置是否正确。

     执行**LST DRKEYNF**命令进行检查，如配置错误，则重新执行5进行设置。
