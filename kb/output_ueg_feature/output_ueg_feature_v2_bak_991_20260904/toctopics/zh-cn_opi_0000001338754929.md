# 配置PCF/PCRF

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

园区UEG提供语音等业务时，UEG上需要配置PCF/PCRF实体功能。以保证用户能够正常开展业务。

## 必备事项

前提条件

- 已完成软件安装。
- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

## 操作步骤

- 登录“UEG MML命令”界面。

  **说明** 

  外联口IP和路由数据，均在“UEG MML命令”界面执行。

- 直连DCGW组网时，配置外联口IP和路由数据。（USCDB与另一UEG内的USCDB互通）

  **说明** 

  园区部署两套UEG进行容灾时需要配置。

  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_DATA";
     ADD VPNINSTAF:VRFNAME="VRF_DATA",AFTYPE=ipv4uni, VRFRD="192.168.225.215:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_DATA",AFTYPE=ipv6uni, VRFRD="192.168.225.215:100";
     ```
  2. 配置外联口IP地址。

     1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

        ```
        LST INTERFACE:;
        ```
     2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

        ```
        MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up;
        MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
        ```

        ```
        MOD INTERFACE:IFNAME="Ethernet64/0/12",IFADMINSTATUS=up;
        MOD INTERFACE:IFNAME="Ethernet64/0/13",IFADMINSTATUS=up;
        ```
     3. 添加Eth-trunk接口及Eth-trunk子接口。成员端口数量以网设规划的为准。

        ```
        ADD INTERFACE:IFNAME="Eth-trunk1";
        MOD TRUNKIF:IFNAME="Eth-Trunk1",WORKMODE=Manual;
        ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/4";
        ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/5";
        ADD INTERFACE:IFNAME="Eth-trunk1.4";
        ```

        ```
        ADD INTERFACE:IFNAME="Eth-trunk2";
        MOD TRUNKIF:IFNAME="Eth-Trunk2",WORKMODE=Manual;
        ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/12";
        ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/13";
        ADD INTERFACE:IFNAME="Eth-trunk2.4";
        ```
     4. 增加接口绑定VPN。

        ```
        ADD IPBINDVPN:IFNAME="Eth-trunk1.4",VRFNAME="VRF_DATA";
        ```

        ```
        ADD IPBINDVPN:IFNAME="Eth-trunk2.4",VRFNAME="VRF_DATA";
        ```
     5. 在以太网子接口上关联VLAN ID。

        ```
        ADD ETHSUBIF:IFNAME="Eth-trunk1.4",VLANTYPEVID=2215;
        ```

        ```
        ADD ETHSUBIF:IFNAME="Eth-trunk2.4",VLANTYPEVID=2225;
        ```
     6. 配置IPv6使能。

        ```
        SET IFIPV6ENABLE: IFNAME="Eth-trunk1.4", ENABLEFLAG=TRUE;
        ```

        ```
        SET IFIPV6ENABLE: IFNAME="Eth-trunk2.4", ENABLEFLAG=TRUE;
        ```
     7. 配置外联口IP地址。

        ```
        ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.4",IFIPADDR="192.168.215.2",SUBNETMASK="255.255.255.248";
        ```

        ```
        ADD IFIPV6ADDRESS:IFNAME="Eth-trunk1.4",IPV6ADDRESS="FC00::215:2",PREFIXLEN=125;
        ```

        ```
        ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.4",IFIPADDR="192.168.225.2",SUBNETMASK="255.255.255.248";
        ```

        ```
        ADD IFIPV6ADDRESS:IFNAME="Eth-trunk2.4",IPV6ADDRESS="FC00::225:2",PREFIXLEN=125;
        ```
  3. 新建BFD会话。

     //配置BFD单臂echo探测。直连DCGW场景或PE不支持BFD时，请配置该步骤。PE支持BFD时，可采用单臂echo或双向BFD探测。

     ```
     ADD BFDSESSION: SESSNAME="BfdName215_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.215.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_DATA",MINECHORXINT=500,LOCALDISCR=2151,IFNAME="Eth-trunk1.4";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName215_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_DATA",LOCALDISCR=2153,IFNAME="Eth-trunk1.4",DESTADDR6="FC00::215:1";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName225_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.225.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_DATA",MINECHORXINT=500,LOCALDISCR=2251,IFNAME="Eth-trunk2.4";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName225_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_DATA",LOCALDISCR=2253,IFNAME="Eth-trunk2.4",DESTADDR6="FC00::225:1";
     ```

     //配置双向BFD探测。PE支持BFD探测且使用双向BFD探测时，请配置该步骤。其他场景请跳过该步骤。

     ```
     ADD BFDSESSION: SESSNAME="BfdName215_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.215.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_DATA",LOCALDISCR=2151,REMOTEDISCR=2152,IFNAME="Eth-trunk1.4";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName215_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_DATA",LOCALDISCR=2153,REMOTEDISCR=2154,IFNAME="Eth-trunk1.4",DESTADDR6="FC00::215:1";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName225_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.225.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_DATA",LOCALDISCR=2251,REMOTEDISCR=2252,IFNAME="Eth-trunk2.4";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName225_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_DATA",LOCALDISCR=2253,REMOTEDISCR=2254,IFNAME="Eth-trunk2.4",DESTADDR6="FC00::225:1";
     ```
  4. 采用静态路由+BFD时，配置静态路由并绑定BFD会话。

     //“PREFIX”/“MASKLENGTH”是目的IP地址及所在网段掩码长度，请根据网设文档替换。

     ```
     ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_DATA",DESTVRFNAME="VRF_DATA",IFNAME="Eth-trunk1.4",NEXTHOP="192.168.215.1",SESSIONNAME="BfdName215_v4";
     ```

     ```
     ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_DATA",DESTVRFNAME="VRF_DATA",IFNAME="Eth-trunk1.4",NEXTHOP="FC00::215:1",SESSIONNAME="BfdName215_v6";
     ```

     ```
     ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_DATA",DESTVRFNAME="VRF_DATA",IFNAME="Eth-trunk2.4",NEXTHOP="192.168.225.1",SESSIONNAME="BfdName225_v4";
     ```

     ```
     ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_DATA",DESTVRFNAME="VRF_DATA",IFNAME="Eth-trunk2.4",NEXTHOP="FC00::225:1",SESSIONNAME="BfdName225_v6";
     ```

- 直连DCGW组网时，配置外联口IP和路由数据（登录PGW Web LMT使用）。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_OM";
     ADD VPNINSTAF:VRFNAME="VRF_OM",AFTYPE=ipv4uni, VRFRD="192.168.225.216:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_OM",AFTYPE=ipv6uni, VRFRD="192.168.225.216:100";
     ```
  2. 配置Loopback接口IP。用于建立BGP邻居。

     ```
     ADD INTERFACE:IFNAME="LoopBack216";
     ADD IPBINDVPN:IFNAME="LoopBack216",VRFNAME="VRF_OM";
     ADD IFIPV4ADDRESS:IFNAME="LoopBack216",IFIPADDR="192.168.225.216",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
     ```

     ```
     SET IFIPV6ENABLE: IFNAME="Loopback216", ENABLEFLAG=TRUE;
     ADD IFIPV6ADDRESS:IFNAME="Loopback216",IPV6ADDRESS="FC00::225:216",PREFIXLEN=128;
     ```
  3. 配置BGP VPN实例。

     ```
     ADD BGPVRF: VRFNAME="VRF_OM", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.216";
     ```
  4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

     ```
     ADD BGPVRFAF: VRFNAME="VRF_OM", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
     ```

     ```
     ADD BGPVRFAF: VRFNAME="VRF_OM", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
     ```
  5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。
