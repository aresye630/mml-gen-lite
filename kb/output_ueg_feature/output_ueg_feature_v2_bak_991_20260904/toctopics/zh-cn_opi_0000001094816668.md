# 配置静态带宽管理规则

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当APP/管理面MEPM没有下发动态带宽管理规则时，如果需要对用户访问APP的业务流进行上下行带宽控制，支持在MPF本地配置带宽管理规则。

**说明** 

适用于MPF。

## 必备事项

## 操作步骤

- 配置基于APP的带宽控制，对访问该APP的所有业务进行带宽管理。
  1. 配置BWM业务。

     1. 设置分类属性。

        **ADD CATEGORYPROP**
     2. 设置基于分类属性的BWM业务，MPF仅支持非TOS业务，采用三四层的过滤规则进行识别。

        **ADD BWMSERVICE**
     3. 配置BWM控制器，设置CAR参数。

        **ADD BWMCONTROLLER**
     4. 配置BWM控制器中的用户组级业务带宽和连接数等配置数据是基于业务处理单元生效还是整机生效。

        **SET BANDWIDTHMNG**
     5. 定义带宽管理用户组，配置优先级和业务类型。

        **ADD BWMUSERGROUP**
     6. 配置用户组级带宽控制规则。

        **ADD BWMRULE**
  2. 配置三四层过滤条件。

     1. 配置三四层过滤条件，IP地址为APP的IP地址。

        **ADD FILTER**
     2. 配置FlowFilter。

        **ADD FLOWFILTER**
     3. 将Filter绑定到FlowFilter。

        **ADD FLTBINDFLOWF**
     4. 刷新Filter配置。

        **SET REFRESHSRV**
  3. 配置带宽管理使用的业务策略组合。

     1. 配置带宽管理使用的规则，当根据CategoryProp区分业务时，BWM Rule与Rule通过策略名称关联。

        **ADD RULE**
     2. 配置User Profile。

        **ADD USERPROFILE**
     3. 增加带宽管理用户组User Profile绑定。

        **ADD UPBINDBWMUSRG**
     4. 将User Profile指定为全局User Profile。

        **ADD LOCALUSERPROF**

        **说明** 

        **ADD LOCALUSERPROF**命令的“USERPROFILENAME”和**ADD USERPROFILE**命令的“USERPROFILENAME”必须配置为相同值。
     5. 将配置的Rule绑定到User Profile。

        **ADD RULEBINDING**
- 配置全局带宽规则，对MPF上所有用户的所有业务进行带宽管理。
  1. 配置BWM控制器，设置CAR参数。

     **ADD BWMCONTROLLER**
  2. 配置BWM控制器中的用户组级业务带宽和连接数等配置数据是基于业务处理单元生效还是整机生效。

     **SET BANDWIDTHMNG**
  3. 定义带宽管理用户组，配置优先级和业务类型。

     **ADD BWMUSERGROUP**
  4. 配置用户组级带宽控制规则。

     **ADD BWMRULE**

## 任务示例

任务描述

任务一：配置基于APP的带宽控制，过滤条件是APP的IP地址，对所有命中该APP带宽管理规则的业务进行带宽控制。

任务二：配置全局带宽规则，对MPF上所有用户的所有业务进行带宽管理。

脚本

**任务一：配置基于APP的带宽控制，过滤条件是APP的IP地址，对所有命中该APP带宽管理规则的业务进行带宽控制。**

//配置BWM业务。

```
ADD CATEGORYPROP:CATEPROPNAME="cp_category";
ADD BWMSERVICE:BWMSERVICENAME="bwm-service",BWMSERVICETYPE=NONTOS,NONTOSSRVTYPE=CATEGORY_PROP,CATEPROPNAME="cp_category";
ADD BWMCONTROLLER:BWMCNAME="bc-global-up",CTRLTYPE=CAR,CIR=100,PIR=700,GREEN=PASS,YELLOW=PASS,RED=DISCARD;
ADD BWMCONTROLLER:BWMCNAME="bc-global-down",CTRLTYPE=CAR,CIR=100,PIR=600,GREEN=PASS,YELLOW=PASS,RED=DISCARD;
SET BANDWIDTHMNG: RANGE=SYSTEM;
ADD BWMUSERGROUP:USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="ug_test",USERGROUPPRI=1,USERGLEVSRVTYPE=NONTOS;
ADD BWMRULE: USERGROUPTYPE=SPECIFIC_GROUP, USERGROUPNAME="ug_test", BWMRULETYPE=GROUP_SPECIFIC, BWMRULENAME="bwm_rule_test", BWMSERVICENAME="bwm-service", UPBWMCTRLNAME1="bc-global-up", DNBWMCTRLNAME1="bc-global-down", BWMRULEPRI=1;
```

//配置带宽管理规则使用的三四层过滤条件，过滤器的IP地址为APP的IP地址。

```
ADD FILTER:FILTERNAME="filter_test",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=IP,SVRIP="10.1.1.1",SVRIPMASKTYPE=IPTYPE,SVRIPMASK="0.0.0.0";
```

```
ADD FLOWFILTER:FLOWFILTERNAME="flow-l34";
```

```
ADD FLTBINDFLOWF:FLOWFILTERNAME="flow-l34",FILTERNAME="filter_test";
```

```
SET REFRESHSRV:REFRESHTYPE=ALL;
```

//配置带宽管理规则使用的规则。

```
ADD RULE:RULENAME="rule_bwm",POLICYTYPE=BWM,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flow-l34",PRIORITY=1,POLICYNAME="cp_category";
```

//配置带宽管理规则使用的业务策略组合。

```
ADD USERPROFILE:USERPROFILENAME="up_test";
```

```
ADD UPBINDBWMUSRG:USERGROUPNAME="ug_test",USERPROFILENAME="up_test";
```

```
ADD LOCALUSERPROF:USERPROFILENAME="up_test";
```

```
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_bwm";
```

**任务二：配置全局带宽规则，对MPF上所有用户的所有业务进行带宽管理。**

```
ADD BWMCONTROLLER:BWMCNAME="bc-global-up",CTRLTYPE=CAR,CIR=100,PIR=700,GREEN=PASS,YELLOW=PASS,RED=DISCARD;
ADD BWMCONTROLLER:BWMCNAME="bc-global-down",CTRLTYPE=CAR,CIR=100,PIR=600,GREEN=PASS,YELLOW=PASS,RED=DISCARD;
SET BANDWIDTHMNG: RANGE=SYSTEM;
ADD BWMUSERGROUP:USERGROUPTYPE=DEFAULT_GROUP,USERGLEVSRVTYPE=NONTOS;
ADD BWMRULE: USERGROUPTYPE=DEFAULT_GROUP, BWMRULETYPE=GROUP_DEFAULT, UPBWMCTRLNAME1="bc-global-up", DNBWMCTRLNAME1="bc-global-down";
```
