## 操作场景

## 必备事项

## 操作步骤

1. 登录“USCDB MML命令”界面。

   2~6用于配置USCDB与PCF/PCRF对接。容灾组网中，同一UEG内的FE和BE对接，不同UEG内不交叉对接。

   如已完成园区UDM的配置，则不需要重复配置2，请跳转到3。
2. 设置分组开关。

   ```
   SET GROUPSWITCH: GROUPNAME="UPCF", GROUPSWITCH=OPEN;
   ```
3. 增加远端Location信息。

   DC1:

   ```
   ADD RLOCATION: RLOCID=13, RMT="UPCF", LP=5, REDUNFLAG=No;
   ADD RLOCATION: RLOCID=13, RMT="UPCF-SESSION", LP=5, REDUNFLAG=No;
   ```

   DC2:

   ```
   ADD RLOCATION: RLOCID=15, RMT="UPCF", LP=10, REDUNFLAG=No;
   ADD RLOCATION: RLOCID=15, RMT="UPCF-SESSION", LP=10, REDUNFLAG=No;
   ```
4. 增加远端DBS。

   **说明** 

   参数“RDSGMID”通过在“UEG MML命令”下使用“LST DBSSERVICENO:;”查询。

   - DC1:

     **虚机容器**：

     ```
     ADD RDSG: RLOCID=13, RDSGMID=301, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=13, RDSGMID=302, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=13, RDSGMID=301, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=13, RDSGMID=302, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ```

     **裸机容器**：

     ```
     ADD RDSG: RLOCID=13, RDSGMID=301, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=13, RDSGMID=301, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ```

   - DC2:

     **虚机容器**：

     ```
     ADD RDSG: RLOCID=15, RDSGMID=301, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=15, RDSGMID=302, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=15, RDSGMID=301, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=15, RDSGMID=302, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ```

     **裸机容器**：

     ```
     ADD RDSG: RLOCID=15, RDSGMID=301, RDSGST="UPCF", RDSGTYPE=DBS;
     ADD RDSG: RLOCID=15, RDSGMID=301, RDSGST="UPCF-SESSION", RDSGTYPE=DBS;
     ```
5. 增加远端网元IP地址。

   DC1:

   ```
   ADD RIPADDR: RLOCID=13, ID=1, IPVER=IPV4, IPV4IP1="10.200.200.22", IPV4IP2="10.200.200.23", RDPUST="UPCF";
   ADD RIPADDR: RLOCID=13, ID=1, IPVER=IPV4, IPV4IP1="10.200.200.22", IPV4IP2="10.200.200.23", RDPUST="UPCF-SESSION";
   ```

   DC2:

   ```
   ADD RIPADDR: RLOCID=15, ID=1, IPVER=IPV4, IPV4IP1="10.201.200.22", IPV4IP2="10.201.200.23", RDPUST="UPCF";
   ADD RIPADDR: RLOCID=15, ID=1, IPVER=IPV4, IPV4IP1="10.201.200.22", IPV4IP2="10.201.200.23", RDPUST="UPCF-SESSION";
   ```
6. 增加PGW订阅通知配置。操作员通过PGW修改全局数据或用户数据后，PGW负责通知FE相关的修改内容。

   DC1:

   ```
   ADD NOTIFYCFG: FETYPE="UPCF", FEID=3, INFTYPE=MCI, SYNCHROSWITCH=ASYNC, LOCATIONID=13, NOTIFYDEST=2;
   ```

   DC2:

   ```
   ADD NOTIFYCFG: FETYPE="UPCF", FEID=4, INFTYPE=MCI, SYNCHROSWITCH=ASYNC, LOCATIONID=15, NOTIFYDEST=2;
   ```
7. 登录“UEG MML命令”界面。

   8~11用于配置PCF/PCRF与USCDB对接。容灾组网中，同一UEG内的FE和BE对接，不同UEG内不交叉对接。

   如已完成园区UDM的配置，则不需要重复配置8~9，请跳转到10。
8. 设置DBS分组开关。

   ```
   SET DBSGRPSWITCH: GROUPNAME="UPCF", GROUPSWITCH=OPEN;
   ```
9. 增加远端Location信息。

   DC1:

   ```
   ADD DBSRLOCATION: RLOCID=14, RMT=USCDB, LP=5;
   ```

   DC2:

   ```
   ADD DBSRLOCATION: RLOCID=16, RMT=USCDB, LP=10;
   ```
10. 增加远端DSG。

    **说明** 

    在“MML-USCDB”下使用“LST MODULE: MT=DSG;”查询参数“RDSGMID”的值，需要将查询出来的所有DSG模块号配置在此处。如下以查询到DSG模块号为1017、1018、1019和1020为例。

    DC1:

    ```
    ADD DBSRDSG: RLOCID=14, RDSGMID=1017, RDSGST="UPCF";
    ADD DBSRDSG: RLOCID=14, RDSGMID=1018, RDSGST="UPCF";
    ADD DBSRDSG: RLOCID=14, RDSGMID=1019, RDSGST="UPCF-SESSION";
    ADD DBSRDSG: RLOCID=14, RDSGMID=1020, RDSGST="UPCF-SESSION";
    ```

    DC2:

    ```
    ADD DBSRDSG: RLOCID=16, RDSGMID=1017, RDSGST="UPCF";
    ADD DBSRDSG: RLOCID=16, RDSGMID=1018, RDSGST="UPCF";
    ADD DBSRDSG: RLOCID=16, RDSGMID=1019, RDSGST="UPCF-SESSION";
    ADD DBSRDSG: RLOCID=16, RDSGMID=1020, RDSGST="UPCF-SESSION";
    ```
11. 增加远端网元IP地址。

    DC1:

    ```
    ADD DBSRIPADDR: RLOCID=14, ID=21, IPVER=IPV4, IPV4IP1="10.200.200.32", IPV4IP2="10.200.200.33", RIPST="UPCF";
    ADD DBSRIPADDR: RLOCID=14, ID=22, IPVER=IPV4, IPV4IP1="10.200.200.32", IPV4IP2="10.200.200.33", RIPST="UPCF-SESSION";
    ```

    DC2:

    ```
    ADD DBSRIPADDR: RLOCID=16, ID=21, IPVER=IPV4, IPV4IP1="10.201.200.32", IPV4IP2="10.201.200.33", RIPST="UPCF";
    ADD DBSRIPADDR: RLOCID=16, ID=22, IPVER=IPV4, IPV4IP1="10.201.200.32", IPV4IP2="10.201.200.33", RIPST="UPCF-SESSION";
    ```
12. 登录“USCDB MML命令”界面。执行如下命令，激活IP链路。

    ```
    ACT IPDISP:;
    ```
13. 登录“UEG MML命令”界面。执行如下命令，激活IP链路。

    ```
    ACT DBSIPDISP:;
    ```

## 验证方法

1. 登录“USCDB MML命令”界面。
2. 执行**DSP DSGSCTP**命令，查询BE和FE之间链路状态是否正常。
   - 正常，请执行3。
   - 不正常，请联系华为技术支持工程师。
3. 登录“UEG MML命令”界面。
4. 执行**DSP DBSSCTP**命令，查询FE和BE之间链路状态是否正常。
   - 正常，结束。
   - 不正常，请联系华为技术支持工程师。
