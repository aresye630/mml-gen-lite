## 操作场景

去使能负荷分担容灾模式时（比如进行网元卸载、容灾模式改造等），需要参考本页面进行配置。

**注意** 

本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。

## 操作步骤

1. 关闭负荷分担容灾功能。

   ```
   SET DRCOUPLINGRESET: COUPLINGRESET=NO;
   ```
2. 将监控的服务都设置为不监控。

   ```
   SET DRKEYNF: AMF=NO, UDM=NO, SMF=NO, UPF=NO, UDR=NO;
   ```

## 验证方法

1. 执行对应的LST命令，检查配置是否与规划一致。
   - 检查是否去使能负荷分担容灾功能。

     执行**LST DRCOUPLINGRESET**命令进行检查，如配置错误，则重新执行1进行设置。
   - 检查监控的服务设置是否正确。

     执行**LST DRKEYNF**命令进行检查，如配置错误，则重新执行2进行设置。
