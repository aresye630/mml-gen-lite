# 配置静态地址用户路由冗余功能

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

**对于风筝S**：

如下两种场景下，终端采用静态签约的IP时，需要配置静态地址用户用户路由冗余功能。

- 1+1主备容灾场景，需要在园区的两个UPF之间部署静态地址用户路由冗余功能，保证主用UPF故障恢复时，备用UPF上激活的用户业务连续。
- 主备跨级容灾场景，需要在园区的UPF和地市的UPF之间部署静态地址用户路由冗余功能，保证主用UPF故障恢复时，备用UPF上的用户业务连续。

**对于风筝M/风筝L**：

两套UEG间采用负荷分担模式容灾场景，终端采用静态签约的IP时，需要在园区的两个UPF之间部署静态地址用户路由冗余功能，保证两个UPF都正常时，SGi/N6侧发布低优先级路由的UPF上激活的用户业务连续。

## 操作步骤

1. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      - 如果“自动配置开关”值为“TRUE”，需要执行1.b和1.c关闭自动配置开关。
      - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到2。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
2. 配置主UPF到备UPF的IP路由数据。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Redundancy";
      ADD VPNINSTAF:VRFNAME="VRF_Redundancy", AFTYPE=ipv4uni, VRFRD="192.168.225.150:100";
      ```
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack100";
      ADD IPBINDVPN:IFNAME="LoopBack100",VRFNAME="VRF_Redundancy";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack100",IFIPADDR="192.168.225.150",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Redundancy", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.150";
      ```
   4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Redundancy", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。

      ```
      ADD BGPPEER: VRFNAME="VRF_Redundancy", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.20", REMOTEAS="60002", LOCALIFADDR="192.168.225.150", LOCALIFNAME="Loopback100", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Redundancy", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.20", REMOTEAS="60002", LOCALIFADDR="192.168.225.150", LOCALIFNAME="Loopback100", EBGPMAXHOP=10;
      ```
   6. 添加以太网隧道多虚拟网卡自动化配置模板。如已配置，请跳过本步骤。

      ```
      ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=6, VNICLIST="6 7";
      ```
   7. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Redundancy_2100_v4",VPNNAME="VRF_Redundancy",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=6,VLANID=2100, BEGINADDR4="192.168.100.2", ENDADDR4="192.168.100.30", MASKLEN=27;
      ```
   8. 增加BFD会话自动部署模板。

      ```
      ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2100_v4", BFDTYPE=Static, SERVICENAME="ServName_Redundancy_2100_v4", IPVERSION=IPv4, DESTADDR4="192.168.100.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
      ```
   9. 增加静态路由自动部署模板。

      //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Redundancy_2100_v4", VRFNAME="VRF_Redundancy", IPVERSION=IPv4, PREFIX4="192.168.79.20", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.100.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Redundancy", BFDTEMPLATENAME="BFD_2100_v4"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Redundancy_2100_v4", VRFNAME="VRF_Redundancy", IPVERSION=IPv4, PREFIX4="192.168.78.20", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.100.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Redundancy", BFDTEMPLATENAME="BFD_2100_v4";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_Redundancy_2100_v4", VRFNAME="VRF_Redundancy", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.100.1", BFDENABLE=TRUE, DESCRIPTION="VRF_Redundancy", BFDTEMPLATENAME="BFD_2100_v4";
      ```
   10. 配置Loopback接口IP。用作Tunnel隧道的源接口。

       ```
       ADD INTERFACE:IFNAME="LoopBack10";
       ADD IPBINDVPN:IFNAME="LoopBack10",VRFNAME="VRF_Redundancy";
       ADD IFIPV4ADDRESS:IFNAME="LoopBack10",IFIPADDR="10.11.1.1",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
       ```
   11. 配置BGP引入到10.11.1.1的IP路由，即对外发布到Tunnel隧道的源接口IP的路由。

       ```
       ADD NETWORKROUTE:VRFNAME="VRF_Redundancy",AFTYPE=ipv4uni,NETWORKADDRESS="10.11.1.1",MASKLEN=32;
       ```
3. 打开自动部署开关。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```

   **说明** 

   从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行**DSP OPSASSISTSTATE**命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。
4. 配置虚拟重定向IP。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD REDUNDRDTIP: IPVERSION=IPv4, IPV4ADDRESS="192.168.0.1";
   ```

   ```
   ADD REDUNDRDTIP: IPVERSION=IPv6, IPV6ADDRESS="fc00:3::1";
   ```
5. 配置GRE Tunnel。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD INTERFACE: IFNAME="Tunnel1", IFMTU=1500;
   ADD GRETUNNEL: TNLNAME="Tunnel1", SRCTYPE=if_name, DSTIPADDR="10.10.0.1", TNLTYPE=gre, SRCIFNAME="LoopBack10", DSTVPNNAME="VRF_Redundancy", GREKEYEN=TRUE, GREKEY="200", REDUNDANCYEN=TRUE, KEEPALVEN=TRUE;
   ```

   ```
   ADD IPBINDVPN: IFNAME="Tunnel1", VRFNAME="VRF_LocalDN";
   ADD IFIPV4ADDRESS: IFNAME="Tunnel1", IFIPADDR="10.11.1.3", SUBNETMASK="255.255.255.0";
   SET IFIPV6ENABLE: IFNAME="Tunnel1", ENABLEFLAG=TRUE, MTU=1500;
   ADD IFIPV6ADDRESS: IFNAME="Tunnel1", IPV6ADDRESS="fc00:2::1", PREFIXLEN=64;
   ```
6. 配置到虚拟重定向IP的路由。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   ADD SRROUTE: AFTYPE=ipv4unicast, PREFIX="192.168.0.1", MASKLENGTH=32, VRFNAME="VRF_LocalDN", IFNAME="Tunnel1";
   ```

   ```
   ADD SRROUTE6: AFTYPE=ipv6unicast, PREFIX="fc00:3::1", MASKLENGTH=128, VRFNAME="VRF_LocalDN", IFNAME="Tunnel1";
   ```
7. 使能静态地址用户路由冗余功能。主备UPF上均需要执行本步骤。

   ```
   SET REDUNDUSER: SWITCH=ENABLE;
   ```
8. 修改静态地址池，打开地址池的冗余备份开关。

   此处以配置主UPF为例。备UPF的配置与主UPF的配置过程相同，仅数据不同，请替换成实际规划的数据。

   ```
   MOD POOL(风筝S)/MOD UPPOOL(风筝M或L): POOLNAME="pool_ipv4_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
   ```

   ```
   MOD POOL(风筝S)/MOD UPPOOL(风筝M或L): POOLNAME="pool_ipv6_APN1", POOLTYPE=EXTERNAL, REDUNDFUNC=ENABLE;
   ```
9. 开启APN路由冗余上行报文隧道转发功能。仅在备用UEG配置，主UPF上不配置。

   ```
   SET APNREDUNDUPSW: APN="apn-op1", IPV4SWITCH=ENABLE, IPV6SWITCH=ENABLE;
   ```
10. 配置CU Full Mesh数据。在主备UPF上均需要执行本步骤。

    //打开本特性的License配置开关。

    ```
    SET LICENSESWITCH:LICITEM="LKV3G5CUFM01",SWITCH=ENABLE;
    ```

    //配置用户面支持分配F-TEID。

    ```
    SET CPTEIDUALLOC: SWITCH=DISABLE;
    ```
