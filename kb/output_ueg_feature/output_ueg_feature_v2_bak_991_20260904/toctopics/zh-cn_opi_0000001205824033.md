## 操作场景

园区UDM（风筝L）上需要配置鉴权数据（K4密钥和K4加密算法），用于和从中心UDM同步的用户鉴权参数（KIVALUE和OPCVALUE）配合实现网络与用户双向鉴权。

**须知** 

园区UDM（风筝L）配置的K4密钥和K4加密算法，需要与中心UDM完全一致。

## 必备事项

前提条件

操作人员具有PGW Web LMT的操作权限。

数据

## 操作步骤

1. 登录“UDM业务管理”窗口。
2. 执行**ADD AMF**命令设置AMF值。

   //计算鉴权时使用**SET MAPSERV**中配置的AUTH\_MILENAGE\_C1~C5和AUTH\_MILENAGE\_R1~R5参数值。

   ```
   ADD AMF: HLRSN=1, AMFSNO=1, AMFVALUE="1111", CONSTANTPROV=FALSE, XRES_LENTH=255, NGCSQNIND=18;
   ```

   //计算鉴权时使用本命令设置的C1~C5和R1~R5参数值。

   ```
   ADD AMF: HLRSN=1, AMFSNO=1, AMFVALUE="1111", CONSTANTPROV=TRUE, C1="00000000000000000000000000000000", C2="00000000000000000000000000000001", C3="00000000000000000000000000000002", C4="00000000000000000000000000000004", C5="00000000000000000000000000000008", R1="40", R2="00", R3="20", R4="40", R5="60", XRES_LENTH=8, NGCSQNIND=18;
   ```
3. 执行**ADD K4**命令设置用于加密KI的K4值。

   ```
   ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=ClearKey, ALGTYPE=AES128, K4VALUE="*****";
   ```
4. USIM卡中烧制了OP时，执行**ADD OP**命令设置OP值。USIM卡中烧制了OPC时，请跳过本步骤。

   ```
   ADD OP: HLRSN=1, OPSNO=1, OPVALUE="1234567890abcdef1234567890abcde1";
   ```

## 验证方法

1. 检查用户数据文件同步是否正常。
   - 是，请执行2。
   - 否，请参考配置用户数据文件同步处理，确保用户数据同步正常后执行2。
2. 登录“UDM业务管理”窗口。
3. （风筝L）用户开机，观测用户是否正常注册到网络。
   - 是，调测结束。
   - 否，请联系华为技术支持工程师处理。
