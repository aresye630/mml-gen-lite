# 配置USCDB内存库备份文件加密

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

内存数据库备份文件中保存了用户业务正常运行所需的重要数据，为了保护数据的机密性和提升备份文件的安全性，支持对内存库备份文件进行加密。

系统默认关闭对内存库备份文件进行加密的功能，当需要对内存库备份文件进行加密时，可以参考本章节操作。

## 对系统的影响

- 内存库备份文件加密功能开启，会增加备份和恢复时长，请谨慎启用此功能。
- 内存库备份文件加密后，发生故障需要华为技术支持人员进行分析时，如果涉及内存库备份文件的分析，则需要提供加密用的密钥材料和盐值用于解密内存库备份文件。

## 必备事项

前提条件

向系统管理员获取OM Portal的帐号的密码。

数据

该操作无需准备数据。

## 操作步骤

1. 登录“USCDB MML命令”界面。
2. 执行**MOD INSP**命令，打开加密备份开关。

   ```
   MOD INSP: INSPT=FE, INSPN=FILEBKPENCSWT, INSPV=1, FETYPEN="SUP-FE";
   ```
3. 执行**SET FILEBKPENC**命令设置文件备份加密信息。

   ```
   SET FILEBKPENC: KEY1=密钥材料1, KEY2=密钥材料2, KEY3=密钥材料3, DESC=描述;
   ```
