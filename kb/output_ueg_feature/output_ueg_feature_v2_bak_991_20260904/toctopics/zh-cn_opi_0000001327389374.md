# 配置PCF/PCRF

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

园区UEG提供语音等业务时，UEG上需要配置PCF/PCRF实体功能。以保证用户能够正常开展业务。

## 必备事项

前提条件

- 已完成软件安装。
- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

## 操作步骤

- 登录“MML命令行-UEG ”界面。

  **说明** 

  外联口IP和路由数据，均在“UEG MML命令”界面执行。

- 关闭自动配置开关。

  1. 查询自动配置开关。

     ```
     LST AUTOCONFIG:;
     ```

     - 如果“自动配置开关”值为“TRUE”，需要执行2.b和2.c关闭自动配置开关。
     - 如果“自动配置开关”值为“FALSE”，说明已关闭自动配置开关，请跳转到3。
  2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

     ```
     DSP OPSASSISTSTATE:;
     ```
  3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

     ```
     SET AUTOCONFIG:SWITCHFLAG=FALSE;
     ```

- 配置外联口IP和路由数据（USCDB与另一UEG内的USCDB互通）。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_DATA";
     ADD VPNINSTAF:VRFNAME="VRF_DATA",AFTYPE=ipv4uni, VRFRD="192.168.225.215:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_DATA",AFTYPE=ipv6uni, VRFRD="192.168.225.215:100";
     ```
  2. 添加以太网隧道多虚拟网卡自动化配置模板。如已配置，请跳过本步骤。

     ```
     ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=6, VNICLIST="6 7";
     ```
  3. 配置外联口自动部署模板。

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_DATA_2215_v4",VPNNAME="VRF_DATA",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=6,VLANID=2215, BEGINADDR4="192.168.215.2", ENDADDR4="192.168.215.30", MASKLEN=27;
     ```

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_DATA_2215_v6",VPNNAME="VRF_DATA",AFTYPE=IPv6,IPALLOCTYPE6=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=6,VLANID=2215, BEGINADDR6="FC00::215:2", ENDADDR6="FC00::215:1E", MASKLEN=123;
     ```
  4. 增加BFD会话自动部署模板。

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2215_v4", BFDTYPE=Static, SERVICENAME="ServName_DATA_2215_v4", IPVERSION=IPv4, DESTADDR4="192.168.215.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2215_v6", BFDTYPE=Static, SERVICENAME="ServName_DATA_2215_v6", IPVERSION=IPv6, DESTADDR6="FC00::215:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```
  5. 增加静态路由自动部署模板。

     //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（USCDB上和另一USCDB互通的业务IP地址和掩码）。

     ```
     ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_DATA_2215_v4", VRFNAME="VRF_DATA", IPVERSION=IPv4, PREFIX4="10.201.200.32", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.215.1", BFDENABLE=TRUE, DESCRIPTION="VRF_DATA", BFDTEMPLATENAME="BFD_2215_v4"; 
     ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_DATA_2215_v4", VRFNAME="VRF_DATA", IPVERSION=IPv4, PREFIX4="10.201.200.33", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.215.1", BFDENABLE=TRUE, DESCRIPTION="VRF_DATA", BFDTEMPLATENAME="BFD_2215_v4";
     ```

     //“PREFIX6”和“MASKLENGTH”是目的IP和掩码（USCDB上和另一USCDB互通的业务IP地址和掩码）。

     ```
     ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_DATA_2215_v6", VRFNAME="VRF_DATA", IPVERSION=IPv6, PREFIX6="FC00::10:201:200:32", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::215:1", BFDENABLE=TRUE, DESCRIPTION="VRF_DATA", BFDTEMPLATENAME="BFD_2215_v6"; 
     ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_DATA_2215_v6", VRFNAME="VRF_DATA", IPVERSION=IPv6, PREFIX6="FC00::10:201:200:33", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::215:1", BFDENABLE=TRUE, DESCRIPTION="VRF_DATA", BFDTEMPLATENAME="BFD_2215_v6";
     ```

- 配置外联口IP和路由数据（登录PGW Web LMT使用）。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_OM";
     ADD VPNINSTAF:VRFNAME="VRF_OM",AFTYPE=ipv4uni, VRFRD="192.168.225.216:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_OM",AFTYPE=ipv6uni, VRFRD="192.168.225.216:100";
     ```
  2. 配置Loopback接口IP。用于建立BGP邻居。

     ```
     ADD INTERFACE:IFNAME="LoopBack216";
     ADD IPBINDVPN:IFNAME="LoopBack216",VRFNAME="VRF_OM";
     ADD IFIPV4ADDRESS:IFNAME="LoopBack216",IFIPADDR="192.168.225.216",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
     ```

     ```
     SET IFIPV6ENABLE: IFNAME="Loopback216", ENABLEFLAG=TRUE;
     ADD IFIPV6ADDRESS:IFNAME="Loopback216",IPV6ADDRESS="FC00::225:216",PREFIXLEN=128;
     ```
  3. 配置BGP VPN实例。

     ```
     ADD BGPVRF: VRFNAME="VRF_OM", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.216";
     ```
  4. 增加BGP VPN实例地址族。UEG对接2个负荷分担的BGP PEER时，“MAXIMUMLOADBALANCE”设置为“2”。

     ```
     ADD BGPVRFAF: VRFNAME="VRF_OM", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
     ```

     ```
     ADD BGPVRFAF: VRFNAME="VRF_OM", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
     ```
  5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

     ```
     ADD BGPPEER: VRFNAME="VRF_OM", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.216", REMOTEAS="60002", LOCALIFADDR="192.168.225.216", LOCALIFNAME="Loopback216", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_OM", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.216", REMOTEAS="60002", LOCALIFADDR="192.168.225.216", LOCALIFNAME="Loopback216", EBGPMAXHOP=10;
     ```

     ```
     ADD BGPPEER: VRFNAME="VRF_OM", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:216", REMOTEAS="60002", LOCALIFADDR="FC00::225:216", LOCALIFNAME="Loopback216", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_OM", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:216", REMOTEAS="60002", LOCALIFADDR="FC00::225:216", LOCALIFNAME="Loopback216", EBGPMAXHOP=10;
     ```
  6. 配置BGP引入wlr路由。

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_OM", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_OM", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```
  7. 添加以太网隧道多虚拟网卡自动化配置模板。如已配置，请跳过本步骤。

     ```
     ADD AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=4, VNICLIST="4 5";
     ```
  8. 配置外联口自动部署模板。

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_OM_2216_v4",VPNNAME="VRF_OM",AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=10,VLANID=2216, BEGINADDR4="192.168.216.2", ENDADDR4="192.168.216.30", MASKLEN=27;
     ```

     ```
     ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_OM_2216_v6",VPNNAME="VRF_OM",AFTYPE=IPv6,IPALLOCTYPE6=USER_CONFIG,AUTOCFGIFTYPE=ETHTRUNK,ETHTRUNKTMPID=10,VLANID=2216, BEGINADDR6="FC00::216:2", ENDADDR6="FC00::216:1E", MASKLEN=123;
     ```
  9. 增加BFD会话自动部署模板。

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2216_v4", BFDTYPE=Static, SERVICENAME="ServName_OM_2216_v4", IPVERSION=IPv4, DESTADDR4="192.168.216.1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```

     ```
     ADD AUTOSCALINGBFD: TEMPLATENAME="BFD_2216_v6", BFDTYPE=Static, SERVICENAME="ServName_OM_2216_v6", IPVERSION=IPv6, DESTADDR6="FC00::216:1", MINECHORXINT=500, DETECTMULTI=4, ONEARMECHO=TRUE;
     ```
  10. 增加静态路由自动部署模板。

      //“PREFIX4”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_OM_2216_v4", VRFNAME="VRF_OM", IPVERSION=IPv4, PREFIX4="192.168.79.216", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.216.1", BFDENABLE=TRUE, DESCRIPTION="VRF_OM", BFDTEMPLATENAME="BFD_2216_v4"; 
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_OM_2216_v4", VRFNAME="VRF_OM", IPVERSION=IPv4, PREFIX4="192.168.78.216", MASKLENGTH=32, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.216.1", BFDENABLE=TRUE, DESCRIPTION="VRF_OM", BFDTEMPLATENAME="BFD_2216_v4";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX4”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_OM_2216_v4", VRFNAME="VRF_OM", IPVERSION=IPv4, PREFIX4="0.0.0.0", MASKLENGTH=0, NEXTHOPALLOCTYPE4=CONFIG, NEXTHOP4="192.168.216.1", BFDENABLE=TRUE, DESCRIPTION="VRF_OM", BFDTEMPLATENAME="BFD_2216_v4";

      ```

      ADD AUTOSCALINGSRROUTE: SERVICENAME="ServName_OM_2216_v6", VRFNAME="VRF_OM", IPVERSION=IPv6, PREFIX6="FC00::78:216", MASKLENGTH=128, NEXTHOPALLOCTYPE6=CONFIG, NEXTHOP6="FC00::216:1", BFDENABLE=TRUE, DESCRIPTION="VRF_OM", BFDTEMPLATENAME="BFD_2216_v6";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX6”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
