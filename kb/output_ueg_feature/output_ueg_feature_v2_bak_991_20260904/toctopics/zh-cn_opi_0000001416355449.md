## 操作场景

**注意** 

如已通过极简开站方式完成PCF对接配置，则无需执行本页面。

采用动态PCC且通过N7接口实现与PCF互通时，需要参考本页面进行SMF的配置。

采用动态PCC且通过Gx接口实现与PCF互通时，请参考配置Gx接口数据进行SMF的配置。

## 必备事项

前提条件

- 请仔细阅读特性概述。
- 完成加载License（开站后通过OM Portal可一键开启所有License项，IOPS场景无需手动开启）。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置SMF服务化接口。
   1. 配置逻辑接口。

      **ADD LOGICIP**
   2. 配置Nsmf接口的HTTP本端端点组信息。

      **ADD HTTPLEGRP**
   3. 配置HTTP本端端点信息。

      **ADD HTTPLE**
   4. 配置本端服务化接口接入点信息。

      **ADD SBIAPLE**
3. 配置SMF到PCF的数据 。
   1. 配置PCF的Profile信息。

      **ADD PNFPROFILE**
   2. 配置PCF的服务信息。

      **ADD PNFSERVICE**
   3. 配置对端PCF的实例信息，可以基于PLMN发现PCF。

      **ADD PNFPLMN**
   4. 配置对端PCF支持的SUPI信息，可以基于SUPI选择PCF。

      **ADD PNFSUPI**
   5. 配置对端PCF实例支持的服务切片信息。

      **ADD PNFNS**
   6. 配置对端PCF实例支持的DNN，可以基于DNN选择PCF。

      **ADD PNFDNN**
   7. 增加本地配置的对端PCF实例信息。

      **ADD PNFPCFINFO**
4. 打开License配置开关。

   **SET LICENSESWITCH**
5. 使能SMF上的全局用户的PCC功能。

   **SET PCCFUNC**
6. 使能SMF上基于APN的PCC功能。如果有多个APN，则可以多次执行本步骤。

   **SET APNPCCFUNC**
7. 配置PCC策略组。用于动态PCC时的预定义规则。

   **ADD CPPCCPOLICYGRP**
8. 配置SMF上的本地rule。用于动态PCC时的预定义规则。

   **ADD CPRULE**
9. 配置SMF上的UserProfile，将本地rule绑定到UserProfile上。用于动态PCC时的预定义规则组。
   1. 配置UserProfile。

      **ADD CPUSERPROFILE**
   2. 将rule绑定到UserProfile。

      **ADD CPRULEBINDING**
10. 设置PGW-C/SMF与PCF之间的策略接口模式。

    可只设置其中一种，也可以两种都设置。两种都设置时，基于APN的比基于全局的优先级高。请根据需要进行设置。

    1. 设置全局的策略接口的选择模式。

       **SET POLICYMODE**
    2. 增加基于APN的策略接口的选择模式。

       **ADD APNPOLICYMODE**

## 任务示例

任务描述

SMF上全局和指定APN使能动态PCC功能。

脚本

//增加SMF服务化接口的IP地址。

```
ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.200.200.8", VPNINSTNAME="VPN_CN", DESC="FOR Server SBI";
```

//配置HTTP本端端点组信息。

```
ADD HTTPLEGRP: INDEX=2, DESC="SMF";
```

//配置分别作为HTTP服务的服务端和客户端的本端端点信息。

```
ADD HTTPLE: INDEX=4,HTTPLEGRPIDX=2, LETYPE=CLIENT, IPTYPE=IPv4, IPV4="10.200.200.9", VPNNAME="VPN_CN", DESC="SMF Client";
```

//置SMF服务化接口接入点信息。

```
ADD SBIAPLE: INDEX=2, HTTPLEGRPIDX=2, NFTYPE=NFTypeSMF, DESCRIPTION="SMF";
```

//配置到PCF的数据，包括PCF的Profile、Service、PLMN信息、支持的SUPI范围等信息。

**说明** 

SMF可以基于DNN、DNAI、切片、TAI、PLMN、SUPI、GroupID选择PCF，园区可以基于规划的选择条件进行配置，此处以PLMN、SUPI为例说明配置过程。

```
ADD PNFPROFILE: NFINSTANCEID="PCF_Instance_0", NFTYPE=NfPCF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.0.0.28", PORT=8080;
ADD PNFSERVICE: NFINSTANCEID="PCF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NpcfSmplcCtrl, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
ADD PNFPLMN:NFINSTANCEID="PCF_Instance_0",MCC="460", MNC="003";
ADD PNFSUPI: INDEX=1,NFINSTANCEID="PCF_Instance_0", QUERYTYPE=START_END, RANGESTART="123031200100001",RANGEEND="123031200100100";
ADD PNFPCFINFO: NFINSTANCEID="PCF_Instance_0", RXDIAMHOST="huawei.com", RXDIAMREALM="huawei.com";
ADD PNFDNN:INDEX=1, NFINSTANCEID="PCF_Instance_0", DNN="huawei.com";
ADD PNFNS:INDEX=1, NFINSTANCEID="PCF_Instance_0", SST=1, SD="010101";
```

//打开License配置开关。

