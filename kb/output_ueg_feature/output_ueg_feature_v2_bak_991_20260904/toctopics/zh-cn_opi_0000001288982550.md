# 配置应急AMF和应急SMF

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

高可用边缘网关部署在企业园区，新开局场景，需要配置应急AMF和应急SMF实体功能，以保证应急场景下新注册用户或发生信令交互的已注册用户能够正常开展业务。

**图1** 应急AMF和应急SMF与其他网络实体的逻辑接口

## 必备事项

前提条件

- 已完成软件安装。
- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
- 已加载License文件。

## 操作步骤

- 登录“MML命令行-UEG”界面。

- 直连DCGW时，配置UEG间互通的IP路由数据。例如：传输应急UDM通过N8接口向另一UEG中的应急AMF主动发送的cancel location报文。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_SBI";
     ADD VPNINSTAF:VRFNAME="VRF_SBI",AFTYPE=ipv4uni, VRFRD="192.168.225.205:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_SBI",AFTYPE=ipv6uni, VRFRD="192.168.225.205:100";
     ```

     **说明** 

     步骤2.b~步骤2.f是BGP相关数据，仅采用BGP over静态路由+BFD时需要配置。采用静态路由+BFD时不需要配置。
  2. 配置Loopback接口IP。用于建立BGP邻居。

     ```
     ADD INTERFACE:IFNAME="LoopBack205";
     ADD IPBINDVPN:IFNAME="LoopBack205",VRFNAME="VRF_SBI";
     ADD IFIPV4ADDRESS:IFNAME="LoopBack205",IFIPADDR="192.168.225.205",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
     ```

     ```
     SET IFIPV6ENABLE: IFNAME="Loopback205", ENABLEFLAG=TRUE;
     ADD IFIPV6ADDRESS:IFNAME="Loopback205",IPV6ADDRESS="FC00::225:205",PREFIXLEN=128;
     ```
  3. 配置BGP VPN实例。

     ```
     ADD BGPVRF: VRFNAME="VRF_SBI", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.205";
     ```
  4. 增加BGP VPN实例地址族。

     //UEG对接2个负荷分担的BGP PEER，“MAXIMUMLOADBALANCE”设置为“2”。

     ```
     ADD BGPVRFAF: VRFNAME="VRF_SBI", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
     ```

     ```
     ADD BGPVRFAF: VRFNAME="VRF_SBI", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
     ```
  5. 配置BGP对等体。此处以对接2个IPv4v6双栈的BGP对等体为例。

     ```
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.205", REMOTEAS="60002", LOCALIFADDR="192.168.225.205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.205", REMOTEAS="60002", LOCALIFADDR="192.168.225.205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ```

     ```
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:205", REMOTEAS="60002", LOCALIFADDR="FC00::225:205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ADD BGPPEER: VRFNAME="VRF_SBI", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:205", REMOTEAS="60002", LOCALIFADDR="FC00::225:205", LOCALIFNAME="Loopback205", EBGPMAXHOP=10;
     ```
  6. 配置BGP引入wlr路由。

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_SBI", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```

     ```
     ADD IMPORTROUTE: VRFNAME="VRF_SBI", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
     ```
  7. 配置外联口IP地址。

     1. 添加Eth-trunk子接口。此处以与N3/N4复用物理端口为例。

        ```
        ADD INTERFACE:IFNAME="Eth-trunk1.3";
        ```

        ```
        ADD INTERFACE:IFNAME="Eth-trunk2.3";
        ```
     2. 增加接口绑定VPN。

        ```
        ADD IPBINDVPN:IFNAME="Eth-trunk1.3",VRFNAME="VRF_SBI";
        ```

        ```
        ADD IPBINDVPN:IFNAME="Eth-trunk2.3",VRFNAME="VRF_SBI";
        ```
     3. 在以太网子接口上关联VLAN ID。

        ```
        ADD ETHSUBIF:IFNAME="Eth-trunk1.3",VLANTYPEVID=2205;
        ```

        ```
        ADD ETHSUBIF:IFNAME="Eth-trunk2.3",VLANTYPEVID=2105;
        ```
     4. 配置IPv6使能。

        ```
        SET IFIPV6ENABLE: IFNAME="Eth-trunk1.3", ENABLEFLAG=TRUE;
        ```

        ```
        SET IFIPV6ENABLE: IFNAME="Eth-trunk2.3", ENABLEFLAG=TRUE;
        ```
     5. 配置外联口IP地址。

        ```
        ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.3",IFIPADDR="192.168.205.2",SUBNETMASK="255.255.255.248";
        ```

        ```
        ADD IFIPV6ADDRESS:IFNAME="Eth-trunk1.3",IPV6ADDRESS="FC00::205:2",PREFIXLEN=125;
        ```

        ```
        ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.3",IFIPADDR="192.168.105.2",SUBNETMASK="255.255.255.248";
        ```

        ```
        ADD IFIPV6ADDRESS:IFNAME="Eth-trunk2.3",IPV6ADDRESS="FC00::105:2",PREFIXLEN=125;
        ```
  8. 新建BFD会话。

     //配置BFD单臂echo探测。直连DCGW场景，请配置该步骤。PE支持BFD时，可采用单臂echo或双向BFD探测。

     ```
     ADD BFDSESSION: SESSNAME="BfdName2051_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.205.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_SBI",MINECHORXINT=500,LOCALDISCR=10541,IFNAME="Eth-trunk1.3";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2051_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_SBI",LOCALDISCR=10561,IFNAME="Eth-trunk1.3",DESTADDR6="FC00::205:1";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2052_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.105.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_SBI",MINECHORXINT=500,LOCALDISCR=10543,IFNAME="Eth-trunk2.1";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2052_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_SBI",LOCALDISCR=10563,IFNAME="Eth-trunk2.3",DESTADDR6="FC00::105:1";
     ```

     //配置双向BFD探测。PE支持BFD探测且使用双向BFD探测时，请配置该步骤。其他场景请跳过该步骤。

     ```
     ADD BFDSESSION: SESSNAME="BfdName2051_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.205.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_SBI",LOCALDISCR=10541,REMOTEDISCR=8542,IFNAME="Eth-trunk1.3";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2051_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_SBI",LOCALDISCR=10561,REMOTEDISCR=8562,IFNAME="Eth-trunk1.3",DESTADDR6="FC00::205:1";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2052_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=FALSE,DESTADDR4="192.168.105.1",LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_SBI",LOCALDISCR=10543,REMOTEDISCR=8544,IFNAME="Eth-trunk2.3";
     ```

     ```
     ADD BFDSESSION: SESSNAME="BfdName2052_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=FALSE,LINKTYPE=IP,MINTXINT=500,MINRXINT=500,DETECTMULTI=4,VRFNAME="VRF_SBI",LOCALDISCR=10563,REMOTEDISCR=8564,IFNAME="Eth-trunk2.3",DESTADDR6="FC00::105:1";
     ```
  9. 采用静态路由+BFD时，配置静态路由并绑定BFD会话。采用BGP over静态路由+BFD时，请跳过该步骤。

     //“PREFIX”/“MASKLENGTH”是另一UEG的S6a/N8/N14逻辑接口IP地址及所在网段掩码长度，请根据网设文档替换。

     ```
     ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="192.168.205.1",SESSIONNAME="BfdName2051_v4";
     ```

     ```
     ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="FC00::205:1",SESSIONNAME="BfdName2051_v6";
     ```

     ```
     ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="192.168.105.1",SESSIONNAME="BfdName2052_v4";
     ```

     ```
     ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="FC00::105:1",SESSIONNAME="BfdName2052_v6";
     ```
  10. 采用BGP over静态路由+BFD时，配置静态路由并绑定BFD会话。采用静态路由+BFD时，请跳过该步骤。

      //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.205",MASKLENGTH=32,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="192.168.205.1",SESSIONNAME="BfdName2051_v4";
      ```

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.205",MASKLENGTH=32,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="192.168.105.1",SESSIONNAME="BfdName2052_v4";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="192.168.205.1",SESSIONNAME="BfdName2051_v4";
      ```

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="192.168.105.1",SESSIONNAME="BfdName2052_v4";
      ```

      //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00::79:205",MASKLENGTH=128,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="FC00::205:1",SESSIONNAME="BfdName2051_v6";
      ```

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00::79:205",MASKLENGTH=128,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="FC00::105:1",SESSIONNAME="BfdName2052_v6";
      ```

      //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="0:0:0:0:0:0:0:0",MASKLENGTH=0,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk1.3",NEXTHOP="FC00::205:1",SESSIONNAME="BfdName2051_v6";
      ```

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="0:0:0:0:0:0:0:0",MASKLENGTH=0,VRFNAME="VRF_SBI",DESTVRFNAME="VRF_SBI",IFNAME="Eth-trunk2.3",NEXTHOP="FC00::105:1",SESSIONNAME="BfdName2052_v6";
      ```

- 园区内部署AAA服务器进行二次鉴权时，配置SMF与园区AAA服务器互通的外联口IP和路由数据。
  1. 配置VPN实例。

     ```
     ADD L3VPNINST:VRFNAME="VRF_AAA";
     ADD VPNINSTAF:VRFNAME="VRF_AAA",AFTYPE=ipv4uni, VRFRD="192.168.225.206:100";
     ```

     ```
     ADD VPNINSTAF:VRFNAME="VRF_AAA",AFTYPE=ipv6uni, VRFRD="192.168.225.206:100";
     ```
  2. 配置Loopback接口IP。用于建立BGP邻居。
