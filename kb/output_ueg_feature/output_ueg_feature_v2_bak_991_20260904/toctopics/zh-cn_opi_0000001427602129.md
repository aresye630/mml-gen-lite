# 配置Gx接口数据

- 操作场景
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

Gx接口是PGW与PCRF之间的接口，基于Diameter协议进行通信。主要用于PGW-C和PCRF间信令交互实现PCC策略控制功能。

由于N7接口不支持传递PTT业务的策略，部署PTT业务时，需要配置该页面。

## 必备事项

前提条件

- 操作员了解UEG各类接口的类型及命名规范。
- 操作员了解UEG与对端网元互通时可以采用的各种组网方式，以及每种组网方式的实现及特点等信息。
- 如果运营商规划采用VPN组网方式，则操作员在执行本操作前应已创建了相应的VPN实例。
- 需要配置逻辑接口的PBU正常运行，且PBU上无用户存在。当PBU还未启动或正在启动过程中，将无法在该PBU上配置逻辑接口。

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- 如果本接口采用IPv6组网，则需要开通逻辑接口支持IPv6特性，即加载对应的License项“81203214 LKV3G5V6LI01 逻辑接口支持IPv6”。
- 已经获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置Gx逻辑接口。

   ```
   //DC1
   ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.200.200.88", IPV4MTU=1500, DESC="Gx";
   ADD CPLOGICINF:NAME="gxif1/0/0", IPV4ADDRESS1="10.200.200.88", IPV4MASK1="255.255.255.255", IPVERSION=IPV4;
   //DC2
   ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.201.200.88", IPV4MTU=1500, DESC="Gx";
   ADD CPLOGICINF:NAME="gxif1/0/0", IPV4ADDRESS1="10.201.200.88", IPV4MASK1="255.255.255.255", IPVERSION=IPV4;
   ```
3. 配置Diameter本端信息。

   ```
   //DC1
   ADD DIAMLOCINFO:HOSTNAME="smf01", REALMNAME="smf01.huawei.com", PRODUCTNAME="smf", VENDORID=10415, FIRMWAREREV=0, ORIGINSTATEID=DISABLE, SUPPORTVENDORID=DISABLE;
   //DC2
   ADD DIAMLOCINFO:HOSTNAME="smf02", REALMNAME="smf02.huawei.com", PRODUCTNAME="smf", VENDORID=10415, FIRMWAREREV=0, ORIGINSTATEID=DISABLE, SUPPORTVENDORID=DISABLE;
   ```
4. 添加PCRF。

   ```
   //DC1
   ADD CPPCRF:HOSTNAME="upcf01.huawei.com", REALMNAME="huawei.com", SUPFEANEGOSW=DISABLE, FEATURELIST=ADC-0&CNO_ULI-0&EXTENDED_BW_NR-0&NETLOC-0&PCSCF_RESTORATION_ENHANCEMENT-0&PENDINGTRANSACTION-0&PROVAFSIGNALFL-0&RELEASE10-0&RELEASE8-1&RELEASE9-1&SGW_REST-0&UMCH-0, DSCPV=255, WALVALUE=0, CARRYSUPFEASW=ENABLE;
   //DC2
   ADD CPPCRF:HOSTNAME="upcf02.huawei.com", REALMNAME="huawei.com", SUPFEANEGOSW=DISABLE, FEATURELIST=ADC-0&CNO_ULI-0&EXTENDED_BW_NR-0&NETLOC-0&PCSCF_RESTORATION_ENHANCEMENT-0&PENDINGTRANSACTION-0&PROVAFSIGNALFL-0&RELEASE10-0&RELEASE8-1&RELEASE9-1&SGW_REST-0&UMCH-0, DSCPV=255, WALVALUE=0, CARRYSUPFEASW=ENABLE;
   ```
5. 添加对端信息。

   ```
   //DC1
   ADD DIAMPEERADDR:HOSTNAME="upcf01.huawei.com", ADDRTYPE=IPv4, IPV4ADDRESS="10.200.200.87", PORT=3868;
   //DC2
   ADD DIAMPEERADDR:HOSTNAME="upcf02.huawei.com", ADDRTYPE=IPv4, IPV4ADDRESS="10.201.200.87", PORT=3868;
   ```
6. 添加Diameter链路组。

   ```
   //DC1
   ADD DIAMCONNGRP:CONNGROUPNAME="upcf01.huawei.com", LOCALHOSTNAME="smf01", PEERHOSTNAME="upcf01.huawei.com", APPLICATION=GX, SELECTMODE=SESSION_ID;
   //DC2
   ADD DIAMCONNGRP:CONNGROUPNAME="upcf02.huawei.com", LOCALHOSTNAME="smf02", PEERHOSTNAME="upcf02.huawei.com", APPLICATION=GX, SELECTMODE=SESSION_ID;
   ```
7. 添加pcrf组。

   ```
   //DC1
   ADD PCRFGROUP:PCRFGRPNAME="upcf01.huawei.com", LOADBALANCEMODE=MASTER_SLAVE, FAILOVERSW=DISABLE;
   //DC2
   ADD PCRFGROUP:PCRFGRPNAME="upcf02.huawei.com", LOADBALANCEMODE=MASTER_SLAVE, FAILOVERSW=DISABLE;
   ```
8. 绑定PCRF到PCRF组。

   ```
   //DC1
   ADD PCRFBINDGRP: PCRFGRPNAME="upcf01.huawei.com", PCRFHOSTNAME="upcf01.huawei.com";
   //DC2
   ADD PCRFBINDGRP: PCRFGRPNAME="upcf02.huawei.com", PCRFHOSTNAME="upcf02.huawei.com";
   ```
9. 添加主pcrf。

   ```
   //DC1
   SET MASTERPCRF: PCRFGRPNAME="upcf01.huawei.com", MASTERPCRF="upcf01.huawei.com";
   //DC2
   SET MASTERPCRF: PCRFGRPNAME="upcf02.huawei.com", MASTERPCRF="upcf02.huawei.com";
   ```
10. 增加Diameter链路。

    ```
    //DC1
    ADD DIAMCONNECTION: DIAMCONNGRP="upcf01.huawei.com", LOCINTERFACE="gxif1/0/0", PEERADDRTYPE=IPv4, PEERIPV4ADDR="10.200.200.87", PEERPORT=3868, LOCALPORT=0;
    //DC2
    ADD DIAMCONNECTION: DIAMCONNGRP="upcf02.huawei.com", LOCINTERFACE="gxif1/0/0", PEERADDRTYPE=IPv4, PEERIPV4ADDR="10.201.200.87", PEERPORT=3868, LOCALPORT=0;
    ```
11. 绑定pcrf group到APN下。

    ```
    //DC1
    ADD PCRFGRPBNDAPN: APN="ptt.voice", DEFAULTFLAG=DEFAULT, PCRFGRPNAME="upcf01.huawei.com";
    //DC2
    ADD PCRFGRPBNDAPN: APN="ptt.voice", DEFAULTFLAG=DEFAULT, PCRFGRPNAME="upcf02.huawei.com";
    ```
12. 设置APN PCC功能，打开PCC开关。

    ```
    //DC1
    SET APNPCCFUNC: APN="ptt.voice", HOMEPCCSWITCH=ENABLE, ROAMPCCSWITCH=ENABLE, VISITPCCSWITCH=ENABLE;
    //DC2
    SET APNPCCFUNC: APN="ptt.voice", HOMEPCCSWITCH=ENABLE, ROAMPCCSWITCH=ENABLE, VISITPCCSWITCH=ENABLE;
    ```
13. 控制走4G Gx口。

    ```
    //DC1
    SET POLICYMODE: TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=DISABLE, FORCED=Gx;
    //DC2
    SET POLICYMODE: TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=DISABLE, FORCED=Gx;
    ```

## 验证方法

1. 测试终端使用“huawei.com”接入网络。
2. 执行**DSP PCRFSTATUS**命令查询PCRF的连接状态。
   - **预期结果：**PCRF的连接状态正常，Gx 状态=Normal，调测完成。
   - **异常结果：**PCRF的连接状态异常。请执行3。
3. 收集信息并寻求技术支持。
   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 收集归纳所有信息并联系华为技术支持解决。
