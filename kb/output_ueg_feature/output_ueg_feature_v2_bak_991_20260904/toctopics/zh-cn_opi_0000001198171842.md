## 操作场景

风筝L双DC部署，需要参考本页面配置容灾参数。

**说明** 

园区UEG中规划同时部署UDM和PCF实体功能时，本页面不需要重复配置。如已完成配置容灾参数，则此处不需要重复配置。

## 操作步骤

1. 登录“USCDB MML命令”界面。
2. 修改容灾局所有Cluster的主备属性。

   **须知** 

   - 开局时，“主备标识”配置为“ACTIVE”，否则会导致数据库无法配置。
   - 容灾对接时，将容灾局的“ROLE”参数修改为“REDUNDANCY”。此处以DC2为容灾局为例。

   //DC2：

   //取值为“0”时，表示修改所有的Cluster信息。

   ```
   MOD CLUSTER: CID=0, ROLE=REDUNDANCY;
   ```
3. 设置主用局和容灾局之间的数据同步方式。

   DC1和DC2都需要配置。

   1. 执行**LST INSP**命令，确认“REDUNDANCYSWITCH”的软件参数值是否为“0”。

      ```
      LST INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH;
      ```

      - 为“0”，请执行4。
      - 不为“0”，请执行3.b。
   2. 将“REDUNDANCYSWITCH”的值修改为“0”。

      ```
      MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=0, FETYPEN="HSS9860";
      ```
4. 根据实际规划，调整全局数据定时刷新周期。
   1. 执行**LST INSP**命令，确认“GLOBALDATAREFRESHCYCLE”的值是否与规划一致。

      ```
      LST INSP: INSPT=PGW, INSPN=GLOBALDATAREFRESHCYCLE;
      ```

      - 是，配置结束。
      - 否，请执行4.b。
   2. 将“GLOBALDATAREFRESHCYCLE”的值修改为规划值。

      //DC1：

      ```
      MOD INSP: INSPT=PGW, INSPN=GLOBALDATAREFRESHCYCLE, INSPV=0;
      ```

      //DC2：

      ```
      MOD INSP: INSPT=PGW, INSPN=GLOBALDATAREFRESHCYCLE, INSPV=300;
      ```

## 验证方法

1. 在主用局设备上执行**LST CLUSTER**命令，检查是否所有Cluster的“ROLE”值都是“MASTER”。
   - 是，请执行2。
   - 否，请联系华为技术支持工程师。
2. 在容灾局设备上执行**LST CLUSTER**命令，检查是否所有Cluster的“ROLE”值都是“REDUNDANCY”。
   - 是，请执行3。
   - 否，请联系华为技术支持工程师。
3. 在主用局设备上执行**DSP CLUSTER**命令，检查Cluster信息是否正确。

   当主用USCDB和备用USCDB的Cluster数量相等，且Cluster状态正常时，说明Cluster信息正确。

   ```
   DSP CLUSTER:;
   ```
