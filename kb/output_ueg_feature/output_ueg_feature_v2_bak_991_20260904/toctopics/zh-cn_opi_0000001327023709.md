## 操作场景

开局时，配置PCF基础数据。

**说明** 

PCF/PCRF从逻辑上划分为FE（Front End）和BE（Back End）两个业务网元：

- FE（Front End）网元也称为PCF/PCRF网元，实现PCF/PCRF功能实体的功能，包括协议处理、业务处理以及数据管理。
- BE（Back End）网元也称为USCDB网元（Unified Subscriber Center DataBase），实现UDR（Unified Data Repository）功能实体的功能，提供用户数据的增加、删除、更新和查询服务，为FE提供数据存储、数据管理、数据服务等功能支撑。

  PCF/PCRF部署在园区网络时，用户数据的增加、删除和更新通过业务发放系统或在PGW本地（在PGW Web LMT上执行MML批操作文件）进行业务发放。在一个UDR（USCDB）上进行开户，该UDR（USCDB）会将用户数据自动备份到另一个UDR（USCDB）。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 设置FE序号。

   ```
   SET FESN: SN=0;
   ```
3. 增加PCRF实体。

   //DC1：

   ```
   ADD PCRF: PCRFID=1, DN="ucn.3gppnetwork.org", HN="pcrf01.ucn.3gppnetwork.org";
   ```

   //DC2：

   ```
   ADD PCRF: PCRFID=1, DN="ucn.3gppnetwork.org", HN="pcrf02.ucn.3gppnetwork.org";
   ```

   **说明** 

   - 执行本命令后，需要在CSP界面执行**RST POD**命令，重启HLB、DLB、PES和DUS服务。具体重启操作请参考**ADD PCRF**联机帮助。

     刀片式服务器2U不需要部署DUS服务，故不需要重启DUS服务。
   - 执行完重启命令后，可以通过**DSP POD**查询服务是否已经恢复。
4. 配置dbbroker信息，用于微服务和USCDB对接。如采用中心UDM或园区UDM未完成基础数据配置，请执行本步骤；否则请跳转到5。
   1. 检查Location标识是否与规划一致。

      **说明** 

      - 执行**LST LOCATION**命令和**LST DBSLOCATION**命令，检查“Location标识”参数值是否相等，且与规划一致。
      - 主用局PCF/PCRF、主用局USCDB、容灾局PCF/PCRF、容灾局USCDB的Location标识各不相同。

      - 一致，请执行4.c。
      - **LST DBSLOCATION**命令查询结果为空，请执行4.b。
      - 其他查询结果，请联系华为技术支持工程师处理。
   2. 设置DBS Location标识。

      //DC1：

      ```
      SET DBSLOCATION: LOCID=13, CNFM=YES;
      ```

      //DC2：

      ```
      SET DBSLOCATION: LOCID=15, CNFM=YES;
      ```
   3. 设置本端服务ID。

      **说明** 

      参数“PODNAME”，通过以下操作获取：

      1. 在OM Portal界面选择“应用配置>服务治理”，在“应用名称”选项中选择对应FE网元的名称，搜索“UDRDbbroker”服务。
      2. 展开“UDRDbbroker”服务列表，选中“UDRDbbroker”服务实例对应的“属性”列会显示属性信息，属性信息中“podName”对应的值即为POD名称。

      **虚机容器**：

      ```
      ADD DBSSERVICENO: SERVICENO=301, PODNAME="dbb-all-pod13-0";
      ADD DBSSERVICENO: SERVICENO=302, PODNAME="dbb-all-pod13-1";
      ```

      **裸机容器**：

      ```
      ADD DBSSERVICENO: SERVICENO=301, PODNAME="dbb-all-pod13-0";
      ```
   4. 配置网元IP，用于FE与对端BE进行对接。

      //DC1：

      ```
      ADD DBSIPADDR: DBSIPINDEX=1, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.200.200.22", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.200.200.23", IPV4MASK2="255.255.255.255";
      ```

      //DC2：

      ```
      ADD DBSIPADDR: DBSIPINDEX=1, IPVER=IPV4, IP1VPNNAME="VRF_DATA", IPV4IP1="10.201.200.22", IPV4MASK1="255.255.255.255", IP2VPNNAME="VRF_DATA", IPV4IP2="10.201.200.23", IPV4MASK2="255.255.255.255";
      ```
5. 配置HTTP IP，用于和AMF/SMF/PGW-C通信。

   //DC1：

   ```
   ADD HLBDEVADDR: DEVAID=2, VPNNAME="VRF_SBI", IPVER=IPV4, IP="10.200.200.47", HTTPSFUNC=OFF;
   ```

   //DC2：

   ```
   ADD HLBDEVADDR: DEVAID=2, VPNNAME="VRF_SBI", IPVER=IPV4, IP="10.201.200.47", HTTPSFUNC=OFF;
   ```
6. 配置Diameter信令IP，用于和PCEF通信。部署PTT业务时需要配置，其他场景请跳过本步骤。

   //DC1：

   ```
   ADD DLBVPN: VPNINDEX=6, VPNNAME="_public_";
   ADD DLBDEVADDR: DEVAID=6, VPNINDEX=6, IPVER=IPV4, IP="10.200.200.87";
   ```

   //DC2：

   ```
   ADD DLBVPN: VPNINDEX=6, VPNNAME="_public_";
   ADD DLBDEVADDR: DEVAID=6, VPNINDEX=6, IPVER=IPV4, IP="10.201.200.87";
   ```
7. 配置PMS IP，用于配置策略数据。

   //DC1：

   ```
   ADD PMSVPN: VPNINDEX=3, VPNNAME="VRF_OM";
   ADD PMSDEVADDR: DEVAID=3, VPNINDEX=3, IPVER=IPV4, IP="10.200.200.99";
   ```

   //DC2：

   ```
   ADD PMSVPN: VPNINDEX=3, VPNNAME="VRF_OM";
   ADD PMSDEVADDR: DEVAID=3, VPNINDEX=3, IPVER=IPV4, IP="10.201.200.99";
   ```

   **说明**

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**NGPING**命令，查看平面“VRF\_DATA”配置的业务IP是否与外联口IP互通。

   ```
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="ADD DBSIPADDR所定义的业务IP", DSTIPV4ADDR="ADD IFIPV4ADDRESS所定义的外联口IP";
   样例：
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.42", DSTIPV4ADDR="192.168.48.43";
   NGPING: IPTYPE=IPv4, VPNNAME="VRF_DATA", SRCIPV4ADDR="10.200.200.43", DSTIPV4ADDR="192.168.48.43";
   ```

   - 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请联系华为技术支持。
