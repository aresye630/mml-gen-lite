## 操作场景

当需要对园区用户进行二次鉴权时SMF需要和园区RADIUS server对接，可按照本操作指导执行。

以下配置数据以及步骤均以UEG双DC组网场景的配置规划为例进行介绍。

双DC组网场景下，两个DC内的SMF均需要和企业的AAA Server对接。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- 已完成组网路由配置。
- 如果本接口采用IPv6组网，则需要开通逻辑接口支持IPv6特性，即加载对应的License项“81203214 LKV3G5V6LI01 逻辑接口支持IPv6”。
- 已经获取网设LLD文档。

## 操作步骤

1. 配置Gi逻辑接口。

   ```
   //DC1
   ADD CPVPNINST: VPNINSTANCE ="VPN_CN";
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.8.20.1", VPNINSTNAME="VPN_CN", DESC="gi";
   ADD CPLOGICINF: NAME="giif1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="10.8.20.1",IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_CN";
   //DC2
   ADD CPVPNINST: VPNINSTANCE ="VPN_CN";
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.8.20.2", VPNINSTNAME="VPN_CN", DESC="gi";
   ADD CPLOGICINF: NAME="giif1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="10.8.20.2",IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_CN";
   ```
2. 配置鉴权AAA服务器。
   1. 配置AAA服务器组以及服务器的工作模式。

      ```
      //DC1
      ADD RDSSVRGRP:RDSSVRGRPNAME="isprg";
      //DC2
      ADD RDSSVRGRP:RDSSVRGRPNAME="isprg";
      ```
   2. 设置鉴权AAA服务器的IP地址、目的端口号、所属VPN、密钥。

      ```
      //DC1
      ADD RDSSVR: RDSSVRGRPNAME="isprg", SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="10.168.10.1", PORT=1812, CIPHERKEY="ispchina", VPNINSTANCE="VPN_CN", CIPHERKEYCNFM="ispchina";
      //DC2
      ADD RDSSVR: RDSSVRGRPNAME="isprg", SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="10.168.10.2", PORT=1812, CIPHERKEY="ispchina", VPNINSTANCE="VPN_CN", CIPHERKEYCNFM="ispchina";
      ```
   3. 配置APN。

      ```
      //DC1
      MOD CPAPN: APN="huawei.com", HASVPN=ENABLE, VPNINSTANCE="VPN_CN", HASVPNIPV6=DISABLE, RESTORPGWSWITCH=INHERIT, REACWITHDEL=DISABLE;
      //DC2
      MOD CPAPN: APN="huawei.com", HASVPN=ENABLE, VPNINSTANCE="VPN_CN", HASVPNIPV6=DISABLE, RESTORPGWSWITCH=INHERIT, REACWITHDEL=DISABLE;
      ```
   4. **可选：**开启RADIUS Pod功能。

      ```
      //DC1
      SET APNAUTHATTR: APN="huawei.com", DISCONNECT=ENABLE;
      //DC2
      SET APNAUTHATTR: APN="huawei.com", DISCONNECT=ENABLE;
      ```
   5. **可选：**配置APN是否支持增加域名功能（即用户去AAA服务器鉴权时，是否携带域名），以及是否支持剥离域名功能。如果需要同时开启这两个功能，则执行该命令两次。

      ```
      //DC1
      SET APNRADIUSATTR:APN="huawei.com",DOMAINNAMEACT=ADD_DISABLE_STRIP_ENABLE;
      //DC2
      SET APNRADIUSATTR:APN="huawei.com",DOMAINNAMEACT=ADD_DISABLE_STRIP_ENABLE;
      ```
   6. 配置APN下的Client-IP。

      ```
      //DC1
      ADD APNRDSCLIENTIP:APN="huawei.com",AUTHORACCT=AUTHENTICATION,INTFNAME="giif1/0/0";
      //DC2
      ADD APNRDSCLIENTIP:APN="huawei.com",AUTHORACCT=AUTHENTICATION,INTFNAME="giif1/0/0";
      ```
   7. APN实例下绑定RADIUS服务器组。

      ```
      //DC1
      ADD APNRDSSVRGRP:APN="huawei.com",RDSSVRGRPNAME="isprg";
      //DC2
      ADD APNRDSSVRGRP:APN="huawei.com",RDSSVRGRPNAME="isprg";
      ```
3. 配置激活RADIUS分配IP地址功能。

## 验证方法

1. 测试终端使用“huawei.com”接入网络。
2. 执行**DSP PDUSESSION**命令查询用户的PDU会话信息。
   - 预期结果：用户接入成功并创建会话，且“APN或者DNN”与实际规划值一致，调测完成。
   - 非预期结果：用户创建会话失败，或者“APN或者DNN”与实际规划值不一致，请执行3。
3. 查看终端设置的用户名和密码是否正确。
   - 如果测试终端设置的用户名和密码正确，请执行4。
   - 如果测试终端设置的用户名和密码不正确，请重新设置用户名和密码，再执行1。
4. 收集信息并寻求技术支持。
   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 收集归纳所有信息并联系华为技术支持解决。
