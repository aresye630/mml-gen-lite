# 激活用户身份保密性功能（适用于5G）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

新建部署后配置GUTI重分配策略和定时器，或运维阶段需要修改GUTI重分配策略和定时器时，执行本操作。

**说明** 

适用于AMF。

## 必备事项

前提条件

请仔细阅读GWFD-021504 用户身份保密性功能特性概述（适用于5G）。

数据

| 类别           | 参数名称           | 取值样例                   | 获取方法   | 说明   |
|:-------------|:---------------|:-----------------------|:-------|:-----|
| SET NGMMPARA | GUTI重分配定时器（h）  | 1                      | 全网规划   | -    |
| SET NGMMPARA | GUTI重分配        | INIT_REG-1&MOBIL_REG-1 | 全网规划   | -    |
| SET NGMMPARA | GUTI重分配最大间隔（h） | 1                      | 全网规划   | -    |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 配置GUTI重分配策略和定时器。

   **SET NGMMPARA**

## 任务示例

任务描述

配置在初始注册和移动性注册更新时重分配GUTI，GUTI重分配定时器为1小时，且GUTI重分配最大间隔为1小时。

脚本

//配置在初始注册和移动性注册更新时重分配GUTI，GUTI重分配定时器为1小时，且GUTI重分配最大间隔为1小时。

```
SET NGMMPARA: GUTIREALLOC=INIT_REG-1&MOBIL_REG-1, GUTITMR=1, GUTIREALLOCTMR=1;
```
