## 操作场景

本页面用于指导操作员配置HLR（UDM）通过MAP信令与对端网元的对接数据。适用于如下场景：

- HLR（UDM）和SMSC之间通过C接口对接。
- HLR（UDM）和IP-SM-GW之间通过J接口对接。

## 必备事项

前提条件

- 已完成配置UDM基础数据。
- HLR（UDM）和SMSC/IP-SM-GW之间外联口通信正常。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 增加M3UA本地实体。

   ```
   ADD M3LE: LENM="HLR_0", NI=NAT, OPC="111111", LET=AS;
   ```
3. 增加M3UA目的实体。

   ```
   ADD M3DE: DENM="M3DE_MSC3_0", LENM="HLR_0", NI=NAT, DPC="333333", STPF=FALSE, SLSSM=B1111, DET=AS, ADJF=TRUE, RC=0, EXNI=NAT;
   ```
4. 增加M3UA链路集。

   ```
   ADD M3LKS: LSNM="M3LKS_MSC3_0", ADNM="M3DE_MSC3_0", SLSM=B1111, TM=LOADSHARE, WM=IPSP;
   ```
5. 增加M3UA路由。

   ```
   ADD M3RT: RTNM="M3RT_MSC3_0", DENM="M3DE_MSC3_0", LSNM="M3LKS_MSC3_0";
   ```
6. 增加M3UA链路。

   ```
   ADD M3LNK: LNKNM="M3LNK_MSC3_8", IPVER=IPV4, LOCIPV4IP1="10.200.200.98", LOCIPV4IP2="10.200.200.99", LOCPORT=3000, PEERIPV4IP1="172.16.1.94", PEERIPV4IP2="172.17.1.94", PEERPORT=5000, CS=C, LSNM="M3LKS_MSC3_0", QOS=TOS;
   ```

   ```
   ADD M3LNK: LNKNM="M3LNK_MSC3_9", IPVER=IPV4, LOCIPV4IP1="10.200.200.98", LOCIPV4IP2="10.200.200.99", LOCPORT=3001, PEERIPV4IP1="172.16.1.94", PEERIPV4IP2="172.17.1.94", PEERPORT=5000, CS=C, LSNM="M3LKS_MSC3_0", QOS=TOS;
   ```
7. 增加SCCP目的信令点。

   ```
   ADD SCCPDSP: DPNM="SCCPDSP_MSC3_0", NI=NAT, DPC="333333", OPC="111111";
   ```
8. 增加SCCP子系统。
   1. 增加远端子系统。

      ```
      ADD SCCPSSN: SSNNM="SCCPSSN_MSC3_0", NI=NAT, SSN=SCMG, SPC="333333", OPC="111111";
      ADD SCCPSSN: SSNNM="SCCPSSN_MSC3_1", NI=NAT, SSN=HLR, SPC="333333", OPC="111111";
      ```
   2. 增加本地子系统。

      ```
      ADD SCCPSSN: SSNNM="SCCPSSN_HLR_0", NI=NAT, SSN=SCMG, SPC="111111", OPC="111111";
      ADD SCCPSSN: SSNNM="SCCPSSN_HLR_1", NI=NAT, SSN=MSC, SPC="111111", OPC="111111"; 
      ADD SCCPSSN: SSNNM="SCCPSSN_HLR_2", NI=NAT, SSN=HLR, SPC="111111", OPC="111111";
      ```

      **说明** 

      - 直联组网情况下，需要为每个目的信令点增加SCMG子系统。
      - 本地还需要配置MSC子系统和HLR子系统。
      - 远端还需要配置HLR子系统。
9. 增加SCCP全局翻译码。
   1. 增加对端实体的全局翻译码。

      ```
      ADD SCCPGT: GTNM="GT_MSC3_0", NI=NAT, GTI=GT4, TRANTYP="00", ADDR=K'8613901601234, RESULTT=LSPC2, SPC="333333";
      ```
   2. 增加本端实体的全局翻译码。

      ```
      ADD SCCPGT: GTNM="GT_HLR_0", NI=NAT, GTI=GT4, TRANTYP="00", ADDR=K'8613902701234, RESULTT=LSPC2, SPC="111111";
      ```

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行命令**DSP M3LNK**查询链路状态。
3. 在CSP上进行跟踪链路测试消息。
   1. 选择“监控分析 > 消息跟踪 > 任务管理”，在“导航跟踪树”区域框中选择“UDM应用 > M3UA User消息跟踪”，创建消息跟踪。
   2. 在下拉菜单中选择已经存在的BSG模块号。

      查询BSG模块号，可通过**LST MODULE**命令查询。
   3. 在组合框中，选中“SCCP消息”。
   4. 单击“确认”，开始跟踪测试消息。
   5. 根据测试消息判断链路状态。
      - 如果跟踪到本端（或对端）发送的HEARTBEAT消息和对端（或本端）回送的HEARTBEAT ACK消息，说明链路正常。
      - 如果不能观察到正常的消息流，说明链路不正常，请联系华为技术支持工程师。
