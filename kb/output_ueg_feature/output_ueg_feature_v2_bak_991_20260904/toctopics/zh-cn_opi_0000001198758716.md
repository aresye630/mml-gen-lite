# 配置CHR假名化本地策略（通过MML）（AMF/MME/SMF/GW-C）

- 对系统的影响
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

UEG支持通过MML命令设置CHR假名化本地策略。

为保证个人隐私数据的安全性，建议开启该功能。请运营商遵从所在国家的相关法律开启该功能。

## 对系统的影响

用户标识在UEG设备上做加密处理。

## 必备事项

前提条件

请仔细阅读个人隐私数据保护。

数据

无。

## 操作步骤

- 执行MML命令**SET PSEUDONYPOLICY**开启本地CHR假名化功能，并配置假名化口令。假名化口令为密码类型，长度必须为偶数（最小16位，最大30位），且只能输入0-9、A-F、a-f。

  ```
  SET PSEUDONYPOLICY: LOCALPOLICY=ON, KEY="*****";
  ```

  - 当UEG未连接U2020/MAE，或已连接U2020/MAE但U2020/MAE上未进行假名化/匿名化功能设置时，根据UEG上MML命令配置判断是否做假名化处理。
  - 当UEG已连接U2020/MAE，且U2020/MAE上已有假名化/匿名化功能配置时，根据U2020/MAE上配置的假名化/匿名化功能状态判断是否做假名化处理。

## 验证方法

如果用户标识假名化和匿名化功能已开启，则UEG保存的跟踪消息、CHR、日志中不再含有原始的用户标识信息。

如果用户标识假名化和匿名化功能未生效，则UEG保存的跟踪消息、CHR、日志中的用户标识仍是明文。
