## 操作场景

去使能热备容灾功能时（比如进行网元卸载、容灾模式改造等），需要参考本页面进行配置。

**注意** 

- 本页面中的命令均为高危命令，请在华为工程师指导下执行。否则可能导致业务受损。
- 按照本章节操作去使能热备容灾功能后，由于2台UEG的业务IP依然相同，备用UEG重启后，会导致主用UEG无法正常工作。因此必须先规划好备用UEG的目标业务IP，在运行状态为“备用”的UEG上去使能热备容灾功能后，必须将该UEG的业务IP更改成目标业务IP，才能重启备用UEG。

## 操作流程

以上去使能主、备UEG热备容灾功能操作均完成后，需要先规划修改主、备UEG的逻辑接口地址、UE地址池地址段，使主备UEG的逻辑接口地址不同、UE地址池地址段不同，之后整机重启主UEG、备UEG。

**注意：去使能热备容灾功能后，由于2台UEG的逻辑接口地址、UE地址池地址段相同，主、备UEG重启后会发布相同逻辑接口地址路由、UE地址段路由，****导致主、备UEG均无法正常工作。****因此必须先规划修改主、备UEG的目标逻辑接口地址、目标UE地址池地址段，使主备UEG的逻辑接口地址不同、UE地址池地址段不同，之后才能整机重启主、备UEG。**

## 操作步骤

1. 在主用UEG进行去使能操作，进入“MML命令行-UEG”窗口。
2. 去使能热备容灾组。说明：参数“ISAUTOACTIVE”仅25.0及以上的版本支持，低版本不需要配置该参数。

   ```
   SET DRGROUPABLEMENT: DRGROUPABLEMENT=DISABLE, ISAUTOACTIVE=TRUE;
   ```
3. 删除容灾控制通道相关信息。

   ```
   RMV DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="10.10.198.8", PDCIP="10.10.199.8", VPNINSTANCE="VRF_PS_Signal";
   ```
4. 删除容灾组信息。

   ```
   RMV DRGROUPINFO: DRGROUPID=1;
   ```
5. 将监控的服务信息恢复成默认配置。

   ```
   SET DRKEYNF: UPF=NO;
   ```
6. （可选）删除DRDCI仲裁/数据通道对应VPN实例。说明：仅风筝S场景需要删除。

   ```
   RMV VPNINST: VPNINSTANCE="VRF_PS_Signal";
   ```
7. 在备用UEG进行去使能操作，与主用UEG的去使能步骤相同。
8. 规划修改主、备UEG的逻辑接口地址、UE地址池地址段，使主、备UEG的逻辑接口地址不同、UE地址池地址段不同。
9. 整机重启主、备UEG。
