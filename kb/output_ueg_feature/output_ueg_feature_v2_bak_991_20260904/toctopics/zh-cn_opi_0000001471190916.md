# 激活NB-IoT终端标准接入（适用于MME）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本特性支持NB-IoT（NarrowBand Internet of Things）制式终端通过NB-IoT RAN接入MME，实现对NB-IoT终端的移动性管理与会话管理。

**说明** 

适用于MME。

## 必备事项

前提条件

- 请仔细阅读GWFD-026101 NB-IoT终端标准接入特性概述（适用于MME）。
- 已完成激活S-GW/P-GW拓扑选择特性和配置到MSC的数据（SGs接口）。

数据

| 类别         | 参数名称                    | 取值样例    | 获取方法   | 说明                             |
|:-----------|:------------------------|:--------|:-------|:-------------------------------|
| SET DMCMPT | 是否支持NBIoT RAT（NBIOTRAT） | SUPPORT | 全网规划   | 设置Diameter兼容性参数，保证网元间支持信元的兼容性。 |

## 操作步骤

1. 进入“MML命令行-UEG”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. **可选：**配置S6a接口兼容性策略。

   **SET DMCMPT**

   **说明** 

   - 当对端HSS不支持NB-IoT RAT时，则将参数“NBIOTRAT（是否支持NBIoT RAT）”设置为“NOT\_SUPPORT”，此时系统对终端的接入控制将不考虑从HSS获取的签约数据。

## 任务示例

任务描述

假设对端HSS能识别NB-IoT RAT，配置本特性。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2NBPS01", SWITCH=ENABLE;
```

//配置用户为NB-IoT第一档用户。

```
SET LICENSESWITCH: LICITEM="LKV2NBFQ01", SWITCH=ENABLE;
```

//配置用户为NB-IoT第二档用户。

```
SET LICENSESWITCH: LICITEM="LKV2NBFQ02", SWITCH=ENABLE;
```

//配置S6a接口兼容性策略。

```
SET DMCMPT: NBIOTRAT=SUPPORT;
```
