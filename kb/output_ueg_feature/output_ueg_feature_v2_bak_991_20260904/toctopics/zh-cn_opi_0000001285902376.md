# 配置PCF本局数据

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

开局时，配置PCF的本局数据。

**说明** 

如园区部署UDM，则不需要配置该页面。

## 必备事项

前提条件

已完成配置PCF和USCDB对接数据。

数据

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别           | 参数名称                | 取值样例 （DC1）   | 取值样例 （DC2）   | 获取方法     | 说明                                                    |
|:-------------|:--------------------|:-------------|:-------------|:---------|:------------------------------------------------------|
| ADD SYSHLRSN | SYSHLRSN (系统HLR序列号) | 1            | 1            | 已配置数据中获取 | 该参数取值与USCDB MML命令界面上的SET SYSNO命令配置的“SYSTEMNO”参数的取值相同。 |
| ADD SYSHLRSN | HLRNAME（系统HLR名称）    | HLR01        | HLR01        | 本端规划     | 统一规划。                                                 |
| ADD SYSHLRSN | STATUS (状态)         | MASTER       | MASTER       | 固定取值     | -                                                     |

文档

获取网设LLD文档。

## 操作步骤

1. 登录PGW Web LMT MML命令界面。

   此处以完整模式HLR（输入“HLRSN”“用户名”、“登录密码”）登录PGW Web LMT为例，详细操作请参见登录与退出PGW Web LMT。
2. 增加系统序列号。

   ```
   ADD SYSHLRSN: SYSHLRSN=1, HLRNAME="HLR01", STATUS=MASTER;
   ```
