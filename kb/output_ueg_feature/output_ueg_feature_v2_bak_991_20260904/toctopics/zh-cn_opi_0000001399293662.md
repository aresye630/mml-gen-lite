# 配置USCDB和USCDB对接数据

- 操作场景
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

双DC部署，为了提升可靠性，需要USCDB之间实现实时数据同步。因此，开局时，配置DC间的USCDB与USCDB的对接数据。

## 必备事项

前提条件

- 已完成配置USCDB基础数据。
- 已完成配置UDM基础数据。

数据

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

表1中，取值样例（DC1 USCDB）是DC1 USCDB需要配置的数据，取值样例（DC2 USCDB）是DC2 USCDB需要配置的数据。

| 类别            | 参数名称                        | 取值样例 （DC1 USCDB）   | 取值样例 （DC2 USCDB）   | 获取方法     | 说明                                                         |
|:--------------|:----------------------------|:-------------------|:-------------------|:---------|:-----------------------------------------------------------|
| ADD RLOCATION | RLOCID（远端Location标识）        | 16                 | 14                 | 已规划数据中获取 | 表示远端Location标识，在远端“MML-USCDB”下使用LST LOCATION命令查询。          |
| ADD RLOCATION | RMT（远端网元类型）                 | USCDB              | USCDB              | 固定取值     | -                                                          |
| ADD RLOCATION | LP (位置ID优先级值)               | 10                 | 5                  | 本端规划     | 优先级值越小，对接的USCDB的优先级越高。 仅两个UEG间的BE和BE对接，该参数没有意义。            |
| ADD RLOCATION | REDUNFLAG（是否容灾关系）           | Yes                | Yes                | 固定取值     | -                                                          |
| ADD RDSG      | RLOCID（远端Location标识）        | 16                 | 14                 | 已规划数据中获取 | 该参数须在对接的远端USCDB网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。 |
| ADD RDSG      | RDSGMID （远端DSG模块号）          | 1718               | 1718               | 已规划数据中获取 | 在远端“MML-USCDB”下使用“LST MODULE: MT=DSG;”查询。                  |
| ADD RDSG      | RDSGST（远端DSG业务类型）           | HSS9860            | HSS9860            | 本端规划     | 此处以仅配置UDM/HSS为例。                                           |
| ADD RDSG      | RDSGTYPE（远端DSG类型）           | DSG                | DSG                | 固定取值     | -                                                          |
| ADD RIPADDR   | RLOCID（远端Location标识）        | 16                 | 14                 | 已规划数据中获取 | 该参数须在对接的远端USCDB网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。 |
| ADD RIPADDR   | ID（远端DPU模块号/远端IP的VPN索引）     | 1                  | 1                  | 已规划数据中获取 | 该参数须在对接的远端USCDB网元由ADD SRVIPADDR先定义。                        |
| ADD RIPADDR   | IPVER（IP类型）                 | IPV4               | IPV4               | 全网规划     | 本页面以IPv4地址为例。                                              |
| ADD RIPADDR   | IPV4IP1（远端Location IPV4地址1） | 10.201.200.32      | 10.200.200.32      | 全网规划     | 这个地址必须在对接的远端USCDB网元中已经配置完毕。                                |
| ADD RIPADDR   | IPV4IP2（远端Location IPV4地址2） | 10.201.200.33      | 10.200.200.33      | 全网规划     | 这个地址必须在对接的远端USCDB网元中已经配置完毕。                                |
| ADD RIPADDR   | RDPUST（远端IP地址业务类型）          | HSS9860            | HSS9860            | 固定取值     | 通过LOD FEPLUG命令加载UDM/UPCF插件后在此引用。 此处以仅配置UDM/HSS为例。          |

文档

获取网设LLD文档。

## 操作步骤

1. 登录“USCDB MML命令”界面。
2. 增加远端Location信息。

   //DC1：

   ```
   ADD RLOCATION: RLOCID=16, RMT="USCDB", LP=10, REDUNFLAG=Yes;
   ```

   //DC2：

   ```
   ADD RLOCATION: RLOCID=14, RMT="USCDB", LP=5, REDUNFLAG=Yes;
   ```
3. 增加远端DSG。

   //DC1：

   //UDM/HSS：

   ```
   ADD RDSG: RLOCID=16, RDSGMID=17, RDSGST="HSS9860", RDSGTYPE=DSG; 
   ADD RDSG: RLOCID=16, RDSGMID=18, RDSGST="HSS9860", RDSGTYPE=DSG;
   ```

   //DC2：

   //UDM/HSS：

   ```
   ADD RDSG: RLOCID=14, RDSGMID=17, RDSGST="HSS9860", RDSGTYPE=DSG; 
   ADD RDSG: RLOCID=14, RDSGMID=18, RDSGST="HSS9860", RDSGTYPE=DSG;
   ```
4. 增加远端网元IP地址。

   //DC1：

   //UDM/HSS：

   ```
   ADD RIPADDR: RLOCID=16, ID=1, IPVER=IPV4, IPV4IP1="10.201.200.32", IPV4IP2="10.201.200.33", RDPUST="HSS9860";
   ```

   //DC2：

   //UDM/HSS：

   ```
   ADD RIPADDR: RLOCID=14, ID=1, IPVER=IPV4, IPV4IP1="10.200.200.32", IPV4IP2="10.200.200.33", RDPUST="HSS9860";
   ```
5. 登录“USCDB MML命令”界面。执行如下命令，激活IP链路。

   ```
   ACT IPDISP:;
   ```

## 验证方法

1. 登录“USCDB MML命令”界面。
2. 执行**DSP DSGSCTP**命令，查询BE和BE之间链路状态是否正常。
   - 正常，调测结束。
   - 不正常，请联系华为技术支持工程师。
