## 操作场景

PCF/PCRF通过Gx接口（基于Diameter协议）与SMF/PGW-C对接时，请参考本页面进行配置。

N7接口不支持传递PTT业务的策略，因此，部署PTT业务时，需要配置该页面。

## 操作步骤

1. 登录“UEG MML命令”界面。
2. 配置Diameter信令IP，用于和PCEF（基于Diameter协议）通信。如已完成配置PCF基础数据中的和PCEF（基于Diameter协议）互通的Diameter信令IP数据，则不需要重复配置。

   //DC1：

   ```
   ADD DLBVPN: VPNINDEX=6, VPNNAME="_public_";
   ADD DLBDEVADDR: DEVAID=6, VPNINDEX=6, IPVER=IPV4, IP="10.200.200.87";
   ```

   //DC2：

   ```
   ADD DLBVPN: VPNINDEX=6, VPNNAME="_public_";
   ADD DLBDEVADDR: DEVAID=6, VPNINDEX=4, IPVER=IPV4, IP="10.201.200.87";
   ```
3. 增加PCEF实体。

   //DC1：

   ```
   ADD PPCEF: PCRFID=1, PCEFID=71, PN="smf01", PT=DIAMETER, DN="smf01.huawei.com", HN="smf01", LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=ON, DATIME=720, ABILITYDICTID=68;
   ```

   //DC2：

   ```
   ADD PPCEF: PCRFID=1, PCEFID=72, PN="smf02", PT=DIAMETER, DN="smf02.huawei.com", HN="smf02", LSMODE=LOAD_BALANCE, SBMODE=SHARE, DASWITCH=ON, DATIME=720, ABILITYDICTID=68;
   ```
4. 配置Gx链路信息。

   //DC1：

   ```
   ADD PPCEFL: PCRFID=1, PCEFID=71, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=TCP, IPVER=IPV4, LIP="10.200.200.87", LPT=3868, PIP="10.200.200.88", PPT=0, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

   //DC2：

   ```
   ADD PPCEFL: PCRFID=1, PCEFID=72, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=TCP, IPVER=IPV4, LIP="10.201.200.87", LPT=3868, PIP="10.201.200.88", PPT=0, ADSTS=ENABLE, LPTMODE=MultiplePorts;
   ```

## 验证方法

1. 登录“UEG MML命令”界面。
2. 执行**DSP PPCEFL**命令，检查“链路状态”参数项的返回结果。

   - “链路状态”值为“在线” => PCF-PCEF链路正常，PCF-PCEF设备对接调测结束。
   - “链路状态”值不是“在线” => 3。
3. 执行**LST PPCEF**/**LST PPCEFL**，检查数据配置是否与规划一致。
   - 是 => 4。
   - 否 => 修正配置后重新执行2。
4. 请联系华为技术支持处理。
