# 配置全局数据

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成4G/5G全局数据的配置。

**说明** 

- 园区用户在园区UDM（UEG设备）开户时，UDM全局数据建议随用户开户数据一起配置。
- 园区用户在中心UDM开户，园区UDM从中心UDM/外置SFTP服务器同步数据时，UDM全局数据参考本页面配置。

## 操作步骤

1. 重启PGW模块。
   1. 登录“CSP MML命令”界面。
   2. 重启PGW模块。如已重启过PGW模块，请跳过本步骤。

      **说明** 

      重启PGW模块的操作需要在登录PGW Web LMT之前进行，否则PGW Web LMT界面的Service Management MML导航树显示为空。

      ```
      RST MODULE: MID=7, MT=PGW; 
      RST MODULE: MID=8, MT=PGW;
      ```
2. 登录PGW Web LMT MML命令界面。

   此处以完整模式HLR（输入“HLRSN”“用户名”、“登录密码”）登录PGW Web LMT为例，详细操作请参见登录与退出PGW Web LMT。
3. 增加系统HLR。

   ```
   ADD SYSHLRSN: SYSHLRSN=1, HLRNAME="HLR01", STATUS=MASTER;
   ```
4. 增加虚拟HLR。

   ```
   ADD VHLRSN: SYSHLRSN=1, HLRSN=1, HLRNAME="VHLR01";
   ```
5. 登录“UDM业务管理”窗口。
6. 设置CB密码。“GPRSMANAGER”请使用样例值，否则不支持4G用户数据同步功能。

   ```
   SET MAPSERV: CBPASSWD="0000", GPRSMANAGER=NotSupportGPRSManager;
   ```
7. 增加HLR序列号。

   ```
   ADD HLRSN: HLRSN=1, HLRNO="8613910000", STATUS=MASTER, CCODE="86";
   ```
8. 设置UDM业务参数。

   ```
   SET UDMSERV: AUTHENTICATION_TYPE=AUTHENTICATION_TYPE_AUSF;
   ```
9. 配置随机密钥。配置的随机密钥用于对K2值进行加密保存。“SORTCNTXTID”请使用样例值，否则不支持4G用户数据同步功能。

   ```
   SET MAPCONF: SUPPORT_RANDOMKEY=TRUE, SORTCNTXTID=FALSE;
   ```

   ```
   SET RANDOMKEY: KEYID=1;
   SET MAPSERV: DEFKEYID=1;
   ```
10. 配置对KI加密的K2值。

    //K2是用来给KI加密储存的密钥、对K2加密存储的KI值进行解密的密钥。

    ```
    ADD K2: HLRSN=1, K2SNO=100, KEYTYPE=ClearKey, K2VALUE="*****";
    ```

    ```
    SET DEFAULTK2SNO: TYPE=K2, HLRSN=1, K2SNO=100;
    ```
11. 登录“系统管理”界面。

    详细操作请参见登录PGW Web LMT MML命令界面。
12. 增加账号，用于企业访问PGW。

    ```
    ADD OPR: SYSHLRSN=1, OPNAME="pgwuser", DESC="To enterprise", PWD="*****", CFM="*****", UG=OBSERVER, STATUS=ACTIVE, ATP=MAN-MACHINE;
    ```
