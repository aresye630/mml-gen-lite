# 配置模板数据

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

该操作指导工程师在开局阶段，新建UDM网元时，完成4G/5G模板数据的配置。

## 必备事项

前提条件

具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

## 操作步骤

1. 登录“UDM业务管理”窗口。

   - 同步5G用户数据时，请执行2~3。
   - 同步4G用户数据时，请执行4~6。
2. 增加5G QoS模板。

   //5G QoS模板需要与中心UDM保持一致。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", NGQI=1, ARPPRILEVEL=1, PREEMPTIONCAP=FALSE, PREEMPTIONVUL=FALSE,  NGQIPRILEVEL=1;
   ```
3. 增加5G DNN QoS模板。

   //5G DNN QoS模板需要与中心UDM保持一致。不支持5G LAN时：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV6, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, NGCQOSTPLID=1, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```

   //5G DNN QoS模板需要与中心UDM保持一致。支持5G LAN时：

   ```
   ADD DNNQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test", PDUTYPE=IPV4, ALLOWEDPDUTYPE=IPV6&ETHER, SSCMODE=SSC_MODE_1, ALLOWEDSCCMODE=SSC_MODE_2, NGCQOSTPLID=1, AMBRUP=100, UPUNIT=Mbps, AMBRDW=1, DWUNIT=Mbps, CHARGE="1111", UPINTEGR=NOT_NEEDED, UPCONFID=NOT_NEEDED;
   ```
4. 配置EPS QoS模板。

   //EPS QoS模板需要与中心UDM保持一致。此处以配置“AMBRMAXREQBWUL”和“AMBRMAXREQBWDL”为例。

   ```
   ADD EPSQOSTPL: HLRSN=1, TPLID=1, TPLNAME="test_EPS", QOSCLASUID=5, PRILEVEL=1, PREEMPTIONCAP=DISABLE, PREEMPTIONVUL=DISABLE, AMBRMAXREQBWUL=10000, AMBRMAXREQBWDL=200000;
   ```
5. 配置4G APN模板。

   //APN模板需要与中心UDM保持一致。

   ```
   ADD APNTPL: HLRSN=1, TPLID=1, APN="APN1", PDNGWALLOCTYPE=STATIC, MIPHAHOST="PDN-GW", MIPHAREALM="huawei.com", MIPHAADDRIPV4="10.144.98.135", MIPHAADDRIPV6="FC00:0:0:0:10:144:98:135", NONIPDATADELMECH=SGi_BASED_DATA_DELIVERY;
   ```

   ```
   ADD APNTPL: HLRSN=1, TPLID=1, APN="APN1", PDNGWALLOCTYPE=DYNAMIC, APNOI="huawei.com", NONIPDATADELMECH=SGi_BASED_DATA_DELIVERY;
   ```
6. 配置APN运营商标识符模板。

   //APN运营商标识符模板需要与中心UDM保持一致。

   ```
   ADD APNOITPL: HLRSN=1, TPLID=1, TPLNAME="test_apnoi", APNOI="huawei.com";
   ```
