# 配置动态带宽管理规则

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当APP通过Mp1接口/管理面MEPM通过Mm5接口下发动态带宽管理规则，用于管理访问APP的上下行带宽时，需要配置本页面，将动态带宽管理规则激活生效。

**说明** 

适用于MPF。

## 必备事项

前提条件

- 请仔细阅读带宽管理规则的获取和执行和增/删/改/查动态带宽管理规则。
- 已完成配置Mp1接口数据。
- 已完成加载License。

数据

| 类别                 | 参数名称                      | 取值样例                 | 获取方法   | 说明                                                                                                                                                                                                                                           |
|:-------------------|:--------------------------|:---------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SET DNSLITEPARA    | 轻量DNS规则匹配开关（DNSLMATCHSW）  | ENABLE               | 本端规划   | 本参数配置为“ENABLE”后，表示开启DNS Rule开关，支持DNS Rule匹配功能。动态DNS Rule和静态DNS Rule均支持。                                                                                                                                                                      |
| SET DNSLITEPARA    | 轻量DNS策略执行开关（DNSLPOLICYSW） | ENABLE               | 本端规划   | 本参数配置为“ENABLE”后，如果DNS Rule匹配成功，则支持UE发起DNS查询并响应。                                                                                                                                                                                              |
| SET APPTRAFFICPARA | 应用流量规则开关（TRAFFICRULESW）   | ENABLE               | 本端规划   | 打开应用流量规则开关。                                                                                                                                                                                                                                  |
| SET APPTRAFFICPARA | 规则来源（RULESOURCE）          | DYNAMIC_TRAFFIC_RULE | 本端规划   | 当“规则来源”设置为“DYNAMIC_TRAFFIC_RULE”，表示使用动态Traffic Rule进行规则匹配，携带IP地址的数据报文命中动态Traffic Rule进行本地分流。当“规则来源”设置为“DNS_RULE_EXTENDED”，表示使用DNS Rule衍生的IP地址匹配，携带IP地址的数据报文命中DNS Rule的IP地址进行本地分流。  说明： 基于动态Traffic Rule的分流功能和DNS Rule衍生的基于目的IP的本地分流功能不能同时生效。 |
| SET APPPOLICYPARA  | 应用带宽策略开关（BWALLOCATION）    | ENABLE               | 本端规划   | 配置为“ENABLE”后，支持基于动态分流的带宽控制功能。                                                                                                                                                                                                                |
| ADD QOSCARBURST    | Qos-Car速率（千比特/秒）（RATE）    | 128                  | 本端规划   | 指定速率，该参数一般由运营商规划给出。                                                                                                                                                                                                                          |
| ADD QOSCARBURST    | 突发尺寸类型（BURSTTYPE）         | Auto_Calculate       | 本端规划   | 指定流量的突发尺寸的计算类型。                                                                                                                                                                                                                              |
| ADD QOSCARBURST    | 自动计算时长（毫秒）（DURATION）      | 1000                 | 本端规划   | 配置duration-milliseconds，表示突发尺寸为流量的速率与duration-milliseconds的乘积。                                                                                                                                                                               |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
2. 配置使能动态DNS Rule进行业务匹配。

   **SET DNSLITEPARA**
3. 配置使能动态Traffic Rule进行业务匹配。

   **SET APPTRAFFICPARA**
4. 打开带宽管理策略开关，根据命中的Traffic Rule查找相同appName的带宽管理规则。

   **SET APPPOLICYPARA**
5. 配置用户做car的参数。

   ****ADD QOSCARBURST****

## 任务示例

任务描述

打开带宽管理策略开关，支持动态带宽管理功能。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5BWMF01",SWITCH=ENABLE;
```

//配置使能动态DNS Rule和动态Traffic Rule的报文匹配。

```
SET DNSLITEPARA: DNSLMATCHSW=ENABLE, DNSLPOLICYSW=ENABLE;
SET APPTRAFFICPARA: TRAFFICRULESW=ENABLE, RULESOURCE=DYNAMIC_TRAFFIC_RULE;
```

//配置支持基于动态分流的带宽控制功能。

```
SET APPPOLICYPARA: BWALLOCATION=ENABLE;
```

//配置用户做car的参数。

```
ADD QOSCARBURST:RATE=128,BURSTTYPE=Auto_Calculate,DURATION=1000;
```
