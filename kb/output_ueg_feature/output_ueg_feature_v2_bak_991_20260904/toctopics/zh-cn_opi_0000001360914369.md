# 更新GaussDB数据库弱口令字典

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

在日常维护中，系统管理员需要在弱口令字典中添加/删除弱口令。

## 对系统的影响

修改数据库用户密码时，会对新密码进行是否是弱口令的校验；如果新密码为弱口令，会修改密码失败。

## 必备事项

前提条件

已登录OM Portal。

数据

已准备待更新的新弱口令。

**说明** 

单个弱口令长度不能超过32字符。

## 操作步骤

1. 按照a到d操作，分别进入到主GaussDB服务和备GaussDB服务所在的容器内。

   1. 登录OM Portal，选择“应用配置>服务治理”，展开GaussDB服务列表，光标移动至“属性”列。“status”为“M”的服务为**主GaussDB服务**，“status”为“S”的服务为**备GaussDB服务**，记录该服务实例中的“nodeID”，如图1。

      **图1** 主GaussDB服务实例“属性”信息

      **说明** 

      IPv4场景下，“nodeID”的值即为**GaussDB服务所在的主用节点IP**。

      IPv6场景下，将“nodeID”的值中“-”替换为“:”后为**GaussDB服务所在的主用节点IP**。
   2. Windows操作系统使用mtuser用户通过Putty工具登录GaussDB服务所在的主用节点IP，Linux操作系统通过终端模拟器登录GaussDB服务所在的主用节点IP，执行**su root**切换至root用户。
   3. 通过**which docker**检查容器引擎类型，并进入GaussDB容器。
      - 如果存在docker可执行文件，如下命令所示。

        ```
        dfp07-csp-a-0:/home/mtuser # which docker
        /usr/bin/docker
        ```

        执行**docker ps|grep cspgaussdb**获取GaussDB dockerId。

        执行**docker exec -it -u paas *dockerId* bash**进入GaussDB容器。
      - 如果没有找到docker可执行文件，如下命令所示。

        ```
        inipv6-csp-a-0:/home/mtuser # which docker
        which: no docker in (/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin)
        ```

        执行**crictl ps |grep cspgaussdb**获取GaussDB containerdID。

        ```
        inipv6-csp-a-0:/home/mtuser # crictl ps |grep cspgaussdb
        d7706d396a48a       registry.fusionstage.local:20202/csp/cspgaussdb_docker:23.0.0.B159                About an hour ago    Running             gauss-softwarecomp              0                   6c60ce978ec69
        ```

        执行**crictl exec -it *containerdID* bash**进入GaussDB容器。
   4. 按照b、c步骤，登录备节点后执行相同的操作。
2. 在主备GaussDB服务容器内都执行如下命令：

   ```
   [paas@gaussdb-e1d23b62-0 /]# cd /opt/host/gaussdb/bin/gaussServer/install/
   ```
3. 执行a添加弱口令，或执行b删除弱口令。

   1. 调用weak\_password.sh脚本，添加弱口令到字典中，具体命令如下：

      ```
      [paas@gaussdb-e1d23b62-0 install]# sh weak_password.sh -a 2 'Test@123!' 'Test@456'
      ```

      **说明** 

      参数说明：

      - -a，添加弱密码口令操作。
      - 2，需要添加的弱口令个数。
      - 弱口令必须写在单引号中， 如：'Test@123!' 'Test@456' 。

      - 若操作界面出现“Add weak passwords to dictionary success.”表明添加弱口令到弱口令字典中成功。
      - 若操作界面出现“Add weak passwords to dictionary failed.”表明添加弱口令到弱口令字典中失败，需要重新执行该脚本并保证输入参数的正确性。
   2. 调用weak\_password.sh脚本，从弱口令字典中删除，具体命令如下：

      ```
      [paas@gaussdb-e1d23b62-0 install]# sh weak_password.sh -d 2 'Test@123!' 'Test@456'
      ```

      **说明** 

      参数说明：

      - -d，删除弱密码口令操作。
      - 2，需要删除的弱口令个数。
      - 弱口令必须写在单引号中， 如：'Test@123!' 'Test@456' 。
      - 若弱口令字典中不包含要删除的弱口令，执行删除操作直接返回成功。
      - 添加弱口令操作和删除弱口令操作不能并发执行。

      - 若操作界面出现“Del weak passwords from dictionary success.”表明在弱口令字典中删除弱口令成功。
      - 若操作界面出现“Del weak passwords from dictionary failed.”表明在弱口令字典中删除弱口令失败，需要重新执行该脚本并保证输入参数的正确性。
