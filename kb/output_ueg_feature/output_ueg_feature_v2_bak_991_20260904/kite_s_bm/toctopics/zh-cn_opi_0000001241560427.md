## 操作场景

UEG部署在园区，作为企业专用主锚点UPF。

N3/N4/N9使用SR-IOV bonding组网（Eth-trunk接口），直连DCGW时，一个Eth-trunk接口的成员端口连接到DCGW1和DCGW2；直连PE时，一个Eth-trunk接口的成员端口必须连接到同一个PE设备；UEG与LocalDN使用非SR-IOV bonding组网（以太网接口），物理接口分别与两个PE/两个DCGW连接。

UEG通过BGP over静态路由+BFD与对端网元实现网络互通。

- 直连DCGW时，UEG与gNodeB之间的组网示意如图1所示，UEG与SMF之间的组网与图1类似。
- 直连PE时，UEG与gNodeB之间的组网示意如图2所示，UEG与SMF之间的组网与图2类似。
- 直连DCGW/PE时，UEG与企业园区服务器之间的组网示意如图3所示。

**说明** 

- 直连DCGW时，推荐使用BGP over静态路由+BFD与对端实现网络互通。
- 直连PE时，UEG支持：
  - 通过BGP over静态路由+BFD与企业园区服务器之间实现网络互通。
  - 通过静态路由+BFD与对端网元（gNodeB/SMF/园区服务器）实现网络互通。采用静态路由+BFD时：
    - UEG上不需要配置BGP相关数据。
    - 在直连三层设备上配置到UEG的逻辑接口IP&UE IP的路由，下一跳是UEG的外联口IP。
  - 直连PE时，UEG支持通过OSPF动态路由与园区服务器实现网络互通。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。
- VNF与网络实体之间的网络环境已经构建完成（连线要求请参见外联口介绍(刀片式服务器2U)）。

数据

**说明**

## 操作步骤

1. 配置基础数据。

   配置基础数据包括：修改网元浮动IP、修改公共参数等。详细配置与组网无关，具体请参见《参考：详细配置指导 > 配置基础数据》章节。
2. 激活全局BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 激活全局BGP。

   ```
   SET BGP: BGPENABLE=TRUE, ASNUM="60001";
   ```
4. 直连DCGW时，配置UPF（UEG）到无线侧(R)AN（gNodeB）的IP路由数据。直连PE时，请跳过本步骤。
   1. 配置VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_Access";
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv4uni, VRFRD="192.168.225.135:100";
      ```

      ```
      ADD VPNINSTAF:VRFNAME="VRF_Access",AFTYPE=ipv6uni, VRFRD="192.168.225.135:100";
      ```

      **说明** 

      步骤4.b~步骤4.f是BGP相关数据，采用BGP over静态路由+BFD时需要配置。采用静态路由+BFD时不需要配置。
   2. 配置Loopback接口IP。用于建立BGP邻居。

      ```
      ADD INTERFACE:IFNAME="LoopBack5";
      ADD IPBINDVPN:IFNAME="LoopBack5",VRFNAME="VRF_Access";
      ADD IFIPV4ADDRESS:IFNAME="LoopBack5",IFIPADDR="192.168.225.135",SUBNETMASK="255.255.255.255",ADDRTYPE=main;
      ```

      ```
      SET IFIPV6ENABLE: IFNAME="Loopback5", ENABLEFLAG=TRUE;
      ADD IFIPV6ADDRESS:IFNAME="Loopback5",IPV6ADDRESS="FC00::225:135",PREFIXLEN=128;
      ```
   3. 配置BGP VPN实例。

      ```
      ADD BGPVRF: VRFNAME="VRF_Access", DEFAULTAFTYPE=noaf, ROUTERID="192.168.225.135";
      ```
   4. 增加BGP VPN实例地址族。

      //UEG对接2个负荷分担的BGP PEER，“MAXIMUMLOADBALANCE”设置为“2”。

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni, MAXIMUMLOADBALANCE=2;
      ```

      ```
      ADD BGPVRFAF: VRFNAME="VRF_Access", AFTYPE=ipv6uni, MAXIMUMLOADBALANCE=2;
      ```
   5. 配置BGP对等体。此处以对接IPv4v6双栈的BGP对等体为例。

      //直连DCGW时，UEG对接2个负荷分担的BGP PEER。

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.79.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv4, PEERADDR="192.168.78.5", REMOTEAS="60002", LOCALIFADDR="192.168.225.135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```

      ```
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::79:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ADD BGPPEER: VRFNAME="VRF_Access", ADDRESSTYPE=ipv6, PEERADDRV6="FC00::78:5", REMOTEAS="60002", LOCALIFADDR="FC00::225:135", LOCALIFNAME="Loopback5", EBGPMAXHOP=10;
      ```
   6. 配置BGP引入wlr路由。

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv4uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```

      ```
      ADD IMPORTROUTE: VRFNAME="VRF_Access", AFTYPE=ipv6uni, IMPORTPROTOCOL=wlr, MEDENABLE=FALSE;
      ```
   7. 配置外联口IP地址。

      1. 查询接口名，确认可使用的外联口的接口类型和接口编号。

         ```
         LST INTERFACE:;
         ```
      2. 配置主接口的管理状态为up。将网设规划的接口的管理状态设置为up。

         ```
         MOD INTERFACE:IFNAME="Ethernet64/0/4",IFADMINSTATUS=up;
         MOD INTERFACE:IFNAME="Ethernet64/0/5",IFADMINSTATUS=up;
         ```

         ```
         MOD INTERFACE:IFNAME="Ethernet64/0/12",IFADMINSTATUS=up;
         MOD INTERFACE:IFNAME="Ethernet64/0/13",IFADMINSTATUS=up;
         ```
      3. 添加Eth-trunk接口及Eth-trunk子接口。成员端口数量以网设规划的为准。

         ```
         ADD INTERFACE:IFNAME="Eth-trunk1";
         MOD TRUNKIF:IFNAME="Eth-Trunk1",WORKMODE=Manual;
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/4";
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk1",MEMBERIFNAME="Ethernet64/0/5";
         ADD INTERFACE:IFNAME="Eth-trunk1.1";
         ```

         ```
         ADD INTERFACE:IFNAME="Eth-trunk2";
         MOD TRUNKIF:IFNAME="Eth-Trunk2",WORKMODE=Manual;
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/12";
         ADD TRUNKMEMBER:TRUNKIFNAME="Eth-trunk2",MEMBERIFNAME="Ethernet64/0/13";
         ADD INTERFACE:IFNAME="Eth-trunk2.1";
         ```
      4. 增加接口绑定VPN。

         ```
         ADD IPBINDVPN:IFNAME="Eth-trunk1.1",VRFNAME="VRF_Access";
         ```

         ```
         ADD IPBINDVPN:IFNAME="Eth-trunk2.1",VRFNAME="VRF_Access";
         ```
      5. 在以太网子接口上关联VLAN ID。

         ```
         ADD ETHSUBIF:IFNAME="Eth-trunk1.1",VLANTYPEVID=2005;
         ```

         ```
         ADD ETHSUBIF:IFNAME="Eth-trunk2.1",VLANTYPEVID=2015;
         ```
      6. 配置IPv6使能。

         ```
         SET IFIPV6ENABLE: IFNAME="Eth-trunk1.1", ENABLEFLAG=TRUE;
         ```

         ```
         SET IFIPV6ENABLE: IFNAME="Eth-trunk2.1", ENABLEFLAG=TRUE;
         ```
      7. 配置外联口IP地址。

         ```
         ADD IFIPV4ADDRESS:IFNAME="Eth-trunk1.1",IFIPADDR="192.168.85.2",SUBNETMASK="255.255.255.248";
         ```

         ```
         ADD IFIPV6ADDRESS:IFNAME="Eth-trunk1.1",IPV6ADDRESS="FC00::85:2",PREFIXLEN=125;
         ```

         ```
         ADD IFIPV4ADDRESS:IFNAME="Eth-trunk2.1",IFIPADDR="192.168.185.2",SUBNETMASK="255.255.255.248";
         ```

         ```
         ADD IFIPV6ADDRESS:IFNAME="Eth-trunk2.1",IPV6ADDRESS="FC00::185:2",PREFIXLEN=125;
         ```
   8. 采用BGP over静态路由+BFD或采用静态路由+BFD时，新建BFD会话。

      //配置BFD单臂echo探测。

      ```
      ADD BFDSESSION: SESSNAME="BfdName851_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.85.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_Access",MINECHORXINT=500,LOCALDISCR=8541,IFNAME="Eth-trunk1.1";
      ```

      ```
      ADD BFDSESSION: SESSNAME="BfdName851_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_Access",LOCALDISCR=8561,IFNAME="Eth-trunk1.1",DESTADDR6="FC00::85:1";
      ```

      ```
      ADD BFDSESSION: SESSNAME="BfdName1851_v4",ADDRTYPE=IPv4,CREATETYPE4=SESS_STATIC,ONEARMECHO=TRUE,DESTADDR4="192.168.185.1",LINKTYPE=IP,DETECTMULTI=4,VRFNAME="VRF_Access",MINECHORXINT=500,LOCALDISCR=8543,IFNAME="Eth-trunk2.1";
      ```

      ```
      ADD BFDSESSION: SESSNAME="BfdName1851_v6",ADDRTYPE=IPv6,CREATETYPE6=SESS_STATIC,ONEARMECHO6=TRUE,LINKTYPE=IP,DETECTMULTI=4,MINECHORXINT=500,VRFNAME="VRF_Access",LOCALDISCR=8563,IFNAME="Eth-trunk2.1",DESTADDR6="FC00::185:1";
      ```
   9. 采用静态路由+BFD时，配置静态路由并绑定BFD会话。采用BGP over静态路由+BFD时，请跳过该步骤。

      //“PREFIX”/“MASKLENGTH”是基站的IP地址及所在网段掩码长度，请根据网设文档替换。

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="192.168.85.1",SESSIONNAME="BfdName851_v4";
      ```

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="FC00::85:1",SESSIONNAME="BfdName851_v6";
      ```

      ```
      ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="x.x.x.x",MASKLENGTH=32,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk2.1",NEXTHOP="192.168.185.1",SESSIONNAME="BfdName1851_v4";
      ```

      ```
      ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00:x::x",MASKLENGTH=128,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk2.1",NEXTHOP="FC00::185:1",SESSIONNAME="BfdName1851_v6";
      ```
   10. 采用BGP over静态路由+BFD时，配置静态路由并绑定BFD会话。采用静态路由+BFD时，请跳过该步骤。

       //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.5",MASKLENGTH=32,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="192.168.85.1",SESSIONNAME="BfdName851_v4";
       ```

       ```
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="192.168.79.5",MASKLENGTH=32,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk2.1",NEXTHOP="192.168.185.1",SESSIONNAME="BfdName1851_v4";
       ```

       //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX”设置为“0.0.0.0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

       ```
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="192.168.85.1",SESSIONNAME="BfdName851_v4";
       ```

       ```
       ADD SRROUTE:AFTYPE=ipv4unicast,PREFIX="0.0.0.0",MASKLENGTH=0,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk2.1",NEXTHOP="192.168.185.1",SESSIONNAME="BfdName1851_v4";
       ```

       //“PREFIX”和“MASKLENGTH”是目的IP和掩码（BGP对等体的IP地址和掩码）。

       ```
       ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00::79:5",MASKLENGTH=128,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="FC00::85:1",SESSIONNAME="BfdName851_v6";
       ```

       ```
       ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="FC00::79:5",MASKLENGTH=128,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk2.1",NEXTHOP="FC00::185:1",SESSIONNAME="BfdName1851_v6";
       ```

       //对端网元不发布BGP默认路由时，需要配置该步骤。“PREFIX”设置为“0:0:0:0:0:0:0:0”，“MASKLENGTH”设置为“0”。其他参数与到BGP对等体的路由相同。

       ```
       ADD SRROUTE6:AFTYPE=ipv6unicast,PREFIX="0:0:0:0:0:0:0:0",MASKLENGTH=0,VRFNAME="VRF_Access",DESTVRFNAME="VRF_Access",IFNAME="Eth-trunk1.1",NEXTHOP="FC00::85:1",SESSIONNAME="BfdName851_v6";
       ```
