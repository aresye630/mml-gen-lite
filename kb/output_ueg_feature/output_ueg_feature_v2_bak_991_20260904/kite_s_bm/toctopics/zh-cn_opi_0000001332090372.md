# 更新GaussDB数据库弱口令字典

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤

## 操作场景

在日常维护中，系统管理员需要在弱口令字典中添加/删除弱口令，避免在修改数据库密码时使用弱密码，提高数据库安全。

## 对系统的影响

修改数据库用户密码时，会对新密码进行是否是弱口令的校验；如果新密码为弱口令，会修改密码失败。

## 必备事项

前提条件

已登录OM Portal。

数据

已准备待更新的新弱口令。

**说明** 

单个弱口令长度不超过32个字符。

## 操作步骤

1. 登录OM Portal，选择“应用配置>服务治理”，展开GaussDB服务列表，光标移动至“属性”列。“status”为“M”的服务为主GaussDB服务，记录该服务实例中的“nodeID”，如图1。

   **图1** 主GaussDB服务实例“属性”信息

   **说明** 

   IPv4场景下，将“nodeID”的值去掉"paas-"，其余“-”替换为“.”后为**GaussDB服务所在的主用节点IP**。

   IPv6场景下，将“nodeID”的值去掉"paas-"，其余“-”替换为“:”后为**GaussDB服务所在的主用节点IP**。
2. Windows操作系统通过“putty.exe”工具，Linux操作系统通过终端模拟器登录系统，执行**su root**切换至root用户。
3. 执行**ssh mtuser@<****GaussDB服务所在的主用节点IP****>**登录GaussDB服务所在的主用节点，执行**su root**切换至root用户，执行**docker ps | grep <GaussDB服务实例名称>** 获取GaussDB容器的容器ID，“bdb2fde54106”代表获取的容器ID。

   ```
   [mtuser@host-192-168-0-2 ~]$ su
   Password:
   host-192-168-0-2:/home/mtuser # docker ps |grep gauss
   bdb2fde54106        192.168.0.1:20202/op_svc_pom/cspgaussdb_docker:20.4.1.B114                 "/bin/c-init -v /opt…"   29 hours ago        Up 29 hours                             k8s_gauss-softwarecomp_gaussdb-61e05a60-0_fst-manage_6983e930-6f7b-47ca-840c-44ce2a4666a4_0
   35b191baa417        cfe-pause-arm64:2.11.25                                                    "/pause"                 29 hours ago        Up 29 hours                             k8s_POD_gaussdb-61e05a60-0_fst-manage_6983e930-6f7b-47ca-840c-44ce2a4666a4_0
   ```
4. 执行**docker exec -it -u paas <容器ID> bash**命令进入容器。

   ```
   host-192-168-0-2:/home/mtuser # docker exec -it -u paas bdb2fde54106 bash
   [root@gaussdb-630686a7-1 /]#
   ```
5. 执行如下命令，切换到“/opt/host/gaussdb/bin/gaussServer/install/”目录。

   ```
   [paas@gaussdb-630686a7-1 install]$ cd /opt/host/gaussdb/bin/gaussServer/install
   ```
6. 执行a添加弱口令，或执行b删除弱口令。

   1. 调用weak\_password.sh脚本，添加弱口令到字典中，具体命令如下：

      ```
      [paas@gaussdb-e1d23b62-0 install]# sh weak_password.sh -a 2 'Test@123!' 'Test@456'
      ```

      **说明** 

      参数说明：

      - -a，添加弱密码口令操作。
      - 2，需要添加的弱口令个数。
      - 弱口令必须写在单引号中， 如：'Test@123!' 'Test@456' 。

      - 若操作界面出现“Add weak passwords to dictionary success.”表明添加弱口令到弱口令字典中成功。
      - 若操作界面出现“Add weak passwords to dictionary failed.”表明添加弱口令到弱口令字典中失败，需要重新执行该脚本并保证输入参数的正确性。
   2. 调用weak\_password.sh脚本，从弱口令字典中删除，具体命令如下：

      ```
      [paas@gaussdb-e1d23b62-0 install]# sh weak_password.sh -d 2 'Test@123!' 'Test@456'
      ```

      **说明** 

      参数说明：

      - -d，删除弱密码口令操作。
      - 2，需要删除的弱口令个数。
      - 弱口令必须写在单引号中， 如：'Test@123!' 'Test@456' 。
      - 若弱口令字典中不包含要删除的弱口令，执行删除操作直接返回成功。
      - 添加弱口令操作和删除弱口令操作不能并发执行。

      - 若操作界面出现“Del weak passwords from dictionary success.”表明在弱口令字典中删除弱口令成功。
      - 若操作界面出现“Del weak passwords from dictionary failed.”表明在弱口令字典中删除弱口令失败，需要重新执行该脚本并保证输入参数的正确性。
7. 在备机执行弱口令添加/删除操作。

   登录OM Portal，选择“应用配置 > 服务治理”，展开GaussDB服务列表，光标移动至“属性”列。“status”为“S”的服务为备GaussDB服务，记录该服务实例中的“nodeID”，重新执行步骤2到步骤6。
