## 操作场景

VNF与对端设备可通过静态路由绑定静态BFD探测的方式进行组网连接。在网络拓扑结构比较简单时，通常使用静态路由方式组网，合理的静态路由可以改进网络性能，并为业务保证带宽。同时，利用BFD双向/单臂echo转发检测机制为链路提供双向/单向、轻负荷且持续时间短的快速检测功能，提高链路可靠性。

- 图1为VNF与周边网元的静态路由互通组网示意图。VNF与网关侧运行静态路由协议而接入运营商网络（IP骨干网），网关推荐使用DC-GW，也可以使用运营商的PE（Provider Edge）交换机，或者EOR（End of Row）交换机。无论哪种方式，VNF的配置相同，没有差异。PE的路由配置请参考运营商的网络规划配置，DC-GW/EOR的配置请参考对应型号设备的产品文档。
- 图2为VNF与周边网元的静态路由互通组网示意图。VNF与网关侧运行静态路由协议而接入运营商网络（IP骨干网），DC-GW作为网关设备。VNF和DC-GW之间采用单臂BFD探测。DC-GW的配置请参考对应型号设备的产品文档。

## 必备事项

前提条件

- 请阅读并熟悉特性IPFD-014003 静态路由和IPFD-012003 BFD特性概述。

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- VNF与网络实体之间的网络环境已经构建完成。

数据

VNF使用静态路由绑定静态BFD检测功能与对端设备建立可靠的IP连接。

- 在VNF上配置静态路由与对端建立链路。
- 在VNF上配置静态BFD功能增强链路检测可靠性。
- 在VNF上推荐采用子接口的外联口与外部网络对接。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VPN_Access";
   ADD VPNINSTAF:VRFNAME="VPN_Access",AFTYPE=ipv4uni;
   ```

   **说明** 

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、网关上的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 配置外联口IP地址。

   1. 查询接口名，确认CSLB上可使用的外联口的接口类型和接口编号。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet66/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/5",IFADMINSTATUS=up;
      ```
   3. 配置以太网子接口。

      ```
      ADD INTERFACE:IFNAME="Ethernet66/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/5.1";
      ```
   4. 增加接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Ethernet66/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/5.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/5.1",VRFNAME="VPN_Access";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Ethernet66/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/5.1",VLANTYPEVID=200;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/4.1",VLANTYPEVID=100;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/5.1",VLANTYPEVID=200;
      ```

      **说明** 

      子接口配置了VLAN，则需要在交换机、对接网关上调整VLAN的配置。
   6. 配置外联口IP通过DHCP动态获取。静态配置外联口IP地址时，请跳过该步骤。

      ```
      ADD DHCPCLIENT: IFNAME="Ethernet66/0/4.1", ISDHCPV4CENABLE=TRUE;
      ADD DHCPCLIENT: IFNAME="Ethernet66/0/5.1", ISDHCPV4CENABLE=TRUE;
      ADD DHCPCLIENT: IFNAME="Ethernet67/0/4.1", ISDHCPV4CENABLE=TRUE;
      ADD DHCPCLIENT: IFNAME="Ethernet67/0/5.1", ISDHCPV4CENABLE=TRUE;
      ```
   7. 配置外联口IP地址。DHCP获取外联口IP地址时，请跳过该步骤。

      ```
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/4.1",IFIPADDR="192.168.89.2",SUBNETMASK="255.255.255.248";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet66/0/5.1",IFIPADDR="192.168.89.10",SUBNETMASK="255.255.255.248";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet67/0/4.1",IFIPADDR="192.168.89.3",SUBNETMASK="255.255.255.248";
      ADD IFIPV4ADDRESS:IFNAME="Ethernet67/0/5.1",IFIPADDR="192.168.89.11",SUBNETMASK="255.255.255.248";
      ```

      **说明** 

      如果规划外联口使用IPv4v6双栈地址，则分别执行**ADD IFIPV4ADDRESS**和**ADD IFIPV6ADDRESS**对同一vNIC配置IPv4和IPv6地址。
3. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
4. 新建BFD会话。

   **说明** 

   必须全局使能BFD功能后该命令才可生效。

   //双向BFD：

   ```

   ADD BFDSESSION: SESSNAME="BfdName22", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=FALSE, DESTADDR4="192.168.89.9", LINKTYPE=IP, MINTXINT=500, MINRXINT=500, DETECTMULTI=4, VRFNAME="VPN_Access", LOCALDISCR=122, REMOTEDISCR=222, IFNAME="Ethernet66/0/5.1";
   ADD BFDSESSION: SESSNAME="BfdName23", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=FALSE, DESTADDR4="192.168.89.1", LINKTYPE=IP, MINTXINT=500, MINRXINT=500, DETECTMULTI=4, VRFNAME="VPN_Access", LOCALDISCR=123, REMOTEDISCR=223, IFNAME="Ethernet67/0/4.1";
   ADD BFDSESSION: SESSNAME="BfdName24", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=FALSE, DESTADDR4="192.168.89.9", LINKTYPE=IP, MINTXINT=500, MINRXINT=500, DETECTMULTI=4, VRFNAME="VPN_Access", LOCALDISCR=124, REMOTEDISCR=224, IFNAME="Ethernet67/0/5.1";
   ```

   //单臂BFD（BFD echo）：

   ```

   ADD BFDSESSION: SESSNAME="BfdName22", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.89.9", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VPN_Access", MINECHORXINT=500, LOCALDISCR=122, IFNAME="Ethernet66/0/5.1";
   ADD BFDSESSION: SESSNAME="BfdName23", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.89.1", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VPN_Access", MINECHORXINT=500, LOCALDISCR=123, IFNAME="Ethernet67/0/4.1";
   ADD BFDSESSION: SESSNAME="BfdName24", ADDRTYPE=IPv4, CREATETYPE4=SESS_STATIC, ONEARMECHO=TRUE, DESTADDR4="192.168.89.9", LINKTYPE=IP, DETECTMULTI=4, VRFNAME="VPN_Access", MINECHORXINT=500, LOCALDISCR=124, IFNAME="Ethernet67/0/5.1";
   ```

   ADD SRROUTE:VRFNAME="VPN_Access",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VPN_Access",NEXTHOP="192.168.89.9",IFNAME="Ethernet66/0/5.1",SESSIONNAME="BfdName22",DHCPENABLE=FALSE;

   ADD SRROUTE:VRFNAME="VPN_Access",AFTYPE=ipv4unicast,PREFIX="192.168.53.4",MASKLENGTH=32,DESTVRFNAME="VPN_Access",NEXTHOP="192.168.89.9",IFNAME="Ethernet67/0/5.1",SESSIONNAME="BfdName24",DHCPENABLE=FALSE;

## 验证方法

1. 查看各网元间的路由连接是否正常。

   执行**PING**命令，查看VNF与对端设备间的路由连接是否正常。

   ```
   PING:IPVERSION=IPv4,VPNNAME="VPN_Access",DESTIPV4ADDRESS="对端网关地址";
   ```

   **说明** 

   如果使用了VPN组网，还需使用“VPN实例名称（VPNNAME）”指定VPN实例，这样才能验证VPN实例路由是否正常。

   - 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请执行2。
2. 查看接口状态及信息是否与规划数据一致。

   **LST INTERFACE**:;

   - 如果一致，请执行3。
   - 如果不一致，请参考“操作步骤”重新配置。
3. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   - 如果状态为up，请执行4。
   - 如果为其他状态，请参考“操作步骤”重新配置。
4. 检查生成的IPv4静态路由是否与规划数据一致。

   ****DSP SRROUTE****:;
   - 如果一致，请执行5。
   - 如果不一致，请参考“操作步骤”重新配置，再次执行1，如果问题还存在，则执行5。
5. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
