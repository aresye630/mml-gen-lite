# 配置动态路由OSPFv3+BFD组网（IPv6）

- 操作场景

## 操作场景

VNF与对端设备可通过OSPF动态路由绑定IPv6动态BFD探测的方式进行组网连接，该方式适用于IPv6组网的网络中。

在网络拓扑结构复杂、设备与IP路由繁多的网络部署时，通常使用OSPF动态路由方式发布路由。同时，利用BFD双向转发检测机制为链路提供双向、轻负荷且持续时间短的快速检测功能，提高链路可靠性。

如图1所示为VNF与周边网元的OSPF动态路由互通组网示意图。VNF与网关侧运行动态路由协议而接入运营商网络（IP骨干网），网关推荐使用运营商的PE（Provider Edge）交换机，也可以使用DC-GW，或者EOR（End of Row）交换机。无论哪种方式，VNF的配置相同，没有差异。PE的路由配置请参考运营商的网络规划配置，DC-GW/EOR的配置请参考对应型号设备的产品文档。

## 必备事项

前提条件

- 请阅读并熟悉特性IPFD-014001 支持OSPF特性概述和IPFD-012003 BFD特性概述。

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- VNF与网络实体之间的网络环境已经构建完成。

数据

VNF使用OSPFv3动态路由绑定动态BFD检测功能与对端设备建立可靠的IP连接。

- 在VNF上配置OSPFv3动态路由与对端建立链路。
- 在VNF上配置动态IPv6 BFD功能增强链路检测可靠性。
- 在VNF上推荐采用子接口的外联口与外部网络对接。

本文以一组外联口子接口为例进行说明，一组外联口（对应一个逻辑接口）分别规划在2个CSLB上，每个CSLB上各规划2个子接口负荷分担承载流量。实际场景可根据网设规划进行适配。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VPN_Access";
   ADD VPNINSTAF:VRFNAME="VPN_Access",AFTYPE=ipv6uni;
   ```

   **说明** 

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、网关上的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 配置外联口IP地址。

   1. 查看接口状态及信息。

      ```
      LST INTERFACE:;
      ```
   2. 配置主接口的管理状态为up。

      ```
      MOD INTERFACE:IFNAME="Ethernet66/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet66/0/5",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/4",IFADMINSTATUS=up;
      MOD INTERFACE:IFNAME="Ethernet67/0/5",IFADMINSTATUS=up;
      ```
   3. 配置以太网子接口。

      ```
      ADD INTERFACE:IFNAME="Ethernet66/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet66/0/5.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/4.1";
      ADD INTERFACE:IFNAME="Ethernet67/0/5.1";
      ```
   4. 增加接口绑定VPN。

      ```
      ADD IPBINDVPN:IFNAME="Ethernet66/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet66/0/5.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/4.1",VRFNAME="VPN_Access";
      ADD IPBINDVPN:IFNAME="Ethernet67/0/5.1",VRFNAME="VPN_Access";
      ```
   5. 在以太网子接口上关联VLAN ID。

      ```
      ADD ETHSUBIF:IFNAME="Ethernet66/0/4.1",VLANTYPEVID=105;
      ADD ETHSUBIF:IFNAME="Ethernet66/0/5.1",VLANTYPEVID=205;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/4.1",VLANTYPEVID=105;
      ADD ETHSUBIF:IFNAME="Ethernet67/0/5.1",VLANTYPEVID=205;
      ```

      **说明** 

      子接口配置了VLAN，则需要在交换机、对接网关上调整VLAN的配置。
   6. 配置IPv6使能。

      ```
      SET IFIPV6ENABLE: IFNAME="Ethernet66/0/4.1", ENABLEFLAG=TRUE;
      SET IFIPV6ENABLE: IFNAME="Ethernet66/0/5.1", ENABLEFLAG=TRUE;
      SET IFIPV6ENABLE: IFNAME="Ethernet67/0/4.1", ENABLEFLAG=TRUE;
      SET IFIPV6ENABLE: IFNAME="Ethernet67/0/5.1", ENABLEFLAG=TRUE;
      ```
   7. 配置外联口的IP地址。

      ```
      ADD IFIPV6ADDRESS:IFNAME="Ethernet66/0/4.1",IPV6ADDRESS="FC00::10C2",PREFIXLEN=123;
      ADD IFIPV6ADDRESS:IFNAME="Ethernet66/0/5.1",IPV6ADDRESS="FC00::10E2",PREFIXLEN=123;
      ADD IFIPV6ADDRESS:IFNAME="Ethernet67/0/4.1",IPV6ADDRESS="FC00::10C3",PREFIXLEN=123;
      ADD IFIPV6ADDRESS:IFNAME="Ethernet67/0/5.1",IPV6ADDRESS="FC00::10E3",PREFIXLEN=123;
      ```

      **说明** 

      如果规划外联口使用IPv4v6双栈地址，则分别执行**ADD IFIPV4ADDRESS**和**ADD IFIPV6ADDRESS**对同一vNIC配置IPv4和IPv6地址。
3. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
4. 配置OSPFv3路由数据。

   1. 创建OSPFv3进程。

      ```
      ADD OSPFV3:PROCID=6,VRFNAME="VPN_Access",ROUTERID="10.8.25.1",BFDALLINTFFLG=TRUE,VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
      ```

      **说明** 

      - 当在MCE（Multi-VPN-Instance CE）路由器上支持VPN多实例时，需要取消环路检查（参数“VPNINSCAPSIMFLG”配置为“TRUE”），否则会导致OSPF路由引入失败。
      - 路由器标识Router ID（“SCHEMAROUID”）的选择策略：优选用户配置的Router ID，如果未配置，则选择OSPFv3进程所在VRF内或者公网内的最大接口IP地址。
      - 如果需要为OSPFv3动态路由绑定BFD会话，则配置参数“BFDALLINTFFLG（使能BFD）”为“TRUE”。
      - 当OSPFv3路由配置共网段时，需要将参数“VIRTUALSYSFLAG（OSPFv3共网段虚拟系统使能标志）”配置为“TRUE”。
   2. 增加OSPFv3区域。

      ```
      ADD OSPFV3AREA:PROCID=6,AREAID="0.0.0.5", AREATYPE=NSSA;
      ```

      **说明** 

      参数“AREATYPE（OSPFv3区域类型）”配置为“NSSA”或“Normal”时，都不需要配置Loopback地址。
   3. 当需要配置OSPFv3区域认证。

      **ADD OSPFV3AREAAUTH**: PROCID=6, AREAID="0.0.0.5", AUTHENMODE=hmac-sha256, AUTHTEXTTYPE=cipher, AUTHTEXTMD5="密文验证密码",KEYID=密文验证字标识符;

      **说明** 

      使用区域验证时，一个区域中所有设备的接口上所配置的认证模式和口令必须一致。
   4. 配置OSPFv3协议的接口属性。

      ```
      ADD OSPFV3INTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet66/0/4.1",DRPRI=0,VIRTUALSYSFLAG=TRUE;
      ADD OSPFV3INTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet66/0/5.1",DRPRI=0,VIRTUALSYSFLAG=TRUE;
      ADD OSPFV3INTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet67/0/4.1",DRPRI=0,VIRTUALSYSFLAG=TRUE;
      ADD OSPFV3INTERFACE:PROCID=6,AREAID="0.0.0.5",IFNAME="Ethernet67/0/5.1",DRPRI=0,VIRTUALSYSFLAG=TRUE;
      ```

      **说明** 

      - 参数“NETWORKTYPE”（网络类型）选择“BROADCAST”、“NBMA”、“POINT-TO-POINT”、“POINT-TO-MULTIPOINT”或“P2MP-NONBROADCAST”。
      - 广播或NBMA网络中，根据此接口优先级选举DR和BDR路由器，“优先级”设置为“0”表示不参与DR和BDR的选举。为避免VNF被选为DR或BDR，建议将VNF“优先级”配置为0，对端配置为非0。
   5. 当需要配置OSPFv3接口验证参数。

      **ADD OSPFV3INTERFACEAUTH**: PROCID=6, AREAID="0.0.0.5", IFNAME="接口名称", AUTHENMODE=hmac-sha256, AUTHENTYPE=cipher, AUTHTEXTMD5="密文验证密码",KEYID=密文验证字标识符,INSTANCEID=实例号;

      **说明** 

      参数“IFNAME”（接口名称）引用4.d中的接口名称。
   6. 设置OSPFv3引入路由类型。

      ```
      ADD OSPFV3IMPORTROUTE:PROCID=6,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
      ```

## 验证方法

1. 查看各网元间的路由连接是否正常。

   执行**PING**命令，查看VNF与对端设备间的路由连接是否正常。

   ```
   PING:IPVERSION=IPv6,VPNNAME="VPN_Access",DESTIPV6ADDRESS="对端网关地址";
   ```

   **说明** 

   如果使用了VPN组网，还需使用“VPN实例名称（VPNNAME）”指定VPN实例，这样才能验证VPN实例路由是否正常。

   - 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   - 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请执行2。
2. 查看接口状态及信息是否与规划数据一致。

   **LST INTERFACE**:;

   - 如果一致，请3。
   - 如果不一致，请参考“操作步骤”重新配置，再次执行1。
3. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   - 如果状态为up，请执行4.a。
   - 如果为其他状态，请参考“操作步骤”重新配置。
4. 检查生成的OSPFv3动态路由是否与规划数据一致。
   1. 检查生成的OSPFv3路由是否与规划数据一致。

      **DSP OSPFV3ROUTING**:;
      - 如果一致，请执行4.b。
      - 如果不一致，请参考“操作步骤”重新配置，再次执行1。
   2. 检查接口是否已添加到OSPFv3区域中。

      **DSP OSPFV3INTERFACE**: PROCID=OSPFv3进程号;
      - 如果是，请执行4.c。
      - 如果否，请参考“操作步骤”重新配置，再次执行1。
   3. 检查OSPFV3邻居状态是否正常。

      邻居应包括邻居设备的ROUTER ID、接口的IP地址以及邻居的状态。

      **DSP OSPFV3PEER**: PROCID=OSPFv3进程号;
      - 如果是，请执行5。
      - 如果否，请参考“操作步骤”重新配置，再次执行1。
5. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
