# SMSF典型配置实例

- 操作场景

## 操作场景

本任务实例实现以下场景配置：

UNC（作为SMSF）与周边NF（本例中包含AMF、NRF、UDM、SMSC）通过OSPF动态路由绑定动态BFD实现网络互通。

- 网络形态：5G网络
- 网元形态：SMSF
- 路由协议：OSPF动态路由
- 组网IP格式：IPv4组网
- 接入用户：IPv4单栈用户

## 必备事项

前提条件

- 请了解UNC各类接口的类型及命名规范，可参见业务组网与逻辑接口介绍。
- 基础数据配置、IP路由组网和业务接口配置子任务在前述章节已有详细描述，可参见基础数据配置、配置VNF侧IP路由数据（非SDN）、配置SMSF，本文针对典型的任务场景举例说明整网脚本配置。

数据

可参考各子任务的数据规划准备。

文档

获取网设LLD文档。

## 操作步骤

全部展开

配置IP路由数据

1. 进入“MML命令行-UNC”窗口。
2. 关闭自动配置开关。

   1. 查询自动配置开关状态。

      ```
      LST AUTOCONFIG:;
      ```

      如果自动配置开关值为“TRUE”，需要执行如下步骤关闭自动配置开关。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=FALSE;
      ```
3. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
4. 配置UNC与对端AMF、NRF、UDM的IP路由数据。

   1. 配置外联口的VPN实例。

      ```
      ADD L3VPNINST: VRFNAME="VRF_SBI";
      ADD VPNINSTAF: VRFNAME="VRF_SBI", AFTYPE=ipv4uni;
      ```
   2. 配置OSPF路由。
      1. 创建OSPF进程。

         ```
         ADD OSPF: PROCID=6, VRFNAME="VRF_SBI", SCHEMAROUID="192.168.35.210", BFDALLINTFFLG=TRUE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500, VPNINSCAPSIMFLG=TRUE, VIRTUALSYSFLAG=TRUE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA: PROCID=6, AREAID="10.0.0.5";
         ```

         **说明** 

         如果参数“AREATYPE（区域类型）”配置为“NSSA”时，需要配置Loopback地址，这样设备会自动选取该Loopback地址作为FA。当有其他设备存在多条开销值相同的路径到NSSA设备时，可以形成负载分担。
      3. 设置OSPF引入路由类型。

         ```
         ADD OSPFIMPORTROUTE: PROCID=6, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ```
   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_SBI_100", VPNNAME="VRF_SBI", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=4, VLANID=100, BEGINADDR4="192.168.89.2", ENDADDR4="192.168.89.14", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="10.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_SBI_200", VPNNAME="VRF_SBI", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=5, VLANID=200, BEGINADDR4="192.168.89.18", ENDADDR4="192.168.89.30", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="10.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```
5. 配置UNC与对端SMSC的IP路由数据。

   1. 配置VPN实例。

      ```
      ADD L3VPNINST: VRFNAME="VRF_MME";
      ADD VPNINSTAF: VRFNAME="VRF_MME",AFTYPE=ipv4uni;
      ```
   2. 配置OSPF路由。
      1. 创建OSPF进程。

         ```
         ADD OSPF: PROCID=7, VRFNAME="VRF_MME", SCHEMAROUID="192.168.36.210",BFDALLINTFFLG=TRUE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500, VPNINSCAPSIMFLG=TRUE, VIRTUALSYSFLAG=TRUE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA: PROCID=7, AREAID="10.0.0.6";
         ```
      3. 设置OSPF引入路由类型。

         ```
         ADD OSPFIMPORTROUTE: PROCID=7, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ```
   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_MME_103", VPNNAME="VRF_MME", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=6, VLANID=103, BEGINADDR4="192.168.86.2", ENDADDR4="192.168.86.14", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=7, OSPFAREAID="10.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_MME_203", VPNNAME="VRF_MME", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=7, VLANID=203, BEGINADDR4="192.168.86.18", ENDADDR4="192.168.86.30", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=7, OSPFAREAID="10.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```
6. 配置UNC与对端IP-SM-GW的IP路由数据。

   1. 配置VPN实例。

      ```
      ADD L3VPNINST: VRFNAME="VRF_Access";
      ADD VPNINSTAF: VRFNAME="VRF_Access", AFTYPE=ipv4uni;
      ```
   2. 配置OSPF路由。
      1. 创建OSPF进程。

         ```
         ADD OSPF:PROCID=8, VRFNAME="VRF_Access", SCHEMAROUID="192.168.36.210", BFDALLINTFFLG=TRUE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500, VPNINSCAPSIMFLG=TRUE, VIRTUALSYSFLAG=TRUE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA: PROCID=8, AREAID="10.0.0.6";
         ```
      3. 设置OSPF引入路由类型。

         ```
         ADD OSPFIMPORTROUTE: PROCID=8, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ```
   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_Access_104", VPNNAME="VRF_Access", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=8, VLANID=104, BEGINADDR4="192.168.85.2", ENDADDR4="192.168.85.14", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=8, OSPFAREAID="10.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE: SERVICENAME="VRF_Access_204", VPNNAME="VRF_Access", AFTYPE=IPv4,IPALLOCTYPE4=USER_CONFIG, VNICID=9, VLANID=204, BEGINADDR4="192.168.85.18", ENDADDR4="192.168.85.30", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=8, OSPFAREAID="10.0.0.6", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```
7. 打开IP路由自动配置开关。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```

   **说明** 

   从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行****DSP OPSASSISTSTATE****命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。

配置SMSF基础数据

**说明** 

AMF寻呼用户的定时器默认为6秒，寻呼次数为3次；SMSF的HTTP接口等待响应超时定时器默认为5秒。

在空闲态UE的短信被叫流程中，如果UE不能在5秒之内响应寻呼，SMSF将认为UE不可达，并向短信中心返回SMS传输失败。短信中心再通过重传流程向UE下发短信。

8. 进入“MML命令行-UNC”窗口。
9. 配置运营商基础信息。

   1. 配置运营商签约用户的Home PLMN信息，用于识别用户是否为本网签约用户。

      ```
      ADD NGHPLMN: NOID=0, MCC="123", MNC="03";
      ```
   2. 配置运营商的Serving PLMN信息。

      ```
      ADD NGSRVPLMN: PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      ```
10. 增加SMSF服务化接口数据。

    1. 增加SMSF服务化接口的IP地址，用于和AMF、UDM等NF的对接。

       ```
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.2.180.15", VPNINSTNAME="_public_", DESC="FOR SBI";
       ```
    2. 配置SMSF服务化接口的HTTP信息。

       ```
       ADD HTTPLEGRP:INDEX=6, DESC="SMSF";
       ```
    3. 配置SMSF分别作为HTTP服务的服务端和客户端的本端端点信息。

       ```
       ADD HTTPLE:INDEX=11, HTTPLEGRPIDX=6, LETYPE=SERVER, IPTYPE=IPv4, IPV4="10.2.180.15", PORT=8080, VPNNAME="_public_", TLSFLG=NO, DESC="SMSF_Server";
       ADD HTTPLE:INDEX=12, HTTPLEGRPIDX=6, LETYPE=CLIENT, IPTYPE=IPv4, IPV4="10.2.180.15", VPNNAME="_public_", DESC="SMSF_Client";
       ```
    4. 配置SMSF服务化接口的接入点信息。

       ```
       ADD SBIAPLE:INDEX=6, HTTPLEGRPIDX=6, NFTYPE=NFTypeSMSF, DESCRIPTION="SMSF";
       ```

配置SMSF到NRF的数据（网络中部署了NRF时需要执行）

11. 配置SMSF实例信息，用于后续向NRF注册。

    1. 配置SMSF的实例名称，配置后系统会为SMSF自动分配InstanceID信息。

       ```
       ADD NFUUID:NFTYPE=NfSMSF, NFINSTANCENAME="SMSF_Instance_0";
       ```
    2. 配置SMSF实例的Profile信息，在SMSF向NRF进行注册/更新时携带。

       ```
       ADD NFPROFILE: NFINSTANCENAME="SMSF_Instance_0", NFTYPE=NfSMSF, NFSTATUS=Registered;
       ```
    3. 配置SMSF提供的服务实例及其版本信息。

       ```
       ADD NFSERVICE: NFINSTANCENAME="SMSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmsfSms;  
       ADD NFSERVICEVER: NFINSTANCENAME="SMSF_Instance_0", SRVINSTANCEID="Service_Instance_0", APIFULLVERSION="1.R15.0.0";
       ```
12. 配置NRF数据。

    1. 配置NRF信息。

       ```
       ADD NRF: NRFINSTANCENAME="NRF_Instance_0", TLS=FALSE, PRIORITY=0;
       ```
    2. 配置NRF的地址信息。

       ```
       ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_0", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="10.16.0.7", PORT=31000;
       ```
    3. **可选**：配置NRF协议参数。当开启订阅功能开关时，可以增加订阅条件。当目标NF触发订阅条件和通知事件时，NRF向源NF发送通知。

       ```
       ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_0", WAITINTERVAL=5, MAXRETRYTIMES=3, LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
       ADD SUBCONDITION: NFTYPE=NfUDM, CONDITION=NfInstanceId-1&NFType-0&ServiceName-0&AmfRegionId-0&AmfSetId-0&GuamiList-0&PlmnId-0&NetworkSlice-0&NfGroup-0&Rev1-0&Rev2-0&Rev3-0, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
       ADD SUBCONDITION: NFTYPE=NfAMF, CONDITION=NfInstanceId-1&NFType-0&ServiceName-0&AmfRegionId-0&AmfSetId-0&GuamiList-0&PlmnId-0&NetworkSlice-0&NfGroup-0&Rev1-0&Rev2-0&Rev3-0, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
       ```
    4. **可选**：当网络中规划了双主或者主备NRF时，需要配置本步骤。双主NRF场景下，NF对接的优先级高的NRF为本地DC的NRF；主备NRF场景下，NF对接的优先级高的NRF为主NRF。

       ```
       ADD NRF: NRFINSTANCENAME="NRF_Instance_1", TLS=FALSE, PRIORITY=1;
       ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_1", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="10.26.0.7", PORT=31000;
       ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_1", WAITINTERVAL=5, MAXRETRYTIMES=3, LOADCARRYINHB=FALSE, SUBSCRISWITCH=OFF, OAUTH2SWITCH=OFF;
       ADD SUBCONDITION: NFTYPE=NfUDM, CONDITION=NfInstanceId-1&NFType-0&ServiceName-0&AmfRegionId-0&AmfSetId-0&GuamiList-0&PlmnId-0&NetworkSlice-0&NfGroup-0&Rev1-0&Rev2-0&Rev3-0, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
       ADD SUBCONDITION: NFTYPE=NfAMF, CONDITION=NfInstanceId-1&NFType-0&ServiceName-0&AmfRegionId-0&AmfSetId-0&GuamiList-0&PlmnId-0&NetworkSlice-0&NfGroup-0&Rev1-0&Rev2-0&Rev3-0, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
       ```
    5. SMSF向NRF发起注册，激活SMSF注册状态。

       ```
       ACT NFONLINE: NFINSTANCENAME="SMSF_Instance_0";
       ```

配置本地NRF数据（网络中未部署NRF时需要执行）

**说明** 

- 如果网络中无NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF，则执行本步骤，手工配置SMSF与周边NF的逻辑连接。
- 当网络中既部署了NRF，又本地配置了周边NF时，可以通过**SET NFDISCPLCY**命令配置服务发现流程的策略，默认优先选择本地配置的NF。
- 下述以配置SMSF到周边UDM、AMF为例，说明本地NRF功能的基本步骤，如有其他NF对接需要，请参考进行配置。

13. 配置SMSF到UDM的数据，包括UDM的Profile、Service、SUPI和PLMN信息。

    ```
    ADD PNFPROFILE:NFINSTANCEID="UDM_Instance_0", NFTYPE=NfUDM, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.50.0.213",PORT=8080, PRIORITY=0;
    ADD PNFSERVICE:NFINSTANCEID="UDM_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NudmSdm, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=0;
    ADD PNFSERVICE:NFINSTANCEID="UDM_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NudmUecm, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=0;
    ADD PNFSUPI:INDEX=2, NFINSTANCEID="UDM_Instance_0", QUERYTYPE=START_END, RANGESTART="123030000000000", RANGEEND="123031000000000";
    ADD PNFPLMN:NFINSTANCEID="UDM_Instance_0", MCC="123", MNC="03";
    ```

14. 配置SMSF到AMF的数据，包括AMF的Profile、Service、SUPI和PLMN信息。

    ```
    ADD PNFPROFILE:NFINSTANCEID="AMF_Instance_0", NFTYPE=NfAMF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.50.0.212",  PORT=8080, PRIORITY=0;
    ADD PNFSERVICE:NFINSTANCEID="AMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NamfComm, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=0;
    ADD PNFSERVICE:NFINSTANCEID="AMF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NamfMt, SCHEMA=http, NFSERVICESTATUS=REGISTERED, PRIORITY=0;
    ADD PNFSUPI: INDEX=1, NFINSTANCEID="AMF_Instance_0", QUERYTYPE=START_END, RANGESTART="123030000000000", RANGEEND="123031000000000";
    ADD PNFPLMN:NFINSTANCEID="AMF_Instance_0", MCC="123", MNC="03";
    ```

配置SMSF到SMSC的数据

15. 增加SMSF业务接口IP地址，用于和SMSC的对接。

    ```
    ADD SERVICEIP:IPVERSION=IPv4, SERVICEIPV4="10.2.180.1", VPNINSTNAME="VPN_SIG";
    ```
16. 配置M3UA信令数据。

    1. 增加M3UA本地实体，信令点编码所在的网络为国内网，本地实体为ASP。

       ```
       ADD M3LE:LEX=1, NI=NAT, OPC="0x017701", LET=ASP, LEN="SMSC";
       ```
    2. 配置M3UA目的信令点。

       ```
       ADD M3DE:DEX=1, LEX=1, DPC="0x240011", SLSSM=B0000, STPF=DISABLE, DET=SGP, ADJF=TRUE, NMD=EXCLUSIVE, PVER=RFC3332, DEN="SMSC";
       ```
    3. 配置到SMSC的M3UA信令链路集。

       ```
       ADD M3LKS:LSX=1, DEX=1, SLSM=B0000, WM=ASP, TM=LOADSHARE, LSN="SMSC";
       ```
    4. 配置M3UA信令路由。

       ```
       ADD M3RT:RTX=1, DEX=1, LSX=1, PRI=0, RTN="SMSC";
       ```
    5. 配置SCTP协议参数。

       ```
       ADD SCTPPARA:SCTPPARAINDEX=0, SCTPPARANAME="sctname", PKGERRFAULT=5, PKGERRRECOVER=3, MINRECVPKGNUM=100;
       ```
    6. 配置M3UA信令链路。

       ```
       ADD M3LNK:LNK=1, VPNNAME="VPN_SIG", IPT=IPV4, LOCIPV41="10.2.180.1", LOCIPV42="10.255.255.255", LOCPORT=17171, PEERIPV41="10.50.0.202", PEERIPV42="10.255.255.255", PEERPORT=17171, CS=C, LSX=1, ASF=ACT, PRI=0, CONSTHD=80, CONETHD=40, CROSSIP=NO, EXCHGMODE=SINGLE, LKN="To SMSC", SCTPINDX=0;
       ```
17. 配置SCCP信令数据

    1. 配置SCCP本局信令点（适用于2/3G短消息）。

       ```
       ADD SCCPOPC:OPX=1, NI=NAT, OPC="0x17701", SPN=COREONLY, SGSNN="861390211101", OPN="SMSC";
       ADD SCCPDPC:DPX=1, OPX=1, DPC="0x240011", SS7T=ITUT_SS7, LDP=NOUSE, DPN="rnc";
       ```
    2. 配置SCCP本局信令点（适用于5G短消息）。

       ```
       ADD SMSFOPC: OPX=1, NI=NAT, OPC="0x17701", SMSFN="861390211101", OPN="peklin", MASTER=YES;
       ```
    3. 配置SCCP本局子系统。

       ```
       ADD SCCPSSN:SSNX=1, SSN=SCMG, NI=NAT, DPC="0x017701", OPC="0x017701", SSNNAME="SGSN_BER1-SSN";
       ADD SCCPSSN:SSNX=2, SSN=MSC, NI=NAT, DPC="0x017701", OPC="0x017701", SSNNAME="SGSN internal";
       ```
    4. 配置SCCP层主叫地址中携带的SSN号。

       ```
       SET SMSFSSN: SSN=MSC;
       ```
18. 配置GT翻译数据。

    ```
    ADD SCCPGT:GTX=1, NI=NAT, RT=DPC, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="861390211101", DPC="0x17701", NAME="SGSN_BER1-GT";
    ADD SCCPGT:GTX=2, NI=NAT, RT=DPCGT, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="86139177010000", DPC="0x240011", NAME="SMSC";
    ```
