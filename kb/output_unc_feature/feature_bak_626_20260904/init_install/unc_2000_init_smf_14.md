# SMF典型配置实例

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

本任务实例实现以下场景配置：

UNC（作为SMF+GW-C）与周边NF（本例中包含AMF、NRF、NSSF、UPF）通过OSPF动态路由绑定动态BFD实现网络互通。

- 网络形态：5G网络
- 网元形态：SMF+GW-C
- 路由协议：OSPF动态路由
- 组网IP格式：IPv4组网
- 接入用户：IPv4单栈用户

## 必备事项

前提条件

- 请了解UNC各类接口的类型及命名规范，可参见业务组网与逻辑接口介绍。
- 基础数据配置、IP路由组网和业务接口配置子任务在前述章节已有详细描述，可参见基础数据配置、配置VNF侧IP路由数据（非SDN）、配置SMF，本文针对典型的任务场景举例说明整网脚本配置。

数据

可参考各子任务的数据规划准备。

文档

获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 关闭自动配置开关。
   1. 查询自动配置开关状态。

      ```
      LST AUTOCONFIG:;
      ```

      如果自动配置开关值为“TRUE”，需要执行如下步骤关闭自动配置开关。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
3. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
4. 配置UNC与对端AMF、NRF、NSSF的IP路由数据。
   1. 配置外联口的VPN实例。

      ```
      ADD L3VPNINST:VRFNAME="VRF_SBI";
      ADD VPNINSTAF:VRFNAME="VRF_SBI",AFTYPE=ipv4uni;
      ```
   2. 配置OSPF路由。

      1. 创建OSPF进程。

         ```
         ADD OSPF:PROCID=6, VRFNAME="VRF_SBI", SCHEMAROUID="192.168.35.210", BFDALLINTFFLG=TRUE, LSAARRINTVFLAG=FALSE, LSAARRMAXINTV=1000, LSAARRSTARINTV=500, LSAARRHLDINTV=500, VPNINSCAPSIMFLG=TRUE, VIRTUALSYSFLAG=TRUE;
         ```
      2. 增加OSPF区域。

         ```
         ADD OSPFAREA:PROCID=6, AREAID="10.0.0.5";
         ```

         **说明** 

         如果参数“AREATYPE（区域类型）”配置为“NSSA”时，需要配置Loopback地址，这样设备会自动选取该Loopback地址作为FA。当有其他设备存在多条开销值相同的路径到NSSA设备时，可以形成负载分担。
      3. 设置OSPF引入路由类型。

         ```
         ADD OSPFIMPORTROUTE:PROCID=6, TOPOID=0, PROTOCOL=wlr, IMPTCOSTCFG=FALSE, IMPTTAGCFG=FALSE, IMPTTYPECFG=FALSE;
         ```
   3. 配置外联口自动部署模板。

      ```
      ADD AUTOSCALINGSERVICE:SERVICENAME="VRF_SBI_100", VPNNAME="VRF_SBI", AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=2, VLANID=100, BEGINADDR4="192.168.89.2", ENDADDR4="192.168.89.14", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="10.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE; 
      ADD AUTOSCALINGSERVICE:SERVICENAME="VRF_SBI_200", VPNNAME="VRF_SBI",AFTYPE=IPv4, IPALLOCTYPE4=USER_CONFIG, VNICID=3, VLANID=200, BEGINADDR4="192.168.89.18", ENDADDR4="192.168.89.32", MASKLEN=28, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="10.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
      ```


   从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行****DSP OPSASSISTSTATE****命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。
9. 配置运营商基础数据。当前UNC中默认配置一条“NOID”为0的默认记录，不需单独配置。

      ```
      ADD NGMNO:NOID=0, FULLNAME="Operator A", SHORTNAME="OA";
      ```

      ```
      ADD NGHPLMN:NOID=0, MCC="123", MNC="03";
      ```
   3. 配置运营商签约用户的Serving PLMN。

      ```
      ADD NGSRVPLMN:PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      ```
   4. 配置运营商支持的网络切片。

      ```
      ADD PLMNNS:NSIDX=0, PLMNIDX=0, SST=1, SD="010101", STATE=ACTIVE;
      ```
10. 配置SMF实例信息。
    1. 配置SMF实例的名称。

       ```
       ADD NFUUID:NFTYPE=NfSMF, NFINSTANCENAME="SMF_Instance_0";
       ```
    2. 配置SMF实例的Profile信息。

       ```
       ADD NFPROFILE:NFINSTANCENAME="SMF_Instance_0", NFTYPE=NfSMF, NFSTATUS=Registered;
       ```
    3. 配置SMF的域名等信息。

       ```
       ADD SMFINFO:SMFINSTANCENAME="SMF_Instance_0", SMFNAME="SMF01", PGWFQDN="HUAWEI1.COM.APN.EPC.MNC003.MCC123.3GPPNETWORK.ORG";
       ```
    4. 配置SMF提供的服务实例及其版本信息。

       ```
       ADD NFSERVICE:NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmfPduSes;
       ADD NFSERVICE:NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NsmfEventExp;
       ```

       ```
       ADD NFSERVICEVER:NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", APIFULLVERSION="1.R15.0.0";
       ADD NFSERVICEVER:NFINSTANCENAME="SMF_Instance_0", SRVINSTANCEID="Service_Instance_1", APIFULLVERSION="1.R15.0.0";
       ```
    5. 配置SMF支持的切片信息。

       ```
       ADD NFNS:NFTYPE=NfSMF, NSIDX=0;
       ```
    6. 配置SMF支持的APN/DNN、网络切片支持的DNN。

       ```
       ADD APN:APN="huawei.com", VIRTUALAPN=DISABLE, HASVPN=DISABLE;
       ADD NSDNN:NSIDX=0, DNN="huawei.com";
       ```
11. 配置SMF服务化接口数据。
    1. 增加SMF服务化接口的IP地址。

       ```
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.16.0.6", VPNINSTNAME="VRF_SBI", DESC="FOR Server SBI";
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.16.0.7", VPNINSTNAME="VRF_SBI", DESC="FOR Client SBI";
       ```
    2. 配置Nsmf接口的HTTP信息。

       ```
       ADD HTTPLEGRP: INDEX=2, DESC="SMF";
       ```

       ```
       ADD HTTPLE:INDEX=3, HTTPLEGRPIDX=2, LETYPE=SERVER, IPTYPE=IPv4, IPV4="10.16.0.6", PORT=8080, VPNNAME="VRF_SBI", TLSFLG=NO, DESC="SMF Server";
       ADD HTTPLE:INDEX=4, HTTPLEGRPIDX=2, LETYPE=CLIENT, IPTYPE=IPv4, IPV4="10.16.0.7", VPNNAME="VRF_SBI", DESC="SMF Client";
       ```

       ```
       ADD SBIAPLE:INDEX=2, HTTPLEGRPIDX=2, NFTYPE=NFTypeSMF, DESCRIPTION="SMF";
       ```
12. 配置SMF到NRF的数据。
    1. 配置NRF信息。

       ```
       ADD NRF:NRFINSTANCENAME="NRF_Instance_0", TLS=FALSE, PRIORITY=0;
       ```
    2. 配置NRF的地址信息。

       ```
       ADD NRFADDR:NRFINSTANCENAME="NRF_Instance_0", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="172.16.0.7", PORT=8080;
       ```
    3. 配置NRF协议参数。

       ```
       ADD NRFPARA:NRFINSTANCENAME="NRF_Instance_0", WAITINTERVAL=5, MAXRETRYTIMES=3, LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
       ADD SUBCONDITION:NFTYPE=NfAMF, CONDITION=NfInstanceId-1, REQNOTIFEVENT=NF_REGISTERED-1;
       ADD SUBCONDITION:NFTYPE=NfNSSF, CONDITION=NfInstanceId-1, REQNOTIFEVENT=NF_REGISTERED-1;
       ```
    4. 打开NF注册、认证、发现等与NRF进行交互的基本功能的开关。

       ```
       SET LICENSESWITCH:LICITEM="LKV2NFBSM01", SWITCH=ENABLE;
       SET LICENSESWITCH:LICITEM="LKV2NFASM01", SWITCH=ENABLE;
       SET LICENSESWITCH:LICITEM="LKV2NFDSM01", SWITCH=ENABLE;
       ```
    5. 激活SMF向NRF注册。

       ```
       ACT NFONLINE:NFINSTANCENAME="SMF_Instance_0";
       ```
13. 配置SMF到UPF（N4接口）的数据。
    1. 配置N4接口的IP地址。

       ```
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.26.0.6", VPNINSTNAME="VRF_CP", DESC="FOR N4 Interface";
       ```
    2. 配置控制面节点实例。

       ```
       ADD CPNODE:CPNODEINDEX=0, NODEIDTYPE=CpIPv4, NODEIDIPV4VALUE="10.26.0.6", CPFUNCTION=0;
       ADD CPPOINT:CPPOINTINDEX=0, CPNODEINDEX=0,IPVERSION=IPv4, IPV4="10.26.0.6", VPNNAME="VRF_CP";
       ```
    3. 配置用户面节点实例。

       ```
       ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11",  PORT=8080;
       ```

       ```
       ADD PNFNS:INDEX=3, NFINSTANCEID="UPF_Instance_1", SST=1, SD="000001";
       ADD PNFDNN:INDEX=3, NFINSTANCEID="UPF_Instance_1", DNN="huawei.com", PNFNSINDEX=3;
       ```
    4. 配置用户面节点的位置特征和分流能力。

       ```
       ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", LOCATION=Central, UPFUNCTION=None, LOCK=FALSE, VPNNAME="VRF_CP";
       ```
    5. 配置用户面节点的位置区信息，将位置区与TAI绑定。UPF服务区名称绑定4GTAI范围时，可以使用前缀的方式、后缀方式、前缀+后缀方式，且同一个UPF服务区名称绑定的各4GTAI范围不能有交集。

       ```
       ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI;
       ADD UPAREA:AREANAME="UPAREA2", AREATYPE=S1TAI;
       ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="12303260101", N2ENDTAI="12303260102";
       SET UPAREABINDFUNC:EFFECTIVEMODE=PREFIX;
       ADD UPAREABINDS1TAI:AREANAME="UPAREA2", S1BEGINTAI="123010001", S1ENDTAI="123011111";
       ```
    6. 配置用户面节点支持的为SMF提供服务区域的信息。

       ```
       ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA1";
       ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA2";
       ```
14. 配置S11/S5/S8-C接口的数据。
    1. 配置S11/S5/S8-C接口的GTP-C本地实体组和实体组成员信息。

       ```
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.2.215.26", VPNINSTNAME="VRF_GW", DESC="s11";
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.2.215.22", VPNINSTNAME="VRF_GW", DESC="s5s8_s";
       ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.2.215.21", VPNINSTNAME="VRF_GW", DESC="s5s8_p";
       ADD GTPCLEGRP:GROUPID=0, DESC="s11";
       ADD GTPCLEGRP:GROUPID=1, DESC="s5s8_s";
       ADD GTPCLEGRP:GROUPID=2, DESC="s5s8_p";
       ADD GTPCLEGRPMEM:GROUPID=0, IPTYPE=IPv4, IPV4ADDR="10.2.215.26", VPN="VRF_GW", DESC="s11";
       ADD GTPCLEGRPMEM:GROUPID=1, IPTYPE=IPv4, IPV4ADDR="10.2.215.22", VPN="VRF_GW", DESC="s5s8_s";
       ADD GTPCLEGRPMEM:GROUPID=2, IPTYPE=IPv4, IPV4ADDR="10.2.215.21", VPN="VRF_GW", DESC="s5s8_p";
       ```
    2. 配置S11/S5/S8-C接口信息。

       ```
       ADD GTPCINTF:INTFTYPE=E_GTPCINTF_ITFS11, GROUPID=0;
       ADD GTPCINTF:INTFTYPE=E_GTPCINTF_ITFS5_S, GROUPID=1;
       ADD GTPCINTF:INTFTYPE=E_GTPCINTF_ITFS8_S, GROUPID=1;
       ADD GTPCINTF:INTFTYPE=S5_P_OR_GN, GROUPID=2;
       ```
