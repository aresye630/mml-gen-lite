## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 增加NSA控制策略。

   **ADD NSACTRLPLCY**
3. 配置GTP-C V2协议兼容性。

   **ADD GTPCV2CMPT**
4. 配置S1接口兼容性。

   **SET S1CMPT**
5. 配置Update Location Request消息携带NR as Secondary RAT信元给HSS。

   - 若配置整系统支持Update Location Request消息携带NR as Secondary RAT信元给HSS，则执行如下步骤。

     **SET DMCMPT**
   - 若配置指定范围的用户配置Update Location Request消息携带NR as Secondary RAT信元给HSS，则执行如下步骤。

     1. 查询DMCMPT配置

        **须知** 

        命令**ADD DMCMPTBYIMSI**与**SET DMCMPT**中除“用户范围”、“运营商标识”以及“IMSI前缀”外的其余参数功能均相同，且若系统中同时存在这两条命令的配置，系统会优先匹配命令**ADD DMCMPTBYIMSI**的配置。因此在配置**ADD DMCMPTBYIMSI**前需先执行**LST DMCMPT**查询系统中**SET DMCMPT**的配置记录，确保命令**ADD DMCMPTBYIMSI**的配置记录中所携带的参数默认值不影响系统已有配置。

        **LST DMCMPT**
     2. 配置指定范围的用户配置Update Location Request消息携带NR as Secondary RAT信元给HSS

        **ADD DMCMPTBYIMSI**

## 任务示例

任务描述

配置UNC，使得具有DCNR能力的终端能够接入网络。

脚本

//增加NSA控制策略。

```
ADD NSACTRLPLCY: SUBRANGE=FOREIGN_USER, NOID=2, ISDCNR=YES, ISSECRATRPTSGW=YES, ISSECRATRPT=YES, ISGUUPSEL=YES;
```

//配置GTP-C V2协议兼容性。

```
ADD GTPCV2CMPT: IDX=0, MSGCLS=TM, TMMSGTYPE=CRT_SES_REQ, CRTSESREQ=UPSELIND, UPSELFLAG=DCNR-1;
```

//配置S1接口兼容性。

```
SET S1CMPT: NRR=YES;
```

//配置S6a接口兼容性策略。

```
ADD DMCMPTBYIMSI: SUBRANGE=IMSI_PREFIX, IMSIPRE="460123", SF2=FLSTID2_BIT27-1, HSIMSVOPS=BY_SYS_CAP, NODCNR=YES;
```
