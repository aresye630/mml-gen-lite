# 配置NTP时间同步

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

网元可以同时从FusionStage和NTP服务器同步时间信息，这样当一路故障后，另一路仍然可以正常运行，可以保证时间同步的可靠性，如图1所示。

**图1** 网元同时从FusionStage和外部NTP服务器同步时间信息

- 从FusionStage同步时间：当FusionStage在“系统管理 > 系统配置 > 时间管理”页面时，将“支持夏令时时钟”设置为“是”，同时在“应用管理 > MML”执行**SET TZ**命令，将“是否执行夏令时”设置为“YES(是)”，并将相关时区和夏令时参数和FusionStage设置一致。
- 从NTP服务器同步时间：对于计费类网元（UAMF、USMF），直接配置和NTP服务器对接即可。对于非计费类网元（NRF、NSSF、SMSF），需要和OMC对接，OMC最终和NTP服务器对接来实现时间同步。

前提条件

- 已登录网元OM Portal。
- 已获取NTP服务器信息。

## 操作步骤

1. 登录网元OM Portal，选择“应用管理 > MML”。
2. 执行**ADD NTPSVR**配置对接NTP服务器信息。

   ```
   ADD NTPSVR: SVRNAME="NTPServer1", IPTYPE=IPV4, IPADDRESS="10.10.10.100" ,PROTOCOLVERSION=NTPV4, AUTHFLAG=YES, KEYID=1, SHASTRING=SHA256, KEYSTRING="*****";
   ```
3. 执行**SET TZ**配置时区和夏令时信息与FusionStage一致。

   ```
   SET TZ: TF=GMT, TZONE=E0000, DST=YES, SM=Date, SMONTH=Jun, SDAY=1, ST=00&00, EMONTH=Sep, EDAY=25, ET=18&00, TO=3;
   ```
