# 激活用户身份保密性功能（适用于2G&3G）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本操作指导介绍在运行网络中激活用户身份保密性功能的操作过程。

用户身份保密功能是UNC的基本功能，通过给用户分配分组域临时用户标识P-TMSI，减少在空口上直接使用IMSI，来为用户身份提供保密性措施，防止用户身份泄密。

**说明** 

适用于SGSN。

## 必备事项

前提条件

请仔细阅读WSFD-010302 用户身份保密性功能（适用于SGSN）特性概述。

数据

该操作无需准备数据。

## 操作步骤

- 进入“MML命令行-UNC”窗口。
- 设置GSM移动性管理功能参数。
  1. 开启P-TMSI重分配功能。

     **SET GMMPTMSIREALLOC**

     **说明** 

     参数“REALLOCTMR”用于设定P-TMSI重分配流程的间隔时间长。如果配置为0时，PTMSI重分配功能关闭；配置为其他取值时，PTMSI重分配功能开启。
- 设置UMTS移动性管理功能参数。
  1. 开启P-TMSI重分配功能。

     **SET PMMPTMSIREALLOC**

     **说明** 

     参数“REALLOCTMR”用于设定P-TMSI重分配流程的间隔时间长。如果配置为0时，PTMSI重分配功能关闭；配置为其他取值时，PTMSI重分配功能开启。

## 任务示例

任务描述

在3G网络中，允许进行P-TMSI重分配。

脚本

//开启P-TMSI重分配功能。

```
SET PMMPTMSIREALLOC: WITHRAUPROC=YES, REALLOCTMR=1, REALLOCCOND=IN_PMM_CONNECTED_STATE;
```
