# 配置归属地专网UPF

- 操作场景
- 对系统的影响
- 必备事项
- 任务示例

## 操作场景

通用DNN漫游分流场景中，可选园区内专网UPF分流。如果专网UPF已经开启了动态分流功能，无需重复配置。

## 对系统的影响

无。

## 必备事项

前提条件

已参考运营商配置规范完成网元的基本配置。

数据

| 类别               | 参数名称                      | 取值样例   | 获取方法   | 说明                        |
|:-----------------|:--------------------------|:-------|:-------|:--------------------------|
| SET DEDICATEDLBO | 专网UPF动态分流功能开关（ULCLSWITCH） | ENABLE | 本端规划   | 该参数用于指定系统是否开启专网UPF动态分流功能。 |

## 任务示例

任务描述

配置用户在园区内由专网UPF分流。

脚本

1. 打开用户在园区内由专网UPF动态分流的功能开关。

   ```
   SET DEDICATEDLBO:ULCLSWITCH= ENABLE;
   ```
