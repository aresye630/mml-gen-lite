## 操作场景

本操作指导介绍激活支持HTTP头压缩字典功能的操作过程。

**说明** 

适用于AMF、SMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-202002 支持HTTP头压缩字典特性概述。
- 已完成加载License。

数据

| 类别              | 参数名称                          | 取值样例                | 获取方法   | 说明                                        |
|:----------------|:------------------------------|:--------------------|:-------|:------------------------------------------|
| SET HTTPINFORPT | HTTPLNKINFOLST（HTTP连接信息上报列表）  | HTTPDYNCOMPHDIDXRPT | 本端规划   | 配置HTTP动态头域压缩字典上报功能，以及上报周期，用于控制HTTP连接信息上报。 |
| SET HTTPINFORPT | DYNHDRPTMR（HTTP动态头域压缩字典上报定时器） | 60                  | 本端规划   | 配置HTTP动态头域压缩字典上报功能，以及上报周期，用于控制HTTP连接信息上报。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 配置HTTP动态头域压缩字典上报功能，以及上报周期。

   **SET HTTPINFORPT**

## 任务示例

任务描述

开启HTTP动态头压缩字典上报功能，且上报周期为60秒。

脚本

//打开AMF和SMF的HTTP动态头压缩字典上报功能的License。

```
SET LICENSESWITCH: LICITEM="LKV2HTTPCMPHD01", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV3HTTPCMPHD02", SWITCH=ENABLE;
```

//配置HTTP动态头域压缩字典上报功能，以及上报周期。

```
SET HTTPINFORPT: HTTPLNKINFOLST=HTTPDYNCOMPHDIDXRPT-1, DYNHDRPTMR=60;
```
