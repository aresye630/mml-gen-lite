## 操作场景

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置某个区域信息，以及AreaCode与TAI之间的映射关系。

   - 配置区域编码

     **ADD AREACODE**
   - 为指定的区域增加跟踪区成员

     **ADD AREAMEM**
3. 配置某个用户群组信息。

   - 配置5G用户群标识

     **ADD NGUSRGRP**
   - 配置用户群成员

     **ADD NGUSRGRPMEM**
4. （可选）配置区域漫游限制增强功能，当开关打开时周期性注册更新、服务请求、切换流程中AMF根据本地配置做区域接入限制检查。

   **SET NGMMFUNC**
5. 配置拒绝的原因值（由用户签约的“禁止区域（ForbiddenArea）”控制用户的接入）。

   **SET NGMMPROCTRL**
6. AMF本地配置限制区域信息、用户信息、控制模式以及拒绝原因值（由AMF本地配置的接入限制区域控制用户的接入）。

   **ADD NGACCAREALST**

   **说明** 

   - 限制区域之间不允许存在交叉和重叠，“所有区域”例外。
   - 当同时存在“指定区域”和“所有区域”时，以“指定区域”的策略为准，除非UE当前不在“指定区域”。
   - 对于同一个用户，可能匹配“指定区域”内的多个用户号段，该场景下，AMF按照最长匹配的方式优选。

## 任务示例

任务描述

启用区域漫游限制功能，运营商在“MyTown”区域（跟踪区编码为010101-010102）部署了企业网络，只允许企业员工接入，企业员工从属的用户组ID为888，IMSI前缀为123456，由AMF本地配置的接入限制区域控制用户的接入，拒绝原因值为#15 （No suitable cells in tracking area）。由用户签约的“禁止区域（ForbiddenArea）”控制用户的接入，拒绝原因值为#15 （No suitable cells in tracking area）。

脚本

//配置区域范围。

```
ADD AREACODE：AREACODE="MyTown";
ADD AREAMEM：AREACODE="MyTown",MCC="123", MNC="456", BGNTAC="010101", ENDTAC="010102";
```

//配置用户群组。

```
ADD NGUSRGRP：USRGRPID=888;
ADD NGUSRGRPMEM: USRGRPID=888, IMSIPRE="123456";
```

//由于签约的禁止区域受限拒绝的原因值。

```
SET NGMMPROCTRL: PROT=OTHER_PROC, AREARST=0;
```

//AMF本地配置限制区域信息、控制模式以及拒绝原因值。

```
ADD NGACCAREALST: AREARANGE=AREA_CODE, AREACODE="MyTown", CTRLMODE=WHITELIST, SUBRANGE=USER_GROUP, SUBGRPID=888, DESC="for employees";
```
