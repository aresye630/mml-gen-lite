## 操作场景

本操作指导介绍在运行网络中激活NSSF双活容灾的操作过程，组网请见NSSF主备容灾组网。

NSSF通过跨DC（Data Center）建立双活容灾组，两个NSSF互相备份且都处于运行状态，AMF与两个NSSF均互联且有优先级区分，实现容灾管理。当高优先级NSSF网元故障，AMF检测到高优先级NSSF故障则将业务选择到低优先级的NSSF，低优先级的NSSF网元能够接管故障高优先级NSSF的业务，保证业务连续性。NSSF故障恢复后，AMF会自动回切高优先级NSSF进行业务。

**说明** 

适用于AMF、NSSF。

## 必备事项

前提条件

- 已完成加载License。
- 请仔细阅读NSSF容灾原理。
- 已按照自身组网完成双活NSSF之间的路由配置，对于IPv4组网，各配置场景请参考“初始配置与调测”中自动部署配置动态路由OSPF+BFD组网（IPv4）、配置静态路由+BFD组网（IPv4）、配置BGP over OSPF/静态路由+BFD（IPv4）或手动部署配置动态路由OSPF+BFD组网（IPv4）、配置静态路由+BFD组网（IPv4）、配置BGP over OSPF/静态路由+BFD（IPv4）。
- 已按照自身组网完成双活NSSF之间的路由配置，对于IPv6组网，各配置场景请参考“初始配置与调测”中自动部署配置动态路由OSPFv3+BFD组网（IPv6）、配置静态路由+BFD组网（IPv6）、配置BGP over OSPFv3/静态路由+BFD（IPv6）或手动部署配置动态路由OSPFv3+BFD组网（IPv6）、配置静态路由+BFD组网（IPv6）、配置BGP over OSPFv3/静态路由+BFD（IPv6）。

数据

| 类别         | 参数名称               | 取值样例                      | 获取方法      | 说明            |
|:-----------|:-------------------|:--------------------------|:----------|:--------------|
| ADD DRINST | 容灾实例标识（DRINSTID）   | 0 1                       | 与对端协商     | 配置容灾实例信息。     |
| ADD DRINST | 容灾实例名称（DRINSTNAME） | DR1 DR2                   | 与对端协商     | 配置容灾实例信息。     |
| ADD DRCOMM | 容灾实例标识（DRINSTID）   | 0 1                       | 与对端协商     | 配置容灾实例通信地址信息。 |
| ADD DRCOMM | IP版本号（IPVERSION）   | COMM_IPV4                 | 与对端协商     | 配置容灾实例通信地址信息。 |
| ADD DRCOMM | 通信IPv4地址（COMMIPV4） | 10.5.5.1 10.5.5.2         | 全网规划      | 配置容灾实例通信地址信息。 |
| ADD DRCOMM | 通信IPv6地址（COMMIPV6） | 2001:db8:1:: 2001:db8:2:: | 全网规划      | 配置容灾实例通信地址信息。 |
| ADD DRCOMM | VPN实例名称（VPNNAME）   | DR_VPN                    | 从已配置数据中获取 | 配置容灾实例通信地址信息。 |

## 操作步骤

配置NSSF：每个NSSF都按如下操作配置

1. 完成NSSF基础配置，具体步骤与非容灾组网完全一致，请参考NSSF配置。
2. 进入“MML命令行-UNC”窗口。
3. 配置双活NSSF的容灾实例信息。

   **ADD DRINST**
4. 配置容灾实例通信地址信息。

   **ADD DRCOMM**
5. 等待30秒后查询容灾信息，若数据备份状态为容灾准备状态，则执行下一步，否则请收集信息并寻求技术支持。

   **DSP DRINFO**
6. 在双活NSSF上分别进行“关闭”和“打开”本特性的License配置开关，确保容灾功能成功激活。

   **SET LICENSESWITCH**
7. **可选：**复位NSSF。

   **说明** 

   “容灾实例标识”为0时，不需要复位NSSF。

   **RST NODEBATCH**

配置AMF

NSSF双活容灾组网下需要在AMF本地分别配置对接高低优先级的NSSF（各大区的AMF均配置大区1的NSSF为高优先级，配置大区2的NSSF为低优先级）。

其他配置与NSSF非容灾组网完全一致，请参考AMF配置。

## 任务示例

任务描述

启用NSSF双活容灾功能，配置双活NSSF的容灾实例信息和容灾实例通信地址信息。

脚本

- **配置NSSF**

  **//配置NSSF****1**

  //配置容灾实例信息。

  ```
  ADD DRINST: DRINSTID=0, DRINSTNAME="DR1";
  ```

  //配置容灾实例通信地址信息，包括本端和对端的数据。

  ```
  ADD DRCOMM: DRINSTID=0, IPVERSION=COMM_IPV4, COMMIPV4="10.5.5.1", VPNNAME="DR_VPN";
  ```

  ```
  ADD DRCOMM: DRINSTID=1, IPVERSION=COMM_IPV4, COMMIPV4="10.5.5.2", VPNNAME="DR_VPN";
  ```

  **//配置NSSF2**

  //配置容灾实例信息。

  ```
  ADD DRINST: DRINSTID=1, DRINSTNAME="DR2";
  ```

  //配置容灾实例通信地址信息，包括本端和对端的数据。

  ```
  ADD DRCOMM: DRINSTID=1, IPVERSION=COMM_IPV4, COMMIPV4="10.5.5.2", VPNNAME="DR_VPN";
  ```

  ```
  ADD DRCOMM: DRINSTID=0, IPVERSION=COMM_IPV4, COMMIPV4="10.5.5.1", VPNNAME="DR_VPN";
  ```

  **//等待30秒后查询容灾信息，数据备份状态为容灾准备状态后，再执行下一步。**

  ```
  DSP DRINFO: PEERDRINSTID=0;
  ```

  **//配置NSSF****1**

  //关闭NSSF双活容灾功能的License配置开关。

  ```
  SET LICENSESWITCH: LICITEM="LKV2DLNSSR01", SWITCH=DISABLE;
  ```

  //打开NSSF双活容灾功能的License配置开关。

  ```
  SET LICENSESWITCH: LICITEM="LKV2DLNSSR01", SWITCH=ENABLE;
  ```

  **//配置NSSF****2**

  //关闭NSSF双活容灾功能的License配置开关。

  ```
  SET LICENSESWITCH: LICITEM="LKV2DLNSSR01", SWITCH=DISABLE;
  ```

  //打开NSSF双活容灾功能的License配置开关。

  ```
  SET LICENSESWITCH: LICITEM="LKV2DLNSSR01", SWITCH=ENABLE;
  ```

  **//复位容灾实例标识为“1”的NSSF2。**

  ```
  RST NODEBATCH: APPID=0;
  ```

  **说明** 

  - 此处APPID可使用**LST ME**命令查询结果中的ME ID。
  - 若两套NSSF的容灾实例标识都不为“0”，则两套NSSF都要进行复位。
- 配置AMF

  //配置到NSSF的数据，包括NSSF的Profile、Service等信息。当网络中规划了双活NSSF时，需要配置到两个NSSF的数据。AMF对接两个NSSF的优先级与规划的高低优先级NSSF保持一致。

  ```
  ADD PNFPROFILE: NFINSTANCEID="NSSF_Instance_0", NFTYPE=NfNSSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.182", PORT=8080, PRIORITY=0;
  ADD PNFPROFILE: NFINSTANCEID="NSSF_Instance_1", NFTYPE=NfNSSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.183", PORT=8080, PRIORITY=1;
  ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NnssfNsSel, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
  ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NnssfNssaiAvai, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
  ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_1", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NnssfNsSel, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
  ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_1", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NnssfNssaiAvai, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
  ```
