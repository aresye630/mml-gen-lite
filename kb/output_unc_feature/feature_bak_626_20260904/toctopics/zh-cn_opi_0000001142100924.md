# 激活1/N设备标识检查（适用于5G）

- 操作场景

## 操作场景

本章节指导如何在运行的5G网络中激活1/N设备标识检查特性。

**说明** 

适用于AMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-103006 1/N设备标识检查特性概述（适用于5G）。

- 该特性的依赖特性WSFD-103004 设备标识检查特性已经正常开通，详细请参见激活设备标识检查特性（适用于5G）。
- 完成加载License。

数据

| 类别            | 参数名称                     | 取值样例      | 获取方法   | 说明   |
|:--------------|:-------------------------|:----------|:-------|:-----|
| MOD NGPEIPLCY | 用户范围（SUBRANGE）           | ALL_USER  | 全网规划   | -    |
| MOD NGPEIPLCY | PEI获取策略（GETPEIPLCY）      | GETIMEISV | 全网规划   | -    |
| MOD NGPEIPLCY | PEI检查策略（CHKPEIPLCY）      | CHKIMEISV | 全网规划   | -    |
| MOD NGPEIPLCY | PEI检查上限（CHKPEITHRESHOLD） | 2         | 全网规划   | -    |

## 操作步骤

1. 打开本特性的License配置开关。

   进入“MML命令行-UNC”窗口。

   **SET LICENSESWITCH**
2. 配置PEI检查上限。

   **MOD NGPEIPLCY**

## 任务示例

任务描述

在5G网络中启用1/N设备标识检查功能，设置PEI检查上限为2。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV21NIMEI01", SWITCH=ENABLE;
```

//设置5G网络的PEI检查上限。

```
MOD NGPEIPLCY: SUBRANGE=ALL_USER, GETPEIPLCY=GETIMEISV, CHKPEIPLCY=CHKIMEISV, CHKPEITHRESHOLD=2;
```
