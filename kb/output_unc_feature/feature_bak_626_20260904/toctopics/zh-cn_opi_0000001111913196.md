# 配置5G网络基于实时位置的策略控制功能

## 操作场景

本章节介绍5G用户接入5G网络场景如何开启基于实时位置信息的策略控制功能。本场景下，仅需在SMF配置相关参数。

## 必备事项

前提条件

- 完成加载License（如果有需求，请联系华为技术支持工程师处理）。

- 部署本特性会增加N7接口的负荷，因此在部署本特性之前请对现有网络的业务模型、资费策略、网络资源占用情况进行评估，以降低对整个网络的负荷冲击。
- 需要对端网元PCF激活基于实时位置信息的策略控制功能。

## 操作流程

## 任务示例

任务描述

1. PCF下发基于Cell粒度的位置Trigger场景，在SMF侧配置基于实时位置的策略控制功能。
2. SMF本地配置位置Trigger场景，开启基于TAI粒度的实时位置策略控制功能。

脚本

- 任务一：PCF下发基于Cell粒度的位置Trigger场景，在SMF侧配置基于实时位置的策略控制功能。

  //开启基于实时位置信息的策略控制功能的License。

  ```
  SET LICENSESWITCH: LICITEM="LKV2PYCTRL1",SWITCH=ENABLE;
  ```

  //开启全局位置上报功能。

  ```
  SET SMCOMMFUNC: LOCREPORT=Support;
  ```

  //设置APN（huawei.com）的位置上报功能，指定该APN的位置上报功能继承全局配置。

  ```
  ADD APN: APN="huawei.com", LOCREPORT=INHERIT;
  ```

  //开启NCGI订阅和上报功能。

  ```
  SET N7RCVATTRCTRL: SCELLCHNR=ENABLE;
  ```
- 任务二：SMF本地配置位置Trigger场景，开启基于TAI粒度的实时位置策略控制功能。

  //开启基于实时位置信息的策略控制功能的License。

  ```
  SET LICENSESWITCH: LICITEM="LKV2PYCTRL1",SWITCH=ENABLE;
  ```

  //开启全局位置上报功能。

  ```
  SET SMCOMMFUNC: LOCREPORT=Support;
  ```

  //设置APN（huawei.com）的位置上报功能，指定该APN的位置上报功能继承全局配置。

  ```
  ADD APN: APN="huawei.com", LOCREPORT=INHERIT;
  ```

  //配置本地TAI位置Trigger。

  ```
  SET LOCATIONREPORT: TAITRIGGERFLG=ENABLE;
  ```
