## 操作场景

本操作指导介绍在运行网络中激活网络侧发起的5G位置定位服务特性的操作过程。

网络侧发起的5G位置定位服务是移动通信网络通过无线信号测量来确定UE地理位置信息及其移动速度的技术，本特性中也称为LCS（Location Services）。

**说明** 

适用于AMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-106701 网络侧发起的5G位置定位服务特性概述。
- 已完成AMF初始配置，包括IP路由数据以及AMF基础数据配置参见《UNC初始配置与调测》>组网对接配置。
- 已完成配置AMF和LMF/GMLC对接。
- 完成包含此特性的License文件加载。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. **可选：**当现网在UEG-S上部署LCS功能，且AMF网元版本为20.13.2及以上，UEG-S网元版本低于20.13.2时，需关闭对周期定位的ReportingAmount和ReportingInterval信元的校验。

   **SET AMFSOFTPARAOFBIT**

   **说明** 

   在周期性定位或单次定位过程中，若期望AMF向LMF发送Nlmf\_Location\_DetermineLocation Request消息信元填充前不检查信元的有效性，需要将“DWORD68 BIT32”软参设置为“1”。
3. 设置LCS定位（MT-LR）的参数。

   **SET NGLCSPARA**

   **说明** 

   - 如果采用3GPP协议定义的标准LCS组网（部署LMF），进行精准LCS定位，“LCSSW(定位服务功能开关)”为“ON（开启）”，“LCSPLCY(5G定位服务策略)”为“PROTOCOL\_POSITION（协议模式定位）”。
   - 如果采用未部署LMF网元的LCS组网，进行较低精度的LCS定位，“LCSSW(定位服务功能开关)”为“ON（开启）”，“LCSPLCY(5G定位服务策略)”为“NO\_LMF\_POSITION（无LMF定位）”。
4. **可选：**若LMF不支持显示订阅LPP、NRPPA等类型时，需开启DWORD63 BIT1软参以保证定位流程正常运行。
5. **可选：**位置定位安全加固配置。
   1. 建议增加AMF的位置定位服务白名单配置，确保仅限于合法的GMLC访问。

      **ADD ALLOWSERNAME**
   2. 建议AMF和GMLC侧开启SBI接口加密，降低网络安全风险。

      - AMF侧开启SBI接口加密请参考激活SBI接口加密特性(CERT)。
      - GMLC侧开启SBI接口加密请参考对应的产品描述。
   3. 建议增加定位服务权限，用于AMF收到GMLC的定位请求时检查GMLC的定位请求是否越权，对越权的GMLC，AMF拒绝其定位请求。（用于B2B场景）

      **ADD LCSPERMITCFG**
6. **可选：**针对低功耗终端场景，配置周期性注册更新流程的超长时间间隔。

   **ADD NGPRDREGTIMEDNN**

   **说明** 

   对于低功耗终端，AMF不支持InterAMF切换操作中给基站下发基于DNN配置的T3512。

## 任务示例

任务描述

设置网络侧发起的5G位置定位服务定位参数。

- 场景1：3GPP协议定义的标准LCS组网场景下，部署协议标准的LCS定位（MT-LR）功能。
- 场景2：未部署LMF网元的LCS组网场景下，部署无LMF的LCS定位（MT-LR）功能。

脚本

当AMF网元版本为20.13.2及以上，UEG-S网元版本低于20.13.2时。需关闭对周期定位的ReportingAmount和ReportingInterval信元的校验。

//关闭对周期定位的ReportingAmount和ReportingInterval信元的校验。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=68, VALUE=VALUE_1, POSITION=32;
```

- 场景1：标准的LCS定位（MT-LR）功能。

  //设置LCS定位的参数，选择5G定位服务策略为协议模式定位。

  ```
  SET NGLCSPARA: LCSSW=ON, POSEXPR=30, LCSPLCY=PROTOCOL_POSITION, LRC=YES, GUAMINOTIFY=NO, LCSIDCHK=NO, LMFRETRY=NO;
  ```

  //可选：若LMF不支持显示订阅LPP、NRPPA等类型时，需开启“DWORD63 BIT1”软参以保证定位流程正常。

  执行SET AMFSOFTPARAOFBIT命令设置软参DWORD63中BIT1的取值为“1”。

  ```
  SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=63, VALUE=VALUE_1, POSITION=1;
  ```

  **//设置位置定位安全加固配置。**

  //增加AMF的位置定位服务白名单配置，确保仅限于合法的GMLC访问。

  ```
  ADD ALLOWSERNAME: INDEX=0, NFINSTANCEID="AMF_Instance_0", SERVICENAME="namf-loc", LOCALADDR="10.16.1.5", PEERADDR="10.112.1.5";
  ```

  //开启SBI接口加密，降低网络安全风险。

  ```
  AMF侧请参考激活SBI接口加密特性(CERT)AMF侧配置脚本。GMLC侧请参考对应产品描述。
  ```

  //增加定位服务权限，用于AMF收到GMLC的定位请求时检查GMLC的定位请求是否越权，对越权的GMLC，AMF拒绝其定位请求。（用于B2B场景）

  ```
  ADD LCSPERMITCFG: OPTYPE=Namf_Location_ProvidePositioningInfo, IPTYPE=IPTypeV4, IPV4ADDRESS="10.112.1.5", USRGRPID=20;
  ```

  **//针对低功耗终端场景，配置周期性注册更新流程的超长时间间隔。**

  //增加DNNNI为“abc”、周期性注册时长获取策略为本地配置优先、周期性注册时长780分钟、移动可达定时器792分钟的配置。

  ```
  ADD NGPRDREGTIMEDNN: DNNNI="abc", TIMEPLCY=LOCAL, T3512=780, RCHTMR=792;
  ```
- 场景2：无LMF的LCS定位（MT-LR）功能。

  //设置LCS定位的参数，选择5G定位服务策略为无LMF定位。

  ```
  SET NGLCSPARA: LCSSW=ON, POSEXPR=30, LCSPLCY=NO_LMF_POSITION, LRC=YES, GUAMINOTIFY=NO, LCSIDCHK=NO, LMFRETRY=NO;
  ```

  **//设置位置定位安全加固配置。**

  //增加AMF的位置定位服务白名单配置，确保仅限于合法的GMLC访问。

  ```
  ADD ALLOWSERNAME: INDEX=0, NFINSTANCEID="AMF_Instance_0", SERVICENAME="namf-loc", LOCALADDR="10.16.1.5", PEERADDR="10.112.1.5";
  ```

  //开启SBI接口加密，降低网络安全风险。

  ```
  AMF侧请参考激活SBI接口加密特性(CERT)AMF侧配置脚本。GMLC侧请参考对应产品描述。
  ```

  //增加定位服务权限，用于AMF收到GMLC的定位请求时检查GMLC的定位请求是否越权，对越权的GMLC，AMF拒绝其定位请求。（用于B2B场景）

  ```
  ADD LCSPERMITCFG: OPTYPE=Namf_Location_ProvidePositioningInfo，IPTYPE=IPTypeV4, IPV4ADDRESS="10.112.1.5", USRGRPID=20;
  ```

  **//针对低功耗终端场景，配置周期性注册更新流程的超长时间间隔。**

  //增加DNNNI为“abc”、周期性注册时长获取策略为本地配置优先、周期性注册时长780分钟、移动可达定时器792分钟的配置。

  ```
  ADD NGPRDREGTIMEDNN: DNNNI="abc", TIMEPLCY=LOCAL, T3512=780, RCHTMR=792;
  ```
