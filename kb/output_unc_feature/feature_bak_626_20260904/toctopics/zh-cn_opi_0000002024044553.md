## 操作场景

本操作指导您完成高通量UPF选择解决方案中UPCF侧的初始业务配置。

## 必备事项

前提条件

- 已完成配置UPCF与SMF的对接数据。
- 已阅读高通量UPF特性概述。
- 高通量业务的规则名已全网统一规划。

## 操作步骤

- 登录UPCF WebUI界面。

配置条件组。

导航入口为“策略管理 > 策略 > 条件组”。

**说明** 

- 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
- 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与/或关系由参数“关系”的取值决定。

需要配置条件组，条件组的数据规划如表2所示。

| 类别   | 参数   | 参数.1   | 取值样例                                 |
|:-----|:-----|:-------|:-------------------------------------|
| 条件组  | 基本信息 | 名称     | SubscriberStatus_CG01                |
| 条件组  | 基本信息 | 关系     | AND                                  |
| 条件组  | 条件   | 名称     | SubscriberStatus_C01                 |
| 条件组  | 条件   | 对象属性   | 对象：Subscriber属性：SubscriberIdentifier |
| 条件组  | 条件   | 操作符    | Not Equal                            |
| 条件组  | 条件   | 右值类型   | Attribute                            |
| 条件组  | 条件   | 右值     | System.Null                          |

配置5G动作组。

导航入口为“策略管理 > 策略 > 5G动作组”。

**说明** 

预定义动作的名称需要提前与对端SMF规划一致，具体规则的实现细节由对端SMF配置决定。

需要配置如下动作和动作组，动作组的数据规划如表3所示。

| 类别    | 参数   | 参数.1        | 取值样例                      |
|:------|:-----|:------------|:--------------------------|
| 5G动作组 | 基本信息 | 名称          | UpfSelect_AG01            |
| 5G动作组 | 基本信息 | 类型          | UpfSelectRule             |
| 5G动作组 | 属性   | upfSelectId | 类型：Value值：select_high_upf |
| 5G动作组 | 属性   | reportInd   | 类型：Value值：True            |

配置规则。

导航入口为“策略管理 > 策略 > 规则”。

规则的数据规划如表4所示。

| 类别   | 参数    | 参数.1   | 取值样例                                 |
|:-----|:------|:-------|:-------------------------------------|
| 规则   | 基本信息  | 名称     | N7_High_Rule01                       |
| 规则   | 基本信息  | 操作类型   | Change Rule                          |
| 规则   | 基本信息  | 类型     | 5G Smf Pcc Rule                      |
| 规则   | 条件组   | 关系     | AND  说明： 当规则中只有一个条件组时，“关系”可设置为任意值。   |
| 规则   | 条件组   | 条件组    | SubscriberStatus_CG01  说明： 已在条件组中定义。 |
| 规则   | 5G动作组 | 5G动作组  | UpfSelect_AG01  说明： 已在5G动作组中定义。      |

配置策略。

导航入口为“策略管理 > 策略 > 策略”。

策略的数据规划如表5所示。

| 类别   | 参数   | 参数.1   | 取值样例                         |
|:-----|:-----|:-------|:-----------------------------|
| 策略   | 基本信息 | 名称     | N7_High_Policy01             |
| 策略   | 基本信息 | 类型     | N7 Policy                    |
| 策略   | 触发器  | 名称     | IPCAN_EST                    |
| 策略   | 规则   | 名称     | N7_High_Rule01  说明： 已在规则中定义。 |

配置业务。

导航入口为“业务管理 > 业务 > 业务”。

业务的数据规划如表6所示。

| 类别   | 参数   | 参数.1    | 取值样例                                                      |
|:-----|:-----|:--------|:----------------------------------------------------------|
| 业务   | 基本信息 | 名称      | N7_High_Service01                                         |
| 业务   | 基本信息 | 类型      | VALUE_ADDED_SERVICE                                       |
| 业务   | 基本信息 | 激活方式    | PCEF                                                      |
| 业务   | 基本信息 | 优先级     | 0  说明： 运营商统一规划，用于设置该业务在互斥组中的优先级。当此业务不需配置相关互斥组时，此值取默认值“0”。 |
| 业务   | 基本信息 | QoS模式   | 替换                                                        |
| 业务   | 基本信息 | 签约后才能使用 | 是                                                         |
| 业务   | 策略   | 名称      | N7_High_Policy01  说明： 已在策略中定义。                            |

- 登录“UPCF 业务管理”窗口。

- 发放业务。
  1. 执行**ADD PSUB**增加一个用户。

     **说明** 

     “USRIDENTIFIER”的参数类型受软参VRM\_SUBSRCIPTIONIDTYPE（系统支持的用户类型）控制，默认为“IMSI”。

     ```
     ADD PSUB: USRIDENTIFIER="46010381012****", USRMSISDN="1234567****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA;
     ```
  2. 执行**ADD PSRV**给用户签约业务。

     ```
     ADD PSRV: USRIDENTIFIER="46010381012****", SRVNAME="N7_High_Service01", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
     ```

## 任务示例

任务描述

配置业务。

脚本

```
ADD CONDITIONGROUP:CONDITIONGROUPNAME="SubscriberStatus_CG01",RELATION=AND,USETIMEZONE=No;
ADD CONDITION:CONDITIONGROUPNAME="SubscriberStatus_CG01",CONDITIONNAME="SubscriberStatus_C01",OBJECTATTRIBUTE="Subscriber.SubscriberIdentifier",OPERATOR=Not Equal,RIGHTVALUETYPE=Attribute,RIGHTOBJECTATTRIBUTE="System.Null";
ADD NGACTIONATTR:ACTIONNAME="UpfSelect_AG01",ATTRNAME="upfSelectId",TYPE=Value,VALUE="select_high_upf";
ADD NGACTIONATTR:ACTIONNAME="UpfSelect_AG01",ATTRNAME="reportInd",TYPE=Value,VALUE="True";
ADD RULE:RULENAME="N7_High_Rule01",OPERATION=Change Rule,TYPE=Smf Pcc Rule 5G,PRECEDENCE=0,VOLUMEUSAGEROUNDING=No,EDR=OFF,RELATION=AND;
ADD RULECONDITIONGROUP:RULENAME="N7_High_Rule01",CONDITIONGROUPNAME="SubscriberStatus_CG01";
ADD RULENGACTION:RULENAME="N7_High_Rule01",ACTIONNAME="UpfSelect_AG01";
ADD POLICY:POLICYNAME="N7_High_Policy01",TYPE=N7 Policy;
ADD POLICYRULE:POLICYNAME="N7_High_Policy01",RULENAME="N7_High_Rule01";
ADD POLICYTRIGGER:POLICYNAME="N7_High_Policy01",TRIGGERNAME="IPCAN_EST";
ADD SERVICE:SERVICENAME="N7_High_Service01",SERVICETYPE=VALUE_ADDED_SERVICE,ACTIVATEDBY=PCEF,PRECEDENCE=0,QOSMODE=Replace,SUBSCRIPTIONFORCED=Yes,PROBILLDATE=No,QUOTAALLOCATIONMODE=None,ISSETSHAREDMODE=No,RESUBSCRIPTIONOPERATION=NULL,ISGROUPSERVICE=No,ISTEMPLATE=No,ISRECUSRLOC=No,APNMATCHTYPE=Full Matching,HASBASESERVICE=No,ADDONLEVEL=Exhaust,CALCVALIDFORDYNSUBGROUP=No,CUSTOMIZEDRESET=No,MASTER2MASTERSHARESERVICE=No;
ADD SERVICEPOLICY:SERVICENAME="N7_High_Service01",POLICYNAME="N7_High_Policy01";
```
