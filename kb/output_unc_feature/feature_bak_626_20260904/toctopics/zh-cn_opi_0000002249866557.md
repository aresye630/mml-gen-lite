# 配置业务可靠性

## 操作场景

传统UPF容灾时，主倒备，然后主恢复，SMF会通知备UPF去活所有IKE会话，但在异常场景下，家庭侧仍然与备UPF保持连接，或家庭侧新接入的IKE会话仍然接到备UPF上，这会导致UE侧会话和家庭侧会话不在同一个UPF上，业务不通。此时只能通过UPF定时核查去活家庭会话，业务恢复不及时。

该任务旨在解决此问题，在备UPF上开启智家APN主备状态动态管理功能，确保主UPF恢复场景下，备UPF通过N4接口的信令交互感知到主UPF恢复，然后主动把当前备UPF上的IKE会话踢下线后触发IKE重新激活到主UPF上，达到业务自动及时恢复的目的。

## 任务示例

任务描述

- 备UPF开启家庭侧会话快速核查功能。
- 备UPF开启智家APN主备状态动态管理功能。

脚本

1. 备UPF开启家庭侧会话快速核查功能。

   ```
   SET UPNON3GPPPARA: AGINGTIME=1440, FASTRECOVERYSW=ENABLE;
   ```
2. 备UPF开启智家APN主备状态动态管理功能。

   ```
   SET APNDYNSTATESW: APN="home.area1.dnn", SWITCH=ENABLE;
   ```
