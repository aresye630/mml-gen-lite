## 操作场景

Pod间Base平面亚健康检测是基于Pod间的点到点探测结果，进行的网络亚健康诊断。

操作员可以开启网络亚健康检查开关，并设置检查参数和相关告警上报参数，使系统根据设置参数检查网络亚健康状态并上报相关告警。

## 必备事项

前提条件

请仔细阅读SFFD-010008 通信亚健康自愈。

数据

| 类别                | 参数名称                     | 取值样例   | 获取方法   | 说明                |
|:------------------|:-------------------------|:-------|:-------|:------------------|
| SET COMBASEHEALTH | 检测周期(秒) (DETECTINTERVAL) | 1      | 本端规划   | 设置Base平面的亚健康检测参数。 |
| SET COMBASEHEALTH | 统计周期(秒)（STATISINTERVAL）  | 30     | 本端规划   | 设置Base平面的亚健康检测参数。 |
| SET COMBASEHEALTH | 亚健康告警阈值(THRESHOLD) (千分比) | 50     | 本端规划   | 设置Base平面的亚健康检测参数。 |
| SET COMBASEHEALTH | 使能开关（ENABLEFLAG）         | ENABLE | 本端规划   | 设置Base平面的亚健康检测参数。 |

## 操作步骤

1. 已经登录OM Portal，或者已登录U2020，或者登录MAE并进入Access子系统。
2. 使用**SET COMBASEHEALTH**命令设置Base平面的pod之间链路亚健康检测参数。

   Base平面亚健康可能会导致上报如下相关告警：

   - **ALM-100319 Base平面Pod级亚健康告警**
   - **ALM-221257862 资源单元Base平面亚健康**
   - **ALM-221257870 Base平面亚健康**

## 任务示例

任务描述

本实例中，操作员在网元上进行数据配置实现以下要求：

系统对pod之间Base平面的链路进行健康质量检测，当超过设置的亚健康告警阈值时，会上报相关告警。

脚本

//设置Base平面的亚健康检测参数。

```
SET COMBASEHEALTH: DETECTINTERVAL=1, STATISINTERVAL=30, THRESHOLD=50, ENABLEFLAG=ENABLE;
```
