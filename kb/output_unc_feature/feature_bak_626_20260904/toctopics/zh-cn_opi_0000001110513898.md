# 基于位置区分配IP地址

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

运营商规划UPF为UE分配IP地址，可基于APN/DNN、位置、SMF或其任意组合分配地址，基于位置区分配IP地址的配置方法可参考本章节。

**说明** 

适用于GGSN、PGW-C、SMF、PGW-U、UPF。

## 必备事项

请仔细阅读UPF分配IP地址流程。

## 操作步骤

1. 在UDG上执行如下命令，基于APN/DNN实例使能地址分配属性。
   1. 配置VPN实例。

      **ADD VPNINST**
   2. 配置APN/DNN实例。

      **ADD APN**
   3. 使能该APN/DNN的地址分配属性。

      **SET APNADDRESSATTR**
2. 配置地址池绑定到地址池组。
   1. 配置LOCAL类型地址池。

      **ADD POOL**

      **说明** 

      - 配置本地地址池的时候，选择参数“LOCAL”类型。
      - UPF分配双栈地址时，需要在本地分别规划配置IPv4类型和IPv6类型的POOL。
   2. 配置地址池里的地址段。

      **ADD SECTION**
   3. 配置地址池组。

      **ADD POOLGROUP**
   4. 配置地址池绑定到地址池组。

      **ADD POOLBINDGROUP**
   5. （可选）配置本地地址池中的冲突IPv4地址，标识为冲突状态的IPv4地址不会分配给用户。

      **ADD CONFLICTIP**
3. 配置地址分配维度，配置基于位置区分配地址。

   1. 打开License配置开关。

      **SET LICENSESWITCH**
   2. 配置基于位置区分配地址的开关。
      - 配置基于位置区分配地址的全局开关。

        **SET IPALLOCBYLOCGLBSW**
      - （可选）如果某一指定位置区的地址分配开关不同于全局位置区地址分配开关，则需执行配置基于指定位置区分配地址的开关。

        **SET IPALLOCBYLOCSW**
   3. 配置位置区。
      - 基于TAC位置区分配地址的时候需要配置本步骤。

        配置TAC位置区组。

        **ADD TACGROUP**

        （可选）在S1TAC组内绑定S1TAC号段。

        **ADD S1TACID**

        （可选）在N2TAC组内绑定N2TAC号段。

        **ADD N2TACID**
      - 基于LAC位置区分配地址的时候需要配置本步骤。

        **ADD LACGROUP**

        **ADD LACID**
   4. 配置TAC-Group/LAC-Group与地址池组的映射关系。

      **ADD **POOLGRPMAP****

      **说明** 

      如果要配置基于多个维度分配IP地址，可配置一条映射关系，同时配置DNN、SMF或位置区与地址池组的映射关系。
   5. 配置基于位置区分配IP地址的白名单，在白名单范围中的用户不参与基于位置区的IP地址分配。

      **ADD ADRLOCWHITELST**
4. 配置地址分配规则。

   **说明** 

   地址分配规则支持两级控制：基于全局和基于APN/DNN。默认使用全局地址分配规则。如果配置了使用基于APN/DNN的地址分配规则，则使用APN/DNN的地址分配规则。

   1. 配置全局地址分配规则优先级。

      **SET IPALLOCRULE**

      **说明** 

      每级优先级规则中所选的条件之间为“与”的关系，表示从所选条件映射的地址范围内分配地址，因此此次设置的规则需要与地址池的映射条件一致。例如此处按照位置区+APN（APN-1&LOCATION-1&SMF-0）设置条件，则规划的地址池组也需绑定LOC&APN。
   2. （可选）如果某一APN/DNN的地址分配规则不同于全局地址分配规则，则需执行配置基于APN的地址分配规则优先级。

      **SET APNIPALLOCRULE**
5. 配置手机下行路由。
   1. 启动OSPF进程。

      **ADD OSPF**
   2. 添加OSPF区域。

      **ADD OSPFAREA**
   3. 配置运行OSPF协议的接口。

      **ADD OSPFNETWORK**
   4. 引入WLR路由。

      **ADD OSPFIMPORTROUTE**
6. 在SMF上执行如下命令：配置UPF为IP地址分配主体，同时配置UPF的IPdomain。

   1. 配置UPF优先为UE分配IP地址。

      **SET ADDRESSATTR**
   2. 配置SMF对接的UPF实例。

      **ADD PNFPROFILE**
   3. 配置SMF对接的UPF节点。

      **ADD UPNODE**
   4. 配置SMF对接的UPF IPdomain。

      **ADD UPIPDOMAIN**

## 任务示例

任务描述

UE接入核心网，采用UPF为UE动态分配IPv4地址。其中第一优先级按照从位置区映射的地址范围内分配地址，如果第一优先级规则匹配不上，则分配地址失败。

脚本

UDG上配置：

//配置APN/DNN。

```
ADD VPNINST:VPNINSTANCE="vpn1";
ADD APN:APN="apn-test",HASVPN=ENABLE,VPNINSTANCE="vpn1";
SET APNADDRESSATTR:APN="apn-test",SUPPORTIPV4=ENABLE,SUPPORTIPV6=ENABLE;
```

//配置地址池绑定到地址池组。

```
ADD POOL:POOLNAME="testpool",POOLTYPE=LOCAL,HASVPN=ENABLE,VPNINSTANCE="vpn1";
```

```
ADD SECTION:POOLNAME="testpool",SECTIONNUM=1,IPVERSION=IPV4,V4STARTIP="10.10.1.11",V4ENDIP="10.10.1.20";
```

```
ADD POOLGROUP: POOLGRPNAME="poolgroup1";
```

```
ADD POOLBINDGROUP: POOLGROUPNAME="poolgroup1", POOLNAME="testpool";
```

基于位置区分配地址

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3G5LBAA01",SWITCH=ENABLE;
```

//配置基于位置区分配地址的开关。

```
SET IPALLOCBYLOCGLBSW: SWITCH=DISABLE, IPV6SWITCH=ENABLE;
```

//配置LAC位置区组。

```
ADD LACGROUP:LACGROUPNAME="lac1";
ADD LACID:LACGROUPNAME="lac1",LACSECNUM=2,LACSTARTID="0x000a",LACENDID="0x000b";
```

//配置LAC位置区组与地址池组的映射关系。

```
ADD POOLGRPMAP: MAPPINGNAME="mapping3", LOCATIONGRPTYPE=LAC, LOCATIONGRPNAME="lac1", POOLGROUPNAME="poolgroup1";
```

//配置基于位置区域地址分配用户白名单，白名单中的用户不基于位置区分配IP地址。

```
ADD ADRLOCWHITELST: MSISDN="123456";
```

//配置地址分配规则。

```
SET IPALLOCRULE: FIRSTRULESW=ENABLE, FIRSTRULE=APN-0&LOCATION-1&SMF-0, SECONDRULESW=DISABLE, THIRDRULESW=DISABLE;
```

//配置手机下行路由。

```
ADD OSPF:PROCID=100,VRFNAME="vpn1",SCHEMAROUID="10.10.10.1";
```

```
ADD OSPFAREA:PROCID=100,AREAID="0.0.0.0";
```

```
ADD OSPFNETWORK:PROCID=100,AREAID="0.0.0.0", IPADDRESS="10.13.21.0", WILDCARDMASK="0.0.0.255";
```

```
ADD OSPFIMPORTROUTE:PROCID=100,TOPOID=0,PROTOCOL=wlr;
```

SMF上配置：

```
SET ADDRESSATTR: ALLOCPRECEDENCE=UPF_FIRST;
```

```
ADD PNFPROFILE: NFINSTANCEID="upf1", NFTYPE=NfUPF,NFSTATUS=Registered, FQDN="GLUPF001BHW",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.107.65.183", PORT=8080;
```

```
ADD UPNODE: NFINSTANCENAME="upf1", LOCATION=Central, UPFUNCTION=None, VPNNAME="vpn1";
```

```
ADD UPIPDOMAIN:UPNODE="upf1", IPDOMAIN="Domain_0", DNNSWITCH=ENABLE, DNN="apn-test";
```
