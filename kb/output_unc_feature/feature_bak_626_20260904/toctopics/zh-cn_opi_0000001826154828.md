# 配置5G服务区域

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

指定UPF支持的服务范围时需要以服务区域为粒度进行分配，因此需增加UPF服务区域，以及UPF服务区名称绑定的5G TAI范围，最后规划对端UPF实例支持的为SMF提供服务区域的信息，将对应的跟踪区添加到UPF的服务区中，使得SMF可以正确选择UPF。若SMF不配置UPF服务区，则不会将对应的跟踪区绑定到UPF，最终导致SMF没有可用UPF资源，附着失败。

## 必备事项

- 已经获取网设LLD文档。

## 操作步骤

1. 配置UPF Service Area。

   ```
   ADD UPAREA:AREANAME="area1", AREATYPE=N2TAI;
   ADD UPAREA:AREANAME="area2", AREATYPE=N2TAI;
   ```
2. 配置UPF Service Area对应的TAI。

   ```
   ADD UPAREABINDN2TAI:AREANAME="area1", N2BEGINTAI="12300000001", N2ENDTAI="1230000001F"; 
   ADD UPAREABINDN2TAI:AREANAME="area1", N2BEGINTAI="12300000030", N2ENDTAI="12300000036"; 
   ADD UPAREABINDN2TAI:AREANAME="area2", N2BEGINTAI="12300000101", N2ENDTAI="1230000011F"; 
   ADD UPAREABINDN2TAI:AREANAME="area2", N2BEGINTAI="12300000130", N2ENDTAI="12300000136";
   ```
3. 配置UPF服务的SMF Service Area。

   ```
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="area1"; 
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_2", SMFSERVINGAREA="area1"; 
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_3", SMFSERVINGAREA="area2"; 
   ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_4", SMFSERVINGAREA="area2";
   ```
4. 配置UPF位置信息与该UPF优选支持的服务区的绑定关系。

   ```
   ADD LOCBINDAREA:LOCALITY="locality1", AREANAME="area1"; 
   ADD LOCBINDAREA:LOCALITY="locality2", AREANAME="area2";
   ```
