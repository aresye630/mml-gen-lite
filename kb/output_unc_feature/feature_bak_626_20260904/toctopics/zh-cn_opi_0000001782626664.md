# 配置到对端SMSF的信息

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

在AMF本地配置到对端SMSF网元的连接。AMF拜访SMSF网元的主要目的是为了支持用户短消息的相关服务。添加信息主要包含：

- 添加对端SMSF网元的基本信息。
- 添加对端SMSF网元的PLMN信息。
- 添加对端SMSF网元的实例服务信息。
- 添加对端SMSF网元的SUPI信息。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置到SMSF的数据，包括SMSF的Profile、Service、支持的SUPI、PLMN等信息。

   ```
   ADD PNFPROFILE:NFINSTANCEID="SMSF_Instance_0", NFTYPE=NfSMSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.2.180.15", PORT=8080, PRIORITY=0;
   ADD PNFSERVICE:NFINSTANCEID="SMSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmsfSms, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSUPI: INDEX=1, NFINSTANCEID="SMSF_Instance_0", QUERYTYPE=START_END, RANGESTART="123030000000000", RANGEEND="123031000000000";
   ADD PNFPLMN:NFINSTANCEID="SMSF_Instance_0", MCC="123", MNC="03";
   ```
