## 操作场景

运营商根据UNC本地配置的QoS参数对用户数据进行控制。

**说明** 

适用于SMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-109203 本地QOS控制特性概述。
- 完成配置普通APN**ADD APN** 。

## 操作流程

如果APN下绑定了Qos-profile，则使用Qos-profile下的规则；否则使用QosGlobal下的规则。

全局和APN绑定Qos-profile控制方式相同，都可绑定本地签约QoS，具体如下：获取绑定的Qos-profile，根据Qos-profile下绑定的**ADD 5GCQOSACTION**配置，根据QCI对应的带宽/THP门限进行比较，如果超过则根据动作进行降级还是拒绝用户接入。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. **可选**：更改缺省的ARP和标准5QI的对应关系

   **SET QCI2ARP**
3. **可选**：配置本地签约的QoS信息。

   **ADD 5GCSUBQOS**
4. 配置5G QoS纠错参数。

   **SET 5GCQOSCORRT**
5. 设置全局的QoS信息。

   **SET QOSGLOBAL**
6. 配置基于APN的QoS策略。

   - 配置指定APN实例下的QosProfile名称，并进入QoS实例。

     **ADD QOSPROFILE**
   - 配置5G用户QoS上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作。

     **ADD 5GCQOSACTION**
   - 配置APN实例。

     **ADD APN**
   - 为APN实例绑定QoS profile。

     **SET APNQOSATTR**

## 任务示例

任务描述

UNC对用户携带的QoS进行控制，然后对用户流量进行监管。

脚本

- **可选**：更改缺省的ARP和标准5QI的对应关系

  ```
  SET QCI2ARP:QCI=1,ARPPCI=0,ARPPL=1,ARPPVI=0;
  ```
- **可选**：配置本地签约的QoS信息。

  ```
  ADD 5GCSUBQOS:FIVEQI=5, QOS5QIPL=2, ARPPL=2, AMBRDL=1111, AMBRUL=2222,SUBQOSINDEX=203;
  ```
- 配置5G QoS纠错参数。

  ```
  SET 5GCQOSCORRT:FIVEQI=5, QOS5QIPL=10, ARPVALUE=3, AMBRDL=20000,AMBRUL=20000,GFBRUL=4000,GFBRDL=4000,MFBRUL=5000,MFBRDL=5000;
  ```
- 配置基于全局的EPS QoS信息。

  ```
  SET QOSGLOBAL:QOSPROFILENAME="qos2",BINDEPSSUBQOS=ENABLE,EPSSUBQOS=203;
  ```
- 配置基于APN的QoS。

  //配置指定APN实例下的QosProfile名称，并进入QoS实例。

  ```
  ADD QOSPROFILE:QOSPROFILENAME="qos1",BINDEPSSUBQOS=ENABLE,EPSSUBQOS=203;
  ```

  //配置QoS上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作。

  ```
  ADD 5GCQOSACTION:QOSPROFILENAME="qos1",FIVEQI=2;
  ```

  //进入指定APN实例。

  ```
  ADD APN:APN="apn1";
  ```

  //为该APN实例绑定QosProfile。

  ```
  SET APNQOSATTR:APN="apn1",HASQOSPROFILE=ENABLE,QOSPROFILENAME="qos1";
  ```
