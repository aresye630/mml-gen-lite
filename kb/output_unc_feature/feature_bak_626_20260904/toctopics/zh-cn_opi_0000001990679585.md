## 操作场景

本指导描述UNC离线计费模板相关参数的配置过程。离线计费参数可基于User Profile、APN、Charge Characteristic、全局多个层次进行配置，优先级依次降低。如果高一级的计费参数模板没有配置，则取用下一级的计费参数配置模板。

## 必备事项

前提条件

- 请仔细阅读Ga/Gy接口离线/在线计费。

- 已完成计费属性、APN、User Profile创建。

## 操作步骤

1. 配置离线计费模板下的计费参数。
   1. 配置话单版本信息、产生话单的时间格式、Record Sequence Number字段的起始值、定时器QHT信息和计费方式等。

      **ADD OFCTEMPLATE**
   2. 配置阈值信息。

      **SET OFCTHRESHOLD**
   3. 配置话单产生条件。

      **SET CDRTRIGGER**
   4. 配置话单容器产生条件。

      **SET CONTAINERTRIGGER**
2. 配置离线计费模板绑定User Profile对象。

   **SET USRPROFCHARGE**
3. 配置离线计费模板绑定APN对象。

   **SET APNCHARGECTRL**
4. 配置离线计费模板绑定计费属性CC。

   **ADD GLBOFCTEMPLATE**
5. 配置离线计费模板绑定全局。

   **ADD GLBOFCTEMPLATE**
6. 配置SP合一用户只产生PGW-CDR还是同时产生SGW-CDR和PGW-CDR话单。

   **SET OFCCDRPARA**

## 任务示例

任务描述

任务一：配置User Profile up-test的离线计费参数。

任务二：配置APN实例apn-test的离线计费参数。

任务三：基于计费属性配置离线计费参数。

任务四：配置全局的离线计费参数。

任务五：配置SP合一用户只产生PGW-CDR。

脚本

1. 配置计费参数模板参数。

   ```
   ADD OFCTEMPLATE:OFCTEMPLATENAME="offlinecharge-test", GCDRVERSION=R10_PGW_CDR, PGWCDRVERSION=R10_PGW_CDR, SGWCDRVERSION=R10_SGW_CDR, TQM=QCT, QCTVALUE=0, RECORDSEQNUMBER=1, CDRTIMEFORMAT=LOCAL_TIME, QHTVALUE=0;
   ```

   ```
   SET OFCTHRESHOLD:OFCTEMPLATENAME="offlinecharge-test", THRESHINHERIT=NON_INHERIT, TIMETHRESHOLD=120, VOLUMETHRESHOLD=10240, MINVOLTHRESHOLD=20, CONDITIONCHANGE=3, SERVINGNODECHNG=3, MAXSVCCONTAINER=20, TIMETHRESHCCFH=4294967295, VOLTHRESHCCFH=9000000001, SECRUTHRESHOLD=3;
   ```

   ```
   SET CDRTRIGGER:OFCTEMPLATENAME="offlinecharge-test", CDRTRIGRATCHNG=ENABLE, CDRTRIGSNCHNG=ENABLE, CDRTRIGMAXCHNG=ENABLE, CDRTRIGTIMEZONE=ENABLE, CDRTRIGPLMNCHNG=ENABLE, CDRTRIGMOEXC=ENABLE;
   ```

   ```
   SET CONTAINERTRIGGER:OFCTEMPLATENAME="offlinecharge-test", CONTTRIGRATCHNG=ENABLE, CONTTRIGQOSCHNG=ENABLE, CONTTRIGSNCHNG=ENABLE, CONTTRIGCGISAI=DISABLE, CONTTRIGECGI=DISABLE, CONTTRIGTAI=DISABLE, CONTTRIGULI=DISABLE, CONTTRIGPLMNID=ENABLE, CONTTRIGRAI=DISABLE, CONTTRIGTARRIF=ENABLE, PCCINIT=DISABLE, CONTTRIGENB=ENABLE, USERPLANECHNG=ENABLE, SPLMNRATECHNG=ENABLE, APNRATECHNG=ENABLE, APNRATECHNGCLOSECAUSE=SERVINGPLMN_RATE_CONTROL_CHANGE;
   ```
2. 任务一：配置User Profile up-test的离线计费参数。

   ```
   SET USRPROFCHARGE:USRPROFNAME="up-test", PGWOFCTEMPLATE="offlinecharge-test",SGWOFCTEMPLATE="offlinecharge-test",GGSNOFCTEMPLATE="offlinecharge-test";
   ```
3. 任务二：配置APN实例apn-test的离线计费参数。

   ```
   SET APNCHARGECTRL: APN="apn-test",PGWOFCTEMPLATE="offlinecharge-test",SGWOFCTEMPLATE="offlinecharge-test", GGSNOFCTEMPLATE="offlinecharge-test";
   ```
4. 任务三：基于计费属性配置离线计费参数。

   ```
   ADD GLBOFCTEMPLATE:GLOBALFLAG=CHARGE_CHARACT,CCVALUE="0x0800",CCMASK="0xFFFF",CCPRIORITY=1,PGWTEMPLATE="offlinecharge-test",SGWTEMPLATE="offlinecharge-test", GGSNTEMPLATE="offlinecharge-test";
   ```
5. 任务四：配置全局的离线计费参数。

   ```
   ADD GLBOFCTEMPLATE:GLOBALFLAG=GLOBAL,PGWTEMPLATE="offlinecharge-test",SGWTEMPLATE="offlinecharge-test", GGSNTEMPLATE="offlinecharge-test";
   ```
6. 任务五：配置SP合一用户只产生PGW-CDR。

   ```
   SET OFCCDRPARA:SPCDRCONTROL=PGW-CDR;
   ```
