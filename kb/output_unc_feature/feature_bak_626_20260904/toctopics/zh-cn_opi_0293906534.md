## 操作场景

该场景根据整体方案设计需配置1个业务，该业务挂载1个策略，该策略包含3个规则：

- 规则1（Rule\_Gold），详细内容规划如下：
  - 条件：Subscriber.Category=Gold
  - 动作：ratingGroup=11，maxbrUL=100 Mbps，maxbrDL=100 Mbps
- 规则2（Rule\_Silver），详细内容规划如下：
  - 条件：Subscriber.Category=Silver
  - 动作：ratingGroup=22，maxbrUL=50 Mbps，maxbrDL=50 Mbps
- 规则3（Rule\_Normal），详细内容规划如下：
  - 条件：Subscriber.Category=Normal
  - 动作：ratingGroup=33，maxbrUL=10 Mbps，maxbrDL=10 Mbps

## 对系统的影响

该业务对系统无影响。

## 必备事项

前提条件

已通过学习SM策略E2E实现原理、业务配置方法及业务调测方法了解了SM策略的配置原理及方法。

数据

无。

**说明** 

- 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
- 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与/或关系由参数“关系”的取值决定。

配置“5G动作组”。

导航入口为“策略管理 > 策略 > 5G动作组”。

**说明** 

此场景配置5G动作组需要考虑流信息、业务流开关、计费控制和带宽调整，则需配置动作：FlowInformation、TrafficControlData、ChargingData和QoSData。相关应用场景如下：

- FlowInformation：当需要下发流信息时需配置此动作。
- TrafficControlData：当需要做门限控制时，配置此动作。在下发流描述时，如果不配默认为放通该流，当需要限制流时，此动作必须配置。
- ChargingData：当需要做计费策略控制时，配置此动作。
- QoSData：当需要进行带宽控制时，配置此动作。

根据业务配置逻辑章节介绍的5G场景中QoS Flow的建立方法，此处示例采用“仅使用DynamicPccRule类型动作建立缺省QoS Flow”的方法进行配置。根据整体方案设计步骤可知，该业务场景须建立三条规则，对应了需要配置3个“DynamicPccRule”类型的5G动作组，分别用于在用户等级为金牌用户，用户等级为银牌用户和用户等级为普通用户时动作的下发。详细动作组参数可参见“UPCF产品文档>UPCF WebUI GUI参考>策略管理>5G动作组”。

  执行**ADD PSUB**增加一个金牌用户。

  ```
  ADD PSUB: USRIDENTIFIER="46000120010****", USRMSISDN="861390010****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRCATEGORY="Gold", USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA, USRLANGUAGE=NULL, USRSMSRECEIVEFLAG=All, USRVERSTATUS=Normal;
  ```

  **说明** 

  - “USRIDENTIFIER”的参数类型受UPCF软参“VRM\_SUBSRCIPTIONIDTYPE（系统支持的用户类型）”控制，默认为“IMSI”。
  - “USRCATEGORY”字段定义了用户类别/等级属性，通过执行**MOD PSUB**修改用户等级为Silver（银牌用户）、Normal（其他用户等级）。

- **业务发放。**

  在“UPCF PGW Web LMT>UPCF 业务管理”窗口继续执行**ADD PSRV**给用户签约业务。

  ```
  ADD PSRV: USRIDENTIFIER="46000120010****", SRVNAME="Usr_Category_Service", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
  ```
