# 激活设备标识检查特性（适用于4G）

- 操作场景
- 必备事项

- 任务示例

## 操作场景

本操作指导介绍在运行的4G网络中激活设备标识检查功能的操作过程。

**说明** 

适用于MME。

## 必备事项

前提条件

- 请仔细阅读WSFD-103004 设备标识检查特性概述（适用于4G）。
- EIR已激活设备标识检查功能。
- 完成EIR对接配置。MME通过S13接口对接4G网络EIR时，请参考配置到EIR的数据。MME与AMF融合部署且通过N17接口对接5G-EIR时，请参考配置SBI接口。
- 完成加载License。

数据

| 类别            | 参数名称                          | 取值样例     | 获取方法   | 说明                                                               |
|:--------------|:------------------------------|:---------|:-------|:-----------------------------------------------------------------|

| MOD S1IMEICFG | IMEI获取策略（GETIMEIPLC）          | IMEISV   | 全网规划   | -                                                                |

| MOD S1IMEICFG | EIR接口类型（ITTYPE）               | S13      | 全网规划   | MME通过S13接口对接4G网络EIR时，配置为S13。MME与AMF融合部署且通过N17接口对接5G-EIR时，配置为N17。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**:
3. 设置4G网络设备标识获取和检查策略。

   **MOD S1IMEICFG**

## 任务示例

任务描述

在4G网络中启用设备标识检查功能，配置IMEI获取策略为优先获取IMEISV，实现对所有用户使用S13接口进行IMEI检查。IMEI获取失败允许接入，IMEI检查超时允许接入，允许灰名单用户接入，不允许黑名单用户接入，允许EIR返回用户原因失败时接入，允许EIR返回设备原因失败时接入，EIR响应超时时长为5。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2EIR02", SWITCH=ENABLE;
```

//设置4G网络获取和检查IMEI的策略。

```
MOD S1IMEICFG: SUBRANGE=ALL_USER, GETIMEIPLC=IMEISV, CHKIMEIPLC=IMEISV, ITTYPE=S13, IMEIACCESS=YES, CTFLAG=YES, GRALLOW=YES, BLALLOW=NO, USERERR=YES, PROVIDERR=YES, EIROUTTIMER=5;
```
