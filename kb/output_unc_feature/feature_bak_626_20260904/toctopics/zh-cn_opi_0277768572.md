## 操作场景

本操作指导介绍在运行网络中激活Nnrf接口流控功能的操作过程。

**说明** 

适用于NRF。

## 必备事项

前提条件

请仔细阅读WSFD-010802 周边网元过载保护特性概述（Nnrf接口流控功能特性概述）。

数据

| 类别                  | 参数名称                            | 取值样例     | 获取方法   | 说明                                           |
|:--------------------|:--------------------------------|:---------|:-------|:---------------------------------------------|
| SET NRFNOTIFYFCPARA | NFPROFILE变更事件流控开关（FCSWITCH）     | FUNC_ON  | 本端规划   | 设置NRF每秒处理NFPROFILE变更事件的流控功能信息。               |
| SET NRFNOTIFYFCPARA | 每秒处理NFPROFILE变更事件的数量（FCTHD）     | 200      | 本端规划   | 设置NRF每秒处理NFPROFILE变更事件的流控功能信息。               |
| SET NRFNOTIFYFCPARA | 失败通知重传流控开关（RSDFCSWITCH）         | FUNC_OFF | 本端规划   | 设置NRF每秒处理NFPROFILE变更事件的流控功能信息。               |
| SET NOTIFYRSDPARA   | 失败通知重传开关（NOTIFYRSDSW）           | FUNC_OFF | 本端规划   | 配置NRF不重新发送那些发送失败的通知消息。                       |
| SET NRFNOTIFYFCPARA | NF更新事件缓冲最长时长(秒)（NFCHGCACHETHD）  | 900      | 本端规划   | 设置NRF针对同一频繁变更的NF的多长时间内的变更事件合并。               |
| SET NRFNOTIFYFCPARA | NF更新事件最短缓冲时长(秒)（NFCHGCACHETIME） | 50       | 本端规划   | 设置多长时间内同一个NF超过1次变更就识别此NF为频繁变更，需要对其变更通知做抑制合并。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 设置NRF每秒处理NFPROFILE变更事件的流控功能。

   **SET NRFNOTIFYFCPARA**
3. 配置NRF状态通知失败时重传的参数。

   **SET NOTIFYRSDPARA**
4. 设置NRF平滑通知参数，合并变更通知。

   **SET NRFNOTIFYFCPARA**

## 任务示例

任务描述

系统过载时，启动自保流控。

脚本

//设置基于CPU过载流控开关。

```
SET FCSWITCH: SWITCH=ENABLE;
```

//设置NRF每秒处理NFPROFILE变更事件的流控功能。

```
SET NRFNOTIFYFCPARA:FCSWITCH=FUNC_ON, FCTHD=200, RSDFCSWITCH=FUNC_OFF;
```

//配置NRF状态通知失败时重传的参数。

```
SET NOTIFYRSDPARA:NOTIFYRSDSW=FUNC_OFF;
```

//配置NRF平滑通知参数，抑制合并变更通知。

```
SET NRFNOTIFYFCPARA:NFCHGCACHETHD=900, NFCHGCACHETIME=50;
```
