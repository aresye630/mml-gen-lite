# 配置UDM

- 操作场景
- 必备事项
- 任务示例

## 操作场景

该任务旨在指导操作人员配置一跳入家网关全局数据。

## 必备事项

前提条件

操作人员具有PGW Web LMT的操作权限。

数据

| 类别          | 参数名称                                      | 取值样例               | 获取方法   | 说明                                                          |
|:------------|:------------------------------------------|:-------------------|:-------|:------------------------------------------------------------|
| SET UDMSERV | 支持智家随行业务（SUPP_TOHOME）                     | TRUE               | 本端规划   | 用于标识UDM是否支持一跳入家业务。                                          |
| SET UDMSERV | 5GLAN支持签约相同的DNN和切片（GROUPID_MULTIDNNSILCE） | FALSE              | 本端规划   | 用于标识当执行ADD GROUPID命令给用户签约5G LAN群组时，是否可以签约多个数据网名称和切片标识相同的群组。 |
| ADD VNGROUP | HLR序列号（HLRSN）                             | 1                  | 全网规划   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                |
| ADD VNGROUP | 内部组ID（INGROUPID）                          | 1001-46008-01      | 本端规划   | 用于标识移动网络内部设备之间通信时互相传递的组ID。在该特性中，该参数指的是家庭群组ID。               |
| ADD VNGROUP | 外部组ID（EXTGROUPID）                         | group01@huawei.com | 本端规划   | 用于标识移动网络对外能力开放接口中提供的组ID。                                    |
| ADD VNGROUP | 共享数据ID（SHAREDID）                          | 46008-huawei02     | 本端规划   | 用于标识为内部组创建的共享数据的ID。                                         |
| ADD VNGROUP | 切片标识（SNSSAI）                              | 1-010101           | 本端规划   | 用于标识5G系统中的网络切片。                                             |
| ADD VNGROUP | 数据网名称（DNN）                                | home.area1.dnn     | 本端规划   | 用于标识数据网名称。                                                  |
| ADD VNGROUP | 允许的PDU类型（PDUTYPES）                        | IPV4               | 固定配置   | 用于标识允许的PDU类型。                                               |

## 任务示例

任务描述

任务1：大网UDM和一跳入家UDM合一部署场景下，为某家庭的1个家庭网关、2个家庭成员进行一跳入家业务签约。

任务2：大网UDM和一跳入家UDM分离部署场景下，为某家庭的1个家庭网关、2个家庭成员进行一跳入家业务签约。

脚本

**任务1脚本：**

1. 登录“UDM业务管理”窗口。
2. 执行**SET UDMSERV**命令设置UDM支持一跳入家功能。

   ```
   SET UDMSERV: SUPP_TOHOME=TRUE;
   ```
3. 执行**ADD VNGROUP**命令增加一跳入家使用的5G LAN群组（家庭组）。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="home.area1.dnn", PDUTYPES=IPV4;
   ```

**任务2脚本：**

1. 登录一跳入家UDM的“UDM业务管理”窗口。
2. 执行**SET UDMSERV**命令设置UDM业务数据。

   ```
   SET UDMSERV: SUPP_TOHOME=TRUE, GROUPID_MULTIDNNSILCE=FALSE;
   ```
3. 执行**ADD VNGROUP**命令增加一跳入家使用的5G LAN群组（家庭组）。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="home.area1.dnn", PDUTYPES=IPV4;
   ```

   **说明** 

   大网UDM和一跳入家UDM分离部署场景下，该步骤在大网UDM和一跳入家UDM配置的数据需要保持一致。
4. 登录大网UDM的“UDM业务管理”窗口。
5. 执行**SET UDMSERV**命令设置UDM业务数据。

   ```
   SET UDMSERV: GROUPID_MULTIDNNSILCE=FALSE;
   ```
6. 执行**ADD VNGROUP**命令增加一跳入家使用的5G LAN群组。

   ```
   ADD VNGROUP: HLRSN=1, INGROUPID="1001-46008-01", EXTGROUPID="group01@huawei.com", SHAREDID="46008-huawei02", SNSSAI="1-010101", DNN="home.area1.dnn", PDUTYPES=IPV4;
   ```
