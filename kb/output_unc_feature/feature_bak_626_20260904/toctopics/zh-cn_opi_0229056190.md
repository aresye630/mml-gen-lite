## 操作场景

为了保证用户公平使用流量，需要配置基于会话级的累计流量的策略控制。

- PGW-C/SMF与PCF之间通过N7接口交互时，会话级的累计流量仅需在PCF上进行配置，本端PGW-C/SMF不需要专有配置。
- GGSN/PGW-C与PCRF之间通过Gx接口交互时，需要参考本页面进行配置。

## 必备事项

前提条件

- 请仔细阅读WSFD-109104 基于累计流量的策略控制。
- 请仔细阅读PCC基本功能（2G/3G/4G，基于Gx接口）。
- 完成激活PCC基本功能。
- 完成加载License（如果有需求，请联系华为技术支持工程师处理）。

数据

| 类别               | 参数名称                                   | 取值样例            | 获取方法     | 说明                                 |
|:-----------------|:---------------------------------------|:----------------|:---------|:-----------------------------------|
| SET PCCFUNC      | Monitoring-Key的解析方式（MKPARSEFORMAT）     | UNSIGNED32      | 与对端协商    | 该参数需要与PCRF保持一致。                    |
| MOD PCRF         | PCRF主机名（HOSTNAME）                      | pcrf_01         | 已配置数据中获取 | 使用ADD PCRF定义的PCRF主机名。              |
| MOD PCRF         | Supported-Features动态协商开关（SUPFEANEGOSW） | ENABLE          | 与对端协商    | 使用样例值。                             |
| MOD PCRF         | Feature列表（FEATURELIST）                 | UMCH            | 与对端协商    | PCRF需要支持UMCH功能。                    |
| MOD PCCPOLICYGRP | PCC策略组名称（PCCPOLICYGRPNM ）              | pccpolicygrp_01 | 已配置数据中获取 | 使用ADD PCCPOLICYGRP定义的PCC策略组名称。     |
| MOD PCCPOLICYGRP | Session级FUP累计标识（FUPSESSIONEXC ）        | ENABLE          | 本端规划     | ENABLE表示该PCC策略组对应的业务不计入Session级流量。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 设置累计流量的上报方式。

   **SET PCCFUNC**
4. 与PCRF通过Gx接口交互时，使能流量监控拥塞处理（UMCH）功能。

   **MOD PCRF**
5. 配置将某类业务/应用的流量不统计到会话级流量。

   **MOD PCCPOLICYGRP**

   “Session级FUP累计标识（FUPSESSIONEXC）”默认值为“DISABLE”，表示该PCC策略组对应的业务计入Session级流量。

## 任务示例

任务描述

Gx接口采用3GPP标准的Usage Monitoring机制实现会话级累计流量策略控制。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3W9PCBT12",SWITCH=ENABLE;
```

//设置累计流量的上报方式。

```
SET PCCFUNC:MKPARSEFORMAT=UNSIGNED32;
```

//使能流量监控拥塞处理（UMCH）功能。

```
MOD PCRF: HOSTNAME="pcrf_01",SUPFEANEGOSW=ENABLE,FEATURELIST=UMCH-1;
```

//配置将某类业务/应用的流量不统计到会话级流量。

```
ADD PCCPOLICYGRP:PCCPOLICYGRPNM="pccpolicygrp_01", FUPSESSIONEXC=ENABLE;
```
