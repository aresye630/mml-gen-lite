# 配置会话管理参数

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

配置PGW-C本局数据的基本流程包括：开始→配置APN信息→结束。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- 已经获取网设LLD文档。

数据

**说明** 

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别               | 参数名称                        | 取值样例        | 获取方法   | 说明            |
|:-----------------|:----------------------------|:------------|:-------|:--------------|
| ADD APN          | APN名称（APN）                  | huawei1.com | 本端规划   | 配置APN。        |
| ADD APN          | 虚拟APN（VIRTUALAPN）           | DISABLE     | 本端规划   | 配置APN。        |
| ADD APN          | 绑定VPN（HASVPN）               | DISABLE     | 本端规划   | 配置APN。        |
| SET UEDNSBINDAPN | APN名称（APN）                  | huawei.com  | 本端规划   | 已通过ADD APN配置。 |
| SET UEDNSBINDAPN | IPv4主DNS服务器IP（MDNSSERVERV4） | 10.10.1.1   | 本端规划   | -             |
| SET UEDNSBINDAPN | IPv4备DNS服务器IP（BDNSSERVERV4） | 10.10.1.2   | 本端规划   | -             |
| SET UEDNSBINDAPN | IPv4 第一优先级服务器属性（FIRMODEV4）  | LOCAL       | 本端规划   | -             |

文档

获取网设LLD文档。

## 操作步骤

1. 配置PGW-C支持的APN。

   ```
   ADD APN:APN="huawei.com", VIRTUALAPN=DISABLE, HASVPN=DISABLE;
   ```
2. 在使用DNS服务器场景下，配置指定APN的DNS属性。

   ```
   SET UEDNSBINDAPN:APN="huawei.com", MDNSSERVERV4="10.10.1.1", BDNSSERVERV4="10.10.1.2";
   ```
