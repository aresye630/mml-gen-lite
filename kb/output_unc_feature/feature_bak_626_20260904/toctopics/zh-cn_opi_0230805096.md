# 配置与PCRF对接数据

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当部署PCC基本功能，实现通过PCRF为用户指定控制策略，则需要配置UNC到PCRF的互通数据。

**说明** 

适用于GGSN、PGW-C。

## 必备事项

前提条件

- 请仔细阅读PCC基本功能（2G/3G/4G，基于Gx接口）。
- 操作员了解UNC各类接口的类型及命名规范，具体内容请参见SGW-C、PGW-C、GGSN。
- 操作员了解UNC与对端网元互通时可以采用的各种组网方式，以及每种组网方式的实现及特点等信息。
- 如果运营商规划采用VPN组网方式，则操作员在执行本操作前应已创建了相应的VPN实例。
- 需要配置逻辑接口的PBU正常运行，且PBU上无用户存在。当PBU还未启动或正在启动过程中，将无法在该PBU上配置逻辑接口。

## 操作步骤

1. 配置外联口IP及路由数据，详细请参见组网路由配置。
2. 进入“MML命令行-UNC”窗口。
3. 创建一个VPN实例。

   **ADD VPNINST**
4. **可选：**配置Gx接口Diameter应用集中点模式。缺省情况下，本端的端口号不可配，使用系统自动分配的端口号。

   **SET CONCENPOINT**
5. 配置Gx逻辑接口。
   1. 配置逻辑IP地址。

      **ADD LOGICIP**
   2. 配置Gx逻辑接口。

      **ADD LOGICINF**

   **说明** 

   **ADD LOGICINF**中的“IP地址+VPN实例名称”和**ADD LOGICIP**命令中的“IP地址+VPN实例名称”必须一致。
6. 配置GGSN/PGW-C的设备标识。

   **ADD DIAMLOCINFO**
7. 配置PCRF的信息。
   1. 配置PCRF的设备标识。

      **ADD PCRF**

      **说明** 

      - PCRF绑定的VPN实例必须和Gx逻辑接口绑定的VPN实例一致。
      - 如果GGSN/PGW-C与PCRF之间在TCP传输模式下采用多Diameter链路组网模式，则需要配置多个PCRF IP地址和端口，并配置链路选择模式“SELECTMODE”。
      - 如果需要与指定PCRF进行Supported Features动态协商，则需要将**ADD PCRF**命令中的“SUPFEANEGOSW”参数设置为“ENABLE”，并选择对应的feature选项，且添加到同一个PCRF Group中的PCRF支持的feature能力必须一致。
      - 根据PCRF的接收能力，通过设置“WAL”参数以限制向PCRF发送的消息数。
   2. 如果supported-features-negotiation功能使能，且需要定时或手工删除本地缓存的对端PCRF能力，需要配置动态协商定时器的时长，缺省使用默认值。

      **SET PCCTIMER**
   3. 配置PCRF地址信息。

      **ADD DIAMPEERADDR**
8. 配置到PCRF的链路组信息。

   **ADD DIAMCONNGRP**
9. 配置到PCRF的链路。

   **ADD DIAMCONNECTION**

   **说明** 

   - 配置链路时如果不选择地址类型，则表示本端接口与对端主机的全部地址建立链接。
   - 当“Gx集中点模式”通过**SET CONCENPOINT**命令选择为“LOCALPORT”时，可使用**ADD DIAMCONNECTION**命令设置本端的端口号。

   **同一PGW-C对接多个PGW-U，且不同PGW-U下的用户IP存在相同时，必须执行步骤 10~步骤 16；IP地址不同时，可不配置步骤 10~步骤 16。**
10. 配置Diameter本端主机组。

    **ADD LOCALHOSTGRP**
11. 配置Diameter本端主机与Diameter本端主机组的关联关系。

    **ADD LOCALHOSTBIND**
12. 配置UPF组。

    **ADD GXUPFGROUP**
13. 添加UPF到UPF组中。

    **ADD UPFBINDGXUPFGRP**
14. 配置UPF组与Diameter本端主机组的绑定关系组。

    **ADD UPFGLOCGBNDGRP**
15. 配置UPF组与Diameter本端主机组的绑定关系。

    **ADD UPFGBINDLOCG**
16. 设置PCC本端主机名选择模式。
    - 基于APN设置PCC本端主机名选择模式。
      1. 增加PCC模板。

         **ADD PCCTEMPLATE**
      2. 将PCC模板与APN绑定。

         **SET APNPCCFUNC**
    - 基于全局设置PCC本端主机名选择方式。

      **SET PCCFUNC**
17. **可选：**NB-IoT用户接入场景，设置PGW-C向PCRF/PCF发送消息时的RAT信元值。

    **SET NBIOTRATVALUE**: PCRF=EUTRAN\_NB\_IOT, PCF=EUTRAN\_NB\_IOT;

    - 对接PCRF/PCF支持**EUTRAN-NB-IoT**类型时，“PCRF”/“PCF”设置为“EUTRAN\_NB\_IOT”，PGW-C向PCRF/PCF发送NB-IoT用户的相关消息时，RAT信元值为“EUTRAN-NB-IOT”。系统初始值为“EUTRAN\_NB\_IOT”。
    - 对接PCRF/PCF不支持**EUTRAN-NB-IoT**类型时，“PCRF”/“PCF”设置为“EUTRAN”，PGW-C向PCRF/PCF发送NB-IoT用户的相关消息时，RAT信元值为“EUTRAN”。“PCRF”设置为“EUTRAN”时，还需要开启PCRF免升级License，详细操作请参见激活PCRF免升级。
18. **可选：**LTE-M用户接入场景，设置PGW-C向PCRF/PCF发送消息时的RAT信元值。

    **SET LTEMRATVALUE**: PCRF=LTE\_M, PCF=LTE\_M;

    - 对接PCRF/PCF支持**LTE-M**类型时，“PCRF”/“PCF”设置为“LTE\_M”，PGW-C向PCRF/PCF发送LTE-M用户的相关消息时，RAT信元值为“LTE-M”。系统初始值为“LTE\_M”。
    - 对接PCRF/PCF不支持**LTE-M**类型时，“PCRF”/“PCF”设置为“EUTRAN”，PGW-C向PCRF/PCF发送LTE-M用户的相关消息时，RAT信元值为“EUTRAN”。

## 任务示例

任务描述

任务一：同一PGW-C下的不同PGW-U下的用户IP不同。

- GGSN/PGW-C使用逻辑接口与PCRF连通。
- GGSN/PGW-C使用VPN缺省路由与PCRF建立起正常的IP连接。

任务二：同一PGW-C下的两个PGW-U的用户IP存在相同的情况。

- GGSN/PGW-C使用逻辑接口与PCRF连通。
- GGSN/PGW-C使用VPN缺省路由与PCRF建立起正常的IP连接。
- 该APN下的两个PGW-U的用户IP存在相同的情况，其他APN不存在。
- PCRF要求UE IP + GxLocalHost能唯一确定一个用户。

脚本

**任务一脚本如下：**

1. 参考组网路由配置配置外联口IP及路由。
2. 创建一个VPN实例。

   ```
   ADD VPNINST:VPNINSTANCE="vpn_gxif";
   ```
3. 配置Gx接口Diameter应用集中点模式。

   ```
   SET CONCENPOINT: GXCONCENMODE=LOCALPORT;
   ```
4. 配置Gx逻辑接口。

   ```
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.8.10.1", VPNINSTNAME="vpn_gxif";
   ADD LOGICINF:NAME="gxif1/0/0",IPVERSION=IPV4,IPV4ADDRESS1="10.8.10.1",IPV4MASK1="255.255.255.255",VPNINSTANCE="vpn_gxif";
   ```

   ```
   ADD LOGICIP: IPVERSION=IPv4, LOGICIPV4="10.8.10.2", VPNINSTNAME="vpn_gxif";
   ADD LOGICINF:NAME="gxif1/0/1",IPVERSION=IPV4,IPV4ADDRESS1="10.8.10.2",IPV4MASK1="255.255.255.255",VPNINSTANCE="vpn_gxif";
   ```
5. 配置PCRF信息。

   配置GGSN/PGW-C的设备标识。

   ```
   ADD DIAMLOCINFO:HOSTNAME="pgw_1",REALMNAME="huawei.com", PRODUCTNAME="unc@huawei.com";
   ```

   配置PCRF设备标识。其中GGSN/PGW-C与pcrf1之间建立一条Diameter链路，与pcrf2之间建立两条Diameter链路，不同的用户会话将负荷分担到不同链路上。

   ```
   ADD PCRF:HOSTNAME="pcrf_1",REALMNAME="example.com",VPNINSTANCE="vpn_gxif",SUPFEANEGOSW=ENABLE,FEATURELIST=RELEASE8-1&RELEASE9-1&RELEASE10-1;
   ```

   ```
   ADD PCRF:HOSTNAME="pcrf_2",REALMNAME="example.com",VPNINSTANCE="vpn_gxif",SUPFEANEGOSW=ENABLE,FEATURELIST=RELEASE8-1&RELEASE9-1&RELEASE10-1;
   ```

   ```
   ADD DIAMPEERADDR:HOSTNAME="pcrf_1",ADDRTYPE=IPv4,IPV4ADDRESS="10.11.21.59";
   ```

   ```
   ADD DIAMPEERADDR:HOSTNAME="pcrf_2",ADDRTYPE=IPv4,IPV4ADDRESS="10.11.21.60";
   ```

   ```
   ADD DIAMPEERADDR:HOSTNAME="pcrf_2",ADDRTYPE=IPv4,IPV4ADDRESS="10.11.21.61";
   ```

   ```
   ADD DIAMCONNGRP:CONNGROUPNAME="dconn_pcrf1",LOCALHOSTNAME="pgw_1",APPLICATION=GX,PEERHOSTNAME="pcrf_1",SELECTMODE=SESSION_ID;
   ```

   ```
   ADD DIAMCONNGRP:CONNGROUPNAME="dconn_pcrf2",LOCALHOSTNAME="pgw_1",APPLICATION=GX,PEERHOSTNAME="pcrf_2",SELECTMODE=ROUND_ROBIN;
   ```

   ```
   ADD DIAMCONNECTION:DIAMCONNGRP="dconn_pcrf1",LOCINTERFACE="gxif1/0/0",PEERADDRTYPE=IPv4,PEERIPV4ADDR="10.11.21.59",LOCALPORT=16450;
   ```

   ```
   ADD DIAMCONNECTION:DIAMCONNGRP="dconn_pcrf2",LOCINTERFACE="gxif1/0/1",PEERADDRTYPE=IPv4,PEERIPV4ADDR="10.11.21.60",LOCALPORT=16451;
   ```

   ```
   ADD DIAMCONNECTION:DIAMCONNGRP="dconn_pcrf2",LOCINTERFACE="gxif1/0/1",PEERADDRTYPE=IPv4,PEERIPV4ADDR="10.11.21.61",LOCALPORT=16451;
   ```
