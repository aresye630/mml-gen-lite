# 配置话单采集监控

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

话单采集提醒功能是可选功能。当NCG采用PULL方式提供给计费中心第二份最终话单时，推荐配置此功能，增加话单监控任务，检查PULL任务开放给计费中心的目录下是否有话单长时间未取走并删除。话单采集监控功能的配置可以分为5G场景下的话单采集监控，4G场景下的话单采集监控以及2/3G场景下的话单采集监控。2/3/4/5G场景下的话单采集监控应分开配置。

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

- UNC软件安装已完成。

## 操作步骤

1. 获取分发任务标识。

   在“MML命令行 - UNC”窗口执行**LST CDRDISTR**命令，“TRANSMODE”设置为“PULL（PULL方式）”，查看是否返回多于零个结果：

   ```
   LST CDRDISTR: ISSINGLEBI=NO, TRANSMODE=PULL;
   ```

   - 是 => 获取其分发任务标识，接着执行步骤 2
   - 否 => 其他方式下不需要配置话单采集提醒，操作结束。
2. 确定是否通过自定义路径进行话单监控。

   - 是 => 步骤 3
   - 否 => 步骤 4
3. 通过自定义路径进行话单监控。

   在“MML命令行 - UNC”窗口执行**DSP FEMPACKET**命令获取话单通道名称。

   执行**ADD CDRMONITOR**命令，“ISCUSTOMDIR”选择“YES（是）”，填入上一步获取的通道名称。

   1. 4G话单采集监控。

      ```
      ADD CDRMONITOR: MONITORID="test_monitor_pgwcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=YES, MONSUBDIR="Huawei/PGWCDR";
      ADD CDRMONITOR: MONITORID="test_monitor_sgwcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=YES, MONSUBDIR="Huawei/SGWCDR";
      ```
   2. 2/3G话单采集监控。

      ```
      ADD CDRMONITOR: MONITORID="test_monitor_gcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=YES, MONSUBDIR="Huawei/GCDR";
      ```
4. 通过非自定义路径进行话单监控。

   在“MML命令行 - UNC”窗口执行**LST CDRPROC**命令获取“接入网元分组标识”，执行**DSP FEMPACKET**命令获取话单“通道名称”。

   执行**ADD CDRMONITOR**命令，“ISCUSTOMDIR”选择“NO（否）”，“AGID”和“CHLNAME”分别填入上一步获取的“接入网元分组标识”和“通道名称”。

   1. 4G话单采集监控。

      ```
      ADD CDRMONITOR: MONITORID="test_monitor_pgwcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=NO, AGID="PS2", CHLNAME="pgwcdr";
      ADD CDRMONITOR: MONITORID="test_monitor_sgwcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=NO, AGID="PS2", CHLNAME="sgwcdr";
      ```
   2. 2/3G话单采集监控。

      ```
      ADD CDRMONITOR: MONITORID="test_monitor_gcdr", ISSINGLEBI=NO, CDRDISTRID="test_distr", ISCUSTOMDIR=NO, AGID="PS3", CHLNAME="gcdr";
      ```
