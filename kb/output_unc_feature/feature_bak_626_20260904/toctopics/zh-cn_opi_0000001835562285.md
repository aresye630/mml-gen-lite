# 配置运营商信息

- 操作场景

## 操作场景

配置SMF/PGW-C/SGW-C/GGSN本局数据的基本流程包括：开始→配置移动运营商信息→配置PLMN和切片→配置本端NFUUID→配置NF信息→结束。国漫相关配置请参见5GC国际漫游解决方案功能部署。运营商信息详细原理请参见运营商信息是什么。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- 已经获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置运营商基础信息。当前UNC中默认配置一条“NOID”为0的默认记录，不需单独配置。

   1. 增加运营商信息。

      ```
      MOD NGMNO:NOID=0, FULLNAME="Operator A", SHORTNAME="OA", DESC="Operator A";
      ```
   2. 配置运营商签约用户的Home PLMN信息。

      ```
      ADD NGHPLMN:NOID=0, MCC="123", MNC="03";
      ```
   3. 配置运营商的Serving PLMN信息。

      ```
      ADD NGSRVPLMN:PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      ```
   4. 配置各MCC值所对应的MNC长度。

      ```
      ADD MNCLEN:MCC="123",MNCLEN=2;
      ```
   5. 配置运营商支持的网络切片。如有多个切片，请依次配置多条记录。

      **说明** 

      如果部署了SMF需要配置该命令；如果仅部署了PGW-C/SGW-C/GGSN则无需配置该命令。

      ```
      ADD PLMNNS:NSIDX=0, PLMNIDX=0, SST=1, SD="010101", STATE=ACTIVE;
      ```
