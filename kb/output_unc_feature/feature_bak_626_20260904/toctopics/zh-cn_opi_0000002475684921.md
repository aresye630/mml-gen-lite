# 配置动态IP地址分配

- 操作场景
- 对系统的影响
- 必备事项

## 操作场景

使用专网UPF为UE动态分配IP地址的方式，可参考本页面完成专网SMF侧配置。

## 对系统的影响

无。

## 必备事项

前提条件

已参考运营商配置规范完成网元的基本配置。

数据

## 任务示例

任务描述

采用专网UPF为UE动态分配IP地址，完成专网SMF上的配置。

脚本

1. 在SMF上配置优先使用UPF分配地址。

   ```
   SET ADDRESSATTR: ALLOCPRECEDENCE=UPF_FIRST;
   ```
2. （可选）在现网可能存在不同的UPF为不同的UE分配相同的私网IP地址的情况，为防止PCF误判UE的IP地址冲突，导致正常的PDU会话被释放，SMF侧建议配置UPF的IPdomain，并通过Npcf\_SMPolicyControl\_Update Request消息将IPdomain和UE的IP地址传递给PCF。

   ```
   ADD UPIPDOMAIN:UPNODE="5EA7F228-47CC-2032-03A3-0E1313000001", IPDOMAIN="APP-HDNJIHzjSMFm005BHW-07AHW012.hz.zj.hzupfm001bhw.CMIOTSXSZNSYHYW.ZJ", DNNSWITCH=ENABLE, DNN="stjwt.gd"; 
   ADD UPIPDOMAIN: UPNODE="5EA7F228-47CC-2032-03A3-0E1313000002", IPDOMAIN="PP-HDNJIHzjSMFm005BHW-07AHW012.hz.zj.hzupfm001bhw.CMIAOTSXSZNSYHYW.ZJ", DNNSWITCH=ENABLE, DNN="stjwt.gd";
   ```
