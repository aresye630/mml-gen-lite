# 配置UPF支持的切片和DNN

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

- SMF根据网络规划配置对端UPF支持的服务切片信息。用户激活时，SMF从激活请求中获取用户切片信息，根据UPF支持的服务切片列表选择出符合条件的UPF。
- SMF根据网络规划配置对端UPF支持的DNN。用户激活时，SMF从激活请求中获取用户DNN信息，根据UPF支持的DNN列表选择出符合条件的UPF。

  5G SA架构下，切片和DNN是一对多关系，即：一个切片可以包含多个DNN，一个DNN只能归属于一个切片。切片底下包含很多DNN，如果UPF支持该切片，那么UPF就应该支持切片底下的所有DNN。

## 操作步骤

1. 配置UPF\_Instance\_1~UPF\_Instance\_4支持的网络切片。

   ```
   ADD PNFNS:INDEX=1, NFINSTANCEID="UPF_Instance_1", SST=1, SD="FFFFFF"; 
   ADD PNFNS:INDEX=2, NFINSTANCEID="UPF_Instance_2", SST=1, SD="FFFFFF"; 
   ADD PNFNS:INDEX=3, NFINSTANCEID="UPF_Instance_3", SST=1, SD="FFFFFF"; 
   ADD PNFNS:INDEX=4, NFINSTANCEID="UPF_Instance_4", SST=1, SD="FFFFFF";
   ```
2. 配置UPF\_Instance\_1~UPF\_Instance\_4支持的DNN。

   ```
   ADD PNFDNN:INDEX=1, NFINSTANCEID="UPF_Instance_1", DNN="huawei.com", PNFNSINDEX=1; 
   ADD PNFDNN:INDEX=2, NFINSTANCEID="UPF_Instance_2", DNN="huawei.com", PNFNSINDEX=2; 
   ADD PNFDNN:INDEX=3, NFINSTANCEID="UPF_Instance_3", DNN="huawei.com", PNFNSINDEX=3; 
   ADD PNFDNN:INDEX=4, NFINSTANCEID="UPF_Instance_4", DNN="huawei.com", PNFNSINDEX=4;
   ```
