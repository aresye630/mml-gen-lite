## 操作场景

本操作指导介绍在运行网络中激活5G UE信令控制功能的操作过程。

**说明** 

适用于AMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-206008 5G UE信令控制特性概述。
- 如果采用Parking DNN激活的抑制规则，需要SMF对Parking DNN配置不进行数据业务和不生成话单，并增加Parking切片为支持的切片；需要AMF增加Parking DNN的DNS解析配置，或增加DNS服务器的配置，Parking DNN的DNS解析配置请参考配置Hostfile的数据，增加DNS服务器的配置请参考配置到DNS相关数据。
- 已完成加载License。

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   ****SET LICENSESWITCH****
3. **可选：**开启用户异常信令抑制功能。

   **SET NGSMARTPARA**
4. **可选：**配置异常信令识别门限和测量周期。

   **SET NGSMARTPARA**
5. **可选：**设置异常信令抑制规则和抑制时长。

   **SET NGSMARTPARA**
6. 设置Parking DNN、Parking SST、Parking SD值。

   **SET NGSMARTPARA**
7. **可选：**配置抑制唤醒参数。

   **SET NGSMARTPARA**
8. 配置4G到5G初始注册流程异常信令抑制开关。

   **SET NGSMARTPARA**
9. 配置4G到5G重选流程的异常信令抑制功能相关参数。

   **SET NGSMARTPARA**
10. 配置4G到5G切换流程的异常信令抑制功能相关参数。

    **SET NGSMARTPARA**
11. 配置基于会话粒度的服务请求异常信令抑制功能相关参数。

    **SET NGSMARTPARA**
12. 配置基于会话粒度的PDU会话建立请求异常信令抑制功能相关参数。

    **SET NGSMARTPARA**
13. **可选：**配置AMF对于Paging触发的Service Request流程是否进行信令抑制判断。

    **SET AMFSOFTPARAOFBIT**
14. 配置PDU会话建立流程信令抑制功能去使能后是否执行 Parking DNN 唤醒措施。

    **SET AMFSOFTPARAOFBIT**

## 任务示例

任务描述

为了减轻由于UE的异常行为对网络侧的影响，有效地减少网络中的异常信令，提升网络可用性和可靠性，对5G用户异常反复发送的初始注册请求，服务请求、PDU会话建立请求消息、4G到5G的移动注册更新请求或者4G到5G的切换请求进行抑制，需要对用户手机采用抑制唤醒规则最终使其恢复正常业务。配置执行抑制激活规则（特定原因值拒绝、Parking DNN激活、网络侧去注册、丢弃请求）来消除用户异常行为。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2SAUSC01", SWITCH=ENABLE;
```

//开启用户异常信令抑制功能。

```
SET NGSMARTPARA: CTRLSW=ON, REGSW=ON, SRVREQSW=ON, PDUREQSW=ON;
```

//设置异常识别参数。

```
SET NGSMARTPARA: CTRLSW=ON, REGTHRESH=30, REGMEPERIOD=3600, SRVREQTHRESH=30, SRVREQPERIOD=3600, PDUREQTHRESH=30, PDUREQPERIOD=3600;
```

//设置抑制时长。

```
SET NGSMARTPARA: CTRLSW=ON, REGDURATION=60;
```

//设置抑制措施。

```
SET NGSMARTPARA: CTRLSW=ON, REGCTRLRULE=SPECCAUSEREJ&CNDEREG-1&DISCARD-1, REGREJCAUSE=15, SRVREQCTRLRULE=SPECCAUSEREJ-1&CNDEREG-1&DISCARD-1,SRVREJCAUSE=15, PDUREQCTRLRULE=SPECCAUSEREJ-1&PARKDNNACT-1&CNDEREG-1&DISCARD-1, PDUREQREJCAUSE=65, DEREGISTCAUSE=15;
```

//配置Parking DNN参数以及Parking DNN的抑制唤醒措施。

```
SET NGSMARTPARA: CTRLSW=ON, PARKINGDNN="PARKING",PARKDNNWAKEUP=CNDEACT;
```

//配置4G到5G初始注册流程异常信令抑制开关。

```
SET NGSMARTPARA: CTRLSW=ON, LTETONRINITREGSW=ON;
```

//配置4G到5G重选流程的异常信令抑制功能相关参数。

```
SET NGSMARTPARA: CTRLSW=ON, LTETONRRSLSW=ON, LTETONRRSLTHRESH=50, LTETONRRSLMEPERIOD=3600, LTETONRRSLDURATION=60, LTETONRREGCTRLRULE=SPECCAUSEREJ-1, LTETONRRSLREJCAUSE=15;
```

//配置4G到5G切换流程的异常信令抑制功能相关参数。

```
SET NGSMARTPARA: CTRLSW=ON, LTETONRHOSW=ON, LTETONRHOTHRESH=50, LTETONRHOMEPERIOD=3600, LTETONRHODURATION=60, LTETONRHOCTRLRULE=SPECCAUSEREJ-1, LTETONRHOREJCAUSE=81;
```

//配置基于会话粒度的服务请求异常信令抑制功能相关参数。

```
SET NGSMARTPARA: SESSIONSRSW=ON, SESSIONSRTHR=80, SESSIONSRPERIOD=3600, SESSIONSRDURAT=60, SESSIONSRCTRRUL=SPECCAUSEREJ-1&DISCARD-1, SESSIONSRREJCS=15;
```

//配置基于会话粒度的PDU会话建立请求异常信令抑制功能相关参数。

```
SET NGSMARTPARA: SESSIONPDUSW=ON, SESSIONPDUTHR=30, SESSIONPDUPER=3600, SESSIONPDUDUR=60, SESSIONPDUCTRUL=SPECCAUSEREJ-1&PARKDNNACT-1&DISCARD-1, SESSIONPDUREJCA=65, SESSDNNWAKEUP=CNDEACT;
```

//（可选）配置AMF对于Paging触发的Service Request流程是否进行信令抑制判断。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=72, VALUE=VALUE_0, POSITION=3;
```

//（可选）PDU会话建立流程信令抑制功能去使能后执行 Parking DNN 唤醒措施。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=80, VALUE=VALUE_1, POSITION=21;
```
