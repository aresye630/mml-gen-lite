# 配置到对端AUSF及UDM的信息

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

在AMF本地配置到对端AUSF网元及UDM网元的连接。AMF拜访AUSF网元和UDM网元的主要目的是为了鉴权以及获取用户签约内容。添加信息主要包含：

- 添加对端AUSF网元及UDM网元的基本信息。
- 添加对端AUSF网元及UDM网元的PLMN信息。
- 添加对端AUSF网元及UDM网元的实例服务信息。
- 添加对端UDM网元的SUPI信息。
- 添加对端AUSF网元的路由信息。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置到AUSF的数据，包括AUSF的Profile、Service、路由信息、PLMN等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="AUSF_Instance_0", NFTYPE=NfAUSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.180", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="AUSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NausfAuth, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN: NFINSTANCEID="AUSF_Instance_0",MCC="123", MNC="03";
   ADD PNFSUPI: INDEX=2, NFINSTANCEID="AUSF_Instance_0", QUERYTYPE=START_END, RANGESTART="12303170100001", RANGEEND="12303170100001";
   ADD PNFROUTEIND: NFINSTANCEID="AUSF_Instance_0", ROUTINGIND="0000";
   ```
3. 配置到UDM的数据，包括UDM的Profile、Service、PLMN信息、支持的SUPI范围等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="UDM_Instance_0", NFTYPE=NfUDM, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.180", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="UDM_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NudmSdm, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="UDM_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NudmUecm, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN: NFINSTANCEID="UDM_Instance_0",MCC="123", MNC="03";
   ADD PNFSUPI: INDEX=1,NFINSTANCEID="UDM_Instance_0", QUERYTYPE=START_END, RANGESTART="123031200100001",RANGEEND="123031200100001";
   ```
