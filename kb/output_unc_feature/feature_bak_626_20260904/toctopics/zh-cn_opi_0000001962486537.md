# 配置N19接口

- 操作场景
- 必备事项
- 任务示例

## 操作场景

两个负荷分担关系的UPF对接同一对VxLAN交换机/DCGW或对接不同对VxLAN交换机/DCGW时，本特性支持通过UPF间的N19接口为不同UPF下层二终端组的成员之间提供以太类型的通信服务。

**说明** 

- 两个UPF是负荷分担关系，且连接到同一对DCGW/VxLAN交换机时，同一5G LAN组内成员跨UPF的互访可通过UPF间的VxLAN隧道实现或通过UPF间的N19接口实现。
- 两个UPF是负荷分担关系，且连接到不同对DCGW/VxLAN交换机时，同一5G LAN组内成员跨UPF的互访可通过UPF与DCGW之间的VxLAN隧道实现或通过UPF间的N19接口实现。

## 必备事项

前提条件

已完成配置5G LAN业务基本功能。

数据

| 类别               | 参数                              | 取值样例                        | 获取方法   | 说明                                    |
|:-----------------|:--------------------------------|:----------------------------|:-------|:--------------------------------------|
| SET NGLANFUNC    | 是否发起SMF内5G Lan组内会话数量核查（UECHKSW） | Support                     | 本端规划   | -                                     |
| SET NGLANFUNC    | 是否发起向UPF的组会话核查（GROUPCHKSW）      | Support                     | 本端规划   | -                                     |
| ADD GRPNGLANFUNC | 5G LAN组ID（GROUPID）              | A0000001-460-003-A000000001 | 全网规划   | -                                     |
| ADD GRPNGLANFUNC | 是否支持N19通信（N19SUPPORT）           | SUPPORT                     | 本端规划   | -                                     |
| ADD GRPNGLANFUNC | 是否创建组播PDR规则（MULTICAST）          | SUPPORT                     | 本端规划   | 说明： 当企业需要开启组播功能时，将此参数配置为Support。      |
| ADD GRPNGLANFUNC | 是否支持N6侧上行广播（N6BROADCASTSW）      | SUPPORT                     | 全网规划   | 说明： 当企业需要开启N6侧上行广播功能时，将此参数配置为Support。 |
| ADD GRPNGLANFUNC | 是否支持报文增殖消除（PKTELIMINATESSW）     | SUPPORT                     | 全网规划   | -                                     |
| ADD GRPNGLANFUNC | MAC地址处理模式（MACPROCMODE）          | FULL                        | 全网规划   | -                                     |
| ADD GRPNGLANFUNC | MAC地址组装模式（MACASSEMMODE）         | FULL                        | 全网规划   | -                                     |

## 任务示例

任务描述

某行业用户签约了5G LAN业务，该用户涉及多个分支机构，地理范围跨越了两个UPF的范围，两个分支机构的终端基于两个UPF的N19接口实现数据转发互通。该用户需要开启组播和N6侧上行广播功能。

脚本

//开启5G LAN核查功能。

```
SET NGLANFUNC: UECHKSW=Support, GROUPCHKSW=Support;
```

//配置UPF间基于N19通信，开启组播、N6侧上行广播和报文增殖消除功能，并设置MAC地址的上报处理和下发处理方式。

```
ADD GRPNGLANFUNC: GROUPID="A0000001-460-003-A000000001", N19SUPPORT=SUPPORT, MULTICAST=SUPPORT, N6BROADCASTSW=SUPPORT, PKTELIMINATESSW=SUPPORT, MACPROCMODE=FULL, MACASSEMMODE=FULL;
```

//创建广播PDR规则。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1020, VALUE=VALUE_1, POSITION=22;
```
