## 操作场景

本指导描述话单中某些字段携带规则的配置过程。

对于话单中标识为可选（C）或条件可选（OC）或条件必选（OM）的字段，UNC支持自定义配置是否携带该字段，运营商可根据需要选择配置。

话单可选字段可以基于APN、全局进行配置，它们的优先级顺序是APN > 全局配置 > 默认值。如果高级别的没有配置，则取用低级别的话单字段模板，否则取用默认值。

UNC支持为不同的话单类型绑定不同的CDRFieldTemp话单字段模板，可以分别独立控制SGW-CDR、PGW-CDR、G-CDR话单携带的字段，增强话单字段的灵活度。

**说明** 

- 系统升级时，需注意先升级CG，再升级UNC，以防止UNC先升级后话单中有CG不识别的字段。
- 话单字段修改前需要与对端CG确认是否支持。

## 操作步骤

1. 配置话单字段模板。

   **说明** 

   UNC默认携带话单可选字段，如果不需要携带某个字段，将对应字段设置为**DISABLE**。

   **ADD CDRFIELDTEMP**
2. 配置全局话单字段模板。

   **SET GLBCDRFLDTEMP**
3. 配置APN实例的话单字段模板。

   **SET APNCHARGECTRL**
4. 通过全局参数配置某些话单字段携带规则。

   **SET OFCCDRPARA**

## 任务示例

任务描述

任务一：配置全局话单字段模板，配置话单中支持pdn-connection-id、pgw-address-used、pgw-plmn-identifier、start-time和stop-time字段。

任务二：配置APN实例的话单字段模板，配置UNC话单中不携带apn network identifier字段和ms time zone字段。

任务三：配置gsn-node-id前缀为gsn.huawei，gsn-node-id分隔符为@，PGW-CDR携带List of Traffic Volumes。

脚本

//任务一：配置全局话单字段模板，配置话单中支持pdn-connection-id、pgw-address-used、pgw-plmn-identifier、start-time和stop-time字段。

```
ADD CDRFIELDTEMP:TEMPLATENAME="cdrfield-test", PDNCONNECTIONID=ENABLE, PGWADDRESSUSED=ENABLE, PGWPLMNID=ENABLE, STARTTIME=ENABLE, STOPTIME=ENABLE;
SET GLBCDRFLDTEMP: PGWCDRTEMPLATE="cdrfield-test";
```

//任务二：配置APN实例的话单字段模板，配置话单中支持pdn-connection-id、pgw-address-used、pgw-plmn-identifier、start-time和stop-time字段。

```
ADD CDRFIELDTEMP:TEMPLATENAME="cdrfield-test", PDNCONNECTIONID=ENABLE, PGWADDRESSUSED=ENABLE, PGWPLMNID=ENABLE, STARTTIME=ENABLE, STOPTIME=ENABLE;
SET APNCHARGECTRL: APN="apn-test",PGWCDRTEMPLATE="cdrfield-test";
```

//任务三：配置gsn-node-id前缀为gsn.huawei，gsn-node-id分隔符为@，PGW-CDR携带List of Traffic Volumes。

```
SET OFCCDRPARA:GSNNODEIDPREFIX="gsn.huawei", GNIDELIMITER="@", PGWCDRLOTVSW=ENABLE;
```
