# 离线计费配置（2/3G）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

配置2/3G离线计费（NCG通过Ga接口和GGSN-C对接）话单处理参数。该章节仅针对于组网场景有Ga接口的计费方案。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

- UNC软件安装已完成。

## 操作步骤

1. 配置3G话单处理的格式引擎包及对应软参。

   ```
   ADD CDRPROC: AGID="PS3", PRFNAME="PS_R6_V660_CMCC_NEW.tar.gz", SHAREFILECSN=OFF, SEQNUMMODE=IE;
   ```
2. **可选：**配置格式引擎包对应的软参。

   **说明** 

   - 不同的格式引擎包对软参的支持情况可能不同，可以通过**DSP FMTSOFTPARA**命令查询对应格式引擎包可配置的软参。
   - 软参取值请根据业务实际需要进行配置。

   ```
   ADD FMTPKGCFG:PRFNAME="PS_R6_V660_CMCC_NEW.tar.gz",CFGNAME="MaxDuration",CFGTYPE=FEM_PARA_UINT,CFG_UINT_VALUE=0;
   ADD FMTPKGCFG:PRFNAME="PS_R6_V660_CMCC_NEW.tar.gz",CFGNAME="MaxVolume",CFGTYPE=FEM_PARA_UINT,CFG_UINT_VALUE=0;
   ```
3. 配置2/3G业务处理模块。

   ```
   ADD MODULE: MNAME="AP64_3", AGID="PS3";
   ADD MODULE: MNAME="AP65_3", AGID="PS3";
   ```

   **说明** 

   MNAME格式为APXX\_YY，XX为RUID（从64开始递增），YY为模块ID（4G业务处理模块ID固定为2），国漫的消息量很小，为了简化配置和计费对接，建议只在前两个虚机添加业务模块。
4. 话单处理相关配置。

   ```
   ADD CDRSTOR: CDRSTORID="2G_second64_3", ISSINGLEBI=No, FILETYPE=SecondFinal, AGID="PS3", MNAME="AP64_3", SFSTORDAYS=30, SFSTORDAYSRULE=ByRelativeDays, SFCMRRULE=UNCOMPRESS, CLOSEFILECOND=Unspecify, EMPTYFILE=NO, NAMINGRULE="SGSN000000000001_%Y%m%d%H%M%S_%08L.dat", ENDSN=99999999, NUMSCHSN=NO;
   ADD CDRSTOR: CDRSTORID="2G_second65_3", ISSINGLEBI=No, FILETYPE=SecondFinal, AGID="PS3", MNAME="AP65_3", SFSTORDAYS=30, SFSTORDAYSRULE=ByRelativeDays, SFCMRRULE=UNCOMPRESS, CLOSEFILECOND=Unspecify, EMPTYFILE=NO, NAMINGRULE="SGSN000000000001_%Y%m%d%H%M%S_%08L.dat", ENDSN=99999999, NUMSCHSN=NO;
   ```
5. 配置3G Ga接口本端接入网元分组的接入控制。

   ```
   ADD ACTRL: ACID="R6CDR", AGID="group2", IPRID="ga", PORT=3387;
   ```
