# 激活模块级KPI异常检测与恢复

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本操作用于指导在运行网络中激活模块级KPI异常检测与恢复特性。

## 必备事项

前提条件

- 请仔细阅读WSFD-010808 模块级KPI异常检测与恢复特性概述。
- 已完成网元License加载。

数据

| 类别              | 参数名称                              | 取值样例   | 获取方法   | 说明                                                                                                                         |
|:----------------|:----------------------------------|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| SET CFSHEALCTRL | 模块级KPI异常检测与恢复功能开关（SGLSUBHEALTHSW） | ENABLE | 本端规划   | 用于控制由于网元内单主机出现Fabric丢包/cpu过载故障而导致KPI下降满足阈值时做对应自愈隔离处理的功能开关。  说明： 本开关和License必须同时打开，模块级KPI异常检测与恢复功能才能开启。若只打开本开关，则触发CE信令风暴检测。 |

工具

OM Portal

## 操作步骤

1. 开启License项配置开关。

   **SET LICENSESWITCH**
2. 开启模块级KPI异常检测与恢复功能。

   **SET CFSHEALCTRL**

## 任务示例

任务描述

任务1：在SMF/PGW-C/SGW-C/GGSN上开启模块级KPI异常检测与恢复功能。

任务2：在AMF/MME上开启模块级KPI异常检测与恢复功能。

脚本

任务1脚本：

//开启License项配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2MKEDAR01", SWITCH=ENABLE;
```

//开启模块级KPI异常检测与恢复功能。

```
SET CFSHEALCTRL: SGLSUBHEALTHSW=ENABLE;
```

任务2脚本：

//开启License项配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2SMDEXPDCT01", SWITCH=ENABLE;
```

//开启模块级KPI异常检测与恢复功能。

```
SET CFSHEALCTRL: SGLSUBHEALTHSW=ENABLE;
```
