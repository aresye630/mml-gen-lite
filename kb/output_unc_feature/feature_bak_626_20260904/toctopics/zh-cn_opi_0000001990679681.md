# 配置到NRF信息

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

该任务主要用于NCG向NRF发现OCS等周边NF并订阅后者的状态信息。在对接真实NRF的场景下，需要执行该任务。

**说明** 

NCG信息在SMF本地配置，SMF暂不向NRF查询NCG信息。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

- UNC软件安装已完成。

## 操作步骤

1. 配置主NRF和备NRF实例。

   ```
   ADD NRF: NRFINSTANCENAME ="NRF_Instance_0", TLS=FALSE, PRIORITY=1;
   ADD NRF: NRFINSTANCENAME ="NRF_Instance_1", TLS=FALSE, PRIORITY=2;
   ```

   **说明** 

   执行ADD NRF命令时严禁配置FQDN参数，不支持SBI接口使用FQDN。
2. 配置主NRF业务地址。

   ```
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_0", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="172.16.1.15", PORT=8080;
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_0", IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS="fd00:f111:2222:3333:4444:5555:2111:151", PORT=8080;
   ```
3. 配置备NRF业务地址。

   ```
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_1", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="172.16.1.16", PORT=8080;
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_1", IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS="fd00:f111:2222:3333:4444:5555:2111:152", PORT=8080;
   ```
4. 配置与主NRF和备NRF的对接参数。当开启订阅功能开关时，可以增加订阅条件。当目标NF触发订阅条件和通知事件时，NRF向源NF发送通知。

   ```
   ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_0", WAITINTERVAL=5, MAXRETRYTIMES=3, LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
   ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_1", WAITINTERVAL=5, MAXRETRYTIMES=3, LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
   ```

   **说明** 

   请提前规划**ADD NRFPARA**中“WAITINTERVAL”和“MAXRETRYTIMES”的值，确保NF对NRF的故障探测时长比NRF探测NF的时长要短，避免因链路故障NF还未来得及倒换就被NRF判定为故障。NF探测时长请参考UNC产品文档中“网络部署 > 特性部署 > UNC特性指南 > 容灾功能 > WSFD-114002 NRF双活容灾 > WSFD-114002 NRF双活容灾特性概述”中原理概述的可靠性机制。
5. 配置切换主用NRF开关。

   ```
   SET NFNRFMGMTPARA:SWITCHMASTERNRF=ON;
   ```

   **说明** 

   在NRF主备组网情况下，通过设置“SWITCHMASTERNRF”参数让NF实时感知主用NRF的状态，当主用NRF恢复后，NF切换到主用NRF。
6. 配置NCG订阅CHF(OCS)等周边NF的状态和信息变更通知。

   ```
   ADD SUBCONDITION: NFTYPE=NfCUSTOM_OCS,CONDITION=NfInstanceId-1&NFType-1&ServiceName-1&AmfRegionId-1&AmfSetId-1&GuamiList-1&PlmnId-1&NetworkSlice-1&NfGroup-1&Rev1-1&Rev2-1&Rev3-1, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
   ```
7. 配置OCS寻址策略。

   配置通过GPSI寻址OCS。

   ```
   SET AGFFUNCPARA: OCSRETRYCNT=0, OCSDISCPLCY=SUPI-0&GPSI-1;
   ```

   **说明** 

   - “OCSRETRYCNT”取值范围为0~1。值为0时，请求消息超时不进行重传，直接查找备OCS。值为1时，请求消息超时后重传1次，再次超时则查找备OCS。
   - 如上所示配置表示通过GPSI寻址OCS。
