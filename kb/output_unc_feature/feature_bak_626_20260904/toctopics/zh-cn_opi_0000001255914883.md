# 部署基于动态规则的分流策略控制(4G)（SMF）

## 操作场景

本文档用于指导4G网络中基于动态规则的UL CL分流策略控制功能的部署。

## 必备事项

前提条件

- 请仔细阅读WSFD-223101 基于预定义规则的分流策略控制(4G)特性概述。
- 已完成本特性License加载，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 修改主锚点UPF属性为支持主锚点和分流UPF合设形态。

   **MOD UPNODE**
3. **可选：**配置DNAI关联的位置区域。当采用基于SMF本地DNN使能UL CL分流方式时，需要配置此步骤。
   1. 配置DNAI对应的服务区域。

      **ADD DNAREA**
   2. 配置DNAI服务区名称绑定的4G TAI范围。

      **ADD DNAREABINDS1TAI**
   3. 配置DNAI绑定的服务区域名称。

      **ADD DNAIBINDDNAREA**
4. 配置IPv6会话场景下的分流策略。

   **SET SMFFUNC**
5. 配置开启4G UL CL功能开关。

   **SET SMGTPPROT**

## 任务示例

任务描述

某大学组建了自己的校园网，希望对校内人员可以通过签约统一的套餐来访问校园网资源。

脚本

//修改主锚点UPF属性为支持主锚点和分流UPF合设形态。

```
MOD UPNODE: NFINSTANCENAME="UPF_INSTANCE0", UPFUNCTION=UlClAndBp, SUPULCLBPONLY=Disable, PSACOMBINEULCL=ENABLE;
```

//配置IPv6会话场景下的分流策略。

```
SET SMFFUNC: IPV6LOCALUP=UlClPrefer;
```

//配置开启4G UL CL功能开关。

```
SET SMGTPPROT: LTEULCLSW = ENABLE;
```
