# 激活1/N设备标识检查（适用于2G&3G&4G）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

本操作指导介绍在运行的2G&3G&4G网络中激活1/N设备标识检查功能的操作过程。

**说明** 

适用于SGSN、MME。

## 必备事项

前提条件

- 请仔细阅读WSFD-103006 1/N设备标识检查特性概述（适用于2G&3G&4G）。

- 该特性的依赖特性WSFD-103004 设备标识检查特性已经正常开通，详细操作请参见激活设备标识检查特性（适用于2G&3G）和激活设备标识检查特性（适用于4G）。
- EIR已经配置成功，具体配置内容请参考配置到EIR的数据。
- 需要对端网元EIR激活IMEI检查功能。
- 完成加载License。

数据

| 类别                                        | 参数名称     |   取值样例 | 获取方法   | 说明   |
|:------------------------------------------|:---------|-------:|:-------|:-----|
| MOD GBIMEICFG MOD IUIMEICFG MOD S1IMEICFG | IMEI检查上限 |      2 | 全网规划   | -    |

## 操作步骤

1. 打开本特性的License配置开关。

   进入“MML命令行-UNC”窗口。

   **SET LICENSESWITCH**
2. 配置IMEI检查上限，即指定当IMEI未改变时，UNC每多少次Attach流程发起一次IMEI检查。

   Gb模式下：**MOD GBIMEICFG**

   Iu模式下：**MOD IUIMEICFG**

   S1模式下：**MOD S1IMEICFG**

   **说明** 

   参数“IMEI检查上限”设置为“0”，表示仅UE第一次接入UNC或者IMEI改变时，需要进行IMEI检查，对于IMEI未改变的Attach流程，UNC不发起IMEI检查流程。

## 任务示例

任务描述

在UTRAN网络中启用1/N设备标识检查功能，设置IMEI检查上限为2。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV21NIMEI01", SWITCH=ENABLE;
```

//设置UTRAN网络的IMEI检查上限。

```
MOD IUIMEICFG: SUBRANGE=ALL_USER, GETIMEIPLC=IMEI, CHKIMEIPLC=IMEI, CHKIMEITHRESHOLD=2;
```
