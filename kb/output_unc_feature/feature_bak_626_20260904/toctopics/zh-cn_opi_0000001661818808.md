## 操作场景

上线可选VNFC失败和加载补丁失败时，需要强制下线可选VNFC并清理相关残留数据，请务必在研发人员指导下参考本章节进行操作。

## 必备事项

前提条件

- 可选VNFC功能上线失败。
- 已通过U2020/MAE或UNC OM portal登录华为操作维护系统。

数据

| 类别              | 参数名称   | 取值样例/说明                                                | 获取方法   |
|:----------------|:-------|:-------------------------------------------------------|:-------|
| UNC OM Portal帐户 | IP地址   | 192.168.1.1 操作维护接口IP，即“VNFD模板”中的“MNG_IP”或“MNG_IPv6”参数。 | 本端规划   |
| UNC OM Portal帐户 | 端口号    | 31943                                                  | 本端规划   |
| UNC OM Portal帐户 | 用户名    | admin                                                  | 本端规划   |
| UNC OM Portal帐户 | 密码     | Changeme_123                                           | 本端规划   |

## 操作步骤

1. 登录UNC OM Portal。
2. 执行命令**DSP PODINFO**，查询当前已上线的可选VNFC的Pod。
3. 执行命令，强制下线可选VNFC，此处以IPSec为例。

   ```
   OPR FEATUREDISABLE:PODTYPE="IPSecexec-c8-pod/IPSecctl-pod", DISABLETYPE=Force, FUNCTIONSETNAME="IPSec";
   ```

   **说明** 

   - 参数DISABLETYPE的取值必须为Force，即强制下线。
   - 参数PODTYPE的取值为实际已上线的可选VNFC的Pod。
4. 请务必联系研发人员，在指导下进行相关残留数据的清理。
