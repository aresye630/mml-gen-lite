## 操作场景

需要使用终端二次鉴权时，进行终端二次鉴权激活。

**说明** 

适用于SMF。

## 必备事项

前提条件

- 请仔细阅读二次鉴权特性概述。
- 完成Radius鉴权接入配置。
- 完成Radius功能配置。

  **须知** 

  **UPLIST4RDS**、**UPFRDSCLIENTIP**、**UPFRDSSVR**命令配置中的**UPLISTNAME**参数建议统一用小写。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 可选：当SMF存在多个本端GTP-U地址，增加UPF逻辑接口。

   **ADD UPLOGICINTF**
3. 增加与UPF对接的本端GTP-U地址。

   **ADD CPGTPUADDR**
4. 增加中转使用的UP到RADIUS服务器使用的UPF列表。

   **ADD UPLIST4RDS**
5. 可选配置：增加RADIUS服务器使用的UPF列表中指定UPF的功能属性。

   **ADD RDSUPFCTRL**
6. 新增中转UPF与Radius服务器的绑定关系。

   **ADD UPFRDSSVR**
7. 增加中转UPF与Radius客户端的绑定关系。

   **ADD UPFRDSCLIENTIP**

## 验证方法

具体步骤请参见调测终端二次鉴权。

## 任务示例

任务描述

配置UPF中转Radius鉴权消息。

脚本

//可选：当存在多条本端GTP-U记录时，增加UPF逻辑接口。

```
ADD UPLOGICINTF: UPFINSTANCEID="up1", ITFTYPE=N4U, NETWORKINSTNAME="n4u-vpn", IPVERSION=IPV4, CPN4UIPTYPE=ACCORDING_PEER;
```

//增加与UPF对接的本端GTP-U地址。

```
ADD CPGTPUADDR:IPVERSION=IPV4,IPV4ADDR="192.168.0.20",VPN="n4u-vpn";
```

//向RADIUS服务器使用的UPF列表中增加UPF。

```
ADD UPLIST4RDS: UPLISTNAME="uplist1", UPINSTANCEID="up1";
```

//可选：增加RADIUS服务器的UPF列表中指定UPF的功能属性

```
ADD RDSUPFCTRL: UPLISTNAME="uplist1", UPINSTANCEID="up1",PREFERENCE=1,LOCKED=ENABLE;
```

//增加中转UPF与Radius客户端的绑定关系。

```
ADD UPFRDSSVR: SERVERTYPE=AUTHENTICATION, IPVERSION=IPV4, SERVERIPV4="192.168.10.2", UPLISTNAME="uplist1";
```

```
ADD UPFRDSCLIENTIP: CLIENTYPE=AUTHENTICATION, IPVERSION=IPV4, UPLISTNAME="uplist1", VPNINSTANCE="vpnInstance1", CLIENTIPV4="192.168.10.1";
```
