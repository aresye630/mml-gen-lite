# 激活VoNR承载延时保活

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

用户在VoNR通话过程中，当连接态的UE进入没有无线信号的区域后（例如：电梯、隧道或者山洞），短时间内SMF保留VoNR承载（包括5QI=1（语音）和5QI=2（视频）等等），当用户可以接入网络后，原VoNR不会掉话，提升用户业务体验。

**说明** 

适用于SMF。

前提条件

- 请仔细阅读WSFD-221001 VoNR承载延时保活特性概述。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. **可选：**配置整系统粒度专有QoS Flow去活策略。

   **ADD DEACTQFPLCY**
3. **可选：**配置APN粒度专有QoS Flow去活策略。

   **ADD APNDEACTQFPLCY**
4. **可选：**配置插入或删除I-SMF场景下QoS Flow去活策略。

   **SET QOSFLOWFUNC**
5. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

激活VoNR承载延时保活特性。

脚本

//进入“MML命令行-UNC”窗口。

//配置整系统粒度专有QoS Flow去活策略。

```
ADD DEACTQFPLCY: NGAPCAUSEGROUP=RADIO_NETWORK, NGAPCAUSEVALUE=21, QFPLCY=DELAY_RELEASE, DELAYTIMER=60;
```

//配置APN粒度专有QoS Flow去活策略。

```
ADD APNDEACTQFPLCY: APN="ims", NGAPCAUSEGROUP=RADIO_NETWORK, NGAPCAUSEVALUE=21, QFPLCY=DELAY_RELEASE, DELAYTIMER=60;
```

//配置插入或删除I-SMF场景下QoS Flow去活策略。

```
SET QOSFLOWFUNC: EPSTO5GSQFPLCY=DELAY_RELEASE, ISMFQFPLCY=DELAY_RELEASE, DELAYTIMER=60;
```

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2VCHSM01", SWITCH=ENABLE;
```
