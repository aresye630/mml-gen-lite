# 部署基于PCF静态签约的分流（SMF）

- 操作场景
- 必备事项
- 任务示例

## 操作场景

本章节用于指导部署基于PCF静态签约的分流方案，主要包括分流策略以及DNAI等相关配置。

## 必备事项

前提条件

- 操作人员已了解本功能的原理。
- 已完成和分流UPF的对接配置。
- 完成PCC相关基本功能配置。
- 已完成加载License，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

## 任务示例

任务描述

**【业务描述】**

某高校建立了校园专网，希望教职员工、在校生在高校所在大学城访问校园网时通过专用通道访问，同时这些人员访问Internet的行为不加干涉。

**【业务分析】**

由于高校人员流动性较强，该高校可以针对教职员工和在校生向运营商签约一种套餐，使高校人员在大学城范围内通过UL CL的方式让同时能够访问校园网和Internet，这样既能确保高校人员通过专用通道访问校园网，也能自由访问Internet。

本章节重点体现SMF上的配置，需要配置的内容如下，关键数据如表1所示：

- SMF上配置相关的分流规则，规则需要和PCF上针对高校人员在大学城范围内配置的策略保持一致。
- 流过滤器名称需要在PCF、SMF以及UPF上配置一致。
- 二次鉴权失败后，仍可以访问公网。

| 类别                    | 数据                      | 说明                   |
|:----------------------|:------------------------|:---------------------|
| 数据网络访问标识（DNAI）        | testdnai                | 用于关联支撑企业分流业务的辅锚点UPF。 |
| 园区区域范围（TAI）           | 46001000001~46001000006 | 企业园区的地理范围。           |
| 流过滤器名称（Aplication ID） | ulcl                    | SMF和UPF协商一致的分流规则名。   |

脚本

//配置规则。

```
ADD RULE:RULENAME="testrule",POLICYTYPE=ULCL, POLICYNAME="testulclpropname", FLOWFILTERNAME="ulcl";
```

//配置用户属性模板。

```
ADD USERPROFILE:USERPROFILENAME="testuserprofilename", UPTYPE=ULCL; 
ADD RULEBINDING: USERPROFILENAME="testuserprofilename",RULENAME="testrule",POLICYTYPE=ULCL;
```

//配置UL CL分流策略。

```
ADD FLOWFILTER: FLOWFILTERNAME="ulcl"; 
ADD ULCLPROP: ULCLPROPNAME="testulclpropname", DNAI="testdnai";
```

//配置DNAI对应的服务区域。

```
ADD DNAREA: AREANAME="DNAREA1", AREATYPE=N2TAI;
ADD DNAREABINDN2TAI: AREANAME="DNAREA1", N2BEGINTAI="46001000001", N2ENDTAI="46001000006";
ADD DNAIBINDDNAREA: DNAI="testdnai", AREANAME="DNAREA1";
```

//配置IPv6会话场景下的分流策略。

```
SET SMFFUNC: IPV6LOCALUP=UlClPrefer;
```

//打开本功能的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2PCLBO01", SWITCH=ENABLE;
```

//配置用户二次鉴权失败后，仍可以访问公网。

```
SET APNAUTHATTR: APN="cmnet", AAAREJECTCTRL=CONTINUE;
```
