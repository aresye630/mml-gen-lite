# 激活SMF故障下的业务恢复

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

本章节指导如何在运行的5G网络中激活SMF故障下的业务恢复。

在SMF故障或重启场景下，AMF感知到SMF故障后，协助用户及时恢复VoNR语音业务，实现设备的容灾功能。

**说明** 

适用于AMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-221005 SMF故障下的业务恢复。

数据

| 类别              | 参数名称                  | 取值样例   | 获取方法   | 说明                 |
|:----------------|:----------------------|:-------|:-------|:-------------------|
| SET AMFSMFRESET | SMF故障重选开关（SMFRESEL）   | ON     | 全网规划   | 通过扫描任务方式进行语音业务恢复   |
| SET AMFSMFRESET | 扫描速率(个/秒)（RATE）       | 1      | 全网规划   | 通过扫描任务方式进行语音业务恢复   |
| SET AMFSMFRESET | 单位扫描时间(秒)（INTERVAL）   | 1      | 本端规划   | 通过扫描任务方式进行语音业务恢复   |
| SET AMFSMFRESET | 单位扫描个数（SCANNUM）       | 5      | 本端规划   | 通过扫描任务方式进行语音业务恢复   |
| SET AMFSMFRESET | 自定义扫描速率开关（SCANRATESW） | OFF    | 本端规划   | 通过扫描任务方式进行语音业务恢复   |
| SET AMFSMFRESET | 语音业务恢复开关（SRRECOVERSW） | ON     | 全网规划   | 通过数据业务请求方式进行语音业务恢复 |
| SET AMFSMFRESET | 语音业务DNN（VOICEDNN）     | IMS    | 全网规划   | 通过数据业务请求方式进行语音业务恢复 |

## 操作步骤

1. 设置SMF故障或重启时，AMF对语音业务的业务恢复策略。

   **SET AMFSMFRESET**

## 任务示例

任务描述

在SMF故障或重启场景下，AMF感知到SMF故障后，AMF通过扫描任务和数据业务请求两种语音业务恢复方式，协助用户及时恢复VoNR语音业务。

脚本

//设置业务恢复策略。

```
SET AMFSMFRESET: SMFRESEL=ON, RATE=1, INTERVAL=1, SCANNUM=5, SCANRATESW=OFF, SRRECOVERSW=ON, VOICEDNN="IMS";
```
