## 操作场景

该场景根据整体方案设计需配置1个业务，该业务挂载1个策略，该策略包含2个规则：

- 规则1（PrePcc\_Rule1），详细内容规划如下：
  - 条件：RoamingRegion等于Region\_Local
  - 动作：下发预定义规则名称“Predefined1”（上下行带宽100 Mbit/s）
- 规则2（PrePcc\_Rule2），详细内容规划如下：
  - 条件：RoamingRegion不等于Region\_Local
  - 动作：下发预定义规则名称“Predefined2”（上下行带宽1 Mbit/s）

## 对系统的影响

该业务对系统无影响。

## 必备事项

前提条件

已通过学习SM策略E2E实现原理、业务配置方法及业务调测方法了解了SM策略的配置原理及方法。

数据

无。

配置**“条件组”**。

导航入口为“策略管理 > 策略 > 条件组”。

**说明** 

- 当业务的使用需要设置控制条件时，需要配置条件组。若某规则不配置条件组，表示在同一业务里其他条件都匹配不上时，才触发此规则。
- 条件组是一个或多个条件的组合。条件组中的各条件之间可以是“与”的关系，也可以是“或”的关系。条件之间的与/或关系由参数“关系”的取值决定。

需要配置两个条件组，用于判断用户在国内或国外（漫游区）接入。条件组的数据规划如表3和表4所示，详细参数说明请参见“UPCF产品文档>UPCF WebUI GUI参考>策略管理>条件组”帮助页面。

| 条件组1 | 基本信息 | 关系     | AND                           |
| 条件组1 | 条件   | 名称     | Con1                          |
| 条件组1 | 条件   | 对象属性   | 对象：SmfSession属性：RoamingRegion |

- **开户**。

  **登录“UPCF PGW Web LMT>UPCF 业务管理”窗口**，将配置完成的业务通过UPCF开户签约系统进行下发。

  执行**ADD PSUB**增加一个用户。

  ```
  ADD PSUB:USRIDENTIFIER="46000120010****", USRMSISDN="861390010****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA;
  ```

- **业务发放**。

  在“UPCF PGW Web LMT>UPCF 业务管理”窗口继续执行**ADD PSRV**给用户签约业务。

  ```
  ADD PSRV: USRIDENTIFIER="46000120010****", SRVNAME="Location_Service", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
  ```
