# 配置4G网络基于实时位置的策略控制功能

- 操作场景
- 必备事项
- 操作流程
- 任务示例

## 操作场景

本章节介绍4G用户接入4G网络场景，或者5G用户接入4G网络并通过N7接口连接PCF场景，如何开启基于实时位置的策略控制功能。

## 必备事项

前提条件

- 完成加载License。

- 部署本特性会增加相关接口的负荷，在部署本特性之前，需要对现有网络的业务模型、资费策略、网络资源占用情况进行评估，以降低对整个网络的负荷冲击。
- 需要对端网元PCRF/PCF激活基于实时位置信息的策略控制功能。

## 任务示例

任务描述

5G用户接入4G网络且通过N7接口连接PCF场景，开启基于实时位置的策略控制功能。

脚本

//开启MME小区位置信息上报功能的license。

```
SET LICENSESWITCH: LICITEM="LKV2LCR01",SWITCH=ENABLE;
```

//开启SGW/PGW-C基于实时位置的策略控制功能的license。

```
SET LICENSESWITCH: LICITEM="LKV2PYCTRL1",SWITCH=ENABLE;
```

//开启全局位置上报功能。

```
SET SMCOMMFUNC: LOCREPORT=Support;
```

//设置APN（huawei.com）的位置上报功能，指定该APN的位置上报功能继承全局配置。

```
ADD APN: APN="huawei.com", LOCREPORT=INHERIT;
```

//设置策略接口为Npcf。

```
SET POLICYMODE: TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=DISABLE, FORCED=Npcf;
```
