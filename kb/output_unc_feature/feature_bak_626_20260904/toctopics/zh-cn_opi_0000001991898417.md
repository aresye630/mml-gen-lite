## 操作场景

该任务用于指导工程师完成Ga口的IP资源数据的配置。该章节仅针对于组网场景有Ga接口的计费方案。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

- UNC软件安装已完成。

## 操作步骤

1. 配置Ga接口信令的VPN。

   ```
   ADD VPNINST: VPNINSTANCE="Ga-test";
   ```
2. 配置Ga接口话单处理，加载格式引擎包。

   ```
   ADD CDRPROC: AGID="group1", PRFNAME="PS_R9_V940_huawei_test.tar.gz", SHAREFILECSN=OFF, SEQNUMMODE=IE;
   ADD CDRPROC: AGID="group2", PRFNAME="PS_R9_V940_huawei_test4G.tar.gz", SHAREFILECSN=OFF, SEQNUMMODE=IE;
   ADD CDRPROC: AGID="group3", PRFNAME="PS_R9_V940_huawei_test2G.tar.gz", SHAREFILECSN=OFF, SEQNUMMODE=IE;
   ```
3. 配置Ga接口接入网元分组。

   ```
   ADD MODULE: MNAME="AP64_1", AGID="group1";
   ADD MODULE: MNAME="AP64_2", AGID="group2";
   ADD MODULE: MNAME="AP64_3", AGID="group3";
   ```

   **说明** 

   MNAME目前仅支持APXX\_Y命名，XX为RUID。
4. 配置话单存储规则。

   ```
   ADD CDRSTOR: CDRSTORID="OriginalCDR", ISSINGLEBI=No, FILETYPE=Original;
   ADD CDRSTOR: CDRSTORID="FinalCDR_1stCopy", ISSINGLEBI=No, FILETYPE=FirstFinal, FSTORDAYS=8, FCMRRULE=GZIP;
   ADD CDRSTOR: CDRSTORID="FinalCDR_2ndCopy", ISSINGLEBI=No, FILETYPE=SecondFinal, AGID="PS_GROUP_1", CHLNAME="All", CLOSEFILECOND=BySize, SFCDRSIZE=2048, NAMINGRULE="bABC%08L%A.dat";
   ```

   **说明** 

   存储天数和文件命名规则要根据规划填写，以上只是样例。
