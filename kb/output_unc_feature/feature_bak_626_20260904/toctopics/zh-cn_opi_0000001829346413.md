# 配置到对端SMF及PCF的信息

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

在AMF本地配置到对端SMF网元及PCF网元的连接。AMF拜访SMF网元和PCF网元的主要目的是为了完成用户会话的建立，更新等流程。添加信息主要包含：

- 添加对端SMF网元及PCF网元的基本信息。
- 添加对端SMF网元及PCF网元的PLMN信息。
- 添加对端SMF网元及PCF网元的实例服务信息。
- 添加对端SMF网元及PCF网元的DNN信息。
- 添加对端PCF网元的SUPI信息。
- 添加对端SMF网元的服务切片信息及跟踪区信息。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置到PCF的数据，包括PCF的Profile、Service、PLMN信息、支持的SUPI范围等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="PCF_Instance_0", NFTYPE=NfPCF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.181", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="PCF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NpcfAmPlcCtrl, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="PCF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NpcfUePcy, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN: NFINSTANCEID="PCF_Instance_0",MCC="123", MNC="03";
   ADD PNFSUPI:INDEX=2, NFINSTANCEID="PCF_Instance_0", QUERYTYPE=START_END, RANGESTART="123031200100001",RANGEEND="123031200100001";
   ADD PNFNS:INDEX=2, NFINSTANCEID="PCF_Instance_0", SST=1, SD="010101";
   ```
3. 配置到SMF的数据，包括SMF的Profile、Service、PLMN信息、支持的DNN、支持的切片实例等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="SMF_Instance_0", NFTYPE=NfSMF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="172.16.0.6", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmfPduSes, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NsmfEventExp, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN:NFINSTANCEID="SMF_Instance_0",MCC="123", MNC="03";
   ADD PNFSMFINFO: NFINSTANCEID="SMF_Instance_0", PGWFQDN="huawei.com.apn.epc.mnc001.mcc123.3gppnetwork.org";
   ADD PNFDNN:INDEX=1, NFINSTANCEID="SMF_Instance_0", DNN="huawei.com";
   ADD PNFNS:INDEX=1,NFINSTANCEID="SMF_Instance_0", SST=1, SD="010101";
   ADD PNFTAIRANGE: INDEX=1,NFINSTANCEID="SMF_Instance_0",MCC="123",MNC="03",QUERYTYPE=START_END,RANGESTART="130101",RANGEEND="130102";
   ```
