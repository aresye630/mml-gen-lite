## 操作场景

本操作指导介绍在运行网络中激活基于IMSI号段的QoS控制特性的操作过程。

SMF能够按IMSI号段对特定用户群的QoS进行单独配置，从而实现灵活的QoS控制策略。

**说明** 

适用于SMF。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

- 请仔细阅读WSFD-105104 基于IMSI号段的QoS控制（适用于SMF）。
- 完成加载License。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   ****SET LICENSESWITCH****
3. （可选）针对使用语音业务的用户，如果这些用户不受基于IMSI号段的QoS控制，可将其加入白名单。

   ****ADD QOSCAPWHITEAPNS****
4. 添加QosFlow QoS限制的配置。

   **ADD SMFQOSCAP**
5. **可选：**（可选）当需要基于5QI粒度进一步限制QoS时，添加基于5QI的QosFlow QoS限制配置。

   **ADD QOSCAPBY5QI**

## 任务示例

任务描述

增加一条QoS限制配置，对于IMSI前缀为3080107000（即IMSI号范围在308010700000000～308010700099999内）的用户，将上行APN AMBR限制为20000000，下行APN AMBR限制为16600000，QOS5QI为9，5QI的优先级别为10，ARP的优先级别为5，ARP的抢占能力为MAY\_PREEMPT，ARP的被抢占能力为NOT\_PREEMPTABLE，QoS协商动作为RESTRICT。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2QCBISM01", SWITCH=ENABLE;
```

//（可选）针对使用语音业务的用户，如果这些用户不受基于IMSI号段的QoS控制，可将其加入白名单。

```
ADD QOSCAPWHITEAPNS:APN="ims",SUBRANGE=ALL_USER;
```

//添加QosFlow QoS限制的配置。

```
ADD SMFQOSCAP:SUBRANGE=IMSI_PREFIX, IMSIPRE=3080107000, QOSIDTYPE=NONGBR, AMBRUL=20000000, AMBRDL=16600000,QOS5QI=9,QOS5QIPL=10,ARPPRL=5,ARPPCI=MAY_PREEMPT,ARPPVI=NOT_PREEMPTABLE,QOSACTION=RESTRICT;
```

//当需要基于5QI粒度进一步限制QoS时，添加基于5QI的QosFlow QoS限制配置。

```
ADD QOSCAPBY5QI:SUBRANGE=IMSI_PREFIX, IMSIPRE=3080107000, QOS5QI=9,QOS5QIPL=10,ARPPRL=5,ARPPCI=MAY_PREEMPT,ARPPVI=NOT_PREEMPTABLE;
```
