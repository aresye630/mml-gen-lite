## 操作步骤

1. 增加HTTP固定速率流控的IP地址组信息。

   **ADD HTTPFCIPGRP**
2. 增加HTTP固定速率流控门限。

   **ADD HTTPFIXEDFC**
3. 配置指定类型的消息是否开启固定速率流控。

   **SET HTTPFIXEDFCMSG**
4. 增加基于接口类型的固定速率流控生效的HTTP局向。

   **ADD HTTPOFC**
5. 配置基于接口类型的固定速率流控。

   **ADD HTTPFIXEDFCINF**
6. 配置全局固定带宽流控相关信息。

   **SET HTTPGLBFIXEDBWFC**
7. 开启ReqCB流控开关。

   **SET HTTPCONF**
8. 配置基于ReqCB资源的流控信息。

   **ADD HTTPRESCFG**
9. 配置基于内存的流控信息。

   **SET HTTPMEMFC**

任务描述

脚本

**任务1：**以NRF作为HTTP服务端为例，在NRF上配置链路粒度的基于IP流控组的固定速率流控。

//配置流控组信息。

```
ADD HTTPFCIPGRP: INDEX=1, GROUP=1, IPTYPE=IPv4, IPV4ADDR="192.168.100.1", IPV4MASK="255.255.255.0", DESC="AMF_instance1"; 
ADD HTTPFCIPGRP: INDEX=2, GROUP=1, IPTYPE=IPv4, IPV4ADDR="192.168.101.2", IPV4MASK="255.255.255.0", DESC="AMF_instance2";
```

//配置流控速率。

```
ADD HTTPFIXEDFC: GROUP=1, GROUPTYPE=SERVER, RECVTHD=1000, STATUSCODE=TooManyRequests, RETRYAFTERFLAG=NO, DESC="LINK";
```

**任务2**：以NRF作为HTTP服务端为例，在NRF上配置整机粒度的基于IP流控组的固定速率流控。

//配置流控组信息。

```
ADD HTTPFCIPGRP: INDEX=3, GROUP=2, IPTYPE=IPv4, IPV4ADDR="192.168.200.1", IPV4MASK="255.255.255.0", DESC="AMF_instance1";
```

//配置流控速率。

```
ADD HTTPFIXEDFC: GROUP=2, GROUPTYPE=SERVER, GLBRECVTHD=2000, STATUSCODE=TooManyRequests, RETRYAFTERFLAG=NO, DESC="GLOBAL";
```

**任务3**：以SMF收到AMF发送的Nsmf\_PDUSession\_CreateSMContext Request和Nsmf\_PDUSession\_RetrieveSMContext Request消息为例 ，在SMF上配置指定消息类型的固定速率流控。

//配置指定消息类型的固定速率流控。

```
SET HTTPFIXEDFCMSG: MSGTYPE=NSMF_PDUSESSION_SMCONTEXTSCREATE, FCSWITCH=ON, THRESHOLD=1200;
SET HTTPFIXEDFCMSG: MSGTYPE=NSMF_PDUSESSION_RETRIEVESMCONTEXT, FCSWITCH=ON, THRESHOLD=1200;
```

**任务4**：以SMF到AMF的局向为例，SMF作为HTTP服务端，在SMF上配置基于接口类型的固定速率流控。

//增加基于接口类型的固定速率流控生效的HTTP局向。

```
ADD HTTPOFC: OFCIDX=1, OFCTYPE=NFTYPE, PEERNFTYPE=NFTypeAMF, NFITEM=HTRINTF-0&FIXSPDFCINTF-1, LOCALNFTYPE=NFTypeSMF, OFCNAME="SMF2AMFFIXSPDFCINTF";
```

//配置基于接口类型的固定速率流控。

```
 ADD HTTPFIXEDFCINF: OFCIDX=1, LETYPE=SERVER, RECVTHD=1200, STATUSCODE=TooManyRequests, RETRYAFTERFLAG=NO;
```

**任务5**：配置全局固定带宽流控。

//配置全局固定带宽流控。

```
SET HTTPGLBFIXEDBWFC: SENDFCSWITCH=ON,RECVFCSWITCH=ON,SENDTHD=15000,SENDBIGPKTTHD=1024,RECVTHD=15000,RECVBIGPKTTHD=1024, STATUSCODE=TooManyRequests;
```

**任务6**：以本端作为HTTP客户端为例，配置基于ReqCB资源的流控。

//开启ReqCB流控开关。

```
SET HTTPCONF: REQCBFCSW=TRUE;
```

//配置基于ReqCB资源的流控信息。

```
ADD HTTPRESCFG: INDEX=1, RESTYPE=REQCB, LETYPE=CLIENT, PEERIPTYPE=IPv4, PEERIPV4="192.168.1.1", THRESHOLD=100; 
ADD HTTPRESCFG: INDEX=2, RESTYPE=REQCB, LETYPE=CLIENT, PEERIPTYPE=IPv6, PEERIPV6="2001:0db8::1", THRESHOLD=100;
```

**任务7**：配置基于内存资源的流控。

//配置基于内存资源的流控信息。

```
SET HTTPMEMFC: MEMFCSWITCH=TRUE, MEMFCSTARTTHD=30, MEMFCSTOPTHD=50, MEMFCBIGPKTTHD=512;
```
