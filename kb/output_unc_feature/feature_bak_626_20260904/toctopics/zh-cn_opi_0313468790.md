## 操作场景

本操作指导介绍在运行网络中激活SMSF短消息业务的操作过程。

## 必备事项

前提条件

已完成SMSF初始配置。

数据

| 类别            | 参数名称                    | 取值样例                | 获取方法   | 说明                                                        |
|:--------------|:------------------------|:--------------------|:-------|:----------------------------------------------------------|
| SET NGMMFUNC  | 支持通过NAS传短消息（SMSOVERNAS） | SUPPORT             | 全网规划   | 开启AMF支持通过NAS传短消息功能。                                       |
| ADD NGPEIPLCY | PEI获取策略（GETPEIPLCY）     | GETIMEISV（获取IMEISV） | 本端规划   | 配置网络侧获取用户设备标识，支持配置为不获取、获取IMEI、获取IMEISV。 本例中推荐配置为获取IMEISV。 |

## 操作步骤

配置AMF数据

1. 进入“MML命令行-UNC”窗口。

2. 配置AMF支持短消息功能。

   **SET NGMMFUNC**
3. （可选）打开获取IMEISV开关。如果需要获取用户设备标识，建议配置为GETIMEISV(获取IMEISV)，这样AMF可直接向UE获取IMEISV，减少信令消耗。

   **ADD NGPEIPLCY**

## 任务示例

任务描述

部署短消息基本业务。

脚本

//进入“MML命令行-UNC”窗口。

//配置AMF支持短消息功能。

```
SET NGMMFUNC:SMSOVERNAS=SUPPORT;
```

//（可选）打开获取IMEISV功能。

```
ADD NGPEIPLCY: SUBRANGE=IMSI_PREFIX, IMSIPRE="123456", GETPEIPLCY=GETIMEI, CHKPEIPLCY=NOCHK;
```
