# 配置专用DNN基础数据

- 操作场景
- 必备事项
- 任务示例

## 操作场景

本操作用于指导专用DNN上线时，如何修改PCF向NRF注册的网元信息配置。

## 必备事项

前提条件

已按照运营商配置规范完成PCF网元的基本配置，并与周边网元完成对接。

数据

| 类别           | 参数名称             | 取值样例                        | 获取方法   | 说明                                                                                                          |
|:-------------|:-----------------|:----------------------------|:-------|:------------------------------------------------------------------------------------------------------------|
| ADD NFDNNGRP | GRPNAME（组名称）     | NFDNNGRP-PCF01              | 本端规划   | 用于标识一个网元DNN组信息所属组的信息。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。                                            |
| ADD NFDNNGRP | INDEX            | 1                           | 本端规划   | 用于标识一个网元DNN组信息在组内的唯一一条记录。 取值范围：1~10240 配置原则：该参数在不同的组名称下可以重复，但和组名称组合以后成为全局唯一对象关键字段，组合不能重复。                   |
| ADD NFDNNGRP | DNN              | stjwt.gd                    | 全网规划   | 用于标识DNN。 取值范围：长度不超过64的字符串。  说明： 如果对端SMF不区分大小写，PCF上需要配置为小写。如果对端SMF区分大小写，需和对端SMF协商保持一致。                       |
| MOD NFINFO   | NFINFOID（网元信息标识） | Group-HNGZgdPCF015PCF001BHW | 全网规划   | 标识网元数据记录的关键字段之一，可以使用LST NFINFO命令查询获得。                                                                       |
| MOD NFINFO   | NFTYPE（网元类型）     | PCF(策略控制功能)                 | 全网规划   | 标识网元数据记录的关键字段之一，可以使用LST NFINFO命令查询获得。                                                                       |
| MOD NFINFO   | DNNLIST（DNN列表）   | stjwt.gd                    | 全网规划   | 可选参数，用于指定网元的DNN列表。 取值范围：长度不超过4096的字符串，字符串由数字、字母、“-”，“.”或“,”组成，开头和结尾不能含有“-”、“.”或“,”，多值之间用“,”分隔，但不能连续使用两个“,”。 |
| MOD NFINFO   | NFDNNGRP（DNN组）   | NFDNNGRP-PCF01              | 本端规划   | 可选参数，用于指定本端网元的DNN组。通过ADD NFDNNGRP命令配置。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。                           |

**说明** 

- DNN组支持配置的DNN数最多为8192个。
- 参数“DNNLIST”与“NFDNNGRP”都是指定本端网元的DNN，两者作用等效，同时配置“**NFDNNGRP**”和“**DNNLIST**”，优先使用“**NFDNNGRP**”。且“DNNLIST”修改易出错且长度限制更严格，推荐采用“NFDNNGRP”配置DNN列表。
- 如果同时配置“**NFDNNGRP**”和“**DNNLIST**”，且需要使用“**DNNLIST**”，则需要通过**MOD NFINFO**命令将“**NFDNNGRP**”配置为“**NULL**”。
- 参数“DNNLIST”与“NFDNNGRP”的配置差异点为：通过配置“**DNNLIST**”添加DNN列表的方式无法对本端网元支持的所有DNN进行分组管理，但是通过配置“**NFDNNGRP**”的方式能有效对本端网元支持的所有DNN进行分组管理。
- 在删除DNN组时，若参数“NFDNNGRP”已经通过**ADD NFINFO**配置生效，需要先将参数“NFDNNGRP”设置为“**NULL**”。

## 任务示例

任务描述

登录CSP OM Portal，在UPCF网元下执行MML命令修改PCF向NRF注册的配置。如果现网已配置“DNNLIST”，可通过添加“NFDNNGRP”，将其改造为“NFDNNGRP”。由于“**NFDNNGRP**”参数优先级高于“**DNNLIST**”，原有“**DNNLIST**”可以不删除。

脚本

1. 执行命令**ADD NFDNNGRP**增加网元DNN组信息，添加专用DNN（以stjwt.gd为例）至DNN组。

   ```
   ADD NFDNNGRP: GRPNAME="NFDNNGRP-PCF01", INDEX=1, DNN="stjwt.gd";
   ```
2. 执行**LST NFINFO**查询网元信息，查看是否已配置“DNNLIST”。
   1. 是=>4=>结束
   2. 否=>3=>结束
3. 执行命令**ADD NFINFO**添加网元信息，配置DNN组。

   ```
   ADD NFINFO: NFINFOID="Group-HNGZgdPCF015PCF001BHW", NFTYPE=PCF, NFDNNGRP="NFDNNGRP-PCF01", DNNLIST="stjwt.gd";
   ```
4. 执行命令**MOD NFINFO**修改网元信息，配置DNN组。

   ```
   MOD NFINFO: NFINFOID="Group-HNGZgdPCF015PCF001BHW", NFTYPE=PCF, NFDNNGRP="NFDNNGRP-PCF01";
   ```
