# 激活eMTC基于延迟定时器的信令拥塞控制（适用于PGW-C）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当运营商需要部署基于延迟定时器的信令拥塞控制功能时，需要对本功能进行配置，确保本功能可以正常使用。

**说明** 

适用于PGW-C。

## 必备事项

前提条件

- 请仔细阅读WSFD-216101 eMTC基于延迟定时器的信令拥塞控制特性概述（适用于PGW-C）。
- 完成加载License。

数据

| 类别               | 参数名称                               | 取值样例   | 获取方法     | 说明                                                           |
|:-----------------|:-----------------------------------|:-------|:---------|:-------------------------------------------------------------|
| SET GBACKOFFTIME | 全局Back-Off Time时长(秒)（BACKOFFTIMER） | 600    | 本端规划     | 设置全局Back-Off时长                                               |
| SET BACKOFFTIME  | APN名称（APNNAME）                     | apn-op | 已配置数据中获取 | 规划使能基于延迟定时器的信令拥塞控制功能的APN实例，已通过ADD APN命令配置，可以使用LST APN命令进行查询。 |
| SET BACKOFFTIME  | 系统过载场景下Backoff-time开关（OVERLOADSW）  | ENABLE | 本端规划     | 系统过载时使用APN的Back-off time功能。                                  |
| SET BACKOFFTIME  | 是否继承全局Back-Off时长（INHERIT）          | NO     | 本端规划     | 配置PGW-C Backoff-time字段携带的时间长度。                               |
| SET BACKOFFTIME  | Back-off时长 （秒）（BACKOFFTIMER）       | 900    | 本端规划     | 配置PGW-C Backoff-time字段携带的时间长度。                               |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 设置全局Back-Off时长。

   **SET GBACKOFFTIME**
4. 配置APN的 Back-off时长。

   **SET BACKOFFTIME**

## 任务示例

任务描述

系统过载时使用APN的Back-off time功能。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3WMTSBT11",SWITCH=ENABLE;
```

//设置全局Back-Off时长。

```
SET GBACKOFFTIME:BACKOFFTIMER=600;
```

//配置APN粒度的PGW-C Back-off time功能。

```
SET BACKOFFTIME:APNNAME="apn-op", OVERLOADSW=ENABLE, BACKOFFTIMER=900;
```
