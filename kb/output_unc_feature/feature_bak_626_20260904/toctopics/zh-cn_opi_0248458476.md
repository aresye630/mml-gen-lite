# 激活多时区业务特性（适用于AMF）

- 操作场景

## 操作场景

本操作指导介绍在运行网络中激活AMF的多时区功能的操作过程。

**说明** 

适用于AMF。

## 必备事项

前提条件

- 请仔细阅读WSFD-106009 多时区业务特性概述。
- 该操作不需要开启License。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置UNC是否可以向UE发送网络信息。

   **SET NGMMFUNC**

   **说明** 

   如果此处配置UNC不可以向UE发送网络信息，则在AMF无法通过Configuration Update Command消息向UE下发网络标识、时区和夏令时等信息。
3. **可选：**配置NITZ下发时间时的本地时间根据UTC时间获取，避免向UE发送的时区不符合协议。

   **SET AMFSOFTPARAOFBIT**
4. 基于区域范围和用户群组组合的粒度来灵活设置不同的网络名称。

   - 配置区域编码

     **ADD AREACODE**
   - 为指定的区域增加跟踪区成员

     **ADD AREAMEM**
   - 配置5G用户群标识

     **ADD NGUSRGRP**
   - 配置用户群成员

     **ADD NGUSRGRPMEM**
5. 为指定区域和指定用户群配置网络名称。

   **ADD NITZPLCY**

   **说明** 

   - UNC整系统的网络名称（运营商名称）已在**ADD NGMNO**命令中配置。当需要匹配的区域范围为所有区域，用户群组为所有用户时，则优先使用**ADD NGMNO**配置的移动网络运营商名称，其次使用**ADD NITZPLCY**配置的网络名称。
   - 对于区域范围，网络名称与区域范围的匹配优先级从高到低依次为：“AREA\_CODE(指定区域编码)”，“ALL\_AREA(所有区域)”。
   - 对于指定的用户（群），网络名称的优先级从高到低依次为：“USER\_GROUP(用户群)/IMSI\_PREFIX(指定IMSI前缀)”，“FOREIGN\_USER(外网用户)”或“HOME\_USER(本网用户)”，“ALL\_USER(所有用户)”。
   - USER\_GROUP(用户群)与IMSI\_PREFIX(指定IMSI前缀)为互斥关系。
   - 同一个区域编码中，可以配置不同的USRGRPID，但是不同的USRGRPID在**ADD NGUSRGRPMEM**中不能有相同的IMSIPRE成员。
   - 当配多个指定区域编码时，不同指定区域编码对应的区域成员在**ADD AREAMEM**中不允许交叠。
6. 配置时区和夏令时信息。

   **ADD NGTZLST**
7. 为指定区域的用户配置时区标识。

   **ADD NGAREATZ**

## 任务示例

任务描述

在5G网络中启用多时区功能。用户群组标识为20，为该用户群组在特定区域配置网络名称，全称为“Ch Mobile”，简称为“CM”。特定区域的区域编码为“MyTown”，包含跟踪区TAC1（010101）和TAC2（010102）。

脚本

//设置UNC可以向UE发送网络信息和时区信息。

```
SET NGMMFUNC: SNDNETINFO=YES;
```

//配置NITZ下发时间时的本地时间根据UTC时间获取，避免向UE发送的时区不符合协议。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=5, VALUE=VALUE_1, POSITION=15;
```

//配置区域范围和区域成员。

```
ADD AREACODE：AREACODE="MyTown";
ADD AREAMEM：AREACODE="MyTown", MCC=123, MNC=456, BGNTAC=010101, ENDTAC=010102;
```

//配置用户群组和群成员。

```
ADD NGUSRGRP：USRGRPID=20;
ADD NGUSRGRPMEM：USRGRPID=20, IMSIPRE=123456;
```

//为指定区域和指定用户群配置网络名称。

```
ADD NITZPLCY：AREARANGE=AREA_CODE, AREACODE="MyTown", SUBRANGE= USER_GROUP, USRGRPID=20, FULLNAME="Ch Mobile", SHORTNAME="CM";
```

//配置时区和夏令时信息。

```
ADD NGTZLST: TZID=1, TZONE=E0000, DST=YES, SM=DATE, SMONTH=JAN, SDAY=15, ST=18&10&02, EM=DATE, EMONTH=MAR, EDAY=1, ET=23&10&56, TO=1;
```

//为指定区域的用户配置时区标识。

```
ADD NGAREATZ: MCC="123", MNC="456", BGNTAC="010101", ENDTAC="010102", TZID=1;
```
