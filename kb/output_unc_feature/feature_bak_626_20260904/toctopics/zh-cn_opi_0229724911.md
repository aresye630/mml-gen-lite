## 操作场景

通过配置QoS与流量管理，可实现以下需求：

- 为了保证在资源紧缺时，运营商能够为高优先级用户优先分配资源。
- 在资源相对富余时，更充分地发挥网络资源的效益，提高客户满意度。

QoS与流量管理指UNC支持3GPP QoS，按照QoS等级对用户报文进行分类，还可以提供DiffServ，从而支持流量监管、拥塞管理、拥塞避免等多种QoS实现技术。

## 操作步骤

- 配置签约QoS属性。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置签约QoS。

     **ADD PRER8SUBQOS**
- 配置基于全局的3GPP QoS到DSCP/ToS的映射关系。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置整机使能用户的上下行Remark功能。

     ****SET QOSREMARK****
  3. 配置基于全局的QoS Profile。

     **SET QOSGLOBAL**
  4. 配置PreR8 QoS参数到IP报文头中的DSCP/ToS的映射规则。

     **ADD PRER8REMARK**
- **可选：**配置基于APN的3GPP QoS到DSCP/ToS的映射关系。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置整机使能用户的上下行Remark功能。

     ****SET QOSREMARK****
  3. 配置QosProfile。

     ****ADD QOSPROFILE****
  4. 配置PreR8 QoS参数到IP报文头中的DSCP/ToS的映射规则。

     **ADD PRER8REMARK**
  5. 配置指定AP实例。

     **ADD APN**
  6. 为该APN实例绑定QOSPROFILE。
- 置基于APN的3GPP QoS到DSCP/ToS的映射关系。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置整机使能用户的上下行Remark功能。

     **SET QOSREMARK**
  3. 配置QosProfile。

     **ADD QOSPROFILE**
  4. 配置在5GC架构下，QoS参数到IP报文头中的DSCP/ToS的映射规则。

     **ADD 5GCREMARK**
  5. 配置指定APN实例。

     **ADD APN**
  6. 为该APN实例绑定QOSPROFILE。

     **SET APNQOSATTR**
- 配置PreR8 QoS纠错参数。
  1. 进入“MML命令行-UNC”窗口。
  2. 配置PreR8 QoS纠错参数。

     **SET DEFPRER8QOS**

## 任务示例

任务描述

- 配置基于全局的3GPP QoS到DSCP/ToS的映射关系。
- 配置基于APN的3GPP QoS到DSCP/ToS的映射关系。

脚本

- 配置基于全局的3GPP QoS到DSCP/ToS的映射关系。

  //配置整机使能用户的上下行Remark功能。

  ```
  SET QOSREMARK:DOWNLINK=ENABLE,UPLINK=ENABLE;
  ```

  //配置PreR8 QoS参数到IP报文头中的DSCP/ToS的映射规则。

  ```
  LST QOSGLOBAL:;
  ADD PRER8REMARK:QOSPROFILENAME="globalqos",SERVICELEVEL=CONVERSATIONAL,USERPRIORITY=HIGH,REMARKTYPE=DSCP,DSCP=EF;
  ```

- 配置基于APN的3GPP QoS到DSCP/ToS的映射关系。

  //配置整机使能用户的上下行Remark功能。

  ```
  SET QOSREMARK:DOWNLINK=ENABLE,UPLINK=ENABLE;
  ```

  //配置QosProfile，并进入QoS实例。

  ```
  ADD QOSPROFILE:QOSPROFILENAME="gp1";
  ```

  //配置PreR8 QoS参数到IP报文头中的DSCP/ToS的映射规则。

  ```
  ADD PRER8REMARK:QOSPROFILENAME="gp1",SERVICELEVEL=CONVERSATIONAL,USERPRIORITY=HIGH,REMARKTYPE=DSCP,DSCP=EF;
  ```

  //查找APN实例。

  ```
  LST APN:;
  ```

  //为该APN实例绑定QOSPROFILE。

  ```
  SET APNQOSATTR:APN="apn",HASQOSPROFILE=ENABLE,QOSPROFILENAME="gp1";
  ```
