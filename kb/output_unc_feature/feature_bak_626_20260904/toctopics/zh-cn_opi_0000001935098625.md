# 配置UDM-UIM与专网UPF的对接数据（DRA转接）

- 操作场景
- 必备事项
- 任务示例

## 操作场景

本页面用于指导操作员配置UDM-UIM通过Diameter信令与专网UPF的对接数据，UDM-UIM与专网UPF以DRA转接方式对接。

## 必备事项

前提条件

- 操作人员具有管理员权限。
- CSP与服务器端通信正常。
- UDM-UIM与DRA侧均完成了软件安装和基础数据的配置。
- UDM-UIM与DRA的对接信令数据已经协商。

## 任务示例

任务描述

本范例配置通过DRA转接到专网UPF的Diameter数据。

脚本

1. 登录“UDM MML命令”界面。
2. 使用**ADD DMLE**命令增加Diameter本端实体。

   ```
   ADD DMLE: EN="AAA", LOCTYPE=AAA, DN="huawei.com", HN="UDM.huawei.com";
   ```
3. 使用**ADD DMPE**命令增加Diameter对端实体DRA。

   ```
   ADD DMPE: EN="DRA01", PEERTYPE=OTHER, HN="dra01.huawei.com", PEPRI=15;
   ```

   ```
   ADD DMPE: EN="DRA02", PEERTYPE=OTHER, HN="dra02.huawei.com", PEPRI=15;
   ```
4. 使用**ADD DMRTS**命令增加Diameter路由组数据。

   ```
   ADD DMRTS: RTSNAME="DRA_RT01", RN="huawei.com", APPID=SWm, SMODE=POLLING;
   ```
5. 使用**ADD DMRT**命令增加Diameter路由数据到DRA对端。

   ```
   ADD DMRT: RTNAME="DRA_RT01", PEERNAME="DRA01";
   ```

   ```
   ADD DMRT: RTNAME="DRA_RT02", PEERNAME="DRA02";
   ```
6. 使用**ADD DMLKS** 命令增加Diameter链路集。

   ```
   ADD DMLKS: LINKSNAM="Diameter_aaa01", LOCALNAM="AAA", PEERNAM="DRA01", LNKMOD=ACTIVE;
   ```

   ```
   ADD DMLKS: LINKSNAM="Diameter_aaa02", LOCALNAM="AAA", PEERNAM="DRA02", LNKMOD=ACTIVE;
   ```
7. 使用**ADD DMLNK**命令增加Diameter链路。

   ```
   ADD DMLNK: LNKNAME="LINKDRA01_AAA001", LINKSNAM="Diameter_aaa01", HSFMID=67, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", PIPVER=IPV4, PIPV4="192.168.251.66", IPNAM2="HSFIP2", SPIPVER=IPV4, SPIPV4="192.168.252.66", PPT=5062, LINKPRI=15, CROSSPATHFLAG=NO;
   ADD DMLNK: LNKNAME="LINKDRA01_AAA002", LINKSNAM="Diameter_aaa01", HSFMID=67, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", PIPVER=IPV4, PIPV4="192.168.251.106", IPNAM2="HSFIP2", SPIPVER=IPV4, SPIPV4="192.168.252.106", PPT=5063, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   ```
   ADD DMLNK: LNKNAME="LINKDRA02_AAA001", LINKSNAM="Diameter_aaa02", HSFMID=67, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", PIPVER=IPV4, PIPV4="192.168.251.46", IPNAM2="HSFIP2", SPIPVER=IPV4, SPIPV4="192.168.252.46", PPT=5064, LINKPRI=15, CROSSPATHFLAG=NO;
   ADD DMLNK: LNKNAME="LINKDRA02_AAA002", LINKSNAM="Diameter_aaa02", HSFMID=67, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSFIP1", PIPVER=IPV4, PIPV4="192.168.251.26", IPNAM2="HSFIP2", SPIPVER=IPV4, SPIPV4="192.168.252.26", PPT=5065, LINKPRI=15, CROSSPATHFLAG=NO;
   ```

   **说明** 

   - 配置UDM-UIM的DRA链路时，一般都配置2条链路，两条链路的HSF模块使用不同虚拟机上面的HSF模块。
   - 在对端网元支持的情况下，UDM-UIM一般配置为双归属组网。此时配置两条链路的“对端IP地址”为对方的“对端备用IP地址”。
   - 链路增加后会自动激活，但是如果对链路进行了修改，则需要使用**DEA DMLNK**命令去激活链路，再使用**ACT DMLNK**命令激活链路。
   - 如果同一设备类型配置了多个本地主机名，则DRA需要和该类型的所有本地主机名配置链路。
   - 为保证各IPU（Interface Processing Unit）之间实现负载均衡，需要在HSF模块上配置多个IP。同时，在配置链路时需要将链路均分到多个IP上。
   - 当本命令中的“工作模式”参数设为“SERVERMULTPORT(服务端多端口)”时，由于本端端口与HSF模块一一对应，为保证各HSF模块之间实现负载均衡，在配置链路时需要在多个HSF模块上配置不同的本端端口。同时，将对端的链路配置均分到多个本端端口上。
