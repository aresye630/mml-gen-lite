## 操作场景

本章节用于指导在SMF上配置基于专网业务DNN的分流策略的过程。

## 必备事项

前提条件

- 请仔细阅读WSFD-223003 基于漫游地动态签约的分流策略控制特性概述。
- 已完成本特性License加载，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。
- 已完成**WSFD-109101 PCC基本功能**、**WSFD-107010 UPF选择**和**WSFD-108002 本地分流策略控制**的部署。
- 以下配置过程是基于SMF和**主锚点UPF**以及**“ULCL UPF+辅锚点UPF”**的对接配置已完成情况下的操作。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置指定APN的ULCL策略。
   1. 配置ULCL属性名称和DNAI的绑定关系。

      **ADD ULCLPROP**
   2. 配置ULCL过滤器名称。

      **ADD FLOWFILTER**
   3. 配置ULCL分流策略rule。

      **ADD RULE**
   4. 配置ULCL属性的用户模板。

      **ADD USERPROFILE**
   5. 将上述rule绑定至用户模板。

      **ADD RULEBINDING**
3. 配置基于DNN的分流，将专网DNN绑定至UL CL分流规则中。
   1. 配置使能SMF上的ULCL功能。

      **ADD APN**
   2. 配置用户模板组。

      **ADD USRPROFGROUP**
   3. 将上述用户模板绑定至用户模板组。

      **ADD UPBINDUPG**
   4. 将用户模板组绑定至专网DNN。

      **ADD APNUSRPROFG**
4. 配置IPv6会话场景下的分流策略。

   **SET SMFFUNC**

## 任务示例

任务描述

某商业机构提供专网业务，用户可通过自己的手机号码注册使用该专网业务。假定该专网业务的DNN为dnn-ar，覆盖该商业机构的ULCL UPF的实例ID为UPF\_Instance\_0。

脚本

//配置使能专网业务DNN的ULCL功能。

```
ADD APN:APN="dnn-ar", ULCLFUNC=ENABLE,TRAFFICDIST=ENABLE;
```

//为专网业务添加DNAI信息。

```
ADD PNFDNAI: INDEX=1,NFINSTANCEID="UPF_Instance_0", DNAI="testdnai",PNFDNNINDEX=3;
```

//配置指定DNN的ULCL策略。

```
//配置ULCL属性名称和DNAI的绑定关系。
ADD ULCLPROP: ULCLPROPNAME="testulclpropname", DNAI="testdnai"; 
//配置ULCL过滤器名称。
ADD FLOWFILTER: FLOWFILTERNAME="ulcl"; 
//配置ULCL分流策略rule。
ADD RULE:RULENAME="testrule",POLICYTYPE=ULCL, POLICYNAME="testulclpropname", FLOWFILTERNAME="ulcl"; 
//配置ULCL属性的用户模板，并将ULCL分流策略rule绑定至该模板。
ADD USERPROFILE:USERPROFILENAME="testuserprofilename", UPTYPE=ULCL; 
ADD RULEBINDING: USERPROFILENAME="testuserprofilename",RULENAME="testrule";
//配置用户模板组，并将ULCL属性的用户模板绑定至该模板组，再将模板组绑定至指定APN。
ADD USRPROFGROUP:USERPROFGNAME="ulcl_test";
ADD UPBINDUPG:USERPROFGNAME="ulcl_test",UPBINDTYPE=ULCL,USERPROFILENAME="testuserprofilename";
ADD APNUSRPROFG:APN="dnn-ar",USERPROFGNAME="ulcl_test";
//配置IPv6会话场景下的分流策略。
SET SMFFUNC: IPV6LOCALUP=UlClPrefer;
```
