# 配置和SEPP对接

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

5G SA国际漫游场景下SMF需要和SEPP对接，通过SEPP集中转发信令。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- UNC软件安装已完成。

- 请了解UNC各类接口的类型及协议，具体内容请参见业务组网与逻辑接口介绍。
- 对于IPv4组网，已完成自动部署配置动态路由OSPF+BFD组网（IPv4）、配置静态路由+BFD组网（IPv4）、配置BGP over OSPF/静态路由+BFD（IPv4）或手动部署配置动态路由OSPF+BFD组网（IPv4）、配置静态路由+BFD组网（IPv4）、配置BGP over OSPF/静态路由+BFD（IPv4）。
- 对于IPv6组网，已完成自动部署配置动态路由OSPFv3+BFD组网（IPv6）、配置静态路由+BFD组网（IPv6）、配置BGP over OSPFv3/静态路由+BFD（IPv6）或手动部署配置动态路由OSPFv3+BFD组网（IPv6）、配置静态路由+BFD组网（IPv6）、配置BGP over OSPFv3/静态路由+BFD（IPv6）。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置漫游场景下路由模式以及信令汇聚模式。

   ```
   SET ROAMCOMMPLCY:ROUTEMODE=SEPP, SEPPMODE=HTTPPROXY;
   ```
3. 配置与SEPP组网对接。

   ```
   ADD PNFPROFILE:NFINSTANCEID="SEPP_Instance_0", NFTYPE=NfSEPP, NFSTATUS=Registered, FQDN="sepp1.cluster1.net2.smf.5gc.mnc012.mcc345.3gppnetwork.org", INTERPLMNFQDN="roaming.sepp1.cluster1.net2.smf.5gc.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.182", PORT=80, CAPACITY=100, NFDESCNAME="Roaming_SEPP_01", SCHEME=HTTP;
   ADD PNFPROFILE:NFINSTANCEID="SEPP_Instance_1", NFTYPE=NfSEPP, NFSTATUS=Registered, FQDN="sepp2.cluster1.net2.smf.5gc.mnc012.mcc345.3gppnetwork.org", INTERPLMNFQDN="roaming.sepp2.cluster1.net2.smf.5gc.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.183", PORT=80, CAPACITY=100, NFDESCNAME="Roaming_SEPP_02", SCHEME=HTTP;
   ```
