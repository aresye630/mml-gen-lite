# 配置QoS能力开放功能

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

运营商需要UNC支持外部QoS能力开放服务器通过私有接口查询用户信息，需要激活QoS能力开放的功能。

**说明** 

适用于GGSN、PGW-C。

## 必备事项

前提条件

- 请仔细阅读PCC基本功能（2G/3G/4G，基于Gx接口）。
- 操作员了解UNC各类接口的类型及命名规范，具体内容请参见SGW-C、PGW-C、GGSN。
- 操作员了解UNC与对端网元互通时可以采用的各种组网方式，以及每种组网方式的实现及特点等信息。
- 如果运营商规划采用VPN组网方式，则操作员在执行本操作前应已创建了相应的VPN实例。
- 需要配置逻辑接口的PBU正常运行，且PBU上无用户存在。当PBU还未启动或正在启动过程中，将无法在该PBU上配置逻辑接口。

## 操作步骤

1. 配置外联口IP及路由数据，详细请参见组网路由配置。
2. 进入“MML命令行-UNC”窗口。
3. 创建一个VPN实例。

   **ADD VPNINST**
4. 配置Restif逻辑接口地址。

   **ADD LOGICIP**
5. 配置HTTP本端端点组信息。

   **ADD HTTPLEGRP**
6. 配置HTTP本端端点信息。

   **ADD HTTPLE**
7. 配置服务化接口本端实体。

   **ADD SBIAPLE**
8. 使能HTTP1.1开关。

   **SET HTTPCONF**
9. 开启QoS能力开放功能开关。

   **SET SMCOMMFUNC**

## 任务示例

任务描述

本实例中，操作员在UNC上进行数据配置实现以下要求：

- UNC使用逻辑接口与SBC连通。
- UNC使用VPN缺省路由与SBC建立起正常的IP连接。

脚本

1. 创建一个VPN实例。

   ```
   ADD VPNINST:VPNINSTANCE="vpn_restif";
   ```
2. 配置即Restif逻辑接口地址（HTTP本端端点的逻辑地址信息）。

   ```
   ADD LOGICIP:IPVERSION=IPv6, LOGICIPV6="fe80:8029:5008:6B::247", VPNINSTNAME="vpn_restif", DESC="Restful_IPv6_Client";
   ```

   ```
   ADD LOGICIP:IPVERSION=IPv6, LOGICIPV6="fe80:8029:5008:6B::248", VPNINSTNAME="vpn_restif", DESC="Restful_IPv6_Server";
   ```
3. 配置HTTP本端端点组信息。

   ```
   ADD HTTPLEGRP: INDEX=3, DESC="BSF";
   ```
4. 配置HTTP本端端点信息（包括服务端和客户端）。

   ```
   ADD HTTPLE: INDEX=7, HTTPLEGRPIDX=3, LETYPE=CLIENT, DESC="BSF Client", IPTYPE=IPv6, IPV6="fe80:8029:5008:6B::247", VPNNAME="vpn_restif";
   ```

   ```
   ADD HTTPLE: INDEX=8, HTTPLEGRPIDX=3, LETYPE=SERVER, PORT=80, TLSFLG=NO, DESC="BSF Server", IPTYPE=IPv6, IPV6="fe80:8029:5008:6B::248", VPNNAME="vpn_restif";
   ```
5. 配置服务化接口本端实体。

   ```
   ADD SBIAPLE: INDEX=1, HTTPLEGRPIDX=3, NFTYPE=NFTypeBSF, DESCRIPTION="BSF";
   ```
6. 使能HTTP1.1开关。

   ```
   SET HTTPCONF: HTTPVERSIONSW=TRUE;
   ```
7. 开启QoS能力开放功能。

   ```
   SET SMCOMMFUNC: PCRFQRYSW=ENABLE
   ```
