# 配置通用DNN策略数据

- 操作场景
- 必备事项
- 任务示例

## 操作场景

用户上线接入通用DNN（common.dnn），PCF支持通过N7接口给SMF下发智能分流的动态规则，使园区业务从专用DNN（stjwt.gd）接入访问。

## 必备事项

前提条件

- 已按照运营商配置规范完成PCF网元的基本配置，并与周边网元完成对接。
- 用户已签约大网套餐，不需要PCF配置和下发大网套餐。
- 确认新建场景下的多DNN特性参数已规划，例如，专用DNN名称、IP地址池规划、园区IP地址列表、域名列表。

**说明** 

PCF配置基于漫游的多DNN特性具有以下限制：

- 单个N7会话支持的最大FQDN、URL和IP地址段累计长度不超过10000。
- 最大支持园区数5000个，受限于ADD NGACTION命令配置最大支持5000个类型为MulDNNSessRule的5G Action。

## 任务示例

任务描述

在PCF上配置一个增值类业务（MulDNN\_Service01），关联分流策略（MulDNN\_Policy01），该策略包含以用户从通用DNN（common.dnn）上线为条件，以URL、DNN和切片信息为动作的分流规则（MulDNN\_Rule01）。

若局点已开启异网漫游功能，还需同时满足用户从本网（Localnetwork）接入的条件，用于确保仅对本网接入的用户下发分流策略。

脚本

登录UPCF WebUI界面进行业务配置，在“系统管理 > 批处理 > CLI导入”界面执行以下CLI命令。

**说明** 

登录UPCF WebUI界面可参考《UPCF 产品文档》>UPCF WebUI GUI参考 > UPCF WebUI > 登录UPCF WebUI界面。

1. 添加本网标识，此处以PLMN\_01（MCC="100",MNC="001"）、PLMN\_02（MCC="101",MNC="002"）为例进行配置。仅在局点已开启异网漫游功能时需要配置此条件，现网配置参数以局点实际情况为准。

   ```
   ADD PLMN:PLMNIDENTITY="PLMN_01",PLMNTYPE=Local,MCC="100",MNC="001"; 
   ADD PLMN:PLMNIDENTITY="PLMN_02",PLMNTYPE=Local,MCC="101",MNC="002"; 
   ADD ROAMREGION:ROAMREGIONIDENTITY="Localnetwork";
   ADD ROAMREGIONPLMN:ROAMREGIONIDENTITY="Localnetwork",PLMNIDENTITY="PLMN_01";
   ADD ROAMREGIONPLMN:ROAMREGIONIDENTITY="Localnetwork",PLMNIDENTITY="PLMN_02";
   ```
2. 添加条件组（MulDNN\_CG01），包含条件用户从通用DNN（common.dnn）上线。对于已开启异网漫游功能的局点，还需将用户从本网（Localnetwork）接入添加至此条件组。

   ```
   ADD CONDITIONGROUP:CONDITIONGROUPNAME="MulDNN_CG01",RELATION=AND,USETIMEZONE=No;
   ADD CONDITION:CONDITIONGROUPNAME="MulDNN_CG01",CONDITIONNAME="MulDNN_C01",OBJECTATTRIBUTE="SmfSession.Dnn",OPERATOR=Equal,RIGHTVALUETYPE=Value,RIGHTVALUE="common.dnn";
   /*局点开启异网漫游功能时，需要同时添加用户从Localnetwork上线的条件 */
   ADD CONDITION:CONDITIONGROUPNAME="MulDNN_CG01",CONDITIONNAME="Roaming_C01",OBJECTATTRIBUTE="SmfSession.RoamingRegion",OPERATOR=Equal,RIGHTVALUETYPE=Value,RIGHTVALUE="Localnetwork";
   ```
3. 添加5G动作组，分别用于配置切片信息（MulDNN\_NSSAI），多DNN动作（MulDNN\_5GAG01）和SM策略动作（MulDNN\_5GAG02）的动作类型。

   ```
   /*添加5G动作组MulDNN_NSSAI，用于配置切片信息,动作类型为ServiceNSSAI */
   ADD NGACTION:ACTIONNAME="MulDNN_NSSAI",TYPE="ServiceNSSAI";
   ```

   ```
   /*添加5G动作组MulDNN_5GAG01，用于配置URL、DNN和切片信息，动作类型为MulDNNSessRule，此处以配置IPv4和FQDN为例*/
   ADD NGACTION:ACTIONNAME="MulDNN_5GAG01",TYPE="MulDNNSessRule";
   ```

   ```
   /*添加5G动作组MulDNN_5GAG02，用于配置SM策略动作，动作类型为BasicInfoAction */
   ADD NGACTION:ACTIONNAME="MulDNN_5GAG02",TYPE="BasicInfoAction";
   ```
4. 给5G动作组MulDNN\_NSSAI添加子参数，添加的切片参数以sd=000000，sst=1为例。

   ```
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_NSSAI",ATTRNAME="sd",TYPE=Value,VALUE="000000";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_NSSAI",ATTRNAME="sst",TYPE=Value,VALUE="1";
   ```
5. 给5G动作组MulDNN\_5GAG01添加子参数，配置园区提供服务的多个地址需要用“;”作为分隔符，CLI脚本需要在分隔符前添加转义字符“\”。以配置IPv4和FQDN为例：
   - IPv4地址：10.0.0.1、10.0.0.5、从10.10.10.10到10.10.10.20地址段。
   - FQDN地址：\*.huawei.com。

   ```
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="MulDNNSessRuleId",TYPE=Value,VALUE="MulDNNSessRule01";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceDNN",TYPE=Value,VALUE="stjwt.gd";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceNSSAI",TYPE=Reference ActionGroup,VALUE="MulDNN_NSSAI";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="triggerCategory",TYPE=Value,VALUE="IMMEDIATE_INITIATE";
   /*通过VALUE配置serviceURL*/ 
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,VALUE="IPv4-_-10.0.0.1\;10.0.0.5\;from 10.10.10.10 to 10.10.10.20";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,VALUE="FQDN-_-*.huawei.com";
   ```

   上述serviceURL还可以通过URLTYPE和URLVALUE配置，两种方法选一种配置即可，脚本如下：

   ```
   /*通过URLTYPE和URLVALUE配置serviceURL*/ 
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,URLTYPE=IPv4,URLVALUE="10.0.0.1"; 
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,URLTYPE=IPv4,URLVALUE="10.0.0.5"; 
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,URLTYPE=IPv4,URLVALUE="from 10.10.10.10 to 10.10.10.20";
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG01",ATTRNAME="serviceURL",TYPE=Value,URLTYPE=FQDN,URLVALUE="*.huawei.com";
   ```
6. 给5G动作组添加子参数，给MulDNN\_5GAG02添加MulDNNSessRules参数，用于引用5中配置的多DNN动作组。

   ```
   ADD NGACTIONATTR:ACTIONNAME="MulDNN_5GAG02",ATTRNAME="MulDNNSessRules",TYPE=Reference ActionGroup,VALUE="MulDNN_5GAG01";
   ```
7. 添加规则MulDNN\_Rule01，用于关联2中配置的条件组和6中配置的5G动作组。

   ```
   ADD RULE:RULENAME="MulDNN_Rule01",TYPE=Smf Basic Rule 5G,PRECEDENCE=0,EDR=OFF,RELATION=AND;
   ADD RULECONDITIONGROUP:RULENAME="MulDNN_Rule01",CONDITIONGROUPNAME="MulDNN_CG01";
   ADD RULENGACTION:RULENAME="MulDNN_Rule01",ACTIONNAME="MulDNN_5GAG02";
   ```
8. 添加策略MulDNN\_Policy01，此策略在用户上线时被调用，触发器为IPCAN\_EST、PLMN\_CH（异网漫游场景），用于控制7中配置的规则的下发。

   ```
   ADD POLICY:POLICYNAME="MulDNN_Policy01",TYPE=N7 Policy;
   ADD POLICYRULE:POLICYNAME="MulDNN_Policy01",RULENAME="MulDNN_Rule01";
   ADD POLICYTRIGGER:POLICYNAME="MulDNN_Policy01",TRIGGERNAME="IPCAN_EST";
   ADD POLICYTRIGGER:POLICYNAME="MulDNN_Policy01",TRIGGERNAME="PLMN_CH";
   ```
9. 添加业务MulDNN\_Service01，此业务即为需要PCF下发的分流业务，包含8配置的策略。

   ```
   ADD SERVICE:SERVICENAME="MulDNN_Service01",SERVICETYPE=VALUE_ADDED_SERVICE,ACTIVATEDBY=PCEF,PRECEDENCE=0,QOSMODE=Replace,SUBSCRIPTIONFORCED=Yes,PROBILLDATE=No,QUOTAALLOCATIONMODE=None,ISSETSHAREDMODE=No,RESUBSCRIPTIONOPERATION=NULL,ISGROUPSERVICE=No,ISTEMPLATE=No,ISRECUSRLOC=No,APNMATCHTYPE=Full Matching,HASBASESERVICE=No,ADDONLEVEL=Exhaust,CALCVALIDFORDYNSUBGROUP=No,CUSTOMIZEDRESET=No,MASTER2MASTERSHARESERVICE=No;
   ADD SERVICEPOLICY:SERVICENAME="MulDNN_Service01",POLICYNAME="MulDNN_Policy01";
   ```

在BOSS或PGW Web LMT上进行业务发放。

- 商用场景下，在BOSS上完成园区用户开户，并签约已配置的多DNN业务MulDNN\_Service01。
- 测试场景下，用户需要在PGW Web LMT上完成用户的开户和签约，执行以下命令。

  **说明** 

  - 登录“UPCF 业务管理”窗口可参考《UPCF 产品文档》> PGW Web LMT GUI参考 > PGW Web LMT > 登录“UPCF 业务管理”窗口。
  - 若局点已加载定制适配包AdpConfig\_\*\*\*\_VxxxRxxxCxx.tar，则以下开户和签约命令需要替换为局点对应的定制命令。

  1. 执行**ADD PSUB**增加一个用户。

     ADD PSUB: USRIDENTIFIER="46010381012\*\*\*\*", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=5, USRSUBNETTYPE=MBB, USRLANGUAGE=NULL, USRSMSRECEIVEFLAG=All, USRVERSTATUS=Normal;
  2. 执行**ADD PSRV**给用户签约业务。

     ADD PSRV: USRIDENTIFIER="46010381012\*\*\*\*", SRVNAME="MulDNN\_Service01", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL, SRVCONTACTMETHOD=None, SRVCREATESUBSCRIBER=No, PAYMENTFLAG=Yes;
