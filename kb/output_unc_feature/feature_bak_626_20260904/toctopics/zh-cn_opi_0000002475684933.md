# 配置不同区域下发不同APN（方案二）

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

该任务旨在指导操作人员在4G网络中配置不同区域下发不同APN，配置独立开户模板。

**说明** 

- 运营商大网SMF POOL业务不均质，从POOL中选择两台SMF作为智能分流SMF时，UDM使用此章节方式进行配置。
- 配置不同区域下发不同DNN/APN时用户免签约功能（执行**SET UDMSERV**命令设置“DNN/APN替换业务是否免用户签约”参数）在UDM 20.11.2.15及之后的版本支持，之前的版本无需关注此功能，之后的版本根据局点实际规划进行设置。

## 必备事项

前提条件

- 已完成园区专网UDM的基础配置并与周边网元完成对接。

- 操作人员具有PGW Web LMT客户端业务发放权限。

## 操作步骤

1. 登录“UDM业务管理”窗口。

   **说明** 

   如果现网已配置4G用户数据，则可跳过步骤 5~步骤 8。
2. 执行**SET MAPCONF**命令设置MAP功能流程数据。
3. 执行**SET MAPSERV**命令设置MAP业务数据。
4. 执行**SET UDMSERV**命令设置UDM业务数据。

   **说明** 

   该步骤可选配置“DNN/APN替换业务是否免用户签约”参数。

   - 如果执行**SET UDMSERV**命令设置“DNN/APN替换业务是否免用户签约”参数为“TRUE”，则不需要执行步骤 11。
   - 如果执行**SET UDMSERV**命令设置“DNN/APN替换业务是否免用户签约”参数为“FALSE”，则需要执行步骤 11。
5. 执行**ADD APNTPL**命令增加APN模板。
6. 执行**ADD EPSQOSTPL**命令增加EPS QoS模板。
7. 执行**ADD OPTGPRSTPL**和**MOD OPTGPRSTPL**命令配置优化GPRS/EPS模板。
8. 执行**MOD TPLOPTGPRS**命令给用户签约优化GPRS/EPS业务。
9. 执行**ADD RSITPL**命令增加业务下发模板。
10. 配置全局漫游限制模板。

    - 如果限制区域为本运营商内，则配置PLMN粒度。
      - 执行**ADD PLMNTPL**命令增加PLMN区域漫游模板。
      - 执行**SET MAPSERV**命令设置PLMN粒度全局APN替换漫游模板ID。
    - 如果限制区域为用户归属省内，则配置Diameter粒度。
      - 执行**ADD DIAMRRTPL**命令增加Diameter漫游限制模板。
      - 执行**SET MAPSERV**命令设置Diameter粒度全局APN替换漫游模板ID。
11. （可选）执行**MOD SXZW**命令给用户签约APN替换业务。

## 任务示例

任务描述

在4G网络中配置通用APN下发功能所需的相关数据。

脚本

/\*登录“UDM业务管理”窗口\*/

/\*设置MAP功能流程数据\*/

```
SET MAPCONF: OPTGPRSRSISUPP=TRUE, SUPP_RSI_GPRS=FALSE;
```

/\*设置MAP业务数据\*/

```
SET MAPSERV: GPRSMANAGER=SuppGprsManageOptimizeon, EPC_CHK_5GS_IWK=NOTCHECK;
```

/\*设置UDM业务数据\*/

/\*SXZW\_REPLACE\_MODE参数可选配置，当配置为TRUE时，不需要执行MOD SXZW命令（最后一个步骤）；当配置为FALSE时，需要执行MOD SXZW命令（最后一个步骤）\*/

```
SET UDMSERV: SUPP_DUAL_DOMAINS_DNN=TRUE, SXZW_REPLACE_MODE=FALSE;
```

/\*配置APN模板\*/

```
ADD APNTPL: HLRSN=1, TPLID=111, TPLNAME="APN", APN="common.dnn", PDNGWALLOCTYPE=DYNAMIC, NONIPDATADELMECH=SGi_BASED_DATA_DELIVERY;
```

```
ADD APNTPL: HLRSN=1, TPLID=112, TPLNAME="APN2", APN="stjwt.gd", PDNGWALLOCTYPE=DYNAMIC, NONIPDATADELMECH=SGi_BASED_DATA_DELIVERY;
```

/\*配置EPS QoS模板\*/

```
ADD EPSQOSTPL: HLRSN=1, TPLID=111, TPLNAME="EPSQOS", QOSCLASUID=9, EXTQCI=130, PRILEVEL=6, PREEMPTIONCAP=DISABLE, PREEMPTIONVUL=ENABLE, AMBRMAXREQBWUL=104857600, AMBRMAXREQBWDL=1073741824;
```

/\*配置优化GPRS/EPS模板\*/

```
ADD OPTGPRSTPL: HLRSN=1, TPLID=50, TPLNAME="OPTGPRSTPL", APN_TYPE=EPS_APN, APNTPLID=111, DEFAULTCFGFLAG=TRUE, EPS_QOSTPLID=111, PDPTYPE=IPV4_OR_IPV6, VPLMN=TRUE, CHARGE=NORMAL, IW5GSINDICATOR=SUBSCRIBED;
```

```
MOD OPTGPRSTPL: HLRSN=1, TPLID=50, PROV=ADDPDPCNTX, APN_TYPE=EPS_APN, APNTPLID=112, DEFAULTCFGFLAG=FALSE, EPS_QOSTPLID=111, PDPTYPE=IPV4_OR_IPV6, VPLMN=TRUE, CHARGE=NORMAL, IW5GSINDICATOR=NOT-SUBSCRIBED;
```

/\*执行**MOD TPLOPTGPRS**命令配置模板签约用户的EPS业务，包括common.dnn和stjwt.gd两个APN，其中默认APN为common.dnn\*/

/\*对于新用户，需要先开户再执行该命令\*/

/\*如果用户已开户，直接执行该命令，执行该命令UDM会下发IDR消息\*/

```
MOD TPLOPTGPRS: IMSI="46100000912345", PROV=TRUE, TPLID=50, DELOLD=FALSE;
```

/\*配置业务下发模板，配置DNN/APN替换业务，在特定区域将common.dnn替换为common2.dnn\*/

```
ADD RSITPL: HLRSN=1, TPLID=100, SERCODE=SXZW, OLDAPNLIST="common.dnn", NEWAPNLIST="common2.dnn";
```

/\*配置全局漫游限制模板，区域匹配成功，会把用户签约的common.dnn替换为common2.dnn后下发，下发common2.dnn和专用APN。区域匹配失败的用户，下发用户签约的common.dnn和专用APN\*/

/\*如果限制区域为本运营商内，则配置PLMN粒度。增加PLMN区域漫游模板\*/

```
ADD PLMNTPL: HLRSN=1, TPLID=100, DEFAULTRULE=PERMISSION, RSITPLID=100, MCC="460", MNC="00", ISLOCAL=TRUE, RULE=PERMISSION, CUSTOMRULE=PERMIT;
```

/\*设置PLMN粒度全局APN替换漫游模板ID\*/

```
SET MAPSERV: EPCSXZWPLMNRRID=100;
```

/\*如果限制区域为用户归属省内，则配置Diameter粒度。增加Diameter漫游限制模板\*/

```
ADD DIAMRRTPL: HLRSN=1, TPLID=100, DEFAULTRULE=PERMISSION, RSITPLID=100, DIAMIDENTITYTYPE=HOSTNAME, DIAMIDENTITY="test.huawei.com", RULE=PERMISSION;
```

/\*设置Diameter粒度全局APN替换漫游模板ID\*/

```
SET MAPSERV: EPCSXZWDIAMRRID=100;
```

/\*（可选）如果已执行SET UDMSERV命令配置SXZW\_REPLACE\_MODE参数，当配置为TRUE时，不需要执行MOD SXZW命令；当配置为FALSE时，需要执行MOD SXZW命令\*/

/\*签约4G APN替换业务，CTRLSCHE设置为4GSXZW。如果需要同时签约4G&5G DNN/APN替换业务，CTRLSCHE设置为SXZW，执行该命令会触发CANCEL消息给MME，原因值携带：SUBSCRIPTION\_WITHDRAWAL\*/

```
MOD SXZW: IMSI="46100000912345", CTRLSCHE="4GSXZW";
```
