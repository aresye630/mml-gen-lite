# 配置费率切换

- 操作场景

- 任务示例

## 操作场景

UNC支持节假日、星期及其费率时段的灵活设置，增强话单的计费信息收集功能。运营商可以在UNC上针对节日、周末和工作日的特定时间段设置不同的计费标准，从而吸引移动用户消费，增加运营商收入。

UNC支持如下粒度配置费率切换：“User Profile实例 > APN实例 > 计费属性 > 整机”，优先级依次降低，如果高一优先级的参数没有配置，则默认继承低一优先级的参数配置。

## 必备事项

前提条件

- 请仔细阅读融合计费原理和Ga/Gy接口离线/在线计费。
- 完成加载License。
- 本操作任务涉及的APN/DNN、User Profile、User Profile group已经创建完成，并完成User Profile group与APN/DNN的绑定。

## 操作步骤

1. 配置费率切换。
   1. 配置节假日信息，即设置指定日期的费率类型为节假日。

      **ADD FESTIVAL**
   2. 配置星期表信息，即设置指定星期的费率类型为工作日或周末。

      **ADD WEEKDAY**
   3. 配置节假日，工作日或周末的费率时间段。

      **ADD TARIFFGROUP**
   4. **可选**：配置费率切换模式。

      **SET N40QUOTACTRL**

      **说明** 

      - 当“TCMODE”参数配置为“DEFAULT”时，表示费率切换发生的时间点按照**ADD TARIFFGROUP**命令配置的费率切换生效。
      - 当“TCMODE”参数配置为“DAILY”时，表示在**ADD TARIFFGROUP**命令的费率切换配置基础上，每天00：00再强制进行费率切换，生效范围为所有用户。
      - 当“TCMODE”参数配置为“MONTHLY”时，表示在**ADD TARIFFGROUP**命令的费率切换配置基础上，月初第一天00：00再强制进行费率切换，生效范围为所有用户。
2. 配置全局费率切换组。

   **SET GLBTARIFFGROUP**
3. 为APN实例绑定费率切换组。

   **SET APNCHARGECTRL**
4. 为User Profile实例绑定费率切换组。

   **SET USRPROFCHARGE**

## 任务示例

任务描述

配置整机下的用户费率时间段：

- 节假日：8月1日
- 工作日：星期一，星期二，星期三，星期四，星期五
- 周末：星期六，星期天
- 每天的07:00–23:00是一个费率时段
- 费率切换发生的时间点默认按照**ADD TARIFFGROUP**的费率切换配置生效

脚本

1. 配置费率切换组。

   //配置节假日。

   ```
   ADD FESTIVAL: GLOBALFLG=CHARGE_CHARACT,CCVALUE="0x0800", MONTH=8,DAY=1;
   ```

   //配置星期。

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=MONDAY, TARIFFTYPE=WORKDAY;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=TUESDAY, TARIFFTYPE=WORKDAY;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=WEDNESDAY, TARIFFTYPE=WORKDAY;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=THURSDAY, TARIFFTYPE=WORKDAY;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=FRIDAY, TARIFFTYPE=WORKDAY;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=SATURDAY, TARIFFTYPE=WEEKEND;
   ```

   ```
   ADD WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", DAYOFWEEK=SUNDAY, TARIFFTYPE=WEEKEND;
   ```

   //配置节假日和星期的费率时间段。

   ```
   ADD TARIFFGROUP: TARIFFGRPNAME="tar_nb", GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", TARIFFTYPE=WORKDAY, STARTTIME=07&00, ENDTIME=23&00;
   ```

   ```
   ADD TARIFFGROUP: TARIFFGRPNAME="tar_nb", GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", TARIFFTYPE=WEEKEND, STARTTIME=07&00, ENDTIME=23&00;
   ```

   ```
   ADD TARIFFGROUP: TARIFFGRPNAME="tar_nb", GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x0800", TARIFFTYPE=FESTIVAL, STARTTIME=07&00, ENDTIME=23&00;
   ```

   //配置费率切换模式。

   ```
   SET N40QUOTACTRL: TCMODE=DEFAULT;
   ```
2. 配置全局的费率切换组。

   ```
   SET GLBTARIFFGROUP: GLBTARIFFGRP="tar_nb";
   ```
3. 为APN实例绑定费率切换组。

   ```
   SET APNCHARGECTRL: APN="apn-test", TARIFFGRPNAME="tar_nb";
   ```
4. 为User Profile实例绑定费率切换组。

   ```
   SET USRPROFCHARGE:USRPROFNAME="up-test", TARIFFGRPNAME="tar_nb";
   ```
