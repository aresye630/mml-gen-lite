# 激活网络拥塞的实时检测

- 操作场景
- 必备事项
- 操作步骤
- 任务示例

## 操作场景

当运营商需要了解无线侧网络拥塞情况，配合UPF及NWDAF进行拥塞网络优化时，需要开启本特性。

**说明** 

适用于MME、SGW-C、PGW-C、AMF、SMF。

## 必备事项

前提条件

请仔细阅读WSFD-205013 网络拥塞的实时检测。

数据

| 类别         | 参数名称                  | 取值样例   | 获取方法   | 说明                                                                             |
|:-----------|:----------------------|:-------|:-------|:-------------------------------------------------------------------------------|
| SET SMFUNC | 移动性管理流程ULI上报开关（MMULI） | ON     | 本端规划   | 该参数用于控制UNC在移动性管理流程中发送的Create Session Request/Modify Bearer Request消息是否携带ULI信元。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 开启移动性管理流程ULI上报开关。

   **SET SMFUNC**

## 任务示例

任务描述

运营商需要UNC在移动性管理流程中发送的Create Session Request/Modify Bearer Request消息中携带ULI信元，开启移动性管理流程ULI上报开关。

脚本

//开启移动性管理流程ULI上报开关。

```
SET SMFUNC: MMULI=ON;
```
