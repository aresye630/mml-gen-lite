# 配置N4接口本端信息

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

当前UPF不支持NRF服务发现，需要配置Local NRF。本小节仅配置UPF基本信息，配置后SMF会发起与UPF之间的PFCP偶连建立，但还需要进行配置N4接口对端UPF信息小节相关的UPF业务能力配置，SMF才能够在业务流程中正确发现UPF。

## 必备事项

前提条件

- 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

- 已经获取网设LLD文档。

## 操作步骤

1. 配置N4业务地址对应的逻辑IP地址。

   ```
   ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.26.0.6", VPNINSTNAME="VRF_CP4", DESC="FOR N4 Interface4";
   ADD LOGICIP:IPVERSION=IPv6, LOGICIPV6="fc00:38::2", VPNINSTNAME="VRF_CP6", DESC="FOR N4 Interface6";
   ```
2. 配置N4本端节点和端点。

   ```
   ADD CPNODE:CPNODEINDEX=0, NODEIDTYPE=CpFqdn, NODEIDFQDNVALUE="node.3gppnetwork.org", CPFUNCTION=0;
   ADD CPPOINT:CPPOINTINDEX=0, CPNODEINDEX=0, IPVERSION=IPv4, IPV4="10.26.0.6", VPNNAME="VRF_CP4";
   ADD CPPOINT:CPPOINTINDEX=1, CPNODEINDEX=0, IPVERSION=IPv6, IPV6="fc00:38::2", VPNNAME="VRF_CP6";
   ```
