# 配置高通量UPF（SMF）

- 操作场景
- 必备事项
- 操作步骤

## 操作场景

本操作指导完成高通量UPF选择解决方案中UNC侧的初始业务配置。

## 必备事项

前提条件

- 请仔细阅读高通量UPF特性概述。
- 完成相关接口配置，具体请参考《UNC 产品文档》：初始配置 > UNC初始配置与调测中各接口配置。
- 高通量业务的规则名已全网统一规划。

数据

假设UPF所支持的业务下表所示：

| UPF实例          | 支持业务    | 优先级   |
|:---------------|:--------|:------|
| upf_instance_0 | 智能面&高通量 | 高     |
| upf_instance_1 | 智能面     | 中     |
| upf_instance_2 | 高通量     | 低     |

**说明** 

- SMF上智能面业务相关配置操作，可参考UDC产品文档中《5G Core重点业务保障解决方案》的UNC侧配置进行，本章节仅介绍高通量相关配置。
- 高通量业务的规则名已全网统一规划，在全网所有SMF、高通量UPF、UPCF上统一配置。

配置SMF支持高通量业务（SMF先向UPCF请求策略）

| 类别               | 参数名称                        | 取值样例       | 获取方法   | 说明                                          |
|:-----------------|:----------------------------|:-----------|:-------|:--------------------------------------------|
| ADD APNSMCOMFUNC | APN名称（APN）                  | HUAWEI.COM | 全网规划   | 增加APN粒度的通用会话拓展功能控制，SMF先从UPCF获取会话策略再进行UPF选择。 |
| ADD APNSMCOMFUNC | 在EPS是否先获取策略（GETPOLICYFIRST） | ENABLE     | 本端规划   | 增加APN粒度的通用会话拓展功能控制，SMF先从UPCF获取会话策略再进行UPF选择。 |

## 操作步骤

配置选择支持高通量的UPF（N7接口按pccRules信元下发高通量规则（预定义规则））

1. 进入“MML命令行-UNC”窗口。
2. 配置SMF支持基于用户签约选择高通量UPF。

   ```
   ADD APNSMCOMFUNC: APN="HUAWEI.COM", GETPOLICYFIRST=ENABLE;
   ```
3. 配置业务策略规则。

   ```
   ADD USERPROFILE: USERPROFILENAME=testuserprofilename, UPTYPE=UPSELECT;
   ```
4. 增加UPF选择规则信息。

   ```
   ADD SELECTRULEINFO: RULENAME="testuserprofilename", RULEFUNC=QOSANA-0&QOSEXP-0&QOSCCC-1，DELIVERSW=ENABLE，RULERANGE=CENTRAL;
   ```
5. 配置用户面支持高通量业务。UPF2仅支持高通量、UPF0支持高通量。

   ```
   ADD UPFBINDSELRULE: INDEX=0, NFINSTANCENAME="upf_instance_0", RULENAME="testuserprofilename";
   ADD UPFBINDSELRULE: INDEX=2, NFINSTANCENAME="upf_instance_2", RULENAME="testuserprofilename";
   ```
6. 配置在PFCP Session Establishment Request和PFCP Session Modification Request消息中携带私有信元ActivatedFeatureRule。

   ```
   SET PFCPPVTEXT: FEATURE=Feature_Rule, SWITCH=ENABLE;
   ```

配置选择支持高通量的UPF（N7接口按upfSelectRules信元形式下发高通量规则）

7. 进入“MML命令行-UNC”窗口。
8. 配置SMF支持基于用户签约选择高通UPF。

   ```
   ADD APNSMCOMFUNC: APN="HUAWEI.COM",GETPOLICYFIRST=ENABLE;
   ```
9. 增加UPF选择规则信息。

   ```
   ADD SELECTRULEINFO: RULENAME="select_high_upf", RULEFUNC=QOSANA-0&QOSEXP-0&QOSCCC-1，DELIVERSW=ENABLE，RULERANGE=CENTRAL;
   ```
10. 增加智能规则和UPF的绑定关系。UPF2仅支持高通量、UPF0支持高通量。

    ```
    ADD UPFBINDSELRULE: INDEX=1, NFINSTANCENAME="upf_instance_2", RULENAME="select_high_upf";
    ADD UPFBINDSELRULE: INDEX=2, NFINSTANCENAME="upf_instance_0", RULENAME="select_high_upf";
    ```
11. 配置在PFCP Session Establishment Request和PFCP Session Modification Request消息中携带私有信元ActivatedFeatureRule。

    ```
    SET PFCPPVTEXT: FEATURE=Feature_Rule, SWITCH=ENABLE;
    ```
