# 配置CCR消息中携带的参数

- 操作场景
- 必备事项

## 操作场景

本指导描述UNC上支持配置CCR消息中是否携带某些参数的相关配置操作。

## 必备事项

前提条件

- 请仔细阅读Ga/Gy接口离线/在线计费。
- 完成加载license。
- 已完成计费属性、APN、User Profile创建。
- 已根据配置在线计费模板完成在线计费模板创建和绑定，根据配置在线计费的费率标识完成在线计费费率标识配置。

## 操作步骤

- 为Gy应用配置字典加载路径，并执行加载动作。
  1. 为Gy应用配置字典加载路径。

     **ADD DIAMDICTPATH**

     **MOD DIAMDICTPATH**
  2. 执行字典加载动作。

     **说明** 

     加载Diameter字典可能会导致UNC各Diameter应用对外接口消息发生改变，请在确认UNC对应目录下保存了Diameter字典文件并且对端网元支持字典中定义的消息及信元后再执行此动作。

     **LOD DIAMDICT**
- 配置DCC模板中CCR消息中携带的参数。
  1. 配置CCR消息中是否携带前一个CCA消息中下发的费率切换时间点，配置参数“CCRTARIFFSW”。

     **说明** 

     在线计费中，费率切换时间点只能由OCS下发，UNC上无法配置。此配置是用来控制当UNC检测到发生了费率切换，在后续的CCR消息中上报费率切换信息时，是否连同对应的费率切换点一并上报。

     另外，只有当CCA消息中下发的event-trigger中包含了费率切换，发生费率切换时才会触发CCR上报。
  2. 配置CCR消息中是否携带运营商私有扩展属性开关，配置参数“PRIVATEATTR”。

     **说明** 

     只有在本命令开关使能后，下面配置的运营商私有属性才能生效。
  3. 配置Gy接口按照累加模式上报计费信息，配置参数“QUOTATOTAL”。

     **说明** 

     默认情况下是按照增量方式上报，上述开关打开后按照累加模式上报。
  4. 配置由RAR触发的CCR消息中是否携带全部Rating Group的使用信息，参数为“RARNORGACTION”。
  5. 配置CCR消息中携带一个或多个Multiple-Service-Credit-Control(MSCC) AVP，配置参数“MSCCCARRYTYPE”。
  6. 配置CCR消息中3GPP-PDP-Type AVP的取值方式，参数为“PDPTYPE4NONIP”。

  **ADD DCCTEMPLATE**
- 配置全局DCC模板中CCR消息中携带的参数。
  1. 配置CCR消息中是否携带Requested-Service-Unit (RSU) AVP，配置参数“QHTEXPIREDRSU”。
  2. 配置CCR消息中携带的部分AVP的M标志位是否置为1，配置参数“CCRSPESMFLAG”。

     **说明** 

     涉及的AVP包括：

     3GPP-Charging-Characteristics、3GPP-Charging-Id、3GPP-GGSN-MCC-MNC、3GPP-GPRS-Negotiated-QoS-Profile、3GPP-IMSI-MCC-MNC、3GPP-MS-TimeZone、3GPP-NSAPI、3GPP-PDP-Type、3GPP-RAT-Type、3GPP-Selection-Mode、3GPP-Session-Stop-Indicator、3GPP-SGSN-MCC-MNC、3GPP-User-Location-Info

  **MOD DCCTEMPLATE**

## 任务示例

任务描述

任务一：修改Gy应用第一套字典路径，并执行加载动作。

任务二：修改DCC模板dcc-test中的CCR消息中携带的参数。

脚本

任务一

//修改Gy应用第一套字典路径。

```
MOD DIAMDICTPATH: APPLICATION=GY,DICTNO=1,DICTPATH=CUSTOM1;
```

//执行加载动作。

```
LOD DIAMDICT:DICTFILESELECT=ALL;
```

任务二

//配置DCC template模板。

```
MODD DCCTEMPLATE:DCCTMPLTNAME="dcc-test", CCRTARIFFSW=ENABLE, PRIVATEATTR=ENABLE, QUOTATOTAL=ENABLE, RARNORGACTION=REPORT_ALL_RG, MSCCCARRYTYPE=MULTIPLE, PDPTYPE4NONIP=REALPDPTYPE;
```
