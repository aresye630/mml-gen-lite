## 操作场景

本操作指导介绍在运行网络中激活基于指定区域的策略控制的操作过程。

基于指定区域的策略控制特性是指基于运营商订阅的PRA（Presence Report Area）区域，当用户进入或离开这些区域时，UNC获得用户当前位置信息并向PCRF/PCF上报，PCRF/PCF根据用户位置状态进行策略决策并发起策略更新，执行不同的服务策略（如特殊计费、套餐、信息推送等），满足运营商基于位置信息的差异化和定制化需求，用户通过签约享受相应服务。

**说明** 

适用于SGW-C、PGW-C。

## 必备事项

前提条件

- 请仔细阅读4G网络基于指定区域的策略控制。
- 已完成加载License。

数据

| 类别                   | 参数名称              | 取值样例    | 获取方法   | 说明                      |
|:---------------------|:------------------|:--------|:-------|:------------------------|
| SET SMFFUNC          | 兴趣区（AOI）          | Support | 本端规划   | 配置SGW-C/PGW-C支持兴趣区。     |
| SET SMFSOFTPARAOFBIT | 数据类型（DT）          | Dw      | 全网规划   | 配置SGW-C/PGW-C支持处理PRA信元。 |
| SET SMFSOFTPARAOFBIT | Dword索引（DWORDNUM） | 1001    | 全网规划   | 配置SGW-C/PGW-C支持处理PRA信元。 |
| SET SMFSOFTPARAOFBIT | 软件记录值（VALUE）      | VALUE_1 | 全网规划   | 配置SGW-C/PGW-C支持处理PRA信元。 |
| SET SMFSOFTPARAOFBIT | 比值位（POSITION）     | 9       | 全网规划   | 配置SGW-C/PGW-C支持处理PRA信元。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置基于指定区域的策略控制功能。

   **ADD PCRF**

   **ADD REALMBINDAPN**
3. 配置SGW-C/PGW-C支持兴趣区。

   **SET SMFFUNC**
4. 配置SGW-C/PGW-C支持处理PRA信元，设置软参DWORD1001 BIT9值为1。

   **SET SMFSOFTPARAOFBIT**

## 任务示例

任务描述

校园需要运营商提供基于位置的计费优惠、套餐服务时，会部署基于指定区域的策略控制。根据运营商需求配置SGW-C/PGW-C支持基于指定区域的策略控制。

脚本

**说明** 

ADD PCRF和ADD REALMBINDAPN**二选一****配置**，请根据现网实际情况选择。

- 如果现网是直连PCRF路径，请选择ADD PCRF配置此特性必选参数FEATURELIST=CNO\_ULI-1&RELEASE8-1。
- 如果现网是经DRA的非直连路径，请选择ADD REALMBINDAPN配置此特性必选参数FEATURELIST=CNO\_ULI-1&RELEASE8-1。

//（可选）如果现网是直连PCRF，需要配置FEATURELIST=CNO\_ULI-1&RELEASE8-1，表示支持基于指定区域的策略控制功能。

```
ADD PCRF: HOSTNAME="pcrf1", REALMNAME="www.huawei.com", SUPFEANEGOSW=DISABLE, CARRYSUPFEASW=ENABLE, FEATURELIST=CNO_ULI-1&RELEASE8-1;
```

//（可选）如果现网是经DRA的非直连路径，需要配置FEATURELIST=CNO\_ULI-1&RELEASE8-1，表示支持基于指定区域的策略控制功能。

```
ADD REALMBINDAPN: APN="cmnet", APPLICATION=GX, CONSTBYIMSISW=ENABLE, SUPFTNEGOSW=DISABLE, FEATURELIST=CNO_ULI-1&RELEASE8-1, CARRYSUPFEASW=ENABLE;
```

//配置SGW-C/PGW-C支持兴趣区。

```
SET SMFFUNC: AOI=Support;
```

//配置SGW-C/PGW-C支持处理PRA信元。

```
SET SMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=1001, VALUE=VALUE_1, POSITION=9;
```
