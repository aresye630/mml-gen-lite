# 配置跟踪和日志匿名化功能（通过OM Portal和软件参数）

- 操作场景
- 对系统的影响
- 必备事项
- 操作步骤
- 验证方法

## 操作场景

UNC支持通过OM Portal开启跟踪的匿名化功能，通过软件参数开启日志的匿名化功能。

为保证个人隐私数据的安全性，建议开启该功能。请运营商遵从所在国家的相关法律开启该功能。

## 对系统的影响

用户标识在UNC设备上做加密处理。

## 必备事项

前提条件

请仔细阅读个人隐私数据保护。

数据

无。

## 操作步骤

- 通过OM Portal打开跟踪的匿名化功能：通过OM Portal下载跟踪文件时，在弹出的“下载”界面中勾选“匿名化”。

  - 当UNC未连接U2020/MAE之前，根据OM Portal跟踪“下载”界面的“匿名化”选项状态判断是否做匿名化处理。
  - 当UNC连接U2020/MAE之后，同步保存U2020/MAE上配置的假名化/匿名化功能状态及HMAC密钥信息：
    - 如果U2020/MAE上配置匿名化功能为开启，则强制做匿名化处理；
    - 如果U2020/MAE上配置匿名化功能为关闭，则根据OM Portal跟踪“下载”界面的“匿名化”选项状态判断是否做匿名化处理。
- 通过软件参数打开日志的匿名化功能。

  通过MML命令**SET COMMONSOFTPARAOFBIT**设置软件参数DWORD1 BIT1为0。

  通过MML命令**SET FWSOFTPARABITS**设置软件参数DWORD1601 BIT1为0。

  ```
  SET COMMONSOFTPARAOFBIT: DT=DwCom, DWORDCOMNUM=1, VALUE=0, POSITION=1;
  ```

  ```
  SET FWSOFTPARABITS: PARATYPE=DWORD, DWORDNUM=1601, VALUE=VALUE_0, POSITION=1;
  ```

## 验证方法

如果用户标识假名化和匿名化功能已开启，则UNC保存的跟踪消息、CHR、日志中不再含有原始的用户标识信息。

如果用户标识假名化和匿名化功能未生效，则UNC保存的跟踪消息、CHR、日志中的用户标识仍是明文。
