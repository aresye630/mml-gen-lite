## 操作场景

用户访问园区业务时，智能分流SMF发起园区专网会话创建，数据流被分流到专网UPF上，需要在专网SMF和专网UPF上针对园区业务配置内容计费规则。

场景一：运营商对于园区业务未规划单独费率，则使用缺省费率（RG= 2000000002）。

场景二：运营商对于园区业务的费率有单独规划，按照运营商规划配置对应的费率。

**说明** 

此配置页面内容计费中的URR、PCCPOLICYGRPNM（PCC策略组名称）、RULENAME（规则名称）、USERPROFILENAME（用户模板名称）等需要与专网UPF和PCF中的名称保持一致。

UPF的相关配置参见配置内容计费，PCF的相关配置参见配置专用DNN策略数据。

## 对系统的影响

无。

1. 配置园区业务对应的URR。以下脚本假设园区费率为2000000003为例进行配置。

   ```
   ADD URR:URRNAME="multi_01_cbb_online", URRID=2000000003, USAGERPTMODE=ONLINE, ONLCOMPOUNDTYPE=ONLYRG, ONLINERG=2000000003, ONLMETERINGTYPE=VOLUME;
   ADD URR:URRNAME="multi_01_cbb_offline", URRID=2000010003, USAGERPTMODE=OFFLINE, OFFCOMPOUNDTYPE=ONLYRG, RG=2000000003, OFFMETERINGTYPE=VOLUME;
   ```
2. 配置园区计费规则/用户模板。
   - 场景一：当PCF下发园区业务内容计费对应的规则时，请执行以下脚本：
     1. 配置园区业务流量对应URR Group。

        ```
        ADD URRGROUP:URRGROUPNAME="multi_01_ch_p", UPURRNAME1="multi_01_cbb_online", UPURRNAME2="multi_01_cbb_offline", DOWNURRNAME1="multi_01_cbb_online",DOWNURRNAME2="multi_01_cbb_offline";
        ```
     2. 配置园区业务内容计费规则对应的PCC策略组名并和URR Group绑定。

        ```
        ADD PCCPOLICYGRP:PCCPOLICYGRPNM="multi_01_pcc_p_g", URRGROUPNAME="multi_01_ch_p";
        ```
     3. 配置园区业务内容计费对应的Rule。SMF、UPF上RULENAME以及RULE下配置的POLICYTYPE、POLICYNAME需要保持一致。

        ```
        ADD RULE:RULENAME="multi_01_r", POLICYTYPE=PCC, PRIORITY=60000, POLICYNAME="multi_01_pcc_p_g";
        ADD RULE:RULENAME="multi_01_ipv6_r", POLICYTYPE=PCC, PRIORITY=60010, POLICYNAME="multi_01_pcc_p_g";
        ```
   - 场景二：当PCF下发园区业务内容计费对应的用户模板时，添加园区业务内容计费对应的UserProfile。USERPROFILE的名称统一规划，保证在PCF、SMF、UPF间名称一致。不一致时PCF下发的策略无法生效。

     ```
     ADD USERPROFILE:USERPROFILENAME="u_p_01_multi", UPTYPE=PCC
     ```

   **说明** 

   当PCF同时下发园区业务内容计费对应的规则及用户模板时，以上脚本均需要执行。
3. （条件必选）当同时配置了步骤2中的场景一和场景二时，需要执行此步骤。配置园区业务使用的Rule和园区业务的UserProfile绑定关系。如果配置需要和UPF上配置的UserProfile的名称保持一致。

   ```
   ADD RULEBINDING:USERPROFILENAME="u_p_01_multi", RULENAME="multi_01_r";
   ADD RULEBINDING:USERPROFILENAME="u_p_01_multi", RULENAME="multi_01_ipv6_r";
   ```
