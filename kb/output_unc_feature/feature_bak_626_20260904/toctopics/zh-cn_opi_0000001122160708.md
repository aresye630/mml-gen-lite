## 操作场景

根据整体方案设计，UPF侧需配置两个预定义规则：

- 规则名“Predefined1”：关键参数为5QI=5，ARP=2，MFBR=100Mbit/s及流描述。
- 规则名“Predefined2”：关键参数为5QI=5，ARP=2，MFBR=1Mbit/s及流描述。

## 必备事项

前提条件

- 请仔细阅读UDG特性之《GWFD-020351 PCC基本功能》。
- 完成加载License（如果有需求，请联系华为技术支持工程师）。
- 已通过学习SM策略E2E实现原理、业务配置方法及E2E业务调测了解了SM策略的配置原理及方法。

## 操作流程

此特性的配置流程图如图1所示。

**图1** UPF（UDG）侧业务配置流程图

其中具体可以分为以下三个流程，对应的操作步骤如下：

- 配置流过滤器的流程见1-3。
- 配置PCC策略的流程见4-6。
- 绑定流过滤器和PCC策略至Rule的流程见7。

## 操作步骤

1. 登录UDG CSP OM Portal，进入“MML命令行-UDG”窗口。
2. 配置过滤器。

   //用户从国内接入网络时，即PCF下发预定义规则“Predefined1”场景。

   ```
   ADD FILTER: FILTERNAME="f_fup_service_100M", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
   ```

   //用户从国外（漫游区）的位置区域接入网络时，即PCF下发预定义规则“Predefined2”场景。

   ```
   ADD FILTER: FILTERNAME="f_fup_service_1M", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
   ```
3. 添加流过滤器并绑定过滤器。

   //用户从国内接入网络时，即PCF下发预定义规则“Predefined1”场景。

   ```
   ADD FLOWFILTER: FLOWFILTERNAME="flowfliter_service_100M";
   ADD FLTBINDFLOWF: FLOWFILTERNAME="flowfliter_service_100M", FILTERNAME="f_fup_service_100M";
   ```

   //用户从国外（漫游区）的位置区域接入网络时，即PCF下发预定义规则“Predefined2”场景。

   ```
   ADD FLOWFILTER: FLOWFILTERNAME="flowfliter_service_1M";
   ADD FLTBINDFLOWF: FLOWFILTERNAME="flowfliter_service_1M", FILTERNAME="f_fup_service_1M";
   ```
4. 配置使用量上报属性。

   此处的配置须与SMF侧配置保持严格一致。

   ```
   //配置QoS URR
   ADD URR:URRNAME="urr_QoS2", URRID=2, USAGERPTMODE=QOS;
   ADD URR:URRNAME="urr_QoS3", URRID=3, USAGERPTMODE=QOS;
   ```
5. 配置QoS参数。

   该步骤为预定义规则（组）场景下的可选配置。只有在需要对用户进行带宽控制或建立专有QoS Flow时，才需配置。须配置配额耗尽前、耗尽后两种场景的带宽控制策略。

   //用户从国内接入网络时，即PCF下发预定义规则predefined1场景，此处5QI/ARP取值参考SMF（UNC）侧业务设计规划分别取5和2。

   ```
   ADD QOSPROP: QOSPROPNAME="qosprop_5qi5_arp2_100", MBRUPLKVALUE=100000, MBRDNLKVALUE=100000, QOSURRNAME="urr_QoS2", DECOUPLINGSW=DISABLE, KEYFLOWDETECTSW=DISABLE;
   ```

   //用户从国外（漫游区）的地方接入网络时，即PCF下发预定义规则predefined2场景，此处5QI/ARP取值参考SMF（UNC）侧业务设计规划分别取5和2。

   ```
   ADD QOSPROP: QOSPROPNAME="qosprop_5qi5_arp2_1", MBRUPLKVALUE=1000, MBRDNLKVALUE=1000, QOSURRNAME="urr_QoS3", DECOUPLINGSW=DISABLE, KEYFLOWDETECTSW=DISABLE;
   ```
6. 配置PCC策略组。

   该步骤为预定义规则（组）场景下的必选配置。配置PCC策略组的目的是用于关联QoS URR策略。此处“URRGROUPNAME”参数使用ADD URRGROUP定义的“URRGROUPNAME”。

   //用户从国内接入网络时，即PCF下发预定义规则predefined1场景。

   ```
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccfuppolicy_100M", FUPSESSIONEXC=DISABLE, TOKENFUNCFLAG=DISABLE, SIGNALASSOCIATE=ENABLE, ADCMUTEFLAG=ENABLE, QOSPROPNAME="qosprop_5qi5_arp2_100", HTTP2DEGRADESW=INHERIT, EVENTCHARGEFLAG=DISABLE, EVENTCHGPOINT=RESPONSE, MMSCHARGETYPE=SINGLE;
   ```

   //用户从国外（漫游区）的地方接入网络时，即PCF下发预定义规则predefined2场景。

   ```
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccfuppolicy_1M", FUPSESSIONEXC=DISABLE, TOKENFUNCFLAG=DISABLE, SIGNALASSOCIATE=ENABLE, ADCMUTEFLAG=ENABLE, QOSPROPNAME="qosprop_5qi5_arp2_1", HTTP2DEGRADESW=INHERIT, EVENTCHARGEFLAG=DISABLE, EVENTCHGPOINT=RESPONSE, MMSCHARGETYPE=SINGLE;
   ```
7. 配置预定义规则。

   该步骤为预定义规则（组）场景下的必选配置。主要用于关联PCC策略组。此处预定义规则名称、数量都须与PCF侧定义的保持一致。

   ```
   ADD RULE:RULENAME="Predefined1",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfliter_service_100M",PRIORITY=10,POLICYNAME="pccfuppolicy_100M";
   ADD RULE:RULENAME="Predefined2",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfliter_service_1M",PRIORITY=50,POLICYNAME="pccfuppolicy_1M";
   ```
8. 将新配置的Filter置为生效。

   ```
   SET REFRESHSRV:REFRESHTYPE=ALL;
   ```
