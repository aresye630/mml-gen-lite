# 配置动态路由OSPFv3+BFD组网（IPv6）

## 操作场景

VNF与对端设备可通过OSPF动态路由绑定IPv6动态BFD探测的方式进行组网连接，该方式适用于IPv6组网的网络中。

在网络拓扑结构复杂、设备与IP路由繁多的网络部署时，通常使用OSPF动态路由方式发布路由。同时，利用BFD双向转发检测机制为链路提供双向、轻负荷且持续时间短的快速检测功能，提高链路可靠性。

如图1所示为VNF与周边网元的OSPF动态路由互通组网示意图。VNF与网关侧运行动态路由协议而接入运营商网络（IP骨干网），网关推荐使用运营商的PE（Provider Edge）交换机，也可以使用DC-GW，或者EOR（End of Row）交换机。无论哪种方式，VNF的配置相同，没有差异。PE的路由配置请参考运营商的网络规划配置，DC-GW/EOR的配置请参考对应型号设备的产品文档。

## 必备事项

前提条件

* 请阅读并熟悉特性IPFD-014001 支持OSPF特性概述和IPFD-012003 BFD特性概述。
* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* VNF与网络实体之间的网络环境已经构建完成。

数据

VNF使用OSPFv3动态路由绑定动态BFD检测功能与对端设备建立可靠的IP连接。

* 在VNF上配置OSPFv3动态路由与对端建立链路。
* 在VNF上配置动态IPv6 BFD功能增强链路检测可靠性。
* 在VNF上推荐采用子接口的外联口与外部网络对接。

本文以一组外联口子接口为例进行说明，一组外联口（对应一个逻辑接口）分别在每个CSLB各规划2个子接口负荷分担承载流量，后续扩容CSLB后自动在每个CSLB上扩展2个子接口承载流量。实际场景可根据网设规划进行适配。

## 操作步骤

1. 配置外联口的VPN实例。

   ```
   ADD L3VPNINST:VRFNAME="VPN_Access";
   ADD VPNINSTAF:VRFNAME="VPN_Access",AFTYPE=ipv6uni;
   ```

   一条通信路径上所有节点绑定的VPN实例要一致，才能正常通信，例如VNF逻辑接口、VNF外联口、网关上的VPN，否则从逻辑接口发出去的报文会查询路由失败。
2. 全局激活BFD。

   ```
   SET BFD: BFDENABLE=TRUE;
   ```
3. 配置OSPF路由。

   1. 创建OSPFv3进程。

      ```
      ADD OSPFV3:PROCID=6,VRFNAME="VPN_Access",ROUTERID="10.8.25.1",BFDALLINTFFLG=TRUE, BFDRXCFGFLAG=TRUE, BFDMINRXINTV=500, BFDTXCFGFLAG=TRUE, BFDMINTXINTV=500, DETECTMULINTV=4, VPNINSCAPSIMFLG=TRUE,VIRTUALSYSFLAG=TRUE;
      ```

      * 当在MCE（Multi-VPN-Instance CE）路由器上支持VPN多实例时，需要取消环路检查（参数“VPNINSCAPSIMFLG”配置为“TRUE”），否则会导致OSPF路由引入失败。
      * 路由器标识Router ID（“SCHEMAROUID”）的选择策略：优选用户配置的Router ID，如果未配置，则选择OSPFv3进程所在VRF内或者公网内的最大接口IP地址。
      * 如果需要为OSPFv3动态路由绑定BFD会话，则配置参数“BFDALLINTFFLG（使能BFD）”为“TRUE”。
      * 当OSPFv3路由配置共网段时，需要将参数“VIRTUALSYSFLAG（OSPFv3共网段虚拟系统使能标志）”配置为“TRUE”。
   2. 增加OSPFv3区域。

      ```
      ADD OSPFV3AREA:PROCID=6,AREAID="0.0.0.5", AREATYPE=NSSA, NSSADEFAULTROUTEADVERTISE=FALSE;
      ```

      参数“AREATYPE（OSPFv3区域类型）”配置为“NSSA”或“Normal”时，都不需要配置Loopback地址。
   3. 设置OSPFv3引入路由类型。

      ```
      ADD OSPFV3IMPORTROUTE:PROCID=6,TOPOID=0,PROTOCOL=wlr,IMPTCOSTCFG=FALSE,IMPTTAGCFG=FALSE,IMPTTYPECFG=FALSE;
      ```
4. 关闭自动配置开关。

   1. 查询自动配置开关。

      ```
      LST AUTOCONFIG:;
      ```

      如果自动配置开关值为“TRUE”，需要执行如下步骤关闭自动配置开关。
   2. 查询自动部署维护助手“autoscaling\_autoconfig.py”的状态，确保状态为“准备好状态（Ready）”或者查询无该脚本，以保证当前设备不在自动部署过程中。因为若系统当前有正在进行的自动部署，而自动部署生效有时延，此时若关闭自动配置开关，会影响系统配置效果。

      ```
      DSP OPSASSISTSTATE:;
      ```
   3. 关闭自动配置开关。自动化配置命令只有在自动配置开关为关闭的状态下才可执行，因此需要提前关闭。

      ```
      SET AUTOCONFIG:SWITCHFLAG=FALSE;
      ```
5. 配置外联口自动部署模板。

   ```
   ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_100",VPNNAME="VPN_Access",AFTYPE=IPv6, IPALLOCTYPE6=USER_CONFIG,VNICID=4,VLANID=100, BEGINADDR6="FC00::10C2", ENDADDR6="FC00::10DE", MASKLEN=123, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="0.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
   ```

   ```
   ADD AUTOSCALINGSERVICE:SERVICENAME="ServName_Access_200",VPNNAME="VPN_Access",AFTYPE=IPv6, IPALLOCTYPE6=USER_CONFIG,VNICID=5,VLANID=200, BEGINADDR6="FC00::10E2", ENDADDR6="FC00::10FE", MASKLEN=123, OSPFENABLE=TRUE, OSPFPROCID=6, OSPFAREAID="0.0.0.5", TPINENABLE=FALSE, TPOUTENABLE=FALSE;
   ```

   * 如果规划外联口使用IPv4v6双栈地址，则分别执行该命令对同一vNIC配置IPv4和IPv6地址。
   * 参数“虚拟网卡ID（VNICID）”使用的是cslbip-pod.yaml中定义的网卡ID。EVS/OVS等非SR-IOV场景中，默认情况下，“虚拟网卡ID（VNICID）”取值=I层网络的vNIC号+2。
6. 打开自动配置开关。

   从自动部署开关打开到自动部署功能生效有时延，因此执行其他操作前（例如手动部署路由互通、关闭自动部署开关），务必先执行****DSP OPSASSISTSTATE****命令查询自动部署维护助手“autoscaling\_autoconfig.py”的状态为“准备好状态（Ready）”，否则结果不可预期。

   ```
   SET AUTOCONFIG: SWITCHFLAG=TRUE;
   ```

## 验证方法

1. 查看各网元间的路由连接是否正常。

   执行**PING**命令，查看VNF与对端设备间的路由连接是否正常。

   ```
   PING:IPVERSION=IPv6,VPNNAME="VPN_Access",DESTIPV6ADDRESS="对端网关地址";
   ```

   如果使用了VPN组网，还需使用“VPN实例名称（VPNNAME）”指定VPN实例，这样才能验证VPN实例路由是否正常。

   * 如果收到对端网元的响应且响应报文中有成功收发包的个数，表明连接正常，调测结束。
   * 如果连续出现timeout，表明链路不通，请检查本端或承载网是否存在物理接口故障或者路由配置错误，请执行2。
2. 查看接口状态及信息是否与规划数据一致。

   **LST INTERFACE**:;

   * 如果一致，请执行4。
   * 如果不一致，请执行3，再次执行1。
3. 修改外联口自动部署模板。
   1. 关闭自动化配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=FALSE;
      ```
   2. 查询需要修改的外联口自动部署模板并记录服务名称、起始地址和结束地址等参数。

      ```
      LST AUTOSCALINGSERVICE:;
      ```
   3. 查询需要修改的子接口并记录查询结果。记录哪些接口的IP地址在3.b中记录的起始地址和结束地址范围内。

      ```
      LST IFIPV6ADDRESS:;
      ```
   4. 删除3.c中记录的所有子接口。

      **RMV INTERFACE**
   5. 修改外联口自动部署模板。仅填写必选参数和待修改的参数，其他参数不用填写。

      **MOD AUTOSCALINGSERVICE**

      如参数不支持修改，请先删除自动部署模板，然后重新配置自动部署模板。
   6. 打开自动化配置开关。

      ```
      SET AUTOCONFIG: SWITCHFLAG=TRUE;
      ```
4. 检查BFD会话状态是否为up。

   **DSP BFDSESSION**:;

   * 如果状态为up，请执行5。
   * 如果为其他状态，请参考“操作步骤”重新配置。
5. 调测OSPFv3动态路由。

   1. 检查生成的OSPFv3路由是否与规划数据一致。

      ****DSP OSPFV3ROUTING****:;
      * 如果一致，请执行5.b。
      * 如果不一致，请参考“操作步骤”重新配置，再次执行1。
   2. 检查接口是否已添加到OSPFv3区域中。

      ****DSP OSPFV3INTERFACE****: PROCID=OSPFv3进程号;
      * 如果是，请执行5.c。
      * 如果否，请参考“操作步骤”重新配置，再次执行1。
   3. 检查OSPFV3邻居状态是否正常。

      邻居应包括邻居设备的ROUTER ID、接口的IP地址以及邻居的状态。

      ****DSP OSPFV3PEER****: PROCID=OSPFv3进程号;
      * 如果是，请执行6。
      * 如果否，请参考“操作步骤”重新配置，再次执行1。
6. 收集信息并寻求技术支持。

   1. 执行**EXP MML**命令将当前配置数据导出为MML脚本文件并保存。
   2. 收集并保存上述所有查询信息。
   3. 查看并收集对端设备配置及接口状态信息。
   4. 收集归纳所有信息并联系华为技术支持解决。
