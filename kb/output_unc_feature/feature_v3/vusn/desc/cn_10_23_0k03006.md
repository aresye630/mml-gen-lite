## 操作场景

本操作指导描述核心网组Pool配置过程。

## 操作步骤

1. 配置MME的域名解析。

   为了保证其他MME能通过GUTI找到对应的MME，需要增加该MME的域名解析。

   配置MME的域名解析有两种方式：
   * 方式一：DNS配置方式。
   * 方式二：Hostfile配置方式。

   本例中，对于域名“MMEC8.MMEGI8001.MME.EPC.MNC003.MCC123.3GPPNETWORK.ORG”，将在DNS上配置成为MME1的GTPC地址。
2. **可选：**在使用UNC作为融合节点同时支持SGSN Pool功能和MME Pool功能的场景下，如果MME需要通过S1接口下发LTE GUMMEI和Mapped GUMMEI，需要进行如下操作。

   * 没有规划TA和LA对应关系。

     **ADD POOLLA**: LAC="1011";

     **ADD POOLLA**: LAC="1012";

     **ADD POOLLA**: LAC="6001";
   * 规划了TA和LA的对应关系。

     **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="1011";

     **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="1012";

     **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="6001";

     **ADD POOLLA**: BGNTAI="123033201", ENDTAI="123033205", LAC="1012";

     **ADD POOLLA**: BGNTAI="123033201", ENDTAI="123033205", LAC="6001";
3. 重复步骤 1和步骤 2，配置其他MME的Pool参数，本例中需要配置MME2、MME3的数据。

   **表1** Pool参数配置阶段Checklist

   | 数据配置的一致性检查 | 要求结果 |
   | --- | --- |
   | MMEID | 一致 |
   | License开关 | 打开 |
   | 权重信息 | 一致 |
   | DNS Service MMEID域名解析 | 和规划一致 |
   | POOLLA | 和规划一致 |
   | 建立待割接的第一个eNodeB的所有TAI的性能测量任务（包括Attach，TAU，Service Request，Paging，Relocation基本流程） | 已经建立 |
