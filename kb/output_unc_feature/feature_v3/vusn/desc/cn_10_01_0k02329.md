# Pool功能预设置

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

新建SGSN Pool时对本Pool的功能和参数按前期规划好的数据进行配置。

## 必备事项

前提条件

* 已经申请并加载具有SGSN Iu-flex功能的License和具有用户迁移功能的License。
* SGSN网元已经接入到U2020/MAE的操作维护系统，操作人员已经登录U2020/MAE服务器。
* 网元基础数据配置完成。

数据

该操作无需准备数据。

## 操作步骤

1. 在所有SGSN上打开Iu-flex和Gb-Flex开关。

   **SET LICENSESWITCH**: LICITEM="LKV2IUFLEX02", SWITCH=ENABLE;

   **SET LICENSESWITCH**: LICITEM="LKV2GBFLEX02", SWITCH=ENABLE;

   **SET LICENSESWITCH**: LICITEM="LKV2SGSNMG02", SWITCH=ENABLE;

   其中，LKV2IUFLEX02为Iu-flex特性的部件编码，LKV2GBFLEX02为Gb-flex特性的部件编码，LKV2SGSNMG02为SGSN Pool用户迁移特性的部件编码。

## 任务示例

任务描述

根据全网新建的组网，对Pool功能进行预设置。

脚本

//在SGSN上打开Iu-flex/Gb-flex开关、用户迁移开关。

```
SET LICENSESWITCH: LICITEM="LKV2IUFLEX02", SWITCH=ENABLE;
SET LICENSESWITCH: LICITEM="LKV2GBFLEX02", SWITCH=ENABLE; 
SET LICENSESWITCH: LICITEM="LKV2SGSNMG02", SWITCH=ENABLE;
```
