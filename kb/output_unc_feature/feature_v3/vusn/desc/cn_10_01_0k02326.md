# 核心网侧组Pool过程

## 操作场景

本操作指导描述核心网组Pool配置过程。

## 必备事项

前提条件

Pool功能预设置已经配置完成。

数据

请参见“数据规划”。

## 操作步骤

* 配置新建的SGSN1的Pool参数。
  1. 设置SGSN1的Pool ID和NRI长度。

     **ADD POOL**: POOLID=0, NRILENGTH=5;

     目前NRI长度等于7bit仅在中国部署。在海外部署时，NRI长度采用5bit。
  2. 配置SGSN1的本局NRI，SGSN1在P-TMSI分配时将使用此处设定的NRI值。

     **ADD LOCALNRI**: POOLID=0, NRIVBGN=1, NRINUM=1;
  3. 配置SGSN1的全球CN标识（Global CN ID）。

     配置SGSN的全球CN标识（Global CN ID），使用Iu-flex功能时，SGSN给RAN发送的某些消息中需要带有Global CN ID，RAN侧会在SGSN主动触发的流程比如Reset流程、Relocation Request流程中，使用Global CN ID标识SGSN。

     **SET SYS**: MCC="123", MNC="00", CNID=1;

     假设SGSN移动国家代码为123，移动网号为00。
  4. 设置Pool区内其它SGSN的NRI信息。一般情况下，建议在DNS Server中配置，如果运营商采用POOLNRI配置，则命令如下：

     //设置SGSN2的NRI信息

     **ADD POOLNRI**: POOLID=0, NRIV=2, IPTYPE=IPV4, IPV4="10.2.155.2", SGSNN="SGSN2";

     //设置SGSN3的NRI信息

     **ADD POOLNRI**: POOLID=0, NRIV=3, IPTYPE=IPV4, IPV4="10.2.151.3", SGSNN="SGSN3";

     该Pool区内其它SGSN的NRI信息，主要是在Inter RAU流程时，根据NRI与IP地址的对应关系获取对端SGSN的地址信息。一个NRI对应一个SGSN，是一一对应的。

     如果对端SGSN存在多个GTPC地址时，通过**ADD POOLNRI**命令配置其中一个即可。为了实现对端SGSN不同GTPC IP之间的负载均衡，可通过本命令配置对端SGSN不同的GTPC IP。
  5. 设置Pool区内其它SGSN的非广播路由区信息。一般情况下，建议在DNS Server中配置，如果运营商采用NONRAI配置，则命令如下：

     //设置SGSN2的非广播路由区信息

     **ADD NONRAI**: NONRAI="12300615555", IPTYPE=IPV4, IPV4="10.2.155.2", SGSNN="SGSN2";

     //设置SGSN3的非广播路由区信息

     **ADD NONRAI**: NONRAI="12300616666", IPTYPE=IPV4, IPV4="10.2.151.3", SGSNN="SGSN3";

     该Pool区内其它SGSN的非广播路由区信息，主要是在Inter RAU流程时，根据非广播路由区与IP地址的对应关系获取对端SGSN的地址信息。一个非广播路由区对应一个SGSN，是一一对应的。

     如果对端SGSN存在多个GTPC地址时，通过**ADD NONRAI**命令配置其中一个即可。为了实现对端SGSN不同GTPC IP之间的负载均衡，可通过本命令配置对端SGSN不同的GTPC IP。
  6. 复位SGSN1，使得Pool相关参数的设置生效。

     **RST NODEBATCH**:APPID=0;
  7. 在SGSN1上打开需要加入Pool的RNC/BSC的Flex开关。

     Iu-Flex：**MOD RNC**: RNCX=0, IU\_FLEX=YES;

     Gb-Flex：
     + Gb接口静态配置：**MOD NSE**: NSEI=0, GB\_FLEX=YES;
     + Gb接口动态自动配置：**MOD GBNSECFGPARA**: PARAINDEX=1, GB\_FLEX=YES;
  8. 配置本局迁移参数信息。

     //设置本SGSN的迁移参数信息

     **SET OFFLOADINF**: OFFLOADTMR=4, FIRSTTM=54, NONRAI="12300614444", POOLID=0, NULLNRIV=10;

     迁移参数信息只在进行迁移流程才使用，该脚本含义为设置SGSN容量为100K，迁移模式周期路由区更新定时器时长为4s，第一阶段迁移时间为54min，非广播路由区为：12300614444，所迁移用户Pool区标识为0，NULL NRI值为10。
  9. **可选：**在使用UNC作为融合节点同时支持SGSN POOL功能和MME POOL功能的场景下，如果MME需要通过S1接口下发LTE GUMMEI和Mapped GUMMEI，需要进行如下操作。

     + 没有规划TA和LA对应关系

       **ADD POOLLA**: LAC="0001";

       **ADD POOLLA**: LAC="0002";

       **ADD POOLLA**: LAC="0003";
     + 规划了TA和LA的对应关系

       **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="0001";

       **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="0002";

       **ADD POOLLA**: BGNTAI="123033101", ENDTAI="123033105", LAC="0003";

       **ADD POOLLA**: BGNTAI="123033201", ENDTAI="123033205", LAC="0002";

       **ADD POOLLA**: BGNTAI="123033301", ENDTAI="123033305", LAC="0003";
* 配置SGSN2、SGSN3数据

  与配置SGSN1数据步骤和过程类似，请参见配置新建的SGSN1的Pool参数。
* 数据配置完成后，需要进行数据配置一致性检查、Flex功能检查、核心网配置检查，具体检查项如表1所示。

  **表1** 数据配置检查Checklist

  | 数据配置检查项 | 要求结果 |
  | --- | --- |
  | Pool ID | 一致 |
  | NRI长度 | 一致 |
  | Local NRI | 不重复，与规划数据一致。 |
  | CN ID | 不一致 |
  | Pool NRI | 所有SGSN均配置了Pool内其他SGSN的NRI和IP地址的对应关系，且IP地址配置一致。 |
  | 建立待割接的第一个RNC的所有RAI的性能测量任务 | 已经建立 |
  | LICENSESWITCH配置 | Iu-flex/Gb-flex开启 |
  | 鉴权开关（Inter RAU 、PDP激活鉴权、Attach、签名不匹配、无签名等） | 打开 |
  | POOLLA | 与规划一致 |
  | RNC/BSC | Flex开关已打开 |
  | Iu Paging | 查询结果中包含割接RNC的RAI信息。 |
