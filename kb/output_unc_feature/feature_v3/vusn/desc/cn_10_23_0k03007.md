# 接入网侧组Pool过程

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本配置指导描述新建MME Pool时接入网侧组Pool的配置过程。

## 必备事项

前提条件

* 数据规划已完成。
* 网元基础数据配置完成。
* Pool功能预设置完成。

数据

无需准备数据。

## 操作步骤

1. 按照之前准备的脚本，配置新增连接的eNodeB1与MME1之间的链路数据，调通S1链路。
2. 配置MME1数据。

   将一个eNodeB1加入到MME1。具体操作过程参考《UNC初始配置与调测》中“到MME的数据配置”。
3. 配置eNodeB1到MME1的相关信令和链路数据。

   * 在eNodeB1上检查MME1的MMEID和权重是否正确。
   * 在MME1上配置eNodeB1相关的TALIST。

     ```
     ADD TALST: TALISTID=0, TAI="123033101";
     ADD TALST: TALISTID=0, TAI="123033102";
     ADD TALST: TALISTID=0, TAI="123033103";
     ADD TALST: TALISTID=0, TAI="123033104";
     ADD TALST: TALISTID=0, TAI="123033105";
     ```
   * 在MME1上检查4G的PAGING表是否上报。

     ```
     LST S1PAGING: TAI="123033101", SERVICETYPE="USN_VNFC";
     LST S1PAGING: TAI="123033102", SERVICETYPE="USN_VNFC";
     LST S1PAGING: TAI="123033103", SERVICETYPE="USN_VNFC";
     LST S1PAGING: TAI="123033104", SERVICETYPE="USN_VNFC";
     LST S1PAGING: TAI="123033105", SERVICETYPE="USN_VNFC";
     ```

     4G的PAGING表是自动上报的，链路配置完成之后，使用命令检查LST S1PAGING，查询TA上报是否符合规划。
4. 配置eNodeB1到其他MME（MME2，MME3）的相关信令和链路数据。
5. **可选：**如果TA（eNodeB1）对应的S-GW的域名解析使用DNS Server配置，可以跳过此步。如果TA对应S-GW的域名解析使用的是MME（MME1，MME2，MME3）上的hostfile，需要在MME（MME1，MME2，MME3）对应S-GW的域名解析。

   * 增加IPV4DNSH解析。

     **ADD IPV4DNSH**: HSINDEX=20, HOSTNAME="TOPON.SGW.SGW1.NODES.EPC.ENVID50.MNC03.MCC123.3GPPNETWORK.ORG", ADDRSECTION=SECTION1, IPV4ADDR1="10.168.163.1";
   * 增加DNSN解析。

     **ADD DNSN**: FQDN="TAC-LB04.TAC-HB31.TAC.EPC.MNC003.MCC123.3GPPNETWORK.ORG", HSINDEX=20, ENTITY=SGW, INTYPE=S11;
6. 配置Pool内TA区对应Pool内MME的域名解析。

   为了保证从Pool外MME到Pool内MME的切换分摊均匀，需要在DNS Server或Hostfile上针对所有Pool内TA区增加Pool内MME（MME1，MME2，MME3）的IP。

   配置MME的域名解析有两种方式：
   * 方式一：DNS配置方式。
   * 方式二：Hostfile配置方式。

   对于Hostfile配置方式，需要在Pool区外周边TA区对应的MME上配置。

   本例中，对于域名“TAC-LB04.TAC-HB31.TAC.EPC.MNC003.MCC123.3GPPNETWORK.ORG”，将在DNS上将eNodeB1的路由区域名解析成为扩展MME1、MME2和MME3的GTPC地址。并通知与该eNodeB1覆盖范围相邻的非本MME Pool的其他MME做相应的数据修改。

   通常地，本网内有一个本地DNS Server，上一级DNS Server不在本地。这种情况下，当核心网内多个MME改造成Pool后，该DNS Server可以视作Pool外的DNS Server，也可以视作Pool内的DNS Server，它除了保留原有的域名解析数据、解析功能外，还需要为MME Pool增加TA对应的IP地址配置。

   以华为为例：

   * 方式一：在华为DNS Server的LMT上配置，主备均需要：

     **ADD RESREC**: TYPE=A, NAME="MNC0000.MCC0123.gprs", DOMAIN="TAC-LB04.TAC-HB31.TAC.EPC", IP="10.168.155.2";

     **ADD RESREC**: TYPE=A, NAME="MNC0000.MCC0123.gprs", DOMAIN="TAC-LB04.TAC-HB31.TAC.EPC", IP="10.168.151.1";
   * 方式二：在不带LMT的DNS Server上，在named.ra文件中增加A记录（详细参见《DNS产品文档》）：

     TAC-LB04.TAC-HB31.TAC.EPC IN A 10.166.155.2

     TAC-LB04.TAC-HB31.TAC.EPC IN A 10.166.155.2

   * 如果本网的运营商除了本地DNS Server外，还有上一级的DNS Server也在本地，在改造成MME Pool后，Pool内有一个DNS Server A，Pool外还有一个上级的DNS Server B，则，TA对应IP地址的数据配置就需要在DNS Server B上完成。这种情况比较少见。
   * 如果修改了DNS Server的数据，需要清除各MME的cash数据。
7. 重复步骤 1~步骤 6，完成其他eNodeB（eNodeB2，eNodeB3）的配置。
