## 操作场景

新建MME Pool时对本Pool的功能和参数按前期规划好的数据进行配置。

## 必备事项

前提条件

* MME网元已经接入到U2020/MAE的操作维护系统，操作人员已经登录U2020/MAE服务器。

  U2020/MAE的操作步骤具体请参见《U2020 MBB网络管理系统 虚拟化产品文档》（“安装与调测 > U2020 虚拟化集群系统调测指南 > 集成核心网和无线接入网网元到U2020”章节）/《iMaster MAE产品文档》（“安装与调测 > MAE调测指南 > 调测MAE-Access > 集成核心网和无线接入网网元到MAE”章节）。
* 网元基础数据配置完成。

数据

无需准备数据。

## 操作步骤

1. 在MME上增加MMEID。

   **ADD MMEID**
2. 申请并加载具有MME Pool功能的License和具有MME Pool用户迁移功能（可选）的License。

   **ACT LICENSE**
3. 在所有MME上打开MME Pool开关。

   **SET LICENSESWITCH**
4. 在MME1上配置本MME的权重信息。

   **SET SYS**

## 任务示例

任务描述

根据全网新建的组网，对Pool功能进行预设置。

脚本

//可选：在MME上增加MMEID。

```
ADD MMEID: MCC="123", MNC="00", MMEGI="8001", MMEC="8";
```

//申请并加载License。

```
ACT LICENSE: FN="LIC4MMEPOOL.xml";
```

```
ACT LICENSE: FN="LIC4USERMIGRA02.xml";
```

//在MME上打开MME Pool开关。

```
SET LICENSESWITCH: LICITEM="LKV2POOL02", SWITCH=ENABLE;
```

//在MME1上配置本MME的权重信息。

```
SET SYS: CAP=100;
```
