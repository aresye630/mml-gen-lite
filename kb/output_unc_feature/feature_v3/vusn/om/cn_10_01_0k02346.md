# 配置举例

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本操作指导Pool区通过新建SGSN来扩容SGSN侧的配置过程。

## 必备事项

前提条件

网元基础数据配置完成。

数据

需要准备的数据请参考新建SGSN割入Pool。

## 操作步骤

1. 路由准备和配置同步阶段。
   1. 申请并加载具有SGSN Iu-flex（LKV2IUFLEX02）和SGSN Pool用户迁移（LKV2SGSNMG02）功能的License。
   2. 链路准备阶段。

      准备Iu接口和Gb接口的路由配置脚本。
   3. 各SGSN配置参数同步。
2. Pool参数配置阶段。

   配置新建SGSN3的Pool参数

   1. 设置SGSN3的Pool ID和NRI长度。

      **ADD POOL**: POOLID=0, NRILENGTH=5;

      目前NRI长度等于7bit仅允许在中国部署。在其他国家部署时，NRI长度不能超过5bit。
   2. 配置本局NRI信息，SGSN3在P-TMSI分配时将填写此处设定的NRI值。

      **ADD LOCALNRI**: POOLID=0, NRIVBGN=3, NRINUM=1;
   3. 设置SGSN3侧CN ID。

      **SET SYS**: CNID=1;
   4. 在SGSN3配置原Pool区内的SGSN与NRI的对应关系。一般情况下，建议在DNS Server中配置，如果运营商采用POOLNRI配置，则命令如下：

      //设置SGSN1的NRI信息

      **ADD POOLNRI**: POOLID=0, NRIV=1, IPTYPE=IPV4, IPV4="192.168.153.1", SGSNN="SGSN 1";

      //设置SGSN2的NRI信息

      **ADD POOLNRI**: POOLID=0, NRIV=2, IPTYPE=IPV4, IPV4="192.168.155.2", SGSNN="SGSN 2";
   5. 在SGSN3上配置Pool区内其他SGSN的NONRAI信息。一般情况下，建议在DNS Server中配置，如果运营商采用NONRAI配置，则命令如下：

      **ADD NONRAI**: NONRAI="12300611111", IPTYPE=IPV4, IPV4="192.168.153.1", SGSNN="SGSN 1";

      **ADD NONRAI**: NONRAI="12300612222", IPTYPE=IPV4, IPV4="192.168.155.2", SGSNN="SGSN 2";
   6. 打开SGSN3兼容性配置中的Flex开关。

      Iu：

      **SET LICENSESWITCH**: LICITEM="LKV2IUFLEX02", SWITCH=ENABLE;

      Gb：

      **SET LICENSESWITCH**: LICITEM="LKV2GBFLEX02", SWITCH=ENABLE;
   7. 在SGSN3配置迁移相关参数。

      **SET OFFLOADINF**: OFFLOADTMR=4, FIRSTTM=54, NONRAI="12300613333", POOLID=0, NULLNRIV=0;
   8. 可选：如果没有规划POOLLA，跳过此步。如果规划了POOLLA，即MME是使用UNC作为融合节点同时支持SGSN POOL功能和MME POOL功能，进行如下操作。

      * 没有规划TA和LA对应关系

        **ADD POOLLA**: LAC="0001";

        **ADD POOLLA**: LAC="0002";

        **ADD POOLLA**: LAC="0003";
      * 规划了TA和LA的对应关系

        ```
        ADD POOLLA: BGNTAI="123033101", ENDTAI="123033105", LAC="0001";
        ADD POOLLA: BGNTAI="123033101", ENDTAI="123033105", LAC="0002";
        ADD POOLLA: BGNTAI="123033101", ENDTAI="123033105", LAC="0003";
        ADD POOLLA: BGNTAI="123033201", ENDTAI="123033205", LAC="0002";
        ADD POOLLA: BGNTAI="123033301", ENDTAI="123033305", LAC="0003";
        ```
   9. 在Pool中原有SGSN上配置新建SGSN3相关PoolNRI记录和NonRAI记录。一般情况下，建议在DNS Server中配置，如果运营商采用POOLNRI配置，则命令如下：

      **ADD POOLNRI**: POOLID=0, NRIV=3, IPTYPE=IPV4, IPV4="192.168.151.3", SGSNN="SGSN 3";
   10. Pool参数配置完成后，需要进行数据配置一致性检查。

       **表1** 预配置数据阶段Checklist

       | 数据配置的一致性检查 | 要求结果 |
       | --- | --- |
       | Pool ID | 一致 |
       | NRI长度 | 一致 |
       | Local NRI | 不重复，与规划数据一致 |
       | CN ID | 不重复，与规划数据一致 |
       | Pool NRI | SGSN3配置了Pool内其他SGSN的NRI和IP地址的对应关系，且IP地址配置一致。 |
       | POOLLA | 一致 |
       | 建立待割接的第一个RNC的所有RAI的性能测量任务 | 已经建立 |
3. 链路配置阶段。

   进行链路配置，对于Gb接口保证NS层配通；对于Iu接口保证SCCP配通；但是RAN侧不向新建SGSN分发用户。
4. 割接阶段。

   割接阶段就是将RAN逐个连接到新建的SGSN。

   1. 根据之前准备的脚本进行链路配置，将Gb接口和Iu接口配通。
   2. 在待割接的RAN上配置RAN侧Pool参数。

      在待割接的RAN上配置新建SGSN的CN ID、NRI值和负荷权重。
   3. 在新建SGSN上配置待割接的RAN的相关参数。

      1. 在新建SGSN3配置待割接的RAN的NSE或RNC记录，打开Flex开关。

         Iu-Flex：**MOD RNC**: RNCX=1, IU\_FLEX=YES;

         Gb-Flex：
         * Gb接口静态配置：**MOD NSE**: NSEI=1, GB\_FLEX=YES;
         * Gb接口动态自动配置：**MOD GBNSECFGPARA**: PARAINDEX=1, GB\_FLEX=YES;
      2. 在新建SGSN3配置IuPaging表，以及基于规划扩展DNS中的RAI记录。

         **ADD IUPAGING**: LAI="123000011", RAC="01", RNCINDEX=1;

         **ADD IUPAGING**: LAI="123000012", RAC="01", RNCINDEX=2;
   4. 进行业务拨测。

      详细请参见SGSN Pool改造配置举例中“业务拨测”步骤。
   5. 重复上述步骤，以相同的方式割接剩余的RAN。
