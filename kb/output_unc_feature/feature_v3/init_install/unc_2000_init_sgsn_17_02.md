# 配置3G会话管理

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本操作指导介绍在运行网络中配置会话管理特性的操作过程。

3G会话管理是MS获取网络服务的前提。在网络中存在3G MS时，每台SGSN均需要配置3G会话管理功能。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020客户端或登录OM Portal）。

* UNC软件安装已完成。
* 已经完成HPLMN配置。

数据

| 类别 | 参数名称 | 取值样例 |  | 获取方法 | 说明 |
| --- | --- | --- | --- | --- | --- |
| ****SET IUSM**** | T3385（s）（T3385） | 8 |  | 参见“水平网设LLD文档 ”。 | 设置3G SM协议配置表信息。 |
|  | N3385（times）（N3385） | 4 |  |  |  |
|  | T3386（s）（T3386） | 8 |  |  |  |
|  | N3386（times）（N3386） | 4 |  |  |  |
|  | T3395（s）（T3395） | 8 |  |  |  |
|  | N3395（times）（N3395） | 4 |  |  |  |

文档

获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 设置3G SM协议配置表信息。

   ```
   SET IUSM: T3385=8, N3385=4, T3386=8, N3386=4, T3395=8, N3395=4;
   ```
