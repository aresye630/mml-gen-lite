# 配置漫游用户数据

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

执行该任务的场景如下：

* 开局
* 扩容
* 现网引入新HLR
* 业务调整

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020客户端或登录OM Portal）。

* UNC软件安装已完成。
* 本局7号信令与SG数据已经配置完成。

文档

获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置互联PLMN。

   ```
   ADD CONNECTPLMN: MCC="460", MNC="11", CC="86", SM=YES, SMS=YES;
   ```
3. 配置IMSI-GT转换关系。

   ```
   ADD IMSIGT: IMSIPRE="46011", GT="86111";
   ```
