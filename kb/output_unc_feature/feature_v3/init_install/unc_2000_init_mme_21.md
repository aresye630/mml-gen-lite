## 操作场景

本任务实例实现以下场景配置：UNC与RNC、SG、HLR、GGSN、DNS、CG通过IP骨干网相连。UNC到HLR通过两个SG负荷分担转接，采用M3UA通信，在链路上由层三设备汇聚后再与SG相连。UNC到RNC、GGSN和到CG均采用VRF+OSPF动态路由+BFD组网方式，UNC通过业务网与DNS互通。

## 必备事项

前提条件

* 请了解UNC各类接口的类型及命名规范，可参见业务组网与逻辑接口介绍。
* 基础数据配置、IP路由组网和业务接口配置子任务在前述章节已有详细描述，可参见基础数据配置、配置VNF侧IP路由数据（非SDN）和配置SGSN。本文针对典型的任务场景举例说明整网脚本配置。

数据

参考各子任务的数据规划准备。

文档

获取网设LLD文档。
