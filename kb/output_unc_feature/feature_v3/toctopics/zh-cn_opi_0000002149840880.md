## 操作场景

本操作指导介绍在运行网络中去激活小区位置信息上报功能的操作过程。

适用于MME

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* 操作人员已经登录U2020/MAE。
* 小区位置信息上报功能已经激活。

数据

无需准备数据。

## 操作步骤

1. 关闭本特性的License配置开关。

   在“MML命令行-UNC”窗口上执行：

   **SET LICENSESWITCH**: LICITEM="LKV2LCR01"，SWITCH=DISABLE；
2. 配置特定的GGSN/P-GW不允许使用该功能。

   在“MML命令行-UNC”窗口上执行：

   **MOD LOCRPTCFG**:RANGE=对端设备范围，IPT=IP地址类型，GWIPV4=GGSN/P-GW的信令面地址，MASKV4=掩码,LOCRPT=支持位置上报功能；

## 任务示例

任务描述

关闭小区位置信息上报功能。

脚本

```
//关闭License配置开关。
SET LICENSESWITCH: LICITEM="LKV2LCR01", SWITCH=DISABLE;

//配置特定的GGSN/P-GW不允许使用该功能。
MOD LOCRPTCFG: RANGE=SPECIFIC_GGSN/P-GW, IPT=IPV4, GWIPV4="10.2.3.4", MASKV4="255.255.255.0", LOCRPT=NO;
```
