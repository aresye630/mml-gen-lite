## 操作场景

本操作指导介绍部署SMSF 1+1互备组网的操作过程。

## 必备事项

前提条件

* 请仔细阅读WSFD-130011 SMSF双活容灾特性概述。
* 已完成SMSF初始配置。

数据

| 命令 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET COMMONSOFTPARAOFBIT** | DWORD16 BIT3 | 1 | 全网规划 | 开启SMSF到UDM的数据一致性检查功能。 |

## 操作步骤

配置SMSF数据

1. 打开SMSF和UDM数据一致性检查功能。

   **SET COMMONSOFTPARAOFBIT**

配置AMF数据

2. 配置AMF到SMSF的对接数据。

   **ADD PNFPROFILE**

配置SMSC/STP数据

3. 配置SMSC/STP到SMSF的对接数据。

   **ADD M3LE**

   **ADD M3DE**

## 任务示例

任务描述

部署SMSF 1+1互备容灾业务。

脚本

//进入“MML命令行-UNC”窗口。

**//****配置SMSF数据。**

//打开SMSF和UDM数据一致性检查功能。

```
SET COMMONSOFTPARAOFBIT: DT=DwCom, DWORDCOMNUM=16, VALUE=VALUE_1, POSITION=3;
```

**//配置SMSC/STP数据**。

//SMSC/STP上需要对接两个不同优先级的SMSF。

```
ADD M3LE:LEX=1, NI=NAT, OPC="0X017701", LET=ASP, LEN="SMSC";
ADD M3DE:DEX=1, LEX=1, DPC="0x240011", SLSSM=B0000, STPF=DISABLE, DET=SGP, ADJF=TRUE, NMD=EXCLUSIVE, PVER=RFC3332, DEN="SMSC";
```

**//配置AMF数据。**

//AMF需要对接两个不同优先级的SMSF。

```
ADD PNFPROFILE:NFINSTANCEID="SMSF_Instance_0", NFTYPE=NfSMSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.2.180.15", PORT=8080, PRIORITY=0;
ADD PNFPROFILE:NFINSTANCEID="SMSF_Instance_1", NFTYPE=NfSMSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.2.180.16", PORT=8080, PRIORITY=1;
```
