# 配置5G LAN业务基本功能

## 操作场景

本操作用于指导在SMF侧开通5G LAN相关业务，完成相关配置。

## 必备事项

前提条件

* 操作人员已了解本功能的原理。
* 已完成加载License，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

数据

| 类别 | 参数 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET SMFFUNC** | 支持是否建立5G LAN会话（NGLANSWITCH） | Support | 本端规划 | 配置开启5G LAN功能开关。 |
|  | 5G LAN会话是否向UDM查询VnGroupData（VNGROUPDATASW） | Support | 本端规划 |  |
| **SET UPSELECTFLAG** | 5G LAN UPF选择开关（NGLANUPFSELSW） | LOCALABILITY | 本端规划 | 配置对5G LAN UPF的选择机制。 |
| **MOD UPNODE** | UPF实例名称（NFINSTANCENAME） | UPF\_Instance0  UPF\_Instance1 | 全网规划  与**ADD PNFPROFILE**命令中的“NF实例标识”参数取值保持一致 | 配置对端UPF支持5G LAN。 |
|  | 是否支持5G LAN（NGLANSW） | ENABLE | 本端规划 |  |
| **SET PFCPPVTEXT** | 特性名称（FEATURE） | NGLAN | 本端规划 | 配置5G LAN关键信元。 |
|  | 私有信元携带开关（SWITCH） | ENABLE | 本端规划 |  |

## 任务示例

任务描述

某行业用户签约了5G LAN业务，该用户涉及多个分支机构，地理范围跨越了两个UPF（UPF\_Instance0和UPF\_Instance1）的范围，两个分支机构的终端基于两个UPF的N6接口实现数据转发互通。

脚本

//配置开启5G LAN功能开关。

```
SET SMFFUNC: NGLANSWITCH=Support, VNGROUPDATASW=Support;
```

//配置对5G LAN UPF的选择机制。

```
SET UPSELECTFLAG: NGLANUPFSELSW=LOCALABILITY;
```

//配置对端UPF支持5G LAN。

```
MOD UPNODE: NFINSTANCENAME="UPF_Instance0", NGLANSW=ENABLE;
MOD UPNODE: NFINSTANCENAME="UPF_Instance1", NGLANSW=ENABLE;
```

//配置5G LAN关键信元。

```
SET PFCPPVTEXT: FEATURE=NGLAN,SWITCH=ENABLE;
```
