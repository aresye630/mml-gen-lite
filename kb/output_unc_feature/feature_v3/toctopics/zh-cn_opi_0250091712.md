## 操作场景

本操作指导介绍在运行网络中，UE进行跨区域移动，所在区域超出了原来SMF的服务范围的场景下，保证UE会话业务连续性的操作过程。

适用于AMF、SMF。

## 必备事项

前提条件

* 运营商已完成不同SMF所服务的TAI范围的规划（每个SMF可能支持部分TAI，所有SMF共同支持网络所有TAI）。
* 请仔细阅读WSFD-205012 跨域互联互通特性概述。
* 完成加载License。

数据

| 类别 | 参数 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD SMFSELPLCY** | 用户范围（SUBRANGE） | HOME\_USER | 全网规划 | I-SMF选择策略。 |
|  | 是否支持I-SMF选择（ISMFSW） | YES | 本端规划 |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。-AMF
2. 打开本特性AMF的License配置开关。

   **SET LICENSESWITCH**
3. 配置I-SMF选择策略。

   **ADD SMFSELPLCY**
4. 进入“MML命令行-UNC”窗口。-SMF
5. 打开本特性SMF的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

支持I-SMF选择策略。UE跨区域移动到SMF无法覆盖的区域时，保证UE PDU会话业务连续性。

脚本

//打开License配置开关，适用于AMF。

```
SET LICENSESWITCH: LICITEM="LKV2ASLSR01", SWITCH=ENABLE;
```

//打开License配置开关，适用于SMF。

```
SET LICENSESWITCH: LICITEM="LKV2ASLSR02", SWITCH=ENABLE;
```

//启用I-SMF选择策略。

```
ADD SMFSELPLCY:SUBRANGE=HOME_USER,ISMFSW=YES;
```
