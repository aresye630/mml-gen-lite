# 配置到对端NSSF的信息

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

在AMF本地配置到对端NSSF网元的连接。AMF拜访NSSF的主要目的是为了获取NSSF上保存的用户切片信息。添加NSSF网元信息主要包含：

* 添加对端NSSF网元的基本信息。
* 添加对端NSSF网元的PLMN信息。
* 添加对端NSSF的实例服务信息。

## 必备事项

前提条件

参考配置本端HTTP信息-必备事项-前提条件。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 当网络中规划了主备NSSF时，需要配置到备NSSF的数据。NF对接NSSF的优先级与规划的主、备NSSF保持一致，NF对接的优先级高的NSSF为主NSSF。

   ```
   ADD PNFPROFILE: NFINSTANCEID="NSSF_Instance_0", NFTYPE=NfNSSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.182", PORT=8080, PRIORITY=0;
   ADD PNFPROFILE: NFINSTANCEID="NSSF_Instance_1", NFTYPE=NfNSSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.183", PORT=8080, PRIORITY=1;
   ```
3. 配置到NSSF的数据，包括NSSF的Profile、Service等信息。设置AMF订阅NSSF切片可用性服务的有效期时长，超时后AMF重新发起订阅。

   ```
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NnssfNsSel, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NnssfNssaiAvai, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_1", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NnssfNsSel, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_1", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NnssfNssaiAvai, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ```
4. 配置NSSF的PLMN信息。

   ```
   ADD PNFPLMN: NFINSTANCEID="NSSF_Instance_0",MCC="123", MNC="03";
   ADD PNFPLMN: NFINSTANCEID="NSSF_Instance_1",MCC="123", MNC="03";
   ```
