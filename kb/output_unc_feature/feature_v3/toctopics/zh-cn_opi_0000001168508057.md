## 操作场景

该任务旨在指导操作人员配置UDM上的5G NAS短消息业务。

## 必备事项

前提条件

* 请仔细阅读**“UDM产品文档”**-->**“业务部署”**--> **“特性部署”** --> **“UDM 5G UDM FE基本特性” --> “****WHFD-450410 5G NAS短消息特性概述****”**。
* 操作人员具有PGW Web LMT的操作权限。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **MOD AMDATA** | IMSI(IMSI) | 123031200100003 | 本端规划 | 运营商统一规划。 |
|  | PROV(是否提供AM签约数据) | TRUE | 本端规划 | 固定取值。 |
|  | SMSSUBSCRIBED(是否允许SMS over NAS) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MTSMS(是否允许被叫短信) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MTSMSBA(是否闭锁被叫短信) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MTSMSBR(是否闭锁被叫漫游短信) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MOSMS(是否允许主叫短信) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MOSMSBA(是否闭锁主叫短信) | TRUE | 全网规划 | 运营商统一规划。 |
|  | MOSMSBR(是否闭锁主叫漫游短信) | TRUE | 全网规划 | 运营商统一规划。 |
| **SET UDMSERV** | CANCELVLRATSMSFREG(SMSF和VLR单注册) | TRUE | 全网规划 | 运营商统一规划。 |

## 操作步骤

1. 登录“UDM业务管理”窗口，参考**“UDM产品文档”**-->**“OM参考”**--> **“PGW Web LMT”** --> **“UDM PGW Web LMT GUI参考” --> “****登录PGW Web LMT MML命令界面****”--> “****登录‘UDM业务管理’窗口****”**。
2. 执行**MOD AMDATA**命令，为用户签约NAS短消息业务。
3. 执行 **SET UDMSERV**命令，设置UDM业务的“SMSF和VLR单注册”参数为“TRUE”。

## 任务示例

任务描述

为IMSI为“123000009123456”的用户签约5G NAS短消息业务。

脚本

//为用户签约NAS短消息业务

```
MOD AMDATA: IMSI="123031200100003", PROV=TRUE, SMSSUBSCRIBED=TRUE, MTSMS=TRUE, MTSMSBA=TRUE, MTSMSBR=TRUE, MOSMS=TRUE, MOSMSBA=TRUE, MOSMSBR=TRUE;
```

//设置UDM业务

```
SET UDMSERV: CANCELVLRATSMSFREG=TRUE;
```
