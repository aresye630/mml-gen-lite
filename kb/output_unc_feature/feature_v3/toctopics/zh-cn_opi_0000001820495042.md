## 操作场景

当运营商网络完成了融合计费接口改造，网络中部署了CHF/NCG，UNC与CHF/NCG对接实现对用户实现融合计费时，需要配置N40接口与CHF/NCG对接。

**图1** 服务化接口协议栈图

N40接口是服务化接口，服务化接口间采用相同的协议栈，传输层统一采用HTTP/2协议，应用层携带不同的服务消息。因为底层的传输方式相同，所有的服务化接口就可以在同一总线上进行传输，支撑业务灵活上线。

HTTP/2（HyperText Transport Protocol 2.0）：下一代超文本传输协议。基于HTTP协议的信息交换分为四个过程：建立连接、发送请求信息、发送响应信息、关闭连接。

TLS（Transport Layer Security）：安全传输层协议。在两个通信应用程序之间提供保密性和数据完整性。

**配置建议**

* GGSN/PGW-C/SMF的服务化接口业务IP地址不能和GGSN/PGW-C/SMF其他接口业务IP地址共用。
* GGSN/PGW-C/SMF的服务化接口端口号没有明确时，使用HTTP知名端口号8080。
* 一个NF类型需要配置一个HTTP本端端点组和对应的HTTP本端端点，然后根据实际部署NF数量配置分别配置对应的SBI端点并绑定对应的HTTP本端端点组。

## 操作步骤

1. 增加N40接口的IP地址。当需要通过FQDN信息获取其他NF的IP信息时，无需配置此步骤。

   **ADD LOGICIP**
2. 配置N40接口的HTTP本端端点组及其包含的分别作为HTTP服务的服务端和客户端的本端端点信息。
   1. 配置HTTP本端端点组信息。

      **ADD HTTPLEGRP**
   2. 配置分别作为HTTP服务的服务端和客户端的本端端点信息。

      **ADD HTTPLE**
3. 配置N40接口接入点信息。

   **ADD SBIAPLE**
4. 配置HTTP属性。在超大报文场景下，可以通过合理设置接收HTTP响应/请求消息体的超时时间、HTTP响应/请求消息体的最大大小、请求消息中JSON数据的最大叶子节点个数等参数，避免发送/请求报文不完整，导致业务处理异常。

   **SET HTTPCONF**
5. 配置CHF实例。

   **ADD TNFINS**
6. 配置CHF实例IP。

   **ADD TNFINSIP**
7. 配置CHF组。

   **ADD TNFGRP**
8. 将CHF实例绑定到CHF组中。

   **ADD TNFBINDGRP**
9. 配置CHF选择策略。

   * 配置全局默认CHF组。建议配置全局默认组，避免出现选择不到CHF组的情况。

     **SET GLBDFTCHFGROUP**
   * 配置基于计费属性选择CHF组。

     **ADD SELECTCHFGBYCC**
   * 配置基于号段选择CHF组。

     **ADD SELCHFGBIMSISEG**
   * 基于NRF选择CHF，不需要专有配置。
   * 基于本地NRF配置选择CHF。
     + 选择支持特定SUPI的CHF：**ADD PNFSUPI**
     + 选择支持特定GPSI的CHF：**ADD PNFGPSI**

## 任务示例

任务描述

本场景提供GGSN/PGW-C/SMF与CHF对接时的配置范例。

* 采用本地配置CHF的方式，部署两台CHF实例，target\_chf\_0和target\_chf\_1，作为主备计费服务器，分别绑定在ChfGroup1和ChfGroup2中。
* 对于计费属性为0x0800和IMSI在12345678901-12345678905之间的用户，主CHF组为ChfGroup1，备CHF组为ChfGroup2。
* 全局默认的主CHF组为ChfGroup1，备CHF组为ChfGroup2。

脚本

1. 参考**《UNC产品手册》：UNC初始配置与调测->****组网路由配置->****配置VNF侧IP路由数据（非SDN）->****手动部署****->****配置静态路由+BFD组网（IPv4）**配置对应的组网。
2. 增加N40接口的IP地址。当需要通过FQDN信息获取其他NF的IP信息时，无需配置此步骤。

   ```
   ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.17.0.6", VPNINSTNAME="VRF_CHF", DESC="FOR Server SBI";
   ADD LOGICIP:IPVERSION=IPv4, LOGICIPV4="10.17.0.7", VPNINSTNAME="VRF_CHF", DESC="FOR Client SBI";
   ```
3. 配置N40接口的HTTP本端端点组及其包含的分别作为HTTP服务的服务端和客户端的本端端点信息。
   1. 配置HTTP本端端点组信息。

      ```
      ADD HTTPLEGRP:INDEX=3, DESC="SMF For CHF";
      ```
   2. 配置分别作为HTTP服务的服务端和客户端的本端端点信息。

      ```
      ADD HTTPLE:INDEX=5, HTTPLEGRPIDX=3, LETYPE=SERVER, IPTYPE=IPv4, IPV4="10.17.0.6", PORT=8080, VPNNAME="VRF_CHF", TLSFLG=NO, DESC="SMF Server";
      ADD HTTPLE:INDEX=6, HTTPLEGRPIDX=3, LETYPE=CLIENT, IPTYPE=IPv4, IPV4="10.17.0.7", VPNNAME="VRF_CHF", DESC="SMF Client";
      ```
4. 配置N40接口接入点信息。

   ```
   ADD SBIAPLE:INDEX=3, HTTPLEGRPIDX=3, NFTYPE=NFTypeSMF, PEERNFTYPE=Nchf, PEERSERVICE=Nchf_ConvCharg, DESCRIPTION="SMF For CHF";
   ```
5. 配置HTTP属性。在超大报文场景下，可以通过合理设置接收HTTP响应/请求消息体的超时时间、HTTP响应/请求消息体的最大大小、请求消息中JSON数据的最大叶子节点个数等参数，避免发送/请求报文不完整，导致业务处理异常。

   ```
   SET HTTPCONF:SERVERRCVBDTMT=15, SERVERSNDRSPTMT=15, MAXBODYSIZE=15, MAXJSONLEAFNUM=100000;
   ```
6. 配置CHF实例。

   ```
   ADD TNFINS:TNFINSINDEX=1, TNFTYPE=CHF, TNFINSNAME="target_chf_0", SCHEMA=http, FQDN="chf1.hw.com";
   ADD TNFINS:TNFINSINDEX=2, TNFTYPE=CHF, TNFINSNAME="target_chf_1", SCHEMA=http, FQDN="chf2.hw.com";
   ```
7. 配置CHF实例IP地址。

   ```
   ADD TNFINSIP:TNFINSINDEX=1, IPTYPE=IPV4, IPV4ADDR="192.168.94.2", PORT=3220;
   ADD TNFINSIP:TNFINSINDEX=2, IPTYPE=IPV4, IPV4ADDR="192.168.104.2", PORT=3230;
   ```
8. 配置CHF组。

   ```
   ADD TNFGRP:TNFGRPINDEX=1, TNFTYPE=CHF, TNFGRPNAME="ChfGroup1";
   ADD TNFGRP:TNFGRPINDEX=2, TNFTYPE=CHF, TNFGRPNAME="ChfGroup2";
   ```
9. 将CHF实例绑定到CHF组中。

   ```
   ADD TNFBINDGRP:TNFGRPINDEX=1, TNFINSINDEX=1;
   ADD TNFBINDGRP:TNFGRPINDEX=2, TNFINSINDEX=2;
   ```
10. 配置基于计费属性和IMSI号段选择CHF组。

    ```
    ADD SELECTCHFGBYCC:CCTYPE=VALUE, CCVALUE="0x0800", MASK="0xffff", PRIORITY=2, PRIMARYCHFGRP="ChfGroup1", SECONDARYCHFGRP="ChfGroup2";
    ADD SELCHFGBIMSISEG:SEGSTART="12345678901", SEGEND="12345678905", PRIMARYCHFGRP="ChfGroup1", SECONDARYCHFGRP="ChfGroup2";
    ```
11. 配置全局默认CHF组。

    ```
    SET GLBDFTCHFGROUP:PRIMARYCHFGRP="ChfGroup1", SECONDARYCHFGRP="ChfGroup1";
    ```
