## 操作场景

在行业用户签约专用DNN场景下，需要将用户请求的DNN纠正为专用DNN再进行后续流程。

可按此指导配置AMF上的DNN纠错功能。

## 必备事项

前提条件

* 请仔细阅读WSFD-228001 跨域业务访问特性概述。
* 已完成特性License（82209921 LKV2DNNC01 DNN纠正）加载并打开license配置开关，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD LOCALNSDNN** | SUBRANGE（用户范围） | IMSI\_PREFIX | 全网规划 | 增加DNN纠正和DNN纠正策略配置。 |
|  | IMSIPRE（IMSI前缀） | 12303 |  |  |
|  | CORRECTTYPE（纠正类型） | DNN\_CORRECTION |  |  |
|  | DNN（AMF本地配置的DNN） | Huawei.com |  |  |
|  | DNNPLCY（DNN纠正策略） | Default\_DNN\_preferred |  |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置DNN纠正信息及DNN纠正策略。

   **ADD LOCALNSDNN**

## 任务示例

任务描述

某行业签约了专用DNN “Huawei.com”，希望用户无论身处何处，都能够使用该专用DNN访问行业总部提供的业务服务。

运营商为某行业分配了IMSI前缀为12303的号段，由于运营商给行业用户发放的sim卡默认设置的是运营商的通用DNN，为满足用户随时随地访问总部业务服务的诉求（业务始终锚定到业务归属地的锚点UPF），需要在用户业务流程中将用户默认请求的通用DNN纠正为专用DNN。

脚本

//为全网IMSI前缀为12303的用户配置DNN纠正信息，AMF本地配置的DNN是Huawei.com，DNN纠正策略为签约default DNN优先。

```
ADD LOCALNSDNN:SUBRANGE=IMSI_PREFIX,IMSIPRE="12303",CORRECTTYPE=DNN_CORRECTION,DNN="Huawei.com",DNNPLCY=Default_DNN_preferred;
```
