## 操作场景

本操作指导介绍在运行网络中激活MEC单点模式故障保护特性的操作过程。

MEC单点模式是指位于边缘侧的“**ULCL UPF+辅锚点UPF**”的共部署节点只有一个，没有和它形成双主/多主负荷分担的其他UPF。该模式下当该单节点UPF故障，SMF能够感知故障并将该UPF从用户会话中删除，此时用户可通过**主锚点UPF**来访问本地DN和Internet大网。

ULCL UPF+辅锚点UPF表示ULCL UPF和辅锚点UPF共部署节点，以下用“**ULCL UPF+辅锚点UPF**”来表示。

## 必备事项

前提条件

* 请仔细阅读WSFD-108005 MEC单点模式故障保护。
* 已完成加载License。
* 以下配置过程是基于SMF和**主锚点UPF**以及**“ULCL UPF+辅锚点UPF”**的对接配置已完成情况下的操作，SMF和主锚点UPF的对接配置参见N4接口配置，SMF和**“ULCL UPF+辅锚点UPF”**的对接配置参见配置SMF和“UL CL UPF+辅锚点UPF”对接。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置UPF粒度的SMF到UPF的心跳探测并开启故障场景下去活该UPF上用户会话的功能。

   **ADD UPFPFCPPARA**
3. **配置****“ULCL UPF+辅锚点UPF”单点部署模式下****UPF故障时SMF删除用户N4会话的速率。**

   **SET UPFAULTOPERPARA**
4. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

某运营商针对某工业园区边缘侧采用**“ULCL UPF+辅锚点UPF”**单节点部署，该UPF的实例标识为UPF\_Instance\_0，希望在该UPF故障时用户访问本地业务能够正常进行，在开启本特性。

脚本

//配置SMF对“ULCL UPF+辅锚点UPF”的心跳探测机制。

```
ADD UPFPFCPPARA: UPFINSTANCEID="UPF_Instance_0", HBINTERVAL=30, HBT1=5, HBN1=3, DEACTIVEFLAG=ENABLE, DACTINTERVAL=900;
```

//配置“ULCL UPF+辅锚点UPF”单点部署模式下UPF故障时SMF删除用户N4会话的速率。

```
SET UPFAULTOPERPARA: UPMIGRATE=1000;
```

//打开本功能的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2SMECFP01", SWITCH=ENABLE;
```
