# 激活智能信令风暴平滑处理（适用SGW-C）

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

当运营商需要部署SGW-C上智能信令风暴平滑处理，需要激活该功能。

适用于SGW-C。

## 必备事项

前提条件

* 请仔细阅读WSFD-010804 智能信令风暴平滑处理特性概述。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET DDNTIMEOUTCTRL** | 用户延时删除开关（DELAYSUBDELSW） | ENABLE | 全网规划 | 使能“DDN消息无响应时进行用户延时删除处理”功能，并设置延时时长。 |
|  | 延时定时器时长下限分钟值（MINDELAYTIMER） | 40 | 全网规划 |  |
|  | 延时定时器时长上限分钟值（MAXDELAYTIMER） | 70 | 全网规划 |  |
|  | 抑制时长（分）（SUPPTIME） | 15 | 全网规划 |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 使能“DDN消息无响应时进行用户延时删除处理”功能，并设置延时时长。

   **SET DDNTIMEOUTCTRL**

## 任务示例

任务描述

运营商希望开启DDN消息无响应延时删除用户功能，配置用户延时删除定时器时长区间值为40分钟至70分钟。

脚本

//使能“DDN消息无响应时进行用户延时删除处理”功能，并设置延时时长。

```
SET DDNTIMEOUTCTRL: DELAYSUBDELSW=ENABLE, MINDELAYTIMER=40, MAXDELAYTIMER=70;
```
