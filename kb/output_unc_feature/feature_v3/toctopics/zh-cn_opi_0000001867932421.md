# UNC清除DNS缓存

* 操作场景
* 必备事项
* 任务示例

## 操作场景

DNS缓存（DNS Cache）是指使用DNS服务器解析时查找到的域名和IP地址信息在系统中的缓存，用于快速解析域名。无线割接、应急执行等场景下，会涉及清除DNS缓存。

清除DNS缓存会导致系统的CPU负荷增大，系统向DNS服务的查询次数可能会增加。

## 必备事项

前提条件

已登录OM Portal。

数据

无。

## 任务示例

任务描述

清除DNS缓存使服务器记录生效。

不同版本的操作命令有差别，请先确认已选取正确版本的资料。

脚本

//清AMF侧DNS缓存使服务器记录生效。

```
CLR DNSC: CACHETYPE=L2CACHE, SERVICETYPE="LINK_VNFC";
CLR NGDNSCACHE: QUERYTYPE=QUERY_TYPE_NAPTR, CLEARMANNER=All;
```

//清MME&SGSN侧DNS缓存使服务器记录生效。

```
CLR DNSC: CACHETYPE=ALL, SERVICETYPE="LINK_VNFC";
```

//清AMF&MME&SGSN侧DNS缓存使服务器记录生效。

```
CLR DNSC: CACHETYPE=ALL, SERVICETYPE="LINK_VNFC";
CLR NGDNSCACHE: QUERYTYPE=QUERY_TYPE_NAPTR, CLEARMANNER=All;
```
