## 操作场景

当希望辅助用户为上行流量选择合适的路由，在PDU会话建立后产生的上行流量能定时被路由到指定DNN，而不是运营商定义的通用DNN时，需要激活URSP功能。

## 必备事项

前提条件

* 请仔细阅读WSFD-211102 支持URSP能力。
* 完成激活PCC基本功能相关操作。
* 参考UPCF产品文档中特性《WHFD-611068 N15接口(使用HTTP协议)策略控制》，在PCF上完成UE策略关联配置。
* 完成加载License。

## 操作步骤

* 配置AMF的URSP功能。
  1. 进入“MML命令行-UNC”窗口。
  2. 打开License配置开关。

     **SET LICENSESWITCH**
  3. 配置应用网络侧规划的AM策略/UE策略的用户群。默认不使用网络侧规划的AM策略/UE策略。

     **MOD AMUEPLCYCTRL**

     支持基于DNN创建UE策略时，将“DNNUEPLCYSW”设置为“YES”，并提供DNN关键字。
  4. 允许N14接口传递UE策略。

     **SET AMFPLCYFUNC**
  5. 允许N14接口消息携带“pcfUePolicyUri”和“uePolicyReqTriggerList”。

     **SET AMFSBICMPT**
  6. 若希望在UDM故障重选时，AMF支持创建UE策略偶联，请将如下软参值设置为1。

     **DWORD68 BIT31**
  7. 若希望在AMF内移动性注册更新和基于N2接口切换后的移动性注册更新流程中创建UE策略偶联，请将如下软参值设置为1。

     **DWORD71 BIT25**
  8. 配置AMF支持使用PCF通过Location信元携带的地址进行通信。

     **SET AMFPEERSELFUNC**

## 任务示例

任务描述

AMF上规划开启PCC功能，DNN“dnn-test”下使能基于DNN的AM策略和UE策略建立。

脚本

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2URSPAM01", SWITCH=ENABLE;
```

//在AMF上配置支持基于DNN的AM策略和UE策略创建。

```
MOD AMUEPLCYCTRL: SUBRANGE=HOME_USER, NSGRPID=0,ISUEASSOC=YES, DNNUEPLCYSW=YES, DNNUEPLCYKEYWD="dnn-test",DESC="Enable UE URSP for Subscribers";
```

//在AMF上配置允许N14接口传递UE策略。

```
SET AMFPLCYFUNC: OLDUEPLCY=YES;
```

//在AMF上配置允许N14接口携带“pcfId”、“pcfUePolicyUri”和“uePolicyReqTriggerList”。

```
SET AMFSBICMPT: SBITYPE=N14, OLDPCFID=YES, OLDUEPLCYURI=YES, OLDUEPLCYTRIG=YES;
```

//在AMF上配置在UDM故障重选时，AMF支持创建UE策略偶联”。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=68, VALUE=VALUE_1, POSITION=31;
```

//在AMF上配置在AMF内移动性注册更新和基于N2接口切换后的移动性注册更新流程中，AMF支持创建UE策略偶联”。

```
SET AMFSOFTPARAOFBIT: DT=Dw, DWORDNUM=71, VALUE=VALUE_1, POSITION=25;
```

//配置AMF支持使用PCF通过Location信元携带的地址进行通信。

```
SET AMFPEERSELFUNC: NFLOCATION=PCF-1;
```
