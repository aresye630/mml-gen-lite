# 配置Routing Behind MS功能

* 操作场景
* 必备事项
* 任务示例

## 操作场景

该任务旨在指导操作人员完成一跳入家所需要的Routing Behind MS功能。本方案中，只需从Radius AAA服务器获取后路由信息，SMF本地无需配置后路由。

## 必备事项

前提条件

已完成**Routing Behind MS**功能的License加载。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ****SET LICENSESWITCH**** | License项（LICITEM） | LKV3W9RBMS12 | 本端规划 | 打开Routing Behind MS的License。 |
|  | 开关（SWITCH） | ENABLE | 固定配置 | - |
| ****SET APNADDRESSATTR**** | APN名称（APN） | home.dnn | 已配置数据中获取 | 规划使能Routing Behind MS功能的APN实例，已通过**ADD APN**命令配置，可以使用**LST APN**命令进行查询。 |
|  | 手机后路由（FRAMEDROUTE） | ENABLE | 本端规划 | 配置指定APN是否允许手机后路由用户接入。 |

## 任务示例

任务描述

使能APN“home.dnn”的Routing Behind MS功能。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV3W9RBMS12",SWITCH=ENABLE;
```

//使能该APN的Routing Behind MS功能。

```
SET APNADDRESSATTR:APN="home.dnn",FRAMEDROUTE=ENABLE;
```
