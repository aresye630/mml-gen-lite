## 操作场景

PCRF/PCF需要感知到应用数据流（L7），并为应用数据流提供QoS保障时，需要在UNC上激活ADC基本功能。

PGW-U/UPF检测应用并通过UNC上报给PCRF/PCF。

## 必备事项

前提条件

* 请仔细阅读WSFD-109102 ADC基本功能。
* 完成加载License（如果有需求，请联系华为技术支持工程师）。
* 完成激活PCC基本功能。

数据

**表1** 数据规划（PCRF/PCF通过动态规则下发appid）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD FLOWFILTER** | 流过滤器名称（FLOWFILTERNAME） | flowfilter\_ADC01 | 本端规划 | 不同流过滤器之间，该参数不能重复。  GGSN-C/PGW-C/SMF、PGW-U/UPF、PCRF/PCF三个网元上的该参数必须一致，否则无法正常上报。 |
| **ADD ADCPARA** | 流过滤器名称（FLOWFILTERNAME） | flowfilter\_ADC01 | 已配置数据中获取 | 使用**ADD FLOWFILTER**命令定义的流过滤器名称。 |
|  | 流信息上报开关（FLOWINFORPT） | ENABLE | 本端规划 | PCRF/PCF需要获取流信息时，设置为ENABLE。默认取值是DISABLE。 |

**表2** 数据规划（PCRF/PCF通过预定义规则下发APPLICATION\_START和APPLICATION\_STOP Event-Trigger）

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD RULE** | 规则名称（RULENAME） | rule\_test | 本端规划 | 存在多条数据时，该参数+策略类型不能完全相同。 |
|  | 策略类型（POLICYTYPE） | ADC | 本端规划 | 需根据业务策略选择相应的策略类型。 |
| **ADD USERPROFILE** | 用户模板名称（USERPROFILENAME） | up\_test | 全网规划 | 配置GGSN-C/PGW-C/SMF上的UserProfile。 |
|  | 用户模板类型（UPTYPE） | PCC | 固定取值 |  |
| **ADD RULEBINDING** | 用户模板名称(USERPROFILENAME) | up\_test | 已配置数据中获取 | 将本地rule/预定义规则rule绑定到UserProfile上。 |
|  | 规则名称(RULENAME) | rule\_test | 已配置数据中获取 |  |

## 操作步骤

1. 打开本特性的License配置开关。

   **SET LICENSESWITCH**:LICITEM="LKV2BADCF01",SWITCH=ENABLE;
2. PCRF/PCF要下发应用Start和Stop的两个Event Trigger，当PCRF/PCF通过动态规则下发appid时，请执行本步骤。
   1. 配置ADC业务使用的appid。

      **ADD FLOWFILTER**
   2. 配置ADC参数。

      **ADD ADCPARA**
3. PCRF/PCF要下发应用Start和Stop的两个Event Trigger，当PCRF/PCF不通过动态规则下发appid时，请执行本步骤。
   1. **可选：**配置SMF上的本地rule。

      **ADD RULE**
   2. **可选：**配置SMF上的UserProfile，将本地rule绑定到UserProfile上。

      1. 配置UserProfile。

         **ADD USERPROFILE**
      2. 将rule绑定到UserProfile。

         **ADD RULEBINDING**

## 任务示例

任务描述

任务示例一：PCRF/PCF通过动态规则下发appid，当UPF检测到appid对应的业务开始/结束时，需要向PCRF/PCF上报，且PCRF/PCF需要获取流信息。

任务示例二：PCRF/PCF通过预定义规则下发APPLICATION\_START和APPLICATION\_STOP Event-Trigger，当UPF检测到appid对应的业务开始/结束时，需要向PCRF/PCF上报。UPF决定是否向PCRF/PCF上报流信息，GGSN-C/PGW-C/SMF负责透传流信息。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH:LICITEM="LKV2BADCF01",SWITCH=ENABLE;
```

//（任务示例一）配置ADC业务使用的appid。

```
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_ADC01";
```

//（任务示例一）配置ADC参数。

```
ADD ADCPARA: FLOWFILTERNAME="flowfilter_ADC01",FLOWINFORPT=ENABLE;
```

//（任务示例二）配置预定义规则/预定义规则组。

```
ADD RULE:RULENAME="rule_test",POLICYTYPE=ADC;
ADD USERPROFILE:USERPROFILENAME="up_test",UPTYPE=PCC;
ADD RULEBINDING:USERPROFILENAME="up_test",RULENAME="rule_test";
```
