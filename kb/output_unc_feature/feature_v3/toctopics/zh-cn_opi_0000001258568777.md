## 操作场景

本文档用于指导跨域业务漫游访问的反向分流方案。

## 必备事项

前提条件

* 请仔细阅读WSFD-228001 跨域业务访问特性概述。
* 已完成本特性License（82200EDE LKV2SACDSA01 跨域业务访问）加载，可以通过**DSP LICENSE**命令查询确认，如果本特性的License在查询列表中可见，即可认为本特性License已加载成功。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置UL CL属性名称和DNAI的绑定关系。

   **ADD ULCLPROP**
3. 配置反向分流DNAI信息。

   **ADD DNAIINFO**
4. 配置专用DNN Always的分流功能。

   **ADD APN**
5. 配置专用DNN下UPF位置特征。

   **ADD APNUPFINFO**
6. 修改园区UPF为支持主锚点和分流UPF合设形态。

   **MOD UPNODE**
7. 配置IPv6会话场景下的分流策略。

   **SET SMFFUNC**

## 任务示例

任务描述

某行业的业务服务部署在行业总部所在的区域内，希望其职员无论身处何处都能够访问内部业务，同时也能够在不换卡、不换号的基础上平滑地访问Internet。行业对其数据是否出园区比较敏感。

综上，需要为行业用户签约专用DNN（Huawei.com）才能确保数据永远锚定在业务所在地，另外鉴于用户对数据是否出园区比较敏感，选择将位于园区的UPF改造成主锚点和分流UPF合设态的UPF，实现对访问行业的业务和访问Internet的业务进行分流。

脚本

```
//配置UL CL属性名称和DNAI的绑定关系。
ADD ULCLPROP: ULCLPROPNAME="testulclpropname", DNAI="testdnai"; 
//配置反向分流DNAI信息。
ADD DNAIINFO: DNAI="testdnai", SHUNTDIRECT=REVERSE, SHUNTLOC=HOME, ALWAYSSHUNTSW=ENABLE
//配置专用DNN Always的分流功能。
ADD APN: APN="Huawei.com", ALWAYSPSAULCLSW=ENABLE;
//配置专用DNN下UPF位置特征。
ADD APNUPFINFO: APN="Huawei.com", UPFINSTANCEID=UPF_INSTANCE0, LOCATION=INHERIT, PSACOMBINEULCL=ENABLE;
//修改园区UPF为支持主锚点和分流UPF合设形态。
MOD UPNODE: NFINSTANCENAME=UPF_INSTANCE0, LOCATION=Central, SUPULCLBPONLY=Disable, PSACOMBINEULCL=ENABLE; 
//配置IPv6会话场景下的分流策略。
SET SMFFUNC:IPV6LOCALUP=UlClPrefer;
```
