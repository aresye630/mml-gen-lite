# DHCP接口跟踪

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

* 系统运行出现故障需要进行接口消息跟踪定位排除故障。
* 维护人员调试设备运行情况。

  + 设备出口跟踪中能够显示消息，不代表跟踪到的消息一定从本设备向外发送成功，请关注系统其他异常告警和性能统计。
  + 跟踪功能主要用于保障网络运营和服务、检测通信传输中的故障和错误，该功能涉及使用个人用户标识和用户通信内容。建议您只有在所适用法律法规允许的目的和范围内方可启用相应的功能。在使用用户通信内容的过程中，您应采取足够的措施以确保用户的通信内容受到严格保护。
  + 操作员在现场使用跟踪功能时，消息跟踪中的IP地址、端口等信息仍然是用户的真实信息，是未被加密的。

## 必备事项

前提条件

* 具备管理员权限的操作员已经登录OM Portal。
* 维护人员具有接口消息跟踪权限。

数据

| 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- |
| IP地址类型 | IPv4/IPv6 | 本端规划 | 接口地址类型 |
| 代理IPv4地址 | 192.168.0.5 | 本端规划 | 代理IPv4地址，可以通过“LST AGENTIP”命令查询。 |
| 代理IPv6地址 | fc00::1 | 本端规划 | 代理IPv6地址，可以通过“LST AGENTIP”命令查询。 |
| DHCP IPv4服务器地址 | 192.168.245.155 | 全网规划 | DHCP IPv4服务器地址，可以通过“LST DHCPSERVER”命令查询。 |
| DHCP IPv6服务器地址 | fcff::1 | 全网规划 | DHCP IPv6服务器地址，可以通过“LST DHCPSERVER”命令查询。 |

## 操作步骤

1. 输入DHCP接口跟踪任务参数：在左侧跟踪导航树界面选择“UNC”->“接口跟踪”->“DHCP接口跟踪”后，单击“创建跟踪任务”，进入DHCP接口跟踪任务创建的界面，依次输入“任务名称”、“跟踪时长”和“定位条件”参数，如图1 DHCP接口跟踪所示。

   **图1** DHCP接口跟踪

   参数说明如表1 DHCP接口跟踪参数配置说明所示。

   **表1** DHCP接口跟踪参数配置说明

   | 参数名称 | 参数说明 | 取值范围 | 默认值 |
   | --- | --- | --- | --- |
   | 任务名称 | 该次跟踪任务的名称 | - | - |
   | 定位条件 | IP地址类型 | IPv4/IPv6 | IPv4 |
   |  | 代理IPv4地址/代理IPv6地址 | IPv4或IPv6地址 | － |
   |  | DHCP IPv4服务器地址/DHCP IPv6服务器地址 | IPv4或IPv6地址 | － |
   | 跟踪时长 | 该参数用于指定该次跟踪任务的时长。 | 1分钟~720小时59分钟 | 1（小时） |
2. 单击“确定”，启动跟踪任务。
