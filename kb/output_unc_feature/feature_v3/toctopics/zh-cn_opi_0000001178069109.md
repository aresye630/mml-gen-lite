# 配置与NSSF对接数据

* 操作场景

## 操作场景

* 如果网络中部署了NRF，则需执行配置到NRF的数据。
* 如果网络中无NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF，则执行可选：本地配置到NSSF的对接数据。

  当网络中既部署了NRF，又本地配置了本地配置到NSSF的对接数据时，可以通过**SET NFDISCPLCY**命令配置服务发现流程的策略，默认为优先选择本地配置的NSSF。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* UNC软件安装已完成。
* 已经获取网设LLD文档。

## 操作步骤

**可选：配置到NRF的数据**

如果网络中未部署NRF，则无法执行本步骤，需手工配置AMF与周边NF的逻辑连接，配置步骤参见配置与NSSF对接数据。

1. 进入“MML命令行-UNC”窗口。
2. 配置NRF信息。

   ```
   ADD NRF: NRFINSTANCENAME="NRF_Instance_0", TLS=FALSE, PRIORITY=0;
   ```
3. 配置NRF的地址信息。

   ```
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_0", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="172.16.0.7", PORT=8080;
   ```
4. **可选：**配置NRF协议参数。当开启订阅功能开关时，可以增加订阅条件。当目标NF触发订阅条件和通知事件时，NRF向源NF发送通知。

   ```
   ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_0", WAITINTERVAL=5, MAXRETRYTIMES=3,LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
   ADD SUBCONDITION: NFTYPE=NfSMF, CONDITION=NfInstanceId-1, REQNOTIFEVENT=NF_REGISTERED-1;
   ```
5. **可选：**当网络中规划了双主或者主备NRF时，需要配置本步骤。双主NRF场景下，NF对接的优先级高的NRF为本地DC的NRF；主备NRF场景下，NF对接的优先级高的NRF为主NRF。

   ```
   ADD NRF: NRFINSTANCENAME="NRF_Instance_1", TLS=FALSE, PRIORITY=1;
   ADD NRFADDR: NRFINSTANCENAME="NRF_Instance_1", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS="172.26.0.7",  PORT=8080;
   ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_1", WAITINTERVAL=5, MAXRETRYTIMES=3,LOADCARRYINHB=FALSE, SUBSCRISWITCH=ON, OAUTH2SWITCH=OFF;
   ADD SUBCONDITION: NFTYPE=NfSMF, CONDITION=NfInstanceId-1, REQNOTIFEVENT=NF_REGISTERED-1;
   ```

   + 请保证已完成AMF到双主或者主备NRF的路由数据配置。
   + 请提前规划**ADD NRFPARA**中“WAITINTERVAL”和“MAXRETRYTIMES”的值，确保AMF对NRF的故障探测时长比NRF探测NF的时长要短，避免因链路故障NF还未来得及倒换就被NRF判定为故障。AMF探测时长请参考WSFD-114002 NRF双活容灾特性概述中“原理概述”>“可靠性机制”小节。
6. 打开NF注册、认证、发现等与NRF进行交互的基本功能的开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV2NFBAM01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV2NFAAM01",SWITCH=ENABLE;
   SET LICENSESWITCH:LICITEM="LKV2NFDAM01",SWITCH=ENABLE;
   ```
7. 激活AMF向NRF注册。

   ```
   ACT NFONLINE: NFINSTANCENAME="AMF_Instance_0";
   ```

**可选：本地配置到NSSF的对接数据**

8. 配置到NSSF的数据，包括NSSF的Profile、Service等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="NSSF_Instance_0", NFTYPE=NfNSSF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="10.255.255.182", PORT=8080, PRIORITY=0;
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NnssfNsSel, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="NSSF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NnssfNssaiAvai, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ```
