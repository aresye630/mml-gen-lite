# 配置切片选择可选功能

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本章节用于配置以下可选功能：

* 是否由初始AMF决策网络切片。
* 是否使能区域切片功能，并配置TA级限制切片。
* 切片选择中AMF重定向方式。
* 拒绝UE注册请求时是否携带Rejected S-NSSAI信元。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* UNC软件安装已完成。
* 已经获取网设LLD文档。

## 操作步骤

**配置由初始AMF决策网络切片**

1. 判断是否由初始AMF决策网络切片。

   ```
   SET NSSELPARA:SELFDETERMINE=YES;
   ```

**配置AMF到NSSF的网络切片可用性信息的自动同步功能**

2. 配置AMF到NSSF的网络切片可用性信息的自动同步。

   ```
   SET NSSELPARA:SYNSW=ON,INTERVAL=5;
   ```

**使能区域切片功能，并配置TA级限制切片**

3. 5分钟（AMF到NSSF的网络切片可用性信息的同步间隔时间）之后配置由AMF携带其服务的TAI列表向NSSF订阅网络切片可用性信息。

   ```
   OPR NSAVLINFO: OPTYPE=SUBSCRIBE;
   ```
4. 配置AMF是否使能区域切片功能。

   ```
   SET NSSELPARA:CAMPUSNSSW=ON;
   ```
5. 增加TA级切片限制区域码。

   ```
   ADD RSTRNSAREACODE:AREACODE="jq001.pd006.sh.mcc123.mnc45";
   ```
6. 增加TA级限制切片所属跟踪区成员

   ```
   ADD RSTRNSAREAMEM:AREACODE="jq001.pd006.sh.mcc123.mnc45", MCC="123", MNC="45", BGNTAC="120101";
   ```
7. 增加TA级限制切片。

   ```
   ADD AMFRSTRNSSAI:RSTRAREARANGE=ALL_AREA,SUBRANGE=FOREIGN_USER,SST=1,SD="010101";
   ```

**配置切片选择中AMF重定向方式**

8. 配置初始AMF通过重定向流程接入到目标AMF。

   ```
   SET NGMMFUNC: RESELTYPE=RE_DIRECT;
   ```

**配置拒绝UE注册请求时携带Rejected S-NSSAI信元**

9. 配置拒绝UE注册请求时携带Rejected S-NSSAI信元。

   ```
   SET NASCMPT:NASMSGTYPE=REGISTRATION_REJECT,SNDREJNS=YES;
   ```
