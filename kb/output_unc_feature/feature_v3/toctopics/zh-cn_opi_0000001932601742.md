## 操作场景

当用户在拜访地接入网络时，归属地UPCF侧通过归属地SMF侧在Npcf\_SMPolicyControl\_Create/Npcf\_SMPolicyControl\_Update请求消息中携带了vplmnQos信元判断此时用户需要进行SA国际漫游策略控制，随之归属地的UPCF通过更新下发已配置的关联了CmdSessionRule动作的规则来实现SA国际漫游策略控制功能，下发更新的带宽。

本特性支持配置任意条件或不配置条件，只要购买了本特性license（即“82403309 LRM0PCFSAIR100 SA国际漫游策略控制”）且用户在拜访地接入网络时Npcf\_SMPolicyControl\_Create/Npcf\_SMPolicyControl\_Update请求消息中携带了vplmnQos信元，即可支持SA国际漫游策略控制。

以用户在拜访地上线，不配置条件，UPCF对接华为UNC为例：

* SMF发送给UPCF的Npcf\_SMPolicyControl\_Create请求消息中携带“vplmnQos”信元，最大上、下行带宽分别为1000 Kbps、1000 Kbps。
* UPCF上配置的会话级最大上、下行带宽分别为50 Mbps、20 Mbps。
* 系统比较用户请求的带宽和UPCF上配置的带宽，取带宽低的进行下发。

## 对系统的影响

该特性对系统无影响。

## 操作步骤

1. 确认已加载特性License。

   确认已经在NF上申请并加载对应的License项。国际漫游解决方案涉及的License控制项详细请参考特性映射与交互。
2. 登录UPCF Web UI界面。
3. 配置5G动作组。

   导航入口为“策略管理 > 策略 > 5G动作组”。

   此场景需配置动作：Arp、Ambr、DefaultQosInformation、SessionRuleAction、CmdSessionRuleAction，相关应用场景如下：

   * Ambr：用于设置会话类型的上下行带宽。
   * Arp：当需要配置“类型”为“DefaultQosInformation”的动作组时必须配置此动作。
   * DefaultQosInformation：用于设置会话类型的QoS信息。
   * SessionRuleAction：当需要配置会话类型规则，配置此动作。
   * CmdSessionRuleAction：当需要配置会话类型规则，配置此动作。

   动作组的数据规划如表2所示，详细参数说明请参见动作组参数表。

   * 动作组gjmy\_SessAction：动作Arp、Ambr、DefaultQosInformation、SessionRuleAction
   * 动作组gjmy\_CmdSessAction：动作Arp、Ambr、DefaultQosInformation、CmdSessionRuleAction

8. 发放业务。
   1. 执行**ADD PSUB**增加一个用户。

      “USRIDENTIFIER”的参数类型受软参**VRM\_SUBSRCIPTIONIDTYPE（系统支持的用户类型）**控制，默认为“IMSI”。

      ```
      ADD PSUB:USRIDENTIFIER="46010381012****", USRMSISDN="12345678901", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA;
      ```
   2. 执行**ADD PSRV**给用户签约业务。

      ```
      ADD PSRV: USRIDENTIFIER="46010381012****", SRVNAME="gjmy_5GPCC", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
      ```

## 任务示例

任务描述

配置业务。

脚本

```
ADD NGACTION:ACTIONNAME="gjmy_arp",TYPE="Arp";
ADD NGACTION:ACTIONNAME="gjmy_cmdarp",TYPE="Arp";
ADD NGACTION:ACTIONNAME="gjmy_defQos",TYPE="DefaultQosInformation";
ADD NGACTION:ACTIONNAME="gjmy_CmddefQos",TYPE="DefaultQosInformation";
ADD NGACTION:ACTIONNAME="gjmy_AMBR",TYPE="Ambr";
ADD NGACTION:ACTIONNAME="gjmy_CmdAMBR",TYPE="Ambr";
ADD NGACTION:ACTIONNAME="gjmy_SessAction",TYPE="SessionRuleAction";
ADD NGACTION:ACTIONNAME="gjmy_CmdSessAction",TYPE="CmdSessionRuleAction";
ADD NGACTIONATTR:ACTIONNAME="gjmy_arp",ATTRNAME="priorityLevel",TYPE=Object Attribute,VALUE="SmfSession.SubsDefQosPriorityLevel";
ADD NGACTIONATTR:ACTIONNAME="gjmy_arp",ATTRNAME="preemptCap",TYPE=Object Attribute,VALUE="SmfSession.SubsDefQosPreemptionCap";
ADD NGACTIONATTR:ACTIONNAME="gjmy_arp",ATTRNAME="preemptVuln",TYPE=Object Attribute,VALUE="SmfSession.SubsDefQosPreemptionVuln";

ADD NGACTIONATTR:ACTIONNAME="gjmy_cmdarp",ATTRNAME="priorityLevel",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQosArpPriorityLevel";
ADD NGACTIONATTR:ACTIONNAME="gjmy_cmdarp",ATTRNAME="preemptCap",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQosArpPreemptionCap";
ADD NGACTIONATTR:ACTIONNAME="gjmy_cmdarp",ATTRNAME="preemptVuln",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQosArpPreemptionVuln";

ADD NGACTIONATTR:ACTIONNAME="gjmy_defQos",ATTRNAME="5qi",TYPE=Object Attribute,VALUE="SmfSession.SubsDefQos5qi";
ADD NGACTIONATTR:ACTIONNAME="gjmy_defQos",ATTRNAME="arp",TYPE=Reference ActionGroup,VALUE="gjmy_arp";

ADD NGACTIONATTR:ACTIONNAME="gjmy_CmddefQos",ATTRNAME="5qi",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQos5qi";
ADD NGACTIONATTR:ACTIONNAME="gjmy_CmddefQos",ATTRNAME="arp",TYPE=Reference ActionGroup,VALUE="gjmy_cmdarp";

ADD NGACTIONATTR:ACTIONNAME="gjmy_AMBR",ATTRNAME="uplink",TYPE=Value,VALUE="1000 Kbps";
ADD NGACTIONATTR:ACTIONNAME="gjmy_AMBR",ATTRNAME="downlink",TYPE=Value,VALUE="1000 Kbps";

ADD NGACTIONATTR:ACTIONNAME="gjmy_CmdAMBR",ATTRNAME="uplink",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQosAmbrUplink";
ADD NGACTIONATTR:ACTIONNAME="gjmy_CmdAMBR",ATTRNAME="downlink",TYPE=Object Attribute,VALUE="SmfSession.VPlmnQosAmbrDownlink";

ADD NGACTIONATTR:ACTIONNAME="gjmy_SessAction",ATTRNAME="authDefQos",TYPE=Reference ActionGroup,VALUE="gjmy_defQos";
ADD NGACTIONATTR:ACTIONNAME="gjmy_SessAction",ATTRNAME="authSessAmbr",TYPE=Reference ActionGroup,VALUE="gjmy_AMBR";
ADD NGACTIONATTR:ACTIONNAME="gjmy_SessAction",ATTRNAME="sessRuleId",TYPE=Value,VALUE="gjmy_SessAction_1";

ADD NGACTIONATTR:ACTIONNAME="gjmy_CmdSessAction",ATTRNAME="authDefQos",TYPE=Reference ActionGroup,VALUE="gjmy_CmddefQos";
ADD NGACTIONATTR:ACTIONNAME="gjmy_CmdSessAction",ATTRNAME="authSessAmbr",TYPE=Reference ActionGroup,VALUE="gjmy_CmdAMBR";

ADD RULE:RULENAME="gjmy_SR",TYPE=Smf Session Rule 5G,RELATION=AND;
ADD RULE:RULENAME="gjmy_CmdSR",TYPE=Smf Session Rule 5G,RELATION=AND;
ADD RULENGACTION:RULENAME="gjmy_SR",ACTIONNAME="gjmy_SessAction";
ADD RULENGACTION:RULENAME="gjmy_CmdSR",ACTIONNAME="gjmy_CmdSessAction";
ADD POLICY:POLICYNAME="gjmy_5GPCC",TYPE=N7 Policy;
ADD POLICYRULE:POLICYNAME="gjmy_5GPCC",RULENAME="gjmy_SR";
ADD POLICYRULE:POLICYNAME="gjmy_5GPCC",RULENAME="gjmy_CmdSR";
ADD POLICYTRIGGER:POLICYNAME="gjmy_5GPCC",TRIGGERNAME="IPCAN_EST";
ADD SERVICE:SERVICENAME="gjmy_5GPCC",SERVICETYPE=VALUE_ADDED_SERVICE,SP="default1",ISMETERTOBASIC=Yes,ACTIVATEDBY=PCEF,PRECEDENCE=0,QOSMODE=Replace,SUBSCRIPTIONFORCED=Yes,PROBILLDATE=No,QUOTAALLOCATIONMODE=None,ISSETSHAREDMODE=No,RESUBSCRIPTIONOPERATION=NULL,ISGROUPSERVICE=No,ISTEMPLATE=No,ISRECUSRLOC=No,APNMATCHTYPE=Full Matching,HASBASESERVICE=No,ADDONLEVEL=Exhaust,CALCVALIDFORDYNSUBGROUP=No;
ADD SERVICEPOLICY:SERVICENAME="gjmy_5GPCC",POLICYNAME="gjmy_5GPCC";
```
