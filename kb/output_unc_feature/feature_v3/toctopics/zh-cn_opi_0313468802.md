# 检查SMSF链路状态

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

通过检查SMSF的链路状态，确保SMSF与其他NF间交互链路正常，保证SMSF正常提供业务。

## 必备事项

前提条件

操作人员已经登录OM Portal或U2020/MAE。

数据

该操作无需准备数据。

## 操作步骤

1. 通过**DSP SBILINKSTATUS**命令检查SMSF作为服务端和客户端时的服务化接口链路状态。

   ```
   DSP SBILINKSTATUS: ENTITYTYPE=Client, PEERNFINSTID="123e4444-e22b-11d2-a345-446655440000";
   DSP SBILINKSTATUS: ENTITYTYPE=Server;
   ```

   * 预期结果：“链路状态”为“正常”。
   * 非预期结果：“链路状态”为非“正常”，执行3。
2. 通过**DSP M3LNK**命令查询LINK链路实时状态。

   ```
   DSP M3LNK: SRT=ALL;
   ```

   * 预期结果：“链路状态”为“激活”。
   * 非预期结果：“链路状态”为非“激活”，执行3。
3. 检查结果不符合预期，请收集告警信息、日志信息和配置信息，并联系华为技术支持处理。
