# 媒体中继UPF选择配置

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

本操作指导完成媒体中继UPF选择中SMF侧的业务配置。

## 必备事项

前提条件

* 请仔细阅读媒体中继UPF选择原理、媒体中继UPF选择场景。
* 完成SMF和UPF的N4接口配置，具体请参考《UNC 产品文档》：初始配置 > UNC初始配置与调测中各接口配置。
* 媒体中继业务的规则名已全网统一规划。

数据

假设UPF Pool中同时存在如下UPF

| UPF实例 | 支持业务 | 优先级 |
| --- | --- | --- |
| upf\_instance\_0（普通UPF） | 内容计费业务 | 高 |
| upf\_instance\_1（双域UPF） | 双域+普通内容计费业务 | 中 |
| upf\_instance\_2（智能+双域UPF） | 智能面+双域业务 | 低 |
| upf\_instance\_3（媒体中继+智能+双域UPF） | 媒体中继+双域+智能面业务 | 低 |

## 操作步骤

配置选择媒体中继UPF（PCF通过pccRules信元下发UPF选择规则）

1. 进入“MML命令行-UNC”窗口。
2. 配置SMF支持基于用户签约选择媒体中继UPF。

   ```
   ADD APNSMCOMFUNC: APN="huawei.com", GETPOLICYFIRST=ENABLE;
   ```
3. 配置业务策略规则。

   ```
   ADD RULE:RULENAME="relayrule", POLICYTYPE=NON_SPECIFIC_TYPE;
   ADD USERPROFILE: USERPROFILENAME="testuserprofilename", UPTYPE=UPSELECT, RELAYSW=ENABLE;
   ADD RULEBINDING: USERPROFILENAME="testuserprofilename", RULENAME="relayrule", POLICYTYPE=NON_SPECIFIC_TYPE;
   ```
4. 配置UPF选择规则信息。

   ```
   ADD SELECTRULEINFO: RULENAME="testuserprofilename", RULEFUNC=QOSANA-0&QOSEXP-0&QOSCCC-0&RELAY-1, DELIVERSW=ENABLE, RULERANGE=CENTRAL;
   ```
5. 配置用户面支持媒体中继业务。upf\_instance\_3支持媒体中继业务。

   ```
   ADD UPFBINDSELRULE: INDEX=0, NFINSTANCENAME="upf_instance_3", RULENAME="testuserprofilename";
   ```
6. 配置在PFCP Session Establishment Request和PFCP Session Modification Request消息中携带私有信元ActivatedFeatureRule/DeactivatedFeatureRule。

   ```
   SET PFCPPVTEXT: FEATURE=Feature_Rule, SWITCH=ENABLE;
   ```

配置选择媒体中继UPF（PCF通过upfSelectRules信元下发UPF选择规则）

1. 进入“MML命令行-UNC”窗口。
2. 配置SMF支持基于用户签约选择媒体中继UPF。

   ```
   ADD APNSMCOMFUNC: APN="huawei.com", GETPOLICYFIRST=ENABLE;
   ```
3. 配置UPF选择规则信息。

   ```
   ADD SELECTRULEINFO: RULENAME="select_relay_upf", RULEFUNC=QOSANA-0&QOSEXP-0&QOSCCC-0&RELAY-1, DELIVERSW=ENABLE, RULERANGE=CENTRAL;
   ```
4. 配置规则和UPF的绑定关系。upf\_instance\_3支持媒体中继业务。

   ```
   ADD UPFBINDSELRULE: INDEX=1, NFINSTANCENAME="upf_instance_3", RULENAME="select_relay_upf";
   ```
5. 配置在PFCP Session Establishment Request和PFCP Session Modification Request消息中携带私有信元ActivatedFeatureRule/DeactivatedFeatureRule。

   ```
   SET PFCPPVTEXT: FEATURE=Feature_Rule, SWITCH=ENABLE;
   ```
6. 配置业务策略规则。标识媒体中继业务相关的预定义规则。

   ```
   ADD RULE:RULENAME="relayrule", POLICYTYPE=NON_SPECIFIC_TYPE;
   ADD USERPROFILE: USERPROFILENAME="testuserprofilename", UPTYPE=PCC, PROFILERANGE=CENTRAL;
   ADD RULEBINDING: USERPROFILENAME="testuserprofilename", RULENAME="relayrule", POLICYTYPE=NON_SPECIFIC_TYPE;
   ```
