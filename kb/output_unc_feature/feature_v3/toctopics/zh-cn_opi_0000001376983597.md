## 操作场景

本操作指导介绍在运行网络中激活负荷动态调整特性的操作过程。

适用于GGSN、SGW-C、PGW-C、SMF。

## 必备事项

前提条件

请仔细阅读WSFD-010005 负荷动态调整特性概述。

## 操作流程

请按照操作步骤的顺序进行操作。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 设置服务类型为USM\_0的微服务的Token分配权重管理策略为动态策略。

   **SET TOKENALLOCWT**
3. 设置服务类型为USM\_0的微服务的动态权重调整相关参数。

   **SET DYNAMICPOLICY**
4. 增加不同CPU类型的能力系数和基础消耗。

   **ADD CPUABILITYCFG**

## 任务示例

任务描述

设置服务类型为USM\_0的微服务的Token分配权重管理策略为动态策略和动态权重调整相关参数，使USM的Pod实例间CPU负荷差异超过阈值时，系统进行动态负荷调整。

脚本

//设置服务类型为USM\_0的微服务的Token分配权重管理策略为动态策略。

```
SET TOKENALLOCWT:SERVICETYPE=USM_0,WEIGHTPOLICY=DYNAMIC;
```

//设置服务类型为USM\_0的微服务的动态权重调整相关参数。

```
SET DYNAMICPOLICY: SERVICETYPE=USM_0, ADJUSTTHRESHOLD=75, GAPTHRESHOLD=6, GLBBASEOST=5, GAPBUSY=10, CONFIRM=Y;
```

//（可选）增加不同CPU类型的能力系数和基础消耗。

```
ADD CPUABILITYCFG: CPUTYPE=X86_64, CPUGENERATE="1", CPUFREQUENCY=2, COEFFICIENT=500, BASECOST=0, CONFIRM=Y;
```
