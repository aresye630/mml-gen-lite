# 检查NRF系统状态

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

通过检查虚拟机的资源单元的状态，检查微服务的容器状态以及进程状态，来确保NRF运行正常。

## 必备事项

前提条件

操作人员已经登录OM Portal或U2020/MAE。

数据

该操作无需准备数据。

## 操作步骤

1. 通过**DSP PODINFO**命令查询已部署的Pod实例信息，是否与实际规划一致。

   * 预期结果：与实际规划一致。
   * 非预期结果：执行5。
2. 通过**DSP RU**命令查看资源单元信息。

   * 预期结果：“运行状态”为“正常”。
   * 非预期结果：执行5。
3. 通过**DSP MSPROCESS**命令查询NRF微服务的进程状态：

   ```
   DSP MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_NFM";
   ```

   ```
   DSP MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_DISC";
   ```

   ```
   DSP MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_AUTH";
   ```

   * 预期结果：“进程状态”均为“就绪状态”或“正常状态”。
   * 非预期结果：“进程状态”为“未知状态”或“异常状态”，执行5。
4. 根据实际情况每天不定时对以下项目进行选择观察：

   1929471512 NF注册成功率

   1929471513 NF更新成功率

   1929471514 NF订阅成功率

   1929471850 NF服务发现成功率

   * 预期结果：上述指标值接近100%且稳定。
   * 非预期结果：上述指标值出现突降，或存在远小于100%的取值，执行5。
5. 检查结果不符合预期，请收集告警信息、日志信息和配置信息，并联系华为技术支持处理。
