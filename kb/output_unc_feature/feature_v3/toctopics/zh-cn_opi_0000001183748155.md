## 操作场景

运营商无需GGSN/P-GW承担Proxy的作用，需要去激活GGSN/P-GW信令代理特性。

适用于GGSN、PGW-C

## 对系统的影响

去激活GGSN/P-GW信令代理特性时，如果有用户正在使用该功能，则这些用户将无法激活，导致业务处理异常。所以建议在无用户使用该功能时进行该操作。

## 必备事项

前提条件

* 请仔细阅读WSFD-205107 GGSN/P-GW信令代理。
* 完成激活GGSN/P-GW信令代理
* 已在本地备份配置文件。

## 操作步骤

1. 以下命令在“MML命令行 - UNC”窗口上执行。关闭本特性的License配置开关。

   **SET LICENSESWITCH**:LICITEM=LKV3W9GPSP11,SWITCH=DISABLE;
2. 删除Home group与APN的绑定关系。**RMV HOMEGRPBINDAPN**:APN=APN，HOMEGROUPINDX=Home group的编号；
3. 关闭网关的Proxy功能  
   **SET GWPROXYFUNC**:PROXYSW=网关Proxy开关；
4. 删除在Home group下配置的归属P-GW的IP地址。

   **RMV HOMEIP**:HOMEGROUPINDX=组号；
5. 删除Home group。

   **RMV HOMEGROUP**:HOMEGROUPINDX=home group的编号；
6. **可选：**删除将要对其进行信令代理操作IMSI/MSISDN号码段和号码段组。

   1. 删除IMSI/MSISDN号码段。

      **RMV PRIMSIMSISDNSEG**:SEGMENTNAME=IMSI/MSISDN号段名称；
   2. 删除IMSI/MSISDN号码段组。

      **RMV PRIMSIMSISDNG**:SEGGROUPNAME=IMSI/MSISDN号段组名称；
7. **可选：**删除将要对其进行信令代理操作的计费属性信息。

   1. 删除指定计费属性组的计费属性值。

      **RMV CCVALUE**: CCGROUPNAME=计费特征组名称;
   2. 删除计费属性组。

      **RMV CCGROUP**: CCGROUPNAME=计费特征组名称;
8. 关闭APN的proxy功能。  
   **RMV APNGWPROXYFUNC**:APN=APN，PROXYSW=网关Proxy开关；

## 验证方法

查询GGSN/P-GW信令代理功能是否关闭。

**LST APNGWPROXYFUNC**

```
LST APNGWPROXYFUNC:APN="apn-test";
```

```
APN网关Proxy功能参数 
------------------------------------                  
                                           APN  =  apn-test          
                          网关Proxy开关  =  不使能 
(结果个数 = 1) 
---    END
```

## 任务示例

任务描述

去激活指定APN的GGSN/P-GW信令代理功能。

脚本

1. 关闭本特性的License开关。

   ```
   SET LICENSESWITCH:LICITEM=LKV3W9GPSP11,SWITCH=DISABLE;
   ```
2. 删除Home group与APN的绑定关系。

   ```
   RMV HOMEGRPBINDAPN:APN="apn-test",HOMEGROUPINDX=1;
   ```
3. 关闭网关的proxy功能。

   ```
   SET GWPROXYFUNC:PROXYSW=DISABLE;
   ```
4. 删除在Home group下配置的归属P-GW的IP地址。

   ```
   RMV HOMEIP:HOMEGROUPINDX=1;
   ```
5. 删除Home group。

   ```
   RMV HOMEGROUP:HOMEGROUPINDX=1;
   ```
6. 可选：删除将要对其进行信令代理操作IMSI/MSISDN号码段和号码段组。

   ```
   RMV PRIMSIMSISDNSEG:SEGMENTNAME="msisdn-test";
   ```

   ```
   RMV PRIMSIMSISDNG:SEGGROUPNAME="group-test";
   ```
7. 可选：删除将要对其进行信令代理操作的计费属性信息。

   ```
   RMV CCVALUE:CCGROUPNAME="cc_group1";
   ```

   ```
   RMV CCGROUP:CCGROUPNAME="cc_group1";
   ```
8. 关闭APN的proxy功能。

   ```
   RMV APNGWPROXYFUNC:APN="apn-test",PROXYSW=DISABLE;
   ```
