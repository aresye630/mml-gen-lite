# 配置和SMSC对接（直连）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

SMSF与SMSC之间采用M3UA进行通信，寻址方式为DPC。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* UNC软件安装已完成。
* 已经获取网设LLD文档。

数据

本文以IPv4组网为例说明。

* 如果是IPv6组网，请将逻辑接口地址规划为IPv6地址。
* 如果是IPv4v6双栈组网，则对逻辑接口配置双栈地址即可。

**如下数据仅为举例，请注意修改成局点规划的数据。**

**表1** SMSF本端信息

| 类别 | 数据规划 |
| --- | --- |
| SMSF业务接口IP地址（用于对接SMSC） | 10.2.180.1  10.2.180.2 |
| 本端端口 | 17171  17172 |
| SMSF在M3UA链路中的应用模式：服务端/客户端 | 客户端 |
| 本局信令点编码 | 0x017701  0x017702 |

**表2** SMSC信息

| 类别 | 数据规划 |
| --- | --- |
| SMSC业务接口IP地址 | 10.2.180.1  10.2.180.2 |
| SMSC端口 | 17171  17172 |
| SMSC在M3UA链路中的应用模式：服务端/客户端 | 服务端 |
| SMSC信令点编码 | 0x017701  0x017702 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 增加SMSF业务接口IP地址，用于和SMSC的对接。

   ```
   ADD SERVICEIP:IPVERSION=IPv4, SERVICEIPV4="10.2.180.1", VPNINSTNAME="VPN_SIG";
   ADD SERVICEIP:IPVERSION=IPv4, SERVICEIPV4="10.2.180.2", VPNINSTNAME="VPN_SIG";
   ```
3. 配置M3UA信令数据。

   1. 增加M3UA本地实体，信令点编码所在的网络为国内网，本地实体为ASP。

      ```
      ADD M3LE:LEX=1, NI=NAT, OPC="0x017701", LET=ASP, LEN="SMSF1";
      ADD M3LE:LEX=2, NI=NAT, OPC="0x017702", LET=ASP, LEN="SMSF2";
      ```
   2. 配置M3UA目的信令点。

      ```
      ADD M3DE:DEX=1, LEX=1, DPC="0x240011", SLSSM=B0000, STPF=DISABLE, DET=SP, ADJF=TRUE, NMD=EXCLUSIVE, PVER=RFC3332, DEN="SMSC1";
      ADD M3DE:DEX=2, LEX=1, DPC="0x240012", SLSSM=B0000, STPF=DISABLE, DET=SP, ADJF=TRUE, NMD=EXCLUSIVE, PVER=RFC3332, DEN="SMSC2";
      ```
   3. 配置到SMSC的M3UA信令链路集。

      ```
      ADD M3LKS:LSX=1, DEX=1, SLSM=B0011, WM=ASP, TM=LOADSHARE, LSN="SMSC1";
      ADD M3LKS:LSX=2, DEX=2, SLSM=B0011, WM=ASP, TM=LOADSHARE, LSN="SMSC2";
      ```
   4. 配置M3UA信令路由。

      ```
      ADD M3RT:RTX=1, DEX=1, LSX=1, PRI=0, RTN="SMSC1";
      ADD M3RT:RTX=2, DEX=2, LSX=2, PRI=0, RTN="SMSC2";
      ```
   5. 配置SCTP协议参数。

      ```
      ADD SCTPPARA:SCTPPARAINDEX=0, SCTPPARANAME="sctname", PKGERRFAULT=5, PKGERRRECOVER=3, MINRECVPKGNUM=100;
      ```
   6. 配置M3UA信令链路。

      ```
      ADD M3LNK:LNK=1, VPNNAME="VPN_SIG", IPT=IPV4, LOCIPV41="10.2.180.1", LOCIPV42="10.2.180.2", LOCPORT=17171, PEERIPV41="10.50.0.202", PEERIPV42="10.50.0.203", PEERPORT=17171, CS=C, LSX=1, ASF=ACT, PRI=0, CONSTHD=80, CONETHD=40, CROSSIP=NO, EXCHGMODE=SINGLE, LKN="To SMSC1", SCTPINDX=0;
      ADD M3LNK:LNK=2, VPNNAME="VPN_SIG", IPT=IPV4, LOCIPV41="10.2.180.2", LOCIPV42="10.2.180.1", LOCPORT=17172, PEERIPV41="10.50.0.203", PEERIPV42="10.50.0.202", PEERPORT=17172, CS=C, LSX=1, ASF=ACT, PRI=0, CONSTHD=80, CONETHD=40, CROSSIP=NO, EXCHGMODE=SINGLE, LKN="To SMSC1", SCTPINDX=0;
      ADD M3LNK:LNK=3, VPNNAME="VPN_SIG", IPT=IPV4, LOCIPV41="10.2.180.1", LOCIPV42="10.2.180.2", LOCPORT=17171, PEERIPV41="10.50.0.102", PEERIPV42="10.50.0.103", PEERPORT=17171, CS=C, LSX=2, ASF=ACT, PRI=0, CONSTHD=80, CONETHD=40, CROSSIP=NO, EXCHGMODE=SINGLE, LKN="To SMSC2", SCTPINDX=0;
      ADD M3LNK:LNK=4, VPNNAME="VPN_SIG", IPT=IPV4, LOCIPV41="10.2.180.2", LOCIPV42="10.2.180.1", LOCPORT=17172, PEERIPV41="10.50.0.103", PEERIPV42="10.50.0.102", PEERPORT=17172, CS=C, LSX=2, ASF=ACT, PRI=0, CONSTHD=80, CONETHD=40, CROSSIP=NO, EXCHGMODE=SINGLE, LKN="To SMSC2", SCTPINDX=0;
      ```
4. 配置SCCP信令数据。

   1. 配置SCCP本局信令点。
      * 适用于2/3G短消息。

        ```
        ADD SCCPOPC:OPX=1, NI=NAT, OPC="0x17701", SPN=COREONLY, SGSNN="861390211101", OPN="SMSF1";
        ADD SCCPOPC:OPX=2, NI=NAT, OPC="0x17702", SPN=COREONLY, SGSNN="861390311101", OPN="SMSF2";
        ADD MSCOPC: OPX=1, NI=NAT, OPC="0x17701", MSCN="861390211101", MASTER=YES;
        ADD MSCOPC: OPX=2, NI=NAT, OPC="0x17702", MSCN="861390311101", MASTER=YES;
        ```
      * 适用于5G短消息。

        ```
        ADD SCCPOPC: OPX=1, NI=NAT, OPC="0x17701", SPN=COREONLY, SGSNN="861390211101", OPN="SMSF1";
        ADD SCCPOPC: OPX=2, NI=NAT, OPC="0x17702", SPN=COREONLY, SGSNN="861390311101", OPN="SMSF2";
        ADD SMSFOPC: OPX=1, NI=NAT, OPC="0x17702", SMSFN="861390211101", OPN="SMSF1", MASTER=YES; 
        ADD SMSFOPC: OPX=2, NI=NAT, OPC="0x17702", SMSFN="861390311101", OPN="SMSF2", MASTER=YES;
        ```
   2. 配置SCCP目的信令点。

      ```
      ADD SCCPDPC:DPX=1, OPX=1, DPC="0x240011", SS7T=ITUT_SS7, LDP=BACKUP, BDPX=2, DPN="SMSC1";
      ADD SCCPDPC:DPX=2, OPX=1, DPC="0x240012", SS7T=ITUT_SS7, LDP=BACKUP, BDPX=1, DPN="SMSC2";
      ```
   3. 配置SCCP本局子系统。

      ```
      ADD SCCPSSN:SSNX=1, SSN=SCMG, NI=NAT, DPC="0x017701", OPC="0x017701", SSNNAME="SGSN_BER1-SSN";
      ADD SCCPSSN:SSNX=2, SSN=MSC, NI=NAT, DPC="0x017701", OPC="0x017701", SSNNAME="SGSN internal";
      ```
   4. 配置对端SMSC的SCCP子系统。

      ```
      ADD SCCPSSN:SSNX=5, SSN=SCMG, NI=NAT, DPC="0x240011", OPC="0x017701", SSNNAME="SCMG-SSN1";
      ADD SCCPSSN:SSNX=6, SSN=SCMG, NI=NAT, DPC="0x240012", OPC="0x017701", SSNNAME="SCMG-SSN2";
      ```

      //如果SMSC需要使用SSN号寻址则需要配置下面的脚本。

      ```
      ADD SCCPSSN:SSNX=7, SSN=MSC, NI=NAT, DPC="0x240011", OPC="0x017701", SSNNAME="MSC-SSN1";
      ADD SCCPSSN:SSNX=8, SSN=MSC, NI=NAT, DPC="0x240012", OPC="0x017701", SSNNAME="MSC-SSN2";
      ```
   5. 配置SCCP层主叫地址中携带的SSN号。

      ```
      SET SMSFSSN: SSN=MSC;
      ```
5. 配置GT翻译数据。

   1. 配置本局SCCP GT翻译数据。

      ```
      ADD SCCPGT:GTX=1, NI=NAT, RT=DPC, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="861390211101", DPC="0x17701", NAME="SGSN_BER1-GT";
      ADD SCCPGT:GTX=2, NI=NAT, RT=DPC, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="861390311101", DPC="0x17701", NAME="SGSN_BER1-GT";
      ```
   2. 配置SMSC的SCCP GT翻译数据。

      ```
      ADD SCCPGT:GTX=3, NI=NAT, RT=DPCGT, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="86139177010000", DPC="0x240011", NAME="SMSC";
      ADD SCCPGT:GTX=4, NI=NAT, RT=DPCGT, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="86139177010001", DPC="0x240011", NAME="SMSC";
      ```
