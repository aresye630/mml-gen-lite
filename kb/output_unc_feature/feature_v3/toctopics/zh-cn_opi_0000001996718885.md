# 安装后检查

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

检查资源单元的状态，确保设备运行正常。

## 必备事项

前提条件

已经登录OM Portal，或者已登录U2020，或者登录MAE并进入Access子系统。

数据

该操作无需准备数据。

* 检查是否已安装Core Master工具，且已经完成网元与网管的对接。
* 如已安装Core Master工具，通过Core Master工具进行安装后检查，并查看Core Master检查结果详情，预期“检查结果”为“通过”。如果“检查结果”为“不通过”，可参见“详情”中的“修复建议”进行修复，如果“检查结果”为“人工核查”，可参见“详情”进行检查。
* Core Master工具的安装操作请参见Core Master用户指南，获取方式如下：登录华为Support网站，依次选择：技术支持>产品支持>运营商服务与软件>网络部署与集成服务>电信网络云化集成与优化服务>云核心网集成服务>Core Master OP。
* Core Master工具检查操作请参见Core Master联机帮助，获取方式如下：登录Core Master，在“单工具任务”区域单击“单工具任务 > 采集/检查/数据转换/部署执行工具”，进入任务管理界面。单击“新建任务”，选择“应用类型”和“子应用类型”为“检查评估”，填写“任务名称”，单击右上角。
* 如未安装Core Master工具，则需执行如下步骤。

## 操作步骤

1. 在UNC OM portal，选择“监控分析 > 告警管理 > 活动告警”，查看系统是否上报如下告警，如果上报则处理相应告警。

   * ALM-221257768 资源单元故障告警
   * ALM-221257751 进程故障告警
   * ALM-221257752 资源进程故障
   * ALM-100145 实例化部分失败
   * ALM-100001 进程故障告警
2. 当MAE-VNF LCM为V100R024C10及之前版本时，查询VNFM鉴权用户名及密码有效期。
   1. 通过**LST VNFMINFO**命令查询VNFM鉴权用户名。
   2. 登录MAE-VNF LCM业务面客户端，单击图标，选择“系统 >安全管理 > 用户管理 > 用户”。
   3. 单击目标用户，在“基本信息”页签中，单击“修改”，单击“高级设置”，查询“密码有效天数”。

      预期结果：“密码有效天数”为“0”。

      异常结果：“密码有效天数”为其他值。请勾选“启用密码修改时间策略”，设置“密码有效天数”为“0”，单击“确定”，将该用户密码设置为永不过期。
