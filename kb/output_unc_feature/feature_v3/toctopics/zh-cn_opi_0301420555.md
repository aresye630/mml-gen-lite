# 激活下行数据通知信令抑制功能（SGW-C）

## 操作场景

短时间内SGW-C向MME发送大量DDN消息会触发MME交互大量的寻呼信令，在SGW-C上激活下行数据通知信令抑制功能，从而达到保护MME的目的。

适用于SGW-C。

## 必备事项

前提条件

请仔细阅读WSFD-010803 下行数据通知信令抑制（适用于SGW-C）特性概述。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET DDNTHROTTLING** | DDN Throttling功能开关（DDNThrotswitch） | ENABLE | 本端规划 | 设置DDN Throttling开关。 |
| **ADD DDNPRIORITYARP** | ARP数值（ARP） | 1  2  3 |  | 添加DDN消息的ARP优先级规则。 |
|  | 优先级（PRIORITY） | DDN\_HIGH |  |  |
| **ADD DDNPRIORITYAPN** | APN名称（APN） | ims |  | 设置DDN消息的APN优先级规则。 |
|  | 优先级（PRIORITY） | DDN\_HIGH |  |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开DDN Throttling开关。

   **SET DDNTHROTTLING**
3. 配置高优先级DDN消息的ARP。

   **ADD DDNPRIORITYARP**
4. 配置高优先级DDN消息的APN。

   **ADD DDNPRIORITYAPN**

## 任务示例

任务描述

使能DDN Throttling功能并配置高优先级DDN消息的ARP和APN。

脚本

//使能DDN Throttling功能。

```
SET DDNTHROTTLING: DDNTHROTSWITCH=ENABLE;
```

//配置高优先级DDN消息的ARP为**1**、**2**、**3**。

```
ADD DDNPRIORITYARP: ARP=1,PRIORITY=DDN_HIGH;
```

```
ADD DDNPRIORITYARP: ARP=2,PRIORITY=DDN_HIGH;
```

```
ADD DDNPRIORITYARP: ARP=3,PRIORITY=DDN_HIGH;
```

//配置高优先级DDN消息的APN为**ims**。

```
ADD DDNPRIORITYAPN: APN="ims",PRIORITY=DDN_HIGH;
```
