## 操作场景

本章节指导如何开启内生安全的特性License配置开关。

适用于AMF、SMF、NSSF。

## 必备事项

前提条件

* 请仔细阅读内生安全概述、WSFD-219002 OS面入侵检测、WSFD-219003 恶意文件检测、WSFD-219004 资产风险管理和WSFD-219005 微隔离。
* 完成加载License。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（LICITEM） | * LKV2OSDFUNC01 * LKV2MFDFUNC01 * LKV2ARMFUNC01 * LKV2MSFUNC01 | 本端规划 | 开启内生安全的特性License配置开关。 |
|  | 开关（SWITCH） | ENABLE | 本端规划 |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 开启内生安全的特性License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

开启内生安全的特性License配置开关。

脚本

//开启内生安全的特性License配置开关。

//（可选）开启WSFD-219002 OS面入侵检测的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2OSDFUNC01", SWITCH=ENABLE;
```

//（可选）开启WSFD-219003 恶意文件检测的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2MFDFUNC01", SWITCH=ENABLE;
```

//（可选）开启WSFD-219004 资产风险管理的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2ARMFUNC01", SWITCH=ENABLE;
```

//（可选）开启WSFD-219005 微隔离的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2MSFUNC01", SWITCH=ENABLE;
```
