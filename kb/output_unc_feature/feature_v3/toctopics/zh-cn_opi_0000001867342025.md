## 操作场景

UNC支持配置在不同类型终端接入不同网络时选择计费接口，计费接口选择有三种方式，优先级从高到低为：基于用户漫游属性选择计费接口 （对应指令为**ADD ROAMCHGMODE**）> 基于APN/DNN选择计费接口 （对应指令为**ADD APNCHGMODE**）> 全局配置计费接口（对应指令为**SET CHGMODE**）。图1绘制了不同类型终端接入不同网络时计费接口选择。

**图1** 不同类型终端接入不同网络时计费接口选择逻辑图

SGW独立部署的场景下，需要SGW发起计费会话。在这种场景下，通过设置SGW上**ADD ROAMCHGMODE**/**ADD APNCHGMODE**/**SET CHGMODE**指令中“FORSGWONLY”的值可以手动指定计费接口。

UNC支持配置在不同类型终端接入不同网络时选择策略接口，策略接口选择有两种方式，优先级从高到低为：基于APN/DNN选择策略接口 > 全局配置策略接口。图2绘制了不同类型终端接入不同网络时策略接口选择。

**图2** 不同类型终端接入不同网络时策略接口选择逻辑图

当UNC上述计费接口和策略接口决策下，需要基于PCF实例标识调整用户最终使用的计费接口时，可以通过**ADD PCCCHGMODEBYPCFID**命令配置。此时，用户的计费接口类型以**ADD APNCHGMODE**或**SET CHGMODE**为初选结果，在此基础上，可以通过本命令决策是否由N40回落GaGy，或者是否由GaGy升级为N40。

适用于GGSN、PGW-C、SMF。

## 操作步骤

1. 配置在不同类型终端接入不同网络时所选择的计费接口。

   **SET CHGMODE**
2. **可选：**配置不同的APN/DNN在不同类型终端接入不同网络时所选择的计费接口。

   **ADD APNCHGMODE**
3. **可选：**配置不同漫游类型在不同类型终端接入不同网络时所选择的计费接口。

   **ADD ROAMCHGMODE**
4. 配置策略接口的选择方式。

   **SET POLICYMODE**
5. **可选：**配置基于APN/DNN的策略接口的选择方式。

   **ADD APNPOLICYMODE**
6. **可选：**配置基于PCF的计费接口和策略接口类型。

   **ADD PCCCHGMODEBYPCFID**

## 任务示例

任务描述

任务一：配置在不同类型终端接入不同网络时所选择的计费接口：

* 5G终端接入4G网络时，PGW-C使用Nchf接口模式；
* 5G终端接入5G网络时，SMF使用Nchf接口模式；UNC作为V-SMF角色时，也使用Nchf模式；UNC作为I-SMF时不进行计费；
* 非5G终端接入4G网络时，在PGW-C使用GaGy接口模式；
* 终端接入2G网络、3G网络时，GGSN使用GaGy接口模式；
* NB-IoT终端以及LTE-M终端接入时，PGW-C使用GaGy接口模式。

任务二：配置对于APN为ap-test的5G终端接入4G网络时，PGW-C根据5GS互操作标识的取值来选择计费接口。

任务三：配置对于全局的漫游用户，在使用5G终端接入4G网络时，PGW-C使用Nchf计费接口。

任务四：配置全局指定5G终端4G接入的策略接口为Npcf接口，非5G终端4G接入的策略接口为Npcf接口，2G接入、NB-IoT终端接入、LTE-M终端接入、用户从非3GPP网络接入和3G接入的策略接口为Gx接口。

任务五：配置基于APN/DNN的指定5G终端4G接入的策略接口为Npcf接口。

脚本

**任务一**

//配置在不同类型终端接入不同网络时所选择的计费接口。

```
SET CHGMODE:TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=False, FORCED=NchfMode;
SET CHGMODE:TMACCTYPE=UE5G_RAT5G, FORCED=NchfMode, FORVSMFONLY=NchfMode, ISMFCHGSW=DISABLE;
SET CHGMODE:TMACCTYPE=UENON5G_RAT4G, BYIWKUEN5GR4G=False, FORCED=GaGyMode;
SET CHGMODE:TMACCTYPE=RAT2G, FORCED=GaGyMode;
SET CHGMODE:TMACCTYPE=RATNBIOT, FORCED=NchfMode;
SET CHGMODE:TMACCTYPE=NON_3GPP, FORCED=GaGyMode;
SET CHGMODE:TMACCTYPE=RATLTEM, FORCED=GaGyMode;
SET CHGMODE:TMACCTYPE=RAT3G, FORCED=GaGyMode;
```

**任务二**

//配置对于APN为ap-test的5G终端接入4G网络时，PGW-C根据5GS互操作标识的取值来选择计费接口。

```
ADD APNCHGMODE:APN="apn-test", TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=True;
```

**任务三**

//配置对于全局的漫游用户，在使用5G终端接入4G网络时，PGW-C使用Nchf计费接口。

```
ADD ROAMCHGMODE:TMACCTYPE=UE5G_RAT4G, CTRLTYPE=GLOBAL_LEVEL, ROAMINGTYPE=ROAMING, BY5GSIWKI=False, FORCED=NchfMode;
```

**任务四**

//配置全局指定5G终端4G接入的策略接口为Npcf接口，非5G终端4G接入的策略接口为Npcf接口，2G接入、NB-IoT终端接入、LTE-M终端接入、用户从非3GPP网络接入和3G接入的策略接口为Gx接口。

```
SET POLICYMODE:TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=DISABLE, FORCED=Npcf, PCFRESELBYPCFID=FALSE;
SET POLICYMODE:TMACCTYPE=UENON5G_RAT4G, FORCED=Npcf, PCFRESELBYPCFID=FALSE, BYIWKUEN5GR4G=DISABLE;
SET POLICYMODE:TMACCTYPE=RAT2G, FORCED=Gx, PCFRESELBYPCFID=FALSE;
SET POLICYMODE:TMACCTYPE=RATNBIOT, FORCED=Gx, PCFRESELBYPCFID=FALSE;
SET POLICYMODE:TMACCTYPE=NON_3GPP, FORCED=Gx, PCFRESELBYPCFID=FALSE;
SET POLICYMODE:TMACCTYPE=RATLTEM, FORCED=Gx, PCFRESELBYPCFID=FALSE;
SET POLICYMODE:TMACCTYPE=RAT3G, FORCED=Gx, PCFRESELBYPCFID=FALSE;
```

**任务五**

//添加APN/DNN策略接口选择方式，指定5G终端4G接入的策略接口为Npcf。

```
ADD APNPOLICYMODE:APN="apn-test", TMACCTYPE=UE5G_RAT4G, BY5GSIWKI=DISABLE, FORCED=Npcf;
```
