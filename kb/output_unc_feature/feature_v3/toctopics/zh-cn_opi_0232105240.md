# 检查补丁状态

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该操作是对已经安装好的补丁进行全面检查，以确认补丁的运行状态是否正常。

## 必备事项

前提条件

已经登录OM Portal，或者已登录U2020，或者登录MAE并进入Access子系统。

数据

该操作无需准备数据。

## 操作步骤

1. 通过执行****DSP ACSPATCHINFO****命令查看当前系统中已有补丁的状态以及生效时间。

   预期结果：“补丁状态”为“运行”。
2. 如果检查结果不符合预期，请查看是否存在补丁相关告警并处理。
3. 如果告警处理完毕后，运行状态仍然不符合预期，请收集相关信息并联系华为技术支持处理。
