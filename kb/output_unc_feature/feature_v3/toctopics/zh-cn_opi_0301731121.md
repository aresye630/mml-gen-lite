# 配置话单可靠性保证（SGSN）

## 操作场景

本操作指导介绍在运行网络中激活话单可靠性保证功能的操作过程。

计费中心的计费依据是用户的话单记录，SGSN要保证话单无重复、无丢失和内容真实、可靠，从而来保证计费的准确性、可靠性和实时性。

适用于SGSN。

## 必备事项

前提条件

* 请仔细阅读离线计费话单（SGSN）。
* 无特殊前提条件。

数据

| 相关命令 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET CHGCDR** | 配置本地话单序列号（LRSNP） | PRESENT | 全网规划 | 本地话单序列号 |
| **SET CHGGA** | 硬盘空间不足门限(%)（HDDFSL） | 90 |  | 硬盘话单文件覆盖功能 |
|  | 覆盖硬盘上话单文件（CDROVERWRITE） | YES |  |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置本地话单序列号。

   **SET CHGCDR**

   参数“LRSNP”（配置本地话单序列号）固定选择“PRESENT”（有）。
3. 配置硬盘话单文件覆盖功能。

   **SET CHGGA**

   参数“CDROVERWRITE”（覆盖硬盘上话单文件）固定选择“YES”（覆盖）。

## 任务示例

任务描述

为用户配置本地话单序列号和硬盘话单文件覆盖功能。

脚本

//配置本地话单序列号。

```
SET CHGCDR:LRSNP=PRESENT;
```

//配置硬盘话单文件覆盖功能。

```
SET CHGGA:HDDFSL=90,CDROVERWRITE=YES;
```
