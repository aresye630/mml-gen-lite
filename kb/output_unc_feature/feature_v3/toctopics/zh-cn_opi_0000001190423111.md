# 激活基于PCF的VoNR业务快速恢复

* 操作场景
* 必备事项
* 操作步骤
* 任务示例

## 操作场景

在UNC上激活基于PCF的VoNR业务快速恢复功能，降低P-CSCF服务器故障时，对用户业务的影响。

适用于SMF。

## 必备事项

前提条件

* 请仔细阅读WSFD-221003 基于PCF的VoNR业务快速恢复特性概述。
* 完成激活P-CSCF故障时IMS业务恢复。
* 已完成加载License。

数据

该操作无需准备数据。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

开启基于PCF的VoNR业务快速恢复功能开关。

脚本

//进入“MML命令行-UNC”窗口。

//打开本特性的License配置开关。

```
SET LICENSESWITCH:ITEM="LKV2FRVNRPCF01",SWITCH=ENABLE;
```
