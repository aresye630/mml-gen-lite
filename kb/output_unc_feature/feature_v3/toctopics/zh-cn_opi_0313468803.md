# SMSF本局数据配置

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

配置SMSF本局数据。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* UNC软件安装已完成。
* 已经获取网设LLD文档。

数据

该操作无需准备数据。

文档

获取网设LLD文档。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置运营商基础信息。

   1. 增加运营商信息。

      ```
      MOD NGMNO:NOID=0, FULLNAME="Operator A", SHORTNAME="OA";
      ```
   2. 配置运营商签约用户的Home PLMN信息，用于识别用户是否为本网签约用户。

      ```
      ADD NGHPLMN: NOID=0, MCC="123", MNC="03";
      ```
   3. 配置运营商的Serving PLMN信息。

      ```
      ADD NGSRVPLMN: PLMNIDX=0, NOID=0, MCC="123", MNC="03";
      ```
