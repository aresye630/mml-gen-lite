## 操作场景

本操作用于指导在专网UPF上开启通用DNN漫游分流特性。

## 必备事项

前提条件

已参考运营商配置规范完成网元的基本配置。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET LICENSESWITCH** | License项（LICITEM） | LKV3G5LALG01  LKV3G5MVCA01 | 本端规划 | 该参数用于指定需要开通的License项。 |
|  | 开关（SWITCH） | ENABLE | 本端规划 | 该参数用于表示License项的配置开关是否已经打开。 |
| **SET RTSDNNPARA** | IPv4 NAT ALG协议（NATALGPROTV4） | FTP-1&RTSP-1 | 本端规划 | 该参数用于指定系统是否开启通用DNN漫游分流特定协议类型NAT ALG的IPv4地址替换。 |
|  | IPv6 NAT ALG协议（NATALGPROTV6） | FTP-1 | 本端规划 | 该参数用于指定系统是否开启通用DNN漫游分流特定协议类型NAT ALG的IPv6 地址替换。 |
| **SET RTSDNNPARA** | 专网通用DNN漫游分流开关（PRIVATENETSW） | ENABLE | 本端规划 | 该参数用于指定系统是否开启专网的通用DNN漫游分流功能。 |

## 任务示例

任务描述

实现通用DNN漫游分流功能前，需开启特性开关，并打开需要支持的license开关。

脚本

1. （可选）当需要使用FTP访问、下载业务，或者RTSP协议类视频相关业务时，并已申请了该license，则需要开启轻量化ALG license开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5LALG01",SWITCH=ENABLE;
   SET RTSDNNPARA: NATALGPROTV4=FTP-1&RTSP-1, NATALGPROTV6=FTP-1;
   ```
2. 专网UPF是UEG产品时，需要开启通用DNN漫游分流的license开关。

   ```
   SET LICENSESWITCH:LICITEM="LKV3G5MVCA01",SWITCH=ENABLE;
   ```
3. 打开专网的通用DNN漫游分流功能开关。

   ```
   SET RTSDNNPARA:PRIVATENETSW= ENABLE;
   ```
