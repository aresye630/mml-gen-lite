## 操作场景

图1中，中心和两个地市各部署一个UPF，正常情况下地市1的用户按照位置区优先选择UPF1，地市2用户同理选择UPF2，图中LOCALITY1和LOCALITY2分别对应地市1和地市2的位置信息。UPF1或UPF2故障场景下的容灾方式如下：

* 当UPF1故障时，地市1的用户选择UPF2进行业务，当UPF2故障时，地市2的用户同理选择UPF1进行业务。
* 当UPF1和UPF2都故障后，两个地市的用户可以选择中心侧的UPF3进行业务。

该方案中上述UPF需要配置和地市1、地市2相关联的位置信息，SMF在用户会话激活过程中根据位置信息优选UPF。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. **SMF本端添加UPF**。

   **ADD PNFPROFILE**
3. **配置用户面支持的服务切片信息**。

   **ADD PNFNS**
4. **配置UPF的DNN属性**。

   **ADD PNFDNN**
5. **为UPF添加DNAI信息。**

   **ADD PNFDNAI**
6. **配置UPF的属性。**

   **ADD UPNODE**
7. **配置UPF服务区域。**

   * **配置用于SMF本端判定UPF归属区域的区域类型**。

     **ADD UPAREA**
   * **配置UPF归属区域对应的区域范围。**

     **ADD UPAREABINDN2TAI**
   * **SMF本端配置UPF所覆盖的区域**。

     **ADD PNFSMFSERAREA**
8. **配置UPF位置信息与该UPF优先支持的服务区的绑定关系。**

   **ADD LOCBINDAREA**
9. **打开UPF按位置区的优先级开关。**

   **SET UPSELECTFLAG**

## 任务示例

任务描述

如图1所示，UPF1和UPF2服务的区域为“1230320101”~“1230320111”和“1230320105”~“1230320115”。

UPF1、UPF2以及UPF3对应的UPF实例标志分别为UPF\_Instance\_1、UPF\_Instance\_2和UPF\_Instance\_3，对应的IP地址为192.168.126.11、192.168.126.12和192.168.126.13。

脚本

//**SMF本端添加UPF**。

```
ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered,FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11",LOCALITY="DataCenter1";
ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_2", NFTYPE=NfUPF, NFSTATUS=Registered,FQDN="upf02.node.mnc003.mcc123.3gppnetwork.org",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.12",LOCALITY="DataCenter2";
ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_3", NFTYPE=NfUPF, NFSTATUS=Registered,FQDN="upf03.node.mnc003.mcc123.3gppnetwork.org",IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.13";
```

//**配置用户面支持的服务切片信息**。

```
ADD PNFNS: INDEX=3, NFINSTANCEID="UPF_Instance_1", SST=1, SD="000001";
ADD PNFNS: INDEX=4, NFINSTANCEID="UPF_Instance_2", SST=1, SD="000001";
ADD PNFNS: INDEX=5, NFINSTANCEID="UPF_Instance_3", SST=1, SD="000001";
```

//**配置UPF的DNN属性**。

```
ADD PNFDNN:INDEX=3, NFINSTANCEID="UPF_Instance_1", DNN="Huawei1.com";
ADD PNFDNN:INDEX=4, NFINSTANCEID="UPF_Instance_2", DNN="Huawei1.com";
ADD PNFDNN:INDEX=5, NFINSTANCEID="UPF_Instance_3", DNN="Huawei1.com";
```

//**配置UPF的属性。**

```
ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", LOCATION=Central;
ADD UPNODE:NFINSTANCENAME="UPF_Instance_2", LOCATION=Central;
ADD UPNODE:NFINSTANCENAME="UPF_Instance_3", LOCATION=Central;
```

//**配置用于SMF本端判定UPF归属区域的区域类型**。

```
ADD UPAREA:AREANAME="UPAREA1", AREATYPE=N2TAI; 
ADD UPAREA:AREANAME="UPAREA2", AREATYPE=N2TAI;
```

//**配置UPF归属区域对应的区域范围。**

```
ADD UPAREABINDN2TAI:AREANAME="UPAREA1", N2BEGINTAI="1230320101", N2ENDTAI="123032011";
ADD UPAREABINDN2TAI:AREANAME="UPAREA2", N2BEGINTAI="1230330201", N2ENDTAI="1230330203";
```

//**SMF本端配置UPF所覆盖的区域**。

```
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA1";
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_2", SMFSERVINGAREA="UPAREA1";
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_3", SMFSERVINGAREA="UPAREA1";
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_1", SMFSERVINGAREA="UPAREA2";
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_2", SMFSERVINGAREA="UPAREA2";
ADD PNFSMFSERAREA:NFINSTANCEID="UPF_Instance_3", SMFSERVINGAREA="UPAREA2";
```

//**配置UPF位置信息与该UPF优先支持的服务区的绑定关系。**

```
ADD LOCBINDAREA: LOCALITY="DataCenter1",AREANAME="UPAREA1";
ADD LOCBINDAREA: LOCALITY="DataCenter2",AREANAME="UPAREA2";
```

//**打开UPF按位置区的优先级开关。**

```
SET UPSELECTFLAG: LOCALITYFLAG=ENABLE;
```
