# 配置N4接口对端UPF信息

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

配置N4接口对端UPF信息需要配置SMF为优先使用UPF分配地址、配置对端UPF节点、配置对端NF实例概述信息和配置UPF绑定到特定的IP Domain，同时需配置N4接口可靠性。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* 已经获取网设LLD文档。
* **SMF和UPF对接支持Full Mesh组网，若未申请对应license，可能仅支持一套SMF和一套UPF对接。如果涉及多套SMF和UPF互相对接，请提前完成加载“82209930 LKV2CUFMN01 CU FullMesh组网”License控制项。CU Full Mesh组网详细请参考WSFD-213001 CU FullMesh组网。**

## 操作步骤

1. **涉及多套SMF和UPF互相对接时，打开CU Full Mesh的License配置开关。如未来有计划规划Full Mesh组网，强烈建议执行该步骤，避免后续由于License申请和操作遗漏导致SMF和UPF对接失败。**

   ```
   SET LICENSESWITCH: LICITEM="LKV2CUFMN01",SWITCH=ENABLE;
   ```
2. 配置UE地址优先由UPF分配，如UPF未分配，则由SMF分配。

   ```
   SET ADDRESSATTR:ALLOCPRECEDENCE=UPF_FIRST;
   ```
3. 配置N4接口对端UPF\_Instance\_1~UPF\_Instance\_4的UPF节点。

   ```
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_1", LOCATION=Central, UPFUNCTION=None, VPNNAME="VRF_CP4";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_2", LOCATION=Central, UPFUNCTION=None, VPNNAME="VRF_CP6";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_3", LOCATION=Central, UPFUNCTION=None, VPNNAME="VRF_CP4";
   ADD UPNODE:NFINSTANCENAME="UPF_Instance_4", LOCATION=Central, UPFUNCTION=None, VPNNAME="VRF_CP6";
   ```
4. 配置N4接口对端UPF\_Instance\_1~UPF\_Instance\_4的PNFPROFILE。

   执行该命令会触发SMF向UPF发起建立PFCP偶连。

   ```
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_1", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf01.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.126.11", PORT=8080, CAPACITY=100, PRIORITY=50, LOCALITY="locality1"; 
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_2", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf02.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS1="fc00:39::2", PORT=8080, CAPACITY=100, PRIORITY=50, LOCALITY="locality1"; 
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_3", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf03.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="192.168.127.11", PORT=8080, CAPACITY=100, PRIORITY=50, LOCALITY="locality2"; 
   ADD PNFPROFILE:NFINSTANCEID="UPF_Instance_4", NFTYPE=NfUPF, NFSTATUS=Registered, FQDN="upf04.node.mnc003.mcc123.3gppnetwork.org", IPADDRESSTYPE=IPTypeV6, IPV6ADDRESS1="fc00:40::2", PORT=8080, CAPACITY=100, PRIORITY=50, LOCALITY="locality2";
   ```
5. **可选：**配置UPF绑定到特定的IP Domain，当该UPF给用户分配的地址时，SMF内部会在此地址前加上该IP Domain前缀，并带给PCF，用于扩展地址池。

   针对U面分配地址的场景，为了解决不同地址池的地址重叠问题时，需要将不同UPF/PGW-U绑到不同的IP Domain。

   ```
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_1", IPDOMAIN="upf12.node.mnc003.mcc123.3gppnetwork.org", DNNSWITCH=ENABLE, DNN="huawei.com"; 
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_2", IPDOMAIN="upf12.node.mnc003.mcc123.3gppnetwork.org", DNNSWITCH=ENABLE, DNN="huawei.com"; 
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_3", IPDOMAIN="upf34.node.mnc003.mcc123.3gppnetwork.org", DNNSWITCH=ENABLE, DNN="huawei.com"; 
   ADD UPIPDOMAIN:UPNODE="UPF_Instance_4", IPDOMAIN="upf34.node.mnc003.mcc123.3gppnetwork.org", DNNSWITCH=ENABLE, DNN="huawei.com";
   ```
6. 配置N4接口可靠性。

   ```
   SET PFCPPARA:HBINTERVAL=30, HBT1=3, HBN1=5, DEACTIVEFLAG=ENABLE, DACTINTERVAL=900, RPTRSPAGETIME=16, MIGINTERVAL=60, CHECKFLAG=ENABLE;
   ```
