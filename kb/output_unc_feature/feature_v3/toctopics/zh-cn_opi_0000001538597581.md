## 操作场景

本操作指导介绍激活NRF全故障业务逃生的操作过程。

适用于AMF、SMF、NRF、NSSF、SMSF。

## 必备事项

前提条件

* 请仔细阅读13.1-WSFD-113013 NRF全故障业务逃生特性概述 。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET NFDISCPLCY** | CACHESWITCH（缓存开关） | ON | 本端规划 | 该参数用于指定是否开启缓存开关。缓存指的是从NRF中获得的远端NF信息缓存数据。开关设置为ON后，NF进行服务发现流程时可以在缓存中查找目标网元；反之则不会。 |
| **ADD SUBCONDITON** | NFTYPE（NF类型） | NfAMF | 本端规划 | 该参数用于指定订阅的目标NF类型。 |
|  | CONDITION（订阅条件） | NfInstanceId | 全网规划 | 该参数用于指定订阅的条件类型。 |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置缓存开关。

   **SET NFDISCPLCY**
3. 订阅目标NF。

   **ADD SUBCONDITION**

## 任务示例

任务描述

开启缓存开关，增加NF类型为NfAMF的订阅信息。

脚本

//开启缓存功能。

```
SET NFDISCPLCY: CACHESWITCH=ON;
```

//增加NF类型为NFAMF的订阅信息，订阅条件为NfInstanceId，通知事件为NF\_REGISTERED。

```
ADD SUBCONDITION: NFTYPE=NfAMF, CONDITION=NfInstanceId-1&NFType-0&ServiceName-0&AmfRegionId-0&AmfSetId-0&GuamiList-0&PlmnId-0&NetworkSlice-0&NfGroup-0&Rev1-0&Rev2-0&Rev3-0, REQNOTIFEVENT=NF_REGISTERED-1&NF_DEREGISTERED-1&NF_PROFILE_CHANGED-1;
```
