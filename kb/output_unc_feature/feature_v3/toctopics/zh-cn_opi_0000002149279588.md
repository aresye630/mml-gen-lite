# 用户签约一跳入家业务

## 操作场景

该任务旨在指导操作人员给用户配置一跳入家网关签约数据。

完成了一跳入家基础的业务部署与调测，网络就具备了为家庭用户开通一跳入家的能力。当家庭用户有开通业务诉求时，可以通过如下方式完成数据签约和业务开通。

* 家庭成员和家庭网关在运营商BOSS系统进行签约。签约完成后BOSS系统通过运维接口下发签约信息到UDM上 。
* 如果BOSS系统和UDM之间的运维接口尚未支持，请参考本章节在UDM上人工配置签约数据。

## 必备事项

前提条件

* 操作人员具有PGW Web LMT的操作权限。
* 一跳入家家庭网关IMSI号码已开户。用户A和用户B已分别完成5G开户。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD GRPMEMBER** | 智家随行家庭网关MSISDN号码（ISDN） | * 13310911001 * 13310911003 | 本端规划 | 用于标识待签约一跳入家家庭网关的MSISDN号码。 |
|  | 智家随行家庭网关名称（GRPNAME） | home1 | 本端规划 | 用于标识一跳入家家庭网关名称。 |
|  | 智家随行内部群组号（INGROUPID） | 1001-46008-01 | 已配置数据中获取 | 用于标识一跳入家内部群组号，指的是一跳入家群组使用的5G LAN群组号。该参数必须由**ADD VNGROUP**命令定义后才能在此处引用。 |
|  | 智家随行家庭网关扩展ID（EXTID） | * 460030913121001\_85617811 * 460030913121003\_85617813 | 本端规划 | 用于标识一跳入家群组中家庭网关的扩展ID。 |
| **ADD GROUPID** | MSISDN（ISDN） | * 13310911003 * 13310911005 | 本端规划 | 用于标识需要加入5G虚拟网络组的用户的MSISDN号码。 |
|  | 内部组ID（INGROUPID） | 1001-46008-01 | 已配置数据中获取 | 用于标识移动网络内部设备之间通信时互相传递的组ID。该参数必须由**ADD VNGROUP**命令定义后才能在此处引用。 |

## 任务示例

任务描述

任务1：大网UDM和一跳入家UDM合一部署场景下，为某家庭的1个家庭网关、2个家庭成员进行一跳入家业务签约。

任务2：大网UDM和一跳入家UDM分离部署场景下，为某家庭的1个家庭网关、2个家庭成员进行一跳入家业务签约。

脚本

**任务1脚本：**

1. 登录“UDM业务管理”窗口。
2. 执行**ADD GRPMEMBER**命令将家庭网关设备加入群组，以下两种方案二选一。
   * 营业厅直接分配家庭网关扩展ID

     ```
     ADD GRPMEMBER: ISDN=13310911003, GRPNAME="home1", INGROUPID="1001-46008-01", EXTID="460030913121003_85617813";
     ```
   * UDM分配家庭网关扩展ID

     ```
     ADD GRPMEMBER: ISDN=13310911003, GRPNAME="home2", INGROUPID="1001-46008-01";
     ```

   * “智家随行家庭网关IMSI号码”为“460030913121003”，“智家随行家庭网关MSISDN号码”为“13310911003”。
   * 一个家庭网关只能被一个一跳入家家庭网关IMSI号码管理。
3. 执行**ADD GROUPID**命令给成员A（已经完成5G开户，ISDN为13310911003）签约住宅所在5G LAN群组。

   ```
   ADD GROUPID: ISDN=13310911003, INGROUPID="1001-46008-01";
   ```
4. 执行**ADD GROUPID**命令给成员B（已经完成5G开户，ISDN为13310911005）签约住宅所在5G LAN群组。

   ```
   ADD GROUPID: ISDN=13310911005, INGROUPID="1001-46008-01";
   ```

**任务2脚本：**

1. 登录一跳入家UDM的“UDM业务管理”窗口。
2. 执行**ADD GRPMEMBER**命令将家庭网关设备加入群组，以下两种方案二选一。
   * 营业厅直接分配家庭网关扩展ID

     ```
     ADD GRPMEMBER: ISDN=13310911001, GRPNAME="home1", INGROUPID="1001-46008-01", EXTID="460030913121001_85617811";
     ```
   * UDM分配家庭网关扩展ID

     ```
     ADD GRPMEMBER: ISDN=13310911001, GRPNAME="home2", INGROUPID="1001-46008-01";
     ```

   * “智家随行家庭网关IMSI号码”为“460030913121001”，“智家随行家庭网关MSISDN号码”为“13310911001”。
   * 一个家庭网关只能被一个一跳入家家庭网关IMSI号码管理。
3. 登录大网UDM的“UDM业务管理”窗口。
4. 执行**ADD GROUPID**命令给成员A（已经完成5G开户，ISDN为13310911003）签约住宅所在5G LAN群组。

   ```
   ADD GROUPID: ISDN=13310911003, INGROUPID="1001-46008-01";
   ```
5. 执行**ADD GROUPID**命令给成员B（已经完成5G开户，ISDN为13310911005）签约住宅所在5G LAN群组。

   ```
   ADD GROUPID: ISDN=13310911005, INGROUPID="1001-46008-01";
   ```
