# 配置SWm接口对接数据（直联）

## 操作场景

专网UPF采用华为UDG产品，新增SWm接口用于与Non-SIM AAA UDM-UIM进行消息交互，目的是进行家庭网关的身份认证。

该任务旨在指导操作人员完成UPF的SWm接口对接配置。

* SWm接口当前版本仅支持IPv4栈类型。
* 专网UPF配置SWm接口时，不支持开启入不转板功能特性。

## 对系统的影响

该操作对系统正常运行无影响。

## 必备事项

前提条件

* UPF软件安装已完成。
* UPF初始配置已完成。
* 已完成一跳入家依赖功能的License加载。
* 已完成一跳入家要求的移动VPN相关配置。

## 任务示例

任务描述

UPF到UDM-UIM（Non-SIM AAA）的数据配置。

VPN和路由的配置操作流程与UDG产品的初始配置流程基本相同，详细配置步骤请参见“UDG产品文档”>“网络部署”>“初始配置”手册。

脚本

1. 创建VPN实例。可选配置，如果已配置VPN跳过此步骤。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_Signaling";
   ADD L3VPNINST: VRFNAME="VPN_Signaling";
   ADD VPNINSTAF: VRFNAME="VPN_Signaling", AFTYPE=ipv4uni;
   ```
2. 配置SWm接口的集中点模式为本端端口模式。

   ```
   SET UPCONCENPOINT: SWMCONCENMODE=LOCALPORT;
   ```
3. 配置SWm逻辑接口，VPN实例名称为VPN\_Signaling。

   ```
   ADD LOGICINF: NAME="swmif1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="192.168.1.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_Signaling";
   ADD LOGICINF: NAME="swmif1/0/1", IPVERSION=IPV4, IPV4ADDRESS1="192.168.2.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_Signaling";
   ```
4. 配置Diameter。
   1. 配置本端端点的主机信息。

      ```
      ADD UPDIAMLOCINFO: HOSTNAME="udg_1", REALMNAME="huawei.com", PRODUCTNAME="udg@huawei.com", ORIGINSTATEID=DISABLE, SUPPORTVENDORID=DISABLE;
      ```
   2. 配置Non-SIM AAA。

      ```
      ADD UPDIAMETERAAA: HOSTNAME="3gppaaa", REALMNAME="3gppaaa.huawei.com", VPNINSTANCE="VPN_Signaling";
      ADD UPDIAMPEERADDR: HOSTNAME="3gppaaa", ADDRTYPE=IPv4, IPV4ADDRESS="10.10.10.1";
      ```
   3. 建立本端与对端的链路组，并配置链路选择模式。

      ```
      ADD UPDIAMCONNGRP: CONNGROUPNAME="groupname", LOCALHOSTNAME="udg_1", APPLICATION=SWM, PEERHOSTNAME="3gppaaa", SELECTMODE=SESSION_ID;
      ```
   4. 配置到Non-SIM AAA的链路。

      ```
      ADD UPDIAMCONN: DIAMCONNGRP="groupname", LOCINTERFACE="swmif1/0/0", PEERADDRTYPE=IPv4, PEERIPV4ADDR="10.10.10.1", PEERPORT=3868, LOCALPORT=19865;
      ```
   5. 设置Non-SIM AAA服务器组。

      ```
      ADD UPDIAMAAAGRP: GROUPNAME="groupname";
      ```
   6. 指定主用Non-SIM AAA服务器组。

      ```
      ADD UPDIAMAAABNDG: GROUPNAME="groupname", SERVERTYPE=PARA_3GPP, HOSTNAME="3gppaaa", PRIORSEC=PRIMARY;
      ```
   7. 绑定Non-SIM AAA服务器组到APN。

      ```
      ADD UPAPNDIAMAAAG: APN="062apn1.com", GROUPNAME="groupname";
      ```
