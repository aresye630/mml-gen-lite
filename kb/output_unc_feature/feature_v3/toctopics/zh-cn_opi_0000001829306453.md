# 配置到对端5G-EIR的信息

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

在AMF本地配置到对端5G-EIR网元的连接。AMF拜访对端5G-EIR网元的主要目的是为了完成用户设备识别等操作。添加信息主要包含：

* 添加对端5G-EIR网元的基本信息。
* 添加对端5G-EIR网元的实例服务信息。

## 必备事项

前提条件

参考配置本端HTTP信息-必备事项-前提条件。

数据

**如下数据仅为举例，请注意修改成局点规划的数据。**

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD PNFPROFILE** | NF实例标识（NFINSTANCEID） | 5G\_EIR\_Instance\_0 | 参见“水平网设LLD文档 -> 5G Core业务IP对接设计”。 | 配置周边NF的Profile信息。 |
|  | NF类型（NFTYPE） | Nf5G\_EIR |  |  |
|  | NF状态（NFSTATUS） | Registered |  |  |
|  | IP地址类型（IPADDRESSTYPE） | IPTypeV4 |  |  |
|  | IPV4地址1（IPV4ADDRESS1） | 172.16.2.5 |  |  |
|  | 端口号（PORT） | 8080 | 全网规划 |  |
| **ADD PNFSERVICE** | NF实例标识（NFINSTANCEID） | 5G\_EIR\_Instance\_0 | 全网规划 | 配置周边NF的服务信息。 |
|  | 服务实例标识（SRVINSTANCEID） | Service\_Instance\_0 | 全网规划 |  |
|  | 服务名称（SERVICENAME） | N5gEirEic | 全网规划 |  |
|  | 协议模式（SCHEMA） | http | 全网规划 |  |
|  | 服务实例状态（NFSERVICESTATUS） | REGISTERED | 全网规划 |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置到5G-EIR的数据。

   ```
   ADD PNFPROFILE: NFINSTANCEID="5G_EIR_Instance_0", NFTYPE=Nf5G_EIR, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="172.16.2.5", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="5G_EIR_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=N5gEirEic, SCHEMA=http, NFSERVICESTATUS=REGISTERED
   ```
