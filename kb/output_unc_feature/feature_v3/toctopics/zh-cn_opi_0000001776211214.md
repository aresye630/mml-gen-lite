## 操作场景

本操作指导介绍在运行网络中激活SMF支持多服务区操作过程。

适用于AMF。

## 必备事项

前提条件

* 请仔细阅读WSFD-205015 SMF支持多服务区特性概述。

  如果网络中没有部署NRF，或对端SMF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置对端SMF的场景下，配置对端SMF实例相关的信息。否则，无需做对端SMF实例的相关配置。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开开关，AMF发现SMF时，支持使用的smfInfoList信元匹配。

   **SET NFDISCPLCY**
3. 如果本地配置目标SMF，则执行此步骤。

   **ADD PNFPROFILE**

   **ADD PNFTAI**

   **ADD PNFTAIRANGE**

## 任务示例

任务描述

打开开关，AMF发现SMF时，支持使用的smfInfoList信元匹配。根据AMF对SMF的服务发现，是经由NRF进行的，还是基于本地服务进行的，分为两种场景进行配置举例。

脚本

**场景一. 经由NRF发现SMF**

//打开开关，AMF发现SMF时，支持使用的smfInfoList信元匹配。

```
SET NFDISCPLCY: SMFINFOLISTPLCY=RESTRICTED;
```

**场景二. 本地配置目标SMF**

SMF1、SMF2均支持TAC1（345012000001）、TAC2（345012000002）、TAC3（345012000003）、TAC4（345012000004）、TAIrange11（345012000011~345012000019）、TAIrange21（345012000021~345012000029），新用户从TAC1、TAC3、TAIrange11接入时优选SMF1，从TAC2、TAC4、TAIrange21接入时优选SMF2。

//打开开关，AMF发现SMF时，支持使用的smfInfoList信元匹配。

```
SET NFDISCPLCY: CFGTAIPRISW=ON;
```

//配置SMF1相关信息。

```
ADD PNFPROFILE: NFINSTANCEID="smf1", NFTYPE=NfSMF, NFSTATUS=Registered, PRIORITY=1;
ADD PNFTAI: NFINSTANCEID="smf1", TAI="345012000001", PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf1", TAI="345012000003", PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf1", TAI="345012000002", PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf1", TAI="345012000004", PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
ADD PNFTAIRANGE: INDEX=11,NFINSTANCEID="smf1",MCC="345",MNC="012",QUERYTYPE=START_END,RANGESTART="000011",RANGEEND="000019",PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAIRANGE: INDEX=21,NFINSTANCEID="smf1",MCC="345",MNC="012",QUERYTYPE=START_END,RANGESTART="000021",RANGEEND="000029",PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
```

//配置SMF2相关信息。

```
ADD PNFPROFILE: NFINSTANCEID="smf2", NFTYPE=NfSMF, NFSTATUS=Registered, PRIORITY=1;
ADD PNFTAI: NFINSTANCEID="smf2", TAI="345012000002", PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf2", TAI="345012000004", PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf2", TAI="345012000001", PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
ADD PNFTAI: NFINSTANCEID="smf2", TAI="345012000003", PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
ADD PNFTAIRANGE: INDEX=21,NFINSTANCEID="smf2",MCC="345",MNC="012",QUERYTYPE=START_END,RANGESTART="000021",RANGEEND="000029",PRISWITCH=INHERIT, CAPSWITCH=INHERIT;
ADD PNFTAIRANGE: INDEX=11,NFINSTANCEID="smf2",MCC="345",MNC="012",QUERYTYPE=START_END,RANGESTART="000011",RANGEEND="000019",PRISWITCH=SPECIFIC, PRIORITY=10, CAPSWITCH=INHERIT;
```
