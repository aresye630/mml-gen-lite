## 操作场景

本指导描述在线计费用户转离线计费后，是否可以自动切回在线计费的相关配置操作。

在线计费用户因OCS故障等原因转离线后，在holding-time超时前，OCS故障恢复，用户可以自动恢复为在线计费用户。

UNC支持在DCC template模板、DCC global模板下开启本功能，此处以前者为例说明功能激活过程。

## 必备事项

前提条件

* 请仔细阅读Ga/Gy接口离线/在线计费。
* 在线转离线功能已经通过（可选）配置DCC处理动作开启。

  在线计费回切功能要求转离线功能中：

  + **SET OCSDOWNACTION**:“OCSDNACTION”需配置为“PERMIT。”
  + **ADD DCCTEMPLATE**:“CCFH”。
  + **ADD CMDRCACT**:“CMDRCACT”为“CONTINUE”。
* 完成加载license。
* 已完成计费属性、APN、User Profile创建。
* 已根据配置在线计费模板完成在线计费模板创建和绑定。

数据

如下示例参数值为举例，请根据业务实际需要进行配置。

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **ADD DCCTEMPLATE**  **MOD DCCTEMPLATE** | DCC模板名称（DCCTMPLTNAME） | dcc-test | 本端规划 | 配置在线计费自动回切功能。 说明：  * 用户转离线时如果配置了**SET HOLDINGTIME**命令的“HOLDINGTIME”，则UNC在*HOLDINGTIME*超时前一直按照**ADD DCCTEMPLATE**命令配置的“RECOVERINTERVAL”值定期尝试恢复在线计费；若未配置“HOLDINGTIME”，则视作该值无限大。 * 如果需要配置在线计费全局参数，则需要使用**MOD DCCTEMPLATE**命令，“DCCTMPLTNAME”参数值为“global”。 |
|  | 在线计费自动恢复功能开关（ONLCHGRECOVER） | ENABLE | 与对端协商 |  |
|  | 在线计费自动恢复间隔 （分钟）（RECOVERINTERVAL） | 10 |  |  |

## 操作步骤

1. 配置在线计费自动回切功能。

   **ADD DCCTEMPLATE**

   **MOD DCCTEMPLATE**

## 任务示例

任务描述

DCC template模板下开启在线计费回切功能。

脚本

//为在线计费模板dcc-test配置在线计费自动回切功能。

```
MOD DCCTEMPLATE:DCCTMPLTNAME="dcc-test",ONLCHGRECOVER=ENABLE,RECOVERINTERVAL=10;
```
