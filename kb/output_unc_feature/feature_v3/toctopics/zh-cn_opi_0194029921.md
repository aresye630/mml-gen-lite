## 操作场景

本操作指导介绍在运行网络中激活支持GPRS加密功能：GEA特性的操作过程。

GEA（GPRS Encryption Algorithm）是对LLC（Logic Link Control）层传递的用户数据进行加密的一种算法，加密范围从SGSN到MS，用来保证数据传输的安全性。加密处理的数据部分主要包括LLC帧所携带的信息域和校验域。GEA分为三种类型：GEA-1、GEA-2和GEA-3。

请至少激活GEA-1/GEA-2/GEA-3中的至少一种加密算法。

适用于SGSN。

## 必备事项

前提条件

* 请仔细阅读支持GPRS加密功能：GEA（仅用于Gb 模式）特性概述。
* 完成加载License。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 激活GEA功能。

   * GEA-1：**MOD GBAUTHCIPH**
   * GEA-2：**MOD GBAUTHCIPH**
   * GEA-3：**MOD GBAUTHCIPH**

   * 参数“SUBRANGE”（用户范围）选择“ALL\_USER”。
   * 参数“SECPLC”（安全策略）选择“AUTHANDPROTECTED”。
3. 打开GEA特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

启用鉴权加密功能，加密算法为GEA\_1。

脚本

//启用鉴权加密功能，加密算法为GEA-1。

```
MOD GBAUTHCIPH: SUBRANGE=ALL_USER, SECPLC=AUTHANDPROTECTED, CIPHALG=GEA_1-1;
```

//打开License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2GEA102", SWITCH=ENABLE;
```
