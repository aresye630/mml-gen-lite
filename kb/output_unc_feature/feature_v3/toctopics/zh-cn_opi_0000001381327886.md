# Rcap接口跟踪

* 操作场景
* 必备事项

## 操作场景

* 此跟踪用于VLR/SMSF和注册中心Rcenter之间的消息跟踪。
* 系统运行出现故障需要进行Rcap接口定位排除故障。
* 维护人员调试设备运行情况。

* 设备出口跟踪中能够显示消息，不代表跟踪到的消息一定从本设备向外发送成功，请关注系统其他异常告警和性能统计。
* 跟踪功能主要用于保障网络运营和服务、检测通信传输中的故障和错误，该功能涉及使用个人用户标识和用户通信内容。建议您只有在所适用法律法规允许的目的和范围内方可启用相应的功能。在使用用户通信内容的过程中，您应采取足够的措施以确保用户的通信内容受到严格保护。
* 操作员在现场使用跟踪功能时，消息跟踪中的IP地址、端口等信息仍然是用户的真实信息，是未被加密的。

## 必备事项

前提条件

* 具备管理员权限的操作员已经登录OM Portal。
* 维护人员具有Rcap接口跟踪权限。

## 操作步骤

1. 输入Rcap接口跟踪任务参数：在左侧跟踪导航树界面选择“UNC”->“接口跟踪”->“Rcap接口跟踪”后，单击“添加”，进入Rcap接口跟踪任务创建的界面，依次输入“任务名称”、“跟踪时长”和“定位条件”参数，如图1所示。

   **图1** Rcap接口跟踪

   参数说明如表2所示。

   **表2** Rcap接口跟踪参数配置说明

   | 参数名称 | 参数说明 | 取值范围 | 默认值 |
   | --- | --- | --- | --- |
   | 任务名称 | 用于指定该次跟踪任务的名称。 | - | - |
   | Rcap索引 | ADD RCENTER提供的Rcap索引，必填。 | 0或者1 | - |
   | 跟踪重定向 | 用于指定是否创建重定向跟踪任务。 | ·False  ·True | False |
   | 跟踪时长 | 用于指定该次跟踪任务的时长。 | 1分钟~720小时59分钟 | 1（小时） |
2. 单击“确定”，启动跟踪任务。
