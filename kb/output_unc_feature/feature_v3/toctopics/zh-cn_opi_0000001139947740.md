# 激活支持用户发起的二次激活

* 操作场景
* 必备事项

* 任务示例

## 操作场景

本操作指导介绍在运行网络中激活支持终端侧发起二次PDP上下文激活特性的操作过程。

适用于GGSN。

## 必备事项

前提条件

* 请仔细阅读WSFD-205104 支持用户发起的二次激活特性概述
* 完成加载License。

数据

该操作无需准备数据。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开本特性的License配置开关。

   **SET LICENSESWITCH**
3. 打开UE发起二次激活开关。

   **ADD APN**

## 任务示例

任务描述

激活支持终端侧发起二次PDP上下文激活特性。

脚本

//打开本特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV3W9SACT11", SWITCH=ENABLE;
```

//打开UE发起二次激活开关

```
ADD APN: APN="huawei.com", USRINTSECACTSW=ENABLE;
```
