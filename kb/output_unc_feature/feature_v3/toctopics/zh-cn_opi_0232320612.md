## 操作场景

本操作指导介绍在运行网络中激活系统过载控制功能的操作过程。

适用于NSSF。

## 必备事项

前提条件

请仔细阅读WSFD-010801系统过载控制功能特性概述（适用于NSSF）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET FCSWITCH** | 开关（SWITCH） | ENABLE | 本端规划 | 设置基于CPU过载的流控开关。 |
| **SET HTTPFIXEDFCMSG** | 流控消息类型（MSGTYPE） | NNSSF\_NSSAIAVAILABILITY\_NSSAIAVAILABILITYPOST | 全网规划 | 设置服务化接口上指定消息类型固定速率流控信息。 |
|  | 固定速率流控开关（FCSWITCH） | On |  |  |
|  | 流控速率门限(个/秒)（THRESHOLD） | 4000 |  |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 设置基于CPU过载流控开关。

   **SET FCSWITCH**
3. 设置服务化接口上指定消息类型的固定速率。

   **SET HTTPFIXEDFCMSG**

## 任务示例

任务描述

系统中度或者重度过载时，启动自保流控。

脚本

//设置基于CPU过载流控开关。

```
SET FCSWITCH: SWITCH=ENABLE;
```

//设置服务化接口上指定消息类型的固定速率流控参数。

```
SET HTTPFIXEDFCMSG:MSGTYPE=NNSSF_NSSAIAVAILABILITY_NSSAIAVAILABILITYPOST,FCSWITCH=ON,THRESHOLD=4000;
```
