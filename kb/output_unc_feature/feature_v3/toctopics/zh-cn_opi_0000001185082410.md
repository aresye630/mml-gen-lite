## 操作场景

NetBIOS是Network Basic Input/Output System的简称，是一个网络协议。运行在TCP上的NetBIOS又称为NetBIOS Over TCP，简称NBT，NBT可以提供三种不同的服务：

* 名字服务（NetBIOS Name Service），**即NBNS**，提供网络节点名称或IP地址查询服务，类似于TCP/IP协议中的DNS，负责查找目标节点的节点IP地址，并赋予其一个NetBIOS名称。
* 数据包服务（NetBIOS Datagram Service），提供基于UDP的不可靠的无连接的数据包传输服务。
* 会话服务（NetBIOS Session Service），提供可靠的基于TCP连接的数据包传输服务。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置APN实例。

   **ADD APN**
3. 配置指定APN实例的NBNS信息，包括NBNS主备地址及优先级。

   **ADD APNNBNS**
4. 配置全局缺省的NBNS信息，包括NBNS主备地址及优先级。

   **SET GLOBALNBNS**

## 任务示例

任务描述

为APN“apn1”配置NBNS信息。为UNC-USMF配置全局缺省的NBNS信息。

脚本

//配置“apn1”的APN实例。

```
ADD APN: APN="apn1";
```

//配置“apn1”APN的NBNS信息。

```
ADD APNNBNS: APN="apn1",IPV4PRIMARYIP="192.168.5.2",IPV4PRIORFIRST=LOCAL,IPV4SECONDARYIP="192.168.5.3";
```

//配置全局缺省的NBNS信息。

```
SET GLOBALNBNS: NBNSSWITCH=ENABLE,MNBNSSERVER="10.1.1.1",BNBNSSERVER="10.2.2.2",FIRSTMODE=LOCAL,SECONDMODE=RADIUS,THIRDMODE=DHCP;
```
