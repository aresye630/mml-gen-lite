# 网元选择配置举例

* 操作场景

## 操作场景

本操作指导以PDU会话建立中的AMF选择SMF为例，介绍各种网元选择方式的配置方法。

运营商要求AMF优先选择同大区同数据中心的SMF，且优先使用远端优先的选择方式（先在缓存查找满足服务发现条件的网元（如果缓存功能关闭，则跳过此步），如没有命中服务发现条件则去NRF查找，如仍无命中再在本地配置查找）。

## 必备事项

前提条件

* AMF、SMF已完成到NRF的注册。
* 如果SMF不具备向NRF自动注册的能力，NRF上支持手动配置NF Profile，完成手动注册后，SMF可以正常在网络中使用NRF方式发现和被发现。SMF手动注册请参考NRF解决方案。
* 完成包含“WSFD-113000 NF发现”特性的License加载。

## 操作步骤

配置服务发现策略选择方式

+ 服务发现流程策略为远端优先。

```
SET NFDISCPLCY: POLICY=REMOTE_FIRST;
```

+ 配置目标NF的服务发现策略，如果同时配置**SET NFDISCPLCY**和**ADD PNFDISCPLY**命令，则目标NF以**ADD PNFDISCPLY**的服务发现策略为准。

```
ADD PNFDISCPLCY: NFTYPE=NfSMF, POLICY=REMOTE_FIRST;
```

配置通过NRF选择方式选择

配置AMF选择同区域同数据中心的SMF。

1. 打开本特性的License配置开关，适用于AMF。

   ```
   SET LICENSESWITCH: LICITEM="LKV2NFDAM01", SWITCH=ENABLE;
   ```
2. 打开本特性的License配置开关，适用于NRF。

   ```
   SET LICENSESWITCH: LICITEM="LKV2NFDNR01", SWITCH=ENABLE;
   ```
3. AMF选择同区域同数据中心的SMF。

   ```
   ADD NFLOC: NFTYPE=NfAMF, TGTNFTYPE=SMF, LOCTYPE=LOCALITY;
   SET NFDISCPLCY: LOCSELECT=LOCSELECT_DATACENTER;
   ```

配置通过本地配置方式选择

1. 配置待选择的SMF的数据（注册时与AMF同locality），包括SMF的Profile、Service、PLMN信息、支持的DNN、支持的切片实例信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="SMF_Instance_0", NFTYPE=NfSMF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="172.16.0.6", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmfPduSes, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFSERVICE: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_1", SERVICENAME=NsmfEventExp, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN:NFINSTANCEID="SMF_Instance_0",MCC="123", MNC="03";
   ADD PNFDNN:INDEX=1, NFINSTANCEID="SMF_Instance_0", DNN="huawei.com";
   ADD PNFNS:INDEX=1,NFINSTANCEID="SMF_Instance_0", SST=1, SD="010101";
   ```
2. 配置基于同区域同数据中心选择SMF，即选择到上一步配置的SMF。

   ```
   ADD NFLOC: NFTYPE=NfAMF, TGTNFTYPE=SMF, LOCTYPE=LOCALITY;
   SET NFDISCPLCY: LOCSELECT=LOCSELECT_DATACENTER;
   ```

配置通过缓存方式选择

设置缓存开关为开启。

```
SET NFDISCPLCY: CACHESWITCH=ON;
```
