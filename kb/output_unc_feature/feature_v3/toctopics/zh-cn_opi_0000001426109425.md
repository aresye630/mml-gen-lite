# 激活N6接口故障隔离特性

* 操作场景
* 必备事项

* 任务示例

## 操作场景

当网络中存在UPF/PGW-U/GGSN-U与DNN/APN数据网络之间的接口（N6接口、SGi或者Gi接口）故障时，可以激活N6接口故障隔离特性，使SMF/PGW-C/GGSN-C在选择UPF/PGW-U/GGSN-U时屏蔽N6/SGi/Gi接口故障的用户面网元。激活N6接口故障隔离特性，需要在UPF/PGW-U/GGSN-U侧和SMF/PGW-C/GGSN-C侧分别进行配置。SMF/PGW-C/GGSN-C侧配置请参考本章节进行操作。UPF/PGW-U/GGSN-U侧配置请在SMF/PGW-C/GGSN-C侧配置完成后参考UPF/PGW-U/GGSN-U的产品文档进行配置。

适用于GGSN、PGW-C、SMF。

## 必备事项

前提条件

* 请仔细阅读WSFD-213006 N6接口故障隔离特性概述。
* 已激活WSFD-107010 UPF选择特性，详细操作请参考WSFD-107010 UPF选择。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET APNFAULT** | APN名称（APN） | huawei.com | 全网规划 | - |
|  | UP链路故障处理模式（UPFAULTMODE） | DETECTION | 全网规划 |  |
|  | SMF是否支持用户面链路故障恢复（RESTOREFAULT） | ENABLE | 全网规划 |  |
| **SET PFCPPARA** | 用户面链路故障信息老化时间(小时)（UPFAULTAGETIME） | 5 | 全网规划 | 该参数应大于UPF上配置的路径状态上报周期。 |
| **SET UPCSCANRATE** | 扫描任务类型（SCANTYPE） | APNFAULT | 本端规划 | 设置APN故障任务扫描用户的速率。 |
|  | 扫描速率(个/秒)（RATE） | 20 | 本端规划 |  |

## 操作步骤

1. 配置检测到N6接口故障后进行联动的APN。

   **SET APNFAULT**
2. 配置用户面链路故障老化时间。

   **SET PFCPPARA**
3. 设置APN故障任务扫描用户的速率。

   **SET UPCSCANRATE**

## 任务示例

任务描述

在SMF侧增加支持故障联动的APN信息，使SMF选择UPF时能够过滤N6接口故障的网元，实现UPF故障隔离功能。

脚本

//配置检测到N6接口故障后进行联动的APN。

```
SET APNFAULT: APN="huawei.com",UPFAULTMODE=DETECTION,RESTOREFAULT=ENABLE;
```

//配置用户面链路故障老化时间。

```
SET PFCPPARA: UPFAULTAGETIME=5;
```

//设置APN故障任务扫描用户的速率。

```
SET UPCSCANRATE: SCANTYPE=APNFAULT, RATE=20;
```
