# 激活基于TA List的寻呼自动流控（适用于MME）

## 操作场景

本操作指导在运行网络中激活基于TA List的寻呼自动流控功能。

## 必备事项

前提条件

* 请仔细阅读WSFD-010901 基于TA List的寻呼自动流控特性概述（适用于MME）和实现原理（适用于MME）。
* MME已对接网管系统，并且在网管上创建5分钟周期的性能测量任务，并勾选如下指标和待监控的测量对象：
  + 117494562 指定TAI组的S1模式寻呼请求次数
  + 117494414 指定TAI组的S1模式寻呼成功率
  + 117494413 指定TAI组的S1模式二次寻呼请求次数

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET S1TAIPAGMONPARA** | TAI寻呼异常监控开关（SWITCH） | ON | 本端规划 | 设置S1 TAI组对象寻呼异常监控功能参数。  说明：  除“寻呼最大重试次数”、“语音业务TAI寻呼流控开关”和“告警开关”参数外，本命令的其它任何参数修改都会导致学习到的基准值被清除，已经发生的流控被取消，待MME重新检测到指标异常后再次进行流控。 |
|  | S1模式TAI组寻呼成功率初始值（%）（PAGSUCRATDEFVAL） | 90 | 本端规划 |  |
|  | S1模式TAI组寻呼请求次数起始监控阈值（MINPAGREQTHD） | 1000 | 本端规划 |  |
|  | S1模式TAI组寻呼成功率降幅阈值（%）（PAGRATEEXPTHD） | 5 | 本端规划 |  |
|  | S1模式TAI组二次寻呼请求次数增幅阈值（%）（PAGREQEXPTHD） | 50 | 本端规划 |  |
|  | TAI寻呼消息启控连续异常周期个数（PAGEXPTIMESTHD） | 1 | 本端规划 |  |

|  | 语音业务TAI寻呼流控开关（IMSPAGINGSW） | ON | 本端规划 |  |
|  | 告警开关（ALARMSW） | ON | 本端规划 |  |

## 操作步骤

1. 参考激活分区域网络运维配置S1 TAI组测量对象。
2. 设置S1 TAI组对象寻呼异常监控功能参数。

   **SET S1TAIPAGMONPARA**

## 任务示例

任务描述

开启基于TA List的寻呼自动流控功能。

脚本

//设置S1 TAI组对象寻呼异常监控功能参数。

```
SET S1TAIPAGMONPARA:SWITCH=ON,PAGSUCRATDEFVAL=90, MINPAGREQTHD=1000, PAGRATEEXPTHD=5, PAGREQEXPTHD=50, PAGEXPTIMESTHD=1, PAGRETRYTIMES=0, IMSPAGINGSW=ON, ALARMSW=ON;
```
