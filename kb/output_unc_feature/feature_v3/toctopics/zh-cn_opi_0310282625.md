## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开LTE一键通功能特性的License配置开关。

   **SET LICENSESWITCH**
3. 基于全局的一键通业务配置：

   1. 查询PTT业务QCI是否已经配置为标准QCI。

      **LST STDQOSID**
   2. 开启基于全局的PTT业务配置开关。

      **SET PTTFUNC**
   3. （可选）增加PTT业务QoS参数到Pre-R8 QoS参数映射规则。

      **SET EPSQCI2PRER8**
   4. （可选）配置PTT QCI和ARP的映射规则。

      **SET QCI2ARP**
   5. （可选）配置PTT QCI到TOS/DSCP的映射规则。

      **ADD EPSREMARK**
   6. （可选）配置EPS本地QoS策略下缺省QoS参数，用于纠错。

      **SET DEFEPSQOS**
   7. （可选）配置用户的签约QoS属性支持PTT QCI。

      **ADD EPSSUBQOS**
   8. （可选）配置QosProfile信息。

      **ADD QOSPROFILE**
   9. （可选）配置PCC预定义规则的QoS参数。

      **ADD QOSPROP**
4. 基于APN的一键通业务配置：

   1. 查询PTT业务QCI是否已经配置为标准QCI。

      **LST STDQOSID**
   2. 开启基于APN的PTT业务配置开关。

      **ADD APNPTTFUNC**
   3. （可选）配置用户的签约QoS属性支持PTT QCI。

      **ADD EPSSUBQOS**
   4. （可选）配置QosProfile信息。

      **ADD QOSPROFILE**
   5. （可选）为APN实例绑定QosProfile。

      **SET APNQOSATTR**

## 任务示例

任务描述

配置APN为“apn1”，基于此APN激活LTE一键通功能特性。

脚本

//进入“MML命令行-UNC”窗口。

//打开LTE一键通功能特性的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2QPPT02", SWITCH=ENABLE;
```

//查询PTT业务QCI是否已经配置为标准QCI。

```
LST STDQOSID: QOSIDTYPE=QCI;
```

//配置APN为“apn1”。

```
ADD APN: APN="apn1";
```

//开启基于APN的PTT业务配置开关。

```
ADD APNPTTFUNC: APN="apn1", LTEPTTSWITCH=ENABLE;
```
