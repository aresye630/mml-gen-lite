## 操作场景

部署基于IP地址的本地分流功能，需要配置三四层分流规则。

## 必备事项

前提条件

* 请仔细阅读分流原理。
* 已完成与周边网元的对接。
* 完成**加载license**（如果有需求，请联系华为技术支持工程师处理）。

## 操作步骤

1. 配置UL CL与PSA1共部署功能开关。

   **SET COLOCATEDLBO**
2. 配置基于IP地址的本地分流过滤条件。
   1. 配置流过滤器。

      **ADD FLOWFILTER**
   2. 配置三四层过滤条件。

      **ADD FILTER**
   3. 绑定三四层过滤条件。

      **ADD FLTBINDFLOWF**
3. 配置本地分流流过滤器组。

   **ADD FLOWFILTERGRP**

   * 流过滤器组对应SMF下发的AppID。一个流过滤器组中需要绑定基于IP地址的本地分流过滤条件，才能实现针对一个AppID的分流功能。
   * 匹配中流过滤器组后，根据ApplD检索到分流PDR，然后按照PDR中的转发规则FAR、QoS规则QER执行策略动作。

## 任务示例

任务描述

开启UPF的本地分流功能，UPF将访问目的地址为192.168.1.1的用户业务报文执行分流动作。

脚本

//配置UL CL与PSA1共部署的本地分流功能开关。

```
SET COLOCATEDLBO: ULCLSWITCH=ENABLE;
```

//配置基于IP地址的本地分流过滤条件。

```
ADD FLOWFILTER:FLOWFILTERNAME="flowfilter_ulcl03";
ADD FILTER:FILTERNAME="filter_test03",L34PROTTYPE=STRING,L34PROTOCOL=ANY,SVRIPMODE=IP,SVRIP="192.168.1.1",SVRIPMASKTYPE=LENGTHTYPE,SVRIPMASKLEN=32;
ADD FLTBINDFLOWF:FLOWFILTERNAME="flowfilter_ulcl03",FILTERNAME="filter_test03";
```

//配置本地分流流过滤器组。

```
ADD FLOWFILTERGRP:FLWFLTRGRPNAME="flowfiltergrp_ulcl01",FLOWFILTERNAME="flowfilter_ulcl03",FLWFLTRLOGICGRP=OR;
```
