# 配置到对端AMF的信息

* 操作场景

* 操作步骤

## 操作场景

在AMF本地配置到对端AMF网元的连接。AMF拜访对端AMF网元的主要目的是为了完成用户位置更新等操作。添加信息主要包含：

* 添加对端AMF网元的基本信息。
* 添加对端AMF网元的PLMN信息。
* 添加对端AMF网元的实例服务信息。
* 添加对端AMF网元的位置区域信息。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 配置到AMF的数据，包括AMF的Profile、Service、PLMN等信息。

   ```
   ADD PNFPROFILE: NFINSTANCEID="AMF_Ins_1_Local", NFTYPE=NfAMF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="172.16.1.5", PORT=8080;
   ADD PNFSERVICE: NFINSTANCEID="AMF_Ins_1_Local", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NamfComm, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
   ADD PNFPLMN:NFINSTANCEID="AMF_Ins_1_Local",MCC="123", MNC="03";
   ADD PNFAMFINFO: NFINSTANCEID="AMF_Ins_1_Local", AMFREGIONID="00", AMFSETID="001";
   ```
