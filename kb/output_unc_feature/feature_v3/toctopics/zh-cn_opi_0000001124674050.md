## 操作场景

根据整体方案设计，SMF侧需配置1个预定义规则与1个预定义规则组：

* 规则名“Rule\_Normal”：关键参数为5QI=5，ARP=2，MFBR=100 Mbit/s及流描述。
* 规则组名“up\_Exhaust”：关键参数为5QI=5，ARP=2，MFBR=1 Kbit/s、流描述及重定向。

## 必备事项

前提条件

* 请仔细阅读UDG特性之《GWFD-020351 PCC基本功能》。
* 完成加载License（如果有需求，请联系华为技术支持工程师）。
* 已通过学习SM策略E2E实现原理、业务配置方法及E2E业务调测了解了SM策略的配置原理及方法。

## 操作流程

此特性的配置流程图如图1所示。

**图1** UPF（UDG）侧业务配置流程图

其中具体可以分为以下三个流程，对应的操作步骤如下：

* 配置流过滤器的流程见2-4。
* 配置PCC策略的流程见5-8。
* 配置规则、预定义规则组的流程见9-10。

## 操作步骤

1. 登录UDG CSP OM Portal，进入“MML命令行-UDG”窗口。
2. 配置L3/4层流过滤器。

   用户配额耗尽前，即PCF下发预定义规则“Rule\_Normal”场景。

   ```
   ADD FILTER: FILTERNAME="f_fup_service_100M", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
   ```

   用户配额耗尽后，即PCF下发预定义规则“up\_Exhaust”场景。

   ```
   ADD FILTER: FILTERNAME="f_fup_service_1K", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
   ```
3. 添加L3/4层流过滤器并绑定过滤器。

   用户配额耗尽前，即PCF下发预定义规则“Rule\_Normal”场景。

   ```
   ADD FLOWFILTER: FLOWFILTERNAME="flowfliter_service_100M";
   ADD FLTBINDFLOWF: FLOWFILTERNAME="flowfliter_service_100M", FILTERNAME="f_fup_service_100M";
   ```

   用户配额耗尽后，即PCF下发预定义规则“up\_Exhaust”场景。

   ```
   ADD FLOWFILTER: FLOWFILTERNAME="flowfliter_service_1K";
   ADD FLTBINDFLOWF: FLOWFILTERNAME="flowfliter_service_1K", FILTERNAME="f_fup_service_1K";
   ```
4. 添加重定向场景流过滤器（两种配置选一种即可）

   * 采用7层流过滤配置

     添加过滤器

     ```
     ADD L7FILTER: L7FILTERNAME="f_Redirection",SUBL7FLTNAME="f_SubRedirection";
     ```

     添加流过滤器及绑定关系

     ```
     ADD FLOWFILTER:FLOWFILTERNAME="flowfliter_Redirection",TETHERDETFLAG=FILTER;
     ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfliter_Redirection",PROTOCOLNAME="http",L7FILTERNAME="f_Redirection";
     ```
   * 采用L3/4层流过滤配置

     添加过滤器

     ```
     ADD FILTER: FILTERNAME="f_Redirection", L34PROTTYPE=STRING, L34PROTOCOL=ANY;
     ```

     添加流过滤器及绑定关系

     ```
     ADD FLOWFILTER:FLOWFILTERNAME="flowfliter_Redirection",TETHERDETFLAG=FILTER;
     ADD PROTBINDFLOWF:FLOWFILTERNAME="flowfliter_Redirection",PROTOCOLNAME="http";
     ```
5. 配置使用量上报属性。

   此处的配置须与SMF侧配置保持严格一致。

   ```
   //配置QoS URR、MK URR及URR Group绑定关系
   ADD URR:URRNAME="urr_QoS2", URRID=2, USAGERPTMODE=QOS;
   ADD URR:URRNAME="urr_QoS3", URRID=3, USAGERPTMODE=QOS;
   ADD URR:URRNAME="urr_MK", URRID=32, USAGERPTMODE=MONITORINGKEY;
   ADD URRGROUP: URRGROUPNAME="urrg_qos_service", UPURRNAME1="urr_MK", DOWNURRNAME1="urr_MK";
   ```
6. 配置QoS参数。

   该步骤为预定义规则（组）场景下的可选配置。只有在需要对用户进行带宽控制或建立专有QoS Flow时，才需配置。须配置配额耗尽前、耗尽后两种场景的带宽控制策略。

   用户配额耗尽前，此处5QI/ARP取值参考SMF（UNC）侧业务设计规划分别取5和2。

   ```
   ADD QOSPROP: QOSPROPNAME="qosprop_5qi5_arp2_100M", MBRUPLKVALUE=100000, MBRDNLKVALUE=100000, QOSTYPE=QOS_FLOW_PARA, ARPVALUE=2, FQI=5, QOSURRNAME="urr_QoS2";
   ```

   用户配额耗尽后，此处5QI/ARP取值参考SMF（UNC）侧业务设计规划分别取5和2。

   ```
   ADD QOSPROP: QOSPROPNAME="qosprop_5qi5_arp2_1K", MBRUPLKVALUE=1, MBRDNLKVALUE=1, QOSTYPE=QOS_FLOW_PARA, ARPVALUE=2, FQI=5, QOSURRNAME="urr_QoS3";
   ```
7. 配置重定向及绑定关系。

   添加重定向URL等信息（根据实际情况选择如下两种配置中的一种即可）。

   ```
   //7层流对应的重定向配置
   ADD REDIRECT: REDIRECTNAME="Redirect_Name", URL="www.example.com";
   //L3/4层流对应的重定向配置
   ADD REDIRECT: REDIRECTNAME="Redirect_Name", URL="http://172.30.26.103:8080";
   ```

   添加PCC动作用于绑定重定向内容。

   ```
   ADD PCCACTIONPROP:PCCACTPROPNAME="PCCAction_Name",UPINITREDIRNM="Redirect_Name",UPINITUPGATE=PASS,UPINITDNGATE=PASS,DNINITUPGATE=DISCARD,DNINITDNGATE=DISCARD;
   ```
8. 配置PCC策略组。

   该步骤为预定义规则（组）场景下的必选配置。配置PCC策略组的目的是用于关联QoS URR策略。此处“URRGROUPNAME”参数使用ADD URRGROUP定义的“URRGROUPNAME”。

   用户配额耗尽前，即PCF下发预定义规则“Rule\_Normal”场景。

   ```
   //PCC策略关联QoS URR Group及MK URR Group
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccfuppolicy_100M", TOKENFUNCFLAG=DISABLE, URRGROUPNAME="urrg_qos_service", SIGURRGRPNAME="urrg_qos_service", QOSPROPNAME="qosprop_5qi5_arp2_100M";
   ```

   用户配额耗尽后，即PCF下发预定义规则“up\_Exhaust”场景。

   ```
   //PCC策略关联QoS URR Group及MK URR Group
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccfuppolicy_1K", TOKENFUNCFLAG=DISABLE, URRGROUPNAME="urrg_qos_service", SIGURRGRPNAME="urrg_qos_service", QOSPROPNAME="qosprop_5qi5_arp2_1K";
   //PCC策略绑定重定向
   ADD PCCPOLICYGRP: PCCPOLICYGRPNM="pccfuppolicy_Redir", PCCACTPROPNAME="PCCAction_Name";
   ```
9. 配置预定义规则。

   该步骤为预定义规则（组）场景下的必选配置。主要用于关联PCC策略组。

   ```
   ADD RULE:RULENAME="Rule_Normal",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfliter_service_100M",PRIORITY=10,POLICYNAME="pccfuppolicy_100M";
   ADD RULE:RULENAME="Rule_Exhaust",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfliter_service_1K",PRIORITY=20,POLICYNAME="pccfuppolicy_1K";
   ADD RULE:RULENAME="Rule_Redirection",POLICYTYPE=PCC,FILTERINGMODE=FLOWFILTER,FLOWFILTERNAME="flowfliter_Redirection",PRIORITY=30,POLICYNAME="pccfuppolicy_Redir";
   ```
10. （配额耗尽场景）配置预定义规则组。

    添加UserProfile

    ```
    ADD USERPROFILE: USERPROFILENAME="up_Exhaust", ALIASMARKFLAG=DISABLE, DDOSCHECK=DISABLE, CAPMODETHRES=0, LOCRPTSWITCH=INHERIT, TETHERINGMAXNUM=255;
    ```

    添加规则与UserProfile绑定关系

    ```
    ADD RULEBINDING: USERPROFILENAME="up_Exhaust",RULENAME="Rule_Exhaust";
    ADD RULEBINDING: USERPROFILENAME="up_Exhaust",RULENAME="Rule_Redirection";
    ```
11. 将新配置的Filter置为生效。

    ```
    SET REFRESHSRV:REFRESHTYPE=ALL;
    ```
