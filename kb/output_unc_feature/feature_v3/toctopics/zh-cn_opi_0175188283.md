# N4接口跟踪

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

* 系统运行出现N4接口故障需要N4接口跟踪定位排除故障。
* 维护人员调试设备运行情况。

* 设备出口跟踪中能够显示消息，不代表跟踪到的消息一定从本设备向外发送成功，请关注系统其他异常告警和性能统计。
* 跟踪功能主要用于保障网络运营和服务、检测通信传输中的故障和错误，该功能涉及使用个人用户标识和用户通信内容。建议您只有在所适用法律法规允许的目的和范围内方可启用相应的功能。在使用用户通信内容的过程中，您应采取足够的措施以确保用户的通信内容受到严格保护。
* 操作员在现场使用跟踪功能时，消息跟踪中的IMSI、IP地址等信息仍然是用户的真实信息，是未被加密的。

## 必备事项

前提条件

* 具备管理员权限的操作员已经登录OM Portal。
* 维护人员具有接口消息跟踪权限。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| N4接口跟踪 | IP地址类型 | IPv4/IPv6 | 本端规划 | 接口地址类型 |
|  | Cp IPv4/Cp IPv6 | 192.168.0.1/2001:0db8::1 | 本端规划 | 本端CP地址，可以通过“LST CPPOINT”命令查询。 |
|  | Up IPv4/Up IPv6 | 192.168.0.2/2001:0db8::2 | 全网规划 | 对端UP地址，可以通过“LST PNFPROFILE”命令查询。 |

## 操作步骤

1. 进入跟踪操作界面：登录OM Portal，在OM Portal主界面依次选择“监控分析”->“消息跟踪”，进入跟踪导航树界面，如图1所示。

   **图1** 消息跟踪操作界面
2. 填写用户跟踪任务参数：在左侧跟踪导航树界面选择“UNC”->“接口跟踪”->“N4接口跟踪”后，单击“添加”，进入N4接口跟踪任务创建的界面，依次填写“任务名称”、“跟踪时长”、“定位条件”和“组合条件”参数，如图2所示。

   **图2** N4接口跟踪参数配置对话框
3. 在对话框中进行参数配置，参数说明如表1所示。

   **表1** 用户跟踪参数配置说明

   | 参数名称 | 参数说明 | 取值范围 | 默认值 |
   | --- | --- | --- | --- |
   | 任务名称 | 该次跟踪任务的名称 | - | - |
   | 定位条件 | IP地址类型 | IPv4/IPv6 | IPv4 |
   |  | Cp IPv4/Cp IPv6 | IPv4或IPv6地址 | － |
   |  | Up IPv4/Up IPv6 | IPv4或IPv6地址 | － |
   | 组合条件 | N4控制消息 | 选中/未选中 | 全选 |
   |  | N4数据消息 | 选中/未选中  说明：  * 全选时，N4控制消息和N4数据消息都会上报。 * 只选N4控制消息或者N4数据消息时，只会上报选中的类型消息进行上报。 * 都不选时，没有消息上报。 | 全选 |
   | 跟踪时长 | 该参数用于指定该次跟踪任务的时长。 | 1分钟~720小时59分钟 | 1（小时） |
4. 单击“确定”，启动跟踪任务。
