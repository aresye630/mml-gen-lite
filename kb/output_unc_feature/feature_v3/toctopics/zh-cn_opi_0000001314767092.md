# 部署SMF选择ULCL合一策略增强

## 操作场景

为5G用户配置UL CL部署模式，从而实现UL CL合设锚点的选择可基于UE的位置灵活切换。

## 必备事项

前提条件

已开启UL CL分流相关功能特性：

* WSFD-107010 UPF选择
* WSFD-108002 基于预定义规则的分流策略控制
* WSFD-108001 动态分流策略控制

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| ADD DNAIINFO | 数据网络访问标识（DNAI） | huawei | 全网规划 | 打开ALWAYS分流开关。 |
|  | Always分流开关（ALWAYSSHUNTSW） | ENABLE | 全网规划 |  |
| ADD ULCLAREADPMODE | APN名称（APN） | huawei.com | 全网规划 | 增加指定DNAI服务区域粒度的ULCL部署模式为优先使用辅锚点分流。 |
|  | 数据网络访问标识（DNAI） | huawei | 全网规划 |  |
|  | DNAI服务区域名称（DNAREANAME） | dnarea1 | 全网规划 |  |
|  | ULCL部署模式（ULCLDEPLOYMODE） | AUXSHUNTPREFER | 本端规划 |  |
| ADD ULCLDNAIDPMODE | APN名称（APN） | huawei.com | 全网规划 | 增加指定DNAI粒度的ULCL部署模式为只使用主锚点分流。 |
|  | 数据网络访问标识（DNAI） | huawei | 全网规划 |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 打开ALWAYS分流开关。

   ```
   ADD DNAIINFO:DNAI="huawei",ALWAYSSHUNTSW=ENABLE;
   ```
3. 增加指定DNAI服务区域的UL CL部署模式。

   ```
   ADD ULCLAREADPMODE:APN="huawei.com",DNAI="huawei",DNAREANAME="dnarea1",ULCLDEPLOYMODE=AUXSHUNTPREFER;
   ```
4. 增加指定DNAI的UL CL部署模式。

   ```
   ADD ULCLDNAIDPMODE:APN="huawei.com",DNAI="huawei",ULCLDEPLOYMODE=PSASHUNTMUST;
   ```
5. 增加指定APN的UL CL部署模式。

   ```
   ADD ULCLAPNDPMODE:APN="huawei.com",ULCLDEPLOYMODE=PSASHUNTMUST;
   ```

## 任务示例

任务描述

SMF为某一校园用户配置DNAI服务区域，DNAI，DNN三种粒度的UL CL分流节点部署策略。在DNAI服务区域内优先选择辅锚点作为分流ULCL，APN为huawei.com，DNAI名称为huawei，DNAI服务区域为dnarea1。在DNAI内必须选择主锚点作为分流ULCL，APN为huawei.com，DNAI名称为huawei。在DNN内必须选择主锚点作为分流ULCL，APN为huawei.com。

脚本

```
//打开ALWAYS分流开关。
ADD DNAIINFO: DNAI="huawei", ALWAYSSHUNTSW=ENABLE;
//增加指定DNAI服务区域的UL CL部署模式。
ADD ULCLAREADPMODE:APN="huawei.com",DNAI="huawei",DNAREANAME="dnarea1",ULCLDEPLOYMODE=AUXSHUNTPREFER;
//增加指定DNAI的UL CL部署模式。
ADD ULCLDNAIDPMODE:APN="huawei.com",DNAI="huawei",ULCLDEPLOYMODE=PSASHUNTMUST;
//增加指定DNN的UL CL部署模式。
ADD ULCLAPNDPMODE:APN="huawei.com",ULCLDEPLOYMODE=PSASHUNTMUST;
```
