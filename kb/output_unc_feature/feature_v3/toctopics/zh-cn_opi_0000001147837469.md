# 部署基于位置信息的分流策略控制（AMF）

* 操作场景
* 必备事项

## 操作场景

本操作用于指导基于位置信息的分流策略控制特性关于AMF上PRA配置以及UE Location Report功能配置的操作过程。

## 必备事项

前提条件

* 请仔细阅读WSFD-223001 基于位置信息的分流策略控制和WSFD-106010 基于指定区域的策略控制。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |

|  | DESC（描述信息） | "for EastLake Campus" |  |  |

## 任务示例

任务描述

运营商需要为某企业用户提供基于小区粒度用户位置信息的UL CL分流方案，覆盖该企业的小区范围为900001~900003，PRA ID为8388616。

脚本

//AMF配置PRA区域（校园）基本信息。

```
ADD NGPRA: PRAID=8388616, DESC="for EastLake Campus";
```

//AMF在指定的PRA区域配置位置信息。

```
ADD NGPRAMEM: PRAID=8388616, LOCTYPE=NRCELLID, MCC="123", MNC="45", NGCIDBEGIN="000900001", NGCIDEND="000900003";
```

//配置感兴趣区域订阅失败后的处理策略。

```
SET NGMMFUNC: SUBLOCRPTSW=YES;
```

//设置NGAP兼容性参数。

```
SET NGAPCMPT: AOILIST=NO;
```
