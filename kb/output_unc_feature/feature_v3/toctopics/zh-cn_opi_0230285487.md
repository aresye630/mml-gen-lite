## 操作场景

本操作指导介绍在运行网络中激活系统过载控制功能的操作过程。

适用于NRF。

## 必备事项

前提条件

请仔细阅读WSFD-010801系统过载控制功能特性概述（适用于NRF）。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET FCSWITCH** | 开关（SWITCH） | ENABLE | 本端规划 | 设置基于CPU过载的流控开关。 |
| **SET NRFFUNCSW** | 管理类消息流控开关（NFMFCSWITCH） | FUNC\_ON | 本端规划 | 开启针对管理类消息和发现类消息的自保流控功能。 |
|  | 发现类消息流控开关（DISCFCSWITCH） | FUNC\_ON | 本端规划 |  |
| **SET NRFFCPARA** | 流控等级（FCLEVEL） | LOW | 本端规划 | 设置不同流控级别对应的流控响应。 |
|  | 流控响应（FCREP） | TooManyRequest\_429 | 本端规划 |  |
| **SET NRFNOTIFYFCPARA** | NF更新事件缓冲最长时长(秒)（NFCHGCACHETHD） | 900 | 本端规划 | 设置NRF针对同一频繁变更的NF的多长时间内的变更事件合并。  设置多长时间内同一个NF超过1次变更就识别此NF为频繁变更，需要对其变更通知做抑制合并。 |
|  | NF更新事件最短缓冲时长(秒)（NFCHGCACHETIME） | 50 | 本端规划 |  |
| **SET HTTPFIXEDFCMSG** | 流控消息类型（MSGTYPE） | NNRF\_NFDISCOVERYSERVICE\_SEARCHNFINSTANCES | 全网规划 | 设置服务化接口上指定消息类型固定速率流控信息 |
|  | 固定速率流控开关（FCSWITCH） | On |  |  |
|  | 流控速率门限(个/秒)（THRESHOLD） | 4000 |  |  |

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 添加具体实例的流控参数。

   **ADD FCPARAM**
3. 设置基于CPU过载流控开关。

   **SET FCSWITCH**
4. 开启针对管理类消息和发现类消息的自保流控功能。

   **SET NRFFUNCSW**
5. 设置不同流控级别对应的流控响应。

   **SET NRFFCPARA**
6. 设置NF变更事件合并发送通知相关阈值。

   **SET NRFNOTIFYFCPARA**
7. 设置服务化接口上指定消息类型的固定速率。

   **SET HTTPFIXEDFCMSG**

## 任务示例

任务描述

系统过载时，启动自保流控。

脚本

//添加具体实例的流控参数，增加微服务类型为UesmCtrlSvc、微服务实例ID为999、流控套餐ID为0的流控参数，最小令牌数为30，最大令牌数为5000。

```
ADD FCPARAM: SERVICETYPE="UesmCtrlSvc", SERVICEID=999, CASEID=0, PARAMCAT=GENERAL, MINTOKEN=30, MAXTOKEN=5000;
```

//设置基于CPU过载流控开关。

```
SET FCSWITCH: SWITCH=ENABLE;
```

//开启针对管理类消息和发现类消息的自保流控功能。

```
SET NRFFUNCSW: NFMFCSWITCH=FUNC_ON, DISCFCSWITCH=FUNC_ON;
```

//设置不同流控级别对应的流控响应。

```
SET NRFFCPARA: FCLEVEL=LOW, FCRSP=TooManyRequest_429;
SET NRFFCPARA: FCLEVEL=MEDIUM, FCRSP=ServiceUnavailable_503;
SET NRFFCPARA: FCLEVEL=HIGH, FCRSP=NoResponse;
```

//设置NF变更事件合并发送通知相关阈值，50s内NF再次发生变更，则将此NF在900s内的变更事件合并发送，减少NRF发送变更通知的数量。

```
SET NRFNOTIFYFCPARA:NFCHGCACHETHD=900, NFCHGCACHETIME=50;
```

//设置服务化接口上指定消息类型的固定速率流控参数。

```
SET HTTPFIXEDFCMSG:MSGTYPE=NNRF_NFDISCOVERYSERVICE_SEARCHNFINSTANCES,FCSWITCH=ON,THRESHOLD=4000;
```
