## 操作场景

本操作指导介绍在运行网络中激活NB-IoT终端的位置延迟定位服务特性的操作过程。

适用于MME。

## 必备事项

前提条件

* 操作人员已经登录U2020\MAE-Access。
* 本特性为可选特性，需要加载支持该特性的License，对应的License项为“NB-IoT终端的位置延迟定位服务”。
* 3GPP协议定义的标准LCS组网场景下，已经完成SLg和SLs接口数据配置，详细请参见配置到GMLC的数据和配置到E-SMLC的数据。
* 请仔细阅读WSFD-215206 NB-IoT终端的位置延迟定位服务特性概述。

## 操作步骤

1. 增加一条E-SMLC配置，并设置MME向E-SMLC请求定位时携带RAT Type信元。

   **ADD ESMLC**:ESMLCID=E-SMLC 标识, ESMLCNAME= E-SMLC名称, RATIESW=YES;

   如果使用已配置的E-SMLC，请使用**MOD ESMLC**命令，修改“RATIESW”为“YES”。
2. 增加发起定位请求的GMLC的权限。

   **ADD GMLCAU**:GMLCID=GMLC 标识，CLTTYPE=支持的客户端类型，SERTYPE=支持的LCS业务类型;
3. **可选：**设置延迟定位业务的运行参数。

   **SET LCSPARA**:TR1=隐私验证定时器（s），POSTIMER=EPC 位置获取定时器(s)，POSIDLE=EPC 位置信息表老化时长(min), GMLCAU=EPC UE级的GMLC的鉴权方案, DELAYLOCTIMER=延迟定位超时时长;
4. 打开本特性的License配置开关。

   **SET LICENSESWITCH**: LICITEM="LKV2DPNB01",SWITCH=ENABLE;

## 任务示例

任务描述

3GPP协议定义的标准LCS组网场景下，部署协议标准的LCS定位功能。

脚本

//增加一条E-SMLC配置，并设置MME向E-SMLC请求定位时携带RAT Type信元。

```
ADD ESMLC:ESMLCID=1, ESMLCNAME="ESMLC1", RATIESW=YES;
```

//增加一条“GMLC 标识”为“1”，“支持的客户端类型”为“PLMN\_OPERATOR\_SERVICES（运营商业务）”，“支持的LCS业务类型”为“3”的GMLC配置记录。

```
ADD GMLCAU: GMLCID=1, CLTTYPE=PLMN_OPERATOR_SERVICES, SERTYPE=3;
```

//设置延迟定位服务的运行参数，设置EPC位置获取定时器为60s，延迟定位超时时长为12小时。

```
SET LCSPARA: TR1=20, POSTIMER=60, POSIDLE=60, GMLCAU=AUALL,DELAYLOCTIMER=720;
```

//打开位置定位服务（LCS）的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2DPNB01",SWITCH=ENABLE;
```
