# 卸载VPROBE服务

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

当运营商不需要VPROBE服务或VPROBE服务动态上线失败时，可以单独卸载VPROBE pod，从而下线VPROBE服务。

## 必备事项

前提条件

* 已经完成网络设计，已规划下线VPROBE pod的类型和数量。
* 如果动态下线失败，只能继续重新触发动态下线任务。

数据

| 类别 | 参数名称 | 取值样例/说明 | 获取方法 |
| --- | --- | --- | --- |
| UNC OM Portal帐户 | IP地址 | 192.168.1.1  操作维护接口IP，即“VNFD模板”中的“MNG\_IP”或“MNG\_IPv6”参数。 | 本端规划 |
|  | 端口号 | 31943 | 本端规划 |
|  | 用户名 | admin | 本端规划 |
|  | 密码 | Changeme\_123 | 本端规划 |
| 特性下线  OPR FEATUREDISABLE | Pod类型列表（PODTYPE） | All Pod | 固定取值 |
|  | 下线方式（DISABLETYPE） | Normal | 本端规划 |
|  | FUNCTIONSETNAME  （网络功能集名称） | VPROBE | 固定取值 |

## 操作步骤

1. 登录UNC OM Portal。
2. 执行命令**RMV VPROBEIP**和**RMV VPROBESVRIP**，删除配置数据。

   避免由于残留配置数据的导致再次上线本服务失败。

   ```
   RMV VPROBEIP: INDEX=3;
   RMV VPROBESVRIP:ACCESSNAME="ACCESS1";
   ```
3. 执行命令，动态下线VPROBE pod。

   ```
   OPR FEATUREDISABLE: PODTYPE="All Pod", DISABLETYPE=Normal, FUNCTIONSETNAME="VPROBE";
   ```
4. 执行命令，确认已经成功下线VPROBE pod。

   ```
   DSP FEATUREOPRHIST:;
   ```

   回显为“处理结果=处理成功”。

   ```
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="vprobectrl-pod";
   DSP POD: MEID="网元ID", TYPE=byType, PODTYPE="vprobeexec-pod";
   ```

   回显“查询Pod不存在”。
5. 执行命令，确认已经下线VPROBE服务。

   ```
   DSP FUNCTIONSETSTAT:;
   ```

   回显为中没有VPROBE服务。
