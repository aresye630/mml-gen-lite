# 离线计费配置（5G）

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

该任务用于指导操作人员完成融合计费中的离线计费对接话单处理参数。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录MAE客户端或登录OM Portal）。

* UNC软件安装已完成。

## 操作步骤

1. 配置5G话单处理的格式引擎包。
   1. 配置格式引擎包。

      ```
      ADD CDRPROC: AGID="PS1", PRFNAME="PS_R15_VF80.tar.gz", SHAREFILECSN=OFF, SEQNUMMODE=IE;
      ```
   2. **可选：**配置格式引擎包相关软参。

      * 不同的格式引擎包对软参的支持情况可能不同，可以通过**DSP FMTSOFTPARA**命令查询对应格式引擎包可配置的软参。
      * 软参取值请根据业务实际需要进行配置。

      ```
      ADD FMTPKGCFG: PRFNAME="PS_R15_VF80.tar.gz", CFGNAME="MergeSwitch", CFGTYPE=FEM_PARA_UINT, CFG_UINT_VALUE=0;
      ADD FMTPKGCFG: PRFNAME="PS_R15_VF80.tar.gz", CFGNAME="FilterZeroCDR", CFGTYPE=FEM_PARA_UINT, CFG_UINT_VALUE=1;
      ```
2. 配置5G业务处理模块。

   ```
   ADD MODULE: MNAME="AP64_1", AGID="PS1";
   ```
3. 配置话单处理相关配置。
   1. 原始话单参考如下命令进行配置，默认保存7天。

      ```
      ADD CDRSTOR: CDRSTORID="Original1", ISSINGLEBI=No, FILETYPE=Original, STORDAYS=7, STORDAYSRULE=ByRelativeDays, CMRRULE=ZLIB;
      ```
   2. 第一份最终话单参考如下命令进行配置，保存为30天。

      ```
      ADD CDRSTOR: CDRSTORID="first1", ISSINGLEBI=No, FILETYPE=FirstFinal, FSTORDAYS=30, FSTORDAYSRULE=ByRelativeDays, FCMRRULE=GZIP;
      ```
   3. 第二份最终话单文件命名可以参考如下命令进行配置，相关文件命名需要根据现场规范进行配置。

      “MNAME”来源于步骤2中**ADD MODULE**命令，“MNAME”个数与**LST SERVICERUSTATE**命令查询出的RU个数一致。当“MNAME”有多个时**ADD CDRSTOR**命令需要配置多条。

      ```
      ADD CDRSTOR: CDRSTORID="5G_second64_1", ISSINGLEBI=No, FILETYPE=SecondFinal, AGID="PS1", MNAME="AP64_1", SFSTORDAYS=30, SFSTORDAYSRULE=ByRelativeDays, SFCMRRULE=UNCOMPRESS, CLOSEFILECOND=Unspecify, EMPTYFILE=NO, NAMINGRULE="SMF000000000001_%Y%m%d%H%M%S_%08L.dat", ENDSN=99999999, NUMSCHSN=NO;
      ```
