## 操作场景

Pod间Fabric平面亚健康检测是基于Pod间的点到点探测结果，进行的网络亚健康诊断。

操作员可以开启网络亚健康检查开关，并设置检查参数和相关告警上报参数，使系统根据设置参数检查网络亚健康状态并上报相关告警。

## 必备事项

前提条件

请仔细阅读SFFD-010008 通信亚健康自愈。

数据

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET FABRICSUBHEALTHY** | 亚健康阈值 (SUBHEALTHYTHRESHOLD) | 50 | 本端规划 | 设置Fabric平面的亚健康检测参数。 |
|  | 亚健康探测周期（s）（SUBHEALTHYINTERVAL） | 30 |  |  |
|  | Fabric链路切换是否使能（ISLINKSWITCHENABLE） | TRUE |  |  |

## 操作步骤

1. 已经登录OM Portal，或者已登录U2020，或者登录MAE并进入Access子系统。
2. 使用**SET FABRICSUBHEALTHY**命令设置Fabric平面的Pod之间链路亚健康检测参数。

   Fabric平面亚健康可能会导致上报如下相关告警：

   * **ALM-100339 Fabric链路出现亚健康**
   * **ALM-100340 Fabric端口通信出现亚健康**

## 任务示例

任务描述

本实例中，操作员在网元上进行数据配置实现以下要求：

系统对Fabric平面的链路进行健康质量检测，当超过设置的亚健康告警阈值时，会上报相关告警。

脚本

//设置Fabric亚健康全局配置，包括亚健康阈值和亚健康检测周期。

```
SET FABRICSUBHEALTHY:SUBHEALTHYINTERVAL=30,SUBHEALTHYTHRESHOLD=50;
```
