# 配置SWu接口对接数据（IPSec隧道）

* 操作场景
* 对系统的影响
* 必备事项
* 任务示例

## 操作场景

SWu是家庭终端SDK接入专网UPF信令接口，同时又是IPSec类型会话的数据传输的接口，SSG在收到SWu接口上送的报文后，需要区分信令和数据，并进行不同的处理。本章介绍家庭网关如何通过SWu接口与UPF之间进行IKE协商，建立IPSec隧道。

## 对系统的影响

该操作对系统正常运行无影响

## 必备事项

前提条件

* UPF软件安装已完成。
* UPF初始配置已完成。
* 已完成一跳入家依赖功能的License加载。

## 任务示例

任务描述

SWu是家庭终端SDK接入专网UPF信令接口，同时又是IPSec类型会话的数据传输的接口，SSG在收到SWu接口上送的报文后，需要区分信令和数据，并进行不同的处理。本章介绍家庭网关如何通过SWu接口与UPF之间进行IKE协商，建立IPSec隧道。

脚本

1. 创建VPN实例。

   ```
   ADD VPNINST: VPNINSTANCE="VPN_SWu";
   ```
2. 创建L3VPN实例。

   ```
   ADD L3VPNINST: VRFNAME="VPN_SWu";
   ADD VPNINSTAF: VRFNAME="VPN_SWu", AFTYPE=ipv4uni;
   ```

3. 配置swuif逻辑接口，VPN实例名称为VPN\_SWu。

   ```
   ADD LOGICINF: NAME="swuif1/0/0", IPVERSION=IPV4, IPV4ADDRESS1="192.168.1.1", IPV4MASK1="255.255.255.255", VPNINSTANCE="VPN_SWu";
   ```
4. 配置IKE。
   1. 配置DPD功能。

      ```
      SET IKEGLOBALCONFIG: DPDTYPE=Periodic, DPDINTERVAL=60, DPDRETRYINTRVL=3;
      ```
   2. 创建IPsec微服务的IPsec隧道接口，绑定VPN并配置IP地址。IKE认证需要该配置。

      ```
      ADD L3VPNINSTIPSEC: VRFNAME="VPN_SWu";
      ADD VPNINSTAFIPSEC: VRFNAME="VPN_SWu", AFTYPE=ipv4uni;
      ADD INTERFACEIPSEC:IFNAME="Tunnel10", IFADMINSTATUS=Up;
      ADD IPBINDVPNIPSEC: IFNAME="Tunnel10", VRFNAME="VPN_SWu", IPTYPECHECK=Ipv4;
      ADD IFIPV4ADDRESSIPSEC:IFNAME="Tunnel10", IFIPADDR="192.168.1.1", SUBNETMASK="255.255.255.255", ADDRTYPE=Main;
      ```
   3. 增加IKE安全提议号为1的IKE安全提议。

      ```
      ADD IKEPROPOSAL: PROPOSALNUMBER=1, AUTHMETHOD=Pre_share, AUTHALGORITHM=Sha2_256, ENCRALGORITHM=Aes_cbc_128, INTEGALGORITHM=Hmac_sha2_256, DHGROUP=Dh_group1;
      ```
   4. 增加名称为“peer1”的IKE对等体，同时指定交换模式为main模式，IKE版本1为FALSE，IKE版本2为TRUE，LOCALIDTYPE为FQDN。

      ```
      ADD IKEPEER: PEERNAME="peer1", PRESHAREDKEY="abcde", EXCHANGEMODE=Main, PROPOSAL=1, LOCALIDTYPE=Fqdn, VERSION1=FALSE, VERSION2=TRUE, DPDHASHSEQ=Hash_notify, IKEMSGSYNC=Disable, IPSECMSGSYNC=Disable;
      ```
   5. 增加名称为“asdf2”的IPsec安全提议。

      ```
      ADD IPSECPROPOSALIPSEC: PROPOSALNAME="asdf2", IPSECPROTOCOL=Esp, ESPAUTHALGO=Sha2_256, ESPENCRYPTALGO=Aes_256, ENCAPMODE=Tunnel;
      ```
   6. 增加IPsec策略模板。

      ```
      ADD IPSECPOLICYTM: POLICYNAME="ipsecply2tm", SEQUENCENUMBER=10, PEERNAME="peer1", IPSECPROPNAME="asdf2", TRAFFSADISFLG=FALSE, ACLTYPE=AclIPv4, TFCENABLE=TRUE;
      ```
   7. 增加IPsec安全策略POLICY。

      ```
      ADD IPSECPOLICY: POLICYNAME="ipsecply2", SEQUENCENUMBER=10, POLICYMODE=Isakmp, TEMPLATEMODE=PolicyTemplate, TEMPLATENAME="ipsecply2tm";
      ```
   8. tunnel口绑定POLICY。

      ```
      ADD IPSECINTFCFGIPSEC: INTERFACENAME="Tunnel10", TNLTYPE=IPSEC, POLICYNAME="ipsecply2";
      ```
   9. 设置SWu接口UE接入速率和UPF老化时长。
      * 主UPF配置，设置SWu接口UE接入速率为1000个/s，老化时长为0：

        ```
        SET UPNON3GPPPARA: SWUWAL=1000, AGINGTIME=0;
        ```
      * 备UPF配置，设置SWu接口UE接入速率为1000个/s，老化时长为1440：

        ```
        SET UPNON3GPPPARA: SWUWAL=1000, AGINGTIME=1440;
        ```
