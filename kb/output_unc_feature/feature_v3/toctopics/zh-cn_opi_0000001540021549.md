# 5G广播会话跟踪

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

* 系统运行出现故障需要进行5G广播跟踪定位排除故障。
* 维护人员调试设备运行情况。

## 必备事项

前提条件

* 具备管理员权限的操作员已经登录OM Portal。
* 维护人员具有用户消息跟踪权限。
* 有5G广播业务激活。

数据

| 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- |
| TMGI | 460-03-000001 | 本端规划 | - |

## 操作步骤

1. 进入跟踪操作界面：登录OM Portal，在OM Portal主界面依次选择“监控分析”->“消息跟踪”，进入跟踪导航树界面，如图1所示。

   **图1** 消息跟踪操作界面
2. 输入用户跟踪任务参数：在左侧跟踪导航树界面选择“UNC” ->“用户跟踪” -> “5G广播跟踪”后，单击“添加”，进入用户跟踪任务创建的界面，依次输入“任务名称”、“跟踪时长”和“定位条件”、参数，如图2所示。

   **图2** 5G广播跟踪参数配置对话框

   * 上图中的过滤选项不会过滤MsgBetweenHttpLocm和MsgBetweenHttpMbms5g两种消息名称的消息。
   * 开启此跟踪功能后，SBIM服务作为Server端接收外部请求消息量越大，SBIM Pod内HTTP进程CPU开销越大，可能产生“ALM-100117 HTTP资源过载”告警。执行DSP HTTPPROCES命令查询HTTP进程CPU负载超过65%后，不建议创建此跟踪。
   * MBS广播会话跟踪建立后会增加系统负荷，当前仅支持同时创建**2**个广播会话跟踪。

   参数说明如表2所示。

   **表2** 5G广播跟踪参数配置说明

   | 参数名称 | 参数说明 | 取值范围 | 默认值 |
   | --- | --- | --- | --- |
   | 任务名称 | 用于指定该次跟踪任务的名称。 | - | - |
   | 跟踪时长 | 用于指定该次跟踪任务的时长。 | 1分钟~720小时59分钟 | 1（小时） |
   | TMGI | 当 “选项”值为 “TMGI”时，该参数会显示，表示需跟踪的MBS广播会话标识。 | 字符串，格式为MCC-MNC-MBS Service ID | 无 |
   | 上报内部消息 | 用于选择是否开启内部消息上报。 | ·False  ·True | True |
3. 单击“确定”，启动跟踪任务。
