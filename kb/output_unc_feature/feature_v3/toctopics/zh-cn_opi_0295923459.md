## 操作场景

普通在线计费不区分业务内容进行统一计费，在线计费的计费粒度有四种：UserProfile、APN、计费属性Charging Characteristics和全局，优先级依次降低。如果高一级别的计费参数没有配置，则继承低一级别的计费参数。

适用于GGSN、PGW-C。

## 必备事项

前提条件

* 请仔细阅读Ga/Gy接口离线/在线计费。
* 完成配置到OCS的数据(静态路由+BFD组网)。

## 操作步骤

1. 配置计费属性。

   **ADD CHARGECHAR**

   如果该计费属性实例没有绑定APN实例或者UserProfile实例，则配置的计费属性不生效。
2. 配置用户的计费方式是在线计费。

   **SET CHARGECTRL**
3. 配置在线计费的费率标识。
   1. 配置URR，从而配置相应的计费费率标识，包括必须配置的RG和可选配置的SID。

      **ADD URR**
   2. 配置URR组，将上下行URR绑定到URR组上。上下行可以使用不同的URR。

      **ADD URRGROUP**
4. 配置DCC模板。

   1. 全局DCC模板。

      **MOD DCCTEMPLATE**
   2. DCC模板。

      **ADD DCCTEMPLATE**

   配置全局DCC模板使用命令全局**MOD DCCTEMPLATE**，其他粒度（UserProfile、APN、计费属性Charging Characteristics）的DCC模板使用命令**ADD DCCTEMPLATE**，在模板下配置在线计费参数（如步骤 6~步骤 9），最后绑定不同的粒度范围。

   由此可见，主要是粒度范围不一致，其他的计费参数命令类似。
5. 配置在线计费设备标识。
   1. 配置在线计费中通信的GGSN/PGW-C设备标识，重复执行本步可添加多个Gy应用的本地信息。

      **ADD DIAMLOCINFO**
   2. 配置OCS信息。重复执行本步可增加多个OCS信息。

      **ADD OCS**
   3. 配置OCS组。

      **ADD OCSGROUP**

      **ADD OCSBINDING**
   4. 配置主从OCS组。

      **ADD DCCTEMPLATE**
6. 配置配额门限（配额空耗时间QCT、配额空闲时间QHT、流量门限阈值VQT、时长门限阈值TQT）。

   **ADD DCCTEMPLATE**
7. 配置CCR触发机制（SGSN/SGW地址改变发送CCR、业务触发请求CCR、CCR-I消息中允许携带的RG的最大个数）。

   **ADD DCCTEMPLATE**
8. 配置定时器。
   1. 配置Tx定时器的时长。

      **SET TXTIMER**
   2. 配置Tx定时器超时以后的处理方式。

      **ADD DCCTEMPLATE**
9. 配置MSCC层消息码为异常返回码时的业务处理动作。

   **ADD MSCCRCACT**
10. 为APN实例绑定计费属性、计费方式、DCC模板。

    本实例以APN粒度为例说明普通在线计费的配置步骤，对于UserProfile和计费属性Charging Characteristics粒度的配置步骤，与APN粒度的配置步骤类似，只是绑定范围不同。

    对于全局粒度的普通在线计费配置步骤，没有绑定动作，不同的是采用的是全局DCC模板**MOD DCCTEMPLATE**。

    为APN实例"apn-test"绑定计费属性、计费方式、计费模板。

    **SET APNCHARGECTRL**

    针对同一个用户，**ADD CHARGECHAR**和**ADD CHARGEMETHOD**配置的结果要保持一致，要么是“ONLINE”，要么是“OFFLINE”，或者两者同时使能，如果不一致将导致用户计费方式错误。

## 任务示例

任务描述

在GGSN/PGW-C上实现基于APN的普通在线计费，即不区分内容的计费。

脚本

1. 配置计费属性。

   ```
   ADD CHARGECHAR:CCNAME="testchgcha", HOME="0x0800", ROAM="0x0800", VISIT="0x0800", HOMESGSN=ENABLE, ROAMSGSN=ENABLE, VISITSGSN=ENABLE;
   ```
2. 配置用户的计费方式是在线计费。

   ```
   SET CHARGECTRL: HOMEONLINE=ENABLE, VISITONLINE=ENABLE, ROAMONLINE=ENABLE;
   ```
3. 配置在线计费的费率标识。

   ```
   ADD URR: URRNAME="onlineURR", URRID=1100, USAGERPTMODE=ONLINE, ONLCOMPOUNDTYPE=RGSID, ONLINERG=10, ONLINESID=20;
   ```

   ```
   ADD URRGROUP: URRGROUPNAME="urrgroup1", UPURRNAME1="onlineURR", DOWNURRNAME1="onlineURR";
   ```
4. 配置DCC模板（配额门限、CCR触发机制）。

   ```
   ADD DCCTEMPLATE: DCCTMPLTNAME="dcc-test", QCT=0, QHT=0, VQT=20, TQT=20, CCRINITRGNUM=5, CCFH=TERMINATE, SGSNTRIGGER=ENABLE, SERVICETRIGGER=ENABLE;
   ```
5. 配置在线计费设备标识。

   ```
   ADD DIAMLOCINFO: HOSTNAME="pgw1",REALMNAME="huawei.com",PRODUCTNAME="unc@huawei.com";
   ```

   ```
   ADD OCS: OCSHOSTNAME="ocs_host", REALMNAME="ocs_realm";
   ```

   ```
   ADD DIAMPEERADDR: HOSTNAME="ocs_host", ADDRTYPE=IPv4, IPV4ADDRESS="192.168.40.10";
   ```

   ```
   ADD OCSGROUP: OCSGRPNAME="ocs-grp";
   ```

   ```
   ADD OCSBINDING: OCSGRPNAME="ocs-grp", OCSHOSTNAME="ocs_host";
   ```

   配置DCC模板绑定的OCS组。

   ```
   MOD DCCTEMPLATE: DCCTMPLTNAME="dcc-test", PRIOCSGRPNAME="ocs-grp";
   ```
6. 配置定时器。

   ```
   SET TXTIMER: DCCTMPLTNAME="dcc-test", TXTIMERFLAG=TXTIMER_VALUE, TXTIMER=10;
   ```
7. 配置业务处理动作。

   ```
   ADD MSCCRCACT: DCCTMPLTNAME="dcc-test", MSCCRC="4012", MSCCRCACT=TERMINATE;
   ```

   ```
   ADD MSCCRCACT: DCCTMPLTNAME="dcc-test", MSCCRC="5003", MSCCRCACT=BLOCK;
   ```
8. 为APN实例"apn-test"绑定计费属性、计费方式、DCC模板。

   ```
   SET APNCHARGECTRL: APN="apn-test", ONLINESW=ENABLE, DCCTEMPLATE="dcc-test", CCNAME="testchgcha";
   ```
