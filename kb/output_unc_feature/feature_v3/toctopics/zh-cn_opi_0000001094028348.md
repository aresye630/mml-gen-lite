## 操作场景

本操作指导介绍在运行网络中激活支持ODB特性的操作过程。

支持ODB（Operator Determined Barring）特性，即运营商决定的闭锁，运营商能够通过设置ODB参数限制一些用户的业务和服务。

适用于AMF

## 必备事项

前提条件

* 请仔细阅读WSFD-106005 支持ODB（适用于AMF）特性概述。
* 需要对端网元UDM支持ODB特性。

数据

该操作无需准备数据。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. 开启ODB注册和PDU会话建立流程参数检查开关。

   **SET NGMMFUNC**
3. 配置注册流程ODB拒绝原因值。

   **SET NGMMPROCTRL**
4. 配置PDU会话建立流程ODB拒绝原因值。

   **SET SMPDUCTRL**

## 任务示例

任务描述

配置AMF支持禁止用户所有分组域业务。

脚本

//开启ODB参数检查开关。

```
SET NGMMFUNC: REGODBPLCY=YES,PDUESTODBPLCY="YES"；
```

//配置注册流程ODB拒绝原因值。

```
SET NGMMPROCTRL: PROT=UDM_REGISTRATION, ODBREJCAUSE=0;
```

//配置PDU会话创建流程ODB拒绝原因值。

```
SET SMPDUCTRL: ODBREJCAUSE=0;
```
