# 检查主备NRF运行状态

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

通过检查NRF容灾组的运行状态，确保主、备NRF运行正常。

## 必备事项

前提条件

操作人员已经登录OM Portal或U2020/MAE。

数据

该操作无需准备数据。

## 操作步骤

1. 分别通过**DSP GRGROUP**命令查询正在运行的主、备NRF的状态信息，容灾数据备份状态信息是否与实际规划一致。

   * 预期结果：
     + “运行状态”为“主”或“备”，“握手状态”为“连接”。
     + “容灾数据备份状态”为“实时备份”或短时间为“批量备份”。
   * 非预期结果：执行2。
     + “运行状态”为“无”或“空闲”。
     + “运行状态”为“主”或“备”，“握手状态”为“断连”。
     + “容灾数据备份状态”为“无备份”或“异常”或一直为“批量备份”。
2. 检查结果不符合预期，请收集告警信息、日志信息和配置信息，并联系华为技术支持处理。
