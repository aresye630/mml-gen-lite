## 操作场景

该场景根据整体方案设计需配置1个业务，该业务挂载在1个策略，该策略包含2个规则：

* 规则1（Rule\_Normal）：
  + 条件：QuotaStatus=Normal
  + 动作：下发预定义规则标识“Rule\_Normal”。
* 规则2（Rule\_Exhaust）：
  + 条件：QuotaStatus=Exhaust
  + 动作：下发预定义规则标识“up\_Exhaust”。

## 对系统的影响

该业务对系统无影响。

## 必备事项

前提条件

已通过学习SM策略E2E实现原理、业务配置方法及业务调测方法了解了SM策略的配置原理及方法。

数据

无。

## 操作步骤

1. 登录**“UPCF Web UI”**界面。
2. 配置“配额”。

   导航入口为“业务管理 > 业务 > 配额”。

   |  |  | 类型 | 会话级 |

3. 配置“短信/邮件模板”。

4. 配置“消息通知”。

   导航入口为“策略管理 > 策略 > 消息通知”。

   “唯一键”为抑制发送消息通知的条件。例如，在配额状态不改变时，则抑制发送相同的消息通知，“唯一键”选择对象“Quota”下的属性“QuotaStatus”。

10. **开户。**

    **登录“UPCF PGW Web LMT>UPCF 业务管理”窗口**，将配置完成的业务通过UPCF开户签约系统进行下发。

    执行**ADD PSUB**增加一个用户。

    ```
    ADD PSUB: USRIDENTIFIER="46001122334****", USRMSISDN="861358700****", USRSTATE=Normal, USRPAIDTYPE=NULL, USRSTATION=Master, USRCONTACTMETHOD=SMS, USRBILLCYCLEDATE=NULL, USRSUBNETTYPE=eMBB-SA, USRLANGUAGE=NULL, USRSMSRECEIVEFLAG=All, USRVERSTATUS=Normal;
    ```
11. **业务发放。**

    在“UPCF PGW Web LMT>UPCF 业务管理”窗口继续执行**ADD PSRV**给用户签约业务。

    ```
    ADD PSRV: USRIDENTIFIER="46001122334****", SRVNAME="Redirection_Service", SRVUSAGESTATE=Normal, SRVROAMINGTYPE=NULL;
    ```
