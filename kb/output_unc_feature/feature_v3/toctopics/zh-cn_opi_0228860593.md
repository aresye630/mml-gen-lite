## 操作场景

本操作指导介绍“主锚点UPF双主负荷分担部署模式”容灾组网配置的操作过程。

## 必备事项

前提条件

* 请仔细阅读WSFD-108004 MEC冗余模式故障保护。
* 已完成加载License。
* 以下配置过程是基于SMF和**主锚点UPF**的对接配置已完成情况下的操作。且需要在**主锚点UPF双主负荷分担部署模式**下确保SMF对每个主锚点UPF配置相同的DNN、位置区选择策略。SMF和主锚点UPF的对接配置参见N4接口配置。

## 操作步骤

1. 进入“MML命令行-UNC”窗口。
2. **配置主锚点UPF双主负荷分担部署模式****下的故障保护机制**。

   1. 确认UPF模式位置特征为Central模式。

      **MOD UPNODE**
   2. 配置SMF到UPF的心跳探测并开启故障场景下去活该UPF上用户会话的功能。

      **SET PFCPPARA**
   3. 配置UPF粒度的SMF到UPF的心跳探测并开启故障场景下去活该UPF上用户会话的功能。

      **ADD UPFPFCPPARA**
   4. 配置故障场景下对用户会话的去活速率。

      **SET DEACTIVERATE**
3. 打开本特性的License配置开关。

   **SET LICENSESWITCH**

## 任务示例

任务描述

主锚点UPF1和UPF2下沉边缘侧，开启主锚点UPF双主负荷分担部署模式下的故障保护功能。这两个UPF对应的实例标识分别为UPF\_Instance\_0、UPF\_Instance\_1，其中对UPF\_Instance\_0的故障探测机制继承SMF全局探测机制，对UPF\_Instance\_1则需要单独的故障探测机制。

脚本

//确认UPF模式位置特征为Central模式。

```
MOD UPNODE: NFINSTANCENAME="UPF_Instance_0",LOCATION=Central;
MOD UPNODE: NFINSTANCENAME="UPF_Instance_1",LOCATION=Central;
```

//配置SMF到UPF的心跳探测并开启故障场景下去活该UPF上用户会话的功能。

```
SET PFCPPARA: HBINTERVAL=30,HBT1=3,HBN1=5,DEACTIVEFLAG=ENABLE,DACTINTERVAL=900;
ADD UPFPFCPPARA: UPFINSTANCEID="UPF_Instance_1", HBINTERVAL=60, HBT1=5, HBN1=3, DEACTIVEFLAG=ENABLE, DACTINTERVAL=900;
```

//配置故障场景下对用户会话的去活速率。

```
SET DEACTIVERATE: RATE=1000;
```

//打开本功能的License配置开关。

```
SET LICENSESWITCH: LICITEM="LKV2DMECFP01", SWITCH=ENABLE;
```
