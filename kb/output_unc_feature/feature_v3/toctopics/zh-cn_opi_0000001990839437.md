## 操作场景

本指导描述离线计费话单缓存功能的相关配置过程。

开启离线计费后，当CG发生故障或者UNC与CG之间链路异常导致无法发送话单时，为避免造成计费损失，UNC支持将话单消息暂时缓存在本地。待CG状态恢复正常后，再将缓存的话单重新发送到CG。

当UNC本地有缓存话单文件时，会上报**ALM-81025 话单缓存**告警；当本地不再有缓存话单文件时，告警恢复。当缓存话单文件长期未处理，缓存时长超过配置的超时时间则会上报**ALM-81059 超期缓存话单**告警，提示维护人员处理缓存话单，以免造成计费损失；当本地没有已配置话单版本的超期缓存话单文件时，告警恢复。

## 必备事项

前提条件

请仔细阅读Ga/Gy接口离线/在线计费。

数据

如下示例参数值为举例，请根据业务实际需要进行配置。

| 类别 | 参数名称 | 取值样例 | 获取方法 | 说明 |
| --- | --- | --- | --- | --- |
| **SET CDRSTORAGECTRL** | 话单缓存超期天数（CDREXPIREDAY） | 3 | 本端规划 | 配置缓存话单文件的超期时间。 |
|  | 话单缓存超期周数（CDREXPIREWEEK） | 3 | 本端规划 |  |
| **SET OFCCDRPARA** | 话单缓存加密开关（STGENCRYPT） | DISABLE | 本端规划 | 配置是否对离线计费缓存话单进行加密。此处以不对离线计费缓存话单加密举例，请根据业务需要配置。 |

## 操作步骤

1. 配置缓存话单文件的超期时间。

   **SET CDRSTORAGECTRL**
2. 配置是否对离线计费缓存话单进行加密。

   **SET OFCCDRPARA**

## 任务示例

任务描述

配置离线计费话单缓存功能。

脚本

1. 配置缓存话单文件的超期时间。

   ```
   SET CDRSTORAGECTRL: CDREXPIREDAY=3,CDREXPIREWEEK=3;
   ```
2. 配置不对离线计费缓存话单进行加密。

   ```
   SET OFCCDRPARA: STGENCRYPT=DISABLE;
   ```
