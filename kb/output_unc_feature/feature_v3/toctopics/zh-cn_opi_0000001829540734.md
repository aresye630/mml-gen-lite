# 配置UPF选择优先级策略

* 操作场景
* 必备事项
* 操作步骤

## 操作场景

SMF/PGW-C/SGW-C/GGSN选择UPF先根据选择UPF的**必选条件**选择UPF，再根据选择UPF的**优选条件**选择UPF，确定最终选择的UPF。

更多UPF选择内容请参考UPF选择专题。

## 必备事项

前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* 已经获取网设LLD文档。

数据

| 类别 | 参数名称 | 取值样例 |  | 获取方法 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **SET UPSELECTFLAG** | 位置区UPF优选开关(LOCALITYFLAG) | ENABLE（不推荐） |  | 本端规划 | 设置UPF选择条件开关。 |
|  | 基于位置优选主锚点UPF开关(PSAPOSPRIFLAG) | ENABLE（推荐） |  | 本端规划 |  |
| **SET UPSELECTPRI** | 第一优先级(FIRSTPRIORITY) | LocS11Priority |  | 本端规划 | 设置UPF选择策略次序。 |

文档

获取网设LLD文档。

## 操作步骤

1. 配置UPF选择优先级(5G)。

   //（可选）配置UPF服务的位置区域关联关系。

   * 对于省内部署了多个覆盖全省或者覆盖多个地市的中心UPF，但是每个UPF又规划为针对单个地市做位置优选时，才可以采用该locality方式做位置优选。
   * 针对SMF/PGW-C/SGW-C/GGSN对PGW-U和GGSN-U的位置优选，推荐LOCALITY绑定方式。SMF直接基于LOCALITY优选锚点UPF的前提是ADD PNFSMFSERAREA、ADD UPAREABINDLAI、ADD UPAREABINDS1TAI、ADD UPAREABINDN2TAI配置了各个地市UPF的覆盖服务范围。

   ```
   SET UPSELECTFLAG:LOCALITYFLAG=ENABLE;
   ```
2. 配置SMF/PGW-C/SGW-C/GGSN选择锚点UPF时根据位置区做优选，包括4G激活时选择PGW-U，以及2G激活时选择GGSN-U。

   ```
   SET UPSELECTFLAG:PSAPOSPRIFLAG=ENABLE;
   ```
3. 配置SMF/PGW-C/SGW-C/GGSN选择UPF的优先级。

   ```
   SET UPSELECTPRI: FIRSTPRIORITY=Combined, SECONDPRIORITY=LocS11Priority,THIRDPRIORITY=Load;
   ```
