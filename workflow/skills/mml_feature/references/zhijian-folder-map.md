```

```

### 提取注意事项

1. **命令链来源**：
   - 有"任务示例"的 496 个文件 → 直接从脚本段提取可执行 MML
   - 只有"操作步骤"+"数据"的 444 个文件 → 从数据表的命令名+参数表拼接 MML

2. **适用条件提取**：
   - 网元类型：操作场景段落的文本（"适用于 PGW-U、UPF"）
   - 组网场景：文件路径中的目录名（kite_s_vm → 风筝S容器版）
   - 版本信息：文件名中可能包含版本号（ueg_2110_... → V200R021C10）

3. **toctopics 目录的文件是导航目录**，不含命令示例，不要索引为 KB 记录。

4. **分类标签提取**：
   - 特性级分类：`<场景>/feature/` 目录下的文件
   - 解决方案级：`<场景>/cdgw/ic/` 下的命令示例
   - 目录级：nav 文件的层级关系（仅用于标签，不存命令内容）

## output_ueg_mml（命令校验来源）


## output_ueg_nav（不存 KB，仅辅助分类）

### 文件结构

纯目录导航文件，结构示例：
```
# 5GC toB 原子能力-5G LAN
## 目录内容
- 5GC toB 原子能力-5G LAN
  - 特性指南
    - UEG特性指南
      - 可选功能
        - 漫游场景5G LAN终端互访控制
          - 漫游场景5G LAN终端互访控制配置
        - GWFD-030703 支持IGMP Snooping
          - 激活IGMP Snooping
```

### 唯一用途

提取**特性-场景-功能**的多级分类体系，用于 KB-A 记录的标签生成：
- 从目录树的每一级提取分类标签
- 记录特性之间的关系（父级、同级、子级）
- 用于检索时的分类过滤和推荐扩展

### 为什么不存 KB

- 导航文件本身不含任何配置命令
- 目录关系可在 feature 文件的文件路径中推断（<场景>/feature/<特性>.md）
- nav 文件的维护状态与 feature 文件不同步，不可靠
