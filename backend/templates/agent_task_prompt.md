【★★★ 必选参数完整性（平台会校验，G10）】

逐条对照命令文档的 `可选必选说明`：

1. 标「**必选参数**」的：必须给值，或给 `<参数名>` 占位符（与 CSV 同名）。
2. 标「**条件必选参数**」的：按文档「前提条件」判断是否成立，成立即视为必选。
   例：
   - `ADD SECTION` 的 `V4STARTIP/V4ENDIP` 仅在 `IPVERSION=IPV4` 时必选；
   - `ADD FILTER` 的 `HOSTNAME` 仅在 `SVRIPMODE=DOMAIN/HOSTNAME` 时必选；
   - `ADD SECTION` 的 `V6PREFIXSTART/V6PREFIXEND` 仅在 `IPVERSION=IPV6` 时必选。
3. 条件成立但确实无值：**不得省略**，写 `<参数名>` 占位符并列入「待澄清点」。
4. 查询类命令（`LST` / `DSP`）的条件必选参数是**查询过滤条件，可省略**，不必硬填。

常见条件组合（易漏，务必对照）：
- `ADD FILTER/FILTERIPV6` 当 `SVRIPMODE=DOMAIN` 时 `HOSTNAME` 与 `DOMAINVALUE` 两个都要给；
- `ADD FILTER` 当 `SVRIPMODE=IP` 时用 `SVRIP`+`SVRIPMASKTYPE`+`SVRIPMASKLEN`
  （IPv6 族用 `SVRIPV6`+`SVRIPV6MASKTYPE`+`SVRIPV6MASKLEN`）；
- `ADD RPTSVRADDR` 当 `IPTYPE=IPV6` 时必须给 `IPV6_ADDR`；
- `RMV URRGRPBINDING` 必选 `URRGROUPTYPE`（SERVICE/SIGNALING/TCP/REDIRECT）；
- `LCK SECTION` / `LCK APN` 的 `ISLOCKED` / `LOCKED` 是必选。

【★ 落盘方式(强制,违反会导致产物丢失)】
长内容禁止一次性写出,必须**分段追加**。原因:一次写十几 KB 会因流式生成被截断,
而截断的 JSON 无法修复,工具参数会被清空 ⇒ 文件根本没写出来(实测损失率高)。
所有 .md / .csv / .py 产物一律按下面的**固定格式**分段落盘:

  第 1 段(建文件,只写标题块,不超过 20 行):
      write_file(path="<工作目录>/配置分析_<主题>.md", content="第一段内容")
  第 2..N 段(逐段追加,每段不超过 40 行):
      terminal(command="cat >> <工作目录>/配置分析_<主题>.md <<'EOF'
      <该段内容>
      EOF")

  要求:
  - 每段 ≤ 40 行;整份文档按五段式拆成 5~8 段依次追加
  - 每段追加后必须看到 terminal 返回 0(失败则重试该段)
  - CSV 同样分段:先用 python3 生成表头+前若干行写入,再 `>>` 追加后续行
  - 禁止用 `cat >`(覆盖),只用 `cat >>`(追加),否则前段会被冲掉
