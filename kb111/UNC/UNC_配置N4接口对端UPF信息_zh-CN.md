```text
## 操作场景
配置N4接口对端UPF信息需要配置SMF为优先使用UPF分配地址、配置对端UPF节点、配置对端NF实例概述信息和配置UPF绑定到特定的IP Domain，同时需配置N4接口可靠性。

## 必备事项
前提条件

* 具备管理员权限的操作人员已经登录华为操作维护系统（登录U2020/MAE客户端或登录OM Portal）。

* 已经获取网设LLD文档。
* **SMF和UPF对接支持Full Mesh组网，若未申请对应license，可能仅支持一套SMF和一套UPF对接。如果涉及多套SMF和UPF互相对接，请提前完成加载"82209930 LKV2CUFMN01 CU FullMesh组网"License控制项。CU Full Mesh组网详细请参考WSFD-213001 CU FullMesh组网。**
```

## 3 命令模板定义
<!-- @mml:block=commands -->

### 1 **涉及多套SMF和UPF互相对接时，打开CU Full Mesh的License配置开关。如未来有计划规划Full Mesh组网，强烈建议执行该步骤，避免后续由于License申请和操作遗漏导致SMF和UPF对接失败。**

```jinja2
{%- for item in set_licenseswitch_list -%}
    SET LICENSESWITCH:
    {#- --- 必选参数 --- -#}
    LICITEM="{{item.LICITEM}}",
    SWITCH={{item.SWITCH}},
    ;
{%- endfor -%}
```

### 2 配置UE地址优先由UPF分配，如UPF未分配，则由SMF分配。

```jinja2
{%- for item in set_addressattr_list -%}
    SET ADDRESSATTR:
    {#- --- 可选参数 --- -#}
    {%- if item.ALLOCPRECEDENCE is not none -%}
        ALLOCPRECEDENCE={{item.ALLOCPRECEDENCE}},
    {%- endif -%}
    ;
{%- endfor -%}
```

### 6 配置N4接口可靠性。

```jinja2
{%- for item in set_pfcppara_list -%}
    SET PFCPPARA:
    {#- --- 可选参数 --- -#}
    {%- if item.HBINTERVAL is not none -%}
        HBINTERVAL={{item.HBINTERVAL}},
    {%- endif -%}
    {%- if item.HBT1 is not none -%}
        HBT1={{item.HBT1}},
    {%- endif -%}
    {%- if item.HBN1 is not none -%}
        HBN1={{item.HBN1}},
    {%- endif -%}
    {%- if item.DEACTIVEFLAG is not none -%}
        DEACTIVEFLAG={{item.DEACTIVEFLAG}},
    {%- endif -%}
    {%- if item.RPTRSPAGETIME is not none -%}
        RPTRSPAGETIME={{item.RPTRSPAGETIME}},
    {%- endif -%}
    {%- if item.MIGINTERVAL is not none -%}
        MIGINTERVAL={{item.MIGINTERVAL}},
    {%- endif -%}
    {%- if item.CHECKFLAG is not none -%}
        CHECKFLAG={{item.CHECKFLAG}},
    {%- endif -%}
    {#- --- 条件可选参数 --- -#}
    {#- --- 条件可选：DEACTIVEFLAG=ENABLE 时可选 --- -#}
    {%- if item.DEACTIVEFLAG == 'ENABLE' -%}
        {%- if item.DACTINTERVAL is not none -%}
            DACTINTERVAL={{item.DACTINTERVAL}},
        {%- endif -%}
    {%- endif -%}
    ;
{%- endfor -%}
```
