```text
## 操作场景
该IPFarm被用于重定向时，修改该IPFarm的VIRTUALIP。适用于PGW-U、UPF。

## 必备事项
前提条件

* 请仔细阅读GWFD-110282 Web Proxy。
* 完成配置Web Proxy。
```

## 3 命令模板定义
<!-- @mml:block=commands -->

### 1 修改IPFARM对应的VIRTUALIP。

#### 1.1 //修改IPFARM对应的VIRTUALIP。

```jinja2
{%- for item in rmv_rule_list -%}
    RMV RULE:
    {#- --- 必选参数 --- -#}
    RULENAME="{{item.RULENAME}}",
    ;
{%- endfor -%}
```

```jinja2
{%- for item in mod_ipfarm_list -%}
    MOD IPFARM:
    {#- --- 必选参数 --- -#}
    IPFARMNAME="{{item.IPFARMNAME}}",
    {#- --- 可选参数 --- -#}
    {%- if item.IPVERSION is not none -%}
        IPVERSION={{item.IPVERSION}},
    {%- endif -%}
    {#- --- 条件可选参数 --- -#}
    {#- --- 条件可选：IPVERSION=IPV4 时可选 --- -#}
    {%- if item.IPVERSION == 'IPV4' -%}
        {%- if item.VIRTUALIP is not none -%}
            VIRTUALIP="{{item.VIRTUALIP}}",
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：IPVERSION=IPV6 时可选 --- -#}
    {%- if item.IPVERSION == 'IPV6' -%}
        {%- if item.VIRTUALIPV6 is not none -%}
            VIRTUALIPV6="{{item.VIRTUALIPV6}}",
        {%- endif -%}
    {%- endif -%}
    ;
{%- endfor -%}
```
