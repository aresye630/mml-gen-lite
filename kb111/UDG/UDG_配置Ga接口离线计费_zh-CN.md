```text
## 操作场景
离线计费中，UDG支持按用户使用的业务进行离线计费，UDG与UNC消息交互时需要用到URR ID，上报计费信息。适用于SGW-U、PGW-U。

## 必备事项
前提条件

请仔细阅读Ga/Gy接口离线/在线计费。
```

### 配置内容计费使用的URR Group。

#### 1.1 配置URR。

```jinja2
{%- for item in add_urr_list -%}
    ADD URR:
    {#- --- 必选参数 --- -#}
    URRNAME="{{item.URRNAME}}",
    URRID={{item.URRID}},
    USAGERPTMODE={{item.USAGERPTMODE}},
    {#- --- 条件可选参数 --- -#}
    {#- --- 条件可选：USAGERPTMODE=OFFLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE == 'OFFLINE' -%}
        {%- if item.OFFMETERINGTYPE is not none -%}
            OFFMETERINGTYPE={{item.OFFMETERINGTYPE}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE == 'ONLINE' -%}
        {%- if item.DFTQUOTAPARA is not none -%}
            DFTQUOTAPARA={{item.DFTQUOTAPARA}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE == 'ONLINE' -%}
        {%- if item.DFTQUOTATIME is not none -%}
            DFTQUOTATIME={{item.DFTQUOTATIME}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE == 'ONLINE' -%}
        {%- if item.DFTQUOTAVOLUME is not none -%}
            DFTQUOTAVOLUME={{item.DFTQUOTAVOLUME}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE == 'ONLINE' -%}
        {%- if item.ONLMETERINGTYPE is not none -%}
            ONLMETERINGTYPE={{item.ONLMETERINGTYPE}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE/OFFLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE in ['ONLINE', 'OFFLINE'] -%}
        {%- if item.RG is not none -%}
            RG={{item.RG}},
        {%- endif -%}
    {%- endif -%}
    {#- --- 条件可选：USAGERPTMODE=ONLINE/OFFLINE 时可选 --- -#}
    {%- if item.USAGERPTMODE in ['ONLINE', 'OFFLINE'] -%}
        {%- if item.SID is not none -%}
            SID={{item.SID}},
        {%- endif -%}
    {%- endif -%}
    ;
{%- endfor -%}
```

### 6 **可选**：设置URR上报失败后的动作处理参数。

```jinja2
{%- if is_optional_set_urr_fail_action -%}
    SET URRFAILACTION:
    ;
{%- endif -%}
```

### 该命令在离线计费新业务场景下生效。

### 当业务部署调整导致SGW-U/PGW-U的URR ID在SGW-C/PGW-C上不存在时(比如，先添加SGW-U/PGW-U上**ADD URR**，后添加SGW-C/PGW-C上**ADD URR**)，会导致SGW-C/PGW-C无法处理SGW-U/PGW-U的计费用量上报。为减小该场景下对用户业务的影响，可通过该命令设置SGW-U/PGW-U向SGW-C/PGW-C进行计费用量上报失败时的处理动作。

### 当计费URR上报失败，业务被阻塞时，如果想要放通业务，可以执行**SET URRFAILACTION**命令，配置“RETRYFAILACT”参数为“CONTINUE”，则URR对应的业务将不计费。在SGW-U/PGW-U向SGW-C/PGW-C进行用量上报恢复后，将恢复对该URR的计费。
