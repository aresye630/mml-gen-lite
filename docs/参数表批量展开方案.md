# 参数表批量展开方案

## 问题

大工单本质是「一套模板 × N 个业务对象」：
```
NC20260824002208：
  42 个池组名（grp-cmnet-ipv6-lfsmf01-tj-bcq / ... / grp-cmnet-ipv6-lfsmf03-tj-xqq）
  每个池组对应 5 条命令：POOLGROUP + POOLBINDGROUP + POOLGRPMAP×3 + POOL

  GT 645 条 = 42 组 × 约 15 条
  agent 产物 69 组 ≈ 334 行（只配了 3-4 个池的模板）
```

## 方案：模板 + 变量 + 清单 → 展开

### 第一步：agent 输出「模板」

在 params.csv 里，用**变量占位符**表示可替换的部分：

```csv
序号,组,网元,命令族,参数,值,来源,说明
1,POOLGROUP#T,UDG,ADD POOLGROUP,POOLGRPNAME,{{grp_name}},template,池组名
2,POOLGROUP#T,UDG,ADD POOLGROUP,IPV4ALLOCPRIALG,DISABLE,template,
3,POOLGROUP#T,UDG,ADD POOLGROUP,IPV6ALLOCPRIALG,ENABLE,template,
4,POOLBINDGROUP#T,UDG,ADD POOLBINDGROUP,POOLGROUPNAME,{{grp_name}},template,
5,POOLBINDGROUP#T,UDG,ADD POOLBINDGROUP,POOLNAME,{{pool_name}},template,
...
```

**关键：`{{grp_name}}` 是变量，而不是具体值。**

### 第二步：清单文件（用户提供或从意图提取）

```
grp-cmnet-ipv6-lfsmf01-tj-bcq
grp-cmnet-ipv6-lfsmf01-tj-bdq
...
```

### 第三步：代码展开

```python
for i, grp in enumerate(grp_list, 1):
    for row in template_rows:
        new_row = row.copy()
        new_row['组'] = row['组'].replace('#T', f'#{i}')
        new_row['值'] = row['值'].replace('{{grp_name}}', grp)
        # 派生变量
        new_row['值'] = new_row['值'].replace('{{pool_name}}', grp.replace('grp-', 'pool-'))
        out.append(new_row)
```

### 第四步：generate 出最终 mml

用现有的 `/regenerate` 即可。

## 变量命名约定（不硬编码）

| 变量 | 含义 | 从哪来 |
|---|---|---|
| `{{<族名>_name}}` | 该族的主键值 | 清单文件 |
| `{{prev_var}}` | 上一条命令的主键值 | 自动 |
| 派生规则 | `pool-*` 从 `grp-*` 推导 | agent 在模板里写明 |

**关键：派生规则由 agent 在模板里声明，代码只做替换。**

## 需要 agent 配合的改动

在 prompt 里说明：
```
业务数据里有 N 个同类对象时：
  · 只写一份模板，变量用 {{xxx}} 表示
  · 在「说明」列写清变量来源（如「来自业务数据池组名清单」）
  · 如果某个参数是从其他参数派生的，说明派生规则
```

## 实现清单

1. `/expand` 接口：输入会话 ID + 变量清单 → 输出展开后的 params.csv
2. 界面：产物面板加「批量展开」按钮，弹窗填清单
3. prompt：引导 agent 用 `{{var}}` 模板
4. G21：校验展开后的数量与清单一致
