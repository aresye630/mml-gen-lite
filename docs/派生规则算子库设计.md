# 派生规则算子库设计

## 设计原则

1. **算子固定**：代码里只有有限的几种字符串变换算子
2. **规则数据化**：YAML 配置，不是代码
3. **agent 只填表**：从算子库里选，不能自创语法
4. **可校验**：用 GT 反推的样本验证算子覆盖度

## 算子集合（从真实数据分析得出）

### 算子 1：前缀替换 `PREFIX_REPLACE`
```
输入：grp-cmnet-ipv6-lfsmf01-tj-bcq
规则：PREFIX_REPLACE(old=grp, new=pool)
输出：pool-cmnet-ipv6-lfsmf01-tj-bcq

真实用例：
  grp-* → pool-*
  grp-* → map-*
  cmnet → pgrp-cmnet
```

### 算子 2：追加后缀 `APPEND`
```
输入：sos
规则：APPEND(suffix=_sig_f_001)
输出：sos_sig_f_001

真实用例：
  sos → sos_sig_f_001
  sos → sos_sig_f_002
  tj-bcq → tj-bcq-2g
```

### 算子 3：中间插入 `INSERT`
```
输入：up_sos
规则：INSERT(after=up, text=group_)
输出：up_group_sos

真实用例：
  up_sos → up_group_sos
```

### 算子 4：拼接列 `CONCAT`
```
输入：(区=tj-bcq, 制式=2g)
规则：CONCAT(cols=[区, 制式], sep=-)
输出：tj-bcq-2g

真实用例：
  LOCATIONGRPNAME = 区 + "-" + 制式
```

### 算子 5：条件映射 `MAP`
```
输入：2g
规则：MAP({2g: LAC, 4g: TAC, 5g: TAC}, default=TAC)
输出：LAC

真实用例：
  LOCATIONGRPTYPE 2g→LAC，其他→TAC
```

### 算子 6：序号递增 `SEQ`
```
输入：-
规则：SEQ(prefix=1, step=1)
输出：1, 2, 3...

真实用例：
  SECTIONNUM 递增
  PRIORITY 递增
```

### 算子 7：条件拆分 `EXPAND`
```
输入：2g;4g;5g
规则：EXPAND(sep=;)
输出：[2g, 4g, 5g]（每个开一个新实例）

真实用例：
  制式列拆成多实例
```

## 规则文件格式（YAML）

```yaml
# derive_rules.yaml
# 每个工单的派生规则由 agent 生成，但只能从上面的算子库选用

templates:
  POOLGROUP#T:
    POOLGRPNAME:
      source: $CSV.池组名
      ops: []                          # 原样

  POOL#T:
    POOLNAME:
      source: $CSV.池组名
      ops:
        - PREFIX_REPLACE: {old: grp, new: pool}

  POOLGRPMAP#T:
    MAPPINGNAME:
      source: $CSV.池组名
      ops:
        - PREFIX_REPLACE: {old: grp, new: map}
        - CONCAT: {cols: [{{制式}}], sep: -}
    LOCATIONGRPTYPE:
      source: $CSV.制式
      ops:
        - MAP: {2g: LAC, 4g: TAC, 5g: TAC, default: TAC}
    LOCATIONGRPNAME:
      source: $CSV.区
      ops:
        - CONCAT: {cols: [区, {{制式}}], sep: -}

expand:
  by: $CSV.制式
  sep: ';'
```

## 校验机制

```
1. 算子合法性：agent 只能用算子库里的名字，代码校验，不认识就报错
2. 结果可验证：展开后跑 G21（csv ↔ mml 一致）+ C2（引用闭合）
3. 抽样对比：展开结果 vs EXP 里同类对象的命名规律
```

## 为什么这样不依赖模型

| 环节 | 谁做 | 是否确定性 |
|---|---|---|
| 算子实现 | 代码 | ✅ 确定性 |
| 算子选择 | agent（填 YAML） | ⚠️ 模型决策，但受限于固定算子集 |
| 算子执行 | 代码 | ✅ 确定性 |
| 结果校验 | 代码 | ✅ 确定性 |

**关键：agent 只在「有限算子集」里选，不能自创语法。选错会导致校验失败，而不是产生难查的错误。**
